# YulongDa - TK103

<div className="device-logo">
![TK103](./logo.jpg)
</div>

The YulongDa TK103 is a compact vehicle GPS tracker designed for location monitoring and basic vehicle security applications. It supports global GSM frequency bands and operates across a wide DC 9 24V input range for compatibility with many vehicle types. The device includes a built in vibration sensor for anti theft alerts, ACC ignition detection for engine status notifications, an external SOS button for emergencies, and a built in backup battery so it can continue reporting if main power is removed. Optional accessories such as an external relay, microphone, and loudspeaker extend security and monitoring capabilities.

As a Plaspy compatible model, the TK103 can transmit location and status data into Plaspy for centralized visibility and fleet oversight. When paired with Plaspy the tracker’s alerts and position updates become part of a unified monitoring workflow, enabling fleet managers and vehicle owners to see real time locations, receive event notifications, and run operational reports. Compatibility with Plaspy makes the TK103 a practical choice for organizations seeking straightforward tracking and alerting without complex integration work.

## Key Highlights

- Global GSM quad band support for broad coverage and international use
- Wide voltage range DC 9 24V for compatibility with common vehicle power systems
- Built in vibration sensor for anti theft movement detection and tamper alerts
- ACC ignition detection to report engine on and off status events
- External SOS button for user initiated emergency alerts
- Built in backup battery to maintain reporting if main power is cut
- Optional external relay and audio accessories to support immobilization and voice monitoring

## How It Works with Plaspy

The TK103 sends position updates and event notifications which Plaspy ingests to provide map based visibility, alerting, and reporting. Within Plaspy the device can be managed alongside other trackers so organizations get a single view of assets and operational history.

- Real time location display on Plaspy maps to monitor vehicle movement
- Event alerts such as vibration tamper warnings ACC changes and SOS buttons delivered into Plaspy notifications
- Fleet level dashboards and historical reports to analyze trips and activity patterns
- Centralized device listing for status checks battery and connectivity overview
- Grouping and filtering of vehicles to support operational oversight and dispatch

## Typical Use Cases

- Personal vehicle tracking and theft deterrence for cars and motorcycles
- Small to medium fleet monitoring for delivery or service vehicles
- Rental and shared vehicle oversight to track usage and security events
- Remote emergency alerting for drivers using the SOS button
- Asset concealment and discreet monitoring thanks to a compact form factor
