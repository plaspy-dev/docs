# YulongDa - TK103

![TK103](./logo.jpg)

The YulongDa TK103 GPS tracker is a versatile and reliable device that offers a range of useful features for tracking and monitoring vehicles. With its GSM quad-band frequency, it can be used globally, making it suitable for various applications. The tracker has a wide input voltage range of DC 9-24V, ensuring compatibility with different types of vehicles. 

One of the standout features of the TK103 is its built-in vibration sensor, which provides smart anti-theft functionality. This sensor detects any unauthorized movement or tampering with the vehicle and sends an alert to the user. Additionally, the tracker has ACC ignition detection, allowing users to receive notifications about the vehicle's status, such as when the engine is turned on or off.

For emergency situations, the TK103 is equipped with an external SOS button, which can be used to send distress signals in case of an emergency. The device also has a built-in backup battery, ensuring that it can continue to function and send alarms even if the main power is cut off. 

The TK103 offers optional accessories such as an external relay, which can be used to remotely cut off engine power or oil, enhancing security measures. It also supports an external microphone for voice monitoring and an external loudspeaker for phone calls or alarms.

Technical Specifications:
- GSM frequency: 900/1800MHz or 850/1900MHz
- GPRS: Class12, TCP/IP
- Voltage range: DC 9-24V
- Standby Current: ≈0.2mA
- Power Consumption: 0.5w/h
- GPS initialization: Cold boot 38s \(Open sky\), Warm boot 2s \(Open sky\)
- GPS Accuracy: 10m \(2D RM\)
- Working Temperature: -2℃ to +70℃
- Working Humidity: 20%-80%RH
- Dimension: 80.0\(L\)\*65.0\(W\)\*25.0\(H\)mm
- Net weight: 133g

With its compact size and lightweight design, the TK103 is easy to install and conceal, making it suitable for various tracking and monitoring applications. Whether you need to keep an eye on your personal vehicle or manage a fleet of vehicles for your business, the YulongDa TK103 GPS tracker offers the features and reliability you need.
