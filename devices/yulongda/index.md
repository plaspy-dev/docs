## How YulongDa devices work with Plaspy

Plaspy connects to compatible YulongDa devices using standard GPS tracking protocols and common cellular data reporting methods. Once a device is configured to report to Plaspy, the platform receives location and status updates so you can view real time positions, historical tracks, and telemetry in the Plaspy dashboard.

This brand page is intended to help you confirm compatibility and find device model pages and setup guides within Plaspy. Device specific configuration and APN settings belong on each device model page rather than here.
