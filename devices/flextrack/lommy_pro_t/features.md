# Flextrack - Lommy Pro T Features

This page provides a public, non sensitive overview of the Flextrack Lommy Pro T feature set as it relates to use with Plaspy. It focuses on practical capabilities, how telemetry and location data flow into Plaspy, and what operators can expect when deploying Lommy Pro T for cold chain visibility and asset tracking.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The content below is derived from the supplied device description and highlights supported capabilities without replacing the official manufacturer documentation.

## Feature Overview

Lommy Pro T is a temperature monitoring and GPS tracker designed for continuous cold chain oversight of temperature sensitive and high value shipments. Its combination of high precision temperature telemetry and location reporting helps teams document storage conditions while maintaining asset location awareness in transit.

- High precision temperature telemetry for continuous monitoring of cold chain conditions
- Combined GPS positioning and GSM triangulation for improved location availability
- Continuous 24 7 data logging to produce auditable temperature records
- Immediate alarm notifications when configured temperature thresholds are exceeded
- Flexible power options including internal battery plus ability to leverage external power sources
- Adaptable installation for refrigerated boxes, containers, freezer rooms and vaccine carriers

## Core Features of Flextrack - Lommy Pro T

- Continuous temperature logging with timestamped records for audit and compliance
- Wide measurement range suitable for demanding cold chain applications
- GPS positioning combined with GSM triangulation for dual location capability
- Real time alarm generation for temperature excursions and other configured events
- Internal battery with option to use external cooling unit power for uninterrupted operation
- Plaspy compatible open API integration for telemetry, location and event streaming
- Adaptable form factor allowing stand alone use or integration into refrigerated units

## How These Features Work with Plaspy

When connected, Lommy Pro T streams temperature readings, event alarms, and location updates into Plaspy so operators can monitor conditions centrally. Plaspy automatically detects supported tracker protocols and ingests telemetry into the platform for visualization, alerting and archival.

- Live map visualization of position updates and location history inside Plaspy
- Temperature charts and time series logs available for review and export
- Immediate alarm routing for configured temperature threshold breaches to notify teams
- Historical trail and secure documentation storage for regulatory evidence and audits
- Remote configuration and management of reporting intervals and alert recipients through the device API integration
- Combined visibility of location and environmental telemetry to support corrective action workflows

## Typical Use Cases

- Long distance refrigerated container and trailer monitoring with real time alerts
- Cold storage rooms and warehouses where continuous temperature records are required
- Portable vaccine carriers and last mile delivery monitoring during outreach campaigns
- Asset protection and recovery using GPS and GSM based positioning for missing units
- Regulatory compliance and forensic analysis of temperature excursions and handling
