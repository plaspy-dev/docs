# Flextrack - Lommy Pro Features

This page describes the public feature context for using the Flextrack Lommy Pro tracker with Plaspy. It summarizes practical capabilities, typical uses, and how Lommy Pro reports location and telemetry into Plaspy for fleet management, anti theft monitoring, and asset oversight. The content focuses on features that are relevant to Plaspy users and does not replace manufacturer documentation.

Exact feature availability and behavior can vary by device firmware version, hardware revision, chosen accessories, and installation type. Deployment specifics such as wired vehicle fits versus autonomous battery deployments, accessory options, and regional cellular variants can change what features are present or enabled on any given unit.

## Feature Overview

Lommy Pro is a compact, power aware tracker designed to deliver continuous GNSS positioning and vehicle telemetry to Plaspy for live mapping, historical routes, and automated alerts. It is built for mixed installations where either a wired power source or an internal backup battery may be used, and it exposes a set of vehicle grade interfaces and configurable sleep modes to balance reporting needs with battery life.

- Multi constellation GNSS positioning for reliable location fixes in varied environments.
- Dual cellular connectivity with LTE Cat M1 and GSM for broad telemetry reporting and remote commands.
- Internal rechargeable Li Ion backup battery plus configurable sleep modes for battery backed deployments.
- Built in movement sensing and event detection for trip logging, overspeed and idling detection.
- Vehicle interfaces including CAN and serial inputs along with analog and digital I O for telemetry and sensors.
- Expandable accessory support such as RF beacons and external temperature sensors for environmental monitoring.

## Core Features of Flextrack - Lommy Pro

- Multi constellation GNSS support to improve positioning reliability across regions.
- LTE Cat M1 and GSM connectivity to deliver position and telemetry to Plaspy in real time.
- Internal rechargeable Li Ion backup battery with power management and configurable sleep modes.
- Movement sensing and trip logging for accurate tracking of journeys and odometer style records.
- Overspeed detection and idling monitoring for operational alerts and efficiency reporting.
- Immobilizer control and start stop detection to support anti theft workflows.
- Vehicle grade interfaces including CAN J1939 and serial connections plus analog and digital inputs and a configurable digital output.
- Support for remote configuration and firmware updates to streamline device maintenance.

## How These Features Work with Plaspy

Lommy Pro reports GNSS fixes and telemetry to Plaspy using standard tracker reporting methods. Plaspy ingests position and vehicle telemetry, normalizes the data, and exposes it through maps, timeline replay, alerts, and reporting tools so fleets and asset owners can act on events and trends.

- Live maps and position updates in Plaspy based on GNSS fixes from the device.
- Telemetry and vehicle data such as CAN and analog inputs appear in Plaspy dashboards for monitoring and historical analysis.
- Alerts and rules in Plaspy can trigger on events like overspeed idling or temperature thresholds and notify operators through configured channels.
- Remote commands and immobilizer actions can be delivered from Plaspy back to the device where supported by the device firmware and network.
- Remote configuration and firmware management are supported to help maintain device settings and updates across a fleet.

## Typical Use Cases

- Fleet management with live tracking, trip history, and utilization reporting.
- Anti theft and immobilizer workflows that use start stop detection and remote command capabilities.
- Fuel and engine telemetry monitoring via CAN and analog inputs for consumption analysis.
- Temperature and door sensor monitoring for refrigerated trailers and conditioned cargo.
- Battery backed asset tracking for trailers, equipment, and boats where mains power may be absent.
- Mixed installation environments where the same device model is used both wired in vehicles and as autonomous units.

## Feature Availability Notes

- Feature set can depend on installed firmware version and manufacturer firmware features enabled on each unit.
- Some capabilities require specific accessories or wiring such as external sensors, RF beacons, or particular vehicle interfaces.
- Regional cellular band support and regulatory variants can affect connectivity options and should be checked for your deployment region.
- Installation type matters: wired vehicle installs may enable more continuous telemetry compared with strictly battery powered configurations.
- Always consult the manufacturer documentation and release notes for the particular hardware revision and firmware you plan to deploy.

## Why Use Plaspy with These Features

Using Lommy Pro with Plaspy provides a practical route to centralized visibility and operational oversight across vehicles and mobile assets. Plaspy can ingest location and vehicle telemetry from the tracker, present it in real time on maps and timelines, and let teams build alerts and reports that match their operational needs. The combination of multi constellation GNSS, cellular connectivity, vehicle interfaces, and battery backed operation makes Lommy Pro useful for mixed fleets that require both wired and autonomous deployments.
