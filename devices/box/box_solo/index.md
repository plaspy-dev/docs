# Box - Box Solo

![Box Solo](./logo.jpg)

The Box Solo is a trailer tracking unit engineered to continuously log trailer position and report that data for fleet oversight. It pairs high sensitivity GPS receivers with quad band GSM GPRS communication to provide ongoing location records and remote data transmission. The device is built for durability and compliance, meeting Vehicle Certification Agency approval and EMC FCC UL standards, and is configured for use in US GSM bands including 850 and 1900 MHz.

As a Plaspy compatible device, the Box Solo can feed reliable position reports and status data into Plaspy for centralized visibility. Its design and feature set make it suitable for organizations that need persistent trailer location history, straightforward telemetry capture, and streamlined inclusion into a fleet tracking platform such as Plaspy.

## Key Highlights

- Continuous trailer position logging using sensitive GPS reception for consistent tracking
- Quad band GSM GPRS connectivity for remote data transmission across supported networks
- Approved and compliant design with VCA approval and EMC FCC UL conformity for markets that require certification
- Built in backup battery and internal memory to help preserve tracking data during interruptions
- Compact and durable casing intended for trailer environments and routine fleet operations
- Practical installation approach and basic inputs for integration with trailer wiring and simple sensors

## How It Works with Plaspy

When connected into a tracking workflow, the Box Solo provides position and basic status data that Plaspy can present within its fleet management tools. Plaspy ingests the device data to give operators a consolidated view of trailer locations and activity, allowing consistent monitoring alongside other assets.

- Real time and historical location visibility for trailers within the Plaspy platform
- Fleet level monitoring and map view to track trailer movements and stationary status
- Alerts and event notifications based on position or device reported conditions
- Reporting and exportable location history for audits, route analysis, and operational review
- Operational oversight for trailer allocation, recovery, and logistics planning

## Typical Use Cases

- Trailer asset recovery and theft deterrence monitoring
- Rental and leasing companies monitoring trailer usage and location
- Intermodal trailer visibility for yard management and dispatch coordination
- Fleet managers consolidating trailer telemetry alongside powered vehicles
