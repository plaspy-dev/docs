# Supermate - D12 Features

This page describes the public feature context for using the Supermate D12 GPS tracker with Plaspy. It summarizes the model's practical capabilities, how those capabilities appear inside Plaspy, and common operational scenarios where the device can add value. The content is intended for readers researching device functions and Plaspy compatibility rather than for detailed configuration instructions.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where relevant, this page highlights practical implications of those variations and encourages verification against the manufacturer documentation and current device firmware notes.

## Feature Overview

The Supermate D12 is positioned as a compact, user friendly tracker for asset management and personal safety. It emphasizes live location reporting, boundary alerts, and a simple emergency alert function, making it useful across vehicle, equipment, and personal use cases.

- Real time location reporting to enable continuous monitoring of assets
- Geo fencing capability to set geographic boundaries and receive entry or exit alerts
- SOS button for one touch emergency alerting
- Compact and lightweight design for discreet placement on a wide range of assets
- Sturdy construction and tolerance for varied environmental conditions

## Core Features of Supermate - D12

- Real time tracking updates to report current position for ongoing visibility
- Geo fencing support that can trigger alerts when a device crosses predefined boundaries
- Dedicated SOS button to send an immediate alert for emergency situations
- Compact, lightweight form factor for discreet installation on assets
- Straightforward, user friendly installation for a broad range of users
- Durable build with design considerations for operational humidity and temperature ranges
- Support for GSM network frequency bands and high GPS sensitivity to maintain location reporting

## How These Features Work with Plaspy

Plaspy provides a platform view of the D12's publicly documented capabilities so organizations can monitor locations, boundary events, and emergency signals alongside other fleet or asset data. Plaspy automatically detects the tracker protocol and accepts device reports on the standard Plaspy port, allowing the D12 to deliver its core events into the Plaspy system for visualization and alerting.

- Live location updates from the D12 appear on Plaspy maps for position awareness and tracking history
- Geo fence entry and exit events are shown as configurable alerts inside Plaspy for operational oversight
- SOS activations are surfaced as priority events so teams can review last known position and recent movement
- Device connectivity and reporting status are visible in Plaspy so administrators can identify when a unit is offline or unable to report
- Plaspy receives standard location and event reports from compatible trackers and provides consolidated views for mixed-device fleets

## Typical Use Cases

- Fleet tracking for light commercial vehicles and asset visibility during operations
- Portable asset protection where discreet placement and low impact on the asset are important
- Personal safety monitoring using the SOS button for quick alerting of an emergency
- Equipment oversight on job sites where compact trackers are required for transportable items
- Remote location awareness when assets move between sites or regions

## Feature Availability Notes

- Firmware version and manufacturer configuration can affect which features are enabled and how alerts are reported
- Hardware revisions or regional variants may use different GSM frequency sets that influence connectivity in some areas
- Installation method and placement can change GPS reception and reporting performance
- Some behaviors such as alert timing, retry logic, and event formatting are controlled by device firmware and server-side settings
- Always consult manufacturer documentation for device specific limitations or configuration options
