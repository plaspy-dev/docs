# Supermate - D11 Features

This page describes the public feature context for using the Supermate D11 GPS tracker with Plaspy. It summarizes the D11's practical capabilities, explains how those capabilities map into visibility and monitoring inside Plaspy, and helps you understand where the device fits in common tracking workflows.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation type, and the manufacturer's implementation. For the most current device specific details consult the official Supermate documentation and release notes.

## Feature Overview

The Supermate D11 is presented as a compact, portable tracker designed for general purpose asset and personal tracking. It focuses on straightforward installation, reliable location reporting, and core safety functions useful for both personal and fleet scenarios.

- Real time location tracking for continuous visibility of assets and people
- Geo fencing support to define boundaries and receive entry or exit alerts
- Emergency SOS button to send immediate alerts when needed
- Lightweight discreet form factor that is easy to place on assets or carry
- Designed for wide environmental tolerance and durable daily use

## Core Features of Supermate - D11

- Real time GPS tracking for location updates and ongoing visibility
- Geo fencing capability to create geographic zones and trigger alerts
- Emergency SOS button for immediate alerting in critical situations
- Compact and lightweight design for discreet placement and portability
- Compatibility with a range of power inputs for flexible installation
- High GPS sensitivity to improve positioning in challenging areas
- Multi band GSM compatibility intended for broad cellular coverage
- Robust construction designed for everyday durability

## How These Features Work with Plaspy

When a D11 is used with Plaspy, its location and event reports are processed and presented within Plaspy's tracking platform so teams can monitor assets and respond to events efficiently.

- Live position updates shown on Plaspy maps for location awareness
- Geo fence events appear as alerts or notifications in Plaspy so you can act on boundary breaches
- SOS events from the D11 are surfaced as high priority alerts within Plaspy for rapid attention
- Historical location history and playback let you review past movements and routes
- Device labeling and grouping in Plaspy help organize trackers by asset type or fleet
- Plaspy automatically detects supported tracker protocols and integrates reported events into the platform for monitoring and reporting

## Typical Use Cases

- Vehicle fleet tracking for operational oversight and route visibility
- Asset protection for portable equipment, tools, and high value items
- Personal security use to monitor the location of family members or lone workers
- Rental equipment monitoring to track location and usage history
- Temporary deployments where discreet and portable tracking is required
- Logistics and delivery visibility for basic location and route monitoring

## Feature Availability Notes

- Firmware differences can affect which features are available and how alerts behave

- Installation method and wiring can influence which functions are active in a given deployment
- Manufacturer settings and configuration can enable or disable features such as SOS or geo fencing
- Always check the device label and documentation for the exact model and revision you have
