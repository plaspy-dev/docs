# Supermate - D12-G Features

This page provides a public, non-sensitive summary of the Supermate D12-G tracker features as they relate to use with Plaspy. It summarizes the device capabilities described by the manufacturer and explains how those capabilities are commonly used inside Plaspy for visibility, monitoring, and basic event handling.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device-specific configuration, advanced behavior, or the latest technical details consult manufacturer documentation and firmware release notes.

## Feature Overview

The Supermate D12-G is described as a compact GPS tracker intended for asset management and personal security. It emphasizes real time location reporting, perimeter alerts, and a manual emergency alert function while being designed for straightforward installation and discreet placement.

- Real time location updates for continuous tracking of mobile assets and vehicles
- Geo-fencing capability to define geographic boundaries and receive entry or exit alerts
- SOS button to send an immediate alert in emergency situations
- Compact and lightweight design for discreet mounting on a wide range of assets
- High GPS sensitivity intended to improve location accuracy in dense urban areas

## Core Features of Supermate - D12-G

- Real time GPS tracking to report live position information
- Geo-fencing with alerts when configured boundaries are crossed
- Dedicated SOS button for manual emergency alerts
- Compact form factor for discreet placement and easy installation
- High sensitivity GPS reception for improved performance in built environments
- Designed for durability and compliance with international safety and efficiency standards
- Adaptable power input and support for multiple frequency bands for broader regional network compatibility

## How These Features Work with Plaspy

Plaspy provides a platform layer that receives and presents positional and event information from compatible trackers such as the Supermate D12-G. Data reported by the tracker becomes visible in Plaspy for map display, alerting, and review.

- Live location points appear on Plaspy maps so operators can monitor asset position in near real time
- Geo-fence events reported by the tracker surface as alerts in Plaspy and can be used to trigger notifications or workflow actions
- SOS alerts from the device are shown in Plaspy as distinct events to help operators prioritize emergency responses
- Historical position data sent by the tracker is retained in Plaspy for route review and operational analysis
- Plaspy can accept connections from devices to the platform domain and can auto-detect supported tracker protocols to simplify onboarding
- Devices may be configured to use common transport options accepted by Plaspy for data delivery

## Typical Use Cases

- Fleet location monitoring and basic perimeter control for vehicles
- Asset security for high value portable equipment or freight
- Personal safety tracking where an SOS alert provides a manual emergency signal
- Remote visibility for rental equipment and shared assets
- Urban tracking scenarios that benefit from enhanced GPS sensitivity

## Feature Availability Notes

- Functionality such as geo-fence behavior and SOS handling depends on the device firmware and how the device is configured at installation
- Hardware revisions and regional variants can affect supported frequency bands and network compatibility
- Installation type and mounting location influence GPS reception and the practical accuracy of location reports
- Manufacturer firmware updates can add, change, or refine device features over time
- For precise technical parameters consult the Supermate product documentation and release notes

Using Plaspy with a device like the Supermate D12-G provides a unified view of position and event data so teams can monitor assets, respond to alerts, and review historical movement in one place.
