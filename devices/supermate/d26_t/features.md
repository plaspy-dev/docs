# Supermate - D26-T Features

This page provides a public feature overview for the Supermate D26-T and describes how its capabilities map to monitoring and management inside Plaspy. It covers the practical, non sensitive functions you can expect when using the D26-T with Plaspy and highlights the kinds of visibility and operational value the device can deliver.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a high level guide and verify specific functionality against device firmware notes and the official Supermate documentation.

## Feature Overview

The Supermate D26-T is positioned as a versatile, compact GPS tracker suitable for personal and commercial applications. It is built for straightforward installation and continuous location monitoring, and it provides several user facing features that support asset oversight and safety monitoring.

- Real time tracking for ongoing location visibility of assets and vehicles
- Geo fencing to define areas and receive entry and exit notifications
- Emergency SOS button for urgent alerting when immediate attention is required
- Compact and lightweight design for discreet placement on a wide range of assets
- High GPS sensitivity and multi band network support to improve location reliability

## Core Features of Supermate - D26-T

- Real time location reporting to support continuous monitoring

- Compact form factor for flexible and discreet installation

- Rugged construction and wide operating temperature support for daily use
- Multi band GSM compatibility for broad mobile network coverage
