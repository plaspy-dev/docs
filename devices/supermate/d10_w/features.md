# Supermate - D10-W Features

This page describes the public feature context for using the Supermate D10-W tracker with Plaspy. It focuses on the practical capabilities visible to users when the device is used with the Plaspy platform and explains how those capabilities support location awareness, alerting, and asset oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. For device specific technical details and the latest firmware notes consult the official manufacturer documentation.

## Feature Overview

The Supermate D10-W is presented as a compact GPS tracker aimed at personal, commercial, and industrial use. In Plaspy, its core benefits translate into continuous location visibility, boundary monitoring, and an emergency alert option intended to increase operational safety and asset control.

- Real time tracking for continuous location updates and live monitoring
- Geo fencing to define areas and receive boundary alerts
- Emergency SOS button for immediate alerting in critical situations
- Compact lightweight form factor for discreet placement on mobile assets
- Multi band GSM connectivity and power flexibility to support varied installations

## Core Features of Supermate - D10-W

- Real time position reporting to support live monitoring of assets
- Geo fencing capability to set virtual boundaries and receive alerts
- Emergency SOS button for immediate alert generation and notification
- Compact and lightweight design for discreet installation on many asset types
- User friendly installation intended to simplify field deployment
- Multi band GSM support for compatibility with common cellular networks
- Robust design characteristics aimed at daily operational use

## How These Features Work with Plaspy

When a D10-W is added to Plaspy, the device's broadcasted location and alert events are integrated into Plaspy views to provide operational context and oversight. Plaspy detects compatible tracker protocols automatically and accepts reports from devices configured to send data to the Plaspy server domain.

- Live location updates appear in Plaspy maps and tracking panels for continuous visibility
- Geo fence events are represented as area alerts so teams can monitor entry and exit activity
- SOS activations are ingested as high priority events to notify operators and trigger workflows
- Device status and recent communication are shown in Plaspy so you can confirm connectivity
- Grouping and labeling in Plaspy helps organize multiple D10-W units across fleets or asset categories
