# Supermate - D11-G Features

This page provides a public feature overview for the Supermate D11-G and how its capabilities map to Plaspy for everyday tracking, monitoring, and oversight. It summarizes practical, non-sensitive information about what the D11-G can do when used with Plaspy and highlights the kinds of visibility and alerts you can expect at a high level.

Exact feature availability for any specific unit can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For definitive, device-specific behavior refer to the manufacturer's documentation and verify firmware details where needed.

## Feature Overview

The Supermate D11-G is presented as a compact, portable GPS tracker designed for asset management, personal safety, and light fleet use. Its combination of real-time location, configurable boundary alerts, and an emergency alert function make it useful for a wide range of monitoring tasks.

- Real time tracking for continuous location visibility of assets and people.
- Geo fencing support to define geographic boundaries and receive entry or exit alerts.
- Emergency SOS alert button for immediate notification when assistance is required.
- Lightweight and compact form factor for discreet placement on portable assets.
- Broad network compatibility and multiple power input options for flexible installation.
- Durability and wide temperature tolerance for reliable operation in varied conditions.

## Core Features of Supermate - D11-G

- Real time location reporting to allow ongoing position awareness.
- Geo fence functionality for setting virtual perimeters and receiving alerts.
- Dedicated SOS alert to notify a monitoring platform or contacts in emergencies.
- Compact, portable design to enable discreet installation on many asset types.
- Multiple power input compatibility to support varied installation environments.
- Environmental tolerance aimed at reliable operation across typical temperature ranges.
- Durable construction intended for daily use and routine handling.

## How These Features Work with Plaspy

When the D11-G is used with Plaspy, the device's location updates and event signals are reflected in the Plaspy platform to support monitoring, alerts, and operational workflows. Plaspy automatically detects compatible tracker protocols so setup is streamlined for deployment at scale.

- Real time position updates appear on Plaspy maps for live tracking and route review.
- Geo fence events from the device generate entry and exit notifications inside Plaspy.
- SOS alerts reported by the D11-G surface as high-priority events for immediate attention.
- Device status and recent activity are displayed in Plaspy device lists for quick oversight.
- Plaspy centralizes alerts and historical location data so teams can review incidents and trends.

Note: Plaspy detects supported protocols and accepts device reports; specific configuration steps and available event fields can depend on the device firmware and settings.
