# Supermate - D10-T Features

This page describes public feature information for the Supermate D10-T and how those capabilities integrate with Plaspy for location visibility and alerting. It focuses on practical, non-sensitive details about what the tracker can do and how those functions typically appear when used with Plaspy.

Exact feature availability and behaviour can vary by firmware version, hardware revision, installation method, and how the manufacturer implements specific functions. For the latest device-specific details consult the manufacturer documentation and firmware notes.

## Feature Overview

The Supermate D10-T is a compact, lightweight GPS tracker designed for a range of personal, commercial, and industrial tracking needs. It emphasizes unobtrusive installation, continuous location reporting, and basic alerting features to support asset monitoring and safety workflows.

- Real time location reporting for continuous visibility of tracked assets
- Geo fencing support to define boundaries and receive entry or exit alerts
- Emergency SOS button to trigger immediate alerts when pressed
- Compact and lightweight form factor for discreet placement on assets
- Support for global GSM frequency bands and high GPS sensitivity for urban tracking

## Core Features of Supermate - D10-T

- Real time tracking that provides frequent location updates for live monitoring
- Geo fencing capability to create virtual boundaries and notify on crossings
- Emergency SOS button to send an immediate alert in urgent situations
- Compact and lightweight design for flexible placement on vehicles or personal items
- User friendly installation intended to simplify deployment without specialized tools
- Support for multiple GSM frequency bands to enable broad network compatibility
- High GPS sensitivity to improve position fixes in challenging urban environments
- Flexible power input options to accommodate different installation environments

## How These Features Work with Plaspy

When connected to Plaspy, the D10-T’s location and event messages become part of a centralized monitoring view where live position, alerts, and device status are visible to authorized users. Plaspy automatically detects supported tracker protocols and consolidates device reports for consistent display and alerting.

- Live location updates appear on Plaspy maps to support route monitoring and asset tracking
- Geo fence events can be surfaced as alerts within Plaspy for entry and exit monitoring
- SOS events from the device are presented as immediate alerts to enable rapid response
- Device identity and compact form factor make it easy to tag assets and manage inventory in Plaspy
- Plaspy accepts tracker reports using standard connection methods and detects the device protocol automatically, allowing straightforward integration
- Plaspy centralizes alerts and location history so teams can review events and operational patterns
