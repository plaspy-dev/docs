# Supermate - D26-H Features

This page provides a public feature overview for the Supermate D26-H as it is used with Plaspy. It summarizes the practical capabilities you can expect to see reported into Plaspy for monitoring and management, and highlights how the tracker’s functions map to common visibility and operational needs on the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, how the device is installed, and the manufacturer implementation. Use this page as a practical, non-sensitive guide and consult the device manufacturer for the latest, device specific technical details.

## Feature Overview

The Supermate D26-H is a compact, lightweight tracker designed for versatile placement and simple installation. Its core value is continuous location awareness combined with user-facing features that support asset monitoring, personal safety, and fleet oversight.

- Real-time tracking for continuous location updates and operational awareness
- Geo-fencing capability to define areas and detect entry and exit events
- Emergency SOS button for immediate alerting in urgent situations
- Compact and lightweight form factor for discreet placement on many asset types
- High GPS sensitivity for improved position accuracy in challenging environments
- Designed to operate across a range of voltages and environmental conditions

## Core Features of Supermate - D26-H

- Real-time location reporting suitable for live monitoring and historical playback

- Emergency SOS alerting to notify responders or operators of urgent events
- Compact, lightweight design for easy and discreet installation on assets

- Durable construction intended for everyday use and varied environments
- Support for a range of input voltages enabling global deployment options

## How These Features Work with Plaspy

Plaspy receives and surfaces the device reports so teams can monitor locations, review events, and respond to alerts from a single platform. The D26-H’s capabilities translate into visible elements in Plaspy that help with operational decision making.

- Live location updates appear on Plaspy maps for tracking and route review
- Geo-fence entry and exit events are shown as alerts or timeline events inside Plaspy
- SOS notifications from the device can be highlighted in the Plaspy alert stream for rapid attention
- Compact placement and discreet form factor make it easier to track a wider variety of assets in Plaspy without invasive installation
- Plaspy automatically detects supported tracker protocols and supports common network transport options so the device can report into the platform with minimal manual configuration
