# GOTOP - L17 Features

This page provides a public overview of the GOTOP L17 feature set as it relates to using the device with Plaspy. It focuses on practical, non-sensitive information about capabilities you can expect to surface in Plaspy for monitoring, alerts, and historical reporting when the L17 is configured to report to the platform.

Exact feature availability and behavior can vary by firmware release, hardware revision, regional variant, and how the device is installed or provisioned. For the most current and device-specific details, consult the manufacturer documentation and firmware release notes from GOTOP in addition to this Plaspy-focused feature summary.

## Feature Overview

The L17 is a compact 4G GPS smart bracelet designed for continuous personal use. Its combination of GNSS positioning, cellular connectivity, wearable form factor, and onboard health sensors provides a practical mix of location awareness, emergency alerting, and basic health telemetry for everyday monitoring.

- Real-time GNSS location reporting for live tracking and history in Plaspy
- One-touch SOS alerting with two-way calling for immediate response coordination
- Onboard health telemetry including heart rate, SpO2, blood pressure, and temperature for situational awareness
- Optional BLE support to extend short-range sensor or beacon data to the device
- IP67 wristwatch form factor suitable for continuous personal wear and daily activities

## Core Features of GOTOP - L17

- GNSS positioning module providing regular location fixes for tracking
- 4G LTE cellular connectivity with GSM fallback for wide area reporting
- SOS button for instant emergency alerts
- Two-way voice calling to enable direct communication with responders
- Health sensors including heart rate, SpO2, blood pressure, and temperature
- Accelerometer based activity and fall detection for motion event reporting
- Nano SIM and eSIM compatibility for flexible cellular provisioning
- IP67 rated wearable design for everyday use

## How These Features Work with Plaspy

When an L17 is connected to cellular service and configured to report to Plaspy, its location and telemetry streams feed into Plaspy dashboards and alarms so teams can monitor status and respond to events.

- Real-time location points appear on Plaspy maps and feed route history for review
- SOS button presses generate immediate alerts that can be surfaced to operators and responders inside Plaspy
- Health telemetry such as heart rate, SpO2, blood pressure, and temperature are available for monitoring and can be used to trigger alerts
- Activity and fall detection events are reported as status updates or alarms for rapid attention
- Optional BLE sensor data paired to the device can be relayed and viewed alongside location and event history
- Plaspy automatically detects compatible tracker protocols and integrates L17 data into its tracking and alarm engine

## Typical Use Cases

- Child safety monitoring with wrist-mounted location and SOS capability for parents and guardians
- Elderly health and fall monitoring where caregivers need both position and basic vital telemetry
- Lone worker protection using compact wearable alerts and two-way voice for rapid assistance
- Personal anti-theft and traveler security with continuous location and emergency functions
- Short-range sensor or beacon monitoring when BLE peripherals extend local telemetry to Plaspy

## Feature Availability Notes

- Some features such as BLE peripherals, eSIM, or specific sensor models may depend on the device hardware revision or regional SKU
- Firmware versions can change telemetry formats, update reporting intervals, and add or remove specific alarm behaviors
- Installation and provisioning (for example SIM choice and cellular plan) affect connectivity and reporting reliability
- Manufacturer configured settings or carrier restrictions can influence two-way calling and cellular roaming behavior
- Verify device capabilities and supported firmware features by consulting GOTOP documentation for your specific L17 unit
