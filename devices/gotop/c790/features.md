# GOTOP - C790 Features

This page provides a public feature overview for the GOTOP C790 GPS tracker and how its capabilities are used with the Plaspy fleet management platform. Content here focuses on user facing features and practical functions that can be expected when pairing a C790 device with Plaspy for location monitoring, event visibility, and basic remote control.

Exact feature availability and behavior depend on device firmware, hardware revision, installation method, and manufacturer implementation. Read this overview as a general guide grounded in the publicly available product description and always verify device specific details against the manufacturer documentation for the current revision.

## Feature Overview

The GOTOP C790 is a compact vehicle tracker that combines satellite positioning and mobile data communication to provide real-time location and basic vehicle control functions. It is designed for vehicle tracking and security use cases and can integrate with Plaspy for centralized monitoring and history review.

- Real time satellite positioning using GPS and Beidou for continuous location updates
- GPRS based data communication to report position and alerts to a tracking platform
- Remote fuel cut off and control of the vehicle oil and electricity switch via mobile command
- ACC detection to monitor ignition status and support event driven reporting
- Alarm inputs including vibration alarm, over speed alarm, and power failure alarm
- SOS button and geofence electric fence alerts with trackable event history up to 180 days

## Core Features of GOTOP - C790

- Satellite positioning with GPS and Beidou to provide location coordinates
- GPRS communication for sending position and alarm reports over mobile networks
- Remote fuel cut off allowing control of the vehicle oil and electricity switch from a remote command
- ACC detection to detect ignition on or off state and trigger reports
- Vibration alarm to detect movement or tampering
- Over speed alarm for speed threshold alerts
- Power failure alarm to report external power loss
- SOS button to signal emergency assistance

## How These Features Work with Plaspy

Plaspy receives the tracker reports and presents them within a shared monitoring interface so teams can see location, alerts, and recent activity from the C790 in one place. Plaspy automatically detects the tracker protocol and ingests location and event messages sent from the device, enabling operational visibility and historical review.

- Real time positions and location updates from the device are shown on Plaspy maps for tracking and dispatch
- Alarm events such as vibration, over speed, SOS, and power loss are logged and can be viewed in event lists
- Remote fuel cut off actions initiated by device commands are visible as control events and can be correlated with location and time
- Geofence electric fence entries and exits are reported and available as alerts in Plaspy
- Driving history retained by the device for up to 180 days can be imported or viewed as trip history through Plaspy reporting
- Plaspy supports device connectivity over common transport methods and automatically detects supported protocols when the tracker reports to d.plaspy.com

## Typical Use Cases

- Vehicle security and recovery where remote fuel cut off and SOS alerts add layers of protection
- Fleet monitoring for businesses that need location awareness, route review, and event logging
- Theft deterrence and intervention using the device ability to disable fuel or electrical supply remotely
- Remote monitoring of ignition state to confirm vehicle usage or unauthorized starts
- Geofence based notifications to track vehicle entry and exit from defined areas
- Historical trip review for compliance, billing, or operational analysis

## Feature Availability Notes

- Some features may vary by firmware version or hardware revision of the C790 device
- Manufacturer configuration and installation practices can change how inputs and remote control functions behave
- Regional variants or carrier configurations can affect GPRS connectivity and reporting frequency
- Verify whether a specific C790 unit is the C790-Y variant and whether that variant includes the exact functions you require
- Consult official manufacturer documentation for hardware pinouts and command details before attempting installation or control integration

Using Plaspy with the GOTOP C790 gives organizations a single platform to centralize device location, alerting, and basic remote control events. Plaspy’s monitoring view and event history make it easier to respond to security incidents, analyze vehicle movement, and maintain operational oversight across a fleet of trackers.
