# GOTOP - G59 Features

This page provides public feature context for using the GOTOP G59 tracker with Plaspy. It summarizes the G59's primary capabilities, how those functions can appear in Plaspy, and practical considerations for pet owners and administrators who want consistent tracking, alerts, and activity visibility through the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional configuration, and manufacturer implementation. Where specific behavior is important for your deployment, confirm current details with GOTOP documentation or firmware release notes before relying on particular functions.

## Feature Overview

The G59 is a compact IP67 waterproof collar tag designed for pet tracking with multi mode positioning and pet oriented features. Its core strengths are continuous outdoor suitability, multiple location sources for improved fixes, voice interaction, and built in pet care features that report status and events to Plaspy for monitoring and history.

- Real time location reporting and SMS location messages with Google Maps links for quick sharing.
- IP67 waterproof construction for rain and temporary immersion during outdoor activity.
- Multi mode positioning using GPS, BeiDou, Wi Fi and LBS to improve location reliability in varied environments.
- Two way voice calling and remote monitoring through a large speaker for direct owner interaction.
- Pet centric tools including sound and light locating, pedometer counts, feeding reminders, geo fence alerts, and low battery notifications.

## Core Features of GOTOP - G59

- 4G LTE real time tracking with SMS location link support for immediate position access.
- IP67 waterproof collar tag form factor optimized for continuous outdoor use.
- Multi mode positioning: GPS and BeiDou GNSS plus Wi Fi and LBS assistance for diverse environments.
- Two way voice calling and remote audio monitoring with a large volume speaker.
- Sound and light locating to help physically locate a pet in proximity.
- Pedometer and feeding reminder functions for basic activity and care prompts.
- Geo fence alerts to notify when a configured boundary is crossed.
- Intelligent power management via a 3D sensor with low battery notifications and quick charging support.

## How These Features Work with Plaspy

Plaspy ingests the G59's reported position and status messages so owners and administrators can see live locations, historical tracks, and alerts in one place. Plaspy automatically detects the tracker protocol and maps incoming messages to device status, event logs, and alerting rules for straightforward monitoring.

- Live location display and position history in the Plaspy dashboard using the device's GNSS and assisted location reports.
- Geo fence events and low battery notices delivered as platform alerts and optional notifications based on user preferences.
- SMS location links remain useful for quick sharing; Plaspy also preserves reported coordinates and timestamps for records and reporting.
- Voice call and monitoring activity is logged as device events so administrators can see call attempts and status in Plaspy.
- Activity telemetry such as pedometer counts and power saving state are represented in device logs to support operational oversight.

## Typical Use Cases

- Daily urban dog walking with reliable location fixes in dense environments using Wi Fi and LBS assistance.
- Outdoor adventures and water play where IP67 waterproofing maintains tracking continuity.
- Rapid recovery for lost or stolen pets using geo fence alerts, live location links, and remote locating features.
- Basic activity monitoring and routine reminders for pet care using pedometer and feeding notifications.
- Shared access scenarios where SMS links provide a quick position to family members or caregivers without app access.
- Remote reassurance through live voice calling when owners want to check on a pet during separation.

- Firmware version can change how certain functions behave or which data fields are reported to Plaspy; check firmware notes for differences.
- Hardware revisions or regional variants may affect cellular bands, network fallbacks, and SMS behavior.
- Installation type and collar fit can influence sensor performance for pedometer and power saving features.
- Manufacturer settings and provisioning (SIM, APN, and regional configuration) determine how the device reports to cloud platforms and sends SMS.
