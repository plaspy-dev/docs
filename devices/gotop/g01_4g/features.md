# GOTOP - G01-4G Features

This page provides a public feature summary for the GOTOP G01-4G GPS tracker and how those features integrate with the Plaspy fleet and asset monitoring platform. It focuses on the practical capabilities you can expect to use in Plaspy for vehicle tracking, alerting, and operational oversight.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation type, and manufacturer implementation. Before deployment, verify the specific firmware build, regional variants, and installation wiring with the manufacturer and your integrator to ensure the G01-4G supports the functions you need.

## Feature Overview

The GOTOP G01-4G is a Plaspy compatible vehicle tracker built for continuous location reporting and vehicle event monitoring. It combines 4G LTE connectivity with SMS fallback, rugged packaging, and vehicle I O to support real world fleet and anti theft workflows.

- Real time GPS tracking over 4G LTE with SMS fallback for continuity in low data coverage
- Configurable geo fence alarms and event reporting for perimeter and location based notifications
- Vehicle telemetry including ACC ignition detection and main power cut alarms to monitor vehicle state
- SOS emergency reporting and listen in microphone plus external speaker support for incident handling
- Remote engine cut control to support immobilization workflows when used with Plaspy
- IP67 rated ABS enclosure and wide operating voltage for automotive and fleet installations

## Core Features of GOTOP - G01-4G

- 4G LTE connectivity with SMS fallback for position and event updates
- Geo fence capability for location based alarms and notifications
- SOS button support and emergency reporting for safety incidents
- ACC ignition detection and digital inputs for vehicle state monitoring
- Remote engine cut function to support anti theft responses
- Vibration and movement alarm reporting for tamper and intrusion detection
- Listen in microphone and external speaker support for audio monitoring
- Rugged IP67 ABS housing and wide operating voltage for vehicle environments

## How These Features Work with Plaspy

When the G01-4G is connected to Plaspy, the device reported locations and event streams are ingested into a centralized monitoring interface. Plaspy normalizes incoming location fixes and alarms so fleet teams can view live status, receive alerts, and generate reports from a single platform.

- Live location and mapping updates appear in Plaspy dashboards for real time tracking
- Geo fence alarms and movement events are surfaced as notifications and event history
- Ignition changes and main power cut detection show vehicle operational state in Plaspy
- SOS and audio related events are flagged for incident response and logged for review
- Remote immobilization commands and other device controls can be issued from Plaspy where supported by the tracker and installation
- Telemetry and external sensor inputs are available in Plaspy reporting if those signals are enabled on the device

## Typical Use Cases

- Fleet operations tracking for cars, taxis, rental vehicles and light trucks with live location and event reporting
- Anti theft workflows using vibration alarms, power cut detection and remote engine cut to recover stolen assets
- Rental vehicle protection with geo fence enforcement and SOS emergency handling
- Driver safety and incident verification using SOS alerts and listen in audio capabilities
- Telematics extensions that use the device I O and serial interfaces to bring additional vehicle data into Plaspy
- Centralized monitoring and historical reporting for compliance and operational analysis

## Feature Availability Notes

- Feature sets can differ by firmware version and the regional hardware variant shipped by the manufacturer
- Some functions require correct wiring and installation such as ACC detection, main power monitoring, and immobilizer outputs
- External peripherals and serial integrations require compatible accessories and correct configuration
- Manufacturer provided specifications should be consulted for regional cellular band support and exact operating voltage ranges
- Plaspy will ingest events and locations from the device but exact field names and telemetry availability depend on the device firmware and configuration

Using the GOTOP G01-4G with Plaspy brings device level location and alarm data into a single platform for visibility and operational control. Plaspy helps translate tracker events into actionable alerts, centralized maps, and historical reports so fleet managers and safety teams can prioritize responses and maintain oversight across vehicles.
