# GOTOP - S7 Features

This page provides a public, features-focused overview of the GOTOP S7 GPS tracker and how its capabilities map into Plaspy for real-time tracking, alerts and historical reporting. The content is intended to help fleet managers, integrators and technical users understand the S7's practical functions when used with Plaspy without diving into device configuration or private implementation details.

Exact availability and behavior of individual features can vary by firmware version, hardware revision, installation method and regional device variants. For precise technical instructions, firmware details and the latest specifications consult the manufacturer documentation and release notes.

## Feature Overview

The GOTOP S7 is a rugged, Plaspy compatible tracker designed for vehicles and outdoor assets. It focuses on reliable position reporting, robust power handling and flexible peripheral support so telemetry and key events can be streamed into Plaspy for monitoring and reporting.

- IP66 rated enclosure with integrated GPS and cellular antennas for dependable outdoor use on cars, motorcycles, boats and commercial fleets.
- Wide DC input range (8–92V) and industrial protection for compatibility with a broad set of vehicle electrical systems.
- 4G LTE with 2G fallback via Quectel EG915U and high-sensitivity GNSS via Quectel L70-R for consistent positioning and connectivity.
- Built-in fuel monitoring that reads the vehicle factory fuel gauge without an external fuel sensor required, plus a configurable analog input for additional sensors.
- Digital ACC/ignition detection, an open-drain output for control or immobilization, and an RS232 port for cameras, RFID or other peripherals.
- Internal backup battery to provide continued reporting during temporary power loss and onboard memory for local data storage.

## Core Features of GOTOP - S7

- IP66 waterproof and dust resistant housing suitable for exposed vehicle and marine installations.
- Wide voltage input support 8–92V making the device suitable for cars, motorcycles, commercial trucks and rental fleets.
- Integrated 4G LTE modem with 2G fallback for broad cellular coverage and roaming resilience.
- High-sensitivity GNSS receiver with typical position accuracy on the order of 10 meters.
- Factory fuel gauge reading support for fuel theft and fill detection without external fuel sensors.
- One digital input commonly used for ACC/ignition detection and one 12-bit analog input configurable for sensor data.
- RS232 serial interface for connecting cameras, RFID readers or other peripherals to enrich telemetry.
- Internal backup battery and onboard flash memory to maintain reporting and temporary storage during power interruptions.

## How These Features Work with Plaspy

When connected to Plaspy, the S7 streams location and selected telemetry so teams can monitor assets and respond to events from a central platform. Plaspy detects compatible device protocols and presents location and event data in maps, dashboards and reports.

- Live location updates and historical tracks appear in Plaspy maps and trip logs for fleet oversight.
- Ignition and ACC status reported by the S7 enable trip segmentation and engine on/off event reporting inside Plaspy.
- Fuel readings and fuel anomaly detection from the factory gauge are visible in Plaspy telemetry and can trigger alerts or reports.
- RS232-sourced events and peripheral inputs can be surfaced as custom telemetry fields or events in Plaspy dashboards.
- Open-drain output state changes and tamper or movement conditions reported by the device can be used to drive alerts and automated workflows.

## Typical Use Cases

- Fleet management and routing for cars, vans and light trucks with wide input voltage tolerance and reliable cellular connectivity.
- Anti-theft monitoring and immobilization workflows using ignition detection, alerts and the configurable output.
- Fuel monitoring and theft detection using factory fuel gauge readings to reduce retrofit complexity.
- Asset tracking for motorcycles and small boats where IP66 waterproofing and integrated antennas ease installation.
- Rental fleet telematics and usage logging with ignition-based trip reports and historical playback.
- Perimeter and specialty integrations where RS232 peripherals add event context to location data.

## Feature Availability Notes

- Some features and parameter behaviors depend on the S7 firmware version; functions available on one firmware may differ on another.
- Hardware revisions and regional variants can affect supported cellular bands, power handling and peripheral wiring.
- RS232 peripheral compatibility and available telemetry fields depend on how peripherals are configured and what data they provide.
- Installation practices such as wiring choices and grounding influence ignition sensing and analog input results.
- Always check the latest manufacturer documentation for wiring diagrams, firmware release notes and optional accessory compatibility.
