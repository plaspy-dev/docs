# GOTOP - C790-Y Features

This page provides a public feature overview of the GOTOP C790-Y and how its capabilities map into Plaspy for vehicle tracking and fleet monitoring. It summarizes the practical, user-facing functions you can expect when deploying the C790-Y with Plaspy and describes how key telemetry and alarm events are surfaced inside the platform.

Exact feature availability for any individual unit can vary by firmware version, hardware revision, installation method and regional manufacturer implementation. For device specific behavior such as alarm thresholds, reporting intervals or supported interfaces verify the latest details with the device manufacturer and your installation provider.

## Feature Overview

The C790-Y is a compact vehicle tracker built to deliver location, status and alarm reporting to centralized tracking platforms such as Plaspy. It focuses on continuous position updates, event driven alerts and features commonly used for anti theft protection and fleet oversight.

- Real time GPS and BeiDou location updates delivered over cellular GPRS for live map tracking and route monitoring.
- Geofence entry and exit alerts, overspeed and vibration alarms to detect unauthorized use or potential incidents.
- Ignition or ACC detection to report vehicle on and off status for usage monitoring and scheduled workflows.
- Remote fuel cut off and power failure tamper alarm to support anti theft response and recovery procedures.
- SOS emergency button and remote listening to assist with driver safety and incident verification.
- Historical route playback up to 180 days for investigation, compliance and operational review.

## Core Features of GOTOP - C790-Y

- GPS and BeiDou satellite positioning for continuous location reporting.
- GPRS communication to transmit location and telemetry to a tracking platform.
- Ignition or ACC detection for reporting vehicle run state and supporting rules.
- Remote fuel cut off control to enable immobilization workflows when needed.
- Power failure tamper alarm to notify potential removal or tampering events.
- Overspeed and vibration alarms for driver behavior and security monitoring.
- SOS emergency input and remote listening for safety and response coordination.
- Historical route storage and playback capability for up to 180 days.

## How These Features Work with Plaspy

Plaspy ingests the C790-Y telemetry and presents it within maps, dashboards and alerting channels so operators can monitor fleets, respond to alarms and review historical activity. Plaspy automatically detects device protocol and provides a consolidated view of position and event data from supported trackers.

- Live location and movement visible on the Plaspy map with timestamped updates and route traces.
- Alarm events such as geofence triggers, overspeed, vibration, SOS and power tamper appear as notifications and can trigger configurable workflows.
- Ignition or ACC state reported to Plaspy enables on/off reporting, usage summaries and rule based alerts.
- Remote immobilization events from fuel cut off can be coordinated with Plaspy alerting and operator procedures.
- Historical route playback and trip logs are available in Plaspy for incident review and compliance reporting.
- Device connection and configuration are simplified because Plaspy automatically detects compatible tracker protocols; devices commonly report to the Plaspy domain for ingestion.

## Typical Use Cases

- Fleet management with live tracking, trip history and event based alerts for operational oversight.
- Vehicle anti theft protection using remote fuel cut off, tamper detection and geofence monitoring.
- Emergency response workflows using SOS input and remote listening to verify driver safety.
- Small business vehicle usage and billing reconciliation using ignition event logs and route history.
- Rental or shared vehicle monitoring to detect unauthorized use and recover assets.
- Personal vehicle security where discreet installation and arming modes reduce theft risk.
