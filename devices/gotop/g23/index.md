# GOTOP - G23

![G23](./tracker.jpg)

The Mini Wire GPS Tracker G23 is a compact, Plaspy compatible GPS tracker engineered for discreet vehicle installation and reliable real-time tracking. Built for cars, motorcycles, e-bikes and light commercial vehicles, the G23 provides hybrid positioning \(GPS + BeiDou + LBS\) with positioning accuracy of around 5 meters. Its slim form factor and internal antennas make it ideal for fleet management and anti-theft applications where a low-profile tracker is required.

Designed with practical vehicle telemetry in mind, the G23 supports ignition \(ACC\) detection, remote power/fuel cut \(usable as an immobilizer function\), power-off alarm, overspeed and vibration/movement alerts. With wide DC input \(9–95V\), low sleep current and an 80 mAh backup polymer battery for offline alerts, the G23 delivers dependable uptime and rapid integration with Plaspy for reporting, alerts and centralized fleet control.

## Key Highlights

- Plaspy compatible for centralized, real-time GPS tracker monitoring and fleet management.
- Accurate hybrid positioning \(GPS + BeiDou + LBS\) with approximately 5 m accuracy for precise location and route playback.
- Essential anti-theft and immobilizer capabilities via remote power/fuel cut and power-off alarm.
- Wide DC input \(9–95V\) to support cars, trucks, motorcycles and e-bikes without additional converters.
- Low power design with sleep current around 5–15 mA \(12V\) and an 80 mAh backup battery to report offline events.
- Vehicle telemetry inputs: ACC ignition detection, overspeed, vibration and illegal ACC/engine alerts for comprehensive event tracking.
- Compact, discreet ABS housing \(77 × 28 × 15 mm\) that simplifies hidden installations and theft prevention.

## How It Works with Plaspy

The G23 transmits location and event telemetry to Plaspy using its 2G GSM link. Once connected, Plaspy ingests GNSS positions, status markers and alarm events to provide real-time tracking, historical playback, geofence alerts and fleet reporting. Integration is straightforward: Plaspy receives standard location reports and event codes from the G23 and maps them to dashboards, notifications and automation workflows used in fleet management and anti-theft monitoring.

- Real-time location and telemetry updates \(GNSS + LBS\) forwarded to Plaspy for live maps and reports.
- Ignition \(ACC\) detection and illegal ACC/engine alerts to monitor unauthorized starts and driver behavior.
- Remote power/fuel cut for immobilizer-style intervention controlled via Plaspy when permitted by installation and local regulations.
- Power-off alarm and backup battery notifications allow Plaspy to flag tampering or vehicle power loss events.
- Overspeed, vibration and movement alarms feed into Plaspy rules for alerts, driver coaching and safety workflows.
- Works alongside Plaspy’s broader ecosystem — while G23 does not include Bluetooth sensors, Plaspy can integrate BLE accessories and third-party sensors within the platform to expand telemetry when additional hardware is used.

## Technical Overview

| Connectivity | GSM \(MT6261D module, 2G\) |
| --- | --- |
| Bands | 850 / 900 / 1800 / 1900 MHz |
| Power & Battery | DC 9V–95V input; working current 30–60 mA \(12V\); sleep current ~5–15 mA \(12V\) |
| Backup Battery | 80 mAh, 3.7V polymer \(supports offline alerts\) |
| Interfaces | 1 low-level output \(power/fuel cut\), 1 H-IN \(ACC detection\), 1 UART-TTL \(3.3V\) for configuration |
| GNSS | ZKMicro AT6558D \(GPS + BeiDou + LBS\), sensitivity −162 dBm, cold start ~32 s, hot start ~1 s, ~5 m accuracy |
| SIM & Antenna | Micro SIM slot; internal GPS and GSM antennas |
| Bluetooth | Not included in device \(no BLE module\) |
| Remote Management | Device configuration via 3.3V UART-TTL serial port; no FOTA or web management specified |
| Form Factor | Compact mini wire tracker, ABS housing, 77 × 28 × 15 mm; weight 32 g |
| Environmentals | Operating −30°C to 75°C; storage −30°C to 80°C; humidity 5%–95% |
