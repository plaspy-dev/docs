# GOTOP - VT-391 Features

This page provides a public features overview for the GOTOP VT-391 GPS tracker and how its capabilities can be used with Plaspy for vehicle and fleet monitoring. It summarizes the VT-391 feature set in non-sensitive terms and explains the practical value these functions bring when the device reports into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation choices. Use this page as a high level reference and consult the manufacturer documentation for precise device specifications and any feature differences between units.

## Feature Overview

The VT-391 is positioned as a versatile vehicle tracker with multimedia, identification, and multiple connectivity options, designed for applications that require both location awareness and event capture. Below are the most relevant practical capabilities that users typically leverage with Plaspy.

- Built in WiFi connectivity for wireless data transmission alongside cellular channels
- Integrated camera support to log images with location and driving context
- RFID driver identification for mapping driver presence to vehicle activity
- Onboard storage support for SD cards up to 64 GB for extended media and data logging
- Alerts for harsh braking and acceleration plus accident detection for timely event reporting

## Core Features of GOTOP - VT-391

- WiFi module for local wireless communication and data uplink when available
- Camera port and image logging capability to capture visual context for events
- RFID driver identification to associate drivers with trips and events
- SD card slot supporting up to 64 GB for storage of pictures and logs
- Two way audio allowing remote listening and speaking for in vehicle communication
- Multiple analog and digital I O options including analog inputs for external sensor connections
- Harsh braking and acceleration alarms and accident alerting for rapid event notification
- OTA firmware support for manufacturer provided updates

## How These Features Work with Plaspy

When a VT-391 reports into Plaspy the device features translate into visibility and event data that operators can act on. Plaspy automatically detects the tracker protocol and accepts connections from supported devices, so VT-391 units can be monitored alongside other fleet devices.

- Location updates received from the tracker appear on Plaspy maps and timelines
- Event alerts such as harsh braking accident SOS and over speed are surfaced as platform events
- Driver identity data reported by the RFID reader can be linked to driver profiles in Plaspy
- Camera images and event media transmitted by the device are associated with events and timestamps in Plaspy when provided by the tracker
- Digital and analog input states reported by the VT-391 are available as inputs or event triggers inside Plaspy
- Device status including connectivity method and reported firmware or configuration can be viewed from the Plaspy device details page

## Typical Use Cases

- Fleet location tracking with supplemental visual records for incident review
- Driver identification and accountability using RFID based check in and trip association
- Real time alerting for safety events such as harsh braking and accident detection
- Media enabled incident logging where images are captured and time stamped with location
- Monitoring of external analog sensors for operational oversight using the device inputs
- Two way voice communications for dispatch or driver support during operations

## Feature Availability Notes

- Feature presence and behavior depend on device firmware and hardware revision from the manufacturer
- Some functions such as the camera RFID or certain inputs may require specific accessory cabling or optional modules
- Regional variants and carrier approvals can affect which connectivity methods are available by default
- SD card performance and maximum supported capacity can change with firmware updates or manufacturer guidance
- Plaspy will list device reported features and inputs but exact interaction for advanced features may require configuration on both the tracker and the platform

## Why Use Plaspy with These Features

Combining the VT-391 with Plaspy gives organizations a unified view of location, driver identity, and event driven media. Plaspy collects and presents the device telemetry and alerts so operators can monitor routes, review incidents with image context, and correlate driver presence with vehicle activity for operational decision making.
