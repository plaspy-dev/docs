# GOTOP - TK-120 Features

This page summarizes the public feature context for using the GOTOP TK-120 mini GPS tracker with Plaspy. It focuses on the practical capabilities you can expect to use in Plaspy for location monitoring and reporting, based on the TK-120's documented behavior such as GPS positioning, GSM connectivity, SMS reporting, and GPRS reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific technical details or the latest changes consult the official GOTOP documentation and firmware release notes.

## Feature Overview

The GOTOP TK-120 is a compact and discreet tracker that uses GPS satellites for position fixes and the GSM network for communication. It supports both SMS based coordinate reporting and GPRS based reporting to tracking platforms, providing flexible options for remote monitoring and basic real time visibility.

- Sends longitude and latitude via SMS to a phone number for direct location updates.
- Replies to SMS queries with a Google Maps link for quick visual inspection of position.
- Supports GPRS reporting so position data can be sent to tracking platforms at user configured intervals.
- Small form factor suited for discreet installations on people, small assets, vehicles, or pets.
- Offers flexible reporting modes so users can choose SMS for occasional checks or GPRS for continuous tracking.

## Core Features of GOTOP - TK-120

- GPS satellite based positioning for latitude and longitude coordinates.
- GSM network communication for SMS based reporting and remote queries.
- SMS reply with a Google Maps link to view position in a map interface.
- GPRS support to transmit periodic position data to tracking software.
- Compact and discreet design intended for easy placement and minimal visibility.
- Configurable reporting intervals when using GPRS for more frequent updates.

## How These Features Work with Plaspy

When used with Plaspy, the TK-120's reporting capabilities translate into location visibility and event awareness inside the platform. Plaspy is designed to recognize common tracker reporting methods and map incoming position data to a vehicle or asset record for monitoring and history.

- GPRS position reports can be received by Plaspy and shown on live maps for continuous tracking.
- SMS reported coordinates and Google Maps links provide a fallback method for quick location checks outside of Plaspy.
- Plaspy records received positions over time so users can review historical movement and routes.
- Alerts and status updates in Plaspy can reflect changes in reported positions or loss of communication.
- Plaspy automatically detects supported tracker protocols so device reporting is mapped without manual protocol selection.

## Typical Use Cases

- Discreet location monitoring of a small asset or personal item.
- Vehicle tracking where a compact, easy to hide unit is required.
- Pet tracking for general location awareness when periodic updates are sufficient.
- Temporary or short term monitoring where SMS updates are preferred.
- Continuous fleet or asset monitoring using GPRS reporting into a central platform.
