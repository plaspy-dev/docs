# GOTOP - W07 Features

This page provides a public feature overview of the GOTOP W07 mini GPS tracker and how its capabilities map to Plaspy monitoring and fleet workflows. It focuses on practical, non sensitive details you can expect when using the W07 with Plaspy, including its reporting options, alert types, positioning behavior, and typical operational uses.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation method, regional cellular support, and the manufacturer's implementation choices. For firmware level details, advanced configuration or the most current technical specifications consult the manufacturer documentation referenced at the end of this page.

## Feature Overview

The GOTOP W07 is a compact, waterproof GPS tracker designed for discreet tracking and basic telemetry reporting. It combines GNSS positioning, global cellular connectivity, and a set of motion and power related alerts that are commonly used for personal, pet, luggage and small asset tracking.

- Real time GPS and LBS positioning for live location updates and breadcrumb trails.
- Motion and vibration alerts plus geofence, overspeed, power off, and low battery notifications for event driven monitoring.
- SMS and GPRS reporting with Google Map link support for quick one tap location viewing and route playback.
- Small waterproof housing and rechargeable battery for portable and discreet installations.

## Core Features of GOTOP - W07

- Compact waterproof enclosure sized for collars, luggage, and covert placements.
- GNSS positioning using the MT2503D chipset with A GPS assistance for reliable satellite fixes and typical position accuracy around 5 meters.
- Global cellular modem based on the SIMCOM A7670SA module with quad band GSM and multiple LTE FDD bands for broad network coverage.
- Multiple reporting channels including SMS and GPRS for integration into web platforms and mobile apps.
- Motion and internal vibration sensor to trigger movement alerts and anti theft notifications.
- Geofence support for virtual perimeter alerts and overspeed alarm for basic speed event notifications.
- Power off and low battery alarms to help detect tampering or loss of power.
- Rechargeable battery for continuous portable tracking without external power.

## How These Features Work with Plaspy

Plaspy ingests the W07 location and event messages and presents them in its monitoring dashboard and mobile views. Data sent by the device via GPRS or SMS appears as live positions, alerts, and historical tracks so operators can respond and review incidents.

- Live location updates and breadcrumb trails displayed in Plaspy for situational awareness and route playback.
- Motion, geofence, overspeed, power off, and low battery events converted into Plaspy alerts and visible in the event timeline.
- Historical tracking available in Plaspy using the device timestamps and stored coordinates for post event review.
- Google Map links and coordinate messages provide one tap map viewing; Plaspy shows full tracks and contextual location data.
- Plaspy automatically detects common tracker protocols and accepts messages from compatible devices so integration is typically straightforward for W07 deployments.

## Typical Use Cases

- Personal safety and lone worker tracking where compact real time location and motion alerts are required.
- Pet and luggage tracking using the waterproof housing and discreet form factor for collars and bags.
- Discreet asset monitoring of small high value items with movement and geofence alerts.
- Small vehicle and micro fleet tracking for scooters, mopeds, or similar light mobility applications.
- Anti theft monitoring to capture power off events, movement detection, and low battery notifications during transit.
