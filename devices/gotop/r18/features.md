# GOTOP - R18 Features

This page provides a public feature overview for the GOTOP R18 GPS tracker and explains how its capabilities can be used with Plaspy. It is written to help operators, integrators, and fleet managers understand the practical functions the R18 supplies when integrated into Plaspy for location awareness, alerts, and reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. Use this page for high level planning and reference Plaspy alongside the device documentation for deployment details.

## Feature Overview

The GOTOP R18 is a compact 4G GPS tracker engineered for vehicle and asset tracking with a focus on discreet installation and flexible telemetry. It provides core location services, configurable alarms, and inputs useful for fleet and anti-theft workflows, making it suitable for use with Plaspy for real-time monitoring and historical reporting.

- Compact 4G LTE Cat 1 connectivity with internal GPS and GSM antennas for reliable cellular location reporting.
- Wide DC input range for direct installation on motorcycles, cars, trucks and marine batteries.
- Multiple tracking modes including real-time, timed intervals, distance-based, direction-change, and mobile-phone assisted tracking.
- Configurable alarm suite covering SOS, geo-fence, external power cut and other event types for security and operations.
- Analog and digital inputs plus an output for integration with ignition detection, sensors, and optional relay accessories.
- Built-in backup battery for short-term runtime during power loss and support for OTA firmware updates.

## Core Features of GOTOP - R18

- 4G LTE Cat 1 cellular connectivity with regional 2G fallback variants as provided by the manufacturer.
- Internal GPS and GSM antennas in a rugged, discreet enclosure sized for small vehicles and assets.
- Wide DC input range of 8–90V to accommodate varied vehicle battery systems.
- Multiple telemetry modes: real-time tracking, time-interval reporting, distance-based reporting, direction-change triggers, and mobile-phone based location modes.
- Comprehensive alarm and event support including SOS alarm, geo-fence breach alerts, external power-cut detection, speeding and harsh driving alerts as implemented by the device.
- Digital inputs including an ACC input for ignition detection and an analog input (0–26V) for voltage-based sensors.
- Optional relay-based remote engine stop capability when used with the manufacturer relay accessory and in accordance with local regulation.
- Small form factor and low weight for discreet mounting and reduced visibility.

## How These Features Work with Plaspy

When the R18 is connected to Plaspy, its location and event data are received by the platform and presented as map tracks, events, and reports useful to fleet and security teams. Plaspy normalizes device telemetry so common features such as location updates, alarms, and inputs are viewable across devices in the platform.

- Real-time and periodic GPS updates appear as live location markers and route tracks on Plaspy maps.
- Alarm events such as SOS, geo-fence breaches, and power-cut are forwarded to Plaspy and can trigger notifications, escalation rules, or automated workflows.
- Ignition and ACC status reported by the device is reflected in Plaspy for idling detection, trip segmentation, and engine-on/off analytics.
- Analog input readings can be shown as voltage telemetry or used to feed custom dashboards for fuel or battery monitoring when configured.
- Relay control and remote immobilization options are surfaced as actionable events or control points when the device is provisioned and permitted for that functionality.

## Typical Use Cases

- Fleet management for cars, trucks, and motorcycles with mixed vehicle types that benefit from a single tracker supporting wide input voltages.
- Anti-theft monitoring with SOS alerts, power-cut detection, geo-fencing and optional relay-based immobilization workflows.
- Discreet motorcycle and small vehicle tracking where compact size and internal antennas simplify installation.
- Marine and small craft monitoring where wide voltage tolerance and GSM based location help maintain asset visibility.
- Voltage based telemetry collection for fuel level or auxiliary sensors using the analog input.
- Short-term backup tracking during power loss using the device internal battery.

## Feature Availability Notes

- Specific alarms, telemetry intervals, and input behavior can vary by firmware version and manufacturer configuration.
- Regional hardware variants may differ in cellular band support and 2G/4G availability; verify the correct regional model for your deployment.
- Optional features such as relay-based engine stop depend on accessory installation and may be restricted by local regulations.
- Some inputs and behaviors require correct wiring and installation; installation type can affect sensor availability and event accuracy.
- Always confirm OTA firmware update policies and current firmware features with the manufacturer documentation before large scale rollout.
