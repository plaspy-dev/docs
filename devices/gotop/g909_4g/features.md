# GOTOP - G909-4G Features

This page provides a public feature overview of the GOTOP G909-4G and how its capabilities are used with the Plaspy platform. It describes the tracker in practical, non-sensitive terms so fleet managers, integrators, and asset owners can understand what the device reports to Plaspy and how those reports support monitoring and operational workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and the manufacturer implementation. Where necessary, confirm specific capabilities, configuration options, and firmware behavior with the device manufacturer documentation and release notes.

## Feature Overview

The G909-4G is a compact asset and vehicle tracker designed for continuous position reporting and event-driven alerts over 4G networks. Its design emphasizes reliable satellite positioning, resilient connectivity, and power efficient operation for deployed assets and vehicles.

- 4G LTE FDD primary communication with GSM GPRS fallback for broad coverage and real-time reporting.
- Dual GNSS reception using GPS and BDS with an anti-jamming ceramic module and AGPS for faster fixes.
- Built-in large capacity offline storage to cache data during network loss and upload after reconnect.
- Intelligent power saving with multiple operating modes to extend deployment life in diverse installations.
- Integrated 3-axis acceleration sensor for motion and vibration detection plus event generation.
- Fleet oriented alarms and features including overspeed alarm, geo-fencing, vibration alerts, and remote voice monitoring.

## Core Features of GOTOP - G909-4G

- Native compatibility with Plaspy for TCP IP domain or IP server connections to the platform.
- 4G LTE FDD communication with high sensitivity GSM GPRS fallback for reliable uplink.
- Dual GNSS support GPS and BDS with anti-jamming ceramic GNSS module and AGPS assistance.
- Built-in offline data storage that preserves telemetry during signal outages and uploads on reconnect.
- Intelligent power saving and three adaptable operating modes for long term deployments.
- Integrated 3-axis acceleration sensor for attitude and vibration based event detection.
- Onboard event generation including overspeed alarm, vibration alarm, and geo-fence enter and exit events.
- Remote device management features such as remote configuration and online firmware upgrades.

## How These Features Work with Plaspy

When connected to Plaspy, the G909-4G’s location and event data are ingested into the platform for visualization, history, and alerting. Plaspy can receive the tracker’s telemetry, display positions on maps, and surface generated alarms for operational response.

- Real time GNSS positions and historical tracks appear in Plaspy maps and reports for location awareness.
- Acceleration derived events like vibration alerts and motion changes are available as platform events for monitoring.
- Geo-fence enter and exit events and overspeed alarms upload to Plaspy for immediate notifications and incident logging.
- Offline stored records from the tracker are synchronized into Plaspy once the device reconnects to the network.
- Remote configuration and firmware upgrade events reported by the device can be coordinated through Plaspy to simplify fleet maintenance.
- Plaspy automatically detects many tracker protocols and presents incoming data without requiring manual protocol selection.

## Typical Use Cases

- Fleet tracking and route history for light vehicle fleets and asset fleets.
- Anti theft monitoring with vibration alerts, real time tracking, and geo-fence notifications.
- Logistics and asset visibility for trailers, containers, and portable equipment.
- Equipment status and incident investigation using combined location and motion event history.
- Long term deployments where power saving modes and offline storage are important for reliability.
