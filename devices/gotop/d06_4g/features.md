# GOTOP - D06-4G Features

This page provides a public feature overview of the GOTOP D06-4G and how its capabilities are typically used with Plaspy for live tracking, alarms, and fleet management. It focuses on user-facing functions and operational value you can expect when integrating this model into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, installation method, and manufacturer implementation. For device-specific configuration and the latest technical details, consult the official GOTOP documentation and release notes.

## Feature Overview

The D06-4G is a compact, discreet tracker designed to provide continuous position reporting and event telemetry to Plaspy. It combines broad cellular coverage with multi-mode location techniques and on-device buffering to maintain useful tracking data in typical vehicle and exposed installations.

- Real-time tracking over 4G LTE with 2G fallback to maintain connectivity across networks.
- Multi-mode positioning including GPS and BeiDou with supplementary WiFi and LBS data to improve fix availability.
- Internal memory for offline coordinate storage so route history is preserved during network outages.
- Comprehensive alarm reporting including geofence alerts, power-cut detection, vibration alarms, low battery and offline warnings.
- Remote relay control for immobilization-style actions when configured and supported by installation.
- IP65-rated, compact enclosure for discreet mounting on cars, motorcycles, e-bikes and similar vehicles.

## Core Features of GOTOP - D06-4G

- 4G LTE connectivity with automatic 2G fallback for wide coverage and continuous reporting.
- Multi-mode GNSS positioning with additional WiFi/LBS sources to reduce blind spots.
- Internal flash memory that caches location records while the device is disconnected from the network.
- Geofence management and event reporting for boundary breaches and related alerts.
- Alarms for power-cut/power failure, vibration detection, low battery, and offline status.
- SOS button support for immediate emergency signalling when pressed.
- Remote relay control capability for cut-off or immobilizer-style remote actions.
- IP65 rated housing and compact form factor for exposed or discreet vehicle installations.

## How These Features Work with Plaspy

Plaspy ingests the D06-4G telemetry and presents it in dashboards, maps, and alerting workflows so operators can monitor vehicles in real time and review historical movement. Plaspy automatically detects compatible tracker protocols when the device is configured to report to the platform.

- Live map visualization of GNSS positions and supplementary location info for operational awareness.
- Event and alarm forwarding for geofence breaches, power-cut warnings, vibration events, SOS activations and offline alerts.
- History playback and route reconstruction using stored records uploaded by the device after network restoration.
- Remote command and control actions for relay-based immobilization where the device and installation allow remote control.
- Plaspy receives device connections directed at the platform domain and supports standard TCP or UDP transport methods commonly used by trackers.
- Centralized alerting and notification routing so teams and contacts receive timely alarms from the tracker.

## Typical Use Cases

- Fleet management for cars, motorcycles and e-bikes requiring live location, route history and basic telemetry.
- Vehicle anti-theft and recovery operations using geofence alerts, vibration detection and remote relay control.
- Compliance and incident investigation with internal memory preserving route history during connectivity gaps.
- Emergency response coordination using SOS alerts forwarded to operators and contacts.
- Discreet tracking installations for authorized surveillance or security tasks where compact size and a hidden antenna are required.
- Long-term deployments on exposed vehicles benefitting from IP65 durability and internal backup storage.

## Feature Availability Notes

- Feature sets can differ by firmware release; some alarms or behaviors may be enabled or refined in later firmware updates.
- Hardware revisions and regional model variants may change supported cellular bands, optional accessories, or connector availability.
- Optional features such as an external microphone or specific relay configurations depend on the purchased model and local regulations.
- Installation choices (hardwired vs plug-in) affect which inputs and relay functions are available for immobilization or power-cut detection.
- Always confirm feature support, wiring diagrams, and legal requirements for audio monitoring or remote control with the manufacturer documentation.
