# GOTOP - D06-4G

![D06-4G](./tracker.jpg)

The D06-4G is a compact, Plaspy compatible GPS tracker built for reliable real-time tracking and fleet management of cars, motorcycles, e-bikes and other vehicles. Designed for discreet installation, the D06-4G combines a high-sensitivity GNSS receiver with 4G LTE connectivity \(with 2G fallback\) to deliver continuous location and status information to Plaspy or directly to mobile phones and server platforms. Its IP65-rated housing and internal memory for offline storage make it ideal for exposed vehicle installations and long-term anti-theft deployments.

As a Plaspy compatible device, the D06-4G provides the telemetry and event reporting fleet managers and security teams need: geofence alerts, power-cut detection, SOS, vibration alarms and remote relay control for immobilization. Whether you are implementing fleet management workflows, vehicle anti-theft recovery, or covert tracking where discretion matters, the D06-4G is purpose-built to feed accurate position data and event telemetry into Plaspy for live monitoring, history playback and actionable alerts.

## Key Highlights

- Plaspy compatible GPS tracker with real-time tracking over 4G LTE and fallback 2G for broad network coverage.
- Multi-mode positioning \(GPS/BeiDou/WiFi/LBS\) for improved location availability in urban and rural environments.
- Comprehensive alarm set: geofence, power-cut/power failure, low battery, vibration and offline alarms plus an SOS button for emergencies.
- Remote relay control enabling power cut or immobilizer-style actions to help recover stolen vehicles or stop unauthorized use.
- Internal memory stores coordinates during network outages, preventing data loss and ensuring complete route history after reconnection.
- Optional external microphone for remote listen-in capability when covert audio monitoring is required and legally permitted.
- Compact, robust IP65 ABS enclosure and built-in antenna for discreet, weather-resistant installations on many vehicle types.

## How It Works with Plaspy

Integrating the D06-4G with Plaspy delivers live location, event telemetry and alerting through a straightforward data pipeline. The tracker collects GNSS position fixes and local network information \(WiFi/LBS\), then transmits these records via LTE \(or 2G fallback\) to the configured server IPs. Plaspy ingests the data stream to present real-time tracking, geofence enforcement, route history playback and alarm notifications to operators and mobile users.

- Real-time location and telemetry updates: continuous position fixes delivered to Plaspy for map visualization and live fleet oversight.
- Comprehensive alarm reporting: geofence breaches, power-cut/power failure, low battery warnings, vibration and offline alarms are forwarded to Plaspy as events.
- SOS emergency alerts: one-touch SOS activation is reported immediately to Plaspy and configured contacts for rapid response.
- Remote immobilizer/relay control: Plaspy can trigger the device’s remote relay function to cut power or otherwise immobilize a vehicle where configured.
- Offline storage and recovery: internal memory caches coordinates while the device is offline and uploads the stored history once a connection is restored.
- Optional remote listen-in: when an external microphone is installed, Plaspy can initiate audio monitoring in compliance with applicable laws and permissions.
