# GOTOP - G06B Features

This page provides a public feature overview for the GOTOP G06B and how its capabilities are used with Plaspy for vehicle locating and monitoring. It focuses on user-facing features and practical value when the G06B is reporting location and events into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and the way the device is installed or configured. For device-specific and up-to-date details consult the manufacturer documentation and firmware release notes.

## Feature Overview

The GOTOP G06B is a compact, weather‑resistant 4G car GPS tracker intended for continuous vehicle locating and event reporting. In practice it provides position updates, status alarms, and a set of remote or local inputs that can be reflected in fleet and asset monitoring workflows.

- 4G LTE connectivity for near real‑time location reporting and updates
- GPS based vehicle locating with frequent position reports for tracking
- Built‑in SOS button for emergency alerts to notify monitoring systems
- ACC detection to indicate ignition or vehicle power state changes
- Remote engine cut capability for vehicle recovery and security workflows
- Multiple alarm types including geo‑fencing, movement, vibration, low battery, and main power cut

## Core Features of GOTOP - G06B

- 4G LTE network support for faster reporting and reduced latency in position updates
- GPS location reporting for continuous vehicle position awareness
- SOS panic button that sends an alert when pressed
- ACC detection to monitor ignition on/off status
- Remote engine cut function to support immobilization where configured
- Geo‑fencing alarm to trigger alerts when the vehicle enters or leaves defined areas
- Movement and vibration alarms to detect unexpected motion or impacts
- Low battery and main power cut alarms to notify of power issues

## How These Features Work with Plaspy

Plaspy receives location and status messages from the G06B and presents them as location points and events inside the platform so fleets and vehicle owners can monitor activity and respond to alerts. Plaspy automatically detects common tracker protocols and maps incoming events to dashboard alerts and historical logs.

- Real‑time and periodic location updates appear on Plaspy maps for live tracking
- Alarm events such as SOS, geo‑fence breach, movement, and power cut are recorded as alerts in Plaspy
- ACC detection is represented as ignition or vehicle power state in device telemetry
- Remote immobilization or engine cut status (where enabled and configured) is reflected in device state and event history
- Low battery and main power cut alarms help highlight vehicles needing maintenance or inspection

## Typical Use Cases

- Personal car tracking for location visibility and alerting
- Fleet monitoring for delivery, service, or sales vehicles needing real‑time location
- Theft detection and recovery workflows using SOS alerts and remote cut features
- Rental and shared vehicle oversight with geo‑fencing and movement alerts
- Asset protection where water resistance and compact installation are required

## Feature Availability Notes

- Firmware version and regional hardware variants can enable, change, or limit certain features
- Installation method and wiring affect availability of inputs such as ACC detection and main power cut reporting
- Some remote control capabilities require additional configuration and may be restricted by local regulations or operator policy
- Manufacturer feature names and alarm thresholds may differ between releases; consult official documentation
- Plaspy integration reflects the data the device sends; if a feature is disabled on the device it will not appear in Plaspy

## Why Use Plaspy with These Features

Using the GOTOP G06B with Plaspy brings device events and location into a single monitoring platform so teams can maintain visibility, respond to incidents, and analyze vehicle activity over time. Plaspy aggregates position history, alerts, and device state to support operational decisions and improve fleet oversight.
