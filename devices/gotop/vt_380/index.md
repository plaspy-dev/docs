# GOTOP - VT-380

![VT-380](./tracker.jpg)

The GOTOP VT-380 is a professional vehicle GPS/GPRS tracker designed for reliable real-time tracking and fleet management. Built for fleet operators, rental companies and vehicle security integrators, the VT-380 combines a high-sensitivity GNSS module with quad-band GSM communications, long-term on-device logging and a range of vehicle inputs and alarms to support telematics and anti-theft workflows.

As a Plaspy compatible device, the VT-380 can stream location, alarm and sensor data into Plaspy for centralized dashboards, alerts and reporting. Its capacity to store many waypoints while offline and to upload stored routes when connectivity resumes makes it a practical fit for Plaspy deployments that require continuous route history, event fidelity and integrated operational oversight.

## Key Highlights

- Designed for professional fleet use with reliable GNSS positioning and robust GSM communications.
- Configurable reporting and comprehensive alarm set including SOS panic, geo-fencing and power-cut alerts.
- Large internal logging buffer for long term waypoint storage when connectivity is intermittent.
- Remote engine-cut output and included relay support anti-theft and remote immobilization workflows.
- Multiple vehicle inputs for telemetry and event signals that feed into fleet reports and alerts.
- Compact vehicle grade form factor with backup battery and low-power behavior for continuous monitoring.

## How It Works with Plaspy

When paired with Plaspy, the VT-380 delivers vehicle position fixes, alarm events and analog/digital input telemetry into Plaspy dashboards and reporting tools. Plaspy ingests the device data to present live tracking, historical playback and rule based notifications so fleet managers can monitor assets and respond to events quickly.

- Real time location updates and telemetry are visible in Plaspy for live monitoring and dispatch.
- Alarm events such as SOS, geo-fence triggers, speeding and power loss appear as immediate notifications in Plaspy.
- Logged waypoints stored on the device are uploaded after reconnection so Plaspy has complete route history for playback and compliance reports.
- Vehicle telemetry from analog and digital inputs can feed Plaspy reports for fuel monitoring and event analysis.
- Remote immobilization events and related status changes can be reflected in Plaspy to support security workflows.

## Typical Use Cases

- Fleet operations needing continuous location visibility and historical route playback for compliance and optimization.
- Rental vehicle management where theft protection, engine-cut control and rapid alerts are required.
- Security integrators deploying trackers for anti-theft systems and centralized alarm monitoring.
- Fuel monitoring and consumption analysis using analog inputs combined with Plaspy reporting.
- Assets operating in low coverage areas that rely on long term on-device logging until data upload is possible.
