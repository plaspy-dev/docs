# GOTOP - G25C Features

This page provides a public feature overview for the GOTOP G25C GPS tracker and describes how its capabilities map to Plaspy. It focuses on user-facing functionality you can expect when using the G25C with Plaspy for location monitoring, alerts, and operational visibility.

Exact feature availability and behavior can vary with firmware version, hardware revision, regional variants, and installation method. For device specific settings, firmware notes, or advanced configuration consult the manufacturer's documentation and release notes.

## Feature Overview

The GOTOP G25C-4G is a 4G-enabled satellite positioning tracker built for long-term deployments and a variety of vehicle and asset tracking scenarios. It combines LTE connectivity with GPS and BDS satellite positioning and includes a large built-in battery and a sealed enclosure suitable for outdoor use.

- 4G LTE connectivity combined with GPS and BDS positioning for real time location updates.
- Large internal battery offering extended standby operation and multiple power saving modes.
- Multiple alarm functions including drop off, movement, low battery, shake, and geo-fence alerts.
- Voice monitoring and recording capability to remotely listen to device surroundings where supported.
- IP65 water resistant enclosure and a magnetic mounting option for non-invasive installation.

## Core Features of GOTOP - G25C

- 4G LTE cellular connectivity for reliable data reporting and remote visibility.
- Dual satellite support with GPS and BDS positioning for improved location accuracy.
- High capacity internal battery with long standby life and selectable power saving modes.
- Multiple configurable alarms: drop-off alarm, movement alarm, low battery alarm, shake alarm, and geo-fence alarm.
- Voice monitoring and recording for remote audio checks where permitted by local law.
- Built-in antenna design intended for consistent signal performance in varied installations.
- SMS parameter setting and SMS Google Map links for lightweight configuration and location access.
- Compatibility with web and mobile platforms for monitoring and device administration.

## How These Features Work with Plaspy

Plaspy receives and interprets position and event data from compatible trackers like the G25C so organizations can monitor assets in real time and get actionable alerts. Plaspy automatically detects supported tracker protocols and presents device activity in the platform dashboard.

- Real time locations and historical tracks appear in Plaspy for vehicle and asset oversight.
- Alarm events from the G25C such as geo-fence and low battery are surfaced as alerts in Plaspy.
- Long battery life and power modes reduce reporting frequency when desired, which Plaspy reflects in device activity and offline indicators.
- Voice monitoring events and recorded files can be referenced in Plaspy if the device reports the data and it is enabled.
- Devices can be pointed at the Plaspy server (d.plaspy.com) using standard TCP or UDP on the platform port; Plaspy auto-detects supported protocols and normalizes incoming data.
- SMS configuration options on the tracker provide an alternate setup method before full integration into Plaspy.

## Typical Use Cases

- Long duration asset tracking where extended standby battery life reduces maintenance intervals.
- Fleet monitoring for cars, rental vehicles, and light trucks that need continuous location visibility.
- Temporary or stealth installations using magnetic mounting for non-invasive attachment.
- Remote monitoring of trailers or equipment that benefit from geo-fence alerts and movement notifications.
- Situations requiring occasional remote audio checks for situational awareness when permitted.
- Lightweight deployments where SMS links and web/mobile access simplify initial setup.
