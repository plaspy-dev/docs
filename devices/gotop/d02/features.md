# GOTOP - D02 Features

This page provides a public feature summary for the GOTOP D02 pet tracker and explains how its capabilities map to Plaspy for visibility and operational use. It covers the main user-facing functions you can expect when using this model with Plaspy and highlights practical scenarios where the tracker can help keep pets safe.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, and installation method. Manufacturer implementation and settings controlled through the device firmware or companion applications may change how features appear in Plaspy, so treat the items below as a functional overview rather than a device manual.

## Feature Overview

The GOTOP D02 is presented as a waterproof pet tracker that combines multiple positioning methods, real-time reporting, and a set of pet-oriented features to aid in finding and monitoring a pet. It is designed to be durable for outdoor use and provides both active locating tools and passive activity awareness.

- Multiple positioning options including GPS, WiFi, LBS, and BeiDou for indoor and outdoor locating
- IP68 waterproof rating for reliable operation during swimming or wet conditions
- Real-time 4G LTE tracking and SMS location with a Google map link for quick recovery
- Sound and light pet seeking plus a loud speaker and remote voice calling for close-range location
- Remote monitoring and recording to check surroundings when needed
- Power saving with a 3D sensor, quick charge support, and long standby characteristics

## Core Features of GOTOP - D02

- GPS, WiFi, LBS, and BeiDou multi-mode positioning for broader location coverage
- IP68 waterproof design suitable for swimming level exposure
- 4G LTE real-time tracking capability for continuous position updates
- SMS location feature that returns a Google map link for quick location sharing
- Sound and light pet seeking function to help locate pets visually and audibly
- Large volume speaker with remote voice calling to communicate with the pet
- Remote voice monitoring and recording to listen to or record the device surroundings
- Built-in activity features including a pedometer and feeding reminders for routine tracking

## How These Features Work with Plaspy

Plaspy provides a unified platform view for compatible trackers like the GOTOP D02 and will display position, alerts, and available events as reported by the device. Plaspy automatically detects many tracker protocols and accepts device reports to provide location awareness and event visibility on d.plaspy.com. Within Plaspy, the D02 capabilities typically translate into visible location points, event notifications, and contextual state information.

- Real-time location updates appear on the Plaspy map when the device reports over the cellular network
- Geo-fence and low battery alarms from the device can be surfaced as alerts inside Plaspy
- SMS location with map links offers an alternate recovery method that complements Plaspy live tracking
- Sound and light seek or remote voice actions initiated from the device are reflected as activity events in logs
- Activity data such as pedometer and feeding reminders can be recorded as events or notes available for review
- Plaspy can accept device reports over standard transport methods and will present position and event history for analysis

## Typical Use Cases

- Locating a lost or wandering pet with real-time 4G tracking and SMS map links
- Monitoring pet activity levels using pedometer and scheduled feeding reminders
- Recovering a pet quickly in outdoor wet environments thanks to the IP68 rating
- Using sound and light seek plus remote voice calling to find a pet nearby
- Reviewing remote voice monitoring recordings for situational awareness after an incident
- Maintaining longer deployment with power saving enabled by the device 3D sensor
