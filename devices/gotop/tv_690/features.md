# GOTOP - TV-690 Features

This page describes the public feature context for using the GOTOP TV-690 personal remote positioning device with Plaspy. It summarizes the tracker capabilities that are relevant to Plaspy users and explains how those capabilities can be used for location visibility and operational monitoring inside the Plaspy platform.

Exact feature availability and behavior depend on the device firmware, hardware revision, installation method, and manufacturer implementation. Differences between firmware versions, regional variants, or how the device is installed can affect which functions are available and how they perform.

## Feature Overview

The GOTOP TV-690 combines a GPS receiver and a GSM GPRS communication module in a compact housing to provide accurate location information for people, property, or animals. Its practical strengths are reliable satellite based positioning and simple user workflows for getting location data, including SMS based replies and Google Maps links for quick visual checks.

- Compact personal tracker design suitable for discreet placement or carrying
- GPS based position reporting intended to deliver accurate location information
- GSM GPRS connectivity for remote positioning and data reporting
- SMS location query and reply functionality returning coordinates or Google Maps links
- Practical applications for tracking elderly people children property and animals

## Core Features of GOTOP - TV-690

- GPS positioning for satellite based location accuracy
- GSM GPRS module for remote communication and position reporting
- SMS based location query that replies with coordinates
- SMS replies can include Google Maps links for quick map viewing
- Compact form factor for personal or lightweight attachment
- Designed for personal protection and easy remote positioning tasks
- Suitable for use cases like tracking elderly individuals children and animals

## How These Features Work with Plaspy

Plaspy can be used to collect and visualize location information reported by compatible trackers like the TV-690 and provide ongoing visibility into device locations and movement. When the TV-690 uses mobile data to send reports, Plaspy displays those positions on maps and in device histories, while SMS reporting provides a simple fallback for manual lookups.

- Plaspy displays GPS coordinates reported by the device on interactive maps
- Position history and recent location are available in Plaspy for operational oversight
- SMS based location replies provide an immediate manual method to obtain coordinates
- When configured for data reporting the tracker can feed regular updates into Plaspy
- Plaspy automatically detects the tracker protocol to simplify integration

Using the GOTOP TV-690 with Plaspy gives organizations and individuals a straightforward way to turn personal positioning reports into actionable location visibility. Plaspy consolidates reported GPS positions into maps and histories so teams can monitor whereabouts, review recent movements, and maintain operational awareness for safety and asset protection.
