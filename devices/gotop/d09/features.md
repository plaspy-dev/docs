# GOTOP - D09 Features

This page provides a public feature overview for the GOTOP D09 asset GPS tracker and how its capabilities are used with Plaspy for asset monitoring, alerting, and history playback. It focuses on user facing features and practical value when the D09 is integrated into Plaspy accounts and workflows.

Exact feature availability and behavior of a specific D09 unit can vary based on firmware version, hardware revision, regional variants, installation method, and manufacturer implementation. For device specific configuration, firmware details, and the latest technical guidance consult the manufacturer documentation.

## Feature Overview

The GOTOP D09 is a portable magnetic tracker designed for covert mounting and continuous asset visibility. It combines multi mode positioning, rugged packaging, and configurable alarms with multiple battery sizes to support a wide range of asset protection and fleet monitoring scenarios.

- Real time tracking and history trace replay for continuous visibility and recovery workflows.
- Multi mode positioning using GPS, BDS, AGPS, WiFi positioning and LBS to improve location reliability.
- Rugged waterproof enclosure and a super strong magnet for secure, covert attachment to metal assets.
- Multiple rechargeable battery options to match autonomy needs for short term or extended deployments.
- 4G LTE and 2G cellular connectivity plus SMS location links for immediate location checks without platform access.

## Core Features of GOTOP - D09

- Plaspy compatible real time tracking and alert delivery for live map views and reporting.
- Multi mode GNSS and network assisted positioning including GPS, BDS, AGPS, WiFi positioning and LBS.
- Three rechargeable battery options (D09A, D09B, D09C) to adjust runtime for different deployments.
- Rugged, waterproof enclosure with a powerful magnetic mount for covert placement on vehicles and equipment.
- Cellular coverage across common 2G and 4G bands for broad regional connectivity.
- Comprehensive alarm set including drop off, movement, shake, geo fence, low battery, parking reminder and sound level alerts.
- Remote power save and remote on off capabilities to extend battery life and control device state.
- SMS location messages with Google Map links and native web and mobile access for flexible device access.

## How These Features Work with Plaspy

When a D09 is linked to Plaspy, its location updates and events feed into Plaspy for visualization, alerting, and historical analysis. Plaspy surfaces the device position, relevant alarms, and device state so teams can respond quickly to security and operational events.

- Live position updates and breadcrumb history shown on Plaspy maps and dashboards for situational awareness.
- Movement, drop off, shake, sound level and low battery events generate alerts that can be routed through Plaspy notification rules.
- Historical trace replay in Plaspy enables recovery workflows and post event review.
- Remote sleep and power control actions from Plaspy help optimize device runtime and manage deployed units.
- SMS location links act as a fallback for immediate location checks when platform access is not available.

## Typical Use Cases

- Fleet and trailer anti theft with covert magnetic mounting and drop off alerts to detect unauthorized removal.
- Container and heavy equipment monitoring using waterproof enclosures and larger battery options for extended autonomy.
- Covert asset tracking and recovery where discreet placement and voice monitoring options are desired.
- Temporary or field deployments that require quick installation and configurable runtime based on battery selection.
- Operational visibility such as parking reminders, geo fence monitoring and movement alerts for site management.
