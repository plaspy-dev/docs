# GOTOP - VT-390 Features

This page provides a public feature overview for the GOTOP VT-390 GPS tracker and explains how its capabilities map to Plaspy for tracking, monitoring, and operational oversight. It summarizes the practical functions you can expect when using the VT-390 with Plaspy and highlights the types of data and events that the device can provide to the platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, installed accessories, and how the unit is integrated into a vehicle. Use this page as a high-level reference and consult manufacturer documentation for the most current device specifications and configuration options.

## Feature Overview

The GOTOP VT-390 is designed for fleet and vehicle security applications and combines location tracking with driver identification, event alerts, media support, and I O connectivity. Its capabilities are focused on improving vehicle oversight, driver accountability, and evidence collection while allowing remote control actions where supported.

- Location reporting and real time tracking for fleet visibility
- RFID driver identification to link drivers to vehicle use
- Camera input for capturing images tied to location or events
- Storage support for media and logs using an SD card
- Event and safety alerts such as SOS, over speed, movement, and harsh driving alarms

## Core Features of GOTOP - VT-390

- RFID driver identification system for authorized user tracking and anti theft workflows
- Camera port and support for logging pictures for situational records
- Two way audio functionality enabling listen and speak for in vehicle communication
- Built in motion sensor to reduce power draw when the vehicle is stationary
- Multiple I O options including digital inputs, outputs, and analog inputs for external sensors and connections
- Support for external fuel sensor connections to monitor fuel related inputs
- Remote control engine functionality to allow authorized remote actions where enabled
- Mileage reporting to track vehicle distance and usage

## How These Features Work with Plaspy

Plaspy receives device reports and translates the VT-390 events and telemetry into platform features for dispatching, alerting, and reporting. The VT-390’s driver ID, images, alerts, and I O events can be surfaced in Plaspy to improve operational decision making and record keeping.

- Driver identification events from the VT-390 can be associated with driver profiles in Plaspy for accountability and trip attribution
- Camera images and SD stored media can be linked to events or location timestamps in Plaspy for incident review
- SOS, movement, over speed, and harsh driving alerts appear as notifications and timeline events inside Plaspy
- Mileage and route data reported by the device feed into Plaspy reports for fleet analytics and maintenance planning
- Digital and analog inputs from the VT-390 can be represented as discrete sensor events in Plaspy for monitoring connected peripherals

## Typical Use Cases

- Fleet operations tracking vehicles, driver assignments, and route mileage
- Driver authentication and anti unauthorized use using RFID based driver identification
- Incident documentation and review using camera images tied to location and alerts
- Safety monitoring with harsh driving, over speed, and movement alerts to improve driver behavior
- Remote intervention scenarios where authorized engine control is needed for security or recovery
- Fuel monitoring setups using external fuel sensor inputs for consumption oversight

## Feature Availability Notes

- Many VT-390 capabilities depend on installed accessories such as RFID tags, camera modules, and SD cards
- Firmware version and hardware revision can change how specific alerts, audio, and remote control behave
- Installation method and vehicle wiring can affect which inputs and outputs are available or recommended
- Regional variants and network availability may influence how the tracker reports over cellular networks
- Review manufacturer release notes and firmware change logs for feature updates and behavior changes
