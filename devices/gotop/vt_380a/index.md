# GOTOP - VT-380A

<div className="device-logo">
![VT-380A](./logo.jpg)
</div>

The GOTOP VT-380A is a vehicle GPS/GPRS tracking device designed for real time tracking and fleet management. It uses an onboard GPS module to obtain position data and leverages GSM connectivity to transmit that data to a specified mobile phone or server. The unit includes internal memory so it can store GPS coordinates when a GPRS connection is unavailable or when configured to log at set intervals. An optional microphone can be routed into the vehicle cabin for monitoring where permitted.

This model is compatible with Plaspy, making it a viable device for organizations that want to combine GOTOP hardware with Plaspy fleet software. Plaspy can receive the VT-380A location updates, stored position uploads, driver ID events and alarm notifications to provide consolidated visibility, reporting, and operational oversight for mixed fleets.

## Key Highlights

- Real time GPS and GPRS based vehicle tracking for continuous location visibility
- Internal memory for storing location data when network connectivity is interrupted
- Driver ID solution using inductive RFID cards and an external reader for driver assignment
- Built in car alarm behavior that can arm and cut fuel and power when the driver card is not present
- Alarm notifications sent to phone and server for prompt awareness of security events
- Optional microphone input for in cabin audio monitoring where required

## How It Works with Plaspy

When used with Plaspy, the VT-380A sends position and status messages that Plaspy can display and manage within its fleet monitoring tools. Plaspy ingests the device messages to provide unified tracking, alerting, and historical playback alongside other fleet assets.

- Show vehicle location and recent movement on Plaspy maps for live monitoring
- Associate driver ID events from the VT-380A with driver records and trip logs
- Upload cached coordinates after connectivity is restored so Plaspy maintains a continuous location history
- Surface alarm events from the tracker as notifications and platform alerts for rapid response
- Include VT-380A devices in Plaspy reporting and operational dashboards for fleet oversight

## Typical Use Cases

- Fleet vehicle location monitoring for logistics and delivery operations
- Driver authentication and accountability using RFID driver ID cards
- Theft deterrence and recovery workflows using automatic arming and alarm notifications
- Route reconstruction and historical location analysis after trips or incidents
- Monitoring of company cars, rental fleets, taxis, and service vehicles
