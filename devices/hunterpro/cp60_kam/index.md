# HunterPro - CP60-KAM

<div className="device-logo">
![CP60-KAM](./logo.jpg)
</div>

The HunterPro CP60-KAM is a GPS tracker designed for vehicle monitoring that adds image capture to standard tracking features. According to the available description, the device can capture images from the monitored vehicle without extra service costs, and it can automatically take a photo when a Panic Event is detected. These visual capabilities provide an additional layer of situational awareness beyond location alone.

As a model compatible with Plaspy, the CP60-KAM can be used alongside Plaspy's fleet and asset monitoring platform to bring both location and visual event context into a single operational view. That compatibility makes the CP60-KAM relevant for organizations that want to combine GPS tracking with photographic evidence for incidents, safety reviews, and operational oversight inside the Plaspy platform.

- Automatic photo capture triggered by Panic Events for emergency documentation
- Image capture feature provided without additional service charge as described
