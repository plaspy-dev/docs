# HunterPro - CP60-KAM Features

This page summarizes the public feature context for using the HunterPro CP60-KAM tracker with Plaspy. It describes the practical capabilities you can expect to see in Plaspy when this model is connected, focusing on user facing functions such as image capture and event driven recording rather than detailed configuration steps.

Exact feature availability can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. Consult the manufacturer for model specific details and confirm which functions are active on your device before relying on any single capability for operational workflows.

## Feature Overview

The CP60-KAM is a GPS tracker designed to provide location awareness alongside in-vehicle image capture. Its features are intended to add a visual layer to traditional tracking, helping operators and owners obtain context around events without subscribing to a separate imaging service.

- GPS location reporting for vehicle tracking and position history
- Onboard image capture that can collect photos from the monitored vehicle
- Automatic image capture triggered by a Panic Event to provide visual context
- Image capture provided without an additional imaging service fee per the device description
- Compatibility with Plaspy so images and events can be viewed alongside location data

## Core Features of HunterPro - CP60-KAM

- GPS location reporting for standard tracking and historical routes
- Built-in image capture capability to obtain photos from the monitored vehicle
- Automatic photo capture when a Panic Event is detected to provide immediate visual evidence
- Visual evidence is intended to complement location and event logs
- Designed for both fleet and personal vehicle monitoring scenarios
- Compatibility with Plaspy for centralized visibility of location and event data

## How These Features Work with Plaspy

Plaspy collects and presents the device's location and event information alongside associated images where the device provides them. That allows teams to correlate photos with position and event timelines for faster incident understanding.

- Photos captured by the device can appear alongside the event timeline in Plaspy
- Panic Event photos are presented with the associated event so operators see context immediately
- Location markers and timestamps help correlate images to specific positions or route points
- Centralized event and history views in Plaspy let users review image-backed incidents across a fleet
- Plaspy detects and integrates compatible trackers so device-reported features are surfaced automatically

## Typical Use Cases

- Fleet incident documentation where a photo helps clarify what occurred during an event
- Driver safety monitoring with immediate visual context for panic or emergency events
- Supporting recovery and investigation efforts with timestamped images linked to location
- Delivery and route verification where images provide proof of vehicle surroundings
- Personal vehicle security to obtain visual context in the event of an alarm or emergency
