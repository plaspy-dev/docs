# HunterPro - CP60-COUNTER

<div className="device-logo">
![CP60-COUNTER](./logo.jpg)
</div>

The HunterPro CP60-COUNTER is a GPS tracker built for passenger transport enterprises to monitor passenger entry and exit. It combines location tracking with passenger counting and transmits data in real time so operators can view passenger flows and vehicle positions from a central computer. The device is described as using GPRS for secure and reliable data delivery and is designed for use in operational transport environments.

As a Plaspy compatible device, the CP60-COUNTER can feed its location and passenger information into Plaspy so fleet managers and dispatchers gain consolidated visibility. Plaspy can present the CP60-COUNTER data alongside other fleet assets, helping teams monitor passenger loads, vehicle movements, and basic operational metrics from a single platform.

## Key Highlights

- Purpose built for passenger transport monitoring and entry exit counting
- Real time data transmission to central systems using GPRS
- Accurate vehicle location reporting for route and fleet visibility
- Designed for reliable operation in transport environments

## How It Works with Plaspy

When used with Plaspy, the CP60-COUNTER provides location and passenger count data that Plaspy ingests and displays in context with other fleet information. This enables centralized monitoring, simple reporting, and operational oversight without requiring multiple separate systems.

- Display live vehicle locations and recent position history on Plaspy maps
- Surface passenger entry and exit counts alongside vehicle status for quick assessment
- Create alerts and notifications in Plaspy based on location events or passenger thresholds
- Generate reports that combine passenger data and trip histories for operational analysis
- Use Plaspy dashboards to monitor multiple CP60-COUNTER units across a fleet
