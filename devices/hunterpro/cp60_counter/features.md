# HunterPro - CP60-COUNTER Features

This page provides a public feature overview for the HunterPro CP60-COUNTER and how its capabilities map to use with Plaspy. It summarizes the device's practical functions for passenger transport enterprises, focusing on location tracking, passenger entry and exit monitoring, and real-time data transmission into a centralized monitoring platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation type, and manufacturer implementation. Use this page as general guidance for operational planning and confirm device-specific details from HunterPro and the device firmware release notes before deployment.

## Feature Overview

The CP60-COUNTER is designed for passenger transport operators who need an integrated view of vehicle location and passenger flows. It combines GPS location reporting with passenger entry and exit monitoring and transmits that information in near real time so central systems can maintain accurate operational status.

- Real time GPS location reporting for vehicle tracking and route awareness
- Passenger entry and exit counting to support ridership monitoring and reporting
- GPRS based data transmission for continuous updates to a central server
- Built for transport environments with a user oriented interface for installation and operation
- Reliable performance aimed at consistent data delivery under normal operating conditions

## Core Features of HunterPro - CP60-COUNTER

- Accurate location tracking using GPS to show vehicle position during operation
- Passenger entry and exit counting to capture boarding and alighting events
- Real time data transmission using cellular data for prompt reporting to a central system
- Vehicle level monitoring from a desktop or centralized platform
- User friendly interface to support configuration and daily use
- Durable construction intended for transport environments to provide consistent service

## How These Features Work with Plaspy

Plaspy receives and normalizes the CP60-COUNTER data stream so fleet managers can view location and passenger events together in one operational interface. Plaspy’s device detection helps present incoming data without requiring manual protocol selection, and the platform surfaces location and event records for oversight, historical review, and reporting.

- Live vehicle positions displayed on Plaspy maps for route and location awareness
- Passenger entry and exit events visible in Plaspy event logs to support ridership analysis
- Time stamped reporting for integration into operational reports and audits
- Historical playback and review of location traces and passenger events for incident analysis
- Centralized visibility for operations teams to monitor multiple vehicles and compare activity

## Typical Use Cases

- Monitoring passenger boarding and alighting counts across a bus or shuttle fleet
- Centralized route tracking for public transport and private shuttle operations
- Collecting ridership data to support route planning and service adjustments
- Shift handover and daily reporting where passenger counts and locations are required
- Operational oversight to confirm vehicles are on assigned routes and schedules
