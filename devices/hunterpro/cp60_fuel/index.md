# HunterPro - CP60-FUEL

![CP60-FUEL](./logo.jpg)

The HunterPro CP60-FUEL is a purpose built GPS tracker for measuring fuel level in transport unit tanks. It uses a coaxial probe design where a metallic outer tube and a central electrode form a capacitive probe that changes capacity with fuel height. The device converts the probe capacity into digital pulses, enabling reliable correlation between measured capacity and fuel volume once a tank calibration procedure is completed.

As a Plaspy compatible device, the CP60-FUEL can feed fuel level data into Plaspy for combined location and fuel visibility across a fleet. That compatibility makes the tracker relevant for operations that need centralized monitoring of fuel volumes alongside standard vehicle tracking, helping fleet managers integrate fuel readings into Plaspy dashboards, reports, and alerts.

## Key Highlights

- Designed specifically for fuel level measurement in transport unit tanks
- Coaxial capacitor style probe provides a linear relationship between fuel height and measured capacity
- Onboard circuitry converts capacity changes into digital pulses for straightforward processing
- Tank calibration procedure allows mapping sensor output to actual fuel volume for improved accuracy
- User friendly design intended for routine fleet monitoring scenarios
- Compatible with Plaspy for centralized fleet and fuel oversight

## How It Works with Plaspy

When integrated with Plaspy, the CP60-FUEL supplies calibrated fuel level information that Plaspy can present alongside location and trip data. This enables fleet operators to monitor fuel volumes in context and use platform features to track changes over time or detect unexpected events.

- Display fuel level trends on Plaspy dashboards for individual vehicles
- Combine location and fuel data to analyze consumption against routes and usage
- Generate reports that include fuel volume history for accounting and reconciliation
- Configure alerts for sudden drops or deviations in fuel levels to support operational response
- Use Plaspy visibility to compare fuel metrics across a fleet for benchmarking and optimization

## Typical Use Cases

- Monitoring fuel volumes in trucks and transport units to control consumption
- Fuel reconciliation for fleet accounting and operational oversight
- Detecting unusual fuel level changes that could indicate losses or maintenance needs
- Integrating fuel data with route and usage reports for operational planning
- Centralized fuel monitoring for mixed fleets using Plaspy dashboards
