# Jointech - JT701 Features

This page provides a public feature overview for the Jointech JT701 and explains how its capabilities relate to Plaspy. It focuses on user facing functions such as positioning, secure access control, tamper detection and event logging that operators can expect to see when the device reports into Plaspy-enabled fleet and logistics platforms.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant and installation method. Manufacturer implementation and device configuration options also affect which functions are active on any given unit, so treat the details here as high level guidance based on the model description.

## Feature Overview

The JT701 is an intelligent tracking lock designed to combine GPS positioning and cellular connectivity with integrated access control and tamper awareness. It is intended to protect cargo and create auditable access trails while providing persistent telemetry for monitoring and incident response.

- Real time GPS tracking and position updates for container, trailer and vehicle monitoring
- Secure access control using RFID credentials and remote password unlocking for auditable access events
- Tamper detection and illegal unlocking alarms to trigger immediate alerts and event records
- Long endurance and low power operation to support remote or long haul deployments
- Compact, rugged design suited to containers, trailers, vans and trucks with history logging for compliance

## Core Features of Jointech - JT701

- Integrated GPS positioning for ongoing location awareness
- Built in cellular connectivity for sending telemetry and events to cloud platforms
- RFID based unlocking to simplify keyless access workflows
- Remote password unlocking to enable controlled remote access when needed
- Tamper detection and illegal unlocking alarm generation for security events
- Event history logging and access records for audit and chain of custody purposes
- Low power design and large capacity battery support for extended field operation

## How These Features Work with Plaspy

When the JT701 reports telemetry and events, Plaspy ingests that data and makes it available in dashboards, alerts and historical reports. This pairing allows operators to combine positional data with access and tamper events for operational oversight and response.

- Live map views and location timeline populated by JT701 GPS reports
- Tamper and illegal unlocking events surfaced as alerts and recorded incidents in Plaspy
- Access logs from RFID and remote unlocks synchronized into event history for audits
- Battery and device health information shown in device summaries to plan maintenance
- Historical telemetry stored for compliance reporting and post incident review

## Typical Use Cases

- Container and cargo security monitoring during transit and storage
- Trailer and van fleet tracking with access event logging for custody control
- Supply chain compliance workflows requiring auditable lock and unlock records
- Protection of high value or regulated shipments with tamper alarm notifications
- Remote asset deployments where long battery life reduces maintenance visits
- Simplified logistics workflows by replacing physical keys with RFID and remote unlock

## Feature Availability Notes

- Firmware versions and feature sets may differ between production runs and over-the-air updates
- Hardware revisions and regional variants can affect supported cellular bands and optional components
- Installation method and mounting location can influence tamper detection behavior and signal performance
- Some access control functions require configuration and appropriate user permissions to operate
- Plaspy automatically detects compatible tracker protocols so devices can report without manual protocol selection

## Why Use Plaspy with These Features

Using the JT701 together with Plaspy gives operators a combined view of location, access events and security alarms in a single platform. That consolidated visibility helps reduce incident response time, supports audit and compliance needs, and enables straightforward review of custody and tamper history across fleet assets.
