# Jointech - JT301A Features

This page provides a public feature overview for the Jointech JT301A and how its capabilities are presented when used with Plaspy. It focuses on the practical, non-sensitive aspects of the device that matter for asset visibility, scheduled location reporting, and sensor-driven alerts inside the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional model variant, and manufacturer implementation. For device-specific configuration, regional compatibility, and the latest technical details consult the manufacturer documentation and firmware release notes.

## Feature Overview

The JT301A is designed as a compact, rechargeable asset tracker that emphasizes long-term, low-maintenance deployments. It provides periodic cellular LBS location updates plus simple sensor monitoring that feeds status and event information into Plaspy for reporting and alerts.

- Scheduled LBS location updates to conserve battery while providing position awareness for assets.
- Door open and close detection to surface loading, unloading, and potential tampering events.
- Illumination monitoring to flag unexpected light exposure that may indicate access or container opening.
- Rechargeable low-power design for extended deployments and easy redeployment across assets.
- Compact, lightweight form factor for straightforward mounting on containers, pallets, and cargo.
- Cost-effective telemetry that complements higher-power GPS devices in mixed fleets.

## Core Features of Jointech - JT301A

- Periodic LBS based location reporting for timed asset position updates.
- Door open and close detection for access and tamper event visibility.
- Illumination monitoring to indicate light exposure or opening events.
- Rechargeable battery and ultra-low power operation to support long-duration use.
- Compact, lightweight enclosure suited for container and pallet attachment.
- Reusable design intended for redeployment across mixed fleet operations.
- Plaspy compatible out of the box for scheduled telemetry and event reporting.

## How These Features Work with Plaspy

When integrated with Plaspy, the JT301A reports its timed location fixes and sensor-driven status messages so operators can monitor assets and receive alerts without continuous GPS telemetry. Plaspy ingests those messages and presents them alongside other fleet data for consolidated visibility and historical review.

- Scheduled LBS updates appear as periodic location points in Plaspy maps and history views.
- Door open and close events generate status notifications and can be used to trigger alerts or workflows.
- Illumination alerts are shown as event markers to help identify potential access or handling incidents.
- Device health and battery status reported by the tracker are available for maintenance planning and asset provisioning.
- Plaspy can combine JT301A feeds with higher-frequency GPS trackers to create a layered visibility strategy across the fleet.

## Typical Use Cases

- Container and pallet monitoring during long transit legs where periodic position checks and tamper alerts suffice.
- Box truck and freight cargo oversight to detect door opens and changes in light exposure during loading and unloading.
- Long-duration logistics deployments that need rechargeable, low-maintenance trackers to reduce total cost of ownership.
- Express package or high-value pallet supervision within distribution centers and last mile staging areas.
- Complementary coverage for mixed fleets, using JT301A devices for economical monitoring of noncritical assets.
