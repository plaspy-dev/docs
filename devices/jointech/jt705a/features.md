# Jointech - JT705A Features

This page describes the public feature context for using the Jointech JT705A with Plaspy. It focuses on user-facing capabilities, operational value, and how JT705A telemetry and security signals are intended to appear in Plaspy workflows. The content is intended for fleet managers, logistics teams, and technical evaluators who want a clear features-oriented overview.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, regional variant, and manufacturer implementation. Where necessary, consult official Jointech documentation for device specific details and confirm capabilities for your intended deployment.

## Feature Overview

The JT705A is a purpose built container monitor and GPS tracker designed to provide continuous location awareness and security status for multimodal cargo. In Plaspy the device is used to bring container focused telemetry and tamper protection into centralized tracking and fleet workflows, helping teams monitor location and security events across long transits.

- Continuous position reporting suitable for container and asset tracking during long transits and multimodal legs.
- Tamper detection and tamper evidence reporting to support chain of custody and customs supervision.
- Remote and on site unsealing capability to support inspections and controlled access events.
- Local OLED display and audible voice prompts for quick field checks and clear on device status feedback.
- Designed for rugged container and refrigerated unit use to reduce risk of device damage and unauthorized removal.

## Core Features of Jointech - JT705A

- Continuous location awareness and position reporting for container level visibility.
- Tamper detection and tamper evidence generation to record security incidents.
- Remote unsealing and on site unsealing functions to support customs and inspection workflows.
- Local OLED display for readable device status when inspecting units in the field.
- Real time voice prompts to provide audible alerts and operational guidance on site.
- High capacity battery design to support extended deployments during lengthy routes and storage.
- Robust mechanical protections including anti theft and anti dismantling design features.

## How These Features Work with Plaspy

When the JT705A is used with Plaspy, its container focused telemetry and security signals feed into a single platform for monitoring, alerts, and historical review. Plaspy ingests reported events and location updates so teams can see container status alongside other fleet assets.

- Live location and historical playback of position reports inside Plaspy for route verification and exception review.
- Tamper and unseal events appear as discrete events so security and compliance teams can track chain of custody.
- Alarm notifications from the device are surfaced in Plaspy for escalation and operational response.
- Local device status indicators such as OLED messages and voice alerts support field verification that can be correlated with Plaspy records.
- Mixed fleet correlation lets operators view JT705A container telemetry alongside other asset data for end to end oversight.

## Typical Use Cases

- Continuous monitoring of shipping containers during long sea, rail, and road transits.
- Customs supervision workflows that use remote and on site unsealing to streamline inspections.
- Security monitoring for high value or risk sensitive consignments that require tamper evidence.
- Integration into cold chain operations where container security is tracked alongside dedicated temperature systems.
- Multimodal logistics where single pane visibility of container location and security status improves handoffs and exception handling.
