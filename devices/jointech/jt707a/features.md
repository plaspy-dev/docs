# Jointech - JT707A Features

This page provides a public feature summary for using the Jointech JT707A with Plaspy. It focuses on user facing capabilities, operational value, and how the device integrates into Plaspy workflows for location telemetry and secure seal monitoring. The goal is to help operations, logistics, and security teams understand what to expect when deploying the JT707A with Plaspy.

Exact feature availability and behaviour can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. For device configuration details, firmware updates, and the latest specifications consult the official Jointech documentation and release notes.

## Feature Overview

The JT707A is a compact GPS seal tracker designed for cargo and logistics applications. It pairs GNSS location reporting with dedicated secure seal monitoring so teams can track both position and seal integrity during transit. When integrated with Plaspy, location fixes and seal events become part of an auditable event trail that supports monitoring, alerts, and historical review.

- GNSS based real time location telemetry for continuous shipment visibility
- Secure seal monitoring with tamper and unseal event notifications
- Rechargeable and disposable battery options to suit short term or longer deployments
- Configurable reporting intervals and geofence alerts to balance battery life and tracking resolution
- Event logging and historical playback for audits, claims handling, and customs checks

## Core Features of Jointech - JT707A

- GNSS location fixes for real time position reporting
- Dedicated seal status monitoring with tamper and unseal detection
- Support for rechargeable and disposable battery configurations
- Configurable reporting intervals to optimize battery use and data frequency
- Geofence event support for location based alerts and monitoring
- Event logging and historical playback for chain of custody and audits
- Compact form factor intended for containers, trailers, vans, and packages
- Compatibility with remote management platforms including integration with Plaspy

## How These Features Work with Plaspy

When the JT707A is connected to Plaspy, its telemetry and seal events feed into Plaspy dashboards and alerting systems so operations teams can maintain situational awareness and an auditable history of incidents.

- Real time location and seal status appear in Plaspy for continuous monitoring
- Tamper and unseal events generate alerts that can be routed to operations or security teams
- Reporting interval settings from the device influence update frequency and battery consumption as reflected in Plaspy
- Geofence triggers and event logs are recorded in Plaspy for compliance and incident review
- Historical playback of tracked routes and seal events supports audits and claims analysis

## Typical Use Cases

- Container security for international and cross border shipments where seal integrity is critical
- Trailer and truckload protection with immediate notification on seal compromise
- Parcel and high value package monitoring combining location and seal status
- Logistics and freight forwarding operations that require auditable event logs for customs and compliance
- Short term single leg shipments using disposable battery option
- Recurring routes or long term asset monitoring using rechargeable battery option
