# Jointech - JT705C Features

This page provides a public feature overview of the Jointech JT705C as used with Plaspy. It summarizes the device capability areas that matter to fleet managers, customs teams, and logistics operators when consolidating location, alarm, and video telemetry into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For implementation specifics, installation guidance, and the latest technical details consult Jointech documentation or your supplier before deployment.

## Feature Overview

The JT705C is a purpose built GPS video lock intended for customs supervision, high value cargo protection, and container monitoring. It combines location reporting with event driven video capture and controlled unlocking to provide an auditable trail of activity during transit.

- Real time GPS tracking paired with onboard video for continuous cargo visibility
- Event triggered video recording that captures clips on impacts, rollovers, or tamper attempts
- Remote live view access and recorded clip references for incident review and verification
- Remote and on spot unlocking options to support compliant access and customs workflows
- Audit ready logs and video evidence suitable for investigations and regulatory record keeping

## Core Features of Jointech - JT705C

- Integrated GPS tracking for position updates during transit
- Onboard video monitoring with event based recording
- Event detection types described by the manufacturer including impact, rollover, and tamper alarms
- Remote live view capability for situational awareness when network conditions allow
- Remote and local unlocking mechanisms to support controlled access
- Recorded video clips and timestamped event logs for audit and evidence purposes
- Designed for customs supervision and high value shipment protection
- Compatibility with Plaspy for telemetry ingestion and centralized management

## How These Features Work with Plaspy

When the JT705C is configured to report into Plaspy, its location, alarm events, and references to video clips feed into the Plaspy dashboard to improve monitoring, alerting, and post incident workflows.

- Real time and periodic location updates appear on Plaspy maps for route monitoring and positional awareness
- Alarm events such as impact, rollover, or tamper generate notifications and event entries inside Plaspy
- Recorded video clips and event logs are referenced in Plaspy incident reports to support investigations and compliance reviews
- Remote live view sessions can be initiated from Plaspy where network and device configuration allow
- Device reporting parameters can be set to point to Plaspy endpoints and Plaspy automatically detects compatible tracker protocols

## Typical Use Cases

- Multimodal container monitoring across road, rail, and port handoffs where auditability is required
