# Jointech - JT706 Features

This page provides a public feature overview for the Jointech JT706 and explains how its capabilities map to Plaspy for container and cargo monitoring. It focuses on practical, non-sensitive descriptions of what the device reports and how that information is used inside Plaspy for visibility, alerts, and historical review.

Exact feature availability and behavior can vary by firmware revision, hardware variant, installation method, and the manufacturer's implementation choices. For device-specific technical limits, installation guidance, and firmware details consult the official Jointech documentation and release notes.

## Feature Overview

The JT706 is a low-profile, container-focused tracker that combines hybrid positioning with continuous environmental sensing to support persistent tracking and condition monitoring of containers and cargo. Its concealed mounting is intended to reduce tampering and enable long-term deployment on refrigerated and dry shipments.

- Hybrid positioning (GPS plus LBS) to improve location coverage in mixed visibility environments.
- Continuous internal temperature and humidity telemetry for cargo integrity monitoring.
- Door status reporting and smart empty/full loading detection for security and operational awareness.
- Concealed, ventilation-compatible mounting designed to reduce detection and tampering risk.
- Real-time reporting and alerts for immediate incident response plus historical logs for compliance and analysis.

## Core Features of Jointech - JT706

- Hybrid GPS and LBS positioning for consistent location fixes across transport modes.
- Temperature telemetry to monitor refrigeration and perishable cargo conditions.
- Humidity telemetry to help detect environmental changes that could affect cargo.
- Door open/close status reporting to track access and support anti-theft workflows.
- Smart empty/full detection to assist in loading checks and asset utilization tracking.
- Low-profile concealed mounting suitable for container ventilation points to reduce tampering.
- Continuous telemetry streaming intended for real-time monitoring and historical records.

## How These Features Work with Plaspy

Plaspy ingests the JT706's location and sensor telemetry so operators can monitor containers in real time, configure alerts, and review historical condition data for compliance and operational decisions. Plaspy automatically recognizes supported tracker data formats and presents device events alongside other fleet information.

- Real-time location updates shown on the Plaspy map for tracking movement across road, rail, and sea legs.
- Sensor readings (temperature and humidity) displayed in dashboards and historical charts for trend analysis.
- Door event visibility in Plaspy event streams to trigger alarms and access logs for security workflows.
- Smart loading state exposed in asset lists to support inventory checks and operational planning.
- Alarm and notification routing in Plaspy based on thresholds or unusual events reported by the JT706.

## Typical Use Cases

- Container anti-theft monitoring with immediate alerts when door events occur.
- Refrigerated cargo oversight to detect temperature or humidity excursions during transit.
- Customs supervision and audit trails with historical location and condition logs.
- Intermodal shipment visibility combining GPS and LBS for continuous coverage.
- Long-haul logistics and fleet planning using loading state and condition history to optimize operations.
- Supply chain exception handling where rapid response to environmental alarms reduces spoilage.
