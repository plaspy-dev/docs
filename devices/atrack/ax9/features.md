# ATrack - AX9 Features

This page summarizes the public feature context for using the ATrack AX9 with Plaspy. It focuses on practical capabilities you can expect when integrating the AX9 into Plaspy for location awareness, OBDII data collection, and driving event visibility. The content here is intended for customers, integrators, and fleet managers seeking an overview of what the device offers when used with Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and the manufacturer's implementation. Use this page as a high level guide and consult the device documentation and firmware release notes for the most current, device-specific details.

## Feature Overview

The AX9 is a plug-and-play OBD-II compatible tracker designed for straightforward vehicle installation and continuous monitoring. Its combination of network flexibility, low-power behavior, and driving event detection makes it suitable for fleet oversight and vehicle diagnostics when paired with a management platform such as Plaspy.

- Simple plug-and-play OBD-II installation for rapid deployment in compatible vehicles
- Support for 2G and 3G networks to maintain connectivity across available mobile networks
- Ultra-low current consumption in deep sleep mode for reduced power draw when idle
- High GPS sensitivity to improve position accuracy and signal acquisition
- Built-in 3-axis G-sensor to detect harsh driving behavior and driving events
- OBDII data collection for vehicle diagnostics and fuel economy related reporting

## Core Features of ATrack - AX9

- OBD-II interface enabling direct connection to a vehicle diagnostics port
- Plug-and-play design that simplifies physical installation and initial setup
- Support for multiple cellular generations including 2G and 3G network operation
- Ultra-low current deep sleep capability to reduce power use when the vehicle is not active
- High sensitivity GPS receiver for consistent positioning in varied environments
- Integrated 3-axis G-sensor for detecting harsh acceleration, braking, and cornering events
- OBDII data collection for access to vehicle diagnostic values and related reporting
- Configurable event control and user-defined report support for customized monitoring

## How These Features Work with Plaspy

When the AX9 is connected to Plaspy, the device’s location, event signals, and OBDII-derived data can be surfaced for monitoring, reporting, and operational workflows. Plaspy auto-detects many tracker protocols and consolidates incoming device data so teams can view and act on fleet information in one place.

- Location and trip data appear in Plaspy for live monitoring and historical route playback
- Harsh driving events flagged by the AX9 G-sensor are shown as event markers for review
- OBDII-derived diagnostics and economy indicators can be included in device reports and logs
- Low-power and sleep behavior influence device online/offline status and wake events visible in Plaspy
- Configurable event control on the device can map to Plaspy alerts and scheduled reports
- Plaspy aggregates device events and user-defined reports for operational oversight

## Typical Use Cases

- Fleet management and route monitoring for small and medium vehicle fleets
- Usage based insurance programs that combine location and driving behavior data
- Car rental oversight including trip history and driving event review
- Teen or young driver monitoring with event-based feedback on driving behavior
- Vehicle diagnostics review and fuel economy analysis using OBDII data
- Long term vehicle presence monitoring where low power draw is important

## Feature Availability Notes

- Firmware and software revisions may enable, change, or restrict specific features over time
- Hardware revisions and regional product variants can affect network compatibility and available interfaces
- OBDII data availability depends on vehicle make, model, and the specific OBDII parameters supported by that vehicle
