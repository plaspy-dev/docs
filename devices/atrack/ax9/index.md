# ATrack - AX9

![AX9](./logo.jpg)

The ATrack AX9 is a compact OBDII GPS tracking unit designed for vehicle monitoring and diagnostics. It provides plug and play installation through the OBDII interface and supports 2G and 3G wireless networks for data transmission. The AX9 emphasizes efficient power use with an ultra low current deep sleep mode, and it includes high GPS sensitivity plus a built in 3 axis G sensor for detecting harsh driving events.

As a Plaspy compatible device, the AX9 can feed location, event and vehicle data into Plaspy for consolidated fleet oversight. Its OBDII data collection and configurable reporting capabilities make it suitable for organizations that want diagnostic insight alongside location tracking. Plaspy can ingest AX9 data to provide live visibility, historical reports, and operational alerts while keeping deployment straightforward.

## Key Highlights

- Plug and play OBDII installation for quick setup in most vehicles
- Support for 2G and 3G network connectivity to transmit tracking data
- Ultra low current consumption in deep sleep mode for long term operation
- High GPS sensitivity for reliable positioning in varied environments
- Built in 3 axis G sensor to detect and report harsh driving behavior
- OBDII data collection for basic vehicle diagnostics and fuel economy analysis
- User defined reports and configurable event controls for tailored monitoring

## How It Works with Plaspy

When used with Plaspy, the AX9 streams location and vehicle event data to the platform so teams can monitor assets in one place. Plaspy processes the incoming data to display live positions, generate alerts, and produce historical reports for operational review.

- Real time location visibility and map tracking for fleet oversight
- Event alerts based on harsh driving detection and other configurable triggers
- Historical trip and mileage reporting using collected OBDII and GPS data
- Custom report generation to analyze driver behavior and vehicle usage
- Centralized dashboarding to combine AX9 feeds with other device data in Plaspy

## Typical Use Cases

- Fleet management and vehicle tracking for small to medium sized fleets
- Car rental monitoring for usage and basic diagnostics
- Usage based insurance and telematics driven programs requiring driving event data
- Teen or family driver monitoring to observe driving habits
- Long term vehicle tracking where low power consumption is important
