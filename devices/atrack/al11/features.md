# ATrack - AL11 Features

This page provides a public feature overview for the ATrack AL11 and explains how its capabilities apply when used with Plaspy. It focuses on user-facing features and practical uses of the AL11 for asset and vehicle monitoring while describing how those features surface inside Plaspy for operational visibility.

Exact feature availability for any specific AL11 unit can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation choices. Where relevant, this page notes those variations and encourages checking official manufacturer documentation for the most current device details.

## Feature Overview

The ATrack AL11 is positioned as a rugged, cellular-capable tracker for mobile assets. It combines modern cellular connectivity with a weatherproof enclosure and a simple wiring footprint, making it suitable for many outdoor and vehicle tracking scenarios.

- 4G Cat.1 and 3G cellular connectivity for timely location reporting and data transmission
- IP67 rated enclosure for protection against dust and temporary water immersion
- Built-in 3-axis accelerometer to detect impacts and movement events
- Compact design with a 3-wire connection for straightforward and discreet installation
- Designed for continuous location updates to support real-time monitoring workflows

## Core Features of ATrack - AL11

- 4G Cat.1 and 3G cellular support for reliable mobile data connectivity
- IP67 rugged housing to withstand dust and moisture exposure in field environments
- Integrated 3-axis accelerometer for detecting impacts and motion events
- Simple 3-wire installation option suited for covert or space-constrained fittings
- Real-time location reporting capability for up-to-date asset visibility
- General compatibility with common tracking platforms including Plaspy

## How These Features Work with Plaspy

Plaspy can receive and interpret location and event reports from compatible AL11 devices to provide location visibility, event history, and operational monitoring. Plaspy automatically detects many tracker protocols and presents incoming data in its device views so teams can act on location and motion events without custom parsing.

- Real-time position updates appear on Plaspy maps for continuous tracking and historical playback
- Movement and impact events from the AL11 accelerometer can be shown as events in Plaspy timelines
- IP67-rated deployment makes the AL11 suitable for assets tracked in outdoor Plaspy fleets
- Simple wiring and compact installation reduce deployment time for devices reported into Plaspy
- Plaspy supports common transport methods and can accept reports from compatible devices with automatic protocol detection

## Typical Use Cases

- Fleet vehicle tracking where rugged enclosures and cellular reporting are required
- Monitoring of trailers and mobile equipment that operate outdoors or in dusty environments
- Asset tracking where discreet installation is preferred for security or aesthetic reasons
- Event detection use cases where impact or sudden movement should be logged and reviewed
- Real-time location monitoring to support dispatch, recovery, and operational oversight

## Feature Availability Notes

- Manufacturer firmware and feature sets may change; the exact behavior of motion reporting and event thresholds can vary by firmware version
- Hardware revisions or regional variants may affect supported cellular bands and certifications
- Installation type and wiring will influence available inputs and how the device reports certain events
- Plaspy integration depends on the device being configured to report to Plaspy endpoints and on compatible protocol settings
- For the most accurate, unit-specific details consult the manufacturer's official product documentation

## Why Use Plaspy with These Features

Using the ATrack AL11 with Plaspy gives organizations a straightforward path to turn device reports into operational insights. Plaspy presents location data and motion events in context, enabling dispatch, monitoring, and historical review without requiring custom parsing or extensive configuration for supported trackers.
