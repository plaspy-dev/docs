# ATrack - AL1

![AL1](./logo.jpg)

The ATrack AL1 is a compact and easy-to-install vehicle GPS tracker that utilizes GPS and GSM/GPRS communication to provide real-time monitoring and remote control capabilities. With its intelligent event control engine, users have the flexibility to define various combinations of vehicle conditions and generate customized actions to meet their unique requirements.

One of the standout features of the AL1 is its high accuracy GPS positioning, ensuring precise and reliable location tracking. Additionally, the tracker is equipped with a built-in 3-axis G-sensor, allowing for the detection of harsh driving behavior events. This feature is particularly useful for fleet management, as it enables the monitoring of driver behavior and promotes safer driving practices.

The AL1 also offers configurable real-time tracking and logging, giving users the ability to monitor vehicle movements and generate detailed reports. It supports data communication through SMS, USSD, TCP, and UDP, providing multiple options for data transmission. Furthermore, the tracker supports FOTA \(Firmware Over-The-Air\) firmware upgrades using FTP, ensuring that the device can be easily updated with the latest features and improvements.

With its small form factor and easy installation, the ATrack AL1 is an ideal choice for a wide range of applications, including vehicle tracking, fleet management, and asset tracking. Its robust feature set, including GSM jamming detection, configurable GPIOs, and support for external fuel level sensors, makes it a versatile and reliable GPS tracker for any tracking needs.

### Key Features:

- Small and easy installation
- Data communication by SMS/USSD/TCP/UDP
- High accuracy GPS positioning
- GSM jamming detection
- Built-in 3-axis G-sensor
- FOTA firmware upgrade using FTP
- Configurable Real Time Tracking & Logging
- Intelligent event control engine
- 3 Configurable GPIOs
- Roaming preference settings
- Harsh driving behavior events
- Configurable power management
- 32 user defined geofences
- Support external fuel level sensor
