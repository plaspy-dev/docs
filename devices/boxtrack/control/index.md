# BoxTrack - Control

<div className="device-logo">
![Control](./Logo.png)
</div>

The Boxtrack Anti Theft Control is a compact vehicle GPS tracker built for real time monitoring and security. Designed to provide accurate position updates with reported accuracy under 5 meters, the Control model includes anti theft features such as a remote engine cut off function, an SOS panic button, live audio monitoring via an external microphone, and a G sensor for impact and harsh driving detection. It also offers wide area connectivity and onboard memory to retain reports when communication is interrupted.

As a device compatible with Plaspy, the Control brings those security and monitoring capabilities into Plaspy's fleet management environment. Plaspy can ingest the tracker's location and event messages, surface alerts for rapid operational response, and provide centralized visibility across vehicles equipped with the Control. This combination is useful for organizations that need anti theft protection alongside everyday fleet oversight.

## Key Highlights

- High accuracy real time location reporting with reported position accuracy under 5 meters
- Remote engine cut off capability for theft response and vehicle immobilization
- SOS panic button for immediate emergency signalling
- Live audio monitoring support using an external microphone
- G sensor for impact detection and driving behavior alerts
- Onboard memory to store up to 2,000 reports for continuity during signal interruptions
- Backup battery providing several hours of autonomy to maintain tracking in critical situations

## How It Works with Plaspy

When integrated with Plaspy, the BoxTrack Control feeds position and event data into the Plaspy platform so teams can monitor devices from a single interface. Plaspy surfaces location history and alerts, and helps operators act on events reported by the Control when remote actions are available.

- Centralized live tracking and map visibility for vehicles equipped with the Control
- Alerting and notification for SOS events, G sensor incidents, and tamper or impact detections
- Access to historical reports and trip data derived from the device and its internal memory
- Remote command support where the device reports commandable functions, enabling coordinated responses through Plaspy
- Reporting and exported logs to support operational review and incident follow up

## Typical Use Cases

- Anti theft protection for cars, vans, or light commercial vehicles
- Fleet monitoring where rapid response to unauthorized use is required
- Emergency response workflows using the SOS panic button for driver safety
- Incident investigation using stored reports and impact event history
- Operations that need continuous tracking even during temporary signal loss
