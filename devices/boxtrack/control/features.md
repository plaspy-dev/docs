# BoxTrack - Control Features

This page provides a public overview of the BoxTrack Control tracker and how its supported features are commonly used with the Plaspy platform. It focuses on user facing capabilities, practical value, and the ways those features are typically surfaced inside Plaspy for monitoring and operational oversight.

Exact feature availability and behaviour can vary by device firmware, hardware revision, regional model, and installation choices. Always confirm current, device specific capabilities with the manufacturer and check that your deployment and firmware version support the functions you plan to use with Plaspy.

## Feature Overview

The BoxTrack Control is an anti-theft focused GPS tracker designed for continuous vehicle monitoring and remote intervention options. It combines precise location reporting with security-focused functions and local data buffering to reduce information gaps when connectivity is intermittent.

- High accuracy location reporting suitable for vehicle tracking and recovery operations
- Remote engine cut-off and power control options for theft response when supported by installation
- SOS panic button for emergency alerts from the vehicle
- Live audio monitoring via an external microphone where the microphone is installed and enabled
- Impact and harsh driving detection via G-sensor to flag collisions or abrupt events
- Local data storage to retain up to 2,000 reports when network connectivity is unavailable

## Core Features of BoxTrack - Control

- GPS position accuracy reported at under 5 meters for improved location certainty
- Remote engine cut-off capability that can be activated via remote commands when device and installation support it
- SOS panic button for immediate alerting of emergency events
- Live audio input support through an external microphone for situational monitoring
- G-sensor based impact and harsh driving detection for event-based alerts
- 4G/2G/GPRS cellular connectivity to maintain communications across network conditions
- Internal memory able to store approximately 2,000 reports for temporary buffering
- Integrated backup battery providing limited autonomy for continued operation during power loss

## How These Features Work with Plaspy

When a BoxTrack Control device is connected to Plaspy, the platform presents location and event information to help teams monitor assets and respond to incidents. Plaspy reflects device-reported positions, alerts, and buffered data so that operations staff can maintain situational awareness.

- Real-time and near real-time location display on Plaspy maps, with position accuracy shown according to device reports
- Event logs for SOS activations, G-sensor events, and other device-generated alerts visible in the timeline and event viewer
- Buffered reports uploaded from internal memory after connectivity resumes, reducing data gaps on Plaspy
- Remote command actions such as engine cut-off or siren activation can be exposed in Plaspy where the device firmware and deployment permit platform-based control
- Audio monitoring or recorded audio access may be presented in Plaspy when the device and deployment allow live audio streaming or storage

## Typical Use Cases

- Vehicle anti-theft protection with remote disable options and recovery support
- Emergency alerting using the SOS panic button for drivers or occupants
- Incident investigation and post-event review using G-sensor event logs and location history
- Continuous tracking for high-value vehicles where backup battery and internal memory reduce data loss risk
- Security patrol or supervised asset movement with live monitoring options when audio is enabled
- Operations that require a combination of remote intervention and audit trails for compliance or insurance purposes

## Feature Availability Notes

- Manufacturer firmware and hardware revisions may add, remove, or change behavior of features; verify the exact feature set for your device serial or model revision
- Some functions require specific installation steps or external accessories, for example a microphone, siren, or wiring for engine cut-off and ignition sensing
- Cellular connectivity performance and supported bands vary by region and model variant; confirm regional compatibility for 4G or 2G operation
- Internal memory and backup battery capacity are subject to usage patterns, reporting frequency, and device configuration
- Plaspy visibility of certain controls (for example remote engine shutdown or live audio) depends on device configuration, permissions, and whether those capabilities are implemented in the deployed firmware
