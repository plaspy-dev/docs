# AoYa - AY-T801 Features

This page provides a public, non-sensitive overview of the AoYa AY-T801 features and how those capabilities are commonly used with Plaspy for vehicle monitoring and fleet oversight. It is intended to help users understand the device's practical functions, what Plaspy displays and manages, and where to look for more device specific details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation wiring, and the manufacturer's configuration. Always confirm current capabilities and any implementation differences with the official manufacturer documentation before finalizing an installation or operational plan.

## Feature Overview

The AY-T801 is a compact vehicle tracker that blends Beidou, GPS, and LBS positioning to provide location awareness and event reporting. It is designed for discreet installation in cars and supports a range of security and tracking functions useful for individual vehicles and multi vehicle monitoring.

- Dual mode positioning using Beidou and GPS with LBS assist for broader coverage
- Track recording with playback and track compensation for clearer history
- Remote oil or engine cut capability combined with ACC detection for control and status
- Multiple alarm types including power, vibration, low, speed, fence, and light alarms
- Electronic fence (geofence) functionality for zone entry and exit alerts
- Web platform and synchronized mobile app access for real time monitoring and control

## Core Features of AoYa - AY-T801

- Beidou and GPS positioning with LBS assistance for redundant location reporting
- Compact ultra small body for discreet installation in a variety of car models
- Track playback and track compensation to review historical routes
- Remote oil off or engine cut capability where supported by the vehicle installation
- ACC detection to report ignition or accessory status changes
- Electronic fence support for zone based alerts
- Multiple alarm methods including power alarm, vibration alarm, low alarm, speed alarm, fence alarm, and light alarm
- Multi vehicle monitoring available under a main account via web and mobile interfaces

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible trackers like the AY-T801 to present maps, history, and alerts in a single monitoring platform. When the device is configured to report to Plaspy, the platform shows position updates, plays back recorded routes, and surfaces alarms and status changes as events for operators to review.

- Live location displayed on Plaspy maps using the device position reports
- Route history and track playback available in Plaspy when the tracker supplies recorded points
- Geofence events and alarms forwarded into Plaspy as location based notifications
- Alarm conditions such as power, vibration, speed, and fence triggers appear as event records in Plaspy
- Remote control actions such as engine or fuel cut can be initiated from Plaspy where the device and installation allow remote commands
- Plaspy automatically detects compatible tracker protocols and accepts device connectivity to the platform, simplifying setup for supported devices

## Typical Use Cases

- Vehicle theft deterrence and recovery with alarm monitoring and geofence alerts
- Fleet route review and driver oversight using track playback and route history
- Remote immobilization of a vehicle after authorization for security or asset protection
- Real time monitoring of ignition and vehicle status through ACC detection
- Centralized management of multiple vehicles from a single main account on web or mobile
- Alerting operations teams to abnormal conditions such as unauthorized movement or rapid speed events

## Feature Availability Notes

- Manufacturer firmware versions and hardware revisions can change feature sets and behavior; verify the tracker firmware on the unit you receive
- Some functions such as remote engine or fuel cut require appropriate installation and vehicle wiring to be present and enabled
