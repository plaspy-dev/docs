# AoYa - T128GPS Features

This page describes the public feature context for using the AoYa T128GPS tracker with Plaspy. It focuses on practical, user-facing capabilities and how those capabilities are reflected in a Plaspy deployment rather than on private configuration or undocumented behavior.

Exact feature availability and reporting behavior can vary depending on the device firmware, hardware revision, installation method, and how the manufacturer implements specific functions. For definitive device-level details consult the manufacturer documentation and firmware release notes.

## Feature Overview

The AoYa T128GPS is a compact, magnetically mounted tracker intended for personal and asset tracking. It combines easy placement with standard GPS and GSM tracking capabilities to provide location awareness and event reporting that can be integrated into fleet and asset management platforms such as Plaspy.

- Strong magnetic housing for quick and secure installation on metal surfaces
- Built-in GPS and GSM antennas for location determination and cellular reporting
- Real time tracking support to monitor location updates as the device reports them
- Geofencing support for virtual boundary monitoring and alerts
- Rechargeable battery power for portable and temporary installations
- Built-in SOS button for emergency signaling when the tracker is configured to report that event

## Core Features of AoYa - T128GPS

- Magnetic design for tool free mounting and flexible placement on metal assets
- Compact and lightweight form factor suited for discreet placement
- Integrated GPS and GSM antennas for position fixes and cellular communication
- Real time location updates when the tracker is reporting
- Geofence capability to define virtual zones and receive entry or exit alerts
- Rechargeable internal battery for portable tracking needs
- Built in SOS button to trigger an emergency event notification
- Compatibility with common consumer devices for access to tracking data and alerts

## How These Features Work with Plaspy

Plaspy provides a central platform to receive, normalize, and display the position and event information reported by the T128GPS. When the tracker sends location or event data, Plaspy surfaces that information in maps, event logs, and notification channels so teams can act on it.

- Live location display and recent position history as reported by the tracker
- Geofence events shown as alerts or timeline entries in Plaspy when the device reports zone transitions
- SOS events flagged in Plaspy event streams so operators can identify emergency signals
- Device metadata such as mounting notes or model identifier available for asset management
- Access the tracker data from desktop and mobile devices through Plaspy’s interface

## Typical Use Cases

- Temporary vehicle monitoring for rentals, maintenance, or short term assignments
- Asset tracking of wheeled equipment, containers, or other portable items with metal surfaces
- Personal safety monitoring where discreet placement and an SOS function are useful
- Short term deployment for recovery or surveillance where magnetic mounting speeds installation
- Remote visibility for field assets that need periodic or continuous location updates

## Feature Availability Notes

- Feature presence and behavior depend on the tracker firmware and firmware version
- Hardware revisions and regional variants may change antenna performance and cellular compatibility
- Installation method and placement affect GPS reception and reporting frequency
- SOS behavior and notifications depend on how the device is configured and what data it sends
- Confirm supported capabilities and configuration steps with the manufacturer documentation
