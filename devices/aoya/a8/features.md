# AoYa - A8 Features

This page provides a public feature summary for the AoYa A8 personal GPS tracker and explains how its capabilities map to monitoring and operational visibility in Plaspy. It focuses on non-sensitive, user-facing functionality and the practical value the A8 brings when used with Plaspy for real-time location and safety monitoring.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a high-level guide to features known from the AoYa A8 product description and confirm device-specific behavior with the manufacturer documentation when needed.

## Feature Overview

The AoYa A8 is a compact personal tracker designed for portable use and continuous monitoring. It pairs basic safety functions with live tracking, making it suitable for personal safety and asset monitoring scenarios where small size and remote listening are relevant.

- Compact and lightweight form factor for discreet carry or attachment
- Quad band GSM support for broad regional mobile coverage
- Live tracking capability for viewing real-time location through web or mobile platforms
- SOS button to send distress signals when immediate attention is needed
- Voice monitoring and built-in microphone enabling remote listening and two-way communication
- Rechargeable Li ion battery rated at 450 mAh with typical operational runtime stated as 3 to 5 days depending on use

## Core Features of AoYa - A8

- Small dimensions and low weight for portable personal tracking
- GSM band support for 850 900 1800 1900 MHz to match common cellular networks
- Dedicated SOS button for quick distress signaling
- Voice monitoring functionality and integrated microphone for remote audio listening and two-way voice
- Real-time live tracking accessible via web or mobile applications
- Rechargeable 450 mAh Li ion battery with multi-day runtime under typical conditions

## How These Features Work with Plaspy

Plaspy is designed to present device activity and location information in a clear, operational view. When an AoYa A8 reports into Plaspy, the platform surfaces location and event activity so teams can monitor status and respond to incidents. Plaspy also provides automatic protocol detection for compatible trackers to simplify onboarding.

- Live location updates from the A8 appear on Plaspy maps for continuous monitoring
- SOS events from the A8 can be surfaced as alerts or events in Plaspy to prompt rapid response
- Voice monitoring and two-way audio capability on the device are noted as supported device features and can be invoked according to the device and local rules; Plaspy shows device connectivity and available features
- Plaspy reflects device online and reporting status so administrators can see when the A8 is actively reporting
- Plaspy automatically detects tracker protocol and accepts connections for configured trackers; devices may be set to report using UDP or TCP to the Plaspy server domain
- Platform visibility helps correlate device location with timestamps and operational context for oversight
