# AoYa - A10 Features

This page provides a public feature overview for the AoYa A10 GPS tracker and explains how those features relate to using the A10 with Plaspy. It is intended to describe user-facing capabilities and practical value when the device is connected to Plaspy for location visibility and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For the most current device specifics and any region or model variants consult the manufacturer documentation referenced at the end of this page.

## Feature Overview

The AoYa A10 is a compact automotive GPS tracker designed to deliver reliable position information and extended field use. Its small size and communication options make it suitable for discreet installation in vehicles while providing continuous position updates for monitoring and fleet workflows.

- Compact footprint that supports flexible installation in personal vehicles and fleet assets.
- Multi network connectivity for continuous position reporting across common cellular and wireless networks.
- High precision GNSS positioning using a UBLOX GPS chip with consumer grade accuracy in typical conditions.
- Built in rechargeable battery that supports multi day operation for situations without constant vehicle power.
- Integrated microphone to capture ambient sound where device firmware and local regulations permit.

## Core Features of AoYa - A10

- Compact automotive form factor with small physical dimensions for space constrained installations.
- Support for GSM GPRS and Wi Fi networks enabling location reporting in a variety of coverage conditions.
- UBLOX GPS receiver providing high sensitivity and positioning accuracy suitable for vehicle tracking and route reconstruction.
- Rechargeable 3.7V 450mAh Li ion battery designed to support extended runtime between charges.
- Up to several days of operation on battery power depending on reporting frequency and network conditions.
- Built in microphone for audio monitoring capabilities where firmware support and legal requirements allow.
- Designed for vehicle tracking use cases such as on demand location checks and periodic reporting.

## How These Features Work with Plaspy

Plaspy receives and displays the A10 device position reports so users can monitor location, view history, and manage assets from a single platform. Plaspy automatically detects many tracker protocols and accepts standard position updates from compatible devices like the A10.

- Live position updates appear on Plaspy maps allowing real time visibility of vehicle location.
- Historical tracks and location history can be reconstructed in Plaspy using the device position reports.
- Location based workflows in Plaspy such as geofence monitoring and route review use the A10 position feed.
- Device state and connectivity information reported by the tracker is surfaced in Plaspy to aid operational oversight.
- Plaspy treats the A10 as a compact vehicle tracker and organizes device data alongside other fleet assets for unified management.

## Typical Use Cases

- Real time vehicle location monitoring for personal cars and light fleet vehicles.
- Short term tracking for rental or shared vehicles where compact concealment is needed.
- Route tracking and review for small fleet operations using historical position data.
- Position checks during trips when vehicle power is intermittent or unavailable.
- Asset oversight where a small, battery powered tracker simplifies installation.

## Feature Availability Notes

- Functionality such as microphone availability, reporting intervals, and network support can depend on the device firmware and regional hardware variants.
- Battery runtime is affected by reporting frequency, cellular and Wi Fi signal conditions, and configuration choices made during installation.
- Some features may require specific firmware settings or manufacturer configuration to be enabled.
