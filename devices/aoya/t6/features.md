# AoYa - T6 Features

This page describes the public feature context for using the AoYa T6 GPS tracker with Plaspy. It summarizes the tracker capabilities that are relevant to location visibility and fleet monitoring inside the Plaspy platform and explains how those capabilities translate into practical information for operators.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and how the manufacturer has implemented particular functions. Where possible this page references the device characteristics supplied by the manufacturer, and users should consult the official AoYa documentation for precise, model specific details.

## Feature Overview

The AoYa T6 is a compact automotive GPS tracker designed for discreet vehicle installation while providing multi‑mode positioning and network connectivity. Its combination of GPS, assisted GPS, and LBS positioning plus support for common cellular networks make it suited for continuous location reporting and basic vehicle monitoring.

- Real time position reporting using GPS with AGPS assistance for faster fixes
- LBS fallback to provide location where GPS coverage is limited
- Support for multiple cellular networks to maintain connectivity across regions
- Very small form factor and light weight for simple, discreet installation
- Built in emergency backup battery to continue reporting during vehicle power loss

## Core Features of AoYa - T6

- GPS tracking with AGPS assisted positioning for improved fix times
- LBS based location fallback for areas with weak satellite signals
- Support for GSM GPRS and CDMA network connectivity for data reporting
- Reported GPS accuracy in the manufacturer description of around 5 to 10 meters
- GPS sensitivity specification provided by the manufacturer
- Compact physical dimensions and low weight suited to hidden or space constrained installs
- Emergency internal battery to preserve location reporting during main power interruption
- Designed primarily for automotive power supply with onboard backup battery

## How These Features Work with Plaspy

Plaspy receives and displays the location reports and status information the T6 sends, making device position and recent history available for monitoring and operational decision making. Plaspy also detects the tracker protocol automatically so device data appears in the platform without manual protocol selection.

- Live location plotted on the Plaspy map for route visibility
- Position history and timestamps retained for playback and review
- Power and connectivity events from the device visible in Plaspy when the tracker reports them
- Network connectivity behavior reflected in device online/offline status on Plaspy
- AGPS and LBS supported positioning contributes to improved location availability inside Plaspy

## Typical Use Cases

- Basic fleet vehicle tracking where compact installation is needed
- Discreet location monitoring for loaner or rental vehicles
- Vehicle recovery support by keeping recent and live positions available
- Monitoring vehicle movement and location history for operational oversight
- Use in mixed coverage environments where LBS can provide fallback location

## Feature Availability Notes

- Firmware level can change how frequently the device reports and which parameters it includes
- Hardware revisions or regional variants may alter supported cellular bands or network behavior
- Installation method and antenna placement materially affect GPS accuracy and performance
- Emergency battery capacity and behavior under power loss are manufacturer specified and can vary
- Always confirm features and supported configurations with the official AoYa documentation

## Why Use Plaspy with These Features

Using the AoYa T6 with Plaspy provides a straightforward way to turn the device's position reports into operational visibility. Plaspy aggregates live positions, historical tracks, and reported status so teams can monitor assets, review recent movements, and maintain awareness of device connectivity across a deployment.

Learn more about how Plaspy can visualize and manage vehicle trackers on the Plaspy website https://www.plaspy.com.
