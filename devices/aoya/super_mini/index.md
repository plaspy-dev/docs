# AoYa - super mini

![super mini](./logo.jpg)

The AoYa Super Mini GPS Tracker is a compact and versatile tracking device that combines GPS LBS and WIFI positioning with a built in light sensor to provide accurate real time location information. Its small footprint is designed for discreet vehicle monitoring while offering common fleet tracking features such as geo fencing history route playback and multiple alarm types for unusual events.

As a Plaspy compatible device, the super mini can feed location and event data into the Plaspy platform to provide centralized visibility and management. Plaspy users can leverage the tracker’s real time updates and alarm events to monitor vehicle movements, review past routes, and set operational rules without needing complex hardware changes.

## Key Highlights

- Compact form factor suitable for discreet vehicle tracking and small fleet use
- Multiple positioning methods for improved location accuracy in varied environments
- Built in light sensor enabling light alarm events for unauthorized access detection
- Real time tracking capability for up to date location visibility
- Geo fencing support to define virtual areas and trigger entry and exit alerts
- History route playback for reviewing past movements and operational analysis

## How It Works with Plaspy

When paired with Plaspy, the AoYa super mini delivers its tracking and alarm events into the Plaspy dashboard so fleet managers and operators can monitor assets from a single interface. Plaspy consolidates the device data to support operational oversight, alerts, and reporting.

- Centralized map view for live location and movement of vehicles tracked by the super mini
- Alert forwarding for key events such as light alarm power cut over speed and vibration to help detect incidents
- Geo fence notifications and event history to support compliance and perimeter monitoring
- Route history playback inside Plaspy for trip review and performance analysis
- Remote immobilization events available in Plaspy workflows where the tracker supports engine or fuel cut functions

## Typical Use Cases

- Car rental monitoring and security for discreet asset tracking and return verification
- Small fleet management where compact devices and real time visibility are priorities
- Theft prevention and recovery workflows using alerts and remote immobilization features
- Route verification and historical review for billing or operational auditing
- Situations requiring discreet installation and non intrusive monitoring

The AoYa super mini pairs a small physical profile with a set of practical tracking features that address common needs in vehicle monitoring and small fleet operations.
