# AoYa - A202 Features

This page provides a public overview of the AoYa A202 GPS tracker and how its features relate to use with Plaspy. It summarizes the practical capabilities you can expect when pairing the A202 with Plaspy for vehicle and asset tracking, and it highlights what Plaspy displays and manages from the device data.

Exact feature availability for any A202 unit can vary by firmware version, hardware revision, installation method, and manufacturer configuration. The information below is based on the device description provided and on general Plaspy compatibility notes; consult the manufacturer for the most current device specifications.

## Feature Overview

The AoYa A202 is positioned as a compact automotive tracker designed for reliable location reporting and extended deployments. It combines cellular connectivity and a GNSS receiver to deliver real time location and event information suitable for fleet and personal tracking scenarios.

- Compact dimensions and lightweight form factor for easy installation and concealment in vehicles
- GSM GPRS cellular connectivity to send location and event data for real time tracking
- UBLOX GNSS receiver with a stated position accuracy around 5 meters and high sensitivity
- Speed monitoring and geofence alert support for basic movement and boundary reporting
- Large 10000 mAh Li ion battery to enable extended tracking without frequent recharging
- Waterproof and dustproof construction for durable operation in challenging environments

## Core Features of AoYa - A202

- Compact physical size and low weight for discreet installation in vehicles
- GSM GPRS network support for continuous data uplink to tracking platforms
- UBLOX GNSS module specified for high sensitivity and sub 5 meter positioning accuracy
- Speed measurement capability to monitor vehicle movement
- Geofence alert capability to detect entry or exit of defined areas
- Large capacity Li ion battery for prolonged operation between charges
- Dustproof and waterproof enclosure for ruggedized use
- Suited for automotive and asset tracking installations

## How These Features Work with Plaspy

Plaspy receives device reports and presents location and event information in the platform so operators can monitor assets and vehicles in real time. The A202's core reporting elements translate into visible items in Plaspy's monitoring tools and reporting workflows.

- Real time location points from the A202 appear on Plaspy maps for continuous position awareness
- Speed information is available to Plaspy so operators can review movement patterns and identify potential issues
- Geofence events reported by the device generate notifications and event records in Plaspy when configured
- Long battery life helps keep devices online longer between service intervals, improving historical coverage in Plaspy
- Plaspy automatically detects supported tracker protocols and accepts data from compatible A202 units
- Devices configured to communicate with Plaspy can use common server settings supported by the platform

## Typical Use Cases

- Fleet vehicle tracking and route oversight
- Personal vehicle monitoring for theft deterrence and recovery
- Long term asset tracking where infrequent recharging is preferred
- Remote vehicle deployments operating in wet or dusty conditions

- Geofence based location monitoring for site entry and exit control
