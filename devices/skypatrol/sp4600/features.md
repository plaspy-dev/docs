# SkyPatrol - SP4600 Features

This page provides a public, feature-oriented overview of the SkyPatrol SP4600 and how its capabilities are presented when the device is used with Plaspy. It explains the practical functions that matter for fleet tracking, telematics, and vehicle location workflows and focuses on the SP4600 series features that are relevant in a Plaspy deployment.

Exact feature availability for any individual SP4600 unit can vary with firmware version, hardware revision, the specific 2G or 3G variant, installation choices, and manufacturer settings. For final device behavior and the latest technical details consult the official SkyPatrol documentation.

## Feature Overview

The SkyPatrol SP4600 Series is a family of vehicle focused trackers designed for demanding fleet and telematics applications while remaining suitable for mainstream vehicle tracking and recovery use. The series provides cellular connectivity options, remote device management, geofencing capacity, and detection features that support operational monitoring.

- Quad band GSM GPRS connectivity with 2G and 3G variant options for broad regional coverage
- Over the air device management and maintenance to support remote configuration and updates
- Firmware update over the air capability to simplify keeping devices current
- Hardware based geofence support with up to 28 programmable geofences for location based events
- GSM jamming detection to report possible interference events to the platform

## Core Features of SkyPatrol - SP4600

- Quad band cellular connectivity available in 2G and 3G versions for flexible deployment
- Over the air device management for remote configuration, provisioning, and maintenance
- FOTA support to receive firmware updates without physical access to the unit
- Hardware support for up to 28 geofences for entry and exit monitoring
- GSM jamming detection to identify potential cellular interference situations
- Built for fleet tracking and telematics deployments including insurance and recovery use cases

## How These Features Work with Plaspy

Plaspy receives and normalizes location and event information reported by compatible trackers like the SP4600, making those signals visible in maps, reports, and alerting workflows. Plaspy automatically detects tracker protocol where the device supplies it, helping reduce configuration steps during onboarding.

- Location updates and position history are shown on Plaspy maps for operational visibility
- Geofence events from the SP4600 can be surfaced as alerts or used in rules and reports inside Plaspy
- Device reported events such as jamming detection are available as status indicators or notifications when the device transmits them
- Remote device identification and basic status reported by the tracker are displayed in Plaspy device listings
- Plaspy accepts standard telematics reporting from compatible SP4600 units so teams can combine location and event data into operational dashboards

## Typical Use Cases

- Fleet vehicle location and route monitoring for dispatch and operations oversight
- Insurance telematics scenarios where periodic location and fleet behavior are required
- Vehicle location and recovery support by providing recent positions and geofence history
- Field service and mobile workforce coordination with mapped positions and status
- Logistics and asset oversight where location awareness and event alerts improve operations

## Why Use Plaspy with These Features

Using the SkyPatrol SP4600 with Plaspy gives organizations a straightforward way to turn device-reported location and event data into operational insight. Plaspy consolidates position history, geofence activity, and device status into a single platform so fleet managers, dispatchers, and analysts can monitor movement, respond to events, and generate reports without needing to manually interpret device messages.
