# SkyPatrol - SP4824 Features

This page provides a public, feature-oriented overview of the SkyPatrol SP4824 and how its capabilities map to use with the Plaspy telematics platform. It is intended to explain the device's practical functions, integrations supported by Plaspy, and typical operational value for fleet, subprime automotive, and consumer telematics programs.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation wiring, and manufacturer implementation. Always confirm critical device-specific details and the latest firmware capabilities with the manufacturer and your installer when planning deployments.

## Feature Overview

The SP4824 is a latest generation vehicle tracker designed for broad carrier and regional certifications and engineered for direct integration with Plaspy. It focuses on continuous location reporting, flexible telemetry I O, and resilient operation during power or network transitions to support tracking, driver identification, and recovery workflows.

- Real time GNSS location reporting for live tracking and historical routes.
- LTE 4G Cat1 connectivity with 2G fallback to maintain coverage across networks.
- Multiple digital and analog I O plus a serial port for external telemetry and status inputs.
- 1-wire interface for temperature sensors or driver ID keys to support simple logging and identification.
- Integrated two way audio for voice verification and event confirmation.
- Internal backup battery to provide limited operation when vehicle power is removed.

## Core Features of SkyPatrol - SP4824

- High sensitivity GNSS receiver for reliable position fixes in varied environments.
- LTE 4G Cat1 with 2G fallback to balance modern connectivity and broad network reach.
- Multiple digital and analog inputs and outputs for monitoring ignition, door, or auxiliary signals depending on installation.
- Serial port for external sensor integration or third party device communication.
- 1-wire interface to support temperature sensors or driver ID key readers.
- Built in two way audio for voice communication during verification or recovery events.
- Internal backup battery to maintain basic tracking and event reporting after vehicle power loss.

## How These Features Work with Plaspy

Plaspy ingests location and peripheral telemetry from compatible devices and presents that data in a unified interface for monitoring, alerts, and reporting. When an SP4824 is connected to Plaspy, the platform receives GNSS coordinates, input state changes, serial data, and supported sensor readings so operators can act on live events and historical trends.

- Live location updates and track history appear on Plaspy maps for dispatch and oversight.
- Digital and analog I O events can be displayed as ignition, door, alarm, or custom status indicators depending on wiring and configuration.
- Serial port messages and 1-wire readings can be recorded in Plaspy for external sensor or driver ID workflows.
- Two way audio capability enables voice verification workflows when supported by the deployment and platform setup.
- Backup battery events and power loss sequences can be recorded to flag potential tampering or recovery situations.
- Plaspy automatically detects compatible tracker protocols to streamline device onboarding and data ingestion.

## Typical Use Cases

- Fleet tracking and utilization reporting where continuous location and I O visibility improve operations and dispatch.
- Subprime automotive and consumer telematics with driver ID and location reporting for risk management and recovery.
- Anti theft and vehicle recovery programs using backup battery, two way audio, and alerting to verify events and coordinate response.
- Cold chain or temperature sensitive asset monitoring using 1-wire temperature sensors for basic temperature logging.
- Remote diagnostics and auxiliary sensor telemetry via serial and analog inputs when integrated with vehicle systems.
- Regional rollouts where carrier and country certification coverage reduces deployment complexity.

## Feature Availability Notes

- Firmware versions may enable or disable specific features; check the device firmware release notes for precise behavior.
- Hardware revisions and regional variants can change available network bands, certifications, or connectors.
- Installation wiring determines which inputs map to ignition or other vehicle signals; installer configuration affects reported events.
- Manufacturer provided accessories and sensor types affect how serial and 1-wire integrations function in practice.
- For deployment planning, verify compatibility with local carriers and regional certification requirements.

Using the SP4824 together with Plaspy lets organizations centralize vehicle location, peripheral telemetry, and event history into a single platform for operational oversight.
