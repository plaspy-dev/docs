# SkyPatrol - SP7401 Features

This page describes the public feature context for using the SkyPatrol SP7401 with Plaspy. It focuses on the SP7401 capabilities that are relevant to vehicle tracking and diagnostics and explains how those capabilities are typically used within the Plaspy platform for visibility and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the vehicle or manufacturer implementation. Always consult the device documentation and the manufacturer for the most current technical details before deployment.

## Feature Overview

The SkyPatrol SP7401 is a CDMA based GPS tracker designed for straightforward installation in automobiles and to expose vehicle diagnostics when connected to the vehicle OBD II port. It is positioned for automotive use cases such as insurance telematics, rental and fleet management, and driver behavior monitoring.

- CDMA connectivity to provide reliable position reporting where CDMA networks are in service
- OBD II compatibility to access vehicle diagnostics like engine performance metrics and diagnostic trouble codes
- Real time location updates for live tracking and position awareness
- Integrated backup battery to maintain operation if vehicle power is interrupted
- Easy installation intended for automotive environments and fleet deployments

## Core Features of SkyPatrol - SP7401

- CDMA cellular connectivity for consistent signal reception in supported regions
- Compatibility with OBD II to read vehicle diagnostic parameters and trouble codes
- Real time GPS location reporting for current position tracking
- Backup battery support to continue reporting during power loss
- Designed for simple installation in automobiles
- Practical applications in insurance telematics, rental monitoring, and driver management

## How These Features Work with Plaspy

Plaspy receives the location and diagnostic data reported by compatible devices and presents that information in a single interface for monitoring and reporting. When the SP7401 is connected and configured to report, Plaspy organizes position and diagnostics data to support operational workflows and historical review.

- Live position plotting on Plaspy maps for immediate vehicle location awareness
- Vehicle diagnostic values and diagnostic trouble codes available in device telemetry and logs when the device reports OBD II data
- Historical trips and event history retained for review and reporting inside Plaspy
- Alerts and reports based on changes in location or reported diagnostics as configured in Plaspy
- Centralized fleet visibility so multiple SP7401 devices can be monitored alongside other compatible devices

## Typical Use Cases

- Insurance telematics for monitoring driving patterns and vehicle health indicators
- Rental fleet tracking to maintain location visibility and basic diagnostics
- Driver behavior programs where location history supports activity review
- Fleet oversight for small and medium vehicle fleets needing affordable tracking
- Vehicle status monitoring to capture diagnostic trouble codes for maintenance planning

## Feature Availability Notes

- OBD II data availability depends on vehicle make model and which parameters the vehicle exposes via the OBD II interface
- Firmware and hardware revisions can change available telemetry fields and behavior over time
- Regional CDMA network availability affects where CDMA connectivity is practical for deployment
- Installation choices such as direct OBD II connection or hardwired mounting affect which diagnostics and power behaviors are available
- Always check SkyPatrol documentation and release notes for the most current feature list and firmware information

## Why Use Plaspy with These Features

Using the SkyPatrol SP7401 with Plaspy provides a simple path to aggregate vehicle location and available OBD II diagnostics in a single platform. For organizations that need operational visibility, the combination supports live tracking, historical review, and diagnostics-aware monitoring without requiring separate tools for telemetry and location.
