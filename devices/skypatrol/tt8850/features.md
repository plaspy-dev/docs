# SkyPatrol - TT8850 Features

This page provides a public feature overview of the SkyPatrol TT8850 and explains how its capabilities relate to use with Plaspy. The content focuses on practical, non sensitive descriptions of what the tracker does and how those functions are useful when the device reports into the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation type, and the manufacturer implementation. For implementation specific details such as firmware updates, accessory compatibility, and region specific variants consult the manufacturer documentation.

## Feature Overview

The TT8850 is a compact live GPS tracker designed for discreet and portable applications where unobtrusive tracking and long run times are important. Its combination of long battery endurance, movement detection, and an emergency alert button make it suitable for situations that require extended monitoring with minimal intervention.

- Live GPS tracking in a compact, discreet form factor suitable for covert placement.
- Long continuous tracking runtime and extended standby between charges to reduce maintenance.
- Built in 3D motion sensor to detect movement and improve tracking relevance.
- Integrated SOS button to send an emergency alert to a designated contact.
- Water resistant IPX5 rating for reliable operation in a range of weather conditions.

## Core Features of SkyPatrol - TT8850

- Live GPS position reporting for continuous location awareness.
- Long battery endurance with typical continuous tracking reported at around 10 to 12 days.
- Standby runtime reported up to approximately 25 days for extended inactivity periods.
- Built in 3D motion sensor to detect movement and enable motion based reporting.
- Integrated SOS button for manual emergency alerts.
- IPX5 water resistant enclosure for protection against water spray and light exposure.
- Quad band GSM GPRS network support for broad regional coverage.
- Support for FOTA and OTA updates to allow remote firmware maintenance when provided by the manufacturer.

## How These Features Work with Plaspy

When a TT8850 is used with Plaspy, the device functions translate into operational visibility and event awareness on the Plaspy platform. Plaspy automatically detects supported tracker protocols and makes incoming position and event data available for monitoring and alerts.

- Real time location updates appear on Plaspy maps for tracking and routing visibility.
- Motion sensor activity can reduce irrelevant updates and help focus attention on actual movement events.
- SOS alerts from the device can be surfaced in Plaspy as an event requiring immediate attention.
- Extended battery life reduces the frequency of device maintenance and supports longer deployment intervals tracked within Plaspy.
- The TT8850 can be configured to report to Plaspy infrastructure using standard network transport options supported by the platform.

## Typical Use Cases

- Covert personnel tracking where a discreet form factor is required.
- Temporary surveillance assignments that need extended runtime between charges.
- Situations that require a portable tracker attached to metallic surfaces using optional magnetic mounting.
- Emergency alerting workflows using the integrated SOS button.
- Long duration monitoring where device standby efficiency is important.

## Feature Availability Notes

- Firmware versions can enable or change device behavior; features such as FOTA depend on manufacturer support and provisioning.
- Hardware revisions or regional variants may affect network band support and accessory compatibility.
- Installation style and mounting method can influence signal reception and motion sensor behavior.
- IPX5 provides water resistance for spray and light exposure but is not a guarantee of full submersion protection.
- Confirm SOS alert routing and contact configuration with the installer and manufacturer documentation for reliable emergency handling.
