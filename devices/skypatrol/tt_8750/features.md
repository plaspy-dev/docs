# SkyPatrol - TT 8750+ Features

This page provides a public feature overview for the SkyPatrol TT 8750+ when used with Plaspy. It focuses on practical, non sensitive information about what the tracker can do and how those capabilities are represented in Plaspy for monitoring and operational oversight. Where applicable, the text highlights what aspects of the device are most relevant to Plaspy users.

Exact feature availability and behavior can vary with firmware version, hardware revision, installation wiring, and manufacturer implementation. The information below reflects the device description provided by the manufacturer and is intended as general guidance; for device specific configuration details consult the official SkyPatrol documentation.

## Feature Overview

The TT 8750+ is designed for reliable location tracking across a wide range of vehicle and asset installations. Its combination of cellular connectivity, a sensitive GPS engine, flexible inputs and outputs, and a compact splash proof housing make it suitable for many tracking scenarios.

- Quad band cellular modem for broad regional compatibility and reliable reporting where cellular service exists
- Ultra sensitive GPS engine with embedded antenna array for improved satellite reception and consistent position fixes
- SMA connector for an optional external GPS antenna to support installations with challenging signal conditions
- Multiple I O options including 2 digital inputs plus an ignition input, 1 analog input, and 3 digital outputs for integration with vehicle wiring
- Motion sensor and backup battery for basic movement detection and short term operation when external power is interrupted

## Core Features of SkyPatrol - TT 8750+

- Quad band modem to maintain connectivity across common cellular bands
- Ultra sensitive GPS engine with integrated antenna array for reliable positioning
- SMA connector support for an external GPS antenna where required by installation
- Two digital inputs plus ignition input for monitoring switch or ignition states
- One analog input for reading variable signals if configured by installation
- Three digital outputs for signaling or third party device control where wiring supports it
- Motion sensor for movement detection and wake or reporting logic
- Built in backup battery and splash proof housing for resilience in mobile environments
