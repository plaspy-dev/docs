# SkyPatrol - SP8824 Features

This page provides a public overview of the SkyPatrol SP8824 feature set and how those capabilities present when the device is used with Plaspy. It focuses on user facing functionality such as location tracking, motion awareness, battery behavior, and practical uses for personal and small asset monitoring while connected to the Plaspy platform.

The SP8824 is described as a compact personal GPS tracker with LTE Cat M1 connectivity, an integrated GPS antenna, a 3‑axis accelerometer for motion detection, and an internal rechargeable battery that enables extended standby operation. Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation, so this page presents safe, general guidance rather than exhaustive technical specifics.

## Feature Overview

The SP8824 combines efficient cellular connectivity with a compact design to deliver continuous location updates and motion based reporting while conserving battery life. When paired with Plaspy, the tracker provides straightforward onboarding and normalized reporting so positions and events are visible in a single monitoring interface.

- Compact, discreet form factor suitable for body carry and small assets
- LTE Cat M1 cellular for energy efficient uplink and extended standby
- Integrated GPS antenna for reliable position fixes in typical mobile scenarios
- 3‑axis accelerometer for motion detection and activity based reporting
- Internal rechargeable battery designed for long standby times between charges
- Compatibility with Plaspy for real time tracking, alerts, and basic telemetry

## How These Features Work with Plaspy

When the SP8824 is used with Plaspy, location and motion events are delivered into Plaspy’s tracking environment so organizations and families can monitor positions and receive alerts. Plaspy presents device updates in a unified dashboard and normalizes incoming information for consistent viewing across devices.

- Real time location visibility inside the Plaspy platform for tracking movement and position history
- Motion detection events mapped to alerts or activity logs in Plaspy to show movement or inactivity
- Battery and device status reporting surfaced for proactive monitoring of power and connectivity
- Geofence and entry or exit alerts available through Plaspy based on reported positions
- Simple onboarding and device visibility so devices appear in accounts for monitoring without complex setup
