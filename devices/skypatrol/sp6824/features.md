# SkyPatrol - SP6824 Features

This page provides a public feature overview of the SkyPatrol SP6824 and how those capabilities relate to use with Plaspy. It is intended to help fleet managers, operations teams, and integrators understand the practical functions the SP6824 can provide when reporting into the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, selected installation method, and manufacturer implementation. Where applicable this page notes optional variants and recommends consulting official manufacturer documentation for the most current device specific details.

## Feature Overview

The SP6824 is an ultra thin GPS tracker built for discreet vehicle and lot installations with a focus on continuous location reporting and practical telemetry for fleet, financing, and recovery workflows. When paired with Plaspy the device delivers real time position updates and event visibility that support operational monitoring and alerting.

- Low profile ultra thin form factor for discreet installation in vehicles and on lots
- 4G LTE Cat M1 connectivity for resilient low power cellular reporting over wide geographic coverage
- Super sensitive GPS module and internal antennas for improved position fixes in challenging conditions
- Optional OBDII plug and play variant to surface vehicle diagnostics and OBD sourced telemetry when available
- Multiple digital and analog I O interfaces to capture door, alarm, and tamper events for event driven alerts

## Core Features of SkyPatrol - SP6824

- Real time location reporting optimized for vehicle and lot tracking
- LTE M cellular connectivity for continuous telemetry delivery
- Super sensitive GNSS receiver for faster fixes and enhanced tracking in urban or obscured environments
- Internal cellular and GPS antennas to support low profile installations
- Optional OBDII plug and play interface to forward vehicle diagnostics and OBD telemetry into monitoring workflows
- Multiple I O interfaces for external sensors such as door switches and alarm inputs
- Compact, ultra thin design suited to mixed fleet and dealer lot deployments

## How These Features Work with Plaspy

Plaspy ingests the SP6824 position and event data to provide unified visibility and workflow automation. The SP6824 feeds into Plaspy reporting and alerting so teams can monitor location, events, and vehicle state from a single platform.

- Real time location updates appear in Plaspy for live tracking and route history
- OBDII sourced diagnostics and telemetry are available in Plaspy when the OBDII variant is used and the vehicle exposes those parameters
- Door, alarm, and tamper events tracked via the device I O ports are routed into Plaspy alerting and workflows
- Geofence, speed, and route alerts can be configured inside Plaspy using the SP6824 live feed
- Plaspy can consolidate SP6824 telemetry with other supported sensor data to extend monitoring and reporting where available

## Typical Use Cases

- Fleet management and route monitoring for mixed vehicle fleets
- Vehicle financing and repossession workflows requiring location and event visibility
- Dealer lot and inventory control with discreet trackers on stored vehicles
- Theft recovery and anti theft monitoring using event alerts and location history
- Remote diagnostics reporting when using the optional OBDII variant
- Rental fleet oversight for location and usage tracking

## Feature Availability Notes

- The OBDII plug and play option is an available variant and provides additional telemetry only when present and supported by the vehicle
- Firmware versions and hardware revisions can affect available telemetry, event behavior, and configuration options
- Regional cellular band support and network behavior depend on the specific hardware revision and carrier provisioning
- I O behavior and wiring expectations vary by installation method and must be validated during setup
- Consult the manufacturer for details on remote management features such as firmware updates and advanced device configuration
