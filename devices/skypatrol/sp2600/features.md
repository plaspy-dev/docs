# SkyPatrol - SP2600 Features

This page provides public feature context for the SkyPatrol SP2600 and how the device can be used with Plaspy. It describes the SP2600 capabilities that matter for fleet tracking, monitoring, and basic telematics reporting inside the Plaspy platform, and explains how those capabilities translate to operational value.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional components, installation method, and the manufacturer implementation. Use this page for general guidance and consult SkyPatrol documentation or your device supplier for definitive, model specific details.

## Feature Overview

The SP2600 Series is positioned as an economical, reliable GPS tracker for vehicle and fleet applications. It focuses on core tracking and motion sensing features while offering optional components and firmware update support to keep deployments current.

- Compact vehicle tracker designed for 12 volt and 24 volt mobile installations and fast installation workflows
- Optional 750 mAh backup battery to maintain operation during primary power loss
- FOTA capability to enable firmware updates over the air through the manufacturer process
- Integrated 3 axis accelerometer for motion sensing and basic activity detection
- Single input and single output I O for simple integration with external devices or vehicle systems

## Core Features of SkyPatrol - SP2600

- GPS location reporting suitable for fleet and vehicle tracking
- Optional internal backup battery rated at 750 mAh for limited off power operation
- Firmware Update Over The Air FOTA that supports remote firmware delivery and maintenance
- 3 axis accelerometer enabling motion and activity detection for movement based reporting
- One digital input and one output for basic external signal integration
- Available in 2G and 3G variants with full 3G band coverage in supported models
- Designed for 12 V and 24 V vehicle electrical systems for broad vehicle compatibility
- Quick installation workflow aimed at reducing field time and deployment cost

## How These Features Work with Plaspy

When connected to Plaspy the SP2600 provides location and event data that Plaspy can present for monitoring and operational use. Plaspy automatically detects many tracker protocols and ingests the device data so teams can observe position, movement, and basic I O events inside the platform.

- Location reports from the SP2600 appear in Plaspy for live tracking and historical route playback
- Motion events derived from the 3 axis accelerometer can be used to trigger activity indicators or movement based reports
- Input and output state changes from the device can be surfaced in Plaspy as simple event markers or status attributes
- FOTA keeps the device firmware up to date according to the manufacturer process and Plaspy will accept data from devices after firmware updates
- The optional backup battery helps maintain reporting to Plaspy during short power interruptions so visibility is preserved

## Typical Use Cases

- Basic fleet vehicle tracking where cost and reliable connectivity are primary concerns
- Monitoring vehicle movement and activity using accelerometer based motion detection
- Deployments that need a low cost tracker with an optional backup battery for resilience
- Installations requiring simple external signal integration using one input and one output
- Regions or fleets using either 2G or 3G network options based on device variant availability
