# SkyPatrol - SP3400C

![SP3400C](./logo.jpg)

The SkyPatrol SP3400C is a rugged CDMA GPS tracking device designed for vehicle telematics and carrier level certifications. Built to withstand harsh operating conditions, the SP3400C targets vehicle location applications across subprime automotive, fleet operations, and consumer telematics. Key hardware and firmware features mentioned by the manufacturer include an optimized cellular antenna design, integrated GPS and cellular antennas, a high precision GPS engine, a built in 3 axis accelerometer, over the air firmware update capability, and discrete I O circuits for vehicle control functions.

As a device noted to be compatible with Plaspy, the SP3400C can be used to provide location, motion and basic input output status into the Plaspy platform. Its support for cellular data transports and text based messaging along with OTA update capability makes it a practical device for organizations that need reliable vehicle visibility, remote configuration, and the ability to incorporate I O state changes into operational workflows managed in Plaspy.

## Key Highlights

- Designed for vehicle telematics with durable construction for harsh environments
- CDMA dual band connectivity and integrated cellular and GPS antennas for improved signal performance
- High precision GPS engine and built in 3 axis accelerometer for reliable positioning and motion detection
- Over the air firmware update capability for remote maintenance and configuration
- Two discrete digital outputs and inputs plus an ignition input for basic vehicle control and status sensing
- Supports common data transports and messaging methods for reporting location and events to backend systems

## How It Works with Plaspy

When paired with Plaspy, the SP3400C provides continuous location and event data that Plaspy ingests for monitoring, reporting, and operational oversight. Plaspy can use the device's location fixes, motion events, and input output status to present fleet visibility, generate alerts, and populate historical reports for analysis.

- Real time location visibility in Plaspy dashboards for fleet monitoring and dispatch
- Event processing from the accelerometer and input signals for motion alerts and status changes
- Use of discrete outputs and ignition input to reflect vehicle state in Plaspy and support operational controls
- Over the air firmware and configuration updates coordinated with Plaspy workflows to reduce on site maintenance
- Historical playback and reporting within Plaspy for route review and compliance checks
- Alerting and notifications based on thresholds and events reported by the device

## Typical Use Cases

- Field service and delivery vehicle monitoring for route management and performance reporting
