# SkyPatrol - SPL1204 Features

This page provides a public feature overview of the SkyPatrol SPL1204 (SkyOne Lock Tracker) and how its capabilities are exposed when used with Plaspy. It is intended to describe the practical, non-sensitive functions of the device and how those functions can support asset tracking, anti-theft workflows, and chain of custody tracking inside Plaspy-powered systems.

Exact feature availability and behavior can vary based on device firmware, hardware revision, installation method, and manufacturer implementation. For device-specific technical details and the latest firmware behavior consult the manufacturer documentation and release notes.

## Feature Overview

The SPL1204 is a lock-style GPS tracker designed for logistics and high-value cargo protection. It combines location reporting with lock-specific event telemetry to support anti-theft and chain-of-custody workflows while operating in exposed transport environments.

- Integrated GPS positioning with 4G connectivity for real-time location reporting to Plaspy.
- RFID unlocking to record authorized access events and simplify secure handoffs.
- Tampering alerts to notify operators of unauthorized attempts on the lock.
- Rechargeable lithium battery for repeatable deployments without single use power sources.
- Rugged weatherproof lock form factor suited to trailers containers and exposed cargo.
- Event logging designed to support chain of custody and audit workflows in Plaspy.

## Core Features of SkyPatrol - SPL1204

- 4G enabled GPS tracking for continuous positional awareness.
- Built-in RFID unlocking capability to capture authorized access events.
- Tamper detection and alert reporting for anti-theft monitoring.
- Rechargeable battery that supports redeployment and maintenance scheduling.
- Weatherproof and ruggedized enclosure appropriate for outdoor transport use.
- Lock form factor that combines physical security with telemetry reporting.
- Event logging suitable for chain-of-custody and delivery verification.

## How These Features Work with Plaspy

When connected to Plaspy the SPL1204 forwards location and event telemetry so operators can monitor assets and respond to incidents from a unified platform. Plaspy ingests the lock-originated signals and presents them alongside other fleet and asset data for operational oversight.

- Real-time location updates appear in Plaspy maps and tracking views for continuous visibility.
- RFID unlock events and tamper alerts are logged as time stamped events for auditing and incident workflows.
- Battery and power state information reported by the device can be used to schedule maintenance before power loss.
- Chain-of-custody timelines and access records become searchable and reviewable within Plaspy reporting.
- Plaspy can correlate lock events with other Plaspy-compatible telemetry sources in the same deployment to provide richer context.

## Typical Use Cases

- Anti-theft protection for trailers containers and high-value shipments in transit.
- Sealed shipment monitoring with recorded RFID unlocks for handoff verification.
- Depot and yard security to detect tampering while assets are stationary or staged.
- High-value logistics where physical lock status and location are both required for compliance.
- Complementary deployments where lock events are correlated with other fleet telemetry for investigative workflows.

Using the SPL1204 with Plaspy provides centralized visibility into both physical lock status and asset location, helping operations teams detect tampering, verify authorized access, and maintain chain-of-custody records from a single platform.
