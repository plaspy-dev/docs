# SkyPatrol - SP8502 Features

This page provides a public, feature oriented overview of the SkyPatrol SP8502 and how its capabilities are used with Plaspy for monitoring and operational visibility. It focuses on the practical, user facing functions of the device and explains how those functions map to typical workflows inside the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and how the manufacturer implements each function. For device specific configuration, firmware changes, or the latest technical details, refer to manufacturer documentation.

## Feature Overview

The SkyPatrol SP8502 is a compact, portable GPS tracker designed for discreet location monitoring and basic alerting. It is commonly used to track people and field staff where a small form factor and a user controlled alert are important.

- Compact and portable design that is easy to carry or conceal for personal or field use
- User activated alert button to notify designated contacts when assistance is needed
- Real time location tracking accessible from a smartphone or PC for situational awareness
- Boundary alerts to notify supervisors or guardians if the device crosses predefined limits
- Durable construction intended for everyday use in personnel and asset monitoring

## Core Features of SkyPatrol - SP8502

- Compact portable form factor for discreet placement or carrying
- User activated alert button for immediate attention events
- Real time GPS location updates for monitoring movements
- Geofence or boundary alert support to notify when predefined areas are exited
- Designed for monitoring people such as field personnel, seniors, and children
- Basic durable construction intended for regular operational use

## How These Features Work with Plaspy

Plaspy receives and presents the SP8502's location and alert events so teams can monitor movement and respond to incidents from a central interface. Plaspy helps turn the device signals into actionable visibility for operations and safety monitoring.

- Real time locations appear on Plaspy maps for live tracking and playback
- User activated alerts are represented as events so designated users can be notified
- Boundary alerts reported by the device translate to notifications and event logs in Plaspy
- Device identification and protocol detection are handled automatically by Plaspy to simplify onboarding
- Historical location data and alert history are retained in Plaspy for review and auditing

## Typical Use Cases

- Monitoring field personnel movements for dispatch and safety
- Tracking vulnerable individuals such as seniors or children for welfare checks
- Equipping couriers or sales representatives with a small tracking device
- Providing security officers with a portable alert option when they need assistance
- Short term missions or assignments where a discreet tracker is required
