# SkyPatrol - SP3600 Features

This page provides a public feature overview for the SkyPatrol SP3600 and explains how those capabilities map to Plaspy for everyday vehicle tracking and fleet monitoring. It is written to describe practical, non sensitive functions that users can expect when the SP3600 is used with Plaspy, including common operational scenarios like fleet management, dispatch, insurance telematics, and vehicle recovery.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and how the device is installed. The information below uses the SP3600 description as the reference point; for device specific technical details and the latest firmware behavior consult the official SkyPatrol documentation.

## Feature Overview

The SkyPatrol SP3600 is a vehicle-focused GPS tracker designed for reliable communications and core location services. In operational terms it delivers continuous position awareness, boundary monitoring, and basic sensor telemetry suited to fleet and vehicle applications.

- Real time tracking for continuous location visibility of vehicles
- Geofencing support to define virtual boundaries and receive zone events
- Quad band GSM GPRS communications for wide area connectivity
- Onboard sensors including an accelerometer and a temperature sensor for movement and environment data
- Robust design targeted at vehicle installations and demanding operational use

## Core Features of SkyPatrol - SP3600

- Quad band GSM GPRS connectivity for broad cellular coverage and dependable reporting
- Real time GPS location reporting for up to date vehicle position visibility
- Geofencing capability to detect entry and exit of predefined zones
- Accelerometer sensor to indicate vehicle movement and activity events
- Temperature sensor for monitoring ambient or equipment temperature where applicable
- Designed for vehicle use cases including fleet operations, dispatch, and recovery
- Compatibility with tracking platforms such as Plaspy for centralised management

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible trackers like the SP3600 and presents that information within a unified fleet management view. This allows operators to correlate position data with geofence events and basic sensor readings for operational insight.

- Location updates from the SP3600 appear in Plaspy as live position markers and historical tracks
- Geofence events reported by the device are surfaced in Plaspy as zone entry and exit notifications
- Movement events based on the accelerometer can be shown in timelines or event lists for activity auditing
- Temperature readings reported by the device can be recorded and viewed alongside vehicle location where available
- Plaspy automatically detects supported tracker protocols to simplify platform onboarding and device reporting

## Typical Use Cases

- Fleet location monitoring and route oversight for commercial vehicles
- Dispatch coordination using real time vehicle positions
- Insurance telematics where movement patterns and basic sensor data are of interest
- Vehicle location and recovery support through continuous tracking
- Environmental monitoring of vehicle cargo or compartments using temperature readings
- Activity logging and event review using accelerometer based movement data

## Why Use Plaspy with These Features

Using the SkyPatrol SP3600 with Plaspy provides a practical way to centralise vehicle position, zone events, and basic sensor telemetry into a single operational view. For organisations that need continuous location awareness, consistent geofence reporting, and simple movement or temperature data, the SP3600 supplies the device-level inputs while Plaspy handles aggregation, visualization, and event management.
