# SkyPatrol - TT 9200 Features

This page provides a public overview of the SkyPatrol TT 9200 feature set and explains how those capabilities map to monitoring and reporting when the device is used with Plaspy. It is intended as a features-oriented reference to help fleet managers, integrators, and technical buyers understand practical device functions and what to expect when pairing the tracker with Plaspy.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a general guide and consult current SkyPatrol documentation for device specific limits and configuration details.

## Feature Overview

The TT 9200 is a compact GPS tracker designed for flexible tracking deployments. Its core value is a combination of precise positioning, configurable device-based geofencing, and global GSM connectivity that works with Plaspy for location visibility and event reporting.

- Device based geofencing with support for up to 250 circular or polygonal geofences per device
- Support for 24 point device based corridors for route and route compliance monitoring
- Low power consumption for extended deployment life between charges or maintenance
- Quad band GSM modem for broad international network compatibility
- Durable splash proof housing for reliable field use
- Ultra sensitive GPS reception for improved location accuracy in difficult reception areas

## Core Features of SkyPatrol - TT 9200

- EDDIE+ custom protocol implemented by SkyPatrol for device reporting
- Device side geofence capacity up to 250 geofences providing local event triggering
- Support for 24 point device based corridors for route monitoring and corridor alerts
- Multiple geofence shapes supported including circular geofences polygonal geofences and route geofencing
- Seven device counters offering event or usage counting at the device level
- Low power design to support longer field operation between charging cycles
- Quad band GSM connectivity enabling use on GSM networks in many countries
- Splash proof enclosure to improve durability in everyday environments

## How These Features Work with Plaspy

When connected to Plaspy the TT 9200 reports its location and device events using the device protocol so Plaspy can present location history and event timelines. Plaspy automatically detects the tracker protocol to simplify initial setup and device onboarding.

- Device based geofence and corridor events reported by the tracker can appear as geofence entries and exits in Plaspy
- Route geofencing and corridor violations reported by the device can be surfaced in Plaspy for operational review
- Device counters reported by the TT 9200 can be captured as events or counter values in Plaspy depending on the data the device sends
- Global GSM connectivity helps maintain continuous reporting to Plaspy across supported regions
- Low power behavior improves long term tracking consistency which supports longer historical location records in Plaspy

## Typical Use Cases

- Vehicle location tracking with device side geofencing for entry and exit monitoring
- Route adherence monitoring using device based corridors for delivery or service routes
- Asset tracking where compact and splash proof design is beneficial
- International tracking deployments leveraging quad band GSM compatibility
- Long term or intermittent tracking where low power consumption extends deployment life
- Use cases requiring device side counters for usage or event aggregation

## Feature Availability Notes

- Firmware and software revisions from the manufacturer can change which features are available or how they behave
- Hardware revisions or different product SKUs may alter capacities such as geofence limits or supported geofence shapes
- Installation type and signal conditions can affect GPS sensitivity and reporting reliability
- Regional cellular variants may change network compatibility for some deployments
- For precise device configuration options and the full list of supported counters consult the official SkyPatrol documentation

## Why Use Plaspy with These Features

Plaspy provides a unified platform to visualize location history and device events from the TT 9200 so teams can monitor movement patterns and respond to geofence and corridor events. Using Plaspy helps centralize visibility across fleets and assets while respecting device side processing like geofences and counters that reduce reporting overhead.
