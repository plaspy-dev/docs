# SkyPatrol - SP8801 Features

This page provides public feature context for using the SkyPatrol SP8801 personal GPS tracker with Plaspy. It summarizes the device capabilities that are relevant to tracking, monitoring, and alerting when the tracker is used together with Plaspy, helping you understand practical value and expected behavior from an operational perspective.

Exact feature availability and behavior for any individual SP8801 unit can vary by firmware version, hardware revision, installation method, regional variant, and manufacturer configuration. For device specific setup, limits, and the latest technical details always consult the manufacturer documentation and release notes.

## Feature Overview

The SP8801 is built as a compact personal GPS tracker for real time location and movement awareness. It is designed for easy placement and quick access to location data and alerts, making it useful for both family safety and simple field personnel monitoring.

- Real time tracking accessible from a smartphone or PC for immediate location awareness
- Boundary alerts that notify when the device leaves predefined areas
- Customizable emergency alert function activated by a push button to notify designated contacts
- Discreet and portable form factor suitable for a pocket, purse, or bag
- Appropriate for personal safety scenarios and basic tracking of field personnel

## Core Features of SkyPatrol - SP8801

- Real time location reporting so users can see current position updates
- Smartphone and PC access for on demand tracking and monitoring
- Boundary alert functionality to detect and report departures from preset areas
- Button activated emergency alerts that send notifications to configured contacts
- Compact and portable design for inconspicuous placement
- Intended use cases covering personal safety and simple workforce monitoring

## How These Features Work with Plaspy

Plaspy is a platform that accepts tracker reports and presents location and event information in a unified view. When an SP8801 is connected to Plaspy, the device capabilities translate into visibility and event signals that support monitoring and operational oversight.

- Live location updates from the device appear on Plaspy maps and device lists for situational awareness
- Boundary alert events reported by the tracker are shown in Plaspy as alerts or events for quick review
- Emergency button activations are reflected in Plaspy as high priority events so designated users can be informed
- Plaspy automatically detects supported tracker protocols to simplify device onboarding
- Device movements and reported events can be monitored from the Plaspy interface on desktop or mobile
