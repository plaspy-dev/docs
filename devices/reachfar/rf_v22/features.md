# Reachfar - RF-V22 Features

This page provides a public, features-oriented overview of the Reachfar RF-V22 and how its door state telemetry can be used with Plaspy. It covers the practical capabilities visible to operators and administrators when the RF-V22 is integrated into Plaspy for centralized monitoring, alerting, and event logging.

Exact feature availability and behavior can vary by factory firmware, hardware revision, installation method, and manufacturer implementation. Use this page as a high level reference for Plaspy compatibility and operational context, and consult the official Reachfar documentation for current device specifics.

## Feature Overview

The RF-V22 is a cellular door status detector designed to report open and close events over GSM/GPRS networks and feed those events into monitoring platforms such as Plaspy. It is intended for supervised entry control in settings where wired networking may not be available or desirable and where straightforward, reliable door event telemetry is required.

- Sends door open and close events over GSM/GPRS for remote monitoring
- Plaspy compatible so door state appears in dashboards, logs, and alert rules
- IP67 rated enclosure for indoor and semi outdoor installations
- Near real time event reporting to support timely notifications and workflows
- Installer resources and video guidance to simplify configuration and deployment

## Core Features of Reachfar - RF-V22

- Cellular GSM GPRS connectivity for remote door state reporting without local Wi Fi
- Reporting of discrete door open and door close events as the primary telemetry
- IP67 ingress protection for dependable installation in challenging indoor and semi outdoor locations
- Plaspy compatibility for integration into centralized monitoring and alerting systems
- Near real time delivery of door events to monitoring endpoints to enable fast response
- Compact, discreet enclosure available in white or black to match facility aesthetics
- Manufacturer supplied manual and installation video to streamline setup and configuration
- Remote technical resources and downloads available from the manufacturer

## How These Features Work with Plaspy

When the RF-V22 is configured to send events to Plaspy, door open and close signals are treated as telemetry inputs that can be displayed, logged, and used to trigger automated responses. Plaspy provides the central view and rule engine that transforms RF-V22 event streams into operational alerts and historical records.

- Door open and close events show up as telemetry or event entries inside Plaspy dashboards
- Events can trigger notifications, alarms, or conditional automation within Plaspy
- Plaspy retains event history for auditing and compliance reporting
- RF-V22 inputs can be correlated with other devices managed in Plaspy for richer situational awareness
- Integration requires device configuration per the manufacturer manual so Plaspy receives the expected event messages

## Typical Use Cases

- Quarantine and isolation areas where door openings must be monitored and recorded
- Healthcare and assisted living facilities for staff notification and safety oversight
- Perimeter and facility access control where cellular supervision is preferred or needed as a backup
- Temporary clinics, field sites, and pop up deployments that lack wired network infrastructure
- Combined monitoring workflows where door telemetry is correlated with asset location and status in Plaspy

## Feature Availability Notes

- Feature behavior can differ between firmware versions and hardware revisions; confirm with the product manual
- Power and battery specifications are not provided in the supplied materials and should be checked in the official documentation
- Regional cellular band support and availability may vary by market and model variant
- Installation method and wiring choices can affect what signals the device reports to Plaspy
- The RF-V22 is a dedicated cellular door alarm and does not provide GPS location telemetry

## Why Use Plaspy with These Features

Using the RF-V22 with Plaspy gives operators a simple way to centralize door state telemetry alongside other operational data. Plaspy brings visibility, configurable alerts, and event history that help teams respond quickly to door events, maintain audit trails, and combine door information with other monitored devices for coordinated workflows.
