# Reachfar - RF-V10+

![RF-V10+](./tracker.jpg)

The RF-V10+ is a compact, super power-saving GPS tracker designed for vehicle and motorcycle security. Plaspy compatible out of the box, it pairs reliable real-time tracking with long standby performance, comprehensive anti-theft alarms, and simple integration via GPRS or SMS so fleets and individual owners get prompt location, alerting, and playback where they need it.

The RF-V10+ combines quad-band GSM \(850/900/1800/1900 MHz\) GPRS Class 12 TCP/IP connectivity with dual positioning \(GPS + LBS\) to maintain accurate tracking even when GPS signals are weak. Its built-in 520 mAh battery, compact form, and automotive-grade tolerance to temperature and humidity make it a practical choice for fleet management, motorcycle anti-theft and remote vehicle monitoring when used with Plaspy’s platform and apps.

## Key Highlights

- Plaspy compatible GPS tracker with real-time tracking via GPRS/TCP and SMS fallback for dependable location updates.
- Ultra low-power design with built-in 520 mAh lithium battery — extended standby \(approx. 3–7 days on battery, GSM standby ~4–5 days under normal conditions\).
- Quad-band GSM \(850/900/1800/1900 MHz\) and GPRS Class 12 for wide network coverage and TCP/IP telemetry delivery.
- Dual positioning: GPS for precise fixes and LBS fallback \(approx. 200–800 m accuracy\) when GPS is unavailable.
- Comprehensive anti-theft features: vibration alarm \(4 sensitivity levels\), SIM-change alerts, low-battery SMS notifications, geo-fence alerts, and remote arm/disarm and start/stop engine control via SMS or key fob.
- Rugged automotive-ready design with built-in GSM antenna, temperature range -20°C to +70°C and humidity tolerance 5%–95% RH.
- Easy monitoring via the manufacturer’s web platform \(http://www.gps123.org\), “Track Anywhere” app \(iOS/Android\), or direct SMS commands for address/map links and status queries.

## How It Works with Plaspy

Integrating the RF-V10+ with Plaspy provides continuous location and alarm telemetry to your Plaspy dashboard and mobile apps. The device transmits position, alarms and status updates over GPRS/TCP to a tracking server or can send SMS alerts directly to designated emergency contacts. Plaspy consumes those data streams to deliver live maps, playback, rule-based alerts and fleet reporting.

- Real-time location and telemetry updates delivered to Plaspy via GPRS/TCP with SMS as a fallback mechanism.
- Alarm and status notifications: vibration alarm events, SIM-change alerts and low-battery warnings forwarded to Plaspy for immediate action.
- Geo-fence notifications and track playback available in Plaspy using the device’s location history.
- Remote immobilizer / start-stop engine control via SMS or remote key fob, enabling anti-theft responses through Plaspy alert workflows.
- Simple SMS queries \(for example, an address/map link request\) and full web/app monitoring via the device’s compatible platforms — all consumable inside Plaspy for unified fleet management and incident response.
