# Reachfar - RF-V03-SOS Features

This page provides a public overview of the Reachfar RF-V03-SOS feature set and explains how those features are presented and used when the device is connected to Plaspy. It is intended to help fleet managers, rental operators, and private owners understand the practical capabilities of this Plaspy compatible tracker without diving into device internals.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation type. For device specific parameters, firmware notes, and the most current manufacturer guidance consult the official Reachfar documentation and support resources.

## Feature Overview

The RF-V03-SOS is a rugged vehicle tracker built for continuous telemetry and practical fleet use. It combines position reporting, event alarms, and resilience features to support tracking in mixed coverage environments and to assist with safety and anti-theft workflows.

- Real time tracking using dual positioning GPS plus LBS with open sky accuracy up to 10 meters for reliable location awareness.
- Wide input voltage support to simplify installations across cars, trucks, and industrial vehicles without additional converters.
- Safety and recovery features such as one click SOS and vibration alarm for faster incident response.
- Remote engine power cut and engine status detection to support immobilizer style control and operational workflows.
- Built in backup battery and dead zone storage holding more than 2,000 points to preserve data when cellular connectivity is lost.

## Core Features of Reachfar - RF-V03-SOS

- Real time GPS and LBS dual positioning with open sky accuracy up to 10 meters
- Wide operating input voltage range supporting diverse vehicle power systems
- One click SOS emergency alert for rapid notification
- Remote engine power cut capability and engine status detection for immobilization workflows
- Vibration alarm to detect tampering or unauthorized movement
- Built in backup battery for brief power loss operation and recovery
- Dead zone storage storing over 2,000 data points when cellular data is unavailable
- Voice monitoring supported on GSM and LTE CAT4 variants for situational assessment

## How These Features Work with Plaspy

When the RF-V03-SOS is connected to Plaspy, the tracker reports position, status, and event data so teams can monitor assets centrally. Plaspy collects incoming device reports, displays them on live maps, logs history, and triggers alerts based on configured rules.

- Live location and movement updates appear on Plaspy maps for immediate operational visibility
- SOS events and vibration alarms create alert notifications so dispatch or response teams can act quickly
- Engine status and power cut events are visible in Plaspy to support start stop reports and immobilization workflows
- Stored dead zone data is uploaded and reconciled into Plaspy history when connectivity is restored
- Voice monitoring availability is reflected as a supported event where the device variant includes that function

## Typical Use Cases

- Vehicle anti theft and recovery workflows using remote engine cut and live tracking
- Driver safety and emergency response using one click SOS and voice monitoring where supported
- Fleet route history and compliance reviews using stored position history and playback
- Asset tracking in low coverage areas where dead zone storage prevents data loss
- Mixed fleet deployments where wide input voltage tolerance simplifies installations
- Rental fleet oversight and recovery support for high turnover vehicles
