# Reachfar - RF-V43 Features

This page summarizes the public feature context for using the Reachfar RF-V43 tracker with Plaspy. It describes the RF-V43 capabilities most relevant to pet tracking and explains how those capabilities are surfaced in Plaspy for monitoring and operational visibility. The content is intended for planners, fleet or asset administrators, and pet owners who want a clear view of what this model can offer when paired with Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. Where useful, this page refers to practical, user facing capabilities described by the manufacturer, but you should confirm specific behavior for your unit and firmware level with the official Reachfar documentation and firmware notes.

## Feature Overview

The Reachfar RF-V43 is presented as a lightweight pet tracker with multi mode location methods and weather resistant construction. It prioritizes real time location awareness, perimeter alerts, and simple tools to find and monitor a pet in everyday conditions.

- Real time tracking over 4G networks for timely location updates and improved coverage.
- Three tracking modes using GPS, LBS, and WiFi to improve location accuracy across different environments.
- Virtual boundaries via GPS-fence and WiFi-fence to notify caretakers when a pet leaves a defined area.
- IP67 rated waterproof design to maintain operation in wet conditions and outdoor use.
- Smart LED for remote visibility and sport data reporting to monitor activity levels.
- Calling feature, fast charging support, and a low battery alarm to reduce downtime and maintain connectivity.

## Core Features of Reachfar - RF-V43

- 4G network connectivity for real time position updates.
- Multi mode location using GPS, LBS, and WiFi to provide location options indoors and outdoors.
- GPS-fence support for defining geofenced safe zones and receiving alerts.
- WiFi-fence support for location and boundary detection using nearby WiFi signals.
- IP67 waterproof rating for use in rain and splashes.
- Remote controllable smart LED for locating a pet in low light.
- Sport data tracking to monitor activity and movement patterns.
- Low battery alarm and fast charging capability to help maintain continuous operation.

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible trackers like the RF-V43 and presents it in a centralized interface for monitoring and operational use. Plaspy is designed to detect compatible tracker protocols and translate incoming updates into map positions, alerts, and activity summaries so teams can act on them quickly.

- Location updates from the RF-V43 appear on Plaspy maps for live tracking and historical playback.
- Geofence and WiFi-fence events generate alerts and can be shown in event lists for review and reporting.
- Activity or sport data is surfaced as activity indicators to help evaluate a pet's movement patterns over time.
- Low battery notifications and similar device events are reported to Plaspy so caretakers can schedule charging or maintenance.
- Remote actions described by the device, such as controlling an LED, can be represented in Plaspy as an available device control or status where supported.
- Plaspy automatically detects many tracker protocols and maps common device attributes into the platform for consistent display.
