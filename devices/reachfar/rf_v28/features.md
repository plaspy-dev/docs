# Reachfar - RF-V28 Features

This page provides a public feature overview of the Reachfar RF-V28 GPS Tracking SOS Pendant and how it works with the Plaspy platform. It describes the RF-V28’s user-facing capabilities, the practical value those features provide to caregivers and administrators, and how Plaspy surfaces location and alert information for monitoring and review.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. Use this page as a product-focused summary for Plaspy users and confirm device-specific details and the latest firmware behavior with the official Reachfar documentation.

## Feature Overview

The RF-V28 is a compact wearable designed for continuous personal location monitoring and emergency response. It combines multiple positioning methods, direct emergency calling, and configurable safe-zone capabilities so caregivers can receive timely alerts and review movement history through Plaspy.

- Real-time location reporting using multiple positioning methods for better indoor and outdoor coverage
- One-touch SOS with sequential multi-number calling to reach up to five contacts until answered
- Automatic fall-detection alarms that initiate SOS procedures and notify caregivers
- Wi‑Fi safe-zone (Wi‑Fi fence) configuration to trigger alerts when the pendant exits or enters defined Wi‑Fi areas
- Historical route playback for incident review and situational context within Plaspy

## Core Features of Reachfar - RF-V28

- Plaspy compatible out of the box for direct tracking and alert ingestion
- Multi-method positioning: GPS, A‑GPS, Wi‑Fi positioning, and LBS for broader coverage
- Two-way voice calling capability for direct communication with the wearer
- Sequential multi-number SOS calling to up to five whitelist contacts
- Automatic fall-detection alarm that triggers SOS mode and notifications
- Wi‑Fi fence support to define safe areas by Wi‑Fi networks and trigger events on leave/enter
- Historical route storage and playback (manufacturer states up to 90 days)
- Local control via smartphone app and SMS commands for on-device configuration

## How These Features Work with Plaspy

Plaspy receives the RF-V28’s location and event data so monitoring teams can view live positions, receive alerts, and review historical routes without custom integration work. Plaspy automatically recognizes compatible trackers and integrates reported events into platform mapping and notification workflows.

- Live map display of GPS/A‑GPS/Wi‑Fi/LBS positions for current situational awareness
- Immediate SOS and fall-detection notifications routed through Plaspy alerts and dashboards
- Geofence and Wi‑Fi fence events delivered to Plaspy for configurable notifications and escalation
- Historical route playback inside Plaspy for incident review and context up to the device’s retained period
- Ability to combine RF-V28 telemetry with other Plaspy-compatible devices to support broader operational views

## Typical Use Cases

- Senior care monitoring with fall alerts and one-touch SOS for rapid caregiver notification
- Child safety with discreet wearable tracking and Wi‑Fi safe-zone alerts for home or school
- Lone worker protection where a wearable SOS and two-way calling support incident response
- Personal security and rapid emergency escalation during distress situations
- Mixed deployments that pair personal trackers with other Plaspy devices for unified oversight

## Feature Availability Notes

- Manufacturer firmware and hardware revisions can change feature behavior and availability; verify specifics before large deployments
- Some features require correct configuration on the device or via SMS/app commands; setup steps can affect reporting and alerting
- Battery life and standby estimates depend on reporting intervals and usage patterns configured on the device
- Wi‑Fi fence performance depends on the availability and stability of local Wi‑Fi networks and correct safe‑zone configuration
- Fall-detection sensitivity and SOS calling behavior may be adjustable or vary across firmware versions

Using the Reachfar RF-V28 with Plaspy gives organizations a straightforward way to combine wearable personal-safety telemetry with centralized monitoring, notification, and historical review.
