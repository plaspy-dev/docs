# OKB Tehnoavtomatika - MTA-Glonass (ver.12M-CAN-PRO)

![MTA-Glonass (ver.12M-CAN-PRO)](./tracker.jpg)

The MTA-Glonass \(ver.12M-CAN-PRO\) is a professional vehicle monitoring terminal engineered for reliable satellite tracking and telematics. Purpose-built for fleet management and vehicle telemetry, this Plaspy compatible GPS tracker-class device delivers high-sensitivity GNSS positioning and multi-channel communications \(GPRS, SMS and dedicated DATA\) so dispatch centers and Plaspy users can maintain real-time tracking, event logging, and remote diagnostics with minimal integration effort.

Compact and rugged for in-vehicle installation, the MTA-Glonass \(ver.12M-CAN-PRO\) combines CAN bus integration, pulse and analog inputs, and an optional output and temperature interface to support fuel monitoring, sensor telemetry, and anti-theft workflows. When paired with Plaspy, the terminal provides a turnkey solution for fleet operators who need accurate positioning, CAN-derived vehicle data, and dependable communications across typical cellular networks.

## Key Highlights

- Plaspy compatible vehicle tracker with high-sensitivity 50-channel GNSS receiver for accurate satellite positioning and responsive real-time tracking.
- Multi-channel communications: GSM 900/1800 connectivity with GPRS, SMS and a dedicated DATA channel to ensure reliable telemetry uplink and downlink.
- Direct CAN bus integration for engine, ignition and vehicle network telemetry — ideal for fleet management and remote diagnostics.
- Fuel monitoring and pulse sensor support via dry-contact \(negative-activated\) input and a general-purpose ADC for analog sensor telemetry.
- Built-in rechargeable backup battery \(up to 600 mAh\) with a minimum of 6 hours average standby to maintain tracking and event buffering during power loss.
- Low power consumption modes \(active / standby / sleep\) to reduce load on vehicle systems and extend battery-backed operation.
- Event-rich logging \(16,000–125,000 records depending on memory\) and configurable internal/external events for audit trails, alerts, and anti-theft workflows.

## How It Works with Plaspy

The MTA-Glonass \(ver.12M-CAN-PRO\) transmits GNSS position and vehicle telemetry to Plaspy over GPRS, DATA channel or SMS. Once connected, Plaspy ingests location updates, CAN-sourced parameters, and input-triggered events to deliver real-time tracking, customizable alerts, and historical reports. The unit’s internal event storage ensures no data loss if cellular connectivity is temporarily unavailable; stored records are forwarded to Plaspy when the link is restored.

- Real-time location and telemetry updates sent to Plaspy via GPRS/DATA channel for live tracking dashboards.
- Ignition and engine status available through CAN bus integration for accurate trip start/stop and idle detection.
- Fuel monitoring supported with pulse/frequency input and analog ADC for level sensors and flow meters; Plaspy can calculate consumption and anomalies.
- Remote immobilizer or control actions can be implemented using the optional open-collector output \(subject to installation and configuration\), enabling anti-theft workflows through Plaspy.
- Temperature telemetry via optional 1-Wire input can be captured and reported in Plaspy for refrigerated cargo or environmental monitoring.
