# OKB Tehnoavtomatika - MTA-Glonass (ver.12-M RS-485)

![MTA-Glonass (ver.12-M RS-485)](./tracker.jpg)

The MTA-Glonass \(ver.12-M RS-485\) is a Plaspy compatible GPS tracker and vehicle monitoring terminal designed for fleet operators and service providers who need accurate positioning and wired sensor integration. Combining a 50-channel high-sensitivity GPS/GLONASS receiver with reliable GSM 900/1800 communications \(DATA, GPRS and SMS\), this unit provides real-time tracking, extensive telemetry and robust fuel monitoring via RS-485 connections.

Built for vehicles and telematics installations, the MTA-Glonass delivers fast technical readiness and low power draw while supporting multiple digital inputs, an ignition input, pulse/frequency fuel sensors and an RS-485 port for Omnicomm and similar fuel level sensors. Its compact IP30 enclosure and internal battery keep critical tracking and event logging running for hours after power loss — making it a practical choice for Plaspy-compatible fleet management, anti-theft and telemetry applications.

## Key Highlights

- Plaspy compatible GPS tracker with GPS/GLONASS 50‑channel receiver for precise, reliable positioning and real-time tracking.
- GSM 900/1800 communications supporting DATA, GPRS and SMS for flexible server and subscriber reporting.
- RS-485 interface for direct integration with Omnicomm fuel level sensors and other intelligent wired peripherals for accurate fuel monitoring.
- Multiple configurable digital inputs and an ignition input for engine hours counting, sleep-mode control and event-driven telemetry.
- Internal rechargeable battery \(up to 600 mAh\) and non-volatile event memory \(16,000–125,000 records depending on configuration\) to preserve data during power loss.
- Low power consumption \(active, idle and sleep modes documented\) and fast readiness \(technical readiness within 1 minute\), ideal for continuous fleet management.
- Compact, lightweight form factor \(≤90 × 65 × 30 mm, \<200 g\) suitable for discreet vehicle installation and asset tracking.

## How It Works with Plaspy

When integrated with Plaspy, the MTA-Glonass acts as a source of location and wired-sensor telemetry. The unit reports position, timed events and sensor data over GPRS/DATA or SMS to Plaspy-compatible servers for real-time tracking, configurable alerts and historical reports. Its RS-485 port enables direct fuel-level telemetry to be forwarded into Plaspy dashboards or used in fuel monitoring rules.

- Real-time location and telemetry updates sent to Plaspy via GPRS/DATA or SMS for continuous visibility.
- Ignition input provides engine-on/engine-off status and supports engine hours counting for fleet management and maintenance planning.
- Fuel monitoring via RS-485 \(Omnicomm and compatible sensors\) and a pulse/frequency input for flow or pulse-based fuel sensors.
- Event logging and buffered non-volatile memory ensure no loss of critical records if connectivity is intermittent.
- Optional open-collector output can be used for remote control actions \(for example, immobilizer or other vehicle control\) when configured and supported by installation procedures.
- Although this terminal is built around wired RS-485 integration rather than Bluetooth sensors, it complements Plaspy deployments that also include BLE-enabled devices if BLE-capable trackers are used in parallel.
