# Laipac - Starfinder Datalogger Features

This page provides a public, feature-oriented overview of the Laipac Starfinder Datalogger as it is used with Plaspy. It summarizes the device's practical capabilities, how those capabilities map to Plaspy workflows, and the kinds of operational value you can expect when the tracker is part of a Plaspy-powered monitoring and reporting setup.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation choices, and the manufacturer's implementation. Use this page for general guidance and planning; verify device-specific details, firmware notes, and installation requirements with the official Laipac documentation before deployment.

## Feature Overview

The Starfinder Datalogger is a purpose-built GPS tracker that provides live NMEA position output while also recording persistent waypoint logs for later analysis. It is designed for reliable wired connections to radios, computers, and data collection systems, and for installations in vehicles and heavy equipment where a wide input voltage tolerance is beneficial.

- Live NMEA positioning output for real-time location visibility and telemetry integration.
- Persistent local waypoint logging for post-mission replay, mapping, and analysis.
- Dual wired interfaces (RS232 and USB-C) to connect directly to radios, host computers, or collection equipment.
- Global GNSS positioning support for waypoint capture across geographic regions.
- Wide input voltage tolerance for flexible in-vehicle and heavy equipment installations.

## Core Features of Laipac - Starfinder Datalogger

- Standard NMEA sentence output suitable for real-time ingestion by compatible systems.
- Dual wired interfaces: RS232 serial and USB-C NMEA streams for direct connections.
- Onboard datalogging that records waypoints and positional tracks for later export.
- Designed for vehicle and heavy-equipment installations with practical mounting and power tolerance.
- Global GNSS support to capture waypoints in diverse operating regions.
- Simultaneous live output and local logging to support both real-time monitoring and post-mission workflows.
- Manufacturer Quick Start Guide and documentation to assist initial integration and setup.

## How These Features Work with Plaspy

When used with Plaspy, the Starfinder Datalogger supplies standard positioning streams and logged waypoint files that Plaspy can use for both live tracking and historical review. Plaspy automatically detects many compatible tracker protocols and can incorporate incoming location data into dashboards and reports.

- Live NMEA streams from RS232 or USB-C can be routed into Plaspy-compatible ingestion points for real-time location updates.
- Logged waypoint files exported from the device can be uploaded to Plaspy for replay, mapping, and audit trails.
- Simultaneous live and logged operation lets Plaspy maintain current situational awareness while preserving historical data for analysis.
- Plaspy consolidates incoming data into fleet and monitoring dashboards so operators can view live paths and historical tracks together.
- The device's wired interfaces make it straightforward to integrate with gateway or host systems that forward position data to Plaspy.
