# Starfinder Datalogger

The Starfinder Datalogger is a purpose-built GPS tracker and datalogger designed for professional mapping, telemetry and radio integrations. As a Plaspy compatible device, it delivers live NMEA positioning data over wired interfaces while simultaneously recording persistent waypoint logs for post-mission analysis. The Starfinder is optimized for workflows that require accurate waypoints, dependable real-time tracking, and straightforward connection to radios, computers, or data collection systems.

Built for vehicle and heavy-equipment installations, the Starfinder accepts a wide input power range \(9–36 VDC\) so it tolerates common installation environments without needing special power conditioning. Its global GNSS support and standard NMEA outputs \(RS232 and USB-C\) make it an effective, reliable choice for GIS mapping, scientific research, fleet management, and telemetry use cases that are part of Plaspy-powered monitoring and reporting solutions.

## Key Highlights

- Plaspy compatible — outputs standard NMEA sentences for seamless integration with Plaspy’s real-time tracking and waypoint ingestion workflows.
- Dual wired interfaces — NMEA output available over RS232 and USB-C to connect directly to radios, computers, or data collection devices.
- Persistent waypoint logging — local datalogger stores positional tracks for post-mission analysis and archival.
- Global GNSS coverage — designed to capture accurate waypoints worldwide for mapping and scientific applications.
- Wide vehicle power tolerance — 9 to 36 VDC input supports installation in cars, trucks, heavy equipment and fixed installations.
- Designed for live integration — supplies real-time NMEA sentences while recording data, supporting telemetry and live monitoring.
- Practical documentation — manufacturer-provided Quick Start Guide \(PDF\) speeds setup and initial integration with Plaspy and other systems.

## How It Works with Plaspy

The Starfinder Datalogger integrates with Plaspy by supplying standard NMEA output and recorded waypoint files that Plaspy can ingest for live monitoring and historical analysis. In a live deployment, feed the Starfinder’s RS232 or USB-C NMEA stream into a Plaspy gateway, data collector, or host computer to enable real-time tracking and telemetry dashboards. For post-mission workflows, export or upload the stored waypoint log to Plaspy for replay, mapping, and reporting.

- Real-time location and telemetry updates via NMEA streams for Plaspy-compatible endpoints.
- Live NMEA sentences over RS232 or USB-C to integrate with radios, telemetry heads, or data acquisition systems.
- Persistent waypoint logs for post-mission import into Plaspy for mapping, analysis, and audit trails.
- Works alongside fleet management tools and telemetry platforms that feed Plaspy dashboards, enabling consolidated reporting.
- Suitable for radio-linked telemetry systems where live NMEA position data is required for tracking or situational awareness.

## Why Choose This Tracker with Plaspy

The Starfinder Datalogger is a practical choice when you need a reliable GPS tracker that emphasizes accurate waypoint logging and straightforward real-time NMEA output. Its wired RS232 and USB-C interfaces remove complexity for integrations with radios, telemetry devices, and Plaspy ingestion points. The wide input voltage range and global GNSS coverage make it resilient for in-vehicle and heavy-equipment installs commonly found in fleet management, transport, and field research.

Choosing the Starfinder for a Plaspy-compatible deployment delivers clear operational value: dependable real-time tracking through standard NMEA, persistent waypoint archives for post-mission mapping and compliance, and simple wired integration that avoids network-dependent complications. If your program includes fuel monitoring, ignition control, immobilizer functions, or Bluetooth sensors, the Starfinder can be combined with peripheral telemetry or IO modules and host systems to create a full fleet or asset management solution that Plaspy can visualize and report on.
