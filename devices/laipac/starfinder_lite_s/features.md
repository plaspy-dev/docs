# Laipac - Starfinder Lite S Features

This page provides a public, features-oriented overview of the Laipac Starfinder Lite S and how its capabilities relate to use with Plaspy. It focuses on practical, non sensitive functionality that fleet operators and integrators can expect when using the Starfinder Lite S with the Plaspy platform for centralized tracking and event monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific limits, wiring instructions, or the latest firmware capabilities consult the official Laipac documentation and release notes.

## Feature Overview

The Starfinder Lite S is a compact vehicle mounted 4G LTE GPS tracker designed for fleet and asset tracking. It combines GNSS positioning with configurable reporting modes and a simple I/O and dataport interface to deliver real time location, event telemetry, and alerts that feed into Plaspy for visualization and reporting.

- Reliable GNSS positioning with 4G LTE connectivity for real time location updates
- Configurable reporting by time interval or distance traveled to balance update frequency and data use
- I/O and dataport interface to monitor main power state and enable remote control actions
- Built in event alerts such as tow detection, overspeed, geofence violation, and missing main power
- Event logging and driver performance reports for historical analysis and compliance
- Compact vehicle mounted form factor suitable for fleet vehicles and onsite equipment

## Core Features of Laipac - Starfinder Lite S

- GNSS based location for accurate real time and historic position tracking
- 4G LTE cellular connectivity to deliver location and event telemetry to a monitoring platform
- Time interval and distance based reporting modes for flexible update strategies
- I/O and dataport for vehicle integration to report main power and accept remote inputs or actions
- Tow detection, overspeed, geofence violation, and missing main power alerts for anti theft workflows
- Event logging that records movement and state changes for later analysis
- Designed for vehicle mounting with a compact form factor suited to fleet and asset protection

## How These Features Work with Plaspy

When paired with Plaspy, the Starfinder Lite S streams location updates and event telemetry into the Plaspy platform where fleet managers can view live positions, receive alerts, and generate reports. Plaspy ingests the device events and positions to provide centralized monitoring and operational oversight.

- Real time location and telemetry displayed on Plaspy maps for live tracking and monitoring
- Device generated alerts for tow, overspeed, geofence, and power loss create notifications and escalation workflows
- I/O and dataport state changes appear as device state events in Plaspy for power monitoring and remote control signaling
- Movement logs and scheduled reports are available in Plaspy for historical playback and driver performance analysis
- Plaspy automatically detects many tracker protocols to simplify initial device onboarding and reduce manual configuration
