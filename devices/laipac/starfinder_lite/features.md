# Laipac - StarFinder LITE Features

This page describes the public feature context for using the Laipac StarFinder LITE tracker with Plaspy. It focuses on user-facing capabilities, operational value, and how the device’s reports and alerts can be consumed within the Plaspy platform. The content is intended to help fleet managers, site operators, and end users understand practical functions available when the tracker is paired with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and the manufacturer’s configuration choices. For device-level details such as firmware behavior, wiring specifics, and accessory options please consult Laipac’s official documentation.

## Feature Overview

The StarFinder LITE provides compact real-time vehicle tracking using GPS and cellular connectivity together with a set of inputs, outputs, alerts, and onboard logging to support both live monitoring and post-event review. It is designed to deliver position, movement and event information useful for vehicle oversight and basic remote control functions.

- Real-time GPS tracking and cellular reporting for continuous location awareness
- Onboard data logger storing over 15,000 waypoints for route history and recovery
- Configurable alerts including geofence, over speed, tow/collision, main power disconnection, and panic
- Digital and analog I/O for connection to vehicle wiring and external sensors or switches
- Remote control capabilities for vehicle functions where supported by the installed hardware
- Audio interface with speaker and microphone jacks for voice calls when configured

## Core Features of Laipac - StarFinder LITE

- Real-time vehicle position reporting via GPS with support for enhanced satellite correction
- GSM GPRS cellular connectivity for worldwide coverage and remote reporting
- Built-in data logger capable of storing more than 15,000 waypoints for historical playback
- Multiple digital inputs and outputs plus an analog input for event and status monitoring
- Geofence and overspeed alerting to notify when vehicles cross boundaries or exceed limits
- Panic button and voice call capability through speaker and microphone jacks
- Main power disconnect alert, G-sensor alerts, and other tamper or event notifications
- USB port, harness wiring, and provided antennas for installation and configuration

## How These Features Work with Plaspy

Plaspy receives reports from compatible StarFinder LITE units and surfaces location, alerts, and historical data for operational use. Plaspy’s device detection and reporting pipeline make it straightforward to view tracker activity and configure alerting to match your workflows.

- Live location and heading shown on maps for monitoring vehicle movement in real time
- Historical routes and saved waypoints available for playback using the device’s logged data
- Alert handling in Plaspy for geofence entry/exit, overspeed, main power loss, panic, and other event types
- Display of digital input and output states and analog input events where the tracker reports them
- Remote command support in Plaspy where the tracker installation and configuration permit remote control actions
- Plaspy automatically detects tracker protocol and accepts device reports to the Plaspy server domain for integration

Note: Plaspy can accept StarFinder LITE connections and automatically detect the tracker protocol. Device configuration options such as TCP or UDP transport and server settings are handled during device setup and registration.

## Typical Use Cases

- Fleet management for real-time visibility, route playback, and alerting across a mixed vehicle fleet
- Taxi and passenger transport monitoring with panic call and voice connectivity where used
- Emergency vehicle and ambulance tracking to maintain location awareness and dispatch support
- Construction vehicle and stationary equipment tracking to monitor movement and power state
- School bus monitoring for route and stop oversight combined with event alerts
- Personal vehicle or asset logging for users who need on-device waypoint history

## Feature Availability Notes

- Feature support can vary with device firmware; some alerts or remote commands may require specific firmware releases
- Hardware revisions and optional harness wiring determine which digital inputs, outputs, and remote control functions are available
- Installation choices (for example how outputs are wired to vehicle systems) affect what remote control or diagnostic functions are practical
- Regional cellular coverage and SIM configuration influence reporting reliability and data delivery
- Always consult Laipac documentation for the exact wiring diagrams and accessory requirements for advanced functions
