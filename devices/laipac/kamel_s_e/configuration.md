# Laipac - Kamel S - E Configuration

This page provides the public configuration context for using the Laipac Kamel S - E GPS tracker with Plaspy. It explains the shared server settings Plaspy expects and the practical steps you should follow to prepare the device so it can communicate with the Plaspy platform. The guidance below draws on the device description and general public setup practices while keeping platform settings explicit.

Plaspy uses shared server settings for all supported devices and automatically detects the tracker protocol when the device connects. Exact manufacturer side steps for the Kamel S - E can vary by firmware version, hardware revision, installation type, or vendor configuration tools. Use this page to understand the Plaspy endpoint and workflow, then confirm the precise manufacturer steps with Laipac documentation and your installer tools.

## Configuration Overview

The goal of the configuration process is to point the Kamel S - E at the Plaspy server and confirm reliable reporting so the device becomes visible and manageable in the Plaspy platform. This includes setting the Plaspy endpoint, selecting the transport protocol if required, and validating connectivity over the device's 4G LTE link.

- Configure the tracker to report to the Plaspy server endpoint so data reaches the platform.
- Ensure the device is reachable over its 4G LTE connection and has adequate power and a valid SIM if required.
- Choose the transport protocol the tracker requires and set the server port to match Plaspy.
- Save and apply configuration changes and restart the tracker if the device requires it.
- Validate that the tracker is sending data and is visible in Plaspy after configuration.

## Plaspy Server Settings

- Server domain d.plaspy.com  
- Server IP 54.85.159.138  
- Port 8888  
- Transport support for UDP or TCP depending on the tracker configuration  
- Plaspy automatically detects the tracker protocol when the device connects  
- Note that Plaspy uses the same port for all supported devices which simplifies server configuration

## Typical Requirements Before Setup

- A charged or installed tracker battery and the device powered on and accessible for configuration.  
- Active cellular connectivity for the device according to its 4G LTE capability and a working SIM with data if the tracker requires one.  
- Access to the official Laipac configuration method or software used to set server and transport values.  
- Network coverage at the installation location to allow initial registration and testing.  
- Credentials or account access for Plaspy if you need to confirm device visibility on the platform.  
- Physical access or installer support to apply and verify the configuration on the tracker.

## How This Tracker Connects to Plaspy

The Kamel S - E is configured to send its location and event data to the shared Plaspy server endpoint and port. Once the tracker points to d.plaspy.com or 54.85.159.138 on port 8888 and the device transmits, Plaspy will identify the tracker protocol automatically and begin ingesting data for visibility and monitoring.

- The tracker transmits position and event packets over its cellular data link to the Plaspy server.  
- Data is sent to d.plaspy.com or 54.85.159.138 on port 8888 so it arrives at the Plaspy endpoint.  
- The transport can be UDP or TCP depending on device configuration and network requirements.  
- Plaspy performs automatic protocol detection to interpret the tracker messages.  
- Once reporting is established, Plaspy displays location updates and alerts generated by the tracker.

## Common Configuration Workflow

1. Access the official Laipac configuration method or software provided for the Kamel S - E.  
2. Locate the server or monitoring endpoint settings in the manufacturer tool or menu.  
3. Enter the Plaspy server by domain d.plaspy.com or by IP address 54.85.159.138.  
4. Set the server port to 8888 as required by Plaspy.  
5. Choose UDP or TCP if the device requires you to select a transport protocol.  
6. Apply or save the configuration in the device tool and restart the device if the device or tool recommends a reboot.  
7. Validate that the tracker reports to Plaspy by confirming the device appears and sends updates to the platform.
