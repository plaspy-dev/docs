# Laipac - Lite S Features

This page provides a public feature overview of the Laipac Lite S (also marketed as Starfinder Lite S) and explains how its capabilities are used with Plaspy for fleet and asset monitoring. Content here focuses on user-facing functions and how those functions map into Plaspy visibility and reporting.

Exact feature availability can vary by firmware version, hardware revision, installation method, and regional or manufacturer implementation. For device specific technical details and the latest firmware behavior, consult the official Laipac documentation.

## Feature Overview

The Laipac Lite S is a compact GPS tracker that combines GNSS positioning with cellular connectivity to deliver location information, configurable reporting, and a set of operational alerts. When integrated with Plaspy, these capabilities provide location awareness, event visibility, and routine reporting for vehicles and assets.

- Real time GNSS location tracking for vehicles and movable assets
- 4G LTE cellular connectivity for live updates and periodic reporting
- Time interval and distance based reports for movement history and mileage summaries
- Event alerts including tow detection, overspeed warnings, and geofence violations
- Remote IO control features and missing main power alerts to support monitoring and basic device control

## Core Features of Laipac - Lite S

- GNSS based positioning for accurate location data
- 4G LTE cellular connection for reporting and live updates
- Real time location updates to support tracking and monitoring
- Time interval and distance travelled reports for logging and review
- Configurable alerts for tow events, overspeed conditions, and geofence violations
- Driver performance monitoring features to support operational oversight
- Remote I/O control to operate or monitor external inputs and outputs
- Missing main power alerts to notify when primary power is interrupted

## How These Features Work with Plaspy

Plaspy receives and interprets the Lite S location and event data so teams can monitor assets, respond to alerts, and analyze historical movement. Plaspy automatically detects common tracker protocols and presents device activity in the platform without requiring manual protocol selection.

- Map view showing live and recent positions reported by the device
- Event notifications and log entries for tow alerts, overspeed alarms, and geofence violations
- Scheduled and on demand report access using the device time interval and distance reports
- Visibility into power loss alerts and remote IO state changes when the device reports them
- Historical playback and exportable records for audits and operational analysis

## Typical Use Cases

- Fleet location tracking and route verification for light commercial vehicles
- Asset protection and recovery assistance for mobile equipment
- Construction equipment oversight and unauthorized movement detection
- Monitoring driver behavior trends and operational efficiency
- Geofence based area monitoring for site access control
- Remote control or status monitoring of simple I O connected systems

## Feature Availability Notes

- Feature sets can vary by firmware level and hardware revision; not every unit will have identical behavior
- Some alerts and remote IO functions depend on correct installation and wiring at the vehicle or asset
- Regional cellular variants can affect connectivity and should be selected based on deployment location
- Manufacturer firmware updates can add or change functionality over time
- Verify feature support and configuration steps in Laipac documentation for device specific details

## Why Use Plaspy with These Features

Using the Laipac Lite S with Plaspy brings device-level location and alerting into a centralized monitoring and reporting environment. Plaspy helps turn tracker reports and alerts into operational insight, making it easier to supervise fleets, respond to events, and keep historical records for analysis.
