# Laipac - S911 LOLA S Features

This page provides a public feature overview of the Laipac S911 LOLA S and how its capabilities map into Plaspy for real time personal safety monitoring. It focuses on the practical, user facing features of the device and explains what you can expect when integrating the model with Plaspy for consolidated monitoring and response workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, accessory configuration and the way the device is installed or provisioned. For the most current device specific details verify the manufacturer documentation and firmware release notes supplied by Laipac.

## Feature Overview

The S911 LOLA S is a compact mobile personal emergency response system designed for immediate situational awareness and two way contact during an incident. In everyday use it provides location reporting and event-driven alerts that caregivers, dispatchers or monitoring centers can use to speed triage and response.

- Real time GNSS location reporting over cellular networks for continuous position visibility.
- Dedicated SOS emergency button to trigger immediate alerts and escalation workflows.
- Two way voice capability so a responder can speak directly with the device user during an event.
- Automatic fall detection and scheduled check ins to detect and log possible incidents.
- Geofence support to define safe areas and generate alerts on unexpected exits.
- Accessory options such as straps and cases to suit wear and carry preferences.

## Core Features of Laipac - S911 LOLA S

- Real time GNSS position reporting for continuous location awareness.
- Dedicated SOS button for manual emergency alerts.
- Two way voice communication to enable direct conversation with a monitoring center.
- Fall detection (man down) using G force sensing to raise automated alerts.
- Automatic check in and reminder capabilities to support daily care routines.
- Geofence creation and geofence violation alerts for perimeter monitoring.
- Compact pendant style form factor with accessory support for wearability.

## How These Features Work with Plaspy

When the S911 LOLA S is used with Plaspy, the device becomes part of a unified monitoring environment where position, events and status updates are visible alongside other assets. Plaspy ingests location and event data to provide consolidated views and alerting for operations teams and caregivers.

- Real time GNSS updates are shown on Plaspy maps with timestamped positions for live tracking and historical review.
- SOS events are delivered into Plaspy alert streams so dispatchers receive immediate notification and can act.
- Two way voice events and incident notes can be logged in Plaspy to support incident handling and audit trails.
- Fall detection and automatic check ins appear as event types that can trigger notifications and workflow rules.
- Geofence alerts from the device can be used to fire Plaspy notifications or trigger operational responses.
- Plaspy automatically detects supported tracker protocols so the S911 LOLA S can be added without manual protocol selection in most managed deployments.
