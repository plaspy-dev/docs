# Laipac - S911 LOLA S

![S911 LOLA S](./tracker.png)

The S911 LOLA S is a compact mobile Personal Emergency Response System designed for real time personal safety and remote monitoring. Built for dependable 4G LTE GNSS reporting, the Lola S provides continuous real time tracking, a dedicated SOS button and two way voice so caregivers, dispatchers or monitoring centers can locate and speak with a user instantly during an emergency. Its built in fall detection, automatic check ins and geofence alerts make it a practical choice for programs that need fast, reliable situational awareness.

As a Plaspy compatible device, the S911 LOLA S can feed location, status and event data into Plaspy dashboards and workflows. That compatibility lets organizations consolidate personal safety telemetry alongside other assets in Plaspy, enabling unified alerting, historical reporting and operational oversight without fragmenting monitoring across separate systems.

## Key Highlights

- Real time GNSS location reporting over 4G LTE for timely position updates
- Dedicated SOS emergency button for immediate alarm signaling
- Two way voice communication to enable direct contact between user and responder
- Automatic fall detection using a G force based man down feature
- Scheduled automatic check ins and medicine reminders to support daily care
- Geofence creation with violation alerts to monitor safe zones
- Multiple accessory options such as wrist straps, lanyards and belt cases for varied wear or carry needs

## How It Works with Plaspy

When integrated with Plaspy, the S911 LOLA S becomes a Plaspy compatible GPS tracker that contributes position and event streams to your existing monitoring environment. Plaspy can accept GNSS coordinates and device events from the Lola S so teams can view live locations, trigger alerts and keep consolidated history for incident review and reporting.

- Live location and timestamped updates appear on Plaspy maps for operational visibility
- SOS events are captured and routed into Plaspy alerting rules so responders are notified promptly
- Fall detection and automatic check in events are logged for incident review and follow up
- Geofence violations and scheduled reminders generate notifications that integrate with existing workflows
- Event metadata and activity history are available for reporting and post incident analysis

## Typical Use Cases

- Elderly care and memory care monitoring with fall alerts and check in reminders
- Lone worker protection where SOS and two way voice assist rapid response
- Campus security for student and staff personal safety with geofence and panic notifications
- VIP and first responder personal protection requiring discreet location and emergency calling
- Field staff safety for real estate agents and visiting personnel who need portable panic and contact options
