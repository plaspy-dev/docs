# Laipac - Kamel S - NA Features

This page provides a public, non sensitive overview of the Laipac Kamel S - NA tracker and how its capabilities map to monitoring and management inside Plaspy. It is intended to help users and integrators understand the practical feature set you can expect when using this model with the Plaspy platform.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation method, and the manufacturer's implementation. Where appropriate, this page notes practical expectations but users should consult manufacturer documentation for device specific details.

## Feature Overview

The Kamel S - NA is positioned as a compact, attachable asset tracker designed for straightforward deployment and ongoing monitoring. It combines cellular connectivity and GNSS positioning to provide location awareness, and it reports event types useful for usage analysis and security.

- Real time GNSS based location reporting for tracking assets on a map
- 4G LTE cellular connectivity to relay location and events to monitoring platforms
- Time interval and distance travelled reports to measure usage and movement
- Tow alerts plus over speeding and geofence violation alerts for activity monitoring
- Simple attach and go setup with no installation required for fast deployment
- IP68 water resistance and a long lasting Li Ion polymer battery for rugged on asset use

## Core Features of Laipac - Kamel S - NA

- GNSS based position tracking for continuous or periodic location updates
- 4G LTE cellular connectivity for reliable reporting to cloud services
- Time interval reports to analyze movement during defined periods
- Distance travelled reporting to quantify asset usage over trips or time ranges
- Tow alert reporting to signal unauthorized movement of assets

- Geofence violation alerts when assets leave or enter predefined zones
- IP68 water resistance and a long lasting Li Ion polymer battery for durable field use
