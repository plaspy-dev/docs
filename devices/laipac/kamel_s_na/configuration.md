# Laipac - Kamel S - NA Configuration

This page covers the public configuration context for using the Laipac Kamel S - NA tracker with Plaspy. It describes the shared server settings Plaspy uses, the typical steps required to point a device at the platform, and practical guidance to validate connectivity and reporting. The information here is intended to help installers and administrators prepare the device for use with the Plaspy platform.

Plaspy uses a shared server endpoint and port across supported devices and automatically detects the tracker protocol, while exact manufacturer side setup steps can vary by firmware, hardware revision, installation type, and vendor tools. The Laipac Kamel S - NA provides 4G LTE GNSS tracking with built in reporting features such as time interval reports, distance reports, and alerts that can be forwarded to Plaspy when the device is configured to report to the Plaspy endpoint.

## Configuration Overview

This configuration process prepares the Laipac Kamel S - NA to communicate with Plaspy so you can monitor assets and receive alerts through the platform. The goal is to update the device server settings, verify connectivity over the cellular network, and confirm that location and event reports appear in Plaspy.

- Point the device to the Plaspy server endpoint so reporting is routed to the platform
- Select the transport protocol supported by the device and Plaspy, UDP or TCP
- Set the shared port used by Plaspy and save the device configuration
- Validate that the tracker is reporting GNSS positions and alerts to Plaspy
- Confirm that distance, interval, and geofence events generated by the device are visible in Plaspy

## Plaspy Server Settings

Use these public Plaspy settings when configuring the Laipac Kamel S - NA:

- Server domain d.plaspy.com
- Server IP 54.85.159.138
- Port 8888
- Transport support for UDP or TCP
- Automatic protocol detection in Plaspy meaning the platform will detect the tracker protocol after the device reports

All devices in Plaspy use the same port and Plaspy will automatically detect the tracker protocol after the device connects.

## Typical Requirements Before Setup

- Ensure the Kamel S - NA battery is charged and the device is powered on
- An active cellular SIM with a data plan compatible with 4G LTE networks for the region
- Access to the official Laipac configuration method or vendor tool for the Kamel S - NA
- The device IMEI or identifier available for platform registration and troubleshooting
- Adequate cellular coverage at the installation location for GNSS and data upload
- A Plaspy account or project where devices will appear after successful reporting

## How This Tracker Connects to Plaspy

When configured, the Kamel S - NA sends its location and event data to the shared Plaspy server endpoint and port so the platform can process and display the information. Plaspy receives device reports and automatically identifies the protocol the tracker is using.

- The tracker is set to report to d.plaspy.com or directly to 54.85.159.138 on port 8888
- You can choose UDP or TCP transport on the device depending on firmware support
- GNSS position reports and periodic interval reports are sent to Plaspy for visibility
- Alerts such as tow, overspeed, and geofence events are forwarded to the Plaspy platform
- Plaspy automatically detects the tracker protocol so the same port is reused across devices

## Common Configuration Workflow

1. Access the official Laipac configuration method or software for the Kamel S - NA as provided by the manufacturer or vendor
2. In the device server settings enter d.plaspy.com or the IP 54.85.159.138 as the reporting endpoint
3. Set the device port to 8888 which is the shared Plaspy port used for all devices
4. Choose UDP or TCP if your device requires a transport selection
5. Apply or save the configuration through the manufacturer tool or SMS method if supported
6. Restart the device if the manufacturer documentation recommends a reboot after changing server settings
7. Validate that the device reports to Plaspy by checking for incoming positions and events on the Plaspy platform

## Example Configuration Commands

The exact commands and format to configure the Kamel S - NA depend on the Laipac configuration tool, web interface, or SMS command set for your firmware version. In general, you will supply the Plaspy server domain or IP and port and choose the transport method. For example you would configure the server settings to point to d.plaspy.com or 54.85.159.138 and set port 8888 with UDP or TCP selected when required.

If you have a Laipac SMS or command tool for your firmware the equivalent public actions are typically to set the server host and port and save the configuration. Refer to Laipac configuration instructions for exact command syntax for your device firmware.

## Configuration Notes

- Firmware versions and configuration interfaces vary by hardware revision and region so follow the device specific Laipac instructions
- Choose UDP or TCP based on network reliability and the device firmware recommendations; Plaspy supports both transports
- Because Plaspy uses the same port for all devices and auto detects protocol, you only need to ensure host and port are set correctly
- Installer practices such as testing in an open sky area help verify GNSS fixes before final installation
- For vendor specific command sets or SMS formats consult the official Laipac documentation
