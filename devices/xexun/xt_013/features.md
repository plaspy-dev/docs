# Xexun - XT-013 Features

This page provides public feature context for using the Xexun XT-013 GPS tracker with Plaspy. It summarizes the device capabilities that are relevant when devices report into Plaspy, and explains how those capabilities appear in the Plaspy platform for monitoring, alerting, and historical review.

The XT-013 description here is based on the model summary and focuses on user facing features. Exact feature availability and behavior can vary depending on firmware version, hardware revision, installation method, and manufacturer implementation. For device level configuration or the most current technical details consult the manufacturer documentation.

## Feature Overview

The Xexun XT-013 is a compact, waterproof GPS tracker designed to provide continuous position updates and event alerts in a small package. Its built in power and antenna make it suitable for standalone deployments where reliable position reporting and basic alerts are required.

- Real time location updates to support live monitoring and tracking
- Auto tracking mode for regular position reporting without manual polling
- Move and geofence alerts to detect unauthorized movement or area changes
- Overspeed limit alert to notify when a specified speed threshold is exceeded
- Low battery alert to indicate when the device needs recharging or attention
- Compact waterproof design for discreet and durable outdoor use

## Core Features of Xexun - XT-013

- Real time GPS location reporting for live visibility in tracking platforms
- Auto tracking capability for periodic position transmissions
- Move alert to notify when the unit is moved from its parked or stored location
- Geofence alert to signal entry and exit of predefined geographic areas
- Overspeed limit alert to flag when a set speed threshold is passed
- Low battery alert to help maintain uninterrupted tracking
- Compact and lightweight form factor suitable for discreet mounting
- Waterproof construction to withstand exposure to weather during normal use

## How These Features Work with Plaspy

Plaspy receives the XT-013 position updates and event messages and presents them as map locations, event timeline entries, and alerts in the platform. Plaspy automatically detects supported tracker protocols and will expose the device telemetry and alerts in standard interface elements for monitoring and reporting.

- Live position updates appear on the Plaspy map for real time tracking and dispatch
- Move, geofence, and overspeed events are recorded in the Plaspy event timeline for review and notification
- Low battery alerts surface in device status so operators can schedule maintenance
- Auto tracking updates become part of location history and playback for route review
- Plaspy detects compatible trackers and accepts their reports so devices integrate without manual protocol selection
