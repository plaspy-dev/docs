# Xexun - TK-101 Features

This page provides a public feature overview for the Xexun TK-101 GPS tracker and explains how its capabilities relate to using the device with Plaspy. It is intended to describe the user facing functions you can expect when the TK-101 reports location and events to a tracking platform such as Plaspy.

Exact feature availability and behavior can vary depending on the device firmware, hardware revision, installation method, and the manufacturer implementation. For device specific settings and the latest behavior, please consult official Xexun documentation.

## Feature Overview

The TK-101 is a compact GPS tracker that uses GSM GPRS and GPS to provide location reporting and basic event notifications. It supports both SMS and GPRS reporting methods, offers automated position reporting, and includes a set of alert features designed for asset and vehicle monitoring.

- Real time location tracking via GPS with latitude and longitude coordinates
- Position reporting over SMS or GPRS so locations can be checked remotely
- Auto reporting to provide regular position updates without manual queries
- Blind area fallback sending last known location when GPS signal is unavailable
- Geofence alerts and movement related notifications for perimeter and motion monitoring

## Core Features of Xexun - TK-101

- GPS position reporting that delivers latitude and longitude coordinates for map plotting
- GPRS and SMS connectivity options for flexible remote reporting
- Auto reporting mode for periodic position updates
- Last known location reporting when GPS is temporarily unavailable
- Geofencing capability to trigger alerts when a device enters or leaves defined areas
- Movement and overspeed notification features for detecting motion and speed threshold events
- SOS and monitoring functions to enable remote listening and emergency signaling
- User management controls to add or change usernames and passwords for access security

## How These Features Work with Plaspy

When connected to Plaspy, the TK-101's location and event messages become visible inside the platform for monitoring and operational oversight. Plaspy detects the tracker protocol and maps reported coordinates and alerts into the platform so you can see positions on a map and review event history.

- Regular auto reporting appears as periodic location updates on Plaspy maps and timelines
- Geofence events and movement alerts are recorded as events that can be filtered and reviewed
- SOS and monitoring activations are shown as high priority events for quick operator awareness
- Last known location messages from blind areas are visible in event logs to help locate coverage gaps
- SMS or GPRS based reports are consolidated into the device history so location checks are available alongside alerts

## Typical Use Cases

- Rental vehicle tracking to monitor location and movement during rental periods
- Asset and equipment monitoring for remote machinery or field devices
- Fleet visibility for small business vehicles that need periodic position reporting
- Personal vehicle or property tracking for cars, cargo, or other valuable items
- Safety monitoring where SOS alerts and remote listening are desired

## Feature Availability Notes

- Firmware revisions can change available menu options, reporting intervals, and alert behaviors
- Hardware revisions and region specific models may vary in supported networks and functions
- Installation and wiring choices affect which alerts and inputs are available after setup
- Some functions may rely on SMS availability or GPRS connectivity depending on local carriers
- Verify exact model capabilities and configuration steps with the manufacturer documentation

## Why Use Plaspy with These Features

Using the Xexun TK-101 with Plaspy provides a straightforward way to centralize location data and event alerts from this tracker into a single monitoring platform. Plaspy surfaces position updates, geofence events, movement notifications, and SOS signals so operators can maintain situational awareness, review historical tracks, and respond to incidents more efficiently.
