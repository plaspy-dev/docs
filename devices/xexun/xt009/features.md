# Xexun - XT009 Features

This page provides a public feature overview for the Xexun XT009 GPS motorcycle tracker and how those capabilities are used with Plaspy. It summarizes the device functions you can expect to see in Plaspy for monitoring and operational oversight, based on the manufacturer description and typical tracker behavior.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this guide for general planning and integration considerations, and consult the official Xexun documentation for the most current device specific details.

## Feature Overview

The XT009 is a compact motorcycle tracker designed for discreet installation and continuous location monitoring. Its built in GPS and GSM GPRS connectivity, weather resistant enclosure, and a set of user focused alarms make it suitable for vehicle visibility, security alerts, and remote status monitoring.

- Discreet motorcycle tracking with compact form and built in GPS and GSM GPRS antennas for easier concealment on two wheel vehicles
- IP67 rated enclosure for reliable operation in wet and muddy conditions
- Wide input voltage support for straightforward integration with vehicle power systems
- Selectable single location or continuous tracking modes with fast signal acquisition for timely position updates
- Multiple alarm types including speed alarm, movement alarm, low battery alarm, main power cut alarm, and ACC start off alerts
- SOS button, up to five authorized mobile numbers, SD card slot for GPRS data backup, motion shake alarm, and remote cut off capability

## Core Features of Xexun - XT009

- Built in GPS receiver and GSM GPRS module for remote location reporting and cellular data transmission
- Compact design with integrated antennas to support discreet mounting on motorcycles
- IP67 waterproof rating for operation in rain and challenging outdoor conditions
- Wide DC input compatibility to work with typical motorcycle and vehicle battery systems
- Flexible tracking modes including single location and continuous tracking plus fast signal acquisition
- Suite of alarms for security and operational awareness including speed, movement, low battery, main power cut, and ACC start off alerts
- SOS button and support for up to five authorized mobile numbers for emergency location sharing
- SD card slot for saving GPRS data and a built in motion sensor that can generate a shake alarm

## How These Features Work with Plaspy

Plaspy receives and interprets location and event data sent by compatible trackers like the XT009, presenting position, movement, and alarm events in dashboards and reports. Plaspy is designed to detect common tracker protocols automatically and accepts device reports for centralized monitoring.

- Real time and historical location visualization in Plaspy based on the device tracking mode and report frequency
- Alarm and event visibility for movement, speed, low battery, main power loss, and ACC events as platform notifications or logged events
- SOS alerts visible in Plaspy as high priority events when the device sends an emergency notification
- Remote control functions such as cut off or command based features can be coordinated through Plaspy when the device and installation support remote command execution
- Device status and connectivity indicators in Plaspy help show whether the XT009 is reporting as expected or if there are gaps in coverage

## Feature Availability Notes

- Functionality can vary with device firmware and hardware revision; some features may require specific firmware releases
- Installation choices such as wiring to vehicle battery and ACC lines affect availability of ACC alerts and main power cut notifications
- Remote cut off and other command functions typically require correct wiring and configuration and may be restricted in some regions
- Cellular coverage and a properly provisioned SIM card are required for GSM GPRS based reporting and SMS features
- SD card backup stores data locally on the device and may be useful for data recovery but is not a replacement for server side reporting
