# Xexun - TK-103 Features

This page provides a public feature overview for the Xexun TK-103 GPS tracker and explains how those capabilities can be used with Plaspy. It focuses on user facing functions, monitoring benefits, and how Plaspy can reflect the device behavior without getting into private configuration details.

Exact feature availability for any installed TK-103 can vary by firmware version, hardware revision, installation wiring, and manufacturer implementation. Where appropriate this page calls out common options and optional features, but users should verify device specific behavior in manufacturer documentation and their installed unit before relying on any particular function.

## Feature Overview

The Xexun TK-103 is presented as a flexible vehicle tracking device with real time location and monitoring features suited to cars, leased vehicles, outdoor equipment, and corporate fleets. Its capabilities center on location reporting, scheduled tracking, alarms, and options for remote control and local storage.

- Immediate inquiry location for on demand position checks of vehicles or equipment
- Regularly scheduled time tracking for automated position updates
- Address SMS inquiry support for human readable location responses
- GPS tracking blind capabilities and GSM base station location for position resilience
- Multiple alarm types including speed, vibration, SOS, and power related alarms
- Optional features such as SD card storage, dual SIM network switching, and remote power off the oil option

## Core Features of Xexun - TK-103

- Immediate inquiry location allowing a quick location response on demand
- Scheduled time tracking to report positions at user defined intervals
- Address SMS inquiry to request a textual location response via SMS
- GPS tracking blind capabilities and GSM base station location to improve position availability
- Multiple alarm types including speed alarm, vibration alarm, low battery alarm, SOS emergency alarm, GPS antenna cut off alarm, and external power supply cut off alarm
- Historical track playback for reviewing past routes and movement
- Electronic fence functionality for entry and exit alerts tied to defined areas
- Remote upgrade and remote monitoring support to manage firmware and oversight remotely

## How These Features Work with Plaspy

Plaspy can ingest and display the TK-103 reporting and events so fleet managers and operators gain timely visibility into location and alarm conditions. Plaspy automatically recognizes supported tracker protocols and surfaces core device events in the web platform and dashboards.

- Real time position updates and scheduled tracking appear on Plaspy maps for live monitoring
- Alarm events such as speed, SOS, and power loss are shown as alerts for operator attention
- Historical track data reported by the device is available for playback inside Plaspy
- Electronic fence events generate zone entry and exit notifications within the platform
- Dual SIM and network switching help maintain reporting continuity that Plaspy will display as ongoing position updates

## Typical Use Cases

- Private car tracking for location awareness and theft deterrence
- Vehicle leasing and rental monitoring to track usage and support returns
- Outdoor mechanical equipment anti theft tracking for dispersed assets
- Corporate vehicle management for route oversight and fleet optimization
- Remote monitoring where scheduled reporting and alarms reduce the need for physical checks
- Asset recovery workflows where immediate inquiry location and alarms aid response

## Feature Availability Notes

- Feature sets can differ between firmware releases and hardware revisions; confirm the unit firmware level when assessing capability
- Optional items such as SD card storage and the remote power off the oil option may require additional hardware, specific wiring, or dealer activation
- Regional device variants and local regulatory constraints can affect supported network functions and alarm behaviors
- Installation type and vehicle wiring influence availability of power related alarms and external power detection
- Manufacturer settings and provisioning determine SMS based features like address inquiry
