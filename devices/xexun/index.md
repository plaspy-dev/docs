# Xexun

Xexun produces a range of GPS tracking devices commonly used for vehicle and asset tracking. Plaspy recognizes Xexun devices and provides a unified platform to monitor location, status, and movement across fleets and equipment. This page explains how Xexun devices work with Plaspy, outlines typical capabilities and use cases, and helps you find the right Xexun device to pair with the Plaspy platform.

## How Xexun devices work with Plaspy

Xexun devices that are compatible with Plaspy can be configured to report their location and telemetry to the Plaspy platform. Typically this involves configuring the device reporting settings so that it sends position updates and status messages to Plaspy. Once the device is added to your Plaspy account, you can view real time location, history, and alerts alongside other devices in your fleet.

Plaspy provides a centralized interface for device setup guidance, data visualization, and alerting. For device specific connection and configuration instructions see the model pages accessible from the catalog below, which link to the configuration steps needed to point a device to Plaspy.
