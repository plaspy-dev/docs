# Xexun - DDX14

![DDX14](./tracker.jpg)

The DDX14 GPS/Beidou Tamper-proof Ankle Bracelet is a purpose-built Plaspy compatible GPS tracker for community corrections, healthcare supervision, and special-industry monitoring. Designed for reliable, continuous tracking, the DDX14 fuses GPS and Beidou satellite signals with WiFi and LBS positioning and transmits secure location and alarm data over domestic 2G/3G/4G cellular networks to Plaspy for real-time tracking and case management.

The DDX14 is optimized for scenarios that require strong anti-tamper measures and precise proximity detection. A conductive strap circuit triggers immediate tamper alarms, and an optional UWB module provides centimeter-level ranging when deployed with monitoring base stations. Paired with Plaspy, the DDX14 delivers real-time alerts, historical playback, configurable geo-fences and reliable offline data handling for continuous supervision and telemetry insight.

## Key Highlights

- Plaspy compatible GPS tracker: seamless integration into Plaspy for centralized real-time tracking and case workflows.
- Hybrid positioning: GPS + Beidou fused with WiFi and LBS for faster fixes and improved accuracy \(\<10 m typical\).
- Tamper-proof design: conductive strap loop triggers immediate tamper alarms plus a B-level lock core to deter unauthorized opening.
- High-precision proximity \(optional\): built-in UWB ranging module for ~0.3 m accuracy when used with base stations.
- Reliable offline behavior: blind-zone data storage with automatic re-upload when the network is restored.
- Comfortable recharging: clip-style wireless mobile power pack enables charging while the wearer moves.
- Custom alerts and voice prompts: 80 dB speaker plays custom voice messages on alarm activation.

## How It Works with Plaspy

When integrated with Plaspy, the DDX14 becomes a managed endpoint in a secure supervision or healthcare monitoring solution. The tracker collects mixed-satellite and local signals, assembles location and status telemetry, and sends packets over cellular networks to Plaspy for immediate display, alerting, and archival. Plaspy can ingest DDX14 alarms and telemetry to automate notifications, enforce geo-fence policies, and provide case officers or caregivers with up-to-date real-time tracking.

- Real-time location and telemetry updates transmitted via 2G/3G/4G to Plaspy dashboards.
- Tamper/strap conductive loop alarm reported instantly, with custom voice alert via the 80 dB speaker.
- UWB proximity and over-distance alarms when paired with monitoring base stations \(centimeter-level detection\).
- Blind-zone local storage and automatic re-upload of tracks and alarms after network recovery.
- Scheduled tracking intervals, geo-fence alerts, route deviation detection and historical track query within Plaspy.
- Remote firmware upgrade \(FOTA\) and device management through the platform for ongoing maintenance.

## Why Choose This Tracker with Plaspy

As a Plaspy compatible GPS tracker, the DDX14 delivers a balanced combination of durable anti-theft features, reliable satellite-based location and optional high-precision UWB proximity sensing. Its tamper-proof conductive strap, local offline storage and automatic re-upload make it well suited to supervision workflows that cannot tolerate data loss. Integration with Plaspy ensures supervisors and caregivers receive real-time tracking, historical playback, and configurable alerts in a single platform.

While the DDX14 focuses on person-centered monitoring rather than vehicle telemetry, organizations that use Plaspy for fleet management can run unified dashboards: Plaspy supports a variety of telemetry sources including vehicle trackers with ignition, immobilizer and fuel monitoring. This allows agencies to consolidate data across both personal supervision devices like the DDX14 and vehicle GPS trackers for comprehensive situational awareness.
