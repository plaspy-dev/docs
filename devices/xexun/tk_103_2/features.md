# Xexun - TK-103-2 Features

This page describes the public feature context for using the Xexun TK-103-2 GPS tracker with Plaspy. It focuses on user-facing capabilities, typical operational behavior, and how the device’s messaging and alarms can be used within Plaspy for visibility and monitoring. The goal is to help fleet managers, operators, and technical evaluators understand what the tracker offers when paired with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The information below reflects the TK-103-2 feature set as commonly documented by manufacturers and observed in field deployments; always refer to the device documentation from Xexun for the most current device specific details.

## Feature Overview

The Xexun TK-103-2 is designed for vehicle and asset tracking across a range of industries. It delivers location reporting, scheduled updates, and multiple alarm types to help operators detect events and review historical movements. When used with Plaspy, these capabilities support live monitoring, event-driven notifications, and playback for operational oversight.

- Real time tracking and immediate location inquiry for on demand position checks
- Scheduled time tracking for periodic location updates and routine monitoring
- Multiple alarm types including speed, low battery, vibration, SOS, GPS antenna cut off, external power cut off, and illegal fire alarm
- Historical track playback and electronic fence features for after the fact review and perimeter monitoring
- Remote upgrade and remote monitoring support to keep device behavior up to date
- Dual SIM automatic network switching and optional SD card support for added resilience and storage

## Core Features of Xexun - TK-103-2

- Real time position reporting and support for immediate location inquiries
- Scheduled time tracking with configurable reporting intervals
- Alarm suite including shift alarm, speed alarm, low battery alarm, vibration alarm, SOS emergency alarm, GPS antenna cut off alarm, external power supply cut off alarm, and illegal fire alarm
- Historical track playback for route reconstruction and review
- Electronic fence support for defining geographic boundaries and related events
- Remote upgrade capability to apply firmware updates remotely
- Remote monitoring functions for live listening or oversight as supported by device firmware
- Dual SIM card support for automatic network switching and optional SD card storage for additional local logging

## How These Features Work with Plaspy

Plaspy ingests location updates, alarms, and event reports from compatible trackers like the TK-103-2 and presents them on dashboards, maps, and event timelines. Plaspy automatically detects tracker protocols and surfaces incoming data so users can focus on operational decisions rather than low level protocol handling.

- Real time locations appear on the Plaspy map to support live tracking and dispatch decisions
- Device alarms are recorded as events in Plaspy so teams can review and be notified of critical conditions
- Historical track playback available in Plaspy uses the device reported positions for route reconstruction
- Geofence events generated by the tracker can be reflected in Plaspy for perimeter monitoring and alerts
- Remote management actions such as remote upgrade and other supported remote commands are coordinated through the platform when the device firmware supports those commands
- Plaspy detects compatible trackers and accepts data reporting to the platform domain d.plaspy.com using standard transport options so devices can report without manual protocol selection
