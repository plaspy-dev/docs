# Zilogic - Fleet

<div className="device-logo">
![Fleet](./logo.jpg)
</div>

The Zilogic BlackKite Fleet is a GPS tracker designed for mobile assets and fleet management. It integrates a highly accurate SiRF IV GPS receiver and provides dedicated interfaces to monitor key vehicle signals such as ignition, battery, and a panic button. The device also exposes multiple digital inputs and outputs plus analog inputs and a serial connection, enabling additional monitoring and control functions useful in fleet operations.

As a model compatible with Plaspy, the BlackKite Fleet can feed location and vehicle event data into a centralized fleet management platform. That compatibility makes it a practical option for organizations that want to combine precise tracking, input and output monitoring, and connection to external devices with Plaspy’s visibility, alerting, and reporting tools.

## Key Highlights

- Integrated highly accurate SiRF IV GPS for reliable location information
- Dedicated vehicle interfaces for ignition, battery, and panic button monitoring
- Three configurable digital inputs for remote status monitoring like door or meter signals
- Three digital outputs that can be used for device control or vehicle immobilization
- Two analog inputs for measuring vehicle parameters such as fuel level or temperature
- RS232 serial interface for connecting external devices such as access readers or sensors

## How It Works with Plaspy

When connected to the Plaspy platform, the Zilogic BlackKite Fleet provides position updates and event data that Plaspy aggregates for real time monitoring and historical reporting. Plaspy can display location, highlight input and output events, and use those signals to trigger alerts and operational workflows.

- Live map visibility of unit location and recent movement history
- Event alerts for ignition, panic button presses, and input state changes
- Monitoring dashboards and reports that consolidate analog and digital input data
- Remote commands and control workflows routed through platform interfaces for outputs where supported
- Fleet level oversight with grouping, filtering, and status summaries for operational decision making

## Typical Use Cases

- Managing commercial vehicle fleets for delivery, transport, and service operations
- Taxi and passenger services with fare meter and door status monitoring
- Security and theft response with immobilization and panic button alerts
- Fuel and temperature monitoring for vehicles that require analog measurement
- Operator authentication and access control using external readers via serial connection

## Why Choose This Tracker with Plaspy

The Zilogic BlackKite Fleet is a practical choice for organizations that need a balance of precise positioning and vehicle signal monitoring. Its mix of digital and analog inputs, outputs, and serial connectivity makes it adaptable to common fleet scenarios without relying on extensive custom hardware changes.

Paired with Plaspy, the tracker’s telemetry and event data can be turned into actionable visibility, alerts, and reports that support daily operations and longer term analysis.
