# Zilogic - RTU

![RTU](./logo.jpg)

The Zilogic RTU, also marketed as the BlackKite-RTU, is a versatile remote monitoring unit designed for machine to machine cloud platforms. It supports cloud-ready device protocols and provides a range of inputs and outputs for acquiring, monitoring, and controlling remote field devices. The RTU includes features for data buffering during connectivity outages, configurable reporting intervals, and optional GPS for location tracking, making it suitable for a variety of remote monitoring scenarios.

As a Plaspy compatible device, the RTU can feed location and status information into Plaspy for fleet and asset oversight. Its support for common cloud protocols and configurable transmission behavior means it can integrate with Plaspy to provide regular updates, event notifications, and historical data that Plaspy uses for visualization, alerts, and reporting. This compatibility makes the RTU a practical choice for organizations that want to combine field hardware flexibility with Plaspy operational tools.

## Key Highlights

- Cloud ready with HTTP and MQTT protocol support for straightforward integration with cloud platforms
- Configurable data transmission interval starting from 30 seconds to balance update frequency and data usage
- Internal FLASH memory that stores up to 24 hours of data during GPRS outages to prevent data loss
- IO expansion options and an optional ModBus interface to connect and control a wide range of field devices
- Optional GPS support for location monitoring of assets and vehicles
- Two level authentication for remote device access to help maintain secure connectivity
- Visual status indicators to simplify installation verification and basic troubleshooting

## How It Works with Plaspy

When paired with Plaspy, the Zilogic RTU delivers field data and device status to the Plaspy platform where it can be monitored, aggregated, and acted upon. Plaspy ingests the RTU data and provides dashboards, alerts, and reporting suited to fleet and remote asset management needs.

- Use Plaspy to visualize location data when the RTU is configured with optional GPS support
- Configure event and state alerts in Plaspy based on RTU IO changes and device generated alerts
- Monitor device connectivity and buffered data behavior in Plaspy during temporary GPRS outages
- Aggregate RTU telemetry in Plaspy for historical reporting and operational analysis
- Combine RTU inputs with other connected assets in Plaspy for unified fleet and field device oversight

## Typical Use Cases

- Remote asset tracking and basic fleet monitoring where optional GPS is required
- Industrial or utility site monitoring with digital and analog IO reporting to a cloud platform
- Remote control and actuation of field devices via digital outputs and serial interfaces
- Data collection for sites with intermittent connectivity, using onboard storage to bridge gaps
- M2M deployments that require protocol flexibility and IO expansion for diverse sensors and actuators

## Why Choose This Tracker with Plaspy

The Zilogic RTU is a practical option for organizations that need a flexible remote monitoring unit capable of integrating with cloud platforms. Its support for HTTP and MQTT, configurable transmission intervals, and onboard storage for outage resilience align well with Plaspy workflows for continuous monitoring, alerting, and reporting. Optional ModBus expansion and serial connectivity make the RTU adaptable to a range of field hardware without requiring custom hardware changes.

Because Plaspy specializes in aggregating and presenting device data for operational use, pairing the RTU with Plaspy is useful when you want a managed view of distributed devices, timely notifications of IO state changes, and historical visibility for analysis. If your deployment needs configurable reporting cadence, buffered data during outages, and optional location data, the RTU is worth evaluating as part of a Plaspy solution.
