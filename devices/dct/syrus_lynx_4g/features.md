# DCT - Syrus Lynx 4G Features

This page provides a public feature overview of the DCT Syrus Lynx 4G and how its capabilities are used with Plaspy. It focuses on practical, non-sensitive information about the tracker’s telemetry, connectivity, and operational features that Plaspy can surface for monitoring, alerts, and reporting.

Exact feature availability can vary by firmware version, hardware revision, installation choices, and manufacturer implementation. Use the content here as a general guide to capabilities and integration points; verify device-level behavior with the manufacturer documentation for final deployment decisions.

## Feature Overview

The Syrus Lynx 4G is a compact vehicle tracker designed for continuous GNSS reporting, discreet installation, and large scale fleet deployments. When integrated with Plaspy, the device provides location and event streams that support real-time monitoring and operational workflows.

- Real-time GNSS location reporting for mapping and live tracking in Plaspy
- LTE Cat 1 4G connectivity with 3G and 2G fallback for wide area coverage
- Internal backup battery to preserve reporting during power loss or tamper events
- Time-based and heading reports plus driving behavior telemetry for operational analysis
- Tow alarm detection and remote immobilizer support to aid anti-theft responses
- Multi carrier M2M Cloud Connect SIM to reduce coverage gaps in high volume rollouts

## Core Features of DCT - Syrus Lynx 4G

- GNSS positioning for accurate location, heading, and periodic time-based reports
- LTE Cat 1 4G cellular link with fallback to 3G and 2G to maintain connectivity
- Internal backup battery to keep the device reporting during vehicle power interruptions
- Tow alarm detection to generate tamper or movement alerts
- Driving behavior monitoring that captures telemetry useful for scoring and reports
- Remote vehicle immobilization support for anti-theft or misuse mitigation
- Multi carrier M2M SIM provisioning to simplify coverage across regions
- Over-the-air configuration, remote device management, and open APIs for cloud integration

## How These Features Work with Plaspy

Plaspy ingests the Lynx 4G position and telemetry streams so operators can view live status, receive alerts, and run historical reports. Device events and telemetry reported by the tracker become actionable items within Plaspy’s dashboards and notification systems.

- Live location and heading display on Plaspy maps for real-time tracking
- Alarm and tow event notifications forwarded into Plaspy for immediate alerts
- Driving behavior telemetry available for scoring, reports, and operational review
- Remote immobilizer commands initiated from Plaspy are relayed to the device via cloud APIs
- Historical route review and time-based reporting accessible through Plaspy reporting tools
- Device provisioning and remote configuration workflows supported through cloud management

## Typical Use Cases

- Fleet management for continuous location visibility and route monitoring
- Rental operations requiring discreet installation and tamper awareness
- Anti-theft protection using tow alarms and remote immobilization workflows
- Insurance telematics programs that rely on driving behavior telemetry for usage based assessments
- High-volume rollouts where multi carrier SIM provisioning and cloud management simplify logistics
- Large deployments needing centralized monitoring, alerts, and OTA configuration

## Feature Availability Notes

- Firmware differences can change telemetry cadence, available reports, or alarm behavior; check firmware release notes for specifics.
- Hardware revisions and regional variants may affect cellular band support and physical interfaces.
- Some capabilities depend on installation choices and wiring; inputs for alarms or immobilizer control are installation dependent.
- Integration of external sensors or third party telemetry may require additional configuration on both the device and Plaspy side.
- Manufacturer platform features and cloud services can influence over-the-air management and API behavior.

Using the Syrus Lynx 4G with Plaspy gives organizations a practical path to consolidate location, alerts, and telematics into a single operational view.
