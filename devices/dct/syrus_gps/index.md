# DCT - Syrus GPS

![Syrus GPS](./logo.jpg)

The DCT Syrus GPS is a high-performance GPS tracker designed for IoT/M2M applications that require fast and reliable data transfer. With its high-speed data transfer capabilities, this tracker ensures efficient communication and interaction between devices.

One of the standout features of the Syrus GPS is its 3-Axis Internal Digital +-16G accelerometer. This accelerometer provides instant acceleration monitoring and has a back log for crash condition history reports. It also features a fully integrated 3-axis accelerometer that enables motion and shock detection, driver metrics performance, tow alert, and power management applications. These configurable events make it a versatile tracker for various use cases.

In addition, the Syrus GPS offers backup satellite communication capability. It is compatible with the IRIDIUM network, allowing for reliable communication even in remote areas. This feature requires a SATCOM accessory, which can be purchased separately. The tracker can be configured and managed through the PEGASUS Gateway, which provides advanced OTA configuration management.

The Syrus GPS is built to withstand harsh weather conditions, thanks to its water-resistant IP65 rating. It is suitable for use in all kinds of vehicles and mobile assets that are exposed to challenging environments. The tracker also includes tamper detection functionality, which accurately detects when the device's case has been opened.

Other notable features of the Syrus GPS include ECU Monitor compatibility for easy CAN/OBD integration, a large store and forward buffer that can save up to 30,000 events when no network is available, intelligent geofencing capability with support for up to 100 circular and 50 polygonal user-defined geofences, and low energy consumption during sleep mode to conserve power.
