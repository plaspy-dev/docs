# DCT - Syrus 4G Lite Features

This page provides a public feature overview for the DCT Syrus 4G Lite and how its capabilities map to use with Plaspy. It focuses on user-facing functionality and practical operational value when the device is deployed into Plaspy for fleet tracking, telemetry, and remote device management.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For the most current device specific details and technical references consult the official DCT documentation and release notes.

## Feature Overview

The Syrus 4G Lite is a rugged IoT telematics gateway intended for continuous location tracking, event capture, and remote diagnostics in demanding vehicle and field asset environments. Its combination of multi‑mode cellular connectivity, onboard GNSS, blackbox logging and an internal backup battery supports uninterrupted data flow into fleet platforms such as Plaspy.

- Real time GNSS location and route logging for live vehicle visibility and historical replay
- Blackbox incident recording that preserves time stamped telemetry for post event analysis
- Engine diagnostics and fault code reporting to enable proactive maintenance workflows
- Multi mode cellular support including 4G Cat 1 and LTE IoT variants for broad coverage
- Rugged IP65 enclosure with integrated antennas and an internal backup battery for resilient field operation
- Edge programmability and scripting for local logic and data filtering prior to Plaspy ingestion

## Core Features of DCT - Syrus 4G Lite

- Onboard GNSS receiver providing continuous position and route data
- Blackbox recording to capture pre and post event telemetry for incident review
- Engine fault code reading and vehicle diagnostics reporting for maintenance prioritization
- Multi mode cellular connectivity with support for mainstream LTE IoT modes for extended coverage
- IP65 rated rugged enclosure with integrated cellular and GNSS antennas for vehicle and outdoor use
- Internal backup battery to maintain connectivity during power interruptions or tamper events
- Apex Linux Yocto based platform and Syruslang scripting for edge programmability and custom logic
- Remote management and over the air firmware update capability to simplify fleet maintenance

## How These Features Work with Plaspy

Plaspy ingests the Syrus 4G Lite telemetry to provide centralized monitoring, reporting and device management. Plaspy automatically detects supported tracker protocols and maps incoming location and telemetry into dashboards, alerts and historical reports so operators can act on real world events.

- Real time location and telemetry appear in Plaspy dashboards for live tracking and route playback
- Blackbox logs and time stamped event data are available for incident reconstruction and audit
- Engine fault codes and vehicle health indicators feed maintenance and service scheduling workflows
- Remote configuration and OTA updates can be coordinated from Plaspy device management where supported
- Peripheral signals such as ignition, door or alarm inputs can be correlated with location and diagnostics when those signals are provided by the installation

## Typical Use Cases

- Fleet theft deterrence and investigation using blackbox logs and remote monitoring
- Proactive vehicle maintenance driven by engine fault code reporting and telemetry
- Trailer and equipment tracking in harsh outdoor environments with a rugged IP rated enclosure
- Incident analysis and insurance documentation using time stamped blackbox recordings
- Industrial asset telemetry and remote diagnostics for logistics and field service operations
