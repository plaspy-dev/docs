# DCT - Syrus Satcom Lite Features

This page provides a public feature overview for using the DCT Syrus Satcom Lite tracker with Plaspy. It summarizes practical capabilities, operational value, and how the device can feed location and telemetry into Plaspy for consolidated monitoring and alerts. Content here is intended for general planning, discovery, and SEO visibility rather than device configuration.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, optional accessory modules, and how the manufacturer configures the unit. For implementation details, gateway settings, and the most current technical specifications, consult the official manufacturer documentation.

## Feature Overview

The Syrus Satcom Lite is a battery powered, satellite enabled GPS tracker built to extend Plaspy compatible real time tracking to assets operating beyond cellular coverage. It pairs motion sensing and comparative GPS reporting with configurable auxiliary inputs and alert forwarding to provide continuous visibility in remote or harsh environments.

- Satellite enabled communications for tracking where cellular networks are unavailable
- Battery powered rugged design for long term deployments in remote locations
- Motion sensing and comparative GPS position reporting to detect movement and location change
- Configurable auxiliary sensor inputs that allow custom telemetry to be reported
- Configurable intermediate reports and urgent alerts that can be forwarded by email or text
- Managed via Pegasus IoT Cloud and integrable with Plaspy for centralized tracking

## Core Features of DCT - Syrus Satcom Lite

- Satellite enabled location reporting for out of coverage asset visibility
- Battery powered operation suited for remote and harsh deployments
- Built in motion sensing to detect movement events and trigger reports
- Comparative GPS position logic to identify location changes between updates
- Configurable auxiliary sensor inputs for custom telemetry and status monitoring
- Emergency and exception alerting with forwarding to email or text contact lists
- Remote management through Pegasus IoT Cloud for visualization and device control
- Designed for integration with cloud platforms such as Plaspy for consolidated tracking

## How These Features Work with Plaspy

When Syrus Satcom Lite is used as a Plaspy compatible tracker, satellite and GPS telemetry flow into Plaspy so teams can monitor assets, receive alerts, and review historical movement on maps and dashboards. Plaspy ingests location updates, motion events, and auxiliary sensor data to support rules based monitoring and operational response.

- Real time location and telemetry updates appear in Plaspy for continuous situational awareness
- Motion detection events and comparative GPS changes can drive anti theft alerts and notifications
- Auxiliary sensor inputs reported by the device are available in Plaspy for condition monitoring
- Emergency and exception alerts forwarded by email or text are routed into operational workflows
- Plaspy displays supported telemetry such as ignition, fuel monitoring, immobilizer, or Bluetooth sensor data when those inputs or accessory modules are provided by the device or integrations

## Typical Use Cases

- Fleet oversight for long duration or off grid assets requiring periodic reporting and alerts
- Condition based monitoring using auxiliary inputs to report custom telemetry back to Plaspy
