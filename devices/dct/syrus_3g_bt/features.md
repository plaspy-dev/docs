# DCT - Syrus 3G+ BT Features

This page describes the public feature context for using the DCT Syrus 3G+ BT tracker with Plaspy. It summarizes the device capabilities as they relate to real-time tracking, sensor integration, and cloud connectivity through Plaspy so fleet and telemetry teams can evaluate fit and operational value.

Exact feature availability can vary by device firmware, hardware revision, installed accessories, and manufacturer implementation. The information below is based on the device description provided by the manufacturer and highlights functionality commonly used when integrating Syrus 3G+ BT with Plaspy.

## Feature Overview

The Syrus 3G+ BT is a rugged telematics gateway built to aggregate location and peripheral telemetry for vehicle and industrial deployments. When used with Plaspy it provides a flexible edge node for collecting Bluetooth sensor data, accessory inputs, and continuity options for remote operations.

- Bluetooth 4.1 Smart Ready for pairing with low power sensors and tags such as the Syrus BTT-1634
- Multiple physical accessory ports to connect telemetry peripherals and status inputs
- Optional Iridium satellite backup accessory to preserve connectivity beyond cellular coverage
- Pegasus Gateway REST APIs for cloud integration and abstracted device management
- Rugged form factor intended for vehicle and industrial installations for reliable field operation
- Designed to forward location and sensor streams for real-time tracking and reporting

## Core Features of DCT - Syrus 3G+ BT

- Bluetooth 4.1 Smart Ready support for low-power sensor pairing and beacon integration
- Compatibility with Syrus BTT-1634 multi-sensor tag for expanded telemetry
- Multiple accessory ports for connecting external sensors and vehicle interfaces
- Optional Iridium Satcom accessory support for satellite backup messaging
- Pegasus Gateway REST APIs to simplify cloud integration and device abstraction
- Rugged telematics gateway design suitable for vehicle and industrial settings
- Modular sensor ecosystem allowing multi-sensor deployments with external peripherals

## How These Features Work with Plaspy

Syrus 3G+ BT devices can forward location and sensor information into Plaspy so operators see vehicle position, status, and peripheral telemetry in a unified platform. Plaspy receives device data streams and presents them as map markers, events, and reports for operational oversight.

- Real-time location updates and historical tracks shown within Plaspy map and reporting views
- Bluetooth sensor data from paired tags can surface as telemetry channels in Plaspy dashboards
- Accessory port inputs are forwarded to Plaspy as status or event data when configured and installed
- Optional satellite backup preserves essential alerting and location reporting to Plaspy when cellular is unavailable
- Pegasus Gateway REST APIs enable API-driven device configuration and remote management workflows that integrate with Plaspy
- Plaspy can detect and interpret supported tracker protocols automatically to simplify onboarding

## Typical Use Cases

- Fleet tracking and route visibility for vehicle operations with combined location and sensor data
- Anti-theft monitoring that combines device location and external sensor inputs with alerting
- Industrial asset monitoring using Bluetooth tags for environmental or tamper indications
- Fuel and status telemetry when external sensors are attached to accessory ports and relayed to Plaspy dashboards
- Hybrid connectivity deployments using cellular primary transport and optional satellite fallback for remote assets
- Rapid deployments where Pegasus Gateway APIs reduce integration time for cloud forwarding to Plaspy
