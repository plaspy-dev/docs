# DCT - Syrus 3G+ Features

This page provides a public feature overview of the DCT Syrus 3G+ and how its capabilities map to Plaspy for fleet and asset tracking. It describes the device features relevant to Plaspy deployments, developer integrations, and typical operational use without replacing manufacturer documentation or formal integration guides.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, installation method, and how the manufacturer implements specific functions. For device specific technical details and the latest firmware or datasheet updates, consult official DCT documentation and your supplier.

## Feature Overview

The Syrus 3G+ is positioned as a rugged, API ready telematics hub designed to deliver location and telemetry into cloud platforms such as Plaspy. It combines durable enclosure design, low power operation, and a developer oriented integration stack to support real time tracking, telemetry enrichment, and automated workflows.

- API ready Pegasus Gateway and REST API support to accelerate cloud integration and data ingestion.
- Multi port sensor and accessory support for collecting extended telemetry beyond basic GPS coordinates.
- IP65 sealed enclosure for reliable outdoor and vehicle installations in harsh environments.
- Ultra low power sleep mode suitable for battery backed or remote deployments.
- Built in counters and event logic for route monitoring, metric reporting, and automation triggers.
- Developer kit and enablement platform to support rapid prototyping and M2M workflows.

## How These Features Work with Plaspy

Plaspy ingests the Syrus 3G+ telemetry and location streams and exposes those inputs through live maps, historical replay, alerts, and dashboards. The device's API focused design and developer resources make it practical to onboard Syrus payloads quickly and convert raw inputs into operational insights inside Plaspy.

- Real time location updates and historical position replay visible on Plaspy maps and reports.
- Event and metric reporting surface counters, route events, and custom telemetry for dashboards and alerts.
- Sensor visualization in Plaspy driven by the Syrus multi port input data to show external sensor values and states.
- Integration support for security and anti theft workflows coordinated through Plaspy automation where vehicle wiring and actions are configured.
- Developer enablement via the Pegasus Gateway and REST API to map Syrus telemetry to Plaspy data models and to build webhooks or custom parsing.
- Automatic protocol detection in Plaspy simplifies device onboarding and initial connectivity for many common tracker payloads.
