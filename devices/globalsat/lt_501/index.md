# GlobalSat - LT-501

![LT-501](./logo..jpg)

The GlobalSat LT-501R Series is a LoRa GPS asset tracker designed for both indoor and outdoor monitoring of objects. With its compact and lightweight design, this tracker is easy to use and provides reliable tracking capabilities. It is compatible with the Helium Network, ensuring seamless connectivity and efficient data transmission.

One of the standout features of the LT-501R is its long battery life, thanks to the built-in 19A battery. This ensures that the tracker can provide basic power usage for extended periods, reducing the need for frequent recharging or battery replacements.

With support for LoRaWAN™ Class A/Class C, the LT-501R offers flexible tracking options. It allows for both regular and real-time tracking, with customizable report intervals and the ability to enable or disable GPS functionality. The device is also equipped with a built-in 3-axis accelerometer for motion detection, making it ideal for monitoring objects in various environments.

In addition to its tracking capabilities, the LT-501R features built-in Bluetooth Low Energy \(BLE\) for indoor positioning using beacons. It also supports geo-fencing functions, allowing users to set up virtual boundaries and receive alerts when the tracker enters or exits these predefined areas. The device is equipped with a micro USB connector for easy charging and data transfer.

With its robust feature set and reliable performance, the GlobalSat LT-501R Series is an excellent choice for asset tracking applications that require long battery life and accurate location monitoring. Whether you need to track assets indoors or outdoors, this tracker provides the versatility and functionality to meet your needs.

### Key Features:

- Supports LoRaWAN™ Class A/Class C
- Outdoor/Indoor geo-location
- Long-distance transmission
- Regular/Real-time tracking
- Built-in 3-axis accelerometer for motion detection
- Built-in Bluetooth Low Energy \(BLE\) for indoor positioning
- Supports geo-fencing functions
- Micro USB connector for easy charging and data transfer

Technical Specifications:

- Dimension: 84 x 69.6 x 52.8 ± 0.15 mm
- Weight: 98 ± 5 g \(without battery\); 200 ± 10g \(with battery\)
