# GlobalSat - TR-313 Features

This page summarizes the public feature context for using the GlobalSat TR-313 with Plaspy. It focuses on the practical capabilities that matter when the TR-313 is deployed with the Plaspy fleet and asset monitoring platform, and explains how those capabilities are typically represented in a tracking service.

The TR-313 is a compact 3G personal tracker with a fast acquisition GPS module, built in microphone and speaker for two way voice, and an emergency button for rapid alerts. Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, cellular plan, and manufacturer implementation, so refer to official GlobalSat documentation for device specific details.

## Feature Overview

The TR-313 provides a small form factor personal tracking solution designed for location awareness and personal safety. In Plaspy, the device is treated as a compatible tracker that reports location and event information so operators can monitor movement and receive alerts.

- Accurate location reporting from a fast acquisition GPS module for real time position awareness
- Compact and lightweight design makes the unit suitable for personal carry or discreet placement
- Built in microphone and speaker enable hands free two way communication between the device and paired phone numbers
- Emergency button for immediate signaling to pre set contacts and for sending alert events
- User friendly operation intended for personal tracking scenarios such as child or elder monitoring

## Core Features of GlobalSat - TR-313

- 3G network personal tracker for cellular based position reporting
- Fast GPS acquisition for timely location fixes
- Built in microphone for remote audio monitoring when enabled by the device
- Built in speaker for two way voice interaction initiated from the device or pre configured numbers
- Dedicated emergency button that triggers calls and emergency alerts to configured contacts
- Compact lightweight enclosure suited for personal carry and discreet use

## How These Features Work with Plaspy

When a TR-313 is used with Plaspy the platform receives and displays the device's location and event signals to support monitoring and response workflows. Plaspy detects compatible tracker protocols and shows device status and event history alongside map views and reporting tools.

- Real time location updates appear on Plaspy maps and in position history for playback and auditing
- Emergency button activations are surfaced as alert events so operators can prioritize response
- Device status and recent activity are visible in the device list and detail view for operational oversight
- Two way communication remains a device level capability while Plaspy records related events and timestamps where available
- Plaspy handles protocol detection and integrates the TR-313 into device management and reporting dashboards
