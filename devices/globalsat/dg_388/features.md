# GlobalSat - DG-388 Features

This page provides a public feature overview for the GlobalSat DG-388 and explains how its logged GPS telemetry can be used with Plaspy for historical route import, activity reporting, and telemetry analysis. It focuses on practical, non sensitive information about what the device records and how that data is useful inside Plaspy workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The content here is based on the DG-388 public description and is intended to help you understand capabilities in a Plaspy context while encouraging verification against manufacturer documentation.

## Feature Overview

The DG-388 is a standalone GNSS data logger designed to capture detailed location tracks for later export and analysis. It is useful when continuous cellular connectivity is not required and when accurate historical routes are needed for mapping, reporting, or incident reconstruction.

- Records time stamped GPS points including coordinates, speed, altitude, and time for accurate route reconstruction.
- Large onboard memory to store long trips and detailed track histories before downloading.
- Rugged, compact and waterproof design suited for outdoor activity tracking and travel.
- Multiple logging modes and motion assisted recording to balance battery life with data density.
- Onboard feedback via vibrator and beeper to confirm recording status during use.

## Core Features of GlobalSat - DG-388

- High performance GNSS chipset for faster satellite fixes and improved location accuracy.
- Large logging capacity capable of storing up to 500,000 points for extended journeys.
- Rechargeable battery with smart power management to support long duration logging sessions.
- IPX7 waterproof compact housing for reliable outdoor use.
- Built in motion sensor plus vibrator and beeper for low power automatic logging and user feedback.
- Flexible logging modes including time, distance, and speed interval options.
- PC download and export tool to retrieve recorded sessions and create standard track files.

## How These Features Work with Plaspy

The DG-388 is a local logger rather than a live cellular tracker. Its primary Plaspy value is as a source of verified historical telemetry that can be imported into Plaspy for analysis, reporting, and archival.

- Export logged tracks with the supplied PC tool and import exported track files into Plaspy for route history and activity reports.
- Time stamped coordinates, speed and altitude provide accurate inputs for Plaspy mapping, timelines and performance analysis.
- Motion sensor events and activity markers can be used to filter or annotate imported sessions inside Plaspy.
- Adjustable logging intervals let you control data density before import, making analytics and storage more efficient in Plaspy.
- Offline recording is suitable for generating evidence or historical records that supplement Plaspy real time streams.

## Typical Use Cases

- Outdoor sports and adventure tracking where ruggedness and offline recording are required.
- Travel and trip logging for later mapping and timeline analysis in Plaspy.
- Personal activity monitoring and elder care scenarios using motion triggered logging and feedback.
- Evidence collection and post incident route reconstruction for investigations or insurance reviews.
- Offline asset or equipment location history when live GSM tracking is not necessary.

## Feature Availability Notes

- Feature behavior such as logging intervals, motion sensitivity, and battery endurance can change with firmware updates.
- Hardware revisions or regional variants may alter available functions or included accessories.
- Installation and user settings influence recorded data density and battery life, so results vary by configuration.
- Use the manufacturer PC tool supplied with the device to export data in formats compatible with Plaspy.

Using the DG-388 with Plaspy is useful when you need high quality historical telemetry to complement real time monitoring or to populate archives and reports. Plaspy can ingest exported tracks and present them alongside live streams, enabling unified timelines, map visualizations, and activity analytics that benefit fleet managers, investigators, and individual users alike.
