# GlobalSat - GTR-388C1 Features

This page provides a public feature overview of the GlobalSat GTR-388C1 and how its capabilities map to the Plaspy platform. It is intended to describe the model's practical functions, typical uses, and the ways telemetry and events from this tracker appear in Plaspy dashboards and reports.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional SKU, installation method, and manufacturer implementation. For device specific technical limits, configuration options, or the latest firmware details please consult the official GlobalSat documentation and release notes.

## Feature Overview

The GTR-388C1 is a compact, rugged GPS tracker designed for small vehicles, motorcycles and eBikes. It combines cellular connectivity, high sensitivity GNSS, and a waterproof enclosure with a backup battery and versatile I/O so that Plaspy can ingest live position and event data for monitoring and fleet workflows.

- Real time location reporting over cellular networks for live tracking and route replay in Plaspy
- IPX7 waterproof enclosure and compact form factor for exposed and concealed installations on small vehicles
- Built-in backup battery to continue reporting on main power loss for anti theft and persistence of alerts
- Multiple I/O including ACC ignition detection, emergency input, analog input and a digital output for remote relay control
- Support for firmware over the air updates to keep device behavior current and manageable at scale

## Core Features of GlobalSat - GTR-388C1

- 4G LTE Cat 1 connectivity with automatic fallback to 3G and 2G to maximize area coverage
- High sensitivity GNSS receiver with A GPS support for faster position fixes and accurate route history
- IPX7 rated waterproof enclosure with waterproof cable connector suitable for exposed outdoor mounting
- Built in 820 mAh rechargeable backup battery that sustains operation during power interruptions
- Rich I O set including ACC/ignition detection, multiple digital inputs including emergency button, one analog input and one digital output for relay control
- Firmware updates over the air for remote maintenance and feature updates
- Compact and lightweight form factor with mounting accessories for concealed or surface installations
- Support for reporting and configuration via common channels including TCP UDP HTTP and SMS

## How These Features Work with Plaspy

When the GTR-388C1 is installed and configured, it streams GNSS positions and I O events into Plaspy so fleet managers can monitor vehicles and react to events without needing to access the device directly.

- Live position updates and historical route replay appear in Plaspy maps and trip reports
- Ignition ACC input allows Plaspy to correlate driving time, idling periods and ignition events for operational reporting
- Motion and tamper related events can be used to trigger alerts and anti theft workflows inside Plaspy
- Analog input data can be integrated into Plaspy dashboards when connected and calibrated for specific telemetry like external sensors
- Digital output control can be used to implement remote relay actions or immobilization workflows coordinated through Plaspy

## Typical Use Cases

- Anti theft protection for motorcycles and eBikes with movement alerts, backup battery persistence and remote relay control options
- Small vehicle and last mile delivery fleet tracking with live positions, route replay and ignition based usage reporting
- Concealed asset tracking for rental fleets and shared micromobility where waterproofing and compact mounting are required
- Historical route analysis for safety reviews and compliance monitoring using GNSS fixes recorded and visualized in Plaspy
- Remote telemetry extension for vehicles using analog inputs and digital outputs when paired with accessories

## Feature Availability Notes

- Some features depend on the installed firmware version and may be expanded or refined by manufacturer firmware updates

- Optional accessories such as external relays or OBDII adapters may be required to enable specific telemetry or control workflows

Pairing the GTR-388C1 with Plaspy gives organizations a lightweight and rugged tracker option that feeds position and event data into a central platform for visibility, alerting and reporting. The combination of GNSS performance, backup power and flexible I O makes this model suitable for small vehicle fleets and two wheeled assets that require discreet installation and reliable continuity of reporting.
