# GlobalSat - TR-616C1 Features

This page summarizes the public feature context for using the GlobalSat TR-616C1 with Plaspy. It is focused on practical, user facing capabilities and how those capabilities map to Plaspy visibility and fleet workflows. Where useful, this content highlights the device features that enable integration with Plaspy for tracking, alerts, and remote management.

Exact feature availability and behavior can vary by firmware version, hardware revision, region, installation method, and manufacturer implementation. For device specific setup, firmware behavior, or accessory options consult GlobalSat documentation and your device vendor for the most current technical details.

## Feature Overview

The TR-616C1 is designed as a compact vehicle tracker that delivers real time location and essential vehicle telemetry to a fleet platform such as Plaspy. Its combination of GNSS sensitivity, multi band cellular connectivity, and support for remote management makes it suitable for continuous tracking and recovery scenarios.

- Real time GPS position reporting to Plaspy using TCP UDP or SMS for integration flexibility.
- Buffered logging of up to 3,000 location points to preserve history during connectivity interruptions.
- Vehicle telemetry inputs including ignition ACC status and visible LED indicators for cellular GPS and power.
- Built in backup battery to maintain operation during main power loss for recovery and continuity.
- Support for OTA firmware upgrades and remote configuration for reduced field maintenance.

## Core Features of GlobalSat - TR-616C1

- High sensitivity GNSS receiver for reliable position fixes in typical vehicle deployments.
- Multi band cellular modem supporting a range of regional networks for broad coverage and fallback.
- Real time reporting via TCP UDP and SMS for flexible data delivery to Plaspy.
- Buffered storage of location points so data can be uploaded after network reconnection.
- Ignition ACC input to report engine on off state for drive time and usage analytics.
- Built in backup battery to provide several hours of operation during power loss.
- Remote management features including OTA firmware upgrades and AT command support for integration.

## How These Features Work with Plaspy

Plaspy receives position updates, event messages, and telemetry from the TR-616C1 and makes those data points available for mapping alerts and reporting. The device features enable common monitoring flows and help keep historical records complete even when connectivity is intermittent.

- Live positions and periodic updates appear in Plaspy maps and tracking views when the device reports via TCP UDP or SMS.
- Buffered logs are uploaded after reconnect so Plaspy can display continuous history and route replay without gaps.
- Ignition status and event messages are visible in Plaspy to support drive time analytics and engine on off reporting.
- Event driven alerts such as motion detection, power loss, and geo related triggers can be forwarded to Plaspy for notifications and rule based actions.
- Remote configuration and OTA updates help ensure the tracker remains aligned with your Plaspy reporting and firmware policy.

## Typical Use Cases

- Driver and vehicle activity monitoring using ignition status and event reporting.
- Logistics and courier tracking where buffered logging preserves history during coverage gaps.
