# GlobalSat - TR-606 Features

This page presents the public feature context for using the GlobalSat TR-606 tracker with Plaspy. It summarizes the TR-606 capabilities that are relevant for vehicle tracking and fleet operations and explains how those capabilities are typically reflected when the device reports into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Users should treat the descriptions here as high level public guidance and verify device specifics with the manufacturer documentation when required.

## Feature Overview

The GlobalSat TR-606 is designed as a compact AVL tracker that provides reliable position reporting and remote control capability via cellular networks. It combines a high sensitivity GPS component with multi band cellular communication to support continuous tracking and status updates useful for fleet and logistics operations.

- Accurate real time GPS location reporting suitable for vehicle tracking
- Dual band UMTS HSDPA and quad band GSM cellular connectivity for broad network coverage
- Compact and lightweight enclosure for straightforward installation in vehicles
- Vehicle status updates reported to a server for monitoring and operational oversight
- Remote vehicle control capabilities that can be invoked from a management platform

## Core Features of GlobalSat - TR-606

- High sensitivity GPS chipset for consistent location acquisition
- Dual band UMTS HSDPA support for 3G cellular networks
- Quad band GSM support for broad 2G cellular coverage
- Real time GPS location reporting to a remote server
- Vehicle status reporting suitable for AVL use cases
- Remote vehicle control functions initiated from a remote platform
- Compact, rugged enclosure for straightforward mounting and installation

## How These Features Work with Plaspy

Plaspy receives and processes the TR-606 position and status messages to give operators visibility into vehicle location and operational status. Plaspy is designed to detect supported tracker protocols automatically and present location updates and events in the platform interface.

- Position reports and vehicle status messages appear in Plaspy as location updates and timeline events
- Remote control commands available on the TR-606 can be issued from Plaspy when the device and installation permit remote actuation
- Plaspy automatically detects the tracker protocol during device registration to simplify setup
- The tracker can be pointed at Plaspy servers for reporting so that location and status flow into Plaspy dashboards
- Real time tracking in Plaspy supports operational monitoring, dispatch, and route oversight
