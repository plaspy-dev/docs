# GlobalSat - TR-300V Features

This page provides a public feature overview for the GlobalSat TR-300V and explains how its capabilities are commonly used with Plaspy for monitoring and alerting. It focuses on user facing functions described by the manufacturer and how those functions map to operational visibility in Plaspy.

Exact feature availability and behavior can vary by firmware level, hardware revision, installation method, and manufacturer implementation. For device specific setup, configuration commands, and the latest technical details consult the official GlobalSat documentation and the device manual.

## Feature Overview

The TR-300V is a compact 3G personal tracker designed for child and elder safety with a focus on simple operation and long run time. Its core purpose is to provide location awareness, emergency alerting, and basic remote monitoring so caregivers and monitoring centers can maintain visibility and respond when needed.

- Compact lightweight form factor suitable for wearable or pocket carry
- Two way hands free voice communication using built in microphone and speaker
- SOS button that calls preset contacts and sends an SOS alarm to a monitoring endpoint
- Long run time from a high capacity battery to reduce charging frequency
- Remote configuration and tracking via command messages to the device
- Geo fence setup to define permissible or restricted areas for monitoring

## Core Features of GlobalSat - TR-300V

- 3G network personal tracking for continuous location reporting as supported by the device
- Built in microphone and speaker enabling hands free two way voice communication
- Dedicated SOS button to trigger immediate call and SOS alarm to pre configured recipients
- High capacity battery designed to extend operational intervals between charges
- Remote configuration and tracking via manufacturer supported command messages
- Geo fence configuration to create permitted and restricted areas for monitoring
- Compact and easy to use design aimed at children and elderly users

## How These Features Work with Plaspy

Plaspy provides a central platform to receive and present the events and location updates the TR-300V reports. Where the device reports status or alarm events, Plaspy surfaces that information so operators and guardians can see it in a single monitoring view.

- Display of reported location and recent position history for situational awareness
- SOS alarms and alert events flagged so monitoring staff or contacts can respond
- Visualization of geo fence zones and notification of zone entries and exits when the device reports those events
- Visibility of voice related events or timestamps if the device includes call logs or reports call state to the platform
- Centralized device presence and status reporting to support monitoring workflows
- Plaspy automatically detects supported tracker protocols and integrates reported events into the device timeline for inspection

## Typical Use Cases

- Child safety monitoring with location checks and quick emergency alerts
- Elder care and assisted living oversight where simple emergency calling is required
- Lone person safety monitoring for caregivers and family members
- Monitoring center integration to receive alarms and remote tracking updates
- Temporary monitoring for outings or travel where an easy to carry device is needed
- Situations where hands free two way communication improves response options
