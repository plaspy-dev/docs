# Mtx

Mtx is a recognized brand in the GPS tracking space with device models that can be used for vehicle and asset monitoring. This page explains how Mtx trackers integrate with Plaspy, what to expect from compatible devices, and where to find model specific information inside Plaspy. Use the catalog below to jump directly to supported models and device pages.

## How Mtx devices work with Plaspy

Plaspy ingests location and telemetry data from compatible Mtx devices so you can monitor assets from a single platform. Integration typically involves configuring the device to send data to the Plaspy server using the device settings shown on the model page. The BrandCatalog component on this page lists every Mtx model that works with Plaspy and links to device specific setup instructions and protocol details.

## Common features found in Mtx devices

Mtx models commonly provide the basic building blocks needed for fleet and asset tracking. While features vary by model, many devices may offer:
- GPS position reporting at configurable intervals
- Motion detection and status reporting
- Inputs for simple sensors and outputs for remote control
- Battery and power state monitoring
Refer to the individual model pages in the catalog for precise capabilities and supported telemetry for each device.

## Typical use cases for Mtx GPS trackers

Mtx devices are suitable for a range of tracking scenarios, including:
- Vehicle fleet location and route monitoring
- Short and long term asset tracking
- Basic telematics for status and movement alerts
- Remote asset security and recovery assistance

## Why choose Plaspy for Mtx device monitoring

Plaspy provides a centralized platform to collect, visualize, and act on data from Mtx devices. Key benefits you can expect include:
- Unified device management and model specific setup pages
- Map based live tracking and historical route playback
- Alerts and notifications based on location and status changes
- Integration points for reporting and exporting telematics data
If you need assistance choosing or configuring an Mtx device for Plaspy, consult the model pages in the catalog or reach out to Plaspy support for guidance.
