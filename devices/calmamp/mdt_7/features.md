# CalmAmp - MDT-7 Features

This page describes the public feature context for using the CalmAmp MDT-7 with Plaspy. It summarizes the MDT-7's user-facing capabilities and explains how those capabilities can be reflected within the Plaspy platform for operational visibility and workflow integration.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and the manufacturer's implementation choices. For precise, model-specific technical details consult the manufacturer documentation and the device release notes.

## Feature Overview

The MDT-7 is an open Android based mobile data terminal designed to host business applications and capture in-vehicle information for fleet and mobile workforce operations. Its combination of a touchscreen interface, onboard storage, camera capture, and wired and wireless connectivity makes it useful for tasks where driver interaction, data capture, and message exchange are important.

- Open Android OS environment enabling custom user applications and licensed third party software
- 7 inch touch display that provides a driver facing interface for apps, dispatch, and messaging
- Front and rear facing cameras plus on-board memory and micro SD support for storing captured media and application data
- Wired and wireless connectivity options that work with a connected CalAmp LMU to transport messages and captured information over cellular networks
- Optional integration with Magellan fleet navigation and driver productivity tools to assist routing and safety workflows
- Over the air serviceability to install or update business applications and reduce service visits

## Core Features of CalmAmp - MDT-7

- Open Android application platform for market specific workflows and licensed apps
- 7" touch display for interactive driver applications and messaging
- Dual camera support for front and rear capture of incidents, proof of delivery, or other events
- On-board memory with micro SD support for local storage of media and application data
- Wired and wireless connectivity options for integration with vehicle telematics and communications devices
- Centralized workflow applications that reduce paperwork and integrate driver dispatch and messaging
- Message and captured information transport via a connected CalAmp LMU across the cellular network
- Optional Magellan fleet navigation with truck attributes and driver productivity features

## How These Features Work with Plaspy

Plaspy receives and presents the operational data that MDT-7 applications and captures produce when the MDT-7 is deployed with a compatible CalAmp LMU. Plaspy is designed to detect compatible trackers and surface location, messaging, and captured information to fleet managers for oversight and reporting.

- Data and messages generated by MDT-7 applications can be transported to Plaspy through a connected CalAmp LMU and displayed in the platform
- Images and captured media stored on the device or micro SD can be sent as part of message payloads and referenced inside Plaspy as attachments or event records
- Plaspy provides visibility into driver dispatch and messaging events originating from MDT-7 workflow applications
- Devices are typically configured to report to the Plaspy server domain d.plaspy.com and Plaspy supports device connections over UDP or TCP on the platform port; Plaspy automatically detects the tracker protocol during onboarding
- Plaspy centralizes events and status so teams can correlate MDT-7 application activity with vehicle location and operational timelines

## Typical Use Cases

- Long haul and regional trucking where in-cab applications and navigation assist drivers and capture trip documentation
- Local delivery and logistics operations that require proof of delivery capture and messaging between drivers and dispatch
- Mobile workforce management where driver workflows, messaging, and captured information are consolidated for operations
- Fleet operations seeking to reduce paperwork by digitizing dispatch, forms, and communication
- Integrations where captured events and application data need to be transported into backend business systems via the telematics link

## Feature Availability Notes

- Feature availability depends on device firmware and the specific software bundle installed on each MDT-7 unit
- Hardware revisions and regional variants may change supported connectivity options or accessory compatibility
- A connected CalAmp LMU is referenced for cellular transport of messages and captured information; installation and integration details can affect data flow
- Optional Magellan navigation and some productivity tools may require separate licensing and configuration
- Over the air serviceability can reduce onsite updates but depends on carrier connectivity and device provisioning
