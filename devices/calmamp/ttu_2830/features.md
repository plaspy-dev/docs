# CalmAmp - TTU-2830 Features

This page provides a public feature overview of the CalmAmp TTU-2830 and how its capabilities map to monitoring and management inside Plaspy. It focuses on user facing features and practical value when the TTU-2830 is used as part of Plaspy's fleet and asset visibility platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Where relevant this page notes operational context, but you should confirm the current device feature set and firmware behavior with the manufacturer documentation for the TTU-2830.

## Feature Overview

The TTU-2830 is a weatherproof trailer tracker designed for long term deployments and intermittent power scenarios. It provides a compact package with internal antennas and an on board rechargeable battery so it can continue reporting while a trailer is disconnected from vehicle power.

- Small weatherproof enclosure suitable for trailer mounting and outdoor deployments
- Internal rechargeable battery pack including an on board 5.2 Ah battery for reporting when external power is absent
- Super sensitive GPS performance with internal GPS antenna for dependable location fix in challenging environments
- Three configurable inputs and three outputs for integration with external sensors and simple control logic
- Multi network cellular communications including GPRS CDMA 1xRTT and HSPA and support for text and packet messaging for reliable telemetry

## Core Features of CalmAmp - TTU-2830

- Weatherproof design suitable for exposed trailer and asset installations
- Internal rechargeable battery with capacity to support reporting during extended off power intervals
- Compact physical footprint and internal antennas to simplify installation and minimize external components
- Super sensitive GPS receiver for improved satellite acquisition and position accuracy
- Three inputs and three outputs to enable basic digital monitoring and control scenarios
- Support for multiple cellular link types and messaging methods to maintain connectivity across networks
- On board PEG programmable event engine for rule based local event detection and alerting
- PULS over the air device management for remote configuration updates and firmware maintenance

## How These Features Work with Plaspy

Plaspy receives and processes location and event reports from compatible devices such as the TTU-2830 and presents that data in the Plaspy interface for monitoring and reporting. Plaspy automatically detects compatible tracker protocols to simplify onboarding and makes device state and alerts visible to operators.

- Location reporting from the TTU-2830 is displayed in Plaspy maps and location histories for asset visibility
- PEG rule triggered events are reflected as alerts and events inside Plaspy so expectation based conditions are visible to users
- Battery and connectivity status reported by the device can be surfaced in Plaspy for operational health monitoring
- Inputs and outputs state changes reported by the device can be represented as events or custom indicators in Plaspy
- Over the air updates and configuration via the device management system support maintaining consistent behavior for fleets integrated with Plaspy

## Typical Use Cases

- Trailer and towed asset location monitoring where units may be disconnected from vehicle power
- Long term deployments that require weatherproof hardware and internal battery backup
- Event based monitoring using PEG rules for movement detection, geo zone presence, or input state changes
- Fleet health oversight combining device connectivity status and battery condition in Plaspy dashboards
- Simplified installations where internal antennas reduce the need for external cabling
