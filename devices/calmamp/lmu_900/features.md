# CalmAmp - LMU-900 Features

This page provides a public, feature-focused overview of the CalmAmp LMU-900 and how its capabilities can be used with Plaspy for vehicle location, monitoring, and operational visibility. It is intended to describe practical, non-sensitive functions and to explain how those functions typically map into a fleet management platform like Plaspy.

Exact feature availability and behavior can vary by unit firmware, hardware revision, installation choices, and the manufacturer's implementation. Always confirm the features and firmware behavior for a specific device or deployment with the manufacturer's documentation and your installer.

## Feature Overview

The LMU-900 is a compact automotive GPS tracker built for reliable location reporting, event monitoring, and flexible integration into vehicle systems. It is designed for standard 12 or 24 volt vehicle installations and supports cellular communications and remote management features common to fleet and recovery use cases.

- Accurate GPS location reporting for vehicle tracking and AVL applications
- 3-axis accelerometer for motion and tilt sensing to detect movement and activity
- Four configurable inputs and four outputs for integration with external devices
- Support for cellular networks and enhanced SMS or UDP messaging for data transport
- Ultra-low power sleep modes to reduce power draw when the vehicle is inactive

## Core Features of CalmAmp - LMU-900

- Compact form factor and enhanced GPS performance for dependable location data
- 3-axis accelerometer enabling motion and tilt sensing for event detection
- Four digital inputs to receive status or sensor signals from the vehicle
- Four outputs for driving external indicators or control interfaces
- Support for common cellular networks for broad coverage in vehicle environments
- Enhanced SMS or UDP messaging as transport options for sending data to servers
- PEG programmable event engine for customer-defined alert rules and exception reporting
- PULS over-the-air serviceability for remote configuration, firmware updates, and unit health monitoring

## How These Features Work with Plaspy

Plaspy is designed to ingest tracker data and present location and event information in a unified interface. The LMU-900's reporting and on-board event capabilities can be reflected inside Plaspy to support real-time monitoring and historical analysis.

- GPS position reports from the LMU-900 appear in Plaspy as location updates for vehicle tracking and route history
- Movement and tilt events generated by the 3-axis accelerometer can be surfaced as motion or activity events
- Digital input and output state changes are presented as discrete events or statuses for monitoring connected devices
- PEG-generated alerts and exception rules can be sent to Plaspy as events to trigger notifications or operator workflows
- Remote device health and configuration changes enabled by PULS can be coordinated with Plaspy for centralized device oversight

## Typical Use Cases

- Small fleet tracking for location awareness and route monitoring
- Stolen vehicle recovery where accurate GPS reporting and alerting are required
- Automotive insurance programs that need movement and event data
- Vehicle finance and repossession monitoring workflows
- Auto rental and shared vehicle programs requiring usage visibility
- General AVL deployments for monitoring vehicle assets and activity

- Hardware revisions and regional cellular variants can affect supported network bands and messaging methods
- Installation choices such as antenna type and mounting location can influence GPS reception and reporting reliability

Using the CalmAmp LMU-900 together with Plaspy gives organizations a practical route to consolidate device-reported locations, events, and health status into a single operational view.
