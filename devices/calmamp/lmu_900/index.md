# CalmAmp - LMU-900

![LMU-900](./logo.jpg)

The CalmAmp LMU-900 is a compact GPS tracker designed for reliable installation in automobiles. It is intended for a range of vehicle tracking and AVL applications including small fleets, automotive insurance programs, stolen vehicle recovery, vehicle finance, and auto rental operations. The device emphasizes accurate GPS performance, motion and tilt sensing via a 3-axis accelerometer, and flexible input and output options for integrating external devices.

As a device compatible with Plaspy, the LMU-900 can be used to feed location, movement, and event data into the Plaspy platform for monitoring and reporting. Plaspy can consume the unit's messages and use its event information to provide fleet visibility, alerts, and operational reports that help teams manage vehicles and respond to exceptions more efficiently.

## Key Highlights

- Compact form factor suited to automotive installations and discreet mounting
- High quality GPS performance for consistent location tracking
- Built in 3-axis accelerometer for motion and tilt detection
- Ultra low power sleep modes to minimize power draw when idle
- Four configurable inputs and four outputs for external device integration
- Supports cellular communication and messaging methods for server reporting
- Onboard programmable event engine for custom alerts and rules

## How It Works with Plaspy

The LMU-900 transmits location and event messages that Plaspy uses to provide real time visibility and historical reporting. Plaspy maps incoming data, evaluates configured rules, and delivers alerts and reports to operational users.

- Display vehicle location and movement history on Plaspy maps for live monitoring
- Trigger alerts in Plaspy based on device events such as motion, tilt, or I O changes
- Use Plaspy reporting to analyze trip history, idle time, and event occurrences
- Monitor device health and message activity within Plaspy to spot connectivity issues
- Combine LMU-900 input and output events with Plaspy rules for exception based workflows

## Typical Use Cases

- Small and midsize fleet location tracking and operational oversight
- Stolen vehicle recovery and location assistance workflows
- Auto rental and vehicle hire monitoring for asset control
- Automotive finance vehicle tracking and recovery support
- Insurance telematics scenarios for usage and incident detection

## Why Choose This Tracker with Plaspy

The CalmAmp LMU-900 pairs a compact hardware footprint and motion sensing with flexible I O options, making it a practical choice for organizations that need reliable vehicle location and event reporting. When used with Plaspy, the LMU-900 becomes part of a managed tracking solution where incoming location and event data are translated into maps, alerts, and actionable reports for operations teams.

Because the LMU-900 supports programmable event generation and cellular messaging, it can fit into many monitoring and recovery workflows while Plaspy provides the software layer for visibility, alerting, and historical analysis. If you need a device that balances concise hardware capability with platform level oversight, the LMU-900 is a sensible option to evaluate alongside Plaspy.
