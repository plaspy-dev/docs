# CalmAmp - LMU-700 Features

This page provides a public oriented feature summary for the CalmAmp LMU-700 and explains how its capabilities are used with Plaspy. It focuses on the device features that are relevant to fleet and vehicle tracking workflows and how those features appear in a Plaspy deployment.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional cellular configuration, and manufacturer implementation. For the latest technical specifications and model specific details refer to the official CalmAmp documentation and firmware release notes.

## Feature Overview

The LMU-700 is presented as a compact vehicle tracker built for automotive applications where straightforward installation, reliable GNSS performance, and flexible communications are important. Below are the most relevant practical capabilities for operators considering this model with Plaspy.

- Compact form factor suitable for discreet installation in 12 volt and 24 volt vehicles
- Super sensitive GPS performance for improved location acquisition in challenging conditions
- Internal cellular and GPS antennas to reduce installation complexity and costs
- Communication over cellular networks using enhanced SMS and UDP messaging for reporting
- Three inputs and three outputs providing basic monitoring and control interfaces
- On board programmable event engine PEG and over the air management via PULS for configuration and updates

## Core Features of CalmAmp - LMU-700

- Compact design for easy concealment and installation in passenger and commercial vehicles
- Rated for operation on common 12 volt and 24 volt vehicle electrical systems
- Super sensitive GPS receiver to improve fix reliability in marginal signal areas
- Internal antennas for cellular and GPS to simplify wiring and installation
- Support for enhanced SMS and UDP based messaging over cellular networks
- Three digital inputs and three digital outputs for monitoring external signals and basic control
- PEG programmable event generator for rule based event detection on time motion location and inputs
- PULS over the air serviceability for remote parameter updates and firmware maintenance

## How These Features Work with Plaspy

Plaspy receives device reports and events from compatible trackers and presents location, status, and alerts in a unified interface. The LMU-700 capabilities translate into visibility and operational controls inside Plaspy without exposing low level protocol details on this page.

- Location reports from the LMU-700 appear on the Plaspy map for real time tracking and history
- PEG generated events can be mapped to Plaspy alerts or notifications so threshold conditions are visible to operators
- Input and output states reported by the device are available in Plaspy device details for monitoring and simple remote workflows
- Device health and message logs from SMS or UDP deliveries are visible in Plaspy to help troubleshoot connectivity and reporting
- Over the air management activity reported by PULS can be tracked as device configuration or firmware state inside Plaspy

## Typical Use Cases

- Stolen vehicle recovery and post recovery tracking workflows
- Vehicle finance and repossession monitoring where discreet installation and reliable location matter
- Auto rental fleet monitoring and asset visibility for operations staff
- General fleet tracking for cars and light commercial vehicles that need compact hardware
- Event driven monitoring using PEG rules for location or input changes
- Remote maintenance and configuration using PULS to reduce field visits
