# CalmAmp - LMU-200 Features

This page provides a public feature overview for the CalmAmp LMU-200 and how its capabilities are used with Plaspy for vehicle visibility, monitoring, and operational reporting. It summarizes the LMU-200's practical functions as they relate to Plaspy without reproducing private configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and installation method. For device-specific technical details, firmware notes, or the latest capabilities consult the manufacturer's documentation and release notes.

## Feature Overview

The LMU-200 is a compact vehicle tracker built for discreet installation and continuous location visibility. It balances cost effectiveness with practical features that support tracking, event monitoring, and remote management for fleets and individual vehicles.

- Accurate GPS positioning designed for vehicle tracking and recovery scenarios
- Optional internal 200 mAh backup battery to provide limited tracking after power loss
- Ultra-low power sleep modes to minimize power draw when the vehicle is stationary
- Onboard motion sensing via a 3-axis accelerometer for movement detection
- Up to four external Inputs/Outputs for flexible connections to vehicle signals or accessories
- Internal cellular and GPS antennas for simplified installation without external antennas

## Core Features of CalmAmp - LMU-200

- GPS location reporting for continuous vehicle position awareness
- Optional internal backup battery to preserve tracking during power interruptions
- Low power sleep modes to extend operational life while idle
- 3-axis accelerometer enabling motion detection and movement-based events
- Up to four configurable I/O channels for external sensor or signal integration
- Cellular communication using CDMA networks for telemetry and event reporting
- Support for enhanced SMS and UDP messaging for command and data exchange
- On-board programmable event engine (PEG) for defining exception-based alerts

## How These Features Work with Plaspy

Plaspy receives and interprets location and event data from compatible trackers like the LMU-200 so fleets and operators can monitor vehicles in a single interface. Plaspy automatically detects device protocol and supports common transport methods so configuration is streamlined.

- Location updates and motion events from the LMU-200 appear in Plaspy as position points and event records
- PEG-generated alerts map to exception events in Plaspy for rule-based visibility
- I/O state changes reported by the device are shown as inputs or custom events in Plaspy
- The LMU-200 can be configured to send data to Plaspy servers; Plaspy auto-detects supported tracker protocols
- Over-the-air management features from the device manufacturer can be coordinated with Plaspy workflows for device health and fleet maintenance visibility

## Typical Use Cases

- Stolen vehicle recovery and post-incident vehicle location tracking
- Vehicle finance and asset monitoring for repossession prevention or recovery
- Auto rental fleet monitoring for utilization and location oversight
- Basic fleet tracking for small to medium commercial vehicle operations
- Exception-based monitoring where alerts are needed for movement, input changes, or location conditions
- Remote health and firmware monitoring when combined with manufacturer OTA services
