# CalmAmp - LMU-1100 Features

This page describes the public feature context for using the CalmAmp LMU-1100 tracker with Plaspy. It focuses on the device capabilities that matter to Plaspy users and explains how the LMU-1100 can be used for monitoring vehicles and outdoor assets inside the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where useful, this page highlights practical functions that the LMU-1100 provides, but customers should confirm device specifics against CalAmp documentation and the installed unit configuration.

## Feature Overview

The LMU-1100 is a compact GPS tracker designed for easy installation on recreational vehicles and outdoor assets. It combines accurate location reporting with on-board event logic and remote management to support monitoring and recovery workflows.

- Compact form factor suited for motorcycles, snowmobiles, and similar outdoor vehicles
- Accurate GPS location reporting for continuous position visibility
- 1000 mAh backup battery to maintain tracking when vehicle power is removed
- Two digital inputs and one output for basic external event monitoring and control
- Programmable Event Generator PEG for custom on-board event rules based on time, location, motion, geo zones, and input events
- Over the air management via CalAmp PULS for remote configuration and firmware updates

## Core Features of CalmAmp - LMU-1100

- Compact design for discreet installation on outdoor vehicles and assets
- Reliable GPS performance for position accuracy and tracking continuity
- 1000 mAh internal backup battery to enable limited operation off main power
- Two inputs and one output for monitoring external sensors or signaling events
- PEG programmable event engine for creating device side rules and alerts
- Remote configuration and firmware management through CalAmp PULS
- Designed for asset recovery and monitoring workflows common to recreational vehicles

## How These Features Work with Plaspy

When integrated with Plaspy, LMU-1100 reports and on-board events translate into actionable information for fleet managers and asset owners. Plaspy receives device messages and surfaces location and event data through maps, timelines, and alerts.

- Real time and historical location updates appear on the Plaspy map for tracking and playback
- PEG generated events can be reported into Plaspy as custom events or alerts for immediate visibility
- Input and output activity from the device can be recorded as events in Plaspy to reflect external sensor status
- Battery backup behavior and power state changes can be tracked in Plaspy as device status indicators
- Remote device provisioning and firmware updates authored via PULS support maintaining consistent configurations across devices when used alongside Plaspy
- Plaspy detects compatible trackers and presents device activity without requiring users to manage low level protocol details

## Typical Use Cases

- Theft recovery and location tracking for motorcycles, snowmobiles, and similar outdoor vehicles
- Monitoring location and movement of seasonal or stored assets
- Rental fleet tracking for small recreational vehicles to verify location and usage
- Remote asset oversight for equipment left outdoors or off site
- Event driven alerts for input state changes such as accessory or tamper detection

## Feature Availability Notes

- PEG capabilities and available rule types depend on the device firmware version and PEG configuration
- PULS based remote management requires the CalAmp service and appropriate device provisioning to be enabled
- Input and output behavior may vary with installation wiring and the specific accessories connected
- Hardware revisions or regional variants of the LMU-1100 can alter supported features and certifications
- Always verify the feature set for a given unit against the device configuration and firmware running on that unit
