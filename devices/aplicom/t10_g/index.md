# Aplicom - T10 G

![T10 G](./logo.png)

The Aplicom T10 G is a robust, Plaspy compatible GPS tracker-class CAN-tracker purpose-built for modern fleet management and vehicle telemetry. Manufactured by Aplicom, the T10 G combines a rugged IP67 enclosure, plug-and-play installation and built-in CAN bus access to deliver reliable vehicle data for real-time tracking, diagnostics and fleet telematics workflows integrated with Plaspy.

Designed for roaming fleets and harsh environments, the T10 G uses future-proof cellular connectivity \(LTE Cat M1 with global 4G roaming and 2G fallback\) together with Aplicom Silver Cloud device management for remote provisioning and data delivery. Use it with Plaspy to add vehicle-level telemetry, CAN-derived signals and continuous location reporting to your fleet operations, anti-theft workflows and telemetry dashboards.

## Key Highlights

- Plaspy compatible: integrates vehicle telemetry and location reporting into Plaspy dashboards and workflows for real-time tracking.
- Rugged, IP67-rated enclosure for reliable operation in demanding fleet and industrial environments.
- Built-in CAN interface collects vehicle-bus data such as ignition status, engine diagnostics and fuel-related telemetry when available on the bus.
- Future-proof cellular: LTE Cat M1 support with global 4G roaming plus 2G fallback to maintain connectivity across regions.
- Plug-and-play installation minimizes downtime and accelerates deployment across a mixed fleet.
- Remote device management via Aplicom Silver Cloud enables provisioning, configuration and firmware workflows at scale.
- Starter kit and 2G variant available for testing and deployments in legacy-network areas.

## How It Works with Plaspy

The Aplicom T10 G streams vehicle telemetry and CAN bus data to Aplicom’s device management layer and can be connected to Plaspy for real-time tracking, alerts and reporting. Plaspy can consume the telemetry payloads provided by the T10 G \(location and CAN-derived signals\) to deliver fleet management insights, anti-theft alerts and operational reports.

- Real-time location and telemetry updates \(location reporting available where GNSS is enabled on the device/variant\).
- Vehicle CAN bus data such as ignition status, diagnostic trouble codes and fuel-level telemetry when these signals are present on the vehicle bus.
- Remote provisioning and configuration through Aplicom Silver Cloud lets you start streaming mission-critical telematics to Plaspy quickly.
- Network resilience via LTE Cat M1 and 2G fallback keeps telemetry flowing in variable coverage areas, important for roaming fleets.
- Starter kit support for pilot deployments and testing before wide rollout into Plaspy-managed fleets.

## Use Cases

- Fleet management: centralized vehicle tracking, route monitoring and telemetry input into Plaspy for operational visibility.
