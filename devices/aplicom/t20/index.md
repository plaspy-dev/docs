# Aplicom - T20

![T20](./tracker.png)

The Aplicom T20 is a compact, Plaspy compatible GPS tracker and telematics gateway built for reliable vehicle and mobile equipment tracking. With LTE‑M cellular connectivity optimized for IoT and telematics, the T20 is positioned as a future‑proof solution for integrators and fleet operators who require continuous real‑time tracking, robust telemetry capture and secure over‑the‑air management.

The T20’s industrial interfaces and dual CAN bus ports let you collect vehicle and machine diagnostics directly from CAN networks and attach peripherals such as iButton readers, keypads, RFID readers and temperature sensors. Combined with Aplicom’s SDK and Silver Cloud OTA tools, the T20 enables edge processing, reduced cellular bandwidth usage and streamlined device management for fleet management, anti‑theft workflows and broader telemetry use cases.

## Key Highlights

- Plaspy compatible GPS tracker workflow: integrates vehicle location and telemetry into Plaspy for real‑time tracking and fleet management dashboards.
- LTE‑M cellular connectivity for low‑power, IoT‑optimized communications and long‑term network support.
- Dual CAN bus interfaces capture vehicle and machine diagnostics for advanced telemetry and fuel monitoring support via CAN data.
- Multiple industrial I/O for peripherals: supports iButton readers, keypads, RFID readers and temperature sensors to expand anti‑theft and cargo monitoring capabilities.
- Aplicom SDK enables custom edge applications to filter and preprocess data on‑device, reducing cloud costs and cellular data usage.
- Over‑the‑air \(OTA\) management through Aplicom Silver Cloud for remote configuration, firmware updates and deployment of custom applications at scale.
- Compact form factor for easy installation in vehicles, trailers, construction machines and other mobile assets.

## How It Works with Plaspy

The Aplicom T20 connects to Plaspy by forwarding processed telemetry and location data over LTE‑M. Integrators can use the onboard SDK to run edge logic that aggregates or filters raw CAN and sensor inputs before sending events to Plaspy, enabling efficient real‑time tracking and actionable alerts. Plaspy then consumes location, telemetry and event streams for mapping, reporting and automated workflows.

- Real‑time location and telemetry updates to Plaspy for live fleet monitoring and route analysis.
- Direct CAN bus telemetry and diagnostic data for engine status, vehicle health and fuel monitoring when such signals are available on the vehicle CAN network.
- Peripheral sensor inputs \(iButton, RFID, keypad, temperature sensors\) sent as events to Plaspy for access control, cargo monitoring and temperature‑sensitive logistics.
- Remote configuration and firmware updates via Aplicom Silver Cloud, coordinated with Plaspy device management tasks.
- Edge processing to reduce data volume, allowing Plaspy to receive only the most relevant location and telemetry events for reporting and alerts.
- Integrator‑driven ignition or immobilizer control and anti‑theft workflows can be implemented through vehicle CAN or external I/O when configured by the installer and supported by the vehicle systems.
- Support for adding Bluetooth sensors or other external radios via peripherals or gateway attachments can be integrated into Plaspy workflows when such sensors are connected and handled by custom edge code.
