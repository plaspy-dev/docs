# GenX Mobile - GNX-6 Features

This page provides a public overview of the GenX Mobile GNX-6 feature set and how those features integrate with Plaspy for fleet and mobile resource visibility. It focuses on practical, user-facing capabilities and how the device can be used within Plaspy for monitoring and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For critical technical details or deployment guidance consult the official GenX Mobile documentation and release notes.

## Feature Overview

The GNX-6 is positioned as a versatile GPS tracker designed for vehicle tracking and general mobile resource management. It combines configurable reporting, robust reception hardware, and event detection to support reliable location awareness and operational monitoring.

- Accurate location tracking suitable for vehicles and mobile assets
- Highly configurable reporting options to match different tracking needs
- Built in high performance cellular and GPS antennas for stronger signal reception
- Auto calibrating 3 axis accelerometer for event detection such as rapid acceleration or harsh cornering
- Robust construction and quality components intended for reliable field use

## Core Features of GenX Mobile - GNX-6

- GPS based location tracking for continuous position updates
- Highly configurable settings to adapt reporting behavior and thresholds
- Integrated high performance cellular antenna for improved connectivity
- Integrated high performance GPS antenna for reliable satellite reception
- Auto calibrating 3 axis accelerometer with event reporting for driver behavior insights
- Designed for mobile resource management and vehicle tracking deployments
- Built with quality components for durable, consistent operation
- Compatibility with Plaspy for centralized monitoring and management

## How These Features Work with Plaspy

Plaspy can collect and present the GNX-6's location and event data to provide operational visibility and actionable insights. The platform is designed to recognize supported tracker protocols and present data in a way that supports monitoring and decision making.

- Location updates from the GNX-6 appear on Plaspy maps for real time position awareness
- Accelerometer detected events such as rapid acceleration or harsh cornering are indicated as events in Plaspy for review and reporting
- Configurable reporting behavior on the device maps to Plaspy reporting and history views for tailored tracking frequency
- Reliable antenna reception improves continuity of data in Plaspy, reducing gaps in position history
- Plaspy automatically detects supported tracker protocols and integrates incoming device data for immediate use

## Typical Use Cases

- Fleet vehicle location monitoring for daily operations and dispatch
- Mobile resource management for assets that move between job sites
- Driver behavior monitoring and event review for safety programs
- Route visibility and post trip review using position history and event markers
- Operational oversight where reliable reception and configurable reporting are required

## Feature Availability Notes

- Feature sets can vary by firmware version and manufacturer firmware updates may change behavior
- Hardware revisions or regional product variants can affect cellular or GPS performance
- Installation quality and antenna placement can influence reception and accuracy
- Accelerometer sensitivity and reporting thresholds may be configurable and differ by firmware
- Always confirm the capabilities on deployed units against the manufacturer documentation

## Why Use Plaspy with These Features

Using the GNX-6 with Plaspy provides a straightforward way to centralize location data and event visibility for fleets and mobile assets. Plaspy presents position history, event markers, and configurable reporting in a unified interface to help operations teams maintain situational awareness and review incidents efficiently.
