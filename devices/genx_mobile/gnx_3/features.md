# GenX Mobile - GNX-3 Features

This page provides a public overview of the GenX Mobile GNX-3 features in the context of using the device with Plaspy. It summarizes the GNX-3's practical capabilities, explains how those capabilities map into Plaspy for monitoring and operational use, and highlights considerations that affect feature availability.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For complete device-level details and the most current specifications consult the manufacturer documentation and release notes.

## Feature Overview

The GNX-3 is presented as a flexible GPS tracker designed for vehicle tracking and mobile resource management. Its configuration options and sensing capabilities make it suitable for operations that require reliable location updates and event-based insight into movement and driving behavior.

- Real-time and accurate location tracking for moving assets and vehicles
- Highly configurable settings to adapt reporting and event behavior to operational needs
- Integrated high-performance internal cellular and GPS antennas for reliable signal reception
- Auto-calibrating 3-axis accelerometer to detect and report rapid acceleration, deceleration, and other dynamic events
- Engineered for mobile resource management and vehicle tracking deployments

## Core Features of GenX Mobile - GNX-3

- Real-time GPS location reporting designed for continuous tracking
- Highly configurable device settings to tailor reporting intervals and event triggers
- Internal high-performance cellular and GPS antennas for consistent connectivity
- Auto-calibrating 3-axis accelerometer for monitoring sudden motion and driving events
- Targeted use cases for mobile resource management and vehicle tracking
- Built with reliability and quality components for persistent field use

## How These Features Work with Plaspy

Plaspy can receive GNX-3 reports and surface location and event data for monitoring and operational workflows. Plaspy automatically detects the tracker protocol and accepts standard device reports, allowing the GNX-3 to be used in dashboards, live maps, and reporting workflows. Devices can be configured to report to the Plaspy server endpoint such as d.plaspy.com and use standard transport options supported by the platform.

- Location updates are visualized on Plaspy maps for live tracking and historical playback
- Accelerometer-driven events (for example sudden acceleration or harsh braking) are represented as event markers for driver behavior review
- Device configuration options on the GNX-3 can be aligned with Plaspy reporting needs to manage update frequency and event thresholds
- Plaspy presents device status and connectivity so operators can see when a GNX-3 is online and reporting
- Alerts and reports in Plaspy can be based on GNX-3 events to support operational workflows and oversight

## Typical Use Cases

- Fleet vehicle tracking and route monitoring for delivery or service fleets
- Mobile resource management for crews and equipment in the field
- Driver behavior insight through accelerometer event reporting and analysis
- Operational visibility for dispatch centers monitoring active assets
- Historical route playback and activity reporting for compliance or performance review

Using the GNX-3 with Plaspy gives organizations a practical way to convert raw device reports into operational awareness. Plaspy focuses on making location, event, and connectivity information accessible in dashboards, maps, and reports so teams can monitor assets, review driving events, and act on real-time information.
