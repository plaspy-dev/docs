# Castel - IDD-212B Features

This page provides a public, non-sensitive overview of the Castel IDD-212B feature set and how those features are relevant when the device is used with Plaspy. It explains the device capabilities described in manufacturer materials and shows the practical value those capabilities can deliver inside Plaspy for vehicle data visibility and operational monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. This page focuses on public feature context and practical uses; for device specific technical details consult the official Castel documentation and firmware notes.

## Feature Overview

The Castel IDD-212B is an OBD car scanner that uses Bluetooth connectivity and is designed to read engine and vehicle parameters from the ECU. Its built in data storage and motion detection make it useful for logging and later review, while mobile compatibility enables live access to diagnostic and performance data.

- Reads vehicle running parameters such as speed, RPM, temperature, and diagnostic trouble codes
- Reports fuel consumption and mileage information for performance and usage insight
- Stores up to two months of recorded data in built in flash memory for offline logging
- Includes a G sensor to detect and record sudden movements or impacts
- Connects via Bluetooth to compatible mobile devices and is MFi certified for iPhone compatibility

## Core Features of Castel - IDD-212B

- Bluetooth 4.0 connectivity for pairing with supported mobile devices
- MFi certification for compatibility with iPhone ecosystems
- OBD access to ECU data including speed, RPM, temperature readings, and DTCs
- Fuel consumption and mileage reporting for operational visibility
- Built in flash memory capable of storing approximately two months of device data
- G sensor for detecting and recording sudden movement events or impacts
- Wide operating voltage range and designed for low power consumption for vehicle use

## How These Features Work with Plaspy

When used with Plaspy, the IDD-212B's vehicle data and events can be presented alongside other fleet telemetry to support monitoring and analysis. Plaspy receives and displays the data the device reports and helps organize it into operational views and historic records.

- Diagnostic readings and error codes reported by the device can appear as device events in Plaspy for review
- Fuel consumption and mileage metrics can be used in Plaspy reports to help track vehicle usage and performance trends
- G sensor events reported by the device can be surfaced in Plaspy as movement or impact events for operator awareness
- Stored data retained on the device can be synchronized to Plaspy when the device uploads records, enabling retrospective review
- Bluetooth paired use enables real time access via a connected mobile app and Plaspy can present received live readings alongside recorded history

## Typical Use Cases

- Fleet monitoring where engine parameters and mileage are needed for maintenance planning
- Remote diagnostics and fault tracking by collecting DTCs and engine data for technician review
- Fuel usage analysis to help identify inefficiencies or abnormal consumption patterns
- Incident logging by capturing G sensor events and correlated vehicle parameters
- Data collection where continuous mobile connectivity is intermittent and local storage is required
- Vehicle performance monitoring during service or test drives using live device data
