# Castel - MPIP-618-WA Features

This page provides a public feature overview for the Castel MPIP-618-WA and explains how its capabilities relate to the Plaspy platform. It focuses on user facing functions and practical behavior that are relevant when the device is used with Plaspy for vehicle location, diagnostics, and fleet oversight.

Exact feature availability and behavior can vary with firmware version, hardware revision, installation method, and manufacturer implementation. The descriptions below are grounded in the device specification and public manufacturer details, and users should confirm specifics with official documentation when planning deployments.

## Feature Overview

The MPIP-618-WA is a vehicle terminal that combines GPS tracking with OBD style diagnostics and a suite of alarms and reporting features designed for passenger cars and business vehicles. In Plaspy it is typically used to provide continuous location data, event alerts, and vehicle usage statistics that support fleet operations and maintenance planning.

- Built for quick installation using a standard OBD style interface for many passenger and commercial vehicles.
- High sensitivity GPS and quad band GSM with GPRS for consistent positioning and data transfer in supported regions.
- Multiple intelligent alarms including SOS button support, ignition status alerts, fatigue driving alerts, and speeding alerts.
- Vehicle analytics features such as mileage statistics, maintenance reminders, and fuel consumption reporting where the device and vehicle provide that data.
- Flexible configuration options including remote COTA updates, SMS command setup, and PC software configuration.

## Core Features of Castel - MPIP-618-WA

- OBD compatible interface for rapid installation and access to vehicle diagnostic related signals.
- High sensitivity GPS reception using a SIRF III grade chipset for reliable positioning.
- Quad band GSM and GPRS data connectivity to report location and events to a tracking platform.
- Intelligent alarm set including SOS button and LED indicator plus ignition status, fatigue driving, and speeding alerts.
- Trip and mileage statistics plus maintenance reminder capability for operational scheduling.
- Fuel consumption statistics and onboard data memory for buffering reports when connectivity is intermittent.
- Multiple input ports for vehicle signals and accessory compatibility to support a range of transport use cases.
- Configurable by COTA, SMS commands, or PC software to adapt settings and alert thresholds.

## How These Features Work with Plaspy

When connected to Plaspy, the MPIP-618-WA can provide continuous location visibility and event reporting to help teams monitor and manage vehicles in real time. Plaspy detects supported tracker protocols and presents incoming data as location points, alerts, and reports for operational use.

- Real time and historical location tracking displayed on the Plaspy map for operational oversight.
- Vehicle alarms such as SOS and speeding appear as events in Plaspy so operators can triage incidents.
- Mileage and usage statistics reported by the device are available in Plaspy reports for maintenance planning and performance review.
- Fuel consumption and trip summaries can be reviewed in Plaspy where the device supplies those metrics.
- Data buffering on the device helps reduce gaps in the Plaspy timeline when temporary connectivity interruptions occur.
