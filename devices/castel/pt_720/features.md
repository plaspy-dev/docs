# Castel - PT-720 Features

This page provides a public feature overview for the Castel PT-720 kids GPS tracker watch and explains how its capabilities map to Plaspy for monitoring, event visibility, and day to day location oversight. It focuses on the practical, user-facing features of the device and how those features are typically used when the device reports into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and how the manufacturer configures the device. Where possible this page cites device features from the PT-720 description; for the latest device specific details consult the manufacturer documentation.

## Feature Overview

The Castel PT-720 is a compact wearable designed for child safety and basic activity awareness. Its core value is continuous location visibility combined with simple communication and emergency alert functions that parents and caregivers can use through the device vendor app or through a fleet/monitoring platform such as Plaspy.

- Real time location using combined GPS LBS and WiFi positioning for more complete coverage.
- Two way voice calling that allows parents to call the device and children to answer via an answer key.
- SOS emergency alert that calls a preset administrator and sends alert messages to up to six emergency contacts.
- Geo fence support through the companion app to notify contacts when the device leaves a designated area.
- Historical route reporting for reviewing up to one month of past movements.
- Pedometer and step counting driven by an integrated three axis G sensor.

## Core Features of Castel - PT-720

- Kids wearable watch form factor with compact dimensions of 45.5 x 40.5 x 15.5 mm, lightweight design around 41 g, and a 1.3 inch OLED or TFT screen for basic status and interaction.
- Dual way voice communication enabling direct parent to child calls and a simple answer key on the device for children to pick up.
- Multi mode positioning that combines GPS with LBS and WiFi based positioning to improve location availability in different environments.
- SOS emergency function configurable with up to six emergency contacts; SOS activation triggers preset call behavior to the administrator and sends alert messages to emergency contacts.
- Geo fence capability via the accompanying app to define safe zones and receive alerts when the device exits those areas.
- Historical route logging with the ability to view past trips for up to one month through the companion interface.
- Step counting implemented with a three axis G sensor to provide pedometer data and basic activity awareness.
- Power and connectivity details including a 400 mAh battery (3.7 V), standby time reported up to approximately 103 hours, support for a nano SIM card, and an operating temperature range from minus 10 to 55 degrees Celsius.

## How These Features Work with Plaspy

Plaspy provides centralized visibility and event handling for compatible trackers including the PT-720. When a tracker reports position and events to Plaspy, those data points become available for live monitoring, event notifications, and historical review inside the Plaspy platform.

- Real time and periodic location reports from the device are shown on the Plaspy map for live tracking and situational awareness.
- SOS activations and geo fence alerts are displayed as events in Plaspy so managers and caregivers can see alarms and their timestamps.
- Route history reported by the device can be accessed and replayed in Plaspy to review movements over the available period.
- Pedometer and simple activity markers reported by the device can be recorded as part of the device telemetry when the device provides that data.
- Plaspy automatically detects many common tracker protocols and accepts device reports to its ingestion endpoint; Plaspy supports typical transport modes used by trackers so devices like the PT-720 can send data into d.plaspy.com for visibility.
- Event logs and alerts from the PT-720 can be combined with Plaspy rules and notification channels to fit operational workflows.

## Typical Use Cases

- Parental monitoring of a child’s location during school runs, playground visits, and short trips.
- Rapid response to emergencies using the SOS alert that notifies multiple contacts.
- Boundary management where caregivers set geo fences for neighborhoods, school grounds, or home areas.
- Reviewing a child’s movement history for the previous month to understand daily patterns and routes.
- Basic activity awareness for parents who want step count summaries and simple activity indicators.
- Temporary monitoring for babysitters, relatives, or caregivers during outings.

## Feature Availability Notes

- Behavior and available features can differ with firmware updates and hardware revisions; features described here reflect the device description but may change over time.
- Some capabilities require the manufacturer companion app or specific configuration on the device to enable geo fence, SOS contacts, and route history.
- Network compatibility and SIM provisioning (the device uses a nano SIM) can affect location reporting and call behavior depending on the region and mobile operator.
- Sensor derived measurements such as step counting rely on the device firmware and the three axis G sensor; accuracy and reporting cadence depend on implementation.
- When integrating with Plaspy ensure device reporting settings and manufacturer server parameters are configured so the device sends events and position reports to Plaspy correctly.
