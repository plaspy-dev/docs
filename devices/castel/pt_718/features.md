# Castel - PT-718 Features

This page describes the public feature context for using the Castel PT-718 tracker with Plaspy. It summarizes the PT-718 capabilities that are relevant to Plaspy users, explains how common functions map into a fleet and asset monitoring platform, and highlights the practical value of the device without going into private configuration details.

Exact feature availability for any PT-718 device can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Confirmation of device-specific behavior, alert thresholds, and app integration should be performed against the manufacturer documentation and the device firmware provided with your unit.

## Feature Overview

The Castel PT-718 is a compact, portable personal tracker designed for people, vehicles, and pets. It combines GPS and assisted GPS positioning with cellular connectivity to provide location updates, emergency alerts, and configurable notifications. Below are the most relevant user facing capabilities that matter when using the device with a monitoring platform like Plaspy.

- Real time tracking via GPRS with SMS as an alternate reporting method for locations and queries
- SOS alert function to notify caregivers or monitoring systems of emergency events
- Dual position modes with GPS and A GPS to improve fix reliability and speed of initial position
- Geo fence alerts to notify when the device enters or exits predefined areas
- Built in high capacity battery and low power consumption to support extended standby time
- Compatibility with Android and iOS through the manufacturer app for direct mobile access

## Core Features of Castel - PT-718

- SOS alert function for sending distress notifications
- Real time monitoring and timing positioning for periodic location updates
- GPS and A GPS dual position modes for improved positioning reliability
- Geo fence alert to trigger boundary notifications
- Track by SMS or GPRS to support flexible reporting workflows
- Built in high capacity rechargeable battery for longer standby intervals
- Low voltage alert to warn of impending power depletion
- Compact and lightweight housing built from ABS plus PC material

## How These Features Work with Plaspy

Plaspy can receive and present key PT-718 events and location data so operators gain visibility and control. The platform is designed to detect tracker protocols automatically and translate incoming reports into map positions and alert events for monitoring and reporting.

- Real time location reports from the PT-718 appear on Plaspy maps for live tracking and historical playback
- SOS alerts reported by the device are surfaced as high priority events in Plaspy so operators can respond quickly
- Geo fence triggers from the tracker generate notifications and event records inside Plaspy for boundary monitoring
- Device status indicators such as low voltage alerts can be shown in the Plaspy device dashboard to support operational maintenance
- When GPRS is available, Plaspy receives automated position updates; SMS based queries can be used as a fallback reporting method where supported

## Typical Use Cases

- Personal safety monitoring for lone workers, children, or caregivers who need emergency alerting
- Pet tracking for location recovery and boundary alerts
- Vehicle or light asset tracking where a compact portable tracker is preferred
- Temporary or ad hoc deployments that need a rechargeable, portable device
- Remote monitoring where combined GPS and assisted GPS position modes improve fix performance

## Feature Availability Notes

- Manufacturer firmware and regional variants can change how features behave or which settings are available
- Some functions such as timing intervals, geofence behavior, and SOS handling may be configurable only through manufacturer tools or firmware updates
- Network reporting behavior depends on local GSM network coverage and whether the device is operating over GPRS or using SMS as a fallback
- Battery life and standby numbers vary with configuration, reporting frequency, and signal conditions
- App features on Android and iOS are provided by the manufacturer and may differ from how events are shown in Plaspy
