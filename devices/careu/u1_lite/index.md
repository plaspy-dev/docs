# CAREU - U1 Lite+

![U1 Lite+](./logo..png)

The CAREU U1 Lite+ is a compact and cost effective GPS tracker designed for vehicle and asset monitoring. It provides cellular data connectivity across 4G with fallbacks to 3G and 2G, built in WiFi and internet access for auxiliary data use such as video transmission, and extensive I O expansion through RS 232 ports and additional inputs and outputs. The device includes position logging, motion detection, support for 1 Wire peripherals, and jamming detection, making it suitable for a broad set of tracking and security scenarios.

As a Plaspy compatible device, the U1 Lite+ can deliver positional updates, event alerts, and peripheral data into the Plaspy platform for visualization and operational oversight. Plaspy can display live location, historical routes, and alerts generated by the device while providing fleet level reporting and monitoring. This compatibility makes the U1 Lite+ a practical option for organizations that want to combine CAREU hardware capabilities with Plaspy fleet management tools.

## Key Highlights

- Multi generation cellular connectivity with WiFi support for internet enabled features and video transmission
- Integration options for RS 232 accessories and additional digital and analog I O for sensor and peripheral data
- 1 Wire support for temperature control and basic driver identification workflows
- Jamming detection for cellular networks to help identify interference during transport
- Large onboard position logging capacity for extended offline recording
- Remote configuration and firmware update capability through network methods

## How It Works with Plaspy

When used with Plaspy, the U1 Lite+ streams location and event information to the platform where fleet managers can monitor assets, configure alerts, and analyze historical activity. Plaspy brings this device data into dashboards and reporting tools so teams can keep operations under continuous supervision.

- Live location tracking and route playback on Plaspy maps for fleet visibility
- Alerting for geofence events, motion and tampering notifications, and jamming detection
- Aggregated reporting on distance, time on site, and user defined events for operational review
- Inclusion of accessory and peripheral inputs in telematics records to correlate sensor data with location
- Support for handling video enabled workflows when cameras use the tracker for connectivity
- Centralized remote configuration and device status monitoring from within Plaspy

## Typical Use Cases

- Vehicle fleet tracking for deliveries and service operations requiring route oversight
- Secure transport monitoring where jamming detection provides additional situational awareness
- Video augmented monitoring for high value or safety critical transports using compatible cameras
- Integration of driver identification and temperature or auxiliary sensors for compliance or cold chain monitoring
- Mixed asset tracking where extended logging is required during intermittent connectivity

The CAREU U1 Lite+ combines a versatile hardware feature set with options for accessory integration and video capable connectivity. That versatility aligns well with Plaspy which is designed to bring location, alerts, and peripheral data together into a single operational view.
