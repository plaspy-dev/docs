# CAREU - UW1 Features

This page provides a public feature overview of the CAREU UW1 and how its capabilities map to Plaspy for fleet operators, integrators, and security teams. It focuses on practical, non sensitive descriptions of what the UW1 can do when used with Plaspy and what fleet managers can expect to see in the platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional model configurations, installation type, and manufacturer implementation. For device specific technical details, configuration procedures, or the latest firmware notes, consult the official CAREU documentation and your local integrator.

## Feature Overview

The CAREU UW1 is positioned as an industrial grade GPS tracker built for demanding vehicle and asset tracking scenarios and is compatible with Plaspy for telemetry ingestion and fleet management. It combines rugged mechanical design, cellular connectivity, multi GNSS positioning, and extended offline logging to support continuous monitoring even in challenging environments.

- Rugged IP67 enclosure and vibration resistant construction suitable for vehicles and heavy equipment.
- Cat 1 LTE connectivity with fallback to 3G and 2G for broad coverage and resilient uplink.
- Multi GNSS positioning using GPS, GLONASS, and QZSS for reliable location fixes across regions.
- Large onboard logging capacity that stores many position records for later upload when connectivity returns.
- Flexible interfaces for external sensors and vehicle data including 1 Wire, RS 232, and optional CAN bus.
- Built in accelerometer options for event detection related to harsh driving and impacts.

## Core Features of CAREU - UW1

- Industrial IP67 waterproof housing and vibration resistant design for harsh environments.
- Cat 1 LTE connectivity with automatic fallback to 3G and 2G networks and multiple transport options.
- Multi GNSS support including GPS, GLONASS, and QZSS for improved positional reliability.
- Large offline logging capacity capable of storing up to 200,000 position entries.
- Built in accelerometer for harsh driving and impact detection, with optional enhanced axis support.
- 1 Wire sensor support for temperature probes and i Button driver identification.
- RS 232 peripheral interface and optional CAN bus integration for vehicle telemetry.
- Anti theft functions including geofence reporting and remote immobilization controls.

## How These Features Work with Plaspy

When connected to Plaspy, the UW1 streams location, alarm, and sensor data into the platform where it can be visualized, reported, and acted upon. Plaspy ingests position updates, telemetry and event messages so teams can monitor devices in real time and review historical behavior.

- Real time location updates and historical position playback in Plaspy maps and reports.
- Alarm and event visibility such as geofence breaches and impact or harsh driving notifications.
- Offline log upload handling so stored position history is reconciled in Plaspy after network restoration.
- Sensor telemetry from 1 Wire and connected peripherals available for dashboarding and reporting.
- Vehicle data from RS 232 and optional CAN bus surfaced in combined device reports when integrated.
- Centralized device state and event timeline for operational oversight and incident review.

## Typical Use Cases

- Fleet management for heavy trucks and service vehicles requiring resilient real time tracking and long offline logs.
- Motorcycle and two wheeler tracking where a vibration resistant, compact tracker is required for recovery.
- Construction and heavy equipment monitoring on sites with rough conditions and intermittent coverage.
- Asset protection for remote high value items with geofence and anti theft controls.
- Cold chain and logistics monitoring using temperature probes and driver identification for compliance.
- Security and cash logistics with impact alerts and historical logs for forensic analysis.
