# CAREU - U1 Lite+ LTE Features

This page describes the public feature context for using the CAREU U1 Lite+ LTE tracker with Plaspy. It summarizes the tracker capabilities that are relevant to Plaspy users and how those capabilities translate into operational value for fleet monitoring, diagnostics, video telematics, and anti-theft workflows when the device is connected to the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific configuration, regional variants, and the most current technical details consult the manufacturer documentation and release notes.

## Feature Overview

The U1 Lite+ LTE is a compact vehicle telematics unit designed to deliver position tracking, engine telemetry, fuel monitoring, and video telematics support while minimizing integration effort. It is described as Plaspy compatible out of the box and includes features aimed at commercial vehicle, heavy truck, and refrigerated fleet deployments.

- Real-time GNSS tracking using GPS, GLONASS, and QZSS for continuous positional awareness.
- Integrated OBD II and CAN interpretation for engine telemetry including odometer, RPM, engine temperature, and fuel level.
- Advanced fuel monitoring with support for ultrasonic and external sensors to support fuel reports and consumption analysis.
- Video telematics ready on Cat.4 models with optional internal Wi‑Fi hotspot to support dash cam connectivity and video transmission.
- Multi-network cellular connectivity with LTE Cat 4 or Cat 1 and 3G/2G fallbacks to maximize coverage and continuity.

## Core Features of CAREU - U1 Lite+ LTE

- GNSS reception supporting GPS, GLONASS, and QZSS for reliable position fixes.
- OBD II and CAN interpreter compatible with J1939 and J1708 protocols for engine and vehicle data.
- Fuel monitoring support including ultrasonic and external fuel sensors for accurate fuel level reporting.
- Multi network cellular support with LTE Cat 4 or Cat 1 plus 3G and 2G fallbacks for broad coverage.
- Optional internal Wi‑Fi hotspot on Cat.4 variants to support video telematics and camera uplink.
- Built in 3‑axis accelerometer for harsh event and impact detection as described in product literature.
- Remote configuration and FOTA firmware update support to simplify device management at scale.
- Anti theft features including remote engine immobilization and GSM jamming detection as part of the device feature set.

## How These Features Work with Plaspy

When connected to Plaspy, the U1 Lite+ streams position, diagnostics, and sensor data into the platform so operators can monitor vehicles in real time and run automated policies. Plaspy reads standardized telemetry reported by the device and presents it in dashboards, geofence rules, and reports to support operational decisions.

- Real-time location and movement history displayed in Plaspy maps and trip reports.
- Engine telemetry from OBD II and CAN such as odometer, RPM, engine temperature, and reported fuel level visible in Plaspy dashboards.
- Fuel monitoring data from ultrasonic and external sensors integrated into fuel reports and consumption analytics.
- Geofence events and configurable alerts for arrivals, departures, and violations processed by Plaspy rules engine.
- Remote immobilizer actions and anti-theft alerts surfaced for operator response within Plaspy workflows.
- Video ready connectivity indicated in device details where Cat.4 models support camera integration and video upload pathways through compatible workflows.

## Typical Use Cases

- Fleet anti-theft and recovery workflows using remote immobilization and jamming detection.
- Video assisted incident review and security monitoring for vehicles equipped with dash cams on Cat.4 models.
- Fuel management and consumption analysis for fleets using ultrasonic and CAN based fuel inputs.
- Refrigerated transport and cold chain monitoring where 1‑Wire or external sensor inputs are used for temperature control environments.
- Heavy truck diagnostics and maintenance planning using OBD II and CAN telemetry streams.
- Mixed fleet deployments where Plaspy centralizes data from vehicles with varied connectivity and sensor sets.

## Feature Availability Notes

- Some features are model dependent; Cat.4 variants include the optional internal Wi‑Fi hotspot while other variants may not.
- Firmware version and manufacturer configuration can enable or limit particular telemetry items and remote management functions.
- Hardware revisions and regional cellular variants can affect supported bands and network fallbacks; consult the manufacturer for regional details.
- Installation type affects available interfaces and telemetry; OBD II connected units will expose different data than hardwired installations.
- Optional peripherals such as Bluetooth devices or external sensor modules may be supported depending on device options and firmware.
