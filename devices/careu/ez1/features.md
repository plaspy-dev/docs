# CAREU - EZ1 Features

This page provides a public, feature-focused overview of the CAREU EZ1 tracker and how its capabilities are used with Plaspy. It is intended to describe the practical functions and operational value you can expect when deploying the EZ1 with Plaspy for vehicle tracking and fleet management.

Exact feature availability and behavior can vary by firmware level, hardware revision, regional variant, installation method, and manufacturer implementation. Use this page as a general guide and confirm device-specific details in the manufacturer documentation where necessary.

## Feature Overview

The CAREU EZ1 is a compact AVL tracker designed to deliver essential vehicle tracking capabilities in a small form factor. It offers global cellular connectivity options, discrete installation possibilities, and accessory interfaces that broaden operational use.

- Compact and discreet form factor for flexible installation locations
- Global cellular connectivity with LTE Cat 1 and 3G/2G fallback or a 2G variant
- Bluetooth 3.0 for two way voice and remote configuration on supported versions
- GPS and GLONASS satellite positioning for reliable location fixes
- Built in 3 axis accelerometer to detect harsh events like sudden impacts or aggressive driving
- Support for accessory interfaces such as 1 Wire and RS232 for auxiliary sensors and identification

## Core Features of CAREU - EZ1

- LTE Cat 1 with 3G and 2G fallback in the advanced version for broad cellular coverage
- 2G model option that includes Bluetooth 3.0 for voice and configuration use cases
- GPS and GLONASS satellite systems for positional accuracy and tracking
- Integrated 3 axis accelerometer for harsh acceleration, harsh braking, and impact detection
- 1 Wire support for temperature monitoring and i Button driver identification
- RS232 interface for external accessories such as third party sensors and readers
- Geofence reporting with circular and polygonal zone types plus odometer and user defined reporting
- Firmware over the air updates via FTP and remote configuration capabilities including Bluetooth configuration on LTE units

## How These Features Work with Plaspy

Plaspy collects and displays the EZ1 reporting so fleets can monitor location, events, and accessory inputs in one platform. Plaspy automatically detects the tracker protocol and the device can be pointed to the Plaspy server for data reporting and management.

- Real time location and track history visible on Plaspy maps and reports
- Harsh event notifications and event histories based on accelerometer data for operational review
- Geofence events and corresponding reports for entry and exit monitoring
- Odometer and user defined reports visible in Plaspy for mileage and activity tracking
- Accessory and sensor inputs forwarded into Plaspy when configured, enabling temperature or identification workflows where used
- Devices typically report to the Plaspy server domain and can be configured for UDP or TCP reporting as supported by the tracker

## Typical Use Cases

- Fleet location and route monitoring for logistics and delivery operations
- Driver behavior and safety monitoring using harsh event detection
- Discreet asset tracking where small size and compact installation matter
- Car rental and vehicle financing use cases where mileage and location history are required
- Utility and service fleets that need accessory sensor integration and identification
- Remote device configuration and firmware maintenance over the air to reduce site visits

## Feature Availability Notes

- Feature sets may differ between the LTE Cat 1 variant and the 2G variant with Bluetooth 3.0
- Some functions require optional accessories or specific wiring and installation choices
- Firmware revisions can add, change, or remove features such as reporting options and accessory support
- Regional cellular band support and network availability may affect connectivity and fallback behavior
- Always confirm exact capabilities for your device serial number and firmware on the manufacturer site

## Why Use Plaspy with These Features

Using the CAREU EZ1 with Plaspy provides a unified way to visualize location, events, and accessory inputs from the tracker alongside other devices and fleets. Plaspy's device detection and platform features help turn EZ1 telemetry into actionable operational insight, making it easier to manage routes, monitor driver events, and produce reports that support business workflows.
