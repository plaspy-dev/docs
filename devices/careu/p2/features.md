# CAREU - P2 Features

This page provides a public overview of the CAREU P2 GPS Personal Tracker and the practical feature context for using the device with Plaspy. It focuses on user-facing capabilities, what the tracker is typically used for, and how those capabilities are represented in Plaspy for visibility and monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation method, and manufacturer implementation. For device specific technical details and the latest specifications consult the manufacturer documentation linked at the end of this page.

## Feature Overview

The CAREU P2 is a compact personal GPS tracker designed for reliable position reporting and personal safety use. It combines network connectivity, configurable reporting, and a set of safety features to support tracking scenarios for individuals and light commercial deployments.

- Continuous position reporting with configurable update rates, including the ability to report every second for high precision tracking
- Two way voice communication with the ability to call and receive calls and store up to four emergency numbers
- SOS emergency alert and man down detection to signal urgent situations
- Optional Charging Station that supports wireless battery charging and Bluetooth 4.1 pairing for sync and power management
- Geofence support with predefined and dynamic circle boundaries and automatic alerts when paired devices leave a safe area

## Core Features of CAREU - P2

- 3G and 2G network connectivity for wide area coverage where cellular service is available
- SOS emergency alert for rapid notification of urgent situations
- Two way voice calls and memory for up to four emergency contact numbers
- Configurable high frequency reporting, including support for 1 second position updates
- Man down alert supported together with adjustable sensitivity settings
- 3 axis accelerometer for activity and posture detection as used by man down logic
- Assisted GPS and smart GSM multi cell positioning for improved location reliability
- Optional Charging Station with wireless charging, Bluetooth synchronization, and smart safe zone support

## How These Features Work with Plaspy

Plaspy displays device location, events, and alerts from compatible trackers to provide operational oversight and historical context. The CAREU P2 can be integrated into Plaspy so that position updates and safety events appear alongside other fleet or personal tracking assets.

- Location updates reported by the P2 are visible on Plaspy maps and can be monitored in near real time when the device is configured to report frequently
- SOS and man down events are treated as critical alerts in Plaspy to help operators identify and respond to emergencies
- Geofence exits from predefined or dynamic circle zones are shown as events in Plaspy for boundary monitoring and notifications
- Low battery and other device alerts reported by the tracker are surfaced in Plaspy to help maintain device uptime
- Two way call capability is a device level feature; Plaspy records and displays related events and alerts but voice calls are managed by the device and cellphone network
- Plaspy automatically detects supported tracker protocols and can accept device reports when the tracker is configured to send data to Plaspy servers

## Typical Use Cases

- Elder care monitoring for location awareness and emergency alerts
- Child safety tracking with quick SOS and two way call options
- Lone worker protection where man down detection and SOS help improve response
- Security and patrol workflows that require frequent position updates
- Short range paired device scenarios using the Charging Station for battery management and BLE sync
- Business use cases requiring consistent reporting into a centralized visibility platform

## Feature Availability Notes

- Firmware and software versions can change how features behave; not all features are guaranteed on every firmware release
- Some features are optional and require the Charging Station or accessories such as wireless charging stickers and pouches
- Hardware revisions and regional variants may alter network band support or accessory compatibility
- Installation and configuration choices can affect feature behavior, for example reporting intervals and sensitivity settings
- Always check the latest manufacturer documentation for the most current technical specifications and accessory support
