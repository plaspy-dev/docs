# Bofan - PT-60 Features

This page provides a public feature overview for the Bofan PT-60 and how its core capabilities can be used together with Plaspy. It summarizes the PT-60’s user-facing functions such as real-time locating, geo-fence alerts, SOS notifications, alarms, and two-way communication in the context of monitoring and reporting within Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, cellular service, and manufacturer implementation. For device-specific configuration steps, firmware notes, or the most recent technical details refer to the manufacturer documentation.

## Feature Overview

The PT-60 is a compact personal GPS/GSM/GPRS tracker intended for real-time location monitoring and basic alerting. It combines position reporting with event alarms and voice-capable functions to support personal safety and asset oversight.

- Real-time locating and tracking for continuous position awareness
- Geo-fence function that issues an alert when defined areas are breached
- SOS button that sends an emergency alert together with the device location
- Movement alarm and excess speed alarm to detect unauthorized motion
- Low-battery alert to notify when device power needs attention
- Two-way talking communication and short-range listen-in for voice contact

## Core Features of Bofan - PT-60

- GPS based position reporting paired with GSM GPRS connectivity for remote reporting
- Real-time tracking suitable for monitoring current device location
- Geo-fence capability allowing defined safe or restricted areas and breach alerts
- SOS function that transmits a help alert with location to authorized contacts
- Excess speed alarm to notify when the device exceeds a set speed threshold
- Movement alarm to detect and report unexpected motion
- Low-battery alarm to aid timely recharge or maintenance
- Two-way voice communication and listen-in functionality for direct contact with or monitoring around the device

## How These Features Work with Plaspy

When the PT-60 is configured to report to Plaspy, the device’s location updates and event alerts are presented in the Plaspy platform for operational visibility and history. Plaspy automatically detects tracker protocol and surfaces reported events alongside position data to help you monitor devices centrally.

- Live position updates displayed on Plaspy maps to follow device movement
- Geo-fence breach notifications and event timestamps recorded in device history
- SOS alerts highlighted for rapid identification of emergencies reported by the tracker
- Alarm events such as movement, excess speed, and low battery shown in the event log for auditing
- Two-way communication and listen-in activities appear as reported events or call logs when the device forwards that information to the platform
- Centralized device listing and status view to see recent reported health and alert conditions

## Typical Use Cases

- Personal safety monitoring for children, elderly family members, or vulnerable individuals
- Vehicle and light equipment monitoring to track location and movement events
- Personnel tracking and check-in for field teams where location awareness is needed
- Asset protection for portable or high-value items during transit or storage
- Emergency response where SOS alerts provide rapid location information

## Feature Availability Notes

- Feature presence and exact behavior depend on the device firmware and hardware revision installed by the manufacturer
- Two-way audio and listen-in functions require cellular voice capability and may be influenced by local mobile network support
- Geo-fence, speed and movement alarms need correct configuration and may behave differently based on installation and update intervals
- Low-battery reporting is tied to the device power system and firmware thresholds
- Regional variants or carrier restrictions can affect GPRS reporting or voice services; check manufacturer and carrier guidance

## Why Use Plaspy with These Features

Using the PT-60 together with Plaspy centralizes location and event visibility so organizations and individuals can monitor devices from a single interface. Plaspy collects location updates and alarm events, presents them on maps and timelines, and keeps an event history that supports operational oversight and incident review. Plaspy’s automatic protocol detection simplifies adding compatible trackers like the PT-60 to the platform.
