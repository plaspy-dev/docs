# Bofan - B5 Features

This page provides a public, non sensitive overview of the Bofan B5 GPS vehicle tracker and how its features operate when used with Plaspy. It covers the B5’s principal capabilities, the user value they deliver in fleet and security workflows, and the ways Plaspy surfaces location and event data from the device.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Use this page for general guidance on practical capabilities and integration patterns, and consult the manufacturer documentation for current device specific details.

## Feature Overview

The B5 is a compact vehicle tracker designed for around the clock fleet monitoring, anti theft protection, and operational telemetry reporting into Plaspy. It emphasizes reliable GNSS positioning, event detection, and configurable data modes to balance connectivity and cellular cost.

- Real time GNSS location reporting for live tracking and historical playback on Plaspy.
- Configurable geo fence and event alerts to notify managers of entry, exit, or exceptional conditions.
- Remote engine control capability via a digital output to support immobilization workflows.
- Built in accelerometer driven movement, towing, and crash detection to trigger timely alerts.
- Local flash storage for offline trip logging and automatic upload when connectivity returns.
- GPRS data saving and configurable reporting modes to reduce cellular usage while preserving key telemetry.

## Core Features of Bofan - B5

- Plaspy compatible out of the box for centralized tracking and alarm handling.
- Continuous GNSS positioning with internal high gain antennas for consistent reception.
- Configurable geo fence and overspeed style event detection mapped to alerts.
- Built in accelerometer for movement, towing and crash detection events.
- Remote engine control via digital output to support immobilization actions.
- Four digital inputs and one digital output to capture ignition and external signals.
- Local event buffering in internal flash memory for later upload when the device regains connectivity.
- Intelligent GPRS data saving modes and configurable GPRS commands to manage cellular usage.

## How These Features Work with Plaspy

Plaspy ingests the B5’s location and event messages so fleet managers can monitor assets in real time, receive alarms, and run historical reports. The platform displays position, event timestamps, and the status of configured inputs or outputs in a single view for operational oversight.

- Real time position updates and replayable track history appear on Plaspy maps.
- Geo fence, towing, crash, jamming, unplug and other scenario alerts map to Plaspy alarms and workflows.
- Digital input state and engine runtime indicators reported by the device are used for utilization and maintenance reporting.
- Remote commands issued from Plaspy can adjust configuration and, where installed, trigger the device’s engine control output.
- Offline trip logs stored in the device flash are uploaded to Plaspy when connectivity is restored to fill gaps in history.

## Typical Use Cases

- Fleet anti theft and immobilization where remote engine control and tamper alerts reduce recovery time.
- Driver and vehicle utilization reporting using ignition sensing and engine runtime analytics.
- Emergency response and occupant safety using one touch SOS and event driven alerts.
- Asset protection with unplug, jamming, towing and crash detection to notify operations teams.
- Route compliance and operational efficiency using geo fence and event based monitoring.
- Temporary offline operation with local logging for vehicles that operate in low coverage areas.

## Feature Availability Notes

- Firmware version affects available features and alert behavior; manufacturers may add or adjust functions over time.
- Hardware revisions and regional variants can change supported bands, interfaces, or included sensors.
- Installation choices and wiring determine which digital inputs and outputs are available for ignition sensing and immobilization.
- Some features such as remote voice monitoring or SOS behavior may require additional installation configuration or accessories.
- Always confirm the specific feature set and firmware behavior with the manufacturer documentation before deployment.

## Why Use Plaspy with These Features

Combining the Bofan B5 with Plaspy gives fleet teams a unified view of location, events, and device state that supports faster incident response and clearer operational insight. Plaspy’s platform is designed to surface the device alerts, historical tracks, and input/output status the B5 reports, enabling coordinated workflows for anti theft, maintenance planning, and driver oversight.
