# Bofan - PT502 Features

This page provides a public feature overview for the Bofan PT502 GPS tracker and how its capabilities are used with Plaspy. It describes the tracker features that matter to fleet managers, operators, and integrators when the PT502 is connected to Plaspy for live tracking, telemetry, alarm handling, and event capture.

Exact feature availability for an individual PT502 unit can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific settings, firmware behavior, and the most current technical details please consult the manufacturer documentation and firmware notes.

## Feature Overview

The PT502 is a purpose built 4G vehicle tracker designed for professional fleet management and security workflows. When integrated with Plaspy, the PT502 delivers real time position updates and a range of event driven telemetry that help teams monitor vehicle status and respond to incidents.

- Real time GPS tracking for live location awareness and trip replay.
- External camera support for automatic photo capture on alarms and events.
- Driver identification using RFID to associate drivers with vehicles.
- Ultrasonic fuel sensing support for fuel level monitoring and discrepancies.
- Remote immobilizer and speed limiting controls via device outputs and relays.
- Configurable alarm suite including SOS, geo fence, speed, ACC on off, and power cut.

## Core Features of Bofan - PT502

- 4G cellular connectivity for live tracking and timely telemetry delivery.
- Support for up to four external cameras for event and alarm photo capture.
- RFID based driver identification to link driver identities with trips.
- Ultrasonic fuel sensor integration for fuel level reporting and alerts.
- Remote engine shutdown and speed limitation using the device relay outputs.
- Multiple alarm types including SOS, geo fence, speed, ACC on off, power cut, and harsh driving events.
- Digital inputs and outputs for external sensors and relays to extend integration options.

## How These Features Work with Plaspy

Plaspy ingests the PT502 location, event, and sensor data and presents it in live maps, alerts, and historical reports so operators can maintain situational awareness and review incidents. The PT502's event driven reporting pairs with Plaspy rules and views to convert raw signals into actionable information.

- Live location and trip data available on Plaspy maps and in trip history.
- Alarm and event notifications routed into Plaspy alerting workflows for quick operator response.
- Driver ID records from RFID mapped to driver profiles and trip assignments in Plaspy.
- Camera images captured by the device attached to alarm events are visible in Plaspy for incident verification.
- Fuel level and discrepancy alerts from ultrasonic sensors reflected in Plaspy reports and alert rules.
- Remote command support from Plaspy to operate outputs for immobilizer or restriction actions where configured.

## Typical Use Cases

- Anti theft response and immobilization workflows for recovered or suspicious vehicles.
- Driver identification and accountability by linking RFID tags to trips and reports.
- Fuel usage monitoring and theft detection using ultrasonic fuel sensing integrated with trip data.
- Event driven photo capture for collision, security incidents, and verification of events.
- Maintenance scheduling and mileage based reminders driven by recorded trip data.
- Fleet monitoring and compliance reporting for operations and safety oversight.

Using the PT502 with Plaspy gives fleet operators an integrated view of location, alarms, driver identity, fuel telemetry, and event imagery. Plaspy turns device signals into visual context, alerts, and historical reports so teams can act on incidents, analyze operational patterns, and maintain oversight across a vehicle fleet.
