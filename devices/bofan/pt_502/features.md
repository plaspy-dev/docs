# Bofan - PT-502 Features

This page summarizes the public feature context for using the Bofan PT-502 GPS car tracker with Plaspy. It focuses on user-facing capabilities and how those capabilities map to visibility and monitoring inside Plaspy, helping fleet and vehicle owners understand what the device can provide when used with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. Where useful, this page highlights common functions reported for the PT-502, but you should confirm specific behavior for your unit with the official manufacturer documentation.

## Feature Overview

The PT-502 is positioned as a versatile vehicle tracker that supports real-time monitoring and several security and reporting features. It provides multiple reporting methods and a set of alarms and controls that are useful for theft deterrence, location awareness, and basic event logging.

- Real time tracking using GPRS and SMS reporting for current location and movement updates.
- Combined GNSS positioning with Glonass and GPS for improved location accuracy.
- Remote engine cut capability to help immobilize a vehicle in case of unauthorized use.
- SOS alarm with up to three preset emergency numbers for immediate alerts.
- Position logging capacity of 7000+ waypoints for historical route review.
- Geo-fence control, speed alarm, and low power alerts to notify events and conditions.

## Core Features of Bofan - PT-502

- Tracking via SMS and live tracking by GPRS enabling live location updates and remote queries.
- Glonass plus GPS positioning to provide consistent coordinate information.
- Remote engine cut functionality available as an optional control.
- SOS alarm function with the ability to preset three emergency contact numbers.
- Geo-fence control to trigger alerts when predefined boundaries are crossed.
- Position logging capacity of over 7000 waypoints for on device history.
- Speed alarm and low power alert features to notify abnormal conditions.
- I/O and analog support including two digital inputs (one negative and one positive trigger), one output, and a 10 bit analog input for basic sensor or input monitoring.

## How These Features Work with Plaspy

When used with Plaspy, the PT-502's reporting and alarm features feed into the platform to provide operational visibility and event awareness. Plaspy automatically detects compatible tracker protocols and surfaces device reports for monitoring and historical review.

- Live and historical location data from GPRS reports appear in Plaspy maps and trip histories for situational awareness.
- Alarm events such as SOS, geo-fence breach, speed alerts, and low power warnings are recorded in Plaspy as events for notifications and audit trails.
- Remote control actions supported by the device, such as engine cut when enabled, are tracked in Plaspy event logs when triggered through approved commands or workflows.
- Position logs stored on the device can be uploaded or reconciled with Plaspy histories to fill gaps in coverage.
- Mileage and distance based reporting capabilities are reflected in Plaspy reports when the device supplies distance or movement updates.

## Typical Use Cases

- Anti theft and recovery workflows using remote engine cut plus SOS alerts to aid rapid response.
- Fleet location monitoring with live GPRS updates and route history from waypoint logging.
- Geo-fence based zone monitoring for site entry and exit notifications.
- Speed monitoring and driver behavior observation using speed alarms and event reports.
- Remote status checks and address retrieval using SMS queries for locations when cellular data is unavailable.
- Distance and mileage reporting for basic operational metrics and cost tracking.
