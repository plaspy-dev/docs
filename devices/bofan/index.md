# Bofan

Bofan produces a range of GPS tracking devices used for vehicle and asset monitoring. On this page you will find practical information about using Bofan trackers with Plaspy, how the devices typically integrate with fleet software, and guidance to help you choose the right device for your deployment. Use the device catalog below to browse all Bofan models that are compatible with Plaspy.

## How Bofan devices work with Plaspy

Bofan trackers send location and telemetry data over cellular networks using standard GPS and GNSS positioning. Plaspy receives that data through device configuration that points trackers to Plaspy ingestion endpoints. Once connected, Plaspy ingests, decodes, and displays the live location, history, and telematics in the Plaspy platform so teams can monitor movement, set alerts, and analyze fleet performance.

Connectivity and setup are handled at the device level. Plaspy provides the server endpoints, protocol information, and configuration guidance needed to direct a Bofan device to send data to your Plaspy account. Detailed device specific setup steps are available on each device page accessible from the catalog below.

## Common features found in Bofan devices

Bofan devices used with Plaspy typically provide a standard set of capabilities useful for fleet and asset tracking. Common features include:
- Real time GPS location reporting and position history
- Movement and ignition detection signals suitable for vehicle monitoring
- Configurable reporting intervals for location and status
- Basic geofencing and tamper or low battery alerts that Plaspy can surface
- Support for cellular connectivity and sometimes auxiliary inputs for sensors

Note that exact feature sets vary by model. The Brand Catalog above lists all compatible devices and links to their specific technical documentation and configuration guides.

## Typical use cases for Bofan GPS trackers

Bofan devices are commonly used in:
- Light and medium vehicle fleet tracking for routing and utilization monitoring
- Asset monitoring where periodic location and status reports are sufficient
- Metered equipment or trailer tracking to regain visibility on mobile assets
- Basic driver behavior and route playback workflows when combined with Plaspy reporting

These use cases align with standard fleet telematics workflows that Plaspy supports such as live tracking, route history, alerts, and data exports for analysis.

## Why choose Plaspy for Bofan device monitoring

Plaspy provides the platform layer to collect, normalize, and present GPS and telematics data from Bofan trackers alongside other devices in your fleet. Key benefits include:
- Unified dashboard for live location and historical playback across mixed device fleets
- Alerts and rule automation based on position, movement, and inputs reported by Bofan devices
- Scalable data ingestion that handles multiple device types and reporting intervals
- Reporting and export options that help operations teams analyze utilization and performance

Plaspy focuses on flexible device compatibility so organizations can continue using hardware they already own while getting modern visibility and control. To learn more about the platform and available plans visit https://www.plaspy.com.

## Help finding the right Bofan device

The Brand Catalog component above shows all Bofan models compatible with Plaspy. Use the following quick checklist to decide which device best fits your deployment:
