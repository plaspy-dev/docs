# EV - EV-04 Features

This page provides public feature context for using the EV-04 personal GPS tracker pendant with the Plaspy platform. It summarizes the practical capabilities you can expect when integrating the EV-04 into Plaspy for real-time tracking, SOS handling, fall alerts, and device telemetry so caregivers and monitoring services can maintain situational awareness.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method, and how the manufacturer configures the unit. Where applicable, this page highlights the device features described by the manufacturer and how those features are reflected in Plaspy, but you should confirm details against the official manufacturer documentation and firmware release notes.

## Feature Overview

The EV-04 is a lightweight, wearable pendant designed for personal protection and remote patient monitoring. When combined with Plaspy, it provides location awareness, event reporting, and voice communication capabilities that help monitoring centers and caregivers respond quickly.

- One-button SOS with integrated two-way calling for immediate voice contact during emergencies.
- Highly sensitive fall detection that can automatically trigger SOS events and voice prompts to the wearer.
- Multi-technology positioning combining GNSS with Wi‑Fi, BLE beacon assistance, and cell tower LBS for improved coverage and indoor support.
- BLE pairing for medical device telemetry and optional BLE beacon support to enhance indoor accuracy for monitored environments.
- IP67 rated pendant design with a dedicated charging base for convenient daily use and maintenance.

## Core Features of EV - EV-04

- Plaspy compatible real-time tracking and event reporting for centralized monitoring.
- One-button SOS with integrated speaker and microphone enabling two-way voice calls.
- Fall detection with automatic SOS triggering and voice prompts or TTS guidance.
- Hybrid location technologies including GPS plus Wi‑Fi, BLE beacon assistance, and LBS for broader positioning coverage.
- High-frequency update capability during SOS events for more frequent location reporting.
- BLE support for pairing with medical devices to surface RPM telemetry without requiring a separate user app.
- FOTA remote firmware upgrade support and platform management for maintenance and updates.
- Compact, IP67 pendant form factor with a drop-in charging base for simple daily charging.

## How These Features Work with Plaspy

Plaspy ingests location and event telemetry from the EV-04 so operators, caregivers, and integrated monitoring services can view device state, respond to alarms, and audit historical events. Plaspy automatically detects compatible tracker protocols and presents incoming data in a centralized dashboard for operational use.

- Real-time location and SOS event updates delivered to Plaspy for live tracking and alarm handling.
- Fall detection and automatic SOS alerts forwarded into Plaspy so monitoring teams can review event details and timestamps.
- Two-way call events and voice call status logged in Plaspy for incident records and follow up.
- BLE sensor and beacon-assisted positioning information displayed to improve indoor visibility where available.
- Device management workflows in Plaspy available for coordinating firmware upgrades and monitoring battery and connectivity status.

## Typical Use Cases

- Personal protection for seniors and family members who may need rapid assistance via SOS and live location sharing.
- Remote patient monitoring (RPM) where BLE pairing with medical devices and centralized telemetry support clinical oversight.
- Lone worker safety programs that require an always-on SOS pendant with voice contact and location visibility.
- Assisted living and home care providers who use BLE beacons and centralized alerts to manage resident safety and device charging routines.
- Monitored service providers and alarm centers that need reliable event forwarding, audit logs, and two-way communication records.
- Organizations seeking a lightweight wearable for continuous personal safety rather than vehicle or fleet telemetry.
