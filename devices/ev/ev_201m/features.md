# EV - EV-201M Features

This page provides a public feature overview for the EV-201M GPS tracker and how its capabilities integrate with Plaspy for centralized tracking, telemetry, and activity visibility. It focuses on user-facing functions and practical behavior when the device is used with Plaspy rather than implementation or private configuration details.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation type, regional model, and manufacturer implementation. Where possible this page reflects the EV-201M’s standard capabilities such as live tracking, manual location requests, BLE beacon detection, and activity timelines, but users should confirm specifics for their hardware revision and firmware level.

## Feature Overview

The EV-201M is a compact GPS tracker optimized for pet tracking and activity monitoring, designed to operate on LTE-M and NB-IoT networks and to be compatible with Plaspy out of the box. It emphasizes rugged outdoor use, energy efficiency, and a small form factor suited to collars and pet accessories.

- Plaspy compatible device for centralized live location, telemetry, and event visibility.
- IP67 waterproof rating for dependable outdoor use in wet or dirty conditions.
- Energy efficient design with an 800 mAh battery and IoT power saving modes for extended stand-by between charges.
- Fast outdoor live tracking updates, with position reports as frequently as every 10 seconds when Live Tracking is enabled.
- Manual single-location requests via a dedicated device button for on-demand position checks.
- Bluetooth beacon detection and BLE sensors to assist with home detection and activity context.

## Core Features of EV - EV-201M

- 4G LTE-M and NB-IoT network support for low-power wide area connectivity across supported regions.
- GPS GNSS positioning to provide outdoor location fixes and route history.
- IP67-rated enclosure for dust and water protection suitable for pet use.
- 800 mAh battery with optimized IoT power-saving modes to extend operational intervals.
- Dedicated manual location button for single-location requests on demand.
- Bluetooth Low Energy support for home beacon detection and companion sensor interaction.
- Activity timeline and mobile app integration for daily movement summaries and consecutive location history.

## How These Features Work with Plaspy

When an EV-201M is used with Plaspy, the tracker forwards location fixes, telemetry, and event messages to the Plaspy cloud where they are presented on maps, timelines, and dashboards. Plaspy can display the device’s live feed, history, and alerts alongside other monitored devices to simplify oversight.

- Live location streaming and periodic position updates appear on Plaspy maps for near real-time visibility.
- Manual single-location requests initiated from the device result in an on-demand position update visible in Plaspy.
- Activity timelines and consecutive location history are available in Plaspy to review routes and daily movement.
- BLE-assisted home beacon events and device telemetry such as battery status can be surfaced as device status information or alerts.
- Plaspy detects and interprets compatible tracker protocol messages so the EV-201M integrates with minimal user setup.

## Typical Use Cases

- Pet recovery and locating a lost pet using real-time tracking and on-demand position requests.
- Monitoring a pet’s roaming territory and reviewing route history to understand habitual ranges.
- Safe-zone and geo-fence management to notify owners when a pet leaves or returns to a defined area.
- Activity and movement tracking to view daily exercise patterns through the device timeline.
- Home detection using BLE beacons to reduce false alerts when the pet returns to a known location.
- Consolidated visibility for owners who want pet trackers monitored alongside other assets in a single Plaspy view.
