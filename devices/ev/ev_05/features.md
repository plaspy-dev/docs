# EV - EV-05 Features

This page provides a public feature overview for the EV-05 wearable GPS tracker and explains how its capabilities map into Plaspy for monitoring, alerting, and operational use. It is intended to help caregivers, monitoring centers, and technical evaluators understand what to expect from the EV-05 when used with Plaspy and which features are typically visible in the platform.

Exact feature availability and behavior can vary between firmware versions, hardware revisions, regional variants, and installation choices. Where useful, this page draws on the device description for public details, but users and integrators should confirm the current feature set with the device manufacturer and review device-specific documentation for the most up to date technical information.

## Feature Overview

The EV-05 is a wristwatch-style safety tracker built for continuous personal protection and remote monitoring. It combines multi‑network cellular connectivity with Wi‑Fi and beacon location methods, continuous live updates during emergencies, and personal safety telemetry to support caregivers and monitoring services.

- Wearable GPS tracking for continuous location visibility with multi-modal positioning for improved coverage
- One-button SOS and emergency calling with accelerated live updates during alarm conditions
- Fall detection and no-motion alerts to highlight potential incidents to caregivers or monitoring operators
- Heart-rate monitoring and health telemetry with caregiver notifications for abnormal readings
- Two-way voice calling and voice prompts for direct communication during an event

## Core Features of EV - EV-05

- Continuous position reporting using GPS plus complementary location methods such as Wi‑Fi, beacon, and LBS as provided by the device
- One-button SOS that triggers high-priority alerts and increased reporting frequency during emergencies
- Fall detection and no-motion alerts to help surface potential incidents automatically
- Heart-rate telemetry and activity counts with caregiver notification capability
- Two-way voice calls and dedicated call button for direct communication between wearer and responder
- Wearable design features including an IP67 waterproof rating, lockable strap, and replaceable wristband for 24/7 use
- Bluetooth pairing for integration with compatible medical peripherals and nearby beacons

## How These Features Work with Plaspy

Plaspy receives and processes position updates, safety events, and health telemetry from compatible devices so operators and caregivers can monitor status from a unified dashboard. Plaspy automatically detects supported tracker protocols and presents device data alongside other tracked assets on the platform.

- Real-time location tracks and event timelines visible in Plaspy dashboards and maps
- High-priority SOS and fall alerts forwarded into Plaspy so that rules, notifications, and operator workflows can act immediately
- Health telemetry such as heart-rate readings shown as monitored data and usable in alert rules or reporting
- Presence and geofence events derived from Wi‑Fi or beacon information available for caregiver notifications and automation
- Call and voice activity logged as events so operators can see when two-way communication occurred

## Typical Use Cases

- Elderly care and assisted living monitoring where rapid incident detection and caregiver notifications are essential
- Patient monitoring and remote patient monitoring scenarios that use heart-rate telemetry and Bluetooth sensor integration
- Lone worker protection where wearable alerts and two-way voice enable faster response
- Managed monitoring services operating 24/7 alarm handling for SOS and fall events
- Family or self-monitoring arrangements that rely on wearable alerts and location sharing for reassurance

## Feature Availability Notes

- Firmware and software revisions can alter reporting intervals, alarm sensitivity, and the set of available telemetry values
- Hardware variants or region specific models may differ in cellular band support, pairing options, or bundled accessories
- Installation choices and subscription or monitoring service setups can change which destination systems receive alerts and how they are routed
- Manufacturer settings and configuration options may enable or disable specific features such as Bluetooth pairing or automated SOS contacts
- Always consult the device quick start guide and the manufacturer technical documentation for model specific details
