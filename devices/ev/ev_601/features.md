# EV - EV-601 Features

This page provides a public, non-sensitive overview of the EV EV-601 GPS tracker and how its capabilities are used with the Plaspy platform. It focuses on user-facing features, practical uses, and how tracking and event information from the EV-601 is presented inside Plaspy for fleet and vehicle monitoring.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. For the most current device-specific technical details, consult the manufacturer documentation and firmware release notes before deployment.

## Feature Overview

The EV-601 is a vehicle and motorcycle tracker designed to provide real-time location reporting, event alerts, and remote control features that support monitoring and asset protection. It combines location services with reporting, local storage, and user alerts to help operators maintain situational awareness.

- Real-time web-based tracking and SMS access for live location visibility.
- GSM/GPRS simultaneous communication for continuous connectivity.
- Built-in data memory for offline logging when coverage is intermittent.
- Geo-fencing with entry and exit alerts to monitor area-based activity.
- Suite of alarms including over-speed, power lost, GPS signal lost and recovery, and movement detection.
- Remote control functions including engine/oil cut-off and outputs for door lock or siren control where configured.

## Core Features of EV - EV-601

- Real-time tracking via the device's online service and SMS reporting.
- GSM and GPRS communication for sending position and event reports.
- Internal memory chip for storing location history during disconnection.
- Geo-fence support with alerts on enter and exit events.
- Time-interval auto-tracking for periodic location updates.
- Multiple alarm types including power lost, backup battery low, over-speed, GPS signal lost and recovery, and movement alarm.
- SOS panic button for emergency notifications and a listen-in function for remote audio monitoring.
- Remote engine or oil cut-off and configurable outputs for control actions such as door lock or siren activation.

## How These Features Work with Plaspy

When used with Plaspy, the EV-601 can report location and event information to the platform where operators can view and act on that data. Plaspy automatically detects supported tracker protocols and provides a unified view for monitoring compatible devices.

- Live map visualization of reported positions and path history for each device.
- Event and alarm notifications surfaced in Plaspy for quick operator awareness.
- Geo-fence events shown as enter and exit alerts tied to mapped zones.
- Historical playback from stored reports to review routes and events when needed.
- Visibility of SOS and movement alerts so teams can prioritize responses.
- Ability to coordinate remote actions where device and platform configurations allow for control commands.

## Typical Use Cases

- Monitoring vehicle and motorcycle fleets for real-time location and route oversight.
- Alerting operators to unauthorized movement or entry into restricted areas using geo-fencing.
- Receiving power loss and backup battery alerts to detect tampering or power issues.
- Using SOS panic and movement alarms to escalate security incidents rapidly.
- Reviewing historical tracks for incident investigation or route optimization.
- Applying remote cut-off and auxiliary outputs as part of theft response procedures where supported.

## Feature Availability Notes

- Feature behavior may differ across firmware versions; check firmware release notes for precise behavior.
- Hardware revisions or regional model variants can affect which inputs, outputs, and alarms are present.
- Some remote control functions require proper installation of vehicle wiring and configuration by a qualified technician.
