# EV - EV-603 Features

This page provides a public, non-sensitive summary of the EV-603 tracker feature set and how those capabilities map to use with Plaspy. It focuses on practical, user-facing information about device functions that are relevant when operating the EV-603 together with the Plaspy fleet and asset monitoring platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, and the way the unit is installed or configured. For device-specific technical details, firmware notes, or advanced configuration, consult the manufacturer's documentation and release notes.

## Feature Overview

The EV-603 is a compact vehicle and motorcycle tracker designed for continuous location monitoring and event detection in harsh environments. Its weather resistant enclosure, internal antennas, motion sensing, and built-in power backup make it suitable for mobile tracking where reliable position reporting and event alerts are required.

- Waterproof and dust resistant enclosure with IP66 level protection for outdoor and exposed installations
- Internal GPS and GSM antennas for position and cellular connectivity without external antenna routing
- Inbuilt 3D G-sensor for motion detection and power management driven alerts
- Geo-fence management and over-speed alarm functions to support location based event monitoring
- Remote control and I/O features such as engine/oil cut-off, door and ACC input detection, plus outputs for locks or siren
- Built-in data logging with internal flash memory to retain historic locations when real-time connection is unavailable

## Core Features of EV - EV-603

- Weather resistant IP66 housing suitable for vehicle and motorcycle mounting
- Internal GPS and cellular antennas for simplified installation and reliable reception
- 3D G-sensor for detecting shocks and motion events and for power saving modes
- Geo-fence and over-speed alarm capability for location and driving behavior alerts
- Input detection for ACC ON/OFF, SOS panic, and door open/close monitoring
- Outputs and a built-in relay to support remote locking, siren activation, or engine/oil cut-off
- Onboard flash memory for data logging and storage of location history between uploads
- Integrated backup battery to maintain operation and reporting during vehicle power loss

## How These Features Work with Plaspy

Plaspy ingests compatible position and event reports from the EV-603 and presents them in a unified monitoring interface, making location, motion, and input events visible to fleet managers and operators. Plaspy's device detection recognizes compatible trackers so data appears in the platform without manual protocol selection.

- Real-time location updates and historical playback based on the EV-603 position reports
- Visibility of geo-fence events and over-speed triggers as platform alerts or timeline events
- Presentation of input-based events such as ACC state changes, SOS activations, and door status in the device event log
- Ability to view device offline or power loss notifications that stem from backup battery and power alarm reports
- Use of stored device location logs for reconstructing trips when live connectivity is interrupted

## Typical Use Cases

- Fleet vehicle tracking for route monitoring, trip history, and location-based alerts
- Motorcycle recovery and monitoring where a compact, weather resistant unit is required
- Security use where motion detection and listen-in access help confirm unauthorized movement
- Temporary or covert installations on assets that benefit from internal antennas and magnetic mounting
- Remote immobilization workflows using relay based engine or fuel cut-off in theft prevention scenarios
- Situations requiring local data logging to preserve tracking history during temporary network outages

## Feature Availability Notes

- Firmware and hardware revisions can change which features are enabled or how they behave; not every unit will offer identical functionality
- Some capabilities, such as listen-in or remote cut-off, may be subject to regional regulations and require proper configuration and consent
- Installation method and wiring affect inputs, outputs, and backup battery behavior; professional installation is recommended for critical use
- Manufacturer documentation should be consulted for exact flash memory limits, battery runtime, magnet mounting guidance, and safety instructions
- Plaspy displays events sent by the device; availability of particular events depends on the EV-603 configuration and firmware settings
