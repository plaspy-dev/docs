Arusnavi is a brand known for producing GPS tracking devices used in vehicle and asset tracking. ## How Arusnavi devices work with Plaspy

Arusnavi trackers typically send location and telemetry data over cellular networks to a server. Plaspy receives that data, decodes the tracker messages according to supported protocols, and presents it in a unified web interface for monitoring, alerts, and reporting. On this page the Brand Catalog lists the Arusnavi models that have been identified as compatible with Plaspy so you can choose the right device for your setup.

Key integration points to consider
- Data transport and protocol compatibility between the tracker and Plaspy
- Device configuration for sending data to Plaspy endpoints
- Telemetry fields transmitted by the device that Plaspy can interpret for location, speed, ignition, and sensor values

For manufacturer details, you can also visit the Arusnavi website at https://www.arusnavi.ru.

## Common features found in Arusnavi devices

While device capabilities vary across models, Arusnavi devices commonly provide the following types of functionality that are relevant when used with Plaspy:

Plaspy consumes the telemetry that devices send and exposes those features through location history, geofencing, and alert rules.
