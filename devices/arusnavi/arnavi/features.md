# Arusnavi - Arnavi Features

This page summarizes the public feature context for using the Arusnavi Arnavi navigation controller with Plaspy. It highlights the practical capabilities you can expect when integrating this model into Plaspy for remote monitoring of vehicles and mobile equipment, and it explains how those capabilities map to operational visibility inside the Plaspy platform.

Exact feature availability can vary by firmware version, hardware revision, installation method, and how the manufacturer configures the unit. For device specific configuration, sensor wiring, or firmware behavior please consult the official manufacturer documentation and release notes.

## Feature Overview

The Arnavi is designed as a flexible navigation controller for remote monitoring tasks. It provides data collection from multiple sensor types and integrates with vehicle systems to bring location and condition information into compatible tracking platforms like Plaspy.

- Supports a broad set of sensor interfaces for digital, discrete, analog, and frequency pulse inputs for complementary telemetry.
- Integrates with vehicle bus systems via CAN bus support to access vehicle data where available.
- Intended for remote monitoring of mobile objects including vehicles and vehicle-mounted equipment.
- Designed for compatibility with third party tracking software, enabling straightforward integration into Plaspy and similar platforms.
- Useful for centralized visibility of location and sensor driven events across a fleet or set of assets.

## Core Features of Arusnavi - Arnavi

- Multi sensor support including digital inputs, discrete inputs, analog inputs, and frequency pulse inputs.
- CAN bus connectivity for integration with supported vehicle onboard systems.
- Remote monitoring focus for mobile objects and vehicle mounted equipment.
- Designed for software compatibility to simplify integration with tracking platforms.
- Practical telemetry collection aimed at operational visibility and equipment condition monitoring.
- Flexible deployment options to suit different installation environments.

## How These Features Work with Plaspy

Plaspy provides a central platform for collecting and displaying location and sensor data reported by compatible trackers. When an Arnavi device is integrated with Plaspy, its sensor and vehicle bus data become visible alongside GPS location for monitoring and operational decision making.

- Sensor inputs reported by the Arnavi can be shown as events or telemetry in Plaspy for status monitoring.
- CAN bus data available from the Arnavi can be mapped to vehicle parameters within Plaspy where applicable.
- Device compatibility allows the Arnavi to be added to Plaspy and managed alongside other trackers in a single interface.
- Real time and periodic reports from the Arnavi feed Plaspy dashboards and history views for review and analysis.
- Plaspy detects supported tracker protocols and displays incoming data in context for fleet oversight.

## Typical Use Cases

- Fleet vehicle location tracking combined with sensor status monitoring.
- Monitoring condition of vehicle mounted equipment through analog and discrete inputs.
- Capturing frequency pulse inputs for counting or usage metrics where applicable.
- Integrating vehicle bus data into centralized monitoring for maintenance and status checks.
- Consolidating multiple tracker models into a single Plaspy account for unified visibility.

## Feature Availability Notes

- Firmware version can affect which sensor and CAN bus features are available or how specific signals are reported.
- Hardware revisions and regional variants may change supported interfaces or connector assignments.
- Installation method and wiring determine which sensor inputs are usable and how signals are interpreted.
- Manufacturer configuration and optional modules may enable or restrict certain integrations.
- Always review the device label and manufacturer documentation to confirm capabilities for a specific unit.
