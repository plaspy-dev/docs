# Arusnavi - Arnavi L2 (cigarette lighter version with panic button)

![Arnavi L2 (cigarette lighter version with panic button)](./tracker.png)

The Arnavi L2 \(cigarette lighter version with panic button\) is a plug-and-play GPS tracker engineered for fast, no-drill installation and easy relocation between vehicles. Designed for fleet managers, rental and rideshare operators, and short-term leased vehicles, this Plaspy compatible tracker delivers continuous position reporting, driver behavior telemetry and emergency signaling without permanent wiring—ideal where rapid deployment and anti-theft measures matter.

The L2 combines multi-constellation GNSS positioning, a 2G GSM/GPRS modem, BLE connectivity for external sensors and a dedicated panic button for immediate alarm reporting. With built-in accelerometer-based towing and driving-style detection, offline black-box logging and wide input protection, the Arnavi L2 provides the core telemetry and safety features required for reliable real-time tracking and fleet management on Plaspy.

## Key Highlights

- Plaspy compatible plug-and-play GPS tracker that installs via cigarette lighter harness for fast vehicle swaps.
- Multi-constellation GNSS \(GPS/GLONASS/Galileo/BeiDou/QZSS\) for robust satellite positioning.
- Real-time tracking and telemetry over 2G GPRS with support for remote configuration and firmware updates.
- Dedicated panic \(alarm\) button plus built-in accelerometer for emergency signaling, tow detection and eco-driving analysis.
- Bluetooth Low Energy support for up to five external sensors—temperature, door, BLE tags for guard mode and more.
- 8 MB on-board logging \(~12,000 records\) for offline black-box recording when coverage is intermittent.
- Universal protected I/O for fuel sensors or immobilizer relays, and discrete inputs for ignition sensing.

## How It Works with Plaspy

The Arnavi L2 integrates with Plaspy using its server-configurable protocols to deliver GNSS position, telemetry and event data to your Plaspy account in near real time. Out-of-coverage data is stored locally in the device’s flash and uploaded when the connection is restored, enabling continuous auditing and accurate trip history.

- Real-time location and telemetry updates \(GNSS + 2G GPRS\) for continuous fleet visibility on Plaspy dashboards.
- Panic button alerts and accelerometer-triggered events \(tow, crash or aggressive driving\) forwarded immediately to Plaspy for rapid response.
- Ignition status via positive discrete input for engine-on/off events and mileage-based reporting in Plaspy.
- Fuel monitoring and immobilizer control via the universal protected I/O—frequency fuel sensors and relay-based immobilizers are supported.
- Bluetooth sensors and tags \(up to five\) for guard mode, temperature monitoring and accessory telemetry integrated into Plaspy sensor feeds.
