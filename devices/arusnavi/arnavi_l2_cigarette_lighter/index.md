# Arusnavi - Arnavi L2 (cigarette lighter)

![Arnavi L2 (cigarette lighter)](./tracker.png)

The Arnavi L2 \(cigarette lighter\) is a compact GPS tracker and navigation controller designed for quick, non-invasive installation and portable telematics. Plaspy compatible out of the box, the Arnavi L2 provides reliable real-time tracking and telemetry for fleets that need a plug‑in solution — ideal for taxis, rental cars, and service vehicles that require fast transfer between units without hardwiring.

Powered from a vehicle cigarette lighter socket, the Arnavi L2 combines cellular 2G/GPRS connectivity, multi‑GNSS positioning \(GPS, GLONASS, Galileo, BeiDou, QZSS\) and Bluetooth Low Energy to support BLE sensors and driver‑behavior features. With remote configuration, black‑box storage and protected I/O for ignition and actuators, it delivers the essentials for fleet management, anti‑theft monitoring and sensor‑based telemetry when integrated with the Plaspy platform.

## Key Highlights

- Plaspy compatible plug‑and‑play GPS tracker for fast installation via cigarette lighter socket — no hardwiring required.
- Real‑time tracking over GSM \(2G/GPRS\) paired with multi‑GNSS positioning for reliable location data.
- Bluetooth Low Energy support for up to five wireless sensors, enabling telemetry and environmental monitoring.
- Discrete ignition input and a protected universal I/O \(output up to 500 mA\) to support ignition detection and remote immobilizer or relay control.
- Built‑in accelerometer and EcoDriving features for driver behavior monitoring and motion‑based alerts.
- Internal temperature sensor and small black‑box memory \(8 MB, up to ~12,000 records\) for offline data capture.
- Remote configuration, firmware updates via web, USB PC tool and mobile app for streamlined fleet management.

## How It Works with Plaspy

When integrated with Plaspy, the Arnavi L2 streams position, status and sensor data to the platform for real‑time tracking, alerts and historical reporting. Plaspy ingests the device’s telemetry and exposes it through dashboards, geofencing, route playback and automated reports — enabling fleet managers to act on location and behavior data immediately.

- Real‑time location and telemetry updates transmitted over GSM \(2G/GPRS\) and processed by Plaspy for mapping and alerts.
- Ignition status reporting via the discrete positive input for engine‑on/off events and driver session tracking.
- Universal I/O that can be used for immobilizer/relay control or alarm output, supporting anti‑theft workflows when commanded through Plaspy.
- Bluetooth sensors support \(up to 5 devices\) for temperature, door/guard tags, and other BLE telemetry that Plaspy can display and alert on.
- Local black‑box buffering \(8 MB\) ensures records are retained during temporary connectivity loss and uploaded to Plaspy when the link is restored.

## Technical Overview

| Connectivity | GSM \(2G/GPRS\) |
| --- | --- |
| GNSS | GPS, GLONASS, Galileo, BeiDou, QZSS \(built‑in GNSS antenna\) |
| Bluetooth | Bluetooth Low Energy \(BLE\) — supports up to 5 wireless sensors |
| Power & Battery | Operating voltage 8–40 V; low average consumption \(sleep–active 2–40 mA\); no internal backup battery |
| Inputs & Outputs | One discrete positive input \(e.g., ignition\); one universal I/O with inductive spike protection \(output up to 500 mA\); one discrete negative input; power input protection up to 60 V |
| Local Storage | Black box: 8 MB \(~up to 12,000 records\) |
| Interfaces | Nano‑SIM / SIM‑chip slot; USB interface for configuration; 60 cm wiring harness for cigarette lighter installation |
| Sensors | Built‑in accelerometer \(motion and EcoDriving analysis\), internal temperature sensor |
| Protocols & Servers | Supported protocols: INTERNAL, EXTERNAL, USER\_AG, EGTS; reports to two monitoring servers |
| Remote Management | Web remote configuration and firmware update, PC configuration tool over USB, mobile app via Bluetooth/USB |
| Form Factor | Cigarette lighter plug; dimensions 61 × 42 × 13 mm; weight 35 g |
| Excluded Interfaces | No Wi‑Fi; no CAN, RS232, RS485, UART or 1‑WIRE |
