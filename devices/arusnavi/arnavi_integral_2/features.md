# Arusnavi - Arnavi Integral 2 Features

This page provides a public feature overview of the Arusnavi Arnavi Integral 2 and how its capabilities relate to use with Plaspy. It focuses on user facing functions such as real time location reporting, geofencing, and general remote monitoring that Plaspy can surface for operational visibility.

Exact feature behavior and available telemetry can vary by firmware revision, hardware variant, installation method, and manufacturer implementation. For the most current device specific details, consult Arusnavi documentation and release notes.

## Feature Overview

The Arnavi Integral 2 is described as a navigation controller intended for remote monitoring of mobile objects. In practice this makes it useful for tracking location, observing movement, and receiving boundary alerts when used with a compatible platform such as Plaspy.

- Real time location reporting for continuous visibility of mobile objects
- Geofencing capabilities to define virtual boundaries and receive alerts
- Compatibility with third party tracking platforms for flexible deployment
- Compact durable design for discreet installation on assets
- Designed for extended monitoring intervals with long battery life

## Core Features of Arusnavi - Arnavi Integral 2

- Remote monitoring of mobile objects for tracking and oversight
- Real time tracking data suitable for live location displays
- Geofencing support to register entry and exit events for predefined areas
- Broad software compatibility to integrate with platforms like Plaspy
- Compact and robust form factor intended for everyday field use
- Simple installation and placement for discreet asset monitoring
- Extended operational endurance enabled by long battery life

## How These Features Work with Plaspy

When connected to Plaspy, the Arnavi Integral 2 can provide monitored location and event information that is presented through the Plaspy platform for operational use. Plaspy is designed to accept device data and make those device features visible to users without requiring special per device setup in most cases.

- Live position displayed on Plaspy maps for situational awareness
- Geofence events available as alerts and timeline items when reported by the device
- Historical position logging to review past routes and movement for each tracked object
- Device state and battery information shown in Plaspy if the tracker reports those values
- Standardized device handling so a single platform view can include Arnavi Integral 2 units alongside other compatible trackers

## Typical Use Cases

- Rental and shared asset oversight to verify return and usage zones

- General purpose tracking for mobile objects where discreet installation is required
