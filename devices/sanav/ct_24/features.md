# Sanav - CT-24 Features

This page provides a public overview of the Sanav CT-24 feature set and how those capabilities are commonly used with Plaspy. It focuses on user facing functions and operational value — highlighting what the device is designed to do and how Plaspy can make those capabilities visible and actionable for tracking, monitoring, and reporting.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. Use this page as a practical orientation for Plaspy compatibility and refer to the manufacturer for device specific technical details and the latest firmware information.

## Feature Overview

The Sanav CT-24 is a compact tracker designed for long battery operation and discreet installation. Its design enables placement under a vehicle dashboard without requiring an external antenna while still offering inputs and sensors useful for a variety of tracking scenarios.

- Long battery operation suited for extended deployments and infrequent maintenance
- High GPS and GSM sensitivities allowing reliable reception even when installed under a dashboard
- Operation without an external antenna for discreet vehicle or asset installations
- Two sets of open I O for integration with external contacts and simple inputs
- Built in vibration sensor and reed switches for movement and contact events
- Internal memory and backup battery to retain data and continuity when connectivity is temporarily lost

## Core Features of Sanav - CT-24

- Long battery life for extended tracking intervals and reduced maintenance
- High GPS sensitivity to maintain location fixes in obstructed installations
- High GSM sensitivity for improved cellular connectivity in difficult locations
- Ability to function without an external antenna for discreet mounting
- Two sets of open I O for custom input wiring and external contact monitoring
- Vibration sensor for movement detection and basic tamper awareness
- Reed switches for door or contact change detection
- Internal memory and backup battery to store data and preserve basic operation during interruptions

## How These Features Work with Plaspy

Plaspy receives and displays the CT-24 reporting data so operators can view location, input events, and device status in a centralized platform. Plaspy also automatically detects the tracker protocol to simplify initial integration and bring device data into maps and event streams.

- Real time and periodic location updates shown on Plaspy maps for live tracking and replay
- Input events from vibration sensors and reed switches appear as discrete events or alarms in Plaspy
- Internal memory allows the CT-24 to store positions offline and forward them to Plaspy when network access is restored
- Device status indicators such as battery condition and backup battery presence are visible in Plaspy device panels
- Plaspy auto detects the tracker protocol to streamline device onboarding and reporting
- The CT-24 can be pointed to Plaspy server endpoints so data flows into the platform for visualization and analysis

## Typical Use Cases

- Vehicle tracking where discreet installation under a dashboard is preferred
- Asset or container tracking for long term monitoring with minimal power maintenance
- Personal or pet tracking where compact form factor and long battery life matter
- Covert or security monitoring using internal vibration and reed switch events
- Unattended deployments that need internal memory for temporary offline recording
- Situations that require voice capable devices when audio or call features are useful
