# Sanav - CT-58 Features

This page provides a public feature summary for the Sanav CT-58 and explains how its capabilities map to Plaspy for location visibility and event awareness. It is intended to describe practical, user facing functions and how those functions are useful when the CT-58 is used with the Plaspy platform.

Exact feature availability and behaviour for a particular CT-58 can vary by firmware level, hardware revision, installation method, and manufacturer implementation. Use this page as a general feature guide and consult the manufacturer documentation and your device settings for the final, device specific details.

## Feature Overview

The Sanav CT-58 is a compact GPS tracker designed for vehicle, container, and portable asset tracking. It emphasizes movement detection through a high sensitivity vibration sensor and offers optional panic button reporting for SOS events. Improved GPS and GSM reception and a rugged small enclosure make the unit suitable for discreet installations and field use.

- Miniature form factor suitable for discreet vehicle or asset installation
- High sensitivity vibration sensor for movement detection and reporting
- Optional external panic button to trigger an SOS style report
- Improved GPS and GSM reception for more reliable location updates
- Real time location updates and event reports for operational monitoring

## Core Features of Sanav - CT-58

- Compact and robust enclosure for easy installation and concealment
- High sensitivity vibration sensor to detect movement and trigger reports
- Optional external panic button available to send SOS reports when pressed
- Designed for vehicle tracking as well as container and general asset monitoring
- Improved GPS reception to support accurate position reporting
- Improved GSM reception to support reliable communication back to platforms
- Lightweight design enabling installation in tight spaces

## How These Features Work with Plaspy

Plaspy receives location and event reports from compatible trackers like the CT-58 and presents them through map views, event lists, and historical traces. Plaspy automatically detects the tracker protocol and accepts device reports so that movement events and SOS alerts are visible to operators without extensive manual protocol setup.

- Location updates from the CT-58 appear on Plaspy maps for real time position awareness
- Vibration triggered movement reports show as events that can support theft or movement detection workflows
- SOS or panic button presses are recorded as alert events so teams can respond to emergency notifications
- Historical position data and event timestamps are retained in Plaspy for audit and review
- Plaspy detects the tracker protocol automatically and supports TCP or UDP device reports on the platform entry point to simplify setup

## Typical Use Cases

- Movement based alerts for theft detection or unauthorized use

- Short term placement for route verification or delivery tracking
