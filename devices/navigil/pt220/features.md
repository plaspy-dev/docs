# Navigil - PT220 Features

This page provides a public feature overview of the Navigil PT220 and how its capabilities map to the Plaspy platform. It is written for users who want to understand the practical functions of the PT220 when used for location reporting, event reporting, and basic device monitoring inside Plaspy.

Exact feature availability and behavior depend on firmware version, hardware revision, installation configuration, and how the manufacturer has implemented specific functions. For the most current device-specific details consult the manufacturer documentation referenced below.

## Feature Overview

The PT220 is a compact, portable GPS tracker built for personal tracking and simple deployments. It emphasizes straightforward setup, rechargeable power, and flexible reporting modes that suit both continuous tracking and on-demand location queries.

- Location tracking for personal safety and situational awareness
- Simple deployment by inserting a SIM card and configuring access rights
- Rechargeable internal battery with USB or wall charger convenience
- Two reporting modes: automatic GPRS reporting and manual SMS query mode
- Intelligent power management with low-power sleep and multiple wake triggers

## Core Features of Navigil - PT220

- Location reporting designed for tracking people and personal items
- Easy setup workflow using a SIM card and access configuration
- Rechargeable internal battery usable with a USB cable or wall charger
- Automatic GPRS mode for periodic and event driven reporting
- Manual SMS mode enabling location queries via SMS or phone call
- Event reporting capability such as geofence breach notifications when configured
- Power saving with low-power sleep modes and wake triggers from scheduled events, motion, or external input

## How These Features Work with Plaspy

Plaspy ingests location and event reports from compatible trackers and displays them for monitoring, history, and operational oversight. When used with the PT220, the platform can present periodic position updates and highlight configured events that the device reports.

- Device positions from automatic GPRS reports appear in Plaspy as live or recent location updates
- Event driven messages such as geofence breaches are visible in Plaspy as time stamped events
- Manual query workflows can be used when the device is in SMS mode and later reconciled with Plaspy history when GPRS reports are available
- Plaspy shows device online status and recent activity to help with operational monitoring
- Plaspy automatically detects many tracker protocols to simplify adding compatible devices

## Typical Use Cases

- Personal safety tracking for children, elderly relatives, or care recipients
- Short term tracking for luggage, backpacks, or handheld items during travel
- Lone worker check ins and basic presence monitoring in the field
- Temporary or ad hoc deployments where quick setup and portability are important
- Situations where scheduled reporting and low power operation extend time between charges

## Feature Availability Notes

- Firmware differences can enable or change reporting intervals and event behavior
- Hardware revisions and regional variants may alter supported features or power characteristics
- Installation and device placement can affect motion detection and GPS reception
- Some features such as geofence notifications require both device-side configuration and platform-side handling
- Always verify the behavior of a given device unit against the manufacturer documentation and release notes

## Why Use Plaspy with These Features

Using the PT220 together with Plaspy gives organizations and individuals a central place to view position history, monitor event activity, and manage multiple devices. Plaspy aggregates periodic and event-driven reports so teams can maintain situational awareness without managing multiple raw message streams.
