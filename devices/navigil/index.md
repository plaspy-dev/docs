# Navigil

Navigil is a recognized name in the GPS tracking and telemetry space, offering hardware designed for location, telemetry and remote monitoring. This page explains how Navigil devices can work with Plaspy, what to expect from device capabilities, and how to find the right device for your tracking needs. Use the model catalog below to jump straight to devices compatible with Plaspy and to view images and links.

## How Navigil devices work with Plaspy

Navigil devices transmit position and telemetry data over mobile networks to tracking platforms. Plaspy ingests those data streams, decodes the device messages, and presents location, status, and alerts in a unified interface. Integration is typically achieved by configuring the device with Plaspy connection settings and registering the device identifier in Plaspy so the platform can associate incoming messages to the right asset.

On Plaspy you can:
- View live position updates and location history
- Configure alerts and geofences based on device telemetry
- Monitor battery status and other available sensors
- Consolidate data from multiple devices into fleet dashboards

If you need specific setup steps for a model, open the model in the catalog above and follow the device page for recommended configuration tips.

## Common features found in Navigil devices

While features vary across models, Navigil devices compatible with tracking platforms commonly offer a combination of the following capabilities:
- GNSS based positioning for precise location data
- Cellular connectivity for data uplink to cloud platforms
- Basic telemetry channels such as digital inputs and analog sensors
- Power and battery monitoring for portable installations
- Support for configuration of reporting intervals and sleep modes

Refer to the individual model pages in the catalog for exact feature sets and supported sensors.

## Typical use cases for Navigil GPS trackers

Navigil hardware is used across many monitoring scenarios. Common use cases include:
- Fleet vehicle tracking and route history
- Asset tracking for trailers, containers, and equipment
- Remote asset telemetry and status monitoring
- On demand location services for field teams and service vehicles

Plaspy helps convert device data into actionable insights across these scenarios with mapping, alerts, and reporting tools.

## Why use Plaspy with Navigil devices

Plaspy focuses on giving integrators and fleet managers a single platform to manage devices and visualize telemetry. When used with Navigil devices, Plaspy provides:
