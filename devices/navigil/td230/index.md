# Navigil - TD230

![TD230](./logo.jpg)

The Navigil TD230 is an OEM tracking device designed to help businesses bring GPS tracking capabilities to market quickly. It ships with production ready TG2 firmware and a rebrandable user interface membrane, and offers a range of membrane layouts with different button and LED options to fit varied product designs. The TD230 emphasizes quick time to market and flexible hardware personalization for companies that want to embed tracking into their own products.

As a Plaspy compatible device, the TD230 aligns with typical fleet and asset monitoring workflows supported by modern telematics platforms. Its built in features such as geofences, vehicle state monitoring, periodic server reporting, power saving logic, over the air configuration, and an available SDK make it straightforward to integrate into Plaspy for location visibility, alerting, and operational reporting. The combination of OEM customization and production software makes the TD230 a practical choice for organizations deploying tracking hardware alongside Plaspy.

## Key Highlights

- OEM friendly design that supports rapid product integration and rebranding
- Production ready TG2 firmware with common tracking features like geofences and state monitoring
- Customizable membrane with multiple button and LED layouts for tailored user interfaces
- Over the air upgrade capability for firmware and configuration files to keep devices current
- SDK available for further device level customization and feature extension
- Intelligent power management and low power sleep modes for extended field operation
- Server reporting designed for periodic communication with back end platforms

## How It Works with Plaspy

The TD230 can be integrated into Plaspy to provide location and operational data from deployed devices to the Plaspy platform. Because the device supports production firmware features and periodic server reporting, Plaspy can surface location, event, and status information for fleet and asset management use cases.

- Live and historical location visibility on Plaspy maps and timelines
- Geofence event forwarding and alerting for perimeter and route monitoring
- Vehicle or asset state reporting to aid operational oversight and dispatching
- Regular server reports that enable trip playback and usage reporting in Plaspy
- Power saving behavior that balances reporting frequency and battery life for remote deployments
- OTA capable firmware and configuration that complements device management workflows in a platform environment

## Typical Use Cases

- OEM integration when manufacturers want to add GPS tracking to their own products
- Fleet tracking for light vehicles and service fleets requiring location and state awareness
- Remote asset monitoring where long battery life and periodic reporting are important
- Rental and shared equipment tracking with custom UI requirements for end users
- Deployments that need a production ready firmware baseline with room for custom enhancements via SDK

## Why Choose This Tracker with Plaspy

The TD230 is a sensible option for businesses that need an off the shelf OEM tracker with production level firmware and options for visual rebranding. Its firmware feature set covers common fleet and asset tracking needs while the SDK and membrane customization allow product teams to tailor behavior and user interaction to their service offering. For organizations using Plaspy, the TD230 provides the device side capabilities that map well to platform features like mapping, alerts, reporting, and device management.
