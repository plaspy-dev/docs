# QuecLink - GV300 Features

This page provides a public feature overview of the QuecLink GV300 and how its capabilities integrate with Plaspy for vehicle tracking and telemetry. It focuses on user facing features, typical operational uses, and how data from the GV300 can be used inside Plaspy while avoiding device configuration and sensitive details.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method, and how the manufacturer implements specific functions. For device specific parameters and the most current technical details, consult official QuecLink documentation and release notes.

## Feature Overview

The GV300 is a compact vehicle tracker aimed at demanding telematics deployments where reliable GNSS position, flexible wired inputs and robust communications are required. When paired with Plaspy the tracker delivers location, event reporting and telemetry that support real time monitoring and automated workflows.

- High sensitivity u blox GNSS for consistent position reporting and reliable location data
- Quad band cellular connectivity with TCP UDP and SMS transport for resilient reporting
- Multiple wired inputs and outputs plus RS232 for accessory and telemetry integration
- CAN data capture support via compatible CAN adapter to ingest vehicle bus data
- Configurable alarms and event reporting such as geo fence tow antenna disconnect and crash detection
- Internal backup battery and wide vehicle grade operating voltage for power loss resilience

## Core Features of QuecLink - GV300

- u blox GNSS receiver delivering high sensitivity positioning suitable for vehicle tracking
- Quad band GSM GPRS connectivity with support for TCP UDP and SMS reporting modes
- Ignition detection via dedicated positive trigger input for trip and engine state monitoring
- Multiple digital inputs and outputs plus analog inputs for wired sensor and control integration
- CAN data capture capability when used with a CAN adapter to surface vehicle bus frames
- RS232 serial interface for accessory telemetry and third party device integration
- Configurable alarms including geo fence tow antenna disconnect crash detection and driving behavior monitoring

## How These Features Work with Plaspy

Plaspy ingests the GV300 telemetry and event reports to deliver location awareness, alerts and operational dashboards. Device data feeds into Plaspy so fleets and security teams can monitor status and act on events without needing per device custom code.

- Real time GNSS positions and scheduled reports appear in Plaspy maps and history views
- Digital and analog input changes are visible as events and attributes for monitoring and reporting
- CAN frames and decoded vehicle telemetry can feed Plaspy dashboards when a CAN adapter is used
- Device alarms such as geo fence alerts tow and antenna disconnect are usable for automated notifications
- Remote output control and OTA managed outputs can be reflected in Plaspy workflows where supported by the device firmware

## Typical Use Cases

- Fleet management with live tracking scheduled reporting and route oversight
- Anti theft and stolen vehicle recovery using ignition detection tow alerts and remote output control
- Cold chain and environmental monitoring via partner sensors integrated through analog inputs or CAN
- Insurance telematics including crash detection and driving behavior event capture for analysis
- Vehicle telemetry and fuel monitoring using analog inputs and CAN data capture
- Secure asset tracking where wide operating voltage and backup power enhance reliability
