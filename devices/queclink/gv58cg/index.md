# Queclink GV58CG GNSS Telematics Tracker — Plaspy compatible

The GV58CG is a compact, cost-effective GNSS tracker purpose-built for fleet management and vehicle security. Designed for easy integration with Plaspy, the GV58CG delivers real-time tracking, telemetry and essential vehicle control functions in a small form factor. Its LTE Cat 1 connectivity with 2G fallback and internal multi-antenna design provides reliable data transmission across broad network coverage, making it ideal for fleet management, car rental and stolen vehicle recovery applications.

Integrators and fleet operators will appreciate the device’s practical I/O and accessory support: ignition detection, fuel cut-off control, a single analog input for fuel or sensor readings, and driver identification via 1-wire iButton or Bluetooth Low Energy \(BLE\). Native BLE 5.2 lets the GV58CG work with temperature, humidity, fuel level and tilt sensors from Queclink and partners — extending telemetry and anti-theft use cases when used together with Plaspy for centralized monitoring and reports.

## Key Highlights

- Plaspy compatible for seamless real-time tracking and fleet management integration.
- LTE Cat 1 with EGPRS fallback ensures continuous connectivity and timely telemetry delivery.
- High-sensitivity u‑blox GNSS \(GPS/GLONASS/Galileo/BeiDou\) with \<2.0 m CEP position accuracy.
- Ignition detection and fuel cut-off control enable anti-theft and immobilizer workflows.
- BLE 5.2 and 1‑wire support for driver ID and BLE sensor-based fuel monitoring, temperature and tilt sensing.
- Compact, covert-ready form \(86.7 x 46.4 x 18.1 mm\) with internal Li‑Polymer backup battery for power-loss reporting.
- Advanced alarms and reporting \(geo-fence, tow, crash detection, scheduled reporting\) for proactive fleet telemetry.

## How It Works with Plaspy

When paired with Plaspy, the GV58CG streams location and vehicle telemetry to your Plaspy dashboard using standard telematics protocols \(TCP, UDP, SMS\). Plaspy ingests position updates, status events and sensor telemetry, enabling real-time tracking, alerts, analytics and historical reports for fleet managers.

- Real-time location and telemetry updates via LTE Cat 1 \(with 2G fallback\) to Plaspy for continuous tracking.
- Ignition detection \(positive digital input\) reported to Plaspy for engine-on/off events and driver shift logs.
- Fuel monitoring via single analog input plus optional BLE fuel level sensors; Plaspy displays fuel trends and alerts.
- Remote immobilizer and fuel cut-off control can be executed through configurable digital output commands issued from Plaspy.
- BLE sensors and iButton driver identification integrate into Plaspy workflows for asset environment monitoring and driver attribution.
