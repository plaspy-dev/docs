# QuecLink - GL505 Features

This page describes the public feature context for using the QuecLink GL505 tracker with Plaspy. It focuses on practical capabilities you can expect to use inside Plaspy for livestock and remote asset monitoring rather than low level configuration details.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and the manufacturer's implementation. Always compare the information here with the device's official manufacturer documentation for the most current device-specific details.

## Feature Overview

The GL505 is a compact, battery powered GPS tracker designed for long deployments in pastoral and remote environments. Integrated with Plaspy, it provides location visibility, configurable alerts, and long standby life to minimize field maintenance while supporting common livestock and asset monitoring workflows.

- High precision GNSS location reporting to track animal or asset position over time.
- Configurable geo fences that trigger alerts when an animal or asset enters or leaves defined areas.
- Motion based inactivity alerts to notify owners when movement stops for a configured period.
- Rugged, weatherproof IPX7 enclosure designed for concealed collar mounting and tamper resistance.
- Extremely long standby battery life designed to reduce frequency of battery changes for remote deployments.

## Core Features of QuecLink - GL505

- GNSS location reporting for reliable position updates and movement history.
- Configurable geo fence support for perimeter and area monitoring.
- Motion sensor with inactivity detection to generate health or welfare alerts.
- Tamper friendly, screw mounted enclosure suitable for installation inside animal collars.
- Weatherproof IPX7 construction for durability in wet and dusty pastoral settings.
- Optimized battery usage and reporting profiles to extend time between maintenance.
- Designed compatibility with Plaspy for centralized monitoring and alerting.

## How These Features Work with Plaspy

When the GL505 is used with Plaspy, location and event data are forwarded into the Plaspy platform so teams can monitor positions, receive alerts, and review historical telemetry for operational decisions and recovery actions.

- Real time and historical location playback inside Plaspy for situational awareness and audits.
- Geo fence events appear in Plaspy so managers can create rules and notifications for perimeter breaches.
- Inactivity alerts are delivered through Plaspy to highlight potential injury, illness, or entrapment.
- Tamper or mounting status can be monitored in Plaspy to detect possible device loss or interference.
- Plaspy automatically detects compatible tracker protocols and presents incoming telemetry for integration into workflows.

## Typical Use Cases

- Anti theft and recovery of livestock through geo fence alerts and location history.
- Animal welfare monitoring using inactivity detection to identify individuals that stop moving.
- Remote herd management across large pastures with reduced need for physical checks.
- Pasture rotation monitoring and movement analytics to inform grazing decisions.
- Long duration tracking of static rural assets where weatherproofing and battery life are critical.
