# QuecLink - GV355CEU

![GV355CEU](./tracker.png)

The Queclink GV355CEU is a high‑precision LTE vehicle GPS tracker engineered for demanding fleet management and regulatory compliance applications. As a Plaspy compatible device, the GV355CEU delivers robust real‑time tracking, comprehensive vehicle telemetry and remote tachograph retrieval so fleets can monitor vehicle location, driver hours and critical diagnostic data from a single platform.

Built for mixed fleets and intensive use, the GV355CEU combines LTE Cat‑1 connectivity with 2G fallback, a u‑blox GNSS engine and wide vehicle interface support \(dual CAN, J1708, K‑Line and OBDII\). When integrated with Plaspy, this tracker enables continuous position accuracy under 2 meters, automated DDD file downloads from supported tachographs and actionable alerts for anti‑theft, driver behaviour and maintenance workflows.

## Key Highlights

- Plaspy compatible GPS tracker offering reliable real‑time tracking and fleet management visibility.
- Advanced tachograph support — remote DDD file download for driver hours and compliance workflows.
- Dual CAN, J1708 and OBDII interfaces for rich telemetry and diagnostic trouble code \(DTC\) extraction.
- High‑precision GNSS \(GPS/GLONASS/Galileo/BeiDou\) with autonomous accuracy under 2 meters for precise routing and geofencing.
- BLE 5.2 and 1‑Wire support for Bluetooth sensors, temperature probes and driver ID \(iButton\) integration.
- Compact, rugged form factor with internal antennas and a backup battery to maintain reports during power events.
- Event and alarm suite: geo‑fencing, tow alarm, harsh driving/crash detection and configurable input alarms for anti‑theft protection.

## How It Works with Plaspy

When paired with Plaspy, the GV355CEU streams location and vehicle telemetry to the platform over LTE/2G using TCP/UDP or SMS. Plaspy ingests GNSS positions, CAN‑bus parameters and tachograph DDD files so fleet managers gain a unified view of vehicle location, driver hours, diagnostics and status events. Alerts and reports are generated in Plaspy from device events, scheduled reports and geo‑fence triggers.

- Real‑time location and telemetry updates transmitted to Plaspy for live tracking and historical playback.
- Remote tachograph \(DDD\) file downloading from D8 and CAN‑interface tachographs for compliance reporting.
- Ignition and digital/analog input status \(doors, alarms, PTO\) used by Plaspy to trigger rules and workflows.
- Fuel monitoring and engine parameters available via CAN/OBDII when the vehicle exposes those signals, enabling fuel monitoring and efficiency reporting.
- Remote output control to support immobilizer or engine cutoff workflows when integrated through Plaspy commands and device outputs.
- Bluetooth sensors and 1‑Wire probes feed temperature, driver ID and accessory data into Plaspy for cargo or driver management.
