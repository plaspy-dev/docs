# QuecLink - GB130MG Features

This page covers the public feature context for using the QuecLink GB130MG tracker with Plaspy. It summarizes the device capabilities that are relevant when deploying the GB130MG to stream location and telemetry into Plaspy for fleet management, usage based insurance, anti theft workflows, and related telematics use cases.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific technical details, configuration options, and the latest firmware notes consult official QuecLink documentation and release notes.

## Feature Overview

The GB130MG is a compact, waterproof LTE vehicle tracker designed for large scale telematics and UBI deployments. It emphasizes reliable GNSS positioning, high fidelity motion sensing, and durable packaging for exposed or under hood mounting, while supporting Bluetooth accessory integration for extended telemetry.

- Global LTE Cat M1 and NB2 cellular connectivity with 2G fallback to maintain reporting in varied coverage areas.
- Multi constellation u‑blox GNSS positioning with reported autonomous accuracy better than 2 meters for dependable location updates.
- Integrated BLE 5.2 for connecting external sensors and accessories to extend telemetry alongside position data.
- Rugged IP67 enclosure and an internal high temperature NiMH backup battery for harsh environment installations.
- High rate 6‑axis accelerometer sampling up to 400 Hz with pre and post event capture for crash analytics and incident reconstruction.

- Plaspy compatible tracker designed for real time tracking and large scale telematics deployments.

## How These Features Work with Plaspy

When connected to Plaspy, the GB130MG streams GNSS positions, motion events, and Bluetooth sensor telemetry so platform users can monitor location, behavior, and incidents in near real time. Plaspy ingests the device data and exposes it through maps, reports, alerts, and workflows appropriate for fleet and insurance operations.

- Live location updates and historical tracks visible on Plaspy maps for dispatching and asset oversight.
- High frequency accelerometer events surfaced as incident alerts and attached to event records for reconstruction and claims workflows.
- BLE sensor readings correlated with GNSS positions so environmental or cargo telemetry can be reviewed alongside location history.
- Trip detection and vehicle state derived from device telemetry to power trip reports, idle detection, and utilization metrics.
- Tow alarm and ignition related events integrated into platform alerts and operator workflows for anti theft response.
- Scheduled and rule driven reporting that uses device position and telemetry to trigger notifications and generate reports.
