# QuecLink - GMT100 Features

This page covers the public feature context for using the QuecLink GMT100 tracker with Plaspy. It summarizes the GMT100 capabilities relevant to fleet and asset tracking and explains how those capabilities can be used within Plaspy for location visibility, motion awareness, and event reporting.

Exact feature availability for any installed unit can vary depending on firmware revision, hardware revision, the specific installation and wiring, and manufacturer implementation choices. Users should treat this page as a functional overview and consult manufacturer documentation for device specific technical details.

## Feature Overview

The GMT100 is designed for low current drain applications such as motorcycles and boats, with an emphasis on reliable location fixes, configurable reporting, and long standby time. It combines a sensitive GPS receiver, cellular data reporting, motion detection, and configurable I O to support periodic or real time monitoring workflows.

- Accurate and fast location fixes from a high sensitivity GPS receiver for reliable tracking in mobile environments
- Low power design and multiple power modes to extend standby time for vehicles with limited power budgets
- Built in 3 axis accelerometer for motion detection and power saving based on activity
- Quad band GSM GPRS support for global cellular coverage and server reporting
- Multiple I O interfaces for integration with external sensors and installation specific monitoring
- Support for detailed report types including emergency alerts, geo fence crossings, low battery notices, and scheduled position reports

## Core Features of QuecLink - GMT100

- High sensitivity GPS receiver for fast time to first fix and consistent location data
- 3 axis accelerometer enabling motion detection and power management strategies
- Quad band GSM GPRS connectivity for wide cellular coverage
- Multiple I O interfaces to support monitoring and simple control integrations
- Configurable power consumption and three working power modes to match operational needs
- Support for scheduled GPS position reports and a range of event reports
- Water resistant design rated to IPX6 for outdoor marine and exposed vehicle use
- Wide operating voltage range to accommodate diverse vehicle power systems

## How These Features Work with Plaspy

Plaspy ingests standard location and event reports from compatible trackers and presents them in dashboards, maps, and alert feeds. The GMT100 reports location, motion events, and status updates that Plaspy uses to provide operational visibility and historical playback.

- Location updates appear on live maps and position history timelines in Plaspy for route review and playback
- Motion detection events from the accelerometer can be used to mark vehicle activity and trigger alerts in Plaspy
- Scheduled position reports and low battery notifications are surfaced as events so operators can prioritize follow up
- Geo fence boundary reports and emergency alerts are treated as discrete events that can generate notifications and audit logs
- Plaspy automatically detects the tracker protocol and accepts standard reports so the GMT100 can be added to a Plaspy account without custom protocol selection

## Typical Use Cases

- Motorcycle fleet tracking where low power consumption and compact installation are important
- Small boat monitoring with water resistant GPS and reliable position reporting while underway
- Periodic offline reporting scenarios where long standby time and scheduled positions are needed
- Remote asset monitoring that benefits from motion based wake up and activity reporting
- Installations requiring simple external sensor inputs tied into event reporting
- Operations that need global cellular coverage from a quad band device
