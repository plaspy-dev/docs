# QuecLink - GV620MG

![GV620MG](./tracker.png)

The Queclink GV620MG is a rugged LTE trailer GPS tracker designed for heavy-duty vehicles — trailers, tankers, refrigerated units and flatbed trucks. Built for harsh transportation conditions, the GV620MG is Plaspy compatible out of the box, providing reliable real-time tracking and telemetry for fleet management, anti-theft protection and sensor-driven monitoring across global LTE Cat M1/NB2 networks with 2G fallback.

With IP67 sealing, an integrated unique antenna solution and a high-capacity internal battery, the GV620MG keeps trailers visible on the Plaspy platform even when external power is lost. Use the device to capture GNSS position, ignition and input status, accelerometer events and BLE sensor data — all delivered to Plaspy for alerts, geo-fences, reporting and remote control of digital outputs.

## Key Highlights

- Plaspy compatible GPS tracker optimized for trailer and heavy-vehicle fleet management.
- Global LTE Cat M1 / NB2 connectivity with 2G fallback for broad network coverage and reliable real-time tracking.
- IP67 rugged enclosure and internal antennas simplify installation on trailers, tankers and refrigerated units.
- Long-life internal battery \(2 × 18650 Li-ion, 3.7V, 5800 mAh\) providing up to 120 days standby for continued tracking during power loss.
- u-blox GNSS receiver \(GPS/GLONASS/Galileo/Beidou\) with \<2 m CEP accuracy and fast TTFF for precise location data.
- BLE 5.0 for wireless temperature/humidity sensors, key fobs and BLE padlocks; extensive wired I/O for refrigeration controllers and telemetry integration.
- Configurable reporting, geo-fence alarms, accelerometer-driven motion/speed alerts and OTA control of digital outputs for immobilizer-style use cases.

## How It Works with Plaspy

The GV620MG sends GNSS positions, telemetry and sensor states to Plaspy via LTE Cat M1/NB2 \(with fallback to 2G\). Plaspy ingests location, input/output events, BLE sensor readings and battery/cellular status to provide real-time tracking, alerts and historical reports. Administrators can configure reporting intervals, geofences and alarm thresholds from Plaspy and push commands back to the unit for remote control.

- Real-time location and telemetry updates delivered to Plaspy for live map tracking and history playback.
- Ignition input and digital input/outputs reported to Plaspy for engine/run-state monitoring and remote control.
- Fuel and analog sensor telemetry can be integrated via the analog input and shown in Plaspy dashboards when paired with compatible sensors.
- OTA remote control of digital outputs enables immobilizer-like workflows and remote switching from Plaspy.
- Bluetooth sensors \(BLE 5.0\) feed temperature/humidity and proximity data into Plaspy for refrigerated trailer monitoring and access control.
