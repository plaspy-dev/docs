# Carscop - CCTR-800G-4G

![CCTR-800G-4G](./tracker.jpg)

### CCTR-800G-4G

The CCTR-800G-4G is a rugged, portable GPS tracker designed for long-duration outdoor tracking and easy integration with cloud platforms such as Plaspy. Built to withstand demanding environments, this Plaspy compatible unit combines global 2G/3G/4G connectivity with high-sensitivity GPS + BeiDou positioning, a large 6000mAh rechargeable battery, IP65 waterproofing, and a strong built-in magnet for quick, hidden mounting on metallic surfaces — making it an ideal choice for reliable real-time tracking, fleet management, and anti-theft monitoring.

Engineered for flexible deployments, the CCTR-800G-4G supports configurable upload IP/web address and an open protocol approach so integrators can point device data to Plaspy or other third-party platforms. With offline track recording, SMS locating for network fallback, OTA firmware upgrades, and multiple working modes to extend battery life, this GPS tracker offers telemetry-ready data and resilient connectivity for vehicles, assets, and personnel.

## How It Works with Plaspy

The CCTR-800G-4G connects to cellular networks and reports GNSS telemetry to a server address you configure. Because the device supports a configurable upload IP/web address and an open protocol \(with protocol change options\), it can be pointed directly to Plaspy endpoints for real-time tracking, alerts, and reporting. Plaspy receives location fixes, movement and alarm events, and battery state to display live positions, generate geofence and shock alarms, and produce fleet management reports.

- Real-time location and telemetry updates \(configurable upload interval; default 30 seconds\).
- Alarm events: shock alarm, SOS notifications, and low-battery alerts delivered to Plaspy as platform pushes or via SMS/call as backup.
- Offline track storage: internal memory holds tracks when GSM is unavailable; stored data is uploaded to Plaspy when the connection resumes.
- OTAs: firmware can be upgraded over-the-air to maintain compatibility and add features for Plaspy integrations.
- SMS locating and auto APN/GPRS configuration provide fallback reporting if platform connectivity is temporarily lost.
