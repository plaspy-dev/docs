# Carscop - CCTR-800G-4G Features

This page provides a public feature overview for the Carscop CCTR-800G-4G while used with Plaspy. It focuses on the practical tracking, telemetry, and integration capabilities you can expect when the device is pointed to a cloud tracking platform such as Plaspy, including how the device reports location and events for fleet monitoring and asset protection.

Exact feature availability and behaviour can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific configuration, firmware changelogs, and I O options consult the official Carscop documentation and your supplier before deployment.

## Feature Overview

The CCTR-800G-4G is a rugged portable GPS tracker built for long duration outdoor tracking and straightforward cloud integration. It combines multi generation cellular connectivity with dual GNSS positioning, large rechargeable capacity, and physical design features intended for covert or mobile use.

- High sensitivity GNSS positioning with GPS plus BeiDou support for reliable location fixes.
- Global multi generation cellular connectivity for continuous reporting and cloud integration.
- Large 6000mAh rechargeable battery with configurable power modes to extend operational life.
- IP65 rated enclosure and integrated magnet for quick mounting to metallic surfaces.
- Internal track recording and SMS locating as fallbacks when real time server connectivity is interrupted.

## Core Features of Carscop - CCTR-800G-4G

- Plaspy compatible through a configurable upload address and open protocol approach for direct platform integration.
- GNSS positioning using GPS and BeiDou with A GPS assistance for faster fixes.
- Multi generation cellular support covering global 2G 3G and 4G networks for broad coverage.
- Large 6000mAh rechargeable battery and multiple working modes including continuous and standby options.
- IP65 rugged enclosure with a strong built in magnet for covert mounting and outdoor use.
- Offline track recording in internal memory for later upload when network access is restored.
- OTA firmware upgrade support to maintain compatibility and add features over time.
- Alarm and notification support including shock alarm, SOS notifications to up to three numbers, and low battery alerts.

## How These Features Work with Plaspy

When configured to report to your Plaspy account, the CCTR-800G-4G delivers location fixes, movement and alarm events, and battery state so Plaspy can display live positions, produce alerts, and generate reports. Plaspy detects common tracker protocols and surfaces device telemetry for monitoring and historical review.

- Real time location and telemetry updates are visible in Plaspy according to the device upload interval and configured reporting mode.
- Alarm events such as shock alarms, SOS notifications, and low battery alerts can be delivered to Plaspy and shown as platform events or push notifications.
- Offline recorded tracks are uploaded to Plaspy when cellular connectivity is restored so historical movement is preserved.
- OTA firmware updates help keep device behaviour aligned with Plaspy integrations and feature improvements.
- SMS locating and fallback reporting can be used alongside Plaspy for redundancy when platform connectivity is temporarily unavailable.
