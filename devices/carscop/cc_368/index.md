# Carscop - CC-368

![CC-368](./tracker.JPG)

The CC-368 4G T-Box is a purpose-built GPS tracker and vehicle telematics/control unit engineered for car rental, car sharing and remote vehicle management. Plaspy compatible out of the box, the CC-368 combines global cellular connectivity \(2G/3G/4G LTE\), a U‑Blox GPS module with A‑GPS and external antennas to deliver reliable real-time tracking and robust telemetry for mixed fleets. Its integrated OBD II CANBUS interface, built-in Bluetooth \(BLE\) access and multiple I/O make it practical for turnkey keyless rental, fleet management and anti-theft workflows.

The unit is designed to simplify integration with Plaspy for live location, diagnostics and remote control. Operators gain remote immobilizer and engine start capabilities, event-based alerts \(shock, door, ACC\), internal track logging when GSM is unavailable, and API/TCP interfaces for custom server-side workflows. Packed with safety features—backup battery, power-down alarm and configurable inputs/outputs—the CC-368 is oriented toward scalable car sharing services, rental fleets and professional fleet management where secure, Plaspy compatible telematics are required.

## Key Highlights

- Plaspy compatible GPS tracker with real-time tracking across global 2G/3G/4G LTE networks.
- OBD II CANBUS reading and control for vehicle diagnostics, DTC codes and telemetry integration.
- Keyless access via NFC, built-in touch pad password module and Bluetooth \(BLE\) for flexible user entry.
- Remote immobilizer and remote engine start support for secure anti-theft and unattended rental workflows.
- External 4G and GPS antennas, internal memory for offline track recording and LBS fallback positioning.
- Wide operating voltage \(9–40V\) and support for gasoline, diesel and electric vehicles.
- FOTA firmware upgrades, TCP/IP and API access for integrators and custom fleet management systems.

## How It Works with Plaspy

When connected to Plaspy, the CC-368 streams location and telemetry so operators can monitor assets and manage remote vehicle access in real time. The device transmits GNSS coordinates, OBD-sourced vehicle parameters, alarm events and discrete I/O status to Plaspy via secure TCP/IP or SMS fallback. Plaspy-compatible integration enables scheduled and event-driven reports, geofence alerts, and remote command execution for immobilizer and engine start where authorised.

- Real-time location and telemetry updates to Plaspy for live tracking dashboards and historical routes.
- Ignition, door, shock and alarm status forwarded as events to trigger Plaspy alerts and automations.
- Fuel monitoring and engine parameters via OBD-II/CANBUS where vehicle data exposes those PIDs.
- Remote immobilizer/remote engine start via internet or SMS commands when configured through Plaspy.
- Bluetooth sensors and BLE access control supported for proximity-based unlocking and sensor data forwarding.

## Use Cases

- Unattended car rental and car sharing — secure keyless entry via NFC, touch pad or BLE and Plaspy-managed access control.
- Fleet management — centralized real-time tracking, OBD diagnostics, driver behavior logging \(G‑sensor\) and scheduled telemetry uploads.
- Anti-theft protection — remote immobilizer, cut-engine commands and alarm reporting for quick recovery and loss prevention.
- Remote diagnostics and predictive maintenance — DTC reads and vehicle parameter forwarding to Plaspy for maintenance workflows.
- Mixed-fleet deployments — supports gasoline, diesel and electric vehicles with wide voltage range and configurable power-saving modes.

## Why Choose This Tracker with Plaspy

The CC-368 offers a balanced combination of vehicle control, telemetry and secure access tailored to Plaspy-compatible deployments. For operators focused on reducing operational friction in car sharing or improving fleet visibility, the unit's OBD II CANBUS integration and BLE/NFC/touch pad access options deliver practical value: fuel monitoring and engine parameters can be read where available, ignition and immobilizer control enable rapid anti-theft response, and the internal battery plus offline logging keep data continuity even during network loss. Integrators benefit from FOTA, open TCP/IP and API interfaces to connect Plaspy to existing back-office systems and custom mobile apps, while demo platforms and ready-to-fit hardware speed time-to-market.
