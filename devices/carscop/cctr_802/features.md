# Carscop - CCTR-802 Features

This page provides a public feature overview of the Carscop CCTR-802 GPS tracker and how its capabilities are used with Plaspy for vehicle monitoring and operational oversight. It summarizes the device functionality that is relevant to Plaspy users and describes the practical value of each feature without reproducing sensitive configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and how the manufacturer configures the unit. Where relevant, this page notes common differences and encourages checking current manufacturer documentation for the most accurate, device specific information.

## Feature Overview

The Carscop CCTR-802 is presented as a compact, covert vehicle tracker that reports location and selected events to online platforms and stores tracks when GSM connectivity is not available. It is designed for discreet attachment to a metal surface and for use in varied weather environments.

- Real time GSM GPS tracking with GPRS upload to a web monitoring service for live location visibility
- Covert mounting with a magnet tab for discreet attachment to vehicle metal surfaces
- IP56 rated waterproof housing for use in varied environments
- Built in memory to record tracks when there is no GSM connection, with later upload when coverage returns
- Shock sensor that controls GPS activity to help conserve battery and provide move or shock alert functionality

## Core Features of Carscop - CCTR-802

- Real time location reporting via GSM and GPS to a web platform
- GPRS upload of current location for near real time monitoring
- Magnet mounting with a secret tab for covert installation on metal surfaces
- IP56 waterproof housing for exposure to splashes and outdoor use
- Built in track memory for offline recording when GSM network is unavailable
- Shock sensor that can trigger GPS and alarm related behavior for movement detection
- Preset phone numbers for SMS alerts including SOS and alarm messages
- Backup rechargeable polymer battery with quoted standby range and a car recharge option for extended operation

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible devices and displays them in a unified monitoring environment. The CCTR-802 can be used with Plaspy to centralize tracking, view history, and receive event notifications alongside other devices in a fleet.

- Real time position updates from the tracker appear on Plaspy maps for live location awareness
- Historical tracks recorded on the device are made available in Plaspy after the unit uploads stored data once connectivity is restored
- Events such as shock or movement alerts, SOS messages, and over range or over speed alerts are surfaced in Plaspy as timeline events or notifications
- Plaspy automatically detects many tracker protocols to simplify integration and receive incoming data without manual protocol selection
- Device connectivity and reporting status are visible in Plaspy to help operators identify when a unit is offline or uploading stored records

## Typical Use Cases

- Covert monitoring of transport assets where discreet installation is required
- Tracking of rental cars, taxis, or fleet vehicles where real time location is useful
- Monitoring vehicles operating in wet or outdoor conditions thanks to waterproof housing
- Recording routes in areas with intermittent GSM coverage and later uploading tracks for review
- Theft recovery support and move detection using shock sensor alerts
- Short term deployment where a maintenance free charger and backup battery enable flexible use

## Feature Availability Notes

- Feature behavior can differ across firmware versions and hardware revisions supplied by the manufacturer
- Some functions depend on how the unit is installed and whether it is connected to vehicle power or running on internal battery
- Regional GSM and GPRS coverage and operator settings can affect real time upload and SMS alert delivery
- The free web monitoring service provided by the device manufacturer may have its own terms and capabilities that differ from Plaspy
- Verify that the specific unit you receive includes the magnet mount, rechargeable battery configuration, and shock sensor as described by the manufacturer
