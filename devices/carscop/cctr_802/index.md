# Carscop - CCTR-802

<div className="device-logo">
![CCTR-802](./logo.jpg)
</div>

The Carscop CCTR-802 is a compact, covert GPS tracker designed for vehicle monitoring and recovery. Its magnetized enclosure and discreet form factor make it suitable for hidden placement on cars, buses, taxis, rental vehicles, and other moving equipment. The device supports real time GPS location upload to a web platform, includes a built in memory for recording tracks when connectivity is unavailable, and is housed in a weather resistant case for use in varied conditions.

As a Plaspy compatible device, the CCTR-802 can provide live location updates, historical track records, and event alerts into Plaspy for centralized fleet oversight. Its real time upload capability, offline track storage and alarm features make it a practical option for operators who want to add covert hardware to a Plaspy managed fleet while retaining continuity of location data and incident notifications.

## Key Highlights

- Covert magnet mounting for discreet attachment to metal vehicle surfaces
- Real time location upload to a monitoring service for current position visibility
- Waterproof housing rated for outdoor use in varied weather conditions
- Built in memory for recording tracks when GSM is unavailable to prevent data loss
- Shock sensor that can trigger alarms and help preserve battery when idle
- Preset SMS alert numbers and SOS alarm capability for immediate notifications
- Backup rechargeable battery offering extended standby between charges

## How It Works with Plaspy

When integrated with Plaspy, the CCTR-802 sends position and event information that Plaspy can present alongside other fleet assets, enabling consolidated monitoring and reporting. Plaspy ingests location uploads and alerts so operators can manage vehicles from a single platform.

- Live position display for real time fleet visibility within Plaspy
- Historical track playback using stored route data uploaded by the device
- Event and alarm notifications routed into Plaspy for timely operator response
- Geofencing and over range alerts viewable and actionable in Plaspy dashboards
- Consolidated reporting and activity summaries combining CCTR-802 data with other devices

## Typical Use Cases

- Covert recovery and surveillance of stolen or unauthorized vehicles
- Rental and fleet asset monitoring where discreet tracking is preferred
- Taxi and rideshare vehicle oversight with incident and SOS alerts
- Long term route logging for transport and delivery fleets operating across low coverage areas
- Temporary tracking of equipment or trailers that need non permanent installation
