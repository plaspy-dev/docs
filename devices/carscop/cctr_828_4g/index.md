# CCTR-828-4G

The CCTR-828-4G is a compact vehicle GPS tracker engineered for seamless Plaspy-compatible deployment in fleet management, rental, and personal vehicle monitoring. With 2G/4G \(Cat1\) cellular connectivity, high-sensitivity built-in GPS and cellular antennas, and a rechargeable backup battery, the CCTR-828-4G delivers reliable real-time tracking and essential anti-theft telemetry for cars, trucks, motorcycles and light commercial vehicles.

Designed for hidden installation and broad vehicle compatibility, this GPS tracker supports wide input voltages \(9–90V\), configurable upload behavior, motion-triggered uploads, and remote engine shutdown capability \(requires an add-on cut-off relay\). It integrates with mobile apps \(iPhone and Android\), supports open GPRS protocol for third-party platform integration, and can be pointed to Plaspy servers for real-time fleet oversight and reporting.

## Key Highlights

- Plaspy compatible: open GPRS protocol and configurable server/APN make it easy to integrate with Plaspy for real-time tracking and fleet management.
- Dual-network connectivity: supports 2G GSM and 4G \(Cat1\) for broad cellular coverage and stable telemetry uploads.
- High-sensitivity GNSS and cellular antennas built-in for discreet installation and reliable positioning indoors and outdoors.
- Rechargeable backup battery with power-down alarm and removal detection for enhanced anti-theft protection.
- Wide 9–90V input supports cars, trucks, buses, motorcycles and other vehicle classes without additional power modules.
- Motion sensor with immediate upload when movement is detected and configurable idle upload to save battery.
- Remote engine shutdown supported \(requires external cut-off relay\) for immobilizer-style control when integrated into fleet security workflows.
- Includes wiring and user manual; compact form factor makes hidden mounting straightforward.

## How It Works with Plaspy

The CCTR-828-4G sends location and telemetry to an internet server using GPRS over 2G or 4G Cat1. To make the device Plaspy compatible, point the tracker's server IP and APN to your Plaspy instance \(server/APN can be configured via SMS\). Once directed to Plaspy, the unit provides continuous real-time tracking, event-driven uploads, and history playback through Plaspy’s interface and mobile apps.

- Real-time location and telemetry updates delivered to Plaspy over GPRS \(2G/4G Cat1\).
- Power-down alarm and removal detection notify Plaspy immediately on tamper or power-cut events.
- Motion sensor triggers instant upload when movement is detected for fast anti-theft response.
- Remote engine shutdown \(immobilizer control\) is supported when the required cut-off relay is fitted and configured via Plaspy controls.
- Configurable upload behavior \(e.g., stop uploads after vehicle has been stationary for 2 minutes\) conserves device battery and network usage while maintaining critical telemetry for Plaspy analytics.
