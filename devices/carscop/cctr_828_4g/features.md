# Carscop - CCTR-828-4G Features

This page provides a public feature summary for the Carscop CCTR-828-4G and how its capabilities map to Plaspy fleet management workflows. It is intended to help operators, integrators, and prospective users understand the practical functions of this tracker when deployed with Plaspy, including the device features that are commonly used for real-time monitoring and basic anti-theft workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Where relevant this page highlights device functions documented by the manufacturer and how they are typically presented in Plaspy, but users should verify the exact feature set for a specific unit and firmware release prior to critical deployments.

## Feature Overview

The CCTR-828-4G is a compact vehicle GPS tracker designed for discreet installation and broad vehicle compatibility. It supports both 2G and 4G Cat1 cellular networks, integrated high-sensitivity GNSS and cellular antennas, and a rechargeable backup battery to preserve reporting during power interruptions. The unit is often deployed where continuous location, motion detection, and tamper awareness are required.

- Real-time GPS location reporting over GPRS using 2G or 4G Cat1 networks for continuous vehicle visibility.
- Built-in high-sensitivity GNSS and cellular antennas for reliable positioning in common urban and rural environments.
- Rechargeable backup battery with power-down alarm and removal detection to support anti-theft workflows.
- Motion-triggered and configurable upload behavior to balance immediate alerts with battery and data usage.
- Wide input voltage range for compatibility across cars, trucks, buses, and light commercial vehicles.
- Remote engine shutdown supported when an external cut-off relay is fitted and configured.

## Core Features of Carscop - CCTR-828-4G

- Dual cellular support 2G and 4G Cat1 for resilient telemetry uploads across network conditions.
- High-sensitivity GNSS receiver with integrated antenna for position fixes in typical vehicle installations.
- Rechargeable internal backup battery providing power-down alarm and removal detection.
- Motion sensor that triggers immediate uploads when movement is detected.
- Configurable reporting logic to reduce idle uploads and conserve battery and data usage.
- Wide voltage input range 9–90V to support diverse vehicle types without extra power modules.
- Remote engine shutdown capability when combined with a manufacturer recommended cut-off relay.
- SMS based configuration options for server, APN, and basic device settings.

## How These Features Work with Plaspy

When pointed to a Plaspy instance, the CCTR-828-4G delivers location and event data that Plaspy ingests for display, alerts, and history. Devices can be configured to report to Plaspy servers and Plaspy will present the incoming telemetry as live position updates and events for fleet operators to act on.

- Real-time location updates and history playback visible in Plaspy dashboards and maps.
- Motion and power-down events reported to Plaspy so tamper and movement can generate alerts.
- Configurable upload parameters reflected in Plaspy as reduced idle reports and focused event reporting.
- Remote immobilization support surfaced in Plaspy when the vehicle is equipped with the required cut-off relay and proper configuration.
- Devices can be directed to the Plaspy server domain and Plaspy will detect the protocol to begin processing incoming data.
