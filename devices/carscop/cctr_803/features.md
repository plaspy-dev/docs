# Carscop - CCTR-803 Features

This page presents the public feature context for the Carscop CCTR-803 when used with Plaspy. It summarizes the device capabilities that are relevant for location visibility, alarms, and basic remote functions and explains how those capabilities can be used within the Plaspy fleet management platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific configuration steps, firmware details, or the latest technical specifications consult the official Carscop documentation.

## Feature Overview

The CCTR-803 is a vehicle GPS tracker focused on real time position reporting, SMS based control and alerts, and remote software maintenance. Its combination of GPS and LBS locating, SMS reporting options, and platform reporting makes it suitable for fleet and individual vehicle monitoring.

- Real time GPS and LBS positioning for flexible location reporting
- SMS based location and control including Google map links or text descriptions
- Built in antenna for discreet installation and an external microphone for in vehicle audio monitoring
- Remote software upgrade over GPRS and automatic APN configuration options
- Multiple alarm types delivered to preset phone numbers and to a tracking platform
- Built in battery backup and local track memory to maintain records during network loss

## Core Features of Carscop - CCTR-803

- GPS and LBS hybrid locating which enables position reporting with or without GPS signal
- Built in 4 band GSM and u Blox GPS module with A GPS assisted locating for faster fixes
- SMS location and call to locate capabilities that work without a server
- Location reporting by SMS with Google map link or plain text location description
- Online GPRS software upgrade and the ability to auto download and configure APN and GPRS settings
- Alarms including SOS alerts, move alarm, shock alarm, and power down alarm sent by SMS and to a platform
- Built in rechargeable battery for backup and local memory to record tracks when GSM is unavailable
- Remote control features such as preset phone numbers, SIM balance check via SMS, and remote engine cutoff functionality

## How These Features Work with Plaspy

When connected to Plaspy, the CCTR-803 can report vehicle positions and alarm events into the platform for centralized monitoring and history. Plaspy detects compatible tracker protocols automatically and accepts device reporting so fleet managers can combine live visibility with stored history.

- Position updates and alarm notifications appear on Plaspy maps and event timelines for each device
- SMS based reporting options supplement GPRS uploads, giving alternative reporting paths if needed
- Platform history storage preserves recorded tracks and events for operational review and compliance
- Alarms and SOS events sent to the platform can trigger notifications and be routed to assigned users
- Remote features reported by device status messages are visible in Plaspy for oversight and diagnostics

## Typical Use Cases

- Fleet location and route monitoring for cars, trucks, taxis, and buses
- Theft deterrence and recovery support using remote alerts and last known position reporting
- Rental and sharing fleets that need discreet installation and remote oversight
- School bus and transport fleet tracking with event logging and alarm reporting
- Remote monitoring of vehicles that operate in areas with intermittent GPS coverage using LBS fallback
- Use cases that require remote firmware updates and APN management over the air

## Feature Availability Notes

- Feature availability may depend on the shipped firmware and any regional hardware variants
- Some functions require specific SIM and mobile network support such as GPRS uplink or SMS services
- Installation type and wiring choices can affect backup battery behavior and reporting of power down events
- Manufacturer configuration options set by SMS or during setup can enable or disable particular reporting modes
- Plaspy integration typically uses the device upload settings provided by the tracker and may require device configuration
