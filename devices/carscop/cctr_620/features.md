# Carscop - CCTR-620 Features

This page provides a public facing summary of the Carscop CCTR-620 feature set and how those capabilities can be used with Plaspy for location monitoring and alerting. It is intended to describe practical, user facing functions and to explain the typical ways the device reports position and events into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, SIM and network conditions, and manufacturer implementation choices. For device specific technical details and the latest firmware behavior consult the official Carscop documentation.

## Feature Overview

The Carscop CCTR-620 is a compact, portable tracker aimed at personal tracking scenarios such as children, pets, and small valuables. It supports multiple locate and reporting paths and includes configurable working modes to balance responsiveness and battery life.

- Web, app, SMS, and WeChat locate options for flexible user access
- Dual locate capability using GPS and LBS Cell ID to improve coverage
- Reporting via GPRS or SMS to deliver locations and alarms
- Multi working and report modes configurable by SMS for different tracking profiles
- Built in shock sensor that helps control GPS on and off to extend battery life
- On device alarms including over speed and geo fence notifications

## Core Features of Carscop - CCTR-620

- Web and mobile app locate support to view position from common platforms
- SMS locate and SMS based configuration for basic access without data
- GPS locate plus LBS Cell ID locate to provide coverage indoors and in weak GPS conditions
- GPRS reporting to send position and alarm data to a server when data service is available
- Multi working modes and flexible report modes that can be adjusted by SMS commands
- Built in shock sensor that can influence GPS activity to conserve battery
- Over speed alarm and geo fence alarm configurable via SMS or calling
- Rechargeable and replaceable Li ion battery with standby times suitable for personal use

## How These Features Work with Plaspy

The CCTR-620 is compatible with Plaspy and can report location and alarm information into the platform. Plaspy will detect supported tracker protocols automatically and present location and event data so fleet managers and personal users can monitor devices centrally.

- Devices can be registered to report into Plaspy where location updates appear on the map
- Alarms such as geo fence and over speed are shown as events in Plaspy for quick review
- Multi working and report modes affect how frequently the device sends updates to Plaspy
- When GPRS is available the tracker sends data to Plaspy for real time visibility, with SMS used as a secondary reporting or configuration path
- Plaspy automatically detects tracker protocol and supports common transport methods, allowing the device to connect to the Plaspy server domain for reporting

## Typical Use Cases

- Tracking children while providing location visibility to parents through web and mobile interfaces
- Monitoring pets and small animals during outdoor activities
- Keeping tabs on valuable personal items with portable tracking
- Supporting outdoor workers who need periodic location check ins
- Use in vehicles for basic location and alarm reporting where portability is required
- Simple installations where SMS based configuration is preferred

## Feature Availability Notes

- Features such as locate methods and alarm types depend on the device firmware and hardware revision
- Reporting behavior may change with installation choices and network availability for GPRS or SMS reporting
- Some features may be region dependent or vary with the SIM carrier and service plan
- Shock sensor behavior and GPS on off control are manufacturer implemented and may be adjusted in firmware updates
- Always check the manufacturer documentation for the most current feature list and configuration commands
