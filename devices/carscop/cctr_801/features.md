# Carscop - CCTR-801 Features

This page describes the public feature context for using the Carscop CCTR-801 GPS tracker together with Plaspy. It summarizes the tracker capabilities that are relevant for real time vehicle monitoring and operational oversight when the device is integrated with a compatible tracking platform such as Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. The information below is based on the public device description and highlights practical capabilities; for device specific and current technical details consult the manufacturer documentation.

## Feature Overview

The Carscop CCTR-801 is a compact, easy to install vehicle tracker designed for continuous location reporting and basic vehicle security functions. It is intended for covert installation or surface mounting and supports several user focused features that help maintain visibility and respond to vehicle incidents.

- Real time location tracking suitable for cars, taxis, buses, and rental vehicles
- Simple installation using 2 to 4 wires and optional attachment to a metal surface with supplied tape
- Remote engine shutdown capability initiated from a platform or by SMS for theft response
- External SOS button that sends an emergency alert to the tracking platform and preset phone numbers
- Local data storage that records track history when GSM network connectivity is unavailable
- Shock sensor based alarm for movement and impact detection

## Core Features of Carscop - CCTR-801

- Compact form factor and lightweight design for discreet placement inside the vehicle
- Easy installation process requiring only a few wires and optional adhesive mounting
- Real time position uploads for continuous tracking and history reconstruction
- Remote engine stop function accessible via the tracking platform or SMS
- External SOS button to notify the platform and up to three preset phone numbers
- Built in memory to record track data when network is lost and upload later
- Shock sensor that triggers movement or impact alarms
- Silent listening mode to monitor sound around the device when supported by firmware

## How These Features Work with Plaspy

When integrated with Plaspy, the CCTR-801 reports its location and events to the platform for visualization, history, and alerting. Plaspy detects compatible tracker protocols and presents device data in a unified interface so operators can monitor devices alongside other fleet assets.

- Live location and track history appear in Plaspy for route review and incident investigation
- SOS and shock events are visible as alerts in the platform and can be routed to operators
- Remote engine shutdown commands can be issued from Plaspy when the device firmware supports platform initiated control
- Offline recorded tracks are uploaded and appended to history in Plaspy once the device regains connectivity
- Silent listening and other device functions are reflected as available actions or events in Plaspy when enabled by the device firmware
- Plaspy can accept device reports to its public endpoint at d.plaspy.com and automatically recognize the device protocol for onboarding

## Typical Use Cases

- Fleet monitoring for small commercial fleets, taxis, and rental vehicles needing real time visibility
- Asset protection where discreet installation and a remote engine stop option add recovery options
- Emergency response using the external SOS button to notify operators and preselected phone numbers
- Post incident investigation using detailed track history stored locally and uploaded after reconnect
- Movement or tamper detection using the shock sensor to trigger operator alerts
- Short term deployments where compact size and easy mounting are priorities

## Feature Availability Notes

- Manufacturer firmware versions can enable or disable specific functions such as silent listening or remote commands
- Hardware revisions and regional variants may affect available features and supported alerts
- Installation type and wiring determine which vehicle circuits the tracker can access for functions like remote engine stop
- Offline tracking behavior depends on internal storage capacity and configured upload intervals
- Verify exact SMS command formats and supported phone number presets with the official manufacturer manual
