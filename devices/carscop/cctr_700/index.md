# Carscop - CCTR-700

<div className="device-logo">
![CCTR-700](./logo.jpg)
</div>

The Carscop CCTR-700 is a compact GPS tracker designed for reliable location tracking and history recording. It determines position from GPS signals and transmits location data via SMS or GPRS. The device supports four frequency channels 850 900 1800 1900 MHz for broad network compatibility and can report longitude and latitude directly or send a website map link for quick viewing on a smartphone. Built in memory stores up to 32768 track points so location history can be retained even when live reporting is interrupted.

As a Plaspy compatible device, the CCTR-700 can feed position updates and alarm events into Plaspy for centralized monitoring and reporting. Plaspy can display live locations on maps, replay recorded tracks from the device memory, and raise operational alerts based on the position data and movement notifications the tracker sends. This combination makes the CCTR-700 a fit for users who need both discreet hardware and a full featured fleet or asset monitoring platform.

## Key Highlights

- GPS based location tracking with SMS and GPRS reporting options
- Quad band support for wide carrier compatibility across regions
- Onboard memory capable of recording up to 32768 track points
- Shock sensor that supports movement alerts and helps conserve device power
- Magnetic mounting option for discreet attachment to metal surfaces
- Smartphone compatible map links for quick location access
- IP56 level durability and rechargeable battery for everyday use

## How It Works with Plaspy

When integrated with Plaspy, the Carscop CCTR-700 provides position updates and event notifications that Plaspy ingests and presents through its monitoring interface. Plaspy makes device data available for live tracking, historical playback, alerts, and reporting so teams can maintain operational oversight and respond to incidents.

- Display live location on Plaspy maps for real time fleet visibility
- Replay historical tracks from the device memory for route review and analysis
- Generate alerts in Plaspy from movement or shock events reported by the tracker
- Consolidate multiple CCTR-700 units for fleet level monitoring and status dashboards
- Include CCTR-700 position data in Plaspy reports for operational and compliance review
