# ArkNav - DX-3 Features

This page describes the public feature context for using the ArkNav DX-3 with Plaspy. It focuses on user-facing capabilities and the practical value the DX-3 provides when integrated into Plaspy for personal safety, on-demand tracking, and incident alerting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Always consider those variables when planning deployments and consult the manufacturer documentation for device-specific technical details.

## Feature Overview

The ArkNav DX-3 is a compact, Plaspy-compatible personal GPS tracker designed primarily for vulnerable-person protection and incident response. It emphasizes privacy by sharing continuous location only when the user enables Start Tracking or when an emergency occurs, while providing immediate alarm and communication options for caregivers and monitoring teams.

- Dedicated rubber panic button and lanyard activation for immediate alerts to Plaspy
- Two-way hands-free voice with built-in speaker and microphone to aid incident communication
- Accessibility aids including vibration, audio cues, and LED indicators to support hearing or vision impaired users
- Privacy-first tracking where continuous location is only shared on demand or during emergencies
- Rugged splash-resistant IP54 housing and stackable charging dock for practical daily use
- Long standby battery around 1100 mAh with approximately 72+ hours between charges for reliable availability

## Core Features of ArkNav - DX-3

- Panic alarm with distinct dedicated button and lanyard trigger for rapid alerting
- Man-down detection and emergency alerting behavior built into device operation
- Start Tracking function for on-demand continuous location sharing only when needed
- Two-way voice capability using the onboard speaker and microphone for hands-free communication
- Accessibility features including vibration, audio cues, and iconic LED indicators
- Contact ID protocol support for standardized alarm messaging where used
- Splash-resistant IP54 enclosure suitable for everyday wearable use
- Stackable charging dock and accessory options for simple device management

## How These Features Work with Plaspy

When the DX-3 is paired with Plaspy, alarm events and on-demand location updates are delivered to the platform so caregivers, dispatchers, or monitoring teams can act quickly without maintaining continuous surveillance.

- Plaspy receives discrete panic and man-down events and surfaces them to operators for rapid response
- Live position updates appear on the Plaspy map when Start Tracking is engaged or during an emergency session
- Two-way voice sessions can be initiated during alerts to enable direct communication if network voice capability is available
- Battery and charger status reported by the device help Plaspy notify caretakers about low power and maintain device uptime
- Contact ID alarm messages can be routed into alarm receiving workflows and integrations supported by Plaspy

## Typical Use Cases

- Elderly safety and discreet wearable protection with immediate panic and man-down alerts for caregivers
- Lone worker protection with on-demand Start Tracking for check-ins and quick incident communication
- Patrol guard and security rounds where simple emergency signalling and hands-free voice are required without continuous tracking
- Vulnerable-person monitoring in assisted living or community care environments that prioritize privacy and independence
- Temporary deployments and events where stackable charging docks and long standby life simplify device rotation and maintenance

## Feature Availability Notes

- Firmware and software updates can change behavior or enable/disable specific features; verify firmware level for exact capabilities
- Hardware revisions and regional variants may affect available accessories, ingress protection, or supported protocols
- Some functions such as two-way voice depend on network voice availability and carrier support in the deployment region
- Installation choices and accessory use (for example lanyard versus docking) influence how emergency triggers and charging are handled
- Contact ID support may be used for standardized alarm messaging but integration behavior can depend on the receiving system configuration

## Why Use Plaspy with These Features

Using the ArkNav DX-3 with Plaspy gives organizations focused on personal safety a way to consolidate incident alerts and on-demand location into a single monitoring workflow. The DX-3’s privacy-first approach and clear emergency interfaces let caregivers and operators receive actionable notifications without needing continuous tracking, while Plaspy provides the visibility and routing needed for timely response.
