# ArkNav - RX-8W Features

This page provides a public feature overview for the ArkNav RX-8W GPS tracker and how its capabilities are used with the Plaspy platform. It focuses on user facing functions, practical telemetry, and the common ways the device integrates into Plaspy for vehicle and asset monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and installation type. For the most current device specific details and implementation notes refer to the manufacturer documentation and release notes.

## Feature Overview

The RX-8W is a rugged, Plaspy compatible tracker built for vehicle and asset monitoring in demanding environments. It combines GNSS positioning, cellular connectivity, onboard sensors, and configurable reporting to support real time visibility and historical playback inside Plaspy.

- IP67 rated waterproof and heat tolerant housing for reliable field deployment and discreet mounting.
- u‑blox GNSS plus cellular fallback for position fixes and continued reporting where satellite reception is limited.
- Wide input voltage tolerance with surge protection and an optional backup battery to support long term field use.
- Built in digital temperature sensing and support for external temperature probes for refrigerated transport monitoring.
- Large local log storage and OTA firmware updates for remote maintenance and reduced downtime.

## Core Features of ArkNav - RX-8W

- Plaspy compatible GNSS and GSM based tracking for live location and historical routes.
- IP67 waterproof enclosure and heatproof design for harsh environments.
- Wide input range with surge protection and optional backup battery for uninterrupted operation.
- Built in digital temperature sensor plus support for external temperature probes.
- Configurable intelligent tracking modes including time distance and angle based reporting.
- 3 axis G force sensing for impact and driving behavior detection.
- Driver ID support via I Button and immobilizer output for anti theft and driver attribution workflows.
- Local log storage capacity to retain location records when connectivity is limited.

## How These Features Work with Plaspy

When used with Plaspy the RX-8W reports position, sensor telemetry, and event data to the platform so fleets and asset managers can monitor status and respond to incidents. Plaspy automatically recognises supported tracker protocols and surfaces device telemetry in map views, alerts, and reports for operational oversight.

- Real time and historical GNSS fixes appear in Plaspy for live tracking and route playback.
- Cell based fallback positions and local log uploads maintain continuity when satellite coverage is weak.
- Sensor and event visibility in Plaspy for temperature, motion and impact events, ignition and immobilizer state, and driver ID attribution.
- OTA firmware and configuration updates help keep devices aligned with Plaspy feature updates and security practices.
- Devices can be configured to report to Plaspy servers using standard transport options; Plaspy detects the tracker protocol automatically and consolidates incoming telemetry.

## Typical Use Cases

- Fleet and delivery operations needing live location, route history, and driver attribution.
- Anti theft and vehicle recovery workflows using discreet mounting, immobilizer control, and event alerts.
- Construction and agricultural equipment tracking where rugged enclosure and wide voltage tolerance are required.
- Temperature sensitive logistics such as refrigerated trailers monitored by built in and external temperature probes.
- Usage based monitoring and trip reporting for maintenance planning and operational analysis.
