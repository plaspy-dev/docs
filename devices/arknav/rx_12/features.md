# ArkNav - RX-12 Features

This page provides a public feature summary for the ArkNav RX-12 GPS tracker and explains how those features map to Plaspy for tracking, telemetry, and fleet workflows. It is intended to help fleet managers, integrators, and technical evaluators understand the RX-12’s practical capabilities when used with Plaspy’s cloud platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installed accessories, and the way the unit is integrated into a vehicle. Consult the manufacturer documentation for variant-specific details and verify features against the installed firmware and configuration.

## Feature Overview

The RX-12 is a compact, rugged LTE-M capable tracker designed for vehicle and asset deployments where durable, discreet mounting and reliable cellular coverage matter. It combines high-sensitivity GNSS positioning, event-driven reporting, and remote management options to provide consistent location and status updates while minimizing installation complexity.

- Real-time GNSS location reporting suitable for cars, vans, trucks, trailers, and heavy machinery.
- LTE‑M primary connectivity with 2G fallback to maximize coverage and low power operation.
- Rugged IP67 enclosure with integrated antennas for discreet, tamper resistant mounting.
- Event-driven reporting on speed, motion, and ignition to reduce data usage while delivering timely updates.
- OTA firmware and configuration updates to keep deployed units current without field visits.

## Core Features of ArkNav - RX-12

- LTE‑M connectivity with EGPRS 2G fallback for broad cellular reach and robustness.
- High-sensitivity u‑blox GNSS receiver for fast and reliable position fixes.
- IP67 rated waterproof and dustproof enclosure with heat tolerance for harsh environments.
- Event triggers including speed, motion, and ignition reporting for efficient telemetry.
- Built-in antennas and compact low‑profile form factor for concealed installations.
- Robust vehicle power protection with surge protection up to 60 V and optional ISO‑7637 module.
- Inputs and outputs supporting active‑high and active‑low configurations plus two configurable outputs and optional immobilizer relay support.
- Remote management via OTA firmware and configuration updates.

## How These Features Work with Plaspy

When connected to Plaspy, the RX-12 becomes an endpoint for location awareness, event visibility, and remote maintenance. Plaspy ingests location fixes and event reports from the device and presents them in dashboards, alerts, and historical reports for operational oversight.

- Position fixes and event-driven updates appear in Plaspy for real-time tracking and route history.
- Motion, ignition, and speed events enable intelligent trip start/stop and event logging in Plaspy.
- IO states and configured outputs can be reflected as device status or control points inside Plaspy dashboards.
- OTA update status and configuration changes are visible to administrators to simplify fleet maintenance.
- Accelerometer events and locally buffered data help Plaspy present accurate motion and impact indicators when available.

## Typical Use Cases

- Fleet management across light and heavy vehicles with real-time tracking and trip reporting.
- Trailer and heavy equipment monitoring where IP67 protection and heat tolerance are required.
- Vehicle recovery and anti-theft workflows using discreet mounting and optional immobilizer control.
- Delivery and dispatch operations that rely on event-triggered position updates for efficient routing.
- Usage based insurance and PAYD telemetry when trip and motion events are needed for reporting.
- Remote device maintenance and staged firmware rollouts using OTA update capabilities.

## Feature Availability Notes

- Some features depend on the device firmware version; capabilities can change with firmware updates.
- Optional accessories such as ISO‑7637 surge protection and immobilizer relays may be required for certain workflows.
- Hardware revisions or regional variants can affect supported cellular bands and physical interfaces; consult the product datasheet.
- Installation type and wiring determine which IO-based features (ignition, external sensor inputs, outputs) are available in practice.
- Manufacturer documentation should be consulted for regulatory, certification, and band support details.
