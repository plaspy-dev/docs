# ArkNav - AT-9000 Features

This page documents the public feature context for using the ArkNav AT-9000 tracker with Plaspy. It focuses on practical capabilities that are relevant to fleet managers, asset owners, and integrators who plan to use the device with Plaspy for location monitoring, event visibility, and historical reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and how the manufacturer has implemented particular functions. Where appropriate, this page highlights common capabilities and how they typically map into Plaspy workflows while encouraging verification with manufacturer documentation.

## Feature Overview

The AT-9000 is a purpose built long-operation tracker for harsh environments and extended deployments. It is designed to provide reliable location and movement telemetry with minimal maintenance, making it suitable for container, trailer, and heavy equipment tracking where external power may be intermittent or unavailable.

- Long runtime capability with a swappable rechargeable battery pack suitable for long deployments in timer driven modes.
- Rugged IP67 rated enclosure and heatproof construction to tolerate outdoor and industrial conditions.
- Hybrid positioning that combines AGPS and cell based location fallback to improve position availability in low sky view scenarios.
- Movement detection using a built in 3-axis accelerometer to enable event driven reporting and power conservation.
- Remote location retrieval via SMS and phone call response with convenient Google Maps links for on demand checks.
- Local flash memory for data buffering and delayed upload when cellular coverage is interrupted.

## Core Features of ArkNav - AT-9000

- Long battery autonomy with swappable rechargeable battery pack and configurable timer activation for extended deployments.
- Rugged environmental protection including IP67 rated housing and heat tolerant design up to the manufacturer stated limit.
- AGPS assisted positioning combined with cell based fallback to improve tracking when GPS reception is degraded.
- Built in 3-axis accelerometer for movement detection and event driven wake or reporting.
- SMS and phone call based remote location retrieval that can return a Google Maps style link for quick on demand location checks.
- Local data storage for resilience with an internal flash buffer that preserves telemetry during coverage gaps.
- Field configuration options including a full size SIM slot and a USB to serial interface for setup and profile updates.
- Compact, asset friendly form factor optimized for containers, trailers, dumpsters, and heavy equipment.

## How These Features Work with Plaspy

When the AT-9000 reports telemetry, Plaspy ingests and presents that data so teams can monitor assets, investigate events, and run historical reports. Plaspy automatically detects compatible tracker protocols and maps incoming position and event data into the platform for visualization and alerting.

- Real time and periodic location updates appear in Plaspy for live tracking and map display.
- Movement events generated by the device are visible as events in Plaspy and can trigger notifications or wake the device according to configured profiles.
- Cell fallback and AGPS positions improve track continuity in Plaspy when GPS fixes are intermittent, helping maintain meaningful location history.
- Buffered telemetry stored locally on the device is uploaded when connectivity returns and is reflected in Plaspy historical playback and reports.
- Configurable reporting profiles on the device translate into frequency and event behavior visible in Plaspy, enabling a balance between visibility and battery life.

## Typical Use Cases

- Container and trailer location tracking in ports, yards, and logistics chains where long autonomy and ruggedness are required.
- Heavy equipment monitoring to detect movement and maintain asset presence without relying on vehicle power.
- Remote asset visibility for dumpsters, portable equipment, and field assets with infrequent maintenance windows.
- Anti theft and recovery workflows where on demand location retrieval and event alerts support rapid response.
- Fleet and asset programs that require low maintenance operation and delayed data delivery during coverage gaps.
- Temporary deployments and equipment leasing scenarios where quick field configuration and swappable batteries reduce downtime.
