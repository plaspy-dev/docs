# RX-9 3G/GPS Waterproof Vehicle Tracker

The RX-9 is a rugged, Plaspy compatible GPS tracker engineered for reliable fleet management, vehicle recovery, and temperature-controlled logistics. Built around uBlox GPS and GSM modules, the RX-9 delivers fast, accurate fixes and improved cell‑based positioning where satellite signals are weak. Its IP67 waterproof and heatproof housing \(rated to 85 °C\), built-in antennas, and high-quality components make it a cost-effective choice for vehicles, trailers, caravans, and heavy machinery operating in demanding conditions.

The RX-9 integrates seamlessly with Plaspy to enable real-time tracking, telemetry and anti-theft workflows. With ignition and motion activation, driver identification via I-Button, immobilizer control and configurable alerting, the device is purpose-built to support fleet telematics, theft deterrence and operational efficiency. Optional accessories expand capabilities for specialized use cases while OTA firmware/configuration updates keep deployments current without garage downtime.

## Key Highlights

- Plaspy compatible for real-time tracking and fleet management via GPRS connection and configurable reporting intervals.
- Rugged IP67 waterproof, heatproof housing and built-in antennas for discreet installation and reliable field performance.
- High-capacity backup battery \(up to 3450 mAh\) and storage for up to 50,000 locations for data continuity during power loss.
- Robust power surge protection rated to 65 volts to safeguard against vehicle electrical spikes.
- Fleet-focused telemetry: ignition/motion activation, 3-axis G‑force sensor, configurable speed and event alerts for anti-theft and safety monitoring.
- Driver identification \(I-Button\) and immobilizer control support for secure vehicle access and remote disabling workflows.
- Built-in digital temperature sensor and support for external temperature sensor accessories for temperature-controlled logistics.
- Over-the-air \(OTA\) firmware and configuration updates to scale and maintain deployments with minimal downtime.

## How It Works with Plaspy

When paired with Plaspy, the RX-9 streams GPS positions and vehicle telemetry to your Plaspy dashboard using GPRS/GSM connectivity and configurable message formats. Plaspy ingests GPS fixes, sensor telemetry and event alerts \(ignition, motion, G-force events, battery status and temperature\) to provide real-time tracking, historical playback, and rule-based notifications. The RX-9’s configurable real-time and idle tracking intervals, heartbeat messages and custom server acknowledgements ensure stable connectivity and predictable data flow to Plaspy.

- Real-time location and telemetry updates via GPRS to Plaspy, including configurable time, distance and angle reporting rules.
- Ignition and motion status reporting for fleet activity monitoring and idle time analysis.
- Onboard temperature telemetry \(and optional external temperature sensor\) for cold-chain and temperature-controlled logistics.
- Driver ID \(I-Button\) events and immobilizer control for anti-theft workflows and driver assignment tracking.
- G‑force sensor events and speeding alerts streamed to Plaspy for safety scoring and incident analysis.
- Local storage and automatic resend of up to 50,000 locations when connectivity is restored, preserving historical data for Plaspy reports.
- OTA configuration and firmware updates allow Plaspy administrators to maintain and update RX-9 units remotely.
