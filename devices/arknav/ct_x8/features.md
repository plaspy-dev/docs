# ArkNav - CT-X8 Features

This page summarizes the public feature context for the ArkNav CT-X8 Container Lock GPS Tracker and how its telemetry and event data are used with Plaspy. It is intended to describe practical capabilities and typical operational value when the CT-X8 is integrated into Plaspy for centralized monitoring, alerts, and event history.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Use this page as a high-level reference and consult the manufacturer documentation and current device datasheet for the most detailed, up-to-date technical specifications.

## Feature Overview

The CT-X8 is a purpose-built container lock tracker designed for ports, intermodal transport, and long-haul logistics. It provides continuous position reporting, tamper and door-open evidence, rugged environmental protection, and configurable reporting profiles to balance visibility and battery life.

- Real-time GPS location reporting for continuous position visibility and historical route review
- Tamper-evident stainless steel lock mechanism and external mounting for chain of custody evidence
- IP67 rated enclosure with heatproof casing to withstand harsh port and transit environments
- Configurable reporting intervals from every second up to hourly to tune telemetry and battery use
- Large backup Li‑Ion battery for extended field operation when external power is unavailable

## Core Features of ArkNav - CT-X8

- Integrated high-sensitivity internal GPS receiver for reliable position fixes in transit
- GSM cellular communications for telemetry and event transmission to a central platform
- Tamper and door-open event detection captured as evidence for inspections and audits
- Rugged stainless-steel lock mechanism with external tamper cable attachments for physical security
- IP67 waterproof housing and heatproof casing rated for elevated ambient conditions
- Configurable reporting profiles to prioritize either continuous tracking or extended battery life
- Large backup battery 3.7 V 10000 mAh to support prolonged operation without external power
- No external power button and power filtering to prevent accidental or intentional shutdowns

## How These Features Work with Plaspy

When deployed with Plaspy, the CT-X8 supplies location and event telemetry that Plaspy ingests and presents in centralized dashboards, alerts, and historical logs. Plaspy automatically detects many tracker protocols and normalizes incoming data so operations teams can focus on event response and compliance.

- Live position and route visualization so operators can monitor container movement in real time
- Immediate intrusion and door-open alerts routed into Plaspy incident streams for quick action
- Configurable reporting profiles reflected in Plaspy to balance update frequency and battery consumption
- Consolidated event history and evidence files within Plaspy for audits and chain of custody workflows
- Mobile-ready notifications and quick location links that work alongside Plaspy alerts and dashboards

## Typical Use Cases

- High-value container security where tamper evidence and continuous tracking deter theft and support recovery
- Customs and regulatory compliance where event logs and forensic evidence are required for inspections
- Long-haul intermodal shipments that need persistent visibility across multiple transport segments
- Port and yard operations that require fast detection of forced entry or unexpected door openings
- Consolidated freight monitoring where operators only escalate inspections when the device reports an event
