# Oigo Telematics - AR-2GM Features

This page covers the public feature context for using the Oigo Telematics AR-2GM tracker with Plaspy. It describes the main capabilities you can expect to operate inside Plaspy when the AR-2GM is deployed, focusing on practical functions such as discreet vehicle installation, event reporting, and GSM data transmission.

Exact feature availability can vary by firmware version, hardware revision, installation approach, and manufacturer implementation. Use this page as a high level reference for how the AR-2GM behaves in typical deployments and consult the device maker for the most current, device specific information.

## Feature Overview

The AR-2GM is part of the AR Series of trackers and is intended for discreet vehicle installations while supporting a flexible set of event reports. It uses GSM networks for communications and is designed to integrate into fleet management and stolen vehicle recovery workflows.

- Discreet form factor for hidden vehicle installations and low visual footprint
- Configurable event reports and alerts for conditions such as excessive speeding, unauthorized use, and geofence breaches
- GSM based data communication for consistent reporting in cellular coverage areas
- Designed for integration with fleet management platforms and stolen vehicle recovery systems
- Compatible with Plaspy for centralized device visibility and event handling

## Core Features of Oigo Telematics - AR-2GM

- Discreet installation design suitable for hidden mounting in vehicles
- GSM communication for transmitting tracker reports to a backend platform
- Support for a diverse set of event reports and alerts configurable on the device
- Examples of event triggers include excessive speeding alerts, unauthorized vehicle use notifications, and geofence breach reports
- Intended compatibility with fleet management and stolen vehicle recovery systems
- Works with Plaspy for reporting, monitoring, and operational oversight

## How These Features Work with Plaspy

When used with Plaspy, the AR-2GM reports and events integrate into Plaspy dashboards and alerting workflows so operators can monitor vehicle status and respond to incidents.

- Location and report events from the tracker are ingested into Plaspy for live map visualization and history
- Event reports such as speeding, unauthorized use, and geofence breaches are reflected as notifications and timeline events
- Discreet installation does not affect visibility inside Plaspy since reporting is message based rather than tied to appearance
- Plaspy helps centralize alerts from multiple AR-2GM devices for fleet level monitoring and incident follow up
- Device compatibility is streamlined because Plaspy detects supported tracker protocols automatically

## Typical Use Cases

- Fleet monitoring where low profile installation is preferred for company vehicles
- Stolen vehicle recovery workflows that rely on discreet trackers reporting location and events
- Driver behavior monitoring where event reports for excessive speed and unauthorized use are useful
- Rental and shared vehicle oversight to detect unexpected use or location departures
- Geofence monitoring for asset control and operational boundaries

## Feature Availability Notes

- Feature sets can differ by firmware version and hardware revision; compare device firmware notes for specifics
- Installation choices such as wiring, mounting location, and external antennas can affect signal quality and behavior
- Regional cellular variants and local network conditions influence GSM communications and coverage
- Manufacturer configuration options and enabled event types may differ between batches or custom deployments
- Verify any required settings for integration with a platform such as Plaspy before wide scale deployment
