# Oigo Telematics - AR-2CX Features

This page provides a public feature overview of the Oigo Telematics AR-2CX and how its capabilities are used with the Plaspy platform. It summarizes practical, non sensitive information about the device, highlights the types of event reporting the AR-2CX can provide, and explains how those reports typically appear in Plaspy for fleet and recovery workflows.

Exact feature availability for the AR-2CX can vary by firmware version, hardware revision, regional variants, and installation method. The content below uses the device description as the factual basis and focuses on safe, user facing capabilities; for device specific technical details consult the manufacturer documentation for the latest information.

## Feature Overview

The AR-2CX is part of Oigo Telematics AR Series and is designed for vehicle location tracking with an emphasis on integration into fleet management and stolen vehicle recovery systems. It is a compact tracker intended for discreet installation and supports configurable event reporting so operators can receive tailored notifications about vehicle status and behavior.

- Compact and discreet design suited to covert vehicle installations
- Integration ready for fleet management and stolen vehicle recovery systems
- Supports a diverse set of event reports and alerts such as speeding notifications and unauthorized use reports
- Customizable event reporting to help teams monitor driver behavior and vehicle status
- Designed to send regular location updates to a fleet platform like Plaspy

## Core Features of Oigo Telematics - AR-2CX

- GPS based vehicle location reporting for real time visibility
- Support for configurable event reports and alert types
- Integration focus for fleet management and stolen vehicle recovery use cases
- Compact form factor intended for discreet installations in vehicles
- Customizable notification behavior for events such as speeding and unauthorized use
- Compatibility with fleet platforms including Plaspy for centralized monitoring

## How These Features Work with Plaspy

When the AR-2CX is used with Plaspy, its location and event reports become part of a single operational view that teams can use for monitoring and response. Plaspy receives the information the device sends and presents it in dashboards, event timelines, and vehicle histories to support day to day fleet operations and recovery workflows.

- Location updates appear on Plaspy maps and vehicle history timelines
- Event reports and alerts are captured in Plaspy event feeds for review and filtering
- Customizable notifications sent by the device can be surfaced as alerts inside Plaspy
- Fleet managers can combine AR-2CX data with other assets for consolidated oversight
- Data from discreet installations helps support stolen vehicle recovery workflows in Plaspy

## Typical Use Cases

- Fleet vehicle tracking for daily route monitoring and operational oversight
- Stolen vehicle recovery where a discreet tracker is needed to aid recovery efforts
- Monitoring of driver behavior via event reports such as speeding or unauthorized use
- Rental or shared vehicle oversight to detect and report unexpected usage
- Centralized fleet reporting where multiple trackers feed into a single platform
