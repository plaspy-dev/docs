# Oigo Telematics - AR-3HU Features

This page summarizes the public feature context for the Oigo Telematics AR-3HU when used with Plaspy. It focuses on the practical capabilities you can expect to use in a fleet management or stolen vehicle recovery workflow and how those capabilities appear when integrated into the Plaspy platform.

Exact feature availability and experience can vary by firmware version, hardware revision, installation type, and how the manufacturer implements each function. Use this page as a general guide and consult the device manufacturer for the most current, device specific details.

## Feature Overview

The AR-3HU is a compact vehicle tracker designed for discreet installation and continuous reporting to fleet management systems. It is built to support timely event reporting and reliable cellular communication to keep vehicle location and event data flowing to a monitoring platform.

- Discreet vehicle installation suitable for hidden placement in customer vehicles
- Support for event reports and alerts including speeding, harsh braking, and unauthorized vehicle use
- 3G HSDPA cellular connectivity for continuous communication with a tracking platform
- Practical fit for fleet management and stolen vehicle recovery deployments
- Competitive pricing with purchase and lease options for different business needs

## Core Features of Oigo Telematics - AR-3HU

- Discreet installation design for hidden mounting in vehicles
- Diverse event reporting framework with alerts for driving events and unauthorized use
- 3G HSDPA connectivity to maintain regular location and event reporting
- Compatibility with fleet management and stolen vehicle recovery workflows
- Real time style event notifications suitable for operational monitoring
- Available purchase and lease options to accommodate budgeting preferences

## How These Features Work with Plaspy

Plaspy ingests standard tracker event reports and location updates, making AR-3HU reports visible in vehicle timelines and monitoring dashboards. Plaspy also detects compatible tracker protocols automatically to simplify onboarding.

- Event reports such as speeding, harsh braking, and unauthorized use are shown as platform events for review and alerting
- Location updates are recorded in Plaspy for live tracking and history views
- Plaspy automatically detects the tracker protocol during integration to reduce manual configuration
- Devices that report events to Plaspy can be managed together with other fleet assets for consolidated oversight
- Network connectivity of the tracker allows Plaspy to deliver near real time notifications and status updates

## Typical Use Cases
