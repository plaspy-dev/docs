# Aquila

Aquila is a recognized name in the GPS tracking space with device models that work with third party platforms. This page explains how Aquila trackers integrate with Plaspy, how to choose the right device for your application, and where to find further documentation. Use the catalog below to browse compatible Aquila devices and jump to device specific pages.

## How Aquila devices work with Plaspy

Plaspy can ingest telemetry from Aquila trackers so you can monitor location, status, and events from a single platform. Integration usually involves registering a device identity in Plaspy and configuring the tracker to report to the platform using the device credentials. Once connected, Plaspy displays live position updates, historical routes, and alerts generated by the tracker.

This page focuses on compatibility and guidance. For device level setup and server details, open the device entry in the catalog and follow the device specific instructions there.

## Common features found in Aquila devices

While model capabilities vary, many Aquila trackers include a set of common features useful for fleet and asset monitoring:
- Continuous or periodic GPS location reporting for position history
- Movement and ignition detection used for activity monitoring
- Power and tamper status reporting to detect unauthorized changes
- Internal battery backup for short term reporting when external power is lost
- Configurable reporting intervals and alert thresholds

Refer to the device pages in the catalog for exact feature lists and hardware specifications.

## Typical use cases for Aquila GPS trackers

Aquila devices are commonly used for:
- Fleet vehicle tracking to monitor routes, driver behavior, and utilization
- Asset tracking for trailers, equipment, and high value mobile assets
- Rental and leasing operations to enforce geofences and usage limits
- Field service and small commercial fleets that need compact trackers
Plaspy can adapt reporting and alerting to these scenarios so operations teams get actionable insights from Aquila devices.

## Why choose Plaspy for Aquila device monitoring

Plaspy provides a unified platform to manage mixed fleets of devices, including Aquila trackers. Key advantages when pairing Aquila devices with Plaspy:
- Centralized device management and provisioning tools for onboarding trackers
- Configurable alerts and geofencing to match operational policies
- Route history and reporting that help reduce downtime and improve utilization
- User roles and permissions to control access across teams

If you already use Aquila hardware, Plaspy helps consolidate data and workflows into a single operational view. Learn more about the platform and enterprise features at https://www.plaspy.com.
