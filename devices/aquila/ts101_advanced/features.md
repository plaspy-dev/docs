# Aquila - TS101 Advanced Features

This page describes the public feature context for the Aquila TS101 Advanced and how its capabilities are typically used with Plaspy. It focuses on practical, non sensitive details about what the tracker can do and how those functions are useful when the device is connected to the Plaspy platform.

Exact feature availability and behavior can vary with device firmware, hardware revision, the way the unit is installed, and how the manufacturer implements optional interfaces. For final configuration specifics and the latest technical details consult the manufacturer documentation and firmware notes.

## Feature Overview

The TS101 Advanced is designed as a compact, rugged tracker for vehicle and asset monitoring across a range of operations. Its combination of real time location, on device record storage, and several vehicle I O interfaces makes it suitable for continuous tracking and event driven monitoring when used with a cloud platform such as Plaspy.

- Real time tracking for continuous location visibility and operational monitoring
- On device solid state storage capable of holding up to 16 000 tracking records for offline logging and later upload
- Rugged IP67 rated ABS casing for reliable operation in harsh environmental conditions
- Vehicle immobilizer and hooter interfaces for remote control and alert integration
- Fuel sensor interface to capture fuel level information where a compatible sensor is installed
- 3 axis accelerometer for motion detection and impact sensing

## Core Features of Aquila - TS101 Advanced

- Compatibility with Plaspy for centralized tracking and management
- Real time GPS location reporting for live fleet and asset visibility
- Local solid state storage of up to 16 000 tracking records to preserve history during connection gaps
- Vehicle immobilizer interface for remote engine disable workflows where installed and supported
- Hooter interface for local audible alerts or status indication
- Fuel sensor interface to surface fuel level information when a sensor is connected
- 3 axis accelerometer enabling motion and impact detection for event based alerts
- IP67 rated ABS enclosure and built in battery backup for continued operation in challenging conditions

## How These Features Work with Plaspy

When registered to Plaspy, the TS101 Advanced can contribute continuous and historical data to a single monitoring environment so teams can maintain situational awareness across vehicles and assets.

- Live location data appears on Plaspy maps for real time tracking and dispatch decisions
- Stored records can be uploaded and replayed in Plaspy to review historical routes or events
- Immobilizer events and control state can be reflected in the platform as device events or status indicators when configured
- Fuel sensor readings reported by the device are visible in Plaspy dashboards or device detail views where a sensor is present
- Motion and impact events detected by the accelerometer can be surfaced as alerts or timeline entries inside Plaspy
- Rugged hardware and battery backup help maintain continuity of position reporting to Plaspy during power interruptions

## Typical Use Cases

- Logistics fleet tracking for route monitoring and historical route analysis
- Taxi and ride fleet operations needing live vehicle location and simple remote controls
- Rent a car fleet management with event history for administered vehicles
- Security tracking for high value assets operating in outdoor or industrial environments
- Insurance telematics scenarios using motion and historical data to support claims analysis
- Asset tracking in sites where environmental protection and battery backup are important

## Feature Availability Notes

- Regional variants or regulatory requirements can change supported configurations or certifications
- Always confirm current feature lists, wiring diagrams, and firmware behavior in the manufacturer documentation
