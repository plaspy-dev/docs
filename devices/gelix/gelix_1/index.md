# Gelix - Gelix 1

![Gelix 1](./logo.jpg)

The Gelix 1 is a passive monitoring GPS data logger designed to record navigation and event data while a vehicle is in motion or when an external event occurs. It stores historical location and event records for later retrieval rather than streaming data in real time. The device supports multiple options for getting stored data off the unit, including automatic retrieval when the vehicle returns to a depot with a radio access point and manual retrieval via wired connection, IrDA, Bluetooth with a PDA, or by removing the unit and connecting it to a PC.

As a Plaspy compatible device, the Gelix 1 fits into workflows that require reliable historical location capture and flexible data collection methods. Plaspy can ingest and present Gelix 1 log data for reporting, route review, and operational oversight alongside other tracked assets. This makes the Gelix 1 a practical choice when intermittent connectivity or depot based synchronization is part of the operating model.

- Passive GPS data logging for continuous record keeping of routes and events during vehicle operation
- Multiple data retrieval paths including automatic depot sync and manual connections for flexible workflows

- Enables consolidated historical records for fleet reporting and operational review

## How It Works with Plaspy

When used with Plaspy, Gelix 1 recorded logs can be imported into the platform to provide historical visibility and analysis. Plaspy can process the uploaded files and present them in dashboards and reports to support fleet management decisions.

- Import Gelix 1 logs into Plaspy for historical route reconstruction and playback
- Configure automatic depot sync workflows so data recorded by the Gelix 1 is collected when vehicles return to a coverage point
- Combine Gelix 1 historical records with other asset data in Plaspy for unified reporting
- Use Plaspy reporting tools to generate mileage, route efficiency, and event summaries from imported logs
- Apply Plaspy alerts and review processes based on events identified in Gelix 1 data to support operational oversight
