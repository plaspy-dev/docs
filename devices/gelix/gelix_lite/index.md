# Gelix - Gelix Lite

![Gelix Lite](./logo.jpg)

The Gelix Lite is a driver telematics device built for integration with GLONASS and GPS systems to track moving objects. As a telematics controller it collects, records, and transmits location and event data using GPRS IP and SMS, and it includes flexible configuration for data format and event registration. The device can send data to two receiver servers, accept operating mode commands from a server, and supports remote firmware upgrades, making it suitable for ongoing fleet and asset management.

As a Plaspy compatible device, the Gelix Lite can feed its location and event streams into the Plaspy platform for visualization and operational oversight. Its support for configurable data formats, digital inputs, dry contact sensors, and serial interface inputs means Plaspy users can centralize tracking, monitor external sensor values, and include event data in reports and alerts. Compatibility with Plaspy provides a practical path to include Gelix Lite devices in broader fleet monitoring workflows.

## Key Highlights

- Designed for driver telematics and real time GLONASS GPS tracking
- Data transmission via GPRS IP and SMS with flexible transfer options
- Configurable event registration and data format to match reporting needs
- Support for two receiver servers for redundancy or staged data routing
- Remote operating mode command and remote firmware upgrade capability
- Integration with external devices including digital inputs, dry contact sensors, and serial interface adapters

## How It Works with Plaspy

When used with Plaspy, the Gelix Lite delivers position and event data to a fleet management backend where it is processed for visualization, alerts, and reporting. Plaspy ingests the device data and surfaces it through dashboard tools that help operators monitor vehicle location, status, and sensor events.

- Real time and near real time location plotting of vehicles on the Plaspy map
- Event and digital input logging visible in Plaspy for pulse counters and dry contact events
- Configurable alerts and notifications based on events reported by the device
- Historical reporting and export of tracked routes and recorded events for analysis
- Visibility into external sensor data collected via the serial interface for integration into vehicle reports
- Use of the device's server command capability to reflect operational modes and event signaling within Plaspy workflows

## Typical Use Cases

- Fleet vehicle tracking for logistics and delivery operations
- Driver telematics and operational oversight in commercial fleets
- Fuel level and sensor based monitoring using serial interface data
- Asset usage counting with pulse sensors and digital input monitoring
- Remote device management and staged server routing for scalable deployments

## Why Choose This Tracker with Plaspy

The Gelix Lite is a practical choice for organizations that need a flexible telematics controller capable of integrating external sensors and supporting multiple data delivery methods. Its support for configurable data formats and server commands complements Plaspy's ability to present location, events, and sensor readings in dashboards, alerts, and reports, helping operations teams maintain situational awareness and act on important events.

Because the Gelix Lite can report a variety of telemetry and event types while supporting remote management functions, it fits well where centralized monitoring and periodic device maintenance are part of the operational workflow. For organizations evaluating trackers, pairing Gelix Lite hardware with Plaspy software creates a cohesive solution for location visibility and event driven reporting.
