# Gelix - Gelix 3 Features

This page provides a public feature context for the Gelix 3 and how its capabilities map to Plaspy for monitoring and operational oversight. It describes the practical functions the Gelix 3 offers, how those functions are commonly used with Plaspy, and what to expect when evaluating the device for telemetry and data logging deployments.

Exact feature availability for any Gelix 3 unit can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. Users should treat the descriptions below as a feature overview and verify specific behaviors and requirements against the device firmware release notes and official Gelix documentation.

## Feature Overview

The Gelix 3 is positioned as a versatile power consumption data logger with built in I/O and network connectivity options. It focuses on capturing and delivering meter and event data while integrating with a range of external devices commonly found in industrial and facility contexts.

- Continuous power consumption monitoring and periodic data logging for downstream reporting and analysis
- Automated I/O for event detection and remote device control integration
- Built in network connectivity via an embedded GSM GPRS modem or Ethernet interface for remote reporting
- Support for device telemetry, event monitoring, and delivery of logged data to remote platforms
- Integration possibilities with meters sensors alarms access control readers and custom devices for consolidated monitoring

## Core Features of Gelix - Gelix 3

- Power consumption monitoring and collection of meter readings for logging
- Persistent data logging with scheduled delivery of recorded measurements
- Automated digital I/O to capture events and interface with external devices
- Embedded GSM GPRS modem or Ethernet connectivity for remote reporting
- Device telemetry reporting to external platforms for status and operational visibility
- Voice listening capability as provided by the manufacturer
- Integration support for meters thermometers access card readers alarms radio adaptors and custom device interfaces

## How These Features Work with Plaspy

Plaspy can ingest and present the Gelix 3 telemetry and logged data to provide visibility and historical context for operations teams. Plaspy automatically detects common tracker protocols and maps incoming data for display and alerting as supported by the device feed.

- Logged power consumption and meter values can be visualized as time series within Plaspy for trend analysis
- Events captured via Gelix 3 I/O appear as discrete incidents that can be filtered and reviewed in Plaspy
- Device telemetry and status updates are surfaced in Plaspy device lists for operational oversight
- Historical data delivery from the Gelix 3 supports report generation and export inside Plaspy
- Integration points allow combining Gelix 3 inputs such as alarm or access events with location or asset context within Plaspy

## Typical Use Cases

- Remote energy usage monitoring and centralized collection of power meter data
- Facility event monitoring combining alarms and I/O signals with telemetry
- Access control integration where card reader events are logged alongside device status
- Environmental device monitoring when paired with external thermometers or sensors
- Remote delivery of logged measurements from distributed sites to a central platform
- Consolidation of alarm and telemetry feeds for security and operations teams

## Feature Availability Notes

- Feature presence depends on the Gelix 3 firmware version and the specific hardware revision in the unit
- Integration with particular external devices may require custom wiring configuration or optional interface modules
- Voice listening and similar capabilities may be subject to local regulations and implementation details from the manufacturer
- Network connectivity options vary by model variant; confirm whether a unit includes the embedded modem or an Ethernet interface
- Plaspy compatibility focuses on receiving and mapping device reports; some features may require device configuration to enable data forwarding

## Why Use Plaspy with These Features

Using the Gelix 3 with Plaspy gives organizations a consolidated view of meter readings, logged data, and event activity across distributed assets. Plaspy helps turn uploaded logs and telemetry into actionable information by making event history searchable and by combining device signals with other operational data.
