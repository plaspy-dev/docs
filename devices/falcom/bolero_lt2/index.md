# Falcom - BOLERO-LT2

![BOLERO-LT2](./logo.jpg)

The Falcom BOLERO-LT2 is a versatile GPS tracker designed for real-time navigation, remote tracking, and monitoring applications. It combines a quad-band GSM GPRS engine that operates on GSM 850 900 1800 1900 MHz with a high sensitivity GPS core based on a µ-blox engine, delivering dependable communication and precise position information. The device is intended for indoor use and fixed installations and supports features such as configurable alert messaging, geofencing, and a data logger that can retain unique location records for up to 45 days.

As a Plaspy compatible device, the BOLERO-LT2 can feed location and status updates into fleet management workflows to improve visibility and operational oversight. Its integration friendly design makes it suitable for connecting with AVL systems, fleet tracking setups, and vehicle security solutions within Plaspy. Organizations using Plaspy can leverage the tracker to receive real time alerts, enforce territory rules, and review historical routes captured by the data logger for later analysis.

## Key Highlights

- Quad band GSM GPRS engine for broad regional communication coverage
- High sensitivity µ-blox GPS core for accurate and reliable positioning
- Configurable alert messaging for real time position updates and status reports
- Geofencing capabilities for territory management and route verification
- Data logger feature that stores unique locations for up to 45 days
- Designed for indoor use and fixed installation scenarios
- Easy integration into AVL systems fleet management and vehicle security workflows

## How It Works with Plaspy

When connected to Plaspy the BOLERO-LT2 supplies location and event information that Plaspy can use for monitoring reporting and alerts. Plaspy ingests the tracker data to present live positions on maps maintain historical traces and trigger notifications based on configured rules.

- Live location visibility and map tracking for vehicles and fixed assets
- Geofence event forwarding so Plaspy can generate alerts when boundaries are crossed
- Historical route playback using stored data logger records for up to 45 days
- Configurable alert mapping to translate device messages into Plaspy notifications
- Fleet status and operational reporting to support oversight and decision making

## Typical Use Cases

- Fixed asset tracking inside facilities or at stationary sites
- Vehicle security and recovery monitoring as part of an integrated solution

- Historical location analysis and reporting using the built in data logger
