# Falcom - BOLERO-LT2 Features

This page provides a public feature overview of the Falcom BOLERO-LT2 and how its capabilities are used with Plaspy for tracking, monitoring, and fleet oversight. It summarizes practical functions and what to expect when integrating the BOLERO-LT2 with the Plaspy platform while keeping technical details at a non sensitive level.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. Always verify device specific capabilities and configuration options against the latest Falcom documentation when planning deployments or expecting particular behaviors.

## Feature Overview

The BOLERO-LT2 is positioned as a versatile tracker for fixed installations and vehicle related tracking tasks. It emphasizes reliable cellular communication and accurate position reporting, plus built in logging and configurable alerts for operational monitoring.

- Quad band GSM GPRS support for broad regional connectivity on standard GSM frequencies
- High sensitivity GPS engine based on a µ blox core for precise location information
- Designed for indoor use and fixed installations where continuous positioning and monitoring are required
- Configurable alert messaging for real time position updates and status reports
- Geofencing functionality to define areas for route verification and prohibited location monitoring
- Onboard data logger capable of storing unique location records for up to 45 days for later retrieval and analysis

## Core Features of Falcom - BOLERO-LT2

- Quad band GSM GPRS engine for consistent cellular reporting across GSM 850 900 1800 1900 MHz bands
- High sensitivity GPS core based on a µ blox engine for improved location fix reliability
- Configurable alert messaging for event driven reporting and status notifications
- Geofencing support for area based monitoring and territory management
- Data logger with long term storage of unique locations for later review and analysis
- Integration friendly design intended for AVL systems and fleet management platforms
- Intended for indoor use and fixed installation scenarios

## How These Features Work with Plaspy

When used with Plaspy, the BOLERO-LT2 reports location and event data to Plaspy servers where it becomes visible for monitoring and operational reporting. Plaspy automatically detects supported tracker protocols and ingests position updates and alerts so they appear in fleet views, event logs, and history reports.

- Real time position updates appear on Plaspy maps and in the device activity timeline
- Geofence events generated by the tracker can be reflected as area entry and exit notifications inside Plaspy
- Alert messages from the device are presented as events and can be used to trigger notifications or workflows in Plaspy
- Data logger records from the device enable historical route reconstruction and offline review in Plaspy
- Plaspy supports common transport options used by trackers and can receive reports from devices configured to send to the Plaspy intake host; Plaspy also handles automatic protocol detection to simplify integration

## Typical Use Cases

- Fleet location monitoring for scheduled routing and route verification
- Territory control and restricted area monitoring using geofencing
- Vehicle security and recovery support where persistent position reporting is required
- Historical route analysis and incident reconstruction using the device data logger
- Fixed asset tracking in indoor or installed environments where constant connection is expected
- Integration into AVL and third party fleet management systems for consolidated monitoring

Using the Falcom BOLERO-LT2 with Plaspy gives organizations centralized visibility into position, geofence events, and historical location data.
