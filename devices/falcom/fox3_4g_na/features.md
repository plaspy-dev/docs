# Falcom - FOX3-4G-NA Features

This page provides a public overview of the Falcom FOX3-4G-NA tracker features and how those capabilities appear when the device is used with Plaspy. It focuses on practical, user facing capabilities such as connectivity, positioning, I O expandability, and premium telematics functions while remaining appropriate for public documentation and search.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device configuration details and the latest technical specifications consult Falcom documentation and your device supplier as needed.

## Feature Overview

The FOX3-4G-NA is designed for industrial grade vehicle telematics and IoT gateway use where high speed cellular connectivity and precise GNSS positioning are required. It supports a range of expansion options and several premium telematics features that are useful for fleet operations and integration with platforms like Plaspy.

- LTE Cat 4 cellular connectivity with 3G and 2G fall back for broad network reach
- Latest GNSS positioning for improved location accuracy and consistent fixes
- Multiple configurable inputs and outputs for integration with vehicle or equipment signals
- Compatibility with IOBOX family modules for CAN, WLAN, and I O expansion
- Automatic switching between internal and external antennas to support installation flexibility
- Premium features such as data encryption, multiple history modes, eco drive and behavior monitoring, data logging, and GSM GPS jamming detection

## Core Features of Falcom - FOX3-4G-NA

- LTE Cat 4 cellular modem with fallback to legacy networks for robust connectivity
- Modern GNSS receiver for precise position reporting
- Configurable inputs and outputs to capture digital states and external signals
- Support for IOBOX MINI IOBOX CAN and IOBOX WLAN modules to extend functionality
- Internal and external antenna support with automatic internal antenna disable when external is connected
- Data encryption and secure data handling features as provided by Falcom
- Multiple history modes and onboard data logging for richer trip and event records

## How These Features Work with Plaspy

Plaspy receives positional and event data from compatible trackers and presents location and operational context in the platform. When a FOX3-4G-NA is connected to Plaspy, common device features translate into visibility and operational insights for monitoring and reporting.

- Real time and historical position data appear on Plaspy maps and trip history views
- Inputs and outputs from the device can be reflected as events or state indicators within Plaspy
- Status reports and alert messaging from the tracker become platform notifications and timeline entries
- Multiple history modes and onboard logging enhance Plaspy reporting where longer or higher fidelity records are required
- Security features such as data encryption and jamming detection provide signals that can be logged or highlighted in Plaspy for operational awareness

## Typical Use Cases

- Fleet vehicle tracking and route history for logistics and service operations
- Industrial IoT gateway scenarios where expanded I O or WLAN connectivity is needed via IOBOX modules
- Remote equipment or asset monitoring that benefits from data logging and history modes
- Driver behavior and eco drive monitoring to support efficiency and safety programs
- Secure tracking deployments where jamming detection and encrypted communications are required
- Installations that require flexible antenna arrangements or external sensor integration

## Feature Availability Notes

- Feature availability depends on the device firmware version and the specific hardware revision installed
- Regional model variants and cellular band support can affect connectivity behavior in different markets
- Some expansion capabilities require the corresponding IOBOX module and may not be present on a base unit
- Installation choices including antenna selection and wiring determine which inputs and outputs are available in practice
- Refer to Falcom documentation for firmware specific features and configuration instructions

Using the FOX3-4G-NA with Plaspy gives organizations a practical way to convert on device connectivity and GNSS data into operational visibility. Plaspy surfaces location, event history, and device state information so teams can monitor assets, analyze trips, and respond to alerts from a central platform.
