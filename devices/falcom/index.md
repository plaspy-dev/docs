# Falcom

Falcom is a manufacturer of GPS tracking and telematics devices used across fleet and asset monitoring applications. On this page you will find how Falcom devices work with Plaspy, which use cases they commonly cover, and guidance to help you find the right device for your deployment. ## How Falcom devices work with Plaspy

Falcom devices transmit location and telemetry data over standard mobile networks. Plaspy can ingest that data from compatible Falcom models so you can monitor vehicles and assets in one central platform. Integration typically involves configuring the device to forward position updates and event messages to Plaspy using supported transport formats. Once connected, Plaspy organizes incoming data for real time tracking, historical playback, alerts, and reporting.
