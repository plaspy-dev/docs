# Falcom - FOX3-2G

<div className="device-logo">
![FOX3-2G](./logo.jpg)
</div>

The FOX3-2G Series from Falcom is a compact and versatile vehicle telematics and gateway device that pairs 2G data connectivity with modern GNSS technology. Designed as an all in one solution, the unit offers a broad set of inputs and outputs and can be extended with optional IOBOX units such as IOBOX-MINI or IOBOX-CAN for increased I O flexibility. The device supports internal and external antenna use, with the internal antennas automatically disabled when external antennas are connected.

As a Plaspy compatible device, the FOX3-2G can forward location, status reports, history records, and alert events into the Plaspy platform for centralized fleet oversight. Its configurable premium features like data encryption, multiple history modes, eco drive and behavior monitoring, plus jamming detection, make it a practical choice for organizations that need a flexible telematics endpoint paired with Plaspy for monitoring, alerts, and reporting.

## Key Highlights

- Compact all in one vehicle telematics and gateway suitable for fleet deployments
- Combines 2G data connection with GNSS positioning for location tracking
- Flexible I O options and optional IOBOX expansion to extend inputs and outputs
- Automatic internal and external antenna management to simplify deployments
- Premium features including data encryption, multiple history modes, and behavior monitoring
- Security oriented capabilities such as GSM GPS jamming detection and alert messaging
- Standard telematics functions supported such as status reports, geofencing, and audio calls

## How It Works with Plaspy

When paired with Plaspy, the FOX3-2G acts as a telematics source that feeds vehicle position, event messages, and history records into Plaspy for visualization and operational use. Plaspy can collect and present the device data so fleets gain centralized visibility and actionable insights across vehicles.

- Map based location display and track history playback using the device history modes
- Event and alert handling in Plaspy for geofence breaches, jamming alerts, and status messages
- Reporting and dashboards for eco drive and behavior monitoring metrics collected by the device
- Monitoring of extended inputs and outputs when IOBOX expansion units are used
- Secure data handling to reflect the device encryption and logging features in platform records

## Typical Use Cases

- Fleet vehicle location tracking and centralized dispatch visibility
- Driver behavior and eco drive monitoring for efficiency programs
- Asset security and anti tampering monitoring with jamming detection alerts
- Vehicles requiring additional I O capabilities via IOBOX expansion
- Mobile data logging and historical playback for operational analysis

## Why Choose This Tracker with Plaspy

The FOX3-2G is a practical option for organizations that need a compact, expandable telematics device that can be integrated into a broader fleet management workflow. Its combination of GNSS positioning, 2G connectivity, configurable history modes, and optional IOBOX expansion provides a flexible hardware base that maps well to Plaspy use cases for tracking, alerts, and reporting.

Because Plaspy can ingest the device's core telemetry and event streams, teams can use Plaspy to centralize monitoring, automate alerts, and build operational reports without relying on multiple point solutions. The FOX3-2G's premium features and expansion options make it a useful device for fleets that expect to scale functionality over time.
