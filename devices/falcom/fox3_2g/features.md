# Falcom - FOX3-2G Features

This page describes the public feature context of the Falcom FOX3-2G series and how those capabilities are surfaced when used with Plaspy. It focuses on user facing capabilities and practical uses of the FOX3-2G family for vehicle telematics, gateway functions, and extended I O options, and explains how these features can be used within Plaspy for tracking and operational visibility.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation type, and manufacturer implementation. For device specific configuration, firmware notes, and the most current technical details consult the official Falcom documentation and release notes.

## Feature Overview

The FOX3-2G is a compact all in one vehicle telematics and gateway device that pairs a 2G data connection with modern GNSS positioning and a flexible set of inputs and outputs. It is designed to be expandable and to support a range of telematics workflows through Falcom premium functions and optional IOBOX add ons.

- Compact all in one telematics gateway combining 2G data and GNSS positioning for vehicle location and movement visibility
- Expandable I O capability using optional IOBOX-MINI or IOBOX-CAN to add external inputs and extend functionality
- Internal and external antenna support with automatic internal antenna disable when external antennas are attached for simplified installations
- Falcom Premium Features for advanced data handling including encrypted data transport, multiple history modes, and enhanced logging
- Built in functions for operational monitoring such as eco drive and behavior monitoring, GSM and GPS jamming detection, and standard reporting and alerting

## Core Features of Falcom - FOX3-2G

- Integrated 2G data connectivity paired with GNSS positioning for location reporting
- Compact all in one vehicle telematics and gateway form factor suitable for a range of vehicle installations
- Flexible inputs and outputs that support diverse installation and sensor needs
- Optional IOBOX-MINI and IOBOX-CAN accessories to extend inputs and gateway capabilities
- Support for both internal and external antennas with automatic internal antenna shutdown when external antennas are used
- Falcom Premium Features including encrypted data handling, multiple history modes, and advanced logging and processing
- Operational functions such as eco drive and behavior monitoring plus GSM and GPS jamming detection
- Standard telematics features including status reports, alert messaging, audio calls, spy calls, and geofencing

## How These Features Work with Plaspy

Plaspy receives and interprets the reporting and events from compatible trackers such as the FOX3-2G to provide live visibility, historical playback, and event based alerts. Plaspy automatically detects supported tracker protocols and maps incoming events so fleets and administrators can monitor operations in one place.

- Real time location and GNSS based reporting appear in Plaspy as live positions and route history
- Multiple history modes and advanced logging are reflected as configurable reporting intervals and richer historical traces in the platform
- Status reports and alert messaging are shown as events and notifications to support operational monitoring and escalation
- Geofence events and behavior monitoring generate location based and driver performance alerts inside Plaspy
- Security events such as GSM and GPS jamming detection can be surfaced as special alerts for investigation
- IOBOX expansion inputs can be mapped to custom inputs or events in Plaspy for extended device telemetry

## Typical Use Cases

- Fleet vehicle location tracking and route history for daily operations and dispatch
- Extended I O installations that require additional sensor inputs or gateway functions via IOBOX accessories
- Driver behavior and eco drive monitoring to support training and efficiency programs
- Security monitoring including jamming detection and geofence breach alerts
- Remote status checks, alert messaging, and in vehicle audio call features for event verification
- Mixed device fleets where the FOX3-2G is used as a compact telematics node with centralized Plaspy visibility

## Feature Availability Notes

- Feature sets such as premium logging modes and encryption depend on the device firmware and may vary by firmware version
- Hardware revisions and optional accessories like IOBOX-MINI or IOBOX-CAN affect which inputs and expansion options are available
- External antenna behavior and installation impacts can change how signals are received and should be planned for each vehicle
- Certain advanced functions listed as Falcom Premium Features may require configuration or licensing from the manufacturer
- Always verify feature lists and capability matrices with the latest manufacturer documentation and release notes

## Why Use Plaspy with These Features

Using the FOX3-2G with Plaspy provides centralised visibility for location, event, and status data across mixed fleets. Plaspy maps incoming tracker events into an operational view so teams can monitor routes, review historical traces, and receive alerts for security and driver behavior concerns without needing custom integrations.
