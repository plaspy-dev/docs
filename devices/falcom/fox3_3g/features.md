# Falcom - FOX3-3G Features

This page provides a public overview of the Falcom FOX3-3G Series and the practical feature context for using this tracker with Plaspy. It focuses on the tracker capabilities that are relevant to Plaspy users, how those capabilities appear in a fleet management workflow, and what to consider when pairing FOX3-3G devices with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, model variant, installation method, and the manufacturer's implementation. Where applicable this page notes model differences such as the audio interface available only on the FOX3-3G-AU variant, and it encourages verification with official Falcom documentation for device specific details.

## Feature Overview

The FOX3-3G Series is positioned as a compact vehicle telematics gateway that combines high-speed mobile data and advanced GNSS positioning with flexible input and output options. It is intended for fleet tracking, driver behavior monitoring, and data collection for logistics use cases, and its modular approach supports accessory expansion for additional capabilities.

- Advanced GNSS reception for reliable position reporting in vehicle environments
- High speed mobile data connectivity for fast telemetry and remote data access
- Multiple inputs and outputs for vehicle integration and telemetry collection
- Support for external antennas to improve signal reception where needed
- Expandable functionality via accessory boxes such as IOBOX-MINI, IOBOX-CAN, and IOBOX-WLAN
- Premium features for mobile data logging, encrypted data handling, and event history modes

## Core Features of Falcom - FOX3-3G

- Advanced GNSS technology for precise location and tracking
- High speed mobile data connection to support frequent reporting and remote data transfer
- Expandable I O and accessory support including IOBOX-MINI IOBOX-CAN and IOBOX-WLAN for extended telemetry
- Premium-Features suite including mobile data logging multiple history modes and data encryption
- Eco drive and driver behavior monitoring capabilities for operational insight
- GSM and GPS jamming detection to improve security and signal awareness
- Standard telematics functions such as status reports alert messaging and geofencing
- Audio call and spy call functionality available on the FOX3-3G-AU model only

## How These Features Work with Plaspy

Plaspy receives and normalizes incoming data from compatible trackers including the FOX3-3G Series so that location information events and logged histories can be monitored and acted on within a single fleet management interface. Plaspy is built to present device features in ways that support operational workflows and oversight.

- Live location and tracking on Plaspy maps using GNSS position reports from the device
- Event and alert visibility for status reports alert messages geofence triggers and jamming detection notifications
- Historical route replay and data history views that reflect device history modes and logged telemetry
- Access to logged data and encrypted payloads presented through Plaspy reporting and export tools
- Visibility of expanded I O and accessory inputs when the device is paired with IOBOX modules and reporting that information into Plaspy
- Automatic protocol detection by Plaspy so FOX3-3G devices can be recognized and integrated without manual protocol selection

## Typical Use Cases

- Fleet vehicle location tracking and route monitoring for daily operations
- Logistics and delivery oversight using frequent position updates and history playback
- Driver behavior and eco driving programs that use behavior monitoring data to improve efficiency
- Integration of vehicle sensors and external boxes for expanded telemetry in specialized fleets
- Security monitoring for attempts at GSM or GPS jamming and related alerting
- Remote voice interactions when using the audio enabled FOX3-3G-AU model for call scenarios

## Feature Availability Notes

- Feature sets may differ between FOX3-3G models and regional variants; the FOX3-3G-AU model includes audio interfaces not present on other variants
- Firmware versions and hardware revisions can enable or change Premium-Features behavior such as history modes or data encryption
- IOBOX accessories are optional expansions and may require separate configuration and installation
- Installation type and wiring affect which inputs and outputs are available for telemetry reporting
- Always confirm current feature lists and firmware behavior with Falcom documentation for the specific device serial and model

## Why Use Plaspy with These Features

Pairing the Falcom FOX3-3G Series with Plaspy provides a centralized way to collect position data events and logged histories across a mixed fleet, presenting those inputs in dashboards alerts and reports that help operations and fleet managers make decisions. Plaspy's device detection and data normalization make it straightforward to incorporate FOX3-3G devices and any attached IOBOX expansions into monitoring and reporting workflows.
