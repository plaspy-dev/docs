# Falcom - FOX-EN Features

This page provides a public feature overview for the Falcom FOX-EN and how its capabilities are used within Plaspy for tracking, monitoring, and operational visibility. It is intended to explain the practical, non-sensitive functions of the device and how those functions map to common workflows in Plaspy.

Exact availability of specific features can vary by firmware version, hardware revision, installation type, and the manufacturer's configuration choices. For final device capabilities and the latest technical details consult the official Falcom documentation and firmware release notes.

## Feature Overview

The FOX-EN is presented as a flexible and adaptable GPS tracker suitable for AVL, fleet management, vehicle security, and recovery use. It is designed to operate autonomously, exchange status and alert messages with servers and users, and support configurable behavior to meet different operational needs.

- Configurable reporting and alerting to tracking servers and to users via SMS
- Integration-ready device that can exchange relevant information with existing systems
- Geofencing and route or area violation reporting for compliance and monitoring
- Voice call features for routine checks and emergency listen-in calls
- Built-in history and data logging that supports driver logbook style records

## Core Features of Falcom - FOX-EN

- Adaptable configuration that can be tuned to specific user requirements and installation needs
- Ability to send status reports and alert messages to tracking servers and to users via SMS
- Geofencing support for reporting entry, exit, and violation of predefined areas or routes
- Voice call capabilities including scheduled calls and emergency listen-in calls
- Autonomous operation with local logic to interact with connected sensors and actors as configured
- Historical data logging and driver logbook style history for post trip review and audit

## How These Features Work with Plaspy

Plaspy can receive and interpret the FOX-EN reports and alerts to provide centralized visibility, event tracking, and historical reporting. Plaspy automatically detects many common tracker protocols which simplifies device onboarding and reduces the need for manual protocol selection.

- Status reports and alerts from the device appear in Plaspy as device events and notifications
- Geofence and route violation messages are translated into Plaspy geofence events for monitoring and alerts
- Logged historical data from the FOX-EN can be presented in Plaspy timelines and trip histories
- Voice call related events or alerts can be surfaced in Plaspy event lists when the device sends related status messages
- Plaspy provides centralized configuration and monitoring tools that let operators view FOX-EN behavior alongside other fleet devices

## Typical Use Cases

- Fleet location tracking and operational oversight for scheduled routes and vehicle movements
- Vehicle security monitoring with alerts for unauthorized area or route deviation
- Remote status reporting to support maintenance planning or operational notifications
- Recovery workflows where timely alerts and location history support asset retrieval
- Driver logbook consolidation for travel recordkeeping and compliance review

## Feature Availability Notes

- Feature support varies by FOX-EN firmware version and software configuration from the manufacturer
- Hardware revisions or optional modules may alter which functions are available on a particular unit
- Installation choices and how the device is wired or integrated can affect the behavior of autonomous logic and connected actors
- Regional variants or regulatory constraints can influence available reporting methods such as SMS services
- Always confirm the feature set of units you purchase with Falcom and review firmware change logs for updates

## Why Use Plaspy with These Features

Using the Falcom FOX-EN together with Plaspy provides a straightforward way to centralize tracking data, alerts, and historical records. Plaspy’s platform can translate the FOX-EN’s status reports, geofence messages, and logged history into actionable dashboards and event feeds that improve visibility and operational decision making.
