# Cityeasy - 201 Features

This page provides a public feature overview of the Cityeasy 201 car GPS tracker and how those capabilities integrate with Plaspy for tracking and fleet monitoring. It is written to describe the practical, user-facing functions you can expect when using the Cityeasy 201 together with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific details and the latest firmware notes, consult the manufacturer's documentation in addition to Plaspy guidance.

## Feature Overview

The Cityeasy 201 is a compact vehicle tracker focused on reliable location reporting and basic tamper awareness. It combines LBS and GPS positioning for live location, stores route history for review, and includes a vibration alert for movement monitoring. The unit is designed for outdoor use with an IP67 rating and includes a removable high capacity battery for extended operation between charges.

- Real time position tracking using LBS and GPS for continuous location awareness.
- Vibration alert system to notify of unauthorized movement or potential tampering.
- Historical route relay for route history and playback of past trips.
- IP67 waterproof rating for protection in outdoor vehicle environments.
- Removable 5000mAh battery to support extended operation and easy servicing.

## Core Features of Cityeasy - 201

- LBS/GPS real time positioning for current location updates.
- Vibration alert system that reports detected movement events.
- Historical route relay enabling retrieval and review of past routes.
- IP67 waterproof design suitable for exterior vehicle mounting environments.
- Removable 5000mAh battery for extended runtime and simple replacement.
- Designed for vehicle tracking scenarios including personal cars and light fleet use.

## How These Features Work with Plaspy

When paired with Plaspy, the Cityeasy 201's location and event data become visible through Plaspy's monitoring and reporting interfaces. Plaspy automatically detects compatible tracker protocols and ingests the device's position and event messages so teams can monitor vehicles in real time and review past activity.

- Live location shown on the Plaspy map for immediate situational awareness.
- Historical route data available in Plaspy for route playback and analysis.
- Vibration alerts registered as events so operators can investigate suspected tampering or movement.
- Device online and event visibility inside Plaspy to support operational oversight.
- Plaspy automatically detects tracker protocol and receives data so initial setup is typically straightforward.

## Typical Use Cases

- Real time tracking of personal vehicles to monitor location and movement.
- Light fleet monitoring where route history and movement events support operations.
- Theft or tamper detection workflows using vibration alerts to trigger investigations.
- Route review for operational analysis and record keeping.
- Outdoor deployments where waterproof protection is required.
- Scenarios where removable battery access simplifies maintenance or replacement.

## Feature Availability Notes

- Feature availability may depend on the installed firmware version and feature set enabled by the manufacturer.
- Hardware revisions or regional variants can affect which positioning methods or alerts are supported.
- Installation type and how the unit is mounted can change LBS versus GPS performance and vibration sensitivity.
- Manufacturer documentation should be consulted for precise battery handling, charging, and replacement instructions.
- Plaspy reflects the data the device reports; not all device telemetry may be forwarded to Plaspy depending on firmware and settings.
