# TK-Star - TK980 Features

This page provides public feature context for using the TK-Star TK980 with Plaspy. It explains the tracker capabilities that are relevant to fleet managers, rental operators, and private vehicle owners who plan to connect the TK980 to Plaspy for real time tracking, telemetry and alerting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. Always consider those variables when planning deployment and consult the official TK-Star documentation for device specific technical details and updates.

## Feature Overview

The TK980 is a plug and play OBD2 tracker designed for quick installation and continuous vehicle monitoring. When used with Plaspy, it provides location awareness and OBD2 telemetry to support real time visibility, alarms, and historical route analysis.

- Plug and play OBD2 installation for fast deployment without additional wiring
- Multi mode positioning combining GPS, BeiDou and GLONASS with LBS and Wi Fi hybrid support for improved coverage
- 4G cellular connectivity with NB IoT and CAT M1 plus 2G fallback for broad network reach
- Built in vibration sensing to detect movement and trigger anti theft alerts
- Geo fencing, overspeed and move alerts with server side historical route storage up to six months
- Compact IP66 rated housing suitable for vehicle environments

## Core Features of TK-Star - TK980

- Direct OBD2 plug in for vehicle diagnostic access and telemetry reporting
- Multi constellation GNSS support including GPS BeiDou and GLONASS for robust positioning
- Hybrid positioning with LBS and Wi Fi to improve indoor and urban performance
- Cellular connectivity that supports 4G NB IoT and CAT M1 with 2G fallback for coverage redundancy
- Built in vibration sensor for movement detection and alarm triggering
- Server side storage of historical routes for retrospective trip review up to six months
- Compact rugged form factor with IP66 environmental protection
- Small rechargeable backup battery to enable temporary tracking and alarm delivery if vehicle power is lost

## How These Features Work with Plaspy

When the TK980 is connected to Plaspy, its location and OBD2 telemetry are reported to the platform so operators can monitor vehicles in real time, configure automated notifications and review historical trips. Plaspy ingests positioning and vehicle parameter data to present actionable views for operations and security teams.

- Real time location updates and hybrid positioning data displayed on Plaspy maps
- OBD2 derived vehicle parameters and diagnostics shown as telemetry and status information in Plaspy dashboards
- Vibration triggered movement and unauthorized motion alerts feeding into Plaspy alarm and notification workflows
- Geo fencing, overspeed and move alerts configurable in Plaspy to automate fleet policies and compliance checks
- Historical route storage accessible from Plaspy for audits trip review and analytics

## Typical Use Cases

- Fleet management for route visibility driver oversight and trip history analysis
- Vehicle anti theft monitoring using vibration alerts and rapid notification
- Rental and car sharing operations benefiting from quick OBD2 installation and server side trip logs
- Cargo and equipment transport where hybrid positioning improves tracking in mixed indoor and outdoor environments
- Vehicle health awareness using OBD2 telemetry to observe basic diagnostics and planning preventive maintenance
- Short term installations and trials where plug and play setup speeds deployment

- Installation method and vehicle OBD2 port behavior can influence sensor readings and alarm reliability
- For the latest technical specs regulatory information and firmware changelogs consult the manufacturer documentation
