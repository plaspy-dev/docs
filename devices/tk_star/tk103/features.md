# TK-Star - TK103 Features

This page describes the public feature context for using the TK-Star TK103 tracker with Plaspy. It summarizes the tracker capabilities most relevant to vehicle location and monitoring, and explains how those capabilities are represented in Plaspy for operational visibility and oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Users should treat the details below as general, practical guidance and verify device specific behavior against the official TK-Star documentation and current firmware notes.

## Feature Overview

The TK103 is a vehicle GPS tracker designed to provide position reporting and basic remote monitoring using the GSM GPRS network together with GPS satellite positioning. It is commonly used to monitor vehicle location, detect movement and speed events, and trigger alarms or remote control actions via SMS or platform commands.

- Real time positioning and location reporting for vehicle tracking and route visibility
- Emergency alarm function to notify authorized contacts when triggered
- Remote commands for controlling engine power and main circuits via SMS based controls
- Remote audio monitoring that allows a caller to listen to sound near the unit
- Movement and overspeed alerts that notify authorized numbers when thresholds are met
- Geo fence capability to define areas and receive breach notifications

## Core Features of TK-Star - TK103

- Positioning and tracking using GPS coordinates reported over the cellular network
- Emergency alarm that sends alerts to predefined phone numbers
- Remote oil and circuit control via SMS commands to enable or disable vehicle power
- Remote monitoring by calling the device to listen to ambient sound near the unit
- Movement alerts that report when the unit begins to move
- Overspeed alerting to notify when a set speed limit is exceeded
- Geo fence setup with breach notifications to authorized contacts
- Mileage statistics and ACC status checking as part of operational reporting

## How These Features Work with Plaspy

Plaspy receives and decodes the TK103 reports and presents position, events, and historical data through its mapping and reporting interfaces. Plaspy automatically detects common tracker protocols and maps supported events to platform alerts and history entries so teams can monitor vehicles in real time.

- Live and historical location display on Plaspy maps for route reconstruction and tracking
- Alarm and event notifications in Plaspy for emergency alarms, movement, overspeed, and geofence breaches
- Event history and timelines that include movement starts stops and mileage summaries when provided by the device
- Visibility of ACC or power status changes as reported by the tracker
- Remote command outcomes shown as events when the device reports state changes back to Plaspy

## Typical Use Cases

- Fleet management for real time location tracking, route monitoring, and mileage reporting
- Vehicle rental monitoring to detect movement, set geo fences, and receive alerts on breaches
- Asset protection and theft response using emergency alarm and remote power control features
- Monitoring of personnel or assigned vehicles for operational oversight and safety
- Compliance monitoring to detect overspeed events and to log movement histories

## Feature Availability Notes

- Some features depend on the TK103 firmware version and may differ between hardware revisions
- Remote control functions such as oil and circuit cut off require correct wiring and installation and may be restricted by vehicle setup
- Geo fence, overspeed, and movement alerts rely on the device sending the relevant event messages to the platform
- Regional variants and SIM configuration can affect reporting intervals and SMS based controls
- Always check the device settings and manufacturer documentation for the precise steps to enable each function
