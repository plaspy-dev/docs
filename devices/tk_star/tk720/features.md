# TK-Star - TK720 Features

This page provides a public overview of the TK-Star TK720 feature set and how the device integrates with Plaspy. It focuses on the practical, user facing capabilities you can expect when the TK720 is used for real time tracking, alerting, and basic remote control workflows within the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, cellular configuration, and manufacturer implementation. For device specific installation guidance, firmware notes, and the most current technical specifications consult the official TK-Star documentation.

## Feature Overview

The TK720 is a compact relay tracker intended for motorcycles, cars, rental vehicles and light equipment. It combines multi GNSS positioning with assisted methods for improved outdoor and indoor location and provides a focused set of security and fleet management functions designed to integrate with Plaspy.

- Multi GNSS positioning including GPS, Beidou and GLONASS with supplemental LBS and Wi Fi for improved coverage in mixed environments
- Sensitive built in vibration detection to notify on impacts or tampering
- Geo fencing, move alerts and over speed notifications to monitor zones and driving behavior
- Remote engine cut off and resume using the relay output for immobilization and recovery actions
- Server side historical route storage for approximately six months to support playback and audits

## Core Features of TK-Star - TK720

- Multi GNSS positioning using GPS, Beidou and GLONASS plus LBS and Wi Fi positioning where available
- Sensitive vibration sensor for instant impact or tamper alerts
- Geo fencing support to detect entry and exit of predefined areas
- Move detection and over speed alerts for behavior monitoring and policy enforcement
- Relay output for remote engine cut off and resume control
- Compact physical form factor suited to motorcycles, scooters, cars and light assets
- Server side route storage retained for approximately six months for retrospective review

## How These Features Work with Plaspy

When the TK720 is commissioned for use with Plaspy, the device reports location and event data to the Plaspy platform where that information is presented to users through maps, dashboards and reports. Plaspy provides consolidated visibility over device locations, alerts and stored routes to support monitoring and operational response.

- Real time location updates appear in Plaspy maps for live tracking and fleet situational awareness
- Vibration, move and over speed alerts are forwarded to Plaspy for notification and escalation workflows
- Geo fencing events trigger Plaspy notifications and can be used to drive automated responses or reporting
- Remote immobilizer commands issued via Plaspy are routed to the device for secure engine cut off and resume actions
- Historical route playback uses the server retained data to review trips, timelines and event context

## Typical Use Cases

- Fleet anti theft and recovery using vibration alerts and remote immobilization
- Rental vehicle monitoring to enforce geographic boundaries and resolve usage disputes
- Motorcycle and scooter protection where discreet, compact installation is required
- Driver behavior monitoring for over speed and move alerts to support coaching and compliance
- Light equipment tracking for small assets that need compact trackers with remote control options
