# TK-Star - TK720

![TK720](./tracker.jpg)

The TK-Star TK720 is a compact relay GPS tracker designed for motorcycles, cars, rental vehicles and light equipment. It combines a UBLOX GNSS receiver with multi position methods including GPS Beidou GLONASS plus LBS and Wi Fi to provide dependable outdoor and indoor location reporting in a small form factor. The device focuses on core tracking and security features such as vibration detection geo fencing move and over speed alerts together with remote engine cut off control.

As a Plaspy compatible device the TK720 integrates with Plaspy for live tracking fleet visibility and operational oversight. When connected to Plaspy the tracker forwards location updates alerts and historical route data so fleet managers and vehicle owners can receive immediate notifications review trip history and use remote control features through the Plaspy platform to support anti theft workflows and routine fleet management.

## Key Highlights

- Compact lightweight relay tracker suited to motorcycles scooters cars and light equipment
- Multi GNSS positioning with supplemental LBS and Wi Fi to improve indoor and urban location
- Sensitive vibration detection for rapid alerting on impacts or tampering
- Geo fencing move and over speed alerts to support zone enforcement and driver monitoring
- Remote engine cut off and resume capability for vehicle immobilization and recovery operations
- Server side historical route storage for approximately six months for audits and trip review
- Integration path with Plaspy for real time visibility and event management

## How It Works with Plaspy

The TK720 periodically reports position and event data to Plaspy where that information is presented on maps dashboards and reports. Plaspy ingests alerts and telemetry from the device to enable real time monitoring escalation and historical analysis while providing authorized users a way to review history and issue supported remote commands.

- Real time location updates sent to Plaspy for live map visualization and fleet monitoring
- Vibration impact move and over speed alerts forwarded instantly to Plaspy for notifications
- Geo fencing events trigger Plaspy notifications and can be used to start automated workflows
- Remote immobilizer and engine cut off commands routed through Plaspy for secure recovery actions
- Historical route playback on Plaspy using up to approximately six months of stored server data
