# TK-Star - TK905 Features

This page summarizes the public feature context for using the TK-Star TK905 GPS tracker with Plaspy. It highlights the device capabilities most relevant to fleet managers and asset operators, and explains how the tracker’s location and event data are typically used inside Plaspy for monitoring, alerting, and reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method, and manufacturer implementation. For device specific commands, wiring, and the latest technical details consult the official TK-Star documentation from the manufacturer.

## Feature Overview

The TK905 is a rugged, long endurance 4G tracker intended for vehicle and asset tracking where reliable positional data and movement alerts matter. It combines multi mode positioning and a long life battery to support extended deployments and anti theft monitoring while feeding location and event data into Plaspy for operational oversight.

- Real time tracking for vehicles, rental fleets, containers and mobile equipment
- Multi mode positioning using GNSS plus network based methods to improve coverage indoors and in urban areas
- Long endurance battery and power management for deployments without constant external power
- Built in vibration movement detection for rapid anti theft alerts
- Geo fence and overspeed alert capabilities with route history retention for post event review

## Core Features of TK-Star - TK905

- Multi constellation GNSS positioning including GPS, BeiDou and GLONASS for improved fix reliability
- Multi mode location support that includes network based positioning methods to supplement GNSS
- 4G cellular connectivity with fallback across common cellular generations for broad regional support
- Large rechargeable battery designed for extended standby and long term asset tracking
- IP65 rated enclosure suitable for outdoor vehicle and equipment mounting
- Sensitive vibration sensor that generates move and vibration alerts for anti theft workflows
- Geo fence detection and overspeed alerting with historical route storage available on the server
- Compact form factor intended for vehicle and container mounting or portable deployments

## How These Features Work with Plaspy

Plaspy ingests the TK905’s location fixes and event signals so operators can monitor assets in real time, receive alerts, and analyze historical movement. The device supplies the core telemetry Plaspy needs to present location, events, and route history on maps and dashboards.

- Real time location updates appear on Plaspy maps for live monitoring and dispatch workflows
- Geo fence and overspeed events are forwarded to Plaspy as notifications and timeline events
- Move and vibration alerts are logged as events so operators can trigger investigations or alarms
- Historical routes and stored telemetry are available in Plaspy for replay and reporting
- Plaspy can accept extended telemetry supplied by an installation or paired hardware when those inputs are present and configured

## Typical Use Cases

- Fleet tracking and route monitoring for vans, cars, and small trucks
- Rental vehicle protection using geo fences and movement alerts
- Anti theft monitoring for parked vehicles and unattended equipment
- Container and cargo tracking where long battery life and outdoor performance are important
- Temporary or portable asset tracking for equipment that is moved between sites
- Remote equipment oversight when external power is intermittent

## Feature Availability Notes

- Firmware and regional hardware variants can change which features or alert types are available
- Installation choices such as permanent wiring versus portable placement affect which telemetry and inputs are present
- Network availability and regional cellular band support influence real time reporting performance
- Manufacturer settings and server configuration determine route retention and alert delivery behavior
- Consult TK Star documentation for the exact commands, LED behaviors, and configuration options for your device

## Why Use Plaspy with These Features

Using the TK905 together with Plaspy gives organizations a single platform to collect location fixes, view events, and manage alerts from distributed vehicles and assets. The tracker’s multi mode positioning and movement detection supply the fundamental signals Plaspy needs to provide situational awareness, historical route analysis, and timely notifications for operational decisions.
