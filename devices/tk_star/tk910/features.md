# TK-Star - TK910 Features

This page provides a public, features-oriented overview of the TK-Star TK910 GPS tracker and how its capabilities map to the Plaspy platform. It focuses on practical, non-sensitive feature descriptions useful for fleet managers, vehicle owners, and technical evaluators who want to understand what the TK910 can deliver when reporting into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation method, and manufacturer implementation. Use this page as a general guide and consult the manufacturer documentation and Plaspy configuration guidance for device specific setup and the latest details.

## Feature Overview

The TK910 is a compact 2G GPS tracker designed for motorcycles, cars, rental vehicles and similar mobile assets. It combines multi constellation GNSS positioning with network and Wi Fi assistance and provides event driven alarms and optional immobilization to support anti theft and fleet monitoring workflows.

- Multi constellation positioning with GPS Beidou and GLONASS plus LBS and Wi Fi assistance for improved indoor and mixed environment fixes.
- Vibration and move detection that generate alarms for anti theft monitoring and event driven notifications.
- Geofence and overspeed alerts to help enforce operational rules and trigger reviews in Plaspy dashboards.
- Optional remote engine cut off immobilizer to support urgent vehicle immobilization when configured.
- Historical route storage and playback for review and reporting of past trips and incidents.

## Core Features of TK-Star - TK910

- Multi constellation GNSS support including GPS Beidou and GLONASS with assisted LBS and Wi Fi positioning.
- Vibration sensor with move and vibration alarm logic for theft detection scenarios.
- Geofencing capability to create area based alerts for entry and exit events.
- Overspeed detection that reports speed based alerts to the platform.
- Optional remote engine cut off immobilizer function when the feature and wiring are present.
- GSM GPRS 2G connectivity for real time position and event reporting.
- Compact form factor suitable for discreet installation on two wheelers and small vehicles.

## How These Features Work with Plaspy

When the TK910 is integrated with Plaspy, the tracker forwards location fixes and event messages that Plaspy ingests, normalizes, and presents in dashboards and notifications. Plaspy automatically detects supported tracker protocols so devices can report with minimal manual protocol selection.

- Real time position updates and assisted fixes appear on Plaspy maps for live monitoring and route tracing.
- Vibration move geofence and overspeed alarms are converted into notifications and event logs for operator awareness and escalation.
- Historical tracks and event timelines are archived in Plaspy for review and reporting up to the retention period supported by the device and server.
- Remote immobilizer commands can be issued from Plaspy to the device where the optional cut off is present and configured.
- Plaspy uses a unified server endpoint and automatic protocol detection to simplify device onboarding and management.

## Typical Use Cases

- Rental and shared mobility scenarios where geofence and historical playback help resolve disputes and monitor returns.
- Overspeed enforcement and driver behavior monitoring through event alerts and reporting.
- Dispatch and operational visibility where live position and alerts support faster response.
