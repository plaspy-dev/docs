# TK-Star - TK750 Features

This page provides a public feature overview of the TK-Star TK750 and how its capabilities map to Plaspy for live tracking, fleet monitoring, and anti-theft workflows. It focuses on user-facing functionality and practical uses when the device is used with Plaspy, rather than detailed configuration or private implementation steps.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device-specific technical details and the latest firmware notices consult the manufacturer documentation and release notes prior to deployment.

## Feature Overview

The TK750 is a compact 4G-capable tracker designed for motorcycles, private cars, light trucks, rental fleets, and electric vehicles. It combines multi-constellation positioning with network assistance and broad cellular options to support reliable outdoor positioning and improved coverage in urban or indoor-adjacent environments.

- Multi-constellation GNSS support (GPS, GLONASS, BeiDou) for more consistent position fixes in varied environments.
- LBS and Wi‑Fi assistance to improve positioning when satellite signals are weak.
- Broad cellular connectivity including 4G FDD/TDD, WCDMA, GSM and support for NB‑IoT and Cat‑M1 where available.
- Vibration sensor, geofence functionality and movement/overspeed alarms for anti-theft and alerting workflows.
- Remote engine cut-off and resume control to support immobilization as part of theft mitigation.
- Compact form factor and options for hardwired or covert installation suited to motorcycles and rental vehicles.

## Core Features of TK-Star - TK750

- Multi-constellation GNSS positioning using GPS, GLONASS and BeiDou.
- Assisted positioning via LBS and Wi‑Fi to help with indoor and urban coverage.
- Wide cellular support across 4G, 3G and 2G networks plus LPWA technologies where supported.
- Vibration and movement detection for tamper and anti-theft monitoring.
- Geofence alerts to detect entry and exit of defined areas.
- Remote engine cut-off and resume control for immobilization workflows when integrated with vehicle wiring.
- Compact, discreet hardware form factor suitable for covert mounting and motorcycle installations.

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible trackers like the TK750 to provide live visualization, alerts and historical reporting. Within Plaspy you can monitor device activity, respond to alarms, and review past routes for operational and security purposes.

- Real-time location updates appear on Plaspy maps for live tracking and dispatch visibility.
- Vibration and movement alerts generate notifications in Plaspy to support rapid anti-theft response.
- Geofence and overspeed alarm events are forwarded to Plaspy for automated alerting and workflows.
- Remote immobilization commands can be sent from Plaspy when the device is wired and configured to accept engine cut-off control.
- Historical route playback and stored trips (as provided by device and server retention policies) are available for incident review and compliance.

## Typical Use Cases

- Anti-theft protection for motorcycles and vehicles using vibration alerts and remote immobilization.
- Rental vehicle monitoring with geofence exit alerts, overspeed notifications, and route history for returns and disputes.
- Light fleet tracking for local delivery, service vehicles and small commercial fleets requiring compact trackers.
- Asset monitoring across regions with mixed network coverage, leveraging multi-band cellular support and LPWA where available.
- Covert installations for high-risk vehicles where discreet size and effective tamper detection are important.

## Feature Availability Notes

- Feature sets such as remote engine cut-off or alarm sensitivity can vary by firmware, hardware revision, and regional variant.
- LPWA technologies like NB‑IoT and Cat‑M1 availability depend on local carrier support and the specific unit configuration.
- Some capabilities require professional hardwired installation and correct integration with the vehicle electrical system.
- Historical data retention and route history duration depend on server-side settings and Plaspy account policies.
- Manufacturer documentation should be consulted for the latest hardware specifications, supported bands, and firmware behavior.
