# TK-Star - LK109 Features

This page summarizes the public feature context for using the TK-Star LK109 GPS tracker with Plaspy. It describes the LK109's primary capabilities, the practical value those capabilities provide, and how those functions can appear and be managed inside Plaspy for fleet or asset monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific technical details, configuration steps, and the most current specifications consult the manufacturer documentation and firmware notes.

## Feature Overview

The LK109 is a portable GPS tracker designed for flexible asset and personal monitoring. It combines real time location reporting with configurable alerts and history review to support situational awareness and ongoing oversight.

- Real time tracking to monitor current location of assets or people
- Auto tracking and blind area tracking for continuous position reporting and recovery after coverage gaps
- Geo fence alerts to notify when the tracker crosses defined boundaries
- Movement and overspeed alerts to detect motion and potential policy violations
- SOS button and remote monitoring for emergency notification and remote oversight
- Low battery alert and a sleeping working mode to extend operation between charges

## Core Features of TK-Star - LK109

- Real time GPS tracking for immediate location visibility
- Auto tracking and blind area tracking to capture movement even across coverage interruptions
- History trace checking to review past routes and location history
- GPS plus GSM connectivity for location reporting and remote updates
- Geo fence support with configurable virtual boundaries and alerts
- Movement detection alerts and overspeed notifications
- SOS button for user initiated emergency signaling
- Low battery alert and sleeping working mode to conserve power

## How These Features Work with Plaspy

Plaspy provides a single platform where LK109 reports and events can be visualized, managed, and archived. Plaspy detects compatible tracker protocols automatically and makes location and alert data accessible in maps, lists, and history views.

- Real time positions and auto tracking updates are displayed on Plaspy maps for live monitoring
- Geo fence events and movement or overspeed alerts generate notifications and event logs in Plaspy
- History trace data from the LK109 is available for playback and audit in Plaspy's trip history views
- SOS activations and low battery warnings appear as high priority events for operator attention
- Plaspy centralizes remote monitoring so multiple devices like LK109 units can be managed from one dashboard
