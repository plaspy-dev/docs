# TS-V1 Professional Vehicle GPS Tracker

The TS-V1 is a compact, hardwired GPS tracker built for professional fleet management, theft prevention and vehicle telemetry. Designed for installation in commercial vehicles, construction machines, rental cars and private vehicles, the TS-V1 delivers reliable real-time tracking, geo-fencing, mileage statistics and remote control features such as fuel/power cut-off and SOS alarms. Its rugged design, broad operating voltage range and removable backup battery make it suitable for continuous fleet operation.

Plaspy compatible out of the box, the TS-V1 integrates with third-party online positioning platforms via configurable IP/port settings and supports both SMS and platform-based command/control. That makes it straightforward to add this GPS tracker to your Plaspy setup for centralized real-time tracking, fleet management, anti-theft response and telemetry reporting.

## Key Highlights

- Plaspy compatible: configurable IP/port and platform-friendly protocols for smooth integration with Plaspy dashboards and alerts.
- Real-time tracking: high-sensitivity SiRF III or U‑blox GNSS chip provides approximately 5 m position accuracy for reliable location updates.
- Wide cellular support: 2G/3G/4G support \(bands depend on destination country\) for global connectivity choices.
- Fleet management ready: mileage statistics, ACC/ignition monitoring and over-speed alerts to support operational visibility and reporting.
- Anti-theft & remote control: SOS alarm, compatibility with original vehicle anti-theft systems, and remote fuel/power cut-off outputs.
- Robust power design: DC 9–36V input with removable 3.7V/600 mAh backup battery for continued operation during power loss.
- Flexible I/O and sensors: multiple digital inputs, one analog fuel input and optional temperature/fuel sensors for expanded telemetry.

## How It Works with Plaspy

Integrating the TS-V1 with Plaspy enables a unified view of vehicle location and status. Install the hardwired unit in the vehicle, connect the supplied GPS and GSM antennas, configure the device to point to your Plaspy server \(modify IP and port if required\), and the unit will upload position and event data in real time. Plaspy then handles visualization, geo-fence management, alerts and historical reporting.

- Real-time location and telemetry updates sent to Plaspy for live map tracking and history playback.
- ACC/ignition status monitoring for engine-on/engine-off events and accurate mileage calculation.
- Fuel monitoring via the analog input for fuel sensors \(e.g., TS-C11\) to support fuel monitoring and consumption reports.
- Remote cut-off outputs for fuel or power circuits—use Plaspy or SMS commands to immobilize a vehicle when required.
- SOS, movement, over-speed and geo-fence breach notifications forwarded to Plaspy for instant operator alerts.
- Remote voice monitoring and compatibility with vehicle anti-theft alarms to enhance recovery and incident verification workflows.

## Use Cases

- Fleet management: real-time tracking, mileage reporting and over-speed alerts to optimize routes and driver behavior.
- Anti-theft and recovery: SOS alarm, compatibility with vehicle anti-theft systems and remote fuel/power cut-off for fast response.
- Remote diagnostics & telemetry: ACC status, analog fuel input and optional temperature sensor feed into Plaspy for ongoing vehicle health and fuel monitoring.
- Construction and specialty vehicles: rugged operating range and wide voltage support make the TS-V1 suitable for heavy equipment and special-purpose fleets.
- Rental and shared vehicles: geo-fencing, movement alerts and remote immobilization help enforce usage policies and reduce misuse.
