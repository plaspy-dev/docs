# ThingSys - TS-V1 Features

This page provides a public feature overview for the ThingSys TS-V1 GPS tracker and explains how its capabilities map to Plaspy for centralized tracking, telemetry, and anti theft workflows. It focuses on user facing functions and the practical value the TS-V1 brings when connected to Plaspy, including integration points and operational scenarios that are safe and non sensitive to describe publicly.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and the specifics of installation or wiring. Where the TS-V1 description notes optional sensors or variant cellular bands, those items may not be present on every unit and should be confirmed with the manufacturer documentation or the device you receive.

## Feature Overview

The TS-V1 is a compact, hardwired vehicle tracker intended for professional fleet and anti theft use. It offers in-vehicle telemetry, event reporting and configurable connectivity options so units can upload position and status data to platforms such as Plaspy for real time visibility and historical reporting.

- Real time GNSS position reporting for live map tracking and history playback.
- Geo fencing and event driven alerts for movement, over speed, and zone breaches.
- Mileage and ignition status reporting to support fleet usage statistics and run time accounting.
- Remote control outputs for fuel or power cut off and SOS alarm reporting to support anti theft response.
- Configurable connectivity with platform friendly IP and port settings plus SMS command support for remote configuration and control.
- Removable backup battery and wide operating voltage support for continued operation during power interruptions.

## Core Features of ThingSys - TS-V1

- Real time GNSS tracking with manufacturer stated accuracy to support reliable position updates.
- Geo fence support and movement alerts for perimeter monitoring and unauthorized movement detection.
- Mileage statistics and ACC or ignition monitoring to help calculate distance and engine on time.
- Over speed detection and event reporting to help manage driver behavior.
- SOS alarm input and compatibility with vehicle anti theft systems for rapid alerting.
- Remote digital outputs for fuel or power cut off to enable immobilization when required.
- Configurable connectivity that supports platform based command and SMS control for remote management.

## How These Features Work with Plaspy

When a TS-V1 is connected to Plaspy, device events and position updates become visible within the Plaspy platform so operators can monitor and act on vehicle status in real time. Plaspy handles visualization, alerting and historical reports while the TS-V1 supplies location and event data.

- Live location updates and history playback provide map based tracking and trip reconstruction inside Plaspy.
- Geo fence events, over speed notices and movement alerts become actionable operator notifications.
- Ignition and mileage data feed fleet reports and utilization dashboards for accurate operational metrics.
- SOS alarms and anti theft events are forwarded to Plaspy so teams can be notified and respond quickly.
- Remote outputs such as fuel or power cut off can be triggered by platform commands or via the device SMS interface, with event confirmation returned to Plaspy.
- Plaspy automatically detects common tracker protocols to simplify onboarding of the TS-V1 into your existing Plaspy account.

## Typical Use Cases

- Commercial fleet tracking for route visibility, mileage reporting and driver oversight.
- Anti theft protection and rapid recovery workflows using SOS alerts and remote immobilization.
- Rental and shared vehicle management to enforce usage policies and receive movement alerts.
- Construction and specialty vehicle tracking where rugged power range and backup battery matter.
- Remote telemetry and vehicle status monitoring for maintenance planning and diagnostics.
- Asset security and location auditing across mixed vehicle fleets.

## Feature Availability Notes

- Feature sets may differ by firmware version or hardware revision; not every unit includes all optional inputs or sensors.
- Regional variants may include different cellular band support; check the specific model variant for your destination country.
- Some sensors and I O options referenced by the manufacturer are optional accessories and require compatible wiring or installation.
- Installation type and wiring choices (for example which inputs are connected) affect which events are reported to Plaspy.
- Confirm the exact feature list and wiring diagrams with the manufacturer documentation for the serial number or model batch you receive.
