# ThingSys - TS-G17Ms

![TS-G17Ms](./tracker.png)

The TS-G17Ms by TS is a compact, Plaspy compatible GPS tracker engineered for dependable real-time tracking and practical vehicle management. Designed for motorcycles, cars and commercial vehicles, this 2G quad-band unit pairs a high-sensitivity GPS chipset with flexible reporting modes so fleet managers and vehicle owners can monitor location, alarms and basic telemetry through the Plaspy platform.

Built with security and remote control in mind, the TS-G17Ms supports SOS emergency alerts, remote voice monitoring \(with optional external microphone\), vibration and overspeed alarms, ACC ignition detection and remote fuel/power cut via an included relay. Its wide 9V–75V input range, low-power sleep modes and discreet form factor make it well suited for anti-theft protection, route and driver behavior monitoring and fast asset recovery when integrated into Plaspy.

## Key Highlights

- Plaspy compatible for seamless real-time tracking and centralized fleet management.
- High-sensitivity GPS chipset provides fast satellite acquisition and reliable fixes in weak-signal or urban canyon environments.
- Dual tracking modes: SMS polling for lightweight queries and GPRS trace tracking for continuous online monitoring.
- Multiple security and control features: SOS alarm, vibration and overspeed alerts, and ACC ignition detection.
- Remote immobilizer capability via relay for fuel/oil circuit cut—enable vehicle shutdown remotely when required.
- Low power consumption with sleep modes and broad vehicle voltage compatibility \(9V–75V\) for a wide range of vehicles.
- Compact, easy-to-hide form factor for discreet installation across vehicle types.

## How It Works with Plaspy

When integrated with Plaspy, the TS-G17Ms streams location and event data so you can view vehicle position, alarms and key telemetry in real time. Plaspy ingests GPRS trace data for continuous monitoring and also supports SMS-based polls for ad-hoc queries. Alerts generated by the device \(SOS, overspeed, vibration, ACC status changes\) appear on Plaspy dashboards and can trigger notifications, geofence events and automated reports for operations teams.

- Real-time location and telemetry updates via GPRS trace tracking or periodic SMS polling.
- ACC ignition detection for start/stop events and driver behavior insights.
- Fuel/power cut via included relay for remote immobilizer actions—useful for anti-theft response.
- SOS emergency alerts and optional remote voice monitoring \(external microphone\) for critical incident response.
- Plaspy integrations can complement the TS-G17Ms with additional telemetry sources — for example, external fuel level sensors or Bluetooth sensors managed through the platform when supported by the vehicle installation.
