# ThingSys - TS-G17Ms Features

This page summarizes the public feature context for using the ThingSys TS-G17Ms tracker with Plaspy. It focuses on the device capabilities that are relevant to fleet managers and vehicle owners when the tracker is integrated into the Plaspy platform for real time location, alarms, and basic telemetry.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method, and manufacturer implementation. Where the TS-G17Ms description mentions optional components such as an external microphone or the included relay, those functions require appropriate installation and may differ between units and firmware releases.

## Feature Overview

The TS-G17Ms is a compact 2G quad band GPS tracker designed for motorcycles, cars, and commercial vehicles. It emphasizes practical tracking and security features that feed location and event data into Plaspy for centralized monitoring and response.

- Real time tracking via GPRS trace reporting with SMS polling available for ad hoc queries
- High sensitivity GNSS positioning for faster satellite fixes and better performance in challenging reception areas
- Built in security alarms including SOS emergency alert, vibration alarm, and overspeed alert
- ACC ignition detection for start and stop events and usage monitoring
- Remote fuel or power cut implemented via the included relay for immobilization when needed
- Wide vehicle voltage support and low power sleep modes for flexible installations across vehicle types

## Core Features of ThingSys - TS-G17Ms

- 2G quad band cellular connectivity supporting GPRS trace tracking and SMS polling
- High sensitivity GPS chipset for reliable position locks in urban and weak signal environments
- SOS emergency alert function to notify monitoring systems and responders
- Remote voice monitoring support with optional external microphone for incident verification
- Vibration and overspeed alarm detection for security and driver behaviour events
- ACC ignition detection input to capture engine on off status
- Included relay for remote fuel or power cut used for immobilization actions
- Wide input voltage range and low power modes suited to motorcycles cars and commercial vehicles

## How These Features Work with Plaspy

When connected to Plaspy, the TS-G17Ms reports location and events so you can view vehicle position and alarms on a central platform. Plaspy accepts GPRS trace data for continuous monitoring and also supports SMS based polling for single queries, allowing mixed reporting modes depending on coverage and configuration.

- Real time location and movement history displayed on Plaspy dashboards via GPRS trace reporting
- SMS polling supported for on demand position requests and basic status checks
- Alarms such as SOS overspeed vibration and ACC status changes are shown as events and can trigger notifications
- Remote immobilizer actions using the relay can be represented in Plaspy as command attempts and follow up status or alarms
- Plaspy can consolidate device events into alerts reports and operational workflows for faster incident handling

## Typical Use Cases

- Vehicle anti theft and recovery workflows using SOS alerts and remote cut off via the included relay
- Real time fleet tracking for route monitoring, dispatch coordination, and asset visibility
- Driver behaviour monitoring with overspeed and ACC event reporting to inform training and compliance
- Motorcycle and discreet vehicle security where compact form factor and wide voltage range are important
- Emergency response and incident verification using SOS and optional remote voice monitoring

## Feature Availability Notes

- Firmware and software revisions can enable or change alarm behavior reporting formats and supported remote commands
- Hardware revisions and regional model variants may differ in supported cellular bands or optional connectors
- Optional features such as external microphone input require correct installation and may not be present on all units
- 2G network availability varies by region and can affect continuous GPRS trace reporting; SMS polling may be used as an alternative where supported
- For installation dependent features such as ACC detection and relay wiring follow manufacturer guidance or an experienced installer

## Why Use Plaspy with These Features

Using the TS-G17Ms with Plaspy gives organizations consolidated visibility into vehicle location and key security events. Plaspy brings tracker telemetry, alarms, and historical position data into one platform so operations teams can monitor fleets respond to incidents and generate operational reports without managing disparate device interfaces.

Plaspy also supports mixed reporting methods and centralized alerting which complements the TS-G17Ms dual reporting modes. This combination helps teams maintain situational awareness and act on security or operational events faster while keeping device management and event history in a single platform.
