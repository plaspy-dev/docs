# ThingSys - TS-V7 Features

This page describes the public feature context for the ThingSys TS-V7 Professional Vehicle GPS Tracker and how those capabilities are used with Plaspy. It focuses on user facing features, practical functions, and what to expect when integrating the TS-V7 with a fleet or vehicle monitoring platform like Plaspy.

Exact availability and behavior of specific features depend on the device firmware, hardware revision, installation method, and the manufacturer implementation. Use this page as a high level guide and confirm device specific details in the official ThingSys documentation for the most current information.

## Feature Overview

The TS-V7 is built as a professional vehicle tracker with a broad set of functions aimed at safety, monitoring, and operational oversight. It supports cellular networks for positioning, several alert types for event notification, and optional accessories that expand telemetry and interface options.

- Multi generation cellular support for network based positioning across common mobile networks
- Positioning and tracking data available via online platforms or smartphone interfaces
- Emergency alarm button that notifies authorized numbers when triggered
- Remote control of vehicle fuel circuit and power features to support vehicle management
- Remote audio monitoring by calling the device to listen to sound in the immediate vehicle vicinity
- Movement alerts, overspeed alerts, geo fence support, mileage statistics, ignition detection, and power cutoff monitoring

## Core Features of ThingSys - TS-V7

- Cellular network support across 2G 3G and 4G to maintain positioning and reporting on available networks
- Position reporting suitable for online platform integration or smartphone viewing
- Dedicated emergency alarm with push button reporting to pre configured contacts
- Remote monitoring capability that allows audio listening to the vehicle surroundings via a call to the unit
- Remote control of fuel and main circuit allowing authorized interruption or restoration of vehicle circuits
- Movement and overspeed alerts that can generate notifications when configured
- Geo fence support to define geographic boundaries and receive exit or entry alerts
- Mileage tracking, ignition detection, and power cutoff awareness for operational metrics

## How These Features Work with Plaspy

Plaspy receives and presents the TS-V7 reporting so operators can monitor location, events, and device state from a central platform. Plaspy automatically detects compatible tracker protocols and shows device activity, alerts, and available telemetry when the tracker sends that data.

- Live and historical location on Plaspy maps for route review and position awareness
- Event notifications for movement, overspeed, geo fence breaches, emergency alarms, and power events
- Logged mileage and ignition events available in Plaspy for usage and reporting
- Remote control actions and power or circuit changes can be reflected in Plaspy when the device and integration support command logging
- Accessory data such as external fuel or temperature sensor readings and RFID events can appear in Plaspy when the TS-V7 transmits that information
- Audio monitoring events or alerts recorded by device triggers can be represented as events or notes in the platform

## Typical Use Cases

- Fleet vehicle tracking for route monitoring, mileage reporting, and driver oversight
- Security monitoring with emergency alarm notifications and audio monitoring for situational awareness
- Remote vehicle immobilization and power circuit control for recovery or security workflows
- Geo fence enforcement to ensure vehicles remain within assigned operational areas
- Fuel and temperature monitoring when external sensors are connected to support operational management
- Integration with accessory systems such as LED advertisement screens or RFID readers for specific operational workflows

## Feature Availability Notes

- Some features require specific firmware versions or hardware revisions to be present and fully functional
- Optional accessories such as fuel sensors, temperature sensors, RFID readers, or LED interfaces may be sold separately and require correct installation
- Network support and cellular behavior can vary by region and mobile operator availability
- Remote control functions may be implemented via SMS, platform commands, or other manufacturer methods depending on device configuration
- Always consult the ThingSys user manual and release notes to confirm how a specific unit implements each feature

## Why Use Plaspy with These Features

Pairing the TS-V7 with Plaspy gives organizations centralized visibility into location, events, and device state across a fleet. Plaspy's device detection and event handling make it straightforward to collect position updates, alerts, and operational metrics from the TS-V7 so teams can act on incidents, analyze usage, and maintain oversight.
