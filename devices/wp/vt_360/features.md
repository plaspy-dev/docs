# WP - VT-360 Features

This page provides a public, non-sensitive overview of the WP VT-360 features and how those capabilities are used with Plaspy for vehicle tracking and monitoring. It summarizes the model’s practical functions, reporting behavior, and the types of alerts and logs you can expect to see in Plaspy without exposing implementation details.

Exact feature availability depends on the unit you receive and how it is deployed. Differences in firmware version, hardware revision, regional cellular variants, and installation method can change which functions are active or how they appear in Plaspy, so review the manufacturer documentation for device specific behavior.

## Feature Overview

The VT-360 is a compact vehicle tracker that pairs GNSS positioning with cellular connectivity to deliver continuous location visibility and event reporting. Its logged history, configurable reports, and alert set make it suitable for fleet oversight and remote monitoring where persistent positioning and event awareness are required.

- Dual GNSS positioning with GPS plus GLONASS for improved location accuracy and reliability
- Real-time tracking for live location updates and operational visibility
- Journey logging with a large waypoint capacity to retain long movement histories
- Configurable reporting and ignition detection to capture usage and trip starts
- Built-in alert types such as geo-fencing reports, towing and speeding alerts, and GSM jamming notices
- Over the air configuration and firmware updates to maintain and adjust device settings

## Core Features of WP - VT-360

- GPS + GLONASS dual mode positioning for enhanced satellite coverage
- 2G and 3G cellular connectivity for wide area data reporting
- Real-time location tracking suitable for live monitoring
- Journey logging with capacity to store over 100,000 waypoints for trip history
- Ignition detection to indicate vehicle on and off events
- Customizable reporting intervals and self-defined report types
- Geo-fence reports, mileage reporting, towing alerts, speeding alerts, and input status change alerts
- Remote configuration and firmware upgrades over the air

## How These Features Work with Plaspy

Plaspy receives the VT-360 telemetry and translates the device’s reports into actionable visibility inside the platform. Plaspy automatically detects common tracker protocols and presents location, history, and alerts alongside vehicle and fleet data for convenient monitoring.

- Live location display and breadcrumb trails using the VT-360 real-time updates and journey logging
- Playback and trip history based on the device’s stored waypoints for post trip review
- Event and alarm notifications in Plaspy for ignition, geo-fence, towing, speeding, and GSM jamming
- Configurable reporting aligned with VT-360 self-defined report capabilities reflected in Plaspy dashboards
- Remote device status and health indicators surfaced so operators can spot connectivity or reporting issues

## Typical Use Cases

- Fleet location tracking and route oversight for light and heavy vehicles
- Trip history and compliance reporting using the device’s long journey log
- Immediate alerts for suspected towing or unauthorized movement
- Ignition based usage monitoring for driver behavior and asset use tracking
- Regional deployments that need dual GNSS accuracy and 2G/3G cellular coverage
- Remote voice communication or monitoring where two-way voice is required

## Feature Availability Notes

- Features may vary by firmware version and manufacturer firmware updates can add or change behaviors
- Hardware revisions and regional cellular band variants can affect cellular connectivity and supported features
- Installation choices and wiring determine which inputs and ignition detection functions are available
- Optional accessories such as external antennas, microphones, speakers, RFID components, displays, or sensors may add capability but are not required for core tracking
- Always verify specific feature presence and behavior against the manufacturer’s official documentation

Using the WP VT-360 with Plaspy gives organizations a centralized way to convert device telemetry into operational insight. Plaspy brings location, event alerts, and historical journeys together in one view so dispatchers, fleet managers, and security teams can make timely decisions based on the VT-360 data. The combination of GNSS positioning, extensive journey logging, and configurable reporting delivers practical value for monitoring vehicle movement and responding to events.
