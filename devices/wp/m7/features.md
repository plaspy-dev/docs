# WP - M7 Features

This page provides a public feature overview of the WP M7 portable GPS tracker and how its capabilities map to the Plaspy platform. It is intended to help users and fleet managers understand the M7's practical functions and how those functions appear when the device is used with Plaspy for vehicle monitoring and tracking.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, and how the device is installed. The information below is grounded in the M7 product description and highlights the features relevant to Plaspy users while advising verification against manufacturer documentation.

## Feature Overview

The WP M7 is a compact, magnetically mounted GPS tracker designed for reliable location reporting, long standby life, and flexible data transmission. It supports several reporting channels and provides tamper and motion detection that are useful for ongoing vehicle oversight.

- Compact portable form factor with magnetic mounting for quick installation
- Accurate GPS positioning combined with GSM GPRS communications for real time reporting
- Multi channel data transmission including SMS, GPRS, UDP, and TCP for flexible connectivity
- Ultra low standby power consumption allowing extended battery life and multi year standby capability
- Tamper or detached alert to notify when the device is removed or disturbed
- IP67 rated enclosure for protection in outdoor and vehicle environments

## Core Features of WP - M7

- Portable magnetic mounting for discreet and fast installation
- High sensitivity GPS location reporting for reliable position updates
- GSM GPRS communications enabling data transmission over cellular networks
- Support for SMS and TCP UDP reporting modes for flexible server delivery
- Detached alert and built in tampering switch for security events
- Motion reporting using the built in acceleration sensor to detect movement
- Low battery level alert and power management settings to extend operational life
- IP67 rated enclosure for water and dust resistance in field conditions

## How These Features Work with Plaspy

When an M7 reports data to Plaspy, the platform consolidates location and event information so teams can monitor device status and vehicle activity. Plaspy automatically detects many tracker protocols and accepts connections from devices configured to report to the platform.

- Location updates from the M7 appear in Plaspy as position points and can be used for live tracking and history playback
- Alerts such as a detached or tamper event and low battery notifications are surfaced as status events in Plaspy
- Motion reports can inform vehicle activity state changes and support event driven monitoring
- The M7 can transmit to the Plaspy data endpoint using standard reporting modes and Plaspy will process incoming messages for visibility
- Power management and reporting behaviors influence how often updates arrive in Plaspy and can be tuned to balance battery life and reporting frequency

## Typical Use Cases

- Temporary or covert vehicle tracking where a compact magnetic unit is needed
- Long term standby tracking for stored or infrequently used assets thanks to extended battery life
- Fleet monitoring for light vehicles or equipment that require occasional location checks
- Security monitoring for vehicles where tamper alerts and motion detection are important
- Outdoor deployments that need a rugged IP67 rated tracker
- Rentals or shared vehicles that benefit from detachable installation and quick redeployment

## Feature Availability Notes

- Firmware and configuration determine which reporting modes and alert types are active on a specific unit
- Hardware revisions and optional modules can affect available features such as additional radio beacons or accessories
- Battery life estimates depend heavily on reporting interval, power management settings, and network conditions
- Regional cellular support and roaming behavior will vary by mobile network availability and the device SIM configuration
- Always consult the manufacturer documentation for the exact feature set of a given serial number or batch

## Why Use Plaspy with These Features

Using the WP M7 with Plaspy gives organizations a single place to view location history, receive alerts, and manage device visibility across a mixed fleet. Plaspy's platform is designed to present location points and event information in a way that helps operations teams maintain situational awareness, respond to incidents, and review historical activity.
