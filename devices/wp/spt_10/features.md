# WP - SPT-10 Features

This page describes the public feature context for the WP SPT-10 portable GPS tracker and how its capabilities are used with the Plaspy platform. It focuses on practical, user facing features and the ways tracking, alerts, and historical data appear when the device reports into Plaspy.

Exact feature availability for any individual SPT-10 unit can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The content below reflects the device description and common features but does not replace the manufacturer documentation for specific firmware behavior or hardware variants.

## Feature Overview

The WP SPT-10 is a compact GPS/GSM/GPRS tracker designed for portable use with real time tracking and a set of security functions. It provides ongoing location reporting, configurable reporting modes, event alerts, and the ability to store and review historical waypoints. When paired with Plaspy, those device events and location updates become part of a unified monitoring view for operations and safety management.

- Real time GPS location reporting suitable for people, pets, assets, and vehicles
- Multiple reporting modes including time based, distance based, and smart reporting
- Large local logging capacity for journey history with long waypoint retention
- Built in panic button for emergency event reporting
- Geo fencing and event triggers for automated alerts and mileage reporting
- Over the air device configuration and firmware updates for remote management

## Core Features of WP - SPT-10

- Real time tracking using GPS with GSM GPRS communication for live updates
- Superior GPS sensitivity to obtain fixes in challenging reception areas
- Panic button to send an immediate emergency alert when pressed
- Configurable reporting modes by time interval, distance interval, or smart mode
- Local journey logging with the ability to store many thousands of waypoints
- Geo fencing support for entry and exit event reporting
- Event and alert types such as emergency alert, speeding moving notifications, and low power alerts
- Security settings including password and SIM pin protections

## How These Features Work with Plaspy

When an SPT-10 is configured to report to Plaspy, its location updates and events appear in Plaspy as actionable telemetry and historical records. Plaspy detects the tracker protocol automatically and reflects the device states and alerts in the platform interface so teams can monitor devices centrally.

- Live location updates show recent GPS fixes and movement on Plaspy maps
- Alerts such as panic events, low power, and geo fence triggers create visible notifications and event logs
- Historical waypoint logs from the device are available for route review and journey reconstruction
- Configurable reporting modes reduce data noise by aligning device intervals with operational needs
- Remote device configuration and OTA firmware actions are coordinated while device data feeds into Plaspy
- Plaspy accepts standard tracker reporting and displays events and statuses without requiring per device custom protocol configuration

## Typical Use Cases

- Monitoring the location of children, elderly family members, or other vulnerable individuals for safety
- Tracking portable assets and equipment during transit or storage
- Vehicle or driver oversight where a small portable tracker is preferred
- Pet tracking where compact size and concealment matter
- Dispatch and operational monitoring for staff who carry a portable tracker
- Logging and reviewing past routes for operational analysis or incident review

## Feature Availability Notes

- Firmware version can change available features and behavior for reporting modes and alerts
- Hardware revisions and regional variants may affect supported frequency bands and local services
- Installation and how the device is used will impact battery life and the frequency of reported waypoints
- Manufacturer settings such as SIM PIN and password protection require correct configuration during setup
- Always confirm OTA update compatibility and procedures against manufacturer instructions prior to applying firmware updates

## Why Use Plaspy with These Features

Pairing the WP SPT-10 with Plaspy gives organizations a way to centralize visibility for portable trackers alongside other fleet and asset devices. Plaspy captures live location, event alerts, and route history from the SPT-10 so teams can act on emergencies, analyze movement patterns, and maintain an audit trail of device activity.
