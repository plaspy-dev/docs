# iTriangle - TS101 BASIC

<div className="device-logo">
![TS101 BASIC](./tracker.png)
</div>

The TS101 BASIC is a compact, rugged GPS tracker designed for essential fleet monitoring and vehicle security. It provides multi constellation GNSS positioning for improved location availability and includes practical vehicle I O to capture ignition and other event signals. Built for continuity, the unit includes onboard storage for thousands of records and a wide vehicle voltage input to support diverse fleet installations.

As a Plaspy compatible device, the TS101 BASIC brings those core telemetry and event streams into the Plaspy platform for real time visibility, alerting, and historical reporting. Its combination of resilient hardware features and remote management capabilities makes it a straightforward option for operators who want dependable tracking and streamlined data flow into Plaspy for operational oversight.

## Key Highlights

- Plaspy compatible device for dependable real time tracking and reporting across fleets and individual vehicles
- Multi constellation GNSS support to improve location availability in varied environments
- Onboard storage for up to 6,000 tracking records to bridge temporary network outages
- Wide voltage input and internal backup battery to preserve telemetry during power interruptions
- Built in motion detection and tamper alerting to support anti theft monitoring and event detection
- Practical I O for ignition monitoring and basic input output control to integrate with vehicle systems
- IP65 rated enclosure and compact form factor for reliable operation in demanding vehicle conditions

## How It Works with Plaspy

When connected to a vehicle, the TS101 BASIC collects position fixes, motion events, ignition status, and I O signals and transmits compact telemetry to Plaspy for ingestion. Plaspy then surfaces this data in live maps, alert rules, and historical reports so operations teams can act on location and event information.

- Real time location and telemetry updates displayed in Plaspy for live tracking and situational awareness
- Ignition and digital input events reported to drive rules, geofence alerts, and driver event tracking
- Onboard record storage ensures points captured during outages sync to Plaspy once connectivity returns
- OTA FOTA and remote configuration workflows enable administrators to update firmware and device settings through supported management paths
- Bluetooth pairing support lets Plaspy display extended telemetry when compatible sensors are used locally with the tracker

## Typical Use Cases

- Fleet management for route monitoring, dispatch support, and utilization analysis
- Anti theft and vehicle security with motion and tamper alerts plus remote workflows using digital output control
- School transport monitoring for ignition and event logging to support safety and compliance
- Logistics and delivery visibility that benefits from onboard storage during coverage gaps
- Sensor enabled telemetry such as fuel or temperature monitoring when paired with appropriate local sensors

## Why Choose This Tracker with Plaspy

The TS101 BASIC is a practical choice for organizations that need a resilient, no frills tracker that integrates into a modern fleet management platform. Its focus on reliable location, event capture, and continuity features like onboard storage and backup power make it suitable for mixed vehicle fleets and routine operational needs.
