# iTriangle - TS101 Basic EV CAN

<div className="device-logo">
![TS101 Basic EV CAN](./tracker.png)
</div>

The TS101 Basic EV CAN is a compact, rugged telematics device designed for dependable vehicle tracking and data logging. Built to serve both electric vehicles and conventional fleets, the TS101 Basic EV CAN provides real time tracking, multi constellation GNSS positioning, and local offline logging to preserve records when network coverage is poor. Its durable IP65 enclosure and wide voltage input make it suitable for a variety of commercial vehicle environments.

As a Plaspy compatible device, the TS101 Basic EV CAN can feed location, event, and telemetry information into the Plaspy platform for centralized monitoring and reporting. Plaspy users can take advantage of the unit’s mixed fleet focus, offline buffering, and event detection to maintain continuous operational visibility, support anti theft workflows, and integrate EV related telemetry into fleet dashboards.

## Key Highlights

- Plaspy compatible real time tracking with multi constellation GNSS for consistent positioning.
- Single channel CAN interface to capture vehicle and EV telemetry for fleet insights.
- Compact IP65 rated housing with wide voltage input for rugged mixed fleet deployment.
- BLE 3.0 support for short range sensor and accessory connectivity.
- Robust offline storage able to buffer thousands of records to avoid data gaps.
- Low power design with internal backup capacity to preserve tracking during interruptions.
- Multiple I O and accelerometer motion detection for event monitoring and anti theft alerts.

## How It Works with Plaspy

When connected to Plaspy, the TS101 Basic EV CAN streams location and event data to the platform and buffers records locally when connectivity is limited. Plaspy ingests the device data to provide live tracking, historical route replay, and event based alerts, helping fleet managers maintain situational awareness and operational records.

- Continuous location updates and route history for fleet visibility and analysis.
- Vehicle status and event reporting based on CAN data and digital input events as configured.
- Offline logging upload to Plaspy after connectivity restoration to prevent gaps in records.
- Sensor and accessory data via BLE associated with vehicle records for richer context.
- Event driven alerts such as motion or tamper detection routed into Plaspy workflows.

## Typical Use Cases

- Mixed EV and conventional fleet tracking where both location and vehicle telemetry are needed.
- Anti theft monitoring and rapid response using motion detection, tamper alerts, and digital control outputs.
- EV telemetry logging for operational oversight and performance trend analysis within Plaspy.
- Short range sensor hubs for driver identification or temperature monitoring tied to vehicle records.
- Rugged commercial vehicle deployments requiring reliable operation across varied power conditions.

## Why Choose This Tracker with Plaspy

The TS101 Basic EV CAN offers a practical balance of rugged hardware and telemetry capability for organizations that rely on Plaspy for fleet management. Its focus on mixed fleet compatibility, offline buffering, and event detection helps maintain continuous operational insight regardless of vehicle type or temporary network outages. Integrating this unit with Plaspy allows teams to consolidate location, event, and vehicle data into a single platform for oversight and reporting.
