# iTriangle - TS101 Basic 4G

![TS101 Basic 4G](./tracker.png)

The TS101 Basic 4G is a compact GPS tracker designed for vehicle telematics and asset monitoring, now fully Plaspy compatible. Built for mixed fleets — electric and conventional vehicles — the TS101 Basic 4G combines LTE Cat‑1 connectivity, GNSS positioning \(GPS/GLONASS/BeiDou\), and edge storage to deliver continuous, reliable real‑time tracking and telemetry for fleet managers who need robust, integrated data on Plaspy.

With a wide 9–90V DC input range, internal 180mAh backup battery, and BLE 5.0 short‑range support, the TS101 Basic 4G keeps vehicles visible and controllable even during power loss or intermittent network coverage. Its configurable I/O, optional CAN/RS485 interfaces, and OTA/FOTA provisioning make it a practical, Plaspy compatible choice for anti‑theft workflows, fuel monitoring, ignition status, immobilizer control, and routine fleet analytics.

## Key Highlights

- Plaspy compatible GPS tracker with LTE Cat‑1 for dependable real‑time tracking and telemetry.
- Wide 9–90V DC input and built‑in 180mAh backup battery for uninterrupted tracking during power loss.
- Multi‑GNSS receiver: GPS, GLONASS and BeiDou for improved positioning in challenging environments.
- Onboard 16 MB data storage capable of retaining up to 6,000 tracking records for offline logging.
- Configurable I/O and optional RS485/CAN interfaces to integrate ignition, immobilizer relays, fuel sensors and CAN bus data.
- BLE 5.0 for Bluetooth sensors and short‑range provisioning or accessory connectivity.
- Movement detection, eco‑driving analysis and geofencing features to support fleet management and driver behavior monitoring.
- OTA/FOTA updates and multiple configuration channels \(USB, SMS, TCP/IP, BLE\) for scalable remote management.

## How It Works with Plaspy

Integrating the TS101 Basic 4G with Plaspy delivers continuous location, event and telemetry streams to your Plaspy dashboard. The device transmits GNSS position fixes and vehicle telemetry via LTE Cat‑1 using TCP/IP, while local BLE and I/O allow Plaspy to correlate sensor inputs, ignition state and immobilizer actions with location history and alerts. Offline records stored on the device are uploaded automatically when network coverage is restored.

- Real‑time location and telemetry updates via LTE Cat‑1 \(TCP/IP\) and multi‑GNSS positioning.
- Ignition, door or alarm status monitoring using the device’s digital input and digital output for event signaling.
- Fuel monitoring and sensor data acquisition through analog input, 1‑Wire interface or optional CAN integration.
- Remote immobilizer support: control immobilization relays or panic outputs via the digital output for anti‑theft workflows.
- Bluetooth sensors and beacons: BLE 5.0 enables short‑range telemetry and accessory connection for temperature, motion or driver ID.
