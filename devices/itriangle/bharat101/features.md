# iTriangle - Bharat101 Features

This page provides a public feature summary for the iTriangle Bharat101 and how its capabilities map to Plaspy for fleet telemetry and operational monitoring. It focuses on practical, non sensitive descriptions of what the device reports and how it can be used with Plaspy for visibility, monitoring, and event-based workflows.

Exact feature availability depends on device firmware, hardware revision, regional variants, and how the unit is installed and configured. The information below reflects the Bharat101 design and common deployment options such as GNSS plus NavIC positioning, embedded eSIM, BLE short range connectivity, digital and analog I O, onboard motion sensors, OTA support, and IP65 enclosure, but operators should verify specifics for their hardware and firmware revision.

## Feature Overview

The Bharat101 is an AIS 140 oriented vehicle tracker built for demanding vehicle environments and direct compatibility with Plaspy. It combines indigenous NavIC augmentation with GPS, a tamper resistant embedded eSIM, short range BLE connectivity, and robust physical protection to deliver continuous location and event telemetry that Plaspy can ingest for fleet dashboards and alerts.

- Combined GPS and NavIC positioning for improved regional accuracy in supported areas
- Embedded eSIM MFF2 for resilient cellular connectivity and simultaneous reporting to multiple servers
- Internal accelerometer and gyroscope for motion, impact, and driving behavior events
- Multiple analog and digital inputs plus digital outputs and RS232 for sensor and peripheral integration
- BLE 4 support for short range sensor or beacon connectivity and OTA/FOTA for remote firmware management

## Core Features of iTriangle - Bharat101

- AIS 140 compliance designed for public and commercial vehicle tracking
- Dual navigation receivers with GPS and NavIC (IRNSS)
- Embedded eSIM MFF2 for managed cellular service and multi server transmission
- Built in accelerometer and gyroscope for motion and impact events
- 2 analog inputs, 4 digital inputs, 2 digital outputs, and RS232 external interface
- BLE 4 for short range sensor and peripheral connectivity
- OTA FOTA capability plus configuration via USB, SMS, TCP IP, and Bluetooth
- Rugged IP65 enclosure and onboard storage for up to 40,000 records with backup battery support

## How These Features Work with Plaspy

Bharat101 devices are Plaspy compatible out of the box and can forward GNSS and NavIC positions, sensor readings, and event data to Plaspy servers for real time monitoring. Plaspy automatically detects the tracker protocol and displays location and event telemetry in dashboards and reports.

- Real time location updates using combined GPS and NavIC positions presented on Plaspy maps
- Motion and impact event records from the accelerometer and gyroscope available for safety and behavior analysis in Plaspy
- Digital input events such as ignition, door, or alarm states are forwarded to Plaspy as discrete events for alerts and reporting
- Analog input values can be transmitted to Plaspy for remote telemetry and integration with custom reports
- BLE device or sensor presence and short range telemetry can extend data available to Plaspy when paired and configured
- Devices can be configured to transmit to Plaspy servers such as d.plaspy.com using TCP or UDP on the standard port used by Plaspy and support multi server forwarding for redundancy

## Typical Use Cases

- Real time fleet tracking for buses, trucks, and commercial vehicles with regional NavIC enhanced positioning
- Public transport deployments requiring AIS 140 compliance and durable IP65 hardware
- Anti theft monitoring and event driven responses using digital inputs and outputs for immobilizer workflows
- Driving behavior and safety analytics using accelerometer and gyroscope event data
- Remote telemetry and fuel or analog sensor monitoring via analog inputs
- Sensor extension and proximity workflows using BLE 4 beacons or short range sensors

Using the Bharat101 with Plaspy provides a straightforward path to combine certified vehicle tracking hardware with a platform designed for fleet visibility and operational oversight.
