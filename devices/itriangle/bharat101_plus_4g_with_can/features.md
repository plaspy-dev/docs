# iTriangle - Bharat101 Plus 4G with CAN Features

This page describes the public feature context for using the iTriangle Bharat101 Plus 4G with CAN GPS tracker with Plaspy. It summarizes the device capabilities that are relevant to fleet tracking, vehicle telemetry, and operational monitoring when the tracker is connected to the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation details, and manufacturer implementation. For device specific installation procedures, supported parameters, and the latest technical specifics consult the official manufacturer documentation linked at the end of this page.

## Feature Overview

The Bharat101 Plus 4G with CAN is a rugged, AIS-140 oriented telematics device built for professional fleet and heavy vehicle use. When paired with Plaspy the tracker provides continuous vehicle location, CAN-sourced diagnostic data, and event-driven alerts to support monitoring, compliance, and theft deterrence workflows.

- AIS-140 certification for regulatory compliance use cases in applicable regions.
- LTE Cat-1 cellular connectivity with fallback for resilient real-time tracking.
- Integrated CAN bus access to surface engine and vehicle diagnostic parameters into Plaspy.
- Rugged IP65 enclosure and wide 9–90V DC input range for reliable vehicle installation.
- Multi constellation GNSS support for improved position accuracy and route replay.
- Onboard sensors and multiple I O options to support ignition detection, tamper alerts, fuel monitoring, and remote immobilization workflows.

## Core Features of iTriangle - Bharat101 Plus 4G with CAN

- AIS-140 certified hardware suitable for commercial fleet and public transport compliance.
- LTE Cat-1 cellular modem with fallback for broad coverage and continuous reporting.
- CAN bus diagnostics to report vehicle parameters and fault related telemetry where available.
- Multi constellation GNSS receiver supporting GPS, Galileo, NavIC and BeiDou for reliable positioning.
- Rugged IP65 rated enclosure and wide input voltage range for harsh environments.
- Multiple analog and digital inputs plus configurable outputs for sensors, ignition, and control functions.
- Onboard accelerometer and gyroscope to support event detection for harsh driving and impacts.
- OTA FOTA firmware update support and onboard storage for offline data logging.

## How These Features Work with Plaspy

Plaspy ingests location, vehicle state, and event data from compatible trackers like the Bharat101 Plus 4G with CAN to produce live maps, trip histories, and diagnostic reports. Plaspy automatically detects compatible tracker protocols and presents incoming telemetry in dashboards and reports for operational teams.

- Live location and historical route replay on Plaspy maps using GNSS data from the device.
- CAN sourced vehicle parameters and diagnostic values available in Plaspy for monitoring and reporting.
- Event visibility in Plaspy for ignition changes, tamper alerts, harsh events, and other sensor triggers.
- Remote control and output state reporting such as immobilizer or output activation reflected in platform logs when configured.
- Offline logging from the device synchronizes with Plaspy after reconnection, enabling data continuity during temporary connectivity loss.
