# iTriangle - TS101 Basic EV Features

This page summarizes the public feature context for using the iTriangle TS101 Basic EV with Plaspy. It focuses on the practical capabilities that matter to fleet managers, EV integrators, and operators who plan to ingest device telemetry into Plaspy for live tracking, event logging, and basic sensor monitoring.

Exact feature availability and behavior can vary depending on firmware version, hardware revision, the specifics of the physical installation, and manufacturer implementation choices. For the most current device-specific details verify the official manufacturer documentation and release notes.

## Feature Overview

The TS101 Basic EV is a compact, rugged GPS tracker designed for electric vehicles and mixed fleets. It provides multi-constellation GNSS positioning, local event buffering, and basic I/O and sensor telemetry with short-range Bluetooth connectivity, making it suitable for straightforward Plaspy integration and resilient field deployment.

- Multi constellation GNSS reception for improved positioning across regions
- Wide voltage tolerance and internal backup battery to support EV and mixed fleet installations
- IP65 rated enclosure and compact form factor for durable vehicle mounting
- Bluetooth 3.0 plus 2G GSM connectivity for local configuration and cellular telemetry
- Onboard accelerometer and tamper detection with local event logging to preserve data during outages

## Core Features of iTriangle - TS101 Basic EV

- Multi-constellation GNSS support including GPS, GLONASS, Galileo, and BeiDou for reliable location fixes
- Wide 9–90V DC power input with an internal backup battery to maintain data capture during power interruptions
- IP65 rugged enclosure and compact dimensions suitable for two- and three-wheeler or larger vehicle installations
- 2G GSM connectivity for reporting telemetry and position data to backend platforms
- Bluetooth 3.0 for local commissioning and short-range sensor pairing or configuration
- Onboard accelerometer and tamper detection for movement and anti-theft event reporting
- Local event storage capable of preserving up to several thousand records to bridge connectivity gaps
- Basic I/O set including analog and digital inputs and a digital output for external sensor and actuator interfacing

## How These Features Work with Plaspy

When integrated with Plaspy, the TS101 Basic EV streams position and event telemetry into the Plaspy platform so operators can monitor vehicles in real time, review historical tracks, and act on movement or tamper alerts. Plaspy automatically detects compatible tracker protocols and maps incoming telemetry to platform views and reports.

- Real-time location updates appear on Plaspy live maps for tracking and route playback
- Movement and tamper events generated by the onboard accelerometer are available as Plaspy alerts and event entries
- Local event buffering ensures recorded telemetry is reconciled into Plaspy after temporary network loss
- Analog and digital input states can be captured and displayed in Plaspy dashboards as basic telemetry channels
- Bluetooth and local configuration options simplify commissioning and on-site setup that align device behavior with Plaspy workflows

## Typical Use Cases

- Centralized fleet management for small commercial operators and electric vehicle fleets requiring reliable position and event telemetry
- Compact tracker installations on two- and three-wheelers where size and IP65 protection are important
- Anti-theft and movement monitoring using accelerometer and tamper detection integrated with Plaspy alerting
- Basic sensor telemetry and vehicle state monitoring via analog and digital inputs for operational oversight
- OEM EV integrations that need a small telematics unit with wide voltage tolerance and local Bluetooth connectivity

## Feature Availability Notes

- Feature set can change across firmware releases; some telemetry fields or behaviors may differ by firmware version
- Hardware revisions and regional device variants can affect cellular bands, Bluetooth behavior, or physical connectors
- Local storage capacity and backup battery runtime depend on configuration and the types of events being logged
- 2G cellular connectivity availability varies by country and mobile operator; check regional network support when planning deployments

Using the TS101 Basic EV with Plaspy provides a practical route to add consistent location awareness and basic telemetry to vehicle fleets and EV deployments. The combination of multi-constellation GNSS, onboard event detection, I/O capability, and local buffering helps organizations maintain visibility and reconcile gaps caused by temporary network outages.
