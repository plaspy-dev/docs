# iTriangle - Bharat101 Plus 4G Features

This page provides a public, non sensitive overview of the iTriangle Bharat101 Plus 4G and how its capabilities map to Plaspy for fleet operators and system integrators. It focuses on the device features that are relevant when the tracker is used as an endpoint feeding location and telemetry into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. For device specific technical details and the latest firmware notes please consult the official iTriangle documentation.

## Feature Overview

The Bharat101 Plus 4G is positioned as an AIS 140 compliant tracker designed for public transport, commercial fleets and heavy equipment. It combines multi constellation GNSS with cellular connectivity and a rugged enclosure to provide continuous tracking, event reporting and remote management when integrated with Plaspy.

- AIS 140 certification for regulatory compliance in supported regions and transport fleets
- 4G LTE Cat 1 connectivity with 2G fallback for broad cellular coverage and real time reporting
- Multi constellation GNSS support including GPS NavIC Galileo and BeiDou for resilient positioning
- Rugged IP65 housing for dust and water resistance suitable for field installations
- Integrated BLE 5.0 for short range sensor and beacon support
- On device offline storage and OTA FOTA support to preserve and update devices during deployment

## Core Features of iTriangle - Bharat101 Plus 4G

- AIS 140 certified GNSS tracking for compliance oriented deployments
- 4G cellular data with fallback to 2G for continuous connectivity
- Multi constellation positioning using GPS NavIC Galileo and BeiDou
- Ignition monitoring panic input and tamper alerts for event driven workflows
- Remote immobilization support via external relay for anti theft operations
- BLE 5.0 for pairing with compatible sensors and beacons
- On device logging with offline storage and OTA FOTA for remote maintenance
- Flexible I O and serial interfaces including RS232 RS485 and analog digital inputs and outputs for external sensor integration

## How These Features Work with Plaspy

When paired with Plaspy the Bharat101 Plus 4G becomes a telemetry endpoint that streams location and events into a central dashboard for monitoring and reporting. Plaspy receives location updates and device events and presents them as live data, historical traces and alarms for operations teams.

- Near real time location updates and multi constellation position fixes visible in Plaspy maps and replay
- Event reporting for ignition changes panic presses and tamper or power disconnect alerts
- Remote immobilizer commands and status reflected in Plaspy control screens where supported by the device installation
- Offline log synchronization after reconnect so historical points and events are retained in Plaspy
- BLE sensor readings and external sensor data sent via the device interfaces can appear in Plaspy dashboards when configured
- OTA FOTA and remote configuration reduce field visits and allow fleet managers to keep devices up to date through supported workflows

## Typical Use Cases

- Public transport compliance and passenger safety reporting for AIS 140 regulated fleets
- Fleet anti theft procedures using tamper alerts and remote immobilization coordinated from Plaspy
- Driver safety and behavior monitoring using motion sensor events for harsh maneuvers
- Logistics and fuel monitoring integrations using analog or serial sensor inputs
- Asset tracking on heavy equipment where wide voltage support and rugged enclosure are required
- Short range monitoring of cargo conditions or proximity using BLE sensors and beacons

## Feature Availability Notes

- Feature presence and exact behavior depend on the installed firmware version and the hardware revision of each unit
- Some integrations such as fuel monitoring require compatible external sensors and proper wiring to the device inputs
- Regional variants or certification differences may affect cellular bands and AIS 140 compliance details
- Remote management methods available can include OTA FOTA TCP IP SMS USB or BLE depending on firmware and provisioning
- Confirm installation specific functions such as relay wiring ignition sensing and panic input mapping with your installer and manufacturer documentation
