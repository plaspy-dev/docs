# iTriangle - TS101 Advance Features

This page describes the public feature context for using the iTriangle TS101 Advance GPS tracker with Plaspy. It summarizes the device capabilities that are relevant to Plaspy users, explains how those capabilities are typically reflected in a fleet management workflow, and highlights practical value for vehicle monitoring, security, and operational oversight.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where specifics matter for deployment, configuration, or regulatory compliance, review the device documentation from iTriangle and check installed firmware and hardware revision before relying on any particular capability.

## Feature Overview

The TS101 Advance is a rugged telematics unit designed to deliver continuous position and event telemetry for vehicle fleets and anti-theft deployments. It combines multi-constellation GNSS positioning, cellular connectivity, on-board motion sensing, and flexible inputs and outputs to provide real-time location, event reporting, and integration points for accessories and vehicle systems.

- Multi-constellation GNSS for improved position reliability in urban and challenging environments.
- 2G cellular connectivity with TCP/IP and SMS support for live reporting and remote commands.
- Built-in motion sensors including accelerometer and gyroscope to capture driving events and harsh movements.
- Comprehensive I/O and RS232 interface for accessory integration such as external sensors and relay control.
- Internal backup battery and tamper detection to support resiliency and anti-theft workflows.
- Remote management options including SMS, USB, Bluetooth, and OTA/FOTA firmware updates for easier maintenance.

## Core Features of iTriangle - TS101 Advance

- Multi-constellation GNSS support (GPS, GLONASS, Galileo, BeiDou) for stable position fixes.
- 2G cellular connectivity with TCP/IP reporting and SMS based management.
- On-board accelerometer and gyroscope for motion detection, harsh event logging, and driving behavior analytics.
- Analog and digital inputs, digital outputs, and an RS232 port for external sensor and relay integration.
- Internal backup battery to maintain tracking and alerts when main power is removed.
- Tamper alerts and ignition detection to support security and ignition-based reporting.
- Rugged IP65 enclosure and wide operating temperature range for demanding outdoor and vehicle environments.
- Bluetooth support for local configuration and BLE sensor connectivity; OTA/FOTA for remote firmware updates.

## How These Features Work with Plaspy

When connected to Plaspy, the TS101 Advance streams location, event, and I/O state information so operations teams can monitor assets, respond to alerts, and analyze historical activity. Plaspy can use the device telemetry and event signals to populate maps, reports, and rule-based alerts that support fleet management and anti-theft workflows.

- Real-time and historical location views in Plaspy for live tracking and route analysis.
- Motion and harsh event data become part of driver behavior and incident reporting inside Plaspy.
- Digital and analog input changes (for example ignition or external sensor triggers) feed into rules and notifications.
- Tamper and backup battery alerts can trigger anti-theft workflows or escalation notifications.
- Remote diagnostics and device state visible in Plaspy help administrators plan maintenance and firmware updates, complementing the device's OTA capabilities.
