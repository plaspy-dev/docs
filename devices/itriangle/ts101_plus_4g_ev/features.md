# iTriangle - TS101 PLUS 4G EV Features

This page provides a public feature overview of the iTriangle TS101 PLUS 4G EV as it relates to Plaspy. It summarizes the practical capabilities you can expect when using this purpose built EV telematics tracker with Plaspy for real time tracking, vehicle telemetry, and fleet monitoring. The content focuses on high level, non sensitive information that helps operators and integrators understand how the device delivers value inside Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation method. Features described here are drawn from the device description and public manufacturer materials; for device specific details such as firmware behavior, configuration methods, and the latest technical specifications consult the official manufacturer documentation.

## Feature Overview

The TS101 PLUS 4G EV is designed to provide continuous location awareness and vehicle telemetry for electric vehicles and mixed fleets. It combines multi GNSS positioning, cellular connectivity, vehicle bus access, and local sensors to feed actionable data into Plaspy for monitoring, alerts, and reporting.

- Multi GNSS positioning for improved accuracy and reliable route replay.
- LTE Cat 1 cellular connectivity with embedded eSIM and fallback for wide coverage.
- Vehicle telemetry via CAN bus and selectable serial interfaces for diagnostics.
- Internal motion sensors to detect harsh events and support driver behavior monitoring.
- Built in BLE 5.0 for proximity sensors and short range extensions without extra antennas.

## Core Features of iTriangle - TS101 PLUS 4G EV

- Multi GNSS support including GPS, Galileo, NavIC, and BeiDou for robust positioning.
- LTE Cat 1 modem with embedded eSIM and 2G fallback for resilient cellular links.
- CAN bus integration and selectable RS232 or RS485 for vehicle diagnostic data.
- Built in accelerometer and gyroscope for motion detection and harsh event flags.
- Internal BLE 5.0 to pair Bluetooth sensors and beacons for extended monitoring.
- OTA and FOTA support for remote firmware and configuration updates.
- Wide 9–90V DC input and rugged IP65 enclosure suitable for diverse EV installations.
- Internal backup battery and onboard storage to retain records during temporary outages.

## How These Features Work with Plaspy

When integrated with Plaspy, the TS101 PLUS 4G EV streams location and vehicle telemetry to the platform so fleet operators can monitor vehicles in real time and act on events. Plaspy automatically detects compatible tracker protocols and ingests GNSS positions, sensor events, and vehicle bus data for dashboards and alerts.

- Real time location updates and historical route replay based on multi GNSS fixes.
- Motion and harsh event reporting from the accelerometer and gyroscope for driver behavior insight.
- CAN bus telemetry appears in Plaspy for diagnostics, uptime monitoring, and performance reporting.
- BLE sensor and beacon data can extend Plaspy visibility to local accessories and proximity use cases.
- Plaspy can receive device reports using standard connections and will auto detect the tracker protocol for easier onboarding.

## Typical Use Cases

- EV fleet management with continuous tracking, route analysis, and remote diagnostics.
- OEM or aftermarket EV integration where CAN bus telemetry is required for vehicle status.
- Micromobility and motorcycle fleet deployments needing rugged hardware and wide voltage support.
- Safety and driver behavior programs using motion event telemetry to reduce incidents.
- Remote maintenance programs using OTA updates and continuous telemetry for proactive servicing.
