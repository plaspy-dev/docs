# Meitrack - TC68L Features

This page provides a public feature overview of the Meitrack TC68L and explains how those features can be used when the device is connected to Plaspy. It focuses on user-facing capabilities and practical uses so you can understand how TC68L data and events appear inside Plaspy for monitoring and operational workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and how the device is installed. Use this content for high-level planning and verification, and consult manufacturer resources for definitive, model-specific technical details.

## Feature Overview

The TC68L is a plug and play OBD II tracker designed for vehicle tracking, anti-theft notifications, and basic telematics. It combines cellular connectivity, backup power, and an SOS function to provide live location and event visibility for private and fleet vehicles.

- Plug and play installation using a standard OBD II connector for quick deployment
- 4G cellular connectivity to support real time location updates and faster data transmission
- Internal backup battery and disconnection alert to maintain tracking and notify when removed
- Built-in SOS button to send immediate distress signals for emergencies
- 4G WiFi hotspot capability to provide internet access for passengers and devices
- OBD data support to access vehicle diagnostics and basic engine information

## Core Features of Meitrack - TC68L

- 4G cellular connectivity for reliable location reporting and faster data delivery
- OBD II plug and play form factor for straightforward installation in vehicles with an OBD II port
- Internal backup battery that allows limited tracking when external power is lost
- Disconnection alert that notifies users when the device is unplugged or loses main power
- SOS button for emergency notifications
- Support for OBD data including access to vehicle diagnostic information
- Built in 3-axis accelerometer for movement and tamper detection signals

## How These Features Work with Plaspy

When a TC68L device is registered with Plaspy, its supported events and telemetry can be surfaced in the Plaspy interface to help teams monitor vehicles and respond to incidents.

- Real time location updates appear on Plaspy maps so operators can follow vehicle movement
- Disconnection and backup battery events are visible in Plaspy as alerts or event entries for anti-theft monitoring
- SOS activations are represented in Plaspy alert streams to enable quick response workflows
- OBD data reported by the device can be recorded and presented as vehicle status or diagnostic information within Plaspy
- Motion or tamper signals from the accelerometer can generate events for activity monitoring

## Typical Use Cases

- Fleet vehicle location monitoring and route oversight for small and medium sized operations
- Anti-theft protection with removal alerts and continuous backup tracking when unplugged
- Personal vehicle safety with a dedicated SOS button for emergency alerts
- Onboard internet access for passengers through the device WiFi hotspot while preserving tracking
- Remote visibility of vehicle diagnostic status via OBD data for maintenance planning
- Short term rental monitoring where plug and play OBD installation simplifies device deployment

## Feature Availability Notes

- Some features such as WiFi hotspot behavior, OBD parameter sets, and alert thresholds can vary by firmware and device revision
- Regional cellular band variants or SKU differences may affect 4G coverage and performance in certain markets
- OBD data availability depends on vehicle make, model, and the specific OBD parameters the vehicle exposes
- The SOS function and removal alerts depend on device configuration and may require enabling specific settings
- Always confirm which hardware variant and firmware is being used when planning deployments
