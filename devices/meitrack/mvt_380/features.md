# Meitrack - MVT-380 Features

This page summarizes the public feature context for using the Meitrack MVT-380 tracker with Plaspy. It focuses on the device capabilities that are relevant when pairing the MVT-380 to Plaspy for monitoring, alerts, and reporting, and explains how those capabilities typically appear in the platform.

Exact availability and behavior of each feature can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device configuration or the most current technical details, consult the manufacturer documentation and your installation provider.

## Feature Overview

The Meitrack MVT-380 provides a set of core tracking and monitoring functions designed for vehicle and asset oversight. Its combination of live location reporting, geofencing, logged history, and remote communication make it suitable for users who need both immediate visibility and historical travel records.

- Real-time tracking to monitor current location and movement
- Geo-fence creation to generate alerts on area entry and exit
- GPS logging that stores routes and distance for later review
- Two-way audio capability for remote voice communication
- Optional engine stop control when a relay accessory is installed
- Energy saving sleep mode to extend operational time between services

## Core Features of Meitrack - MVT-380

- Real-time GPS tracking for continuous position updates
- Geo-fence support to trigger entry and exit notifications
- GPS logging that records traveled routes and distance
- Two-way audio for remote communication with the device
- Remote engine stop command available when a relay is fitted
- Sleep mode to reduce power drain during idle periods
- S.O.S. button for user initiated emergency signaling
- AGPS support for faster position fixes and improved location responsiveness

## How These Features Work with Plaspy

Plaspy receives and interprets the MVT-380 reporting so you can view live location, events, and historical tracks in the platform. Plaspy is built to present device events and location data in dashboards, maps, and reports that support operational oversight and decision making.

- Real-time positions and movement are displayed on Plaspy maps for immediate situational awareness
- Geo-fence events appear as alerts and can be used to drive notifications or reporting within Plaspy
- GPS logging data from the device can be shown as historical tracks for route review and distance analysis
- Two-way audio status and S.O.S. events are visible as device events to support response workflows
- Remote commands such as engine stop (when configured with a relay) are reflected as command history and device state in Plaspy
- Plaspy automatically detects common tracker protocols and accepts device reporting to the platform server domain, simplifying setup

## Typical Use Cases

- Fleet vehicle monitoring with live location and route history for scheduling and dispatch
- Rental or shared vehicle tracking including geo-fence controls to enforce area rules
- Asset movement logging where historical routes and distances are required for reporting
- Remote communication to the vehicle via two-way audio for driver contact or verification
- Emergency response workflows using the S.O.S. button to surface urgent alerts
- Security scenarios where remote engine stop can be used via a fitted relay accessory

## Feature Availability Notes

- Feature sets can differ by firmware version; some functions may be added or improved in later releases
- Hardware revisions and regional model variants can affect which accessories and commands are supported
- Certain functions, such as engine stop, require specific wiring and a compatible relay accessory installed by a qualified technician
- Installation choices and vehicle wiring can influence sleep mode behavior and power management
- Confirm availability of two-way audio, S.O.S., and AGPS behavior for your specific unit in the official Meitrack documentation
