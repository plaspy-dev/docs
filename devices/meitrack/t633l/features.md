# Meitrack - T633L Features

This page provides a public feature summary for the Meitrack T633L and how its capabilities map to Plaspy for fleet tracking and telemetry. It covers practical, non-sensitive feature context to help operators understand what the device can do when integrated into Plaspy workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation choices. For device-level configuration, peripheral wiring, and the latest technical details consult the manufacturer documentation and release notes.

## Feature Overview

The T633L is a professional in‑vehicle tracker focused on high‑precision positioning and extensive vehicle telemetry. When paired with Plaspy it can provide richer location accuracy and telemetry visibility to support real‑time monitoring, reporting, and operational oversight.

- Dual frequency GNSS reception L1 + L5 with optional Dead Reckoning for improved fixes in urban canyons, tunnels and other challenging environments.
- Multi generation cellular connectivity including LTE plus 3G and 2G regional variants to maintain continuous communications across different networks.
- Native CAN bus access and broad peripheral interfaces to capture vehicle telemetry and external sensor data for Plaspy dashboards.
- Peripheral support for Bluetooth devices, RFID and iButton readers, relays, buzzer, microphone and speaker, and ultrasonic fuel and temperature sensors.
- Backup battery and wide DC input for continued operation during power interruptions and professional vehicle installations.
- Rugged environmental tolerance and compact form factor suitable for discreet deployment in commercial vehicles.

## Core Features of Meitrack - T633L

- Dual frequency GNSS L1 + L5 for improved position precision compared to single frequency receivers.
- Optional Dead Reckoning (DR) to maintain position estimates in GNSS‑challenged environments.
- Multi‑generation cellular modem support including LTE Cat variants plus 3G and 2G regional options.
- CAN bus telemetry interface for reading vehicle bus data where installed and configured.
- Bluetooth support for external sensors and beacons to expand telemetry and context.
- Wide peripheral interface set including RFID, iButton, relays, buzzer, microphone and speaker, ultrasonic fuel sensors, and digital temperature sensors.
- On‑device buffering for telemetry to reduce data loss during temporary connectivity gaps.
- Backup battery and wide DC input range designed for robust in‑vehicle operation.

## How These Features Work with Plaspy

When connected to Plaspy, the T633L can contribute precise location updates and vehicle telemetry into Plaspy maps, reports, and alerts. Plaspy detects supported tracker protocols and ingests the telemetry fields the device provides so fleet managers can monitor vehicles in near real time.

- High precision GNSS plus optional DR improves position reliability shown on Plaspy maps and route replays.
- CAN bus fields and peripheral sensor inputs feed into Plaspy for diagnostics, speed visibility, and customized telemetry displays.
- Fuel level readings from ultrasonic sensors or CAN fuel data can be reflected in consumption reports and anomaly alerts inside Plaspy.
- Relay outputs and peripheral events can be surfaced as actionable events in Plaspy and used with configured remote actions when deployed and authorized.
- On‑device memory buffering helps Plaspy receive missed messages after connectivity is restored, improving record continuity.
- Plaspy automatically detects many common tracker protocols and supports standard TCP or UDP reporting to its ingestion endpoint for quick integration.
