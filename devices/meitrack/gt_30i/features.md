# Meitrack - GT-30i Features

This page describes the public feature context for the Meitrack GT-30i when used with Plaspy. It summarizes the practical capabilities you can expect to see in Plaspy for location reporting, alerts, voice monitoring, and event storage based on the GT-30i feature set and its compatibility with Plaspy.

Exact feature availability may vary by device firmware version, hardware revision, installation method, and manufacturer implementation. For the most current, device specific technical details consult the official Meitrack documentation and release notes.

## Feature Overview

The GT-30i is a compact personal GPS/GPRS tracker focused on reliable position reporting and basic two way communications. It combines location reporting, local storage for offline data, and user initiated functions to support guardian monitoring scenarios such as people or pet tracking.

- Real time location reporting via GPRS and SMS for continuous tracking and alerts
- Two way voice communication and listen in for remote audio monitoring and direct calls
- SOS panic button and user accessible buttons for quick alerts or calls
- Internal memory that stores GPS coordinates when network connectivity is unavailable
- Configurable reporting modes including track on demand and periodic interval reporting

## Core Features of Meitrack - GT-30i

- GPS position acquisition with AGPS support using GSM base station assistance
- GPRS TCP and UDP communication alongside SMS reporting options
- Two way voice calls and listen in voice monitoring capability
- SOS panic button and dedicated user buttons for calls or messages
- Local storage of GPS coordinates when GPRS is unavailable to prevent data loss
- Tracking by time interval or distance and track on demand functionality
- Movement alarm, low battery alarm, speeding alarm, and GPS blind area alarm
- Geo fencing control for entry and exit alerts

## How These Features Work with Plaspy

Plaspy receives and visualizes the GT-30i's location and event messages so operators can monitor devices from a central interface. Plaspy is compatible with GT-30i reporting and automatically detects the device protocol to simplify onboarding.

- Location updates and stored GPS points uploaded by the tracker appear in Plaspy maps and device history
- Alerts such as SOS, movement, geofence events, and low battery are surfaced as events in Plaspy for timely response
- Two way voice and listen in are reflected as device capabilities in Plaspy where supported by the tracker and network
- The GT-30i can send data to Plaspy using TCP or UDP and Plaspy will accept standard GPRS reporting from the device
- Plaspy provides historical playback of location traces that include points buffered in the device when offline

## Typical Use Cases

- Personal safety and guardian monitoring for children, elderly people, or vulnerable individuals
- Pet tracking where compact form factor and periodic location updates are needed
- Lone worker check ins and SOS alerting for remote personnel
- Short term rental or borrowed item monitoring with geofence alerts
- Situations where intermittent network coverage requires devices to store and forward location data

## Feature Availability Notes

- Some features may depend on device firmware version and can vary between hardware revisions
- Certain functions require cellular network support and regional GSM compatibility
- Voice monitoring, SOS behavior, and specific alarm thresholds may be configurable and implemented differently by firmware
- SMS and GPRS reporting options can affect how quickly events reach Plaspy depending on network conditions
- Always verify which features are enabled by the vendor or installer for a specific unit before deployment

## Why Use Plaspy with These Features

Using the Meitrack GT-30i with Plaspy provides a straightforward way to centralize location data, alerts, and historical tracking from a compact personal tracker. Plaspy's device protocol detection and event handling make it easy to integrate GT-30i devices so teams can view maps, receive alarms, and review stored location history without manual protocol configuration.
