# Meitrack - T366 Features

This page describes the public feature context for using the Meitrack T366 with Plaspy. It focuses on practical, user-facing capabilities you can expect when the T366 is deployed for real‑time tracking, telemetry collection, and anti‑theft workflows within the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, and the specifics of an installation. For the most current device details and installation guidance consult the manufacturer documentation and release notes from Meitrack.

## Feature Overview

The Meitrack T366 is a rugged, IP67-rated GNSS tracker designed for demanding vehicle and marine environments. It combines reinforced enclosure protection with telemetry interfaces and anti‑theft outputs to support continuous tracking, offline buffering, and remote management in Plaspy.

- IP67 water and dust resistance for marine and off‑road deployments
- Relay-based immobilizer and buzzer outputs for alarm and remote immobilization control
- RS232 port to connect external telemetry devices and fuel sensors for richer data
- 8 MB offline data buffer plus OTA/FOTA support to preserve history and simplify updates
- Wide input voltage tolerance and small backup battery for reliable uptime in vehicle power systems

## Core Features of Meitrack - T366

- Rugged IP67 enclosure suitable for vehicle and marine installations
- Relay immobilizer and buzzer outputs for anti‑theft and alarm integration
- RS232 serial interface to support external peripherals and sensor telemetry
- Support for an external GNSS antenna and high‑accuracy positioning
- 8 MB offline buffer to store location and event history when connectivity is intermittent
- OTA / FOTA support for remote firmware updates and field maintenance
- Driving behavior and event detection such as idling and harsh events for safety monitoring
- Wide DC input range and a small backup battery to maintain operation during power interruptions

## How These Features Work with Plaspy

Plaspy ingests location fixes, sensor telemetry, and event data from the T366 to provide live visibility, historical reports, and anti‑theft controls across a distributed fleet. The platform displays device status, alarms, and telemetry while preserving records when networks are unavailable.

- Real‑time location and telemetry appear on Plaspy maps and dashboards for operational awareness
- Immobilizer and buzzer status are visible in Plaspy, enabling remote alarm and immobilization workflows
- RS232 sensor data such as fuel level and other telemetry can be recorded and trended within Plaspy
- Driving behavior events and collision indicators are available for alerts, driver scoring, and incident review
- Offline buffer and OTA/FOTA support help Plaspy maintain continuity of historical records and coordinate remote updates
- Plaspy automatically detects compatible tracker protocols so devices can be onboarded without manual protocol selection

## Typical Use Cases

- Fleet management for light and heavy vehicles operating in marine, off‑road, and industrial environments
- Anti‑theft monitoring with remote immobilization and audible alarm outputs
- Fuel monitoring using external sensors connected via the RS232 interface to detect anomalies
- Driver behavior monitoring and safety programs based on harsh event detection and idling reports
- Asset tracking for vessels, equipment, and vehicles where ingress protection and temperature tolerance are important
- Remote fleet maintenance workflows enabled by OTA/FOTA updates and offline data buffering

## Feature Availability Notes

- Specific features and sensor support depend on device firmware and the hardware variant shipped for a region
- RS232 peripheral compatibility varies by sensor model and may require configuration or third‑party adapters
- Installation quality and sealing affect IP67 performance; professional installation is recommended for marine uses
- Network availability, including regional cellular coverage, affects real‑time reporting and may require fallback strategies
- Always confirm accessory compatibility and supported peripheral lists with manufacturer documentation
