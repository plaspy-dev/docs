# Meitrack - MT-80i Features

This page describes the public feature context for using the Meitrack MT-80i tracker with Plaspy. It summarizes the device capabilities that are relevant to Plaspy users, including positioning, tracking modes, and alert functions, and explains how those capabilities typically map into a fleet and asset monitoring platform such as Plaspy.

Exact feature availability and behaviour can vary with device firmware, hardware revision, installation method, regional variants, and manufacturer configuration. Use this page as a practical summary; consult the device manual and manufacturer resources for the most current and detailed technical information.

## Feature Overview

The MT-80i is a compact and versatile GPS tracker designed for personal, pet, asset, and vehicle tracking scenarios. Its combination of GNSS positioning, multiple reporting modes, on device logging, and built in sensors provides flexible tracking options for short and long term deployments.

- Compact lightweight design and belt clip for easy attachment and discreet placement
- SiRF III GPS positioning with AGPS assisted fixes using GSM base station information
- Quad band GSM connectivity for global mobile network coverage in supported regions
- Multiple tracking modes including on demand, time interval, distance interval, and reporting via SMS or GPRS using the MEITRACK protocol
- Internal memory for logging position history and inbuilt battery for portable operation
- Built in motion sensor and SOS alarm for event detection and emergency signalling

## Core Features of Meitrack - MT-80i

- SiRF III GPS engine for satellite based location and AGPS assisted positioning
- Quad band GSM support for broad regional network compatibility
- Multiple reporting options via SMS and GPRS using the MEITRACK protocol
- On demand tracking and scheduled tracking by time or distance interval
- Internal 4 Mb memory for local position logging and replay
- Inbuilt motion sensor to support movement detection and power management
- SOS alarm for emergency alerts and priority notification
- Listen in function to remotely monitor surrounding audio where supported by local settings and firmware

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible trackers and presents that data in a centralized interface for monitoring and historical review. When an MT-80i device is configured to report to Plaspy, the platform can display position updates, surface events, and retain history for operational use.

- Plaspy automatically detects supported tracker protocols and accepts MT-80i reports for position and event processing
- Scheduled interval and distance based reports appear as regular position updates and can be visualized on maps and in trip history
- SOS alarm and motion based events are presented as alerts in Plaspy so operators can prioritize responses
- Logged positions stored on the device can be uploaded and reconciled with Plaspy history to fill gaps when network connectivity is intermittent
- Remote commands available via GSM GPRS or SMS can be used to request on demand tracking or to trigger device functions where supported by the device firmware

## Typical Use Cases

- Personal safety and location sharing for outdoor activities or lone workers
- Pet tracking by attaching the unit to a collar for real time location updates and history
- Asset tracking for portable equipment where compact size and internal logging are valuable
- Vehicle tracking for secondary or leased vehicles that require a small form factor tracker
- Temporary deployments where battery powered operation and simple installation are needed
- Emergency monitoring situations where SOS alerts and remote listen in can assist response
