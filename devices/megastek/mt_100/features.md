# Megastek - MT-100 Features

This page provides a public feature overview for the Megastek MT-100 handheld GPS tracker and how its capabilities are used with Plaspy. It describes the main user-facing features that matter for location visibility, alerts, and basic remote interaction when the device is connected to Plaspy's tracking platform.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer settings. This page summarizes the MT-100's commonly documented capabilities but does not replace the official product manual or the manufacturer's documentation for device-specific or firmware-dependent behavior.

## Feature Overview

The MT-100 is a rugged handheld tracker intended for outdoor use and basic personal or asset tracking tasks. It combines assisted GPS positioning with cellular reporting options and a set of user alerts that can be useful for monitoring and incident response.

- Waterproof housing with an IP66 rating for protection against dust and strong water jets
- AGPS position assistance for faster position fixes in typical conditions
- SOS alarm with cellular LBS position assistance to provide an approximate location if GPS is not available
- Two-way communication to send and receive simple remote commands or voice where supported by the device
- Real-time tracking and event-based alerts such as overspeed, geo-fence, vibration, and low battery
- Local data logging to a Micro SD card for offline route playback and record keeping

## Core Features of Megastek - MT-100

- Handheld GPS tracking with AGPS assistance for improved fix times
- IP66 waterproof rating for outdoor and harsh weather use
- SOS alarm function with LBS position assistance for emergency alerts
- Two-way communication capability for remote interaction with the device
- Real-time tracking via cellular transmission using SMS and GPRS
- Geo-fence alarm to notify when predefined boundaries are crossed
- Over speed alarm to alert on excessive speed events
- Vibration alarm and low battery alarm for movement detection and power monitoring
- Local data logging to a Micro SD card for backup and historical review
- Support for up to five authorized cell phone numbers for direct device alerts and interaction

## How These Features Work with Plaspy

Plaspy collects and displays the MT-100's location and alert events so teams can monitor devices centrally. Plaspy's platform automatically detects supported tracker protocols and accepts device reports over common transport methods. For configuration, the MT-100 may be set to report to Plaspy using UDP or TCP on the platform port; Plaspy uses a single configured port for devices and provides the server domain for device setup.

- Real-time position updates from the MT-100 appear on Plaspy maps for continuous visibility
- SOS and alarm events from the device generate alerts that can be viewed and routed within Plaspy
- Geo-fence and overspeed events are shown as discrete events, enabling quick filtering and investigation
- Local data logs (Micro SD) provide an offline record that can complement Plaspy history when needed
- Two-way communication can be coordinated from Plaspy-compatible interfaces or used alongside Plaspy monitoring workflows
- Plaspy automatically handles protocol detection so most MT-100 units will start reporting with minimal configuration

## Typical Use Cases

- Personal safety tracking for lone workers or individuals operating in outdoor environments
- Temporary equipment or asset tracking where a rugged handheld device is preferred
- Field staff monitoring and coordination with event alerts and location history
- Emergency response scenarios using the SOS function combined with location reporting
- Short-term vehicle or pet monitoring when a portable tracker is required
- Route verification and proof of presence using local data logs and Plaspy history

## Feature Availability Notes

- Feature availability can differ across firmware versions and hardware revisions; not all units may expose every function listed here
- Certain features such as two-way communication behavior and LBS accuracy depend on cellular coverage and local network handling
- Installation and configuration choices (for example reporting intervals and alert thresholds) can change how features behave in operational use
- Regional variants of the MT-100 may have different cellular band support or preconfigured settings from the manufacturer
- Refer to the device's official documentation for exact command sets, supported modes, and compliance statements
