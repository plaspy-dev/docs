# Megastek - GMT-368 Features

This page describes the public feature context for using the Megastek GMT-368 motorcycle GPS tracker with Plaspy. It summarizes the tracker capabilities that are relevant to Plaspy users and explains how those features appear in a fleet or device monitoring environment on the platform.

Feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The GMT-368 is presented here by the features provided in the official model description, including real time reporting options, geo fencing, speed and signal alarms, and ACC ignition detection.

## Feature Overview

The GMT-368 is designed for motorcycles and focuses on compact, continuous location monitoring and event reporting. It supports real time updates via SMS or GPRS and includes configurable alerts useful for ownership security and fleet oversight.

- Real time location reporting using SMS or GPRS communication
- Regular interval tracking to send periodic location updates
- Geo fencing support with alerts on area entry and exit
- Over speed alarm to notify when a configured speed threshold is exceeded
- No GPS signal alarm to indicate loss of satellite positioning
- ACC detection to report ignition on and off status

## Core Features of Megastek - GMT-368

- Real time tracking via SMS or GPRS using TCP or UDP reporting where supported
- Configurable periodic location updates for scheduled tracking intervals
- Geo fence capability for creating virtual boundaries and receiving area alerts
- Over speed alarm for notifying when speed limits are exceeded
- No GPS signal alarm to flag loss of location fix or degraded reception
- ACC detection to indicate the motorcycle ignition status

## How These Features Work with Plaspy

Plaspy receives the GMT-368 reporting and presents device location and events inside the platform for monitoring and historical review. Plaspy automatically detects common tracker protocols and surfaces the core events produced by the device so teams can act on location and alarm data.

- Device position updates are shown on the Plaspy map for real time visibility
- Periodic tracking intervals become update points in Plaspy history and playback
- Geo fence entry and exit alerts generate events and notifications in Plaspy
- Over speed and no GPS signal alarms appear as timestamped events for review
- ACC on/off events are available in device event logs to show ignition state changes

## Typical Use Cases

- Motorcycle theft deterrence and recovery monitoring with live location and ignition events
- Fleet oversight for motorcycle couriers or service riders using periodic tracking
- Boundary enforcement and site control using geo fence alerts for assigned areas
- Safety and compliance monitoring with over speed notifications to manage rider behavior
- Operational troubleshooting when no GPS signal alarms indicate positioning issues

## Feature Availability Notes

- Exact alarm thresholds, geo fence limits, and reporting intervals can vary by firmware and configuration
- Some features may depend on how the device is installed and wired on a specific motorcycle model
- Regional firmware variants or manufacturer updates can change feature names or behavior
- Always verify supported commands and configuration options against the device manual and firmware release notes

Using the Megastek GMT-368 with Plaspy adds centralized visibility and historic context to the tracker events. Plaspy consolidates location updates, geo fence alerts, speed alarms, GPS signal status, and ACC events into a single monitoring interface so fleet managers and owners can quickly see current status and review past activity.
