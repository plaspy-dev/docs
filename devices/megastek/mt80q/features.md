# Megastek - MT80Q Features

This page provides a public feature overview of the Megastek MT80Q Personal Tracking Watch and how its capabilities map to Plaspy for tracking, alerting, and historical reporting. It focuses on user-facing features and operational value that are relevant when the MT80Q is used with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, SIM and network environment, and manufacturer configuration. For device-specific configuration, firmware updates, and the latest technical specifications consult Megastek documentation and firmware release notes.

## Feature Overview

The MT80Q is a compact, wearable GPS tracker designed for personal safety, remote telemetry and straightforward platform integration. It uses an established GNSS module for positioning, reports over GSM/GPRS networks, and includes a focused set of safety and anti-tamper functions that are valuable for live monitoring and emergency response when paired with Plaspy.

- Built for personal safety with fall detection and an SOS emergency alarm for rapid alerting.
- Two-way voice and monitoring capability to support direct voice contact and status checks.
- Anti-disassembly belt on/off alarm to notify of possible tampering or removal.
- Wearable durability with a 1.28 inch e-ink display, IP66-67 waterproof rating, and wireless charging for convenience.
- GPRS data logging and automatic APN query to simplify connection to Plaspy and other tracking platforms.
- Power-saving modes and low-battery alerts to extend operational runtime between charges.

## Core Features of Megastek - MT80Q

- GPS positioning using a Ublox GNSS module for location reporting and historical track logging.
- Fall detection that can trigger alerts for potential emergencies.
- SOS emergency button to generate immediate alarm events.
- Two-way voice and monitoring support for direct voice communications and status listening.
- Anti-disassembly belt on/off alarm to reduce tampering and unauthorized removal.
- GPRS data logger with automatic APN query to streamline initial network setup.
- Power-saving modes and low-battery alarm to preserve battery life and notify users when charging is needed.
- Rugged wearable form factor with wireless charging and an e-ink display for basic status information.

## How These Features Work with Plaspy

When integrated with Plaspy, the MT80Q's position and event messages become actionable items in the platform for visibility and response. Plaspy ingests the device's GPRS reports and presents them as location points, history, and event notifications for operators and stakeholders.

- Real-time location reporting and historical track display for route reconstruction and situational awareness in Plaspy.
- Event alerts such as fall detection and SOS forwarded to Plaspy dashboards and notification channels for rapid response.
- Anti-disassembly alarm events presented as tamper or removal notifications inside Plaspy for accountability.
- Low-battery and power state notifications used by Plaspy to trigger maintenance or charging workflows.
- Historical track logging accessible from Plaspy for review, export, and analysis of past movements.
- Automatic APN handling on the device reduces setup steps when connecting the MT80Q to Plaspy.

## Typical Use Cases

- Assisted living and elderly care monitoring with automated fall detection and SOS escalation.
- Lone worker safety and remote personnel tracking where two-way voice and tamper alerts improve worker oversight.
- Child and family tracking for lightweight, everyday wear and straightforward alerting.
- Portable asset protection for strap-on items where removal alarms and live location aid recovery.
- Supplementary personnel telemetry in mixed operations where wearable tracking complements vehicle trackers.
