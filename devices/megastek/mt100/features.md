# Megastek - MT100 Features

This page provides a public feature overview for the Megastek MT100 and explains how the device can be used with Plaspy for real time tracking, alerts, and centralized monitoring. It focuses on user facing capabilities and practical functions that organizations and operators will see when the MT100 is integrated into Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. Where useful, this page describes the typical functions reported by the MT100, but you should verify model specifics and the latest firmware notes with the manufacturer for mission critical deployments.

## Feature Overview

The MT100 is a compact, rugged personal tracker built for safety, security, and continuous monitoring. It combines multi mode positioning, emergency signalling, voice communication, and remote management features that make it suitable for lone worker protection, security teams, and asset monitoring.

- Multi mode positioning that combines GNSS, Wi Fi assistance, A GPS, and LBS for faster and more reliable fixes in mixed environments.
- SOS emergency alarm that transmits coordinates and can trigger rapid notifications and response workflows in Plaspy.
- Two way voice and voice monitoring for direct communication and incident verification when voice metadata is recorded.
- Durable IP67 housing and wireless charging support to keep devices operational in the field with long standby modes.
- Built in G sensor and vibration alarm to detect movement or tampering and report events for anti theft and tamper workflows.

## Core Features of Megastek - MT100

- Compatibility with third party platforms including Plaspy through open protocol documentation for straightforward integration.
- Multi mode positioning using GNSS plus Wi Fi assisted and network based positioning to improve location quality in urban or edge indoor areas.
- SOS emergency alarm with coordinate transmission for rapid alerting and responder notification.
- Two way voice calling and monitoring for direct personnel communication and incident context.
- Built in motion sensing with G sensor and vibration alarm to detect movement or potential tampering.
- Configurable tracking modes with interval or near real time reporting to balance battery life and update frequency.
- Wireless charging and power saving modes for extended standby and practical field use.
- Remote management support including firmware over the air updates to keep devices current and maintain integration stability.

## How These Features Work with Plaspy

Plaspy ingests the MT100 telemetry and event streams so operators can view location, alerts, and activity in a unified dashboard. Integration relies on the device sending GNSS fixes and event messages that Plaspy displays, logs, and uses to trigger rules and notifications.

- Real time location updates and historical playback for tracking personnel and reviewing movement on Plaspy maps.
- SOS alarms with coordinates that generate alerts and can be routed to designated responders through Plaspy rules.
- Motion and vibration events reported to Plaspy for tamper detection and anti theft monitoring.
- Geo fence and time based rules applied to MT100 telemetry to automate notifications and incident workflows.
- Voice call and monitoring events can be correlated in Plaspy when voice metadata is provided, helping provide context for incidents.
- Remote configuration and FOTA status visible to administrators to help manage device fleets and keep firmware consistent.

## Typical Use Cases

- Lone worker safety and personal protection where SOS and two way voice enable rapid response.
- Security patrols and public safety teams that require location visibility and incident logging.
- Portable asset protection using movement and vibration alarms to detect unauthorized handling.
- Event operations and crowd management where discreet waterproof tracking supports staff coordination.
- Managed service deployments that rely on remote configuration and FOTA for large scale maintenance.
- Situations requiring mixed environment positioning such as urban canyons or semi indoor locations.

## Feature Availability Notes

- Not all MT100 units may expose every function listed here; features depend on the device firmware and configured options.
- Hardware revisions and regional variants can change supported radio bands, positioning performance, or accessory availability.
- Installation choices and permissions such as voice monitoring settings may affect what events appear in Plaspy.
- FOTA and protocol support make updates possible, but update schedules and feature rollouts are controlled by the manufacturer and deployment policies.
- Always consult the manufacturer documentation for the exact behaviour of sensors, alarms, and remote management for a given unit.
