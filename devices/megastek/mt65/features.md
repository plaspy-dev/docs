# Megastek - MT65 Features

This page provides a public feature overview of the Megastek MT65 ankle tracker and how its capabilities are used with Plaspy for supervised wearable monitoring. It summarizes the practical functions, alarms, and positioning modes that the MT65 can provide when reporting into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Readers should treat this page as a high level compatibility and features guide and consult manufacturer documentation for device specific implementation details.

## Feature Overview

The MT65 is a purpose built ankle tracker designed for continuous supervision use cases and is compatible with Plaspy for streamlined platform integration. It combines high precision GNSS positioning with multi network cellular communications and supplementary Wi Fi positioning to maintain location continuity in many environments.

- Hybrid positioning that blends GNSS with network and Wi Fi information for improved indoor and outdoor coverage.
- Continuous monitoring with configurable reporting intervals and historical route playback for oversight and audits.
- Tamper and safety alarms including belt on off detection, SOS emergency, geo fence alerts, and low battery warnings.
- Wearable, waterproof construction and a purpose designed strap for continuous use in supervised contexts.
- Reporting and integration via SMS and GPRS so the device can deliver live location and alarm events into Plaspy.

## Core Features of Megastek - MT65

- High precision GNSS reception using a u‑blox chipset for stable satellite fixes and assisted GNSS support.
- Hybrid positioning support including GPS plus LBS, AGPS, and Wi‑Fi based location assistance.
- Cellular communications module compatible with multiple network bands for SMS and GPRS data reporting.
- Tamper detection and safety alarms including belt on off alarm and a dedicated SOS button for emergencies.
- Waterproof wearable form factor rated to IP68 for durability in continuous supervision deployments.
- Long life polymer battery with multi hour operation suitable for daily supervised monitoring cycles.
- Support for remote voice monitoring, status LEDs, and physical buttons for local control and alerts.
- Compatibility with third party tracking servers and straightforward APN handling for faster onboarding.

## How These Features Work with Plaspy

When the MT65 is deployed with Plaspy, the tracker sends location, status, and alarm messages so supervisors and case managers can monitor subjects in near real time. Plaspy detects compatible tracker protocols and presents location and event data for operational use and audit trails.

- Positional fixes and hybrid location data appear on Plaspy maps for live monitoring and historical playback.
- Tamper events, belt on off alarms, SOS triggers, and geo fence alerts generate notifications and are logged in Plaspy for incident handling.
- Device battery status and online/offline telemetry are visible inside Plaspy to support maintenance and scheduling.
- SMS based reports and GPRS data reporting can feed the Plaspy server domain for centralized case management.
- Configurable reporting intervals and event rules in Plaspy let teams tune visibility and alert thresholds to match program policies.

## Typical Use Cases

- Continuous offender supervision and electronic ankle monitoring for parole and house arrest programs.
- Parolee oversight with real time alerts and event logging to support compliance workflows.
- Home isolation monitoring where tamper resistant wearable tracking and SOS alerts are required.
- Case management and auditing scenarios needing historical track playback and event history.
- Situations requiring a wearable tracker that balances comfort, durability, and persistent telemetry.
