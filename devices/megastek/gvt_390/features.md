# Megastek - GVT-390 Features

This page summarizes the public feature context for using the Megastek GVT-390 with the Plaspy fleet and tracking platform. It highlights the device capabilities that are relevant for visibility and monitoring in Plaspy and explains how those capabilities typically translate into operational value on the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Use this page as a practical overview and consult manufacturer documentation for device specific details and firmware related behavior.

## Feature Overview

The GVT-390 is a compact GPS tracker built for both personal and commercial tracking use. It combines a SiRF Star III GPS chipset for position accuracy with a SIM900 quad band GSM modem for wide cellular coverage, and includes a set of alarms, inputs and outputs, and local data logging for flexible deployments.

- Accurate GPS position reporting using SiRF Star III technology for stable location tracking
- Quad band GSM connectivity via SIM900 for broad regional compatibility
- Multiple simultaneous command support plus SMS center and up to five authorized phone numbers for controlled access
- Event and safety features including SOS, geo fencing, over speeding alarm, low power warning, and motion detection
- Local data logging with Micro SD support and discrete inputs and outputs for integration with vehicle or equipment wiring

## Core Features of Megastek - GVT-390

- SiRF Star III GPS chipset for precise position fixes and stable tracking
- SIM900 quad band GSM modem supporting broad cellular bands
- Support for multiple instructions to be executed concurrently for flexible configuration
- SMS center configuration and support for up to five authorized phone numbers for secure command access
- Tracking on demand and a configurable power saving mode to balance reporting frequency and power use
- SOS emergency button and alarms including geo fence alarm, low power warning, and over speeding alarm
- Motion sensor capability and background voice monitoring as part of the device feature set
- Local data logger support via Micro SD card and hardware I O including 4 digital inputs including ACC, 2 analog inputs, and 2 outputs

## How These Features Work with Plaspy

Plaspy can receive and present the GVT-390 location and event information so operators and dispatch can monitor assets and respond to alerts. Plaspy automatically detects many tracker protocols and provides a consistent interface for viewing device telemetry and alarms.

- Real time and historical location tracking visible on Plaspy maps when the device reports GPS positions
- Event alerts such as SOS alarms, geo fence triggers, over speeding, and low power warnings delivered into Plaspy for notification and logging
- Digital and analog input events represented as device attributes or alarms inside Plaspy so users can monitor status changes from the tracker
- Local data logger usage and memory indications shown as part of device reporting when the tracker uploads logged data or reports logger status
- Plaspy accepts standard tracker messages and presents them without requiring manual protocol selection thanks to automatic protocol detection

## Typical Use Cases

- Fleet vehicle location tracking and route monitoring with alarm visibility for overspeed or geo fence events
- Asset protection and concealed tracking for high value portable equipment using discreet installation and local logging
- Personal safety and lone worker protection using SOS alarm and emergency notification features
- Remote monitoring of equipment status using digital and analog inputs to capture on off or measured signals
- Investigative or recovery deployments that leverage background voice monitoring and motion detection where permitted

## Feature Availability Notes

- Feature presence and behavior depend on the installed firmware version and device hardware revision
- Some functions may require specific configuration at installation or enabling via SMS or platform commands
- Regional or carrier differences can affect cellular connectivity and behavior even though the device is quad band
- Micro SD data logging and background voice monitoring may be optional features or may require particular firmware
- Always verify which inputs, outputs, and alarm functions are active on the specific unit before deploying it in production
