# Megastek - GVT-369 Features

This page provides a public, feature-focused overview of the Megastek GVT-369 tracker and how its capabilities appear when used with Plaspy. It summarizes the device functionality that is relevant for monitoring, alerts, and operational visibility on the Plaspy platform without reproducing private configuration instructions.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, or installation method. Installation choices and manufacturer firmware updates can change how particular functions operate, so treat this as a practical summary rather than a definitive technical manual.

## Feature Overview

The Megastek GVT-369 is a compact GPS tracker designed for personal and commercial tracking with a focus on reliable position reporting and event alerts. It combines a SiRF Star III GPS chipset and a SIM900 quad band GSM modem for global positioning and cellular communication, along with on device features for alerts and data logging.

- Precise location tracking using a SiRF Star III GPS chipset for consistent position fixes
- Global cellular connectivity through a SIM900 quad band modem supporting wide regional coverage
- On demand and interval tracking options to suit real time monitoring or periodic reporting
- Built in data logging to store location records when cellular signal is unavailable
- Event and alarm support including SOS button, geo fence alarm, over speed and low battery warnings

## Core Features of Megastek - GVT-369

- SiRF Star III GPS chipset for position accuracy and reliable fixes
- SIM900 quad band GSM modem for broad network compatibility
- Support for up to three authorized phone numbers for restricted access control
- Configurable on demand tracking and timed interval reporting
- Built in memory for data logging and later retrieval
- SOS button for immediate alarm activation
- Motion sensor and geo fence alarm for movement and zone event detection
- Inputs and outputs including three digital inputs (one used for ACC), two analog inputs, and two outputs

## How These Features Work with Plaspy

Plaspy ingests the GVT-369 position and event data to present location, status, and historical routes in a unified interface. When connected to Plaspy, the tracker’s core events and logs become part of vehicle or asset timelines and alert rules.

- Location updates and historical tracks appear on Plaspy maps for live and retrospective review
- Alarms such as SOS, geo fence triggers, over speed, and low battery are forwarded to Plaspy for event visibility and notifications
- Data logged on the device can be synchronized into Plaspy when the tracker regains cellular connectivity
- Digital and analog input events reported by the device surface in Plaspy as status changes or custom events
- Plaspy automatically detects tracker protocol and adapts handling so device messages map into platform events and telemetry
