# Concox - JM-BL11

![JM-BL11](./tracker.png)

The JM-BL11 is a rugged LTE Cat M1 / NB2 GNSS bike-sharing lock engineered for large-scale micro-mobility and shared-bicycle fleets. Designed for demanding outdoor use, the JM-BL11 pairs long battery life and optional solar charging with precise GNSS positioning \(GPS, A-GPS, LBS\) and Bluetooth 4.0 LE local control — making it an ideal Plaspy compatible GPS tracker for operators who need reliable, secure, real-time tracking and anti-theft protection across distributed fleets.

The unit integrates tamper-resistant mechanics, TLS-secured communications, and motion alerts to protect assets and simplify fleet management. When connected to Plaspy, JM-BL11 units deliver location, telemetry, and event data that allow operators to monitor availability, enforce geo-fences, detect theft attempts, and manage large-scale bike-sharing deployments with confidence.

## Key Highlights

- Plaspy compatible GPS tracker for micro-mobility: GNSS-based real-time tracking with A-GPS and LBS fallback for consistent positioning.
- Long-life power with optional solar assistance: 12,000 mAh battery and 6 V / 5 W solar charging option to extend field deployments.
- Rugged, tamper-resistant design: IP66-rated enclosure, reinforced structure, vibration tamper alerts and accelerometer-based motion detection.
- Secure communications: TLS data encryption for secure device-to-cloud telemetry and event reporting.
- Local unlocking and management: Bluetooth 4.0 LE and QR-code unlocking via designated apps for user convenience and operational flexibility.
- Fast, accurate positioning: positioning accuracy better than 2.5 m CEP and tracking sensitivity down to -165 dBm for reliable location under varied conditions.
- Built for scale: compact, purpose-built form factor with micro-SIM support and on-device data storage for resilient operation in large fleets.

## How It Works with Plaspy

Integrated with Plaspy, the JM-BL11 supplies continuous location and event telemetry so fleet managers can operate with real-time visibility. The device streams GNSS fixes, motion events, battery and sensor telemetry, and tamper alerts to Plaspy using LTE Cat M1 / NB2 connectivity \(with EGPRS fallback\), secured by TLS. Plaspy ingests this data to power live maps, geofence enforcement, historical routes, and fleet health dashboards.

- Real-time location and telemetry updates via LTE Cat M1 / NB2 \(with EGPRS fallback\).
- Motion and tamper alerts driven by the onboard accelerometer and vibration detection.
- Battery status, solar charging indicators, and standby runtime telemetry for maintenance scheduling.
- Bluetooth 4.0 LE information for local unlocking events and user interactions \(QR-code unlock workflow supported\).
- Geo-fence events and zone-based alerts to detect unauthorized movement or location breaches.
