# Concox - GT06S Features

This page provides a public feature overview for the Concox GT06S and explains how those features can be used with Plaspy for fleet tracking and operational visibility. It focuses on practical, non-sensitive feature context and how the tracker’s telemetry and events appear in a modern fleet management platform.

Exact feature availability can vary by firmware version, hardware revision, regional variant and the specifics of installation and wiring. Where the GT06S description lists capabilities such as remote cut-off, ignition detection, GNSS positioning, microphone and accelerometer events, this page treats those items as the basis for Plaspy integration while advising verification against manufacturer documentation.

## Feature Overview

The GT06S is a compact vehicle GNSS tracker designed for discreet installation and straightforward integration into Plaspy. It supports a broad input voltage range and a set of on-device features that deliver location, event and anti-theft telemetry suited to motorcycles, cars and heavy vehicles.

- Compact low profile form factor suitable for covert installation on motorcycles and vehicles.
- Wide input voltage support from 9 to 90V for compatibility across vehicle types.
- Multi constellation positioning using GPS, BDS and cell based LBS with high reported accuracy.
- Remote cut-off immobilizer capability and ignition detection for anti-theft response.
- Built-in microphone and accelerometer for situational awareness and movement event detection.
- Offline log storage and backup battery to preserve historical points during outages.

## Core Features of Concox - GT06S

- GNSS positioning with GPS and BDS plus LBS assistance for improved location coverage and faster fixes.
- Wide 9–90V DC input to support motorcycles, passenger cars and heavy duty vehicles.
- Remote cut-off via relay for fuel or power interrupt as part of anti-theft workflows.
- Ignition detection input to report vehicle on off state and support trip segmentation.
- Built-in microphone for listen-in capability where permitted and configured.
- Accelerometer for movement and impact related events and driving behavior signals.
- Offline data logging capacity to store thousands of points for later upload after reconnection.
- Onboard backup battery and low power standby behavior to preserve continuity during power loss.

## How These Features Work with Plaspy

Plaspy ingests the GT06S telemetry so fleet managers can monitor location, status and events in real time and through historical reports. Plaspy automatically identifies supported tracker protocols and surfaces the device data in dashboards, alerts and logs for operational use.

- Real time location updates and historical track playback for route monitoring and investigation.
- Ignition status visible in vehicle timelines and trip reports to separate driving and idle time.
- Remote immobilizer state and commands reflected in Plaspy where hardware wiring and permissions allow control.
- Movement, tamper and low battery events routed as alerts to operators for immediate attention.
- Accelerometer driven events and microphone related status available for post event review and safety analysis.
- Offline log uploads reconciled into Plaspy history after reconnection to maintain continuity.

## Typical Use Cases

- Fleet management and route visibility for mixed fleets of motorcycles, cars and heavy vehicles.
- Anti theft and recovery workflows using remote cut-off, tamper alerts and precise location reporting.
- Dealer inventory protection and discreet asset tracking for motorcycles and small vehicles.
- Driver behavior and safety monitoring using accelerometer events and trip segmentation.
- Continuity monitoring where offline logging and backup battery reduce gaps in history.

## Feature Availability Notes

- Firmware versions and manufacturer software can enable or disable certain features or change event formats.
- Hardware revisions or regional variants may affect cellular bands, GNSS performance and available interfaces.
- Some functions such as remote cut-off and microphone use require correct wiring and legal compliance in the installation jurisdiction.
- Offline log capacity and battery runtimes depend on device configuration and use patterns.
- Always consult the official Concox documentation for device specific commands and wiring diagrams before deployment.
