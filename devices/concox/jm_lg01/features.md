# Concox - JM-LG01 Features

This page presents the public feature context for the Concox JM-LG01 and how it is used with Plaspy. It focuses on user-facing capabilities, operational benefits, and the ways Plaspy can consume and present the device's location and telemetry for fleet and asset monitoring.

Exact feature availability and behaviour can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific limits, configuration options, or the latest technical details, consult the manufacturer documentation and release notes.

## Feature Overview

The JM-LG01 is a compact, portable GNSS tracker built for long-term monitoring of unpowered assets where low maintenance and reliable location are priorities. It combines high-sensitivity positioning, configurable power profiles, tamper-aware telemetry, and local logging to provide continuous visibility with minimal servicing.

- Ultra long standby capability suitable for long term asset deployments where infrequent reporting preserves battery life.
- High accuracy GNSS positioning for dependable outdoor location data and route history.
- Tamper awareness via a light sensor and movement detection to support anti-theft monitoring.
- Strong magnetic mount and IPX5 water resistance for quick, low effort installation on a wide range of assets.
- Local data storage to log positions and events when connectivity is intermittent and resume reporting when back online.
- Compact, lightweight form factor that is easy to deploy across distributed fleets and equipment.

## Core Features of Concox - JM-LG01

- GNSS positioning with high sensitivity and sub 2.5 m outdoor accuracy as reported by the manufacturer.
- Configurable power management and reporting schedules that extend battery life for long standby periods.
- Tamper detection using a light sensor for event driven alerts and security monitoring.
- Movement detection supported by an onboard accelerometer to trigger wake up and reporting.
- Local on-board logging to preserve history during connectivity gaps.
- Durable enclosure with IPX5 water resistance and a strong magnetic mount for near zero install.
- Cellular connectivity via a standard mobile SIM interface for cloud reporting and remote updates.
- Visible device status via a single LED indicator for simple field checks.
