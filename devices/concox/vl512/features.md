# Concox - VL512 Features

This page provides a public feature summary of the Concox VL512 and how its capabilities are used with Plaspy for vehicle tracking and fleet management. It highlights the VL512's practical functions as a compact 4G OBDII tracker and explains what operators can expect when the device reports telemetry into Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant and installation method. Where needed, confirm details such as supported alerts, microphone usage and power reporting against the device firmware notes and the manufacturer's documentation.

## Feature Overview

The VL512 is a plug-and-play OBDII tracker built for rapid deployment in passenger cars. It combines LTE connectivity with GSM fallback, high-accuracy GNSS positioning, motion sensors and on-device buffering to deliver near real-time location and event reporting that Plaspy can ingest for monitoring and reporting.

- Fast OBDII plug-and-play installation for quick vehicle onboarding
- LTE first connectivity with GSM fallback to maintain data links across coverage conditions
- GPS plus BDS satellite positioning for precise location reports suitable for route tracking
- Motion sensing for driving behavior detection and collision indication
- Built-in microphone for remote voice monitoring where permitted by law
- On-device buffering and a small backup battery to preserve recent events during short power or connectivity interruptions

## Core Features of Concox - VL512

- OBDII plug-and-play form factor for easy installation without hardwiring
- LTE Cat 1 connectivity with GSM 2G fallback for redundant cellular links
- Dual constellation GNSS using GPS and BDS with high accuracy positioning
- Accelerometer and gyroscope for detecting harsh driving events and collisions
- Instant event alerts for movement, geo-fence entry/exit, speeding and power disconnection
- Built-in microphone for remote voice monitoring where allowed by regulation
- On-device storage and a small backup battery to report events during transient outages

## How These Features Work with Plaspy

Plaspy ingests location and event messages from compatible VL512 units and maps those signals into dashboards, alerting rules and historical reports. Plaspy automatically detects many tracker protocols and presents telemetry alongside fleet workflows so operators can maintain visibility and respond to incidents.

- Real-time location updates and history playback for position monitoring and route reconstruction
- Event-driven alerts in Plaspy for movement, geo-fence transitions, speeding and power loss
- Driving behavior events from motion sensors surfaced as analytics and scorecards
- Power and ignition state reporting reflected in Plaspy to support engine-on/engine-off workflows
- Buffering and on-device memory reduce data gaps by ensuring recent events are delivered once connectivity is restored
- Where voice monitoring is used and permitted, related indicators can be associated with events for incident verification

## Typical Use Cases

- Fleet management and dispatch where rapid OBDII installation accelerates vehicle onboarding
- Anti-theft monitoring and recovery using movement, geo-fence and power-disconnect alerts
- Usage based telematics and driver scoring using GNSS plus motion sensor data
- Rental and car sharing operations requiring quick deploys and incident verification
- Roadside assistance and service dispatch using location plus ignition and battery status

## Feature Availability Notes

- Function availability can depend on the device firmware version and manufacturer firmware options.
- Hardware revisions and regional variants may change supported cellular bands, microphone behavior or power characteristics.
