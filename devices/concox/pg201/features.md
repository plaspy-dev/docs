# Concox - PG201 Features

This page provides public feature context for using the Concox PG201 personal GPS tracker with Plaspy. It summarizes the device capabilities that are relevant to Plaspy users, explains how common functions appear on the Plaspy platform, and highlights practical operational value for workforce safety and on-person monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, local configuration and installation type. For device specific parameter settings, firmware change logs and the most current technical details consult the manufacturer documentation and release notes.

## Feature Overview

The PG201 is a compact, lightweight personal tracker built for real-time location reporting, emergency response and basic activity monitoring. When paired with Plaspy, the device provides location fixes, alerting and status updates that help supervisors keep visibility on field personnel and respond quickly to incidents.

- Multi system positioning using GPS plus BDS and LBS for improved fix availability in challenging environments
- Dedicated SOS panic button and two way voice communication for rapid incident escalation
- Scheduled, period based and instant reporting modes to balance tracking detail and battery life
- Motion detection with accelerometer based movement or inactivity events for activity awareness
- Compact IPX5 water resistant housing and long standby battery behavior suited for daily field use

## Core Features of Concox - PG201

- Multi constellation positioning GPS BDS and LBS for location fixes and improved coverage
- Dedicated SOS panic button for immediate alerting and location sharing
- Two way communication and speed dial capability to contact personnel after an event
- Motion detection using a built in accelerometer to support movement and inactivity reporting
- Configurable reporting modes including scheduled period based and instant location updates
- Battery powered design with extended standby characteristics suitable for multi day use
- Compact, lightweight and water resistant form factor for on person deployment

## How These Features Work with Plaspy

Plaspy ingests the PG201 device telemetry and presents location and alert information on maps and dashboards so teams can monitor personnel status and respond to events. Plaspy users can set notification rules and use historical telemetry to review incidents and movement patterns.

- Live location updates appear on Plaspy maps for real time tracking and situational awareness
- SOS alerts and associated location are surfaced as high priority notifications for rapid response
- Motion events and inactivity alerts are shown as device status changes to help identify movement or standstill conditions
- Configurable reporting intervals are reflected in Plaspy through update frequency and recent fix timestamps
- Geo fence events and low battery notifications are available as alert types to support supervisory workflows
- Two way call or speed dial records can be tracked alongside alerts to document follow up communications

## Typical Use Cases

- Sanitation and street maintenance crews where route visibility and worker safety are priorities
- Field inspection and service teams requiring location verification and scheduled check ins
- Lone worker protection programs using SOS alerts and two way contact for emergency response
- Construction site personnel tracking to monitor presence and movement within work areas
- Patrol and security staff needing instant location modes and configurable reporting cadence

## Feature Availability Notes

- Feature behavior such as alert formatting and reporting cadence can vary with firmware version and device configuration
- Hardware revisions and regional variants may affect available bands and network behavior for GSM and LBS reporting
- Some capabilities listed are conditional on how the device is provisioned and installed for a specific deployment
- Manufacturer documentation is the authoritative source for technical limits, supported parameters and safety specifications
- Plaspy displays and interprets the telemetry the device reports; verifying device settings ensures the platform shows the expected information

## Why Use Plaspy with These Features

Using the PG201 with Plaspy gives organizations centralized visibility of personal tracker location and alerting without adding vehicle telematics complexity. Plaspy aggregates incoming location fixes, SOS events and motion telemetry so supervisors get timely situational awareness and can document responses and patterns over time.
