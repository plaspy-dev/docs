# Concox - GT350 Features

This page covers the public feature context for using the Concox GT350 personal GPS tracker with Plaspy. It describes the GT350's practical capabilities and explains how those capabilities are reflected in Plaspy for monitoring and operational oversight. The goal is to help administrators, fleet managers, and individual users understand what the tracker can do when paired with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. Where possible this page uses the device description as the factual grounding; for the most current device specific details consult Concox documentation and firmware notes.

## Feature Overview

The GT350 is a compact personal tracker aimed at continuous location monitoring and safety use cases. It is designed for extended standby use and includes user focused features that support emergency response and perimeter monitoring. When connected to Plaspy, the GT350 can provide real time location awareness and event visibility to aid situational awareness and operational workflows.

- Long stand by time to reduce the need for frequent recharging and support extended deployments
- Emergency tracking that enables rapid location reporting when an incident is detected
- Geo fence support with boundary crossing notifications for perimeter awareness
- Voice monitoring capability to check the tracker surroundings as an added security option
- Built in SOS alarm for sending urgent alerts to designated contacts or platforms
- Compact and durable design suitable for personal carry and daily use

## Core Features of Concox - GT350

- Personal location tracking suitable for individuals such as inspectors travelers and outworkers
- Long standby performance for prolonged use between charges
- Emergency tracking mode to report location during incidents
- Geo fence functionality with notifications when set boundaries are crossed
- Voice monitoring for remote listening to the tracker environment
- SOS alarm for quick alerting of emergency situations
- Compact durable form factor designed for daily wear and handling

## How These Features Work with Plaspy

Plaspy provides a unified view and event handling for compatible trackers including the GT350 enabling teams to monitor location and respond to alerts from a central platform. Plaspy automatically detects compatible tracker protocols and receives the device events necessary to display location and key alerts within the platform.

- Location updates from the GT350 appear in Plaspy for real time position tracking and history review
- Geo fence crossings reported by the device generate notifications and can be used to trigger operational workflows inside Plaspy
- SOS alarms from the tracker are visible as high priority events so teams can escalate response quickly
- Emergency tracking events can be reviewed in Plaspy to support incident response and location confirmation
- Voice monitoring activations can be logged as events in Plaspy to provide contextual awareness of an incident
- Plaspy accepts standard device reports and maps them into the platform interface for visibility and reporting
