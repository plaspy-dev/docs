# Concox - JM-LL02

![JM-LL02](./tracker.png)

The JM-LL02 from JM is a rugged, Plaspy compatible GPS tracker engineered for long-term asset deployments where near-zero installation and long standby are essential. Built around LTE Cat M1 / NB2 connectivity with fallback to GSM, and a high-capacity 6,000 mAh industrial Li-Polymer battery, the JM-LL02 delivers dependable real-time tracking and event telemetry to Plaspy for fleet management, asset security and logistics operations. Its integrated magnetic mount, IP67 enclosure and Bluetooth 5.0 configuration make redeployment and field setup fast and tool-free.

Designed for assets such as trailers, containers, construction equipment and rental vehicles, the JM-LL02 focuses on battery longevity, tamper detection and accurate positioning. With multi-source positioning \(GPS + LBS\), high sensitivity \(-165 dBm\) and sub-2.5 m CEP accuracy, this Plaspy compatible tracker provides precise location, geofence events and scenario alerts \(low battery, tamper, vibration, over-speed\) so you can reduce theft risk, manage telemetry and keep operations running smoothly.

## Key Highlights

- Plaspy compatible GPS tracker with LTE Cat M1 / NB2 and GSM connectivity for resilient cellular coverage.
- Exceptional battery life: 6,000 mAh industrial Li‑Polymer pack and up to 1.5 years standby in power-saving mode for long-term deployments.
- Rugged design: IP67-rated enclosure and wide operating temperature \(–20°C to +70°C\) for harsh environments.
- Fast, non-invasive installation via strong integrated magnetic mount—ideal for movable assets and rapid redeployment.
- High-precision positioning: GPS + LBS with –165 dBm sensitivity and \<2.5 m CEP accuracy for reliable location data.
- Bluetooth 5.0 on-board for direct, cable-free configuration and on-site setup without opening the device.
- Comprehensive scenario alerts \(tamper, low battery, vibration, over-speed, geo-fence\) for anti-theft and fleet monitoring workflows.
- Visible LEDs for GNSS, cellular and power status plus a magnetic charging port for convenient maintenance and debugging.

## How It Works with Plaspy

Integration with Plaspy turns the JM-LL02’s GNSS, cellular and on-board sensors into actionable dashboards, geofence rules and alert streams. The tracker streams location and event data over LTE Cat M1 / NB2 \(or GSM where applicable\) to Plaspy, enabling real-time tracking, telemetry aggregation and automated notifications. Bluetooth 5.0 simplifies initial provisioning so devices arrive configured and ready to report into Plaspy with minimal field effort.

- Real-time location and telemetry updates \(GPS + LBS\) delivered to Plaspy for mapping and historical routes.
- Tamper and cover-dismantlement alerts using the integrated light sensor to support anti-theft workflows in Plaspy.
- Scenario alerts supported: low battery, vibration, over-speed and geo-fence entry/exit notifications.
- Local data storage \(32 + 32 MB\) ensures buffered reporting if temporary connectivity loss occurs.
- Bluetooth 5.0 for on-site configuration and rapid redeployment without wired connections.
