# Concox - GT02

![GT02](./logo.jpg)

The Concox GT02 is a versatile GPS tracker that combines GPS, GSM, and GPRS technologies to provide accurate and real-time tracking. With its quad-band GSM frequency, it can be used globally, making it an ideal choice for businesses and individuals who need to track assets or vehicles across different countries.

Equipped with a high-sensitive GPS chipset and built-in GSM and GPS antennas, the GT02 ensures reliable and precise positioning. It supports real-time tracking, allowing you to monitor the location of your assets or vehicles at any time. Additionally, the tracker has an auto-start feature when power is connected, ensuring continuous tracking without any manual intervention.

The GT02 also comes with several advanced features to enhance its performance and usability. It has a built-in watchdog function that automatically reboots the device in case of an accident or system failure. The tracker is equipped with an acceleration sensor, which enables intelligent power-saving and resistance to static drifts. It also has a covert or open installation method, providing flexibility in how you choose to install the tracker.

The GT02 features three LED indicators - GPS \(blue\), GSM \(green\), and power \(red\) - which provide visual feedback on the status of the tracker. Additionally, you can easily check the location of your assets or vehicles via a platform service, making it convenient to monitor and manage your assets remotely.

### Key Features:

- GPS + GSM + GPRS wireless positioning system
- Quad-band GSM frequency for global use
- Built-in high-sensitive GPS chipset
- Built-in GSM & GPS antenna
- Real-time tracking
- Auto start when power connected
- Built-in watchdog function, auto reboot when accident happens
- Built-in switch power supply, with wide voltage input
- Built-in acceleration sensor, intelligent power saving and static drifts resisting
- Installing method: covert / open
- Three LED indicators: GPS - Blue; GSM - Green; Power - Red
- Check location via platform service
