# Concox - TR06 Features

This page describes the public feature context for the Concox TR06 vehicle GPS tracker and how those features are relevant when using the device with Plaspy. It covers the practical capabilities you can expect to see reported into Plaspy for monitoring, location awareness, and event visibility without going into private or device-specific configuration instructions.

Exact feature availability and behaviour can vary by device firmware version, hardware revision, installation method, and manufacturer implementation. Where the TR06 supports a capability at the device level, Plaspy can surface the reported positions and events; however specific commands and alerts depend on the installed unit and its firmware.

## Feature Overview

The Concox TR06 combines GPS satellite positioning with GSM/GPRS connectivity to deliver location reporting, security monitoring, and alarm reporting for vehicles. Its design emphasizes real-time tracking and vehicle security functions that are relevant for both individual vehicle owners and fleet operators.

- GPS satellite positioning for regular location updates and tracking
- GSM GPRS cellular connectivity for reporting position and status to tracking platforms
- Remote engine off capability for stopping a vehicle when supported by installation and configuration
- Security and emergency alarm reporting for theft or critical events
- Real-time tracking and monitoring through compatible GPS software and platforms such as Plaspy

## Core Features of Concox - TR06

- GPS satellite based location reporting for position awareness
- GSM GPRS cellular communication for sending locations and alarms to a server
- Remote engine off capability to cut engine power where the device installation supports it
- Emergency alarm support to notify of critical events reported by the tracker
- Monitoring and surveillance related reports for vehicle security oversight
- Real-time tracking compatibility with GPS tracking software
- Basic event reporting to enable logging of alarms and security incidents

## How These Features Work with Plaspy

Plaspy receives and displays the TR06's reported locations and alarms so operators can monitor vehicles on a live map, review history, and respond to events. Plaspy automatically detects common tracker protocols and will present the information the device sends in a consistent interface for visibility and oversight.

- Live vehicle location on the Plaspy map based on GPS position reports
- Event and alarm logging when the TR06 reports emergency or security alarms
- Remote engine off control surfaced in Plaspy where the device hardware, firmware, and installation support the command
- Location history and playback for route review and incident investigation
- Centralized monitoring and notification options to alert operators of critical events

## Typical Use Cases

- Fleet tracking for visibility into vehicle locations and movements
- Vehicle security monitoring and response to alarm events
- Anti-theft response including remote engine off when supported by the installed unit
- Real-time oversight of high value or sensitive vehicle assets
- Location history review for operational analysis and route verification

## Feature Availability Notes

- Feature support may differ by firmware version and hardware revision from the manufacturer
- Installation wiring and integration affect whether remote engine off and similar controls are available
- Regional cellular variants and SIM configuration can influence connectivity and reporting behavior
- Manufacturer documentation remains the authoritative source for device-specific limits and configuration options
- Plaspy surfaces the data the device reports; not all device features are controllable remotely in every installation

## Why Use Plaspy with These Features

Using the Concox TR06 with Plaspy gives organizations a unified way to view reported GPS locations, monitor security events, and manage operational visibility across vehicles. Plaspy normalizes incoming data from the tracker so dispatchers and fleet managers can quickly see position, alarms, and history in one place.
