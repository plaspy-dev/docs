# Concox - EG02 Features

This page provides a public feature overview for the Concox EG02 and how those features are used with Plaspy for tracking and operational visibility. It summarizes the EG02 capabilities relevant to fleet managers, scooter owners, and integrators who want to understand practical behavior and monitoring when the device reports into Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation approach, and the manufacturer implementation. The content below is based on the manufacturer description and is intended as a practical, non confidential summary of user facing functions rather than a detailed technical manual.

## Feature Overview

The Concox EG02 is positioned as a compact plug and play anti theft tracker for electric scooters and similar small vehicles. It combines location reporting, remote locking and audible alarms with power management features aimed at protecting vehicle batteries.

- Compact plug and play installation for quick fitting on e scooters and comparable vehicles
- Real time location reporting using GPS and LBS for continuous position visibility
- Remote lock and unlock control available via the device mobile app or SMS
- Audible alarm and support for an external buzzer to deter theft and aid device locating
- Wide input voltage compatibility for use across many e scooter and light vehicle types
- Multiple event alerts including vibration, speeding, power off, and geo fence entry or exit

## Core Features of Concox - EG02

- Plug and play form factor designed for easy installation on electric scooters
- GPS and LBS based real time tracking for consistent location updates
- Remote lock and unlock capability through the vendor app or SMS commands
- Built in alarm behavior for unauthorized movement and the ability to drive an external buzzer
- Wide working voltage range for compatibility with a range of vehicle electrical systems
- Battery protection features to minimize battery drain and help preserve vehicle power
- Keyless start functionality via mobile app or SMS as described by the manufacturer
- Event alerts for abnormal vibration, speeding, power off, and geo fence entry and exit

## How These Features Work with Plaspy

Plaspy ingests location reports and event messages from compatible EG02 units to provide centralized map visibility and event tracking. When an EG02 device is connected to Plaspy, its location and alert messages appear as live updates and historical events in the platform.

- Real time and historical location display on Plaspy maps using the EG02 GPS and LBS reports
- Event logging and notifications for alarms, vibration alerts, speeding, power off, and geo fence events
- Audit trail of remote state changes reported by the device such as lock or unlock actions when those events are sent to the server
- Plaspy automatically detects tracker protocol during activation so device messages are mapped to the platform without manual protocol selection
- Device grouping and asset tagging to reflect e scooter fleets and vehicle types supported by the EG02

## Typical Use Cases

- Theft prevention and recovery for personal e scooters using alarm and location reporting
- Fleet monitoring for scooter rental and sharing operations to track location and movement events
- Asset protection and locating of golf carts or light industrial vehicles in managed sites
- Oversight of vehicle power state and battery protection behavior to reduce unexpected drain
- Remote verification of vehicle status and locating a vehicle with audible buzzer or alarm events

## Feature Availability Notes

- Some features depend on the device firmware and may vary between firmware versions or hardware revisions
- Remote functions described by the manufacturer such as SMS control and mobile app lock unlock may require specific firmware and a configured cellular service
- External buzzer and certain alarm behaviors require compatible wiring and installation to function as intended
- Geo fence features and speeding alerts depend on device configuration and how the EG02 is set up in the platform
- Regional device variants or carrier configurations can affect which functions are available in a given market

## Why Use Plaspy with These Features

Using Plaspy with the Concox EG02 brings device reports into a single platform designed for visibility and operational oversight. The combination is useful for operators who need map based tracking, event history, and consolidated alerts to manage scooter fleets or protect individual vehicles. Plaspy presents device events and locations in ways that support day to day monitoring and incident investigation.
