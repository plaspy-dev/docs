# Concox - PL601 Features

This page provides a public, non sensitive overview of the Concox PL601 feature set and how the tracker can be used with Plaspy for live location, alerting, and basic telemetry. It is intended to describe practical capabilities visible to Plaspy users and to help teams assess fit for personal safety and small asset tracking workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant and the way the device is installed and configured. Refer to the official manufacturer documentation for device specific details and to confirm optional sensor support for any particular unit.

## Feature Overview

The PL601 is a compact LTE Cat 1 portable GNSS tracker optimized for personal safety and small asset tracking. It pairs multi mode positioning and AGPS assistance with two way audio and an SOS button, while offering BLE configuration and optional motion related sensors for richer telemetry.

- Multi mode positioning combining GNSS, Wi Fi and LBS with AGPS assistance for faster fixes in challenging locations
- Two way HD audio for remote voice monitoring and safety checks
- Dedicated SOS panic button with instant alerting for rapid notification
- BLE 5.0 support for local configuration and for connecting compatible BLE sensors
- Compact, rugged IP65 enclosure with lanyard and back clip mounting options

## Core Features of Concox - PL601

- LTE Cat 1 cellular connectivity for real time location transmission and alerts
- GNSS plus Wi Fi and LBS positioning with AGPS assistance for reduced time to first fix
- Built in microphone and loudspeaker enabling two way HD audio monitoring
- Dedicated SOS panic button for emergency signaling and immediate alerts
- BLE 5.0 radio for configuration and optional peripheral connectivity
- Optional accelerometer and barometer sensors for motion and environmental context
- Compact IP65 rated design with multiple mounting options for portable use

## How These Features Work with Plaspy

Plaspy ingests the PL601 location and event streams to present live positions, history, and device events in a centralized view. The device reports positioning data and alerts so operators can monitor movement, respond to SOS signals, and review past routes from within Plaspy.

- Real time location updates and historical route playback shown on Plaspy maps and timelines
- SOS panic alerts surfaced as immediate events for operator notification and response workflows
- Two way voice sessions and monitored audio events available through Plaspy event histories and alerts
- Geo fence entry and exit notifications, low battery and abnormal noise events integrated as Plaspy events when configured
- BLE based configuration and peripheral sensor telemetry forwarded to Plaspy where supported

## Typical Use Cases

- Personal safety monitoring for children, elderly family members, or lone workers using SOS and voice monitoring
- Pet and package tracking where a compact, lightweight tracker is required for discreet attachment
- Short term rental and logistics tracking using route playback and geo fence notifications
- Field personnel oversight combining location, motion events and audible alerts for rapid response
- Supplementary telemetry for distributed assets when BLE sensors provide context in Plaspy

## Feature Availability Notes

- Feature sets can differ by firmware release and by regional hardware variants produced for different markets
- Optional sensors such as accelerometer and barometer may not be present on every unit and can depend on the exact model variant
- Mounting, placement and local radio conditions affect GNSS, Wi Fi and LBS positioning performance
- Certain features like audio monitoring and alarm behavior are subject to local regulations and device firmware settings
- Always confirm the capabilities of a specific PL601 unit with the manufacturer documentation for that serial number or batch
