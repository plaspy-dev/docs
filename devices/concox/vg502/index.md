# Concox - VG502

![VG502](./tracker.png)

The VG502 OBDII GNSS tracker is a Plaspy compatible, plug-and-play GPS tracker designed for company cars, private vehicles, and usage-based insurance \(UBI\) programs. Installing in seconds via the vehicle’s OBD-II port, the VG502 delivers reliable real-time tracking and vehicle telemetry without hardwiring—making it an ideal choice for fleet management teams and insurers seeking rapid deployment, rich diagnostics, and actionable driving-behavior insights.

Built around dual GNSS \(GPS + BDS\) and GSM cellular connectivity, the VG502 pairs on-board diagnostics \(mileage, fault codes, ACC/ignition status, fuel consumption, battery voltage, engine speed\) with driving behavior analysis \(DBA\) and instant alerts \(collision, geo-fence, device removal, power loss\). BLE 4.0 support simplifies local configuration and firmware updates and enables optional Bluetooth sensors, lowering maintenance costs while keeping your Plaspy-enabled monitoring and reporting responsive and accurate.

## Key Highlights

- Plaspy compatible OBD-II GPS tracker for plug-and-play installation in private and company cars.
- Dual GNSS \(GPS + BDS\) positioning with quoted accuracy better than 2.5 m CEP and fast TTFF performance.
- Comprehensive telemetry: mileage, fault codes, ACC/ignition status, fuel consumption, battery voltage, and engine speed.
- Driving Behavior Analysis \(DBA\) detects harsh acceleration, braking, cornering and collisions for UBI and fleet safety programs.
- BLE 4.0 for local configuration, firmware updates, and optional Bluetooth sensors to extend monitoring \(e.g., temperature or asset beacons\).
- Instant alerts: fault codes, collision, speeding, device pull-out, geo-fence entry/exit, power disconnection, and vehicle battery monitoring.
- Broad OBD-II protocol support \(ISO 9141-2, ISO 14230-4 KWP, ISO 15765-4 CAN variants\) for compatibility across vehicle makes.

## How It Works with Plaspy

When paired with Plaspy, the VG502 streams GNSS fixes and OBD-II telemetry to your Plaspy dashboard for real-time tracking, alerts, and historical reports. Plaspy ingests the device’s location, diagnostics and event reports and applies geofencing, reporting and analytics rules so fleet managers and insurers can act on vehicle status, driver safety, and usage patterns immediately.

- Real-time location and telemetry updates: GNSS positions and OBD-II data are forwarded to Plaspy for live maps and trip playback.
- Ignition/ACC status: ACC state and engine parameters appear in Plaspy event logs to support idling, duty-time and trip segmentation.
- Fuel monitoring and mileage: OBD-derived fuel consumption and odometer readings feed Plaspy reports for cost and efficiency analysis.
- Driving behavior alerts: harsh acceleration, braking and cornering events trigger notifications and scorecards inside Plaspy.
- Bluetooth sensors: BLE 4.0 enables local accessory connectivity; sensor data can be surfaced through Plaspy where applicable.

## Technical Overview

| Connectivity | GSM cellular \(Nano-SIM\), OBD-II interface |
| --- | --- |
| Bands | GSM: B2 / B3 / B5 / B8 |
| Power & Battery | Vehicle power input 9–36 VDC; backup battery 50 mAh, 3.7 V |
| Interfaces | OBD-II plug \(supports K-Line and CAN Bus; ISO 9141-2, ISO 14230-4 KWP, ISO 15765-4 CAN variants\) |
| GNSS | Dual GNSS: GPS + BDS; sensitivity tracking -162 dBm; acquisition -148 dBm \(cold\) / -156 dBm \(hot\); quoted accuracy &lt; 2.5 m CEP |
| Bluetooth | BLE 4.0 for local configuration, firmware updates, and optional Bluetooth accessory connectivity |
| Data Storage | 4 + 4 MB on-board storage |
| SIM | Nano-SIM slot |
| Remote Management | Local firmware updates via BLE; configuration through BLE tools |
| Form Factor | OBD-II plug; dimensions 61 × 52 × 26 mm; weight approx. 55 g |
