# Concox - JM-VG03 Features

This page provides a public feature overview of the Concox JM-VG03 and how its capabilities are presented when used with Plaspy. It summarizes the model's main functions and practical value for vehicle tracking and fleet oversight while keeping the focus on non-sensitive, user-facing information.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device-specific technical details and the latest firmware notes, consult the official Concox documentation.

## Feature Overview

The JM-VG03 is a compact vehicle tracker designed for broad compatibility across cars, trucks, and motorcycles. Its design emphasizes positioning performance, simple installation options, and a set of monitoring and security-oriented alerts useful for personal and commercial deployments.

- Wide operating voltage range allowing use across many vehicle types
- Inbuilt large antenna and compact form factor for improved positioning and flexible hidden installation
- Anti-theft alerts including power disconnection and tampering notifications
- Driving behavior detection that flags harsh braking, sharp turns, and speeding events
- Remote cut-off capability via an installed relay for vehicle immobilization
- IP65 dust and water resistance for reliable operation in tough environmental conditions

## Core Features of Concox - JM-VG03

- Broad voltage compatibility suitable for cars, trucks, motorcycles and similar vehicles
- Compact housing with inbuilt large antenna for faster positioning and discreet installation
- Anti-theft notifications for power supply disconnection and tamper events
- Driving behavior analysis detecting harsh braking, sharp turns, and speeding
- Remote cut-off (immobilization) support using an installed relay
- Ignition detection monitoring ACC or ignition status
- Geo-fencing support to set virtual boundaries and receive crossing alerts
- Multiple event alerts including low battery, speeding, device removal, and drifting

## How These Features Work with Plaspy

When paired with Plaspy, the JM-VG03 reports location and event information into a centralized tracking platform where administrators and users can monitor vehicle activity. Plaspy's interface and alerting tools help translate the device's signals into actionable visibility and operational oversight.

- Real-time location updates and map visualization for tracked assets
- Event notifications for tampering, power loss, and geo-fence crossings presented in Plaspy
- Driving behavior events visible in trip or event logs to support safety reviews
- Ignition and status indicators shown in asset details for operational context
- Remote immobilization actions coordinated through a relay installation, with status reflected in the platform

## Typical Use Cases

- Fleet oversight for mixed vehicle fleets requiring monitoring across cars, vans, and trucks
- Theft prevention and recovery workflows using tamper and power disconnection alerts
- Driver safety programs that review harsh braking, sharp turns, and speeding events
- Remote immobilization for high-value assets or to prevent unauthorized use
- Route and boundary control using geo-fencing for service areas or restricted zones
- Rugged installations where IP65 ingress protection is required
