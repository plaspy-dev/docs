# Concox - VL103D Features

This page provides a public feature overview for the Concox VL103D and how its capabilities relate to Plaspy. It summarizes the device functions relevant to real time location, vehicle telemetry, and common operational workflows when the VL103D is used with the Plaspy tracking platform.

The VL103D description on this page is grounded in the manufacturer provided device information and the model summary supplied for Plaspy compatibility. Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation, so always confirm device specifics with the vendor documentation.

## Feature Overview

The VL103D is a compact LTE GNSS vehicle terminal designed for discreet installation in motorcycles, passenger cars, and light commercial vehicles. It pairs cellular connectivity and high sensitivity GNSS with vehicle integration interfaces so it can feed position and basic vehicle telemetry into Plaspy for tracking, recovery, and fleet workflows.

- Continuous real time tracking over LTE with 2G fallback for coverage continuity.
- High sensitivity GNSS positioning using GPS and BDS with sub 2.5 meter CEP accuracy for precise location reporting.
- Vehicle integration inputs and outputs including ACC ignition input, relay digital output for remote cut off, configurable SOS input, and a 0 to 5 volt ADC for analog sensors.
- Rugged form factor with IP66 rating, wide operating voltage range, and a small enclosure suited to discreet installations.
- Onboard motion intelligence from a 3 axis accelerometer to report harsh events and driving related activity.

## Core Features of Concox - VL103D

- LTE Cat 1 cellular connectivity with GSM fallback for broad network reach and continuous reporting.
- GPS plus BeiDou positioning and LBS assistance for fast time to first fix and consistent position updates.
- Wide input voltage range 9 to 90 VDC to support installation across vehicle types.
- Built in industrial backup battery for short term power continuity when main power is removed.
- Vehicle I O set including ACC ignition detection, relay digital output for remote cut off, configurable SOS input, and 0 to 5 V ADC for analog telemetry.
- Integrated 3 axis accelerometer for harsh event detection and basic motion sensing.
- Compact IP66 enclosure suitable for exposed vehicle environments and discreet mounting.
- LED indicators for GNSS, cellular, and power status to assist with installation and diagnostics.

## How These Features Work with Plaspy

When a VL103D is connected to Plaspy, the device transmits GNSS positions and telemetry to the platform so operators can view live locations, receive event alerts, and review historical routes. Plaspy ingests the available position, sensor, and alarm data and presents it alongside configurable rules and reporting tools.

- Real time location updates and historical route playback shown on Plaspy maps for operational visibility.
- Ignition status and remote cut off signals reflected in Plaspy as discrete inputs and outputs for monitoring and response workflows.
- Analog sensor readings provided via the 0 to 5 V ADC can be recorded and charted in Plaspy for telemetry dashboards.
- Movement and alarm events from the accelerometer and other device inputs feed alerting rules and incident reports in Plaspy.
- Device state and LED based status information support installation verification and basic in field diagnostics when viewed with Plaspy monitoring.

## Typical Use Cases

- Stolen vehicle recovery workflows that use compact installation, continuous tracking, and remote cut off capability.
- Fleet management for light commercial vehicles requiring position reporting, route history, and driver event visibility.
- Anti theft and remote immobilization scenarios that integrate relay output and movement alarms through Plaspy.
- Analog sensor telemetry for fuel or other vehicle sensors fed into fleet reports and dashboards.
- Motorcycle or covert installations where compact form factor and IP66 protection are required.
- Safety and driver behaviour monitoring using accelerometer based harsh event reporting.
