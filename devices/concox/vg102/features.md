# Concox - VG102 Features

This page describes the public feature context for using the Concox VG102 tracker with Plaspy. It summarizes the VG102 capabilities that are relevant to fleet managers, lenders, leasing operators, and recovery teams who plan to integrate this motorcycle focused tracker into Plaspy for visibility, alerts, and centralized monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The content below uses the provided VG102 description as the basis; for device specific configuration, detailed hardware specs, and the latest firmware notes please consult the official Concox documentation.

## Feature Overview

The VG102 is a compact 2G GNSS tracker purpose built for motorcycles and two wheeler fleets. It is designed for discreet installation and resilient outdoor operation, delivering positioning, event alerts, and anti theft controls that integrate into Plaspy for centralized monitoring and response.

- High sensitivity GNSS positioning using GPS BDS and GLONASS for dependable location reporting suitable for real time tracking.
- Built in relay for remote immobilization to support anti theft and recovery operations when coordinated through a management platform.
- Onboard event alerts including tip over tamper SOS geo fence entry and exit to surface important incidents in dashboards and notifications.
- IP66 rated enclosure and internal backup battery for continued operation in adverse weather and when vehicle power is lost.
- Optional plug and track adapter cable and compact form factor to simplify damage free installation on common motorcycle models.

## Core Features of Concox - VG102

- Compact 2G GNSS tracker designed specifically for motorcycles and two wheeler fleets.
