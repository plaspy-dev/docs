# Concox - GT06E Features

This page describes the public feature context for using the Concox GT06E tracker with Plaspy. It focuses on the user-facing capabilities you can expect to see in Plaspy for this model, how those capabilities are useful in fleet and vehicle monitoring, and which features are called out by the manufacturer in public materials.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, regional model, and installation method. Where a function is optional or depends on device configuration this page notes that dependence, and we recommend checking manufacturer documentation and device settings for final details.

## Feature Overview

The Concox GT06E is presented as a 3G GPS tracker designed for fleet and vehicle monitoring with a set of core tracking and alarm features plus optional I/O functions. It is intended to provide reliable real-time location updates and a range of event and status reporting that can be consumed by a fleet management platform such as Plaspy.

- 3G connectivity for faster and more reliable reporting of location and events
- Real-time tracking and position updates for fleet visibility
- Standard alarms including SOS alarm, overspeed alert, and geo-fence notifications
- Tele-cutoff petrol feature for remote fuel or engine control where supported
- Optional digital outputs for door detection and vehicle pinpoint using audio-visual alert
- External power voltage monitoring for basic power supervision

## Core Features of Concox - GT06E

- 3G network support to improve communication reliability and timeliness
- Real-time GPS location reporting for tracking and route visibility
- Geo-fence functionality to trigger alerts when a vehicle enters or leaves a defined area
- SOS alarm reporting for emergency notification
- Overspeed alert to notify of speed threshold violations
- Tele-cutoff petrol capability for remote cutoff actions where the device and installation support it
- Optional digital I/O for door detection and audio-visual vehicle pinpoint
- External power voltage monitoring to detect changes in external supply status

## How These Features Work with Plaspy

Plaspy receives and normalizes tracker reports so that location, alarms, and I/O status from supported devices like the GT06E appear in a single operational view. Plaspy can automatically detect the tracker protocol and surface events and telemetry in the platform interface for monitoring and historical review.

- Live location and recent movement are shown on Plaspy maps and in device status panels
- Alarms such as SOS, overspeed, and geo-fence events are recorded and can trigger notifications or logs
- Optional digital input events such as door detection are presented as device inputs when the tracker reports them
- External power voltage readings are recorded where the device reports voltage status and can be used for basic power monitoring
- Remote control actions that the device supports, such as tele-cutoff, are reflected in Plaspy as events or commands when enabled and properly configured

## Typical Use Cases

- Fleet location tracking and route monitoring for logistics and service vehicles
- Rapid alerting for emergency SOS events reported by drivers or vehicle occupants
- Geo-fence driven notifications for route compliance and entry/exit monitoring
- Door open and close monitoring for cargo security when optional I/O is fitted
- Power supply supervision to detect and log external power interruptions or changes
- Remote cutoff workflows where tele-cutoff features are required and legally permitted

## Feature Availability Notes

- Some functions listed as optional by the manufacturer depend on specific hardware revisions or accessory wiring and may not be present on every unit
- Firmware version can change how alarms, I/O reporting, and voltage monitoring behave; firmware updates may add or modify features
- Certain remote control capabilities require correct installation and configuration by an installer or technician
- Cellular band and network support for 3G features may vary by region; check your local variant for network compatibility
- For a complete and device-specific feature set, consult the official manufacturer documentation and device configuration guides
