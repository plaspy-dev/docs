# Concox - VL110C Features

This page provides a public, non-sensitive feature summary for the Concox VL110C and how its capabilities are used with Plaspy. It focuses on practical, user facing functions, describing what the device reports and how that information can appear inside Plaspy for monitoring, alerting and fleet workflows.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method and manufacturer implementation. For the latest device specific technical details and installation guidance consult the manufacturer documentation and release notes.

## Feature Overview

The VL110C is a compact vehicle GNSS terminal designed for reliable real time tracking across motorcycles, passenger cars, light commercial vehicles and small equipment. It combines cellular connectivity and rugged hardware with a backup power option and inputs for vehicle state reporting to provide continuous situational awareness.

- Real time GNSS positioning using GPS BDS and GLONASS for precise location reporting under typical conditions.
- 4G LTE Cat 1 communication with GSM 2G fallback to maintain connectivity in marginal coverage areas.
- Rugged IP65 enclosure and wide 9–90V DC input suited to small vehicles and mixed fleet installations.
- Internal backup battery to preserve telemetry when vehicle power is removed for theft recovery and offline reporting.
- Ignition input and relay output support basic vehicle state monitoring and remote cut off actions for anti theft workflows.

## Core Features of Concox - VL110C

- 4G LTE Cat 1 cellular connectivity with GSM 2G fallback for resilient data reporting.
- GNSS positioning with GPS BDS GLONASS and published positioning accuracy under typical conditions.
- Wide voltage input range and vehicle battery protection for flexible installation across different vehicle types.
- Internal industrial backup battery to maintain reporting during external power loss.
- Ignition ACC input for reporting driving state and event tagging.
- Relay output for remote cut off control as part of anti theft workflows.
- GNSS and LTE jamming detection with configurable alarms to support stolen vehicle recovery and security monitoring.
- Compact IP65 rated enclosure for installation on motorcycles cars and light commercial vehicles.

## How These Features Work with Plaspy

Plaspy ingests the VL110C telemetry to present live positions, events and history in unified fleet dashboards. The integration supports live monitoring, event driven alerts and remote commands that help teams respond quickly to incidents and manage vehicle operations.

- Real time location updates appear on Plaspy maps for live tracking and route playback.
- Ignition state and event tags are available in Plaspy dashboards for trip segmentation and basic driving state visibility.
- Alarm and jamming detection events are forwarded to Plaspy so teams can receive alerts and take action.
- Remote relay or immobilizer commands can be issued from Plaspy when supported by the device setup to assist in recovery or theft response.
- Historical position and event logs in Plaspy enable reporting and operational analysis for fleet oversight.

## Typical Use Cases

- Small vehicle and motorcycle fleet management with continuous location and trip visibility.
- Stolen vehicle recovery workflows using jamming detection and remote cut off capabilities.
- Dealer and rental vehicle tracking for handover checks and remote status monitoring.
- Mixed equipment monitoring where compact installation and wide voltage tolerance are required.
- Safety and operational reporting that uses ignition events and driving behavior indicators for basic coaching and incident review.
