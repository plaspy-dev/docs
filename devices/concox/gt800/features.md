# Concox - GT800 Features

This page provides a public, feature-oriented overview of the Concox GT800 tracker and how its capabilities are used with Plaspy for vehicle visibility and event monitoring. It focuses on user-facing functions and practical operational value rather than low level protocol specifics.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation method, and manufacturer implementation. For device specific parameters, wiring, or the most recent firmware behavior consult official Concox documentation and the device packaging details.

## Feature Overview

The Concox GT800 is positioned as a multifunctional vehicle tracker combining location services with basic vehicle status reporting and remote communication. It is suitable for both single vehicle use and managed fleets where visibility and timely alerts are important.

- Real time GPS and AGPS location reporting for ongoing vehicle position awareness
- Door status detection to monitor whether vehicle doors are opened or closed
- Two way communication that enables remote command and status exchanges with the tracker
- SOS call capability to provide an emergency notification mechanism
- Practical suitability for individual owners and small to medium fleet operators

## Core Features of Concox - GT800

- GPS and AGPS based location tracking for continuous position updates
- Real time location visibility suitable for live monitoring
- Door status detection to report open and closed states
- Two way communication support for sending commands and receiving responses
- SOS call feature for emergency notification and rapid response communication
- Designed for vehicle installations with an emphasis on reliability and value

## How These Features Work with Plaspy

Plaspy collects and presents the tracker data so you can monitor location and events from a single management platform. When the GT800 is configured to report to Plaspy, location updates and supported status events become visible in Plaspy dashboards and device histories.

- Plaspy displays live location updates and location history for operational oversight
- Door open and close events reported by the GT800 appear as status events in Plaspy
- SOS call notifications from the tracker can be surfaced in Plaspy as high priority events
- Two way communication from Plaspy can be used to send commands to the tracker where the device firmware supports remote command handling
- Plaspy automatically detects many common tracker protocols and accepts device connections to the platform endpoint

## Typical Use Cases

- Real time vehicle location monitoring for route tracking and asset visibility
- Security monitoring using door status to detect unauthorized access
- Emergency response coordination using SOS notifications to prioritize incidents
- Remote command and status checks for operational control and troubleshooting
- Small fleet oversight where cost effective tracking and event reporting are needed

## Feature Availability Notes

- Feature presence and exact behavior depend on the tracker firmware version and hardware revision

- Regional device variants or custom configurations from resellers may change supported functions
- Plaspy can accept device connections and present data, but specific command sets and event naming may vary by firmware
- Always consult the official manufacturer documentation for the definitive list of supported features and configuration steps
