# Concox - TR02 Features

This page provides a public feature overview for the Concox TR02 and how its capabilities relate to use with the Plaspy platform. It focuses on practical, user facing functions such as locating and tracking, group management, geo fence notifications, and multi account handling so you can understand what the device does in a fleet or vehicle tracking context with Plaspy.

Exact feature availability and behavior can differ by firmware version, hardware revision, installation method, and manufacturer implementation. The descriptions below are based on the TR02 public specifications and intended for general guidance; consult manufacturer documentation for the most current device specific details.

## Feature Overview

The Concox TR02 is a compact vehicle tracker designed to deliver simple, affordable location and tracking for cars and light vehicles. Its built in antenna and lightweight format make it suitable for straightforward installations where basic real time tracking and zone monitoring are required.

- Compact and lightweight design for unobtrusive vehicle installation and straightforward placement.
- Built in high gain GPS antenna with multi channel GPS reception for reliable location fixes.
- Group management tools to organize vehicles and manage fleets by logical groups.
- Geo fence notification to receive alerts when a vehicle enters or exits defined zones.
- Support for multiple user accounts to enable separate company user access and shared fleet management.

## Core Features of Concox - TR02

- Built in GPS antenna designed for vehicle locating and tracking.
- Simple locating and tracking functionality suitable for individuals and small fleets.
- Group management capability to organize vehicles into groups for monitoring.
- Geo fence notification for zone entry and exit alerts.
- Multiple account support for company users and role based access across vehicles.
- Lightweight physical size and low power consumption characteristics for vehicle use.
- Broad input voltage range and environmental tolerance for typical vehicle environments.
- GSM quad band support and multi channel GPS reception based on the public TR02 specification.

## How These Features Work with Plaspy

Plaspy provides a centralized way to visualize and manage TR02 devices alongside other trackers. When a TR02 is configured to report to Plaspy it becomes visible in maps, lists, and group views so teams can monitor vehicle movement and zone activity from a single platform.

- Location updates appear on Plaspy maps for live and historical tracking views.
- Geo fence triggers from the TR02 can be shown as notifications or events inside Plaspy for operational alerts.
- Group management on the device side maps to organizational views in Plaspy for easier fleet oversight.
- Multiple account support facilitates role based access to devices and groups in Plaspy user management.
- Plaspy automatically detects supported tracker protocols so TR02 devices can report without manual protocol selection.
- Devices reporting to the Plaspy server domain can be managed centrally for monitoring and reporting.
