# TrackerKing - EC35

![EC35](./tracker.jpg)

The TrackerKing EC35 is a rugged, Plaspy compatible GPS tracker engineered for demanding vehicle environments. Built around a Quectel 4G Cat1 module with automatic fallback to 2G, the EC35 delivers real-time tracking, reliable telemetry and route history playback for cars, trucks and motorcycles. Its IP68 waterproofing, wide 9–90V input range and internal backup battery make the EC35 a practical choice where uptime and durability matter.

The EC35 integrates sensor interfaces for fuel monitoring, temperature sensing and driver identification \(IButton\), plus optional Bluetooth relay modules for expanded telemetry and on-site connectivity. Designed to report using standard tracking protocols such as GT06, JT808 and Tianqin, the EC35 installs easily and pairs with Plaspy for fleet management, anti-theft protection, remote immobilizer control and detailed vehicle reporting.

## Key Highlights

- Plaspy compatible: supports GT06, JT808 and Tianqin protocols for straightforward integration with Plaspy’s real-time tracking and reporting.
- Reliable real-time tracking over 4G Cat1 with automatic 2G fallback to maintain connectivity across varied coverage areas.
- IP68 waterproofing and robust design for cars, trucks, heavy equipment and motorcycles in harsh conditions.
- Wide 9–90V input and internal backup battery to ensure continuous telemetry and power-failure alerts.
- Integrated ignition detection \(ACC\) and virtual ignition support for accurate mileage, ignition events and fleet telemetry.
- Support for external fuel level and temperature sensors to enable fuel monitoring and cold-chain tracking when required.
- Remote engine and fuel cut-off capability for anti-theft and immobilizer-style control from Plaspy.
- Driver ID with IButton and optional Bluetooth relay for flexible asset and personnel management.

## How It Works with Plaspy

When paired with Plaspy, the EC35 becomes a complete telematics endpoint: it sends location, sensor telemetry and status events to Plaspy’s server using industry-standard GPS tracking protocols. Plaspy ingests the device’s TCP/UDP reports to provide live maps, alerts, historical playback and fleet dashboards. The EC35’s features—such as ACC ignition detection, external sensor inputs and remote cut-off—are exposed in Plaspy for automated rules, notifications and remote control workflows.

- Real-time location and telemetry updates streamed to Plaspy via 4G Cat1 \(with 2G fallback\) for continuous tracking.
- Ignition and virtual ignition events reported to Plaspy for mileage, engine-hours and usage-based analytics.
- Fuel monitoring and external temperature sensor data transmitted to Plaspy for fuel management and cold-chain visibility.
- Remote engine and fuel cut-off \(immobilizer-style control\) actionable from Plaspy dashboards and alerts.
- Optional Bluetooth relay and IButton driver ID integrated into Plaspy for driver attribution and local sensor pairing.
