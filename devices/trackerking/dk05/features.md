# TrackerKing - DK05 Features

This page summarizes the public feature context for the TrackerKing DK05 when used with Plaspy. It focuses on practical, user facing capabilities and explains how DK05 telemetry and alerts are surfaced inside Plaspy for real time pet monitoring, history playback, and notification management.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The DK05 description below is based on the current public specification and model notes; for device level details and the latest firmware behavior please consult the manufacturer documentation linked at the end of this page.

## Feature Overview

The DK05 is a compact pet GPS tracker designed for collar or harness mounting and built for consistent location reporting and basic safety alerts. It combines cellular connectivity, waterproof protection, and a rechargeable battery in a small form factor so owners receive continuous location updates and actionable alerts through Plaspy.

- Real time GPS location reporting tailored for dogs and cats for live tracking on Plaspy maps.
- Movement and vibration alerts that notify owners of unusual motion or activity.
- Geo fence support with breach notifications managed from Plaspy for defined safe zones.
- Low battery warnings delivered to Plaspy so owners can plan recharging.
- Remote voice monitoring through an integrated microphone for short audio check ins via Plaspy.
- IP67 waterproof housing and compact size for comfortable collar use in wet conditions.

## Core Features of TrackerKing - DK05

- GPS based real time positioning for continuous location updates.
- Cellular connectivity with 4G plus 2G Cat‑1 and quad band GSM for broad network coverage.
- IP67 rated waterproof enclosure suitable for wet outdoor use.
- 1000 mAh rechargeable battery with app adjustable power saving modes.
- Movement and vibration alarms for activity and abnormal motion detection.
- Configurable geo fence alerts to monitor safe zones and receive breach notifications.
- Remote voice monitoring using the device microphone accessible from Plaspy.
- Compact collar friendly form factor with low weight for pet comfort.

## How These Features Work with Plaspy

Plaspy receives DK05 location and event data and presents it as live map tracking, alert notifications, and historical route playback. When added to a Plaspy account, the DK05 can be monitored alongside other devices, and Plaspy translates device telemetry into actionable information for owners and administrators.

- Real time positions appear on Plaspy maps and can be replayed in history views for route reconstruction.
- Movement and vibration events generate immediate notifications through Plaspy configured channels.
- Geo fence definitions created in Plaspy trigger breach alerts when the DK05 exits or enters defined zones.
- Low battery alerts are forwarded to Plaspy so users receive proactive recharge reminders.
- Remote voice monitoring sessions are initiated via the Plaspy interface for on demand audio checks.
- Plaspy detects common tracker protocols automatically when the DK05 is added, simplifying integration and setup.
