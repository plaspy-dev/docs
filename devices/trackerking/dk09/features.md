# TrackerKing - DK09 Features

This page provides a public overview of the TrackerKing DK09 features relevant to use with Plaspy. It summarizes the device capabilities that are commonly used for vehicle anti theft, real time tracking, and fleet monitoring when the DK09 is paired with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and the specifics of an individual installation. Refer to the manufacturer documentation for device supplies and firmware details for the most current, device specific information.

## Feature Overview

The TrackerKing DK09 is a Plaspy compatible 4G GPS tracker packaged in a relay style form factor for discreet installation. It is designed to provide continuous location updates, event alerts, and route history for vehicles and equipment, with features aimed at theft response and fleet oversight.

- Real time GPS positioning and historical route playback for location awareness and incident review
- Relay style housing for covert mounting in cars, motorcycles, and equipment
- Remote engine and oil cut off immobilizer control to support theft response workflows
- Movement and vibration alarms, overspeed alerts, geo fence alerts, and ACC ignition detection for event monitoring
- Wide input voltage tolerance and internal backup battery with power failure alarm for resilient operation across vehicle types

## Core Features of TrackerKing - DK09

- 4G GPS tracking for up to date position reporting and history logging
- Discreet relay style form factor for covert installation options
- Remote engine and oil cut off immobilizer capability to enable remote immobilization actions
- Movement and vibration alarm support for unauthorized motion detection
- Overspeed and geo fence alerting to notify on driving behavior and perimeter events
- ACC ignition detection for tracking ignition state and runtime events
- Internal backup battery that triggers a power failure alarm when external power is lost
- Mileage statistics and route logging to support operational reporting

## How These Features Work with Plaspy

When the DK09 is connected to Plaspy, the device’s position updates and event messages are ingested by the platform so fleet managers and owners can monitor assets and respond to incidents. Plaspy automatically recognizes tracker telemetry and surfaces relevant events and history in the dashboard.

- Live location and position history appear in Plaspy for real time monitoring and playback
- Immobilizer actions and ignition state are visible so operators can coordinate theft response
- Motion, overspeed, geo fence, and power failure alarms are routed to Plaspy for alerting and incident workflows
- Mileage and route logs are available for operational reports and review inside Plaspy
- Plaspy treats the DK09 as a telemetry source so alerts and history can be combined with other fleet data for oversight

## Typical Use Cases

- Fleet tracking and route history for scheduling, utilization, and incident analysis
- Vehicle anti theft deployments using covert installation and remote immobilizer control
- Motorcycle monitoring where a small relay style unit is preferable for discreet mounting
- Heavy equipment and generator tracking taking advantage of wide input voltage tolerance
- Operational alerting for overspeed, geo fence breaches, and ignition state changes
- Mileage reporting and route playback for compliance and operational review
