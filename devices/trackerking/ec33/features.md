# TrackerKing - EC33 Features

This page provides a public feature overview for the TrackerKing EC33 and explains how its capabilities are used with Plaspy for real time tracking, alerts, and history playback. It focuses on user facing functions and operational value when the EC33 is connected to a Plaspy fleet or asset management account.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a practical feature reference for Plaspy compatibility and review the official TrackerKing documentation for the most current device specific details.

## Feature Overview

The EC33 is a compact pure 4G tracker designed for reliable real time tracking and secure data delivery into Plaspy. It targets vehicle and motorcycle installations where discreet mounting, solid cellular connectivity, and event continuity are primary requirements.

- Pure 4G connectivity for modern cellular networks and consistent position reporting to Plaspy.
- GT06 protocol compatibility for quick integration and broad platform support.
- Anti theft functions including remote engine and fuel cutoff, vibration alarm, and ignition detection for event driven alerts.
- Large onboard memory with an 8000 point cache and blind area retransmission to preserve history during outages.
- Wide voltage support for mixed vehicle fleets and external battery voltage detection for power monitoring.

## Core Features of TrackerKing - EC33

- Pure 4G GPS tracking optimized for continuous position updates and live monitoring.
- GT06 protocol support enabling straightforward integration with Plaspy and other tracking platforms.
- Ignition ACC detection and virtual ignition reporting for accurate trip boundaries and status events.
- Remote engine and fuel cutoff functionality commonly referred to as an immobilizer for authorized remote intervention.
- Vibration alarm and geo fence alert support for theft detection and perimeter monitoring.
- Overspeed alerting and distance mileage or odometer statistics for fleet oversight.
- 8000 point memory cache with blind area retransmission to recover locations after network restoration.
- Dual IP and IP lock support for server redundancy and improved delivery reliability.

## How These Features Work with Plaspy

Plaspy receives position, status, and event payloads from the EC33 and presents them as live map positions, alerts, and historical routes. Plaspy automatically detects the tracker protocol and maps the EC33 event types to platform features so operators can monitor vehicles and respond to incidents in real time.

- Live location, speed, and heading updates shown on Plaspy maps for dispatch and monitoring.
- Ignition ACC events and virtual ignition status reflected in trip reports and start stop analytics.
- Immobilizer control and remote engine or fuel cutoff available for authorized users through Plaspy workflows.
- Alerts such as vibration, geo fence breach, overspeed, and power failure forwarded into Plaspy’s alerting and notification systems.
- History playback and odometer or mileage statistics synchronized to reconstruct trips and support reporting.
- Data continuity from the EC33 cache and blind area retransmission ensures recovered positions appear in Plaspy after connectivity returns.

## Typical Use Cases

- Fleet management with live tracking, mileage reporting, and overspeed controls to improve operational efficiency.
- Anti theft protection using immobilizer controls, vibration alarms, and power failure notifications to secure vehicles.
- Motorcycle and personal vehicle tracking where compact form factor and discreet installation matter.
- Mixed vehicle deployments that benefit from wide voltage support and external battery monitoring.
- Route reconstruction and compliance reporting using history playback and recovered GPS points.
- Remote monitoring for assets that spend time in areas with intermittent network coverage.

## Feature Availability Notes

- Firmware version, hardware revision, and regional variants can affect which features are present and how they behave.
- Some functions such as immobilizer controls or dual IP behavior may require specific configuration or authorization on both the device and Plaspy.
- Installation type and wiring affect ACC detection and power monitoring outcomes; proper installation is important for reliable telemetry.
- Blind area retransmission and memory cache behavior depend on device storage state and firmware handling of historical data.
- For the most accurate device capabilities confirm the installed firmware and consult the manufacturer documentation.

## Why Use Plaspy with These Features

Using the EC33 with Plaspy provides a practical combination of compact hardware and a platform designed to present live locations, alerts, and recovered history in one place. Plaspy’s automatic protocol detection and mapping of common GT06 events reduce setup time, while history playback and mileage statistics help teams maintain operational records and investigate incidents.
