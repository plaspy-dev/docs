# Pure 4G EC33

The Pure 4G EC33 from TrackerKing is a compact, high-performance GPS tracker purpose-built for reliable Plaspy compatible real-time tracking. As TrackerKing’s smallest pure 4G tracker, the EC33 provides stable 4G connectivity and modern protocol support to integrate quickly with Plaspy for fleet management, anti-theft protection, and personal vehicle monitoring on Android and iOS.

Designed for cars, motorcycles, and mixed fleets, the EC33 combines core telemetry and safety features—ACC ignition detection, remote engine/fuel cutoff \(immobilizer\), vibration and geo-fence alarms, overspeed alerts, and an 8000-point cache—to keep vehicle location, telemetry, and event streams flowing into Plaspy even when networks are unreliable.

## Key Highlights

- Plaspy compatible pure 4G GPS tracker optimized for real-time tracking and fast integration using the GT06 protocol.
- Compact form factor—TrackerKing’s smallest 4G device—ideal for discreet installation on cars and motorbikes.
- Robust anti-theft tools: remote engine and fuel cutoff \(immobilizer\), vibration alarm, and ignition \(ACC\) detection.
- Reliable telemetry and data continuity with an 8000-point memory cache and blind-area retransmission for recovered GPS data.
- Wide operating voltage \(9–90V\) and external battery voltage detection for fleet and heavy-vehicle compatibility.
- Dual IP and IP lock support for server redundancy and secure data delivery to Plaspy.
- History route playback, mileage/odometer statistics, geo-fence and overspeed alerts for better fleet oversight.

## How It Works with Plaspy

The EC33 uses the widely supported GT06 protocol and pure 4G connectivity to stream GPS positions, status events, and telemetry directly to Plaspy. Plaspy reads the device’s event and location payloads to present live maps, alerts, and reports. Because the EC33 caches up to 8000 points and supports blind-area retransmission, Plaspy receives recovered location history once the tracker regains network connectivity, ensuring continuity in route playback and trip summaries.

- Real-time location, speed, and heading updates streamed to Plaspy for live monitoring and dispatch.
- Ignition \(ACC\) status and virtual ignition reporting for accurate engine-on/engine-off events and fuel monitoring workflows.
- Remote engine and fuel cutoff controls available via Plaspy for immobilizer actions when authorized.
- Alerts forwarded to Plaspy: vibration alarm, geo-fence breaches, overspeed, and power-failure notifications.
- History playback and odometer/mileage statistics synchronized with Plaspy for compliance and reporting.
