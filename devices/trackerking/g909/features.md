# TrackerKing - G909 Features

This page provides a public feature summary for the TrackerKing G909 and explains how its capabilities map to the Plaspy platform. It is written to help fleet operators, vehicle owners, and integrators understand the practical functions you can expect when the G909 is installed and managed through Plaspy.

Exact feature availability can vary by firmware version, hardware revision, installation method, and how the manufacturer has implemented specific functions. Use this page as a general compatibility and capability guide and refer to official manufacturer resources for precise, device level details.

## Feature Overview

The TrackerKing G909 is a wired vehicle GPS tracker designed for continuous positioning, tamper-resistant installation, and straightforward platform integration. When paired with Plaspy, the device provides real-time location and event visibility plus remote control options useful for fleet oversight and security workflows.

- Real-time tracking and history route playback for situational awareness and trip review
- Hardwired vehicle power with an internal backup battery to detect power failures and improve uptime
- ACC ignition detection and mileage reporting to support trip analytics and utilization tracking
- Multiple alarm types including SOS, vibration, geo-fence breach, and overspeed to notify incidents
- Remote immobilizer capability using engine or oil cut-off for anti-theft response
- Remote voice monitoring support via an external microphone for on-site verification when allowed

## Core Features of TrackerKing - G909

- Continuous real-time location reporting for live monitoring and display in Plaspy
- Hardwired 9–36V power design with internal backup battery for power-failure alerts
- ACC ignition state detection for accurate trip start and stop recognition
- Mileage statistics for distance tracking and operational reporting
- Alarm reporting including SOS, vibration, geo-fence, and overspeed events
- Remote immobilizer support allowing engine or oil cut-off commands from the platform
- History route playback to review past trips and routes within Plaspy
- External microphone input for remote voice monitoring capabilities subject to policy and configuration

## How These Features Work with Plaspy

Plaspy receives location, status, and event updates from the G909 and presents them in dashboards, alerts, and historical views. The platform centralizes telemetry and control so operators can monitor vehicles, investigate incidents, and issue remote commands where supported.

- Live position updates and history playback are shown in Plaspy for route review and auditing
- Ignition status and trip events are surfaced as telemetry for usage and utilization reports
- Mileage and battery voltage data are available for operational diagnostics and maintenance planning
- Alarm events such as SOS, vibration, geo-fence breach, and overspeed are forwarded to Plaspy alerting channels
- Remote immobilizer commands can be issued through Plaspy to disable vehicle engine or oil feed when configured
- Voice monitoring support is represented as a device capability and can be used for verification when enabled and compliant with local policies

## Typical Use Cases

- Fleet management and utilization tracking with continuous location, mileage, and ignition telemetry
- Anti-theft protection combining real-time alarms and remote immobilizer control
- Vehicle and motorcycle installations requiring a tamper-resistant, permanently wired tracker
- Route auditing and driver oversight using history route playback and trip statistics
- Remote diagnostics and operational health monitoring through battery voltage and alarm reporting
- Emergency response and verification workflows using SOS and remote voice monitoring where permitted
