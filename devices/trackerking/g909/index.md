# TrackerKing - G909

![G909](./tracker.jpg)

The G909 is a wired vehicle GPS tracker built for reliable, continuous positioning and remote control. Designed for direct installation into cars and motorcycles, the G909 delivers Plaspy compatible real-time tracking and platform integration so fleet operators and vehicle owners can monitor location, telemetry and security events from the Plaspy dashboard or API.

With hardwired power and an internal backup battery, the G909 focuses on robust uptime, rapid event alerts and practical control functions such as ACC ignition detection and remote engine/oil cut-off. Its feature set makes the G909 an excellent option for fleet management, anti-theft protection and everyday vehicle tracking where a tamper-resistant, permanently installed GPS tracker is required.

## Key Highlights

- Plaspy compatible GPS tracker for real-time tracking and centralized platform management.
- Hardwired 9–36V design with internal backup battery to trigger a power-failure alarm.
- ACC ignition detection and mileage statistics for accurate telemetry and trip analysis.
- Multiple alarm types: SOS, vibration, geo-fence, and overspeed for immediate incident notification.
- Remote immobilizer capability via engine/oil cut-off to secure assets in theft events.
- History route playback to review past trips, mileage and operational patterns for fleet oversight.
- Remote voice monitoring via external microphone for on-site verification and safety checks.

## How It Works with Plaspy

The G909 connects with Plaspy to deliver location, status and command capabilities to your dashboard and alerts system. Once installed and registered on Plaspy, the device sends periodic telemetry and event-driven updates so managers can perform real-time tracking, review historical routes and issue remote commands like immobilization.

- Real-time location and telemetry updates to Plaspy for continuous situational awareness.
- ACC ignition status reporting for trip detection, start/stop events and ignition-based alerts.
- Mileage statistics and battery voltage telemetry for fleet diagnostics and preventive maintenance planning.
- Remote engine/oil cut-off \(immobilizer\) control via Plaspy to disable a vehicle when required for anti-theft action.
- Alarm events \(SOS, vibration, geo-fence breaches, overspeed\) forwarded to Plaspy for immediate alerting and workflow triggers.
- Remote voice monitoring support using an external microphone to verify driver status or security conditions when permitted by policy.
