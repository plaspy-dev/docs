# Winrich - TK-168 Features

This page summarizes the public feature context for using the Winrich TK-168 GPS tracker with Plaspy. It describes the model's core capabilities, what to expect when the device is integrated with Plaspy, and practical value for vehicle tracking and fleet operations. The information here is intended for general planning, comparison, and platform compatibility guidance.

Exact feature availability and behavior can vary by device firmware version, hardware revision, installation method, and manufacturer implementation. For device-level configuration, wiring details, and the most current technical specifications please consult official Winrich documentation and your installer.

## Feature Overview

The TK-168 is a compact vehicle tracker designed for reliable real-time location reporting and basic telematics. It supports both GPRS data and SMS reporting modes and is built for discreet vehicle installation, making it suitable for fleet monitoring and anti-theft workflows when paired with Plaspy.

- Real-time location reporting via GPRS and SMS for immediate visibility in Plaspy.
- High-sensitivity GNSS reception for stable position fixes in typical urban and open environments.
- Quad-band GSM connectivity for broad regional coverage where cellular networks are available.
- Remote fuel or power cut-off support for immobilization-style anti-theft actions.
- SOS emergency switch for rapid incident alerts and operator notification.
- Route replay and distance logging to support post-trip review and simple mileage reporting.

## Core Features of Winrich - TK-168

- GPRS and SMS reporting modes for flexible connectivity and fallbacks.
- Quad-band GSM support to work across common cellular bands.
- SiRF III GNSS receiver for fast satellite acquisition and position stability.
- Remote engine fuel or power cut-off control as an anti-theft capability.
- SOS emergency switch that can trigger immediate alerts to monitoring systems.
- Compact form factor intended for discreet vehicle installation.
- Support for distance and route history suitable for basic fleet reporting.

## How These Features Work with Plaspy

When the TK-168 is configured to report to Plaspy, the device sends location and telemetry updates that Plaspy ingests for live monitoring, alerts, and historical analysis. Plaspy detects the device protocol automatically to simplify setup and reflect incoming events in the platform.

- Live map tracking and position markers show current vehicle location in Plaspy.
- SOS alerts reported by the device are surfaced as high-priority events for rapid operator attention.
- Remote fuel or power cut-off events can be initiated and logged through Plaspy for anti-theft response and audit trails.
- Historical route replay and distance logs enable post-trip review and basic mileage reporting inside Plaspy.
- Configurable alerts and notifications can be tied to the device events supported by the TK-168 to match operational needs.

## Typical Use Cases

- Fleet anti-theft response and immobilization to prevent unauthorized vehicle use.
- Dispatch and route management with live position updates and route replay for planners.
- Basic driver oversight using distance and route history for coaching and compliance.
- Emergency response coordination using SOS alerts to notify operations teams.
- Discreet vehicle or asset tracking where a low-profile installation is required.
- Simple mileage and trip logging for operational reporting and reconciliation.
