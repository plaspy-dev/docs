# Winrich - GT003 Features

This page summarizes the public feature context for using the Winrich GT003 GPS tracker with Plaspy. It focuses on practical capabilities, operational value, and how the GT003 integrates into Plaspy workflows for real-time tracking, event reporting, and historical route analysis.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and how the device is installed. For the most current device-specific details refer to manufacturer documentation and consult your installer when planning deployments with Plaspy.

## Feature Overview

The GT003 is a compact wired tracker designed to provide continuous position updates and event-based telemetry to Plaspy. It is intended for always-on vehicle monitoring and supports a set of core functions that deliver visibility and operational oversight for mobile assets.

- Continuous GPS positioning and GSM/GPRS data transmission to support live tracking and history in Plaspy
- ACC ignition detection to record engine on/off events and enrich trip segmentation
- Geo-fence and movement alerts for perimeter monitoring and theft response workflows
- Overspeed alerting and route history playback to support compliance reviews and operational analysis
- Low power consumption and wired installation for long-term fleet deployments with minimal intervention

## Core Features of Winrich - GT003

- Real-time GPS location reporting compatible with Plaspy for live mapping
- GSM/GPRS connectivity for cellular data uplink of positions and events
- ACC ignition input to detect engine on and off states for trip logging
- Geo-fence triggers to generate alerts when a vehicle enters or leaves defined areas
- Movement detection and movement alerts to indicate unexpected vehicle motion
- Overspeed alert capability to notify when predefined speed thresholds are exceeded
- Route history storage and playback support for trip audits and driver review
- Compact wired form factor with built-in GPS and GSM antennas for simplified installation

## How These Features Work with Plaspy

When the GT003 is used with Plaspy, its position and event data feed into dashboards and reporting tools that provide visibility across assets. Plaspy ingests incoming telemetry and presents it as live location points, historical tracks, and event notifications for operational teams and managers.

- Live map visualization of ongoing vehicle locations and movement in Plaspy
- Event reporting for ACC ignition changes, geo-fence entries/exits, movement alerts, and overspeed notifications
- Route history playback and trip segmentation based on recorded GPS positions and ignition events
- Alerting and notification workflows in Plaspy triggered by device-generated events
- Consolidated reporting that combines position, route history, and event logs for audits and operations

## Typical Use Cases

- Fleet logistics and delivery operations needing continuous location visibility and route playback
- Rental car management for usage logging, return tracking, and basic misuse detection
- Motorcycle security installations where discreet wired trackers and movement alerts are required
- Taxi and ride service oversight to monitor vehicle location, engine status, and speed incidents
- General vehicle asset tracking across construction, field service, and mobile equipment fleets

## Feature Availability Notes

- Firmware differences can change how particular events are reported or which alert types are available
- Hardware revisions and regional model variants may alter available I/O, antenna configuration, or supported cellular bands
- Installation method and wiring (for example how ACC is wired) affect ignition detection and trip segmentation accuracy
- Some advanced integrations and companion sensor support are dependent on additional modules or installer configuration
- Always verify feature support for your specific device serial number and firmware with the manufacturer documentation
