# Winrich - TK102 Features

This page provides a public, feature-oriented summary of the Winrich TK102 series (often referenced as TK102B) and how its documented capabilities are used with Plaspy for tracking and fleet visibility. It focuses on the practical, non-sensitive feature context you can expect when integrating this tracker with the Plaspy platform.

Exact behavior and available functions can vary by firmware version, hardware revision, regional model variant, and installation method. For device-specific technical details or the latest firmware information, consult the device manufacturer and your supplier.

## Feature Overview

The Winrich TK102B combines GPS and GSM positioning with a small form factor and several practical convenience features that support continuous tracking in varied conditions. The features below describe how the device is positioned to provide reliable location data and operational usefulness when paired with a platform such as Plaspy.

- GPS and GSM dual positioning for continued location reporting when GPS is unavailable
- Support for common GSM frequency bands, making the device usable in many regions
- Replying with real address strings in multiple local languages to improve readability of location responses
- TF card support to locally store GPS positions and maintain a continuous route when network coverage is intermittent
- Built-in shock sensor for impact detection and added situational awareness
- Auto-set APN function to simplify cellular data configuration during setup

## Core Features of Winrich - TK102

- GPS and GSM dual positioning that allows seamless fallback to GSM-based location when GPS signal is poor
- Global GSM frequency coverage for broad regional applicability
- Local language real address replies with support for several languages including Arabic, Russian, Spanish, Portuguese, French, German, and English
- TF card support for local storage of GPS points to preserve route continuity during signal loss
- Built-in shock sensor to indicate potential impacts or tampering events
- Auto-set APN to reduce manual configuration steps during deployment
- Compact size and light weight for discreet installation and portability

## How These Features Work with Plaspy

Plaspy receives and interprets location updates and device events from compatible trackers like the Winrich TK102 series, providing a centralized view of position, route history, and reported events. Plaspy automatically detects the tracker protocol for supported devices and accepts reports into the platform for monitoring and analysis.

- Location reports from the device appear in Plaspy as position points on the map and as part of a continuous route when consecutive updates are available
- Stored locations saved to a TF card by the device can be uploaded and reconciled into the platform so routes maintain continuity after coverage gaps
- Local language address replies improve human readability of position descriptions when those strings are provided by the tracker
- Shock sensor events reported by the device can be represented in Plaspy as event markers or activity flags when the device transmits them
- Plaspy automatically detects compatible tracker protocols and accepts device reports to the platform domain, simplifying integration and configuration

## Typical Use Cases

- Preventing or investigating vehicle theft by maintaining continuous position visibility
- Tracking children, elderly relatives, or pets for safety and location awareness
- Managing personnel or mobile assets where predictable location reporting is important
- Preserving route history across intermittent cellular coverage for fleet operations
- Discreet or portable tracking where a small and lightweight device is preferred
- Areas where local language address replies help operators identify locations quickly

## Feature Availability Notes

- Feature sets and behaviors may differ between TK102 model variants and TK102B labeling; confirm the exact model you have
- Firmware updates can enable, change, or remove behaviors such as address formatting, storage policies, and event reporting
- Hardware revisions and regional variants may affect supported GSM bands and availability in specific countries
- Use of TF card storage requires that a card is installed and that the device is configured to store and later transmit saved points
- Installation and mounting choices can influence GPS reception and shock sensor behavior

## Why Use Plaspy with These Features

Using Plaspy with a compatible Winrich TK102 tracker centralizes location data and reported events so organizations gain a consistent operational picture across devices and deployments. Plaspy’s device detection and ingestion simplify bringing tracker data into the platform, and stored position data from the tracker helps maintain useful route history even when coverage is intermittent.
