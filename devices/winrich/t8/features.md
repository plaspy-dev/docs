# Winrich - T8 Features

This page provides a public feature overview for the Winrich T8 and explains how its capabilities are used with Plaspy for real time tracking, alerts, and basic monitoring workflows. It covers the device features that are relevant to Plaspy users and describes the type of telemetry the T8 supplies to the Plaspy platform.

Exact feature availability can vary by firmware version, hardware revision, installation method, or manufacturer implementation. The T8 is described as a compact pendant style personal tracker with GPS and LBS positioning, a rechargeable internal battery with USB charging, LED status indicators, and a dedicated SOS button for emergency alerts. Users should confirm device specifics where needed with manufacturer documentation.

## Feature Overview

The Winrich T8 is designed as a small wearable tracker that provides continuous location reporting and emergency alerting suitable for people, pets, and small portable assets. It pairs GPS positioning with cellular LBS fallback to improve location usefulness in marginal satellite reception, and it reports key events and status to Plaspy for live visibility and notifications.

- Compact pendant style design for wearing on a lanyard, collar, or keyring for continuous monitoring.
- GPS plus LBS positioning to maintain useful location updates in outdoor and weak signal environments.
- Dedicated SOS button that sends an emergency alert with location information to Plaspy configured contacts.
- Geofence support to generate automated entry and exit notifications for designated safe zones.
- Rechargeable internal battery with USB charging and LED indicators for power and connection status.

## Core Features of Winrich - T8

- Periodic GPS location reporting with cellular location fallback using LBS
- Dedicated SOS emergency alert button for immediate incident signaling
- Geofence trigger reporting for entry and exit notifications
- Battery status reporting and LED indicators for simple device health awareness
- Compact, wearable pendant form factor suitable for people, pets, and small assets
- Rechargeable internal battery with convenient USB charging

## How These Features Work with Plaspy

Plaspy ingests the T8 telemetry to provide live maps, alerts, and historical playback so administrators and caregivers can monitor location and respond to events. The T8 supplies the core event types Plaspy displays and uses to trigger notifications and workflows.

- Live location updates appear on Plaspy maps for continuous situational awareness
- SOS event reporting surfaces immediate alerts with the last known location for rapid response
- Geofence events are recorded and notified through Plaspy to automate boundary monitoring
- Battery and connectivity status are shown to help plan recharging and maintenance
- Historical tracks and event logs are available in Plaspy for review and reporting

## Typical Use Cases

- Personal safety and lone worker monitoring with immediate SOS alerting
- Elderly care supervision with geofence notifications for safety zones
- Child tracking for outings and school commutes using a lightweight wearable
- Pet location tracking when attached to a collar or harness
- Small asset protection for valuables carried or stored in transit
- Short term anti theft recovery workflows using geofences and SOS alerts
