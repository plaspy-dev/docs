# Enfora - Mini MT Features

This page provides a public feature summary for the Enfora Mini MT and explains how the device can be used with Plaspy for location monitoring, event visibility, and basic safety workflows. It covers the practical, user facing capabilities of the tracker as reported in manufacturer materials and how those capabilities are typically reflected when the device reports into Plaspy.

Exact feature availability and behavior depend on the specific hardware revision, firmware version, installation and configuration choices, and manufacturer implementation. Where useful, this page highlights practical considerations; for the latest device specific documentation and firmware notes consult the manufacturer resources.

## Feature Overview

The Enfora Mini MT is a compact, ruggedized GPS tracker designed for mobile workforce and personal safety use. It combines GPS positioning with quad band GSM GPRS communications, voice capability, and programmable emergency functions to support tracking and basic voice or messaging interactions in the field.

- Compact, ruggedized GPS tracker with strong GPS sensitivity for reliable position reports
- Quad band GSM GPRS communications for wide coverage and continuous reporting
- Two way voice communications and messaging capabilities for voice enabled applications
- Programmable panic or emergency response button to signal critical events
- Motion sensor with vibrating alerts to provide activity detection and tactile feedback
- FOTA enabled for remote firmware updates when supported by provisioning and carriers

## Core Features of Enfora - Mini MT

- Quad band GSM GPRS support to work across multiple cellular bands
- High sensitivity GPS performance for consistent location fixes
- Two way voice support and voice enabled design for direct communication
- Programmable panic or emergency response button for urgent alerts
- Motion sensor that can detect movement and trigger alerts or state changes
- Vibrating alerts suitable for personal notification needs
- Firmware Over The Air capability to support remote updates when available
- Compact and rugged enclosure designed for mobile and personal use

## How These Features Work with Plaspy

When an Enfora Mini MT is configured to report to Plaspy, its basic tracking and event capabilities become visible inside the Plaspy platform for monitoring and operational use. Plaspy receives location and event reports and presents them alongside device status for operational oversight.

- Real time location display and historical position history for route and movement review
- Event visibility for panic or emergency button presses so teams can respond quickly
- Motion based events or activity state updates visible as device events in Plaspy
- Connectivity and reporting status shown to help identify devices that are offline or out of coverage
- Message or voice related indicators can be noted in device metadata when the device reports such events
- Device metadata such as firmware version or model identifier may be visible if the tracker provides that information

## Typical Use Cases

- Personal and remote worker tracking for lone worker safety programs
- Emergency response and rapid location of users who activate the panic button
- Child and teen tracking for location awareness and family safety monitoring
- Elderly locator use for oversight of vulnerable individuals
- Mobile and home healthcare check ins and position awareness
- Small fleet or distributed workforce monitoring where compact devices are required

## Feature Availability Notes

- Feature set can vary by firmware version and manufacturer firmware configuration
- Hardware revisions or regional variants may alter supported cellular bands or available functions
- Some features such as FOTA depend on carrier support and provisioning in addition to device capability
- Installation and wiring choices can affect whether buttons and sensors operate as documented
- Check manufacturer documentation and release notes for the most current behavior and supported functions

## Why Use Plaspy with These Features

Using Plaspy with the Enfora Mini MT centralizes location and event data into a single monitoring platform that helps organizations maintain visibility over people and small vehicle fleets. The combination of location reporting, panic event detection, and motion sensing provides practical situational awareness for safety and operational monitoring programs.
