# Enfora - GSM 5108 Features

This page summarizes the public feature context for using the Enfora GSM 5108 with Plaspy. It highlights the practical capabilities you can expect to see in Plaspy when the GSM 5108 transmits GPS and device events to a centralized server. The content focuses on operational value and how those device functions map to typical fleet and asset tracking workflows inside Plaspy.

Exact feature availability for any specific GSM 5108 unit can vary by firmware revision, hardware variant or model configuration, installation wiring, and manufacturer implementation choices. For device specific technical limits, current firmware behavior, and exact configuration options consult Enfora documentation and the device release notes.

## Feature Overview

The Enfora GSM 5108 is part of the Spider MT family and provides integrated GSM GPRS communications for mobile tracking applications. It is designed to transmit GPS data and device events to centralized operations systems, web interfaces, local computers, or mobile data terminals. Below are the most relevant practical capabilities to consider when using the GSM 5108 with Plaspy.

- Reliable GSM GPRS connectivity for transmitting position and status data to central servers worldwide
- GPS data delivery to centralized operations centers, web pages, local computers, or mobile data terminals
- Support for Garmin Fleet Management Interface FMI for extended compatibility with certain telematics workflows
- Built in programmable rules engine and control automation for on device logic and event handling
- Geo fencing support and general purpose inputs and outputs for basic event and sensor integration
- Integrated SMS command and messaging support plus internal battery backup for continuity during power events

## Core Features of Enfora - GSM 5108

- GSM and GPRS connectivity as part of Enfora Spider MT family integrated platforms including dual and quad band variants
- Position reporting to centralized systems and web interfaces for tracking and monitoring
- Garmin FMI support for enhanced fleet management interoperability where applicable
- Built in programmable rules engine to automate device behavior based on inputs and conditions
- Network router and control automation capabilities to support flexible deployment models
- Geo fencing features for area based event detection and reporting
- General purpose inputs and outputs for signal and event integration with vehicle or asset wiring
- Integrated SMS for remote commands and messages along with internal battery backup and auto registration on power up

## How These Features Work with Plaspy

When the GSM 5108 is connected to Plaspy, its core functions translate into operational visibility, event detection, and data continuity. Plaspy automatically detects supported tracker protocols and accepts device connections to the central server, enabling you to use the device capabilities without custom protocol handling on your side.

- Live and historical position display in Plaspy maps and dashboards based on device GPS reports
- Geo fence events and programmable rule triggers appear as alerts or events in Plaspy for operational workflows
- GPIO triggered events and status changes are recorded as device events for monitoring and reporting
- Integrated SMS and on device automation can be coordinated with Plaspy workflows to manage remote commands and messaging as supported by the device
- Plaspy accepts connections from devices to the central server domain and supports common transport options so the GSM 5108 can report into Plaspy with minimal configuration
