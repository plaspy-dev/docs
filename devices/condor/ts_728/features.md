# Condor - TS-728 Features

This page summarizes the public feature context for using the Condor TS-728 with Plaspy. It focuses on the practical capabilities you can expect when the TS-728 is deployed for vessel monitoring and how those capabilities map to Plaspy's unified tracking, alerting, and reporting workflows.

Exact feature availability for any installed TS-728 can depend on factors such as firmware version, hardware revision, installation choices, and how the manufacturer configured the device. For specifics about interfaces, sensor options, and firmware behavior please consult the manufacturer documentation and your device supplier.

## Feature Overview

The TS-728 is a maritime satellite tracker designed to provide continuous global coverage for vessels operating beyond cellular range. When integrated with Plaspy, it enables centralized visibility of vessel location and telemetry, scalable fleet oversight, and event-driven monitoring for maritime operations.

- Global satellite connectivity via the Iridium network for tracking beyond coastal cellular coverage.
- Real-time location reporting to Plaspy for centralized mapping and situational awareness.
- Telemetry forwarding for engine, fuel, and other vessel sensor inputs when those sensors are installed.
- Anti-theft monitoring and event forwarding to support unauthorized movement alerts and recovery workflows.
- Scalable deployment suitable for single vessels or large maritime fleets managed from Plaspy.
- Support for forwarding compatible sensor data, including Bluetooth sensor integration where provided.

## Core Features of Condor - TS-728

- Iridium satellite connectivity for true global coverage and consistent reporting at sea.
- Plaspy compatibility so vessel positions and telemetry are available in the same platform as terrestrial trackers.
- Positioning and GNSS-based tracking to provide vessel location visibility in Plaspy.
- Telemetry collection capability for engine and fuel parameters when the installation includes sensor inputs.
- Anti-theft and movement detection workflows that can trigger alerts and operational responses in Plaspy.
- Support for forwarding sensor data, including Bluetooth sensor data in configurations where that capability is provided.
- Designed for continuous monitoring in remote maritime environments where terrestrial networks are unavailable.

## How These Features Work with Plaspy

Plaspy receives the TS-728 telemetry and location updates and makes that information available through maps, alerts, and reports so shore teams can monitor vessels and respond to events. Integration is focused on delivering actionable vessel visibility and consolidating satellite-tracked assets alongside cellular trackers in the same operational dashboards.

- Real-time vessel location and telemetry appear in Plaspy maps and live tracking views for continuous situational awareness.
- Events and alarms emitted by the TS-728 can be forwarded into Plaspy to generate notifications and escalation workflows.
- Where engine and fuel sensors are present, Plaspy can record and display telemetry for operational reporting and trend analysis.
- Plaspy can include satellite-tracked vessels in fleet reports, history logs, and position archives for compliance and operational review.
- Plaspy automatically detects compatible tracker protocols and consolidates satellite devices into standard monitoring views.

## Typical Use Cases

- Long-range fleet management for fishing fleets, cargo boats, and offshore service vessels operating beyond cellular coverage.
- Single-vessel tracking for yachts and leisure craft that require global location visibility.
- Anti-theft monitoring and recovery workflows for vessels that need movement detection and alerting.
- Remote telemetry collection for engine and fuel data to support maintenance planning and operational efficiency where sensors are installed.
- Cargo and hold condition monitoring when the tracker is configured to forward compatible sensor data.
- Regulatory reporting and voyage logging where position history across international waters is required.
