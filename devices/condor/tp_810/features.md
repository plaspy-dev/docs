# Condor - TP-810 Features

This page describes the public feature context for using the Condor TP-810 tracker with Plaspy. It highlights the practical capabilities you can expect to use inside Plaspy for person-focused monitoring, alerting, and incident visibility, and explains how the device is typically positioned for safety workflows.

Exact feature availability for any given TP-810 unit can vary by firmware revision, hardware revision, installation method, and the way Condor configures device features. Always confirm specific behaviors with the device firmware documentation and the manufacturer where needed.

## Feature Overview

The TP-810 is a compact, wearable GPS tracker positioned for personal safety monitoring and Plaspy compatibility. It is designed to be worn discreetly while providing location updates and a dedicated emergency workflow that integrates with Plaspy for rapid alerting and incident handling.

- Compact and lightweight wearable design suited to continuous wear by adults and children
- Fast location updates that supply position information to Plaspy for live monitoring
- Dedicated panic button that triggers an SOS workflow and immediate alerts in Plaspy
- Built-in emergency telephone call capability to reach assigned contacts from the device
- Purpose built for people monitoring rather than vehicle telemetry or fleet functions

## Core Features of Condor - TP-810

- Plaspy compatible integration for straightforward reporting into a centralized monitoring platform
- Compact wearable form factor for discreet continuous use
- Panic button for instant SOS signaling and alerting
- Emergency telephone call capability for direct contact with caregivers or emergency contacts
- Event-driven workflow that forwards critical incidents to Plaspy for response handling
- Designed for personal safety scenarios rather than vehicle focused telemetry

## How These Features Work with Plaspy

When the TP-810 is used with Plaspy, device events and location information feed into Plaspy’s dashboard and notification system so administrators and caregivers can maintain situational awareness and coordinate responses.

- Live position updates appear on the Plaspy map for tracking and oversight
- Panic button events are forwarded into Plaspy so alerts can be dispatched by configured notification rules
- Emergency call events can be recorded and logged in Plaspy as part of incident records
- Plaspy’s notification and geofencing features can be used with TP-810 events to trigger safe zone alerts and escalation workflows
- Administrators can manage response actions and view event histories for audit and follow up

## Typical Use Cases

- Senior care and dementia safety monitoring with rapid SOS signaling for vulnerable adults
- Child safety and parental monitoring for outings, school, and supervised activities
- Lone-worker protection where discreet personal panic signaling and location visibility are required
- Special needs monitoring where caregivers need a reliable personal safety device
- Short term event monitoring and volunteer oversight for temporary safety programs
- Centralized monitoring programs that require consistent incident logging and response coordination
