# Condor - GE-810 Features

This page provides a public, non-sensitive overview of the Condor GE-810 features and how the device can be used with the Plaspy platform for centralized monitoring and event visibility. It is intended to help operators, integrators, and program managers understand the practical capabilities of the GE-810 when paired with Plaspy, and what to expect in common deployments.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method, and manufacturer configuration. For device-specific technical details, firmware notes, and the latest specifications consult the manufacturer's official documentation.

## Feature Overview

The GE-810 is a Plaspy compatible wearable designed for controlled-supervision environments. It emphasizes reliable cellular communications, simple on-device notifications, and tamper awareness to support continuous oversight workflows.

- Plaspy compatible device for consolidated monitoring and centralized event reporting.
- 4G LTE cellular connectivity for reliable data and two-way voice transmission.
- Two-way voice calling to enable direct communication between the wearer and supervisors.
- Vibration alerts for discreet notifications and acknowledgement workflows.
- Tamper and removal detection that generates alerts when the shackle is manipulated.
- IP67 rated waterproof wearable form factor built for harsh or wet environments.

## Core Features of Condor - GE-810

- Plaspy compatibility for streamlined ingestion of device events and status updates.
- 4G LTE cellular link for event delivery and voice calls in coverage areas.
- Two-way voice capability for direct supervisor to wearer communication and logging.
- Vibration alert support for discreet on-person notifications and compliance prompts.
- Tamper and removal detection to surface potential compromise or interference events.
- Rugged IP67 waterproof enclosure suitable for outdoor and wet-condition use.
- Wearable shackle or bracelet form factor designed for supervised-release and secure monitoring.

## How These Features Work with Plaspy

When the GE-810 is deployed with Plaspy, device events and status updates are reported into the Plaspy platform so monitoring teams can see timely alerts and maintain audit trails. Plaspy presents these events alongside other telemetry to support operational decision making and response.

- Real-time alerting of tamper or removal events within Plaspy for rapid supervisor notification.
- Two-way voice event logs and call records integrated into monitoring workflows and incident history.
- Vibration alert events shown as discrete notifications for compliance checks and reminders.
- Correlation of GE-810 events with other telemetry or tracker feeds in Plaspy to build situational context.
- Audit and reporting tools in Plaspy reflect device state changes and event timelines for case management.

## Typical Use Cases

- Supervised-release and court-mandated programs requiring tamper detection and communications.
- Community corrections and secure supervision where lightweight wearable monitoring is needed.
- Welfare checks and vulnerable-person oversight that use vibration alerts and voice contact.
- Temporary custody and secure transport monitoring where a durable, waterproof wearable is useful.
- Programs that require centralized event visibility and audit trails for compliance reporting.
