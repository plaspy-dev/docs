# Condor - CM-311 Features

This page provides a public feature overview for the Condor CM-311 and how it is used with Plaspy. It summarizes the practical capabilities you can expect when integrating the CM-311 into the Plaspy platform for real-time pet location, route visualization, and routine monitoring without exposing sensitive implementation details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. Where helpful, this page notes those variables and encourages verification against the official Condor documentation for the most current device-specific details.

## Feature Overview

The Condor CM-311 is a compact, pet-focused GPS tracker designed to transmit location data over a cellular network and integrate with the Plaspy platform for straightforward real-time monitoring and playback. It emphasizes a small form factor and simple deployment so owners can monitor pets with minimal interference.

- Plaspy compatible device for live location and route history visualization.
- Cellular transmission of GPS location updates for reliable outdoors tracking.
- Compact, lightweight design intended to minimize discomfort for dogs and cats.
- Route playback and routine monitoring to review daily movement patterns.
- Notifications and missing-pet alerts available through Plaspy when configured.
- Quick attachment and setup for immediate use with Plaspy monitoring.

## Core Features of Condor - CM-311

- Designed for pet tracking with a compact and lightweight form factor.
- Transmits periodic GPS location updates over a cellular network.
- Real-time location visibility when paired with the Plaspy platform.
- Route history and playback for reviewing where a pet has traveled.
- Integration into Plaspy for notifications and missing-pet alerts.
- Simple setup and attachment for rapid deployment on pets.
- Platform telemetry and status reporting viewable within Plaspy.

## How These Features Work with Plaspy

When connected to Plaspy, the CM-311’s location updates become part of a unified monitoring platform that translates position data into usable views and alerts for owners and caretakers.

- Live position display on Plaspy maps for immediate location awareness.
- Route history and playback to analyze movements and habitual routes.
- Alerts and notifications configured in Plaspy for geofence breaches or missing-pet scenarios.
- Device status and basic telemetry presented in the Plaspy interface for operational oversight.
- Manage multiple devices and pets from a single Plaspy account for streamlined monitoring.

## Typical Use Cases

- Everyday pet monitoring to check live location and confirm safe activity.
- Lost pet recovery using rapid location updates and Plaspy alerts.
- Reviewing daily routes to understand where a pet spends time.
- Monitoring pets during temporary care, boarding, or veterinary visits.
- Tracking during walks and outdoor exploration to keep pets safe and found.
- Managing multiple pets or devices from a single Plaspy account.

Using the Condor CM-311 with Plaspy gives pet owners a simple path from a lightweight pet tracker to a mature monitoring platform.
