# Condor - TG-512 Features

This page provides a public feature overview for the Condor TG-512 GPS tracker when used with Plaspy. It summarizes the model's practical capabilities that are relevant to fleet managers and telematics integrators, and explains how TG-512 data is typically used inside Plaspy for location awareness, event monitoring, and telemetry collection.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and by how the device is installed and configured. For device specific technical limits, supported sensors, and the latest firmware behavior consult the manufacturer documentation and release notes.

## Feature Overview

The TG-512 is a compact vehicle and machinery tracker built around high sensitivity integrated GPS and GPRS antennas with flexible onboard interfaces. It is designed to provide continuous location reporting and to accept external sensors and inputs so that Plaspy can present location and event data in fleet workflows.

- Real time GPS location reporting over the cellular network for live tracking and historical playback
- Telemetry and event data inputs via RS 232 serial and 1 wire interfaces for compatible sensors and identification devices
- Multiple general purpose inputs and outputs to report vehicle events and to enable wired control actions when configured
- Microphone and speaker outputs to support two way voice or local audio monitoring where required
- Compact form factor intended for vehicle and machinery installations to simplify mounting and concealment

## Core Features of Condor - TG-512

- Integrated high sensitivity GPS receiver for consistent location fixes in vehicle environments
- GPRS cellular transmission for sending GPS and telemetry updates to a central platform
- RS 232 serial port for connectivity to external telematics modules and third party sensors
- 1 wire interface for compatible one wire sensors and identification devices
- Multiple general purpose inputs and outputs for event monitoring such as ignition or door status when wired accordingly
- Microphone and speaker outputs to enable driver communication or local audio monitoring
- Compact hardware design suited to vehicle and heavy equipment installations

## How These Features Work with Plaspy

When a TG-512 is connected to Plaspy, the device becomes a source of location and event data that Plaspy ingests and presents for operational oversight. Plaspy can display positions on maps, log historical movement, and surface events tied to the tracker inputs so teams can act on live information.

- Live position updates and historical playback shown in Plaspy map and reporting tools
- Input driven events reported to Plaspy for status monitoring such as ignition, doors, or alarms when wired to inputs
- Sensor telemetry from RS 232 and 1 wire connected devices available to Plaspy when compatible sensors are used
- Output driven control options such as remote immobilization workflows can be implemented from Plaspy when the device outputs are professionally installed and configured
- Audio channel events and communications can be associated with vehicle events and user workflows inside Plaspy

## Typical Use Cases

- Real time fleet tracking for route oversight, dispatch, and utilization analysis
- Anti theft monitoring and event driven immobilization where outputs are integrated with vehicle systems
- Heavy machinery and construction equipment tracking to reduce downtime and improve asset visibility
- Telemetry collection from external sensors via RS 232 or 1 wire for fuel and temperature monitoring when supported
- Driver communication and local audio monitoring tied to operational alerts and incident response
- Integration with third party telematics modules to extend telemetry and identification workflows

## Feature Availability Notes

- Feature set and supported sensors depend on the device firmware version and the specific hardware revision installed
- Some functions require professional wiring and secure installation to vehicle systems to ensure safe and reliable operation
- Regional hardware variants or carrier requirements can affect cellular network compatibility and available bands
- Integration with third party sensors over RS 232 or 1 wire requires compatible sensor models and correct configuration
- Consult Condor documentation for up to date lists of supported peripherals and firmware change logs

## Why Use Plaspy with These Features

Using the Condor TG-512 with Plaspy gives organizations a straightforward path to centralize location and event data from vehicles and equipment. The TG-512’s combination of GPS, cellular telemetry, serial interfaces, and general purpose I O makes it a flexible data source that Plaspy can display, alert on, and include in operational reports.
