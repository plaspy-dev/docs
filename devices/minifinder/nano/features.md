# MiniFinder - Nano Features

This page describes the public feature context for using the MiniFinder Nano with Plaspy. It summarizes the Nano's practical capabilities for location, alarms and telemetry, and explains how those capabilities are reflected when the device is connected to Plaspy for centralized monitoring and event management.

Exact feature availability and behavior depend on device firmware, hardware revision, installation type and the manufacturer's implementation choices. Where relevant this page notes variability and encourages verification against current manufacturer documentation.

## Feature Overview

The MiniFinder Nano is a compact wearable designed for personal safety and continuous location awareness. When used with Plaspy, Nano provides live location updates and safety events to a centralized platform so teams can monitor users, route alarms and review historical telemetry.

- Wearable form factor that supports wristband or lanyard use for discreet personal tracking.
- Hybrid positioning that combines outdoor GNSS with Wi Fi and BLE to improve location accuracy indoors and near buildings.
- Dedicated SOS panic alarm and automatic fall detection to create immediate alerts for caregivers or response teams.
- Two way voice support to give responders live context when an alarm occurs.
- BLE beacon and sensor support to extend indoor positioning and attach compatible sensors for additional monitoring scenarios.

## Core Features of MiniFinder - Nano

- Wearable GPS location reporting suitable for continuous personal tracking and short range asset monitoring.
- Hybrid positioning using GNSS together with Wi Fi and Bluetooth to improve fix reliability in mixed environments.
- SOS panic button for manual alarm activation and routing of urgent notifications.
- Automatic fall detection based on onboard motion sensing to trigger alerts without user input.
- Two way voice calling capability to enable direct communication between the wearer and responders.
- Bluetooth Low Energy support including beacon compatibility for enhanced indoor positioning and peripheral sensors.
- Embedded cellular connectivity via eSIM for broad geographic coverage and cloud reporting.
- Low power modes and configurable reporting intervals to balance battery life and update frequency.

## How These Features Work with Plaspy

When a MiniFinder Nano is configured to report into Plaspy, telemetry and alarms are delivered to the platform for visibility, rules processing and historical recording. Plaspy detects tracker protocols automatically and accepts device connections according to standard tracker configuration methods.

- Live location and status are displayed in Plaspy dashboards so operations teams can see current positions and recent movement.
- SOS and fall alarms appear as events in Plaspy and can trigger notification rules, escalation paths and assigned responder workflows.
- Voice call events are surfaced as contextual metadata so incident timelines show when two way calls occurred in relation to alarms.
- BLE and Wi Fi assisted fixes can improve indoor location accuracy in Plaspy maps when the device provides that data.
- Historical telemetry and event logs are stored in Plaspy for post event review and reporting on response performance.
- Plaspy indexing and search let teams filter Nano device history by user, event type or time window for audits and compliance.

## Typical Use Cases

- Eldercare monitoring where caregivers need location awareness, fall detection alerts and an SOS channel for seniors.
- Healthcare and facility staff protection using compact alarms and two way voice for rapid assistance.
- Lone worker safety for remote staff who need a lightweight wearable with panic and automatic alerting.
- Family safety use cases such as child monitoring during travel or activities using wearable form and SOS call features.
- Portable asset protection where a small wearable tracker is attached to high value portable equipment and monitored alongside personnel.
- Integration into mixed telematics deployments to add personal safety telemetry to broader operational oversight.

## Feature Availability Notes

- Feature sets such as fall detection sensitivity, alarm routing and reporting intervals can vary by firmware version and device settings.
- Hardware revisions and regional product variants may affect supported cellular bands, power profiles and sensor behavior.
- Installation context including placement, Wi Fi availability and BLE infrastructure will influence indoor positioning performance.
- Some advanced capabilities require corresponding configuration in both the device management portal and in Plaspy to appear as expected.
- Always consult the manufacturer release notes and configuration guides for the precise behavior of a given device and firmware revision.
