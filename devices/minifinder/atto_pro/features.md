# MiniFinder - Atto Pro Features

This page provides a public overview of the MiniFinder Atto Pro features and how the device integrates with Plaspy for real-time tracking and monitoring. It focuses on the practical capabilities you can expect to use inside Plaspy and highlights the functionality that helps with pet and livestock tracking, alerting, and historical review.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, regional variant and manufacturer configuration. For the most current and device specific technical details please consult the official MiniFinder documentation as noted below.

## Feature Overview

The Atto Pro is a compact, rugged wearable GPS tracker designed for animals and portable assets, and when paired with Plaspy it provides continuous position updates, motion-aware alerts and on-device logging to improve coverage in remote areas.

- Compact IP67 wearable form factor intended for collars and portable mounting
- Global cellular connectivity using LTE M1 NB2 and GSM for wide coverage
- Continuous GNSS positioning with high outdoor accuracy and fast fix performance
- Motion aware alerts and speed detection via a 3 axis accelerometer
- Local flash logging to buffer positions during cellular outages and sync later
- BLE 5.0 for short range sensor or beacon integrations and nearby device workflows

## Core Features of MiniFinder - Atto Pro

- Rugged IP67 enclosure and a small collar friendly form factor suitable for pets and livestock
- Global connectivity using LTE M1 NB2 plus GSM to report positions across many regions
- High accuracy GNSS positioning with outdoor accuracy typically in the meter range
- 3 axis accelerometer used for motion detection, motion based alerts and speed sensing
- Onboard flash memory for local position logging when cellular service is unavailable
- Bluetooth LE 5.0 for nearby sensor support and short range integrations
- Visible status indicators for GPS, cellular and power to aid installation and troubleshooting
- Rechargeable battery with manufacturer supplied runtime guidance for typical update intervals

## How These Features Work with Plaspy

When an Atto Pro is registered in Plaspy, its position and event data become available for live monitoring, alerts and history review. Plaspy ingests the device reports and exposes them through maps, notifications and reporting tools to support day to day operations.

- Real time location updates and position history visible in Plaspy maps and timelines
- Geofence breaches, motion alerts and speed events forwarded into Plaspy for notifications
- Buffered positions stored on the device upload to Plaspy after connectivity is restored, preserving track continuity
- BLE based sensor data and nearby device interactions can feed short range workflows when supported by device firmware
- Multi user access and shared alerting in Plaspy let teams or family members monitor the same device

## Typical Use Cases

- Lost pet recovery with live position updates and geofence alerts to help locate animals quickly
- Theft protection for horses and larger animals using motion alerts and historical tracks
- Monitoring free roaming livestock on large properties with local logging for low connectivity areas
- Tracking hunting dogs to keep teams informed of location and movement during outings
- Portable asset monitoring where a small weatherproof tracker with local logging is required

## Feature Availability Notes

- Feature names and behavior may vary by firmware version and device hardware revision
- Regional cellular band support and network availability affect real world coverage for LTE M1 NB2 and GSM
- Installation method and collar mounting can change motion detection sensitivity and GPS visibility
- BLE functionality and integrations depend on firmware and the presence of any companion sensors
- The Atto Pro is optimized for animal and portable asset tracking and does not list vehicle specific inputs such as ignition sensing or immobilizer control

## Why Use Plaspy with These Features

Using the MiniFinder Atto Pro with Plaspy provides a unified view of location, motion and historical tracks that is useful for teams and households responsible for animals or portable assets. Plaspy centralizes alerts, lets multiple users access shared devices, and preserves recorded positions for later review, which helps reduce data gaps and improves situational awareness.
