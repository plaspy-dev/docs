# Coban - BN-403C

![BN-403C](./tracker.png)

The BN-403C is a compact, vehicle-mounted GPS tracker engineered for concealed installation and continuous vehicle management. Plaspy compatible out of the box, this LTE \(4G\) tracker with 2G fallback delivers reliable real-time tracking and a suite of alarms and remote-control functions tailored for fleet management, private car anti-theft, rental/finance monitoring, and logistics operations. Its wired installation \(12V–24V\) plus a 3.7V 300mAh backup battery ensures position reporting even during power interruptions.

Designed for operators who need dependable telemetry, ignition monitoring, and remote immobilizer capabilities, the BN-403C integrates with Plaspy to provide live location, event alerts, and history playback through mobile and web platforms. Bluetooth configuration and automatic induction arming/disarming simplify deployment, while native support for TCP, UDP and SMS transports ensures flexible connectivity across network conditions.

## Key Highlights

- Plaspy compatible for easy integration into existing fleet management dashboards and apps.
- LTE \(4G\) with broad band support and 2G fallback for robust cellular coverage and real-time tracking.
- High-sensitivity GNSS receiver \(−165 dBm\) with typical GPS accuracy around 5 meters for precise positioning.
- 12V–24V direct vehicle power with a rechargeable 3.7V 300mAh backup battery to report during power loss.
- Comprehensive alarms: door-open, ACC/ignition, shock, overspeed, movement, geo-fence, SOS and low-battery alerts.
- Remote immobilizer and remote fuel/power cut options \(relay/relay accessory\) for enhanced anti-theft control.
- Bluetooth configuration and automatic induction arming/disarming; compatible with Bluetooth sensors for proximity-based workflows.
- Supports TCP, UDP and SMS for flexible telemetry delivery to Plaspy and other backend systems.

## How It Works with Plaspy

The BN-403C streams location and event data to Plaspy using TCP, UDP or SMS. Once connected, Plaspy ingests GNSS positions, telemetry and alarm events to power real-time tracking, notifications, and historical analysis. Device configuration and some functions can be managed locally via Bluetooth or centrally through Plaspy’s device management tools.

- Real-time location and telemetry updates delivered to Plaspy for live maps and fleet dashboards.
- Ignition \(ACC\), door-open and shock alarms reported as discrete events to trigger alerts or workflows.
- Optional fuel monitoring support \(requires a fuel sensor\) reported to Plaspy for fuel monitoring and theft detection.
- Remote immobilizer and remote fuel/power cut control via relay for anti-theft response from Plaspy.
- Bluetooth-based arming/disarming and support for Bluetooth sensors to automate state changes and proximity triggers.
