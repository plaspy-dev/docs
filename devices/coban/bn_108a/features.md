# Coban - BN-108A Features

This page provides a public feature overview for the Coban BN-108A and how its capabilities map to the Plaspy platform. It summarizes the practical functions you can expect when the BN-108A is used with Plaspy for fleet management, mobile asset oversight, and anti-theft monitoring while remaining at a high level suitable for public documentation.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional variant, and manufacturer configuration. For device specific instructions, commands, or the latest technical details, consult the official Coban documentation and firmware notes.

## Feature Overview

The BN-108A is a compact, Plaspy compatible GPS tracker designed for long standby deployment and flexible mounting. It emphasizes extended battery life, discreet attachment, automated arming via Bluetooth, and a suite of alarm types to support anti-theft and asset monitoring workflows.

- Extended 10,000 mAh rechargeable battery designed to reduce maintenance intervals and support long standby deployment.
- Strong magnetic adsorption for rapid, tool free mounting to vehicles, trailers, or portable assets.
- Bluetooth automatic induction used for simplified arming and disarming and proximity based workflows.
- Multiple alarm types including low battery, movement, shock, overspeed, and geofence for timely event reporting.
- Remote voice monitoring and basic remote control options via SMS or network links for on demand situational awareness.

## Core Features of Coban - BN-108A

- Real time location reporting and historical track playback when integrated with Plaspy.
- Large rechargeable battery for extended standby and reduced recharge frequency.
- Magnetic mounting for quick, covert installation without permanent fixtures.
- Bluetooth automatic induction to support proximity based arming and accessory detection.
- Multi type alarms covering low battery, movement, shock, overspeed, and geofence events.
- Remote voice monitoring for on demand ambient audio capture.
- Flexible reporting modes to balance reporting cadence and battery consumption.
- Connectivity options including TCP, UDP, and SMS for flexible server communication.

## How These Features Work with Plaspy

When the BN-108A is connected to Plaspy, the device streams position and event information into the platform where it becomes part of live monitoring, alerting, and historical reporting. Plaspy ingests location and alarm signals to give operators timely visibility and tools for operational follow up.

- Live location display and track playback for situational awareness and post event review.
- Alarm forwarding into Plaspy for instant notifications and dashboard visibility of low battery, movement, shock, overspeed, and geofence events.
- Reporting mode adjustments to help manage battery life while keeping the device visible in Plaspy.
- Remote voice monitoring indicators and event flags that support incident review workflows.
- Centralized event history and telemetry that can be correlated with other fleet data inside Plaspy.
