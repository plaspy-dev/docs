# Coban - BN-408B Features

This page provides a public, feature-focused overview of the Coban BN-408B and how its capabilities map into the Plaspy platform. It highlights practical functions and operational benefits users can expect when the BN-408B is deployed and reporting into Plaspy for real time tracking, alarm telemetry, and historical playback.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, installation method, and manufacturer implementation. Use this page for general planning and platform integration context, and consult manufacturer documentation for model specific technical details and the latest firmware behavior.

## Feature Overview

The BN-408B is a portable, magnet-mount GPS tracker designed for discreet, long standby monitoring of vehicles and assets. It is Plaspy compatible out of the box and reports position and alarm data over cellular networks, delivering continuous location visibility and event notifications for fleet and asset management.

- Real time GPS tracking across 2G 3G and 4G networks for live visibility and map display in Plaspy
- Very large rechargeable battery for extended standby and reduced maintenance intervals
- Magnet mount enclosure for quick, covert attachment without permanent installation
- Comprehensive alarm reporting including tamper, low battery, movement, shock, overspeed, blind area and geo-fence
- Model B variant adds SOS, external power disconnect alarm and remote immobilization for enhanced anti-theft response

## Core Features of Coban - BN-408B

- Portable magnet-mount form factor for covert asset attachment and easy relocation
- Long life 10,000 mAh rechargeable Li ion battery to support extended standby deployments
- Cellular reporting over common channels to transmit location and alarms to backend platforms
- GNSS position reporting suitable for real time tracking and historical route playback
- Wide alarm set including tamper infrared detection, low battery, movement, shock, overspeed, blind area and geo-fence notifications
- Model B specific features: SOS alarm, external power disconnection alarm, and remote immobilization capability
- Remote voice monitoring for situational assessment during incidents
- Remote configuration and reporting flexibility to support fleet scale deployments

## How These Features Work with Plaspy

When the BN-408B is paired with Plaspy, its location and alarm messages are translated into map markers, alerts, and historical events that operators can use for tracking, dispatch, and incident response.

- Live position updates appear on Plaspy maps and can be used for immediate dispatch or monitoring
- Route history and playback enable postincident review and compliance reporting
- Alarm messages such as tamper low battery and movement generate alerts and can feed automation rules in Plaspy
- Model B SOS and external power disconnection events provide high priority notifications for emergency workflows
- Remote immobilization and control features (where enabled) can be coordinated through Plaspy incident handling processes
- Remote voice monitoring events are recorded as incident data to aid verification and response

## Typical Use Cases

- Fleet anti theft monitoring and recovery workflows using SOS and remote immobilization on Model B units
- Long term logistics and equipment tracking where long battery life reduces maintenance visits
- High value asset protection for construction machinery generators and portable equipment with tamper and movement alarms
- Emergency response and incident verification using SOS and remote voice monitoring
- Covert monitoring for rental fleets mobile inventory and leased equipment requiring discreet attachment
- Route reconstruction and compliance checks using historical playback
