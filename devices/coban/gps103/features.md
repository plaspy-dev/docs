# Coban - GPS103 Features

This page provides a public feature overview for the Coban GPS103 and explains how its documented capabilities relate to using the device with Plaspy. It summarizes user-facing functions described by the manufacturer and highlights the practical ways those features can appear inside Plaspy for monitoring and operational use.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and regional manufacturer implementation. Use this page for general guidance on capabilities and how they map to Plaspy workflows, and consult the device manufacturer for the most current technical specifics.

## Feature Overview

The Coban GPS103 is designed for vehicle tracking and monitoring, combining GPS positioning with cellular data and SMS communication to support real-time visibility, alarms, and recorded location history. The tracker’s features are oriented around location accuracy, event reporting, and remote control capabilities that are useful for fleet and security applications.

- Accurate vehicle positioning suitable for on-road tracking and route visualization
- Multiple communication methods including SMS, GPRS, and internet data transmission for real-time updates
- Real-time tracking and remote monitoring through PC or mobile client software, including Google Earth view options
- GPS drift suppression and location based service features to improve positional consistency
- Data logging and upload capabilities for historical route playback and review
- Multiple alarm types and remote control functions including SOS, geo-fence alerts, movement alerts, and remote cut off of oil and power

## Core Features of Coban - GPS103

- Accurate GPS positioning for vehicle location reporting and route tracing
- Support for SMS, GPRS, and internet data transmission for flexible reporting
- Real-time monitoring via PC or mobile clients with optional Google Earth overlay
- GPS drift suppression and location based services for improved tracking consistency
- Onboard data logging and data upload for playback and historical analysis
- Multiple alarm and notification types such as SOS, geo-fence breach, movement alerts, low battery, and power removal
- Remote control capabilities including arm/disarm and remote cut off of oil and power systems
- Ability to switch communication modes and configure the device via USB or supported configuration options

## How These Features Work with Plaspy

When a GPS103 is used with Plaspy, the tracker’s location and event reports are presented in Plaspy’s monitoring and reporting interface to support operational oversight and incident handling. Plaspy surfaces device-reported data and events so teams can act on live and historical information.

- Real-time vehicle location displayed on maps for live monitoring and dispatch
- Alarm and event reporting shown as alerts or timeline events within Plaspy for quick review
- Historical route playback and stored data shown in reports to support post-incident analysis
- Device status and connectivity indicators to help maintain operational visibility
- Where available and configured, Plaspy can relay configuration or control commands for supported remote functions such as arm/disarm or remote cut-off
- Logged data from the device can be used to generate activity summaries and exportable reports
