# Coban - BN-403D Features

This page provides a public feature overview of the Coban BN-403D and how its capabilities integrate with Plaspy for vehicle tracking and operational monitoring. It focuses on practical, non-sensitive information about the tracker that is relevant when used with the Plaspy platform.

Exact feature availability can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device-specific limits, configuration commands, or the latest firmware behavior consult the official Coban documentation and release notes.

## Feature Overview

The BN-403D is a compact vehicle tracker designed to deliver continuous location reporting, alarms, and configurable telemetry useful for fleet managers, vehicle owners, and telematics projects. It combines wide area cellular connectivity, in-vehicle power integration, backup battery support, and configuration options to support concealed installations and robust reporting.

- Real-time GPS tracking with route playback for situational awareness and historical review.
- Multiple alarm types for theft and operational monitoring including ignition, door, shock, overspeed, geofence, SOS and power loss.
- Bluetooth configuration and automatic induction arming and disarming to simplify installation and commissioning.
- One-way remote voice listening plus relay based remote power cut for emergency and control scenarios.
- Optional fuel monitoring support when paired with a compatible fuel sensor for fuel level queries and fuel loss alerts.

## Core Features of Coban - BN-403D

- LTE 4G with 2G fallback for broad cellular coverage and continuous reporting.
- Real-time location reporting and track playback for monitoring vehicle movement.
- Configurable alarms including ACC ignition, door open, shock/vibration, overspeed, geo-fence events, SOS, and low battery or external power loss.
- Bluetooth configuration and automatic induction arming/disarming for on‑vehicle setup and accessory pairing.
- One-way remote voice listening to assist during emergency events.
- Relay output and remote power cut control for managed vehicle shutdown where supported.
- Optional fuel monitoring capability when connected to an approved external fuel sensor.

## How These Features Work with Plaspy

When the BN-403D is connected to Plaspy, its location fixes, status updates and alarm events are reported into the Plaspy platform so operators can monitor vehicles, receive alerts, and review historical activity. Plaspy detects compatible protocols and presents alarms and tracks in dashboards and playback tools to support operational decision making.

- Live location and telemetry appear in Plaspy dashboards for real-time fleet visibility and route review.
- Alarm events such as ignition, door open, shock, geo-fence and SOS are forwarded to Plaspy for alerting and incident tracking.
- Track playback and history enable post incident analysis and route reconstruction inside Plaspy.
- Remote commands and configuration changes can be managed through Plaspy where the device and firmware support remote configuration.
- Optional sensor data such as fuel queries and fuel detection alarms are reflected in Plaspy when the tracker is paired with supported external sensors.

## Typical Use Cases

- Private vehicle anti-theft protection using concealed installation, door/ignition/shock alarms and remote power cut.
- Fleet route monitoring and operations oversight with live tracking and historical playback.
- Insurance telematics and incident analysis using alarm records and telemetry history.
- Public or commercial transport monitoring where one-way voice listening and alarms improve incident response.
- Fuel monitoring and loss prevention in mixed fleets when the optional fuel sensor is used.
