# Coban - BN-401C Features

This page provides a public feature overview for the Coban BN-401C and how its capabilities are commonly used with Plaspy. It focuses on user facing functions, operational behavior, and the practical value the device delivers when integrated into Plaspy for real time tracking, alerts, and basic remote control.

Exact feature availability can vary by device firmware, hardware revision, installation method, regional variant, and manufacturer implementation. For device specific configuration details and the latest technical specifications consult the manufacturer documentation and release notes from Coban.

## Feature Overview

The BN-401C is a compact tracker designed for concealed installation on motorcycles and small vehicles with a focus on reliable position reporting, essential alarm coverage, and simple remote control through a platform such as Plaspy.

- Real time GNSS location reporting with support for continuous tracking and route playback in Plaspy.
- Multi network communications with 2G and 4G support and flexible reporting via TCP UDP or SMS for resilient server integration.
- Onboard rechargeable backup battery to send emergency alarms and limited offline reports when vehicle power is interrupted.
- Built in alarm and notification support including geo fence, overspeed, SOS, movement or shock, low battery, external power disconnect, and ignition ACC notifications.
- Compact concealed form factor and included relay wiring harness option for remote fuel or power cutoff and easier installation on motorcycles.

## Core Features of Coban - BN-401C

- Plaspy compatible GNSS tracking for live location and historical playback.
- Multi network connectivity over GSM GPRS and LTE with TCP UDP and SMS reporting options.
- Internal 3.7V 90mAh backup battery for emergency reporting and brief offline operation.
- Compact concealed housing sized for motorcycles scooters and small vehicles.
- Relay and wiring harness support to enable remote fuel or power cutoff when needed.
- Comprehensive alarm set including geo fence overspeed SOS movement shock low battery and external power disconnect.
- Ignition ACC detection to report engine on off state to Plaspy.
- Smart power or sleep behavior to conserve data and battery while stationary and wake on movement or configured triggers.

## How These Features Work with Plaspy

When connected to Plaspy the BN-401C delivers position and event messages that the platform uses to provide visibility, alerting, and reporting. Plaspy maps device messages into location histories, event timelines, and configurable alerts for operations teams.

- Live position updates appear on Plaspy maps and support route playback for trip review.
- Alarm events such as geo fence breaches overspeed and SOS generate configurable Plaspy notifications and escalation rules.
- Ignition ACC events are translated into engine on off status so administrators can track usage patterns and runtime.
- Low battery and external power disconnect events surface in Plaspy so maintenance or tamper investigation can be scheduled.
- Remote control actions such as relay based fuel or power cutoff can be reflected in Plaspy workflows and command logs where supported.

## Typical Use Cases

- Motorcycle fleet management monitoring routes, ignition events, and alarm incidents for operational oversight.
- Individual motorcycle anti theft protection using discreet installation, SOS alerts, and remote cutoff capability.
- Scooter sharing and mobility services requiring compact trackers for location reporting and tamper detection.
- Small vehicle monitoring when a low profile tracker is preferred for discreet installations.
- Remote immobilization workflows that combine alarm events and relay control for theft response.
