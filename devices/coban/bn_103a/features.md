# Coban - BN-103A Features

This page provides a public overview of the Coban BN-103A features relevant to use with Plaspy. It focuses on the device capabilities that matter to fleet operators, rental supervisors, and security teams when the tracker is integrated into Plaspy for live tracking, event reporting, and operational monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method, and how the manufacturer configures device options. For precise device specifications and the latest firmware behavior consult the manufacturer documentation and detail the installation choices made for your vehicles.

## Feature Overview

The BN-103A is a vehicle mounted tracker designed to deliver dependable location fixes and vehicle event data into a platform like Plaspy. It combines high sensitivity GNSS positioning with multi band GSM connectivity and configurable inputs so operators receive timely location updates, status events, and alarms that support live monitoring and playback.

- High sensitivity GNSS positioning with typical meter level accuracy for dependable location reporting.
- Multi band GSM GPRS connectivity supporting TCP UDP and SMS transport for flexible reporting.
- Configurable alarm inputs and event reporting including ignition and door status for operational visibility.
- Smart reporting modes and sleep behavior to balance timely updates with vehicle power management.
- Remote control and alarm functions including remote immobilization and voice monitor where supported.
- Built in backup battery and external antenna support to improve installation resilience.

## Core Features of Coban - BN-103A

- Plaspy compatible for integration with real time tracking and fleet management workflows.
- High sensitivity GNSS receiver to provide accurate position fixes for live display and playback.
- 2G GSM GPRS multi band support with TCP UDP and SMS transport options for device reporting.
- Configurable alarm inputs reporting events such as ignition status and door open events.
- Remote immobilization capability via remote fuel or power cut off where enabled by installation.
- Remote voice monitoring listen in feature for authorized remote audio monitoring where available.
- Smart reporting modes including motion and stationary reporting and power management features.
- Built in backup battery and support for external GPS and GSM antennas to improve reliability.

## How These Features Work with Plaspy

When the BN-103A is connected to Plaspy, the device reports position and event data so dispatchers and managers can view live locations, review playback, and receive alerts. Plaspy ingests reported telemetry and alarms to produce dashboards, notifications, and historical reports that match operational needs.

- Live location updates and position history are displayed in Plaspy for real time monitoring and route playback.
- Alarm and input events such as ignition and door status feed into Plaspy notifications and event timelines.
- Geo fence and rule based alerts in Plaspy can be triggered from the tracker’s configurable alarm inputs.
- Remote commands issued from Plaspy can be used to invoke supported immobilization or remote monitor functions when the device and installation allow.
- Optional sensor aggregation such as BLE gateway inputs can be combined in Plaspy with BN-103A telemetry if present at installation.

## Typical Use Cases

- Fleet anti theft and immobilization workflows using live tracking and remote cut off capabilities.
- Logistics and transport monitoring with overspeed and event playback to improve route compliance.
- Rental vehicle supervision to track ACC events, geofence breaches, and location history for recovery.
- Equipment and municipal vehicle oversight to centralize alarms and operational telemetry.
- Fuel monitoring and loss control when external fuel sensors are connected and supported by the installation.

## Feature Availability Notes

- Feature sets such as remote immobilization, voice monitor, and fuel sensor support may require specific hardware options or accessory wiring during installation.
- Firmware versions can enable, limit, or change how particular alarms and reporting modes behave; check device firmware notes for exact behavior.
- Regional or carrier variants affect cellular band support and network behavior; confirm compatibility for your region.
- Some integrations such as Bluetooth sensor aggregation rely on additional gateways or accessories and are not intrinsic to all BN-103A installations.
- Manufacturer configuration and installer choices determine which inputs and alarms are active after deployment.
