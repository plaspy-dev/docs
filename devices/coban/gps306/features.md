# Coban - GPS306 Features

This page provides a public feature overview for the Coban GPS306 and explains how its capabilities map to monitoring and operational workflows in Plaspy. It focuses on practical, non sensitive feature descriptions relevant to deciding whether the GPS306 meets your location tracking and alerting needs when used with Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. The descriptions on this page are based on the model description for the GPS306 and are intended as general guidance rather than an exhaustive specification.

## Feature Overview

The Coban GPS306 is a compact GPS tracker designed to locate and monitor remote targets using GPS satellite positioning together with GSM GPRS connectivity. It supports real time updates and a set of configurable alarms that make it suitable for a range of tracking scenarios.

- Real time location updates delivered via SMS or internet for immediate visibility
- GPS satellite based positioning for continuous location awareness
- GSM GPRS multi band support for broad regional coverage
- Geo fencing to define areas and receive entry or exit alerts
- Over speed and movement alarms to detect rapid movement or unauthorized motion
- Compact design for straightforward installation and on device low battery alerting

## Core Features of Coban - GPS306

- GPS satellite positioning for reporting latitude and longitude
- GSM GPRS connectivity for sending location and alarm messages
- Multi band support covering 850 900 1800 1900 MHz for broad regional use
- Real time location updates via SMS or internet delivery
- Geo fencing capability to trigger area based alerts
- Over speed alarm to notify when a configured speed threshold is exceeded
- Movement alarm to detect unexpected motion of the tracked asset
- Low battery alarm to indicate when device power requires attention

## How These Features Work with Plaspy

Plaspy can receive and display the GPS306 tracking and alarm data so teams can monitor assets and events from a central interface. The platform translates incoming location and alarm messages into map positions, timeline events, and configurable notifications.

- Live location points appear on the Plaspy map for active monitoring
- Geo fence events are shown as entry and exit alerts so operators can act on boundary breaches
- Over speed and movement alarms become event notifications for fleet safety and incident review
- Low battery alerts are reflected in device status so maintenance can be scheduled
- Historical position data from the tracker can be reviewed for route and activity analysis

## Typical Use Cases

- Vehicle location and route monitoring for small fleets and service vehicles
- Personal tracking for safety check in scenarios where SMS or GPRS updates are preferred
- Asset tracking of movable equipment that benefits from compact, discreet installation
- Geo fence based zone monitoring for site access control and perimeter oversight
- Overspeed detection for driver coaching and operational safety monitoring
- Movement detection to alert teams when an asset begins unexpected motion

## Feature Availability Notes

- Network delivery options such as SMS versus internet reporting depend on SIM plan and local GSM coverage
- Hardware revisions and regional variants of the GPS306 may alter supported frequency bands or feature sets
- Installation wiring and power choices can affect features such as low battery reporting and continuous connectivity
- For precise command syntax, supported settings, and the latest firmware details consult the official manufacturer documentation
