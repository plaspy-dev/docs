# Coban - GPS310 Features

This page provides a public overview of the Coban GPS310 feature set and how those capabilities can be used with Plaspy for location monitoring and fleet or asset oversight. It focuses on non sensitive, practical information about what the device can do and how Plaspy surfaces that information for users who want location awareness, alerts, and historical tracking.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. The descriptions below use the provided device information as a baseline; for device specific or firmware level details consult the manufacturer documentation and release notes.

## Feature Overview

The Coban GPS310 is a compact GPS tracker designed for discreet portable tracking and basic telemetry reporting over GSM GPRS networks. It combines satellite positioning with cellular reporting to enable remote location queries and alerting for a range of monitoring needs.

- Accurate location reporting using GPS satellites for point locations and movement tracing.
- GSM GPRS connectivity for remote monitoring via text or data reporting to monitoring platforms.
- Compact, portable form factor suitable for concealment and use on luggage, personal items, or vehicles.
- Long standby and schedule mode runtimes to support extended deployments between charges.
- Built in alert functions such as low battery notification, SOS alerts, and geo fencing support.
- Basic event and time logging features for retrospective review of tracked movements and incidents.

## Core Features of Coban - GPS310

- Satellite based position reporting for location tracking and history.
- GSM GPRS network operation for remote reporting and queries.
- Compact dimensions and portable design for discreet placement and easy concealment.
- Extended standby time and schedule mode to reduce recharge frequency.
- Low battery alerts to notify when device power is running low.
- Geo fencing capability to define areas and receive related alerts.
- SOS alert support for manual emergency signaling.
- Time stamped records and event logging to assist with incident review and claims evidence.

## How These Features Work with Plaspy

Plaspy can accept and interpret position and event reports from compatible Coban devices so that locations, alerts, and historical records are visible in the Plaspy platform. Plaspy automatically detects supported tracker protocols and maps incoming messages to the platform display and alerting systems.

- Device locations and movement history appear on the Plaspy map for live monitoring and retrospective playback.
- Battery status and low battery alerts are shown in device telemetry so operators can schedule maintenance.
- Geo fence events and SOS alerts reported by the device become actionable notifications within Plaspy.
- Time stamped records sent by the tracker are stored and searchable in Plaspy for compliance and reporting.
- Plaspy supports standard TCP or UDP reporting configurations used by common GPS trackers and will automatically detect the protocol when the device is pointed at the Plaspy server.

## Typical Use Cases

- Vehicle anti theft monitoring and discreet recovery tracking.
- Tracking of high value luggage or cargo for transit condition and loss claims.
- Monitoring children, elderly, or vulnerable individuals during outings.
- Personnel location oversight for security or lone worker check ins.
- Short term covert tracking for investigations where discreet form factor is required.
- Scheduled location checks for assets that only need periodic reporting to conserve power.

## Feature Availability Notes

- Firmware differences can enable or disable specific alerts or logging behaviors; check the device firmware version when evaluating capabilities.
- Hardware revisions or regional variants may alter radio bands, battery capacity, or available features.
- Installation type and mounting location can affect GPS reception and battery life in practical use.
