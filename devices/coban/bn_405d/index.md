# Coban - BN-405D

![BN-405D](./tracker.png)

The BN-405D is a compact, vehicle-mounted GPS tracker designed for professional fleet management, logistics, construction and public vehicle applications. Plaspy compatible and built for reliable real-time tracking, the BN-405D combines multi-band 4G/3G/2G cellular connectivity with a high-sensitivity GNSS receiver to deliver accurate position, telemetry and alarm reporting across mixed network environments.

Engineered for embedded installation in 12–24V vehicles, the BN-405D provides a comprehensive telematics feature set — from ignition and ACC notifications to remote fuel/power cut and SOS emergency alarms — making it an ideal choice for anti-theft, telemetry-driven fleet optimization and automated vehicle security when integrated with Plaspy.

## Key Highlights

- Plaspy compatible: integrates via TCP/UDP or SMS for fast setup with Plaspy server infrastructure and real-time tracking dashboards.
- Multi-band cellular connectivity \(4G/3G/2G\) for stable coverage and seamless roaming across networks.
- High-precision GNSS with ~5 m typical accuracy and sensitivity to −165 dBm for dependable location reporting.
- Full alarm suite: overspeed, geo-fence, shock, door open, movement, low battery and external power disconnect for strong anti-theft protection.
- Remote control features: fuel/power cut \(remote immobilizer via relay\), arming/disarming, and remote listening for security response.
- Flexible telemetry and sensor support: optional fuel level, temperature & humidity sensors and up to eight Wi‑Fi cameras for photo/video evidence.
- Vehicle-grade design: embedded mount, compact form factor, backup battery for tamper alerts and wide operating temperature range.

## How It Works with Plaspy

Integrating the BN-405D with Plaspy delivers continuous, actionable location and vehicle telemetry to your Plaspy dashboard. The device reports position, status and alarms over TCP/UDP or SMS so Plaspy can display live location, playback historical tracks and trigger automated alerts and workflows for fleet management and anti-theft response.

- Real-time location and telemetry updates sent to Plaspy using TCP, UDP or SMS transport protocols.
- Ignition/ACC notifications and door/open/shock events enable Plaspy to correlate driving behavior and security events.
- Fuel monitoring \(optional\) integrates fuel level data into Plaspy for fuel management and theft detection when an external fuel sensor is attached.
- Remote immobilizer and power/fuel cut via relay enable Plaspy-initiated vehicle shutdown for theft prevention and risk control.
- Bluetooth automatic induction supports arming/disarming flows and can be used with Bluetooth sensors to extend Plaspy-triggered automation.
- Remote listening, SOS and photo/video \(with optional Wi‑Fi camera\) provide evidence capture and emergency response capabilities in Plaspy.

## Technical Overview

| Connectivity | GSM/GPRS/WCDMA/LTE \(4G\) with TCP/UDP/SMS transport |
| --- | --- |
| Bands | 4G: B1/B2/B3/B4/B5/B7/B8/B28A/B28B/B40; 3G: B1/B2/B3/B5/B8; 2G: 850/900/1800/1900 MHz |
| Power & Battery | Vehicle power 12–24V; rechargeable 3.7 V, 90 mAh backup battery for short-term operation and tamper alerts |
| Interfaces | Multiple hardware interfaces for external sensors, relays, external microphone, extension cable with SOS and remote control; supports optional Wi‑Fi cameras and fuel/temperature sensors |
| GNSS | High-precision GNSS receiver; sensitivity −165 dBm; typical accuracy ~5 m; cold start ~45 s, warm start ~35 s, hot start ~1 s |
| Bluetooth | Bluetooth automatic induction for arming/disarming and proximity-based workflows |
| Remote Management | Remote parameter configuration and firmware updates via TCP/UDP; SMS command configuration supported |
| Form Factor | Compact vehicle-mounted terminal, 96 × 54 × 19 mm, ~70 g; designed for hidden/embedded installation |

## Use Cases

- Fleet management: live vehicle tracking, route playback and telemetry for dispatch optimization and driver monitoring.
- Anti-theft and immobilization: instant alarms, remote fuel/power cut and relay-controlled immobilizer to protect high-value vehicles.
- Public transport and passenger vehicles: ACC and door event monitoring, SOS alarm and remote listening for safety and incident response.
- Fuel and asset control: optional fuel level sensors and telemetry reporting for fuel monitoring and theft detection.
- Construction and off-road fleets: rugged vehicle monitoring, location history and alarm-driven wake-up strategies for intermittent operation.

The BN-405D delivers a balanced mix of connectivity, sensors and remote-control features that make it a strong option for organizations deploying Plaspy across mixed fleets. Its multi-band 4G/3G/2G support ensures robust coverage, while the high-sensitivity GNSS provides precise position fixes for effective real-time tracking and track playback. Integration is straightforward: the BN-405D supports TCP/UDP/SMS protocols and remote configuration, enabling quick onboarding to Plaspy servers and centralized fleet dashboards. For companies that need vehicle-grade reliability, rich telemetry and a compact embedded form factor, the BN-405D paired with Plaspy provides a scalable, secure solution for fleet management, anti-theft protection and operational telemetry.
