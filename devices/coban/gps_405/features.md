# Coban - GPS-405 Features

This page provides a public feature overview for the Coban GPS-405 and how its capabilities are commonly used with Plaspy. It focuses on user facing functions and operational value rather than low level protocol details, and is intended to help fleet managers, installers, and technical evaluators understand what the tracker can report and control when integrated with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation method, and manufacturer implementation choices. For device specific configuration, behavior under different network conditions, and accessory compatibility consult the manufacturer documentation and release notes for the specific unit you have.

## Feature Overview

The GPS-405 is a vehicle tracker designed for real time vehicle management across logistics, cash transport, official fleet, and anti theft scenarios. Its feature set combines location reporting, event and alarm detection, optional sensor inputs, and remote control functions that together support operational monitoring and response.

- Real time GPS tracking with reported position and location updates
- Geo fencing and overspeed alerting for route and safety monitoring
- Movement, shock, door, and ACC detection for event driven alerts
- Remote engine oil and power cut off control for immobilization workflows
- SOS button and emergency alert functionality for rapid assistance
- Optional Wi Fi hotspot, temperature and humidity detection, and Wi Fi camera on supported variants

## Core Features of Coban - GPS-405

- Real time GPS position reporting and GPS plus LBS tracking for broader coverage
- Geo fence create and alert support for arrival or boundary breach notifications
- Overspeed alarm and movement alarm to detect driving behavior and unauthorized motion
- ACC on off monitoring and door status detection for ignition and access awareness
- Shock detection and blind area alarm for impact and coverage loss notifications
- Remote cut off of engine oil and power resume where supported by the installed unit
- SOS emergency button for immediate alerting
- Network compatibility across multiple cellular generations and IP66 environmental protection

## How These Features Work with Plaspy

When a GPS-405 is connected to Plaspy, its reported locations, alarms, and status updates are presented in Plaspy interfaces for live monitoring and historical review. Plaspy is designed to integrate common tracker events into dashboards and alerts so operations teams can act on the information.

- Location updates appear on Plaspy maps for live tracking and route playback
- Geo fence and overspeed events generate alerts and can be routed to notification channels
- Movement, shock, ACC, and door events are shown as status changes and logged in event history
- Remote immobilization and resume actions are visible as control events when the device supports those functions
- Plaspy automatically detects common tracker protocols to simplify device onboarding and reporting

## Typical Use Cases

- Fleet logistics monitoring for vehicle location and route compliance
- Cash in transit and secure transport with remote immobilization options
- Corporate and government vehicle management with status and usage oversight
- Anti theft monitoring with SOS and movement detection for rapid response
- Multi modal operations where GPS plus network based location improves coverage
- Condition monitoring on vehicles equipped with optional temperature or camera accessories

## Feature Availability Notes

- Some functions such as Wi Fi hotspot, camera, temperature and humidity sensing, or oil detection are optional and available only on specific hardware variants or accessory packages
- Firmware versions may add, change, or refine behavior for alarms, reporting intervals, and control commands
- Installation choices determine which inputs are available to the tracker for ACC, door detection, and remote cut off control
- Regional cellular banding and model variants affect network compatibility and available connectivity modes
- Always verify the capabilities of the specific unit and firmware build before relying on a particular feature for operational safety or compliance
