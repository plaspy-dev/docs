# Coban - BN-103B Features

This page provides a public feature overview of the Coban BN-103B GPS tracker and how it can be used with Plaspy for real time tracking, event monitoring and fleet management. It summarizes the tracker capabilities relevant to Plaspy integration while keeping the focus on user facing functions such as location reporting, alarm support and remote control options.

Exact feature availability for any individual BN-103B device can vary by firmware version, hardware revision, installation method and the way the manufacturer has implemented functions. For precise device behavior, configuration commands and accessory compatibility consult the official manufacturer documentation and the device user manual.

## Feature Overview

The BN-103B is designed as a vehicle mounted tracker for professional fleet and security use. It supports standard reporting methods and a broad alarm set that together deliver continuous situational awareness and straightforward integration into platform dashboards like Plaspy.

- Real time GNSS location reporting with high sensitivity and typical meter level accuracy for dependable position updates.
- Multiple reporting transports including TCP, UDP and SMS to suit different connectivity needs and platform ingestion methods.
- Comprehensive alarm support including SOS, door open, shock, overspeed, low battery and external power disconnection to surface important events.
- Wired vehicle installation with a rechargeable backup battery to preserve availability during power loss.
- Smart reporting modes that balance frequent updates with power conservation and event driven wake behavior.

## Core Features of Coban - BN-103B

- High sensitivity GNSS positioning with typical accuracy around 5 meters for reliable location data.
- Multiple data transport options including TCP, UDP and SMS for compatibility with telemetry platforms.
- Vehicle wired power input for 12 to 24 volt installations plus a rechargeable 3.7V backup battery to maintain tracking on power loss.
- Rich alarm and digital input set including SOS, door, shock, overspeed, ACC or ignition state, low battery and power disconnection.
- Relay output for fuel or power cutoff enabling immobilization style anti theft control when used with appropriate wiring and accessories.
- Remote voice listening and support for an external microphone for incident verification and monitoring where permitted.
- External GPS and GSM antenna ports to improve reception in vehicle installations and specialized mounting locations.
- Smart reporting modes and alarm persistence so critical events remain visible until acknowledged.

## How These Features Work with Plaspy

When a BN-103B is connected to Plaspy, the device feeds position and event data into the platform so operators can see location, status and alarms in one place. Plaspy ingests the device messages and displays them in maps, lists and alerting workflows to support operational decisions and security responses.

- Real time location updates appear on Plaspy maps with associated telemetry such as speed and heading where reported.
- Alarm events like SOS, door open, shock and power loss are surfaced as alerts and can be tracked until cleared in the platform.
- Ignition or ACC state changes allow trip analysis and engine on off reporting inside Plaspy for better operational reporting.
- Relay based immobilizer actions and remote control functions can be represented as actionable states in Plaspy when remote commands are supported by the device and installation.
- Optional sensor telemetry such as external fuel sensor readings map into Plaspy dashboards when the accessory is installed and reporting.
- Smart online and sleep behaviors from the device are reflected as connectivity and availability status so operators can understand when a unit is sleeping versus offline.

## Typical Use Cases

- Fleet tracking and route visibility for logistics operators needing real time vehicle locations and trip summaries.
- Anti theft and asset protection using alarm persistence, remote immobilization and event logging to aid recovery and response.
- Rental and managed vehicle programs that require ignition monitoring, remote status checks and usage oversight.
- Public service and field engineering fleets that benefit from external antennas and robust installation options for reliable coverage.
- Fuel monitoring and loss detection when an optional fuel sensor is deployed together with relay control for intervention.
- Situational verification and incident investigation using remote listening and event timestamps.

## Feature Availability Notes

- Feature availability may depend on the device firmware version and the configuration applied by the installer or fleet operator.
- Some functions require specific accessories or wiring such as external antennas, fuel sensors, relays or an external microphone to be present and correctly installed.
- Regional cellular support and the presence of SMS or data transport options can vary by market and hardware variant.
- Remote control and immobilizer actions require correct wiring and compliance with local regulations for vehicle safety and anti theft interventions.
- Always verify which features are enabled on a given unit and whether manufacturer firmware updates add or change behavior.
