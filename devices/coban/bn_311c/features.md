# Coban - BN-311C Features

This page provides a public, practical overview of the Coban BN-311C features and how those features are used with Plaspy for real time tracking, alarms, and basic fleet management. It is focused on user facing capabilities and how the device integrates with Plaspy for monitoring motorcycles and small vehicles.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, accessory configuration, and manufacturer implementation. For the latest device specific limitations and configuration details consult the official Coban documentation and release notes.

## Feature Overview

The BN-311C is a compact 2G GNSS tracker designed for concealed hardwired installation on motorcycles and other small vehicles. It combines location reporting, alarm signaling and remote control functions to provide discreet anti theft protection and simple operational oversight when paired with a platform such as Plaspy.

- Compact concealed form factor suitable for motorcycle installations and tight spaces
- GNSS based position reporting with regular updates for live tracking and route playback
- GSM GPRS connectivity with TCP UDP and SMS reporting options to deliver telemetry and alarms
- Multiple anti theft alarms including movement, geo fence breach, shock, illegal ignition, overspeed and external power loss
- C type remote control features such as remote arming disarming and remote fuel or power cut off for immobilization
- Internal rechargeable backup battery to continue reporting after external power loss

## Core Features of Coban - BN-311C

- GNSS positioning for continuous location reporting and historical route playback
- GSM GPRS communication with TCP UDP and SMS reporting for platform integration
- Remote immobilizer support on C type units for fuel or power cut off via relay accessory
- Multiple alarm types: movement, geo fence breach, shock, illegal ignition, overspeed, and external power disconnection
- ACC ignition input and status reporting for start stop detection
- Internal rechargeable backup battery to maintain reporting during external power loss
- Small concealed hardwired design optimized for motorcycles and small vehicles

## How These Features Work with Plaspy

When connected and configured, the BN-311C sends position, status, and alarm messages to Plaspy where those signals are presented as live location, events, and historical tracks. Plaspy surfaces device alarms and remote control actions as actionable items within the platform so operators can monitor and respond to incidents in near real time.

- Live GPS location and route playback available in Plaspy for monitoring asset movement
- Alarm events such as movement, geo fence breach, overspeed, shock, and power loss appear as Plaspy alerts and can trigger notifications
- Ignition and ACC status shown in Plaspy to help track vehicle start and stop events
- Remote immobilizer and remote arming disarming reported and can be incorporated into Plaspy workflows for security responses
- Device messages from TCP UDP or SMS are consumed by Plaspy and mapped to platform events without manual protocol selection

## Typical Use Cases

- Motorcycle anti theft protection with concealed installation and remote immobilization
- Small two wheeler fleets for delivery or courier services needing real time tracking and route history
- Rental and shared scooter or motorcycle operations requiring ignition monitoring and quick alerting
- Individual owners wanting discreet monitoring and push notifications for alarms
- Low cost security deployments that need remote arm disarm and power cut immobilization

## Feature Availability Notes

- Feature sets can differ between BN 311C variants and C type units include remote immobilizer functions not present on all models
- Firmware version and manufacturer configuration can change alarm behavior, reporting intervals, and supported commands
- Installation method and accessory choices such as relays or remote controls affect which remote functions are available
- Regional cellular banding and 2G network availability may affect connectivity depending on the local GSM network
- Verify the exact hardware revision and firmware before planning critical operational workflows

## Why Use Plaspy with These Features

Using the BN 311C with Plaspy provides a straightforward way to convert GNSS and GSM signals into operational visibility. Plaspy presents location, alarms, ignition status, and remote control events in a single view so fleet managers and owners can monitor assets, receive alerts, and act on anti theft events from a centralized platform.
