# Coban - BN-303G

![BN-303G](./tracker.png)

The BN-303G is a compact vehicle mounted GPS tracker from Coban designed for reliable real time tracking and anti theft protection. Built for concealed installation on cars and commercial vehicles, the unit provides high sensitivity GNSS positioning and a set of event alarms so fleet managers, rental operators, and private owners can monitor location, ignition state, and basic telemetry in a straightforward way.

As a Plaspy compatible device, the BN-303G can stream location and event data to the Plaspy platform using common transport options, enabling live tracking, alerting, and historical reporting within a unified fleet management dashboard. Its support for flexible data transport and a broad alarm suite makes it a practical option to integrate into Plaspy for operational visibility and incident response.

## Key Highlights

- Compact vehicle mounted tracker intended for concealed installation and continuous monitoring.
- High sensitivity GNSS positioning for consistent location reporting suitable for fleet oversight.
- Multiple communication transport options including TCP UDP and SMS for flexible back end integration.
- Intelligent power saving mode to reduce power draw while parked and wake on movement or alarms.
- Wide set of alarms including SOS overspeed geo fence door open and low battery for security workflows.
- Internal rechargeable backup battery for short term backup and preservation of settings.
- Remote telecommand capabilities such as one way call remote voice listening and remote cutoff style control for anti theft response.

## How It Works with Plaspy

When used with Plaspy the BN-303G sends location fixes and event messages to the platform so operators can monitor assets in real time and respond to alerts. Plaspy ingests telemetry and alarm data to display maps, notifications, and historical records that support fleet operations and security workflows.

- Real time location and event updates delivered to Plaspy over TCP UDP or SMS.
- Alarm ingestion for SOS overspeed geo fence and door open events to trigger notifications and workflows.
- Vehicle state reporting such as ignition related notifications to support routing and utilization analysis.
- Remote cutoff style telecommands and one way call features integrated into incident response processes.
- Historical route and event reporting to support audits trend analysis and operational reviews.

## Typical Use Cases

- Fleet anti theft monitoring and immobilization style response for stolen or unauthorized vehicles.
- Delivery and transport fleet tracking with overspeed alerts and route history for compliance and efficiency.
- Rental vehicle monitoring to detect geofence breaches ignition events and receive SOS alerts.
- Municipal and public transport oversight where centralized telemetry and event reporting are required.
- Optional fuel level monitoring when integrated with external sensors for consumption and anomaly detection.
