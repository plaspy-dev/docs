# Coban - BN-401A Features

This page provides public feature context for using the Coban BN-401A with Plaspy. It summarizes the tracker capabilities that are relevant for fleet managers, installers, and administrators who plan to integrate BN-401A devices into Plaspy for live tracking, alerts, and basic telemetry.

Exact feature availability and behavior can vary by device firmware version, hardware revision, regional variant, installation wiring, and the manufacturer's implementation. Users should treat the descriptions below as an operational summary and consult official Coban documentation for device specific setup and limits.

## Feature Overview

The BN-401A is a compact LTE 4G motorcycle management terminal designed for simple installation and reliable real-time tracking with Plaspy. It focuses on core fleet and anti-theft features needed for two wheel vehicles and other small vehicles that use a 12–24V electrical system.

- Real-time GNSS location reporting suitable for live tracking and history playback.
- LTE 4G connectivity with GSM fallback and support for TCP, UDP and SMS transport to Plaspy.
- Anti-theft and alerting features including movement/shock detection, SOS, overspeed and low battery alarms.
- Remote immobilization support for fuel or power cut-off to assist vehicle recovery and security.
- Bluetooth assisted local configuration and SMS command support for on-site setup and commissioning.

## Core Features of Coban - BN-401A

- Compact form factor tailored for motorcycles and scooters for discreet mounting.
- LTE 4G primary connectivity with GSM/GPRS fallback and multiple transport options.
- GNSS positioning with typical accuracy suitable for fleet tracking and location awareness.
- ACC ignition status sensing to report vehicle on/off state to Plaspy.
- Movement and shock detection for tamper and theft alerts.
- SOS emergency alarm input for driver or rider initiated alerts.
- Remote immobilizer capability to cut fuel or power via external relay control.
- Configurable reporting strategies that reduce transmission when stationary while prioritizing alarms.

## How These Features Work with Plaspy

When connected to Plaspy, the BN-401A sends position updates and event data that Plaspy surfaces on maps, in alerts, and in historical reports. Plaspy detects the device protocol automatically and ingests the device messages for operational visibility and alerting.

- Real-time location and track playback in Plaspy driven by GNSS reports from the device.
- Event forwarding for ACC/ignition state changes, movement/shock alarms, SOS and low-battery alerts.
- Remote immobilizer actions visible as control events and status changes within Plaspy when implemented by the installer.
- Configurable reporting intervals from the device reflected as update frequency and history density inside Plaspy.
- Alerts and notifications triggered by device events allow Plaspy to notify operators or execute workflows for theft or safety incidents.

## Typical Use Cases

- Real-time fleet tracking for motorcycle courier and delivery services.
- Anti-theft monitoring for personal and commercial two wheel vehicles with movement and shock detection.
- Remote immobilization to assist in vehicle recovery or to enforce fleet security policies.
- Low-profile installations where compact size and quick Bluetooth setup reduce installation time.
- Mixed network deployments that rely on LTE with GSM fallback for improved regional coverage.

## Feature Availability Notes

- Firmware variations can change available features and alarm behavior; manufacturing updates may add or remove functions.
- Hardware revisions and regional band variants affect mobile network compatibility and should be matched to local carriers.
- Installation choices such as wiring for ACC, immobilizer relay, SOS button or external sirens determine which features are active.
- Some capabilities may require specific configuration steps or accessory wiring documented by Coban.
- Verify alarm thresholds, reporting intervals, and immobilizer wiring with official installation guides before deployment.
