# Coban - BN-401B Features

This page provides a public, non sensitive overview of the Coban BN-401B features and how the device can be used with Plaspy for real time tracking and anti theft workflows. It focuses on practical capabilities and the typical functions visible to fleet managers and vehicle owners when the BN-401B reports into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific parameters, firmware changes, or detailed configuration steps consult the official manufacturer documentation and release notes.

## Feature Overview

The BN-401B is a compact 4G GPS tracker designed for motorcycles and small vehicles, offering real time positioning, a set of configurable alarms, and simple remote control features that integrate with Plaspy for monitoring and response. It is intended to provide reliable anti theft protection and essential telemetry with minimal installation effort.

- Real time GPS positioning over 4G networks for continuous location visibility.
- Configurable alarm suite including SOS, movement, overspeed, shock, low battery, external power cut, and Geo-fence alerts.
- Remote immobilization capability via fuel or power cut for rapid anti theft response.
- Bluetooth local configuration for easy commissioning and parameter updates without complex wiring.
- Backup battery and smart sleep modes to maintain reporting during external power loss and conserve energy.

## Core Features of Coban - BN-401B

- 4G connectivity with support for TCP, UDP, and SMS transport for flexible reporting.
- Accurate GPS location reporting suitable for live tracking and track playback.
- Comprehensive alarm reporting: SOS alerting, movement and shock detection, overspeed warnings, low battery and external power disconnect events, and Geo-fence notifications.
- Remote fuel or power cut immobilizer support for coordinated theft response.
- ACC ignition detection and ignition related notifications to reflect vehicle status.
- Built in Bluetooth for local parameter configuration and easier field setup.
- Backup rechargeable battery and wide vehicle input voltage support to handle vehicle power interruptions.

## How These Features Work with Plaspy

When the BN-401B is linked to Plaspy, its location and alarm messages are consumed by the platform to provide visibility, alerts, and historical reporting. Plaspy surfaces the device events and telemetry so operators can act on alarms and review movement history.

- Live location and position updates shown on Plaspy maps for real time tracking.
- Track playback of historical routes using the device reported positions.
- Geo-fence alerts and SOS events forwarded as notifications inside Plaspy workflows.
- Alarm events such as low battery or external power cut appear in the device event log for follow up.
- Remote immobilization and ignition related events can be coordinated through Plaspy workflows and operator actions.

## Typical Use Cases

- Anti theft monitoring and rapid immobilization for motorcycles and light vehicles.
- Personal motorcycle or private car security with immediate SOS and movement alerts.
- Small urban delivery fleets and couriers requiring frequent position updates and incident logging.
- Rental vehicle monitoring where compact installation and ignition status help manage fleet availability.
- Event logging for maintenance scheduling and incident investigation using Plaspy reports and playback.

## Feature Availability Notes

- Firmware and regional hardware variants can change which bands and specific alarms are active or how they behave; check the device firmware level before assuming feature parity.
- Some telematics behaviors depend on installation wiring and configuration, for example ACC detection and external power reporting require the corresponding vehicle connections.
- Bluetooth configuration, SMS commands, and remote immobilizer functions may be restricted or modified by firmware or local regulations.
- Manufacturer manuals and release notes are the authoritative source for detailed instructions and the latest supported features.
- Plaspy displays and reacts to the data the device reports; availability of a feature in Plaspy depends on the tracker sending the corresponding message.

## Why Use Plaspy with These Features

Pairing the BN-401B with Plaspy gives operators a straightforward way to convert the tracker’s alarms and position reports into operational insights. Plaspy aggregates live location, event history, and alarm notifications so teams can monitor assets, respond to theft incidents, and analyze movement patterns without needing deep device level configuration knowledge.
