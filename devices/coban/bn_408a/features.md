# Coban - BN-408A Features

This page provides a public, non sensitive feature overview of the Coban BN-408A and how its capabilities are used with Plaspy for monitoring vehicles and movable assets. It focuses on user facing functionality, operational value, and what operators can expect to see inside Plaspy when reporting from this model.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. Where specific functions depend on firmware or optional accessories, operators should verify the current behavior with the device documentation and any installation notes from the vendor.

## Feature Overview

The BN-408A is a portable, magnetically mountable GPS tracker designed for long duration deployments without permanent wiring. It combines multi network connectivity, configurable reporting strategies, and tamper aware alarms to support straightforward asset tracking and anti theft workflows when integrated with Plaspy.

- Portable magnetic mounting for tool free attachment to vehicles trailers and other movable assets
- Multi network connectivity that allows real time position reports to be delivered to Plaspy
- High capacity rechargeable battery for extended standby and lower maintenance intervals
- Configurable reporting modes including real time Online, Smart Mode for sleep when stationary, and Power Saving Mode
- Infrared tamper detection plus movement shock and low battery alarms to support anti theft monitoring
- Remote voice monitoring and SMS configuration options for on site verification and simple field reconfiguration

## Core Features of Coban - BN-408A

- Portable form factor with strong magnetic adsorption for non invasive mounting
- 3.7V 10,000 mAh rechargeable Li ion battery for extended deployments
- Supports 2G 3G and 4G networks for broad cellular coverage
- Transport over TCP UDP and SMS so the device can report to Plaspy using common channels
- Infrared tamper sensor for detection of unauthorized access or removal
- Multiple alarm types including movement shock overspeed and low battery alerts
- Multiple positioning and power strategies including Real time Online Smart Mode and Power Saving Mode
- Remote voice monitoring capability for situational checks from the platform or mobile app

## How These Features Work with Plaspy

When the BN-408A is reporting, Plaspy ingests its location and status messages so operators can monitor assets in near real time and review historical activity. The device features map directly to visibility and alerting inside Plaspy, enabling practical monitoring and response workflows.

- Live location updates and status indicators appear on Plaspy dashboards for continuous tracking
- Tamper movement and shock alarms generate platform notifications so teams can investigate potential theft or tampering
- Track playback and historical position data support route audit and recovery workflows
- Geo fence events and low battery notifications help operators plan checks and maintenance
- Reporting modes such as Smart Mode and Power Saving Mode influence how often Plaspy receives updates and how long battery powered deployments remain active
- Remote voice monitoring and SMS based configuration enable on site verification and quick field adjustments when needed

## Typical Use Cases

- Temporary fleet tracking for seasonal or leased vehicles where non permanent mounting is preferred
- Trailer and container security using magnetic mounting plus tamper detection to reduce unauthorized removal risk
- Monitoring of high value portable equipment such as generators or tools that move between sites
- Anti theft response workflows where real time tracking and alarm notifications assist recovery efforts
- Long term remote monitoring deployments that rely on power saving modes to extend battery life
- Situational verification via remote voice monitoring when an on site check is required
