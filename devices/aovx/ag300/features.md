# AOVX - AG300 Features

This page covers the public feature context for using the AOVX AG300 with Plaspy. The AG300 is presented as an industrial asset tracker designed for reliable location visibility across indoor and outdoor environments, with multi mode positioning and support for event telemetry that can be used in Plaspy for monitoring and operational oversight.

The exact feature set available in a live deployment can vary based on firmware, hardware revision, installation method, and the manufacturer implementation. For that reason, the most accurate view of AOVX AG300 features should always be confirmed against current manufacturer documentation, while this page explains the practical capabilities most relevant to Plaspy users.

## Feature Overview

The AOVX AG300 is positioned as a rugged GPS tracker for durable asset monitoring, with a focus on long term visibility and reduced maintenance. In Plaspy, its main value comes from combining location reporting with event based telemetry so operators can keep track of assets even when conditions change or installations are spread across different sites.

- Multi mode positioning helps improve location visibility across indoor and outdoor environments.
- Real time tracking supports active monitoring of assets in motion or at rest.
- Motion, vibration, and tamper related events add operational awareness beyond simple location updates.
- BLE 5.0 support can extend the tracker with external Bluetooth sensor data where enabled.
- Rugged protection and magnetic mounting options support practical field installation on assets and equipment.
- Low maintenance design is suited to long duration deployments where frequent servicing is not desirable.

## Core Features of AOVX - AG300

- Multi source positioning using GPS, BeiDou, base station, and Wi Fi signals
- Continuous location reporting for real time asset visibility
- Motion detection for movement aware monitoring
- Vibration detection for event driven status changes
- Tamper and removal alert support for anti theft monitoring
- BLE 5.0 support for compatible external Bluetooth sensors
- Rugged IP68 enclosure for demanding environments
- Optional strong magnetic mounting for secure placement on metal assets

## How These Features Work with Plaspy

When the AG300 is used with Plaspy, its location updates and event messages can be reflected in the platform for live tracking, history review, and operational monitoring. Plaspy automatically detects the tracker protocol and uses the same platform port across supported devices, which simplifies deployment planning for teams managing multiple trackers.

- Location reports from the AG300 can appear in Plaspy for live asset visibility
- Event messages such as motion, vibration, and tamper activity can be monitored in the platform
- Multi mode positioning can help Plaspy maintain better context when GPS reception is limited
- BLE sensor data can be viewed alongside tracker information when supported by the deployment
- Historical tracking and reporting in Plaspy can support analysis of asset movement and utilization
- Centralized monitoring helps teams manage multiple assets from one platform view
