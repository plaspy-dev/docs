# AOVX - GM100 Features

This page covers the public feature context for the AOVX GM100 when used with Plaspy. The GM100 is a Plaspy compatible ultra thin GPS tracker designed for discreet goods and shipment monitoring, with a focus on location awareness and condition visibility during transport.

Because device behavior can vary by firmware, hardware revision, installation type, and manufacturer implementation, the exact feature set may not be identical in every deployment. The information below is intended to help users understand the practical AOVX GM100 GPS tracker features and the kinds of data Plaspy can present from this model.

## Feature Overview

The AOVX GM100 is built for shipment and asset visibility rather than permanent vehicle installation. In Plaspy, it is best understood as a compact tracking device that can help monitor where goods are, how they are moving, and whether basic shipment conditions have changed during transit.

- Discreet ultra thin form factor for attachment to packages and pallets
- Multi mode positioning with GPS, Beidou, cellular base station, and Wi Fi
- Plaspy compatible tracking for location monitoring and reporting
- Temperature and humidity sensing for condition aware shipments
- Tamper and unpacking alert support for protected goods
- Low battery alert support for operational awareness

## Core Features of AOVX - GM100

- Ultra thin, installation free design for discreet placement on goods and shipment units
- Plaspy compatible operation for public tracking and monitoring workflows
- Multi mode positioning using GPS, Beidou, cellular base station, and Wi Fi
- Global Cat M1 and NB IoT connectivity for low power telemetry
- Temperature sensing for shipment condition visibility
- Humidity sensing for cold chain and environmental monitoring
- Tamper and unpacking alert capability for added shipment protection
- Low battery alert support for maintenance planning

## How These Features Work with Plaspy

When the GM100 is used with Plaspy, its location and condition information can be displayed alongside other tracking assets in the same monitoring environment. That makes it easier for teams to follow shipment progress, review event history, and respond to changes that affect cargo integrity.

- Location updates can appear in Plaspy for real time shipment visibility
- Multi mode positioning helps improve practical tracking coverage across different environments
- Temperature and humidity readings can be used for condition monitoring and historical review
- Tamper and unpacking events can be reflected in Plaspy as operational alerts
- Low battery status can help teams plan servicing or device replacement before gaps occur
- Historical telemetry in Plaspy can support audit trails and transport review
