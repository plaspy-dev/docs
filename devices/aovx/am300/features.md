# AOVX - AM300 Features

This page covers the public feature context for using the AOVX AM300 with Plaspy. It is designed to help you understand what the tracker can do in practical terms, how its main capabilities relate to fleet and asset monitoring, and what kind of visibility Plaspy can present when the device is deployed.

The AM300 is positioned as an industrial-grade GPS tracker for long-term asset deployments. Based on the available public description, it combines GNSS positioning, network-assisted location methods, cellular connectivity, rugged protection, and BLE support to help organizations monitor assets with less maintenance and broader deployment flexibility.

## Feature Overview

The AOVX AM300 focuses on durable asset tracking and low-power remote monitoring. In Plaspy, those capabilities are most useful when you need dependable location visibility, event awareness, and flexible deployment across different environments.

- GNSS-based positioning with GPS and BeiDou for location tracking in outdoor and open-sky scenarios
- Base station and Wi-Fi positioning to improve location context when satellite visibility is limited
- Cellular connectivity designed for modern and legacy network coverage
- BLE 5.0 support for integrating compatible Bluetooth sensors and beacons
- Rugged IP68 housing for demanding indoor and outdoor installations
- Magnetic mounting for fast placement on assets where secure attachment is important
- Motion, vibration, and tamper or displacement alarms for basic security awareness
- Low-power operation intended for long-term asset deployments

## Core Features of AOVX - AM300

- GPS and BeiDou GNSS support for primary location tracking
- Base station positioning for added location context in covered environments
- Wi-Fi positioning to support tracking when satellite data is weak or unavailable
- Cat.M1, EGPRS, and NB-IoT connectivity for flexible network use
- BLE 5.0 compatibility for supported sensor and beacon integrations
- Motion, vibration, and tamper or displacement alarms for security-related monitoring
- IP68-rated enclosure for use in harsh or exposed environments
- Strong magnetic mounting for practical asset installation

## How These Features Work with Plaspy

When the AM300 reports into Plaspy, its supported location methods and event signals can be used to provide a clearer picture of asset movement, placement, and status. Plaspy helps turn that device data into operational visibility that is easier to monitor and review over time.

- Location updates from GNSS, Wi-Fi, or network-assisted positioning can appear in Plaspy for ongoing tracking
- Motion and vibration events can be reflected as alerts or status changes for quicker awareness
- Tamper and displacement conditions can support anti-theft monitoring workflows
- BLE-related data can be used in Plaspy when compatible sensors or beacons are part of the deployment
- Historical records and reporting can help teams review where an asset was and when it moved
- Long-life, low-power operation supports remote monitoring use cases where frequent maintenance is not practical

## Typical Use Cases

- Mixed indoor and outdoor tracking scenarios that benefit from Wi-Fi or base station positioning
