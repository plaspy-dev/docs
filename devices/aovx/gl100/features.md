# AOVX - GL100 Features

This page covers the public feature context for using the AOVX GL100 with Plaspy. The GL100 is a compact, installation-free GPS tracker designed for long-term asset monitoring and environmental logging, with GNSS positioning, 2.4 GHz Wi Fi location aids, and onboard temperature and humidity sensing.

In Plaspy, the GL100 can be used to visualize location updates, review sensor-based status information, and support tracking workflows for merchandise, packages, and vehicle cargo. Exact feature availability can vary depending on firmware, hardware revision, installation type, and the manufacturer implementation, so it is always worth confirming the current device details before deployment.

## Feature Overview

The AOVX GL100 is built for practical asset visibility rather than complex vehicle electronics. Its public feature set focuses on location tracking, condition monitoring, and low-maintenance operation, making it suitable for unattended deployments where reliable periodic reporting matters.

- GNSS-based positioning for asset location monitoring
- 2.4 GHz Wi Fi location aids for improved positioning in challenging environments
- Onboard temperature sensing for condition-aware tracking
- Onboard humidity sensing for environmental monitoring
- Motion-based power-aware reporting to help reduce unnecessary updates
- Customizable light detection for trigger-based operation
- Offline storage for deferred position upload
- Rechargeable battery operation for long-term deployment
- USB and OTA firmware updates for simpler maintenance

## Core Features of AOVX - GL100

- Compact, installation-free GPS tracker design
- GNSS location reporting for asset and cargo visibility
- 2.4 GHz Wi Fi assisted location support
- Temperature monitoring from onboard sensing
- Humidity monitoring from onboard sensing
- Motion detection for smarter reporting behavior
- Customizable light detection for trigger-based tracking
- Deferred upload support through onboard memory

## How These Features Work with Plaspy

Plaspy uses the GL100's reported position and sensor information to help teams follow assets over time and review operational status in one place. That makes it easier to monitor movement, understand delivery conditions, and keep historical records for assets that are not permanently installed in vehicles.

- Location updates can appear in Plaspy for map-based visibility and history review
- Temperature and humidity readings can support condition monitoring workflows
- Motion and light-triggered events can help highlight relevant activity
- Stored position records can be reflected after offline periods when the device reconnects
- Periodic reporting can support low-touch monitoring for long-term asset deployments
- Plaspy automatically detects the tracker protocol, helping simplify integration across supported devices
