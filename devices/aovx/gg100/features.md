# AOVX - GG100 Features

This page covers the public feature context for using the AOVX GG100 with Plaspy. It is intended to help you understand what the tracker is designed to do, how its main capabilities can support logistics and asset visibility, and how Plaspy can be used to monitor the device in a practical operational setup.

The GG100 is described as an ultra-thin goods GPS tracker for installation-free deployment across logistics and supply chain operations. Its public feature set emphasizes multi-mode positioning, environmental sensing, Bluetooth 5.0, and tamper or unpacking alerting, making it a fit for shipments, pallets, cartons, containers, and other movable assets.

## Feature Overview

The AOVX GG100 is focused on practical goods tracking rather than complex vehicle telematics. Its public capabilities center on location visibility, environmental monitoring, and simple deployment for large-scale asset use cases. That makes it especially relevant for organizations that need a compact tracker that can be attached quickly and monitored through Plaspy.

- Multi-mode positioning using GPS, Beidou, base station positioning, and Wi-Fi assistance
- Built for installation-free deployment on goods, pallets, cartons, and containers
- Temperature and humidity sensing for environmental monitoring
- Bluetooth 5.0 support for nearby sensor and beacon related use
- Tamper and unpacking alarm functionality with indicator lamp
- Long standby life for extended transit and asset monitoring

## Core Features of AOVX - GG100

The AOVX GG100 feature set is centered on low-friction tracking for logistics assets and shipment workflows.

- Ultra-thin form factor designed for easy placement on goods and packages
- Installation-free use for rapid deployment across large asset pools
- GPS and Beidou positioning for outdoor location awareness
- Base station positioning and Wi-Fi assistance for broader location availability
- Built-in temperature sensor for cargo condition visibility
- Built-in humidity sensor for monitoring sensitive shipments
- Bluetooth 5.0 for local wireless capabilities
- Tamper and unpacking alarm support for handling awareness
- Long standby operation for extended transit and low-touch tracking scenarios
- Recyclable construction for deployments where reuse and sustainability are important

When the GG100 is used with Plaspy, its public feature set can be reflected as live location visibility, environmental status monitoring, and event-based oversight for goods in transit. Plaspy provides the platform layer for organizing this information into a practical tracking workflow.
