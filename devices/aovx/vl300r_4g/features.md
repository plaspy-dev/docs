# AOVX - VL300R - (4G) Features

This page covers the public feature context for the AOVX VL300R - (4G) when used with Plaspy. It focuses on the tracker’s practical capabilities, how those capabilities can appear in a fleet tracking environment, and what users can expect from a Plaspy compatible GPS tracker in everyday operations.

The VL300R - (4G) is described as a robust wired vehicle GPS tracker built for integrators and fleet operators. Its feature set centers on real-time tracking, multi-constellation GNSS, internal antennas, LTE FDD and GSM connectivity, local position storage, and support for driver identification, external sensors, emergency inputs, and firmware management.

## Feature Overview

The AOVX VL300R - (4G) is designed for vehicle tracking scenarios where dependable location reporting and practical telemetry matter. In Plaspy, that means the device can be used as a field tracker for visibility, operational oversight, and event-based monitoring rather than as a consumer-style GPS unit.

- Real-time vehicle location tracking for fleets and work vehicles
- Multi-constellation GNSS for broader positioning support
- LTE FDD and GSM connectivity for wide-area communication
- Internal antennas for compact wired installations
- Local position memory for storing many records when coverage is interrupted
- Support for driver identification and external telemetry inputs
- Firmware management options for ongoing device maintenance

## Core Features of AOVX - VL300R - (4G)

- Wired vehicle GPS tracker for professional installations
- Multi-constellation GNSS positioning
- Internal antenna design
- LTE FDD and GSM cellular connectivity
- Local position memory for stored tracking data
- Driver identification support through iButton and RFID
- Support for environmental sensors through Bluetooth, RS232, or 1-Wire
- Emergency input support for panic-type events

## How These Features Work with Plaspy

When the VL300R - (4G) is connected to Plaspy, the tracker’s location updates and supported telemetry can be used to improve fleet visibility and operational control. Plaspy automatically detects the tracker protocol, which helps make the device practical for ongoing monitoring and reporting in a unified platform.

- Location data can be reflected in Plaspy for live map tracking
- Stored position data helps preserve visibility during temporary communication gaps
- Driver identification can be associated with trips and events in Plaspy
- Emergency inputs can be surfaced as actionable events for monitoring teams
- Sensor data can support broader operational awareness when enabled on the device
- Fleet records can be used for route review, trip history, and general oversight

## Typical Use Cases
