# AOVX - EB110

The AOVX EB110 is an environmental tag designed for monitoring shipments, warehouses, and sensitive inventory. It is built for low power operation and delivers sensor-based telemetry that helps track conditions such as temperature, humidity, light, and motion in environments where product integrity matters.

Because the EB110 is compatible with Plaspy, it can be used as part of a broader visibility strategy that goes beyond location alone. In Plaspy-managed workflows, the device can contribute condition data that supports cold chain oversight, tamper awareness, and better operational decisions across logistics and asset monitoring use cases.

The EB110 can add environmental context to tracking operations managed in Plaspy by sending sensor data through Bluetooth based collection points and connected infrastructure. This helps teams combine location visibility with condition monitoring so they can see not only where an asset is, but also whether it has been exposed to movement or environmental changes that matter to the business.

- Supports visibility into condition changes that may affect shipments or stored goods
