# AOVX - EB110 Features

This page covers the public feature context for using the AOVX EB110 with Plaspy. The EB110 is a Plaspy compatible environmental tag designed for long-life, low-power monitoring of shipments, warehouses, and sensitive inventory. It adds sensor-driven visibility to tracking workflows by reporting condition data that can complement GPS tracker deployments inside Plaspy.

Feature availability can vary depending on firmware, hardware revision, installation type, and the manufacturer implementation. For that reason, the AOVX EB110 features and AOVX EB110 functions described here should be understood as public, practical guidance rather than a complete specification. Users should review official manufacturer documentation for the latest device-specific details.

## Feature Overview

The AOVX EB110 is best understood as a compact BLE environmental tag that supports condition-aware logistics rather than standalone GNSS tracking. In Plaspy, it is useful when the goal is to monitor environmental exposure, movement, and handling context alongside fleet or asset visibility.

- Bluetooth 5.0 connectivity for short-range reporting to gateways, mobile devices, or local collectors
- Temperature and humidity monitoring for storage and shipment condition awareness
- Light-level detection to help identify exposure events
- Motion sensing for transit, handling, and tamper-related context
- Low-power design intended for long-life deployment
- Compact form factor for discreet placement on packages, pallets, and inventory

## Core Features of AOVX - EB110

- Plaspy compatible BLE environmental tag for condition-focused monitoring
- Bluetooth Low Energy 5.0 communication for gateway-based reporting
- Continuous temperature telemetry for cold chain and storage visibility
- Humidity telemetry for tracking environmental stability
- Light sensing to highlight exposure or storage condition changes
- Motion sensing to add activity and handling context
- Long-life, low-power operation suitable for large deployments
- Compact size for use on shipments, pallets, and sensitive inventory

## How These Features Work with Plaspy

In Plaspy, the EB110 can contribute sensor data that improves operational awareness beyond simple location tracking. When BLE gateways or compatible collectors forward the device information, Plaspy can use that data to support dashboards, monitoring workflows, and event visibility across assets in transit or in storage.

- Environmental telemetry can be displayed in Plaspy for easier condition monitoring
- Temperature and humidity data help support cold chain oversight and storage review
- Light and motion events can add context to handling, transit, or exposure situations
- Sensor data can be correlated with GPS tracker information in Plaspy for fuller situational awareness
- Long-life BLE operation supports scalable monitoring across many assets with reduced maintenance effort

## Typical Use Cases

- Cold chain monitoring for pharmaceuticals, food, and other sensitive goods
- Warehouse visibility for temperature and humidity sensitive inventory
- Shipment monitoring where exposure or handling context matters
- Asset condition monitoring for packaged equipment or valuable materials
- Logistics workflows that need both GPS location and environmental telemetry
- Tamper awareness for goods that should remain sealed or undisturbed
