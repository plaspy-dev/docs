# AOVX - VL350 Features

This page summarizes the public feature context for the AOVX VL350 when used with Plaspy. It focuses on the capabilities that are relevant for vehicle tracking, trailer tracking, and operational monitoring, so users can understand how the device fits into a Plaspy-based fleet or asset workflow.

The VL350 is presented as a robust GPS tracker for persistent location reporting and recovery-oriented use cases. Based on the available description, it combines multi-constellation positioning, cellular connectivity, WiFi assistance, BLE support, and control functions that are useful for visibility and anti-theft operations.

## Feature Overview

The AOVX VL350 features are centered on resilient tracking and practical fleet oversight. In Plaspy, that means the device is best understood as a tracker designed to keep moving assets visible, even when conditions are less than ideal or when a trailer is detached from a powered vehicle.

- Multi-constellation positioning using GPS and Beidou for location tracking
- Cell ID and WiFi assistance to help improve location continuity
- Global 4G LTE Cat.1 connectivity for wide-area reporting
- BLE 5.0 support for compatible Bluetooth sensors and beacons
- ACC ignition monitoring for vehicle power state awareness
- Remote oil and electric cut-off and power-on control for recovery workflows
- Designed for trailer fleet management and asset recovery use cases

## Core Features of AOVX - VL350

- GPS and Beidou positioning support for location tracking across different environments
- Cell ID based positioning assistance for situations where satellite signals are weaker
- WiFi assistance to support more resilient location updates
- Global 4G LTE Cat.1 connectivity for communication with Plaspy
- BLE 5.0 compatibility for Bluetooth sensor integration
- ACC ignition monitoring for status visibility in vehicle applications
- Remote oil and electric cut-off control for immobilizer and recovery scenarios
- Remote power-on control as part of recovery-oriented fleet operations

When the VL350 is used with Plaspy, the device can contribute location visibility and operational context to a centralized tracking view. This is especially useful for fleets that need to monitor trailers, vehicles, or assets across depots, roads, and storage locations.

- Location updates can be reflected in Plaspy dashboards for real-time asset visibility
- ACC status can help operators understand whether a vehicle is powered or in use
- Remote control capabilities can support recovery workflows managed through Plaspy
- BLE sensor data can extend the tracked context to compatible cargo, door, or temperature monitoring

- Event visibility in Plaspy can support operational oversight and incident review
