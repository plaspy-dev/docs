# AOVX - VX300 Features

The AOVX VX300 is a compact GPS tracker designed for vehicle tracking and fleet management, with public feature context that fits naturally with Plaspy. This page summarizes the main AOVX VX300 features and shows how the tracker can be used for location visibility, ignition monitoring, sensor integration, and centralized fleet oversight in Plaspy.

The exact VX300 capabilities available in a specific deployment can vary by firmware, hardware revision, installation method, and manufacturer implementation. For that reason, this page focuses on the features that are explicitly described for the model and on the practical ways those functions can be reflected in Plaspy.

## Feature Overview

The VX300 is positioned as a practical tracking device for commercial vehicle use, combining multi-network connectivity with multi-system positioning and several operational inputs and outputs. In Plaspy, those functions are most useful when they are used to maintain reliable visibility over vehicle movement, status changes, and related field activity.

- Designed for vehicle tracking and fleet management use cases
- Supports Cat.M1, 4G Cat.1, and 2G GPRS network options
- Uses GPS and BeiDou positioning, with Wi-Fi and cellular base station positioning as supplemental sources
- Includes ACC ignition detection for start and stop event visibility
- Supports remote oil and power cut-off for immobilization workflows
- Provides extended GPIO for external input and output integration
- Includes Bluetooth support for external sensor communication

## Core Features of AOVX - VX300

- Multi-network connectivity with Cat.M1, 4G Cat.1, and 2G GPRS support
- Multi-system positioning using GPS and BeiDou
- Supplemental location support through Wi-Fi and cellular base station positioning
- ACC ignition detection for operational event tracking
- Remote oil and power cut-off support for anti-theft control
- Extended GPIO for connecting compatible external devices and inputs
- Bluetooth support for external sensor integration
- Compact low-profile design suited to commercial vehicle installation

## How These Features Work with Plaspy

When the VX300 is used with Plaspy, its public-facing features can be reflected as location visibility, event tracking, and additional operational context inside a centralized fleet platform. Plaspy automatically detects the tracker protocol, helping the device report into the platform without shifting the focus away from fleet management and monitoring.

- Location reports can be displayed in Plaspy for day-to-day vehicle visibility
- Ignition events can help distinguish trips, stops, and vehicle activity patterns
- Supplemental positioning data can improve location continuity when primary GNSS coverage is limited
- Remote immobilization functions can support operational anti-theft workflows when used by authorized staff
- GPIO-based integrations can add external status signals to fleet monitoring
- Bluetooth sensor data can be used to extend the tracker’s practical monitoring role in Plaspy
