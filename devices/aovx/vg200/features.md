# AOVX - VG200 Features

This page covers the public feature context for using the AOVX VG200 with Plaspy. The VG200 is an ultra-small vehicle GPS tracker designed for discreet tracking of motorcycles and compact vehicles, with a focus on real-time location visibility, ignition monitoring, and remote fuel or power cut off support.

While the VG200 is positioned for practical fleet and anti-theft use, exact feature availability can vary by firmware, hardware revision, installation method, and the way the manufacturer implements the device. For that reason, the details below describe the public feature set that is relevant to Plaspy without assuming capabilities that are not explicitly confirmed.

## Feature Overview

The AOVX VG200 features are centered on compact vehicle monitoring and simple, effective control. In Plaspy, the tracker is used to surface location updates, movement history, and key vehicle events in a way that supports everyday operations as well as security-focused workflows.

- Ultra-small form factor for discreet installation on motorcycles and small vehicles
- Real-time tracking for current position visibility in Plaspy
- Multi mode positioning using GPS and BeiDou
- Cellular base station and Wi Fi assisted positioning for broader location support
- ACC ignition monitoring to observe engine on and off activity
- Remote fuel and power cut off support for anti-theft response

## Core Features of AOVX - VG200

- Plaspy compatible GPS tracker for vehicle and motorcycle monitoring

When the VG200 is used with Plaspy, the device data can be presented in a clear operational view that helps users follow vehicle movement, monitor ignition events, and respond to security related situations.
