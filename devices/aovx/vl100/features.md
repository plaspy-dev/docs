# AOVX - VL100 Features

This page summarizes the public feature context for using the AOVX VL100 with Plaspy. It is intended to help you understand the tracker’s practical capabilities, how they fit into a Plaspy environment, and what kinds of monitoring workflows are commonly supported by this model.

The VL100 is positioned as a compact, cost-effective GPS tracker for straightforward vehicle monitoring and reliable Plaspy compatible integration. Its public description highlights 4G connectivity with automatic fallback to 2G, GT06 protocol support, wired installation, ignition detection, remote blocking output, local position storage, and firmware maintenance options through USB or OTA updates.

## Feature Overview

The AOVX VL100 focuses on essential tracking functions that are useful in everyday fleet and vehicle oversight. It is designed for users who need dependable location visibility, ignition awareness, and a practical setup that can be integrated into Plaspy without unnecessary complexity.

- Real-time vehicle tracking for cars, trucks, and other vehicles
- 4G connectivity with automatic fallback to 2G for broader coverage
- GT06 protocol support for Plaspy compatible integration
- Wired installation with simple power and signal connections
- Ignition detection for trip and engine status awareness
- Remote block output for immobilizer style control in supported workflows
- Local storage for historical position records when connectivity is interrupted
- Firmware maintenance options through USB or over the air updates

## Core Features of AOVX - VL100

- Compact GPS tracker for vehicle monitoring use cases
- 4G communication with automatic fallback to 2G

- Wired installation designed for straightforward vehicle deployment
- Ignition input for engine status monitoring
- Block output for remote immobilizer related scenarios
- Local memory for storing position records for later retrieval

## How These Features Work with Plaspy

In Plaspy, the VL100 can be used as a practical source of vehicle location and operational status data. Its GT06 compatibility allows Plaspy to interpret supported tracker messages and present them in a way that is useful for monitoring, alerting, reporting, and ongoing fleet supervision.

- Location data can be reflected in Plaspy for live map visibility
- Ignition events can support trip context and engine on or off awareness
- Block output related events can be used in anti theft oriented workflows
- Stored position records can help preserve historical movement data after connectivity returns
- Tracking updates can support route monitoring, operational review, and asset visibility
- Compatibility with Plaspy makes it easier to centralize tracker data in one platform

## Typical Use Cases
