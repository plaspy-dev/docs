# AOVX - EB100 Features

The AOVX EB100 features page provides public information about how this device can be used with Plaspy. The EB100 is a compact Bluetooth Low Energy environmental sensor tag designed for continuous monitoring of temperature, humidity, light, and motion during storage and transport. When the device is paired with BLE gateways or smartphones that forward data to Plaspy, it can contribute useful condition data to broader monitoring workflows.

This page is focused on practical, public-facing feature context rather than private implementation details. Exact feature availability can vary depending on firmware, hardware revision, installation method, and the manufacturer’s implementation, so the most current device behavior should always be checked against official AOVX documentation.

## Feature Overview

The AOVX EB100 is best understood as an environmental sensor tag that helps track conditions around goods, assets, and storage areas. It is designed to broadcast sensor data over Bluetooth Low Energy, allowing compatible gateways or mobile devices to relay that information into Plaspy for visibility and recordkeeping.

- Continuous monitoring of temperature, humidity, light, and motion
- Bluetooth Low Energy 5.0 communication for power efficient data exchange
- Support for BLE gateway or smartphone forwarding into Plaspy
- Optional external high precision temperature and humidity sensor support
- Compact tag form factor for packages, pallets, racks, and transport use
- Event oriented visibility for handling, exposure, or movement related conditions

## Core Features of AOVX - EB100

- Bluetooth Low Energy 5.0 based sensor tag
- Temperature monitoring for storage and transport conditions
- Humidity monitoring for environmental observation
- Light sensing for exposure related awareness
- Motion sensing for handling and movement events
- Optional external high precision temperature and humidity sensor support
- Compact form factor for easy placement on goods or in fixed locations
- Designed for integration through BLE gateways or smartphones that forward data to Plaspy

## How These Features Work with Plaspy

In a Plaspy deployment, the EB100 can add condition awareness to existing GPS tracking and fleet monitoring workflows. Because the device communicates through BLE, nearby gateways or smartphones can collect its data and forward it to Plaspy for centralized viewing and analysis.

- Environmental readings can be recorded in Plaspy alongside other operational data
- Motion and light related events can help indicate handling or exposure conditions
- Gateway based collection can provide site level context for stored or transported goods
- Smartphone forwarding can extend data capture in workflows where mobile collection is practical
- Optional external sensing can improve monitoring for stricter temperature and humidity requirements
- EB100 data can complement vehicle and asset visibility already managed in Plaspy

## Typical Use Cases
