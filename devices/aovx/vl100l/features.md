# AOVX - VL100L Features

This page summarizes the public feature context for using the AOVX VL100L with Plaspy. It is intended to help you understand the tracker’s practical capabilities, what those capabilities mean in day to day operations, and how Plaspy can present the resulting tracking data in a useful way.

The VL100L is described as a compact, low cost GPS tracker designed for fleet management, basic insurance monitoring, and economical vehicle surveillance. It supports Plaspy compatibility through GT06 protocol support and is positioned for real time tracking, continuity during temporary connectivity loss, and simple vehicle control workflows.

## Feature Overview

The AOVX VL100L focuses on essential vehicle tracking functions rather than complex sensor packages. In Plaspy, this makes it a practical option for organizations that want clear location visibility, basic vehicle status awareness, and straightforward tracking operations without unnecessary complexity.

- Real time GPS tracking for live vehicle visibility in Plaspy
- Plaspy compatibility through GT06 protocol support
- 4G connectivity with automatic fallback to 2G for broader continuity
- Internal position memory to preserve location history during outages
- Ignition aware tracking for more useful trip and movement context
- Remote immobilizer support through a blocking output
- Low power operation designed for vehicle installations
- Firmware maintenance through USB or over the air updates

## Core Features of AOVX - VL100L

- Compact wired GPS tracker designed for vehicle use
- Supports Plaspy compatibility through the GT06 protocol
- Uses 4G connectivity with automatic fallback to 2G
- Includes internal position buffering for temporary network interruptions
- Supports ignition input for vehicle on and off awareness
- Provides a blocking output for remote immobilizer control
- Offers firmware updates through USB and over the air methods
- Built for practical fleet, insurance, and vehicle surveillance use

## How These Features Work with Plaspy

When the VL100L is connected to Plaspy, the tracker can send location and status information into the platform for operational monitoring. Plaspy then helps turn that incoming data into a clearer view of vehicle movement, route activity, and basic security related actions.

- Live location data can be displayed in Plaspy for active vehicle monitoring
- Ignition aware information can support trip visibility and movement context
- Buffered positions can help preserve history when network coverage is interrupted
- Blocking output behavior can support immobilizer based workflows in Plaspy
- Protocol compatibility allows the device to integrate with Plaspy in a straightforward way
- Ongoing device activity can be used for fleet oversight and routine tracking review
