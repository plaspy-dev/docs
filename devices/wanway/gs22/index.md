# WanWay - GS22

![GS22](./Logo.jpg)

The WanWay GS22 is a compact 4G vehicle OBD II positioning device designed for in vehicle tracking and fleet oversight. It combines real time tracking, user defined geo fencing, trace playback, and vehicle diagnostics in a small housing measuring 60x46x22mm. The unit includes a built in 140mAh rechargeable battery to continue sending positioning data if vehicle power is lost and provides a disassembly alarm for added security.

As a Plaspy compatible device, the GS22 can feed location and basic vehicle status information into a centralized fleet platform for monitoring and reporting. When paired with Plaspy, this tracker supports common fleet workflows such as live visibility, geofence alerts, trace playback, and diagnostic awareness, helping operators make operational decisions from a single interface.

## Key Highlights

- 4G vehicle tracking and real time location reporting suitable for fleet monitoring
- OBD II based positioning with vehicle diagnostic information for operational insight
- Compact and unobtrusive form factor at 60x46x22mm for easy fitment in vehicles
- Built in 140mAh rechargeable battery provides backup reporting after power loss
- Disassembly alarm for added tamper detection and security notifications
- Supports features like user defined geo fence, trace playback, and remote tracking

## How It Works with Plaspy

The GS22 can transmit its location and diagnostic signals to Plaspy where data is aggregated for visibility, alerts, and reporting. Plaspy collects the information from compatible devices like the GS22 and presents it alongside other fleet data so operators can monitor vehicles and respond to events quickly.

- Live location and position updates visible on Plaspy maps and dashboards
- Geofence alerts created in Plaspy trigger notifications when the GS22 enters or exits defined areas
- Trace playback in Plaspy enables historical route review from GS22 position records
- Disassembly alarm and power loss reporting surface as events for operational follow up
- Vehicle diagnostic flags from the GS22 are available in Plaspy for basic maintenance awareness

## Typical Use Cases

- Car monitoring for single vehicles and small fleets
- Online car rental and shared mobility tracking and oversight
- Traditional car rental fleet management and return monitoring
- Security monitoring where disassembly alarms and backup reporting are important
- Basic operational and maintenance visibility using onboard diagnostic information
