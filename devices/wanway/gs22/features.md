# WanWay - GS22 Features

This page provides a public feature overview of the WanWay GS22 and how its documented capabilities map to use inside Plaspy. It describes the practical functions you can expect when using the GS22 with Plaspy for vehicle tracking, monitoring, and basic diagnostics.

Exact feature availability and behavior can vary by firmware version, hardware revision, country variant, and how the unit is installed. For device specific parameters and the latest technical details consult the manufacturer documentation while using this page as a compatibility and feature reference for Plaspy users.

## Feature Overview

The WanWay GS22 is a compact 4G OBD II vehicle tracker designed for location tracking and vehicle monitoring. It pairs core tracking functions with a small internal battery and security features to support continuous reporting and tamper detection.

- 4G vehicle tracking for near real time position updates
- OBD II form factor for easy connection to vehicle diagnostic port
- Built in rechargeable battery to continue sending position data after external power is removed
- Disassembly alarm to notify when the device is tampered with or removed
- User defined electronic fences with trace playback for reviewing routes
- Wifi hotspot support as noted by the manufacturer

## Core Features of WanWay - GS22

- 4G connectivity for higher speed location reporting and compatibility with modern networks
- OBD II interface for installation on most passenger vehicles
- Internal 140mAh rechargeable battery for backup position reporting when external power is cut
- Disassembly alarm that signals device removal or tampering
- Real time tracking to monitor current vehicle location
- Trace playback to review historical routes on a timeline
- Malfunction diagnostics reported from the device through the vehicle interface
- User defined geo fence functionality for area based monitoring

## How These Features Work with Plaspy

Plaspy can receive and display the GS22 feature data to provide visibility into vehicle location, events, and basic diagnostics. Plaspy automatically detects supported tracker protocols and ingests position and event data into the platform for monitoring and review.

- Real time positions from the GS22 appear on Plaspy maps for live monitoring
- Trace playback of recorded routes is available in Plaspy to review historical movement
- Geo fence definitions created in Plaspy or on device result in fence events and location based logs
- Disassembly alarm events and basic diagnostic reports are visible in the device event history
- Backup positioning from the internal battery is reflected as continued updates when external power is removed
- Devices compatible with Plaspy can be configured to report to Plaspy endpoints and the platform will handle protocol detection and ingestion

## Typical Use Cases

- Continuous vehicle monitoring for company cars and fleets
- Online car rental and short term rental tracking to monitor vehicle usage
- Car rental operations for location history and route playback
- Remote tracking to assist in vehicle recovery after theft or unauthorized movement
- Monitoring diagnostic events and simple malfunction indicators for operational oversight
- Security use where tamper detection and battery backup are useful for continuity of reporting

## Feature Availability Notes

- Firmware updates can enable, modify, or disable specific behaviors such as diagnostics reporting and fence handling
- Hardware revisions and regional product variants may change supported cellular bands or accessory compatibility
- OBD II installation depends on vehicle compatibility and proper access to the diagnostic port
- WiFi hotspot support and its capabilities may vary by firmware and regulatory region
- Battery backup duration depends on battery condition and device configuration

## Why Use Plaspy with These Features

Using Plaspy with the WanWay GS22 gives organizations a centralized way to view location, event history, and device reported diagnostics from their vehicles. The combination of OBD II access, backup battery reporting, tamper alerts, and trace playback makes the GS22 a practical option for operations that need visibility into vehicle movement and basic operational state.
