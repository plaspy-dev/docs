# WanWay - EV02

![EV02](./tracker.webp)

The EV02 from an established tracker family is a compact 2G GPS tracker designed for vehicle anti-theft protection and efficient fleet management. Plaspy compatible out of the box, the EV02 pairs its high-sensitivity GPS positioning with robust power handling and a discreet form factor to deliver reliable real-time tracking for motorcycles, cars, light commercial vehicles, and electric vehicles.

Built for quick installation and concealed mounting, EV02 supports active security controls such as remote cut-off \(petrol or electrical\), cut-wire and ACC detection, and vibration alarms. When integrated with the Plaspy platform, EV02 becomes a practical tool for telemetry, ignition monitoring, immobilizer actions, and responsive alerting across mixed fleets — enabling operators to detect theft, intervene remotely, and keep better operational oversight.

## Key Highlights

- Plaspy compatible 2G GPS tracker that provides consistent real-time tracking and alerting for vehicles in 2G-covered areas.
- Compact design with a small 55 mAh backup battery for concealed installation in motorcycles, cars, electric vehicles, and light commercial assets.
- Wide operating voltage \(9–90 V\) supports a broad range of vehicle power systems, simplifying fleet deployments across mixed vehicle types.
- Active anti-theft features including remote cut-off of petrol or electricity and immobilizer-style control to halt a vehicle when required.
- Cut-wire/ACC detection and vibration alarm for rapid tamper and movement alerts to Plaspy, improving response times for theft or unauthorized use.
- High-sensitivity GPS chip for fast online positioning and dependable geolocation data suitable for fleet telemetry and route oversight.
- Simple 4-pin interface allows fast wiring and installation, reducing time on-site for technicians and installers.

## How It Works with Plaspy

When paired with Plaspy, the EV02 forwards location, event, and status data to the platform in near real time so fleet managers and security operators can monitor assets, receive alerts, and execute remote controls. Plaspy-compatible integration ensures the EV02’s telemetry and security events are displayed in dashboards, included in geofence rules, and available for historical reporting.

- Real-time location and telemetry updates — GPS coordinates and movement state streamed to Plaspy for live tracking and historical playback.
- Ignition and cut-wire/ACC status — ACC detection reports ignition state to Plaspy for trip logging and unauthorized-use alerts.
- Vibration and tamper alarms — immediate notifications through Plaspy when physical tampering or unexpected motion is detected.
- Remote immobilizer / cut-off — execute remote petrol or electrical cut-off commands via Plaspy to stop a vehicle when supported by installation wiring.
- Fuel monitoring and additional telemetry — EV02 supplies core vehicle telemetry to Plaspy; fuel monitoring is available in Plaspy when vehicle fuel sensors or integrations are present.
