# WanWay - EV02 Features

This page provides a public feature summary for the WanWay EV02 tracker and how those capabilities are used with the Plaspy platform. It is written to help fleet and security operators understand the practical functions they can expect when deploying the EV02 with Plaspy for vehicle tracking, tamper detection, and remote immobilizer actions.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation wiring, and the manufacturer's implementation choices. For device specific details, wiring diagrams, and the latest firmware notes consult the official WanWay documentation and release notes.

## Feature Overview

The WanWay EV02 is a compact 2G vehicle tracker designed for concealed installation and practical anti-theft and fleet management tasks. When connected to Plaspy, the EV02 forwards location and event data so operators can monitor assets and receive alerts in near real time.

- Real-time GPS positioning for live tracking and historical playback in Plaspy.
- Active anti-theft controls including remote cut-off for petrol or electrical systems when wired accordingly.
- Tamper detection through cut-wire and ACC status monitoring to indicate unauthorized access or ignition state.
- Vibration alarm for immediate notification of physical tampering or unexpected motion.
- Wide operating voltage range to support mixed fleets with different vehicle power systems.
- Compact form factor and small backup battery for discreet, concealed mounting.

## Core Features of WanWay - EV02

- 2G GSM connectivity for position and event transmission in 2G-covered regions.
- High-sensitivity GPS positioning for dependable location fixes and route tracking.
- Remote cut-off / immobilizer control to halt vehicle operation when installed with appropriate wiring.
- ACC detection for reporting ignition state and supporting trip logging.
- Cut-wire detection to surface tampering attempts to the platform.
- Vibration alarm for physical movement alerts.
- Wide operating voltage tolerance to simplify deployment across varied vehicles.
- Compact design and small backup battery for concealed installations.

## How These Features Work with Plaspy

When integrated with Plaspy, EV02 events and location updates are displayed in dashboards and available for alerting and reporting. Plaspy automatically detects many supported tracker protocols so setup is typically straightforward for standard EV02 deployments.

- Live location updates appear on Plaspy maps and can be reviewed in historical playback.
- Ignition and ACC status are recorded for trip segmentation, utilization reports, and unauthorized-use alerts.
- Tamper and vibration alarms generate immediate notifications inside Plaspy for rapid operator response.
- Remote immobilizer or cut-off actions can be executed from the platform where the installation supports remote control.
- Device events and status are preserved for audit trails, reporting, and operational analysis.

## Typical Use Cases

- Fleet anti-theft monitoring with rapid immobilization options for stolen or misused vehicles.
- Mixed-vehicle fleets where a broad operating voltage simplifies rollout across motorcycles, cars, and light commercial vehicles.
- Electric vehicle security using concealed installation, vibration alarms, and remote cut-off wiring.
- Trip logging and route oversight using GPS position together with ACC state for accurate trip boundaries.
- Concealed tracker installations to improve recovery chances after theft or tampering.
- Small vehicle and motorcycle tracking where compact form factor is important.

## Feature Availability Notes

- Firmware and hardware revisions can enable or change specific behaviors; not all units may expose every listed function.
- Remote cut-off and immobilizer features require correct wiring and may depend on vehicle electrical configuration and installer setup.
- 2G connectivity depends on local network availability and regional operator support.
- Some telemetry or integrations (for example third party sensors) depend on additional wiring or vehicle-installed sensors and are not included by default.
- Always refer to WanWay manufacturer documentation for the most current technical specifications and installation instructions.
