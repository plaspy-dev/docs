# WanWay - GP10 Features

This page provides a public, feature-oriented overview of the WanWay GP10 and how its publicly documented capabilities can be used with Plaspy for tracking and operational visibility. It is intended to help users understand the practical features of the GP10 and what to expect when integrating the device with Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, SIM and network conditions, installation method, and how the manufacturer implements features. For the most current device-specific details consult WanWay documentation and firmware notes.

## Feature Overview

The GP10 is a compact personal tracker designed for continuous location awareness and basic event notifications. Its size and battery capacity make it suitable for portable use while providing features aimed at personal safety and asset tracking.

- Real time tracking for continuous location visibility when the device reports position updates.
- User defined geo fence support to notify when the tracker enters or exits defined areas.
- SMS notification capability for alerts such as low battery, geo fence breaches, and SOS events.
- Remote voice monitoring capability as described by the manufacturer for listening to local audio.
- Built in 800mAh battery to provide extended use between charges for portable deployments.

## Core Features of WanWay - GP10

- Real time position reporting for live location monitoring.
- Geo fence event reporting that supports entry and exit alerts.
- SMS alerts for selected device events including low battery and SOS.
- Remote voice monitoring initiated through the device.
- Compact form factor suitable for personal, pet, or portable asset use.
- Built in 800mAh battery for sustained operation between charges.

## How These Features Work with Plaspy

Plaspy provides a platform to receive, display, and manage the event and location data the GP10 reports. When the GP10 is used with Plaspy, its device-reported updates and events become visible in the platform for monitoring and historical review.

- Real time location updates from the GP10 appear on Plaspy maps for live tracking and route inspection.
- Geo fence events reported by the device can be shown as alerts or events inside Plaspy for rapid attention.
- SMS alert events generated by the tracker can be reflected in Plaspy as device status or event records when the device reports them to the platform.
- Device activity and event history from the GP10 is available in Plaspy for audit and operational review.
- Remote voice monitoring is a device feature; Plaspy can display related event logs or status updates when the device reports them.

## Typical Use Cases

- Keeping track of a family member or individual for personal safety and location visibility.
- Monitoring portable assets or luggage during transit.
- Tracking pets when the device is attached in an appropriate and safe manner.
- Receiving immediate alerts for geo fence breaches around home, school, or work areas.
- Using SMS and event reporting as a secondary notification channel alongside platform alerts.
- Maintaining historical location records for simple audit or timeline review.

## Feature Availability Notes

- Feature behavior can differ between firmware versions; firmware updates may add or change functionality.
- Hardware revisions or regional variants of the GP10 may alter available features or radio behavior.
- SMS notifications require a working SIM and mobile network coverage; message delivery depends on the network operator.
- Remote voice monitoring behavior and access may be subject to manufacturer settings and local regulations; verify lawful use and proper configuration.
- Plaspy visibility of events depends on the device sending those events; consult both Plaspy and WanWay documentation if events do not appear as expected.

## Why Use Plaspy with These Features

Using the WanWay GP10 with Plaspy gives organizations and individual users a straightforward way to consolidate device location and event data into a single monitoring environment. Plaspy helps surface real time location, geo fence events, and device-reported alerts so teams can maintain situational awareness and review device history for operational decisions.
