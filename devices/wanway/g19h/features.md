# WanWay - G19H Features

This page provides a public feature overview for the WanWay G19H tracker and explains how those capabilities are presented and used within Plaspy. It is intended to help operators and technical evaluators understand the device functions that are relevant when the G19H is integrated into Plaspy for fleet and asset monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. For device specific details and the latest technical information consult WanWay documentation and release notes before deploying devices at scale.

## Feature Overview

The G19H is a compact, rugged vehicle tracker focused on reliable location reporting and core security controls. It combines GPS positioning and cellular connectivity in an IP67 housing intended for exposed vehicle installations, and integrates with Plaspy to deliver location, state, and event visibility.

- Real time GPS tracking for live position visibility in Plaspy dashboards and maps
- IP67 waterproofing for durable operation in heavy rain or vehicle wading
- Four wire installation with ACC input for reporting ignition status
- Vibration and tamper alarms to detect potential unauthorized movement or interference
- Remote cut off immobilizer output to allow remote disablement of petrol or electrical supply
- Designed for operation on 2G GSM networks with a compact form factor and built in antenna

## Core Features of WanWay - G19H

- GPS positioning for continuous location reporting
- Integrated GSM cellular connectivity for telemetry uplink
- IP67 rated waterproof enclosure for weather resistant installations
- Four wire interface including ACC detection for ignition state monitoring
- Vibration alarm and tamper alert support for anti theft monitoring
- Remote cut off immobilizer output to support remote disablement workflows
- Compact design intended for discreet mounting within vehicle installations

## How These Features Work with Plaspy

When connected and configured, the G19H reports location and telemetry to Plaspy where those signals become actionable for operations and security teams. Plaspy ingests device updates, displays positions on maps, and exposes device events for alerting and reporting.

- Live location updates and route history available in Plaspy for tracking and replay
- ACC ignition state forwarded to Plaspy to support event based monitoring and operational rules
- Vibration and tamper events appear as alerts in Plaspy so operators can investigate suspicious activity
- Remote immobilizer commands can be issued from management workflows and tracked in Plaspy event history
- Plaspy automatically detects compatible tracker protocols and accepts device reports for consistent device onboarding
- Devices compatible with Plaspy may be configured to report to the Plaspy server domain for seamless integration

## Typical Use Cases

- Fleet operations monitoring with live position, ignition status, and route history
- Anti theft workflows that use tamper and vibration alerts combined with remote immobilizer actions
- Vehicle security and recovery where continuous tracking helps locate assets after unauthorized movement
- Remote operational control to enforce off hour access rules using ACC status and immobilizer outputs
- Deployments in wet or exposed environments where IP67 durability is required
- Discreet installations where a compact tracker and built in antenna reduce visual exposure

## Feature Availability Notes

- Firmware differences can change available features and behavior for alarms, reporting intervals, and remote control functions
- Hardware revisions and regional variants may affect supported 2G bands and connector wiring
- Installation details such as wiring quality and placement influence ACC detection and immobilizer reliability
- 2G network availability varies by region and can affect cellular connectivity and data delivery
- Always verify the exact feature set and wiring instructions in the manufacturer documentation before installation

## Why Use Plaspy with These Features

Combining the WanWay G19H with Plaspy provides a straightforward path to add reliable location awareness, ignition monitoring, and vehicle security controls into a single monitoring and reporting platform. Plaspy collects telemetry and events from the tracker, visualizes live positions on maps, and helps teams automate alerts and operational responses without requiring bespoke integrations.
