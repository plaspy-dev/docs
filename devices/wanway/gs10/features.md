# WanWay - GS10 Features

This page provides a public feature overview for the WanWay GS10 and explains how its capabilities relate to use with Plaspy. It summarizes the GS10's practical functions such as 4G communications, GPS and BDS satellite navigation, real time tracking, ACC detection, remote cut off capability, and on device backup power, with an emphasis on how those features appear in Plaspy for vehicle monitoring and operational oversight.

Exact feature availability depends on the carrier firmware, hardware revision, how the device is installed, and the manufacturer's implementation. Where the device description lists a capability, this page describes the typical behavior and operational value, but installation choices and firmware versions can change how specific functions behave in the field.

## Feature Overview

The GS10 is a compact vehicle GPS tracker designed to provide continuous position reporting and basic vehicle control features suitable for fleet and individual vehicle monitoring. It blends satellite navigation with cellular communications to give near real time visibility and supports remote immobilization where the device and installation provide that capability.

- Real time GPS and BDS satellite position reporting for live tracking and history
- 4G full netcom cellular connectivity for reliable data reporting in supported regions
- Remote cut off of petrol or electricity when the vehicle wiring and firmware support the function
- ACC detection to indicate vehicle ignition on or off for driver and usage monitoring
- Compact form factor and light weight for discreet installation
- Built in backup battery to provide limited reporting if main power is removed

## Core Features of WanWay - GS10

- 4G full netcom wireless communication for cellular data reporting
- GPS and BDS satellite navigation for location fixes
- Real time tracking with periodic position updates
- Remote cut off capability to interrupt fuel or power supply when supported
- ACC detection for ignition state reporting
- Compact dimensions and lightweight design for easy installation
- Wide input voltage range to suit a range of vehicle electrical systems
- Built in backup battery for limited operation after main power loss

## How These Features Work with Plaspy

Plaspy ingests the location and event data the GS10 transmits and presents it in vehicle lists, maps, and event timelines so operators can monitor activity and respond to events. Plaspy automatically detects supported tracker protocols and maps device reports to the platform interface for visibility and operations.

- Live location and recent position history appear on Plaspy maps for route reconstruction and monitoring
- ACC on and off events are shown in Plaspy as ignition state changes to support driver use and scheduling analysis
- Where remote cut off is enabled by device firmware and the physical installation, Plaspy can surface the state and related events and may be used to coordinate immobilization with local procedures
- Backup battery events and mains power loss are viewable as device power events so offline or tampered device situations are easier to detect
- Plaspy captures and stores device reports as events and telemetry for audit and operational review

## Typical Use Cases

- Insurance telematics and anti theft monitoring with remote immobilization options
- Enterprise fleet tracking for routing, utilization, and basic driver behavior oversight
- Rental vehicle monitoring to protect assets and verify usage
- Taxi and passenger vehicle location reporting for dispatch and safety oversight
- Electric new energy vehicle installations where wide voltage input and backup power help compatibility
- Auto manufacturer or dealer installations for demo vehicles and post sale monitoring

## Feature Availability Notes

- Firmware versions and carrier configurations may add, change, or restrict features and command sets
- Hardware revisions and optional wiring determine whether ACC detection and remote cut off behave as expected after installation
- Regional cellular band support affects 4G connectivity depending on local networks and carrier compatibility
- Backup battery runtime depends on battery condition and reported device settings
- Manufacturers may offer configuration options that enable or disable remote commands for safety or regulatory reasons
