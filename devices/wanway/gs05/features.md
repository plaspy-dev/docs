# WanWay - GS05 Features

This page summarizes the public feature context for using the WanWay GS05 tracker with Plaspy. It focuses on user-facing capabilities, what the device reports into Plaspy, and the practical value you can expect when the GS05 is paired with Plaspy for vehicle tracking and fleet oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation wiring, and manufacturer implementation. Use this page as a feature-level reference and consult the device manufacturer for the most current, device specific technical details.

## Feature Overview

The GS05 is a compact 3G GPS tracker designed for straightforward vehicle tracking and fleet management, and it is compatible with Plaspy for real-time visibility and reporting. It combines GPS positioning, 3G GSM connectivity, on-board sensors, and an optional microphone input to provide location and event data useful for operational monitoring.

- Real-time GPS location reporting for vehicle position awareness
- 3G GSM connectivity for cellular data uplink to Plaspy
- Built-in antenna and compact form factor for discreet vehicle installation
- 11PIN connector for flexible power and sensor wiring during installation
- Optional microphone input for listen-in capability where legally permitted

## Core Features of WanWay - GS05

- GPS positioning for regular location updates and route tracking
- 3G GSM network connectivity for sending position and sensor data
- Built-in antenna to simplify placement and signal reception
- 11PIN connector to support vehicle power and external sensor connections
- Multiple onboard sensors for telemetry and event reporting
- Optional built-in microphone support when a microphone is fitted
- Internal backup battery for short-term reporting during power interruptions

## How These Features Work with Plaspy

Plaspy ingests the GS05 position and sensor messages and presents them in live maps, history playback, and telemetry summaries. Plaspy is designed to detect common device protocols automatically, letting the tracker feed position and event data into the platform with minimal manual protocol configuration.

- Live location updates appear on Plaspy maps for real-time tracking
- Historical routes and playback let operators review past movements
- Sensor and event messages are shown in Plaspy dashboards and reports
- Optional audio monitoring is surfaced only where microphone hardware is present and permitted
- Alerts and notifications can be configured in Plaspy based on incoming events from the device

## Typical Use Cases

- Fleet route visibility and dispatch support for small to medium vehicle fleets
- Anti-theft awareness through continuous position monitoring and alerts
- Trip logging and historical playback for driver oversight and incident review
- Situational audio monitoring when a microphone is connected and allowed by law
- Compact installations where discreet tracking hardware is required

## Feature Availability Notes

- Firmware differences can change available messages, report frequency, and sensor behavior
- Hardware revisions or regional variants may affect cellular bands and connector pinouts
- Installation wiring determines which vehicle signals (for example ignition input if wired) are available to the tracker
- Microphone listen-in requires that a microphone is connected and that local laws permit audio monitoring
- Verify specific capabilities, connector pin assignments, and the latest firmware notes with the manufacturer

## Why Use Plaspy with These Features

Pairing the GS05 with Plaspy gives organizations a practical way to turn GPS and sensor data into operational insight. Plaspy centralizes live location, route history, and incoming events so fleet managers and vehicle owners can monitor assets from smartphones and web dashboards, configure alerts, and generate reports for operational decisions.
