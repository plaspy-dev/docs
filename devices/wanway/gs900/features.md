# WanWay - GS900 Features

This page provides a public, features oriented summary of the WanWay GS900 and how its capabilities are used with Plaspy for vehicle monitoring. It focuses on the practical, non sensitive aspects of the tracker that fleet managers and vehicle owners commonly ask about when integrating a GS900 into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and how the manufacturer implements each function. For device specific configuration, detailed parameters, or the latest firmware behavior consult the official WanWay documentation and your device supplier.

## Feature Overview

The GS900 is a vehicle mounted GPS tracker designed for professional tracking and security workflows. It combines cellular connectivity with dual satellite navigation and vehicle inputs to provide live tracking, event alerts, and control actions useful for fleet operations and theft mitigation.

- 4G full Netcom cellular connectivity for continuous real time position reporting and event delivery
- Dual GNSS support with GPS and BDS for improved position fixing in varied environments
- ACC detection to report ignition state for route and usage visibility
- Disassemble tamper alarm and overspeed alerts to support security and safety monitoring
- Mileage statistics to support maintenance scheduling and usage based billing
- Remote cut off of petrol or electricity as an immobilizer capability for anti theft response

## Core Features of WanWay - GS900

- Real time vehicle tracking via cellular network for live location updates
- GPS and BDS satellite navigation for reliable position fixes
- ACC detection input for ignition on off status reporting
- Disassemble tamper alarm to detect tampering or unauthorized removal
- Overspeed alarm to notify when configured speed thresholds are exceeded
- Mileage accumulation and reporting for service planning and billing workflows
- Remote cut off control to immobilize vehicle power or fuel where supported by installation
- Event reporting that sends alarms and status changes to a connected platform

## How These Features Work with Plaspy

When connected to Plaspy, the GS900 feeds location and event data into Plaspy dashboards and reporting tools so operators can monitor vehicles in real time and review historical activity. Plaspy receives the tracker telemetry and presents it as map markers, alerts, and reports suitable for operations and security teams.

- Live location and route playback appear in Plaspy for dispatch and review
- Ignition status and mileage are visible in Plaspy reports to support maintenance windows and usage analytics
- Tamper and overspeed alarms generate notifications in Plaspy to prompt rapid response
- Remote immobilizer actions can be issued from Plaspy when the feature is enabled and wiring supports the control circuit
- Historical event logs and exported reports help with incident investigation and operational analysis

## Typical Use Cases

- Fleet anti theft procedures using tamper alerts and remote immobilizer control
- Driver safety and compliance monitoring with overspeed alerts and event histories
- Mileage based maintenance scheduling and billing for rental or delivery fleets
- Real time dispatch and routing using live location and route playback
- Security monitoring for high value or high risk vehicles requiring tamper detection
- Centralized operations where Plaspy consolidates vehicle telemetry and alerts

## Feature Availability Notes

- Some features are dependent on device firmware and may vary by firmware release or regional firmware variant
- Hardware revisions and regional cellular variants can affect supported cellular bands and performance
- Installation quality and how the tracker is wired into the vehicle influence availability of ACC detection and remote cut off functions
- Manufacturer configuration options and provisioning determine which alarms and remote controls are enabled
- Always verify the exact feature set for a given GS900 unit with WanWay product documentation and your supplier

Plaspy translates the tracker events into visual alerts, reports, and historical playback that help operations teams reduce response times, streamline maintenance planning, and maintain security oversight across fleets.
