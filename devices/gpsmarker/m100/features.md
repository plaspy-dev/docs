# GPSMarker - M100 Features

This page provides a public, non-sensitive feature overview of the GPSMarker M100 and how its capabilities relate to using the device with Plaspy. It summarizes the main functions you can expect from the tracker and highlights practical uses when the M100 is connected to a fleet or asset monitoring platform such as Plaspy.

Exact feature availability can vary by firmware version, hardware revision, installation type, and how the manufacturer configures each unit. Use this page for general guidance on capabilities and how they appear in Plaspy, and consult the manufacturer documentation for the most current device specific details.

## Feature Overview

The GPSMarker M100 is positioned as a durable and accurate tracker for vehicles and valuable assets. Its core strengths are precise location reporting, extended battery life, and a set of sensors designed for security and environmental monitoring. When integrated with Plaspy, these capabilities provide visibility and event awareness across fleets and individual assets.

- High precision GPS positioning enabled by a 72 channel receiver for reliable coordinate fixes
- Long battery life rated up to two years for reduced maintenance in low-power tracking scenarios
- Movement detection, crash detection, and revolution sensing to report motion and impact events
- SOS panic button and temperature monitoring for safety and environmental awareness
- Relay outputs for external device control and management where available
- Geofencing and an open GPRS protocol to support integration with monitoring backends

## Core Features of GPSMarker - M100

- 72 channel GPS receiver for improved satellite reception and location stability
- Long life battery capable of extended deployment without frequent replacement
- Movement detection sensor to detect start of motion and trigger alerts
- Crash detection with event reporting that can include coordinates to registered contacts
- Revolution or shock sensing to monitor handling and transport conditions
- On device panic SOS button for immediate alerting
- Temperature sensor for environmental monitoring near the device
- Relay control capability to interface with external devices when required

## How These Features Work with Plaspy

Plaspy can ingest and present the M100's location and event data to provide centralized visibility and monitoring. The platform adapts to incoming device messages and surfaces actionable information for operations teams, with compatibility designed to make setup straightforward.

- Real time and historical location tracking of the M100 shown on Plaspy maps and timelines
- Movement, crash, and shock events appear as alerts or events in Plaspy dashboards for quick review
- SOS alerts and configured notifications can be routed through Plaspy alerting channels
- Temperature readings reported by the device can be available as telemetry points in Plaspy views
- Geofence events generated by the M100 are reflected in Plaspy to signal boundary crossings
- Relay status and control possibilities can be represented in Plaspy where the backend integration exposes outputs

## Typical Use Cases

- Vehicle security and anti-theft monitoring with movement and crash alerts
- Long term asset tracking where extended battery life reduces maintenance
- Cargo handling visibility by monitoring shock and revolution sensor events
- Environmental monitoring for temperature sensitive loads
- Remote SOS alerting for lone workers or high value assets
- Integration into existing monitoring systems using the device open protocol

## Feature Availability Notes

- Feature presence may depend on device firmware; some units may ship with different firmware feature sets
- Hardware revisions or regional variants can affect which sensors or interfaces are installed
- Installation method and wiring at the time of fitting may enable or disable certain functions such as relay control
- Manufacturer provided firmware upgrades are available and can change behavior or add features
- Always verify the exact capabilities of a specific unit against the device serial, firmware version, and the manufacturer documentation
