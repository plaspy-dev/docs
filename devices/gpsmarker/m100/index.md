# GPSMarker - M100

<div className="device-logo">
![M100](./logo.jpg)
</div>

The GPSMarker M100 is a compact and reliable GPS tracker designed for vehicle and asset protection. It uses a high sensitivity 72 channel GPS receiver to deliver accurate coordinates and consistent position updates. The M100 also includes multiple onboard sensors such as movement detection, crash detection, a revolution sensor for shock monitoring, a temperature sensor, and a panic SOS button to support a wide range of monitoring needs.

Because the M100 supports an open GPRS protocol and offers long battery life and field upgradability, it is a practical choice for integration with monitoring platforms. The M100 is compatible with Plaspy, allowing organizations to consolidate location data, alerts, and sensor events in a single fleet management interface for improved operational oversight.

## Key Highlights

- High sensitivity 72 channel GPS receiver for accurate location reporting
- Extended battery life up to two years for low maintenance deployments
- Multiple security and telematics sensors including movement, crash, shock, temperature, and SOS
- Free firmware upgrades via cable to keep device features up to date
- Relay control for managing external devices or actuators
- Open GPRS protocol for straightforward integration with third party monitoring systems

## How It Works with Plaspy

When used with Plaspy, the GPSMarker M100 feeds location and sensor events into Plaspy's fleet monitoring environment so teams can monitor assets from a single platform. Plaspy can surface real time visibility and historical reporting based on the M100 data, enabling operational and security workflows.

- Centralized live location tracking and position history in Plaspy dashboards
- Sensor driven alerts delivered through Plaspy for movement start, crash events, and SOS triggers
- Geofence notifications to monitor entries and exits of virtual zones set in Plaspy
- Temperature and shock event monitoring to help protect sensitive cargo and validate handling
- Use of relay control events to reflect remote device switching or to trigger workflows in Plaspy

## Typical Use Cases

- Fleet vehicle location tracking and route oversight
- Trailer and container security with movement and shock monitoring
- Cargo temperature monitoring during transport
- Personal safety or asset panic alerts using the SOS button
- Equipment and asset tracking for rental or long term deployments
