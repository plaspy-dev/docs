# GPSMarker - M80 Features

This page describes the publicly available feature context for the GPSMarker M80 and how its capabilities are used with Plaspy for tracking and monitoring. It focuses on user-facing functions, deployment considerations, and the practical value of the M80 when reporting into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and how the manufacturer implements specific functions. For device-level configuration and the most current technical details, consult the manufacturer documentation and release notes.

## Feature Overview

The GPSMarker M80 is a compact tracker designed for long term deployments and low ongoing costs. It emphasizes reliable satellite positioning, long battery life, and a set of onboard sensors that report events useful for asset and vehicle monitoring.

- No recurring subscription requirement for the device itself reducing ongoing costs beyond SMS and GPRS traffic
- 99 channel GPS and GLONASS receiver with AGNNS to improve time to first fix and coordinate reliability
- Sealed enclosure with magnets for easy and secure mounting and discreet installation
- Included micro SIM support and a tariff optimized for online monitoring systems so tracking can start quickly
- Firmware updates available over GPRS so device software can be refreshed remotely
- Long battery life options including weekly wake modes and low battery notification to support extended deployments

## Core Features of GPSMarker - M80

- 99 channel GPS/GLONASS positioning receiver for better satellite visibility
- AGNNS support to assist satellite fixes and improve initial positioning performance
- No subscription fee for the device itself customers pay for outgoing SMS and GPRS usage
- Sealed magnetic enclosure for straightforward mounting and protection in many environments
- Micro SIM card support and compatibility with monitoring-optimized tariff plans
- Remote firmware update capability via GPRS to receive manufacturer updates
- Long standby battery life with configurable wake intervals to extend operating time
- Onboard sensors including movement start detection, crash impact detection, revolution monitoring, panic SOS button, and a temperature sensor

## How These Features Work with Plaspy

Plaspy receives and processes device reports to provide centralized visibility, historical context, and event-driven monitoring. The M80 can be configured to report over standard mobile data or SMS channels into Plaspy, and Plaspy automatically detects compatible tracker protocols and integrates the data for display and analysis.

- Real time and historical location tracking in Plaspy so you can view routes and last known positions
- Sensor events such as movement start, crash alerts, revolution activity, SOS presses, and temperature readings appear as events or status fields in Plaspy
- Battery level reporting and low battery notifications help with maintenance planning and reduce unexpected downtime
- Devices can be pointed to Plaspy infrastructure (for example d.plaspy.com) and may be configured to use UDP or TCP connections that Plaspy accepts on the standard port
- Remote firmware updates from the manufacturer do not require Plaspy intervention but help keep deployed devices up to date while Plaspy continues to collect device data

## Typical Use Cases

- Long term asset monitoring where low ongoing costs and long battery life are important
- Vehicle tracking that benefits from reliable satellite reception and impact detection
- Discreet or temporary installations using the magnetic sealed enclosure
- Monitoring temperature-sensitive cargo or environments with the onboard temperature sensor
- Alerting and incident review using crash detection and SOS button events
- Remote deployments that require occasional firmware updates over the network

## Feature Availability Notes

- Feature availability can depend on the device firmware version and manufacturer firmware updates
- Hardware revisions or regional variants of the M80 may expose different sensor sets or power options
- Installation choices such as mounting location and SIM/tariff selection affect signal quality, data delivery, and costs
- Some functions such as remote firmware updates require active GPRS connectivity and a compatible tariff

## Why Use Plaspy with These Features

Using the GPSMarker M80 with Plaspy provides a consolidated view of location, sensor events, and device status that helps operations teams monitor assets and respond to incidents. The combination of long battery life, discrete mounting options, and event sensors makes the M80 suitable for deployments where maintenance intervals are long and reliable reporting is required.
