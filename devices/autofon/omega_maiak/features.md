# AutoFon - Омега-Маяк + Features

This page summarizes the public feature context for using the AutoFon Омега-Маяк + tracker with Plaspy. It focuses on practical, user-facing capabilities that matter when deploying this compact autonomous GPS/GLONASS beacon together with Plaspy for monitoring, alerts, and historical reporting.

Exact feature availability can vary by firmware version, hardware revision, installed configuration and manufacturer implementation. Installation choices and regional device variants may also affect which functions are present and how they behave in a live Plaspy deployment.

## Feature Overview

The Омега-Маяк + is a small, autonomous GPS/GLONASS tracker designed for discreet, long‑term asset monitoring. It reports position and events over cellular GPRS and can notify owner numbers via SMS. Its design emphasizes long standby autonomy, hidden installation, and presence features that are useful for recovery and proximity checks.

- GPS and GLONASS position fixes for reliable location tracking in Plaspy
- GPRS uplink for server reporting plus optional SMS alerts to owner numbers
- Compact IP54 enclosure and small form factor for hidden installations
- Long standby battery operation suitable for long term beacon modes
- Integrated accelerometer for movement and crash related event detection
- BLE presence features for owner proximity checks and local context

## Core Features of AutoFon - Омега-Маяк +

- GPS and GLONASS positioning for regular location reporting
- GPRS reporting to a monitoring server with SMS fallback to owner numbers
- Rechargeable internal battery optimized for long standby operation in beacon modes
- Compact, semi sealed IP54 enclosure sized for discreet installation
- Integrated digital accelerometer for movement, rollover and shock events
- BLE module for owner smartphone proximity checks and local ranging
- Built in microphone and SOS button for emergency alerting where supported
- Black box storage and retransmission of unsent packets for improved data reliability

## How These Features Work with Plaspy

When used with Plaspy, the Омега-Маяк + transmits standard position, event and telemetry reports that Plaspy parses to provide live visibility and historical context. Plaspy can receive movement events, SOS signals and battery telemetry and surface them in maps, alerts and reports while supporting remote device commands where the device and server-side setup permit.

- Real‑time location and telemetry visible on Plaspy maps and dashboards
- Movement and crash alerts derived from the accelerometer shown as actionable events
- SOS button events and owner SMS alerts reflected in Plaspy alert workflows
- Battery status and telemetry available in device detail views for operational monitoring
- BLE presence flags and proximity indicators represented as contextual device state
- Plaspy can manage device configuration and server side commands when the tracker supports remote management

## Typical Use Cases

- Long‑term monitoring and recovery of discreetly installed vehicle assets where low maintenance is required
- Anti‑theft protection for motorcycles, bicycles and small boats using movement alerts and tracking
- Protection of portable equipment and cargo when external wiring is impractical
- Lone worker or personal safety scenarios using the SOS button and remote alerting
- Short range owner proximity checks and local context via BLE presence
