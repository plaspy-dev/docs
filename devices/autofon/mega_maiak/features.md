## Feature Overview

The AutoFon Мега-Маяк+ is a compact, rugged tracking device that combines satellite positioning, local sensors, and network reporting to provide continuous location and event awareness. It is designed for both mobile and stationary applications and supports redundant communications and buffered reporting for connection interruptions.

- Combined GLONASS and GPS navigation with A GPS assistance for improved sensitivity and faster fixes
- Movement and impact sensing with adjustable sensitivity for detecting starts, impacts, accidents, overturns, and falls
- Dual SIM support to improve cellular availability and fallback between operators
- Local black box buffer capable of storing up to 15,000 GPRS packets for later upload when connectivity returns
- Durable IP67 sealed housing suited for demanding environmental conditions and discreet installations
- Onboard features such as BLE, Wi‑Fi location support, microphone for remote listening, SOS button, and photo sensor for tamper detection

## Core Features of AutoFon - Мега-Маяк+

- GLONASS plus GPS positioning with A GPS assistance to improve fix performance in challenging environments
- Digital accelerometer and sensor suite for movement detection, impacts, crash sensor mode, and configurable sensitivity
- Dual SIM card support to maintain connectivity across different mobile operators
- Local black box memory storing large amounts of GPRS packets for buffered reporting
- Remote firmware update capability via GPRS to apply manufacturer updates without physical access
- IP67 sealed enclosure for water and dust resistance suitable for vehicle and portable use
- Built in microphone and SOS micro-button for additional situational awareness and alerting
- Interfaces for configuration and charging via micro USB and a built in rechargeable battery

## How These Features Work with Plaspy

Plaspy ingests location reports and event messages from compatible trackers and presents them as map positions, timeline events, and alerts. When you register an AutoFon Мега-Маяк+ with Plaspy, the tracker’s transmissions become visible in the Plaspy interface so operators can monitor location history and sensor-triggered events.

- Real time and historical positions appear as map markers and track history inside Plaspy
- Movement and impact events map to timeline entries or configurable alerts for operator awareness
- Buffered black box packets allow the device to upload stored positions to Plaspy after connectivity resumes, preserving history
- Dual SIM and GPRS reporting improve the likelihood that critical events are delivered into Plaspy even when one operator is unavailable
- BLE and Wi‑Fi location hints or presence indicators can be reflected as additional state information where the device reports them
- Plaspy automatically detects common tracker protocols for supported devices, simplifying initial integration and reducing setup complexity
