# AutoFon - Омега Features

This page describes the public feature context for using the AutoFon Омега tracker with Plaspy. It summarizes the tracker capabilities, how those capabilities are typically reflected inside Plaspy, and practical operational value for asset tracking, anti theft protection, and remote monitoring.

Exact feature availability and behavior may vary by device firmware version, hardware revision, regional variant and installation method. For precise, device specific technical details and the latest firmware behavior consult the official manufacturer documentation and release notes.

## Feature Overview

The AutoFon Омега is a compact, Plaspy compatible GPS tracker designed for long autonomous operation and discreet installation. It combines satellite navigation, cellular reporting and short range presence detection to provide position updates, movement alerts and local smartphone proximity awareness.

- Real time tracking via GPRS with SMS reporting as a fallback for resilient position and event delivery.
- Dual GNSS navigation with GPS and GLONASS plus AGPS assistance for faster fixes and improved location reliability.
- Built in accelerometer for motion, impact and tilt detection to support anti theft alerts and movement monitoring.
- Bluetooth LE presence detection for owner smartphone proximity and local ranging capabilities.
- Long life on a 3×AAA lithium battery pack and a compact semi hermetic IP54 enclosure for discreet mounting.
- Black box memory and retry logic with server update support to reduce lost packets and enable remote management.

## Core Features of AutoFon - Омега

- Plaspy compatible reporting over GPRS with SMS fallback for consistent delivery of coordinates and events.
- GPS and GLONASS satellite positioning with AGPS assistance for improved time to first fix.
- Built in accelerometer enabling motion detection, impact and tilt alerts for tamper and towing scenarios.
- Bluetooth LE module for smartphone presence detection and local BLE ranging for refined proximity awareness.
- Long life 3×AAA lithium battery pack designed for extended standby operation depending on reporting profile.
- Black box buffering of unsent messages and retry logic to preserve events during connectivity loss.
- Server side firmware update support over GPRS to apply manufacturer updates remotely.
- Compact semi hermetic IP54 enclosure suitable for discreet installation on vehicles and portable assets.

## How These Features Work with Plaspy

When the Omega is integrated with Plaspy, the device sends position and event telemetry to the monitoring platform so teams can view live location, event history and alert status. Plaspy ingests the device stream and exposes the tracker data through dashboards, event rules and historical playback.

- Real time location updates delivered into Plaspy via GPRS with SMS acting as a delivery fallback.
- Motion, impact and tilt events from the accelerometer appear as immediate alerts or events inside Plaspy for operator notification.
- BLE presence information is reflected as proximity events to help confirm owner presence or local device context.
- Battery level and device health data reported by the Omega are available in Plaspy for proactive maintenance and replacement planning.
- Black box memory and retry behavior reduce missed events by buffering unsent packets until connectivity is restored and Plaspy can receive them.
- Plaspy automatically detects compatible tracker protocols so initial integration is streamlined for supported models.

## Typical Use Cases

- Anti theft protection for cars, motorcycles, scooters and other mobile assets using motion alerts and proximity detection.
- Fleet supervision where discreet units report location and movement for route monitoring and operational visibility.
- Monitoring portable equipment and cargo that require long battery life and covert installation.
- Remote asset recovery and situational awareness when unauthorized movement is detected.
- Temporary tracking of rented equipment or shared vehicles without permanent wiring.
- Supervision of vulnerable people or personal use with presence detection and event reporting.

## Feature Availability Notes

- Some features depend on the installed firmware version and hardware revision; manufacturers may enable or disable functions across different production batches.
- Cellular reporting uses 2G GPRS and SMS; regional network availability and operator support for 2G can affect connectivity and reporting reliability.
- BLE presence and local ranging effectiveness depend on placement and environmental conditions around the device and the paired smartphone.
- Black box buffering and server firmware update support require occasional GPRS connectivity to transmit queued packets and receive updates.
- Always confirm feature lists, firmware capabilities and installation recommendations with the official manufacturer documentation.
