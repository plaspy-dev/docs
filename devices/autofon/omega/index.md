# AutoFon - Омега

![Омега](./tracker.png)

The AutoFon Омега is a compact GPS tracker designed for long autonomous operation and discreet installation. It combines GPS and GLONASS navigation with GPRS and SMS reporting, a built in accelerometer and BLE presence detection to provide reliable position updates, motion and tilt alerts, and local ranging for an owner’s smartphone. Its small IP54 enclosure and battery powered design make it suitable for covert mounting on vehicles, portable equipment and other assets that require continuous telemetry.

As a Plaspy compatible device, the Омега can send coordinates and event data to monitoring servers or via SMS so Plaspy can ingest location and event streams for dashboarding and alerts. Server update and black box buffering features help maintain connectivity and reduce missed events, making the Омега a practical choice to integrate with Plaspy for fleet oversight, anti theft protection and distributed asset monitoring.

## Key Highlights

- Plaspy compatible GPS tracker providing location and event delivery via GPRS with SMS fallback
- GPS plus GLONASS navigation with assisted positioning for reliable fixes in varied environments
- Built in accelerometer for motion, impact and tilt alerts to detect unauthorized movement
- BLE presence detection for owner proximity alerts and local smartphone ranging
- Long life on replaceable AAA battery pack supporting extended standby readiness
- Compact semi hermetic IP54 enclosure suited to discreet mounting on vehicles and assets
- Black box memory and retry logic to buffer unsent messages until connectivity is restored

## How It Works with Plaspy

When connected to Plaspy, the AutoFon Омега transmits periodic coordinates and event telemetry so monitoring teams can track assets in near real time and review historical routes. Plaspy ingests the device data stream to present location on maps, trigger alerts, and generate reports that support operational decisions.

- Real time location updates and periodic telemetry delivered to Plaspy via GPRS with SMS as fallback
- Motion, impact and tilt events mapped to immediate alerts for unauthorized movement or tampering
- BLE presence events used to signal owner proximity and refine local situational awareness
- Battery level and temperature reporting available to Plaspy for proactive device maintenance monitoring
- Buffered black box records ensure data continuity by retrying transmission when connectivity returns

## Typical Use Cases

- Anti theft protection and recovery for cars, motorcycles, scooters and portable equipment
- Continuous fleet monitoring where discreet installation and long standby life are required
- Asset tracking for trailers, containers and cargo that need periodic position and movement alerts
- Supervision of vulnerable people or items using SOS alerts and presence detection
- Long term deployment on remote assets that benefit from buffered telemetry and remote updates
