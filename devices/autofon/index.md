# AutoFon

AutoFon is a recognized name in GPS tracking hardware that produces devices commonly used for vehicle monitoring and fleet tracking. Many AutoFon trackers are compatible with third party telematics platforms, and Plaspy can receive location and telemetry from AutoFon devices so teams can view, analyze, and act on tracking data within a single fleet management interface.

## How AutoFon devices work with Plaspy

AutoFon trackers typically transmit GPS location and basic telemetry over cellular networks. When paired with Plaspy, that data is ingested into Plaspy servers where it is processed, stored, and made available through dashboards, alerting, and reporting tools. Integration with Plaspy allows you to:

- View live location on maps hosted by Plaspy
- Receive movement and status alerts through Plaspy notifications
- Combine AutoFon device data with other fleet inputs in a single interface

Specific configuration steps such as APN settings, device protocols, and server addresses are handled on the device configuration pages for each model. For model level setup guidance consult the device documentation available through the catalog and the Plaspy knowledge base.

## Common features found in AutoFon devices

AutoFon product lines typically include a range of features useful for vehicle and asset tracking. While capabilities vary by model, common items you may encounter include:

- GPS position reporting at configurable intervals
- Cellular connectivity for remote telemetry

- Power management features designed for vehicle installations
