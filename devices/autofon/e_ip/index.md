# AutoFon - E-Маяк IP

![E-Маяк IP](./tracker.jpg)

The AutoFon E-Маяк IP is a compact, autonomous GSM GPS tracker designed for discreet long term location monitoring and alarm reporting. It is built for applications that need reliable position updates and event alerts over extended periods without frequent maintenance, and includes features such as on demand audio monitoring, an SOS button, and motion detection to support anti theft and security scenarios.

As a Plaspy compatible device out of the box, the E-Маяк IP can deliver SMS based position updates and protocol messages that Plaspy can ingest and present on maps and dashboards. This makes the tracker a practical choice for customers who want to add long life, low maintenance assets to Plaspy for real time tracking, alert routing, and basic telemetry without relying on a manufacturer hosted monitoring server.

## Key Highlights

- Direct compatibility with Plaspy via SMS and protocol messages for real time tracking and alerts
- Compact hermetic enclosure suitable for discreet installation in vehicles, boats, containers and remote assets
- Long autonomous operation on internal battery cells with reported service life up to two years depending on configuration
- Integrated microphone and SOS button for remote audio monitoring and immediate alarm signaling
- Digital accelerometer with multiple detection modes for movement start, tipping and impact or accident alerts
- Universal control channel and external alarm input for remote actions such as immobilizer or alarm control
- Robust SMS formatting with map link support plus message retry and queue memory for reliable delivery

## How It Works with Plaspy

Plaspy receives the E-Маяк IP location and event messages whether the device is set to forward SMS messages or to send protocol messages to a server endpoint. Once Plaspy is configured to accept those messages, location, alarm and status information from the tracker appear in Plaspy maps, notifications and reporting tools to support monitoring and incident response.

- Real time location updates delivered via SMS and protocol messages where configured
- Movement, tipping and impact alerts forwarded to Plaspy for immediate notification and logging
- External alarm input and universal control channel status available as digital events for operational use
- SOS button presses and remote audio monitor events routed to authorized contacts and processed by Plaspy
- Device heartbeat and battery or temperature reports used by Plaspy for liveness monitoring and preventative maintenance

## Typical Use Cases

- Covert vehicle or motorcycle tracking for anti theft response and discreet monitoring
- Container and cargo escort with movement and impact notifications during transit
- Remote asset protection for garages, holiday properties and standalone equipment where long battery life matters
- Asset tracking for boats and trailers where a sealed enclosure and SMS reporting are advantageous
- Occasional personnel or pet tracking scenarios requiring an SOS button and occasional audio monitoring
