# AutoFon - E-Маяк IP Features

This page provides a public feature overview of the AutoFon E‑Маяк IP tracker and explains how its capabilities can be used with Plaspy for location monitoring and alerting. It summarizes practical, non sensitive information about the device, how it reports position and alarms, and the types of monitoring and oversight Plaspy can present when the device is configured to report to the platform.

Exact feature availability for any individual unit depends on firmware version, hardware revision, installation method and manufacturer implementation. Some functions described here may be configurable or optional, and behavior such as reporting intervals, alarms and telemetry content can vary with settings and regional variants.

## Feature Overview

The AutoFon E‑Маяк IP is a compact autonomous GSM GPS tracker built for discreet long term monitoring and alarm reporting. It supports SMS based position updates and protocol messaging so Plaspy can receive location and event data without routing through a manufacturer hosted server. The device is designed to balance low power consumption with practical alarm and remote monitoring features.

- Plaspy compatible reporting via SMS and protocol messages for real time location and alerts
- Compact hermetic enclosure suitable for covert or exposed installations on vehicles and assets
- Long autonomous operation on primary cells allowing months to years of service depending on configuration
- Integrated microphone and SOS button for remote audio monitoring and urgent alarm signaling
- Multi mode digital accelerometer for movement, tipping, impact and high g detection plus external alarm input and universal control channel for remote actions

## Core Features of AutoFon - E-Маяк IP

- SMS and protocol message reporting for position updates and alarm forwarding to monitoring platforms
- Compact sealed enclosure ideal for discreet installation in vehicles, containers and remote equipment
- Long battery autonomy on replaceable primary cells with power management for periodic reporting
- Integrated microphone for on demand audio monitoring and a dedicated SOS button for immediate alerts
- Digital accelerometer with multiple detection modes including movement start, tipping and impact or accident detection
- External alarm input and a universal control channel that can be used for remote control actions or status signaling
- Message memory and retry behavior for unsent alerts and configurable heartbeat messages for liveness monitoring

## How These Features Work with Plaspy

When the E‑Маяк IP is configured to forward SMS or protocol messages, Plaspy ingests location, alert and telemetry messages and presents them on maps and dashboards. Plaspy can use the device's event messages to trigger notifications, show device status, and help operators respond to incidents reported by the tracker. Integration is focused on visibility and operational awareness rather than device level configuration.

- Real time location plotting and historical track display based on SMS or protocol position messages
- Accelerometer events such as movement start, tipping and impact forwarded as alerts for operator review
- SOS button activations and remote audio monitor events surfaced to authorized users for incident response
- External alarm input and universal control channel status shown as digital telemetry events in Plaspy
- Heartbeat and battery related messages used to indicate device liveness and support preventative maintenance

## Typical Use Cases

- Covert vehicle or motorcycle monitoring for anti theft response and discreet location awareness
- Container and cargo escort with movement and impact notifications during transit
- Protection of remote assets such as garages, seasonal properties and standalone equipment where long battery life matters
- Asset tracking for boats, trailers and similar assets that benefit from a sealed enclosure and SMS reporting
- Situations requiring remote audio monitoring and an SOS capability for faster incident verification or response

## Feature Availability Notes

- Feature behavior can vary by firmware version and hardware revision shipped by the manufacturer
- Some reporting modes require the device to be configured for SMS forwarding or protocol messaging; not all functions are available in every configuration
- Regional variants and local cellular support may affect message delivery and available GSM bands
- The device does not include Bluetooth or AGPS functionality in certain firmware or hardware variants according to manufacturer notes
- Always confirm which features are enabled on a specific unit and how they are configured at installation
