# AutoFon - Маяк 4.4 Features

This page provides a public, feature-oriented overview of the AutoFon Маяк 4.4 and how its capabilities map to Plaspy for location monitoring, alerting, and command workflows. It summarizes the practical functions you can expect when integrating this compact tracker with Plaspy, based on publicly available device information.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variants, installation method, and manufacturer implementation. For device-specific configuration, firmware details, and the latest specifications consult the official AutoFon documentation and release notes.

## Feature Overview

The AutoFon Маяк 4.4 is a compact, low-power GPS tracker designed for discreet, long-term deployments. It emphasizes intermittent reporting via SMS and interval GPRS packets, remote control via SMS, and a set of basic inputs and outputs suited for asset protection and remote monitoring.

- Plaspy compatible reporting via SMS and periodic GPRS packets for location and status updates.
- Integrated microphone for on-demand remote audio monitoring of the installation environment.
- Very small form factor and optimized power architecture for long autonomous operation on two CR123A cells.
- Single alarm input and one auxiliary channel to signal alarms and control connected external devices.
- PIN protected SMS control and authorized-number restrictions for remote command security.

## Core Features of AutoFon - Маяк 4.4

- GPS positioning with cellular LBS fallback for improved coverage in weak reception areas.
- SMS based control and reporting for remote commands and alerts.
- Interval GPRS packet transmission for periodic location and telemetry updates.
- Built-in microphone enabling remote audio monitoring when requested via command.
- One configurable alarm input for panic or tamper signaling.
- One auxiliary output channel to control external equipment such as immobilizer or siren.
- Long battery life supported by two CR123A lithium cells and external power monitoring.

## How These Features Work with Plaspy

Plaspy ingests location and status reports sent by the Маяк 4.4 and presents them on maps and dashboards while supporting alerting and command workflows. Because the device is optimized for intermittent reporting and low power use, Plaspy is used to aggregate updates, surface important events, and issue SMS commands back to the unit when needed.

- Location display and history on Plaspy maps based on SMS or GPRS reports.
- Alerting for alarm input events and other status messages received from the tracker.
- Remote command workflows where Plaspy operators can send authorized SMS commands to the device for actions like enabling the microphone or toggling the auxiliary channel.
- Device health monitoring using periodic life-signal messages and SIM balance notifications to track connectivity and battery status.
- Support for intermittent reporting patterns so Plaspy can consolidate updates and reduce unnecessary alerts during long-standby operation.

## Typical Use Cases

- Covert vehicle tracking and recovery with discreet installation and remote immobilizer control.
- Monitoring small craft or trailers where power is limited and long battery life is required.
- Asset protection for containers, cargo, and other high value shipments with tamper or alarm signaling.
- Remote site or kiosk monitoring where mains power is unreliable or absent.
- Lone-worker safety or personal emergency applications using the alarm input and remote audio monitoring.
