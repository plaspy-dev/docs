# AutoFon Mayak 4.4

The AutoFon Mayak 4.4 is a compact, Plaspy compatible GPS tracker engineered for long-term, low-maintenance covert tracking. Designed around longevity and discreet installation, Mayak 4.4 delivers dependable GPS positioning with GSM-based reporting \(SMS and interval GPRS packets\), an integrated microphone for remote audio monitoring, and simple remote control via SMS — all features that make it a practical choice for Plaspy users who need reliable location data and basic telemetry from vehicles, assets, and remote sites.

The device’s small size and optimized power architecture \(two CR123A lithium cells\) enable extended autonomous operation in cars, motorcycles, boats, containers, kiosks, and other assets where stealth and long battery life are priorities. When paired with Plaspy, Mayak 4.4 supports location display, alerting, and command-based control workflows that fit fleet management, anti-theft response, and remote asset monitoring scenarios.

## Key Highlights

- Plaspy compatible GPS tracker with SMS and interval GPRS reporting for location updates and alerts.
- Ultra-compact form factor \(70×50×21 mm\) and small GPS antenna for covert installations.
- Long autonomous operation: two CR123A cells \(3.0V each, combined 3000 mAh\) with up to two years standby under typical use.
- Integrated microphone enables remote audio monitoring of the installation environment.
- Single alarm input plus one auxiliary channel to control external devices such as an engine cut-off \(immobilizer\), siren, or pre-heater.
- PIN-protected SMS control, authorized-number control, SIM balance monitoring, and periodic life-signal reporting \(default every 10 days\).
- GPS positioning \(LEADTEK 9101\) with cellular LBS fallback for improved coverage in difficult reception areas.

## How It Works with Plaspy

Mayak 4.4 integrates with Plaspy by delivering location and status data via SMS and periodic GPRS packets that Plaspy can ingest, display on maps, and use to trigger alerts and reports. Because the unit emphasizes long battery life and intermittent reporting, Plaspy is ideal for processing SMS/GPRS updates, scheduling life-sign checks, and sending control commands back to the device when immediate intervention is required.

- Real-time location and telemetry updates — via SMS and interval GPRS packets; can be configured for more frequent reporting within the device’s power budget.
- Alarm input reporting — panic/alarm events can be sent to Plaspy as SMS alerts for rapid notification.
- Auxiliary channel control — Plaspy can send control SMS to authorized numbers to activate the auxiliary channel \(for engine cut-off / immobilizer or siren control where installed\).
- Remote audio monitoring — Plaspy can manage command-based requests to enable the device’s integrated microphone for on-demand audio surveillance.
- Telemetry and life-signs — periodic life signals and SIM/balance monitoring messages are available for Plaspy to track device health and connectivity.

## Technical Overview

| Cellular Connectivity | GSM communications via QUECTEL M10 module; supports SMS and interval GPRS packet transmission \(no continuous GPRS streaming\). |
| --- | --- |
| Positioning | GPS positioning using LEADTEK 9101 module; LBS \(cellular positioning\) fallback. |
| Power & Battery | Two CR123A 3.0V lithium cells \(combined capacity specified as 3000 mAh\); external power input available; monitors external power state; up to two years standby under typical use patterns. |
| Inputs & Outputs | One configurable alarm input \(panic signaling\); one auxiliary channel for controlling external devices \(engine cut-off/immobilizer, siren, pre-heater\); external power monitoring. |
| GNSS Antenna / Dimensions | Unit size: 70×50×21 mm. GPS antenna: 25×25×4 mm. |
| Audio & Sensors | Integrated microphone for remote audio monitoring; built-in single-function digital accelerometer. |
| Communications Features | SMS-based control from authorized numbers; PIN protection; life-signal messages \(default every 10 days\); SIM balance monitoring; preloaded SIM tariff option and quick-reference card included. |
| Remote Management | Remote control via SMS commands; no firmware update over GPRS \(no FOTA indicated\). User manual available for full configuration details. |
| Additional Notes | No advanced AGPS indicated; no continuous advanced telemetry or automatic GPS-included alarm SMS in some legacy modes; optimized for periodic/standby operation. |

## Use Cases

- Covert vehicle tracking and recovery — discreet installation in cars and motorcycles for anti-theft monitoring and remote immobilization control.
- Boat and small craft monitoring — compact form and long battery life suit intermittent maritime tracking and asset protection.
- Cargo, container, and high-value shipment security — concealed placement inside cargo for recovery and tamper alerts.
- Remote site protection — asset monitoring for kiosks, garages, or storage units where mains power is unreliable or unavailable.
- Personal safety and lone-worker applications — panic/alarm input and remote audio monitoring support emergency workflows.

## Why Choose This Tracker with Plaspy

AutoFon Mayak 4.4 is a purpose-built Plaspy compatible GPS tracker for situations where stealth, simplicity, and long battery life matter more than continuous high-bandwidth telemetry. Its reliable GPS/LBS positioning, SMS/GPRS reporting modes, and single auxiliary channel for immobilizer or siren control make it an effective choice for anti-theft deployments, fleet management tasks that require low-maintenance endpoints, and asset protection where power is limited.

When integrated with Plaspy, Mayak 4.4 provides dependable location feeds, event alerts, and command-based control without large data costs or frequent maintenance. Note that this model is optimized for intermittent reporting and long standby — it does not offer continuous advanced telemetry, AGPS-assisted rapid fixes, Bluetooth sensors, or firmware updates over GPRS. For customers who need discreet tracking, long-term autonomy, and straightforward SMS/GPRS integration with Plaspy’s map, alerting, and reporting capabilities, Mayak 4.4 is a pragmatic, cost-effective solution.
