# AutoFon - Маяк 4.4

![Маяк 4.4](./tracker.png)

The AutoFon Маяк 4.4 is a compact, low maintenance GPS tracker designed for discreet long term tracking. It delivers dependable GPS positioning with GSM based reporting via SMS and periodic GPRS packets, includes an integrated microphone for remote audio monitoring, and supports remote control via SMS. The device is built around longevity and a small form factor, making it suitable for vehicles, small craft, containers, kiosks, and other assets where stealth and extended autonomous operation are priorities.

As a Plaspy compatible device, Mayak 4.4 can feed location updates and event messages into the Plaspy platform for map display, alerting, and basic command workflows. Its intermittent reporting and life sign messaging make it particularly useful when paired with Plaspy for scheduled monitoring, alert routing, and simple remote control actions without the need for continuous high bandwidth connectivity.

## Key Highlights

- Compatible with Plaspy for location display and event handling via SMS and periodic GPRS reporting.
- Ultra compact form factor that supports discreet installations across vehicles and portable assets.
- Designed for long autonomous operation on internal cells, reducing maintenance frequency.
- Integrated microphone for on demand remote audio monitoring of the installation environment.
- Single alarm input and one auxiliary channel for controlling external devices such as immobilizer or siren.
- PIN protected SMS control and authorized number management for basic security of remote commands.

## How It Works with Plaspy

When integrated with Plaspy, the Mayak 4.4 sends location and status messages that Plaspy ingests and presents on maps, in alerts, and in device health summaries. Because the device emphasizes low power operation and periodic updates, Plaspy is used to consolidate intermittent messages into a continuous operational picture and to send command SMS when intervention is needed.

- Map based location display of received GPS and fallback positioning messages.
- Alarm and panic reporting routed as notifications to operators and configured contacts.
- Command based control through authorized SMS numbers to trigger auxiliary channel actions.
- Remote audio monitoring requests issued as device commands and tracked within Plaspy.
- Life sign and connectivity monitoring for device health reporting and periodic checks.

## Typical Use Cases

- Covert vehicle tracking and recovery with remote immobilizer or alert capability.
- Boat and small craft monitoring where compact size and long battery life are beneficial.
- Cargo and container security for concealed placement during transit or storage.
- Remote site protection for kiosks, storage units, and equipment with limited power.
- Lone worker or personal safety scenarios using panic input and remote audio monitoring.
