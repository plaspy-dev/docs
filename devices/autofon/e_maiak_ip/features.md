## Feature Overview

The AutoFon E‑Маяк IP is a compact, sealed GSM/GPS tracker designed for discreet, long term monitoring and alarm reporting. It is compatible with Plaspy using SMS and protocol messages so positioning and events can be collected without relying on a manufacturer hosted server.

- SMS based position updates and protocol messaging for real time tracking and alerts.
- Compact hermetic enclosure suitable for covert installation on vehicles, trailers, containers and remote equipment.
- Extended autonomous operation on internal lithium cells with multi‑year potential depending on reporting configuration.
- Integrated microphone and SOS button for remote audio monitoring and immediate alarm signaling.
- Built‑in accelerometer with multiple movement and accident detection modes plus external alarm input and a universal control channel for remote actions.

## How These Features Work with Plaspy

Plaspy ingests the E‑Маяк IP’s SMS and protocol messages so location, alarms and basic telemetry appear on maps and dashboards. Plaspy automatically detects common tracker protocols and can present device events alongside other fleet telemetry.

- Real time location updates received via SMS or protocol messages are shown on Plaspy maps and history.
- Movement, tipping and impact alerts from the accelerometer are forwarded into Plaspy for instant notification and event logging.
- SOS activations and remote audio monitor events are surfaced as incidents in Plaspy for operator response.
- External alarm input and universal control channel states are recorded as digital telemetry for door, alarm or immobilizer‑style events.
- Heartbeat, battery and basic temperature messages help Plaspy track device liveness and maintenance needs.
