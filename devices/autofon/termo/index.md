# AutoFon - Термо

<div className="device-logo">
![Термо](./tracker.jpg)
</div>

AutoFon Термо is a GSM controlled heater module created to manage aftermarket auxiliary parking heaters such as WEBASTO and EBERSPÄCHER. It provides remote start and stop via SMS or an incoming-call voice menu, offers a cabin-mounted push button for local on/off control, and includes a real time clock with two programmable timers for scheduled pre-heating. The unit is intended to work with separately installed auxiliary heaters and is positioned for fleet and private vehicle use where predictable pre-heating is important.

This model is noted as compatible with Plaspy workflows and can augment fleet telematics when used alongside Plaspy or a Plaspy-compatible GPS tracker. In a Plaspy-managed environment the Термо module adds heater control and event information that complements Plaspy’s location, reporting, and fleet monitoring features, giving operators better oversight of vehicle readiness and heating schedules.

## Key Highlights

- GSM remote control using SMS commands and an incoming-call voice menu for convenient driver interaction
- Two programmable timers with a built in real time clock for scheduled pre-heating routines
- Cabin push button for local manual override alongside remote control options
- Designed specifically for aftermarket auxiliary heaters such as WEBASTO and EBERSPÄCHER
- Useful for fleet workflows by enabling coordinated warm up and operational readiness
- Simple integration into heater control circuitry without built in GPS on the module itself
- Voice-menu operation provides an alternative to text based control for drivers

## How It Works with Plaspy

When paired with Plaspy, AutoFon Термо acts as a focused heater controller that delivers remote command capability and timer events into fleet workflows. Plaspy handles location, centralized monitoring, and reporting while Термо provides the heater control layer, enabling coordinated operational procedures across vehicles.

- Log and track remote heater commands such as start and stop actions within Plaspy reports and event histories
- Display scheduled timer events and recent heater activity alongside vehicle status in Plaspy dashboards
- Record local cabin button events and remote activations for operational oversight and troubleshooting
- Keep voice menu confirmations and SMS acknowledgements as part of the event log when available
- Combine with a Plaspy compatible GPS tracker to correlate heater activity with vehicle location, ignition state, and routine telemetry

## Typical Use Cases

- Fleet readiness in cold climates where pre-heating ensures cabins and engines are at operating temperature before shifts
- Private vehicle remote pre-heating for passenger comfort and easier cold starts
- Adjusting or canceling heating schedules remotely when plans change to save fuel and reduce idle time
- Mixed telematics setups where heater control is paired with GPS tracking for full operational context
- Service and maintenance fleets that require predictable warm-up windows for equipment and personnel

AutoFon Термо is a specialist module that fills the narrow but important role of remote and scheduled control for aftermarket auxiliary heaters. For organizations using Plaspy, Термо can extend telematics workflows to include heater scheduling and remote activation without replacing existing GPS hardware, enabling more complete operational readiness and centralized coordination.
