# AutoFon - Термо Features

This page describes the public feature context for using the AutoFon Термо heater controller with Plaspy. It focuses on practical capabilities, how the module augments fleet workflows, and the ways Plaspy can reflect heater control and events in a telematics environment. The content is intended for planners, installers, and fleet operators evaluating integration options.

Exact feature availability and behavior depend on device firmware, hardware revision, installation wiring, and the manufacturer implementation. The AutoFon Термо is designed as a GSM controller for aftermarket auxiliary parking heaters and the manufacturer indicates the unit is discontinued and currently out of stock. Confirm current functionality and support with official documentation and your installer.

## Feature Overview

AutoFon Термо is a specialist GSM module that gives remote and scheduled control of aftermarket auxiliary heaters. It is optimized for fleets and private vehicles that require predictable pre-heating routines, and it is positioned to complement Plaspy-managed telematics when combined with a Plaspy-compatible GPS tracker.

- GSM remote control via SMS commands and an incoming-call voice menu for driver interaction.
- Two programmable timers driven by a built in real time clock for scheduled pre-heating on selected days.
- Cabin-mounted push-button input for local manual on off control in parallel with remote commands.
- Designed for compatibility with aftermarket heaters such as WEBASTO and EBERSPÄCHER when installed as non factory units.
- Simple wiring integration into the heater control circuit so the module augments an existing heater installation.
- Intended to be used alongside Plaspy or a Plaspy-compatible GPS tracker to combine heater control with location and broader telemetry.

## Core Features of AutoFon - Термо

- GSM based remote control using SMS messages for start and stop commands.
- Voice menu operation via incoming phone call to the unit for driver convenience.
- Built in real time clock with two independently programmable timers for scheduled warm ups.
- Cabin push-button input for local override and manual operation.
- Specifically designed for aftermarket auxiliary parking heaters such as WEBASTO and EBERSPÄCHER.
- Wiring integration to the heater control circuit rather than carrying separate GPS hardware.
- Positioning as Plaspy compatible so heater events can be incorporated into fleet workflows when paired with Plaspy services.

## How These Features Work with Plaspy

When AutoFon Термо is part of a Plaspy-enabled deployment, it serves as a complementary heater controller while Plaspy provides tracking, dashboards, and fleet reporting. Plaspy can record and present heater related events alongside vehicle location and other telemetry collected by a Plaspy-compatible GPS unit.

- Remote command logging so SMS starts and stops or voice initiated actions can be recorded in fleet event histories.
- Scheduled timer visibility where Plaspy can show historical start events and correlate them with vehicle schedules.
- Local override tracking so cabin push-button activations and remote commands can both appear in operational logs when event logging is available.
- Correlated telematics when a Plaspy-compatible GPS tracker is present, enabling location aware scheduling and readiness reporting.
- Integration into fleet workflows so centralized dispatch or maintenance teams can monitor heater use as part of vehicle readiness.

## Typical Use Cases

- Cold climate fleet readiness with scheduled warm ups to ensure cabins and engines are at operational temperature before shifts.
- Private vehicle comfort where drivers remotely start and schedule heater runs for daily use.
- Remote extension or cancellation of heater runtime when schedules change or trips are canceled.
- Mixed telematics deployments that combine AutoFon Термо heater control with Plaspy compatible GPS trackers for a fuller operational picture.
- Service and maintenance fleets that require predictable warm start conditions for equipment and crews.
