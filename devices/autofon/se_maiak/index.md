# AutoFon - SE+ Маяк

<div className="device-logo">
![SE+ Маяк](./logo..png)
</div>

The AutoFon SE+ Маяк is a compact GPS tracking device designed to determine and transmit the location of an object to its owner using the GSM network. It supports sending location updates via SMS and forwarding position data to a selected monitoring server over GPRS. The model is built on the v.6.x hardware platform and includes features intended to broaden functionality and improve performance for a variety of tracking tasks.

As a Plaspy compatible device, the SE+ Маяк can deliver its location and event information into the Plaspy platform for visualization, alerts, and reporting. Its small size and feature set make it suitable for integration with Plaspy-powered monitoring workflows where discreet installation, event-driven notifications, and historical playback are needed.

## Key Highlights

- Compact form factor suitable for discreet installation in vehicles, cargo, and portable assets
- Combined GLONASS+GPS navigation for improved position accuracy
- Sends location updates via SMS or to a monitoring server using GPRS
- Built-in microphone for remote listening in supported deployments
- Motion, impact, and accident detection with adjustable sensitivity
- SOS micro-button for emergency signaling
- Onboard black box storage capable of holding a large number of GPRS packets for later retrieval

## How It Works with Plaspy

When configured to report to Plaspy, the SE+ Маяк can feed location and event data into the platform so teams can monitor assets from a central interface. Plaspy can present the device data alongside other fleet and asset information to support operational oversight and incident response.

- Real-time and periodic position updates displayed on Plaspy maps for situational awareness
- Event alerts for movement, impacts, accidents, and SOS signals routed into Plaspy notification channels
- Historical route playback and reporting based on stored position records
- Visibility into device-stored events and message logs to aid investigation and auditing
- Use of the device additional channel where supported to reflect remote control actions in Plaspy dashboards

## Typical Use Cases

- Tracking company cars, delivery vehicles, motorcycles, and boats
- Monitoring valuable cargo and transport containers during transit
- Protection and remote monitoring of stationary objects like garages and kiosks
- Personal tracking for children, caretaking, or assisted monitoring of people and animals
- Fleet oversight where discreet installation and event-triggered alerts are important
