# AutoFon - Омега-Маяк XL Features

This page provides a public feature overview of the AutoFon Омега-Маяк XL tracker and how its capabilities are used with the Plaspy platform. It summarizes key, non-sensitive device functions, explains practical value for monitoring and fleet workflows, and highlights how Plaspy can receive and present the device data.

Exact feature availability and behavior depend on the device firmware, hardware revision, regional variants, and installation method. Where possible the content below is based on the device description from the manufacturer; please consult the manufacturer documentation for implementation specifics and the latest firmware behavior.

## Feature Overview

The Омега-Маяк XL is a multi‑mode GPS tracker built to report precise location and basic event data over cellular networks. Designed for longer deployments and a variety of assets, it combines GNSS positioning, local sensors, and onboard data storage to maintain tracking and event history even when momentary connectivity is interrupted.

- Combined GLONASS and GPS navigation module with A‑GPS support for improved location sensitivity
- Dual SIM support for redundant cellular connectivity and improved reachability across networks
- Local event detection with configurable sensors for movement, impacts, accidents, overturns, and falls
- Onboard black box capable of storing a large number of GPRS packets for offline history and later upload
- Rugged IP67 sealed housing for protection in outdoor and harsh conditions

## Core Features of AutoFon - Омега-Маяк XL

- GLONASS plus GPS navigation with A‑GPS assisted positioning for faster fixes and improved sensitivity
- Configurable motion and impact sensors to detect movement, impacts, overturns, falls, and related events
- Dual SIM card support allowing use of two operators for higher communication reliability
- Built in black box memory to store thousands of GPRS packets when real time upload is not available
- Support for sending coordinates via SMS or forwarding data to a monitoring server by GPRS
- IP67 sealed enclosure providing dust and water resistance for outdoor use
- Remote firmware update capability via GPRS for maintaining device software in the field
- Local features such as Wi‑Fi based location assistance, BLE presence functions, photo sensor for tamper detection, and a built in microphone and SOS button for additional monitoring options

## How These Features Work with Plaspy

Plaspy receives and normalizes position and event data from compatible trackers so teams can monitor assets in a unified interface. Plaspy automatically detects supported tracker protocols and accepts connections using common transport modes; many devices can be configured to report to Plaspy server endpoints such as d.plaspy.com using UDP or TCP on the standard Plaspy port, simplifying setup.

- Position points and GNSS fixes appear in Plaspy maps and history views to show movement and location history
- Sensor events like movement detection, impacts, and tamper alerts are presented as timeline events for operational review
- Black box stored packets uploaded after reconnect appear as historical telemetry so gaps in coverage are visible
- Dual SIM redundancy and remote firmware update status are reflected indirectly via device connectivity and reported events
- SOS button presses, microphone status, and BLE presence events can be shown as alerts or diagnostic notes depending on configuration

## Typical Use Cases

- Vehicle tracking for cars, motorcycles, and boats where discreet installation and long battery life are important
- Asset protection for containers, cargo, and portable equipment that may experience impacts or tampering
- Monitoring of remote stationary objects such as garages, kiosks, or seasonal sites that need resilient connectivity
- Personnel or pet tracking where presence detection and compact form factor are useful
- Environments that demand robust enclosures and offline data retention to survive connectivity interruptions

## Feature Availability Notes

- Feature presence and exact behavior depend on the device firmware version and the hardware revision of the unit
- Some functions such as Wi‑Fi location assistance, BLE presence, or the microphone are optional on certain regional variants or configurations
- Installation choices and wiring can affect sensor availability and sensitivity settings available to the tracker
- Manufacturer default settings may differ from the options Plaspy displays; review device configuration after installation
- Always confirm supported features and limitations in the official device documentation for your specific unit

## Why Use Plaspy with These Features

Using Plaspy with the AutoFon Омега-Маяк XL gives organizations a single platform to collect location points, view event timelines, and manage historical telemetry even when devices store data locally during connectivity outages. Plaspy's automatic protocol detection and standardized server handling make it straightforward to onboard compatible trackers and maintain operational visibility across mixed fleets.
