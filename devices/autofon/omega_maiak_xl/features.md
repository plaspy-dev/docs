# AutoFon - Омега-Маяк XL Features

This page provides a public feature overview for the AutoFon Омега-Маяк XL and explains how its capabilities relate to use with Plaspy. It focuses on practical, non-sensitive details about the device functionality, what Plaspy can display and monitor, and helpful context for operators evaluating compatibility.

Exact behavior and available functions can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Confirm feature details for a specific unit and firmware with the official AutoFon documentation and your installer before relying on any particular capability.

## Feature Overview

The Омега-Маяк XL is a compact, rugged tracker designed for accurate positioning via GLONASS and GPS with A GPS assistance, and flexible reporting over cellular networks. It combines location sensitivity with local data storage and multiple presence and tamper detection options to support continuous monitoring in Plaspy.

- Combined GLONASS and GPS positioning with A GPS assisted fix for improved sensitivity
- Movement and impact related sensors with adjustable sensitivity and reactivation intervals
- Dual SIM support to improve cellular availability across operators
- Local black box storage capable of holding a large backlog of GPRS packets for later upload
- Rugged IP67 sealed housing for deployment on vehicles and remote assets
- Built in microphone and proximity features for additional situational awareness

## Core Features of AutoFon - Омега-Маяк XL

- GLONASS plus GPS navigation module with A GPS support for enhanced satellite acquisition
- Configurable motion and impact detection including overturn and fall detection modes
- Dual SIM card support for improved connectivity and operator redundancy
- Onboard black box that stores up to 15,000 GPRS packets for reliable historical tracking
- IP67 rated sealed enclosure suitable for outdoor and exposed installations
- Built in microphone for remote audio monitoring where supported by device firmware
- BLE and Wi Fi assisted location features for near field detection and presence tagging
- Remote firmware update capability via GPRS as provided by the manufacturer

## How These Features Work with Plaspy

When the Омега-Маяк XL is configured to report to Plaspy, the platform makes the device data visible alongside other fleet and asset telemetry. Plaspy automatically detects supported tracker protocols and presents location and event information in a standardized way for monitoring and reporting.

- Real time and periodic position updates from the GLONASS/GPS module appear on Plaspy maps and location timelines
- Stored black box packets can be uploaded or processed to reconstruct historical routes and gaps in connectivity
- Motion and impact sensor events (movement start stop, impacts, overturns, case open events) are visible as event markers or alerts when the device is configured to send them
- SOS and emergency button presses are delivered to Plaspy as alert events if enabled on the device
- Dual SIM behavior improves online availability and reduces missed reports visible as improved continuity in Plaspy device status
- Device configuration options can be pointed to Plaspy server settings such as the domain d.plaspy.com and, where applicable, UDP or TCP transport on the standard port used by Plaspy

## Typical Use Cases

- Continuous tracking of cars, motorcycles, and commercial vehicles where robust GNSS sensitivity is needed
- Asset protection for trailers, containers, and cargo using the black box to maintain history during temporary loss of connectivity
- Monitoring of high value stationary objects such as remote cabins or kiosks with tamper and case open detection
- Discreet location monitoring for small equipment and watercraft thanks to compact form factor and IP67 protection
- Presence and proximity detection using BLE and Wi Fi assisted features combined with location reporting
- Situational awareness and remote audio monitoring where legal and configured for use
