# Fortuna Impex - Disha 9330 Features

This page describes the public feature context for using the Fortuna Impex Disha 9330 tracker with Plaspy. It summarizes the device capabilities that are relevant to Plaspy users, including real time and historical tracking, alerting, and installation characteristics. The intent is to help fleet managers and technical evaluators understand how the Disha 9330 can deliver operational value when used with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For precise device configuration details, firmware specifics, and the latest documentation, consult Fortuna Impex resources and the device manual.

## Feature Overview

The Disha 9330 is positioned as an intelligent vehicle tracking system for services, delivery, and transportation use cases. It provides continuous location visibility and event reporting that help organizations manage routes, resources, and scheduled reporting workflows.

- Real time location reporting and historical trip data accessible on the web
- Real time alerts and event notifications with scheduled reports available via SMS and email
- Simple dashboard mounting for straightforward installation in vehicles
- Enclosed GPS and GPRS antennas to reduce the need for external antenna installation and to lower the risk of mechanical damage
- Collection and basic analysis of asset information to support resource utilization decisions

## Core Features of Fortuna Impex - Disha 9330

- Real time tracking for active location visibility
- Historical tracking to review past routes and activity
- Real time alerts and event reporting with options for scheduled reports
- Web access to tracking and reports for remote monitoring
- Enclosed GPS and GPRS antennas for integrated installation and protection
- Simple dashboard mount installation requiring minimal wiring

## How These Features Work with Plaspy

Plaspy receives location and event data from compatible trackers like the Disha 9330 and presents that information through its web platform to support monitoring and operational workflows. Plaspy automatically detects compatible device protocol details during onboarding, allowing the tracker to report into the platform with minimal manual protocol selection.

- Live map view and location updates displayed in Plaspy for immediate situational awareness
- Historical tracks and position history available for playback and review
- Event and alert entries recorded in Plaspy so operators can review triggered conditions and timestamps
- Scheduled reports and activity summaries that can be reviewed or exported from the Plaspy interface
- Centralized device listing and status indicators to manage multiple Disha 9330 units across a fleet
