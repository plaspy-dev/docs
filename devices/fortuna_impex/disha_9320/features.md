# Fortuna Impex - Disha 9320 Features

This page summarizes the public feature context for the Fortuna Impex Disha 9320 when used with Plaspy. It focuses on practical capabilities that matter to fleet managers and operators, explains how those capabilities are reflected inside Plaspy, and provides guidance on what to expect from the device in everyday use.

Exact feature availability and behavior can vary based on firmware version, hardware revision, installation type, and how the manufacturer has implemented particular functions. For precise technical details consult the manufacturer documentation and verify the installed unit configuration before relying on any specific behavior.

## Feature Overview

The Disha 9320 is an intelligent vehicle tracking system built for services, delivery, and transportation fleets. It provides location visibility and event reporting intended to help operators monitor assets, improve utilization, and receive timely notifications.

- Real time location tracking and historical position playback through a web interface
- Real time alerts and events with scheduled reports available via SMS and email
- Compact form factor designed for simple dashboard mounting and GPS visibility
- Enclosed GPS and GPRS antennas to reduce external antenna work and potential damage
- Battery powered connection using two wires for straightforward vehicle installation

## Core Features of Fortuna Impex - Disha 9320

- Real time tracking for live location awareness
- Historical tracking for route review and playback
- Real time alerts and event reporting to notify operators of important conditions
- Scheduled reports delivered via SMS and email for recurring oversight
- Enclosed GPS and GPRS antennas to simplify installation and reduce exposed components
- Simple mounting on the front dashboard with requirement for GPS visibility to the sky
- Power connection via two wires to vehicle battery for continuous operation

## How These Features Work with Plaspy

Plaspy receives and processes the device data to present location, event, and reporting information in a centralized platform for monitoring and analysis.

- Live and historical positions from the tracker appear on Plaspy maps and timelines for operational visibility
- Device reported alerts and events are surfaced in Plaspy so teams can respond to exceptions
- Scheduled reports produced by the device can be correlated with Plaspy logs and exported reporting tools
- Device connectivity and status are visible inside Plaspy so administrators can confirm the unit is communicating
- Plaspy automatically detects tracker protocols and supports configuring the device to report to Plaspy servers using UDP or TCP on the standard platform port
