# Fortuna Impex - Disha 9310 Features

This page provides a public feature overview for the Fortuna Impex Disha 9310 and explains how its capabilities map to Plaspy for vehicle tracking and fleet oversight. It focuses on user facing features such as real time and historical tracking, alerting, and installation notes so fleet managers and integrators can understand practical value when the device reports into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific technical detail, configuration parameters, or the latest firmware behavior consult the manufacturer documentation and your installer before deploying at scale.

## Feature Overview

The Disha 9310 is positioned as an intelligent vehicle tracking system that helps service, delivery, and transportation operations monitor and manage mobile assets. It emphasizes live location visibility, historical playback, and timely reporting to support operational decisions and resource utilization.

- Real time vehicle tracking with online visibility and map based location updates
- Historical tracking and route playback for audits and analysis
- Real time alerts and event notifications delivered via SMS and email
- Scheduled reporting by SMS and email for regular operational summaries
- Simple dashboard mounting and enclosed GPS and GPRS antennas for easier installation and protection

## Core Features of Fortuna Impex - Disha 9310

- Real time location reporting for live fleet visibility
- Historical position logging for route review and analysis
- Real time alerts and event generation for notable vehicle conditions
- Scheduled report generation with delivery by SMS and email
- Integrated GPS and GPRS antennas enclosed in the unit to avoid separate antenna installation
- Compact installation procedure designed for dashboard mounting with basic wiring
- Asset data collection and analysis capabilities to support utilization and operational planning

## How These Features Work with Plaspy

When used with Plaspy, the Disha 9310 reports location and event information into Plaspy so operators can monitor assets from a central platform. Plaspy automatically detects the tracker protocol and accepts device data into the system for visualization and reporting.

- Live position updates become map markers and live tracks inside Plaspy
- Historical data and route playback are available through Plaspy history views
- Alerts and events reported by the device can be surfaced as notifications and routed as needed
- Scheduled reports from the device can be integrated into Plaspy workflows for consolidated reporting
- Device connectivity can be configured to report into the Plaspy server at d.plaspy.com and supports UDP or TCP transport on the standard Plaspy port
