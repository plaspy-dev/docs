# SkyMobile

SkyMobile provides GPS tracking hardware used by vehicle and asset managers across diverse industries. This page explains how SkyMobile devices can be monitored through Plaspy, outlines typical device capabilities and use cases, and helps you find the right device model using Plaspy's device catalog and documentation.

## How SkyMobile devices work with Plaspy

Many SkyMobile trackers transmit location and sensor data over cellular networks. Plaspy ingests that incoming telemetry, normalizes device messages, and presents real time and historical data in a unified interface. On Plaspy you can view live positions on maps, access trip history, configure alerts, and generate reports for devices from this brand.

Device specific setup steps such as APN configuration, data format selection, or parameter programming are handled on individual device pages. Use the model catalog above to navigate to the exact device documentation that includes the required configuration details for sending data to Plaspy.

## Common features found in SkyMobile devices

While capabilities vary by model, SkyMobile hardware commonly offers features typical of vehicle and asset trackers. Common features you will encounter include:
- GPS based location reporting with configurable reporting intervals
- Cellular communication for live tracking and data uploads
- Input and output ports for ignition detection and external sensors
- Motion detection and tamper or power loss notifications
- Basic geofencing and activity alerts

Refer to the specific model pages in the catalog for exact feature lists and supported interfaces.

## Typical use cases for SkyMobile GPS trackers

SkyMobile devices are used in scenarios such as:
- Fleet operations that require vehicle monitoring and route history
- Asset tracking for trailers, equipment, and non powered assets
- Theft deterrence and rapid recovery with location alerts
- Rental or shared vehicle monitoring for usage and odometer checks

Plaspy helps turn device telemetry into actionable operations data for these and other use cases.
