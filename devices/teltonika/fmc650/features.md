# Teltonika - FMC650 Features

This page provides a public feature context for using the Teltonika FMC650 GPS tracker with Plaspy. It summarizes the FMC650 capabilities that are relevant to fleet managers, integrators and technical teams who plan to feed location, telematics and tachograph data into the Plaspy platform for real time monitoring, reporting and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant and the specific installation method. Manufacturer implementation details, optional accessories and package contents can change over time, so verify device specifics against vendor documentation for the most current information.

## Feature Overview

The FMC650 is a professional vehicle tracker built for demanding telematics deployments where continuous cellular connectivity, improved GNSS performance and rich vehicle interfaces are required. It is designed to send vehicle position, telemetry and diagnostic data into telematics backends like Plaspy and supports common integrations used in heavy fleet, trailer and specialized machinery operations.

- LTE Cat 1 cellular connectivity with 2G fallback for broad coverage in mixed networks
- Dual channel GNSS module with L1 and L5 support for improved satellite lock and positioning reliability
- Multiple CAN interfaces with J1939 and FMS support to expose engine and vehicle telemetry
- Serial ports RS232 and RS485 for thermographs and other peripheral sensors
- Tachograph live data access and remote tachograph file download for compliance workflows

## Core Features of Teltonika - FMC650

- 4G LTE Cat 1 cellular link with 2G GSM fallback for resilient connectivity across regions
- Separate dual channel GNSS module supporting L1 plus L5 bands for enhanced positioning performance
- Multiple CAN interfaces including J1939 and FMS support for vehicle telemetry and DTC reading
- RS232 and RS485 serial ports to connect thermographs and other serial peripherals
- Tachograph live data access and remote file download via supported tachograph interfaces
- Rugged I O set and vehicle grade packaging suited for heavy fleet, trailer and specialized machinery use
- Regional device variants and packaged cabling with external 4G and GNSS antennas to simplify installation

## How These Features Work with Plaspy

When an FMC650 is integrated with Plaspy, the tracker streams position and vehicle telemetry into the Plaspy backend where data is used for maps, timelines, alerts and maintenance workflows. Plaspy ingests the telemetry and diagnostic feeds to provide operators with operational visibility and tools for decision making.

- Real time GNSS position fixes and movement updates appear on Plaspy maps and live views
- CAN derived telemetry and DTCs can populate engine and vehicle dashboards for remote diagnostics
- Tachograph live data and remote downloads feed compliance and driver hours reporting in Plaspy
- Serial peripherals such as thermographs can send readings to Plaspy for temperature monitoring and alerts
- Trailer and truck pairing workflows use multi interface telemetry to maintain coupled asset context in Plaspy

## Typical Use Cases

- Heavy vehicle fleet tracking that needs robust cellular connectivity and high quality GNSS positioning
- Trailer tracking and trailer to truck pairing for logistics operations using CAN and serial integration
- Proactive maintenance and remote diagnostics by reading DTCs and engine parameters from CAN
- Cold chain monitoring by connecting thermographs through RS232 or RS485 and reporting temperatures to Plaspy
- Tachograph data collection for compliance and driver hours monitoring using supported tachograph interfaces
- Anti theft and recovery monitoring with continuous location and telemetry reporting to Plaspy

## Feature Availability Notes

- Feature presence depends on firmware and hardware revision; some functions are enabled or improved in specific firmware releases
- Regional variants may differ in supported cellular bands and included accessories such as antennas and cabling
- Certain features require access to vehicle CAN networks or proper wiring during installation to expose signals to the tracker
- Tachograph live data and remote download require the compatible tachograph interface and correct wiring or adapters
- Manufacturer documentation and the specific ship ready package should be checked to confirm included items and supported interfaces
