# FMM920 GPS Tracker

The FMM920 is a compact, high-performance GPS tracker designed for Plaspy compatible deployments. Built around 4G LTE Cat M1 / NB‑IoT connectivity and quad-band 2G fallback, the FMM920 delivers reliable real-time tracking and essential fleet management features in a slim 12 mm profile. It is presented as a popular compact Cat M1 model for operators who need continuous position reporting, robust telemetry and simple integration with Plaspy for centralized monitoring and alerts.

Optimized for fleets, rental and sharing services, logistics and light commercial transport, the FMM920 pairs Plaspy compatibility with Bluetooth® Low Energy \(BLE\) support, built-in backup battery operation and remote-control actions such as engine blocking. These capabilities make the unit effective for anti-theft workflows, fuel monitoring programs, eco-driving initiatives and temperature-sensitive cargo monitoring when used with BLE sensors and beacons.

## Key Highlights

- Plaspy compatible GPS tracker for reliable real-time tracking and centralized fleet management.
- 4G LTE Cat M1 / NB‑IoT primary connectivity with quad-band 2G fallback \(B2/B3/B5/B8\) for broad regional coverage.
- Built-in backup battery ensures continued telemetry and location reporting when main power is lost — ideal for anti-theft and recovery.
- Bluetooth Low Energy \(BLE\) support to pair external sensors and beacons for temperature, humidity, magnet detection and movement monitoring.
- Remote management via Teltonika FOTA WEB for firmware and configuration updates, simplifying large-scale deployments and maintenance.
- Remote actions including engine blocking/immobilizer controls for anti-theft and fleet-control measures.
- Slim 12 mm form factor for discreet installation in tight spaces on vehicles and assets.

## How It Works with Plaspy

When integrated with Plaspy, the FMM920 streams location and telemetry into your Plaspy dashboard via secure cellular networks. Plaspy ingests GNSS positions, BLE-sensor data and device state changes to provide real-time tracking, historical trip reports, geo-fencing alerts and remote control actions. The combination enables actionable insights for fleet managers while preserving the low-profile installation and remote management advantages of the FMM920.

- Real-time location and telemetry updates delivered to Plaspy for live tracking and historical replay.
- BLE sensor inputs \(temperature, humidity, magnet, movement\) forwarded to Plaspy as telemetry events.
- Remote immobilizer/engine block commands supported for anti-theft and fleet-control workflows.
- Backup battery reporting and power-loss alerts ensure Plaspy receives continuity and theft-detection signals.
- Over‑the‑air firmware and configuration via Teltonika FOTA WEB to maintain device consistency across a Plaspy-managed fleet.
