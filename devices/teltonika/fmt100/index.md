# Teltonika - FMT100

<div className="device-logo">
![FMT100](./tracker.png)
</div>

The FMT100 is a compact, Plaspy compatible GPS tracker designed for fast, reliable battery mounted installation on vehicles and mobile assets. Housed in an IP65 rated rugged enclosure, it is intended for fleet rollouts, seasonal vehicle use, and rapid deployments where simple mounting and dependable location and event reporting are priorities. The device includes an integrated 3 axis accelerometer and Bluetooth LE support so it can capture motion events and pair with external sensors for extended asset awareness.

As a device that integrates with Plaspy, the FMT100 delivers location updates, accelerometer events, and Bluetooth sensor readings into Plaspy’s monitoring and reporting environment. That compatibility makes it suitable for operations that need quick installation, centralized visibility, and event driven alerts across mixed fleets. Use with Plaspy lets teams convert FMT100 messages into live tracking, incident traces, and automated notifications without extensive configuration.

## Key Highlights

- Compact battery mounted form factor designed for fast deployment on vehicles and assets.
- IP65 rated rugged enclosure for reliable field operation in varied weather conditions.
- Built in 3 axis accelerometer for crash aware event capture and motion detection.
- Bluetooth LE pairing to extend telemetry with external temperature humidity movement or magnet sensors.
- Quad band 2G connectivity for broad legacy network reach to support basic tracking and event reporting.
- Multiple bundle options from the manufacturer with accessory choices for installation flexibility.

## How It Works with Plaspy

When integrated into Plaspy, the FMT100 streams position updates, accelerometer events, and paired Bluetooth sensor data into Plaspy’s dashboards and reporting tools for operational oversight and historical review. Plaspy can ingest the device’s event driven messages to raise alerts, build incident traces, and feed fleet workflows.

- Real time location and movement updates shown on Plaspy maps with historical route playback.
- Accelerometer based crash events forwarded to Plaspy for incident review and alerting.
- Bluetooth LE sensor readings relayed into Plaspy to monitor environmental conditions or asset status.
- Event driven workflows and notifications configured in Plaspy based on device messages and geofencing.
- Optional I O dependent features such as remote control or ignition monitoring depend on selected bundle and vehicle wiring so verify required capabilities before deployment.

## Typical Use Cases

- Large scale rental and seasonal fleet rollouts that require rapid battery mounted installation and central tracking.
- Logistics and delivery fleets needing economical units for basic location reporting and event alerts.
- Crash detection and incident analysis using accelerometer driven traces and automated notifications.
- Asset environment monitoring by pairing BLE temperature or humidity sensors for sensitive cargo.
- Short term deployments and pilot programs where simple installation and predictable reporting reduce deployment time.

## Why Choose This Tracker with Plaspy

The FMT100 provides a pragmatic mix of ruggedness, rapid installability, and sensor flexibility that fits many Plaspy use cases. Its battery mounted design and accessory bundle options reduce installation time and logistics, helping teams get devices reporting into Plaspy quickly. Bluetooth LE sensor support and a built in accelerometer add richer telemetry than a basic tracker while keeping hardware and deployment costs moderate.
