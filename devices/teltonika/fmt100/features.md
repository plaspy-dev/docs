# Teltonika - FMT100 Features

This page provides a public, feature oriented summary of the Teltonika FMT100 as used with Plaspy. It focuses on the practical capabilities that matter for fleet and asset tracking, explaining what the device reports, how those reports are useful in Plaspy, and which aspects of the tracker are relevant when planning deployments.

Exact feature availability and behavior can vary by firmware version, hardware revision, the chosen order code or bundle, and installation type. Manufacturer configuration choices and regional variants also affect which functions are present, so review Teltonika documentation and your device bundle before deployment.

## Feature Overview

The FMT100 is a compact, battery mounted GPS tracker designed for quick installation and dependable location and event reporting. Its combination of a rugged IP65 enclosure, accelerometer driven event reporting, Bluetooth LE sensor pairing, and legacy cellular connectivity make it suitable for large rollouts and short term or seasonal vehicle deployments.

- Fast battery mounted installation for low touch deployment and quick registration in Plaspy
- IP65 rated rugged enclosure for protection in outdoor and vehicle environments
- Built‑in 3 axis accelerometer for crash aware event detection and trace creation
- Bluetooth LE support to pair external sensors such as temperature humidity movement and magnet sensors
- Quad band 2G GSM connectivity to provide broad legacy cellular coverage for location and event reporting
- Multiple bundle options including power cable and clamp accessories to suit different installations

## Core Features of Teltonika - FMT100

- Compact form factor designed for battery mounted installation and quick physical deploys
- IP65 water resistant enclosure to improve field reliability in varied weather
- Built in 3 axis accelerometer with configurable crash detection parameters for incident reporting
- Bluetooth Low Energy for pairing with external beacons and sensors to extend telemetry
- Quad band 2G GSM support for wide legacy network compatibility across regions
- Optional accessory bundles including clamp cables power leads and micro USB where offered
- Multiple order code and bundle variants; check manufacturer documentation for exact kit contents
- Designed for rapid fleet rollouts and seasonal or temporary vehicle use

## How These Features Work with Plaspy

When the FMT100 is registered in Plaspy the device's location updates and event messages are consumed by the platform so operators can monitor assets in real time and review historical activity. Plaspy automatically identifies common tracker protocols and maps incoming telemetry into the tracking dashboard and reporting tools.

- Live location updates and historical route playback for vehicles and portable assets
- Accelerometer driven crash events and traces are forwarded to Plaspy for incident review and alerting
- Bluetooth LE sensor readings can be relayed into Plaspy to provide environment or asset state awareness
- Event driven messages from the device can trigger alerts notifications and workflow automation inside Plaspy
- Quick device registration and bulk rollout support speeds up deployments across mixed fleets

## Typical Use Cases

- Fleet telematics for rental logistics and seasonal fleets needing fast installs and consistent tracking
- Asset recovery and basic anti theft workflows supported by quick location reporting
- Crash detection and incident analysis using accelerometer traces for post event investigation
- Environmental monitoring of cargo or equipment by pairing BLE temperature humidity or movement sensors
- Rapid deployment programs where low installation time and repeatability reduce labor costs
- Short term or temporary vehicle tracking projects that require a compact rugged device

## Feature Availability Notes

- Feature presence and behavior depend on firmware version hardware revision and the specific order code or bundle selected
- Some I O dependent functions such as immobilizer or ignition monitoring require the correct harness or bundle and should be validated on the chosen kit
- Regional cellular support for 2G networks varies by country and operator; confirm network availability for your deployment area
- Bluetooth LE sensor compatibility depends on sensor firmware and pairing procedures defined by Teltonika
- Teltonika publishes End of Life and replacement guidance for some products; verify availability before large rollouts

## Why Use Plaspy with These Features

Using the FMT100 with Plaspy gives organizations a streamlined path from physical installation to operational oversight. Plaspy ingests the FMT100's location updates accelerometer events and BLE sensor readings to provide unified visibility across fleets and assets, enabling real time monitoring and historical reporting without the need for bespoke integration work.
