# Teltonika

Teltonika is a widely recognized name in vehicle and asset tracking hardware. Its range of compact GPS tracking devices is commonly used for fleet management, asset monitoring, and telematics applications. This page explains how Teltonika devices can be used with Plaspy, what to expect from the hardware family, and how to choose the right device for your deployment.

## How Teltonika devices work with Plaspy

Teltonika devices are designed to transmit location, motion, and sensor data to remote tracking platforms. Plaspy receives that data, decodes the reporting format, and presents it through a unified dashboard for monitoring, alerts, and reporting. Onboarding typically involves configuring the device to send data to a Plaspy device server address and registering the device in your Plaspy account.

Plaspy handles device data ingestion, event processing, and visualization so you can manage Teltonika devices alongside other supported hardware without switching platforms. If you need tailored setup guidance, device specific configuration steps are available on the individual device documentation pages in this site.

## Common features found in Teltonika devices

While the exact feature set varies by model, Teltonika devices commonly provide capabilities useful for tracking and fleet operations:
- Real time GNSS location reporting for continuous position updates
- Cellular connectivity for remote data transmission
- Digital and analog inputs for sensors and ignition detection
- Motion and orientation detection through built in sensors
- Geofence and alerting support via platform rules
- Power management options for both hardwired and battery powered installations

These capabilities map directly to Plaspy features like live tracking, events and alerts, sensor telemetry, and reporting.

## Typical use cases for Teltonika GPS trackers

Teltonika devices are used across many industries. Typical applications include:
- Fleet tracking and driver monitoring for light and heavy vehicles
- Asset tracking for trailers, containers, and fixed equipment
- Field service and workforce coordination for mobile teams
- Rental and shared vehicle monitoring for usage and location control
- Remote telemetry for utilities and industrial assets

Plaspy helps convert raw tracker data into actionable insights for each of these scenarios.
