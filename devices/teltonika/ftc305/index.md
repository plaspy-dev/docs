# Teltonika - FTC305

![FTC305](./tracker.png)

The FTC305 is a compact 4G LTE Cat 1 GPS tracker purpose-built for e-mobility and fleet telematics. Plaspy compatible out of the box, the FTC305 brings robust, vehicle-grade telemetry to e-bikes, forklifts, shuttle cars, utility machinery and other electric transport, combining durable IP67 protection with high-voltage support and flexible installation options.

Designed to deliver reliable real-time tracking and detailed CAN-bus telemetry, the FTC305 integrates with Plaspy to support fleet management workflows, anti-theft response and operational analytics. With variant radio profiles, external antenna support and optional external backup batteries, the FTC305 is a practical choice where precise GNSS position, steady cellular connectivity and custom CAN parameter monitoring matter.

## Key Highlights

- Plaspy compatible: integrates CAN-bus telemetry and GNSS data into Plaspy for real-time tracking and reporting.
- 4G LTE Cat 1 with 2G fallback: modern cellular connectivity for broad coverage and longevity in many regions.
- Wide input power \(10–97 V\): supports high-voltage e-mobility platforms such as e-bikes, forklifts and utility vehicles.
- IP67 rugged casing with no-casing factory-installation variant: choose sealed outdoor installation or an embedded module for frame mounting.
- Enhanced GNSS accuracy with support for external GNSS antenna to improve fix reliability in challenging environments.
- CAN-bus reading and custom CAN parameter databases: extract vehicle telemetry for fuel monitoring, ignition events and other ECU-derived metrics when available.
- Flexible ordering and packaging: standard packages and customizable no-casing kits \(with external antenna adapters and optional external backup battery\).
- External backup battery option: larger external 1200 mAh battery available in custom factory packages for extended power resilience.

## How It Works with Plaspy

When paired with Plaspy, the FTC305 streams positional fixes and CAN-bus telemetry into your Plaspy instance for live maps, alerts and historical reports. Plaspy ingests location and vehicle data so fleet managers can monitor route adherence, vehicle state and key metrics in real time. The device’s external antenna options and robust power range help maintain continuous connectivity across e-mobility fleets.

- Real-time location and telemetry updates delivered to Plaspy for mapping and geofencing.
- CAN-bus data available for Plaspy dashboards — useful for fuel monitoring proxies, RPM, battery state and ignition event detection when those signals are exposed on the vehicle CAN.
- Supports external GNSS and cellular antennas to improve signal reception and reduce loss of fixes.
- Backup battery options provide short-term operation during main power loss, enabling Plaspy to raise anti-theft alerts or position traces even when vehicle power is removed.
- Packaging and variant options simplify integration into custom fleet management deployments, with factory-install variants for embedded installations.
