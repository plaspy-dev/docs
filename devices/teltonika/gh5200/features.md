# Teltonika - GH5200 Features

This page describes the public feature context for using the Teltonika GH5200 with Plaspy. It focuses on practical, non-sensitive information about the tracker’s capabilities, and how those capabilities are commonly used and surfaced when integrated with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type and manufacturer implementation. For device specific configuration options, firmware notes and the latest technical details consult the manufacturer documentation as needed.

## Feature Overview

The GH5200 is a compact wearable 2G personal GPS tracker built for workforce safety and personal security. It is designed to be worn on a lanyard, clipped to a belt or attached to an ID holder, and delivers location, alerting and simple voice communications suitable for lone workers and vulnerable personnel.

- Wearable 2G GPS positioning for continuous location awareness in field and service environments.
- Two-way voice plus emergency call and SMS alerting to up to five preconfigured recipients for direct contact.
- Five configurable keys for on-demand tracking, amber alerts or other user defined actions.
- Automatic incident detection including man down and no movement alarms to trigger alerts when a wearer is unable to request help.
- Support for multiple Bluetooth sensors and beacons to extend proximity and environmental telemetry.
- Rechargeable internal battery with long autonomous operation and micro USB charging for straightforward field use.

## Core Features of Teltonika - GH5200

- Compact wearable form factor sized for lanyard, belt or ID holder mounting.
- GPS personal positioning to report wearer location to monitoring platforms.
- Two-way voice capability for direct communication between wearer and responders.
- Emergency call and SMS alerting configured to notify multiple recipients.
- Five programmable buttons for quick reporting and custom event triggers.
- Automatic man down detection to generate incident notifications without manual input.
- No movement detection that creates alerts when expected movement is not observed.
- Bluetooth sensor and beacon support to add proximity and auxiliary telemetry to events.

## How These Features Work with Plaspy

When integrated with Plaspy the GH5200 feeds position, event and status data into a centralized monitoring environment so teams can track personnel and respond to incidents faster. Plaspy ingests the device messages and presents them in dashboards, maps and incident timelines.

- Real time location updates from the tracker appear on Plaspy maps for live tracking and historical replay.
- Man down and no movement events are logged in Plaspy as incident records for dispatch and post incident review.
- Button presses from the five configurable keys are recorded as custom events or alerts within the platform.
- Emergency calls and SMS alerts are reflected as event entries so dispatchers see when a wearer requested help.
- Bluetooth sensor and beacon telemetry is displayed as additional device fields to provide context around incidents and proximity.

## Typical Use Cases

- Lone worker monitoring for utilities, maintenance and field service personnel operating alone or in remote locations.
- Rapid incident response where two way voice plus automatic detection reduces response time to wearer emergencies.
- Vulnerable person tracking for healthcare, social services or security teams requiring continuous location and event logs.
- Agricultural and outdoor workforce safety where wearable form factor is preferred to vehicle devices.
- Compliance and audit scenarios that require retained incident histories and location records for duty of care.
- Service and maintenance teams operating across dispersed sites who need a compact, wearable safety device.
