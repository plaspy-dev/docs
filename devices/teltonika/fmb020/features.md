# Teltonika - FMB020 Features

This page provides a public feature summary for the Teltonika FMB020 and how its capabilities are used with Plaspy. It focuses on practical, non sensitive information about OBD II plug and play installation, GPS location reporting, BLE sensor expansion, and the ways device telemetry can be consumed inside Plaspy for fleet tracking and operational monitoring.

Exact feature availability for any FMB020 unit can vary by firmware version, hardware revision, installation method, regional radio support and how Teltonika implements functionality. For final device specifications and the latest firmware behavior consult manufacturer documentation and release notes.

## Feature Overview

The FMB020 is an ultra compact OBD II GPS tracker designed for quick fitment in passenger cars and light commercial vehicles. When used with Plaspy the device provides live location, OBD derived telemetry and optional BLE sensor inputs that help teams track vehicles, monitor conditions, and run behaviour reports with minimal installation time.

- Plug and play OBD II form factor for fast fleet rollout and discreet installation
- Real time GPS tracking for live location, route history and replay in Plaspy
- BLE Low Energy expansion to add sensors and beacons for environmental and movement awareness
- OBD derived vehicle parameters to support telemetry driven reports and event rules
- Eco driving inputs and fuel related telemetry for driver behaviour insights and efficiency analysis
- Remote management via Teltonika tools for configuration and firmware updates at scale

## Core Features of Teltonika - FMB020

- Plaspy compatibility for immediate integration into live maps and reporting
- Ultra small OBD II design for direct connection to vehicle diagnostic port
- GPS location reporting for real time tracking and historical traces
- OBD II parameter reading to provide vehicle telemetry and status indicators
- Bluetooth Low Energy support for external sensors and beacon devices
- Eco driving support to enable fuel monitoring and driver behaviour analysis
- Remote configuration and firmware update support using Teltonika management tools
- Compact physical dimensions suited to discreet installations and rapid deployment

## How These Features Work with Plaspy

Plaspy ingests location and telemetry from FMB020 units to present live vehicle positions, event alerts and historical reports. Plaspy automatically detects supported tracker protocols and surfaces OBD and BLE data where available so operators can build alerts, dashboards and scheduled reports from a single platform.

- Live location updates and historical routes displayed on Plaspy maps and timeline views
- OBD derived telemetry reported into Plaspy for use in ignition, engine and event rules
- BLE sensor readings such as temperature, humidity, magnet and movement available in Plaspy when paired and transmitted by the device
- Remote provisioning and updates maintained via Teltonika management tools while Plaspy continues to receive telemetry
- Plaspy accepts device connections and automatically discovers tracker protocol details for integrated processing
