# Teltonika - FMM650

![FMM650](./tracker.png)

The FMM650 by Teltonika is a professional 4G LTE Cat M1 tracker engineered for advanced telematics and heavy‑duty fleet management. Plaspy compatible out of the box, the FMM650 delivers robust real-time tracking and comprehensive vehicle telemetry—bringing high-accuracy GNSS, broad cellular coverage \(LTE Cat M1, NB‑IoT with 2G fallback\), and a high-capacity backup battery into a single, integration‑ready device.

Designed for fleets, trucks, trailers and special machinery, the FMM650 enables centralized collection of location, CAN/J1939 data, tachograph live streams and serial sensor telemetry. When paired with Plaspy, fleets benefit from continuous position visibility, remote tachograph monitoring and streamlined maintenance workflows that improve uptime and reduce operating costs.

## Key Highlights

- Plaspy compatible for immediate integration into your fleet management platform and dashboards.
- Dual‑channel GNSS \(L1 + L5\) via a separate GNSS module for improved positioning accuracy in challenging environments.
- LTE Cat M1 and NB‑IoT \(NB2\) primary connectivity with 2G GSM fallback for global coverage and resilient communications.
- High‑capacity backup battery that maintains position reporting and alerts during vehicle power loss.
- Rich vehicle I/O: 2x RS232, 1x RS485, advanced CAN and J1939 interfaces for deep telemetry, EBS and engine data reading.
- Direct support for tachograph live data via K‑Line, Tacho CAN or FMS connections—suitable for remote tachograph monitoring and file download workflows.
- Ready for fleet telematics: external antennas for GNSS and cellular and compatibility with Teltonika accessories \(CAN adapters, cables, RFID and temperature sensors\).

## How It Works with Plaspy

Connecting the FMM650 to Plaspy brings rich vehicle context into your tracking platform. Plaspy ingests the tracker’s GNSS position, telemetry from CAN/J1939 and serial interfaces, and status information from the device’s backup battery and external sensors. Fleet operators receive real-time tracking, driver and vehicle events, and remote tachograph insights for compliance and optimization.

- Real‑time location and high‑accuracy GNSS updates \(dual L1 + L5 channels\) for precise route and asset tracking.
- Tachograph live data and file download support via K‑Line, Tacho CAN or FMS—visible inside Plaspy for compliance and driver activity monitoring.
- CAN / J1939 telemetry for engine diagnostics, DTC reading, fuel monitoring and EBS/trailer data integration.
- Serial integrations \(RS232 / RS485\) for thermographs, RFID readers and other on‑board equipment that feed data into Plaspy reports.
- Continuous reporting during power loss using the built‑in backup battery, improving anti‑theft visibility and post‑theft investigation.
- Remote device management: combine with Teltonika tools \(FOTA WEB, TachoSync, Teltonika Configurator\) for firmware updates and configuration while Plaspy maintains operational telemetry.
