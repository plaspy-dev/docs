# Teltonika - FMC920 Features

This page provides a public feature overview of the Teltonika FMC920 and how its capabilities map to Plaspy for real time tracking and fleet management. It focuses on user facing functions, practical deployment value, and how the tracker’s telemetry and sensor data are typically used inside Plaspy workflows.

Exact feature availability can vary by firmware, hardware revision, regional variant and specific installation. Some FMC920 variants have End of Life notices and optional features such as jamming detection or regional radio configurations, so confirm current capabilities, firmware and certificates with Teltonika before procurement.

## Feature Overview

The FMC920 is a compact 4G LTE Cat 1 tracker designed for discreet vehicle and asset installations while offering core telemetry, Bluetooth LE sensor support, and anti theft controls. When integrated with Plaspy, the device provides live position updates and sensor data that feed maps, alerts and reports for operational oversight.

- Slim 12 mm housing for concealed installations in vehicles and assets.
- 4G LTE Cat 1 connectivity with regional variants available to meet local network needs.
- Bluetooth LE support to pair with wireless beacons and environmental or condition sensors.
- Built in backup battery to continue reporting during temporary power loss.
- Remote engine blocking (immobilizer) capability for anti theft response workflows.
- Optional regional features such as jamming detection depending on variant.

## Core Features of Teltonika - FMC920

- GNSS position reporting for real time vehicle and asset location.
- 4G LTE Cat 1 cellular connectivity with related Cat M1 NB IoT and 2G variants available in some models.
- Bluetooth Low Energy for pairing with temperature, humidity, magnet, movement and liquid level beacons and sensors.
- Compact form factor (12 mm height) suitable for tight installation spaces.
- Built in backup battery to maintain reporting during short power interruptions.
- Remote engine blocking (immobilizer) support for theft mitigation.
- Regional hardware variants and optional features such as jamming detection.
- Plaspy compatibility for integration into centralized tracking, alerting and reporting workflows.

## How These Features Work with Plaspy

Plaspy ingests GNSS position reports and telemetry from the FMC920 to present real time maps, alerts and historical routes so operators can monitor fleets and respond to events. Plaspy automatically detects compatible tracker protocols and consolidates device data into dashboards and notifications for straightforward operational use.

- Real time location updates and historical route playback visible on Plaspy maps.
- Bluetooth sensor data appears alongside location and can be used in Plaspy alerts and reports.
- Immobilizer actions and anti theft events are surfaced for rapid operator response and logging.
- Sensor and telemetry alerts such as tamper, door or beacon thresholds can trigger notifications and reporting workflows.
- Device status and basic health indicators are shown in Plaspy to aid device management and troubleshooting.

## Typical Use Cases

- Anti theft workflows: real time alerts with remote immobilization and tracking to recover vehicles.
- Concealed tracking for rental vehicles, service fleets and high value assets where space is limited.
- Cold chain or temperature sensitive cargo monitoring using Bluetooth temperature and humidity sensors.
- Door and tamper monitoring using BLE magnet and movement beacons to detect unauthorized access.
- Mixed fleet deployments where regional cellular variants are used to match local network availability.
- Short term power loss resilience during vehicle power interruptions thanks to the backup battery.

## Feature Availability Notes

- Feature sets vary by firmware level, hardware revision and regional model; confirm the specific variant you plan to deploy.
- Some FMC920 variants are noted as End of Life; check availability, support and replacement options with Teltonika.
- Bluetooth sensor behavior and supported beacon types depend on firmware and pairing configuration.
- Optional features such as jamming detection and regional band support are variant dependent.
- Installation wiring and configuration affect which outputs or immobilizer functions are available in a given installation.
