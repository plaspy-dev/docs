# Teltonika - FMB910 Features

This page provides a public overview of the Teltonika FMB910 feature set and how those capabilities are presented when the device is used with Plaspy. It focuses on practical, non sensitive information about real time tracking, event streams, and sensor data that Plaspy can ingest to support fleet monitoring, basic remote control workflows, and incident visibility.

Exact feature availability and behaviour can vary by device firmware, hardware revision, installation method, regional variant, and how the manufacturer implements specific functions. Use the content here as a compatibility and capability guide and review official Teltonika documentation for the most current device specific details.

## Feature Overview

The FMB910 is a compact 2G vehicle tracker designed for cost conscious fleet deployments where 2G remains available. It provides straightforward position reporting and event streams that integrate into telematics platforms like Plaspy to deliver location awareness, alerting, and basic remote control workflows.

- Reliable real time GPS tracking and historical position reporting for vehicle visibility.
- Configurable 3 axis accelerometer used for crash detection and motion events.
- I O driven inputs and outputs for ignition monitoring and engine block remote control workflows.
- Bluetooth Low Energy support for pairing external sensors and beacons to extend monitoring.
- Eco driving telemetry to support driver behaviour analysis and operational optimisation.
- Compact 2G design suited for low cost installations where network availability allows.

## Core Features of Teltonika - FMB910

- Real time GPS position reporting and movement history suitable for fleet monitoring.
- Built in 3 axis accelerometer with configurable crash detection and event generation.
- Bluetooth Low Energy support for external sensors and beacons to report environmental or asset status.
- Digital inputs and outputs including ignition input and engine block control for anti theft workflows.
- Eco driving and basic driving behaviour telemetry to inform reports and safety programs.
- Remote firmware and configuration management via Teltonika FOTA WEB as provided by the manufacturer.
- Compact vehicle mounted form factor and 2G network support for cost efficient deployments.

## How These Features Work with Plaspy

When the FMB910 is connected to Plaspy, the device sends location, event, and sensor data that Plaspy ingests into maps, alerts, and historical reports. Plaspy automatically detects common tracker protocols and can surface the FMB910 data streams for monitoring and operational workflows.

- Live map views and location history based on the FMB910 GPS position reports.
- Incident alerts and investigation data derived from accelerometer and crash detection events.
- Ignition and engine block state visibility used to support anti theft monitoring and configured immobilization procedures.
- BLE sensor readings and beacon detections forwarded into Plaspy for environmental or asset monitoring.
- Eco driving metrics and aggregated telemetry presented in reports to help fleets reduce consumption and improve safety.

## Typical Use Cases

- Cost conscious fleet tracking for small and medium sized vehicle fleets that need basic real time visibility.
- Anti theft monitoring and stolen vehicle recovery using location reporting and I O triggered immobilization where configured.
- Incident management and crash reconstruction using accelerometer based detection and event timelines.
- Environmental or asset state monitoring by pairing BLE sensors and beacons for cargo or tamper detection.
- Telematics programs that include eco driving analysis and driver performance reporting.
