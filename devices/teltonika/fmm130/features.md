# Teltonika - FMM130 Features

This page provides a public, non sensitive overview of the Teltonika FMM130 and how its capabilities map to Plaspy for fleet tracking, telemetry and sensor monitoring. It focuses on practical, user facing features and explains what you can expect when using FMM130 devices with Plaspy.

Exact availability and behavior of specific features depend on the installed firmware version, the hardware revision or variant, local network support, and how the device is installed and configured by the integrator. For definitive technical details and the latest firmware notes please consult the manufacturer documentation.

## Feature Overview

The FMM130 is a compact vehicle and asset tracker designed for professional telematics. It combines low power wide area cellular radios with sensor support and vehicle data integration to deliver location, environmental telemetry and remote control features useful in fleet and asset workflows.

- LTE Cat M1 and NB IoT support for efficient cellular connectivity with 2G fallback in selected variants
- Bluetooth Low Energy support for external sensors that report temperature, humidity, magnet or movement status
- CAN bus integration and vehicle parameter reporting for odometer and engine related data where available
- Multiple digital and analog inputs plus impulse input support for fuel flow sensors and other external signals
- Backup battery to continue sending basic reports during main power interruptions
- Remote firmware and configuration management via Teltonika remote tools

## Core Features of Teltonika - FMM130

- LTE Cat M1 and NB‑IoT connectivity for low power wide area telemetry and regional radio variants
- BLE sensor support to ingest environmental and beacon data into telematics workflows
- CAN bus integration for vehicle diagnostics and parameters where the vehicle and firmware support it
- Impulse input and configurable digital/analog inputs for integration with fuel meters and external sensors
- Backup battery reporting to provide visibility during power loss events
- Remote firmware update and configuration capabilities through Teltonika management tools
- Compact form factor suitable for vehicle and asset mounting in professional deployments

## How These Features Work with Plaspy

Plaspy receives the location fixes and telemetry that the FMM130 provides and presents them as unified tracking, reporting and alerting elements. Plaspy’s platform can use the device data to present location, sensor readings and vehicle parameters together for operational insight.

- Live location and route playback based on GNSS fixes reported by the device
- BLE sensor telemetry visible in Plaspy for environmental monitoring and cargo condition checks
- CAN derived parameters and odometer values shown in diagnostics and historical reports when available
- Fuel and impulse input events reflected in consumption reports and alerts in Plaspy
- Backup battery or power loss events visible as device status changes to aid asset security workflows

## Typical Use Cases

- Fleet tracking and route history for cars, vans, trucks and buses with centralized visibility
- Fuel monitoring and theft detection using impulse inputs and CAN based fuel readings
- Cold chain and sensitive cargo monitoring via BLE temperature and humidity sensors
- Remote immobilization and anti theft workflows when I O outputs are configured for that purpose
- Special machinery telemetry where CAN integration provides engine hours and operational parameters
- Asset security with movement and magnet status via BLE beacons plus backup battery reporting

## Feature Availability Notes

- Feature presence depends on firmware version and device hardware variant shipped by the manufacturer
- Regional radio support and fallback options vary by SKU and local cellular operator coverage
- CAN, BLE and certain I O functions require correct wiring, adapters or optional configurations during installation
- Some telemetry and remote control features require corresponding configuration both on the device and within Plaspy to appear correctly
- For the latest capability details and firmware change logs consult the official manufacturer documentation

Using the FMM130 with Plaspy provides a single place to view location, vehicle parameters and environmental sensor data together. That combined visibility helps operations teams monitor routes, detect anomalies in fuel or engine behavior, and respond to cargo condition alerts more quickly.
