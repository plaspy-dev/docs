# Teltonika - FMB010 Features

This page describes the public feature context for using the Teltonika FMB010 tracker with Plaspy. It focuses on the practical capabilities you can expect when the FMB010 is connected to Plaspy for real-time location, basic telematics, sensor inputs, and incident awareness. Use this guide to understand which features are visible in Plaspy and how the device is typically used in fleet and asset workflows.

Exact feature availability depends on the unit you receive and how it is installed. Firmware version, hardware revision or regional variants, the type of OBD-II installation or accessory cables, and the manufacturer's implementation can all affect which functions are present and how they behave in practice. Always consult the device documentation for the most current, device specific details.

## Feature Overview

The FMB010 is a compact, plug-and-play OBD-II GPS tracker designed for fast vehicle installation and straightforward fleet telematics. It brings core tracking, basic vehicle telemetry and external sensor support into Plaspy quickly, making it suitable where simplicity, reliability and continuous reporting are priorities.

- OBD-II plug-and-play form factor for rapid vehicle installation and access to basic vehicle telemetry.
- Real-time GPS tracking for immediate location visibility and historical route playback in Plaspy.
- Internal backup battery to continue reporting during main power loss for improved anti-theft monitoring.
- Bluetooth Low Energy support to pair external beacons and sensors such as temperature, humidity, magnet and movement sensors.
- Built-in 3-axis accelerometer with configurable crash detection and crash trace data for incident reporting.
- Eco driving functions and basic fuel monitoring insights to support efficiency and driver behaviour analysis.

## Core Features of Teltonika - FMB010

- OBD-II plug-and-play installation for fast deployment across vehicles.
- Internal backup battery that enables reporting when vehicle power is interrupted.
- Bluetooth Low Energy connectivity for pairing external beacons and environmental or proximity sensors.
- Built-in 3-axis accelerometer with configurable crash detection and crash trace reporting.
- Eco driving functions to capture driving style metrics and support fuel monitoring insights.
- Real-time GPS location reporting compatible with Plaspy dashboards.
- Quad-band 2G cellular support to provide connectivity in supported markets.
- Compact form factor designed specifically for vehicle OBD-II ports.

## How These Features Work with Plaspy

When the FMB010 is connected to Plaspy, the device streams location and available telemetry into Plaspy dashboards for monitoring and reporting. Plaspy automatically recognises compatible tracker data streams and presents location, events and sensor inputs alongside fleet management tools.

- Real-time location updates and route history become available in Plaspy for live monitoring and playback.
- Crash detection and crash trace data from the accelerometer can trigger incident alerts and be included in event logs.
- OBD-II telemetry and eco driving metrics appear in telematics reports and help drive efficiency analyses.
- BLE sensor readings such as temperature, humidity, magnet and movement integrate as supplementary sensor telemetry within Plaspy.
- Continued reporting from the internal backup battery supports anti-theft workflows and escalation when primary power is lost.

## Typical Use Cases

- Fleet tracking and route monitoring with quick OBD-II deployment across a vehicle fleet.
- Anti-theft detection and recovery workflows using backup battery reporting and BLE beacon assistance.
- Crash event logging and incident workflows using accelerometer based crash detection and trace data.
- Temperature sensitive or condition monitoring for trailers and cargo by pairing BLE sensors.
- Driver behaviour and eco driving oversight to support fuel monitoring and operational efficiency.
- Basic vehicle lifecycle and maintenance planning informed by OBD-II derived telemetry and usage patterns.

## Feature Availability Notes

- Firmware version and manufacturer configuration determine which telematics and sensor features are enabled on a given unit.
- Hardware revisions and regional variants can affect cellular band support and the presence of certain accessories or cable options.
- Installation type matters: direct OBD-II installation typically provides richer vehicle telemetry than remote installations using extension cables.
- BLE sensor support requires compatible external beacons or sensors and correct pairing procedures as described by the manufacturer.
- Check manufacturer product notes for order codes and EOL information before procurement to ensure the specific package meets your requirements.
