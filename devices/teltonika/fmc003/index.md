# Teltonika - FMC003

![FMC003](./tracker.png)

The FMC003 by Teltonika is a plug-and-play OBD-II GPS tracker designed to be Plaspy compatible for fleet management, logistics and e-mobility programs. Delivering LTE Cat 1 \(4G\) connectivity with 2G fallback and OEM-level OBD parameter reading, the FMC003 supplies accurate telemetry — including odometer, fuel level and EV battery metrics — with minimal installation time. Its OBD-II form factor makes it an ideal GPS tracker for rapid deployment across mixed fleets and electric vehicle groups.

Built for real-world fleet management and telematics integrations, the FMC003 reduces setup complexity while increasing data fidelity. When paired with Plaspy, fleet operators get real-time tracking, fuel monitoring, diagnostic insight and EV battery consumption data in a single feed, enabling faster decisions for maintenance, anti-theft response and operational optimization.

## Key Highlights

- Plug-and-play OBD-II installation for fast, tool-free deployment across vehicles — ideal for rapid fleet rollouts.
- LTE Cat 1 \(4G\) connectivity with 2G fallback ensures reliable cellular telemetry for real-time tracking and diagnostics.
- OEM-level telemetry: reads true odometer and fuel level from the vehicle’s ECU for accurate fuel monitoring and maintenance scheduling.
- Explicit support for electric vehicles with compatibility listed for 150+ EV models — enables battery and consumption tracking for e-mobility fleets.
- Flexible deployment options with Teltonika accessories \(extension cables, OBD-II to FMS adapter\) for vehicle- or heavy-duty installations.
- Remote device management through Teltonika tools \(FOTA WEB and Teltonika Configurator\) simplifies updates and configuration at scale.
- SKU variants and frequency options available for regional compliance and optimal network coverage.

## How It Works with Plaspy

FMC003 integrates with Plaspy by delivering continuous vehicle telemetry and location information that Plaspy ingests for real-time tracking, reporting and alerting. Because the FMC003 reads OEM OBD parameters, Plaspy can present high-fidelity data — such as true odometer values, fuel level and EV battery consumption — alongside location and event data, improving fleet visibility and analytics.

- Real-time tracking and telemetry: vehicle position and OBD-sourced parameters visible in Plaspy dashboards for live fleet monitoring.
- Odometer and fuel monitoring: accurate distance and fuel level data support odometer-based maintenance scheduling and fuel monitoring reports.
- EV monitoring: battery and consumption metrics for supported electric vehicles enable Plaspy to track range, consumption and charging events.
- Remote diagnostics and management: device firmware and configuration can be updated remotely via Teltonika tools and reflected in Plaspy workflows.
- Anti-theft and immobilization workflows: precise location plus platform-level immobilizer controls \(where supported by the vehicle interface and Plaspy integration\) help accelerate recovery and response.
