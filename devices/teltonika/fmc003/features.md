# Teltonika - FMC003 Features

This page provides a public feature overview describing how the Teltonika FMC003 works as a Plaspy compatible OBD II GPS tracker. It focuses on the practical capabilities you can expect when the FMC003 is used with Plaspy for fleet management, logistics, and e mobility programs.

Exact feature availability and behavior can vary based on device firmware, hardware revision, installation method, and manufacturer implementation. Review product release notes and Teltonika documentation for device specific details before deployment.

## Feature Overview

The FMC003 is a plug and play OBD II tracker designed for fast deployment across mixed fleets, delivering OEM sourced telemetry and cellular connectivity so platforms like Plaspy can receive higher fidelity vehicle data. It is targeted at operators who need reliable location, odometer, fuel and EV battery metrics with minimal installation time.

- Tool free OBD II installation for rapid vehicle rollouts and reduced installation time
- LTE Cat 1 4G connectivity with 2G fallback to maintain telemetry across networks
- OEM level telemetry including odometer, fuel level and EV battery metrics for more accurate reporting
- Explicit compatibility with a wide set of electric vehicle models to support e mobility fleets
- Support for Teltonika accessories such as extension cables and OBD II to FMS adapter for flexible installations

## Core Features of Teltonika - FMC003

- Plug and play OBD II form factor for quick connection to passenger cars and light commercial vehicles
- Cellular connectivity designed for consistent telemetry and location reporting
- OEM parameter reading that captures true vehicle odometer and fuel level from the ECU
- EV battery and consumption metrics for supported electric vehicle models
- Compatibility with Teltonika remote management tools for firmware updates and configuration
- Accessory ecosystem including extension cables and OBD II to FMS adapter for varied mounting needs
- Multiple SKU and regional frequency options to match local cellular networks

## How These Features Work with Plaspy

When configured to report into Plaspy, the FMC003 supplies location and onboard vehicle parameters that Plaspy ingests for live monitoring, reporting, and operational workflows. Plaspy can combine OBD sourced values with location and event data to improve visibility and decision making.

- Real time vehicle position visible in Plaspy maps and dashboards for live tracking
- Odometer and fuel level values presented in platform reports to support maintenance schedules and fuel monitoring
- EV battery and consumption metrics integrated into Plaspy views for e mobility oversight where the vehicle is supported
- Remote device configuration and firmware updates managed by Teltonika tools and reflected in Plaspy workflows
- Support for anti theft and recovery workflows using precise location data and platform controls where vehicle interfaces allow

## Typical Use Cases

- Rapid fleet rollouts where plug and play OBD II installation reduces installation time and complexity
- Fleet management combining location, odometer and fuel level to optimize maintenance and asset utilization
- Fuel monitoring and cost control using OEM fuel level readings instead of estimations
- Electric vehicle fleet operations tracking battery consumption and range related metrics across supported vehicles
- Preventive maintenance planning driven by accurate odometer readings and vehicle telemetry
- Anti theft monitoring and recovery workflows using real time location and event alerts

## Feature Availability Notes

- Firmware versions and Teltonika tool updates can add or change telemetry behavior and available parameters
- Hardware revisions and SKU regional variants may affect supported cellular bands and exact connectivity performance
- Some telemetry fields are vehicle dependent and require the vehicle ECU to expose those OBD parameters
- Installation method and use of accessories such as extension cables or FMS adapters can affect how the device is mounted and powered
- Confirm EV model coverage and parameter support when planning e mobility deployments

## Why Use Plaspy with These Features

Using the Teltonika FMC003 with Plaspy gives teams a practical, data focused approach to vehicle visibility. The combination of plug and play OBD II installation and OEM level telemetry lets operators collect higher fidelity inputs for maintenance planning, fuel oversight, and EV operations without complex wiring or lengthy installation windows.
