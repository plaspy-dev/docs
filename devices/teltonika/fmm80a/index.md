# Teltonika - FMM80A

![FMM80A](./tracker.png)

The Teltonika FMM80A is a plug-and-play OBD‑II GPS tracker engineered for fast deployment and dependable telematics. Plaspy compatible out of the box, the FMM80A delivers real-time tracking and fleet management data with minimal installation effort — simply plug into the vehicle’s OBD‑II port to begin telemetry and position monitoring for fleet, rental, or delivery applications.

The device combines LTE Cat M1 / NB‑IoT cellular connectivity with 2G fallback, Bluetooth Low Energy support for external beacons and sensors, and a configurable 3‑axis accelerometer for crash detection and trace capture. This FMM80A model is optimized for the North American market and integrates with Teltonika’s remote management tools for easy firmware updates and configuration — making it an efficient choice for scalable Plaspy-compatible tracking solutions.

## Key Highlights

- Plaspy compatible plug-and-play OBD‑II GPS tracker for quick time-to-deployment and immediate real-time tracking.
- LTE Cat M1 / NB‑IoT cellular connectivity with 2G fallback for broad North American coverage and low-power telemetry.
- Built-in BLE \(Bluetooth® Low Energy\) to pair with external sensors and beacons \(temperature, humidity, magnet, movement\) for condition monitoring.
- Configurable 3‑axis accelerometer provides crash detection and detailed crash trace data for post-event analysis.
- Designed for fleet management, rental/car-sharing, delivery logistics, and rapid installation programs.
- Integrates with Teltonika remote management ecosystem \(FOTA, configurator, knowledge base\) for centralized device control.
- North America frequency support and packaging variants to suit distribution and single‑unit deployment needs.

## How It Works with Plaspy

When paired with Plaspy, the FMM80A streams location and telematics data to the platform, enabling live maps, alerts and historical reports. The plug-and-play OBD‑II connection supplies vehicle data and power, while BLE sensors expand telemetry for temperature, humidity and movement monitoring. Plaspy users can combine these inputs to build dashboards, trigger anti-theft alerts, and run fleet-level analytics.

- Real-time GPS location and telemetry updates sent to Plaspy for live tracking and route monitoring.
- Crash detection events and accelerometer traces are transmitted for incident review and reporting.
- BLE sensor data \(temperature, humidity, magnet, movement\) integrates into Plaspy for condition monitoring and alerts.
- OBD‑II telematics access enables vehicle parameters \(fuel/consumption-related telemetry and ignition status\) where available from the vehicle’s CAN/OBD system.
- Remote firmware updates and configuration via Teltonika management tools, enabling centralized device administration for Plaspy deployments.
