# Teltonika - FMM13A Features

This page describes the public feature context for using the Teltonika FMM13A with Plaspy. It focuses on the practical capabilities you can expect when the FMM13A is deployed as a Plaspy compatible tracker and how its telemetry and control features surface in Plaspy for real time monitoring and reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a general guide and consult the official Teltonika documentation or your device configuration to confirm the specific functions available for your unit.

## Feature Overview

The Teltonika FMM13A is a compact vehicle tracking terminal built for North American deployments that emphasizes continuous connectivity and flexible telemetry inputs. When used with Plaspy, the device provides location, sensor readings, and remote control signals that help fleets maintain visibility and respond to incidents.

- LTE Cat M1 connectivity suited to North American LTE FDD bands for reliable cellular reporting.
- Built in backup battery to continue location and telemetry reporting during main power loss.
- Flexible inputs and outputs plus impulse input support for fuel meter integration and event sensing.
- CAN adapter compatibility to ingest vehicle data such as fuel level, odometer, RPM and engine temperature.
- Remote engine blocking and immobilizer capability for theft mitigation and fleet control.

## Core Features of Teltonika - FMM13A

- 4G LTE Cat M1 cellular modem designed for North American LTE FDD networks.
- Standard communications module listed in orders for consistent modem behavior.
- Internal backup battery to maintain reporting during power interruptions.
- Flexible digital inputs and outputs for ignition, event detection, and external sensors.
- Impulse input support for fuel flow meter connections and fuel monitoring workflows.
- Compatibility with CAN bus adapters to read vehicle telemetry like fuel level and odometer.
- Remote engine blocking or immobilizer support for controlled vehicle shutdown.
- Bluetooth Low Energy support for ID beacons and sensor pairing in trailer or sensor workflows.
- Support for Teltonika remote management workflows for firmware and configuration updates.

## How These Features Work with Plaspy

When the FMM13A is connected to Plaspy, device telemetry and events are normalized and displayed through Plaspy dashboards and reports so teams can act on location and vehicle data in real time.

- Real time location updates and movement history visible on Plaspy maps for route oversight.
- Telemetry from impulse inputs and CAN adapters presented as sensor readings and events in Plaspy reports.
- Ignition and immobilizer status reported to Plaspy to support anti theft alerts and remote control actions.
- BLE ID beacon signals and paired sensor data available in Plaspy when used in trailer or sensor monitoring setups.
- Plaspy automatically detects common tracker protocols and normalizes FMM13A data for consistent visualization and reporting.

## Typical Use Cases

- Fleet telematics for delivery and service vehicles with continuous location and operational telemetry.
- Trailer identification and trailer tracking using BLE ID beacons paired to the FMM13A.
- Fuel monitoring and fuel theft detection using impulse input fuel meters and CAN derived telemetry.
- Anti theft and recovery workflows using the internal backup battery plus remote immobilizer controls.
- Cold chain or sensor augmented monitoring when the tracker is paired with external sensors.
- General asset and workforce tracking where compact installation and reliable reporting are required.
