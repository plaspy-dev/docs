# Teltonika - FM 2100

<div className="device-logo">
![FM 2100](./logo.jpg)
</div>

The Teltonika FM 2100 is a compact GPS tracker designed to determine the coordinates of remote objects and transmit that data over GSM. It supports GPRS class 10 and SMS communication, operates on quad band GSM frequencies for broad regional coverage, and provides basic I O controls with two digital inputs and two digital outputs. The device is packaged in a robust casing and includes visual status LEDs and NMEA output for navigation related workflows.

As a model compatible with Plaspy, the FM 2100 can feed location and basic status information into Plaspy for real time monitoring and operational oversight. Its combination of reliable position reporting, simple remote I O control, and durable design makes it a practical choice for businesses that want to add this tracker into Plaspy for fleet visibility, alerts, and routine reporting.

## Key Highlights

- Real time location reporting suitable for vehicles and mobile assets
- GPRS class 10 and SMS communication for data and fallback messaging
- Quad band GSM compatibility for broad regional coverage
- Two digital inputs and two digital outputs for external device control and monitoring
- NMEA output available for navigation or position export workflows
- Durable casing with LED indicators for clear operational feedback

## How It Works with Plaspy

The FM 2100 delivers periodic location updates and basic input output status that Plaspy can ingest to provide unified fleet and asset visibility. When connected to Plaspy, this tracker enables centralized monitoring, event processing, and historical reporting alongside other devices in your fleet.

- Map based live tracking to view real time positions of assets and vehicles
- Event and status monitoring using digital input output changes to trigger alerts
- Historical route and movement logs for operational review and reporting
- Configurable notifications in Plaspy for geofence, movement, and custom events
- Centralized device management and visibility alongside other compatible trackers

## Typical Use Cases

- Routine fleet location and movement tracking for small to mid sized vehicle fleets
- Monitoring of rental vehicles or leased assets where basic I O control is useful
- Asset tracking for equipment that requires ruggedized hardware
- Simple navigation data export using NMEA output for downstream systems
- Basic remote telemetry and alerting where SMS or GPRS based updates are acceptable
