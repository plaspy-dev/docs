# Teltonika - FMB120 Features

This page provides a public feature overview for the Teltonika FMB120 and explains how those capabilities are used with Plaspy. It focuses on practical, non-sensitive details about location reporting, basic telemetry, and how the device integrates into Plaspy workflows for monitoring and remote control.

Exact feature availability can vary by firmware version, hardware revision, regional SKU, and installation choices. Always verify the specific capabilities of your device and firmware state against the manufacturer's documentation and the deployed unit before planning a production rollout.

## Feature Overview

The FMB120 is a compact, cost oriented vehicle tracker designed for continuous GPS location reporting and basic telematics on 2G networks. In practical use it provides live position updates, event reporting via digital inputs, and options to extend monitoring with external sensors and ID readers.

- Real time GPS position reporting for live tracking and historical route playback.
- Remote immobilizer control to support anti theft and fleet disable workflows.
- Bluetooth LE support for connecting external beacons and sensor peripherals.
- 1-Wire port and RFID iButton reader support for temperature probes and driver or asset ID.
- Standard digital I O for ignition sensing and vehicle event inputs.
- Multiple SKUs and packaging options including internal battery variants for flexible deployment.

## Core Features of Teltonika - FMB120

- Continuous GPS location tracking suitable for vehicle mapping and route history.
- 2G GSM cellular connectivity for economical telemetry in supported regions.
- Remote engine immobilization capability to assist anti theft responses.
- Bluetooth Low Energy connectivity for external sensors and beacons.
- 1-Wire interface for direct temperature probe integration.
- RFID iButton reader compatibility for driver or asset identification workflows.
- Standard digital inputs and outputs for ignition status and event monitoring.
- Compact form factor with multiple packaging and battery options.

## How These Features Work with Plaspy

When paired with Plaspy, the FMB120 transmits position and status data into the platform so teams can monitor vehicles, review event history, and trigger workflows. Plaspy ingests location and telemetry and surfaces that information in live maps, alerts, and reports for operational oversight.

- Live location updates and trip playback appear in Plaspy dashboards and maps.
- Digital I O events such as ignition or door sensors are processed for trip logging and rule triggers.
- Remote immobilizer commands can be issued from Plaspy as part of anti theft or fleet control procedures.
- Bluetooth LE sensor data and 1-Wire temperature readings are reported into Plaspy for environmental monitoring when compatible peripherals are used.
- Driver or asset ID events from RFID or iButton readers are available for assignment and audit trails.
- Plaspy automatically detects common tracker protocols so onboarding FMB120 devices is straightforward in most deployments.

## Typical Use Cases

- Anti theft monitoring and remote vehicle immobilization for stolen or unauthorized use.
- Temperature monitored transport using BLE sensors or 1-Wire probes for sensitive cargo.
- Rental, taxi, and carshare fleets using RFID or iButton for driver identification and trip control.
- Basic fleet management for small and mid sized fleets focused on location, trip logging, and simple alerts.
- Door, magnet, or tamper alerts using external sensors paired via Bluetooth or standard digital inputs.
- Cost sensitive deployments where 2G connectivity and compact hardware reduce ongoing expenses.
