# Teltonika - FMB001 Features

This page provides a public features overview for the Teltonika FMB001 as a Plaspy compatible GPS tracker. It summarizes the practical capabilities you can expect when using the FMB001 with Plaspy for real time tracking, telemetry collection, and asset condition monitoring without exposing private implementation details.

Exact feature availability can vary by device firmware, hardware revision, regional order code, and the details of how the unit is installed in the vehicle. Review device labels, your supplier documentation, and the official Teltonika documentation for the most current model specifics before deployment.

## Feature Overview

The Teltonika FMB001 is a compact OBD II plug and play tracker designed to collect vehicle location and OBD sourced telemetry while extending monitoring via Bluetooth LE sensors. It focuses on simple installation and straightforward integration so fleets and individual vehicle owners can gain location and operational visibility quickly.

- Plug and play OBD II form factor for quick installation in compatible vehicles
- Reads vehicle telemetry such as true odometer, fuel level, mileage and engine RPM
- GNSS based location reporting for real time tracking and route history
- Bluetooth LE support for external sensors and beacons to add temperature humidity magnet detection and movement monitoring
- Remote device management support through Teltonika FOTA WEB and Teltonika Configurator for firmware and configuration updates

## Core Features of Teltonika - FMB001

- OBD II plug and play interface for rapid installation without complex wiring
- Direct reading of vehicle parameters including true odometer fuel level mileage and engine RPM
- GNSS positioning for vehicle location tracking and trip recording
- Bluetooth LE connectivity for external beacons and sensors such as temperature humidity magnet detection and movement monitoring
- 2G GSM cellular connectivity with regional order code variants for different markets
- Remote management and firmware update support via Teltonika FOTA WEB and Teltonika Configurator
- Compact form factor suited to fleet rollouts and quick service installations

## How These Features Work with Plaspy

When the FMB001 is installed and reporting, Plaspy ingests location and telemetry streams to present unified vehicle views, historical reports, and alerting. Plaspy's platform lets operators combine OBD data and Bluetooth sensor inputs for a single operational picture.

- Real time location updates and position history visible in Plaspy for live monitoring and route analysis
- OBD sourced telemetry such as odometer fuel level mileage and RPM available in Plaspy for maintenance scheduling and operational analytics
- Bluetooth LE sensor data forwarded into Plaspy alongside location so environmental and movement events are associated with vehicle trips
- Remote configuration and firmware lifecycle events coordinated with device management workflows to keep deployed units consistent
- Event and state inference in Plaspy using vehicle telemetry to support ignition movement and maintenance related rules
