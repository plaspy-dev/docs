# Teltonika - FMB920 Features

This page provides a public feature overview for the Teltonika FMB920 and how its capabilities surface when used with Plaspy. It focuses on practical, non sensitive information about the device role in Plaspy for live tracking, event monitoring, and basic telematics visibility.

Exact feature availability and behaviour can vary by device firmware, hardware revision, installation type, and manufacturer implementation. For device specific technical details and the latest firmware notes, always consult the manufacturer documentation in addition to this summary.

## Feature Overview

The FMB920 is a compact, low profile GPS tracker designed for discreet vehicle installations and continuous telemetry reporting to platforms like Plaspy. It combines position reporting with basic security and sensor inputs to support anti theft workflows and simple fleet monitoring.

- Slim 12 mm form factor that suits tight installation spaces and discreet placements.
- Internal backup battery to maintain reporting and anti theft monitoring during power loss.
- Remote immobilizer support to enable anti theft response and control workflows.
- Telematics inputs for ignition, door, and alarm status to enable event driven alerts.
- Bluetooth LE support for pairing with external beacons and sensors to extend monitoring capabilities.
- Remote management support using Teltonika configuration and FOTA tools for updates and setup.

## Core Features of Teltonika - FMB920

- Compact physical design for discreet mounting in small vehicles or mobile assets.
- GPS position tracking for real time location and historical playback.
- Internal backup battery to provide limited operation when external power is removed.
- Remote immobilizer capability to assist with anti theft and recovery procedures.
- Standard telematics inputs such as ignition, door, and alarm status for event detection.
- Basic fuel monitoring inputs to detect unusual consumption or tampering when configured.
- Bluetooth LE connectivity for external beacons and compatible Bluetooth sensors.
- Support for Teltonika remote management tools for firmware updates and device configuration.

## How These Features Work with Plaspy

When an FMB920 is connected to Plaspy, the tracker’s telemetry and event data are forwarded to the Plaspy platform so operators can monitor vehicles and assets in near real time. Plaspy automatically detects supported tracker protocols and consolidates reports into the platform interface.

- Real time location updates and historical position playback visible on Plaspy maps.
- Ignition, door, and alarm status events appear in Plaspy for event-based monitoring and simple driver activity analysis.
- Fuel monitoring inputs reported to Plaspy can be used to trigger alerts or support basic consumption reviews.
- Remote immobilizer state and controls can be surfaced in Plaspy workflows for anti theft response.
- Bluetooth LE sensor and beacon readings routed through the tracker are available in Plaspy for extended asset condition monitoring.

## Typical Use Cases

- Anti theft and stolen vehicle response with remote immobilizer and backup battery monitoring.
- Small fleet track and trace for light vehicles, deliveries, and service fleets.
- Basic fuel monitoring and unusual consumption detection for operational oversight.
- Monitoring of trailers or cargo using Bluetooth sensors for environmental or movement indicators.
- Discreet asset protection on scooters, light equipment, or concealed vehicle installations.
