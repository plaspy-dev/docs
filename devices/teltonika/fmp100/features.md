# Teltonika - FMP100 Features

This page provides a public, features-oriented overview of the Teltonika FMP100 GPS tracker and how its capabilities map to Plaspy workflows. It focuses on the practical functions, supported sensors, and interaction points you can expect when using the FMP100 with Plaspy for location, event, and telemetry visibility.

Exact availability and behaviour of specific features can vary by device firmware, hardware revision, regional variant, and how the unit is installed or paired with accessories. For device configuration, firmware updates, and the most current technical details consult Teltonika documentation and product resources.

## Feature Overview

The FMP100 is a compact plug and play tracker designed to be powered from a vehicle cigarette lighter socket and provide rapid deployment tracking with optional BLE sensor telemetry. It is aimed at short-term installations, car sharing, rentals, and pilot fleets where ease of installation and quick provisioning are primary requirements.

- Plug and play power via vehicle cigarette lighter for fast, non permanent installation.
- Native GPS positioning for continuous location reporting to Plaspy.
- Bluetooth Low Energy support for pairing with compatible EYE Beacons and EYE Sensors to capture temperature, humidity, magnet detection, and movement telemetry.
- Built-in user button plus RGB LED and buzzer for driver interaction and local event signaling.
- Integrated 1A charger output to power or charge small devices while tracking.
- Remote configuration and firmware update workflows supported through Teltonika FOTA and web tools.

## Core Features of Teltonika - FMP100

- Compact plug and play form factor powered from the cigarette lighter for rapid deployment.
- GPS positioning to provide real time location updates to Plaspy.
- Bluetooth Low Energy for external sensor telemetry when paired with compatible EYE accessories.
- Built in user button for event triggering such as panic or trip mode signaling.
- RGB LED and buzzer for local visual and audible feedback and status indication.
- Integrated 1A charger output for charging smartphones or small accessories.
- Remote management support including FOTA and web configuration workflows via Teltonika tools.
- 2G GSM connectivity with common GSM band support for cellular telemetry in supported regions.

## How These Features Work with Plaspy

Plaspy consumes the FMP100's location and sensor data to present live vehicle status, events, and sensor telemetry in dashboards and reporting tools. After physical installation and any required BLE pairing, the device streams location and paired sensor inputs to Plaspy for mapping, alerting, and historical analysis.

- Live GPS positions appear on Plaspy maps for route tracking and location awareness.
- Button presses and locally signaled events are relayed into Plaspy as alert events for operator review.
- BLE sensor readings such as temperature, humidity, magnet change, and movement are delivered to Plaspy when paired with supported accessories.
- Visual and audible device status (RGB LED and buzzer) is recorded in event logs and can be surfaced in Plaspy activity streams.
- Remote configuration and firmware workflows are managed using Teltonika tools and coordinated with Plaspy device management processes.

## Typical Use Cases

- Rapid fleet deployment where vehicles need quick provisioning without workshop hardwiring.
- Car sharing and rental services that require temporary tracking, usage monitoring, and panic alerts.
- Pilot programs and seasonal fleets that benefit from pop in and pop out tracking capability.
- Monitoring of cargo or temperature sensitive loads using BLE temperature and humidity sensors paired with the tracker.
- Asset security and tamper detection using button events and magnet or movement sensor telemetry.
- Driver convenience scenarios where the integrated charger output can power a phone while the vehicle is tracked.
