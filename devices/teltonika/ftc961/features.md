# Teltonika - FTC961 Features

This page summarizes the public feature context for the Teltonika FTC961 when used with Plaspy. It focuses on practical capabilities, operational value, and how the device integrates into Plaspy workflows for fleet telematics and remote device management.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and how the device is installed and configured. Refer to Teltonika documentation for device specific limits and to ensure your deployment matches the intended capabilities.

## Feature Overview

The FTC961 is a rugged, Plaspy compatible GPS tracker designed for demanding mobile and off road deployments. It combines robust cellular connectivity, enhanced GNSS positioning, and remote management features that help fleets maintain visibility and reduce downtime in harsh conditions.

- Real time GNSS location reporting suitable for fleet tracking and historical playback in Plaspy
- Rugged IP69K enclosure for high pressure washing and dust resistant installations
- Enhanced GNSS precision for improved low speed and difficult signal scenarios
- 4G LTE Cat 1 cellular connectivity with 2G fallback for broad regional coverage
- Digital inputs and outputs plus high voltage input for ignition and external event monitoring
- Remote firmware and configuration management using FOTA WEB and the Teltonika FT platform

## Core Features of Teltonika - FTC961

- Plaspy compatible tracker optimized for fleet telematics and remote monitoring
- Enhanced GNSS performance with support for a large number of visible satellites for improved accuracy
- 4G LTE Cat 1 data connectivity with 2G fallback across listed regional bands
- Rugged IP69K rated enclosure built for heavy duty, off road, and industrial environments
- High voltage input and power management features to suit heavy machinery and specialized vehicles
- Digital inputs and outputs for ignition detection and external event signals
- Remote device management via FOTA WEB and Teltonika FT platform for firmware and configuration updates

## How These Features Work with Plaspy

The FTC961 reports GNSS position and telematics data into Plaspy where fleet operators can monitor movement, events, and device status. Plaspy automatically detects the tracker protocol and accepts telemetry over common transport methods to present location and event data in real time.

- Real time location updates and historical playback visible in Plaspy maps and timelines
- Event detection from digital inputs such as ignition or external sensors shown as device events in Plaspy
- Device status and telemetry delivered to Plaspy for operational monitoring and reporting
- Digital outputs can be used for remote control workflows when configured through Plaspy and Teltonika tools
- Scalable firmware and configuration management combined with Plaspy monitoring supports fleet lifecycle operations
- Devices may be configured to report to d.plaspy.com using standard TCP or UDP reporting on Plaspy’s standard port and are auto detected by the platform
