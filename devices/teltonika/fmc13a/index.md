# Teltonika - FMC13A

<div className="device-logo">
![FMC13A](./logo..png)
</div>

The Teltonika FMC13A is a compact 4G LTE Cat 1 GPS tracker designed for North American deployments. It combines cellular connectivity, multi constellation GNSS positioning, and a compact IP41 enclosure to provide continuous location awareness for a range of vehicles. The device description highlights remote monitoring features and vehicle control capabilities that make it suitable for professional fleet operations.

As a Plaspy compatible device, the FMC13A can be integrated into Plaspy fleet management workflows to provide real time tracking and operational visibility. Its CAN adapter support and impulse input for fuel flow meters make the unit useful for fleets that require fuel and engine related data alongside basic location tracking. Plaspy can use the data the FMC13A provides to improve monitoring and reporting across mixed vehicle fleets.

## Key Highlights

- Designed for North America with 4G LTE Cat 1 cellular support for reliable connectivity
- Multi constellation GNSS support for accurate positioning across GPS GLONASS GALILEO BEIDOU QZSS and AGPS
- Remote monitoring and control capabilities including engine blocking and fleet control measures
- CAN adapter support for reading vehicle data such as fuel odometer RPM and engine temperature
- Impulse input for fuel flow meter readings to help with precise fuel usage monitoring
- Compact form factor and IP41 ingress protection suitable for a variety of vehicle installations
- Operating range suitable for typical fleet environments with durable lightweight construction

## How It Works with Plaspy

When connected to Plaspy the FMC13A provides vehicle location and operational data that Plaspy displays and uses for alerts reporting and oversight. Plaspy can aggregate the tracker data into dashboards and historical logs to support daily fleet operations and management reviews.

- Real time location tracking shown on Plaspy maps for operational visibility
- Alerts and notifications in Plaspy based on movement events or configurable thresholds
- Fleet level dashboards and historical reports using position and vehicle data from the tracker
- Fuel monitoring and consumption trends when CAN and impulse inputs are enabled and mapped in Plaspy
- Remote control actions and status reporting accessible through Plaspy when configured with the device
- Consolidated monitoring for mixed fleets combining FMC13A units with other compatible devices
