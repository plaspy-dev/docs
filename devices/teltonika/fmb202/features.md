# Teltonika - FMB202 Features

This page provides public feature context for using the Teltonika FMB202 tracker with Plaspy. It summarizes the model's user-facing capabilities, common configuration paths, and the practical value you can expect when the device reports into Plaspy's fleet management platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installed accessories, and how the unit is installed. Where relevant, this page flags variations and encourages checking manufacturer documentation for the most current technical details.

## Feature Overview

The Teltonika FMB202 is a compact, waterproof IP67 tracker designed for continued operation when mains power is unavailable and for flexible installations across vehicles and assets. It combines passive sensors, a rechargeable backup battery, and multiple configuration options to support tracking, event detection, and remote management.

- IP67 rated enclosure for outdoor and water exposed installations
- Bluetooth connectivity and internal high gain GNSS and GSM antennas for improved reception
- Integrated high capacity NiMH backup battery capable of extended operation in power saving modes
- Wide input voltage support for 6 to 30 V installations suitable for motorcycles and watercraft
- Built-in accelerometer for motion based events such as green driving and overspeed detection
- Multiple sleep modes to preserve battery and extend offline runtime

## Core Features of Teltonika - FMB202

- IP67 waterproof design for use in exposed or wet environments
- Bluetooth support for local configuration and accessory pairing
- Internal high gain GNSS and GSM antennas for compact installations
- Integrated high capacity NiMH backup battery with multi day runtime in power saving modes
- Wide power input range 6 to 30 V for versatile vehicle and asset integration
- Accelerometer based event detection enabling green driving, overspeed alerts, and motion sensing
- Multiple configurable sleep modes including GPS sleep and deep sleep variants to optimize power use
- Configuration and firmware update options including FOTA Web, FOTA, Teltonika Configurator via USB and Bluetooth, and the FMBT mobile application

## How These Features Work with Plaspy

Plaspy receives telemetry and event data from compatible trackers and presents it in a single operational view. When an FMB202 is connected to Plaspy, device-reported location, battery status, and event conditions become visible to dispatchers and fleet managers for ongoing monitoring and historic review.

- Real time and historic location tracking within Plaspy based on GNSS data reported by the device
- Event visibility for accelerometer based alerts such as overspeed or green driving events
- Battery and power state reporting to help monitor backup battery usage and offline periods
- Fuel monitoring and OBDII sourced data can be reflected in Plaspy when the FMB202 is used with LLS or an OBDII dongle
- Remote configuration and firmware management are supported workflows when the device is registered to Plaspy and updated using Teltonika tools
- Device network setup can be pointed to Plaspy infrastructure; Plaspy automatically detects the tracker protocol and supports common transport modes such as UDP and TCP

## Typical Use Cases

- Asset tracking for trailers and equipment where waterproof protection and compact antennas are required
- Delivery fleets and refrigerated transport where battery backup and sleep modes preserve continuity
- Agriculture and off road vehicles needing a durable tracker with extended standby time
- Motorbikes and water transport installations benefiting from the wide 6 to 30 V power input and IP67 housing
- Security and emergency service assets that require reliable motion detection and remote configuration
- Mixed fleets where optional OBDII or analog fuel monitoring is used to extend telemetry capabilities

## Feature Availability Notes

- Battery life estimates depend on configured sleep modes, reporting intervals, and event thresholds; actual runtime varies by usage pattern
- Some features such as fuel monitoring require optional interfaces like LLS analog sensors or an OBDII dongle and may not be functional without those accessories
- Firmware version and hardware revision can enable or change specific behaviors and configuration options
- Installation details such as wiring, antenna placement, and local cellular coverage will affect GNSS and GSM performance
- Regional cellular variants and regulatory requirements may affect available network features and behavior
