# Teltonika - FMB240 Features

This page describes the public feature context for using the Teltonika FMB240 GPS tracker with Plaspy. It focuses on the practical capabilities you can expect to see when the FMB240 is integrated into Plaspy for real-time tracking, telemetry display, and fleet monitoring workflows.

Exact feature availability can vary by firmware version, hardware revision, selected package, and installation method. The FMB240 is listed by the manufacturer with an End of Life status, so confirm current availability, firmware updates, and variant details with the manufacturer before deployment.

## Feature Overview

The FMB240 is a compact, rugged tracker that brings location plus vehicle and sensor telemetry into fleet management. It is intended for vehicle and asset installations where CAN bus data and Bluetooth LE sensor integration can add operational insight.

- IP67 rated enclosure for dust and water resistance in outdoor and vehicle environments
- Built-in CAN bus data reading using LV-CAN200 or ALL-CAN300 options for vehicle diagnostics
- Bluetooth LE support for pairing external sensors and beacons to extend telemetry
- Global 2G GSM band support on B2 B3 B5 B8 for broad cellular reach
- Multiple package and order code variants to match installation and wiring needs

## Core Features of Teltonika - FMB240

- Compact, vehicle-suitable form factor with rugged IP67 enclosure for field deployments
- Native CAN bus interface via built-in CAN chip to read vehicle diagnostics and telemetry
- Bluetooth LE for connecting external sensors such as temperature humidity movement and magnet detection beacons
- 2G GSM cellular connectivity across key global bands for telemetry uplink
- Plaspy compatibility for feeding location and telemetry into a fleet management platform
- Multiple package and ordering variants that include different cables modules and accessories
- Designed for use across light vehicles trucks buses and special machinery when paired with the appropriate CAN module

## How These Features Work with Plaspy

When connected to Plaspy the FMB240 supplies location updates and CAN or Bluetooth sensor data that Plaspy can normalize and present in dashboards and reports. Plaspy detects compatible tracker protocols and aggregates telemetry for live monitoring and historical analysis.

- Real time GPS location and history playback displayed in Plaspy mapping and timeline tools
- CAN derived signals such as ignition or diagnostic parameters can be mapped for trip detection and status reporting in Plaspy
- Bluetooth LE sensor readings appear as additional telemetry streams that can be charted and alerted on
- Plaspy normalizes incoming CAN messages and sensor data so fleet managers can compare vehicle diagnostics alongside location
- Alerts and reporting in Plaspy can be driven by telemetry thresholds and events reported by the FMB240

## Typical Use Cases

- Fleet tracking and operational visibility where vehicle diagnostics enhance route planning and maintenance
- E mobility and electric vehicle telemetry when paired with the appropriate CAN module for vehicle level data
- Environmental monitoring of assets using Bluetooth LE sensors for temperature humidity or movement detection
- Anti theft monitoring and recovery workflows using live location combined with CAN sourced status information
- Rugged asset tracking for utility machinery or outdoor equipment requiring an IP67 enclosure
