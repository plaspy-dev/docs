# Teltonika - FMB900 Features

This page describes the public feature context for using the Teltonika FMB900 with Plaspy. It focuses on the model's practical capabilities, BLE sensor support, remote management options, and how those features are reflected in Plaspy for vehicle and asset tracking use cases.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and the manufacturer's implementation. For device specific technical limits, configuration steps and the latest firmware details consult the official Teltonika documentation.

## Feature Overview

The FMB900 is a compact, low-cost 2G vehicle tracker designed for straightforward real-time tracking, anti-theft workflows and basic telemetry. Its small form factor and BLE connectivity make it suitable for discreet installations and for extending telemetry with wireless sensors, while remote management options simplify fleet-wide maintenance.

- Slim, low profile design for tight or hidden vehicle installations.
- 2G cellular connectivity for basic position reporting and low bandwidth telemetry.
- Bluetooth Low Energy support to pair with EYE Beacon and EYE Sensor modules for environmental and tamper sensing.
- Remote engine blocking capability for anti-theft and immobilizer workflows.
- Remote device management and firmware updates via Teltonika FOTA WEB and configuration with Teltonika Configurator.

## Core Features of Teltonika - FMB900

- Bluetooth Low Energy (BLE) support for EYE Beacon and EYE Sensor attachments to capture temperature, humidity, magnet and movement inputs.
- 2G GSM cellular connectivity suitable for essential tracking and telemetry reporting.
- Remote engine blocking functionality to support immobilizer workflows.
- Remote device management compatibility using Teltonika FOTA WEB for firmware updates and Teltonika Configurator for device settings.
- Slim form factor with a low height for hidden or tight installations.
- Simple installation package options that include a power cable for straightforward commissioning.
- Designed for basic fleet control and position reporting use cases.

## How These Features Work with Plaspy

When connected to Plaspy, the FMB900 provides core location and sensor inputs that Plaspy surfaces inside its monitoring and reporting tools. Plaspy automatically detects many common Teltonika tracker protocols so incoming position and BLE sensor data can be shown without extensive protocol-level configuration.

- Real-time vehicle location and position history visible in Plaspy maps and activity timelines.
- BLE sensor telemetry from EYE Sensor and EYE Beacon presented as environmental or tamper events in Plaspy reports and alerts.
- Immobilizer and engine blocking events reflected in Plaspy event logs to support anti-theft responses and remote actions.
- Device management workflows supported through Plaspy visibility while firmware and bulk configuration remain compatible with Teltonika FOTA WEB and Configurator.
- Compact device installation reduces visibility on the vehicle while Plaspy maintains continuous monitoring and alerting.

## Typical Use Cases

- Fleet anti-theft and recovery using discreet installation and remote engine blocking.
- Basic fleet tracking and route replay for vans, cars and light vehicles.
- Temperature sensitive cargo monitoring when paired with BLE EYE Sensor devices.
- Small asset and trailer tracking where a compact tracker is required.
- Tamper and movement detection via BLE beacons for door or intrusion monitoring.
- Eco driving oversight through basic telemetry and driving behavior reports surfaced in Plaspy.

## Feature Availability Notes

- Feature availability can depend on the device firmware version and the options enabled by the specific hardware revision.
- BLE sensor capabilities require compatible EYE Beacon or EYE Sensor accessories and correct pairing and configuration.
- 2G network availability and supported frequency bands can vary by region and carrier; check local network coverage before deployment.
- Remote engine blocking requires correct installation and wiring; installer practices and vehicle wiring will affect functionality.
- Teltonika remote management services such as FOTA WEB and Configurator are used for updates and provisioning; access to those services may be required for large deployments.
