# Suntech - ST4345LB Features

This page describes the public feature context for using the Suntech ST4345LB GPS tracker with Plaspy. It summarizes the device capabilities that are relevant to fleet operators, asset managers, and integrators using Plaspy for location visibility, event reporting, and telemetry. The information below is based on the ST4345LB description and focuses on how those features translate into operational value when the device is connected to Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Device options such as cellular band variants, sensor pairing, and remote management settings may differ between units or regions, so check the manufacturer documentation and device configuration for the specifics of any deployed unit.

## Feature Overview

The ST4345LB is a compact, rugged vehicle tracker designed to deliver continuous GNSS positioning, multi mode cellular connectivity, BLE sensor support, and built in vehicle analytics. In Plaspy the tracker provides location, event and sensor data that supports live tracking, alerts, and historical reporting for fleet and asset workflows.

- Reliable GNSS position reporting for live location tracking and breadcrumb history.
- Multi mode cellular connectivity for wide coverage and efficient data usage across LTE Cat M1, NB IoT and EGPRS 2G networks.
- Bluetooth Low Energy sensor forwarding for temperature, door, or motion sensors to enrich asset telemetry.
- Built in vehicle analytics such as driving pattern analysis and crash reconstruction to surface incidents and behavioral events.
- Rugged IP67 enclosure and low power modes to support vehicle and distributed asset deployments.

## Core Features of Suntech - ST4345LB

- Plaspy compatible device capable of streaming location and event data into the Plaspy platform.
- Multi mode cellular radio supporting LTE Cat M1, NB IoT, and EGPRS 2G for flexible connectivity options.
- Bluetooth 4.2 Low Energy for pairing external sensors and beacons to extend telemetry.
- Full GNSS solution with GPS plus GLONASS and SBAS support for improved position accuracy.
- Virtual ignition detection using voltage and motion signals to indicate vehicle run states.
- Driving Pattern Analysis and Crash Reconstruction analytics to generate actionable events.
- Rugged IP67 rated enclosure and low power modes for long term vehicle and asset installations.
- Onboard motion sensor for movement and impact detection and an internal backup battery for short term power resilience.

## How These Features Work with Plaspy

When integrated with Plaspy, the ST4345LB reports position, events and sensor data into the fleet management environment so operators can monitor assets in real time and review historical activity. Plaspy accepts telemetry from compatible devices and can automatically detect the tracker protocol to simplify setup.

- Live position tracking and breadcrumb trails appear in Plaspy maps and historical reports for operational visibility.
- DPA and crash reconstruction events are surfaced as incident records or alerts to support investigations and safety reviews.
- Virtual ignition and motion events enable status changes, run time reports, and mileage or duty workflows inside Plaspy.
- BLE sensor readings forwarded by the device are available in Plaspy for temperature, door, or condition monitoring.
- Geo fence events and perimeter alerts from the device can trigger notifications and rule based actions in Plaspy.
- Plaspy receives device telemetry over standard TCP or UDP feeds to d.plaspy.com and can be configured to accept trackers using the same port profile, with automatic protocol detection simplifying integration.

## Typical Use Cases

- Fleet management for light and heavy vehicles with live tracking and driver behavior analytics.
- Vehicle recovery and anti theft monitoring with continuous location reporting and geo fence alerts.
- Container, trailer and remote asset monitoring where low power modes and wide coverage are important.
- Incident investigation and claims support using crash reconstruction and driving pattern analysis events.
- Mixed asset deployments where BLE sensors add temperature or door status telemetry for distributed monitoring.
