# Suntech - ST8310/U Features

This page provides a public feature overview for the Suntech ST8310/U GPS tracker and explains how those features relate to use with Plaspy. It is intended to help fleet operators, integrators, and installers understand the tracker capabilities that are relevant for real time tracking, telemetry, and remote management when the device is connected to Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and installation choices. Where relevant, this page highlights commonly available functions while encouraging review of manufacturer documentation for the most current device specifics.

## Feature Overview

The Suntech ST8310/U is a rugged vehicle tracker that focuses on reliable GNSS positioning, cellular connectivity, and practical I/O for anti theft and fleet workflows. Its design supports remote management and integration with fleet platforms like Plaspy to provide ongoing telemetry and event reporting.

- Cellular connectivity with LTE Cat 1 and legacy 2G fallback for wide area coverage and continuous reporting.
- High sensitivity GNSS with GPS and GLONASS plus SBAS for improved position accuracy in vehicle environments.
- Configurable inputs and outputs for ignition detection, panic or door inputs, and remote vehicle blocking or siren control.
- Rugged IP67 lugged housing suitable for exposed vehicle installations and fleet use.
- OTA configuration and firmware upgrades for remote device management at scale.
- Optional Bluetooth 4.0 and driver analytics modules for extended telemetry where deployed.

## Core Features of Suntech - ST8310/U

- LTE Cat 1 cellular connectivity with automatic fallback to legacy 2G networks.
- High sensitivity GNSS receiver supporting GPS and GLONASS with SBAS for improved accuracy.
- Configurable I O per model variant: ST8310 typically with 2 inputs and 2 outputs, ST8310U with 2 inputs and 1 output.
- Rugged IP67 rated lugged enclosure designed for in vehicle and exposed installations.
- Over the air configuration and firmware upgrade support via cellular connection.
- Built in motion sensing and jamming detection to support anti theft alerts.
- Internal rechargeable backup battery and low power modes to allow last mile reporting during power loss.
- Optional Bluetooth 4.0 support and optional driver behavior or crash reconstruction modules for enhanced analytics.

## How These Features Work with Plaspy

When the ST8310/U is connected to Plaspy, the tracker reports position, inputs, and event signals so operators can monitor vehicles and respond to incidents. Plaspy consumes GNSS fixes and device events and provides a unified view for live tracking and actioning device outputs when supported.

- Live location updates and historical position replay in Plaspy dashboards for route monitoring and post trip review.
- Input event logging for ignition, panic, and door sensors to support trip detection and event based alerts.
- Output control workflows such as remote blocking or siren activation can be issued from Plaspy to supported tracker outputs.
- Alerts generated by jamming detection or motion sensor events are surfaced in Plaspy for rapid operator awareness.
- OTA settings and firmware workflows can be coordinated through Plaspy and the device maintenance server where deployed.

## Typical Use Cases

- Fleet management with real time tracking, trip logging, and route replay for operational oversight.
- Vehicle recovery and anti theft monitoring using motion detection, jamming alerts, and geofence breach notifications.
- Remote immobilization and siren control for incident response when supported by the installation.
- Last mile and emergency reporting when main vehicle power is interrupted using internal backup battery and low power modes.
- Extended telemetry using optional Bluetooth sensors or driver analytics modules for safety programs and investigations.

## Feature Availability Notes

- Feature presence depends on the specific model variant and hardware revision for ST8310 versus ST8310U.
- Firmware level can enable or change behavior for OTA, analytics modules, and sensor handling; verify firmware status during deployment.
- Optional capabilities such as Bluetooth sensors, driver pattern analysis, and crash reconstruction may require additional licensing or configuration.
- Installation wiring and accessory choices determine which inputs and outputs are available and how immobilizer or siren control is implemented.
- Regional variants and certifications can affect supported cellular bands and regulatory features.

## Why Use Plaspy with These Features

Using the ST8310/U with Plaspy provides a practical path to combine rugged hardware with a platform that collects location, I O events, and security alerts into a single operational view. Plaspy enables fleet operators to monitor vehicles in real time, aggregate event data for reporting, and issue remote commands to supported outputs as part of operational workflows.
