# Suntech - ST 180 Wi-FI

<div className="device-logo">
![ST 180 Wi-FI](./logo.jpg)
</div>

The Suntech ST 180 Wi-FI is a vehicle GPS tracker designed for fleet and telematics applications. It combines core tracking capabilities with onboard storage, holding up to 2000 GPS positions that can be downloaded over a Wi Fi connection. The device is positioned to reduce reliance on continuous cellular connectivity by enabling batch data transfer when Wi Fi is available, helping to control operating costs for fleet operators.

Beyond location logging, the ST 180 can collect vehicle system information from standard vehicle data interfaces, offering insights such as fuel use trends and engine performance metrics. Its set of communication options, event based triggers, digital inputs, power save mode and a backup battery make it a versatile unit for fleets that need reliable position history and vehicle data without assuming constant network availability. As a device confirmed compatible with Plaspy, it can be integrated into a fleet management workflow for centralized monitoring and reporting.

## Key Highlights

- Onboard memory to store up to 2000 GPS positions for later download via Wi Fi.
- Wi Fi download capability reduces dependence on continuous cellular upload and can lower operating costs.
- Support for vehicle data interfaces including J1939 FMS and OBDII standards to capture vehicle system signals.
- Multiple communication options including TCP, UDP and Wi Fi for flexible data transfer.
- Internal events based triggers and multiple digital inputs for configurable monitoring scenarios.
- Power saving sleep mode and a backup battery to maintain basic operation and data retention.

## How It Works with Plaspy

When paired with Plaspy, the ST 180 Wi-FI delivers recorded positions and vehicle data into the Plaspy platform for visualization, alerting and reporting. Plaspy ingests the device data so fleet managers can view location history, monitor vehicle system trends and run operational analytics from a single interface.

- Centralized map view of live and historical positions for route analysis and oversight.
- Alerts and notifications based on events captured by the tracker and relayed to Plaspy.
- Reporting tools in Plaspy that use stored position data to generate trip summaries and utilization reports.
- Use of Wi Fi downloads to upload stored data when vehicles return to base or reach Wi Fi coverage, preserving offline history.
- Vehicle system insights from CAN and vehicle interfaces surfaced in Plaspy dashboards to support maintenance and efficiency planning.

## Typical Use Cases

- Fleet operators who need robust position history and want to minimize cellular data costs by using Wi Fi transfers.
- Businesses that require vehicle system data for fuel monitoring and basic engine performance oversight.
- Vehicle recovery and asset tracking where stored positions help reconstruct routes when continuous connectivity is not guaranteed.
- Mixed coverage operations that benefit from batch uploading of telemetry and position logs at depots or known Wi Fi locations.
- Telematics deployments where configurable inputs and event triggers are used to monitor specific vehicle behaviors.

The ST 180 Wi-FI is a practical choice for organizations that need durable position logging plus access to vehicle system information, while keeping an eye on operational cost. Its ability to store a substantial position history and upload over Wi Fi makes it well suited to fleets that operate in areas with intermittent cellular coverage or that prefer scheduled data transfers.
