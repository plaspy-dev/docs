# Suntech - ST 300A Features

This page provides a public overview of the Suntech ST 300A features and how those capabilities map to Plaspy for tracking, monitoring, and operational visibility. It is intended to describe the practical, non sensitive feature context for organizations considering the ST 300A together with Plaspy.

Exact feature availability and behavior can differ by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a general guide and consult official Suntech documentation for the most current device specifics.

## Feature Overview

The ST 300A is a versatile GPS tracker designed for vehicle and asset applications where sensor integration and event detection are required. It combines onboard connectivity with expansion interfaces and a harness installation option to report a variety of vehicle events and sensor readings.

- Internal antennas for compact installation and signal reception
- 1-Wire support for up to three temperature sensors and i-Button authentication
- RS232 interface and multiple analog inputs for integration with external equipment
- Harness based inputs for door open detection, panic button, immobilization, and license plate monitoring
- Built in anti theft functions including jamming detection and crane drag detection
- Capabilities to support patron management analysis and other operational reporting

## Core Features of Suntech - ST 300A

- 1-Wire interface allowing connection of temperature probes and i-Button devices
- Support for up to three temperature sensors for monitoring temperature sensitive cargo
- RS232 serial interface for integration with compatible devices or third party systems
- Multiple analog inputs for monitoring voltages or other sensor signals
- Harness installation with dedicated inputs for door state detection and panic or emergency button events
- Immobilization and license plate open close detection when connected through the harness
- Anti theft functions such as jamming detection and crane drag detection
- Operational reporting features that can support patron management analysis

## How These Features Work with Plaspy

Plaspy displays incoming events and sensor data from compatible trackers so teams can monitor location, status, and connected sensors in one platform. When an ST 300A is connected to Plaspy, its supported signals can be represented as events and sensor readings within the Plaspy interface for operational oversight.

- Temperature sensor readings from the 1-Wire inputs can be shown as sensor values or alerts for temperature thresholds
- i-Button events and authentication actions can be recorded as discrete events tied to vehicle activity
- RS232 and analog input activity can be surfaced as custom inputs or status channels in Plaspy when configured
- Harness input events such as door open, panic activation, immobilization, and license plate activity appear as digital events for timeline and alerting
- Anti theft signals like jamming detection and crane drag alerts can be mapped to notifications and incident workflows in Plaspy

## Typical Use Cases

- Monitoring refrigerated or temperature sensitive cargo using connected temperature probes
- Vehicle security and theft prevention using jamming detection and harness inputs for door or panic events
- Fleet operations that require additional integration via RS232 or analog sensors for custom telemetry
- Heavy equipment monitoring where crane drag detection and immobilization status are relevant
- Transit or passenger operations using patron management analysis to review boarding or usage patterns

## Feature Availability Notes

- Feature availability depends on the ST 300A firmware version and the exact hardware revision installed

- Regional or configuration variants from the manufacturer may change available interfaces or supported sensors
- Integration behavior inside Plaspy depends on how the tracker is configured to report inputs and sensor values
- Always confirm the installed device firmware and feature set with the device installer or manufacturer documentation
