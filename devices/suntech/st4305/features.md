# Suntech - ST4305 Features

This page provides a public feature overview for the Suntech ST4305 series and explains how the device functions when used with Plaspy. It is written to help fleet managers, integrators, and system architects understand the practical capabilities of the tracker and how those capabilities map into Plaspy for real time tracking, telemetry, and event reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, installation wiring, and manufacturer configuration. Where appropriate this page points to variant differences and configuration options, and recommends consulting manufacturer documentation for device specific and up to date details.

## Feature Overview

The ST4305 series is a wired vehicle tracker family designed for resilient cellular coverage and vehicle grade integration. It offers multi network cellular connectivity, integrated GNSS positioning, a 14 pin wired harness for direct vehicle integration, and variant choices that add serial and antenna options to meet different installation needs.

- Multi network cellular connectivity providing LTE Cat M1, NB IoT and 2G support for broad coverage and low cost data transport.
- Integrated GNSS positioning for continuous location reporting and historical route replay in Plaspy.
- Three installation variants ST4305, ST4305R and ST4305RE to match wiring and telemetry requirements.
- Wired 14 pin connection harness with multiple inputs and outputs to integrate ignition, doors, alarms and third party immobilizer systems.
- Advanced telematics features including Driving Pattern Analysis and Crash Reconstruction for safety and incident review.
- Backup battery and optional jamming detection to improve recovery and anti theft monitoring.

## Core Features of Suntech - ST4305

- Multi network cellular radios supporting LTE Cat M1, NB IoT and fallback 2G connectivity.
- Integrated GNSS receiver for real time position reporting and historical tracking.
- Variant options: ST4305 basic I O, ST4305R with RS 232 serial, ST4305RE with RS 232 and external GNSS antenna provision.
- 14 pin wired connector with configurable inputs and outputs for alarms, ignition detection and accessory integration.
- Driving Pattern Analysis DPA and Crash Reconstruction CR for event based safety telemetry.
- Virtual ignition detection using voltage and motion inputs for vehicle on off state detection.
- Backup battery that preserves telemetry and location reporting during power loss.
- Maintenance server support and downloadable firmware and configuration files for device management.

## How These Features Work with Plaspy

When connected to Plaspy, the ST4305 series reports position, status and event information that Plaspy ingests and presents through live maps, alerts and historical reports. Plaspy automatically detects compatible tracker protocols and surfaces device events alongside vehicle location and telemetry.

- Real time GNSS location and movement data appear in Plaspy for live tracking and route history.
- Ignition and motion states derived from virtual ignition allow Plaspy to separate drive and idle periods and trigger ignition based reports.
- DPA and Crash Reconstruction events are available to Plaspy as incident records for safety review and automated workflows.
- Geofence events and security alerts reported by the device are shown in Plaspy for route enforcement and breach notifications.
- Jamming detection and backup battery status are reported to Plaspy to support anti theft monitoring and recovery actions.
- Serial telemetry from ST4305R and ST4305RE variants can feed diagnostic or third party data streams into Plaspy when configured by the integrator.

## Typical Use Cases

- Fleet management with continuous vehicle location, route replay and configurable operational reports.
- Vehicle recovery and anti theft monitoring using jamming alerts, backup battery reporting and security events.
- Safety and incident analysis using Driving Pattern Analysis and Crash Reconstruction data for post incident review.
- Diagnostics and maintenance workflows using RS 232 serial telemetry from R and RE variants.
- Integrated alarm and immobilizer workflows driven by device inputs and outputs for remote control and deterrence.
- Long term monitoring of mixed fleets where multi network cellular support helps maintain connectivity.

## Feature Availability Notes

- Feature sets vary across ST4305, ST4305R and ST4305RE variants; confirm the chosen model includes the required I O and serial options.
- Firmware level and manufacturer configuration affect which events and telemetry types are enabled by default and how they are reported.
- Installation wiring and harness connections determine available inputs outputs and virtual ignition behavior.
- Regional cellular banding and network availability influence which cellular modes are usable in a given market.
- Review the Suntech datasheet and firmware files for the exact capabilities of your unit and for available firmware updates.
