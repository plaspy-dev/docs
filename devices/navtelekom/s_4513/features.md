## Feature Overview

The СМАРТ S-4513 is a compact GLONASS and GPS vehicle tracker designed for continuous location reporting and flexible telemetry capture. It combines cellular connectivity, redundant SIM support, built in antennas, backup power, and a broad I O set so operators can stream position and sensor data into Plaspy for dashboards, alerts, and reports.

- Real time GNSS position reporting for live maps and history playback in Plaspy.
- Dual SIM 4G cellular connectivity for improved uptime and regional network coverage.
- Internal rechargeable backup battery and robust automotive power protection to maintain reporting through short power interruptions.
- Rich wired interfaces including RS-485, MODBUS, and 1-Wire for wired peripherals and probes.
- Bluetooth 4.0 support for pairing wireless sensors and beacons to extend telemetry without additional gateways.

## Core Features of Navtelekom - СМАРТ S-4513

- GLONASS and GPS positioning for satellite based location awareness.
- 4G modem with dual SIM redundancy to help maintain connectivity across networks.
- Built in GNSS and GSM antennas for simplified installation and consistent reception.
- Rechargeable 380 mAh backup battery to support short power outages.
- Industrial power protection rated to withstand automotive power events up to 200 V.
- Multiple digital and analog inputs and control outputs for event and actuator integration.
- RS-485, 1-Wire and MODBUS support for wired sensors, fuel probes, and industrial telemetry.
- Bluetooth 4.0 for wireless sensor pairing such as temperature or fuel level beacons.

## How These Features Work with Plaspy

When connected to Plaspy, the S-4513 forwards location and telemetry so fleet managers can monitor assets on live maps, run reports, and trigger alerts. Plaspy ingests the device data and exposes it through dashboards, event rules, and history tools for operational oversight.

- Real time position updates appear on Plaspy maps with history playback for route review.
- Discrete digital inputs report status changes such as ignition or door events to Plaspy for alerting and logging.
- Analog inputs and MODBUS connected probes provide fuel or sensor telemetry that Plaspy can include in fuel monitoring views and reports.
- Bluetooth sensor values forwarded by the tracker are visible in Plaspy for temperature control and condition monitoring workflows.
- Control outputs can be linked to operational rules in Plaspy to reflect remote actions or state changes in device driven workflows.
