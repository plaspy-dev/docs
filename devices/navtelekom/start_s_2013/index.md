# Navtelekom - START S-2013

![START S-2013](./tracker.jpeg)

The START S-2013 by Navtelecom is a compact GLONASS/GPS vehicle tracker engineered for installations that require a small form factor and internal antennas. Built for straightforward fleet management and asset monitoring, the START S-2013 delivers reliable positioning and telemetry over GSM \(2G\), a built-in backup battery for graceful operation during power interruptions, and a USB Type-C port for easy setup and charging. As a Plaspy compatible GPS tracker, it integrates cleanly with Plaspy's real-time tracking and reporting tools to provide location, sensor data, and event alerts from a discreet, easy-to-install unit.

Ideal for light commercial vehicles, equipment monitoring, and temperature-controlled assets, the START S-2013 balances minimal wiring with robust sensor support. Its internal GLONASS/GPS and GSM antennas, Bluetooth 4.0 support for wireless sensors, and RS-485 interface let operations expand telemetry — including fuel monitoring and environmental sensing — while maintaining secure, Plaspy-compatible data delivery to your fleet dashboard.

## Key Highlights

- Plaspy compatible GPS tracker: Sends GNSS and telemetry data over GSM \(2G\) for real-time tracking and fleet management integration.
- Ultra-compact design with internal antennas for discreet installation in vehicles and equipment.
- Built-in 130 mAh backup Li-Ion battery and USB Type-C port for reliable power handling and simple commissioning.
- Robust electrical protection up to 200 V to tolerate vehicle power surges and transients.
- Flexible sensor connectivity: wired inputs, RS-485, and Bluetooth 4.0 for wireless fuel, temperature, and humidity sensors.
- Configurable I/O for event-driven telemetry — ideal for fuel monitoring, door/door-alarm signals, or other discreet inputs.
- Quick deployment: minimal external wiring reduces installation time for fleet rollouts and service vehicles.

## How It Works with Plaspy

Integration with Plaspy is straightforward: the START S-2013 transmits GNSS positions and sensor telemetry over the device's 2G GSM link to Plaspy's ingestion endpoints. Plaspy then normalizes location and telemetry into real-time tracking, alerts, and historical reports for fleet managers. The tracker’s configurable inputs and RS-485 interface allow Plaspy to receive custom telemetry such as fuel levels or external controller data, while Bluetooth-connected sensors extend monitoring without additional wiring.

- Real-time location and telemetry updates over GSM \(2G\) to Plaspy's platform for live tracking and historical playback.
- Discrete inputs and analog input can report door, alarm, or sensor events to Plaspy as configurable digital signals.
- Fuel monitoring via wired fuel sensors or wireless fuel-level sensors, with telemetry forwarded to Plaspy for fuel analytics.
- Control output can be used for remote actions such as immobilizer control when paired with Plaspy-issued commands \(requires configuration and appropriate wiring\).
- Bluetooth 4.0 support enables short-range connectivity to mobile devices and Bluetooth sensors for temperature, humidity, or universal sensor data integration.
