# Navtelekom - СИГНАЛ S-4651 (4G) Features

This page provides a public feature summary for the Navtelekom СИГНАЛ S-4651 (4G) when used with Plaspy. It focuses on the practical capabilities you can expect in Plaspy for tracking, telemetry and event monitoring, and explains how the device integrates into fleet workflows managed through Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type and manufacturer implementation. The S-4651 is listed by Navtelekom as an archived model, and while documentation and firmware history remain available, verify specific functions against the device documentation and firmware notes for your unit.

## Feature Overview

The СИГНАЛ S-4651 is a vehicle grade GLONASS and GPS tracking terminal built for continuous fleet monitoring across 2G 3G and 4G LTE networks. It is designed to minimize data loss, provide flexible I O and industrial interfaces for telemetry, and support local logging and remote maintenance tasks.

- Multi network cellular connectivity with dual SIM failover to maintain continuous reporting in mixed coverage areas
- External GLONASS GPS and GSM antenna support for improved reception in vehicle installations
- Rich I O set and configurable outputs for monitoring ignition, doors and other vehicle inputs
- Industrial interfaces and protocol support for third party telemetry and diagnostics
- Local data logging on microSD and an internal backup battery to preserve position and events during power interruptions

## Core Features of Navtelekom - СИГНАЛ S-4651 (4G)

- GLONASS and GPS positioning with external antenna support for reliable satellite reception
- Multi network cellular modem supporting 2G 3G and 4G LTE with dual SIM failover for improved uptime
- Vehicle grade power protection and integrated Li Po backup battery to preserve data during power loss
- Universal I O set including six digital and analog inputs and four configurable control outputs for sensors ignition and immobilizer control
- Industrial communications including RS 232 RS 485 CAN bus and 1 Wire plus MODBUS support for external telemetry devices
- Local data logging on microSD card up to 32 GB for historical playback and recovering missed reports
- Bluetooth 4.0 for local configuration and accessory pairing
- Remote firmware management capability for lifecycle updates and maintenance

## How These Features Work with Plaspy

Plaspy ingests positioning and event data from compatible trackers like the S-4651 so fleet managers can view live location, receive alerts, and review historical telemetry in a single platform. In many deployments Plaspy automatically detects the tracker protocol and presents captured data in the Plaspy dashboard without manual protocol selection.

- Real time GNSS coordinates and position updates are visible in Plaspy for live monitoring and map playback
- Digital and analog input events feed alerts and status indicators such as ignition and door events into Plaspy
- CAN bus RS 485 and MODBUS telemetry can be forwarded to Plaspy for equipment diagnostics and reporting when configured
- Local microSD logs enable reliable historical data recovery and playback inside Plaspy when connectivity is restored
- Configurable outputs including immobilizer or actuator control can be triggered by Plaspy rules or remote commands where supported
