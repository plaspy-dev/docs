# Navtelekom - СИГНАЛ S-2652 Features

This page provides a public overview of the feature set and operational capabilities of the Navtelekom СИГНАЛ S-2652 when used with the Plaspy fleet management platform. It focuses on practical, non-sensitive information about what the device can deliver to Plaspy users and how those functions are typically used in vehicle telematics and fleet operations.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. The S-2652 is listed as discontinued by the manufacturer, so some units in the field may differ from current documentation; users should confirm details against the official Navtelekom materials for the most current information.

## Feature Overview

The СИГНАЛ S-2652 is an industrial on-board tracker built for vehicle telematics where wired I O and reliable logging are important. When integrated with Plaspy it is intended to provide continuous position reporting, resilient cellular connectivity and local data storage for situations where networks are intermittent.

- Real time GNSS positioning using GLONASS and GPS for location awareness in Plaspy
- Dual SIM and 3G cellular modem for connectivity redundancy and continuous reporting
- Local microSD logging up to 32 GB to preserve historical data during network outages
- Multiple universal inputs and controllable outputs for ignition, door and immobilizer workflows
- Industrial serial and CAN interfaces for deep vehicle telemetry integration
- Robust power protection and internal backup battery for harsh vehicle environments

## Core Features of Navtelekom - СИГНАЛ S-2652

- GLONASS and GPS positioning for continuous location tracking
- 3G cellular modem with dual SIM support to maintain connectivity
- microSD card slot for local logging of position and sensor data up to 32 GB
- Multiple universal inputs and controllable outputs for event detection and remote control
- RS-232, RS-485, CAN and 1-Wire interfaces for vehicle and sensor integration
- Internal rechargeable backup battery to support safe shutdown and short power interruptions
- Wide range electrical protection designed for heavy vehicle electrical systems

## How These Features Work with Plaspy

Plaspy ingests position and telemetry sent by the S-2652 and presents those signals in real time dashboards, event feeds and historical reports. Plaspy automatically detects common tracker protocols and accepts device data so operators can see location, input events and logged records without manual protocol mapping.

- Real time GNSS updates appear on Plaspy maps and live tracking widgets for fleet visibility
- Universal input events such as ignition, door or alarm signals are available as event records and can drive alerts
- Onboard microSD logs are forwarded to Plaspy after connectivity is restored so historical records remain complete
- CAN and serial telemetry can be correlated with location data in Plaspy reports and dashboards for operational insight
- Controllable outputs on the device can be used for remote immobilizer or relay actions triggered from Plaspy workflows
- The device can be configured to send data to Plaspy infrastructure and commonly supports TCP or UDP transport to the platform endpoint

## Typical Use Cases

- Remote immobilization and anti theft workflows using controllable outputs and event monitoring
- Door and alarm monitoring for instant alerts and security tracking
- Fuel or vehicle telemetry integration through CAN or serial interfaces for consumption analysis
- Regulatory logging and evidence capture using continuous local microSD storage with later upload
- Legacy fleet modernization where wired integration and industrial interfaces are required
- Route replay and incident investigation using combined GNSS tracks and input event logs
