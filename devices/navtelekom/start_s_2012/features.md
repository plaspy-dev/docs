# Navtelekom - START S-2012 Features

This page describes the public feature context for using the Navtelekom START S-2012 tracker with Plaspy. It summarizes the tracker capabilities that matter for real world fleet and asset workflows and explains how those capabilities appear and behave when combined with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. For device specific wiring diagrams, firmware notes and the most current technical details consult the official Navtelekom documentation.

## Feature Overview

The START S-2012 is a compact hardwired GLONASS/GPS tracker designed for discreet vehicle installation and practical telemetry collection. It pairs GNSS positioning with cellular connectivity and a range of sensor interfaces to deliver location, fuel and environmental data for Plaspy users.

- Compact GLONASS and GPS positioning in a low profile form factor designed for permanent installation in cars and light commercial vehicles.
- Cellular GSM modem with single SIM slot for real time reporting of location and telemetry to Plaspy.
- Support for wired and wireless fuel level sensors plus wireless environmental sensors to gather fuel and temperature or humidity readings.
- Bluetooth 4.0 support to connect BLE sensors and beacons and enrich telemetry visible in Plaspy.
- USB Type C and RS-485 interfaces for integrating external devices and telemetry sources.
- Multiple digital inputs and one control output to report events and enable basic remote control or relay driven workflows.

## Core Features of Navtelekom - START S-2012

- GLONASS and GPS positioning with integrated GNSS antenna for reliable location reporting.
- 2G GSM modem with single SIM slot for cellular uplink of tracking and sensor data.
- Compact, hardwired design with no internal battery and power protection suitable for vehicle electrical systems.
- Support for wired fuel sensors and wireless fuel sensors to support fuel monitoring workflows.
- Bluetooth 4.0 for connecting BLE sensors and proximity beacons to extend telemetry.
- USB Type C port and RS-485 interface for external device integration and data exchange.
- Multiple discrete inputs and one control output for event detection and basic remote control actions.
- Remote configuration and firmware management support using the manufacturer tools NTC Configurator and DRC.

## How These Features Work with Plaspy

When START S-2012 is deployed with Plaspy, the device streams location and sensor measurements over the cellular network so operators can monitor vehicle positions, events and telemetry in real time. Plaspy automatically detects supported tracker protocols and surfaces the most relevant data for operational use.

- Live location updates and historical route playback available in Plaspy dashboards for visibility and investigation.
- Fuel level readings from wired or wireless sensors appear as telemetry points and can be included in fuel history and consumption reports.
- Bluetooth sensor data such as temperature and humidity is presented alongside location and time for environmental monitoring.
- Discrete input events show as time stamped events in Plaspy and can be used to trigger alerts and workflows.
- Control output state can be reflected in Plaspy command workflows where supported, enabling coordinated remote actions.
- Remote device configuration and firmware updates via manufacturer tools complement Plaspy administration and maintenance processes.

## Typical Use Cases

- Compact fleet tracking for cars and light commercial vehicles where a low profile hardwired tracker is preferred.
- Fuel monitoring and consumption analysis using wired or wireless fuel sensors integrated into Plaspy dashboards.
- Anti theft and event based monitoring with door or alarm inputs reported to Plaspy for alerting.
- Temperature sensitive cargo monitoring by pairing Bluetooth temperature and humidity sensors for condition reporting.
- Basic telematics collection for operational oversight and route analysis in small to medium fleets.
- Integrating auxiliary devices through RS-485 or USB to consolidate vehicle data into Plaspy.
