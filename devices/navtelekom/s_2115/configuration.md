# Navtelekom - СИГНАЛ S-2115 Configuration

This page documents the public configuration context for using the Navtelekom СИГНАЛ S-2115 tracker with Plaspy. It summarizes the practical server values and the general steps required to prepare the device for centralized monitoring. Use this guide together with the SIGNAL S-2115 operator guide and the NTC Configurator utility for device specific procedures prior to onboarding to Plaspy.

Plaspy uses shared server settings across supported devices and automatically detects the tracker protocol, while exact manufacturer side setup steps can vary by firmware version, hardware revision, installation type, and vendor tools. The S-2115 combines GLONASS and GPS positioning with GSM communications, provides USB configuration, accelerometer alarms, and supports SMS and voice based interactions for legacy deployments.

## Configuration Overview

Configuring the S-2115 for Plaspy means directing the device to send its position and event reports to the Plaspy ingestion endpoint, validating connectivity, and ensuring the tracker appears in the Plaspy fleet. The goal is reliable telemetry delivery so Plaspy can display live location, process alarms, and store history for reporting.

- Set the network endpoint so the tracker reports to Plaspy instead of a local or vendor server.
- Ensure the tracker has power, GSM connectivity, and any required SIM data plan for packet transmission.
- Use the NTC Configurator or supported SMS/DTMF commands to change server settings and save parameters.
- Validate that the device successfully sends GNSS fixes and alarm messages to Plaspy.
- Confirm the device is visible in Plaspy and that events such as impact or movement alarms are received.

## Plaspy Server Settings

- Server domain d.plaspy.com
- Server IP 54.85.159.138
- Port 8888
- Transport support for UDP or TCP on port 8888
- Plaspy automatically detects the tracker protocol and uses the same port for all supported devices

## Typical Requirements Before Setup

- Access to the SIGNAL S-2115 operator guide and the NTC Configurator utility for local USB configuration.
- A powered and installed S-2115 unit with GSM connectivity and an active SIM card or operator data plan.
- Local access to the device via USB or a way to send configuration commands via SMS if the device supports SMS configuration.
- Confirmation of current firmware version and any vendor notes for archived or discontinued units.
- A test vehicle or bench power setup to validate tracking and alarm delivery prior to full deployment.

## How This Tracker Connects to Plaspy

The S-2115 sends GNSS position fixes and device events over GSM to a Plaspy ingestion endpoint so the platform can provide live tracking and alarm workflows. Configure the device to report to the shared Plaspy endpoint and use the validated port so Plaspy can process the incoming data with its automatic protocol detection.

- The tracker transmits satellite location fixes over GSM to the Plaspy server endpoint.
- Impact, tilt, and movement alarms generated by the internal accelerometer are sent to Plaspy for immediate notification.
- Remote status queries and simple control commands can be issued from operator workflows and verified via reported status.
- Configure the device to use d.plaspy.com or 54.85.159.138 and port 8888 so Plaspy receives telemetry.
- Select UDP or TCP on port 8888 if the device requires an explicit transport choice.

## Common Configuration Workflow

1. Access the official manufacturer configuration method or software such as the NTC Configurator or the approved SMS/DTMF command set.
2. Enter the Plaspy server domain d.plaspy.com or the Plaspy server IP 54.85.159.138 in the device server field.
3. Set port 8888 for the device server parameter. Remember that Plaspy uses the same port for all devices.
4. Choose UDP or TCP if the device requires a specific transport selection when configuring the server.
5. Apply or save the configuration in the configurator tool or send the saved command sequence via SMS if supported.
6. Restart the device if the manufacturer instructions require a reboot to apply network settings.
7. Validate that the device reports to Plaspy by confirming visibility and incoming packets in the Plaspy platform. Plaspy will automatically detect the tracker protocol.

## Example Configuration Commands

The exact configuration commands and sequences for the S-2115 are provided by Navtelekom in the operator guide and the NTC Configurator documentation. Manufacturer tools can use USB utilities or SMS command strings to change server parameters. Because manufacturer firmware and command syntax may vary, consult the official SIGNAL S-2115 documentation or the NTC Configurator help for the precise commands for your firmware revision.

## Configuration Notes

- The S-2115 is listed as archived or discontinued in vendor documentation so confirm that you have the matching operator guide and NTC Configurator version for your unit.
- Firmware differences can change parameter names and SMS command syntax. Always verify the exact commands for your firmware release.
- Use d.plaspy.com or 54.85.159.138 and port 8888 consistently during configuration because Plaspy uses the same port for all supported devices.
- Choose UDP or TCP based on the device requirement and network conditions. Plaspy accepts both transports and automatically detects the protocol.
- Test alarm events and telemetry in a controlled environment before deploying to production to ensure event notification behavior meets operational needs.

## Why Use Plaspy with This Configuration

Integrating the SIGNAL S-2115 with Plaspy gives organizations a practical way to continue using legacy S-2115 units while benefiting from centralized dashboards, historical logs, and alert workflows. Plaspy ingests positioning and alarm reports from the S-2115 so operators can monitor fleets, receive impact and movement notifications, and maintain operational oversight from a single platform.
