# SIGNAL S-2115

The SIGNAL S-2115 is a vehicle monitoring GPS tracker \(GLONASS/GPS\) built for security-minded fleets and individual vehicles. Designed to integrate with centralized platforms such as Plaspy, the S-2115 combines satellite positioning with GSM communications to deliver reliable real-time tracking, impact and movement alarms, and remote control options for routine diagnostics and incident response.

The S-2115 is well suited for fleet management and anti-theft monitoring where straightforward telemetry and alarm reporting are required. With a USB configuration interface, an internal accelerometer for shock and tilt detection, and support for SMS and voice alarm delivery, this device can be incorporated into Plaspy-managed workflows to enhance situational awareness and speed response to vehicle events. Note: this model is listed as discontinued \(archived\); firmware and configuration tools remain available for legacy deployments.

## Key Highlights

- Plaspy compatible positioning: GLONASS and GPS satellite location combined with GSM communications for real-time tracking integration.
- Impact and movement detection via internal accelerometer to trigger alarms on shocks, tilts or unauthorized displacement.
- Flexible alarm delivery — notifications can be sent by SMS or by voice calls for immediate alerts to operators and drivers.
- Remote control and diagnostics using voice menu, DTMF tones, and SMS command strings for configuration and status queries without physical access.
- USB interface for local configuration and firmware updates using the supplied NTC Configurator and firmware archives.
- Designed for fleet management and vehicle anti-theft use cases, supporting centralized monitoring system integration.
- Documentation and installer tools provided: operator guide, NTC Configurator utility, and archived firmware for related SIGNAL models.

## How It Works with Plaspy

When integrated with Plaspy, the SIGNAL S-2115 provides position and event data that Plaspy can use for real-time tracking, alerts, and reporting. The device sends GNSS position fixes and alarm notifications over GSM; Plaspy ingests those inputs to populate vehicle location displays, trigger configurable alarm workflows, and produce telemetry logs for fleet management and forensic analysis.

- Real-time location and telemetry updates: GLONASS/GPS positions transmitted via GSM for live tracking in Plaspy.
- Impact, tilt and movement alarms from the internal accelerometer are delivered for immediate incident notification.
- Alarm delivery via SMS and voice calls — Plaspy can use these channels as part of alert escalation or accept the device’s reports through configured ingestion methods.
- Remote commands and diagnostics using voice menu, DTMF, and SMS allow operators to query status, change parameters, or perform simple remote actions from Plaspy or connected operator workflows.
- Local USB configuration and firmware update support \(NTC Configurator and archived firmware\) for onsite setup and maintenance prior to Plaspy onboarding.
