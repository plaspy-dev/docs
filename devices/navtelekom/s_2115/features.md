# Navtelekom - СИГНАЛ S-2115 Features

This page provides a public feature overview of the Navtelekom СИГНАЛ S-2115 and explains how its documented capabilities map to Plaspy for fleet monitoring and alarm handling. It focuses on user facing functionality and practical uses without exposing private implementation details, drawing on the S-2115 operator guidance and archived documentation.

Exact feature availability and behavior depend on firmware version, hardware revision, installation method, and the manufacturer implementation. Features described here reflect the device documentation for legacy S-2115 units and should be cross checked against the unit in hand and the vendor documentation before deployment.

## Feature Overview

The СИГНАЛ S-2115 is a vehicle mounted GPS tracker that combines GLONASS and GPS positioning with GSM communications for real time location and event reporting. Its design emphasizes straightforward tracking, impact and movement detection, and remote configuration options suitable for fleets and anti theft monitoring.

- Real time GNSS positioning using GLONASS and GPS for vehicle location reporting.
- Impact, tilt and movement alarms generated by the internal accelerometer for incident detection.
- Alarm delivery via SMS and voice calls to notify operators and drivers immediately.
- Remote control and diagnostics using SMS command strings, DTMF tones, and voice menu interactions.
- Local USB configuration and firmware update support through the NTC Configurator utility.

## Core Features of Navtelekom - СИГНАЛ S-2115

- GLONASS and GPS satellite positioning for regular location fixes.
- GSM communications for data transmission and voice based alarm delivery.
- Internal accelerometer for detecting shocks, tilts and unauthorized displacement.
- SMS based commands and reports for remote status queries and parameter changes.
- Voice menu and DTMF support for remote control and rapid operator interaction.
- USB configuration interface for onsite setup and firmware updates using NTC Configurator.
- Documentation and archived firmware availability for legacy maintenance and installers.

## How These Features Work with Plaspy

When connected with Plaspy, the S-2115 supplies position and event data that Plaspy can use to visualize vehicle location, trigger alerts, and maintain historical logs. Plaspy ingests the device reports to provide centralized monitoring and operational workflows.

- Live vehicle location appears in Plaspy dashboards based on GNSS fixes reported by the device.
- Accelerometer based impact and movement alarms are visible in Plaspy as events for immediate operator awareness.
- SMS and voice alarm pathways carried by the device can be used alongside Plaspy workflows for escalation and notification.
- Remote commands and status queries sent via SMS or DTMF can assist operators during troubleshooting and can be reflected in Plaspy incident notes.
- Local USB configuration and firmware updates simplify pre on boarding setup before the device transmits to Plaspy.

## Typical Use Cases

- Fleet tracking for routing, dispatching, and operational visibility using Plaspy maps and history.
- Anti theft monitoring with impact and movement alarms to notify operators and drivers.
- Incident logging for shocks and collisions to support maintenance and post event review.
- Remote diagnostics and parameter changes for operational continuity without physical access.
- Legacy device integration to centralize older trackers into a modern Plaspy managed system.
