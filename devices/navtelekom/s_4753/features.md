## Feature Overview

The СИГНАЛ S-4753 is a professional GLONASS/GPS vehicle tracker designed for demanding fleet and telematics projects. When used with Plaspy, the unit provides continuous position reporting, vehicle telemetry via CAN, event input monitoring, and on-board logging to support live operations and historical analysis.

- Real-time GLONASS/GPS position reporting for live tracking and route monitoring.
- Dual CAN interfaces to capture comprehensive vehicle telemetry such as speed and engine parameters.
- 4G modem with dual SIM and external antenna support for resilient cellular connectivity.
- On-board SD card logging and an internal backup battery for data continuity during outages.
- Rich I/O set including universal inputs, controlled outputs, RS-485, 1-Wire, MODBUS and Bluetooth 4.0 for sensor and peripheral integration.

## Core Features of Navtelekom - СИГНАЛ S-4753

- GLONASS and GPS satellite positioning for accurate location tracking.
- 4G modem with dual SIM redundancy and support for an external antenna to improve cellular and GNSS reception.
- Two independent CAN interfaces for engine and comfort bus telemetry collection.
- On-board microSD logging support up to 32 GB plus an internal 800 mAh Li‑Po backup battery for continued recording.
- Six universal inputs and four controlled outputs to monitor and act on vehicle signals.
- Serial and bus interfaces including RS-485, 1-Wire and MODBUS for external sensor integration.
- Bluetooth 4.0 for short range peripherals and BLE sensors.
- Power and input protection suitable for vehicle installations including rated protection on power lines and inputs.

## How These Features Work with Plaspy

Plaspy ingests position and telemetry from the S-4753 and presents those data points in dashboards, maps, event logs and reports. The integration allows fleet managers to see live status, replay historical traces, and act on device events without exposing sensitive device internals.

- GNSS positions are displayed on Plaspy maps for live tracking and route history.
- CAN-bus telemetry from the dual interfaces is translated into meaningful metrics and available for reporting and analytics.
- On-board SD logs and backup battery behavior support continuous data capture that can be reconciled in Plaspy after network interruptions.
- Universal inputs and controlled outputs generate events in Plaspy for ignition, door, alarm and other wired signals.
- Bluetooth and serial sensor inputs can be surfaced as peripheral events or state changes inside the Plaspy platform.
