# Navtelekom - СИГНАЛ S-2613 Features

This page describes the public feature context for using the Navtelekom СИГНАЛ S-2613 tracker with Plaspy. It focuses on practical capabilities, how the device feeds data into Plaspy, and what fleet managers and integrators can expect when using the S-2613 as part of a Plaspy-managed solution.

## Feature Overview

The СИГНАЛ S-2613 is an entry level professional tracker designed for reliable vehicle and asset monitoring where stable satellite positioning, robust power handling and flexible I O are important. It is intended to provide continuous GNSS positioning, basic telemetry, and local connectivity options while integrating directly with Plaspy for visualization and alerting.

- Stable GLONASS and GPS positioning with external GNSS antenna for real time location.
- 2G GSM modem with a single SIM slot for cellular connectivity in supported regions.
- Backup power and input protection for continuity of tracking during power events.
- Multiple digital and analog inputs plus driver outputs to capture alarms and control external equipment.
- RS 485 interface and Bluetooth 4.0 for local sensor integration and hands free audio.

## Core Features of Navtelekom - СИГНАЛ S-2613

- GLONASS and GPS positioning with external antenna support for consistent satellite reception.
- 2G GSM modem and single SIM slot for cellular reporting in areas with GSM coverage.
- External GNSS and GSM antennas to improve signal reliability in vehicle installations.
- Power input protection up to 200 V and an integrated 800 mAh Li Po backup battery for power loss continuity.
- Four discrete digital inputs, one analog input and four driver control outputs for monitoring and control.
- RS 485 interface for integration with external telemetry devices and controllers.
- Bluetooth 4.0 for local sensor pairing and a hands free speakerphone for voice communication.
- Support for local and remote configuration workflows via manufacturer tools such as NTC Configurator and DRC.
