# Navtelekom - SIGNAL S-4651

![SIGNAL S-4651](./tracker.webp)

The SIGNAL S-4651 is a professional-grade LTE 4G GPS/GLONASS vehicle tracker designed for demanding fleet management and telematics deployments. Built with an LTE Cat-1 modem \(with 3G/2G fallback\), dual SIM support, external GNSS/GSM antenna connections and a comprehensive set of vehicle interfaces, the S-4651 is Plaspy compatible and ready to deliver reliable real-time tracking, rich telemetry and secure logging for commercial fleets.

Engineered for integration, the SIGNAL S-4651 supports CAN bus connectivity, multiple serial ports, Bluetooth 4.0 and SD card logging to ensure continuous data capture and remote diagnostics. With a built-in 800 mAh Li-Po backup battery and robust input protection, this tracker is a solid choice for fleet management, anti-theft workflows, remote telemetry and advanced diagnostics when used with the Plaspy platform.

## Key Highlights

- Plaspy compatible for seamless real-time tracking and fleet management integration.
- LTE Cat-1 modem with 3G/2G fallback and dual SIM for resilient mobile connectivity.
- Comprehensive vehicle I/O: 6 universal inputs, 4 outputs, CAN, RS-232/RS-485 and 1‑Wire.
- Built-in 800 mAh Li‑Po backup battery and SD card support \(up to 32 GB\) for offline logging.
- Bluetooth 4.0 for short-range integrations with BLE sensors and beacons.
- Audio I/O \(microphone and speaker\) enables two-way voice communication with drivers.
- Overvoltage protection on inputs \(up to 200 V\) for robust vehicle-level safety.

## How It Works with Plaspy

Connecting the SIGNAL S-4651 to Plaspy brings vehicle-level data into a single telematics console for live monitoring, alerts and historical reporting. The device streams GNSS position and on-board telemetry to Plaspy over cellular networks; Plaspy then processes location, CAN and I/O data to deliver maps, geofences, alerts and actionable fleet insights in real time.

- Real-time location and telemetry updates via LTE Cat-1 \(with 3G/2G fallback\) for continuous tracking.
- Ignition and status monitoring — ignition inputs and CAN signals can be forwarded to Plaspy for movement and engine state reporting.
- Fuel monitoring — CAN bus telemetry can supply fuel-level and consumption data to Plaspy where available from the vehicle.
- Remote immobilizer/control — control outputs and CAN integration enable remote cutoff/immobilization workflows when configured through Plaspy.
- Bluetooth sensors and beacons — short-range BLE devices can be paired to the tracker and relayed to Plaspy for cargo or driver-sensor telemetry.

## Use Cases

- Fleet management — real-time tracking, route replay and driver behavior telemetry for medium and large vehicle fleets.
- Anti-theft and immobilization — GPS tracking plus remote control outputs and CAN commands enable theft response and restricted restarts via Plaspy.
- Fuel monitoring and diagnostics — collect CAN bus telemetry \(fuel level, consumption, engine data\) and send to Plaspy for fuel monitoring and cost control.
- Cargo and driver environment monitoring — pair BLE sensors and beacons to capture temperature, door/open events or proximity data while logging locally to SD card.
- Two-way driver communications — built-in microphone and speaker allow voice contact for dispatch and safety checks through the telematics workflow.
