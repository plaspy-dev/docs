## Feature Overview

The СМАРТ S-2437 is a compact vehicle tracker combining GNSS positioning, cellular connectivity and a set of vehicle interfaces intended for robust fleet and telematics use. It provides persistent tracking with a backup battery and multiple communications and I/O options that make it suitable for telemetry, anti-theft setups and integration with vehicle systems.

- High-sensitivity GLONASS and GPS positioning for accurate location reporting across regions.
- Dual SIM 2G cellular modem with integrated GSM antennas for resilient connectivity and continuous telemetry.
- Internal rechargeable backup battery (800 mAh) to maintain operation during vehicle power interruptions.
- Two CAN interfaces and a range of I/O and industrial protocols for integrating vehicle diagnostics and external sensors.
- Bluetooth 4.0 for local configuration and onsite parameter tuning using compatible tools.
- Remote device and firmware management via the DRC system for fleet-scale administration.

## Core Features of Navtelekom - СМАРТ S-2437

- GLONASS/GPS high-sensitivity receiver for real-time and historical positioning.
