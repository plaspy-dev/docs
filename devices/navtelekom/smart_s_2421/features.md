# Navtelekom - SMART S-2421 Features

This page provides public feature context for using the Navtelekom SMART S-2421 with Plaspy. It summarizes the practical capabilities and operational value you can expect when integrating this compact GLONASS/GPS vehicle tracker into Plaspy for real time tracking, telemetry collection, and centralized fleet oversight.

Exact feature availability and behaviour can vary by firmware version, hardware revision, installation method and manufacturer configuration. Refer to manufacturer documentation for device specific details and verify which inputs, outputs and sensor options are present on each unit before deployment.

## Feature Overview

The SMART S-2421 is a compact vehicle tracker designed to provide dependable position and telemetry reporting for fleet management and anti theft workflows. Its integrated GNSS and cellular antennas and built in battery make it suitable for standard automotive installations where continuous location visibility and basic sensor integration are required.

- Real time GNSS position reporting using integrated GLONASS and GPS antennas for consistent fixes.
- Cellular connectivity for sending location and telemetry to fleet platforms such as Plaspy.
- Built in rechargeable battery to maintain operation during short power interruptions and support anti theft monitoring.
- Sensor and accessory connectivity via Bluetooth 4.0 and a 1 Wire interface to expand telemetry inputs.
- Multiple configurable inputs and outputs for ignition detection, immobilizer control or accessory switching.

## Core Features of Navtelekom - SMART S-2421

- Integrated GLONASS and GPS antennas for vehicle position tracking.
- Cellular modem support for remote telemetry delivery to fleet servers.
- Built in rechargeable battery for backup power during short outages.
- Automotive grade power line protection rated to withstand transient voltages.
- Bluetooth 4.0 support for external sensors and accessory modules.
- 1 Wire sensor interface to connect compatible external sensors.
- Three universal input lines and two configurable output lines for ignition and control use.
- Compatibility with NTC Configurator and DRC remote device management for configuration and firmware administration.

## How These Features Work with Plaspy

When connected to Plaspy, the SMART S-2421 reports GNSS positions and device telemetry so operators can monitor assets in real time and use events to trigger alerts and reports. Plaspy automatically detects compatible tracker protocols and presents location and input/output events in the platform to support operational decision making.

- Real time location updates appear on Plaspy maps for continuous visibility of vehicles.
- Input events such as ignition changes can be used to derive journey starts and stops inside Plaspy.
- Configurable outputs and event reporting allow Plaspy to reflect immobilizer or accessory actions as status events.
- Sensor data from 1 Wire or Bluetooth modules can feed additional telemetry fields in Plaspy dashboards where supported.
- Device health information such as battery backup status and power line events can be surfaced for maintenance and alerting.

## Typical Use Cases

- Fleet tracking and route visibility for midsize vehicle fleets.
- Anti theft monitoring with backup battery support and input based movement detection.
- Remote diagnostics and device health monitoring to reduce downtime.
- Integration of additional sensors for fuel level, temperature, or cargo condition reporting when compatible sensors are attached.
- Immobilizer or accessory control workflows using configurable outputs and Plaspy event rules.
- Centralized device configuration and firmware management alongside operational monitoring.

## Feature Availability Notes

- Feature presence can depend on firmware version and hardware revision; some interfaces or behaviours may differ between production batches.
- Sensor support requires compatible external modules and correct wiring or pairing during installation.
- Remote management and firmware updates are available via manufacturer tools but may need coordination with Plaspy workflows for maintenance windows.
- Regional cellular band support and modem behaviour depend on the specific SKU and local certification.
- Installation type and vehicle wiring can affect available inputs and outputs and therefore the exact telemetry Plaspy will receive.
