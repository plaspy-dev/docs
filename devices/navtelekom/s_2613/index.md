# Navtelekom - СИГНАЛ S-2613

![СИГНАЛ S-2613](./tracker.jpeg)

The СИГНАЛ S-2613 from Navtelekom is a compact vehicle and asset GPS tracker designed to deliver reliable positioning and basic telematics. As an entry level device in the SIGNAL family, the S-2613 provides GLONASS and GPS positioning, a 2G GSM modem, multiple digital and analog inputs, RS-485 connectivity, Bluetooth 4.0 and a built in backup battery, all intended for continuous location awareness and event monitoring in automotive and industrial contexts.

This model is listed as compatible with Plaspy and is suitable for organizations that need straightforward integration of position and event data into a fleet management platform. When connected to Plaspy, the S-2613 supplies real time location and telemetry that feed dashboards, alert rules and reporting workflows, making it useful for fleet visibility, asset tracking and basic remote monitoring through Plaspy.

## Key Highlights

- Plaspy compatible integration for position, events and telematics reporting
- GLONASS and GPS positioning with external GNSS antenna for stable tracking
- 2G GSM modem with single SIM slot for cellular connectivity where coverage exists
- Power input protection up to 200 V and an integrated 800 mAh backup battery for continuity
- Multiple I O options including discrete digital inputs, an analog input and driver outputs
- RS 485 interface and Bluetooth 4.0 for external sensor and controller integration
- Compact rugged form factor suited to vehicle and asset installation

## How It Works with Plaspy

When paired with Plaspy the СИГНАЛ S-2613 streams location and device telemetry to the platform so fleet managers and operators can monitor assets in near real time. Plaspy ingests position updates and device events, maps historical movement, and uses input states to trigger alerts and automation based on configured rules.

- Real time location updates and telemetry visible on Plaspy dashboards
- Event driven reporting from digital inputs for alarms, door status and ignition events
- Analog input telemetry available for auxiliary sensors when configured and mapped in Plaspy
- Remote control and output state monitoring through Plaspy workflows where supported
- Historical route and activity reports for operational analysis and compliance

## Typical Use Cases

- Fleet management for light and medium vehicle fleets needing continuous location and basic telemetry
- Anti theft monitoring and alarm workflows using discrete inputs and output control
- Cargo and equipment tracking where backup battery helps maintain visibility during power loss
- Integration with external sensors and controllers via RS 485 and analog inputs for operational metrics
- Local sensor pairing and driver interaction using Bluetooth and hands free audio features
