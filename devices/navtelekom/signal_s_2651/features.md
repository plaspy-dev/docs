# Navtelekom - SIGNAL S-2651 Features

This page provides a public, features oriented summary of the Navtelekom SIGNAL S-2651 and how its capabilities map to Plaspy for fleet management, telematics, and asset monitoring. It focuses on practical, non sensitive information about what the tracker can do when used with Plaspy and how that functionality delivers value for monitoring and operations.

Exact feature availability for any SIGNAL S-2651 device can vary by firmware version, hardware revision, installation choices and manufacturer implementation. For device specific behavior, configuration details and the latest firmware related notes consult the official Navtelekom documentation and release notes.

## Feature Overview

The SIGNAL S-2651 is a compact multi constellation GNSS tracker designed for professional telematics scenarios. It combines positioning, resilient cellular connectivity, extensive I O and local logging to provide continuous tracking, event capture and integration options suitable for vehicles and fixed assets.

- Multi constellation positioning using GLONASS and GPS for reliable real time location and route history.
- 2G cellular modem with dual SIM support to improve connectivity resilience for continuous telemetry delivery.
- Multiple vehicle and industrial interfaces including RS-232, RS-485, CAN and 1-Wire for integrating sensors and vehicle data.
- Local SD card logging up to 32 GB to retain data during network outages and support post trip analysis.
- Configurable inputs and switched outputs for ignition, door and event monitoring plus remote actuator control.
- Bluetooth 4.0 for short range configuration and integration with compatible Bluetooth sensors.

## Core Features of Navtelekom - SIGNAL S-2651

- GLONASS and GPS multi constellation GNSS positioning for accurate location and route records.
- Dual SIM 2G cellular modem for redundant connectivity and continuous telemetry transmission.
- Extensive interfaces RS-232, RS-485, CAN and 1-Wire for sensor telemetry and MODBUS device integration.
- Six universal configurable inputs and four switched outputs for event detection and remote control actions.
- Local SD card support up to 32 GB for offline data logging and continuity during coverage gaps.
- Built in Li Po backup battery for safe shutdown logging and short term power retention.
- Bluetooth 4.0 for on site configuration and short range sensor connectivity.

## How These Features Work with Plaspy

When used with Plaspy, the SIGNAL S-2651 streams location updates and event data into the platform so teams can monitor assets in real time and review historical records. Plaspy ingests position and telemetry, presents events and device state, and uses logged data for continuity when live telemetry is interrupted.

- Real time position updates and route history visible in Plaspy for situational awareness and dispatch decision making.
- Event reporting from configurable inputs and switched outputs shown as actionable events within Plaspy workflows.
- CAN and 1-Wire sensor telemetry available to Plaspy for integration into fuel, efficiency or custom reports.
- SD card logging provides a local fallback source that Plaspy can use to restore historical records if network uploads are delayed.
- Bluetooth enabled on site configuration and short range sensor pairing for quick device setup and sensor commissioning reflected in Plaspy device metadata.
