# Navtelekom - СИГНАЛ S-2652 Features

This page provides a public feature summary for the Navtelekom СИГНАЛ S-2652 tracker and explains how its capabilities map to Plaspy for real time tracking, telemetry ingestion, and fleet operations. It is intended to help fleet managers, integrators, and technical users understand the practical value of the device when paired with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and regional manufacturer releases. The S-2652 is a discontinued model with manufacturer replacement recommendations, so verify device specifics against the maker documentation before planning long term deployments.

## Feature Overview

The СИГНАЛ S-2652 is an industrial vehicle telematics unit designed for continuous tracking, robust power environments, and deep wired integration. When used with Plaspy it provides resilient position reporting, local data capture, and a range of inputs and outputs for vehicle monitoring and control.

- GNSS positioning support for GLONASS and GPS to provide location updates for Plaspy dashboards.
- 3G cellular modem with dual SIM for connectivity redundancy and continuous reporting in varied coverage areas.
- Onboard microSD logging for uninterrupted local data collection during network outages and later reconciliation with Plaspy.
- Multiple universal inputs and controllable outputs to report ignition door and alarm status and to support immobilizer workflows.
- Industrial interfaces including serial ports, CAN, and 1-Wire for integrating vehicle telemetry and external sensors.
- Rugged power protection and an internal backup battery to maintain operation in harsh vehicle electrical environments.

## Core Features of Navtelekom - СИГНАЛ S-2652

- GLONASS and GPS positioning for reliable location tracking.

## How These Features Work with Plaspy

Plaspy ingests the S-2652 telemetry and GNSS data to present real time location, events, and historical records in the platform. Plaspy automatically detects supported tracker protocols and maps device inputs, outputs, and logged records into fleet views and reports.

- Real time GNSS position and movement updates are presented on Plaspy maps and live views.
- Universal inputs such as ignition and door status are available as events for alerts and rule based monitoring in Plaspy.
- Controllable outputs such as immobilizer controls can feed remote workflows and status monitoring inside Plaspy.
- Onboard microSD logged records are reconciled with Plaspy when connectivity is restored to ensure no gaps in historical data.
- CAN and serial telemetry can be mapped into dashboards and reports in Plaspy for fuel or vehicle data analytics where those interfaces are used.
