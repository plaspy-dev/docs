# Navtelekom - СИГНАЛ S-2654 Features

This page provides a public feature summary for the Navtelekom СИГНАЛ S-2654 and explains how its capabilities map to Plaspy for tracking, telemetry, and fleet workflows. It focuses on the practical, non-sensitive details that fleet managers and integrators commonly need when evaluating device-platform compatibility.

Exact feature availability can vary by firmware version, hardware revision, regional variant and installation method. The S-2654 is listed as archived by the manufacturer, and integrators should consult Navtelekom resources such as documentation, configuration tools and firmware history for device specific behavior.

## Feature Overview

The СИГНАЛ S-2654 is positioned as an industrial vehicle tracker delivering GNSS positioning, cellular connectivity and flexible I O and serial interfaces for telemetry. In Plaspy, these capabilities are used to provide live location, event monitoring and reconciled historical data for fleet and asset management.

- GLONASS positioning with external GNSS antenna support for vehicle location reporting.
- Built in 3G modem with dual SIM redundancy to improve cellular availability for real time telemetry.
- Local buffering and recovery through microSD logging support up to 32 GB.
- Multiple universal inputs and configurable outputs for event detection and control.
- Serial and bus interfaces such as RS-232, RS-485, CAN and 1-Wire for integration with third party sensors and controllers.
- MODBUS support for structured telemetry exchange with industrial controllers.

## Core Features of Navtelekom - СИГНАЛ S-2654

- GLONASS GNSS positioning combined with an onboard cellular modem for live reporting.
- Dual SIM support and external antenna connections for improved signal resilience.
- Local storage on microSD up to 32 GB for offline logging and post connection reconciliation.
- Six universal inputs and four configurable outputs for ignition, doors, alarms or actuator control.
- Serial and bus connectivity including RS-232, RS-485, CAN bus and 1-Wire for telemetry and device integration.
- MODBUS protocol support for integration with third party controllers and sensors.
- Robust input power protection and line protection designed for vehicle and industrial power environments.
- Built in backup battery to maintain temporary operation when external power is interrupted.

## How These Features Work with Plaspy

When connected to Plaspy, the S-2654 delivers location and telemetry into a single monitoring and reporting environment. Plaspy ingests the device's data stream and presents it for real time visibility, event handling and historical analysis.

- Real time GNSS positions and cellular delivered telemetry appear in Plaspy maps and live tracking views.
- Universal input events can be reflected as alerts, status indicators or triggers for workflows in Plaspy.
- Serial, CAN and MODBUS telemetry can be forwarded into Plaspy for sensor dashboards, reporting and analytics.
- microSD local logs provide a recovery path that Plaspy can reconcile to ensure continuity of historical records after connectivity gaps.
- Configurable outputs on the device can support anti theft or remote control workflows initiated through Plaspy or local device logic.
