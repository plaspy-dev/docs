This page provides a public feature overview of the Navtelekom СИГНАЛ S-4753 and how the device integrates with Plaspy for fleet tracking and telematics. It focuses on the practical capabilities you can expect when using the S-4753 with Plaspy, and explains how those capabilities translate into visibility and operational value on the Plaspy platform.

## Feature Overview

The СИГНАЛ S-4753 is a professional GLONASS/GPS vehicle tracker intended for demanding fleet and transport deployments. Its design emphasizes continuous connectivity, in-vehicle telemetry capture, and on-board data resilience to support monitoring, reporting, and diagnostics workflows when paired with Plaspy.

- GNSS positioning using GLONASS and GPS for reliable location reporting in Plaspy.
- 4G cellular modem with dual SIM redundancy and external antenna support for improved coverage and uptime.
- Dual CAN interfaces for collecting vehicle bus telemetry and richer fleet analytics.
- On-board data logging to microSD plus an internal backup battery to preserve records during outages.
- Broad I/O and communications including multiple universal inputs, controlled outputs, RS-485, 1-Wire, MODBUS and Bluetooth 4.0 for sensor and peripheral integration.
- Vehicle-grade protection and power line resilience suitable for transport installations.

## Core Features of Navtelekom - СИГНАЛ S-4753

- GLONASS and GPS positioning for continuous location updates and historical tracks.
- 4G modem with dual SIM support to reduce cellular downtime and improve connectivity.
- Two independent CAN interfaces to capture engine and comfort CAN telemetry where available.
- On-board microSD logging up to 32 GB and an 800 mAh Li‑Po backup battery for data continuity.
- Multiple universal inputs and controlled outputs for event detection and remote actuation workflows.
- RS-485, 1-Wire, and MODBUS support for integrating external sensors and industrial peripherals.
- Bluetooth 4.0 support for local sensor pairing and short range telemetry.
- Built in protection for vehicle power and input lines suitable for transport environments.

## How These Features Work with Plaspy

When paired with Plaspy, the S-4753 delivers location and vehicle telemetry into a unified fleet management environment. Plaspy ingests position updates, interprets time stamped telemetry, and surfaces events and logs to support monitoring, alerts, and analysis.

- Position and movement data appear in Plaspy live maps and trip history for route monitoring and replay.
- CAN bus telemetry can be mapped to meaningful vehicle metrics in Plaspy dashboards and reports.
- Inputs and outputs generate events that Plaspy can use for alerting, status displays, and automation rules.
- On-board SD logging and the backup battery preserve records during network outages and allow Plaspy to reconcile missing telemetry after reconnection.
- Bluetooth and peripheral interfaces enable Plaspy to incorporate short range sensor data and extended telemetry into asset views.
