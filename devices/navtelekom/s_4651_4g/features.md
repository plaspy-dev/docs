# Navtelekom - СИГНАЛ S-4651 (4G) Features

## Feature Overview

The SIGNAL S-4651 is a professional GLONASS/GPS vehicle terminal designed for demanding fleet applications. Its combination of multi network cellular connectivity, robust I/O, local logging and accessory support provides persistent position and telemetry reporting for integration with Plaspy.

- Multi network cellular connectivity with dual SIM failover for uninterrupted data transmission in mobile environments.
- External GLONASS/GPS and GSM antennas to improve reception in vehicle installations and challenging coverage areas.
- Comprehensive universal inputs and configurable outputs for monitoring ignition, doors, alarms and external sensors.
- Multiple industrial interfaces including RS-232, RS-485, CAN bus and 1-Wire to support third party telemetry and equipment integration.
- Local data logging on microSD and an internal backup battery to preserve recent positions and events during power interruptions.

## Core Features of Navtelekom - СИГНАЛ S-4651 (4G)

- GLONASS and GPS positioning support for reliable satellite-based location.
- 2G, 3G and 4G LTE cellular modem with dual SIM support for network redundancy and continuous data uplink.
- External antenna connections for both GNSS and cellular antennas to improve signal quality in vehicle installations.
- Six universal digital/analog inputs and four configurable control outputs for sensors, ignition and actuator control.
- Industrial interfaces including RS-232, RS-485, CAN bus and 1-Wire plus MODBUS support for telemetry collection.
- Local microSD data logging support up to 32 GB for caching historical data on the device.
- Bluetooth 4.0 for local configuration, accessory pairing and short range accessory connections.
- Integrated Li Po backup battery and robust vehicle power protection to reduce data loss during power events.

## How These Features Work with Plaspy

Plaspy ingests position, telemetry and event data from the S-4651 so fleet operators can monitor vehicles, review history and respond to events from a single platform. Plaspy automatically detects compatible tracker protocols and accepts device connections, enabling straightforward integration.

- Real time location and telemetry updates transmitted over cellular networks and visible in Plaspy maps and live views.
- Input and output events such as ignition, door status and alarms presented as actionable events and used for alerting and reporting.
- Local microSD logs uploaded or parsed by Plaspy to provide historical playback when cellular connectivity resumes.
- Telemetry from RS-232, RS-485, CAN bus and MODBUS sources available in Plaspy as custom data points when configured.
- Bluetooth paired accessories and local diagnostics can be used during on site configuration and maintenance while the device remains managed by Plaspy.

Note: Plaspy automatically detects many tracker protocols and accepts device connections to the platform endpoint. For detailed integration settings consult Plaspy documentation and the device manufacturer resources.
