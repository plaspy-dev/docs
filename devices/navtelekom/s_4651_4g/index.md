# Navtelekom - СИГНАЛ S-4651 (4G)

![СИГНАЛ S-4651 (4G)](./tracker.jpeg)

The SIGNAL S-4651 is a professional GLONASS/GPS vehicle tracking terminal from Navtelecom designed for demanding fleet monitoring applications and is fully compatible with Plaspy for integrated fleet management. This Plaspy compatible tracker extends the proven S-2651 platform with 2G, 3G and 4G LTE cellular connectivity, dual SIM failover and robust vehicle-grade interfaces so fleets can maintain continuous, real-time tracking and telemetry even in challenging electrical environments.

Ideal for operators who need reliable GPS tracker performance, the S-4651 supports local data logging, extensive I/O for sensor and ignition monitoring, Bluetooth 4.0 for accessory connections, and remote firmware management. Note: the SIGNAL S-4651 is listed as discontinued/archived by the manufacturer, but technical documentation and firmware history remain available for maintenance and integration with Plaspy.

## Key Highlights

- Multi-network cellular connectivity \(2G/3G/4G LTE\) with dual SIM for uninterrupted data transmission — supports Plaspy real-time tracking and alerts.
- External GLONASS/GPS and GSM antennas for improved satellite and cellular reception in vehicle installations.
- Comprehensive I/O set: six universal digital/analog inputs and four configurable control outputs for ignition, sensors, and immobilizer control.
- Multiple industrial interfaces \(RS-232, RS-485, CAN bus, 1-Wire\) plus MODBUS support for telemetry and third-party sensor integration.
- Local data logging on microSD \(up to 32 GB\) and integrated Li‑Po backup battery \(800 mAh\) to keep telemetry and position data intact during power interruptions.
- Bluetooth 4.0 for local configuration, accessory pairing or Bluetooth sensors/beacons integration with Plaspy-managed devices.
- Designed for harsh vehicle electrical environments with robust power protection and input line protection up to 200 V.

## How It Works with Plaspy

When connected to Plaspy, the SIGNAL S-4651 delivers real-time location, telemetry and event data over cellular networks so fleet managers can monitor vehicle position, status and diagnostics from a single dashboard. Plaspy ingests GNSS coordinates, I/O events, CAN/MODBUS telemetry and local logs to produce live tracking, historical playback, geofencing alerts, and fleet reports.

- Real-time location and telemetry updates transmitted via 2G/3G/4G to Plaspy.
- Ignition, door and alarm status via the universal digital/analog inputs for event-driven alerts and driver behavior analysis.
- Fuel monitoring and analog sensor capture using the unit’s analog inputs for fuel level sensors and other analog telemetry.
- Remote immobilizer and actuator control using configurable control outputs managed through Plaspy commands or alerts.
- Bluetooth sensors and beacons — local accessory connection and configuration using Bluetooth 4.0 for short-range telemetry and diagnostics.
