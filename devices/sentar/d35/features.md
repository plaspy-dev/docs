# Sentar - D35 Features

This page describes the public feature context for using the Sentar D35 with Plaspy. It focuses on the practical capabilities the D35 exposes for parents, caregivers, and organizations when the device is paired to Plaspy for monitoring, alerts, and situational awareness.

Exact feature availability can vary by firmware version, hardware revision, installation type, and manufacturer implementation. Refer to the device settings and official Sentar documentation for the most current device specific behavior and options.

## Feature Overview

The D35 is a Plaspy compatible 4G Android based kids smartwatch designed for real time positioning, secure communication, and simple parental monitoring. In Plaspy, the D35 supplies continuous location updates and status information that help caregivers maintain awareness and respond quickly when needed.

- Real time location using multi mode positioning for improved accuracy in urban and indoor conditions
- Dedicated SOS physical power button for fast emergency alerts and priority notifications
- Integrated 4G voice and data connectivity for two way communication and live telemetry
- Dual cameras and multimedia capture to provide contextual information for incidents when permitted
- Child friendly touchscreen interface for local interaction and simplified device use

## Core Features of Sentar - D35

- Multi mode location technologies including GPS, AGPS, LBS, and WiFi positioning for layered location data
- 4G connectivity with voice support to maintain continuous telemetry and enable two way communication
- Physical SOS power button for immediate emergency alerting and prioritized notification
- Dual cameras with front and rear capture for photo and video context during events
- 1.69 inch IPS color touchscreen for direct device interaction and simple on device controls
- IPX7 rated splash and rain resistance suitable for everyday wear in varied environments
- Android based platform and on device memory as provided by the manufacturer for application support
- Rechargeable battery with magnetic four pin charging for daily use and straightforward recharging

## How These Features Work with Plaspy

When the D35 is connected to Plaspy, the device streams its network backed telemetry so caregivers can see location, status, and alerts within Plaspy dashboards and maps. Plaspy automatically detects compatible tracker protocols and presents device events in a consistent interface for monitoring and notification workflows.

- Real time location points and position updates shown on maps to support movement tracking and situational awareness
- SOS events are surfaced as priority alerts so caregivers receive timely notifications of emergency button activations
- Connectivity and device status indicators displayed to help determine signal health and online state
- Two way communication and call status surfaced where supported to provide context about voice interactions
- Multimedia captured by the device can be attached to incident records in Plaspy when firmware and permissions allow it
