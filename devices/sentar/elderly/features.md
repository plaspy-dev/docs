# Sentar - Elderly Features

This page provides a public, features oriented summary of the Sentar Elderly 4G GPS watch and how its capabilities are used with the Plaspy platform. It is written to explain the device's practical functions, the ways those functions surface in Plaspy, and what caregivers and organisations can expect when they register the device in Plaspy for centralized monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, local model variants, installation method, and manufacturer implementation. For definitive device specifications and the latest firmware details review the manufacturer documentation referenced at the end of this page.

## Feature Overview

The Sentar Elderly is a Plaspy compatible wearable GPS watch designed for seniors and vulnerable users. It combines multi mode positioning and 4G cellular connectivity with an easy to read touchscreen and on device safety controls to deliver real time location and basic situational information to caregivers through Plaspy.

- Real time location reporting using GPS, AGPS, LBS and WiFi to improve accuracy in mixed indoor and outdoor conditions.
- 4G cellular connectivity for wide area data uplink and continuous position updates to Plaspy.
- Dedicated SOS button that sends an immediate alert and location context for faster caregiver response.
- 1.4 inch IPS touchscreen and a built in camera to provide on device information and quick situational checks.
- IPX7 water resistance and a 700mAh rechargeable battery for reliable day to day wearable use.

## Core Features of Sentar - Elderly

- Multi mode positioning: GPS, AGPS, LBS and WiFi location sources for improved coverage.
- 4G cellular support with fallback to WCDMA and GSM where supported by the device.
- Dedicated SOS emergency button that generates alert events for monitoring.
- On device touchscreen user interface sized for readability and simple operation.
- Built in camera for situational photos subject to device permissions and configuration.
- IPX7 water resistance suitable for typical daily water exposure.
- Rechargeable battery with magnetic charging for convenient recharging.
- Compact wearable form factor designed for seniors and vulnerable users.

## How These Features Work with Plaspy

When the Sentar Elderly is registered to Plaspy, the watch sends location and key status events over cellular networks to the Plaspy platform for centralized visibility. Plaspy presents this information in maps and timelines, and supports alerts and basic device health indicators so caregivers can act on relevant events.

- Live location appears on Plaspy maps with stored position history for later review.
- SOS button activations are forwarded to Plaspy as alert events with location context for prompt notification.
- Battery status and basic device health indicators are reported to Plaspy to help maintain uninterrupted monitoring.
- Photo capture events from the device can be surfaced for situational awareness where device permissions and configuration allow.
- Plaspy automatically detects compatible tracker protocol during device registration to simplify onboarding.

## Typical Use Cases

- Continuous elder care monitoring for independent seniors who need location visibility and one touch emergency alerts.
- Caregiver coordination across family members and care services with centralized alerts and shared location history.
- Short term supervision during travel, appointments, or day trips where cellular real time tracking provides reassurance.
- Mixed device monitoring where personal wearables are managed alongside fleet or asset trackers on the same Plaspy account.
- Situational checks using on device camera photos to support rapid assessment after an alert.
