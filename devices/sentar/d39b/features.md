# Sentar - D39B Features

This page provides a public feature overview for the Sentar D39B and explains how its capabilities are reflected when used with the Plaspy platform. It summarizes the D39B’s core functions relevant to location tracking, communications, and monitoring so that families, schools, and administrators can understand practical behavior when the device reports into Plaspy.

The exact availability and behavior of individual features can vary by firmware version, hardware revision, installation type, carrier and regional configuration, and manufacturer implementation. Where appropriate, the page highlights which features are generally present and advises checking manufacturer documentation for device specific details.

## Feature Overview

The Sentar D39B is a child-focused smart watch that combines layered positioning technologies with 4G voice and data to provide reliable location and communications for guardians and approved contacts. Running Android 8.1 on a small wrist form factor, the D39B is designed to deliver real-time position updates and familiar calling functions while supporting configurable safety modes.

- Multi-source positioning using GPS, AGPS, LBS and Wi‑Fi to improve location reliability in different environments.
- 4G voice and data with support for voice and video calling to approved contacts for immediate communication.
- Child-friendly hardware including a 1.85 inch IPS display and durable wristwatch design for everyday wear.
- Safety and supervision functions such as SOS emergency calling, class mode restrictions, pedometer tracking and optional remote voice monitoring where enabled.
- Android 8.1 platform that supports basic apps and contact management features depending on configuration.

## Core Features of Sentar - D39B

- Layered positioning: GPS combined with AGPS, LBS and Wi‑Fi for improved real-time location reporting.
- 4G voice and video calling for direct communication with pre-approved contacts.
- SOS emergency call support that can trigger alerts and event timestamps when configured.
- Class mode and configurable usage restrictions to limit distractions during scheduled times.
- Activity reporting such as a pedometer for basic step counts and routine checks where enabled.
- Remote voice monitoring and secure contact controls subject to firmware and configuration.
- Android 8.1 operating environment for app-based controls and device management where supported.

## How These Features Work with Plaspy

When the D39B is integrated into Plaspy, the watch’s location data and event reports are normalized and presented alongside other compatible devices so caregivers and administrators can maintain a single view of position and status. Plaspy makes device events and statuses visible in map and timeline interfaces to support situational awareness.

- Real-time location updates from GPS, AGPS, LBS and Wi‑Fi are shown on the Plaspy map for situational awareness.
- SOS events and emergency call timestamps are recorded as alerts so responders can see when incidents occur.
- Voice and video call indicators and approved-contact status appear in event logs when provided by the device.
- Activity and status notifications such as pedometer steps and class mode events are reflected in basic telemetry views where the device reports them.
- Plaspy normalizes incoming telemetry so the D39B appears alongside other trackers for unified monitoring and reporting.

## Typical Use Cases

- Parental location monitoring and rapid response to SOS events for child safety.
- Secure family communication via voice and video calls to approved contacts.
- School deployments where class mode limits distractions during lessons.
- Caregiver oversight with remote monitoring and activity checks for routine supervision.
- Combining D39B watches with other Plaspy devices to centralize monitoring across personal devices and larger telemetry fleets.

## Feature Availability Notes

- Feature availability depends on the device firmware version and the specific software configuration applied by the manufacturer or distributor.
- Regional variants and carrier support can affect 4G voice and video capabilities as well as positioning performance.
- Some functions such as remote voice monitoring, class mode, and step reporting may require explicit configuration or app support and are not guaranteed in every unit.
- Hardware revisions and installation methods can change which sensors or interfaces are present in a given watch.
- Always consult manufacturer documentation and device settings to confirm whether particular features are enabled for your unit.
