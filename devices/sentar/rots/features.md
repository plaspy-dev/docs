# Sentar - ROTS Features

This page provides a public overview of the Sentar ROTS pet GPS tracker and the practical feature context for using the device with Plaspy. It focuses on the device capabilities that are relevant to monitoring pets through the Plaspy platform and explains how data from the tracker appears in centralized tracking and reporting workflows.

Exact feature availability for any individual ROTS unit can vary based on firmware version, hardware revision, installation method, and the manufacturer's implementation choices. Users should treat the information here as a functional summary and check device firmware notes and manufacturer documentation for the most current, device specific details.

## Feature Overview

The ROTS is a compact wearable GPS tracker designed for pets and built to provide dependable location telemetry across broad cellular networks while integrating with Plaspy for visualization and reporting. It targets users who need continuous position updates, simple SIM provisioning, and reliable network fallback across regions.

- Real time location updates over cellular networks for live tracking and playback in Plaspy
- Multi network cellular connectivity with fallback from 4G to 3G to 2G for broader coverage
- Wearable collar friendly form factor suitable for continuous pet monitoring
- Nano SIM slot for flexible carrier selection and straightforward provisioning
- Onboard ASR chipset with 128MB RAM and 128MB ROM for stable continuous operation

## Core Features of Sentar - ROTS

- 4G 3G 2G cellular connectivity for wide area location coverage
- Wearable design optimized for pet collars and prolonged outdoor use
- Nano SIM support to allow carrier choice and easy provisioning
- ASR main chipset with 128MB RAM and 128MB ROM for steady performance
- Location telemetry optimized for position and timestamped tracking
- Broad frequency band support to improve roaming and connectivity across regions

## How These Features Work with Plaspy

When the ROTS tracker is paired with Plaspy, device location messages are sent to the platform where they are processed for visualization, history, and alerts. Plaspy automatically detects many tracker protocols and integrates incoming telemetry into its map and reporting features so owners can monitor pets without custom protocol setup.

- Live position updates appear on Plaspy maps for immediate location awareness
- Historical tracks and playback enable review of a pet's movements over time
- Geofence style alerts and event history can be generated from position data in Plaspy
- SIM based connectivity and multi network fallback reduce gaps visible in Plaspy reports
- Stable on device operation helps maintain consistent reporting into Plaspy

## Typical Use Cases

- Locating a lost or escaped pet using live map position and playback
- Monitoring outdoor activity or roaming patterns during walks and outings
- Remote supervision with alerts when a pet moves outside a predefined area
- Shared family monitoring where multiple users view the same tracked location
- Day to day visibility of pets in peri urban and rural environments

## Feature Availability Notes

- Firmware revisions can enable or change specific behaviors and reporting intervals
- Hardware revisions and regional variants may affect supported cellular bands and roaming
- Installation and collar placement can influence GPS reception and update frequency
- Manufacturer configuration and carrier provisioning impact initial setup and connectivity
- Always consult manufacturer release notes for recent changes to features and compatibility

## Why Use Plaspy with These Features

Using the Sentar ROTS with Plaspy gives pet owners a straightforward way to centralize location telemetry and manage visibility across devices. Plaspy collects and displays position data, stores history for playback, and provides alerting and user access controls that make ongoing pet monitoring practical for individuals and families.
