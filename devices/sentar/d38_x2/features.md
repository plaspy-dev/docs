# Sentar - D38-X2 Features

This page provides a public feature overview for the Sentar D38-X2 smart watch and how its capabilities are used with Plaspy. It summarizes the device functions relevant to caregivers and administrators when the D38-X2 is integrated into Plaspy for location monitoring, device status reporting, and basic event visibility.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and the manufacturer implementation. For device specific details, setup instructions, and the latest firmware behavior consult Sentar documentation and release notes.

## Feature Overview

The D38-X2 is a child-focused smart watch designed to balance real-time location awareness with everyday communication. When paired with Plaspy the watch becomes a monitored endpoint that streams location and status information into a single dashboard for easier oversight.

- Real-time location using GPS and A GPS with LBS and Wi‑Fi assistance for improved positioning in different environments
- Two-way voice calling and support for messaging apps such as WhatsApp for direct communication between caregivers and the child
- Standalone smart device running Android 8.1 with 1GB RAM and 8GB storage to run compatible apps and store local data
- Child-friendly physical design with a removable watch case and interchangeable faces for comfort and personalization
- Parental controls and basic device management features to simplify configuration and supervision via the platform

## Core Features of Sentar - D38-X2

- GPS and A GPS positioning supplemented by LBS and Wi‑Fi positioning to provide practical location fixes
- Two-way voice calling for direct verbal contact between caregiver and wearer
- Support for Android messaging apps including WhatsApp to enable text and multimedia communication where supported
- Android 8.1 based standalone operation with 1GB RAM and 8GB internal storage for local app use and data retention
- Removable watch case and child oriented design for comfortable daily wear and simple customization
- Built-in parental control functions for monitoring and configuring core device behavior
- Compatibility with Plaspy for centralized monitoring and alerts

## How These Features Work with Plaspy

When the D38-X2 is configured to report to Plaspy it sends location and status data into the platform so caregivers can monitor activity from the Plaspy dashboard. Plaspy is designed to ingest standard tracker outputs and surface them as live location points, status indicators, and configurable alerts.

- Live location fixes and assisted positioning data appear in Plaspy for near real time tracking and history
- Communication events such as call presence and messaging availability are reflected as device status updates
- Device health and connectivity state feed into the platform so you can see when a device is online or needs attention
- Centralized alerts can be configured for check ins, out of zone events, and other monitorable conditions
- Plaspy automatically detects common tracker protocols and accepts device data into the platform server endpoint d.plaspy.com using the platform port, simplifying initial setup

## Typical Use Cases

- Family monitoring for daily check ins and caregiver coordination
- School routines where parents want a simple way to confirm presence and stay in contact
- Outdoor play and short trips where dependable location and calling are useful
- Quick messaging and voice access for routine communication between child and caregiver
- Managing device configuration and monitoring multiple devices from a single Plaspy dashboard
