# Sentar - L80 Features

This page describes the public feature context for using the Sentar L80 3G Kids GPS Watch with Plaspy. It summarizes the L80's user-facing capabilities and explains how those capabilities are typically reflected inside Plaspy for location visibility and event monitoring.

Exact availability and behavior of features described on this page can vary by firmware version, hardware revision, installation type, regional variant, and manufacturer implementation. Consult the official Sentar documentation for device specific technical details and the most current information.

## Feature Overview

The Sentar L80 is a wearable 3G GPS watch designed for child safety with multiple location modes and basic safety functions. When used with Plaspy, the L80 provides location reporting and event visibility that helps caregivers track and respond to situations in real time.

- Multiple location modes supported including GPS, AGPS, LBS, and WiFi for flexible location acquisition
- 3G cellular connectivity for live location reporting and remote presence
- Built-in microphone and speaker enabling two-way voice communication on the device
- Dedicated SOS button to signal an emergency condition
- Geo-fence functionality to define safe zones and receive zone-related notifications

## Core Features of Sentar - L80

- 3G cellular connectivity for real-time reporting and communication
- Support for GPS and AGPS location fixes
- LBS and WiFi assisted location modes for improved coverage in urban or indoor environments
- SOS button for user-initiated emergency alerts
- Two-way voice capability via the built-in microphone and speaker
- Geo-fence support to configure safe zones and trigger zone events
- Compact watch form factor and adjustable strap designed for children

## How These Features Work with Plaspy

Plaspy receives location and event data from compatible trackers and presents that information in a unified interface for monitoring and oversight. For the L80, Plaspy can surface location updates and reported events so operators and caregivers can make timely decisions.

- Real-time location displayed on the Plaspy map when the device reports position updates
- Event visibility for reported SOS presses and configured geo-fence entries or exits when the device sends those events
- Historical position data and recent movement history for review and timeline analysis in Plaspy
- Device online status and recent reporting indicators to confirm connectivity
- Alerts and notifications in Plaspy based on incoming events from the L80, subject to what the device reports

## Typical Use Cases

- Child safety monitoring and parental location checking
- Tracking school commutes and after school activity locations
- Rapid visibility for emergency situations via SOS reporting
- Geofenced zone supervision for home, school, and play areas
- Short-term check-ins for caregivers and family members

## Feature Availability Notes

- Feature availability and behavior depend on the device firmware version and hardware revision installed by the manufacturer
- Regional cellular configurations and SIM plan requirements can affect real-time reporting and voice functionality
- Some functions require proper device provisioning and settings on the watch itself before Plaspy will receive corresponding events
- Manufacturer customizations or third party integrations may alter how certain events are reported
- Always verify the exact feature set on the unit you received and compare against manufacturer release notes

## Why Use Plaspy with These Features

Using the Sentar L80 with Plaspy gives organizations and caregivers a centralized way to view location information, receive event alerts, and check reporting history across devices. Plaspy is designed to present device-sourced location and event data in a way that supports situational awareness and operational oversight without replacing the device's native communications.
