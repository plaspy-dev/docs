# Sentar - Q50 Features

This page describes the public feature context for using the Sentar Q50 with Plaspy. It focuses on the practical capabilities that the Q50 provides as a kids GPS watch and how those capabilities map to visibility and monitoring inside Plaspy. Content here is intended for general planning, purchasing, and integration awareness.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, SIM and network configuration, and how the device is installed and configured by the manufacturer or installer. For device-level configuration details and the most current specifications refer to the manufacturer documentation.

## Feature Overview

The Sentar Q50 is a wrist worn GPS device designed for child location and simple communication. It combines multiple positioning methods and a set of user-facing features that aim to provide reliable location information and basic remote interaction.

- Real time location tracking using GPS, AGPS, and LBS for position awareness in different environments
- Two way voice communication and voice messaging for direct contact between caregiver and wearer
- Geo fencing to define safe zones and receive notifications when the device reports entry or exit events
- Dedicated SOS button for emergency signaling to caregivers or monitoring systems
- Remote monitoring capability to listen to the device surroundings for situational awareness
- Water resistant design and extended battery life for everyday use and durability

## Core Features of Sentar - Q50

- Multi mode positioning combining GPS, AGPS, and LBS for improved location availability
- Real time location reporting for live tracking and situational awareness
- Two way voice calls and voice messages for direct communication with the wearer
- Geo fencing support to create and monitor safe zones
- SOS emergency notification via a dedicated button
- Remote audio monitoring to hear environmental audio as allowed by the device
- User friendly watch interface suitable for children
- Compact range of color options to suit personal preference

## How These Features Work with Plaspy

Plaspy provides a centralized platform to receive and display the events and location reports that compatible trackers, like the Sentar Q50, send. When the device reports position or status, Plaspy surfaces that information in maps, timelines, and event lists so teams and caregivers can stay informed.

- Live location points and recent track history appear in Plaspy maps for route review and situational context
- Reported geofence entry and exit events can be shown as alerts when the device supports sending those events
- SOS button events are presented as high priority events so responders can identify time and location quickly
- Status and connectivity indications from the device help indicate whether the tracker is reporting normally
- Plaspy automatically detects many tracker protocols for compatible devices making initial integration simpler
- Two way voice and remote monitoring capabilities remain device managed, while Plaspy records related event notifications if the device transmits them

## Typical Use Cases

- Parental monitoring of a child during school commutes, playtime, or outings
- Caregiver oversight for children in shared custody or group care situations
- Quick emergency response using SOS alerts to locate the device wearer
- Verifying arrival and departure from predefined safe zones such as school or home
- Remote check in and voice contact between caregiver and child when needed
- Monitoring device reporting status for routine safety checks

## Feature Availability Notes

- Firmware releases can add, change, or refine how features work; check current firmware notes for details
- Hardware revisions or regional variants may change supported networks or available feature sets
- Some features require an active cellular service plan and proper SIM configuration to report to cloud services

Using Plaspy with the Sentar Q50 brings device location and event reporting into a single operational view so caregivers and teams can monitor status, review recent movement, and respond to alerts efficiently. Plaspy is designed to present location points, event timelines, and notification history in a way that supports everyday oversight without replacing device level controls.
