# Sentar - L70S Features

This page provides a public feature overview of the Sentar L70S and how its capabilities map to monitoring and visibility inside Plaspy. It is written to help fleet and device managers, parents, and integrators understand the practical functions of the L70S when used with Plaspy, and what to expect from the device at a feature level.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. The L70S description used here highlights the model as a kids GPS tracker watch with an MTK2503 chipset and multiple location modes including GPS, AGPS, LBS, and WiFi, which inform the tracker functionality you will see in Plaspy.

## Feature Overview

The Sentar L70S is positioned as a wearable tracker for children with multiple location technologies to improve positioning in diverse environments. When paired with Plaspy, the tracker can provide continuous location visibility and historical position data that help caregivers monitor movement and general whereabouts.

- Multiple location modes combining GPS, AGPS, LBS, and WiFi to improve position accuracy across indoor and outdoor environments
- Real time and near real time location reporting suitable for continuous monitoring in Plaspy
- Built on an MTK2503 chipset, offering reliable location processing and connectivity performance for its class
- Form factor and styling aimed at children with color options including blue, pink, black, and white for user preference
- Compatible with Plaspy for visibility and centralized device monitoring

## Core Features of Sentar - L70S

- MTK2503 chipset for core tracking and processing performance as described by the manufacturer
- GPS location mode for outdoor satellite positioning
- AGPS mode to assist faster position fixes using network assistance
- LBS location mode to provide network cell based positioning where satellite signals are limited
- WiFi assisted positioning to improve location estimates indoors or in dense urban areas
- Wearable watch form factor designed for child use and everyday wear
- Compatibility with Plaspy for integration into a centralized tracking and monitoring platform

## How These Features Work with Plaspy

Plaspy ingests location updates and displays them on maps and timelines so you can monitor movement and review recent positions. Plaspy automatically detects many common tracker protocols, enabling easier onboarding of devices such as the L70S.

- Location updates from the L70S appear on Plaspy maps to show current position and recent track history
- Mixed mode positioning (GPS AGPS LBS WiFi) improves how the device reports locations that Plaspy can visualize
- Plaspy automatically detects the tracker protocol to simplify connection and reduce manual configuration
- The L70S can be configured to report into Plaspy servers so position and connectivity are centralized for monitoring
- Device status and recent communications are visible in Plaspy to help assess device reachability and reporting cadence

Note: Plaspy commonly receives device data using its public ingestion endpoint d.plaspy.com and supports common transport methods used by trackers. Plaspy uses a consistent ingestion port and will detect the tracker protocol automatically.

## Typical Use Cases

- Parental monitoring to track a child’s location during daily routines and travel to and from school
- Keeping visibility on children during outdoor activities where mixed mode positioning improves coverage
- Centralized monitoring for organizations that distribute wearable trackers to minors or staff
- Quick location checks and history review to confirm recent movements and general whereabouts
- Preference based device selection by color for family or program identification
