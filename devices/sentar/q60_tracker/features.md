# Sentar - Q60 Tracker Features

This page provides a public overview of the Sentar Q60 Tracker and how its feature set relates to use with the Plaspy platform. It focuses on practical, non-sensitive capabilities you can expect when integrating the Q60 with Plaspy for location monitoring, mapping, alerts, and history reporting.

Exact feature availability and behavior can vary depending on installed firmware, hardware revision, regional model variants, and installation or configuration choices. For device specific operational details consult the manufacturer documentation when needed.

## Feature Overview

The Sentar Q60 is a compact GPS tracker designed for personal and small asset location monitoring with built in hybrid positioning and GSM connectivity. It is presented as a Plaspy compatible device that streams location and basic telemetry to the Plaspy platform for real time visibility and historical reporting.

- Hybrid positioning using GPS and BDS plus network fallbacks LBS and WiFi to maintain location updates in varied signal conditions.
- Compact form factor suited to on person carry or attachment to small movable assets.
- GSM GPRS connectivity across quad band frequencies for widespread mobile network support.
- Built in battery and modest memory designed for extended standby use and simple operation.
- Out of the box compatibility with Plaspy for mapping, alerts, and travel history collection.

## Core Features of Sentar - Q60 Tracker

- Multi mode positioning: GPS and BDS plus LBS and WiFi positioning for reliable location fixes.
- Plaspy compatibility: streams location and basic telemetry into the Plaspy platform for real time tracking.
- MTK2503 chipset as the supplied GNSS engine noted in manufacturer materials.
- GSM GPRS quad band support for mobile data connectivity across common cellular bands.
- Built in rechargeable lithium polymer battery sized for extended standby operation.
- Nano SIM slot for cellular connectivity and simple installation.
- Modest onboard memory footprint for device operation and configuration storage.
- Compact personal/asset tracker form factor for discreet placement.

## How These Features Work with Plaspy

When connected to Plaspy the Q60 sends position reports and status data that Plaspy uses to display location on maps, produce histories, and generate alerts. Plaspy ingests the Q60 hybrid positioning so users retain visibility when the unit uses satellite or network based fixes.

- Real time location updates visible on Plaspy maps and device lists.
- Fallback positioning from LBS and WiFi is reflected in Plaspy so you can see when fixes rely on non GNSS sources.
- Alerts and geofence events configured in Plaspy can use incoming Q60 reports to trigger notifications.
- Travel history and exportable reports capture the Q60 location timeline for review in Plaspy.
- Basic device status such as power or session indicators reported by the Q60 can be surfaced as notifications in Plaspy.
