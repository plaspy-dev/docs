# Sentar - V80 Features

This page covers the public feature context for using the Sentar V80 tracker with Plaspy. It summarizes the practical functions you can expect to use when the V80 is connected to Plaspy, and how those device-reported events and location updates are typically surfaced inside the platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and how the device is installed or set up. Where relevant, this page highlights general capabilities while recommending you verify device specifics against manufacturer documentation and firmware notes.

## Feature Overview

The Sentar V80 is a child-focused GPS watch that combines multiple location methods and user safety features to help caregivers maintain location awareness. When connected to Plaspy, the tracker provides location data and event signals that Plaspy can use for monitoring and alerts.

- Multi mode positioning using GPS, AGPS, LBS, and WiFi to improve location reliability in different environments
- Real time location tracking suitable for continuous visibility and periodic updates
- Built in SOS button to send emergency alerts with location information to predefined contacts
- Two way communication allowing voice calls and voice messages between caregiver and device
- Geo fence support to set virtual boundaries and receive notifications on entry or exit
- Compact, kid friendly design available in blue, pink, and orange

## Core Features of Sentar - V80

- Multi mode location: GPS, AGPS, LBS, and WiFi combined for broader location coverage
- Real time tracking: Designed to provide timely position updates for monitoring
- SOS alert button: Sends an emergency notification with location when activated
- Two way voice communication: Allows calls and voice messages between caregiver and device
- Geo fence capability: Supports virtual perimeter rules and corresponding alerts
- Kid oriented design: Compact watch form factor and multiple color options for children
- MTK2503 chipset mentioned in manufacturer material as the positioning engine for this model

## How These Features Work with Plaspy

Plaspy receives location and event data from compatible trackers like the Sentar V80 and presents those items in maps, alerts, and device timelines. Plaspy can automatically detect the tracker protocol and ingest the device reports so you can monitor status without manual protocol selection.

- Location updates from the V80 appear on the Plaspy map and in device position history
- Geo fence events reported by the device become notifications or alerts within Plaspy
- SOS activations are surfaced as high priority events so teams can respond or review the location at the time of alert
- Device identity and reported status are available in Plaspy device details for operational oversight
- Plaspy treats voice call and voice message events as device-reported communication events when those signals are available from the tracker
- Plaspy automatically detects supported tracker protocols to simplify initial setup and data ingestion

## Typical Use Cases

- Real time parental monitoring of a child’s location during daily activities
- Receiving immediate SOS notifications and location when a child needs assistance
- Notifying caregivers when a child arrives at or leaves a defined safe zone using geofences
- Using two way voice to check in with a child without revealing exact device configuration steps
- Maintaining a location history to review routes or movement during a day
- Equipping daycare or school programs with visibility to devices assigned to children
