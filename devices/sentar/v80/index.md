# Sentar - V80

![V80](./logo.jpg)

The Sentar V80 is a compact GPS watch designed for children. Marketed as the V80-1.22 Niños Reloj GPS, the device combines a child friendly design available in blue, pink, and orange with location technologies intended to provide parents with regular position updates. The product description highlights an MTK2503 chipset and multiple location modes including GPS, AGPS, LBS, and WiFi, plus safety features such as an SOS button, two way communication, and geo fence alerts.

As a Plaspy compatible device, the V80 can be used alongside Plaspy to centralize location visibility and safety notifications for caregivers or small fleet administrators responsible for child transport or group activities. Plaspy can collect and display the device location and event information so families and managers have a unified view of movement, geofence events, and emergency alerts in a single monitoring environment.

## Key Highlights

- Purpose built as a children's GPS watch with a compact and colorful design that appeals to kids.
- Multiple positioning modes named in the product description to improve location reliability in varied environments.
- Built in SOS button for sending an emergency alert to predefined contacts.
- Two way communication capability to allow voice contact between caregiver and wearer.
- Geo fence support to notify when the device enters or exits defined areas.
- Based on an MTK2503 chipset, indicating the device uses established positioning hardware.

## How It Works with Plaspy

The V80 can feed position updates and event information into Plaspy so a single platform shows current location, recent movement, and safety events. Plaspy users can then monitor children or small groups alongside other tracked assets and set up notifications and reports.

- Live location monitoring and location history visible in Plaspy dashboards.
- Geofence event notifications relayed to Plaspy for boundary alerts and operational oversight.
- SOS alerts routed into Plaspy so supervisors or family members can receive timely notifications.
- Two way communication events can be logged or referenced from Plaspy for situational context.
- Reporting and exportable event logs to support routine checks and record keeping.
