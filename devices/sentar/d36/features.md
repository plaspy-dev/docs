# Sentar - D36 Features

This page covers the public feature context for using the Sentar D36 with Plaspy. It summarizes the device capabilities that are relevant when pairing the D36 kids smart watch with the Plaspy platform for location awareness, activity monitoring, and basic device status reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. Where functionality is not explicitly documented by the manufacturer you should treat descriptions here as general guidance and consult the official manufacturer manual for device specific details.

## Feature Overview

The Sentar D36 is a purpose built 4G kids smart watch that combines GNSS assisted positioning with network and WiFi assisted fixes and cellular voice capability. When used with Plaspy the D36 provides parents and administrators visibility into real time location, basic device status, and direct voice communication using the device cellular link.

- Real time location reporting using GPS combined with LBS and WiFi assisted positioning for improved indoor and urban coverage
- Two way voice communication over the watch cellular connection for direct parent child calls
- Compact wearable design with durable ABS and PC housing and a child friendly silicone strap for daily use
- Color touchscreen for straightforward device interaction and quick status checks
- Multi band cellular support and a Nano SIM slot to operate on common regional networks
- RTOS based firmware and modest memory footprint for stable daily operation

## Core Features of Sentar - D36

- GPS location reporting supplemented by LBS and WiFi positioning for improved fix success in challenging environments
- 4G WCDMA GSM cellular connectivity and Nano SIM support for data and voice communication
- Two way voice capability enabling direct calls between caregiver and wearer via the device cellular link
- 1.28 inch IPS touchscreen that provides on device status and basic interaction
- Child oriented mechanical design with ABS plus PC housing and soft silicone strap
- RTOS based system software for steady operational behavior
- Built in battery power management designed for typical day use as described by the manufacturer
- Multi band support to enable broader regional compatibility where listed cellular bands are available

## How These Features Work with Plaspy

When configured to report to Plaspy the D36 sends location and status updates over the cellular network for ingestion by the platform. Plaspy uses that incoming telemetry to present live maps, location history, and configurable notifications so caregivers can maintain situational awareness.

- Live map view and history playback based on reported GPS LBS and WiFi assisted locations
- Device status and battery level visibility in Plaspy to help plan recharging and maintenance
- Geofencing and location alerts managed in Plaspy to notify caregivers when a wearer enters or leaves predefined areas
- Voice communication remains routed through the device cellular link while Plaspy provides location and status context alongside call events
- Plaspy detects common tracker protocols automatically and displays incoming telemetry for monitoring and reporting

## Typical Use Cases

- Parent to child location monitoring during school runs, playtime, and commutes
- Direct parent child voice calls without requiring the child to carry a smartphone
- Managing daily check ins and simple situational awareness for caregivers and guardians
- Travel use where multi band cellular coverage enables regional operation within supported bands
- Day care or supervised group environments for location visibility and status checks
- Quick confirmation of device connectivity and battery state before handoffs to caregivers
