# Sentar - Q60 Pet Features

This page describes the public feature context for using the Sentar Q60 Pet with the Plaspy platform. It outlines the tracker capabilities that are relevant for pet owners and operators who want continuous, Plaspy compatible real time tracking and fast location visibility.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and how the manufacturer configures the device. Use this page for general guidance and consult the device maker for the most current, model specific details.

## Feature Overview

The Q60 Pet is a compact pet tracker designed to provide reliable location and basic telemetry to Plaspy using multi mode positioning and GSM GPRS connectivity. It blends GPS and BDS satellite fixes with LBS and WiFi assisted location to improve visibility in urban and indoor environments while delivering battery status and position updates into Plaspy for monitoring and alerts.

- Real time position reporting into Plaspy for live tracking of pets
- Multi mode positioning that mixes GPS, BDS, LBS and WiFi assisted fixes for better coverage
- Micro SIM GSM GPRS connectivity for broad cellular data uplink
- Compact collar friendly design and integrated battery for everyday wear
- Battery level telemetry and standby estimates visible through Plaspy

## Core Features of Sentar - Q60 Pet

- Plaspy compatible tracker that sends position and basic telemetry to the Plaspy platform
- MTK2503 based design enabling multi mode positioning
- Satellite positioning with GPS and BDS for outdoor accuracy
- LBS and WiFi assisted positioning to improve coverage where satellite signals are weak
- GSM GPRS connectivity using a Micro SIM card and quad band support
- Built in 500 mAh polymer battery with standby performance suitable for pet use
- Typical outdoor GPS accuracy in the range of approximately 5 to 15 meters
- Fallback LBS accuracy range that can be roughly 100 to 1000 meters depending on cell coverage

## How These Features Work with Plaspy

When the Q60 Pet is active, it transmits location fixes and battery telemetry over the cellular network and Plaspy receives those updates for display and alerting. Plaspy automatically detects compatible tracker protocols and maps the incoming position and status updates into the platform so you can view movement, set safe zones, and monitor device health.

- Live position updates appear on Plaspy maps and timelines for immediate visibility
- Multiple positioning modes captured in reports provide combined indoor and outdoor coverage
- Battery level and standby information are shown in Plaspy to help schedule recharges
- Safe zones and alerting in Plaspy can notify users when a tracked pet crosses defined boundaries
- Compact telemetry payloads from the device are presented as location and status events in Plaspy

## Typical Use Cases

- Real time pet safety and recovery when a dog or cat wanders off
- Improved indoor visibility for pets using WiFi assisted and LBS positioning
- Day trip and outing monitoring where a lightweight tracker is preferred
- Household management of multiple pets with centralized visibility in Plaspy
- Routine monitoring of movement patterns and battery status for responsible ownership
