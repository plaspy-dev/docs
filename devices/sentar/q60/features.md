# Sentar - Q60 Features

This page covers the public feature context for using the Sentar Q60 tracker with Plaspy. It summarizes the Q60 capabilities described by the manufacturer and explains how those capabilities map to visibility and monitoring inside the Plaspy platform. This is intended as a features-oriented reference for users researching the device and its practical use with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where details depend on firmware or configuration, this page calls out the practical implications and encourages checking manufacturer resources for the most current device specifics.

## Feature Overview

The Sentar Q60 is positioned as a compact, reliable GPS tracker with multiple positioning modes and a focus on accurate location reporting. Its design and location modes make it suited to vehicle and asset tracking scenarios where discreet installation and consistent positioning are important.

- GPS plus AGPS and LBS location modes for improved position reliability in varied signal conditions
- MTK2503 chipset noted for fast and efficient location processing and time to fix
- Real time location reporting suitable for live monitoring and tracking workflows
- Compact, discreet enclosure available in black, white, and blue for flexible installation
- Designed to integrate with tracking platforms such as Plaspy for centralized monitoring

## Core Features of Sentar - Q60

- GPS AGPS LBS hybrid positioning to provide location when GPS alone is not available
- MTK2503 chipset for quicker position fixes and efficient operation
- Real time position updates suitable for live tracking and historical playback
- Compatibility with third party tracking servers and platforms such as Plaspy
- Compact form factor and multiple color options for discreet installs
- Practical for vehicle or portable asset tracking where accurate location is required

## How These Features Work with Plaspy

When integrated with Plaspy, the Q60's location reports become visible within a central tracking dashboard so operators can monitor position and movement. Plaspy automatically detects supported tracker protocols, simplifying setup for many devices.

- Location uploads from the Q60 are displayed as current position and as a historical breadcrumb trail in Plaspy
- Plaspy shows position timestamps and mapping context to support operational decisions and route review
- Plaspy can accept reports from devices configured to connect to the Plaspy server domain using common transport options such as UDP or TCP, and it auto detects protocol settings
- Device identity and reporting status are reflected in Plaspy to help administrators confirm online status and recent activity
- Using Plaspy centralizes device monitoring so teams can manage multiple Q60 units from a single interface

## Feature Availability Notes

- Firmware variations can change how aggressively AGPS or LBS are used and how the device reports location
- Hardware revisions and regional variants may affect radio performance or available configuration options
- Installation orientation and local RF environment will influence GPS accuracy and LBS fallback results
- Confirm server and protocol settings when connecting a device to Plaspy as some trackers require configuration of the server address and transport
- Consult manufacturer documentation for model specific configuration steps and the latest feature list
