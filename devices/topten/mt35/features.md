# TopTen - MT35 Features

This page provides a public overview of the TopTen MT35 tracker feature set and how those capabilities are used with the Plaspy platform. It focuses on user-facing functions, practical value, and how Plaspy can display and manage the device's information without reproducing internal or sensitive configuration details.

Exact feature availability for any MT35 unit can vary by firmware version, hardware revision, fitted optional modules, and how the device was installed. For critical or configuration-specific questions, consult the manufacturer documentation or your device supplier to confirm which functions are present on your unit.

## Feature Overview

The TopTen MT35 is a multi-band 2G/3G GPS tracker designed for vehicle use and built to work with fleet and tracking platforms such as Plaspy. It offers live location reporting, a substantial onboard data logger for route history, several vehicle alarm conditions, and optional voice or SOS capabilities depending on the installed options.

- Multi-network cellular support across common 3G and 2G bands for broad regional compatibility
- Real-time location reporting via SMS, web interface, or a dedicated mobile app
- Built-in data logger that stores up to 5520 waypoints for playback and historical review
- Multiple alarm types including over-speed, movement, engine-on, vibration, and power failure
- Compact waterproof housing suitable for cars, motorcycles, and larger vehicles

## Core Features of TopTen - MT35

- 3G WCDMA and 2G network compatibility with wide band support for regional coverage
- Live location queries and automatic reporting available by SMS, web, or mobile app
- Onboard data logger capable of storing up to 5520 waypoints for route history
- Odometer function to help track distance and vehicle usage over time
- Over-speed alarm and movement alarm to detect and report unusual driving or motion
- Engine on alarm, vibration alarm, and power failure alarm for vehicle state monitoring
- Optional SOS alarm and voice monitoring for enhanced safety and verification
- Optional RFID and wireless immobilizer support for access control and immobilization workflows

## How These Features Work with Plaspy

Plaspy can ingest and present the MT35's location, history, and alarm events so operators and managers can monitor vehicles and review activity. Plaspy's platform automatically detects compatible tracker protocols and displays device reports in a consistent interface for visibility and operational oversight.

- Real-time location updates appear on Plaspy maps for live tracking and address-level context
- Stored waypoints can be shown as historical tracks for trip reconstruction and route analysis
- Alarm events (over-speed, movement, engine on, vibration, power loss) surface as alerts in Plaspy to support rapid response
- Device configuration and command workflows available through Plaspy are aligned with the MT35's supported command methods such as SMS or server reporting
- Optional features like SOS and voice monitoring can be noted in Plaspy as supported by an individual device when enabled

## Typical Use Cases

- Fleet location tracking and route history review for small and medium vehicle fleets
- Personal vehicle monitoring including motorcycles and cars where compact waterproof units are needed
- Delivery and logistics operations that require stored waypoint playback for proof of route
- Security and theft detection using movement, vibration, and power failure alerts
- Driver behavior monitoring via over-speed alerts to support safety programs
- Remote verification and assistance when SOS or voice monitoring is enabled

## Feature Availability Notes

- Some features such as SOS, voice monitoring, RFID, and wireless immobilizer are optional and depend on the specific hardware variant or factory options
- Firmware version and hardware revision can affect which alarms and functions are available or how they behave
- Installation type and wiring (for example, power and engine signal connections) influence engine on and power failure alarms
- Regional cellular band availability may affect network compatibility; confirm local 2G/3G support with your carrier and device variant
- Always check the device's shipped documentation and the manufacturer website for the latest feature lists and configuration notes
