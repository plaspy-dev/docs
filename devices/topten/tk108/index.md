# TopTen - TK108

![TK108](./Logo.jpg)

The TopTen TK108 is a vehicle GPS tracker that combines location reporting with basic alarm and monitoring features. It supports SMS and phone call based arm and disarm commands, provides engine on and off alerts, reports power failure events, and includes an SOS alarm. The unit also accepts an analog input for fuel monitoring and includes an 8Mb data logger to store waypoints when the device is offline. Designed for a wide operating voltage range and built to industrial quality standards, the TK108 is suited to a variety of vehicle types.

As a tracker compatible with Plaspy, the TK108 can feed its location, alarm events, and logged history into a centralized fleet platform for visibility and operational oversight. Plaspy can receive and present alerts such as SOS triggers, engine status changes, and power loss notifications, and it can use stored waypoints from the device to reconstruct routes once a connection is reestablished. This makes the TK108 a practical option for organizations that need both security features and basic fleet monitoring on Plaspy.

## Key Highlights

- GPS location reporting combined with alarm functions for vehicle security
- Arm and disarm control using SMS or phone call commands for simple remote operation
- Alerts for engine on off events and power failure that support timely notifications
- SOS alarm function to escalate critical safety events
- Analog input support for fuel monitoring to track consumption or detect anomalies
- 8Mb onboard data logger retains waypoints during offline periods for later upload
- Wide working voltage range and industrial design with CE and FCC certification

## How It Works with Plaspy

When integrated with Plaspy, the TK108 becomes a source of position data and event notifications that the platform can use for monitoring, reporting, and alerting. Plaspy normalizes incoming messages from compatible trackers and presents them in dashboards and reports for fleet managers.

- Real time and near real time location visibility of vehicles on Plaspy maps
- Delivery of alarm events such as SOS triggers engine status changes and power loss into Plaspy alerting workflows
- Upload and reconciliation of stored waypoints from the TK108 so historical routes are available in Plaspy reporting
- Mapping of analog input data for fuel monitoring into Plaspy for consumption tracking and anomaly detection
- Configuration of notification rules and scheduled reports based on TK108 events and movement

## Typical Use Cases

- Vehicle security monitoring with remote arming disarming and SOS notifications
- Fleet fuel oversight using analog input to support consumption monitoring and audits
- Route reconstruction and incident review using the device data logger when coverage is intermittent
- Monitoring mixed fleets including cars buses and heavy trucks thanks to wide voltage support
- Basic operational oversight for small to mid sized fleets needing location and alarm integration
