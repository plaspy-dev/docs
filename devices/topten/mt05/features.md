# TopTen - MT05 Features

This page describes the public feature context for using the TopTen MT05 tracker with Plaspy. It focuses on practical, user-facing capabilities and explains how the device reports location, alarms, and status into Plaspy so fleet managers and vehicle owners can understand what to expect from integration.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For current, device specific technical details consult the manufacturer documentation while using this page to understand how MT05 features typically appear in Plaspy.

## Feature Overview

The MT05 is a compact vehicle tracker that combines location reporting, alarm functions, and basic vehicle status detection with a design intended for automotive environments. It is designed to report location via SMS, web, or app and to provide multiple alarm conditions and basic safety actions.

- Track location using SMS, web, or mobile app reporting for flexible monitoring options
- Car alarm and arm/disarm control available by SMS web or phone call to manage vehicle security
- Real physical address reporting including city and street name for clear, human readable location context
- Smart engine ON/OFF status detection to identify vehicle running state
- Multiple alarm types such as over speed movement vibration engine on and power failure to highlight events
- Odometer function plus compact waterproof design suitable for vehicles across a wide voltage range

## Core Features of TopTen - MT05

- Multiple reporting channels supported including SMS web and app tracking
- Vehicle alarm features with the ability to arm and disarm remotely via SMS web or phone call
- Real physical address resolution providing city and street level information
- Smart engine ON and OFF status detection for basic running state monitoring
- Safety capability to safely stop the car when speed is less than or equal to 30Km/h
- Alarm suite including over speed movement engine on vibration and power failure alarms
- Odometer function to track distance traveled
- Robust hardware design with waterproof casing and a hardware watchdog for reliability

## How These Features Work with Plaspy

Plaspy receives location and event messages from the MT05 and maps them to vehicle markers and events on the platform. When enabled and properly configured, Plaspy displays address information, status changes, and alarms in the device timeline and on the map so operators can act on events quickly.

- Location reports become map positions and can display the resolved physical address in Plaspy
- Alarm events such as over speed movement vibration engine on and power failure are logged as events and can trigger notifications
- Engine ON and OFF status are shown as device state changes to help identify when a vehicle is running
- Odometer readings reported by the device are available as distance information for operational reporting
- Remote arm and disarm actions available via the device can be coordinated with Plaspy workflows depending on account configuration
- Plaspy accepts device connections and automatically detects compatible tracker protocols to simplify setup; devices may be configured to report into d.plaspy.com

## Typical Use Cases

- Fleet location monitoring and route oversight for small to medium vehicle fleets
- Theft detection and recovery support using address reporting and multiple alarm types
- Vehicle status monitoring to see engine on and off events for usage tracking
- Distance tracking for maintenance scheduling using odometer readings
- Security management for parked vehicles using vibration movement and power failure alarms
- Coverage across motorcycles cars and larger trucks thanks to a wide input voltage range

## Feature Availability Notes

- Some features depend on the device firmware version and may vary between firmware releases
- Hardware revisions and installation wiring can affect which alarms and safety functions are available
- Regional model variants and local regulations can influence supported features and reporting methods
- Manufacturer settings such as SMS or data reporting preferences will change how the MT05 interacts with platforms
- Always verify which functions are enabled on a specific device before relying on critical operational behaviors

Using the MT05 with Plaspy gives organizations a way to centralize location and event information for operational decision making. Plaspy presents location, resolved addresses, alarm events, and basic device state in a unified interface so managers can monitor assets and respond to incidents with context.
