# TopTen - GT08 Features

This page summarizes the public feature context for using the TopTen GT08 tracker with Plaspy. It focuses on what the GT08 offers and how those capabilities can be used inside Plaspy for vehicle monitoring, location awareness, and operational oversight rather than providing device setup instructions.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, optional accessories, and manufacturer implementation choices. Where features are listed as optional, their presence depends on the specific unit and configuration from the vendor.

## Feature Overview

The TopTen GT08 is a compact 2G/3G vehicle tracker designed to provide continuous location awareness, event alerts, and a set of optional access and voice features. It can be used for basic tracking, perimeter and access control workflows, and event-driven monitoring where configurable alarms and digital inputs are important.

- Multi-channel tracking and reporting to allow monitoring via SMS, web, or app interfacing with a tracking platform
- Personnel identification and access control using RFID and optional Mifare card reader
- Real-time and fallback location reporting using GPS and network based location for areas with limited GPS coverage
- Configurable alarms and event detection including power, vibration, overspeed, crash, and SOS where provided
- Inputs and outputs to connect door, ignition, and analog signals for integration with vehicle systems
- Onboard offline logging to retain location history when network connectivity is interrupted

## Core Features of TopTen - GT08

- Track via SMS, web, or app for remote visibility and basic command interaction
- RFID support for personnel identification and keyless arm or disarm functions
- Real-time address reporting and LBS location fallback in low GPS signal conditions
- Smart detection of engine on/off status and door open/close state via digital inputs
- Voice monitoring and optional two-way talking capability where fitted
- Multiple alarm types available including engine on alarm, power failure alarm, vibration alarm, over-speed alarm, crash alarm, SOS, and fatigue driving alarm as provided by the specific unit
- Offline data logger with capacity for thousands of waypoints to preserve history during disconnection
- Wide input voltage range and power saving design to suit a range of vehicle types

## How These Features Work with Plaspy

Plaspy reads and displays the telemetry and events the GT08 reports so fleet managers and operators can maintain situational awareness and respond to incidents. Plaspy automatically detects common tracker protocols and presents location and event data in the platform UI for monitoring and reporting.

- Live location updates and historical tracks for review in Plaspy maps and reports
- Event mapping for alarms such as power loss, vibration, overspeed, and SOS to trigger notifications or workflows
- Use of digital input states and analog readings to reflect engine status, door open events, and other connected signals inside Plaspy
- Offline logged waypoints uploaded to Plaspy when connectivity resumes to keep trip history complete
- RFID related events and keyless alarm actions can be shown as access or authorization events where the tracker reports them
- Plaspy supports standard network reporting and automatically detects tracker protocol so the GT08 can be integrated without manual protocol selection

## Typical Use Cases

- Fleet location tracking and route history for light vehicles, trucks, and motorcycles
- Vehicle access control and operator identification using RFID tags or cards
- Security monitoring with alerts for power loss, vibration, or unauthorized movement
- Remote engine or ignition status monitoring and door state visibility for logistics operations
- Speed monitoring and intervention workflows using the device speed alarm or limiter features
- Rental and shared vehicle oversight combining location and authorization logs
- Backup location and trip recording where intermittent network coverage exists

## Feature Availability Notes

- Several GT08 capabilities are listed as optional by the manufacturer; actual availability depends on the specific device model and whether optional modules were installed
- Firmware version and hardware revision can change how features behave and which alarm types are supported
- Installation choices and wiring determine which digital and analog inputs are populated and how engine or door status is detected
- Regional cellular network support and regulatory variants can affect connectivity and reporting methods
- Always consult the device seller or manufacturer documentation to confirm which optional functions are present on a particular unit
