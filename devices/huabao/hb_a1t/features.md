# Huabao - HB-A1T Features

This page provides a public feature overview for the Huabao HB A1T GPS tracker and how its capabilities are used with Plaspy for fleet and asset management. It describes the practical, non sensitive functions of the device as they relate to tracking, telemetry, alarms and environmental sensing in Plaspy powered workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional modules and how the device is installed. For final device specifications and the latest technical details consult the manufacturer documentation and product change notices.

## Feature Overview

The HB A1T is a rugged GPS tracker intended for trailers and outdoor assets needing weather resistance, long standby and flexible sensor options. It focuses on reliable position reporting, basic anti theft detection and support for external sensors so operators can maintain asset visibility even in remote deployments.

- Real time GNSS positioning using GPS and BeiDou for location awareness
- 4G cellular connectivity with regional module options for continuous reporting
- IP65 weatherproof enclosure designed for trailers, containers and deck mounting
- Large internal battery with extended standby for long storage or transit periods
- Built in tamper detection and a wired relay output for remote power or immobilizer control
- Bluetooth 5.0 support for external temperature and humidity sensors with an optional LoRa module for wider sensor networks

## Core Features of Huabao - HB-A1T

- Dual GNSS positioning with GPS and BeiDou for improved satellite coverage
- 4G cellular data for real time tracking with regional support for lower generation modules where applicable
- IP65 rated housing to protect against water and dust during outdoor use
- Large internal battery and optional higher capacity battery for extended standby operation
- Hall effect tamper detection for disassembly alerts and anti theft monitoring
- Wired relay output to support remote power cut or immobilizer style actions
- Bluetooth 5.0 for temperature and humidity sensor integration and optional LoRa for alternative sensor networks
- CAN bus plus multiple analog and digital inputs for telemetry and vehicle signal integration

## How These Features Work with Plaspy

When deployed with Plaspy the HB A1T reports location, status and sensor inputs to provide a unified operational view. Plaspy ingests position and telemetry from the device, surfaces alerts, and keeps a historical log for reporting and incident review.

- Real time location updates and historical trip records visible inside Plaspy dashboards
- Tamper alerts and geofence notifications relayed to Plaspy for anti theft workflows
- Battery and low battery reporting to help maintain continuous asset visibility
- Sensor data from Bluetooth peripherals or optional LoRa modules available for environmental monitoring
- Remote relay commands initiated from Plaspy can be used to cut power or trigger other wired actions where supported

## Typical Use Cases

- Trailer fleet management with continuous location monitoring and tamper protection for unhitched trailers
- Container tracking during intermodal transport with long standby capability for storage periods
- Refrigerated cargo monitoring using Bluetooth temperature and humidity sensors
- Maritime and port asset tracking for deck mounted containers and smaller vessels
- Remote telemetry for high value assets that need occasional sensor reads and anti theft measures
- Distributed sensor networks on sites using optional LoRa support for low power coverage

## Feature Availability Notes

- Cellular module and network generation can vary by region and project making mobile connectivity options different between units
- Optional components such as LoRa modules and higher capacity batteries are variant dependent and may not be present on every unit
- Firmware versions affect behavior including reporting intervals, alarm logic and sensor handling
- Installation and wiring determine which inputs and relay functions are available for vehicle or trailer integrations
- Manufacturer hardware revisions may change enclosure details or connector layouts over time
