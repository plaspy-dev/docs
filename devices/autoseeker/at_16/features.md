# Autoseeker - AT-16 Features

This page summarizes the public feature context for the Autoseeker AT-16 GPS tracker and how it integrates with Plaspy. It focuses on the user-facing capabilities that matter for fleet managers, rental operators, taxi services, and vehicle owners when the AT-16 is used with Plaspy for continuous tracking and event reporting.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation type, and the manufacturer's implementation. The AT-16 is a plug-and-play OBD tracker that provides real-time tracking, trip history, and a set of security alerts as described by the manufacturer, but specific functions and menu names may differ across firmware versions and regional variants.

## Feature Overview

The AT-16 is a compact OBD plug GPS tracker designed for fast deployment and basic fleet or vehicle monitoring. When paired with Plaspy it provides live location updates, event-driven alerts, and historical trip data that can be used for oversight, theft deterrence, and operational analysis.

- Plug-and-play OBD-II connection for quick installation without vehicle wiring.
- Real-time GPS tracking and trip history accessible via SMS, web platform, or mobile app.
- Security alerts such as unplug detection, illegal ignition detection, geo-fence notifications, towing and movement alarms, and over-speed reporting.
- Remote voice monitoring capability to assess suspicious events in real time.
- Low power design and wide operating voltage support to suit a range of vehicle electrical systems.
- Compact, discreet form factor suitable for rental fleets, taxis, and corporate vehicles.

## Core Features of Autoseeker - AT-16

- OBD-II plug-and-play installation for fast deployment and minimal downtime.
- Real-time location updates and route logging for trip history and playback.
- Event and alarm reporting including unplug/tamper alerts and unauthorized ignition detection.
- Geo-fence notifications and over-speed reporting for automated alerts and policy enforcement.
- Towing or movement detection to flag potential theft or unauthorized movement.
- Remote voice monitoring to help verify suspicious events when supported by firmware.
- Multiple reporting channels supported by the device such as SMS and integration with a web platform and mobile app.
- Low idle current and wide voltage range to help protect vehicle battery and support diverse vehicle types.

## How These Features Work with Plaspy

Plaspy receives location points and event notifications from the AT-16 so operators can monitor assets from a single interface and act on alerts. Plaspy automatically detects compatible tracker protocols and accepts device reports to surface location, event, and trip information in dashboards and logs.

- Live GPS positions and route history are shown in Plaspy for monitoring and playback.
- Ignition state, unplug events, and movement triggers reported by the AT-16 appear as events in Plaspy for alerting and audit trails.
- Geo-fence entry and exit plus over-speed events can be handled by Plaspy rules and notifications.
- Trip summaries and event logs from the device are synchronized to support reporting and compliance workflows.
- Plaspy accepts device reports over standard transport methods and can be configured to receive AT-16 data on the platform endpoint, with the platform handling protocol detection and routing.

## Typical Use Cases

- Fleet management for mixed vehicle fleets requiring straightforward deployment and centralized tracking.
- Rental vehicle monitoring to validate trip history, detect unplugging, and enforce geo-fencing rules.
- Taxi and ride services that need route playback, over-speed alerts, and operational oversight.
- Anti-theft protection for personal and company vehicles using tamper, ignition, and towing alarms.
- Corporate vehicle oversight for usage reporting and internal audit trails.
- Event based telematics where automated alerts drive follow up actions through Plaspy workflows.
