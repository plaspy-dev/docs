This page provides a public feature overview for the Autoseeker AT-07 and explains how the tracker is used with Plaspy. It focuses on user visible capabilities and practical value, helping operators understand what to expect when adding an AT-07 device into the Plaspy platform.

The Autoseeker AT-07 is described as a compact GPS mini tracker intended for a wide range of tracking tasks. Its primary value is in providing location awareness for assets and people while fitting into situations that require a small, discreet device.

- Real time tracking for continuous location awareness
- Compact and discreet form factor for easy placement
- Versatile usage across vehicles trucks containers and personal monitoring
- User friendly interface for viewing location information
- Long battery life for extended deployment without frequent recharge
- Compatible with Plaspy for platform level monitoring and management

## How These Features Work with Plaspy

When an AT-07 is connected to Plaspy the tracker supplies location updates that Plaspy presents through its maps and device lists. Plaspy is built to detect compatible tracker protocols and integrate device reporting so operators can focus on location and status rather than low level setup.

- Live location updates are displayed on Plaspy maps for immediate situational awareness
- Historical position data and recent update timestamps are available for review
- Devices can be named grouped and organized in Plaspy to match fleets or personnel lists
- Plaspy automatically detects compatible tracker protocol simplifying onboarding
- Status and basic device details are shown in Plaspy alongside location information
