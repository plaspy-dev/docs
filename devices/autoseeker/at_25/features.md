# Autoseeker - AT-25 Features

This page provides a public feature overview for the Autoseeker AT-25 GPS tracker and how those features relate to use with the Plaspy platform. It summarizes the tracker’s practical capabilities such as real time location reporting via SMS or GPRS, 4G internet support, configurable interval reporting, and common alert functions that are relevant to monitoring and fleet operations.

Exact feature availability and behavior can vary by firmware version, hardware revision, local network or SIM configuration, and how the unit is installed. For device specific details and the most current technical information, consult the manufacturer documentation and firmware release notes.

## Feature Overview

The Autoseeker AT-25 is designed to provide continuous vehicle location awareness and a set of condition alerts that support security and fleet oversight. It supports multiple reporting channels and configurable reporting intervals so you can balance update frequency and data usage.

- Real time location reporting via SMS and GPRS TCP with 4G network support for faster connectivity
- Configurable time interval tracking that sends periodic position updates to a tracking platform
- Position reporting via SMS as an alternative when data connectivity is unavailable
- Built in backup battery to maintain reporting if vehicle power is removed
- Multiple alerts including shake alarm, overspeed, geofence, ACC illegal engine on detection, and power off alert
- Ability to view historical location data for route review and event investigation

## Core Features of Autoseeker - AT-25

- Real time tracking over SMS and GPRS TCP reporting methods
- 4G internet support for improved data reliability and faster update delivery
- Time interval based position reporting for scheduled location updates
- SMS position query support for on demand location requests
- ACC illegal engine on detection to notify of unauthorized engine starts
- Built in backup 100 mAh battery to continue operation after power loss
- Remote engine cut off capability when supported by the installed configuration
- Alert types including shake alarm, overspeed alert, geofence alert, and power off alert, plus history tracking

## How These Features Work with Plaspy

Plaspy receives and processes the AT-25’s location reports and alerts so operators can track vehicles, review history, and respond to events from a centralized platform. Plaspy automatically detects many common tracker protocols and presents incoming data in a consistent way for visibility and action.

- Live location shown on Plaspy maps when the device sends SMS or GPRS position updates
- Event and alert notifications for overspeed, geofence, power loss, and ACC related events visible in Plaspy
- History playback and route review using the device’s stored tracking records reported to Plaspy
- Remote command support in Plaspy where the device and installation permit functions such as engine cut off, with actions recorded in the platform
- Configurable reporting frequency and alert thresholds in Plaspy to match the tracker’s interval reporting and alarm settings

## Typical Use Cases

- Fleet location monitoring for scheduling and operational oversight
- Theft detection and recovery workflows using alerts and remote immobilization where supported
- Unauthorized use detection through ACC engine on alerts and geofence breaches
- Route and driver behavior reviews using history tracking and overspeed alerts
- Backup tracking via SMS when data connectivity is limited or interrupted
- Security monitoring for parked vehicles with power off and shake alarms
