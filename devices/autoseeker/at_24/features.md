# Autoseeker - AT-24 Features

This page provides public feature context for the Autoseeker AT-24 and how it works with Plaspy for real-time tracking, fleet oversight, and anti-theft workflows. It is intended to describe the tracker’s practical capabilities when paired with the Plaspy platform and to help fleet managers and installers understand what to expect from everyday use.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional feature set, installation method, and manufacturer configuration. For the most current and device specific technical details consult the official Autoseeker documentation and release notes.

## Feature Overview

The AT-24 is a compact 4G GPS tracker designed for permanent, concealed installation in vehicles and mobile assets. It combines wide input voltage tolerance, persistent telemetry reporting, basic event inputs, and a small backup battery to deliver continuous position and status updates useful for fleet operations and theft response.

- Real-time GPS location reporting over cellular networks for live tracking on Plaspy dashboards.
- ACC ignition detection for ignition-based trip logging and event recording.
- Remote fuel cut (immobilizer) capability to support anti-theft immobilization where permitted.
- Built-in backup battery for continued reporting during main power loss or tampering.
- Geofence and overspeed alerts to help enforce operational rules and generate notifications in Plaspy.

## Core Features of Autoseeker - AT-24

- 4G cellular connectivity with GSM/GPRS and SMS reporting support for wide area coverage.
- Wide operating voltage range suitable for cars, trucks, motorcycles, and marine installations.
- ACC input for ignition state detection and trip/event logic.
- Remote fuel cut (immobilizer) control to enable remote vehicle immobilization when configured.
- Internal backup battery to maintain position reporting during power loss or tamper events.
- Geofencing support and configurable geofence event reporting.
- Overspeed and low-battery alerting to surface safety and maintenance issues.
- Compact covert form factor with modular wiring for fast, discreet installation.

## How These Features Work with Plaspy

When connected, the AT-24 sends position and event data to Plaspy, where telemetry is presented as live location, status changes, and historical records. Plaspy ingests the tracker's reports and converts them into actionable alerts, maps, and audit trails for operational teams.

- Live location updates and history available on Plaspy maps and reports.
- Ignition on/off events feed into trip logs and driver activity records in Plaspy.
- Geofence and overspeed events trigger notifications and create event trails for compliance and review.
- Remote immobilizer (fuel cut) actions can be represented in Plaspy controls and event history where administrative controls and local rules allow.
- Low-battery, power loss, and tamper-related messages are surfaced as alerts to improve response to theft or maintenance issues.

## Typical Use Cases

- Commercial fleet tracking for route supervision, trip auditing, and driver event monitoring.
- Anti-theft protection for private vehicles and commercial assets using covert installation and remote immobilization.
- Motorcycle and small boat tracking where compact size and wide voltage tolerance are required.
- Logistics and delivery operations using geofencing and alerts to improve accountability and routing.
- Long-term vehicle monitoring for maintenance scheduling informed by low-battery and power-loss reports.

## Feature Availability Notes

- Feature support depends on the installed firmware and hardware revision; capabilities may differ between production batches.
- Optional features such as SOS button or voice monitoring require the corresponding hardware configuration and wiring at installation.
- Regional cellular band support and carrier provisioning can affect connectivity and reporting reliability in different countries.
- Immobilizer control and remote commands must be configured and used in accordance with local laws and organizational safety policies.
- Always verify the exact feature set for a specific unit with the manufacturer documentation and any firmware release notes.

## Why Use Plaspy with These Features

Pairing the AT-24 with Plaspy gives organizations centralized visibility into location, ignition events, geofence breaches, and tamper conditions, turning raw telemetry into operational workflows. Plaspy’s alerting, mapping, and reporting tools help teams act on immobilizer events, route deviations, and low-battery warnings more quickly and with a complete audit trail.
