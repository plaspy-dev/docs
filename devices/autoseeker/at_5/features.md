# Autoseeker - AT-5 Features

This page provides a public feature overview for the Autoseeker AT-5 and explains how the device’s capabilities are commonly used when paired with the Plaspy fleet and asset monitoring platform. It is intended to help technical users and decision makers understand the practical functions of the AT-5 and what to expect when using it with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, or installation method. Where relevant, this page highlights the AT-5 features described by the manufacturer; for device specific technical details consult the official Autoseeker documentation.

## Feature Overview

The Autoseeker AT-5 is a wireless magnetic asset tracker designed for vehicle and asset placement where a discreet, durable tracker is needed. It combines multi mode positioning, broad cellular compatibility, a large rechargeable battery, and several alarm functions to support persistent tracking and status awareness.

- Multi mode positioning with GPS and Beidou plus wifi and LBS to improve location reliability in varied environments
- 4G full network compatibility for broad cellular coverage on supported carriers
- Magnetic mounting for quick and secure attachment to metal surfaces
- Multiple onboard alarms and user controls including SOS and tamper alerts for immediate events
- Large rechargeable battery and IP68 rated enclosure for extended deployment and environmental resistance

## Core Features of Autoseeker - AT-5

- 4G full network compatibility to work on supported cellular networks
- Four mode positioning that uses GPS, Beidou, wifi, and LBS for flexible location reporting
- Magnetic housing for attachment to iron plates and noninvasive installation
- Built in rechargeable high capacity battery for long runtime between charges
- IP68 water and dust resistance for outdoor and vehicle use
- SOS button for urgent alerts and user initiated help requests
- Multiple alarm types including demolition or tamper alarm, overspeed alarm, displacement alarm, vibration alarm, and low battery alert
- Two way call capability and vibration feedback for incoming calls

## How These Features Work with Plaspy

Plaspy receives and displays location and status information reported by compatible trackers like the AT-5, making it straightforward to monitor assets and respond to events. Plaspy automatically detects many common tracker protocols and surfaces device status in the platform so teams can take action from the dashboard.

- Location information from the AT-5’s multi mode positioning appears on Plaspy maps for tracking and route review
- Alarm events such as demolition, displacement, overspeed, SOS, and low battery are reported into Plaspy so alerts can be routed to operators
- Battery and connectivity status reported by the device are visible in Plaspy for maintenance planning and device health monitoring
- Two way call capability and vibration notifications support on device interactions while Plaspy provides centralized incident and history logs
- Plaspy shows device activity and recent positions to help with operational decisions and recovery actions

## Typical Use Cases

- Covert or temporary vehicle tracking where a magnetic mount is preferred
- Asset recovery and oversight for trailers, containers, or equipment moved between sites
- Remote location monitoring where multi mode positioning improves coverage
- Safety and response workflows using SOS and tamper alerts to notify operators
- Fleet visibility and loss prevention with event driven alerts and battery monitoring
- Situations requiring a rugged, weather resistant tracker for outdoor use
