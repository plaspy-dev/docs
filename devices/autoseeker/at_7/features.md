# Autoseeker - AT-7 Features

This page provides a public feature overview for the Autoseeker AT-7 and how its capabilities are used with the Plaspy platform. It is intended to describe practical, user facing functionality and operational value when the AT-7 is deployed with Plaspy compatible services.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. For device specific technical limits, configuration options, or the latest firmware behavior consult the official Autoseeker documentation.

## Feature Overview

The AT-7 is a compact card style 4G GPS tracker designed for personal safety, pet monitoring, and lightweight asset tracking. It combines multi constellation positioning, cellular connectivity, on device event detection, and offline data handling to provide continuous location and alert reporting into Plaspy.

- Slim card form factor makes the unit easy to carry or mount on collars and small personal items.
- Multi constellation GNSS and assisted positioning for faster fixes and improved location reliability in mixed environments.
- Cellular 4G with legacy GSM fallback to maintain wide area connectivity for real time updates.
- Geofencing plus SOS and vibration alarms to trigger instant notifications and event uploads to Plaspy.
- Motion detection and offline flash caching so location points are preserved during connectivity gaps and uploaded when service resumes.

## Core Features of Autoseeker - AT-7

- Multi constellation positioning including GPS, BDS, AGPS and cellular assisted location for faster satellite acquisition.
- 4G LTE connectivity with GSM fallback to keep telemetry flowing across diverse cellular networks.
- Geofence support for enter and exit zone alerts.
- SOS alarm and vibration alerts to notify designated recipients and log events on the platform.
- Built in 3 axis accelerometer based motion detection to support activity alerts and power saving behavior.
- Offline flash storage that caches location points during coverage loss and uploads missing data when connectivity returns.
- Remote firmware upgrade support to apply manufacturer updates without physical access to the device.
- IP65 rated enclosure for everyday splash and dust resistance.

## How These Features Work with Plaspy

When paired with Plaspy, the AT-7 reports location fixes and events to the platform so teams and families can monitor devices in near real time and review historical tracks. Plaspy automatically detects compatible tracker protocols and presents device telemetry in dashboards and alert channels.

- Real time location updates and multi constellation position fixes displayed on Plaspy maps and timelines.
- Geofence enter and exit events generate notifications and can be routed to assigned recipients inside Plaspy.
- SOS and vibration alarm events are recorded on the platform and can trigger predefined alert workflows.
- Offline cached points are uploaded after reconnection so Plaspy retains a continuous history of movements.
- Remote configuration and firmware update capabilities can be coordinated through Plaspy for centralized device management.

## Typical Use Cases

- Child safety and school roll call monitoring where compact form and reliable position updates matter.
- Elderly care and vulnerable person monitoring that uses motion alerts and SOS reporting for timely assistance.
- Pet tracking for collars and outdoor activity monitoring with lightweight, durable hardware.
- Personal item tracking for wallets, bags, or small assets that benefit from periodic location history.
- Small scale community or institution deployments that need straightforward device management and event alerting.
