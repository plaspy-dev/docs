# Autoseeker - AT-20 Features

This page provides a public, feature-oriented overview of the Autoseeker AT-20 GPS tracker in the context of using the device with Plaspy. It focuses on the practical capabilities you can expect to see when the AT-20 is integrated into Plaspy for real time tracking, alerting, and fleet telemetry.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method and manufacturer implementation. Where useful, this page highlights capabilities described by the manufacturer, but you should confirm device specific details and firmware notes with Autoseeker before deployment.

## Feature Overview

The AT-20 is a vehicle focused 4G tracker designed to deliver location, status and alerting data useful for fleet operations and vehicle security. When paired with Plaspy, those feeds provide live location visibility, historical routes and event driven notifications to support operational workflows.

- Real time GPS location updates and historical route playback for trip analysis
- Geofence entry and exit notifications and over speed alerting for compliance and safety
- ACC ignition detection and motion related event reporting for vehicle state awareness
- SOS emergency reporting and optional external accessories such as SOS button or camera
- Global 4G LTE connectivity with quad band GSM fallback and internal backup battery for resilient communications
- Support for vehicle interfaces including remote fuel cutoff and optional fuel sensor integration

## Core Features of Autoseeker - AT-20

- Real time tracking and timestamped position reporting for live maps and monitoring
- Historical track recording and playback for trip review and audits
- Geofence alerts for entry and exit events configurable on Plaspy
- Over speed detection and event reporting to flag unsafe driving behavior
- ACC ignition detection to report on vehicle on off state to Plaspy
- SOS emergency reporting and optional wired SOS button support for rapid alerts
- Power management and internal backup battery to maintain basic reporting during power loss
- Support for optional accessories such as camera and fuel sensor and support for remote fuel cutoff

## How These Features Work with Plaspy

Plaspy receives location, event and status messages from the AT-20 and renders them in maps, dashboards and reports so operators can act on vehicle telemetry and alarms. Plaspy is designed to automatically detect supported tracker protocols and accept connections over standard telemetry transports, which simplifies integration of the AT-20.

- Live positions appear on Plaspy maps and update trackers in near real time
- Geofence, over speed and SOS events surface as notifications and timeline events in Plaspy
- ACC and motion inputs are reported as status fields to reflect vehicle on off state and movement
- Historical tracks recorded by the AT-20 are available for playback inside Plaspy for route analysis
- Optional fuel sensor and accessory inputs are represented in Plaspy as telemetry or event data when the device and installation provide those feeds

## Typical Use Cases

- Fleet operations monitoring for dispatch, ETA tracking and route optimization
- Vehicle security and anti theft workflows using geofence alerts, SOS reporting and remote cutoff where supported
- Driver safety and compliance programs monitoring speed events and trip histories
- Logistics and cargo protection where motion detection and reliable position reporting help safeguard shipments
- Mixed and heavy vehicle fleets that benefit from wide voltage input and rugged vehicle installations
- Fuel management scenarios when a fuel sensor and remote cutoff are fitted and integrated

## Feature Availability Notes

- Features may differ between firmware versions; firmware updates can add or modify device behavior
- Hardware revisions and optional accessory configurations affect which inputs and sensors are present
- Regional cellular band support or certification may vary by market and model variant
- Some functions such as remote fuel cutoff or camera input require additional wiring and accessory installation
- Confirm configuration details, default settings and supported commands with the manufacturer documentation

Using the Autoseeker AT-20 with Plaspy brings device level tracking and event feeds into a single fleet management view. Plaspy consolidates location, alarm and status data so fleet managers can monitor assets, receive alerts, replay trips and generate reports that support operational decision making.
