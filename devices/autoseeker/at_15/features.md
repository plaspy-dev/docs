# Autoseeker - AT-15 Features

This page provides a public feature overview for the Autoseeker AT-15 and explains how the device's capabilities map to usage inside Plaspy. It is written to help fleet managers, caregivers, and asset owners understand the practical tracking functions you can expect when using the AT-15 with Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. For device specific technical details consult Autoseeker documentation and check firmware release notes when available.

## Feature Overview

The Autoseeker AT-15 is a compact GPS mini tracker designed for flexible use across vehicles, containers, and personal monitoring scenarios. When paired with Plaspy, the emphasis is on reliable location reporting, boundary monitoring, and simple visibility via web and mobile interfaces.

- Real time location reporting for vehicles, trucks, containers, and individuals
- Geofencing support with notifications when boundaries are crossed
- Compact and portable design for discreet installation and easy relocation
- Advanced GPS positioning for improved location accuracy in supported environments
- Monitoring through a user friendly mobile app and web platform

## Core Features of Autoseeker - AT-15

- Real time tracking for continuous visibility of device location
- Geofence support to define virtual boundaries and receive alerts
- Compact form factor suitable for varied mounting or carrying scenarios
- Designed for tracking vehicles, trailers, containers, and people such as seniors
- Integration friendly with third party platforms including Plaspy for centralized monitoring
- User oriented reporting intended for web and mobile monitoring platforms

## How These Features Work with Plaspy

Plaspy provides a centralized platform to receive, display, and act on the location and event information that the AT-15 reports. Within Plaspy you can monitor device movement, receive alerts, and maintain an operational view of assets tracked with the AT-15.

- Live location updates displayed on Plaspy maps for situational awareness
- Geofence enter and exit events surfaced as notifications or alerts in Plaspy
- Device status and recent location history available through Plaspy interfaces
- Centralized device management to keep AT-15 trackers organized across fleets or groups
- Plaspy automatically detects supported tracker protocols to simplify initial setup

## Typical Use Cases

- Fleet vehicle tracking for visibility and route monitoring
- Container and trailer location tracking for logistics and asset control
- Personal safety monitoring for seniors or individuals who need location oversight
- Short term rental and equipment tracking for temporary deployments
- Small fleet or multi asset operations requiring simple centralized monitoring

## Feature Availability Notes

- Feature support may differ between firmware versions and hardware revisions
- Geofence behavior and notification timing depend on device firmware and reporting intervals
- Installation type and antenna placement can affect GPS performance and accuracy
- Regional variants or local regulations can change available features or reporting modes
- Always consult manufacturer documentation for the most current device specifications

Using the Autoseeker AT-15 with Plaspy gives organizations a straightforward way to consolidate location data from compact trackers into a single monitoring platform. Plaspy focuses on visibility and event delivery so teams can act on real time location information, geofence alerts, and device status without managing multiple vendor portals.
