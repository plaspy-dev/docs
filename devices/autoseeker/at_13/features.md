# Autoseeker - AT-13 Features

This page provides a public feature overview for the Autoseeker AT-13 GPS tracker and how its capabilities are used with Plaspy. It describes practical, user facing functions such as real time location reporting, magnetic attachment for quick placement, and remote access through Plaspy. The intent is to explain what the device can do in the Plaspy platform without delving into private configuration details.

Exact feature availability for any specific unit can vary based on firmware level, hardware revision, installation method, and how the manufacturer implements particular functions. For precise, device specific technical details consult the device manufacturer and release notes before planning deployment.

## Feature Overview

The Autoseeker AT-13 is a compact magnetic tracker intended for vehicle location and remote monitoring. Its small form factor and magnetic attachment make temporary or semi-permanent placement straightforward, while the built in backup battery supports extended standby intervals between charges. When used with Plaspy, the AT-13 provides ongoing location visibility and remote access to location data.

- Compact magnetic enclosure that attaches to metal surfaces for easy placement on vehicles
- Real time tracking capability to support location awareness and movement monitoring
- Long standby performance supported by a 1500mAh backup battery for extended periods between charges
- Remote monitoring for accessing current location information from a distance
- Suitable for individual vehicle monitoring and light fleet oversight where discreet placement is helpful

## Core Features of Autoseeker - AT-13

- Compact magnetic design for quick mounting on metal vehicle surfaces
- Real time GPS location reporting for continuous position visibility
- 1500mAh backup battery providing extended standby operation
- Remote monitoring access to check location from a smartphone or computer
- Small footprint that reduces installation time and simplifies temporary deployments
- Designed primarily for vehicle use and fleet monitoring scenarios
- Compatibility with Plaspy for centralized visibility and tracking

## How These Features Work with Plaspy

Plaspy can receive and display the AT-13 location updates so operators can view current positions, recent movement history, and status from a single platform. Plaspy automatically detects many tracker protocols and presents device activity in a consistent interface for monitoring and oversight.

- Live location updates appear on Plaspy maps for situational awareness
- Historical location trails enable review of recent movements inside Plaspy
- Device status and connection visibility help confirm the tracker is reporting
- Centralized device list in Plaspy simplifies management of multiple AT-13 units
- Remote monitoring via Plaspy removes the need to access the tracker directly for routine checks

## Typical Use Cases

- Individual vehicle tracking for owners who want ongoing location visibility
- Fleet monitoring for small fleets needing discreet and easy to install trackers
- Long distance trip tracking where extended standby time reduces the need for frequent charging
- Temporary placement for special assignments or short term monitoring projects
- Asset location for vehicles stored off site or moved occasionally
