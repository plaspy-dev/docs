# Autoseeker - AT-19 Features

This page provides a public summary of the Autoseeker AT-19 features relevant to using the device with Plaspy. It focuses on practical, user facing capabilities and explains how the AT-19 reports location and vehicle telemetry into the Plaspy platform for monitoring, alerts, and route history.

Exact feature availability for any specific AT-19 unit can vary by firmware version, hardware revision, optional accessories, and installation method. Wherever possible this page stays within manufacturer published capabilities and recommends confirming current behavior with Autoseeker documentation and firmware release notes.

## Feature Overview

The Autoseeker AT-19 is a compact 2G GPS tracker designed for discreet vehicle installation and real-time position reporting. It combines GNSS location with core vehicle telemetry and supports multiple reporting transports so fleet managers and vehicle owners can monitor vehicles through Plaspy dashboards.

- Real time GPS position reporting and route history visibility in Plaspy
- 2G GSM/GPRS connectivity with TCP/GPRS and SMS reporting for telemetry and alerts
- Vehicle inputs and alarms including ACC ignition status, door open and overspeed alerts
- Geofence event notifications and configurable alerting for route and zone monitoring
- Remote immobilizer fuel cut support and optional SOS or remote voice monitoring when supported by firmware or accessories

## Core Features of Autoseeker - AT-19

- Real time GNSS location reporting suitable for cars, motorcycles, vans, buses and trucks
- TCP/GPRS and SMS reporting options for flexible telemetry delivery
- ACC input for ignition on off detection to distinguish driving and parked states
- Door open and close alarm inputs for basic intrusion monitoring
- Overspeed alarm reporting to flag driving speed threshold events
- Geofence detection and entry exit event reporting
- Remote fuel cut (immobilizer) output for anti theft interventions where installed and authorized
- Optional SOS input and remote voice monitoring capabilities when enabled by firmware or accessories

## How These Features Work with Plaspy

When connected to Plaspy the AT-19 supplies position and event data that Plaspy displays and stores for real time monitoring, history, and alert workflows. The device can be configured to report into Plaspy using its supported reporting methods; Plaspy automatically detects the tracker protocol and maps incoming telemetry to the platform interface.

- Live location and route playback available on Plaspy maps and history views
- Vehicle state visibility such as ACC on off reported as status events in Plaspy
- Alarm events including door open, overspeed, and geofence entry exit appear as configurable alerts
- Immobilizer or remote fuel cut can be issued from Plaspy command workflows when the device and installation support that output
- Optional SOS or remote voice monitoring events can be surfaced in Plaspy for incident escalation when enabled by the device firmware

## Typical Use Cases

- Fleet management and route oversight for cars, vans, trucks and buses with live tracking and history
- Anti theft response and vehicle recovery using geofence alerts and remote immobilizer actions
- Delivery and logistics tracking where position updates and geofence notifications improve ETA and proof of route
- Personal vehicle security with optional SOS and emergency monitoring features
- Covert or short term monitoring in applications that require a compact, discreet device form factor

## Feature Availability Notes

- Functionality depends on the device firmware and hardware revision; some alarms or optional features require specific firmware or accessories
- Remote immobilizer actions require proper wiring, permissions, and may be restricted by local regulations
- The AT-19 uses 2G GSM/GPRS for cellular connectivity; check regional 2G network availability before deployment
- Manufacturer published specifications include some inconsistent battery and voltage values; verify power and battery details with Autoseeker prior to purchase
- Regional variants or custom enterprise builds may alter supported inputs or outputs; confirm exact model configuration with the supplier
