# Autoseeker

Autoseeker is a recognized name in GPS tracking hardware focused on vehicle and asset location. Plaspy users can pair Autoseeker devices with the Plaspy platform to monitor location, status, and movement in real time. This brand page explains how Autoseeker devices interact with Plaspy, outlines common features, and helps you find the right device model using the catalog below.

## How Autoseeker devices work with Plaspy

Autoseeker devices transmit GPS and telemetry data that Plaspy ingests, processes, and presents through maps, reports, and alerts. Integration typically involves configuring the device to send data to Plaspy using the network and protocol settings supported by the device. Once a device is set up, Plaspy handles location decoding, trip detection, geofence events, and historical playback so fleet managers and operators can act on reliable location information.

Key integration points to consider
- Data endpoint and server settings that point the device to Plaspy
- Device identifiers such as IMEI or unique tracker ID to register devices in Plaspy
- Optional inputs and sensors for status reporting like ignition, battery, or inputs

For specific setup steps consult the device pages in the Plaspy docs and the device manufacturer documentation as needed.
