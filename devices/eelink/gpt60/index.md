# EElink - GPT60

![GPT60](./tracker.jpg)

The GPT60 is a compact, rechargeable personal GPS tracker designed for continuous location telemetry and safety monitoring. It combines multi constellation GNSS positioning with Wi‑Fi and LBS fallback, and includes two way voice through a built in microphone and speaker. The device also provides an SOS button plus automatic fall and vibration alerts, making it suitable for people and portable assets that require reliable real time location and incident reporting.

As a device marked compatible with Plaspy, the GPT60 can feed location, events, and status into a Plaspy deployment without extensive custom integration. Its combination of GNSS plus Wi‑Fi and LBS fallback, cellular connectivity, Bluetooth sensor support, and remote configuration via the EELINK 2.1 protocol make it a practical choice for teams that want to add personal safety and portable asset tracking into Plaspy workflows for monitoring, alerts, and operational reporting.

## Key Highlights

- Compact, rechargeable personal tracker built for continuous location telemetry and safety monitoring
- Multi mode positioning using GNSS with Wi‑Fi and LBS fallback for improved availability
- Two way voice support via built in microphone and speaker for check ins and incident coordination
- SOS button with automatic fall and vibration alerts for rapid escalation
- 600 mAh rechargeable battery with intelligent power modes to extend runtime between charges
- Bluetooth connectivity for local sensor pairing and step count activity telemetry
- IP65 ingress protection and broad cellular support for everyday outdoor use

## How It Works with Plaspy

When integrated with Plaspy, the GPT60 sends location fixes, alerts, and activity data into the Plaspy platform so administrators and users can view real time position, event history, and device status in one place. Plaspy consumes telemetry and event messages delivered by the device, enabling mapping, alerting, and remote parameter updates where supported.

- Real time location and telemetry visible on Plaspy maps and in history playback
- SOS, fall, vibration, and low battery events routed into Plaspy alert dashboards and notification workflows
- Geofence entry and exit events generated by the device and delivered to Plaspy for automated responses
- Two way voice capability available for coordination during incidents as part of Plaspy operational workflows
- Bluetooth paired sensor and step count data available in Plaspy to enrich activity and local sensor reporting

## Typical Use Cases

- Field personnel check ins and emergency coordination using SOS and voice features
- Portable asset tracking for equipment that is carried or relocated frequently
- Outdoor activities where GNSS with Wi‑Fi and LBS fallback improves continuity of location
- Activity and movement monitoring using step count and vibration event data
