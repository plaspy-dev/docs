# EElink - TK116 Features

This page provides a public feature summary for the EElink TK116 GPS tracker and how its capabilities are used with Plaspy. It focuses on user facing functions, event types, and practical value for vehicle and motorcycle tracking when the device is registered and reporting into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessory choices, and installation method. For the most current device level details consult the manufacturer documentation and release notes from EElink.

## Feature Overview

The TK116 is a compact 2G tracker designed for continuous location updates and event reporting. It combines satellite and base station positioning with AGPS assistance and a set of vehicle inputs and alarms that deliver actionable telemetry for monitoring and incident response.

- Real time GPS plus LBS positioning with AGPS assistance to improve fix times and maintain updates in weak signal areas.
- ACC detection for ignition run and stop status to support behavior based rules and reporting.
- Crash, fall and vibration alarms plus speed alarm generation for incident awareness and safety monitoring.
- Optional relay for remote fuel or power cut off to support immobilizer style anti theft workflows.
- Optional SOS button and microphone for emergency alerting and remote listening when present and configured.
- Built in backup battery and external power cut alerts to reduce blind spots during power interruptions.

## Core Features of EElink - TK116

- GPS and LBS positioning with AGPS assistance for faster location fixes.
- ACC detection input to report ignition or accessory status.
- Crash and fall alarm reporting and vibration alarm support for incident detection.
- Speed alarm generation to flag potential overspeed events.
- Geofencing capable for area enter and exit alerts.
- Optional relay output to enable remote fuel or power cut off actions.
- Optional SOS button and microphone events when the accessory option is fitted.
- Built in backup battery with alerts for external power cut and low battery conditions.

## How These Features Work with Plaspy

When the TK116 is installed and registered in Plaspy, the device streams position and event data for visualization, alerting, and historical analysis. Plaspy interprets the tracker telemetry and exposes it through maps, event lists, and rule engines so operators can act on events as they occur.

- Real time position updates appear on Plaspy maps and are available for live tracking and route playback.
- ACC state is represented in Plaspy for run stop analytics and to trigger ignition based rules.
- Crash, vibration and speed alarms generate immediate notifications and event entries in Plaspy for dispatch and review.
- Geofence enter and exit events are recorded and can trigger alerts or automation inside Plaspy.
- Relay control and remote immobilizer style actions can be coordinated from Plaspy where the device has the optional relay fitted and configured.
- SOS and microphone events are captured and shown in Plaspy so emergency workflows can route alerts to dispatchers or responders.

## Typical Use Cases

- Fleet management for cars, vans and light trucks needing position tracking, ignition status, and event alerts.
- Motorcycle tracking where compact size and light weight help conceal and secure the asset.
- Anti theft workflows using optional relay output to perform remote immobilization when an event is detected.
- Safety and emergency response using crash alarms and SOS events to speed assistance.
- Operational monitoring and reporting to reduce idle time and improve vehicle utilization.
- Route verification and historical trace review for dispatch reconciliation and claims handling.

## Feature Availability Notes

- Optional capabilities such as relay, SOS button and microphone depend on the specific TK116 variant and accessory configuration.
- Firmware revisions and manufacturer settings can change alarm thresholds, event formats, and available diagnostics.
- Installation wiring and how ACC or external power is connected affect how ignition and power cut alerts are reported.
- Regional variants and 2G network availability influence device connectivity and reporting behavior.
- Always confirm the exact hardware revision and feature list with EElink product literature and firmware release notes.
