# EElink - TK116 Features

This page provides a public feature overview for the EElink TK116 GPS tracker and how its capabilities are used with Plaspy for real time tracking and fleet management. It summarizes practical, non sensitive device capabilities and the ways Plaspy surfaces location, status, and event data to operators.

Exact feature availability and behavior depend on the device firmware, hardware revision, the specific options fitted at installation, and manufacturer implementation. Users should consider those variables when planning deployments and consult the manufacturer documentation for device specific details.

## Feature Overview

The TK116 is a compact 2G tracker designed for vehicle and motorcycle applications with a focus on continuous location reporting and event driven alerts. When paired with Plaspy, the device provides position updates plus a set of telemetry and alarm signals that support monitoring, theft mitigation, and incident response workflows.

- Real time GPS location with AGPS assistance and LBS fallback for continued tracking in challenging coverage areas
- ACC detection for ignition status reporting and run stop analytics
- Crash, fall and vibration alarms to alert operators to potential incidents
- Configurable geofencing support for zone entry and exit monitoring
- Optional relay for remote power or fuel cut off to support immobilizer style actions
- Optional SOS button and microphone for emergency alerts and remote listening when fitted

## Core Features of EElink - TK116

- GPS positioning with AGPS assistance and LBS base station fallback for resilient location fixes
- ACC input to report ignition or run state to monitoring platforms
- Crash and vibration alarms to trigger immediate event notifications
- Geofencing capability for location based rules and alerts
- Optional relay output for remote power or fuel control when installed
- Optional SOS button and optional microphone for emergency signaling and voice monitoring
- Built in backup battery and external power cut notifications to reduce blind spots during power loss

## How These Features Work with Plaspy

Plaspy ingests the TK116 telemetry and event messages to display real time positions, historical traces, and configurable alerts for operations teams. The platform presents device events and status in dashboards and notifications so managers can act on incidents and operational conditions quickly.

- Real time position updates and historical tracks are visible in Plaspy mapping and reporting
- ACC status is reported for ignition based rules, run stop reporting, and utilization analytics
- Crash, fall and vibration alarms generate immediate alerts and can be routed to dispatch or mobile responders
- Geofence events appear as zone entry and exit alerts to enforce boundaries and trigger workflows
- Optional relay actions can be executed from Plaspy workflows to perform immobilizer style power or fuel cut control when permitted
- SOS and microphone events are captured and surfaced so dispatchers can handle emergencies and, where allowed, initiate remote listening

## Typical Use Cases

- Fleet management for cars, vans, and light vehicles requiring ignition aware tracking and event reporting
- Motorcycle tracking where compact form factor and light weight simplify installation
- Anti theft workflows using geofence alerts and optional relay based immobilization
- Safety monitoring and emergency response driven by crash and SOS events
- Operational oversight to reduce idle time and enforce ignition based policies
- Remote incident investigation using historical traces and event logs

## Feature Availability Notes

- Optional features such as the relay, SOS button, and microphone depend on the specific hardware variant and factory or field fitting
- Firmware version can affect alarm behavior, reporting intervals, and available configuration options
- Installation wiring and how ACC and relay are connected influence what inputs and outputs are detectable and controllable
- Regional cellular network availability and 2G service may impact connectivity and should be considered for deployment planning
- Always verify the exact feature set and configuration procedures against the manufacturer documentation for the unit you have

## Why Use Plaspy with These Features

Using the TK116 with Plaspy gives teams a concise set of location and event signals that integrate into familiar fleet and dispatch workflows. Plaspy turns device location, ignition state, and alarm events into actionable insights through mapping, alerts, and reporting, helping reduce response times and improve asset visibility.
