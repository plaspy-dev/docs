# EElink - GPT46 Features

This page provides a public feature overview for the EElink GPT46 and how its capabilities are exposed when used with Plaspy. Content here focuses on practical, non-sensitive information about the tracker, emphasizing integration points and operational value inside Plaspy’s dashboards and reporting workflows.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer configuration. The descriptions below are grounded in the GPT46 public product context and aim to help operators understand how the tracker typically behaves when connected to Plaspy while recommending verification with the manufacturer documentation for device-specific details.

## Feature Overview

The GPT46 is a compact LTE Cat M1 / NB1 GPS tracker with long-standby design and BLE host capability, built for industrial asset and logistics use. It is optimized for low-power telemetry and periodic reporting, making it suitable for movable asset programs that need consistent location visibility with minimal maintenance.

- Reliable real-time tracking and periodic telemetry reporting optimized for long standby operation
- BLE host support to augment GPS location with paired Bluetooth sensor or beacon data
- Compact and concealment-friendly form factor suitable for trailers, equipment, and transport assets
- Industrial-grade construction intended for demanding field deployments
- Scalable deployment characteristics for fleet management and anti-theft monitoring
- Designed to integrate with cloud platforms such as Plaspy for centralized monitoring

## Core Features of EElink - GPT46

- LTE Cat M1 and NB1 cellular connectivity for low-power wide area network reporting
- GPS position fixes for location tracking and history playback
- BLE host functionality to pair with Bluetooth sensors and beacons for additional context
- Long-standby power profile to reduce frequency of maintenance visits
- Compact, concealment-friendly industrial form factor for discreet installations
- Cloud reporting compatibility to platforms such as Plaspy for centralized visibility
- Engineered for logistics and movable asset management use cases

## How These Features Work with Plaspy

When the GPT46 reports location and telemetry, Plaspy receives and normalizes those inputs so teams can view live position, review history, and respond to operational events. The integration is focused on making location and sensor context visible and actionable within Plaspy’s fleet and asset workflows.

- Real-time and periodic location updates appear in Plaspy for situational awareness and map visualization
- BLE sensor and beacon data paired to the tracker can be surfaced in Plaspy to enrich asset context
- Long-standby check-ins keep device status and last communication timestamps available in Plaspy
- Movement history and basic telemetry are available for playback and event investigation
- When combined with appropriate external interfaces, the tracker can feed additional workflows in Plaspy such as anti-theft alerts or maintenance triggers dependent on extra hardware or integration

## Typical Use Cases

- Trailer and non-powered asset tracking for fleet visibility and utilization monitoring
- Logistics and shipment tracking for movable inventory across transport routes
- Anti-theft monitoring with alerting and movement detection workflows in Plaspy
- Cold chain or container monitoring when paired with BLE temperature or proximity sensors
- Rental equipment and construction tool tracking to reduce loss and improve lifecycle management
