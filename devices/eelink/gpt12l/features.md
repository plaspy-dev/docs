# EElink - GPT12‑L Features

This page provides a public feature overview for the EElink GPT12‑L and explains how its capabilities relate to use with the Plaspy platform. It focuses on practical, non sensitive descriptions of what the device can do and how those functions appear to operators using Plaspy for fleet and asset monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, regional variant, and the manufacturer's configuration choices. For device specific parameters and the most current technical details consult the manufacturer documentation and release notes.

## Feature Overview

The GPT12‑L is an ultra slim IoT asset tracker designed for long term, low maintenance location monitoring with configurable reporting behavior. It targets asset and vehicle workflows that require long standby times combined with the option for sustained live tracking when needed.

- Plaspy compatible device that integrates into live maps, alerts, and historical reports for operational oversight.
- Multi GNSS positioning with reported sub 2 meter accuracy for reliable location data in many environments.
- LTE Cat M1 and NB2 cellular connectivity with global band support and GSM fallback for wide coverage.
- Large 4500 mAh battery with configurable sleep profiles allowing ultra long standby durations and reduced maintenance.
- Emergency real time mode for sustained frequent updates during intensive tracking windows.
- Compact ultra slim form factor for discreet mounting on vehicles and high value assets.

## Core Features of EElink - GPT12‑L

- Multi constellation GNSS support including GPS GLONASS BeiDou Galileo QZSS for improved fix reliability.
- Sub 2 meter GNSS accuracy with fast fix times for timely location updates.
- LTE Cat M1 and NB2 cellular connectivity with GSM fallback for broad regional coverage.
- Large 4500 mAh battery with configurable sleep and wake scheduling to extend time between charges.
- Emergency real time tracking mode that supports continuous updates for extended short term monitoring.
- Geo fence alarms for perimeter based event notifications.
- Remote configuration options via server commands mobile app or SMS to adjust reporting and power profiles.
- Ultra slim physical design for concealed mounting and minimal installation footprint.

## How These Features Work with Plaspy

Plaspy ingests the GPT12‑L position and event data and presents it through live maps alerting and historical routes so operators can monitor assets with configurable update behavior. Integration emphasizes event driven reporting to maximize battery life while allowing immediate visibility when devices are active or in emergency mode.

- Live positions and historical route data appear in Plaspy dashboards when the device reports GNSS fixes.
- Geo fence alarm events are forwarded to Plaspy so rules and alerts can be triggered for rapid notification.
- Battery and operational telemetry reported by the device are available in Plaspy for maintenance planning and status checks.
- Scheduled wake up and sleep behavior can be coordinated through remote configuration to balance visibility and battery conservation.
- Emergency real time mode increases reporting frequency and is reflected in Plaspy as sustained live updates during critical recovery or monitoring periods.

## Typical Use Cases

- Fleet management with scheduled check ins and on demand tracking to support utilization and routing decisions.
- Anti theft detection and recovery using geo fences and emergency live tracking for rapid response.
- Remote asset monitoring for trailers containers and equipment where long standby between maintenance cycles is required.
- Telemetry augmentation where frequent updates during activity and sparse reporting while idle reduce data usage.
- Temporary event tracking where high intensity monitoring is enabled for a limited period without hardware changes.
- International asset deployments benefiting from multi band cellular coverage and GNSS reliability.
