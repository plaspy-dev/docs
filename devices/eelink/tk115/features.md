# EElink - TK115 Features

This page provides a public feature overview for the EElink TK115 and how its capabilities map to use with Plaspy. It focuses on the practical, non sensitive aspects of the tracker that matter to fleet operators, mobility providers, and security teams when integrating TK115 devices into Plaspy for tracking, alerting, and operational workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific parameters, firmware updates, and installation guidance refer to the official EElink documentation and the device release notes.

## Feature Overview

The TK115 is a compact GPS tracker designed for electric motorcycles and scooters and is Plaspy compatible for straightforward fleet and anti theft integration. It combines GPS and LBS positioning with vehicle status reporting and an optional remote relay to deliver core visibility and security functions that feed into Plaspy dashboards and alerts.

- Real time GPS and LBS positioning with AGPS assistance for faster fixes and consistent location reporting.
- Wide DC input range to support common vehicle electrical systems used in two wheel fleets.
- ACC ignition detection for reliable trip start and stop reporting inside Plaspy.
- Optional relay output for remote immobilization or power cut workflows when managed through Plaspy.
- Onboard backup battery and power loss reporting to maintain connectivity and send low battery alerts into Plaspy.

## Core Features of EElink - TK115

- GPS with AGPS assistance for improved time to first fix and position reliability.
- LBS fallback to assist positioning where satellite signal is limited.
- ACC ignition detection to track engine or ignition status changes.
- Optional relay for remote immobilizer or power cut control when supported by the installed unit.
- Security alarms including displacement or towed detection, vibration alerts, speed alarm, and geofence violation events.
- Wide DC input suitable for a range of vehicle voltages commonly found on electric scooters and motorcycles.
- Onboard backup battery to continue reporting during main power loss and to enable low battery notifications.
- Remote parameter setting support for configuration changes managed without physical access to the device.

## How These Features Work with Plaspy

When connected to Plaspy, the TK115 supplies location coordinates and event signals that are usable in live monitoring, alerting, and reporting workflows. Plaspy ingests the tracker telemetry to provide situational awareness, incident handling, and historical reporting for vehicles fitted with TK115 devices.

- Live location updates appear on Plaspy maps to support active monitoring and dispatch.
- ACC status changes are reflected as trip start and stop events for reporting and route analysis.
- Security alarms such as displacement, vibration, speed, and geofence breaches generate immediate events and notifications inside Plaspy.
- Power loss and low battery notifications surface in Plaspy so operators can act on potential tampering or battery replacement needs.
- Optional relay control can be used as part of an immobilization workflow when the installed device and installation support remote relay commands.

## Typical Use Cases

- Fleet anti theft and rapid recovery with remote immobilization and real time alerts for tampering or towing.
- Scooter and motorcycle sharing operations using geofencing and speed alerts to enforce safe zones and rules.
- Last mile delivery on two wheel vehicles with ACC based trip logging and route visibility.
- Towed or displacement detection for immediate response to unauthorized movement.
- Continuity monitoring where backup battery and power loss alerts reduce blind spots during disconnection or vandalism.
- Routine fleet telemetry and maintenance planning using location and ignition data as inputs to operational reports.
