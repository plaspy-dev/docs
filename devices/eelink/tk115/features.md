# EElink - TK115 Features

This page provides a public, feature-focused overview of the EElink TK115 GPS tracker and how its capabilities are used with the Plaspy platform. It is intended to describe practical, non-sensitive functions and the kinds of operational value the device can provide when integrated into Plaspy for fleet monitoring, anti-theft workflows, and telemetry reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and specific installation. For device-specific technical details and the latest firmware information, consult the official manufacturer documentation.

## Feature Overview

The TK115 is a compact tracker designed for electric motorcycles, scooters, and similar light vehicles. Its core strengths are reliable positioning with AGPS assistance, wide voltage support for various vehicle systems, basic vehicle status inputs, and continuity through an onboard backup battery. These capabilities make it suitable for real-time tracking, theft mitigation, and operational monitoring when connected to Plaspy.

- Real-time GPS and LBS positioning with AGPS to improve fix time and location reliability.
- Wide DC input range (9–60 V) for compatibility with common two-wheeler and light commercial power systems.
- ACC ignition detection for trip start/stop awareness and ignition-based reporting.
- Optional relay support to enable remote immobilization or power/fuel cut actions.
- Alarm generation for displacement (towing), vibration, speed, and geofence events with immediate reporting.
- Onboard backup battery and power-loss or low-battery alerts to maintain monitoring during outages.

## Core Features of EElink - TK115

- Plaspy compatible real-time telemetry and event reporting for fleet and security systems
- Wide DC input support suitable for 12 V, 24 V, 36 V and 48 V electrical systems
- GPS with AGPS assistance providing positioning accuracy in the range of approximately 5–15 m
- GSM quad-band connectivity for mobile network coverage in supported regions
- ACC ignition detection for precise trip and status reporting
- Optional relay interface for remote immobilizer or power/fuel cut functionality
- Multiple security alarms including displacement, vibration, speed, and geofence violations
- Onboard backup battery with low-battery and power-loss alerting

## How These Features Work with Plaspy

When the TK115 is connected to Plaspy, the device feeds location coordinates, status signals, and alarm events into a central platform where operators can view, alert, and report on vehicle activity. Plaspy ingests the telemetry and exposes the device state alongside other fleet data to support operational workflows and incident response.

- Live location and periodic position updates displayed on Plaspy maps and dashboards
- ACC/ignition status visible for accurate trip segmentation and ignition-related alerts
- Security alarms (displacement, vibration, speed, geofence) delivered as events into Plaspy for notifications or automation
- Relay-capable units can be managed as part of incident workflows inside Plaspy to initiate immobilization or power cut actions where supported
- Power-loss and low-battery alerts from the backup battery surface in Plaspy to help maintain continuity and trigger maintenance
- Remote parameter updates and configuration sent from Plaspy when remote management is supported by the installed firmware

## Typical Use Cases

- Anti-theft and asset recovery for electric motorcycles and scooters using alarm events and optional immobilizer relay control
- Shared mobility fleets enforcing geofenced areas and speed policies with immediate alerts
- Last-mile delivery and courier operations using ACC detection for accurate trip timing and usage tracking
- Detection of towing or unauthorized movement through displacement and vibration alarms for quick response
- Continuous operational telemetry feeding maintenance scheduling and uptime monitoring
- Light commercial vehicle tracking where wide voltage acceptance simplifies installation across vehicle types
