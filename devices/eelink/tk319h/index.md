# EElink - TK319‑H

![TK319‑H](./tracker.jpg)

The TK319‑H is a compact 3G GPS tracker designed for reliable vehicle tracking and telemetry. It provides continuous location reporting, ACC ignition detection, and a set of motion and safety alarms intended for vehicle and asset monitoring. The device is built with a small form factor and a wide DC input range, making it suitable for varied vehicle types and installations.

As a Plaspy compatible device out of the box, the TK319‑H transmits location and telemetry using EElink's MoveLink protocol so Plaspy can ingest live positions, alarms, and status updates. That integration makes the tracker a practical option for fleets, rental operators, and teams that need straightforward onboarding to Plaspy for real time monitoring and incident response.

## Key Highlights

- Plaspy compatible device using MoveLink EELINK for straightforward platform integration.
- Real time GPS and base station positioning with AGPS support for continuous location visibility.
- Built in alarms for crash, overspeed, vibration, acceleration, and deceleration to support safety monitoring.
- ACC ignition detection and serial GPIO expansion for basic telemetry and status inputs.
- Optional relay support for remote fuel or power cut off workflows when required.
- Wide vehicle power input range and a small backup battery to maintain reporting during short power interruptions.
- Compact and lightweight form factor suited to discreet vehicle installation.

## How It Works with Plaspy

When paired with Plaspy, the TK319‑H sends its position, telemetry, and alarm messages to the Plaspy platform where those inputs feed maps, alerts, and historical records. Plaspy uses this incoming data to support operational workflows, notify stakeholders, and generate reports useful for fleet oversight.

- Live location updates appear on Plaspy maps for real time fleet visibility and routing.
- ACC and ignition messages let Plaspy determine driving versus parked states and trigger ignition based reports.
- Safety alarms such as crash, overspeed, and vibration are forwarded to Plaspy to enable rapid notification and incident logging.
- Relay control can be integrated into Plaspy workflows to perform authorized remote immobilization or power control actions.
- LBS fallback location helps Plaspy maintain continuity when GPS quality is reduced.

## Typical Use Cases

- Fleet management for cars, vans, and light trucks needing continuous tracking and runtime state.
- Rental vehicle monitoring where ignition and location data support utilization and recovery workflows.
- Anti theft and immobilization scenarios using optional relay control coordinated through Plaspy.
- Safety and incident response for organizations that need crash and motion alarms routed to dispatch or operations teams.
- Basic temperature aware shipments when a temperature sensor option is fitted and integrated via the device inputs.
