# Xirgo - XT62

![XT62](./tracker.webp)

The XT62 is a Plaspy compatible asset module designed for refrigerated trailers and cargo containers. Built for cold‑chain visibility, the XT62 provides continuous condition monitoring and location reporting so you can track temperature, door status and remote I/O signals during transit. Integrate XT62 data into Plaspy for unified telemetry, event alerts and fleet management dashboards.

Whether you manage reefers, high‑value cargo or temperature‑sensitive pharmaceuticals, the XT62 lets operations teams combine real‑time tracking with condition monitoring. As a Plaspy compatible device, the XT62 feeds location and sensor data into Plaspy to support route optimization, anti‑theft alerts and regulatory compliance across cold‑chain shipments.

## Key Highlights

- Purpose‑built for cold‑chain: optimized for refrigerated trailer and container monitoring with direct temperature input support.
- Plaspy compatible: sends telemetry and event data to Plaspy for centralized real‑time tracking and reporting.
- Door and roll‑up sensor inputs: monitor access events to reduce theft and cargo tampering risks.
- Remote I/O interfaces: control alarms, trigger external devices, or tie into refrigeration control logic.
- Condition‑based alerts: get immediate notifications for temperature excursions or door breaches through Plaspy.
- Asset‑level visibility: know location and condition together to support efficient fleet management and cold‑chain compliance.
- Designed for mobile assets: rugged form factor and interfaces suited to trailer/container installations.

## How It Works with Plaspy

Integrating the XT62 with Plaspy connects your cold‑chain hardware to a modern telematics platform. The tracker streams location updates and sensor telemetry into Plaspy where data is normalized, visualized on maps, and available to generate alerts, reports, and API feeds. Plaspy can consolidate XT62 inputs with other vehicle or site telemetry for a unified view of fleet and asset health.

- Real‑time location and telemetry updates delivered to Plaspy for mapping and route monitoring.
- Continuous temperature monitoring with event reporting and configurable excursion alerts.
- Door/roll‑up sensor status and access event logging for anti‑theft and compliance workflows.
- Remote I/O control to actuate alarms, logging devices, or interface with refrigeration controls via Plaspy commands.
- Plaspy supports broader telemetry such as fuel monitoring, ignition and immobilizer events or Bluetooth sensors when those data sources are present; XT62 supplies the cold‑chain sensor inputs and I/O that feed into that telemetry ecosystem.
