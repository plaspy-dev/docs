# Xirgo - XT62 Features

This page summarizes the public feature context for using the Xirgo XT62 asset module with Plaspy. It describes the practical capabilities you can expect to see in Plaspy when the XT62 is integrated for refrigerated trailers and cargo container monitoring, focusing on location, temperature, door status, and remote I/O signals.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. Use this page as a high-level guide for how the XT62 is typically used with Plaspy and consult manufacturer documentation for model specific details.

## Feature Overview

The XT62 is designed for cold‑chain visibility by combining continuous condition monitoring with location reporting. When integrated into Plaspy, XT62 telemetry helps operations teams monitor temperature, access events, and remote I/O status alongside asset location to support operational decision making and compliance workflows.

- Continuous temperature monitoring input support for refrigerated trailers and containers.
- Door and roll‑up sensor inputs to detect access events and log status changes.
- Remote I/O interfaces for alarms, external device triggering, or simple control integration.
- Location reporting that pairs condition data with asset position for end-to-end visibility.
- Condition‑based alerts for temperature excursions and door breaches routed into Plaspy.
- Rugged form factor and interfaces suited to trailer and container installations.

- Temperature input support for continuous cold‑chain condition monitoring.

## How These Features Work with Plaspy

When the XT62 feeds telemetry into Plaspy, the platform normalizes location and sensor data so teams can visualize asset condition and respond to events in one place. Plaspy collects XT62 inputs and makes them available for mapping, alerting, reporting, and API access as part of a unified fleet or asset management view.

- Real‑time location and telemetry updates appear on Plaspy maps for route monitoring.
- Temperature readings are available for trend visualization and configurable excursion alerts.
- Door sensor events are recorded for access logs, security reviews, and compliance evidence.
- Remote I/O state can be monitored and used to trigger alarms or automated workflows within Plaspy.
- Plaspy consolidates XT62 inputs with other asset telemetry to give a single operational view.
