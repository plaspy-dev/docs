# Xirgo - XT-2000 Features

This page provides a public, non-sensitive feature overview of the Xirgo XT-2000 and how the device’s capabilities map to operational use inside Plaspy. It covers the XT-2000’s primary user-facing functions and explains what fleet managers and administrators can expect when they deploy the XT-2000 with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a practical guide and consult the manufacturer for the most current device-specific details.

## Feature Overview

The XT-2000 is a plug and play OBD II modem with an integrated GPS engine and on-board sensors, designed for passenger and light-duty vehicles. It relays vehicle location and select OBD II data over cellular networks and is suitable for a range of telematics applications where simple installation and access to vehicle parameters are important.

- Plug and play installation via the integrated J1962 OBD II connector for quick deployment
- Integrated GPS engine and antennas for continuous location tracking and speed awareness
- Access to OBD II parameters including VIN, ignition status, speed, and diagnostic fault codes
- Built-in accelerometer for motion and basic event detection
- Support for TCP, UDP, FTP, and over-the-air firmware updates to keep devices current

## Core Features of Xirgo - XT-2000

- Integrated OBD II interface for vehicle data access through the vehicle diagnostic port
- Embedded GPS engine and GPS antenna for position and speed reporting
- Accelerometer for detecting motion events and providing basic movement awareness
- Support for Diagnostic Fault Codes DTC DFC reporting as available from the vehicle
- Compact, powered design that draws power from the vehicle OBD port for simple installation
- Compatibility with multiple OBD II protocols for broad vehicle support in North America
- Network communication support including TCP UDP and FTP for data uplink and device management

## How These Features Work with Plaspy

Plaspy receives and processes the telemetry and event data the XT-2000 sends, so fleet operators can view location, movement, and selected vehicle parameters on the Plaspy platform. Plaspy automatically detects tracker protocols and ingests location and event data for visibility and reporting.

- Location and speed data from the XT-2000 appear in Plaspy as real-time position updates and historical routes
- OBD II parameters such as VIN and ignition status provided by the device are available for asset identification and status monitoring
- Diagnostic fault codes reported by the XT-2000 can be recorded in Plaspy for maintenance tracking and workflow integration
- Motion events generated by the accelerometer can be surfaced as events inside Plaspy for activity and movement detection
- The XT-2000 can be configured to report to Plaspy over TCP or UDP and Plaspy accepts tracker connections and automatically detects the device protocol

## Typical Use Cases

- Fleet tracking for passenger cars and light-duty vehicles with fast, no-tool installation
- Aftermarket telematics programs where VIN and basic vehicle state are required
- Driver behavior monitoring workflows that leverage speed, ignition state, and motion events
- Maintenance and diagnostics workflows that collect DTCs and OBD II parameters for triage
- Consumer and subscription services providing vehicle location and basic vehicle data access

## Feature Availability Notes

- Device functions depend on firmware version and manufacturer configuration; feature sets can change with updates
- Hardware revisions and regional variants can affect supported OBD II protocols and compatibility
- Some OBD II parameters and diagnostic codes are vehicle dependent and may not be present on all makes and models
- Installation method matters: the XT-2000 requires an OBD II port connection and position may affect GPS reception
- For the latest, device specific details and support documents refer to the manufacturer documentation
