# Xirgo - XT45 Features

This page provides a public feature summary for the Xirgo XT45 and how its capabilities map to Plaspy for fleet and asset tracking. It focuses on non-sensitive, user-facing information about what the XT45 is designed to do and how Plaspy can use the telemetry the device provides for location awareness and operational oversight.

Exact capabilities and behavior may vary by firmware version, hardware revision, installation method, and the manufacturer's implementation choices. For precise technical details, configuration options, and the latest firmware behavior consult the manufacturer's documentation and release notes.

## Feature Overview

The XT45 is a rugged GPS tracker built for resilient asset protection and telemetry where power is intermittent and environments are demanding. It combines integrated cellular and GPS connectivity with supervisory inputs and outputs to deliver location and status information that Plaspy can ingest for real-time monitoring and historical reporting.

- Resilient GPS and cellular connectivity for continuous location reporting in challenging conditions
- Designed to operate with intermittent or part-time power for equipment and trailers
- Supervisory inputs and outputs to capture discrete events such as ignition state and to support remote control actions
- Rugged housing and extended temperature tolerance for exposed assets and construction equipment
- Practical integration into anti-theft workflows, geofencing, and historical playback on Plaspy

## Core Features of Xirgo - XT45

- Integrated GPS and cellular connectivity for location fixes and telemetry
- Designed for intermittent power scenarios to preserve reporting reliability
- Supervisory inputs and outputs for monitoring and remote control use cases
- Rugged enclosure and extended temperature tolerance for harsh environments
- Support for asset protection workflows including ignition sensing and immobilizer control
- Optimized telemetry reporting to support visibility and operational analysis
- Compatibility with external sensor integrations such as Bluetooth peripherals when used in a solution

## How These Features Work with Plaspy

Plaspy ingests the XT45's position and supervisory telemetry to present live location, status, and event information across dashboards, maps, and reports. Plaspy automatically detects supported tracker protocols and maps incoming telemetry into the platform so teams can monitor assets, receive alerts, and review history without manual protocol selection.

- Live position updates and historical playback for asset movement analysis
- Supervisory input events such as ignition or door status shown as discrete events in Plaspy
- Remote control actions using device outputs integrated into Plaspy workflows for immobilizer or shutdown sequences where supported by the device and installation
- Correlation of external sensor data such as Bluetooth peripherals with location and event records for richer context
- Alerts, geofencing, and reporting driven by XT45 telemetry for operational oversight

## Typical Use Cases

- Trailer tracking and protection for towed assets exposed to the elements
- Monitoring of construction machinery and remote equipment with part-time power
- Fleet anti-theft and immobilization workflows using supervisory outputs
- Remote telemetry collection for asset health and status reporting
- Geofencing and historical route analysis for compliance and logistics
- Integrating external sensors to tie fuel or auxiliary telemetry to location events when paired with suitable sensors
