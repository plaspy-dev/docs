# Xirgo - XT-2100 Features

This page provides a public feature context for the Xirgo XT-2100 and describes how those capabilities are used with Plaspy for fleet and asset monitoring. It focuses on the tracker’s practical functions and the ways Plaspy surfaces location, connectivity, and event information to operators and administrators.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific wiring, firmware behavior, or installation instructions consult the official Xirgo documentation and your installer.

## Feature Overview

The XT-2100 is a compact, fully integrated GPS tracker designed for mobile and remote asset monitoring. It combines cellular GPRS communication with an integrated GPS engine and is intended for use in fleet management, aftermarket automotive applications, consumer tracking, and driver behavior monitoring.

- Real time location reporting including position, speed, and direction for operational visibility
- Two all purpose digital inputs for event and state monitoring
- One internal analog input for battery voltage monitoring
- One digital output capable of driving ignition relays or similar control circuits
- Multi protocol connectivity with TCP, UDP, and FTP support and support for quad band GSM networks
- Over the air firmware updates and remote configuration capability for maintenance and feature updates

## Core Features of Xirgo - XT-2100

- Integrated GPS engine for continuous position tracking
- Cellular GPRS modem with quad band network compatibility for broad regional coverage
- Two configurable digital inputs for detecting external switches or alarms
- One internal analog input that can be used for monitoring battery voltage
- One digital output suitable for driving ignition relays or equivalent actuators
- Support for TCP, UDP, and FTP communications for flexible server integration
- Over the air firmware updates and remote configuration to adapt to changing requirements
- Compact enclosure with integrated antennas for discreet installations

## How These Features Work with Plaspy

Plaspy receives and interprets the XT-2100’s reports so fleet managers and operators can monitor assets in near real time. Plaspy automatically detects the tracker protocol and presents device data in the platform for situational awareness and historical review.

- Real time location, speed, and direction appear on Plaspy maps and in trip reports
- Digital input events are recorded as discrete events or alerts inside Plaspy for state change visibility
- Battery voltage reported via the analog input is available in device telemetry to support power health checks
- The device can communicate to Plaspy using standard TCP or UDP connections on the platform port, and Plaspy detects the protocol automatically
- Firmware updates and remote configuration capabilities on the XT-2100 enable centralized management workflows when coordinated with back end tools

## Typical Use Cases

- Fleet vehicle location tracking and route monitoring for improved dispatching
- Aftermarket automotive tracking for recovery, location history, and usage oversight
- Remote asset monitoring where discreet installation and compact size are required
- Driver behavior monitoring and modification programs that rely on speed and movement data
- Battery health monitoring for vehicles and equipment using the internal analog input
- Controlled ignition or immobilization workflows using the device digital output in authorized installations

## Feature Availability Notes

- Some features depend on the XT-2100 firmware and may vary between firmware versions and hardware revisions
- Installation wiring and how inputs or outputs are used will affect what data is available to Plaspy
- Regional cellular network compatibility depends on quad band support and local carrier availability
- Over the air update capability requires network connectivity and appropriate configuration from the device management side
- Manufacturer settings, custom configurations, or dealer-specific firmware can enable or disable certain behaviors

Using the XT-2100 with Plaspy gives organizations a straightforward way to turn raw tracker reports into operational insight. Plaspy consolidates position, event, and telemetry data into maps, reports, and alerting so teams can monitor assets, respond to incidents, and analyze historical activity without managing low level protocol details.
