# Xirgo

Xirgo produces a range of telematics and GPS tracking devices used in vehicle and asset monitoring. On this page you will find how Xirgo devices work with Plaspy, what common features to expect, typical use cases, and help choosing the right tracker. ## How Xirgo devices work with Plaspy

Xirgo trackers transmit location and telemetry data over cellular networks. Plaspy ingests that data using standard telematics protocols and presents it in a single unified interface. Integration covers device provisioning, real time tracking, and data forwarding within Plaspy so fleet managers and operators can monitor assets alongside other device brands.

Key integration points typically include device identification, position updates, event reporting, and basic configuration parameters. For device specific configuration and advanced features consult the model documentation accessible from the catalog and the device guides in Plaspy.

## Common features found in Xirgo devices

While specific capabilities vary across models, many Xirgo devices commonly provide:
- GPS location reporting with configurable update intervals
- Cellular connectivity for live tracking
- Vehicle power detection and sleep modes for battery powered assets
- Input and output pins for sensors and remote control
- Basic event reporting such as ignition, movement, tamper, and geofence entries
These general features are what allow Xirgo hardware to integrate cleanly with Plaspy for tracking and fleet workflows.

## Typical use cases for Xirgo GPS trackers

Xirgo hardware is used in a variety of tracking scenarios:
- Fleet vehicle tracking for dispatch and route oversight
- Asset monitoring for trailers, equipment, and leased assets
- Driver behavior monitoring when combined with telematics workflows
- Location based alerts for geofences and worksite boundaries
Plaspy organizes incoming data from Xirgo devices into dashboards, alerts, and historical reports to support these operational needs.

## Why choose Plaspy for Xirgo device monitoring

Plaspy provides a single pane of glass for mixed brand deployments, making it practical to manage Xirgo devices alongside other telematics hardware. Benefits of using Plaspy with Xirgo devices include:

- Integration options to export data to third party systems or downstream workflows
Plaspy focuses on interoperability and ease of use so teams can onboard Xirgo units without rebuilding tracking processes.
