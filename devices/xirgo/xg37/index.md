# Xirgo - XG37

<div className="device-logo">
![XG37](./tracker.webp)
</div>

The XG37 is a rugged fleet vehicle telematics GPS tracker designed for professional fleet management and compliance workflows. As a proven predecessor to the LX40, the XG37 delivers location tracking together with full CANBUS telemetry, instant geofence notifications, remote tachograph download capability and an SDK for custom device side scenarios. It is built to provide reliable vehicle data and organized telemetry for fleet operations.

Because the XG37 can stream telemetry securely and efficiently, it is a practical Plaspy compatible tracker for organizations that want consolidated real time tracking, vehicle diagnostics and compliance data in a single fleet management platform. Its support for MQTT based transport with TLS 1.2 and device side customization makes it straightforward to feed mapped positions, CANBUS signals and event alerts into Plaspy for monitoring, reporting and operational oversight.

## Key Highlights

- Plaspy compatible device designed to deliver real time tracking and telemetry into Plaspy
- Full CANBUS data access for engine status, ignition and fuel related signals where available
- Secure MQTT based telemetry with TLS 1.2 for encrypted data transfer to back end systems
- Remote tachograph download to support driver hours and regulatory compliance workflows
- Instant geofence notifications for route compliance and anti theft monitoring
- Built in SDK and optional battery configurations for flexible deployment and edge logic

## How It Works with Plaspy

Integration with Plaspy is designed to bring position, vehicle telemetry and compliance events into one monitoring and reporting environment. The XG37 can be configured to send the telemetry Plaspy needs, while device side rules reduce noise and improve the relevance of incoming events.

- Real time location updates sent to Plaspy for mapping and live fleet monitoring
- CANBUS telemetry forwarded to Plaspy for diagnostics, fuel monitoring and vehicle level analysis
- Geofence events and instant alerts arrive in Plaspy to support route compliance and security workflows
- Remote tachograph retrieval delivered into Plaspy for audit and driver hours reporting
- Encrypted transport via MQTT with TLS 1.2 to protect telemetry in transit to Plaspy
- Custom device scenarios implemented with the SDK to tailor sampling and event generation for Plaspy consumption

## Typical Use Cases

- Fleet management and route optimization using live location plus vehicle telemetry
- Regulatory compliance and driver hours administration with remote tachograph collection
- Anti theft and secure yard monitoring through geofence alerts and live tracking
- Telemetry driven maintenance and fuel monitoring based on CANBUS data
- Mixed fleet deployments where secure, configurable telemetry is required

## Why Choose This Tracker with Plaspy

The XG37 is a practical option for organizations using Plaspy that need a mature telematics unit offering rich vehicle data, compliance features and secure transport. Its CANBUS capabilities and remote tachograph support reduce administrative overhead for fleets that must track driver hours and vehicle health, while MQTT and TLS 1.2 provide a modern, secure channel for streaming data into Plaspy.
