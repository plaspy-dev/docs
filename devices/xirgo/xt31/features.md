# Xirgo - XT31 Features

This page provides a public, non sensitive overview of the Xirgo XT31 feature set and how those capabilities can be used with Plaspy. It focuses on practical, user facing information about cargo sensing, gateway behavior, and the types of telemetry and events the XT31 delivers into the Plaspy platform for fleet and logistics workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. For device specific details, configuration options, and the latest firmware behavior consult Xirgo documentation and your integrator before deployment.

## Feature Overview

The XT31 is an industrial IoT gateway and cargo monitoring solution built for trailer and container telematics. It concentrates on delivering cargo condition insights, capacity assessment, and event driven telemetry into fleet platforms such as Plaspy to support routing, utilization, and operational decisions.

- Plaspy compatible gateway that aggregates cargo and event data for centralized monitoring.
- Integrated cargo sensing to capture condition and status without separate middleware layers.
- Remote trailer and container capacity assessment to support loading and dispatch planning.
- Event driven alerts and historical logs for timely operational actions and post trip analysis.
- Designed for trailer and container telematics to address intermodal and fleet use cases.
- Complements GPS tracker feeds by providing cargo and sensor context alongside location data.

## Core Features of Xirgo - XT31

- Plaspy compatibility for centralized ingestion and reporting of cargo telemetry.
- Integrated cargo sensor inputs and on‑device sensor aggregation to reduce backhaul.
- Remote capacity assessment metrics that assist planning and reduce inefficient moves.
- Event driven notifications for load, unload, and other cargo related events.
- Historical status and event logs retained for trend analysis and audits.
- Industrial gateway form factor suited for trailers and containers.
- Designed to work alongside GPS trackers and other telemetry systems for full situational awareness.

## How These Features Work with Plaspy

When deployed with Plaspy, XT31 telemetry and event streams are normalized, visualized, and made actionable alongside other fleet data. Plaspy ingests the XT31 data so operations teams can correlate cargo condition and capacity with routing, schedules, and asset location.

- Real time cargo telemetry and status updates appear in Plaspy dashboards for operational visibility.
- Event driven alerts from the XT31 can trigger Plaspy notifications and workflow automation.
- Historical status and trend data from the XT31 are available in Plaspy for reporting and analysis.
- Capacity assessment metrics are surfaced in Plaspy to support loading decisions and dispatch planning.
- XT31 cargo streams integrate with GPS tracker data in Plaspy to produce a combined view of location and cargo condition.

## Typical Use Cases

- Fleet capacity planning to reduce empty runs and improve asset utilization.
- Container and trailer condition monitoring across intermodal journeys.
- Yard and port operations where gateway aggregation speeds asset turnover.
- Combined telemetry for logistics teams to correlate cargo status with location.
- Post trip analysis and audit using historical event logs and status records.
- Operational alerts to accelerate response to load and handling events.

## Feature Availability Notes

- Firmware and software revisions can change available features and event behavior.
- Hardware variants or regional models may differ in supported sensor interfaces and capabilities.
- Installation method and external sensor choices affect which cargo metrics are available.
- The XT31 is intended to complement, not replace, location tracking devices in a fleet solution.
- Always consult the manufacturer documentation for the precise behavior of a specific unit.

Using the XT31 with Plaspy gives fleets a cargo centric telemetry layer that complements existing GPS trackers and fleet systems. Plaspy brings XT31 cargo events, capacity assessments, and historical records into a single operational view so teams can act faster, plan better, and analyze handling outcomes across assets.
