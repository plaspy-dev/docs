# Xirgo - XT-6300 Features

This page summarizes the public feature context for the Xirgo XT-6300 when used with the Plaspy platform. It focuses on the device capabilities that are relevant to operational tracking, diagnostics, monitoring, and telematics visibility inside Plaspy without reproducing manufacturer configuration instructions.

Exact feature availability and the way data is reported to Plaspy can vary by firmware version, hardware revision, optional interface selection, installation type, and manufacturer implementation. Always verify device behavior against the manufacturer documentation for model specific details.

## Feature Overview

The XT-6300 is positioned as a flexible telematics device for vehicle and equipment tracking, with options for vehicle bus connectivity and expandability. It combines location reporting with diagnostic and motion sensing capabilities intended for fleet and equipment management workflows.

- High precision GPS location reporting for continuous tracking and route visibility
- OBDII and JBUS connectivity options for vehicle diagnostics and telematics data capture
- Script enabled firmware for custom data handling and event generation
- Built in cellular and GPS antennas to simplify installation and ensure reliable signal
- Motion sensing via a 3 axis accelerometer and motion detector for movement and activity detection

## Core Features of Xirgo - XT-6300

- GPS location engine providing precise positioning for tracking and geolocation services
- OBDII and JBUS communication interfaces to access vehicle diagnostic and bus data where implemented
- Embedded cellular and GPS antennas to support out of the box connectivity
- 3 axis accelerometer and motion detector for motion and impact related events
- Script enabled firmware that allows custom logic and event scripting on the device
- Optional Bluetooth functionality for wireless accessory or local device integration
- Support for Garmin FMI, general purpose IO, and 1 Wire bus interface for expanded telemetry and integrations
- Compatibility with XDMI device management platform for remote device administration and monitoring
