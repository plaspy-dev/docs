# Neomatica - ADM300 Features

This page provides a public, product-focused summary of the Neomatica ADM300 and how its documented capabilities map to use with the Plaspy fleet management platform. It explains the main, non-sensitive features relevant to tracking, telemetry, event logging, and integration into Plaspy workflows so fleet managers and integrators can evaluate operational fit.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer configuration. Use this page as a general guide and consult the manufacturer documentation for device-specific and up-to-date technical details.

## Feature Overview

The ADM300 is a compact on-board GNSS vehicle terminal designed for continuous fleet tracking, event reporting and long route history storage. Its open protocol and EGTS support make it suitable for integration into Plaspy-based systems for real-time monitoring and historical analysis.

- Real-time GNSS positioning using GPS and GLONASS for reliable location tracking.
- GPRS-based telemetry and event transmission to a fleet platform for live tracking and alerts.
- Local route history storage on internal memory with microSD expansion for long-term record retention.
- Built-in backup battery, tamper detection, and accelerometer-based movement detection to support anti-theft and movement monitoring.
- Multiple sensor inputs and an RS-485 interface for capturing external sensor states and device integration.

## Core Features of Neomatica - ADM300

- GPS and GLONASS reception with a high-sensitivity GNSS receiver for improved fix reliability.
- EGTS and open protocol compatibility enabling integration into third-party tracking platforms such as Plaspy.
- GPRS packet transmission for location, telemetry and event forwarding to a remote server.
- Internal non-volatile event logging with microSD support for extended route history storage.
- Built-in Li‑Ion backup battery to support continued operation during primary power loss.
- Three-axis accelerometer for movement detection and related event generation.
- Multiple telemetry inputs including analog and pulse inputs plus an RS-485 interface for external device data.
- Tamper detection via case opening and support for voice call capability for operator communication.

## How These Features Work with Plaspy

When integrated with Plaspy, the ADM300 reports position, telemetry and events so operators gain live visibility and historical context. Plaspy processes incoming device data and presents it through mapping, reporting and alerting tools for operational oversight.

- Live location updates appear on Plaspy maps for real-time vehicle tracking and route playback.
- Telemetry and sensor states from analog/pulse inputs and RS-485 are available for monitoring and rule-based alerts within Plaspy.
- Accelerometer events and tamper alerts can be surfaced as incidents or triggers for notifications and response workflows.
- Long-term route history stored on microSD or internal memory can be uploaded and reviewed in Plaspy for compliance and post-incident analysis.
- Remote firmware update capability over GPRS simplifies keeping devices aligned with Plaspy integration requirements.

## Typical Use Cases

- Fleet management for cars, trucks and mixed vehicle fleets requiring continuous location and route history.
- Anti-theft monitoring that combines tamper alerts, accelerometer movement detection and operator contact options.
- Sensor telemetry collection for external inputs such as door or equipment state monitoring.
- Long-route logging for vehicles operating across extended routes where on-board storage improves historical completeness.
- Special equipment tracking where compact form factor and durable GNSS reception are important.

## Feature Availability Notes

- Exact telemetry, sensor input behavior and event definitions depend on firmware version and manufacturer configuration.
- Hardware revisions and regional variants may change supported interfaces or physical characteristics.
- Installation choices and wiring determine which inputs, tamper detection and backup battery functionality are available in the field.
- MicroSD capacity limits and internal record counts depend on manufacturer specifications and may vary with firmware.

## Why Use Plaspy with These Features

Pairing the ADM300 with Plaspy brings practical operational value: Plaspy ingests the device’s real-time location and event streams and turns them into actionable visibility, alerts and historical reports. This combination supports routine fleet oversight, incident investigation, and day-to-day operational decisions without requiring deep protocol work thanks to the ADM300’s open protocol and EGTS compatibility.
