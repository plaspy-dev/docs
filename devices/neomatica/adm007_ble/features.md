# Neomatica - ADM007 BLE Features

This page provides a public feature summary for the Neomatica ADM007 BLE and how its capabilities are used with Plaspy. It focuses on practical, non-sensitive information about what the tracker can do when paired with Plaspy for location tracking, sensor telemetry, remote configuration, and historical route analysis.

Exact feature availability and behavior depend on the device firmware, hardware revision, installation method, regional variants, and the manufacturer's implementation. For the most current and device specific details, consult Neomatica documentation and firmware release notes.

## Feature Overview

The ADM007 BLE is a compact, plug-and-play GNSS tracker designed for fast installation via a vehicle cigarette lighter socket. It pairs GNSS positioning with Bluetooth Low Energy sensor support and local logging to deliver practical tracking and telemetry with low data use and simple deployment.

- Plug-and-play cigarette lighter installation for fast, non-invasive deployment
- GPS and GLONASS positioning with high sensitivity for reliable fixes in difficult conditions
- Bluetooth Low Energy support for up to eight wireless sensors to extend telemetry
- Low mobile data consumption and efficient power use for low operational cost
- Anti-jamming detection to help identify interference or tampering conditions
- Onboard route logging for thousands of records to preserve trip history when connectivity is intermittent

## Core Features of Neomatica - ADM007 BLE

- Cigarette lighter form factor for quick installation without permanent wiring
- GNSS positioning using GPS and GLONASS for accurate location reporting
- Bluetooth Low Energy sensor support for up to eight external wireless sensors
- Anti-jamming detection to notify of potential RF interference or tampering
- Local memory for extensive route logging to keep records during network outages
- Low mobile data usage and efficient current draw for economical operation
- Remote management options including FOTA updates and configuration via Bluetooth, SMS, or GPRS

## How These Features Work with Plaspy

When integrated with Plaspy, the ADM007 BLE reports location and supported sensor telemetry to the platform so teams can monitor assets, view history, and receive alerts. Plaspy aggregates position and sensor data into live maps, route reports, and operational dashboards for oversight and analysis.

- Live location updates and historical routes appear in Plaspy for fleet oversight
- BLE sensor readings reported alongside GNSS fixes are visible as telemetry in Plaspy
- Anti-jamming or interference events can be surfaced as alerts or markers in the platform
- Local route logs stored on the device synchronize with Plaspy when connectivity resumes
- Remote configuration and firmware update workflows can be coordinated to keep devices updated

## Typical Use Cases

- Rapid fleet deployment where vehicles need tracking without hardwiring or installers
- Anti-theft monitoring using discreet, removable installation and interference detection
- Cargo and cold-chain monitoring by pairing BLE temperature or humidity sensors to track environment alongside location
- Short-term rentals and subcontractor vehicles that require temporary, low-maintenance tracking
- Small commercial vehicle telemetry where basic environmental and location visibility supports operations
