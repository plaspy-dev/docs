# Neomatica

Neomatica is a maker of GPS tracking devices used across vehicle and asset monitoring applications. This page explains how Neomatica devices can work with Plaspy, what to expect from the devices in general terms, and how to find the right device for your use case. If you are evaluating trackers for fleet management, asset monitoring, or telematics projects, this page will help you connect Neomatica hardware to the Plaspy platform and get started.

## How Neomatica devices work with Plaspy

Plaspy collects location and telemetry from compatible trackers and presents the data in a single monitoring interface. Neomatica devices that are compatible with Plaspy send positional and status data using standard device reporting methods that Plaspy can ingest and interpret. Once a Neomatica device is configured to send data to Plaspy, you can view live location, history, and alerts inside the Plaspy platform.

Key integration points:
- Device configuration to point reports to Plaspy data ingestion endpoints.
- Mapping device telemetry fields to Plaspy sensors and channels.
- Using Plaspy features such as alerts, geofences, and reporting to act on incoming data.

For device specific setup instructions consult the device documentation available on the device page in this catalog or the official Neomatica site at https://neomatica.com/.
