# ADM500 NEW

The ADM500 NEW is a professional-grade GPS tracker engineered for vehicle and asset telematics. Supporting multi-constellation GNSS \(GPS, GLONASS, BDS and Galileo\) and LTE/GPRS cellular connectivity, the ADM500 delivers reliable real-time tracking and continuous telemetry for fleets, public transport, agricultural machinery and passenger cars. With a compact form factor, dual nanoSIM support and a 1000 mAh internal battery, this Plaspy compatible GPS tracker is built for persistent location accuracy and dependable data flow even during intermittent power conditions.

Designed for integration with modern telematics platforms, the ADM500 is Plaspy compatible through standard telematics protocols and flexible interfaces. Its extensive sensor support — wired and wireless fuel sensors, BLE peripherals, 1-Wire temperature probes, RS-485 devices and multiple I/O channels — makes it a versatile choice for fleet management, anti-theft systems, temperature-controlled transport and advanced telemetry applications.

## Key Highlights

- Plaspy compatible GPS tracker with multi-constellation GNSS for stable real-time tracking and up to 3 m accuracy in 95% of operation time.
- LTE/GSM/GPRS/EDGE communication with dual nanoSIM slots for redundant cellular connectivity and continuous telemetry.
- Flexible sensor ecosystem: supports wired/wireless fuel sensors, up to 5 Bluetooth Low Energy sensors, up to 8 DS18B20 probes and RS-485 peripherals.
- Robust anti-theft and security features including a three-axis accelerometer and signal jamming detection for tamper alerts.
- Built-in 1000 mAh battery for several hours of autonomous operation and on-device storage for up to 246,000 route records.
- Remote management via OTA GPRS updates and Bluetooth firmware updates plus configuration by Windows/Android tools, SMS and server commands.
- Multiple I/O for vehicle telemetry: ignition input, analog and pulse inputs and open-collector outputs suitable for remote control and immobilization strategies.

## How It Works with Plaspy

The ADM500 integrates with Plaspy by sending standardized location and telemetry packets over cellular networks and supporting common telematics protocols. Once connected, Plaspy receives live GPS coordinates, sensor telemetry and event-driven messages to power dashboards, alerts and historical reports. The device’s dual-SIM design and large on-device route memory help maintain data continuity for fleet management and security workflows.

- Real-time location and telemetry updates \(GNSS + cellular\) sent to Plaspy for mapping and live monitoring.
- Ignition status and analog input telemetry captured to feed driver behavior, engine run-time and event reports.
- Fuel monitoring support via wired/wireless sensors and RS-485 fuel sensors for accurate fuel consumption and refill/skim detection.
- Remote immobilizer/control: open-collector outputs can be used with Plaspy workflows to trigger immobilization or remote device control where supported.
- Bluetooth sensors and beacon detection \(BLE\) for temperature, humidity, tilt, Hall effect and queued iBeacon/Eddystone tags — all reported to Plaspy for asset condition monitoring.

## Use Cases

- Fleet management: continuous real-time tracking, route history and telemetry for trucks, vans and mixed fleets using Plaspy dashboards.
- Anti-theft and vehicle security: accelerometer-based movement detection, jamming alerts and remote control outputs to support immobilizer actions via Plaspy.
- Temperature-controlled transport: BLE temperature sensors and DS18B20 probes for refrigerated cargo monitoring and automated alerts in Plaspy.
- Fuel monitoring and fuel theft prevention: support for multiple wired/wireless fuel sensors and RS-485 fuel devices for detailed fuel consumption analytics.
- Stationary asset tracking and environment monitoring: battery-backed operation and BLE/1-Wire sensors make it suitable for semi-permanent asset installations.
