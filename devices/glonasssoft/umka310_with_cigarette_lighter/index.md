# GLONASSsoft - UMKa310 with cigarette lighter

![UMKa310 with cigarette lighter](./tracker.png)

The UMKa310 is a compact, cigarette-lighter plug-in GPS tracker designed for easy installation and reliable vehicle telemetry. Built to integrate with open hosting solutions, the UMKa310 supports EGTS and the Wialon Combine binary protocol and can transmit navigation and telemetry data to multiple endpoints—making it an effective Plaspy compatible GPS tracker for fleet management, real-time tracking, and anti-theft workflows.

The device combines low traffic consumption with high-frequency updates and flexible configuration options. With Bluetooth 4.0 for local setup, optional RS-485 support for fuel sensors, a 32-channel GNSS receiver, and the ability to send data simultaneously to up to three servers, the UMKa310 is suited to customers who need reliable telemetry, fuel monitoring, and event logging in a compact, plug-and-play form factor.

## Key Highlights

- Plaspy compatible via open protocols: EGTS support and Wialon Combine batch transfer enable straightforward integration with Plaspy and other cloud platforms.
- Real-time tracking with low data usage: batch mode transfer reduces traffic consumption while maintaining high-frequency location updates.
- Flexible telemetry and fuel monitoring: optional RS-485 interface supports connection to 1–3 fuel level sensors \(FLSs\) for fuel consumption data.
- Easy configuration: set up and control the unit over SMS, GPRS, or Bluetooth 4.0 for onsite or remote management.
- Black box recording: stores up to 10,000 records to preserve event history during coverage gaps.
- Compact, vehicle-friendly form factor: cigarette-lighter power design enables rapid deployment without hardwiring.
- EGTS and multi-server support: simultaneous transmission to three servers ensures redundancy for fleet management and anti-theft monitoring.

## How It Works with Plaspy

The UMKa310 integrates with Plaspy by sending GNSS coordinates and telemetry using open protocols supported by Plaspy-hosted backends. Its support for the EGTS protocol \(used in ERA-GLONASS systems\) and the Wialon Combine binary protocol means the tracker can forward position, speed, direction, and telemetry to Plaspy in formats the platform accepts. Batch-mode transfers reduce GPRS traffic while preserving frequent updates, and the unit can be configured remotely to align reporting intervals and alert thresholds with Plaspy workflows.

- Real-time location and telemetry updates suitable for Plaspy dashboards and maps.
- Simultaneous transmission to up to three servers—ideal for redundant Plaspy endpoints or split reporting.
- Fuel monitoring via optional RS-485 connections for 1–3 FLSs; data available to Plaspy for fuel consumption reporting.
- Black box storage of up to 10,000 records for event reconstruction if temporary connectivity or coverage gaps occur.
- Local configuration via Bluetooth 4.0 or remote configuration via SMS/GPRS to tailor behavior for Plaspy-based fleet management and anti-theft policies.
