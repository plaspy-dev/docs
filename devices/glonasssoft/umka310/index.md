# GLONASSsoft - UMKa310

![UMKa310](./tracker.png)

The UMKa310 GPS tracker is a compact, Plaspy compatible tracking device built for fleets and mobile assets that need reliable, low‑traffic real‑time tracking and telemetry. Designed to transmit GNSS coordinates and navigation data to GLONASSsoft cloud or any host with an open protocol \(including EGTS used by ERA‑GLONASS\), the UMKa310 delivers continuous location, speed and direction updates while minimizing data usage thanks to a batch transfer method based on the Wialon Combine open binary protocol.

The UMKa310 is purpose-built for integration with modern fleet management platforms such as Plaspy. It supports simultaneous data forwarding to up to three servers, flexible configuration via SMS, GPRS or Bluetooth 4.0, and optional RS‑485 support for fuel sensors. Whether you need real‑time tracking, telemetry, fuel monitoring or anti‑theft workflows, UMKa310 is a practical, Plaspy compatible choice for professional fleet operations and asset monitoring.

## Key Highlights

- Plaspy compatible GPS tracker: sends GNSS navigation data and telemetry to Plaspy or any open‑protocol host \(EGTS support included\).
- Low data consumption: batch transfer using Wialon Combine protocol enables high frequency updates with reduced traffic.
- Simultaneous multi‑server transmission: can forward data to up to three servers at once for redundancy or parallel services.
- Fuel monitoring ready: optional RS‑485 interface supports connecting 1–3 FLS sensors for fuel consumption telemetry.
- Flexible configuration: remotely configure and control the device via SMS, GPRS or Bluetooth 4.0.
- Compact, rugged form: small dimensions, 40 g weight and IP54 ingress protection for vehicle and asset installations.
- Onboard telemetry and memory: accelerometer, intelligent power management and black box storage up to 10,000 records.

## How It Works with Plaspy

Integration with Plaspy is straightforward: the UMKa310 streams GNSS and telemetry data using open and standardized protocols, so Plaspy can ingest location, movement and status data in near real time. The device's batch transfer approach keeps network usage low while allowing frequent updates. Configure the device to forward data directly to your Plaspy server endpoint or to GLONASSsoft/EGTS endpoints as part of your fleet management architecture.

- Real‑time location and telemetry updates: GNSS coordinates, speed and heading are sent to Plaspy for live tracking and history playback.
- Simultaneous server forwarding: send the same stream to Plaspy plus backup/cloud servers for redundancy.
- Fuel monitoring: supports RS‑485 connection of 1–3 FLS sensors so Plaspy can display fuel levels and consumption trends.
- Event and motion detection: onboard accelerometer streams movement events and can trigger alerts in Plaspy for potential incidents or anti‑theft actions.
- Local configuration and diagnostics: device settings are manageable via SMS, GPRS or Bluetooth 4.0 for field technicians and administrators.

## Use Cases

- Fleet management and real‑time tracking: monitor vehicle locations, routes and speed in Plaspy to improve dispatching and routing efficiency.
- Fleet anti‑theft and immobilization workflows: use discrete inputs and open collector output to integrate with vehicle circuits for status monitoring and remote immobilizer control when wired into vehicle systems.
- Fuel monitoring and telemetry: connect RS‑485 fuel level sensors \(1–3 FLS\) to collect fuel data and feed it into Plaspy for consumption reporting and anomaly detection.
- Door, alarm and event monitoring: discrete inputs capture door/open events, alarms or other digital signals and report them to Plaspy for event‑based alerts.
- Bluetooth sensor integration: leverage Bluetooth 4.0 for local configuration and to pair BLE sensors for temperature, cargo monitoring or presence detection where supported.
