# CanTrack - TK200AM Features

This page provides a public feature context for the CanTrack TK200AM and how it can be used with Plaspy for fleet and asset monitoring. It summarizes the device capabilities that are relevant to Plaspy users and explains practical operational value without reproducing private configuration steps.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional variant and manufacturer configuration. For device specific parameters and the latest technical details consult the manufacturer documentation and release notes.

## Feature Overview

The TK200AM is an ultra-compact, Plaspy compatible GPS tracker designed for long-term asset tracking and concealed anti-tamper installations. Its design optimizes battery life for long standby intervals while offering a switchable higher-frequency tracking mode for urgent or real-time needs.

- Ultra-compact low-profile enclosure intended for discreet installation on vehicles, motorcycles, containers and other assets.
- Dual reporting strategy with an energy saving low-frequency mode and a switchable real-time tracking mode for immediate updates.
- Multi-method positioning that combines GPS with supplemental LBS and Wi‑Fi positioning for faster fixes in urban or obstructed environments.
- Built-in anti-tamper alarm that can wake the unit and trigger an immediate location update when the device is detached or protective film is removed.
- GSM/GPRS connectivity using TCP/IP for uplink of position packets and device status to Plaspy-compatible backends.
- Wake-on-demand and remote control via the vendor platform or app to retrieve immediate location without continuous high-frequency reporting.

## Core Features of CanTrack - TK200AM

- Compact form factor suitable for concealed placements and installations where size and weight matter.
- High-sensitivity GNSS engine for reliable GPS fixes under a range of operating conditions.
- Supplemental LBS and Wi‑Fi assisted positioning to improve fix time and coverage in challenging environments.
- Energy optimized reporting modes that allow multi-month standby under low-duty cycles and a switchable real-time mode for high-frequency tracking.
- Tamper detection and alarm functionality that generates a location update when tampering is detected.
- GSM/GPRS data transmission using standard TCP/IP for interoperability with Plaspy and similar platforms.
- Remote wake and platform-driven update capability to balance battery life with on-demand visibility.
- Designed for long-term asset monitoring with a sealed enclosure for low-maintenance deployments.

## How These Features Work with Plaspy

When integrated with Plaspy, TK200AM location and event data become part of centralized dashboards, alerts and historical reporting. Plaspy ingests position and status uploads so fleet managers can view location history, respond to tamper events and switch reporting profiles as needed.

- Location and movement reports from the TK200AM appear in Plaspy for real-time or scheduled monitoring depending on the device mode.
- Tamper alerts from the device can be surfaced as notifications and event records inside Plaspy for faster response.
- Wake-on-demand from the platform lets operators request an immediate position without leaving the tracker in continuous high-power mode.
- Plaspy can combine TK200AM feeds with other telemetry sources available to your fleet for consolidated mapping and reporting.
- Historical route playback and exportable reports in Plaspy support audits and post-incident review using TK200AM data.

## Typical Use Cases

- Long-term monitoring of low-activity assets where long battery standby reduces maintenance and servicing frequency.
- Concealed anti-theft installations on rental cars, service vehicles or high-value equipment to detect tamper events and recover assets.
- Motorcycle and bicycle tracking where small form factor and discreet placement are required.
- Container and logistics monitoring where periodic updates preserve battery life during transit and storage.
- Insurance telematics and risk management scenarios that combine location history and tamper events for verification purposes.
