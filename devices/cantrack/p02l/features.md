# CanTrack - P02L Features

This page provides a public feature overview for the CanTrack P02L and explains how its capabilities map to monitoring and management in Plaspy. It focuses on user facing functions, safety features, and the operational value you can expect when the P02L streams location, status, and alarm data into Plaspy.

Exact feature availability and behaviour can vary by firmware version, hardware revision, installation type, regional variant, and manufacturer implementation. Where appropriate this page highlights practical uses of the device in Plaspy, but always consult the manufacturer for the most current device specific details.

## Feature Overview

The P02L is a compact 4G personal tracker designed for real time location and voice enabled safety communications. It combines multi constellations for positioning, mobile data for telemetry and intercom voice support to deliver location awareness and two way communication for individuals and small teams.

- Real time GPS plus BeiDou assisted location with LBS fallback for persistent positioning in varied coverage areas.
- Global walkie talkie intercom and standard voice call support for long range two way voice communication.
- Dedicated safety functions including SOS panic button and fall down detection for rapid alerting.
- Low power operation and a rechargeable battery for extended field use with timed wake and sleep schedules.
- Bluetooth accessory support and a step counter for basic activity telemetry and local sensor pairing.
- OTA firmware updates and SMS command support for remote configuration and group management.

## Core Features of CanTrack - P02L

- Multi constellation positioning using GPS and BeiDou with assisted LBS for improved fix availability.
- 4G LTE data connectivity for continuous telemetry and near real time reporting.
- Global intercom (walkie talkie) functionality and voice call support over the mobile network.
- SOS and panic button reporting for priority alarms.
- Fall down detection and configurable wake sleep schedules for battery optimisation and safety monitoring.
- Built in step counter and 6 axis motion sensing for activity awareness.
- Bluetooth support for accessory pairing and local sensor integration.
- Remote management via OTA firmware updates and SMS command interface.

## How These Features Work with Plaspy

When a P02L is registered with Plaspy it can stream position fixes, alarm events and supported telemetry into the Plaspy platform for monitoring and historical review. Plaspy automatically detects compatible tracker protocols so reported data appears in the same monitoring environment as other devices.

- Real time location updates and historical tracks for mapping and route review inside Plaspy.
- Priority alarm handling in Plaspy for SOS, panic and fall down events so dispatchers and caregivers can be notified.
- Activity and motion telemetry such as step counts and motion status displayed alongside location for context.
- Visibility of intercom or voice related events as contextual information for team coordination.
- Remote configuration and group level changes reflected through OTA or SMS management workflows to simplify device lifecycle handling.

## Typical Use Cases

- Personal safety monitoring for seniors and children with SOS and fall down alerts sent to Plaspy for caregiver response.
- Outdoor recreation and hiking where real time tracking and global intercom help group coordination and emergency voice contact.
- Lone worker safety with panic button reporting and remote configuration for supervisors using Plaspy.
- Guided tours or small field teams that benefit from centralized tracking plus intercom based group communication.
- Compact wearable deployments where Bluetooth accessory pairing provides optional local sensor data.
