# CanTrack - TK102 Features

This page provides a public overview of the CanTrack TK102 feature set and how those capabilities relate to use with the Plaspy platform. It is written to describe observable, user-facing functions of the tracker and to explain how location and event data from the device can be used inside Plaspy for monitoring and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional variant, and manufacturer implementation. Where appropriate the content stays at a practical level; for device specific configuration steps, the manufacturer documentation should be consulted.

## Feature Overview

The CanTrack TK102 is a compact GPS tracker that uses GPS satellite positioning together with GSM and GPRS networks to provide location and event reporting. It supports both direct SMS location reporting to an authorized phone and data transmission over GPRS to an internet server for real time tracking. The device also includes built in alarms and a voice monitoring capability that can be activated by calling the device.

- Real time location reporting via GPRS to an internet server for tracking on a computer
- SMS location reporting to an authorized mobile number for quick mobile checks
- Remote voice surveillance by calling the device number to listen to the device surroundings
- Geo fencing, movement, speeding, SOS, low voltage, and vibration alarms for event alerts
- TF card support for local data storage when network connectivity is unavailable
- Discreet mounting options such as magnetic cover and waterproof bag for covert placement

## Core Features of CanTrack - TK102

- GPS position fixes for location tracking and route reporting
- GSM GPRS data transmission for sending location and event data to a server
- SMS-based position queries and location replies to authorized numbers
- Voice surveillance feature activated by remote call to the device number
- Geo fence alarm to notify when device leaves or enters a defined area
- Movement and vibration alarms to detect unauthorized motion
- Speeding alarm to indicate when configured speed thresholds are exceeded
- SOS alarm and low voltage alarm for emergency and power status notifications

## How These Features Work with Plaspy

Plaspy can receive and display location and event data reported by the TK102, providing a centralized interface for live monitoring, history, and alerting. Plaspy automatically recognizes supported tracker protocols and shows device positions and events on maps and in device timelines, making device reports actionable for fleet and asset oversight.

- Location updates received via the tracker GPRS reports are shown as live positions in Plaspy
- Geo fence and movement events reported by the device appear as time stamped alerts in Plaspy
- SOS and low battery alarms can be surfaced in Plaspy to support rapid follow up and workflows
- Historical position data stored on the device TF card can complement server records when connectivity is intermittent
- Voice surveillance is a device level feature triggered by call and is outside the Plaspy data stream, but location and event logs provide context for any monitoring activity

## Typical Use Cases

- Vehicle rental and fleet tracking for monitoring location and trip history
- Personal safety and monitoring for children, elderly, or vulnerable individuals
- Asset tracking for portable or high value equipment requiring periodic location reports
- Security or investigative contexts where lawful tracking and discrete placement are required
- Real time monitoring that combines server reporting with local backup via TF card
- Alerting workflows that rely on SOS, movement, or low voltage notifications

## Feature Availability Notes

- Firmware differences across units can change alarm behavior, reporting intervals, and supported commands
- Hardware revisions and regional GSM variants may affect network compatibility and feature availability
- Installation and wiring choices can influence which alarms or power related features are active
- TF card logging depends on the card presence and configuration and may not be enabled by default
- Manufacturer settings and SIM card service plan can change how SMS and GPRS reporting operate

## Why Use Plaspy with These Features

Using Plaspy with the CanTrack TK102 consolidates device reports into a single operational dashboard where location, alerts, and history are visible alongside other devices. This improves situational awareness for fleet operators, security teams, and caretakers by turning raw device messages into contextual events, maps, and timelines that support decision making.
