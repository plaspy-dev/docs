# CanTrack - G900LM-4G Features

This page provides a public feature overview for the CanTrack G900LM-4G and how those capabilities are used with Plaspy for real time tracking and fleet management. It focuses on the practical, non sensitive aspects of the device that are relevant when integrating with Plaspy for continuous location updates, alarms, and remote control workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific configuration and the latest technical detail please consult the manufacturer documentation and any release notes provided by CanTrack.

## Feature Overview

The G900LM-4G is a compact, hard wired vehicle tracker designed for cars, trucks and commercial vehicles. It combines multi band LTE/GSM connectivity with high sensitivity GNSS and an internal backup battery to maintain tracking and alarm reporting in common vehicle environments.

- Real time vehicle tracking and continuous telemetry reporting for live map visibility and historical playback
- Multiple alarm types including movement detection, ignition on off alerts, speeding and angle change notifications for operational awareness
- Flexible installation with 4 pin and 8 pin wiring variants and a wide operating voltage range suitable for mixed fleet deployments
- Optional remote relay control to cut fuel or electrical power, enabling immobilizer style response when integrated with Plaspy
- Broad multi band LTE/GSM support and GT06 series protocol compatibility for straightforward platform integration

## Core Features of CanTrack - G900LM-4G

- Multi band LTE/GSM connectivity for regional deployments and data reporting
- High sensitivity GNSS receiver supporting precise location with industry grade accuracy
- Internal backup battery to preserve short term tracking and alarm reporting during vehicle power loss
- 4 pin and 8 pin wiring variants to support a range of installation scenarios
- Ignition input support and ignition on off alerts for driver and vehicle state monitoring
- Movement detection, speeding alerts, and angle change alarms for security and safety monitoring
- Remote relay control capability for fuel or power cut when installed and authorized
- GT06 series protocol compatibility for widely supported telematics integration

## How These Features Work with Plaspy

Plaspy receives location and event data from the G900LM-4G and presents it in centralized dashboards and maps for fleet operations. When configured, the device reports telemetry that Plaspy uses for alerting, historical playback, and operational reports.

- Live position updates and historical tracks shown on Plaspy maps for dispatch and route review
- Alarm events such as ignition changes, movement detection, speeding, angle changes, and power cut reported into Plaspy for immediate notification and audit
- Optional relay control can be triggered through Plaspy workflows to disable fuel or power when authorized by an operator
- Remote configuration commands and platform based settings allow reporting intervals and alarm toggles to be adjusted centrally via Plaspy
- Short term backup battery events and power loss are visible in Plaspy to aid in tamper detection and recovery workflows

## Typical Use Cases

- Fleet management and dispatcher visibility for route monitoring, utilization, and ETA tracking
- Anti theft and immobilization scenarios using movement and power cut alerts combined with remote relay control
- Delivery and logistics operations requiring location accuracy and speed or angle alerts for last mile verification
- Mixed fleet deployments where a small form factor and wide voltage compatibility simplify installations across vehicle types
- Remote enforcement and recovery workflows that combine alarm reporting with Plaspy based operator response

## Feature Availability Notes

- Feature behavior can differ by firmware version and hardware revision; not all features may be available on every unit
- Some capabilities such as relay control require appropriate wiring and installation during device fitment
- Regional variants of the device may use different LTE band combinations; confirm band support for your deployment region
- Manufacturer commands and supported configuration options are subject to change; review official CanTrack documentation for the latest command set
- Integration behavior inside Plaspy can vary depending on device configuration and reporting intervals set on the tracker

Using the CanTrack G900LM-4G with Plaspy gives operational teams centralized visibility into vehicle location, status, and alarm events. Plaspy consolidates telemetry from compatible devices into live maps, alerts, and historical reports that help fleets reduce risk, respond to incidents, and improve utilization.
