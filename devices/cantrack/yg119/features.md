# CanTrack - YG119 Features

This page provides a public feature overview for the CanTrack YG119 and how its capabilities are used with Plaspy. It focuses on user facing functionality and operational value such as position reporting, in field recovery aids, alerts, and how those inputs appear in the Plaspy platform for monitoring and history.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. Where precise device behavior matters for your setup, consult the official CanTrack documentation and verify firmware details before deployment.

## Feature Overview

The YG119 is a compact rechargeable tracker tailored for hunting dogs and active pets. It delivers periodic or movement triggered position uploads and includes practical recovery features that turn location fixes into actionable events for handlers using Plaspy.

- Real time position uploads based on movement or user configured reporting interval to support continual tracking or conserve battery
- Remote voice listen and an audible buzzer to assist on site recovery and locating in dense outdoor environments
- Long endurance rechargeable battery designed for extended field use between charges
- Multi band cellular connectivity for broad network availability across regional variants
- Geo fence alerts and low battery warnings to improve operational awareness during outings

## Core Features of CanTrack - YG119

- Plaspy compatible position uploads using cellular data and standard TCP IP reporting
- Movement triggered reporting and configurable time interval uploads to balance update frequency and battery life
- Remote voice listen functionality for situational audio on command
- Audible buzzer that can be triggered to help locate a nearby animal
- Geo fence alert support for perimeter monitoring and instant notifications
- Low battery warning reports to prompt recharge actions and avoid unexpected downtime
- Rugged compact form factor built for outdoor use with practical power saving modes

## How These Features Work with Plaspy

The YG119 sends location and event data to Plaspy where the platform converts those inputs into live tracking, notifications, and historical records. Plaspy receives the device uploads and makes them visible through map views and event logs so handlers can act quickly.

- Live location streaming and periodic position updates are displayed on Plaspy maps and device tracks
- Movement triggered and interval reports become events in Plaspy allowing for activity based monitoring
- Geo fence events are captured and routed as notifications to users for immediate awareness
- Low battery and status reports are shown in Plaspy so operators can schedule recharges or replacements
- Remote listen and buzzer activations are recorded as events to support recovery workflows and after action review

## Typical Use Cases

- Tracking hunting dogs in forests and fields with accurate fixes and on site locating tools
- Recovering a lost pet using the mix of map location, remote voice listen, and buzzer actions
- Monitoring working animals across large properties where battery life and intermittent updates matter
- Reviewing location history after training or field sessions to evaluate routes and coverage
- Maintaining situational awareness for handlers who need instant alerts when animals cross boundaries

## Feature Availability Notes

- Feature availability depends on device firmware and the specific hardware revision shipped for a region
- Regional variants may differ in cellular band support and network behavior; check the model label and documentation
- Installation and mounting on an animal can affect GNSS reception and reported accuracy in dense vegetation
- Manufacturer firmware updates can add, change, or refine features such as reporting logic and power modes
- For precise behavior and configuration steps consult the official CanTrack documentation for your YG119 unit
