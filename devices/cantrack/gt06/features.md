# CanTrack - GT06 Features

This page describes the public feature context for the CanTrack GT06 GPS tracker and how its capabilities are commonly used with Plaspy for vehicle tracking and monitoring. It focuses on practical, user facing functions such as location reporting, alarm signals, and the ways that tracking data can be transmitted for real time oversight.

Exact feature availability for any individual GT06 unit can vary by firmware version, hardware revision, optional configuration, and installation method. Where the GT06 supports multiple options those settings and behaviors are set by the installer or manufacturer and should be verified against the device documentation.

## Feature Overview

The CanTrack GT06 is a compact vehicle tracker that uses GPS and the GSM GPRS network to provide location and alarm reporting. It supports both SMS based location messages and GPRS reporting to an internet server for real time tracking on a computer or phone, and includes several built in alarm functions to support vehicle security and operational monitoring.

- Real time location reporting via GPRS to an internet server for live tracking
- SMS location messages to authorized phone numbers for quick checks
- Alarm reporting including overspeed, ACC anti theft, SOS, and power failure
- Real time voice monitoring and optional two way calling for situational awareness
- Optional remote cut vehicle oil or circuit function for asset protection
- Quad band GSM support for broad regional cellular compatibility

## Core Features of CanTrack - GT06

- GPS position acquisition for latitude longitude reporting
- GSM GPRS data transmission to a server for real time tracking
- SMS based location queries and alerts to preconfigured authorized numbers
- Overspeed alarm to indicate if a vehicle exceeds a set speed threshold
- ACC anti theft alarm to report ignition or vehicle power state changes
- SOS alarm to notify authorized contacts of an emergency condition
- Real time voice monitoring function for remote listening when enabled
- Built in backup battery to detect and report power failure events
- Optional two way calling and optional vehicle oil or circuit cut feature

## How These Features Work with Plaspy

Plaspy receives location and event data reported from the GT06 and presents those events and positions on maps and in device timelines. Plaspy automatically detects common tracker protocols and can show the GT06 location and alarm information in the platform without requiring users to decode raw device messages.

- Live map location for vehicles reporting to Plaspy via GPRS
- Alerts and event markers for overspeed, SOS, and power loss visible in Plaspy
- Event timelines and recent history to review alarm sequences and position fixes
- Support for SMS based workflows as a complementary channel depending on installation
- Optional voice events or call related notes surfaced in the device activity log when supported

## Typical Use Cases

- Fleet management and dispatching for light commercial vehicles
- Vehicle rental tracking and return monitoring
- Asset protection and theft response for high value vehicles
- Executive and personnel transport monitoring for situational awareness
- Remote monitoring of vehicle power state and alarm events
- Situations where a combination of SMS fallback and GPRS reporting is useful

## Feature Availability Notes

- Firmware and configuration changes can enable or disable particular alarms and optional features
- Optional functions such as two way calling and oil or circuit cut depend on the device variant and installer wiring
- Regional cellular performance depends on SIM selection and local GSM service
- Hardware revisions and manufacturer settings may affect voice monitoring behavior and alarm thresholds
- Always confirm exact feature support for a purchased unit with official manufacturer documentation

## Why Use Plaspy with These Features

Using the CanTrack GT06 with Plaspy gives organizations a practical way to convert the device's GPS and GSM reporting into operational visibility. Plaspy consolidates incoming position fixes and alarm signals into maps, timelines, and alerting views so fleet managers and operators can monitor location, respond to security events, and review historical movement.
