# CanTrack - GT06

![GT06](./logo.jpg)

The CanTrack GT06 \(also known as TK100\) is a GPS tracker that utilizes the existing GSM/GPRS network and GPS satellites to locate and monitor remote targets. It is designed for easy and compact use in vehicle tracking applications. With its built-in GPS and GSM module, it can capture GPS data and send it to authorized mobile numbers via SMS. Users can view the current location on their phones or track the location on Google Earth or Google Maps. Additionally, GPS data can be transmitted by GPRS to an internet server for real-time tracking on a computer.

This GPS tracker has a wide range of applications, including vehicle rental and fleet management, protecting valuable assets, providing peace-of-mind for businessmen, and managing personnel. It offers various features to enhance tracking and security, such as real-time tracking location via SMS/GPRS, overspeed alarm, ACC anti-theft alarm, SOS alarm, real-time voice monitoring function, and a built-in backup battery for power failure alarm. Optional features include two-way calling and the ability to cut vehicle oil or circuit.

Outstanding features of the CanTrack GT06 \(TK100\) GPS tracker:

- GSM quad-band frequency for global use
- Real-time tracking location by SMS/GPRS
- Recover original password
- Set authorized numbers
- Overspeed alarm
- ACC anti-theft alarm
- SOS alarm
- Real-time voice monitoring function
- Built-in backup battery for power failure alarm
- Optional feature: Cut vehicle oil or circuit
- Optional feature: Two-way calling
