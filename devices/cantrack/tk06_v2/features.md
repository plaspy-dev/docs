# CanTrack - TK06 v2 Features

This page summarizes the public feature context for the CanTrack TK06 v2 and how those features relate to use with Plaspy. It focuses on practical, user facing capabilities such as location reporting, SMS alerts, GPRS reporting, and common vehicle tracking functions so you can understand what to expect when integrating this model with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, optional accessories, and installation method. For device specific commands, configuration options, and the latest firmware details refer to the manufacturer documentation and release notes.

## Feature Overview

The TK06 v2 is a compact vehicle tracker designed to report location and status over GSM networks and GPS satellites. It supports both direct SMS alerts to authorized mobile numbers and GPRS reporting to internet servers, enabling real time monitoring on mapping platforms or fleet systems.

- Real time location reporting via SMS for direct phone alerts
- GPRS reporting to an internet server for live tracking and computer based monitoring
- Compatibility with mapping platforms such as Google Maps or Google Earth for visual location checks
- Voice monitoring capability for listening to the vehicle environment remotely
- Alarms for overspeed, power failure, and ACC related events to signal potential issues
- Optional backup battery and external relay support for additional anti theft or vehicle control functions

## Core Features of CanTrack - TK06 v2

- GPS location capture using satellite positioning for periodic or event driven tracking
- GSM quad band support for broad regional network compatibility
- SMS based location and alert messages sent to authorized phone numbers
- GPRS data transmission to remote servers for continuous online tracking
- Real time voice monitoring function to enable remote audio listening when enabled
- Overspeed alarm to notify when configured speed thresholds are exceeded
- Power failure alarm and optional internal backup battery to detect loss of main power
- ACC anti theft alarm and external relay connectivity to interface with vehicle circuits when installed

## How These Features Work with Plaspy

Plaspy receives and processes location and status reports from compatible trackers like the TK06 v2 so fleet managers and operators can monitor assets centrally. When TK06 v2 is configured to send GPRS data to a tracking server, Plaspy will surface the device position and events in the platform for visibility and historical review.

- GPRS reports from the tracker can be directed to Plaspy so locations appear on the Plaspy map
- SMS alerts remain useful for direct phone notifications while Plaspy provides consolidated event logs
- Alarms such as overspeed and power loss reported by the device are shown as events inside Plaspy for operational awareness
- Voice monitoring capability is a device level feature; any related event or status can be recorded as a device note in Plaspy
- Plaspy automatically detects common tracker protocols and can accept connections directed to the platform domain for integration

## Typical Use Cases

- Fleet management for rental cars and light commercial vehicles requiring periodic location updates
- Motorcycle, scooter, or bike anti theft tracking with immediate alerts and location lookups
- Real time monitoring of vehicle movements for dispatch and logistics coordination
- Personnel or mobile asset tracking where compact vehicle mounted devices are preferred
- Situations where both phone based SMS alerts and server based real time tracking are useful

## Feature Availability Notes

- Some features may be optional or depend on a specific hardware revision or firmware level from the manufacturer
- Voice monitoring, external relay control, and backup battery behavior are subject to local regulations and device configuration
- SMS behavior and GPRS reporting require an active SIM with appropriate network coverage and data plan
- Installation wiring and vehicle integration affect availability and reliability of alarms such as ACC and power failure
- Always confirm the exact feature set and any regional variants with the manufacturer documentation

Using the CanTrack TK06 v2 with Plaspy gives organizations a way to centralize location data, alarms, and operational status from devices that support SMS and GPRS reporting. Plaspy aggregates incoming reports, displays device positions on maps, and retains event history to help with oversight, route analysis, and incident follow up.
