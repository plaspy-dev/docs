# CanTrack - TK06 v2

<div className="device-logo">
![TK06 v2](./logo.jpg)
</div>

The CanTrack TK06 v2 is a compact GPS tracker designed for vehicle tracking and general asset monitoring. It combines GPS satellite positioning with the GSM GPRS network to determine location and deliver that data to authorized recipients. The device supports sending location updates by SMS and can transmit tracking data to an internet server for real time viewing on mapping platforms.

As a Plaspy compatible device, the TK06 v2 can be integrated into Plaspy's fleet monitoring environment to provide centralized visibility over vehicles and tracked assets. Its ability to report location data to a server and to send SMS updates makes it suitable for both live monitoring through Plaspy and simple phone based tracking workflows, giving fleet managers and operators flexible options for oversight.

## Key Highlights

- Compact form factor suitable for vehicle installation and discreet placement.
- Dual reporting modes: SMS messaging and GPRS data upload to a remote server.
- Built in GPS and GSM modules for location fix and network transmission.
- Practical alarms and monitoring features including overspeed and power loss alerts.
- Voice monitoring function and ACC anti theft alarm to support security workflows.
- Optional backup battery and external relay support for circuit control in vehicle use.

## How It Works with Plaspy

When connected to Plaspy, the TK06 v2 sends its location data to a Plaspy configured server endpoint, allowing Plaspy to process and display that data alongside other fleet assets. Plaspy can consolidate the incoming positions and event messages into a single operational view to support tracking and decision making.

- Real time location display for vehicles on Plaspy maps using the device's GPRS uploads.
- Alerts and event handling such as overspeed or power failure surfaced within Plaspy for operator attention.
- Historical route and movement logging in Plaspy to support reporting and operational reviews.
- Centralized fleet monitoring to view multiple TK06 v2 units together with other devices.
- SMS fallback information can be used for quick location checks when server upload is not available.

## Typical Use Cases

- Vehicle rental and fleet management where centralized location and status visibility is required.
- Anti theft protection and recovery support for motorcycles, scooters, and bicycles.
- Real time tracking of small commercial vehicles and delivery fleets.
- Personnel or asset tracking in operations where compact vehicle trackers are preferred.
- Situations requiring both server side monitoring and direct SMS location updates.
