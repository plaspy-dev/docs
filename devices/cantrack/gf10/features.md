# CanTrack - GF10 Features

This page provides a public feature summary for the CanTrack GF10 finger tracker and explains how those features are reflected when the device is used with Plaspy. It focuses on user-facing capabilities and practical uses rather than detailed configuration steps.

Exact feature availability and behavior can vary with firmware version, hardware revision, installation method, and the manufacturer's implementation. For the latest device-specific technical details consult the official manufacturer documentation linked at the end of this page.

## Feature Overview

The CanTrack GF10 is a compact finger-sized GPS tracker that combines GPS, LBS, and AGPS positioning with several on-device alerts and power management modes. It is designed for discreet placement and continuous monitoring where small form factor and basic tamper awareness matter.

- Real-time position updates using GPS with supplementary LBS and AGPS for faster fixes
- Compact and discreet finger-sized form factor for easy concealment or attachment
- Geofence support to generate enter and exit alerts for predefined areas
- Vibration alarm to indicate movement or possible tampering
- Low battery alarm and power-saving sleep modes to extend operating time
- Memory storage of location data when network signal is lost for later upload

## Core Features of CanTrack - GF10

- GPS, LBS, and AGPS hybrid positioning for improved fix time and coverage
- Real-time reporting accessible via SMS, platform, or mobile app
- Geofence capability for virtual boundary monitoring and alerts
- Vibration alarm to detect movement or tampering events
- Low battery alarm to notify when device power is low
- Power-saving and sleep modes to maximize standby time
- Periodic or on-demand GPS activation for fixed tracking intervals
- Local memory storage to retain location logs when GSM signal is unavailable

## How These Features Work with Plaspy

Plaspy presents the GF10's reported data in a centralized tracking platform so teams can monitor location, alerts, and recent history from a single view. Plaspy is built to accept standard tracker reports and will reflect the GF10's events and stored uploads as they arrive.

- Real-time location updates and historical tracks displayed on Plaspy maps
- Geofence events shown in the platform as enter and exit alerts for configured areas
- Low battery notifications surfaced so operators can plan maintenance or replacement
- Movement or vibration events logged so tampering or unexpected motion is visible
- Stored location points uploaded after signal restoration are incorporated into history and reports

## Typical Use Cases

- Discreet tracking of small assets and personal belongings where size matters
- Monitoring of loaned equipment or rented items for location oversight
- Temporary location monitoring for short term assignments or events
- Supplementary vehicle tracking where a compact device is required
- Caregiver or family location awareness in nonmedical contexts

## Feature Availability Notes

- Hardware revisions or regional variants may add or omit certain functions
