# CanTrack - G200 Features

This page describes the public feature context for using the CanTrack G200 tracker with Plaspy. It focuses on practical capabilities and how those functions appear in Plaspy for monitoring, alerts, and historical review. The content here is intended to help technical users and fleet managers understand what to expect when pairing a G200 device with the Plaspy platform.

Exact feature availability and behavior can vary with firmware version, hardware revision, installation method, and manufacturer configuration. Where specifics matter for installation or advanced configuration, verify current device documentation from the manufacturer and confirm settings when you register the device in Plaspy.

## Feature Overview

The CanTrack G200 is a compact magnet GPS tracker designed for vehicle and asset tracking with a focus on long standby life and reliable positioning. It supports multiple positioning methods and includes a set of alerting and storage features that keep tracking operational even when network conditions vary.

- Real-time and power-saving tracking modes to balance update frequency and battery life
- Multiple positioning methods including GPS and LBS for improved availability in different environments
- Ultra-long standby capability of up to 45 days for long-term, intermittent tracking scenarios
- Anti-tamper alert and overspeed notification to support security and safety monitoring
- Geo-fencing support to define areas of allowed or restricted movement
- Local memory data storage that preserves position records when cellular coverage is unavailable

## Core Features of CanTrack - G200

- Real-time tracking with configurable update modes for active monitoring
- Power-saving tracking and sleep behavior when parked to extend standby life
- Ultra-long standby up to 45 days under specified conditions for long deployments
- Multiple positioning options including GPS and LBS to improve fix availability
- Anti-tamper alarm to notify when the device is removed or disturbed
- Geo-fencing capability to trigger alerts when boundaries are crossed
- Overspeed alert for speed threshold monitoring
- Onboard memory data storage to record positions during temporary GSM outages

## How These Features Work with Plaspy

Plaspy collects, displays, and notifies on the events and location data reported by the G200 so teams can monitor assets and respond to incidents. Plaspy automatically detects many common tracker protocols and exposes device-reported events and locations in the platform for immediate use.

- Live location updates and map visualization based on the device's real-time reports
- Event notifications in Plaspy for tamper alerts, overspeed conditions, and geo-fence entries or exits
- Historical playback and trip review using uploaded position records and memory data once the device reconnects
- Device status and mode visibility to show when the tracker is in power-saving or active reporting mode
- Alerts and reporting configured inside Plaspy to match operational thresholds and workflows

## Typical Use Cases

- Discreet vehicle tracking and recovery using the compact magnet design
- Long-term asset monitoring where extended standby time reduces maintenance visits
- Fleet safety monitoring with overspeed alerts and geo-fence rule enforcement
- Remote asset oversight where intermittent GSM coverage requires local data buffering
- Temporary installations that need a low-profile tracker with sleep and power-saving modes

## Feature Availability Notes

- Firmware and hardware revisions can change exact behavior for reporting intervals and power management
- Regional cellular network differences may affect LBS accuracy and GPRS connectivity
- Installation location and antenna placement influence GPS fix quality and sleep behavior
- Device memory storage behavior depends on how and when the tracker uploads buffered records
- Confirm supported features and configuration options against the manufacturer documentation

Using the CanTrack G200 together with Plaspy gives organizations a practical way to turn device-reported positions and events into operational insight. Plaspy provides centralized maps, historical playback, and configurable alerts so teams can monitor movement, respond to tamper or overspeed events, and review recorded trips when the tracker is back online.
