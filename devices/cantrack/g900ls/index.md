# CanTrack - G900LS

![G900LS](./tracker.jpg)

The G900LS is a professional 4G hard-wiring GPS tracker designed for vehicle owners and fleet operators who need precise, reliable positioning and remote control. Plaspy compatible out of the box, the G900LS delivers real-time tracking, rich telemetry, and configurable alarms so operations teams and dispatchers see vehicle location, ignition status, and critical events on the Plaspy web platform or mobile app.

Built as a global LTE/GSM device with both 4-pin and 8-pin installation options, the G900LS supports high-accuracy GPS and a robust set of vehicle inputs and remote commands. Whether your priority is fleet management, anti-theft protection, or rental and leasing oversight, this tracker integrates with Plaspy to give you automated alerts, historical reports, and remote immobilizer control where supported.

## Key Highlights

- Plaspy compatible for easy integration into existing fleet management workflows and real-time tracking dashboards.
- Global 4G LTE coverage with fallback to GSM/GPRS for consistent connectivity across regions.
- High-accuracy GNSS: 66-channel receiver with under 5 m CEP location accuracy for precise route and asset monitoring.
- Multiple vehicle alarms and telemetry: movement, ignition \(ACC\) on/off, speed alerts, power-cut detection, and angle-change updates.
- Built-in 150mAh backup battery to support power-cut alarms and short autonomous operation after mains loss.
- Optional relay control enables remote fuel or power cut for vehicle immobilization and theft response.
- Flexible wiring: available in 4-pin and 8-pin versions to match diverse vehicle harnesses and installation scenarios.

## How It Works with Plaspy

When connected to Plaspy, the G900LS streams location and telemetry over LTE/GPRS using TCP/IP. The tracker's protocol support and configurable upload intervals allow Plaspy to receive frequent, accurate position updates and event-driven alarms. Plaspy then correlates that data with geofences, speed rules, and scheduled reports to provide actionable insights for fleet managers and security teams.

- Real-time location and telemetry updates via LTE/GPRS for live tracking on Plaspy maps.
- Ignition \(ACC\) status, speed detection, and movement alarms feed into Plaspy rules and alerts.
- Power-cut alarm and backup battery events are reported so dispatch can react to tamper or power-loss incidents.
- Remote immobilizer/relay control can be issued from Plaspy \(platform-supported commands\) to disable fuel or power if required.
- Configurable upload intervals and alarm enable/disable commands let Plaspy balance reporting frequency and data usage for each device.

## Technical Overview

| Connectivity | LTE / GSM / GPRS \(4G global version\) |
| --- | --- |
| Bands | LTE-FDD: B1/B2/B3/B4/B5/B7/B8/B28/B66; LTE-TDD: B34/B38/B39/B40/B41; GSM: 850/900/1800/1900 MHz |
| Power & Battery | Operating voltage 9–90 VDC; built-in 150 mAh \(3.7V Li-Polymer\) backup battery for power-cut alerts and limited autonomous operation |
| Protocols | GPRS Class 12 TCP/IP; GT06 series protocol for backend integration |
| Interfaces | 4-pin and 8-pin wiring harness variants; ACC/ignition detection; power-cut detection; optional relay for remote fuel or power cut control |
| GNSS | 66-channel GPS receiver; -165 dBm tracking sensitivity; location accuracy &lt; 5 m CEP; TTFF: &lt;35s cold, &lt;1s hot \(open sky\) |
| Remote Management | SMS and platform commands: APN/server config, GPS queries, status/version checks, configurable upload intervals, alarm enable/disable, remote relay control |
| Operating Conditions | Operating temperature -20°C to +70°C; standby/working consumption between 5 mA and 50 mA |
| Form Factor | Hard-wiring car GPS tracker, compact for discreet vehicle installation |
