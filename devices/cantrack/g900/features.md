# CanTrack - G900 Features

This page provides a public feature overview of the CanTrack G900 and how its capabilities are used when the device reports into Plaspy. It focuses on user facing functions and practical value without reproducing manufacturer configuration steps. Use this as a starting point to understand what the tracker can do in the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific setup details and the latest technical specifications consult the manufacturer documentation and release notes.

## Feature Overview

The CanTrack G900 is a compact vehicle and asset tracker designed for continuous location monitoring and simple event alerts. It combines positioning and cellular communication to deliver live location updates and basic tamper and safety notifications suitable for fleet and asset management workflows.

- Real time tracking for live location monitoring and historical route visibility
- Overspeed alarm to notify when a configured speed threshold is exceeded
- Power cut alarm to indicate when the device loses external power or is disconnected
- IP65 rated enclosure for protection against dust and water splashes in typical field conditions
- GSM GPRS GPS support with quad band cellular compatibility and GPS position reporting

## Core Features of CanTrack - G900

- Real time GPS location reporting for map display and route history
- Overspeed alarm functionality for driving behavior visibility
- Power cut alarm for detection of power disconnection events
- IP65 waterproof shell for improved durability in outdoor and mobile use
- GSM GPRS GPS network support with quad band compatibility
- Positioning accuracy as specified by the manufacturer
- Wide DC input voltage compatibility for vehicle installations

## How These Features Work with Plaspy

When a G900 is connected to Plaspy, its core functions appear as location updates and device events inside the platform. Plaspy automatically detects the device protocol and accepts position and alarm reports, enabling monitoring and alerting without manual protocol selection.

- Live positions are plotted on Plaspy maps and stored for history and route playback
- Overspeed events are surfaced as alerts and can be used in reporting or operational workflows
- Power cut events show up in device status and can trigger notifications to administrators
- Device connectivity and last known status are visible in Plaspy for operational oversight
- The tracker can be configured to report to Plaspy servers using supported transport methods; Plaspy handles protocol detection to simplify integration

## Typical Use Cases

- Fleet location monitoring for scheduled vehicles and deliveries
- Asset recovery and location visibility for mobile equipment
- Basic driver safety programs using overspeed notifications
- Security monitoring with power cut detection for tamper awareness
- Operational oversight for remote or seasonal equipment in harsh environments

## Feature Availability Notes

- Features and alarm behavior may differ between firmware versions and hardware revisions
- Installation type and wiring can affect availability of power related alarms such as power cut detection

- GPS accuracy can vary with satellite visibility, local environment, and antenna placement
- Consult the manufacturer documentation for full technical specifications and regulatory information

Using the CanTrack G900 with Plaspy gives teams a straightforward way to turn raw position and event reports into operational insight.
