# CanTrack - G06L Features

This page provides a public, feature-oriented overview of the CanTrack G06L and how its capabilities are exposed when the device is used with Plaspy. It is intended to describe practical, non-sensitive functionality and the kinds of telemetry and alarms the tracker can report into Plaspy for fleet and vehicle security use cases.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. Where possible this page reflects the G06L feature set as publicly described by the manufacturer, but final details should be confirmed against the device firmware and official documentation.

## Feature Overview

The CanTrack G06L is a compact 4G GPS tracker optimized for motorcycles, cars, scooters and light trucks. It combines discreet internal antennas, reliable GNSS performance, a small backup battery and configurable alarm reporting so operators can maintain continuous location awareness and receive event-driven alerts inside Plaspy.

- Real time GPS tracking and breadcrumb history well suited to vehicle deployments.
- Alarms and event reporting including ignition detection, SOS, movement, speeding and power-cut alerts.
- Small internal antenna housing for discreet installations on motorcycles and cars.
- Built-in backup battery and offline data buffer to preserve last known position and queued points when main power or connectivity is interrupted.
- Multiple configuration and management channels including PC USB, GPRS and SMS plus OTA firmware updates for remote maintenance.

## Core Features of CanTrack - G06L

- 4G LTE / GSM connectivity for live position and telemetry reporting suitable for mobile vehicle use.
- GNSS performance with multi channel reception and published sensitivity and accuracy metrics for dependable fixes.
- Backup battery to support power-cut alarms and short term reporting during main power loss.
- Ignition status detection and digital input to support trip start/stop visibility and event-based reporting.
- Digital output capable of driving a remote power-off relay to enable immobilizer style workflows where configured.
- Alarms and alerts including SOS, movement, speeding and power-cut reporting as part of the device telemetry set.
- Local memory buffer for offline recording of position points so queued data can be uploaded once connectivity is restored.
- OTA firmware updates and multiple configuration methods (PC USB, GPRS, SMS) for remote management and scaling.

## How These Features Work with Plaspy

When the G06L is installed and reporting, Plaspy ingests GPS coordinates, telemetry signals and alarm events to provide live tracking, playback and alerting. Plaspy displays position history, flags event types and lets administrators tune reporting and response behavior to match operational needs.

- Live location and breadcrumb updates appear in Plaspy for monitoring vehicle movements in real time.
- Ignition on/off and movement events are reflected as actionable events to support trip reports and fleet workflows.
- Power-cut and backup battery reporting give Plaspy a last known position and an alarm event if main power is removed.
- Offline-stored points are uploaded to Plaspy when the device regains connectivity so historical data remains continuous.
- Remote commands and configuration changes can be applied through Plaspy where the device and installation are configured to accept remote control.

## Typical Use Cases

- Fleet management for small vehicles and light trucks where discreet installation and continuous visibility are required.
- Anti-theft protection for motorcycles and scooters using discreet mounting, SOS alerts and power-cut reporting.
- Usage based insurance and driving behavior logging using ignition and event history for claims or telematics analysis.
- Rental fleets and service workshops that need ignition and movement alerts plus historical playback for diagnostics and dispute resolution.
- Delivery and last mile operations that require real time location, queued offline points and simple remote control options.
