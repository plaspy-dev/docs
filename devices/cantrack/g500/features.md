# CanTrack - G500 Features

This page provides a public feature overview for the CanTrack G500 and explains how those features fit into the Plaspy platform. It focuses on practical, non sensitive details about what the device can do and how Plaspy can present that data for monitoring and oversight.

The CanTrack G500 uses GSM GPRS networks and GPS satellite positioning for real time tracking and remote monitoring. Exact feature availability depends on firmware version, hardware revision, installation type, and the manufacturer implementation, so consult manufacturer documentation for device specific behavior.

## Feature Overview

The G500 combines satellite positioning with cellular reporting to deliver location awareness and basic remote monitoring. In practice this means the device can report position updates, respond to short message queries, and send alarm notifications that help operators maintain situational awareness.

- Real time GPS positioning for current location updates
- Reporting and remote locate via short messages or mutual contact
- Alarm notifications including ACC mobile alarm and text message alerts
- Uses GSM GPRS connectivity to transmit location and events
- Suitable for tracking vehicles, assets, and personal monitoring scenarios

## Core Features of CanTrack - G500

- GPS satellite positioning for location fixes
- GSM GPRS based communication for remote reporting
- Real time positioning capability for live location tracking
- Remote monitoring and locate through short messages or mutual contact
- Built in alarm functions with text message notification support
- ACC mobile alarm support as described in manufacturer materials
- Practical for vehicle and asset tracking use cases
- Designed for straightforward user interaction and monitoring

## How These Features Work with Plaspy

Plaspy can ingest location and alert reports from the G500 so teams can view position, history, and event notifications from a centralized platform. Plaspy automatically detects the tracker protocol and accepts device reports, allowing the G500 to feed live data into Plaspy dashboards and event streams.

- Location updates appear on Plaspy maps for live tracking and route review
- Alarm messages reported by the device show as events and notifications
- Remote locate responses can be reflected as manual position queries or incoming reports
- Plaspy handles device connectivity and protocol detection so reporting is simplified
- Centralized history and reporting in Plaspy help correlate alerts with location and time

## Typical Use Cases

- Fleet vehicle location visibility and basic monitoring
- Asset tracking where periodic position updates and alerts are needed
- Personal safety monitoring with remote locate and alert messages
- Delivery tracking for location verification and status checks
- Operational oversight where real time positioning and alarms aid decisions
- Situations that rely on SMS based notifications in addition to platform reporting

## Feature Availability Notes

- Feature set and behavior can vary by firmware version and hardware revision
- Installation type and wiring can affect which alarm functions are active
- Regional cellular network support and SIM configuration influence reporting
- Manufacturer documentation is the authoritative source for device specific capabilities
- Plaspy presents data the device reports but does not alter how device firmware generates events

## Why Use Plaspy with These Features

Using the CanTrack G500 with Plaspy gives organizations a way to centralize location data, alarms, and remote monitoring into a single operational view. Plaspy’s device detection and event handling make it straightforward to receive the G500’s reports and translate them into map positions, alerts, and history for operational decision making.

If you want to learn more about how Plaspy works with compatible trackers, visit https://www.plaspy.com.
