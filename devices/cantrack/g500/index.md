# CanTrack - G500

<div className="device-logo">
![G500](./Logo.png)
</div>

The CanTrack G500 is a compact GPS tracker designed to provide real time positioning and remote monitoring. It combines GPS satellite positioning with GSM GPRS connectivity to allow location updates and remote queries via short messages or mutual contact. The device is described as suitable for tracking vehicles, movable assets, and people who require persistent location oversight and timely alerts.

As a Plaspy compatible device, the G500 can feed positional information and alarm events into Plaspy's fleet management environment. That compatibility makes it a practical choice for organizations or individuals who want the G500's on‑the‑ground tracking capabilities presented through Plaspy's centralized dashboards, reporting, and operational oversight tools.

## Key Highlights

- Real time positioning using GPS satellite data for continuous location awareness.
- GSM GPRS connectivity enables remote location queries and notifications via short messages.
- Built‑in alarm functions with text message notifications for alerting on predefined events.
- Features such as ACC mobile alarm and SMS alerts add a layer of immediate notification.
- Versatile application for vehicles, assets, and personal monitoring needs.
- Described as user friendly and suitable for straightforward remote monitoring workflows.

## How It Works with Plaspy

When used with Plaspy, the CanTrack G500's location updates and alarm notifications are made available within a single monitoring platform, enabling centralized visibility and record keeping. Plaspy can present live position data, log events, and help teams act on device alerts from a unified interface.

- View live device locations on Plaspy maps alongside other fleet assets.
- Receive and consolidate alarm events and text based notifications in Plaspy for review.
