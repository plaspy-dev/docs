# CanTrack - G09L Features

This page provides a public feature overview of the CanTrack G09L and how its capabilities map to Plaspy for centralized fleet tracking and monitoring. It focuses on practical, non-sensitive information about the device as used with Plaspy and highlights the functions fleet managers and integrators will commonly rely on.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and installation method. For device-specific parameters, configuration commands or the most current technical details, consult the manufacturer documentation and release notes from CanTrack.

## Feature Overview

The G09L is an oval DOT certified tail light tracker designed to replace a vehicle’s original tail lamp while adding discreet GPS tracking and driving telemetry. Built for heavy vehicles and fleets, it combines vehicle lighting functions with positioning, motion sensing, cellular connectivity and remote management features that integrate with platforms such as Plaspy.

- Discrete oval tail light form factor that replaces factory tail lamps for covert installation and integrated lighting.
- Integrated GNSS positioning (GPS plus BeiDou) for regular location updates and route history.
- Built-in G-sensor for detecting driving events such as harsh braking or collision alarms and reporting event timestamps.
- 4G LTE Cat M1 / Cat NB2 cellular connectivity for wide area coverage and efficient power use, plus remote firmware updates (FOTA).
- Internal backup battery to continue reporting when vehicle power is interrupted and optional external power bank support for longer autonomy.

## Core Features of CanTrack - G09L

- DOT certified oval tail light housing that combines turn, brake and night lamp functionality with tracking electronics.
- Integrated GPS and BeiDou positioning for vehicle location and route playback.
- G-sensor based event detection to log harsh events and trigger alarm reports.
- Internal backup battery (3.7 V / 5000 mAh) with optional larger power bank support for extended backup operation.
- 4G LTE Cat M1 / Cat NB2 cellular radio for reliable wide area connectivity and power-efficient reporting.
- Rugged IP67-rated enclosure suitable for heavy vehicle exterior mounting.
- Remote management support including FOTA firmware updates and SMS based configuration of APN, server and reporting intervals.
- Compatibility with common telematics portals and direct integration into cloud platforms such as Plaspy for centralized monitoring.

## How These Features Work with Plaspy

When provisioned for a Plaspy deployment, the G09L transmits position, sensor events and device status so Plaspy can display live location, notify on important events and retain history for reporting. Plaspy’s platform consolidates the tracker data for fleet oversight, playback and alerting.

- Live GPS and BeiDou location updates appear in Plaspy for tracking and map visualization.
- G-sensor events and crash or harsh-event notifications are forwarded to Plaspy for incident handling and review.
- Device status and battery backup reports help operations teams identify power loss or device offline conditions within Plaspy.
- Remote commands such as a device beep for on-site locating and FOTA triggers are supported by the tracker and managed through portal workflows.
- Plaspy consolidates history playback, geofence checks and event-based reporting to support operational analysis and compliance reviews.

## Typical Use Cases

- Heavy vehicle fleet management with centralized location visibility, route playback and compliance reporting.
- Theft recovery and covert anti-theft monitoring by replacing tail lamps with an integrated tracker.
- Insurance telematics and incident verification using driving event logs and crash alarms.
- Rapid incident response and operational alerts when harsh events or power interrupts occur.
- Equipment and contractor fleet tracking where integrated lighting and low-visibility installation are preferred.

Using Plaspy to manage G09L-equipped vehicles centralizes location, event and device status information so fleet operators can monitor activity across large vehicle fleets, respond quickly to incidents and keep a single source of truth for history and reports.
