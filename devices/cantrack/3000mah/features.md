# CanTrack - 3000mAh Features

This page provides a public, feature oriented overview of the CanTrack 3000mAh magnetic GPS tracker and how its capabilities are presented when used with Plaspy. It summarizes the practical functions you can expect to see in Plaspy and clarifies how the device integrates into fleet or asset monitoring workflows without delving into private configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. Where applicable this page highlights manufacturer reported capabilities, but installers and operators should confirm specific behavior for a given device build and installation before relying on any single function for operational use.

## Feature Overview

The CanTrack 3000mAh (GF40) is a rechargeable magnetic asset tracker designed for long duration covert mounting on vehicles and high value assets. It balances configurable reporting modes with a large battery and rugged housing so operators can prioritize battery life or update frequency depending on the use case.

- Rechargeable 3000mAh battery and optimized power modes for extended standby life.
- Strong magnetic mount and ABS fireproof housing for quick, covert attachment to metal surfaces.
- Multiple working modes including real time, interval, and clock reporting to tune accuracy versus battery use.
- Remote configuration and control via SMS commands or platform settings to adjust intervals and alarms.
- Security features such as geofence alerts, vibration or tamper notifications, and low battery alarm.
- Optional remote voice listen in available as an additional security tool where permitted.

## Core Features of CanTrack - 3000mAh

- Rechargeable 3000mAh battery with configurable wake and sleep behavior to support long term monitoring.
- Magnetic ABS fireproof enclosure with an N54 level magnet for secure tool free mounting on metal surfaces.
- Multiple reporting modes so you can choose real time updates or low power interval and clock reporting.
- GNSS positioning with a multi channel receiver and manufacturer reported accuracy typically under 5 meters.
- Geofence alerts and tamper or vibration notifications to support anti theft and perimeter monitoring.
- Remote control via SMS command set and platform based configuration for remote tuning and status checks.
- Optional remote voice listen in capability for security verification when enabled and legally permitted.
- Internal logging and buffering to reduce data loss when temporary network issues occur.

## How These Features Work with Plaspy

Plaspy receives compatible device reports and presents location and status data through the platform for centralized monitoring and alerting. The CanTrack 3000mAh streams position and telemetry that Plaspy can surface as live markers, history, and events to support operational oversight.

- Live and historical location display in Plaspy so operators can track movement and review past routes.
- Device status indicators in Plaspy for battery level and basic health reporting to plan maintenance.
- Geofence and tamper alerts forwarded into Plaspy workflows to trigger notifications or follow up actions.
- Remote configuration and interval tuning performed via SMS or platform settings to optimize reporting for Plaspy dashboards.
- Optional listen in events can be recorded as security related events in the platform when the feature is active and permitted.

## Typical Use Cases

- Covert tracking of trailers, containers, and rental units where tool free magnetic mounting is required.
- Long term asset monitoring for seasonal or intermittently used equipment that benefits from long standby life.
- Anti theft monitoring of parked vehicles and equipment using geofence and tamper alerts.
- Fleet asset oversight where operators need a simple, rechargeable tracker that reports into a central platform.
- Remote inventory monitoring for dispersed assets requiring periodic check ins rather than constant reporting.

## Feature Availability Notes

- Firmware differences and hardware revisions can change available commands, reporting options, and battery performance.
- Installation location and mounting orientation of the magnet housing can affect GNSS reception and reporting quality.
- Regional cellular variants may affect which network bands are supported in a particular device batch.
- Optional voice listen in and other country specific features may be subject to local laws and regulatory requirements.
- Always consult the device manufacturer documentation for the exact SMS command set, default passwords, and firmware change notes.
