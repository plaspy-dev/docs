# CanTrack - G900LS-4G Features

This page provides a public feature overview for the CanTrack G900LS-4G GPS tracker and explains how those capabilities map into Plaspy for fleet management and vehicle monitoring. It focuses on the practical, non sensitive aspects of the device that are relevant when the tracker is used with Plaspy, including connectivity, telemetry types, alarm support, and optional remote relay control.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation method. Manufacturer implementation and device configuration choices also affect which functions are available, so operators should confirm current details with manufacturer documentation and their device configuration before deployment.

## Feature Overview

The G900LS-4G is a compact vehicle tracker designed for continuous location reporting and basic vehicle telemetry. It is built for broad mobile network coverage and uses a GT06-series protocol with standard TCP/IP reporting for easy integration into platforms such as Plaspy. The device emphasizes real time tracking, essential alarm reporting, and optional remote immobilizer capability.

- Real time GPS location reporting for continuous position awareness and mapping
- Ignition or ACC detection for trip logging and on off event visibility
- Power cut alarm plus a built in backup battery to maintain telemetry during power loss
- Optional remote relay control for fuel or electricity cut off to support immobilization workflows
- Movement, angle change, vibration and other alarm types to detect suspicious events
- Compact form factor and wide input voltage range for mixed vehicle installations

## Core Features of CanTrack - G900LS-4G

- 4G LTE with fallback to GSM for wide area connectivity and reliable reporting
- GT06 series protocol with standard TCP/IP reporting for platform compatibility
- Real time position, speed reporting, and trip related telemetry such as ignition status
- Power cut alarm and an integrated backup battery to support tamper detection
- Optional relay control for remote fuel or electricity cut off and immobilizer use
- Movement, angle change, and vibration sensor alarm support for anti theft monitoring
- Wide input voltage range and small physical footprint for cars, motorcycles, and mixed fleets
- GNSS performance details reported by the manufacturer including multi channel tracking and typical position accuracy

## How These Features Work with Plaspy

When the G900LS-4G is configured to report to Plaspy, the device streams position and event data into the platform where it is visualized, logged, and acted upon. Plaspy detects the tracker protocol automatically and ingests the telemetry to make location, status, and alarm information available to administrators.

- Real time positions and movement history appear on Plaspy maps and timeline views
- Ignition or ACC on off events are visible in trip logs and can be used for reporting
- Power cut and backup battery alerts can trigger notifications and help flag possible tampering
- Alarm events such as movement, angle change, and vibration appear as platform alerts for operator review
- Where the device supports remote relay control, Plaspy can reflect relay state and, where enabled by device configuration, send remote commands or SMS style control through platform workflows

## Typical Use Cases

- Centralized fleet tracking and dispatch for mixed vehicle fleets using real time location and trip data
- Anti theft monitoring with movement and power cut alarms plus optional remote immobilization
- Driver event tracking and compliance using ignition status and speeding reports
- Compact vehicle protection for motorcycles and e bikes where small form factor matters
- Remote command scenarios such as querying device status or toggling relay control when allowed by the installation
- Asset monitoring in regions with mixed 4G LTE and GSM coverage

## Feature Availability Notes

- Functionality depends on the device firmware and hardware revision; features listed by the manufacturer may vary between units
- Optional features such as relay based immobilization require the correct hardware wiring and may need additional accessories or installer configuration
- Regional variants and cellular band support affect network compatibility and should be confirmed before deployment
- Installation type and vehicle wiring influence the availability of ignition detection and some alarm inputs
- Always consult the latest manufacturer documentation for precise specifications and firmware related behavior
