# G900LS-4G

The G900LS-4G is a compact, Plaspy compatible GPS tracker engineered for reliable vehicle tracking and modern fleet management. Built for global 4G LTE coverage and backward GSM support, this unit offers continuous real-time tracking through mobile app and web platform connectivity, enabling operators to monitor location, ignition status, speed, and alarms with confidence.

Designed for mixed fleets and individual vehicle protection, the G900LS-4G supports both 4-pin and 8-pin wiring versions and an optional remote relay for fuel/electricity cut-off and immobilization. Its GT06-series protocol and standard TCP/IP reporting make integration with Plaspy seamless, delivering telemetry, anti-theft controls, and timely alerts that help reduce downtime and improve fleet safety.

## Key Highlights

- Plaspy compatible GPS tracker with GT06-series protocol and TCP/IP reporting for quick platform integration.
- Global 4G LTE + GSM communications for reliable real-time tracking across regions.
- Real-time tracking, speeding and ACC/ignition detection to support driver behavior monitoring and fleet management.
- Power-cut alarm plus a built-in 150 mAh backup battery to maintain telemetry during power loss.
- Optional remote relay control for fuel/electricity cut-off—enables remote immobilizer capability for anti-theft response.
- Angle-change and movement alarms plus vibration/sensor alarm support to detect suspicious vehicle events.
- Compact 79 × 34 × 18 mm form factor and wide 9–90 VDC input make it suitable for cars, motorcycles, e-bikes and mixed fleets.

## How It Works with Plaspy

When connected to Plaspy, the G900LS-4G streams GPS positions and vehicle telemetry in near real time using its GT06-series protocol or standard TCP/IP packets. Plaspy ingests location, speed, ignition/ACC status, alarm events and relay state to populate maps, alerts and reports. Administrators can configure data upload intervals, receive push notifications on critical events, and issue remote commands through the platform where supported.

- Real-time location and telemetry updates \(GPS coordinates, speed, heading\).
- Ignition/ACC on-off detection and related alerts for driver behavior and trip logging.
- Power-cut alarm and backup battery status reporting to detect tampering or power loss.
- Optional remote fuel/electricity cut-off \(relay control\) enabling immobilizer actions via Plaspy or SMS commands.
- Movement, angle-change, speeding and vibration/sensor alarms for anti-theft and incident detection.

## Use Cases

- Fleet management: real-time tracking, speed monitoring, trip logs and ACC events to improve routing and driver performance.
- Anti-theft protection: immediate power-cut alarms, movement/angle-change detection and optional remote fuel/electricity cut-off for immobilization.
- Driver behavior and compliance: speeding, ignition on/off, and timer-based reporting help enforce safety policies and reduce liability.
- Mixed-vehicle deployments: wide 9–90 VDC input and compact form factor suit cars, vans, motorcycles and e-bikes across commercial fleets.
- Remote command and control: SMS and TCP/IP command support allow administrators to query position, change settings, or trigger relay control when integrated with Plaspy.
