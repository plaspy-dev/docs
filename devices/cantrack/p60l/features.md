# CanTrack - P60L Features

This page provides a public overview of the CanTrack P60L feature set and how those capabilities are exposed when the device is used with Plaspy. It describes the practical functions you can expect to use in Plaspy for location, alerts, voice and environmental telemetry while noting the general ways data is delivered into the Plaspy platform.

Exact feature availability and behavior can depend on the device firmware version, hardware revision, installation method and the manufacturer's implementation. Where relevant, this page points to the capabilities described by the manufacturer, but you should confirm device specifics against official CanTrack documentation for the most current details.

## Feature Overview

The P60L is a compact personal tracker designed for continuous location tracking, two‑way voice, SOS alerts and basic environmental telemetry. It pairs multi‑constellation GNSS positioning with cellular connectivity to deliver real‑time updates and supports offline logging to preserve history during coverage gaps.

- Real‑time GNSS location reporting using GPS and BeiDou for improved position availability.
- Two‑way voice support and a dedicated SOS button for immediate incident communication.
- Onboard temperature sensing for environmental telemetry and threshold alerts.
- Offline logging of stored location records that upload when connectivity is restored.
- Remote management features including OTA firmware updates and a comprehensive SMS command set.

## Core Features of CanTrack - P60L

- Plaspy compatible real‑time uploads and alerting for quick integration into tracking dashboards.
- 4G LTE plus fallback GPRS connectivity for low‑latency telemetry and broad cellular coverage.
- Dual GNSS support (GPS and BeiDou) with high channel count for reliable positioning.
- Two‑way voice capability with built‑in microphone and speaker for direct communication.
- Dedicated SOS alarm button for immediate alerting to monitoring teams.
- Onboard temperature monitoring for environmental or asset telemetry.
- Offline data logging to retain location history during intermittent coverage.
- Remote configuration and FOTA (firmware over the air) plus SMS commands for large scale management.

## How These Features Work with Plaspy

Plaspy ingests the P60L’s location and telemetry so teams can visualize movement, receive alerts, and act on incidents in real time. Plaspy automatically detects compatible tracker protocols and maps incoming device events to dashboard locations, rules and notifications.

- Real‑time position updates and telemetry are shown on Plaspy maps and timelines for continuous visibility.
- SOS events and voice alerts are surfaced as high‑priority incidents in Plaspy so operators can triage quickly.
- Temperature readings and threshold events can be used to trigger notifications or logging within Plaspy workflows.
- Offline logged points upload when the device regains connectivity and are reconciled into Plaspy history.
- Remote configuration and firmware updates are supported through the device’s management features to reduce onsite maintenance.

## Typical Use Cases

- Personal safety and elder care monitoring with SOS and two‑way voice for assistance.
- Child tracking and lone worker protection where rapid location and communication are required.
- Asset monitoring that benefits from temperature telemetry and historical location logging.
- Portable equipment or pet tracking that needs compact form factor and standby readiness.
- Situations requiring remote firmware management and scalable SMS configuration for many units.
