# CanTrack - G01 Features

This page provides a public feature overview for the CanTrack G01 and explains how its capabilities are used within Plaspy. It focuses on the practical, non sensitive aspects of the device such as its GPRS and SMS reporting, GPS plus LBS positioning, backup battery operation, and event alerts that can be surfaced in Plaspy dashboards and reports.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional variant, and manufacturer implementation. Where necessary you should confirm device specific details such as firmware features, supported bands, or voice call behavior with the manufacturer documentation.

## Feature Overview

The G01 is a compact GPS tracker designed for discreet personal safety and small asset monitoring with straightforward integration into Plaspy. It provides real time tracking by GPRS with SMS fallback, basic event alerts, and a voice monitoring option that helps with situational awareness.

- Real time location reporting to servers via GPRS for continuous tracking inside Plaspy.
- SMS location replies with Google Maps links for quick location checks when data is unavailable.
- Hybrid GPS plus LBS positioning to improve location availability in weak GNSS areas.
- Built in backup battery to maintain reporting when external power is lost.
- Event alerts such as overspeed alarm that can be mapped to Plaspy notifications.

## Core Features of CanTrack - G01

- Compact form factor for discreet mounting on persons, bikes, and small assets.
- GPRS based real time reporting for live monitoring and route history in Plaspy.
- SMS based location replies with Google Maps links as an alternative reporting method.
- Hybrid GPS and LBS positioning to improve fixes in urban or indoor environments.
- Built in backup battery to continue location updates during power interruptions.
- Real time voice monitoring capability for remote listening workflows.
- Overspeed alarm and other event flags that can trigger notifications.
- Standard device identifiers such as IMEI included in position reports for device mapping.

## How These Features Work with Plaspy

Plaspy ingests the location and event messages the G01 sends so organizations can view live position, playback tracks, and respond to alerts. Plaspy automatically detects common tracker protocols and surfaces the device telemetry in maps, history, and event rule engines, enabling operational oversight without manual protocol configuration.

- Live positions and periodic updates are shown on Plaspy maps for real time monitoring.
- SMS location replies provide quick location links when GPRS is unavailable and can be used as a fallback for immediate viewing.
- Event flags like overspeed generate alerts that Plaspy can convert into notifications, alarms, or rule triggers.
- Location history and route playback allow post event review and simple reporting in Plaspy.
- Voice monitoring events reported by the device are logged so authorized users can follow required safety workflows.

## Typical Use Cases

- Personal safety monitoring for children, elderly family members, or lone workers.
- Discreet tracking of bicycles, scooters, and small assets for anti theft recovery.
- Light fleet or rental asset tracking where basic position history and alerts are sufficient.
- Short term or temporary deployments that benefit from compact size and battery backup.
- Situations that require SMS fallback for quick location checks when data networks are unreliable.
