# CanTrack - GF20-Mini Features

This page provides a public feature summary for the CanTrack GF20-Mini as used with Plaspy. It focuses on practical, non-sensitive capabilities you can expect when integrating the GF20-Mini with Plaspy for fleet management, asset monitoring, and basic security workflows. The goal is to help you understand how the tracker’s functions map to Plaspy visibility and reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and regional manufacturer implementation. Always confirm the device configuration and enabled functions on the specific unit you have and consult the official manufacturer documentation for definitive details.

## Feature Overview

The GF20-Mini is a compact magnet-mounted GPS asset tracker intended for quick deployment where a small form factor and discreet placement are important. It provides continuous position reporting, event notifications, and short-term offline logging to maintain location history through temporary connectivity gaps.

- Real-time location reporting for live monitoring and historical tracking.
- Geo-fence alerts and vibration alarm to notify of movement or boundary events.
- Onboard memory to record positions during GSM outages and sync when connectivity is restored.
- Compact magnetic housing for covert attachment to vehicles, containers, or equipment.
- Optional remote voice listening and voice recording as an added investigative feature.

## Core Features of CanTrack - GF20-Mini

- Compact magnetic housing and small form factor suitable for discreet mounting and rapid deployment.
- High-sensitivity MTK GNSS positioning with sub 10 meter CEP accuracy for dependable fixes.
- Quad-band GSM support for broad cellular coverage and reporting via SMS or platform messages.
- Onboard position memory to retain location history during network outages and forward data when reconnected.
- Geo-fence alerting and vibration alarm to support theft detection and movement monitoring.
- Configurable working modes and low battery notifications to help manage reporting frequency and device runtime.
- Optional remote voice listening and voice recording for investigation and recovery workflows.
- Designed for short-term covert tracking and asset security scenarios where quick installation matters.

## How These Features Work with Plaspy

Plaspy ingests location updates and event messages from the GF20-Mini and presents them alongside other device data for centralized monitoring. When integrated, Plaspy can surface the tracker’s location history, alerts, and status so teams can act on events or review past movements.

- Real-time GPS fixes and periodic position updates appear in Plaspy for live location awareness and mapping.
- Geo-fence triggers and vibration alarms are forwarded as event notifications that can generate alerts or workflows in Plaspy.
- Stored positions collected during GSM outages are synchronized into Plaspy once the device reconnects, preserving continuity of historical data.
- Status messages such as low battery warnings are visible in Plaspy to support proactive device maintenance.
- Optional voice event markers can be logged as part of incident records when that feature is enabled and supported.

## Typical Use Cases

- Temporary vehicle tracking for rental fleets, demonstrations, or short-term monitoring projects.
- Anti-theft and recovery operations using vibration alarms, geo-fence alerts, and location history.
- Container and equipment security where magnetic attachment allows quick installation and removal.
- Covert asset monitoring and investigative scenarios that require a small, discreet tracker.
- Short-term asset audits where simple deployment and centralized reporting are priorities.
