# CanTrack - G500M

![G500M](./tracker.jpg)

The G500M Mini GPS Tracker is a compact OBD plug-and-play GPS tracker built for straightforward installation and dependable vehicle monitoring. Plaspy compatible out of the box, the G500M delivers real-time tracking over GSM/GPRS so fleet managers, rental companies, and personal vehicle owners can access live location, historical playback and essential telemetry without invasive wiring or lengthy installation.

The G500M leverages a high-sensitivity MTK GPS chipset and the standard 16-pin OBD II interface to draw power and capture ignition \(ACC\) status, motion events and collision alerts. With integrated GSM/GPS antennas, local position storage for blind-area scenarios and TCP/IP reporting, this GPS tracker is engineered for reliable vehicle monitoring, anti-theft alerts, and easy integration with Plaspy for centralized fleet management and reporting.

## Key Highlights

- Plaspy compatible for real-time tracking and centralized fleet management via GSM/GPRS.
- True plug-and-play OBD II installation — no hardwiring, fast deployment across multiple vehicles.
- High-sensitivity MTK GNSS \(66 channels\) with under 10 m CEP accuracy for precise location data.
- ACC \(ignition\) detection and ignition status reporting for automated trip logging and telemetry.
- G-sensor, motion detection and angle-change upload to detect collisions and unusual movement.
- Local storage for up to 1,400 positions with automatic re-upload when connectivity returns.
- Power-on and unplug alarms plus scheduled timing reports and geo-fence support for anti-theft workflows.

## How It Works with Plaspy

Once connected to a vehicle’s standard 16-pin OBD II port, the G500M continuously collects GPS positions, ignition \(ACC\) state and motion data, then transmits that telemetry to a backend server using GSM/GPRS \(TCP/IP\). Plaspy ingests this stream for real-time tracking, alerting, historical playback and reporting. The device’s onboard memory bridges coverage gaps and automatically sends stored positions to Plaspy as soon as the network is restored.

- Real-time location and telemetry updates transmitted over GSM/GPRS to Plaspy for live maps and dashboards.
- ACC \(ignition\) and ignition status detection for accurate trip start/stop logging and driver behavior analysis.
- Geo-fence events and motion/unplug alarms delivered as push alerts or email notifications from Plaspy.
- Local memory for blind-area recording with automatic re-upload to Plaspy when connectivity is available.
- G-sensor and angle-change upload feed collision and harsh-event data into Plaspy for incident review.
- Remote voice listening support enables limited in-vehicle monitoring where permitted and configured via Plaspy.

- Rental vehicles: rapid, non-invasive installation makes the G500M ideal for rental car monitoring, unplug and geo-fence alerts, and return compliance checks.
- Anti-theft monitoring: motion detection, unplug alarm and geo-fence alerting help detect unauthorized vehicle use and speed response.
