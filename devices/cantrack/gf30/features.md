# CanTrack - GF30 Features

This page provides a public feature overview of the CanTrack GF30 magnet GPS tracker and how its capabilities are used with Plaspy. It summarizes the practical, non sensitive aspects of the tracker that matter for integration, monitoring, and operational use with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For the most current device specific details consult the official CanTrack documentation and firmware notes before planning deployments.

## Feature Overview

The GF30 is a compact, magnet mounted GPS tracker designed for long duration asset monitoring. When paired with Plaspy it delivers location updates, alarm events, and stored telemetry so teams can monitor assets, respond to incidents, and review historical movement.

- Covert magnetic housing for quick attachment to metal surfaces such as trailers and equipment
- Long duration operation from a high capacity battery suitable for periodic remote monitoring
- Positioning using GPS assisted by network location methods for fast fixes and practical accuracy
- Event reporting including geo fence triggers, vibration alarm, and low battery alerts for operational awareness
- Onboard voice listening and voice recording for additional situational context during recovery or security incidents

## Core Features of CanTrack - GF30

- Magnetic rugged housing for discreet mounting to metal assets, enabling fast installation
- High capacity internal battery for extended remote monitoring intervals and asset recovery
- GPS plus network assisted location for reliable position reporting and faster time to first fix
- Geo fence support to trigger alerts when an asset enters or leaves predefined areas
- Vibration alarm to report movement or tampering events
- Remote voice listening and voice recording to provide situational awareness during incidents
- Local memory storage to retain position and event data when cellular connectivity is unavailable
- SMS reporting and platform reporting options for flexible integration into operations

## How These Features Work with Plaspy

Plaspy ingests the GF30 location updates and event messages to present live maps, alerts, and historical tracks for operational teams. The combination of continuous reporting and stored forwarding helps maintain visibility even when connectivity is intermittent.

- Real time and near real time location updates appear on Plaspy maps for live tracking and routing oversight
- Geo fence and vibration alerts are surfaced as notifications and events inside Plaspy for rapid response
- Low battery and connectivity events are tracked so teams can schedule maintenance or recovery actions
- Stored positions are uploaded after reconnection so Plaspy can display complete historical tracks without gaps
- Voice listening and recordings reported by the device can be associated with incident timelines in Plaspy for context

## Typical Use Cases

- Long term trailer and equipment tracking where covert mounting and battery endurance are priorities
- Asset recovery and anti theft workflows using geo fence and vibration alerts to detect unauthorized movement
- Container and remote equipment monitoring with on device storage to bridge connectivity gaps
- Security incident investigation where voice recording and event history support evidence collection
- Fleet oversight for mixed asset fleets that require discreet trackers for high value or seasonal equipment

## Feature Availability Notes

- Feature behavior can change with device firmware updates; confirm current firmware release notes for the GF30
- Hardware revisions and regional variants may affect cellular band support and some reporting options
- Installation type and placement influence GPS reception and time to first fix; mount location matters for best results
- Some features such as SMS reporting and voice functions depend on local carrier availability and configuration
- Check CanTrack documentation for exact specifications, supported firmware features, and configuration commands
