# CanTrack - TK100B

![TK100B](./tracker.jpg)

The CanTrack TK100B Accurate Pro is a hard-wired in-vehicle GPS tracker designed for continuous real-time location monitoring and vehicle security. As the professional evolution of the GT06/TK100 family, the TK100B provides telemetry and remote vehicle management features over GSM/GPRS with TCP/IP. It includes anti-theft controls such as one-key engine cut and restore, SOS, geo-fencing, two-way voice support and accessory interfaces for siren and remote controller use.

This model is listed as compatible with Plaspy, making it straightforward to bring TK100B location and event data into a centralized fleet management environment. When paired with Plaspy, the TK100B's real-time updates, alerts and remote control capabilities are surfaced in dashboards, notifications and operational workflows that help fleets, taxis and private owners monitor assets and respond quickly to incidents.

## Key Highlights

- Plaspy compatible hard-wired GPS tracker for continuous real-time tracking over GSM/GPRS with TCP/IP
- Anti-theft features including one-key engine cut and remote engine restore via relay control
- Two-way voice capability with external microphone to support remote listening and driver communication
- Accessory support for wireless remote controller and external siren to expand alerting and security options
- Professional MTK2503AV chipset and quad-band GSM support for broad cellular coverage and stable telemetry
- Compact form factor designed for discreet in-vehicle installation and robust operational use
- GNSS performance that targets reliable location fixes and predictable time to first fix for fleet tracking

## How It Works with Plaspy

The TK100B transmits location and vehicle telemetry to Plaspy over GSM/GPRS using TCP/IP. Plaspy ingests that data to provide live tracking, historical playback, configurable alerts and remote command workflows. Fleet managers and vehicle owners use Plaspy to monitor movement, receive alarms and execute supported remote actions based on device events.

- Real-time location and telemetry updates are displayed in Plaspy dashboards for live operational visibility
- Ignition and accessory state reporting plus relay control enable remote immobilizer workflows through Plaspy
- SOS button presses and geo-fence breaches are routed to Plaspy as immediate notifications for incident handling
- Two-way voice and external microphone support can be integrated into monitoring and communication workflows
- Accessory status, remote controller actions and siren triggers are reported to Plaspy and can be logged for auditing
