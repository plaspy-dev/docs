# CanTrack - TK100B Features

This page provides a public feature overview for the CanTrack TK100B and describes how its capabilities are used with Plaspy for vehicle tracking, security monitoring, and remote control. It focuses on practical, user-facing functions such as continuous location reporting, anti-theft controls, accessory interfaces, and the ways those functions appear in Plaspy dashboards and alerts.

Exact feature availability, behavior, and naming can vary by device firmware, hardware revision, installation type, and the manufacturer's implementation. Some functions described here require specific accessories or wiring during installation, so check the device configuration and the official CanTrack documentation for the authoritative device details before deployment.

## Feature Overview

The TK100B is a hard-wired vehicle tracker designed for continuous real-time tracking and remote vehicle management. It provides location telemetry and a set of security and control features that can be reported into Plaspy for centralized monitoring and operational workflows.

- Continuous real-time GPS location reporting for vehicle visibility and historical playback.
- Anti-theft controls including relay-based engine/fuel cut and remote engine restore for fast immobilization.
- SOS button, geo-fence alerts, and car-finding to surface emergency and perimeter events in the platform.
- Two-way voice monitoring via an external microphone and support for driver communications when used with Plaspy workflows.
- Accessory support for external siren, wireless remote controller, and ignition/ACC sensing to expand alerting and control.

## Core Features of CanTrack - TK100B

- GSM/GPRS based reporting over TCP/IP for live telemetry transmission.
- Relay output for one-key engine cut and remote engine restore.
- SOS alarm input and geo-fence event support for immediate incident reporting.
- Two-way voice capability and external microphone input for remote listening and communications.
- Support for wireless remote controller and external siren (horn) to enhance anti-theft responses.
- Ignition and ACC sensing to report vehicle running state and trigger context aware events.
- Professional GNSS performance with high sensitivity and meter-level accuracy for reliable fixes.
- Compact hard-wired form factor designed for discreet 12–36 V vehicle installations.

## How These Features Work with Plaspy

Plaspy ingests the TK100B telemetry and event messages to provide real-time maps, alerts, and remote command workflows. Devices that report location and accessory signals feed into Plaspy for centralized visibility and operational response.

- Real-time and periodic location updates appear on Plaspy maps and in historical route playback.
- SOS and geo-fence events generate configurable alerts and notification workflows inside Plaspy.
- Relay control and ignition state are visible in device status and can be used to trigger remote immobilization actions via supported Plaspy commands.
- Two-way voice and external microphone events are surfaced through Plaspy workflows where supported, enabling remote listening or driver communication.
- Accessory actions such as siren activation or remote controller events are logged and can be used as triggers in Plaspy for incident handling.

## Typical Use Cases

- Fleet management and dispatch with live location, trip history, and route playback for operational oversight.
- Vehicle anti-theft and recovery using relay-based immobilization, siren activation, and remote alerts.
- Taxi and rideshare oversight with two-way voice monitoring and car-finding to assist drivers and operators.
- Logistics and delivery vehicle monitoring with geo-fence alerts and SOS event handling for urgent incidents.
- Private vehicle security and emergency notification via discreet hard-wired installation and SOS reporting.
