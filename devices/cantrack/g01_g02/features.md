# CanTrack - G01 / G02 Features

This page provides a public feature overview for the CanTrack G01 and G02 GPS tracker models and explains how those features are typically used with the Plaspy platform. It summarizes the device capabilities described by the manufacturer and highlights the practical benefits you can expect when connecting these trackers to Plaspy for monitoring and oversight.

Exact feature availability depends on device firmware, hardware revision, installation type, and how the manufacturer implements functions. Where relevant this page notes common variations and encourages verification against the official manufacturer documentation for the latest device behavior.

## Feature Overview

The CanTrack G01 and G02 are compact GPS trackers designed for vehicle and asset tracking. They use the GSM GPRS network together with GPS satellite reception to collect and report position information, and they offer several user oriented features useful for real time monitoring and post event review.

- Real time tracking for up to date location visibility using GPRS reporting
- History trace replay to review past routes and movements
- Geo fence alarm to notify when a device leaves or enters a predefined area
- SOS alarm to send immediate emergency alerts when triggered
- Low battery alarm to warn of diminishing battery level and help avoid data loss
- SMS reporting to authorized mobile numbers in addition to server based reporting

## Core Features of CanTrack - G01 / G02

- Real time position reporting via GSM GPRS to an internet server
- History trace replay for route review over a selectable time window
- Geo fence alarm support for perimeter monitoring and area based alerts
- SOS alarm function for immediate emergency notification
- Low battery alarm to indicate when the internal battery requires attention
- SMS capability to send location data to an authorized mobile number
- Platform monitor compatibility for Android iOS and PC viewing
- Global GSM quad band support for broad cellular coverage in many regions

## How These Features Work with Plaspy

Plaspy receives and interprets the location and event reports sent by the CanTrack G01 and G02 so that teams can visualize device activity, review historical movement, and respond to alerts. Plaspy consolidates incoming reports into maps, timelines, and alerting mechanisms to support operational oversight.

- Real time location updates appear on Plaspy maps for continuous monitoring
- Historical positions and route replay are available inside Plaspy for investigations and reporting
- Geo fence events are translated into alerts and activity records in Plaspy
- SOS alarms are surfaced as high priority events so teams can take prompt action
- Low battery notifications are displayed to help maintain tracking continuity
- SMS sent by the device can complement server reporting and be used as an alternate reporting channel

## Typical Use Cases

- Vehicle location and movement monitoring for small fleets or single vehicles
- Reviewing historical routes for delivery confirmation or route optimization
- Perimeter monitoring using geo fences for asset location control
- Emergency notification for a tracked person or asset using SOS alerts
- Remote monitoring of mobile equipment where cellular coverage is available
- Supplementing server reports with SMS location messages when needed

## Feature Availability Notes

- Feature presence and behavior can vary by firmware version and hardware revision from the manufacturer
- Installation and mounting location affect GPS reception and therefore location accuracy and fix times
- Regional cellular network differences and SIM provisioning can influence GPRS reporting performance
- Some features may require specific device configuration or activation by the manufacturer or reseller
- Always consult the latest CanTrack documentation for model specific limits and recommended settings

## Why Use Plaspy with These Features

Using the CanTrack G01 or G02 with Plaspy gives organizations a single platform to consolidate device data, visualize location and movement, and manage alert workflows. Plaspy helps translate device reports into operational insight so teams can monitor assets, review history, and respond to events more effectively.
