# CanTrack - P901 Features

This page describes the public feature context for using the CanTrack P901 with the Plaspy platform. It summarizes the model's practical capabilities and how those capabilities map to Plaspy visibility, alerts, and device management workflows. The focus is on non sensitive, user facing details to help evaluate the P901 for tracking, team communications, and remote administration when connected to Plaspy.

Exact feature availability can vary by firmware version, hardware revision, installation method, mobile network provisioning, and the manufacturer implementation. Where the P901 provides voice, SOS, GNSS and remote update functions, behavior and supported options such as upload intervals, alert channels, and logging capacity may change with firmware and regional variants.

## Feature Overview

The CanTrack P901 is an ultra thin ID card style tracker that combines GNSS positioning, cellular connectivity, and on device voice communications into a wearable unit intended for personnel and field staff. It is designed to stream location and event data into cloud platforms like Plaspy so teams can monitor assets and respond to incidents in real time.

- Real time GNSS location reporting with LBS fallback for continuous position visibility in Plaspy
- Compact ID card form factor suitable for wearable use, clipping or lanyard mounting
- Integrated two way VoLTE calling and group push to talk for instant voice coordination
- One key SOS alarm with configurable alert channels to escalate incidents quickly
- Remote firmware updates and SMS based configuration to simplify fleet management
- Internal logging for offline recording and later upload to Plaspy for route playback

## Core Features of CanTrack - P901

- Plaspy compatibility for cloud based tracking and telemetry integration
- LTE and GPRS cellular connectivity for live reporting and voice services
- GPS plus Beidou positioning with cellular LBS fallback for resilient location fixes
- VoLTE two way calling and group push to talk for team voice communications
- One key SOS alarm with configurable alarm modes for incident escalation
- Internal storage for offline logging and historical route upload
- Remote firmware over the air updates and SMS configuration support
- Configurable upload and sleep intervals to balance reporting frequency and battery life

## How These Features Work with Plaspy

When used with Plaspy the P901 provides location, event and status information that Plaspy presents on maps, dashboards, and reports. Plaspy automatically identifies device protocol and ingests the device streams so administrators and operators can correlate position and alerts with communications and response actions.

- Real time location and telemetry updates become visible on Plaspy maps and live views
- SOS alarms are forwarded to Plaspy alert channels where they can trigger notifications and response workflows
- Historical routes stored on the device can be uploaded and replayed through Plaspy reporting tools
- Device status such as online state and reported telemetry are available for monitoring in Plaspy
- Remote configuration and FOTA workflows initiated from Plaspy or via supported SMS commands help maintain device fleets

## Typical Use Cases

- Security and patrol teams that need position awareness and instant group voice communication
- Event staff and venue operations that require wearable tracking and rapid incident reporting
- Lone worker protection where SOS and two way voice aid safety monitoring
- Mobile supervisors and field coordinators needing route playback and location oversight
- Compact wearable deployments where inconspicuous tracking and direct voice contact are priorities

## Feature Availability Notes

- Firmware and hardware revisions can change available settings, reporting behavior, and feature names
- Carrier provisioning and SIM voice capability affect VoLTE calling and group PTT functionality
- Regional cellular band support and network compatibility may vary by SKU and market
- Some advanced functions such as upload intervals, local logging limits, and alarm channels can be adjusted by configuration or firmware
- Verify specific feature sets, commands, and operational limits with the manufacturer documentation for your device revision

## Why Use Plaspy with These Features

Using the CanTrack P901 together with Plaspy gives organizations a compact way to combine position awareness, incident alerts, and team voice context into a single operational view. Plaspy consolidates incoming location and event data so teams can monitor assets in real time, review historical movement, and route responses more effectively while maintaining centralized device management.
