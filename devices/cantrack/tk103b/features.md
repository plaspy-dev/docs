# CanTrack - TK103B Features

This page provides a public feature context for using the CanTrack TK103B tracker with Plaspy. It summarizes the model's practical capabilities, alarms, and reporting behaviors that are relevant when the device is deployed for fleet management, theft prevention, and real time vehicle monitoring with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional device variants, and the manufacturer's implementation choices. Use this page as a practical overview and consult the device manufacturer and Plaspy documentation for device specific configuration and the most current details.

## Feature Overview

The TK103B is a compact, hard wired vehicle tracker designed to deliver location, alarm events, and basic telemetry to Plaspy for live monitoring and history playback. It supports multiple reporting and control methods to maintain data continuity and provide operators with timely incident visibility.

- Real time GPS position reporting for live map location and tracking history in Plaspy.
- Alarm generation for events such as overspeed, door open, ignition on, vibration, and SOS.
- Remote engine or power disable capability to assist with vehicle immobilization when required.
- SD card local logging to preserve position history when cellular data is unavailable.
- SMS and TCP/IP reporting methods to enable remote configuration and command control.
- Built in backup battery to allow limited operation after main power loss and support discreet installation.

## Core Features of CanTrack - TK103B

- GPS satellite positioning and regular reporting of vehicle location.
- GPRS TCP/IP reporting and SMS command support for remote communication.
- Alarm inputs and event reporting including overspeed, door open, ignition on, vibration and SOS alerts.
- Remote engine or power disable function for anti theft interventions.
- Local SD card logging for offline history and post incident recovery of data.
- Built in rechargeable backup battery to maintain limited operation after power loss.
- Compact hard wired form factor suitable for discreet installation in vehicles.

## How These Features Work with Plaspy

When connected to Plaspy, the TK103B sends position and event messages so operators can monitor vehicles on live maps, receive alerts, and review historical tracks. Plaspy ingests location and alarm data and presents it through dashboards and notification workflows for operational oversight.

- Live location updates appear on Plaspy maps for real time tracking and dispatch.
- Alarm events such as overspeed, door open, ignition and SOS are converted into notifications and incident records.
- Remote immobilization commands can be initiated through Plaspy and sent to the device according to platform workflows.
- SD card recorded history is used for playback and audit trails when live reporting is interrupted.
- SMS command support can be used as a fallback or for specific remote configuration when data channels are not available.

## Typical Use Cases

- Fleet anti theft and theft response where immobilization and alarm alerts support recovery efforts.
- Commercial fleet tracking for location visibility, route oversight, and operational dispatch.
- Taxi and rental vehicle monitoring to capture ignition and door events plus overspeed alerts.
- Incident investigation and post event analysis using SD card history playback and Plaspy history tools.
- Continuous monitoring across cellular coverage variations using SMS and local logging as backups.

## Feature Availability Notes

- Firmware differences and manufacturer firmware updates can change available alarms, command syntax, and behavior.
- Hardware revisions and regional variants may alter available inputs or supported functions.
- Installation choices such as wiring of ignition or door inputs affect which events the device can detect and report.
- Some capabilities depend on network availability and device configuration, for example whether SMS or GPRS is used as the primary channel.
- Always confirm current feature sets and supported commands with the manufacturer documentation for your unit.

Pairing the TK103B with Plaspy gives operations a single platform to receive location, alarm, and historical data from vehicles. Plaspy converts device reports into live map views, alerts, and history playback so dispatchers and managers can maintain situational awareness and react to incidents quickly.
