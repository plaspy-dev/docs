# Riti - 690s (IDU-403) Features

This page provides a public feature overview for the Riti Locator 690s (IDU-403) and how that device integrates with the Plaspy fleet management platform. It highlights the practical capabilities you can expect to see reported into Plaspy for real time tracking, telemetry, and event reporting based on the manufacturer's feature set and common deployments.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and how the device is installed and configured. Use this page for a high level understanding of capabilities and consult official Riti documentation for device specific details and the latest firmware behavior.

## Feature Overview

The Locator 690s is a compact GNSS tracker and data logger designed for professional fleet and IoT deployments. When paired with Plaspy, the device delivers continuous position reporting, driving event detection, and vehicle telemetry intended to support live monitoring, historical playback, and event alerting.

- Dual GNSS positioning with GPS and GLONASS plus assisted methods for faster fixes.
- Per second odometer and mileage reporting to support usage tracking and maintenance planning.
- Built in G sensor for driving event detection including acceleration braking cornering and impact events.
- Battery voltage monitoring and vehicle fault reporting for proactive health checks.
- Local data storage of approximately 30 000 records to preserve telemetry through connectivity gaps with automatic upload when network is restored.
- Small durable form factor suitable for discreet vehicle installation and fleet use.

## Core Features of Riti - 690s (IDU-403)

- Plaspy compatible out of the box for straightforward integration with Plaspy dashboards and mobile apps.
- Dual GNSS reception GPS plus GLONASS with A GPS and cellular based locate for improved time to first fix.
- Cellular connectivity supporting TCP UDP HTTP FTP and SMS transport protocols for flexible telemetry delivery.
- Per second odometer and accurate mileage accumulation for operational reporting.
- Built in G sensor for detection of acceleration braking cornering and impact related events.
- Battery voltage monitoring and vehicle fault detection reported as telemetry events.
- Local buffer storage of roughly 30 000 records to prevent data loss during network outages.
- SOS input and remote firmware update capability for operational continuity and incident reporting.

## How These Features Work with Plaspy

The Locator 690s streams location data and telemetry into Plaspy where those inputs are visualized and used for alerts reports and historical analysis. Plaspy automatically detects compatible tracker protocols and accepts standard transport options so devices can report with minimal backend configuration.

- Live location and route playback from GPS GLONASS and assisted fixes visible on Plaspy maps.
- Driving event alerts sourced from the G sensor such as harsh acceleration or impact forwarded to Plaspy for notifications and reporting.
- Odometer and mileage values available in Plaspy reports to support fleet utilization and maintenance workflows.
- Battery voltage and fault notifications appear in Plaspy so operators can monitor vehicle health and respond proactively.
- Local data buffering on the device preserves telemetry during outages and auto uploads to Plaspy when connectivity returns ensuring continuity of history.
- Flexible transport options let the device send telemetry to Plaspy using TCP or UDP and Plaspy will detect the tracker protocol for ingestion.
