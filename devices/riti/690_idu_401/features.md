# Riti - 690 (IDU-401) Features

This page describes the public feature context for using the Riti Locator 690 (IDU-401) with Plaspy. It focuses on the device capabilities that are relevant to Plaspy users, including on device AI event detection, automated image capture, and synchronized telemetry and image evidence that Plaspy can index and display for fleet operations.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where helpful, this page references capabilities described by the manufacturer, but you should verify device specific behavior for your deployment and confirm any optional accessories or regional variants before purchasing or installing units.

## Feature Overview

The Locator 690 is a vehicle mounted Mobile IoT device designed to add image backed evidence to conventional GPS tracking. It integrates with existing DVR and MDVR systems and provides event driven photos that are associated with GPS location and event metadata in Plaspy.

- On device AI detection that identifies abnormal driving events and triggers automated image capture for pre event, during event, and post event evidence.
- Indexing of event images alongside GPS tracks in Plaspy to speed incident review and provide visual context for location data.
- Real time retrieval of live images through the Plaspy platform and mobile apps for immediate situational awareness.
- Configurable triggers including up to five digital IO inputs to extend event detection with external sensors and triggers.
- Local buffering of GPS records and circular image storage to preserve recent history during temporary connectivity outages.
- Designed to work with existing vehicle DVR MDVR systems so video systems can remain in place while the device supplies searchable, cloud indexed images.

## Core Features of Riti - 690 (IDU-401)

- Plaspy compatible tracker designed to report telemetry and image evidence into the Plaspy platform.
- On device AI for automated detection of abnormal driving events and automatic image capture.
- Event image capture with pre event and post event indexing to help reconstruct incidents.
- Live image retrieval on demand through Plaspy and mobile applications.
- Configurable IO including support for up to five digital inputs and additional analog and sensor ports as supported by the manufacturer.
- Cellular connectivity support for stable telemetry and image upload across cellular networks.
- Local buffering for GPS records and circular storage for event images to ensure continuity when offline.
- Integration friendly form factor intended for vehicle mounting and use alongside DVR MDVR installations.

## How These Features Work with Plaspy

When connected to Plaspy, the Locator 690 synchronizes position updates and event images so fleet managers can view visual evidence together with GPS tracks. Plaspy indexes uploaded photos and associates them with event metadata so images are searchable and usable in reporting and incident workflows.

- Event indexing in Plaspy pairs pre event, event and post event photos with the corresponding GPS track and timestamp.
- Alerts and notifications in Plaspy can be tied to detected events so operations teams receive timely situational information.
- Live image retrieval through the platform enables immediate checks of vehicle surroundings without replacing existing video recorders.
- Buffered GPS and event data is forwarded to Plaspy after connectivity is restored, preserving continuity of tracks and images.
- IO triggered captures allow external sensors and inputs to initiate image capture that Plaspy will receive and index for review.

## Typical Use Cases

- Fleet incident investigation where pre event and post event images reduce time spent locating evidence in long video recordings.
- Driver behavior programs that pair detected harsh events with photographic context for coaching and review.
- Public transport and municipal fleet monitoring with live image retrieval and indexed event reporting for passenger safety oversight.
- Logistics and delivery operations combining GPS telemetry and event images with peripheral sensors for proof of service and compliance.
- Upgrading vehicle visibility without removing installed DVR MDVR systems by adding searchable image evidence to cloud tracking.
