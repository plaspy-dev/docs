# Riti - SLS-00886 Features

This page provides a public feature summary for the Riti SLS-00886 GPS vehicle tracker and explains how those capabilities relate to use with Plaspy. It describes the tracker’s user facing functions such as SMS and GPRS reporting, location tracking using a high sensitivity SiRF Star III receiver, and practical items like battery voltage detection and history recording so you can understand how the device can function in a Plaspy deployment.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, and installation method. The information below is grounded in the published SLS-00886 description and is intended as a practical, non sensitive guide; for the most current device specific details refer to the manufacturer documentation.

## Feature Overview

The SLS-00886 is designed for reliable vehicle location reporting and basic status monitoring across GSM networks. It supports sending GPS coordinates over GPRS to a backend server and can also send SMS messages directly to configured phone numbers. The tracker pairs practical reporting modes with a compact hardware footprint suitable for vehicles including motorcycles and electric bicycles.

- Real time location reporting to a backend server via GPRS for continuous tracking
- SMS messaging to user defined phone numbers as an alternative communication channel
- High sensitivity SiRF Star III GPS receiver for accurate position fixes in typical urban and suburban environments
- Vehicle battery voltage detection to give basic electrical status information
- Route monitoring and history data recording for later review of trips and positions
- Bundled free professional platform included by the manufacturer for entry level use

## Core Features of Riti - SLS-00886

- SMS and GPRS communication modes for flexible reporting and alerts
- SiRF Star III high sensitivity GPS receiver for reliable satellite fixes
- Quad band GSM module for broad cellular network compatibility
- Ability to deliver GPS coordinates to a back end server via GPRS
- Capability to send GPS position and status information by SMS to user defined numbers
- Vehicle battery voltage detection for basic status monitoring
- Built in history data recording to store route and position logs
- Suitable form factor and installation options for motorcycles and electric bicycles

## How These Features Work with Plaspy

When used with Plaspy, SLS-00886 devices report location and status information into Plaspy’s tracking platform so teams can monitor assets, review routes, and use recorded history for operations. Plaspy automatically detects many tracker protocols and provides a centralized view of incoming device data, making it straightforward to combine device reports with Plaspy visibility and reporting tools.

- GPRS delivered GPS coordinates can be received by Plaspy and displayed on maps for live location awareness
- Recorded history from the tracker can be retained and reviewed in Plaspy for route analysis and auditing
- Battery voltage detection reported by the device can be shown as a status metric inside Plaspy to help monitor vehicle power state
- SMS capability provides an independent fallback channel for position or alert delivery separate from Plaspy reporting
- Plaspy’s device detection reduces manual protocol setup so the SLS-00886 can usually be integrated with minimal configuration
- Plaspy can consolidate multiple SLS-00886 units for fleet level monitoring and operational oversight
