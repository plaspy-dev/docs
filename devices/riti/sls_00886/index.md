# Riti - SLS-00886

![SLS-00886](./logo.jpg)

The Riti SLS-00886 is a GPS vehicle tracker designed for reliable location tracking and remote monitoring of vehicles. It combines a high sensitivity SiRF Star III GPS receiver with a quad band GSM module and supports SMS and GPRS reporting. The device can deliver coordinates to a back end server or send SMS messages to user defined phone numbers, and it includes practical functions such as vehicle battery voltage detection, route monitoring, and history data recording.

As a Plaspy compatible device, the SLS-00886 can feed location and historical data into Plaspy for centralized monitoring and reporting. Its flexible reporting options and bundled free professional platform make it a practical choice for personal users and small to medium sized businesses that want to use Plaspy to gain visibility into vehicle location, movement history, and basic status information.

## Key Highlights

- High sensitivity SiRF Star III GPS for dependable position fixes
- SMS and GPRS transmission options for flexible data delivery
- Quad band GSM module for broad cellular network reach
- Ability to send coordinates to a server or direct SMS messages to users
- Bundled free professional platform suitable for small fleets and personal use
- Supports installation on motorcycles and electric bicycles and records history data
- Includes vehicle battery voltage detection for basic power monitoring

## How It Works with Plaspy

When used with Plaspy, the SLS-00886 can provide the raw location and history messages Plaspy needs to present a consolidated fleet view and operational insights. Plaspy ingests the device reports and makes them available alongside other assets, enabling unified tracking and oversight.

- Real time location visualization on Plaspy maps using the device reporting
- History playback and route monitoring from recorded data sent by the tracker
- SMS reporting can act as a fallback or direct alert channel alongside server reporting
- Fleet overview and status dashboards to monitor multiple SLS-00886 units together
- Reporting and alerting based on received messages and recorded history data
