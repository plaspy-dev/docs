# Riti - 690T (IDU-400) Features

This page provides a public, feature-oriented overview of the Riti Locator 690T (IDU-400) and how its capabilities are used with Plaspy. It summarizes the practical functions you can expect when the device is integrated into a Plaspy compatible fleet management workflow, with emphasis on cloud-based tachograph replacement, high-frequency telemetry, and I/O expansion for fleet use cases.

Exact feature availability and behavior can vary by device firmware version, hardware revision, regional variant, installation method, and manufacturer implementation. For operational deployment and detailed technical instructions consult the official Riti documentation and verify the firmware and hardware revision of your specific unit.

## Feature Overview

The 690T is a digital vehicle recorder and GPS tracker built to feed cloud telematics platforms like Plaspy with high fidelity driving records and operational data. It is designed for fleets that need searchable retention of driving logs, precise trip reconstruction, and integration of auxiliary inputs for regulatory and operational workflows.

- Cloud retention and tachograph replacement for searchable, auditable driving records within Plaspy
- High frequency telemetry capable of recording up to one sample per second for accurate trip and event reconstruction
- Cellular connectivity with fallback options to maintain data upload and real time visibility
- Flexible I/O expansion including temperature sensing, digital inputs, SOS emergency input and i-Button driver identification
- Backup lithium ion battery and continuous vehicle voltage monitoring to preserve reporting after power loss
- Tri axis G sensor for automated harsh event detection and logging

## Core Features of Riti - 690T (IDU-400)

- Digital vehicle recorder functionality for long term driving record retention and audit workflows
- High frequency telemetry sampling to support detailed trip replay and event reconstruction
- Multi band cellular connectivity with legacy network fallback to improve uptime for data uploads
- Flexible input and output expansion for temperature probes, digital sensors, SOS input and i-Button driver ID
- Integrated backup battery and continuous voltage monitoring to continue reporting during power interruptions
- Tri axis G sensor for harsh acceleration, braking, and cornering event capture
- Remote over the air firmware updates and parameter configuration to reduce field maintenance
- GNSS positioning with antenna included for satellite based location and trip logging

## How These Features Work with Plaspy

When the Riti 690T is used with Plaspy, the device streams location, driving records, and event data into the Plaspy platform where fleets can visualize, search, and retain records for inspection and auditing. Plaspy automatically detects the tracker protocol and surfaces device reported events for operational oversight and compliance workflows.

- Real time location updates and historical replay using the device's GNSS position and high frequency telemetry
- Searchable cloud storage of driving records to replace paper tachographs and simplify audit retrieval
- Driver ID entries from i-Button captured and tagged in Plaspy for duty and operator association
- Temperature input data published to Plaspy for cold chain monitoring when connected to external sensors
- Digital input events such as SOS, door or ignition changes available as alerts and reportable events in Plaspy
- Harsh event logs from the tri axis G sensor shown in driver behavior and incident reporting views

## Typical Use Cases

- Replace paper tachographs with auditable cloud storage for inspections and regulatory workflows
- High fidelity trip reconstruction for accident investigation and operational review
- Cold chain and refrigerated fleet monitoring using temperature sensor inputs and cloud retention
- Driver identification and duty logging using i-Button entries tied to recorded trips
- Safety and coaching programs using harsh event detection and driver behavior reports
- Centralized fleet visibility for dispatching, route verification, and performance reporting
