# Riti - IDU-300 Features

This page provides a public feature overview of the Riti IDU-300 and how the device can be used with the Plaspy platform for fleet tracking and operational monitoring. It summarizes the most relevant user facing capabilities, accessory compatibility, and the practical value the tracker brings when paired with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. For device specific setup, accessory wiring, or the latest technical details, review the official Riti documentation and release notes.

## Feature Overview

The IDU-300 is a 3G Intelligent Data Unit designed for fleet dispatch, monitoring, and event reporting. It emphasizes real time visibility and integration with fleet management platforms, and supports optional accessories to extend its monitoring scope.

- 3G cellular connectivity for reliable location reporting and telemetry to a fleet platform
- Real time tracking and dispatch support for operational visibility
- Compatibility with accessories such as a dispatch panel and a temperature sensor
- Reporting of abnormalities and operational events for fleet oversight
- Integration capability with fleet management platforms including eLocation and compatibility with Plaspy

## Core Features of Riti - IDU-300

- 3G based data communication for position and event reporting
- Real time GPS tracking intended for continuous vehicle location updates
- Dispatching support to integrate with operator consoles or dispatch panels
- Accessory support including a dispatch panel interface and temperature sensor input
- Abnormality reporting to flag operational issues via the tracking platform
- Designed to integrate with fleet management systems for decision support
- Suitable for deployment across small and large fleet environments

## How These Features Work with Plaspy

When the IDU-300 is used with Plaspy, device telemetry and accessory data can be routed into the Plaspy platform so fleet managers can monitor assets from a central interface. Plaspy detects compatible tracker protocols and ingests the device data for visualization and reporting.

- Live location and historical trace visualized on Plaspy maps and timeline views
- Accessory sensor readings such as temperature reported into Plaspy when the accessory is connected
- Event and abnormality reports surfaced as device events inside the Plaspy interface
- Dispatch related inputs and status updates reflected in platform monitoring tools
- Plaspy automatically detects tracker protocol and supports device connection to the Plaspy server domain for data ingestion using standard network transport options

## Typical Use Cases

- Real time vehicle dispatch and route monitoring for urban delivery fleets
- Monitoring of temperature sensitive loads when a temperature sensor is attached
- Operational oversight and abnormality reporting for mixed fleet operations
- Integration of a driver dispatch panel into a centralized fleet management workflow
- Scaling from small fleets to larger operations while maintaining centralized visibility

## Feature Availability Notes

- Some features depend on the IDU-300 firmware version and may require a firmware update to enable specific behaviors
- Hardware revisions and regional product variants can affect accessory interfaces and supported inputs
- Accessory compatibility such as dispatch panels and temperature sensors may require specific wiring or optional modules from the manufacturer
- Installation type and vehicle wiring can influence which inputs are available and how events are reported
- Always confirm supported features and accessory specifications with the manufacturer documentation for your unit

## Why Use Plaspy with These Features

Combining the Riti IDU-300 with Plaspy gives organizations a practical way to centralize vehicle location, accessory sensor data, and event reporting in a single platform. Plaspy's device detection and platform features help convert raw tracker data into actionable operational insights for dispatch, compliance, and fleet efficiency.
