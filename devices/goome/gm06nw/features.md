# Goome - GM06NW Features

This page provides a public, features-oriented overview of the Goome GM06NW and how its capabilities are used with the Plaspy fleet platform. It covers the main user-facing functions you can expect to see in Plaspy when the GM06NW is installed and configured to report to the Plaspy service.

Exact feature availability and behavior can vary based on firmware version, hardware revision, installation method, and how the manufacturer implements particular functions. For device specific configuration and the most current technical details, review the official Goome documentation and firmware notes.

## Feature Overview

The GM06NW is a compact GPS tracker that combines GSM communication with GPS positioning and a set of vehicle-oriented sensors and control outputs. It is designed to provide continuous location awareness, basic vehicle event reporting, and a small set of remote control and alarm functions that are useful for vehicle monitoring and security.

- Real time GPS location reporting for live tracking and route visibility
- Geo fence support to notify when a vehicle enters or exits defined zones
- Tracking playback to review historical routes and stops over time
- ACC detection for engine or ignition state monitoring
- Vibration alarm to notify of unusual movement or potential tampering
- Remote fuel or electricity cut off function to assist with vehicle immobilization

## Core Features of Goome - GM06NW

- GPS positioning combined with GSM communications for location reporting
- ACC detection for basic ignition or vehicle on off state reporting
- Vibration alarm for tamper or movement alerts
- Remote power or electricity cut off capability for immobilization where supported
- SOS button and optional microphone support to send SOS alerts and enable audio listening when wired and configured
- Geo fence support for entry and exit notifications
- Tracking history playback to review past routes
- Small form factor and wide input voltage range suitable for many vehicle types

## How These Features Work with Plaspy

Plaspy displays location and event data reported by compatible trackers like the GM06NW, helping operators monitor vehicles, review history, and respond to alarms. Plaspy automatically detects supported tracker protocols and accepts device reports configured for the Plaspy server, allowing visibility into position and event streams without manual protocol selection.

- Live map view showing the GM06NW reported position updates and status
- Geo fence events surfaced as notifications or activity entries in the platform
- Route playback in Plaspy using the device's stored or reported location history
- Alarm and event indicators for vibration and ACC changes to aid incident response
- Remote control state and commands can be represented in Plaspy where the device and installation support remote cut off or similar control operations
- Plaspy recognizes common transport settings and can accept device connections using UDP or TCP on the platform port used for devices

## Typical Use Cases

- Fleet vehicle location monitoring for cars, trucks, and taxis
- Theft detection and response using vibration alarms and remote cut off
- Driver route review and trip playback for operational oversight
- Personal vehicle tracking and family safety monitoring with SOS support
- Motorcycle tracking where compact size and wide input range are helpful
- Short term rental or shared vehicle monitoring for entry exit enforcement
