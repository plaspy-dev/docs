# Goome - GM02G Features

This page describes the public feature context for using the Goome GM02G GPS tracker with Plaspy. It summarizes the tracker capabilities that are relevant for monitoring, alerts, and historical review when the device is connected to the Plaspy platform and visible within Plaspy dashboards.

Exact feature availability and behaviour can vary by device firmware, hardware revision, installation method, and manufacturer settings. The content below is grounded in the manufacturer description of the GM02G and focuses on practical, non-sensitive information for use with Plaspy.

## Feature Overview

The GM02G is a compact in-vehicle tracker designed for discreet installation and continuous location monitoring. It supports both real-time reporting and periodic reporting behavior that conserves power, combined with several vehicle security and historical review features useful for fleet or personal vehicle oversight.

- Compact, easy to install form factor suitable for discreet in-vehicle placement
- Real-time tracking for live location visibility and monitoring
- User-defined geo-fence support with entry and exit alerting
- Trace playback for reviewing historical vehicle movement
- ACC detection to report vehicle ignition status and related events
- Built-in anti-spy and sleep functions to control reporting intervals and motion-based reporting

## Core Features of Goome - GM02G

- Real-time location tracking to provide current vehicle position
- Anti-spy technology and configurable sleep function that controls when the device connects to the server
- Geo-fence capability allowing boundaries to be set and alerts generated on entry or exit
- Trace playback for historical route review and auditing
- ACC detection to monitor ignition or vehicle power status changes
- Over-speed alarm to signal when a configured speed threshold is exceeded
- Cut wire and vibration alarms to indicate tampering or unauthorized movement
- Built-in acceleration sensor to detect sudden changes in motion or driving behavior

## How These Features Work with Plaspy

Plaspy receives and displays the tracking and event data sent by the GM02G, helping teams monitor assets and respond to events in near real time. Plaspy is designed to detect many common tracker protocols automatically, which simplifies bringing a compatible tracker online.

- Live position updates shown on Plaspy maps for ongoing location awareness
- Geo-fence events appear as alerts or notifications when boundaries are crossed
- Historical trace playback accessible in Plaspy based on the device's recorded reports
- Security events such as over-speed, cut wire, vibration, and ACC changes are represented as event notifications for operational follow up
- Motion- or schedule-driven reporting behavior from the device can reduce unnecessary updates and is reflected in Plaspy as periodic or on-motion location records

## Typical Use Cases

- Fleet vehicle location monitoring for route oversight and dispatching
- Theft detection and tamper alerts using cut wire and vibration alarms
- Reviewing historical routes for compliance, driver coaching, or incident investigation
- Monitoring vehicle ignition status to confirm usage or detect unauthorized operation
- Discreet tracking of vehicles where hidden installation is required
- Alerting operations teams when vehicles enter or exit predefined areas

## Feature Availability Notes

- Feature presence and behavior can differ by GM02G firmware version and hardware revision
- Some alarms and detection functions require correct wiring and installation to operate as described
- Regional or carrier variants may affect reporting frequency and network connectivity
- Manufacturer default settings can influence reporting intervals and alarm thresholds
- Always consult official Goome documentation for device-specific configuration steps and the latest firmware notes
