# Goome - EV02 Features

This page provides a public feature overview for the Goome EV02 and how its capabilities are used with Plaspy. It is intended to summarize the EV02's practical functions, the user value they deliver, and how those functions appear when the device is connected to the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For precise device specifications, firmware behavior, and installation guidance always consult the official Goome documentation and the device firmware release notes.

## Feature Overview

The Goome EV02 is an electric motor positioning terminal designed for the electromobile and motorcycle market. It pairs cellular connectivity with satellite positioning to deliver discreet, continuous tracking and basic anti-theft monitoring in a compact package.

- GSM GPRS GPS connectivity for continuous position reporting and communication
- Real-time tracking to view current vehicle location and movement
- User defined geo-fence support to notify when a vehicle enters or exits a boundary
- Trace playback to review historical routes and journeys
- Compact form factor and built-in antenna for easy concealment and reliable reception

## Core Features of Goome - EV02

- GSM GPRS GPS connectivity for combined cellular communication and satellite positioning
- Real-time tracking for immediate location visibility
- User defined geo-fence capability for virtual boundary monitoring
- Trace playback for historical route review and analysis
- Built-in antenna designed to support consistent signal reception
- Compact, discreet enclosure suitable for installation on electric motor vehicles and motorcycles
- Design focus on anti-theft positioning and vehicle security monitoring

## How These Features Work with Plaspy

When the EV02 is used with Plaspy, its core functions translate into visibility and operational insight inside the Plaspy platform. Plaspy automatically detects compatible tracker protocols and surfaces device reports without requiring manual protocol selection.

- Real-time device locations appear on Plaspy maps for live monitoring and dispatching
- Historical trace playback from the EV02 is available in Plaspy for route review and audit
- Geo-fence events configured on the device or in Plaspy generate alerts and event logs for operational oversight
- Compact device status and connectivity information are reflected in Plaspy so teams can verify reporting health
- Plaspy supports standard connections and will detect the EV02 protocol to accept position reports and events

## Typical Use Cases

- Anti-theft monitoring for electric scooters, mopeds, and motorcycles
- Fleet visibility for small commercial electric vehicle fleets
- Route review and incident investigation using trace playback
- Perimeter and area control using geo-fences for restricted zones or parking areas
- Discreet installation where a small, concealed tracker is preferable
