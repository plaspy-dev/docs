## How Goome devices work with Plaspy

Many Goome trackers use standard GPS and cellular connectivity to report location and basic telematics. Plaspy receives device data via supported tracker protocols and makes that information available through a unified dashboard. When a Goome model is compatible, Plaspy can display real time location, history, and alerts from that device so you can manage tracking, reporting, and notifications from one platform.

Compatibility depends on the specific model and its firmware. The Brand Catalog above links to each compatible model so you can view device details and the exact instructions needed to connect it to Plaspy.

## Common features found in Goome devices

Goome hardware typically provides core tracking capabilities useful across many deployments. Common features you can expect at a general level include:

- Cellular connectivity for live updates

Plaspy surfaces these capabilities in the platform so you can configure alerts, view maps, and export tracking data. For fine grained feature lists and sensor support refer to the model pages in the catalog.
