# Goome - U9 Features

This page provides a public overview of the Goome U9 feature set and how those capabilities are presented when the device is used with Plaspy. It summarizes practical, non-sensitive information about location modes, alarms, remote control features, and common operational uses so fleet managers and integrators can quickly understand what to expect from the U9 in Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, and installation method. The notes below use the manufacturer description as the primary source; for device-specific configuration or the latest firmware behavior refer to the official Goome documentation.

## Feature Overview

The Goome U9 is described as a compact, high-accuracy tracker that combines GPS, AGPS, and LBS location modes. It is designed to provide continuous location awareness and includes several built-in alarm and remote control capabilities that support vehicle and asset management workflows.

- Multi-mode positioning: GPS, AGPS, and LBS modes for flexible location reporting.
- Automatic fallback to LBS when GPS signal is poor to maintain location visibility.
- Real-time tracking and trace playback for historical route review.
- User-defined geo-fencing for entry and exit monitoring of defined areas.
- Alarms and remote controls including SOS, cut wire alarm, vibration alarm, and remote engine cutoff via relay.
- Compact hardware design suited for discreet installation.

## Core Features of Goome - U9

- GPS, AGPS, and LBS positioning modes for improved location availability.
- Automatic LBS activation when GPS reception is insufficient.
- Real-time tracking to report current position and status.
- Trace playback to review historical movement and routes.
- User-defined geo-fencing to detect and report area breaches.
- SOS button support for emergency notifications.
- Cut wire alarm and vibration alarm for tamper and movement detection.
- Remote relay control to allow authorized remote engine cutoff when supported by installation and wiring.

## How These Features Work with Plaspy

Plaspy displays and stores key events and location updates from supported trackers like the Goome U9 so teams can monitor assets and act on alerts. When the U9 reports position or alarms, Plaspy surfaces those events in the platform for operational oversight and historical review.

- Real-time location updates appear on Plaspy maps and dashboards for live tracking.
- Trace playback data is available for route reconstruction and compliance checks.
- Geo-fence events (enter and exit) are recorded and can generate notifications inside Plaspy.
- SOS, cut wire, and vibration alarms are presented as events so operators can respond quickly.
- Remote relay actions and related state changes can be tracked in Plaspy when the device and installation expose those events to the server.

## Typical Use Cases

- Fleet monitoring for vehicles where continuous position and route history are required.
- Asset protection with tamper detection and vibration alarms for mounted equipment.
- Remote intervention workflows that use relay control to disable a vehicle in coordination with local procedures.
- Emergency response scenarios relying on the SOS button to escalate incidents.
- Geofence based operations such as delivery zone monitoring or site access control.
- Mixed connectivity environments where LBS fallback helps keep assets visible indoors or in urban canyons.

## Feature Availability Notes

- Firmware differences and software settings can enable or disable specific alarms and remote controls.
- Hardware revision and how the device is wired during installation determine whether relay and cutoff functions are available.
- Regional model variants may alter supported features or regulatory behavior.
- Some features require explicit configuration on the device and in the tracking platform to appear correctly in Plaspy.
