# Parallel track - Trackbox

![Trackbox](./logo.jpg)

The Parallel Trackbox is a versatile GPS tracker that allows you to easily monitor the location of your assets. This hardware device is designed to report its location at regular intervals to a predefined web service, such as Parallel Track, via the mobile phone network or SMS text message on request. With the Trackbox, you can have real-time tracking integrated into your web presence through popular mapping services like Google Maps, Yahoo Maps, or Microsoft Virtual Earth.

One of the key features of the Parallel Trackbox is its ability to send data via standard POST, making it easy to integrate with your own website. Whether you want to track vehicles, equipment, or even people, this GPS tracker provides accurate and reliable location information. With its compact design and easy installation, the Trackbox is suitable for a wide range of applications, including fleet management, asset tracking, and personal tracking.

Key Features:

- Real-time tracking of assets
- Reports location at regular intervals
- Supports mobile phone network and SMS text message
- Integration with popular mapping services
- Data sent via standard POST
- Compact design and easy installation
- Suitable for fleet management, asset tracking, and personal tracking
