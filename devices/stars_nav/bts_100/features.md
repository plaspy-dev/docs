# Stars Nav - BTS-100 Features

This page provides a public feature overview of the Stars Nav BTS-100 and how its capabilities map to use with Plaspy. It focuses on the practical, user facing functions that matter for real time tracking, POI reminders, and telemetry reporting into Plaspy without exposing sensitive configuration details.

Exact feature availability can vary by firmware version, hardware revision, regional model, installation method, and how the manufacturer implements specific options. For precise, device specific behavior consult official Stars Nav documentation and release notes before purchase or deployment.

## Feature Overview

The BTS-100 is a compact in vehicle GPS receiver that streams location and basic telemetry over Bluetooth Serial Port Profile while also providing local speed camera POI reminders. It is designed for in cab use, offering configurable POI storage and energy saving features that make it useful for both temporary and long term installations.

- Streams position and basic telemetry data including longitude, latitude, speed, and UTC over Bluetooth SPP for use with Plaspy connected devices.
- Local POI speed camera reminders with audible speaker and LED notifications to help drivers maintain awareness of camera locations.
- Long run time from an internal rechargeable battery and motion sensing power management for extended in vehicle operation.
- Configurable POI databases uploaded via mini USB and supplied PC utility for customized camera lists.
- Adjustable trace logging intervals to support either high frequency tracking or periodic telemetry to conserve resources.

## Core Features of Stars Nav - BTS-100

- Bluetooth Serial Port Profile streaming of NMEA like position and speed data for external devices and gateways.
- Integrated speed camera POI reminder system with speaker and LED alerts for in cab notifications.
- Internal rechargeable 1100 mAh Li ion battery with extended continuous operation and motion activated power saving.
- High sensitivity GNSS receiver with multi channel tracking to support fast and reliable position fixes.
- User configurable POI storage with optional flash capacities and upload via mini USB and PC utility.
- Flexible trace interval settings ranging from high frequency to periodic logging to match operational needs.
- Compact plug and play form factor for straightforward in vehicle placement and quick pairing to mobile devices.

## How These Features Work with Plaspy

When paired to a Plaspy compatible gateway or device that accepts external GPS input, the BTS-100 supplies recurring location updates and basic telemetry that Plaspy uses for mapping, alerts, and historical reporting. POI data remains available locally for driver warnings while Plaspy stores and presents fleet level insights.

- Real time location and telemetry updates for map visualization and live tracking in Plaspy.
- Speed and position data from the device support route replay, event timelines, and reporting inside Plaspy.
- Local POI alerts act as a driver safety layer while Plaspy retains the telemetry history for compliance and review.
- Configurable trace intervals let you balance update frequency between immediate visibility in Plaspy and longer battery life.
- POI and device configuration managed via PC utility remain local to the unit but complement Plaspy reporting workflows.

## Typical Use Cases

- Provide an external GPS source to older navigation units and mobile devices that accept Bluetooth SPP input.
- Fleet drivers who benefit from local speed camera reminders in addition to centralized tracking and reports.
- Temporary or shared vehicle deployments where a portable Plaspy compatible GPS source is required.
- Situations that need reliable position streaming for real time location visibility and basic speed telemetry.
- Integrations where a classic Bluetooth serial GPS feed is preferred by existing in cab hardware.
