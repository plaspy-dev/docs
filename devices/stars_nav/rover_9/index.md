# Stars Nav - Rover 9

![Rover 9](./tracker.jpg)

The Rover 9 vehicle tracker is a compact, professional-grade GPS tracker built for fleets, security providers, and businesses that require dependable Plaspy compatible real-time tracking. Equipped with a SiRFstarIII GPS module and GPRS communication, the Rover 9 delivers consistent satellite positioning and telemetry while supporting over-the-air programming and updates for remote configuration and maintenance.

The device is designed for vehicle and asset applications where durability and uninterrupted reporting matter: a wide input voltage range \(6–37 V\) accommodates cars, trucks, lorries, and motorcycles, and a built-in backup battery provides 4–8 hours of portable operation when vehicle power is lost. With multiple alarm inputs, immobilizer control, analog monitoring for fuel and temperature, and Bluetooth output, the Rover 9 integrates smoothly with Plaspy for fleet management, anti-theft protection, and telemetry-driven workflows.

## Key Highlights

- Plaspy compatible GPS tracker with SiRFstarIII GNSS for reliable real-time tracking and position fixes.
- Wide 6–37 V input plus built-in backup battery \(4–8 hours\) to maintain reporting during power loss or tampering.
- GPRS communication with sleep mode to reduce data costs and conserve power for long deployments.
- Comprehensive security features: multiple alarm inputs, panic input with automatic emergency dial-out, immobilizer control, and door release output.
- Analog inputs to support fuel monitoring, temperature sensing, or air pressure telemetry for insurance telematics and cold-chain dispatches.
- Driver ID verification and hands-free voice communication to improve driver accountability and in-field coordination.
- Over-the-air programming and updates for remote configuration, ensuring scalable fleet management without downtime.

## How It Works with Plaspy

When integrated with Plaspy, the Rover 9 streams essential location and vehicle data for immediate use in dashboards, alerts, and reports. Plaspy ingests GPS positions, speed and heading, alarm triggers, and analog telemetry so fleet managers and security teams can monitor vehicles in real time, automate rules, and respond quickly to incidents.

- Real-time location and telemetry updates: GPS fixes from the SiRFstarIII module are delivered to Plaspy for live tracking and history.
- Door, alarm, and immobilizer status: multiple alarm inputs, immobilizer control, and door release outputs report security events and support remote immobilization workflows.
- Fuel monitoring and temperature telemetry: analog inputs allow Plaspy to receive fuel level changes and temperature readings for cost control and cold-chain compliance.
- Panic and emergency reporting: panic input with automatic emergency dial-out triggers immediate alerts within Plaspy for rapid response coordination.
- Driver identification and communications: driver ID events and hands-free voice calls can be logged and acted on through Plaspy for driver behavior and incident context.
