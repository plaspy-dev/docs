# Stars Nav - Photo GPS Features

This page provides public feature context for using the Stars Nav Photo GPS with Plaspy. It summarizes the device capabilities that are relevant to photographers, travel users, and operations teams who want to combine logged GPS data and photos inside the Plaspy platform. The focus here is on practical functions and how the Photo GPS data can be used in Plaspy workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation and usage patterns, and manufacturer implementation. For device specific technical details, configuration steps, and the most current behavior, always consult the official Stars Nav documentation.

## Feature Overview

The Stars Nav Photo GPS is designed as a portable GPS logger that stores location records on removable micro SD media and is recognized by a PC as a removable storage device. Its design emphasizes simple data capture for photo geotagging and compatibility with common geo-tagging and photo services.

- Portable GPS logger that mounts as removable storage when connected to a PC
- Uses micro SD cards for expandable storage to accommodate large photo collections
- Produces plain text log files containing longitude, latitude, altitude, time, speed, and direction
- Compatible with popular geo-tagging software and web album services for attaching location data to photos
- Long battery operation on a rechargeable Li‑ION cell suitable for daylong outings
- Visible device state via 4 LEDs for GPS status, memory status, charging, and error or low power indication

## Core Features of Stars Nav - Photo GPS

- Removable storage interface for simple drag and drop access to logged files on a PC
- Expandable storage through micro SD cards for extended recording capacity
- Plain text track logs that include longitude latitude altitude time speed and direction for easy parsing
- Default logging interval of 8 seconds in power saving mode to capture regular position samples
- Compatibility with common geo tagging software and web album services such as Locr Picasa and Google Panoramio
- Rechargeable Li ion battery with long operation time suitable for extended field use
- Compact lightweight design with four LED indicators for quick operational feedback

## How These Features Work with Plaspy

Plaspy can use the Photo GPS output to visualize and manage location data alongside other fleet or asset information. Because the device generates standard text log files and presents them as removable storage, those logs can be imported into Plaspy or processed externally and then uploaded to Plaspy for mapping and analysis.

- Import text log files from the Photo GPS into Plaspy for mapping and timeline visualization
- Match photo timestamps to coordinates to create geotagged photo markers inside Plaspy
- Store and archive trip logs from the device in Plaspy for historical review and reporting
- Use Plaspy tools to view routes speed and directional information derived from the device logs
- Plaspy detects supported tracker formats and can assist with importing commonly used file types for location data

## Typical Use Cases

- Geotagging photo collections from trips fieldwork or events for archiving and sharing
- Travel and landscape photography workflows that require post processing of location metadata
- Creating mapped photo albums for blogs portfolios or social sharing platforms
- Recording routes and location context for field research or site documentation
- Long day outings where extended battery life and expandable storage are priorities
