# Stars Nav - PT-33 Features

This page provides a public feature overview for the Stars Nav PT-33 personal tracker and how its capabilities are used with the Plaspy platform. It highlights what the device reports, the kinds of alerts and logs it supports, and how that information can appear inside Plaspy for monitoring and investigation.

Exact feature availability depends on the device firmware, hardware revision, installation type and the manufacturer's implementation. Some functions described here may be configurable or limited by regional variants, SIM and network setup, or firmware options, so consult the official manufacturer documentation for the most current device-specific details.

## Feature Overview

The PT-33 is a compact personal GPS/GSM tracker designed for reliable location reporting, long-term logging and emergency alerting. Its practical value in Plaspy comes from continuous position updates, stored route history, and on-device alert features that feed into Plaspy's mapping and notification tools.

- Accurate GNSS positioning provided by a u-blox LEA-5S module for regular location updates.
- Large on-board storage capable of holding up to 100,000 location records for later upload and route review.
- Dedicated panic button for immediate alerting and location sharing to authorized contacts and monitoring platforms.
- Auto-answer function that permits authorized callers to access live audio monitoring when configured.
- Configurable low-power and sleep modes to extend deployment life while preserving location logging.
- Built-in event reporting such as speeding alerts, stop-motion or park alerts, and support for up to 10 geo-fenced zones.

## Core Features of Stars Nav - PT-33

- u-blox LEA-5S GNSS module for satellite based positioning and dependable fixes.
- Large internal log memory with capacity for extensive historical records.
- Dedicated panic button to generate immediate alerts and transmit location.
- Auto-answer capability for authorized incoming calls to enable live audio monitoring.
- Configurable low-power and sleep modes to balance battery life and reporting frequency.
- Geo-fence support with multiple programmable zones and entry exit notifications.
- Event reporting including speeding alerts and stop-motion or park alerts.
- Selectable coordinate formats to match mapping and telematics workflow requirements.

## How These Features Work with Plaspy

When the PT-33 is deployed with Plaspy, device position reports, alerts and historical records are incorporated into Plaspy dashboards and workflows for live monitoring and post-event analysis. Plaspy automatically detects compatible tracker protocols and maps incoming data to platform features that support operational oversight.

- Live GPS position updates appear on Plaspy maps for real time tracking and location awareness.
- Panic button activations are forwarded as event notifications so responders and administrators can act quickly.
- Stored location logs can be uploaded to Plaspy for historical route reconstruction and audit reports.
- Geo-fence entry and exit events and speeding or stop-motion alerts show up as rule based notifications within Plaspy.
- Auto-answer capability on the device enables authorized monitoring workflows where voice access is required, subject to configuration and local regulations.

- Outdoor recreation and search and rescue where offline logging and later download are valuable.

- Small asset or portable equipment tracking where compact, wearable devices are needed.
