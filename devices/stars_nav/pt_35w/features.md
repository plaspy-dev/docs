# Stars Nav - PT-35W Features

This page describes the public feature context for using the Stars Nav PT-35W tracker with Plaspy. It focuses on the practical capabilities you can expect when integrating this model into Plaspy for location, status reporting, and basic remote control workflows. The content is intended to help fleet managers, installers, and asset owners understand what the PT-35W delivers in typical Plaspy deployments.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The PT-35W description here is drawn from the device documentation and public manufacturer materials and is presented at a features level suitable for Plaspy integration and operational planning.

## Feature Overview

The PT-35W is a compact, rugged GPS tracker designed for outdoor and marine use with a focus on long standby life and reliable location reporting. It pairs GPS-based position reporting with SMS remote control and a built-in backup battery, making it practical for intermittently powered equipment and unattended assets that need periodic checks or anti-theft responses.

- IP66 rated waterproof housing for exposed outdoor and marine mounting
- GPS based location reporting for real time and periodic position updates
- Internal backup battery plus configurable low power sleep mode for extended standby
- SMS remote control including engine on and engine off command support for remote immobilization workflows
- Panic input for emergency alerts and rapid incident notification
- Automatic return online and battery charging behavior when external power is restored

## Core Features of Stars Nav - PT-35W

- IP66 rugged casing suitable for motorcycles, small boats, caravans, and exposed equipment
- GPS location reporting for tracking and position history
- Wide power input range and automatic battery charging when external power is available
- Internal backup battery with configurable low power sleep mode for long standby
- SMS remote control features including engine on and engine off commands
- Panic input to signal emergency or alert conditions
- Designed for long term unattended tracking and intermittent external power scenarios

## How These Features Work with Plaspy

Plaspy can ingest the PT-35W location and status information so operators can monitor assets, receive alerts, and manage remote workflows from a centralized platform. Integration depends on the device connectivity variant in use and carrier behavior, but the PT-35W features translate into actionable data and events inside Plaspy.

- GPS location updates become map position and breadcrumb history in Plaspy
- Panic input activations and alarm events are represented as alerts for rapid handling
- Online and offline behavior plus sleep and wake events show device availability and battery driven status
- SMS based remote engine on and engine off commands can be used as part of anti-theft or recovery procedures where SMS control is enabled
- Plaspy supports ingestion via standard device protocols or SMS gateways depending on your network and device configuration

## Typical Use Cases

- Motorcycle and scooter tracking for fleet or individual asset monitoring
- Marine and small boat tracking where weather resistance and compact mounting are required
- Caravan and trailer monitoring for location awareness and long standby operation
- Long term unattended asset tracking for seasonal equipment and stored vehicles
- Anti theft and recovery workflows using SMS remote control and panic input alarms
- Periodic inspection and maintenance checks with automated wake on external power
