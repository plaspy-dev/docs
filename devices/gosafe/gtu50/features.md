# Gosafe - GTU50 Features

This page describes the public feature context for using the Gosafe GTU50 GPS tracker with Plaspy. It summarizes the model's practical capabilities and explains how those capabilities are typically used inside Plaspy for monitoring, event handling, and operational oversight.

Exact feature availability can vary by firmware version, hardware revision, how the unit is installed, and manufacturer implementation choices. For the most current device specific details refer to the official manufacturer documentation and release notes.

## Feature Overview

The GTU50 is a compact LTE Cat‑1 tracker with multi GNSS and event logging designed for covert vehicle installations. When paired with Plaspy it provides location visibility, event alerts, and control options that support recovery, fleet operations, and telematics workflows.

- Real time location tracking and position reporting suitable for fleet monitoring and recovery.
- Crash detection and high rate accelerometer logging for incident awareness and post event analysis.
- Ignition sensing and digital relay output to support trip detection and remote immobilization workflows.
- Onboard backup battery and flash memory for short term offline logging and tamper resilience.
- Small covert form factor and wide vehicle voltage support for flexible installations.

## Core Features of Gosafe - GTU50

- LTE Cat‑1 cellular connectivity with 2G fallback for broad network coverage and reliable data transport.
- Integrated multi GNSS receiver combining GPS GLONASS Beidou with assisted positioning for dependable location fix.
- 3 axis accelerometer with high rate crash data recording to capture collision and driver behavior events.
- Ignition detection to mark trip start and stop events and support usage based reporting.
- Digital input for SOS or panic signaling to trigger immediate alerts.
- Digital output to control a relay for starter blocking or immobilizer workflows.
- Internal backup battery and onboard flash memory for local logging during power or connectivity loss.
- Compact, weather resistant housing suitable for covert vehicle and powersport installations.

## How These Features Work with Plaspy

Plaspy ingests the GTU50 telemetry and exposes location and event information in dashboards, alerts, and reports so operators can act on real world events quickly.

- Real time location updates appear in Plaspy mapping and historical playback for route review.
- Ignition events are translated into trip start and stop markers and support driver hours and utilization reporting.
- Crash and accelerometer events are surfaced as incidents with associated high rate logs for investigation or insurer review.
- SOS input can generate immediate alerts and location push to operational teams tracked through Plaspy.
- Digital output status and immobilization commands can be coordinated through Plaspy workflows for recovery or anti theft operations.
- Offline log retrieval and synchronization lets Plaspy recover missed records when the device reconnects.

## Typical Use Cases

- Fleet management for service vans, delivery vehicles, and mixed fleets needing location visibility and trip reporting.
- Stolen vehicle recovery combined with immobilization workflows coordinated through Plaspy.
- Usage based insurance and driver behavior programs using crash and accelerometer telemetry.
- Rental fleet and BHPH inventory control where covert installation and remote control reduce loss.
- Motorcycle and powersport tracking where small form factor and wide voltage tolerance matter.
- Last mile delivery tracking with incident logging and trip reconciliation.
