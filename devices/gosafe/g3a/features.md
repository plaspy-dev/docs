# Gosafe - G3A Features

This page provides a public, non-sensitive overview of the Gosafe G3A tracker and how its capabilities map to the Plaspy fleet and asset monitoring platform. It focuses on the practical functions you can expect when using the G3A with Plaspy and outlines the operational value these features deliver for location awareness and event visibility.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation wiring, and manufacturer implementation. Use this page as a general guide and consult manufacturer documentation or your installer for device specific details and the latest firmware behavior.

## Feature Overview

The Gosafe G3A is a compact tracker that combines continuous tracking resilience with motion awareness and anti-jamming detection in a small form factor. It supports configurable upload modes and external inputs, making it adaptable for a range of tracking scenarios.

- Compact and lightweight design suitable for discreet installations and tight spaces
- Internal backup battery to maintain tracking during external power loss
- GSM jamming detection to alert on potential signal interference events
- Multiple upload modes including distance, change of course, time, and event-based reporting
- Support for external microphone connection and various analog inputs for extended monitoring
- Built-in 2D accelerometer for motion and position change detection

## Core Features of Gosafe - G3A

- Internal backup battery for continued reporting when external power is interrupted
- GSM jamming detection system to identify attempts to interfere with cellular connectivity
- Multiple I/O and configurable upload modes such as distance, change of course, time interval, and event upload
- Connection options for an external microphone and analog inputs to broaden monitoring capability
- Internal 2D accelerometer for detecting motion, stops, and movement events
- Small form factor that supports flexible installation locations
- Compatibility with Plaspy for reporting location and event data into a centralized platform

## How These Features Work with Plaspy

Plaspy receives and interprets the G3A's location and event messages so you can monitor devices on maps, review event histories, and configure notifications. Plaspy automatically detects the tracker protocol and accepts device reports into the service, allowing the G3A to be integrated with standard Plaspy monitoring workflows.

- Location updates and time/distance or event-based reports appear in Plaspy as regular position messages for map and history views
- Motion and accelerometer-based events enable activity status and movement detection inside Plaspy dashboards
- GSM jamming alerts from the G3A are surfaced as events so operators can investigate potential interference
- External input events (microphone or analog inputs) can be shown as custom events or auxiliary signals within Plaspy where supported
- Devices configured to report to Plaspy are typically set to point to the Plaspy server and Plaspy will handle protocol detection and ingestion

## Typical Use Cases

- Vehicle location tracking for route oversight and historical trip review
- Asset monitoring where compact size and a backup battery are required
- Detection of potential signal interference in areas with known jamming risk
- Motion-based monitoring to detect unauthorized movement of equipment or assets
- Use with external analog inputs or microphone for applications that need extra sensor signals alongside GPS

## Feature Availability Notes

- Feature presence and behavior can depend on the device firmware version and the specific hardware revision of the G3A
- Certain inputs or attachments such as microphone or analog sensors require correct wiring and configuration at installation
- Upload modes and thresholds (distance, time, change of course) are configurable and may vary by firmware or device configuration
- Regional cellular variants or firmware builds can affect how jamming detection and reporting operate
- Always verify the exact capabilities of a device with the manufacturer and consult official docs when planning deployments

Pairing the Gosafe G3A with Plaspy gives organizations a straightforward way to consolidate location, motion, and event data into a single monitoring platform. Plaspy's automatic protocol detection and centralized event handling let operators view position history, receive alerts for jamming or motion, and include external input events in operational workflows.
