# Gosafe - GTU100

<div className="device-logo">
![GTU100](./tracker.jpg)
</div>

The GTU100 is a compact, high performance GPS tracker designed for light and commercial fleet management. It provides continuous position updates and vehicle telemetry using multi GNSS positioning and cellular connectivity with fallback options. The device is built to support crash detection and integrated sensor telemetry, making it suitable for operators who need dependable tracking and event capture in everyday fleet operations.

As a Plaspy compatible device, the GTU100 is optimized for rapid integration into fleet management workflows. Onboard event processing and remote device management features simplify rollout and maintenance, while cellular connectivity and sensor support enable Plaspy to ingest location, motion and asset data for real time monitoring, alerts and reporting. This combination makes the GTU100 a practical choice for fleets that want consolidated visibility through Plaspy.

## Key Highlights

- Plaspy compatible GPS tracker offering resilient cellular connectivity with fallback for broad coverage.
- High sensitivity multi GNSS reception for improved positioning and consistent location updates.
- Built in event processing and device management to simplify large scale deployments and ongoing operations.
- Onboard motion detection and crash capture to support timely alerts and incident workflows.
- Configurable inputs and outputs plus support for external sensors to extend functionality for vehicle and cargo monitoring.
- Low power design and a compact vehicle ready form factor to suit mixed fleet installations.

## How It Works with Plaspy

When paired with Plaspy, the GTU100 acts as a telemetry node that streams location, motion and sensor data into the platform for live tracking, alerting and historical analysis. Plaspy can use events generated on the device alongside cloud based rules and reporting to deliver operational insights and manage fleets efficiently.

- Real time location and telemetry feed Plaspy for accurate vehicle tracking and route visibility.
- Trip and driver correlation use ignition sense and driver ID inputs so Plaspy can report runtimes and driver activity.
- Impact and motion events trigger immediate alerts and crash reporting workflows inside Plaspy.
- Remote control and immobilization workflows are supported through configurable outputs and Plaspy driven commands.
- Wireless sensor telemetry such as temperature or door status is ingested by Plaspy for asset condition monitoring.
- Remote management and OTA updates help keep device fleets consistent and maintainable from Plaspy integrated operations.

## Typical Use Cases

- Fleet management for light commercial vehicles with trip logging, driver identification and operational reporting.
- Anti theft and immobilization workflows tied to alerts and remote disable features via Plaspy.
- Crash detection and post event analysis using onboard motion sensing and incident data in Plaspy.
- Temperature and cargo condition monitoring with external sensors for refrigerated or sensitive loads.
- Mixed fleet deployments requiring reliable connectivity and centralized oversight across regions.

The GTU100 combines practical vehicle focused features with onboard event handling and remote management to reduce operational friction for fleet teams. Its multi GNSS positioning, resilient cellular connectivity options and sensor support help maintain continuous visibility for managers using Plaspy, while built in event processing reduces unnecessary data traffic and supports immediate workflows.
