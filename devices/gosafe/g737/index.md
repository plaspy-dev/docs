# Gosafe - G737

![G737](./tracker.png)

The G737 Ankle Bracelet is a purpose-built, Plaspy compatible GPS tracker engineered for continuous electronic monitoring of parolees and offenders. Combining a high-precision 56-channel uBlox GNSS engine with SBAS support, LTE CAT-1 cellular connectivity, tamper-evident fiber-optic strap design and BLE-based home beacon support, the G737 delivers reliable real-time tracking, tamper alerts and event telemetry for court, corrections and community supervision programs.

Designed for field reliability and seamless integration with Plaspy, the G737 supports edge recording, geofence enforcement and over-the-air firmware updates \(FOTA\) so agencies can scale monitoring, automate alerts and centralize reports. Its rugged, waterproof construction and extensive event logging make it suitable for continuous ankle-worn use while providing the data and alerts Plaspy needs to manage compliance, anti-theft detection, and program workflows.

## Key Highlights

- Plaspy compatible GPS tracker: delivers precise location and event telemetry to Plaspy for real-time tracking and reporting.
- High-accuracy positioning: 56-channel uBlox GNSS with SBAS support \(2.0 m CEP\) for reliable location in diverse environments.
- Tamper-evident strap with fiber-optic sensing: detects cuts or interference and reports tamper events immediately.
- Multiple communications & backups: LTE CAT-1 cellular, GSM tower fallback, Micro SIM or embedded eSIM options and onboard storage for up to 50,000 records.
- BLE 4.0 home beacon support: improves home-zone detection and enables Bluetooth sensor workflows.
- Rugged and waterproof: IPX7 rating and military-grade shock & vibration resilience for dependable field performance.
- Operational safety features: SOS button, motion/accelerometer detection and detailed zone/tamper events for actionable alerts.

## How It Works with Plaspy

The G737 feeds Plaspy a steady stream of location, event and telemetry data so supervisors receive actionable information in real time. Location fixes from the device’s uBlox GNSS and cellular tower fallback are transmitted over LTE CAT-1 to Plaspy for live maps, history playback and compliance reports. Tamper, SOS and zone events are pushed as alerts, while onboard edge recording ensures no data is lost during temporary coverage gaps.

- Real-time location and telemetry updates via LTE CAT-1 and GSM fallback
- Tamper, strap-cut and interference alerts reported instantly to Plaspy
- BLE home beacon support for accurate home-zone detection and Bluetooth sensor integration
- SOS button and motion/accelerometer events for welfare checks and emergency escalation
- Edge recording and large onboard storage \(up to 50,000 records\) for gapless history synced to Plaspy
- FOTA \(firmware over-the-air\) to keep device firmware current without field returns

## Use Cases

- Parole and probation monitoring: continuous compliance tracking, tamper alerts and location reporting to Plaspy for case management.
- House arrest / home confinement enforcement: BLE home beacon improves home-zone verification and geofence enforcement with Plaspy alerts.
- Pre-trial release and curfew compliance: automated curfew checks, waypoints with date/time and exclusion zone enforcement.
- Remote welfare checks and SOS response: motion detection and SOS button support rapid notification and welfare workflows.
- Program accessories and autonomy: supports power banks, BLE home beacons, replacement shank bands and chargers to extend operational uptime.

The G737 is engineered to meet the demanding needs of electronic monitoring programs while offering effortless integration as a Plaspy compatible GPS tracker. Its combination of high-accuracy GNSS, LTE CAT-1 communications, robust tamper detection and edge recording ensures supervisors retain continuous situational awareness and reliable audit trails. With FOTA support, BLE home beacon capability and large onboard memory, the G737 reduces field maintenance and supports scalable program workflows.

For organizations that require reliable real-time tracking, anti-theft/tamper detection and rich telemetry, the G737 complements Plaspy’s monitoring, reporting and alerting capabilities. Plaspy integration enables agencies to combine location, event and sensor data into automated alerts, case reports and compliance dashboards — and to incorporate ignition, immobilizer or fuel monitoring workflows where external systems provide those signals.
