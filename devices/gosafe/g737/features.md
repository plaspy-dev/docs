# Gosafe - G737 Features

This page provides a public feature overview of the Gosafe G737 ankle bracelet and how its capabilities are used with Plaspy for monitoring and reporting. It summarizes the main, non-sensitive functions that matter to supervisors, integrators, and procurement teams when evaluating the G737 as a Plaspy compatible GPS tracker.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a practical guide for what the device can deliver in Plaspy, and consult the manufacturer documentation for device specific and up to date technical details.

## Feature Overview

The G737 is a purpose built ankle bracelet designed for continuous electronic monitoring in community supervision programs. It combines high accuracy GNSS positioning with cellular communications, tamper sensing, BLE home beacon support and onboard logging to deliver reliable location and event telemetry to a monitoring platform like Plaspy.

- Precise GNSS positioning with SBAS assisted fixes for accurate location reporting.
- LTE cellular communications with fallback for live location updates and event delivery to Plaspy.
- Tamper evident fiber optic strap that detects cuts or interference and reports tamper events.
- BLE home beacon support to improve home zone verification and enable home beacon workflows.
- Edge recording and large onboard storage to preserve event history during coverage gaps.
- FOTA capable for remote firmware updates to reduce field maintenance.

## Core Features of Gosafe - G737

- 56 channel uBlox GNSS engine with SBAS support for improved positioning accuracy.
- LTE CAT 1 cellular connectivity plus GSM fallback options for broad network coverage.
- Tamper detection via a fiber optic strap design that reports strap cuts and interference.
- BLE 4.0 home beacon support for home zone verification and compatible beacon workflows.
- Onboard edge recording and large storage capacity for extended offline logging.
- Firmware over the air updates to maintain current firmware without device return.
- SOS button and motion sensing to generate welfare and activity events.
- Rugged, waterproof construction designed for continuous ankle worn use.

## How These Features Work with Plaspy

When paired with Plaspy, the G737 supplies location, event and telemetry that Plaspy uses to present live maps, event alerts, and compliance reports. Plaspy ingests the device telemetry so supervisors can monitor activity, review history, and respond to alerts from a centralized monitoring environment.

- Real time location fixes and history playback visible in Plaspy maps and timelines.
- Tamper and strap cut events appear as alerts so supervisors can escalate as needed.
- BLE home beacon events support home zone checks and can be reflected as zone status in Plaspy.
- SOS and motion events are surfaced in Plaspy for welfare checks and incident workflows.
- Edge recorded data is uploaded when connectivity is restored, preserving a continuous audit trail.
- FOTA capability reduces the need for field returns and can be coordinated as part of Plaspy managed deployments.

## Typical Use Cases

- Parole and probation monitoring with continuous compliance tracking and tamper alerts.
- House arrest and home confinement enforcement using BLE home beacon verification.
- Curfew and pre trial release monitoring with automated location checks and history logs.
- Remote welfare checks and SOS response workflows for rapid incident handling.
- Program scale deployments that need remote firmware management and reliable offline logging.
- Situations requiring rugged, waterproof devices for long term ankle worn monitoring.
