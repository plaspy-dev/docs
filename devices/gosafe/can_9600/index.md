# Gosafe - CAN-9600

![CAN-9600](./logo.jpg)

The Gosafe CAN-9600 is a GPS tracker with an SMS serial interface, specifically designed to read FMS data from trucks and buses. It is integrated with standard CAN protocols, working on SEA J1939 and SEA J1708. This tracker receives data from the FMS port and transmits it to the RS232 serial interface, which can be connected to any device or computer with a serial port.

The CAN-9600 has a protocol that is easy to integrate with any GPS tracking device. Gosafe has already integrated it with their GPS trackers, such as the G6S and G92I. This integration allows the data to be sent back to the server, where the owner can access all the required information on the web platform. With the CAN-9600, tracking and monitoring the FMS data of trucks and buses becomes seamless and efficient.

Outstanding features of the Gosafe CAN-9600:

- Designed to read FMS data from trucks and buses
- Integrated with standard CAN protocols \(SEA J1939 and SEA J1708\)
- Transmits data to the RS232 serial interface
- Easy integration with any GPS tracking device
- Compatible with Gosafe GPS trackers such as the G6S and G92I
- Allows data to be sent back to the server for easy access
