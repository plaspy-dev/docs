# Totemtech - AT09 Features

This page describes the public feature context for using the Totemtech AT09 tracker with Plaspy. It summarizes the model's user-facing capabilities and explains how those capabilities typically appear in Plaspy for monitoring, history, and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation method, and manufacturer implementation. For device-specific technical details consult the official Totemtech documentation and firmware release notes.

## Feature Overview

The AT09 is a multi‑function GPS tracker designed to provide real‑time location plus sensor monitoring and external device connectivity for vehicle and asset applications. It combines vehicle-oriented sensors, multiple serial interfaces, local storage, and firmware update support to deliver a flexible tracking solution that can feed Plaspy with location and sensor data.

- Real‑time location tracking plus history traces for movement and route review.
- Tire pressure monitoring to track tire health and safety when the sensor package is installed.
- Support for multiple fuel sensors and temperature sensors for fuel level and environmental monitoring.
- Multiple serial ports to attach displays, cameras, RFID readers, or navigation devices for integrated telemetry.
- Redundant data transmission options to improve reporting reliability.
- Voice monitoring and local storage options for situational awareness and recorded data retention.

## Core Features of Totemtech - AT09

- Tire pressure monitoring in real time when fitted with compatible TPMS sensors.
- Support for up to four fuel sensors and two temperature sensors for simultaneous monitoring.
- Dual server transmission capability to send data to two servers for redundancy.
- Three serial ports and industrial interfaces for external device integration.
- 3‑axis digital accelerometer for movement status and event detection.
- Over‑the‑air firmware update support to keep device software current.
- Built‑in storage options including internal flash memory and Micro SD card support.
- Voice monitoring function with an integrated microphone for permitted audio checks.

## How These Features Work with Plaspy

Plaspy receives the AT09 reporting and presents location, sensor readings, and event history in a centralized interface suitable for fleet and asset monitoring. The platform detects common tracker protocols automatically and consolidates the device data alongside other trackers for unified oversight.

- Location and history traces appear on Plaspy maps and timeline views for route analysis.
- Tire pressure, fuel level, and temperature readings reported by the device are shown where supported and can be monitored over time.
- Movement and status events derived from the accelerometer and device inputs are reflected as events in Plaspy.
- Voice monitoring or recorded audio presence is indicated in device details when the manufacturer enables that function.
- Firmware update status and device storage usage can be tracked in device metadata when that information is reported by the tracker.

## Typical Use Cases

- Fleet fuel monitoring to detect consumption patterns and discrepancies using multiple fuel sensors.
- Tire pressure oversight for commercial vehicles to reduce risk and optimize tire maintenance.
- Temperature monitoring for refrigerated or temperature sensitive cargo using the supported temperature sensors.
- Integrated vehicle setups where displays, cameras, RFID readers, or navigation units are connected via serial ports.
- Historical route analysis and movement status review for logistics and operations.
- Redundant data reporting where dual server transmission improves reliability of telematics data delivery.

## Feature Availability Notes

- Certain features require matching sensors or accessories to be fitted and correctly configured at installation.
- Firmware revisions may add, change, or remove behaviors; functionality can depend on the device firmware level.
- Hardware revisions or regional variants can affect supported interfaces and sensor compatibility.
- Installation choices such as wiring, external modules, and configuration can change which features are available.
- Always verify the exact capabilities of a specific device unit with the manufacturer documentation before procurement or deployment.

Using Plaspy with the AT09 allows organizations to centralize location and multi‑sensor telemetry from vehicles and assets. Plaspy provides consolidated maps, history traces, event visibility, and the ability to monitor sensor trends so teams can make operational decisions based on the tracker data.
