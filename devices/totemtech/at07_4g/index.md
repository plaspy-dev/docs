# Totemtech - AT07-4G

<div className="device-logo">
![AT07-4G](./tracker.jpg)
</div>

The Totemtech AT07-4G is a compact, rugged GPS tracker built for demanding vehicle and asset deployments. It is designed to provide reliable fleet management and anti-theft protection through continuous location reporting, event-driven alerts and support for external telemetry and peripherals such as fuel meters, door and ignition status sensors, and emergency SOS inputs.

As a Plaspy compatible device, the AT07-4G delivers the core telemetry and tracking data Plaspy needs to populate live maps, alerts and historical traces. Its support for multi-constellation GNSS, cellular variants, onboard logging and peripheral interfaces makes it a practical choice for fleets and asset operators who want persistent visibility and operational reporting within the Plaspy platform.

## Key Highlights

- Plaspy compatible device offering real-time tracking and historical trace logging for fleet and asset visibility.
- Multi-constellation GNSS support for reliable position fixes and faster reacquisition in mixed environments.
- 3G and 4G cellular variants with configurable reporting by time distance or course change to balance reporting needs.
- Rich I/O for telemetry and peripherals including serial and 1-wire interfaces plus digital and analog inputs for sensors.
- Onboard flash storage for offline logging when connectivity is lost and support for remote firmware upgrades.
- Comprehensive alarm set covering geo-fencing overspeed SOS door and power loss events to support security workflows.
- Wide power input tolerance and a thermal-tolerant backup battery to help maintain continuity in harsh vehicle conditions.

## How It Works with Plaspy

When integrated with Plaspy the AT07-4G streams location fixes event statuses and sensor telemetry into the platform so fleet managers can monitor vehicles and assets in real time and review historical activity. Plaspy ingests the tracker’s position and I/O events to generate alerts reports and operational dashboards.

- Real-time location updates and movement telemetry for live map visualization and route history.
- Digital event reporting such as door status SOS and external power lost to trigger security and anti-theft alerts.
- Fuel and consumption monitoring using serially connected fuel meters and analog inputs for fuel-related telemetry.
- Temperature and auxiliary sensor data via 1-wire and serial interfaces to support environmental monitoring.
- Local data buffering that preserves records during network outages and uploads stored logs to Plaspy when connectivity returns.
- Configurable reporting profiles that allow reporting frequency to be tuned by time distance or course change for efficient data usage.

## Typical Use Cases

- Continuous fleet management for trucks vans and mixed vehicle fleets requiring live tracking and route history.
- Anti-theft and immobilization workflows using door power and SOS events combined with remote relay control where deployed.
- Fuel monitoring and analysis with serial fuel meter integration and analog inputs for fuel level telemetry.
- Perimeter protection and unauthorized movement detection using geo-fencing towing and vibration alerts.
- Cold chain and environmental monitoring where temperature sensor inputs are used to track asset conditions.
