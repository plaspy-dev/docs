# Totemtech - AT07 Configuration

This page documents the public configuration context for using the Totemtech AT07 GPS tracker with Plaspy. It focuses on the server settings and practical setup workflow you can apply to allow the AT07 to send location and device data to Plaspy using the public information available for this model.

Plaspy uses shared server settings across supported devices and automatically detects the tracker protocol. Exact manufacturer-side setup steps can vary depending on firmware revision, hardware revision, installation type, and vendor configuration tools. The AT07 supports both SMS and GPRS command methods, and this guide uses that public behavior to show how to point the device at Plaspy.

## Configuration Overview

Configuring the AT07 for Plaspy prepares the device to reliably deliver tracking data to a common Plaspy endpoint and ensures the tracker appears in the platform for monitoring. The public configuration typically includes setting the device APN for mobile data, pointing the device to the Plaspy server endpoint, choosing the transport method if required, and validating that the device reports successfully.

- Set the operator APN so the tracker can use GPRS data to reach the Plaspy endpoint.
- Configure the device server entry to point to Plaspy using the provided domain or IP and the shared port.
- Choose UDP or TCP transport on the device if a transport selection is required.
- Use SMS or the manufacturer configuration tool to send the server and APN settings to the AT07.
- Validate connectivity and reporting in Plaspy so the device is visible and sending expected updates.

## Plaspy Server Settings

Use the public Plaspy server settings below when configuring the AT07. Plaspy uses the same port for all supported devices and automatically detects the tracker protocol, so enter the values exactly as shown when prompted by the device or manufacturer tool.

- Server domain d.plaspy.com
- Server IP 54.85.159.138
- Port 8888
- Transport support: device may be configured using UDP or TCP on port 8888
- Plaspy automatically detects the tracker protocol

## Typical Requirements Before Setup

- A powered and accessible AT07 tracker on the vehicle or asset.
- An active SIM card with a data plan and the correct APN details for the mobile operator.
- Access to the manufacturer supported configuration method for the AT07 such as SMS commands or vendor software.
- Knowledge of the device password if SMS configuration is password protected (the public example shows 000000 as the default password).
- A Plaspy account and the ability to validate device reporting in the Plaspy platform.
- Basic tools to restart the device or cycle power if the device requires a restart to apply settings.

## How This Tracker Connects to Plaspy

The AT07 can send GPRS data to an IP address or domain name of your choice and accepts configuration via SMS or GPRS commands. When configured for Plaspy, the tracker reports to the shared Plaspy endpoint so location and status data become visible in the platform.

- The tracker is configured to report to the shared Plaspy server endpoint and port.
- Location updates and device events are sent from the AT07 to Plaspy over GPRS using the chosen transport.
- Movement and status events generated by the AT07 are transmitted to Plaspy for visibility and monitoring.
- Plaspy receives the incoming data on the common port and automatically detects the device protocol for parsing and presentation.
- After successful configuration, the device should appear and report in the Plaspy platform for operational monitoring.

## Common Configuration Workflow

1. Access the official Totemtech AT07 configuration method or software as provided by the vendor, or prepare to send SMS configuration commands if supported.
2. Enter the Plaspy server address by using either the domain d.plaspy.com or the server IP 54.85.159.138 when prompted.
3. Set the port to 8888 as the device server port.
4. Choose UDP or TCP on the device if it requires you to select a transport protocol.
5. Save or apply the configuration on the device or via SMS, following manufacturer instructions.
6. Restart or power cycle the tracker if the device requires a restart to apply new settings.
7. Validate that the device reports to Plaspy and appears in the platform with expected updates.

## Example Configuration Commands

The AT07 supports SMS configuration. The following public SMS commands demonstrate a typical sequence. The device password used in these examples is 000000 which is the public default shown in vendor documentation. The sequence is ordered for typical setup; factory reset is optional and should be used only when needed.

- Factory reset (optional initial step)
```text
*000000,007#
```

- Set the operator APN (replace placeholders with your operator values)
```text
*000000,002,{{apn}},{{apnu}},{{apnp}}#
```
Explanation: {{apn}} is the access point name, {{apnu}} is the APN username, and {{apnp}} is the APN password. Fill or omit username and password according to your SIM operator requirements.

- Set the GPRS server to Plaspy using the public IP and port
```text
*000000,003,54.85.159.138,8888,1
```
Explanation: This command sets the GPRS server entry to the Plaspy server IP and port. The final numeric field is part of the device command format as provided by the manufacturer.

- Enable ACK or acknowledgements as shown in vendor examples
```text
*000000,019,1#
```

- Set the periodic update interval to 60 seconds
```text
*000000,60,60,0,60#
```
Explanation: This example sets a reporting schedule that includes a 60 second update interval. Adjust values to match your reporting needs and local regulations.

## Configuration Notes

- Firmware revisions and hardware variants can change command formats or available features; verify commands against the device firmware and Totemtech documentation.
- The AT07 supports SMS based configuration as well as GPRS configuration methods; pick the method that best fits installer access and security practice.
- You may choose TCP or UDP transport when configuring the tracker; Plaspy accepts either on port 8888 and will auto detect the device protocol.
- Plaspy uses the same port across supported devices which simplifies configuration and server entries for fleet deployments.
- Confirm APN credentials and data connectivity before setting the server parameters to avoid false negatives during validation.
