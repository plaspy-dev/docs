# Totemtech - AT04

![AT04](./tracker.jpg)

The AT04 is a compact, waterproof vehicle GPS tracker engineered for motorcycles, cars and light trucks and positioned here as a Plaspy compatible solution for reliable real-time tracking and fleet management. Its small form factor and wide DC input make it ideal for mixed fleets; built-in GPS/GLONASS/Beidou positioning, integrated GSM/GPS antennas and support for 2G/4G networks deliver continuous telemetry and location data to Plaspy for mapping, alerts and reporting.

Designed for low-power operation and practical in-vehicle use, the AT04 offers SMS alarm center functions, a remote engine cut-off for anti-theft response, a 3D tremble sensor for tamper and movement detection, and an analog input to enable fuel monitoring via a capacitive sensor. Configuration is flexible—via SMS, over GPRS/3G/4G or with the manufacturer’s Windows configuration tool—making integration with the Plaspy platform straightforward and fast.

## Key Highlights

- Plaspy compatible — sends standard location and telemetry data for real-time tracking and fleet management on the Plaspy platform.
- Multi-GNSS positioning \(GPS/GLONASS/BEIDOU\) for precise location with CEP ~2.5 m.
- Low-power design: deep sleep ~10 mA, idle 25 mA @12V — ideal for motorcycles and vehicles with limited power budgets.
- Anti-theft and immobilizer capability via remote engine cut-off and SMS alarm center.
- Fuel monitoring via one analog input supporting capacitive sensors for fuel-level telemetry.
- Built-in antennas and compact IP67 enclosure for discreet, weather-resistant installation \(verify IP rating with vendor\).
- Smart data transmission rules — report on engine state, distance, angle/veer changes, or send immediate alarms.

## How It Works with Plaspy

The AT04 transmits GNSS positions and telemetry over cellular networks using standard protocols supported by many tracking platforms. When connected to Plaspy, the unit provides continuous real-time tracking, event-based alerts, and historical trip data for analytics and fleet oversight. Plaspy ingests the device’s position, sensor and input/output events to create live maps, telemetry dashboards and automated notifications.

- Real-time location and telemetry updates over 2G/4G with configurable reporting intervals and immediate alarm transmission.
- Engine state reporting and ignition-style events via the digital input and smart transmission rules.
- Fuel monitoring telemetry through the analog input when paired with a capacitive fuel sensor.
- Remote immobilizer function \(remote engine cut-off\) that can be triggered from Plaspy or via SMS for anti-theft response.
- Alert delivery \(geofence, tremble/tamper, movement, SOS with accessory\) and historical playback for investigations and compliance.
