# Totemtech - AT04 Features

This page provides a public feature overview for the Totemtech AT04 and explains how its capabilities map to Plaspy for real time tracking, alerts, and fleet management. It focuses on practical, non sensitive information about what the tracker does and how it can be used with the Plaspy platform for mapping, event visibility, and reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional module selection and how the unit is installed. Always confirm device specific capabilities and configuration paths with the manufacturer and your Plaspy administrator before deployment.

## Feature Overview

The AT04 is a compact, weather resistant vehicle tracker designed for motorcycles, cars and light trucks. It combines multi GNSS positioning, cellular connectivity and a set of inputs and outputs to deliver location and telemetry to Plaspy for live monitoring and historical analysis.

- Multi GNSS positioning using GPS, GLONASS and Beidou for improved location reliability.
- Compact IP rated enclosure with integrated antennas for discreet, weather resistant mounting.
- Low power design suitable for motorcycles and vehicles with limited power budgets.
- Inputs and outputs plus a 3D tremble sensor for tamper and movement detection and remote immobilization.
- Analog input supporting capacitive fuel sensors to report fuel level data into Plaspy.
- Flexible configuration via SMS, over cellular data, or the manufacturer Windows configuration tool.

## Core Features of Totemtech - AT04

- Multi GNSS support: GPS, GLONASS and Beidou positioning for consistent location fixes.
- Cellular connectivity: 2G and 4G variants to transmit GNSS and telemetry to tracking platforms.
- Low power consumption: documented deep sleep and idle currents to suit two wheel and light vehicle installations.
- Tamper and movement detection: 3D tremble sensor for detecting vibration and potential tamper events.
- Remote engine cut off: immobilizer capability available for anti theft response when supported by installation.
- Analog input: supports capacitive fuel sensors for fuel-level telemetry when fitted.
- SMS alarm center and configurable alarm delivery for immediate notifications.
- Built in antennas and compact IP rated enclosure for discreet mounting and weather resistance.

## How These Features Work with Plaspy

Plaspy ingests position and telemetry from compatible trackers like the AT04 to present live location, events and historical trips within the Plaspy platform. Plaspy also automatically detects many common tracker protocols to simplify integration and allow devices to report quickly into the system.

- Real time location and telemetry visible on Plaspy maps and dashboards for operational awareness.
- Event based alerts in Plaspy for tremble/tamper, movement and configured alarm conditions.
- Fuel level telemetry from the analog input can be shown in Plaspy reports and used for fueling analytics.
- Remote immobilizer actions and engine state events can be tracked and logged inside Plaspy for security workflows.
- Plaspy supports standard data transport methods and can accept tracker connections that report into the Plaspy server domain for automated processing.

## Typical Use Cases

- Anti theft monitoring and remote immobilization for fleet vehicles and motorcycles.
- Motorcycle and light vehicle tracking where low power draw and compact form factor are priorities.
- Fuel monitoring and loss detection using a capacitive fuel sensor connected to the analog input.
- Movement, door and tamper monitoring for parked assets using tremble sensor and digital inputs.
- Mixed fleet management where compact, multi GNSS trackers provide consistent position feeds to Plaspy.
- Route tracking and historical trip playback for compliance and investigation.
