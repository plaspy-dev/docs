## How Gator devices work with Plaspy

Gator devices that are compatible with Plaspy transmit location and telemetry data that Plaspy ingests and displays in its web platform and APIs. Compatibility typically means a device can be configured to send its tracking messages to Plaspy using standard device protocols. Device level setup steps such as APN configuration, server address, and message formats vary by model and are documented on each model page in the catalog.

Plaspy acts as the central platform that receives data from Gator trackers, normalizes telemetry, and makes that data available for mapping, alerts, reporting, and integrations. If a Gator device model appears in the BrandCatalog above, you can follow the linked device page for the exact configuration steps to connect it to Plaspy.

## Common features found in Gator devices

While specific features depend on the exact model, many Gator trackers share common capabilities useful for fleet and asset tracking:

- Real time GPS location and periodic position reporting
- Movement detection and status inputs such as ignition or external sensors
- Battery monitoring and tamper alerts for asset trackers
- Event driven reporting for geofence entry and exit
- OTA settings or remote configuration options on some models

Plaspy uses incoming reports from these features to power location history, geofence alerts, route playback, and analytics without requiring manual data conversions.
