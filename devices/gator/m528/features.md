# Gator - M528 Features

This page provides a public feature summary for the Gator M528 GPS tracker and explains how its capabilities are used with Plaspy for fleet management and anti theft monitoring. It is intended to describe user facing functions and operational value when the device is paired with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. Where necessary, always verify model specific details against official Gator documentation for the most current and authoritative device information.

## Feature Overview

The Gator M528 is positioned for vehicle tracking and security use across commercial fleets, rental cars, logistics vehicles, and public transport. It combines GNSS positioning with cellular reporting to provide continuous location updates, alarm reporting, and vehicle status signals useful for operational oversight.

- Supports vehicle location reporting via SMS or mobile data for flexible connectivity and reporting modes
- On demand and periodic tracking to suit real time monitoring or scheduled position polling
- SOS alarm for immediate alerting in emergency situations
- Multiple theft and security related alarms including external power disconnection and geo fence alerts
- Built in battery backup so tracking continues when vehicle power is removed
- Remote firmware updates to keep device behavior current over time

## Core Features of Gator - M528

- Dual reporting options using SMS or GPRS style data reporting for location and event transmission
- SOS alarm capability to signal emergencies to monitoring systems or contacts
- Low power alarm and voltage protection to alert on power anomalies
- Resend of stored data from signal dead zones to avoid data loss from coverage gaps
- Voice monitoring for remote listening when configured
- Geo fence, speeding, parking, and fatigue driving alarms for event based monitoring
- Inputs for vehicle status detection including engine, ACC, doors, and air conditioning signals
- Built in Li polymer battery plus digital I O for integration and remote control functions such as engine cut off

## How These Features Work with Plaspy

Plaspy can ingest location and event reports from compatible devices such as the Gator M528 and present them in dashboards, maps, and event streams for operational use. Plaspy automatically detects the tracker protocol for supported devices which simplifies device onboarding.

- Location updates and historical tracks from the M528 are viewable on Plaspy maps for route review and fleet coordination
- Alarm events such as SOS, geo fence breach, or external power loss appear as actionable events in Plaspy notifications and event lists
- Status inputs like engine on off, door or ACC changes are reflected as vehicle state indicators inside the Plaspy interface
- Stored reports uploaded after reentering coverage are reconciled into Plaspy so gaps in coverage do not create blind spots
- Remote device management functions such as firmware updates and configuration changes are supported where the device and manufacturer allow remote control

## Typical Use Cases

- Real time fleet monitoring for construction trucks and logistics vehicles
- Rental car tracking and theft prevention workflows using geo fence and external power alerts
- Public transportation vehicle oversight with driver fatigue and parking event notifications
- Remote emergency response enabled by SOS alarm reporting
- Operational auditing and mileage verification using milemeter and location history
- Security monitoring and remote engine control for theft mitigation

## Feature Availability Notes

- Feature availability depends on the device firmware and the exact hardware revision shipped by the manufacturer
- Some functions require correct wiring and installation to vehicle inputs such as ACC, door, and engine signals
- Regional cellular band support and SIM provisioning affect SMS and data reporting behavior
- Manufacturer enabled features such as voice monitoring or remote engine cut off may be restricted by local regulations or seller configuration
- Always consult the device label and official documentation to confirm the capabilities of a specific unit

Plaspy collects and presents location, alarm, and status data so fleet managers can monitor vehicle movement, respond to security incidents, and analyze operational patterns without parsing raw device messages.
