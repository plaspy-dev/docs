# Orion - BD-3112 Features

This page provides a public overview of the Orion BD-3112 GPS tracker feature set and how those features are used with Plaspy for tracking, monitoring, and event awareness. It focuses on practical, non sensitive descriptions of capabilities you can expect when the BD-3112 is reporting into Plaspy.

Exact feature availability and behavior may vary by device firmware version, hardware revision, installation method, and manufacturer implementation. For device specific configuration, firmware details, or regulatory information consult the official Orion documentation and release notes.

## Feature Overview

The Orion BD-3112 is presented as a compact, portable tracker designed for continuous location monitoring and basic event reporting. It aims to provide real time position updates, boundary alerts, and an emergency alert option while remaining easy to install and maintain.

- Real time location reporting for continuous visibility of tracked assets
- Geo fencing capability to notify on entry or exit of user defined zones
- SOS emergency alert for immediate notification in critical situations
- Lightweight and compact form factor suited to discreet installation
- Multi band GSM compatibility to support network connectivity across regions

## Core Features of Orion - BD-3112

- Real time tracking that provides frequent position updates for active monitoring
- Geo fencing support allowing custom boundary definitions and alerts
- SOS button for sending immediate emergency notifications
- Compact and portable design for flexible asset attachment
- Enhanced GPS sensitivity for improved location fix performance in challenging areas
- Broad GSM frequency compatibility for regional mobile network coverage
- Environmental tolerance designed for routine operational conditions
- Design and manufacturing compliance aligned with international safety and operational standards

## How These Features Work with Plaspy

Plaspy receives position and event data from compatible trackers like the BD-3112 and presents that information through device lists, maps, and event logs for operational oversight. Plaspy normalizes common tracker messages so location, geo fence events, and SOS alerts are visible alongside other devices in one platform.

- Live location updates appear on Plaspy maps and device timelines for real time awareness
- Geo fence triggers are recorded as events so entry and exit actions are searchable and auditable
- SOS alerts can be surfaced as high priority events to notify operators or trigger workflows
- Device status and last reported time are shown so administrators can identify offline or inactive units
- Historical tracks and location history provide context for movement and operational review

## Typical Use Cases

- Fleet location monitoring for route tracking and operational oversight
- Asset protection where compact trackers are attached to equipment or goods
- Personal safety or lone worker monitoring using SOS alerts
- Geofenced zone monitoring for automated entry and exit notifications
- Situational awareness in logistics and field operations for tracking movement

## Feature Availability Notes

- Firmware versions and manufacturer configuration options can affect how often position reports are sent and which events are generated
- Hardware revisions or regional variants may change radio band support and environmental ratings
- Installation method and placement can impact GPS sensitivity and real time accuracy
- Some features such as geo fencing thresholds and SOS behavior are often configurable and may vary by firmware
- Always verify the capabilities of a specific unit with the manufacturer documentation before deployment
