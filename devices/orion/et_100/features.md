# Orion - ET-100 Features

This page provides a public overview of the Orion ET-100 tracker features and how those capabilities are used with Plaspy for visibility and operational monitoring. It is intended to explain the practical functions the device can deliver when paired with Plaspy and to help users understand which features they can expect to see inside the platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation. Where possible this page references the general capabilities of the ET-100, but users should confirm current device specifics with Orion documentation.

## Feature Overview

The Orion ET-100 is designed for compact, discreet asset tracking with features focused on location visibility, boundary alerts, and emergency notification. Its user-facing capabilities make it suitable for a mix of personal and commercial tracking tasks.

- Real time location tracking for continuous visibility of assets and vehicles
- Geo fencing support to define boundaries and trigger entry or exit alerts
- SOS button for immediate emergency alerts to designated recipients
- Compact and lightweight form factor for discreet placement on a wide range of assets
- High GPS sensitivity for improved location accuracy in urban and challenging environments

## Core Features of Orion - ET-100

- Real time tracking that reports current position updates for active monitoring
- Geo fencing functionality to define zones and generate boundary alerts
- SOS emergency alert button to notify when immediate assistance is needed
- Compact design enabling discreet deployment on personal items or vehicle assets
- High GPS sensitivity aimed at maintaining location accuracy in dense areas
- Robust construction intended to suit routine operational use
- Versatile suitability across personal, commercial, and fleet tracking scenarios

## How These Features Work with Plaspy

When used with Plaspy, the ET-100's reported events and location data become visible in a unified monitoring environment, helping teams act on live information. Plaspy automatically detects compatible tracker protocols and surfaces the device data in the platform.

- Live location updates appear on Plaspy maps for immediate position awareness
- Geo fence events are displayed as alerts or timeline events inside Plaspy
- SOS activations can be presented as high priority notifications for operators
- Historical position data is available for review and operational analysis
- Device grouping and asset assignment in Plaspy help organize multiple ET-100 units

## Typical Use Cases

- Fleet tracking and simple vehicle oversight for location visibility
- Securing valuable equipment or personal belongings with discreet placement
- Monitoring the location of high value or movable assets for theft deterrence
- Providing emergency alert capability for individuals and field personnel
- Managing mixed personal and commercial asset inventories
- Situations where compact form factor and reliable location updates are needed
