# Intellitrack - Intellitrac P1 Features

This page provides a public feature overview for the Intellitrac P1 Series personal GPS device and explains how its capabilities relate to use with the Plaspy platform. It focuses on practical, non sensitive descriptions of the device attributes you can expect when deploying the Intellitrac P1 with Plaspy for tracking and monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where possible this page describes the device features reported in public documentation and how those features typically map into Plaspy, but you should confirm device specifics with manufacturer resources.

## Feature Overview

The Intellitrac P1 is a compact, mobile personal tracker designed for discreet tracking in a range of environments. Its design emphasizes portability, environmental protection, and sensors that support motion and altitude awareness. Below are the most relevant practical capabilities users typically seek when evaluating this device for Plaspy.

- Compact and portable form factor for discreet personal or asset tracking
- Waterproof enclosure suitable for outdoor use and exposure to moisture
- Internal backup battery to maintain tracking continuity for several days
- Built in accelerometer for motion detection and activity reporting
- Built in barometer to provide relative height or altitude change information
- Internal antennas for GPS and cellular connectivity to simplify installation

## Core Features of Intellitrack - Intellitrac P1

- Compact mobile design optimized for personal carry and discreet use
- Waterproof enclosure that protects the device in wet conditions
- Internal backup battery for continued operation during temporary power loss
- Internal antenna configuration for GPS and cellular connectivity
- Built in accelerometer to detect motion and movement events
- Built in barometer to report height or altitude changes
- Designed and marketed specifically for personal tracking scenarios

## How These Features Work with Plaspy

Plaspy receives and presents location and event information sent by compatible trackers so teams can monitor movement, history, and activity from a single dashboard. When an Intellitrac P1 reports its data, Plaspy maps that input into live location views and timeline events according to the information provided by the device.

- Location updates from the tracker are plotted on Plaspy maps for live and historical position visibility
- Motion events derived from the accelerometer can be shown as activity or movement events in Plaspy timelines
- Height or altitude changes reported via the barometer are surfaced as additional context in position records
- Battery backup behavior helps maintain continuity of reported positions which Plaspy will display while reports continue
- Plaspy automatically detects compatible tracker protocols and associates incoming data with the correct device profile
- Device attributes such as model name and basic sensor availability are visible in Plaspy device summaries when the tracker reports them

## Typical Use Cases

- Discreet personal location monitoring for safety and check in scenarios
- Monitoring locations of high value portable assets during transit
- Tracking movements of field personnel for operational oversight
- Outdoor activity tracking where waterproof protection is required
- Short term deployments where a compact, battery backed tracker is preferred
