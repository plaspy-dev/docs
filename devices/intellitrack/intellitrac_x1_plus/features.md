# Intellitrack - Intellitrac X1 Plus Features

This page provides a public feature summary for the Intellitrack Intellitrac X1 Plus and explains how its capabilities relate to use with the Plaspy platform. It is intended to help fleet managers, asset owners, and technical evaluators understand the practical functions of this compact GPS tracker when reporting into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation method. Where possible this page reflects capabilities described by the manufacturer, but final deployment details depend on the specific device configuration and firmware provided by the manufacturer.

## Feature Overview

The Intellitrac X1 Plus is a compact, installable GPS tracker designed for discreet asset and vehicle tracking. It offers multiple communication and tracking modes to balance reporting frequency, data use, and battery life. The tracker supports remote configuration and firmware updates to adapt to changing operational needs.

- Compact form factor for discreet installation on vehicles and assets
- Multiple communication options including SMS, CS Data, GPRS TCP UDP and optional voice
- Flexible real time tracking modes based on time intervals, distance intervals, or intelligent mode
- Geo fence control for virtual boundary monitoring and alerts
- Power management features, low power alarm, and a backup battery lasting more than three days
- Remote configuration and firmware upgrades over CS Data or GPRS

## Core Features of Intellitrack - Intellitrac X1 Plus

- Discreet compact hardware suited for vehicle and asset installations
- Support for SMS and CS Data communications alongside GPRS TCP UDP reporting
- Optional voice capability as provided in some device variants
- Multiple tracking strategies: timed reporting, distance interval reporting, and intelligent mode
- Geo fencing control for entry and exit notifications of defined areas
- Power management with low power and power lost alarm notifications
- Backup internal battery rated for more than three days of operation in typical standby modes
- Remote firmware upgrade support using CS Data or GPRS where enabled by the manufacturer

## How These Features Work with Plaspy

Plaspy receives device reports and exposes location and event information through its platform so teams can monitor assets in near real time. The Intellitrac X1 Plus can be configured to report into Plaspy and Plaspy will automatically detect common tracker protocols supported by the platform.

- Devices can be configured to send location and event messages to Plaspy so positions and alarms appear on Plaspy maps and device lists
- Geo fence events and power related alarms from the tracker are visible as events in Plaspy for operational follow up
- Remote configuration and firmware update activities reported by the device appear in Plaspy as status changes or device messages
- Plaspy supports both TCP and UDP reporting and can accept device data routed to the Plaspy server domain for automatic protocol detection
- Backup battery and power lost alarms help maintain visibility in Plaspy even when main power is disconnected

## Typical Use Cases

- Fleet vehicle tracking where discreet installation and periodic reporting are required
- Equipment and asset monitoring for offsite or mobile assets that need persistent location awareness
- Geographically constrained operations using geo fencing to detect unauthorized movement or entry into restricted areas
- Low power or backup battery scenarios where extended offline operation must still provide event alerts
- Remote deployments that benefit from over the air configuration and firmware updates
- Situations requiring optional voice capability for two way checks when supported by the device variant

## Feature Availability Notes
