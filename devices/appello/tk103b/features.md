# Appello - TK103B Features

This page provides a public feature overview of the Appello TK103B and how its capabilities relate to use with Plaspy. It summarizes the user facing functions and operational behaviours that are commonly referenced when deploying the TK103B with a fleet management platform such as Plaspy. The content is intended to help teams understand practical value and typical interactions between the tracker and Plaspy without replacing manufacturer documentation.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where the device description identifies specific functions, this page uses those items as the factual basis. For device specific setup, configuration options, or the most current technical details please consult the manufacturer documentation.

## Feature Overview

The Appello TK103B is a GSM GPRS enabled GPS tracker designed for real time tracking and remote monitoring of vehicles and assets. It supports continuous or interval based reporting, remote control commands, status monitoring, and multiple alert types that are useful for operational oversight.

- Real time location reporting with latitude longitude, speed, and time for situational awareness
- Auto track mode that reports at configurable intervals for routine monitoring
- Remote control functions to issue commands and manage the device from afar
- Multiple alerts including geofence, movement, overspeed, low battery, SOS alarm, and GPS off
- State checking of GSM GPS GPRS and battery to monitor device health and connectivity

## Core Features of Appello - TK103B

- GSM GPRS communication for remote reporting and platform connectivity
- Real time tracking of location coordinates and speed
- Auto track interval reporting to retrieve position data automatically
- Remote command support to manage device behavior from a remote terminal
- Geofencing alerts to notify when a device enters or leaves predefined areas
- Movement and overspeed alerts to detect operational or safety events
- SOS alarm and GPS off alerts for emergency and tamper awareness
- State checking functionality for GSM GPS GPRS and battery status reporting

## How These Features Work with Plaspy

Plaspy can receive and present the TK103B location and event data so teams can monitor assets on maps, review alerts, and manage reporting. Plaspy automatically detects many tracker protocols and exposes the tracker data in the fleet management interface so operators can use the device features without low level protocol work.

- Real time positions and auto track reports are shown on Plaspy maps for continuous visibility
- Alerts from the TK103B such as geofence, movement, overspeed, SOS, and GPS off are surfaced as events in Plaspy for operator attention
- Device state information like GSM GPRS GPS and battery status is available in Plaspy to help diagnose connectivity or power issues
- Remote commands supported by the tracker can be issued and tracked through Plaspy where platform workflows allow for command management
- Plaspy can be configured to accept reports from the TK103B using standard network delivery to the platform server and will present incoming telemetry automatically

## Typical Use Cases

- Fleet vehicle tracking for route oversight and improved dispatching
- Rental vehicle monitoring to enforce usage policies and track returns
- Equipment and asset location tracking on worksites or job locations
- Personal or companion tracking where continuous position awareness is required
- Security and loss prevention to detect movement or unauthorized use
- Operational monitoring with routine auto track reporting for managers
