# SinoTrack - ST-905

<div className="device-logo">
![ST-905](./tracker.jpg)
</div>

The SinoTrack ST-905 is a compact, waterproof magnetic GPS tracker designed for covert mounting on vehicles, bicycles and other mobile assets. Its slim magnet-backed housing and rugged IP-rated enclosure make it suitable for discreet attachment to metal surfaces, while the integrated GNSS receiver and cellular link provide location reporting and status updates for asset protection and anti-theft applications.

The ST-905 is relevant to Plaspy users because it can be configured to forward location and status packets to a custom server IP and APN, allowing the device to integrate with Plaspy’s tracking platform. When pointed at a Plaspy endpoint, the tracker enables live tracking, history, alerts and basic device monitoring inside Plaspy without requiring specialized integration tools.

## Key Highlights

- Plaspy compatible by configuring the device IP and APN via SMS for server reporting.
- Compact magnetic and waterproof enclosure suitable for covert mounting on metal assets.
- Long standby capability with a large rechargeable battery for low-maintenance deployments.
- UBLOX GNSS receiver provides reliable positioning for operational tracking and recovery.
- GSM/GPRS cellular connectivity for location transmission where 2G service is available.
- SMS command configuration for remote setup of reporting behavior and server address.
- Designed for outdoor use with a robust operating temperature and humidity tolerance.

## How It Works with Plaspy

Once the ST-905 is set to report to a Plaspy-reachable server address and uses an appropriate APN, the device transmits position and status reports to Plaspy for processing. Plaspy then ingests those packets and presents them in the platform for real-time visibility, historical playback and alerting.

- Real-time tracking: position updates sent over cellular data appear on Plaspy maps for live monitoring.
- Fleet visibility: group and manage multiple ST-905 units in Plaspy to monitor asset locations and status.
- Alerts and geofencing: use Plaspy to define geofences and receive notifications based on the tracker reports.
- Reporting and history: Plaspy stores location history for playback and operational reporting.
- Device status monitoring: track battery level and online/offline state reported by the tracker in Plaspy.

## Typical Use Cases

- Fleet management for cars, light commercial vehicles and service fleets needing discreet trackers.
- Anti-theft and recovery for vehicles, bicycles and other movable assets.
- Asset protection for trailers, containers and portable equipment during storage and transit.
- Outdoor activity tracking for bikes and gear where waterproofing and compact size matter.
- Low-maintenance deployments where long standby and simple SMS configuration are priorities.

## Why Choose This Tracker with Plaspy

The ST-905 pairs practical hardware features with a simple integration path to Plaspy, offering organizations a straightforward option for adding discreet GPS tracking to their assets. Its magnetic waterproof housing and extended battery life reduce maintenance and help keep devices in the field longer, while SMS-configurable server settings let teams route data to Plaspy or a self-hosted instance without special software tools.
