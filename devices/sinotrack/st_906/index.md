# SinoTrack - ST-906

![ST-906](./tracker.jpg)

The SinoTrack ST-906 is a compact, wired vehicle GPS tracker that can be configured to work with Plaspy for reliable, Plaspy compatible real-time tracking. Designed for motorcycles, cars, trucks, e-bikes and logistics vehicles, the ST-906 uses a built-in antenna and a straightforward SMS configuration flow so fleet managers and individual owners can point the device to any compatible platform — including Plaspy — by setting the server IP, port and APN.

The ST-906 combines live tracking, history playback and remote configuration through SMS with access to SinoTrack’s lifetime-free web platform and SinoTrack Pro mobile app. By sending the required SMS activation commands to set the device’s server and APN, you can integrate vehicle telemetry into Plaspy for geolocation, alerts and fleet management without recurring platform fees from the device manufacturer.

## How It Works with Plaspy

Integration with Plaspy is straightforward because the ST-906 accepts SMS commands to define the platform endpoint \(server IP and port\) and APN settings for the SIM card. Once the device is configured to report to Plaspy’s server, position and telemetry messages can be received in real time by Plaspy for mapping, alerts and reporting.

- Real-time location updates are sent from the tracker to the configured server after APN and server settings are applied.
- History playback and location logs are available from the device via the reporting server once configured.
- Remote configuration via SMS: set server IP, port and APN from any phone to point the tracker at Plaspy.
- Device reports to the configured server IP and port \(manufacturer example: 45.112.204.242:8090\); change these to Plaspy’s endpoint to enable Plaspy ingestion.
- Telemetry and vehicle data sent to Plaspy will depend on the signals the installed unit reports; check the device manual and wiring for supported inputs.
