# SinoTrack - ST-901A Features

This page provides a public summary of the main features of the SinoTrack ST-901A and how those features are commonly used with Plaspy for vehicle tracking and monitoring. It is written to help fleet managers, installers, and technical users understand the practical capabilities of the tracker when integrated into Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where present, features such as remote control functions or specific alarm behavior may require particular configuration or wiring and can differ across device batches.

## Feature Overview

The ST-901A is a compact vehicle tracker designed for reliable position reporting and event notifications. It supports multiple reporting methods and a set of alarms useful for basic security and operational oversight.

- Accurate positioning using a Ubox 7020 GPS module with reported accuracy up to about 10 meters for typical conditions.
- Location reporting via SMS or GPRS, with GPRS supporting reporting over TCP or UDP for real time monitoring.
- Event alarms for main power loss, shock events, and over-speed notifications to highlight potential incidents.
- Remote control capability to enable or disable fuel and power functions where supported and properly installed.
- Small form factor and straightforward installation suitable for personal vehicles and light fleet use.

## Core Features of SinoTrack - ST-901A

- GPS positioning with stated accuracy up to approximately 10 meters under normal reception conditions.
- Support for SMS reporting to request current location on demand.
- GPRS reporting over TCP or UDP for periodic or continuous tracking to a monitoring platform.
- Alarm reporting for main power cut off to indicate external power interruption.
- Shock event alarm to notify of possible impacts or tampering.
- Over-speed alarm to notify when vehicle speed exceeds configured thresholds.
- Remote control of fuel and power functions subject to device configuration and installation.

## How These Features Work with Plaspy

Plaspy can receive and present the location updates and event reports sent by ST-901A devices, making the tracker data actionable for monitoring and operations.

- Position updates received over GPRS are displayed on Plaspy maps for real time location awareness.
- Device alarms such as main power loss, shock, and over-speed can appear as alerts in Plaspy to support incident response.
- On-demand SMS location requests are part of the device feature set; when configured to report into Plaspy, location intervals and reporting behavior can be coordinated for continuous oversight.
- Plaspy automatically detects common tracker protocols and integrates ST-901A reporting without manual protocol selection, simplifying setup.
- Remote control requests from a fleet manager interface can be coordinated with device capabilities when such functions are enabled and wired during installation.

## Typical Use Cases

- Real time vehicle location monitoring for small to medium vehicle fleets.
- On demand location checks for personal vehicles using SMS queries.
- Security monitoring with alerts for main power cut off and shock events to detect tampering or collisions.
- Over-speed monitoring to help identify potential driver behavior concerns and enforce safety policies.
- Remote disable or enable of fuel and power where supported and properly installed to assist theft response or vehicle immobilization workflows.

## Feature Availability Notes

- Firmware version and hardware revision can change which alarm thresholds and remote functions are available or how they behave.
- Remote control of fuel and power typically depends on how the device is wired into the vehicle and may require professional installation.
- SMS versus GPRS behavior depends on the installed SIM and mobile network availability in the operating region.
- Some feature names and exact alarm formats are manufacturer defined and can vary by regional product variant.
- Always verify the feature set on a specific device unit and test critical functions after installation.

Using the ST-901A with Plaspy provides a practical way to turn the tracker’s position and event reports into operational visibility. Plaspy consolidates location data and device alarms into a single interface so fleet managers can monitor movement, receive alerts, and coordinate responses without needing to manage raw device connections.
