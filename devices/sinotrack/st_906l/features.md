# SinoTrack - ST-906L Features

This page provides a public feature overview for the SinoTrack ST-906L and explains how those features are used with Plaspy for centralized vehicle and motorcycle monitoring. It focuses on user-facing capabilities, operational value, and the practical ways the device reports location and events into the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where necessary, consult manufacturer documentation and device firmware notes for exact command sets, installation guidance, and behavior differences before deployment.

## Feature Overview

The ST-906L is a compact 4G GPS tracker designed for cars and motorcycles that supports LTE/GSM connectivity, built-in high sensitivity GPS/GSM antennas, and multiple event reporting methods to enable real-time tracking and anti-theft workflows. When integrated with Plaspy the device provides location awareness, event alerts, and historical route visibility for centralized fleet or single-vehicle monitoring.

- Real-time tracking over LTE/GPRS with optional SMS reporting for location and status.
- Built-in GPS and GSM antennas for reliable positioning in typical vehicle installations.
- Anti-theft toolkit including ACC ignition detection, main power loss alarm, SOS panic calling, and remote relay cut-off for immobilization.
- Alerts for overspeed, shock, and geo-fence events with reporting to platforms and apps.
- Built-in backup battery to report power loss and maintain limited reporting after main power removal.

## Core Features of SinoTrack - ST-906L

- LTE and GSM cellular connectivity for continuous data reporting and SMS.
- High sensitivity built-in GPS antenna for position fixes and route history.
- ACC ignition detection to report vehicle on/off status.
- Main power monitoring with main power-off alarm and backup battery reporting.
- SOS panic button for immediate alerting and sequential caller behavior as supported by the device.
- Overspeed, shock, and geo-fence alerts for event-driven notifications.
- Relay-controlled remote immobilizer for oil or electricity cut-off as supported by the hardware.
- Configuration options via SMS commands for setting server address, APN, and related parameters.

## How These Features Work with Plaspy

When the ST-906L is paired with Plaspy, the device’s location updates and event reports are ingested into Plaspy’s dashboards to provide a single view of vehicle status, alerts, and history. Plaspy detects supported tracker protocols automatically and surfaces device events alongside GPS history to help teams monitor fleet operations and respond to incidents.

- Real-time location points and periodic telemetry appear on Plaspy maps and playback timelines.
- Ignition and power status are reflected in unit summaries and event logs to show running state and power continuity.
- Power loss notifications and backup battery reports are forwarded to Plaspy so outages are visible to operators.
- SOS, overspeed, shock, and geo-fence events create alerts and entries in Plaspy for immediate attention and audit trails.
- Remote immobilizer actions can be coordinated from Plaspy where remote relay control is enabled and supported by the installed device and configuration.
- Devices can be pointed at Plaspy server addresses during setup using the device’s supported configuration method so incoming telemetry is routed to Plaspy for processing.

## Typical Use Cases

- Fleet tracking for small and medium vehicle fleets requiring location visibility and history playback.
- Motorcycle and car anti-theft protection using SOS alerts, power-off notifications, and remote immobilization.
- Driver behavior monitoring with overspeed and shock event logging for coaching and safety programs.
- Rental and shared vehicle monitoring with ignition and geo-fence alerts to detect unauthorized use.
- Single-vehicle monitoring where compact form factor and simple SIM/wiring setup are priorities.

## Feature Availability Notes

- Features depend on the device firmware and hardware revision; not all regions or batches may expose every alert type.
- Installation cabling and how inputs are wired (for ACC, SOS, relay) affect which features are available after installation.
- SMS and GPRS configuration methods are commonly used to set server address and APN; confirm the exact SMS command syntax for your firmware.
- Regional cellular band support and carrier requirements can affect connectivity and performance.
- Manufacturer platform features and free services may be offered in parallel to Plaspy but can change over time.
