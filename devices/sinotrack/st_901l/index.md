# SinoTrack - ST-901L

![ST-901L](./tracker.jpg)

The SinoTrack ST-901L is a compact, vehicle-grade GPS tracker now presented as Plaspy compatible for reliable real-time tracking. Designed for motorcycles, scooters and compact cars, this mini waterproof unit combines 4G connectivity \(with GSM/GPRS fallback\) and high-sensitivity built-in GPS and GSM antennas to deliver timely position updates, alarm reporting and simple server configuration — making it a practical choice for Plaspy users who need discreet, dependable tracking for personal vehicles or small fleets.

Out of the box the ST-901L supports standard tracking channels \(GPRS/SMS\) and step-by-step SMS configuration for IP and APN settings, which enables direct integration with third‑party platforms such as Plaspy. With ACC detection, main power-off alarm \(internal battery backed\), geo-fence and over-speed alerts — plus optional external relay control for ignition or fuel cut-off — the device provides core anti-theft and telemetry features that enhance fleet management and vehicle security when paired with Plaspy’s dashboards and alerting.

## Key Highlights

- Compact, mini waterproof housing for covert installation on motorcycles, scooters and cars.
- 4G network with GSM/GPRS fallback for stable real-time tracking and fast position updates.
- Built-in high-sensitivity GPS and GSM antennas to improve fix reliability in vehicle installations.
- On-device alarms: ACC detection, main power-off alarm \(internal battery\), geo-fence and over-speed alerts.
- Optional external relay interface to enable remote cut-off of fuel or ignition circuits for anti-theft response.
- Easy server/APN setup via SMS commands — configure IP/port and APN quickly for Plaspy compatibility.
- Free smartphone app and web platform support \(SinoTrack PRO and www.sinotrack.com\) plus two-year warranty and vendor support.

## How It Works with Plaspy

The ST-901L sends location and alert packets via GPRS or SMS. Because the device accepts SMS configuration commands for server IP, port and APN, you can point its data stream to Plaspy’s server endpoints and begin receiving telemetry and events in Plaspy’s interface. Integration follows a straightforward activate-and-report flow: configure the APN and target server with the SMS commands supplied by the manufacturer, insert a local SIM, and Plaspy will receive standard position updates and alarm messages for live monitoring and reporting.

- Real-time location and telemetry updates delivered over 4G/GPRS to Plaspy.
- ACC/ignition status reporting to show vehicle on/off state and support ignition-based rules.
- Main power-off alarm via internal battery to detect tampering or power loss events.
- Geo-fence and over-speed alerts sent as events to Plaspy for automated notifications and reports.
- External relay support for remote cut-off of fuel or ignition circuits — can be used as an immobilizer control point when set up with Plaspy and appropriate command workflows.
