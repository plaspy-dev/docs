# SinoTrack - ST-901L Features

This page describes the public feature context for using the SinoTrack ST-901L with Plaspy. It summarizes the ST-901L capabilities relevant to vehicle tracking and fleet oversight, and explains how those capabilities map into Plaspy for monitoring, alerts, and basic remote control workflows. The focus here is practical and non-sensitive information to help you understand what the device can do when paired with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. Review the manufacturer documentation and your device firmware notes for device specific details before planning deployments or advanced workflows.

## Feature Overview

The ST-901L is a compact, waterproof vehicle tracker designed for discreet installation on motorcycles, scooters, and compact cars. With 4G connectivity and GSM/GPRS fallback, built-in high sensitivity GNSS and GSM antennas, and SMS configuration for server and APN settings, the unit can deliver timely position updates and alarm reporting to third party platforms such as Plaspy.

- Compact waterproof housing suited for covert mounting on motorcycles and small vehicles.
- 4G connectivity with GSM GPRS fallback for reliable real time tracking and position updates.
- Built-in high sensitivity GPS and GSM antennas to improve fix reliability in vehicle installations.
- Support for GPRS and SMS tracking plus step by step SMS configuration for server IP and APN.
- On device alarms including ACC detection, main power off alarm using internal battery, geo fence and over speed alerts.
- Optional external relay interface to enable remote cut off of fuel or ignition circuits for anti theft workflows.

## Core Features of SinoTrack - ST-901L

- 4G cellular connectivity with GSM GPRS fallback for continuous reporting.
- Built in high sensitivity GPS and GSM antennas for improved signal reception.
- Mini waterproof form factor intended for motorcycles, scooters, and cars.
- Support for GPRS data reports and SMS based configuration for IP and APN settings.
- ACC detection to indicate vehicle ignition or on off state.
- Main power off alarm backed by an internal battery to detect tampering or power loss.
- Geo fence alerting for perimeter monitoring and automated event generation.
- Over speed alerting to flag potential driving incidents and policy violations.
- Optional external relay control for remote fuel or ignition cut off when needed.

## How These Features Work with Plaspy

When configured to report to Plaspy, the ST-901L sends position updates and alarm events that Plaspy can display, log, and use to trigger notifications. Because the device supports SMS configuration for server and APN settings, you can point its data stream to your Plaspy endpoint and begin receiving standard telemetry and events for monitoring and reporting.

- Real time location updates and position history visible in Plaspy dashboards.
- ACC or ignition status reported as a discrete telemetry field to support on off rules and activity filters.
- Main power off alarm events delivered to Plaspy for tamper detection and alerting.
- Geo fence and over speed events show up as alerts and can trigger notifications and reports.
- Optional relay based immobilization or cut off control can be represented in Plaspy workflows when coordinated with on device relay wiring and command procedures.

## Typical Use Cases

- Small fleet visibility for delivery motorcycles and compact vehicle fleets with live location and event monitoring.
- Motorcycle and scooter theft deterrence and recovery using discreet waterproof installation and power loss alerts.
- Personal vehicle protection with real time tracking, geo fence notifications, and power cut alerts.
