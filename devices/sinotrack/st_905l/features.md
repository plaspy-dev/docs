# SinoTrack - ST-905L Features

This page provides a public feature summary describing the SinoTrack ST-905L and how its capabilities relate to use with Plaspy. The content focuses on practical, non-sensitive information about what the device can do and how it can be configured to report location and telemetry into Plaspy for fleet management and asset monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional variants and how the unit is installed. Always consider those variables when planning deployments and refer to manufacturer documentation for the latest device specific details.

## Feature Overview

The ST-905L is a rugged, waterproof GPS tracker designed for vehicle and high value asset tracking. Its combination of cellular connectivity, a high sensitivity GNSS receiver, a large rechargeable battery and a magnetic weatherproof enclosure make it suitable for remote monitoring and discreet installs where extended standby and reliable position updates are required.

- LTE Cat 1 and 2G GSM cellular connectivity for broad regional network support.
- High sensitivity UBLOX UBX G7020 GNSS receiver for consistent GPS fixes and typical meter level accuracy.
- Large rechargeable 3.7V Li ion battery with long standby performance for intermittent reporting scenarios.
- Magnetic, waterproof housing for fast tool free mounting on metal surfaces.
- SMS based configuration for APN and server settings to simplify field provisioning and activation.

## Core Features of SinoTrack - ST-905L

- LTE Cat 1 and 2G GSM support for data uplink and fall back on available networks.
- UBLOX UBX G7020 GNSS module with high sensitivity and practical location accuracy.
- Built in rechargeable 3.7V Li ion battery sized for extended standby periods.
- Weatherproof magnetic enclosure designed for quick attach and discreet placement.
- SMS configuration commands to set APN and custom server address for cloud integration.
- Ready to accept a data capable SIM for cellular operation.
- Designed for vehicle and asset tracking use cases including motorcycles and light vehicles.

## How These Features Work with Plaspy

When configured for Plaspy, the ST-905L can deliver position updates and telemetry into the Plaspy platform for centralized visibility and monitoring. Plaspy accepts incoming device data on its ingestion endpoint and can display location, history, and event information in the dashboard and mobile interfaces.

- Point the device to your Plaspy ingestion endpoint using SMS based server and APN configuration.
- Real time location updates and routine telemetry reporting are visible in Plaspy once the device is reporting to the platform.
- Battery and power related alerts reported by the device can be surfaced in Plaspy for remote monitoring and anti theft workflows.
- Geofence events, route history and per device reporting become available in Plaspy after server details and APN are configured.
- Plaspy can accept TCP or UDP connections and automatically detect the tracker protocol when the device is pointed to the Plaspy server.

## Typical Use Cases

- Fleet management for light vehicles and motorcycles requiring regular position updates and trip history.
- Anti theft monitoring where discreet mounting and remote alerts help detect unauthorized movement or power loss.
- Asset tracking for equipment deployed outdoors or seasonally where waterproofing and long battery life matter.
- Temporary installs and rentals that benefit from tool free magnetic attachment and quick provisioning.
- Remote monitoring projects that use intermittent reporting to conserve battery while maintaining awareness.
