# SinoTrack - ST-905L

![ST-905L](./tracker.jpg)

The SinoTrack ST-905L is a rugged, waterproof GPS tracker designed for reliable vehicle and asset tracking. It combines LTE Cat‑1 and 2G cellular connectivity with a high sensitivity UBLOX UBX‑G7020 GNSS receiver and a large rechargeable 3.7V Li‑ion battery to provide extended standby and consistent position updates for cars, motorcycles, and other high value assets. The unit ships ready for cellular activation (SIM not included) and is built for quick magnetic mounting to metal surfaces.

This model is Plaspy compatible and can be configured to send real time location and telemetry to a Plaspy server. The ST-905L accepts server and APN settings via SMS commands, making it straightforward to repoint the device from the default platform to Plaspy for centralized fleet monitoring, alerts, and reporting. That flexibility makes the ST-905L appropriate for deployments where discreet mounting, long battery life, and dependable tracking are important.

## Key Highlights

- Plaspy compatible device that can be pointed to a custom server and APN for real time tracking and reporting.
- Rugged waterproof housing with magnetic mount for fast tool free installation onto vehicles and assets.
- Long life rechargeable 3.7V Li ion battery with extended standby times suitable for intermittent reporting.
- High sensitivity UBLOX UBX‑G7020 GNSS receiver providing consistent position updates and practical location accuracy.
- Dual cellular support with LTE Cat‑1 and 2G GSM for broad regional connectivity where networks are available.
- SMS based provisioning for APN and server settings to simplify field activation and integration with Plaspy.

## How It Works with Plaspy

Integration with Plaspy is straightforward because the ST-905L can be configured to send its data to a custom server address and APN via SMS commands. Once the device is provisioned with a data capable SIM and updated server settings, it will transmit location packets and telemetry over the available cellular link to Plaspy for live visibility and historical reporting.

- Sends real time location and telemetry to Plaspy after server IP and APN are set via SMS provisioning.
- Supports delivery of battery and power loss notifications to Plaspy for anti theft workflows and remote monitoring.
- Enables geofencing, route history, and per device reporting to be viewed and managed inside Plaspy dashboards.
- Works with Plaspy fleet features for monitoring, alerts, and operational oversight across vehicles and assets.
- SMS configuration allows field activation without proprietary tools so installers can reconfigure devices to Plaspy on site.

## Typical Use Cases

- Fleet management for light vehicles and motorcycles needing real time location visibility and trip history.
- Anti theft monitoring with discreet magnetic mounting and remote alerts for movement or power interruption.
- Asset tracking for equipment in outdoor or seasonal deployments where waterproofing and long standby matter.
- Short term rentals and temporary installs that benefit from quick attach and removable magnetic mounting.
- Remote or mobile assets where reliable GNSS performance and cellular uplink are required for oversight.
