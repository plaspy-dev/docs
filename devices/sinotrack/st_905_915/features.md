# SinoTrack - ST-905/915 Features

This page provides a public feature overview of the SinoTrack ST-905/915 and how its documented capabilities relate to using the device with Plaspy. It highlights the tracker functions that are most relevant for monitoring, alerts, and long term asset deployments when the device is connected to Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation style, and the manufacturer implementation. Use this page as a practical reference for capabilities commonly associated with the ST-905/915 and consult manufacturer resources for device specific details.

## Feature Overview

The ST-905/915 is positioned as a rugged, compact tracker intended for reliable location reporting and extended deployment. It pairs long battery standby with position accuracy and several event alarms to support asset and vehicle monitoring.

- Long duration standby from a high capacity internal battery for extended deployments without frequent recharging
- GPS positioning with published accuracy suitable for general location monitoring and route history
- Configurable alarm events including low battery, shock, and over speed for security and operational alerts
- Voice monitor capability for remote audio listening where content is permitted and configured
- Magnetized and waterproof enclosure that supports simple mounting and protected outdoor use
- SMS and GPRS connectivity options for remote reporting and command based configuration

## Core Features of SinoTrack - ST-905/915

- High capacity internal battery offering extended standby times appropriate for long term asset tracking
- Positioning accuracy reported at roughly 10 meters 2D RMS under normal satellite conditions
- Built in low battery alarm to signal when device power approaches a configured threshold
- Shock alarm to report impacts or tampering events
- Over speed alarm for basic speed based alerts
- Voice monitor function for remote audio surveillance where supported by local rules
- Magnet and waterproof design for flexible, durable installations
- Support for SMS and GPRS communications for remote tracking and configuration

## How These Features Work with Plaspy

When an ST-905/915 is connected to Plaspy, its key capabilities can be surfaced as routine monitoring data and actionable events. Plaspy is designed to integrate common tracker events into a unified operational view.

- Location updates appear on Plaspy maps and can be used for tracking movement and route history
- Alarm events such as low battery, shock, and over speed are recorded as device events and can generate notifications
- Long battery life supports longer unattended reporting intervals for low maintenance asset monitoring within Plaspy
- Voice monitor activations can be logged as events; availability in Plaspy depends on how the device reports the function
- Plaspy automatically detects the tracker protocol during device setup so basic connectivity and reporting are typically straightforward
- SMS and GPRS based reporting are represented in Plaspy as regular telemetry where the device forwards location and alarms to the platform

## Typical Use Cases

- Security and tamper detection using shock and low battery alerts
