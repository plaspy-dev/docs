# SinoTrack - ST-901AL

![ST-901AL](./tracker.jpg)

The SinoTrack ST-901AL is a wired 4G LTE GPS tracker engineered for reliable vehicle monitoring and security. Designed for professional installs, the ST-901AL reports location via GPRS and SMS, includes an ACC \(ignition\) input for accurate engine-on/off telemetry, and supports remote cut-off through an external relay — making it an excellent choice for Plaspy compatible deployments that require dependable real-time tracking and anti-theft control.

The device is Plaspy compatible because it exposes configurable IP/port and APN settings and supports standard SMS/GPRS reporting protocols, allowing seamless integration with third-party platforms like Plaspy as well as SinoTrack’s own SinoTrack PRO app and VIP.SINOTRACK web portal. Customers can install their own SIM, configure APN credentials, and activate online tracking using SMS commands for quick setup in the field.

## Key Highlights

- Wired 4G LTE GPS tracker with quad-band GSM compatibility for broad network support and consistent real-time tracking.
- ACC input for ignition detection and accurate telemetry on engine status, improving reporting for fleet management and usage analytics.
- Remote immobilizer capability via external relay to cut fuel or power circuits for anti-theft and unauthorized-use response.
- Multiple reporting channels: real-time location via GPRS and SMS for resilient connectivity in varied network conditions.
- Configurable IP/port and APN settings plus documented SMS commands for rapid integration with Plaspy or other tracking platforms.
- Free lifetime access to SinoTrack PRO mobile app and VIP.SINOTRACK web portal \(SIM not included\) for optional platform management.
- Installation guidance and pictorial wiring references provided for cars, motorbikes, and a wide range of vehicle types.

## How It Works with Plaspy

When integrated with Plaspy, the ST-901AL sends location and alarm data over GPRS to the configured server IP and port. Because the tracker supports configurable APN and server settings by SMS, you can point device traffic to Plaspy’s ingestion endpoint and receive real-time tracking, alerts, and telemetry in the Plaspy dashboard or via Plaspy APIs.

- Real-time location and telemetry updates via GPRS \(primary\) and SMS \(fallback\) for continuous visibility.
- ACC \(ignition\) detection — Plaspy can use ignition events to create ignition-based reports and drive-time analytics.
- Remote immobilizer/relay control — trigger a relay-controlled fuel or power cut via Plaspy-issued commands \(requires external relay wiring and appropriate safety/legality checks\).
- Alarm and event notifications — overspeed, authorized-number violations, and stop/start data saving intervals are reported and can be translated into Plaspy alerts.
- Platform configuration by SMS — devices can be re-pointed to Plaspy by sending the documented SMS sequences to set APN, server IP, and port.

## Use Cases

- Fleet management: monitor vehicle location, ignition times, and overspeed events for taxis, delivery trucks, and service fleets.
- Anti-theft protection: use the external relay to remotely disable fuel or power for stolen or misused vehicles when coordinated with Plaspy alerts.
- Private vehicle monitoring: simple setup for cars or motorcycles to track trips and receive real-time alarm notifications.
- Two-wheeler and micro-mobility management: wired installations and mounting guidance make the ST-901AL suitable for e-bikes and scooters with inline power feeds.
- Telemetry-based reporting: ignition events and saved interim data while stopped provide richer telematics records for operational analysis.
