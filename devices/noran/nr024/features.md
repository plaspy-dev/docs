# Noran - NR024 Features

This page describes the public feature context for using the Noran NR024 GPS tracker with Plaspy. It summarizes the NR024 capabilities that are relevant to vehicle and fleet tracking, and explains how those capabilities are typically represented in Plaspy for monitoring, alerts, and operational oversight.

Exact feature availability can vary by firmware version, hardware revision, installation options, and manufacturer configuration. The information below is based on the NR024 feature descriptions provided by the manufacturer and is intended as a practical guide; consult the manufacturer documentation for definitive, device specific details.

## Feature Overview

The Noran NR024 is a vehicle-focused tracker that combines GPS location, wireless data upload, onboard imaging, and vehicle monitoring functions. It is designed to deliver real-time location and supplemental media and telemetry to a tracking platform such as Plaspy for improved situational awareness.

- Real time GPS tracking and navigation reporting for vehicle location awareness
- Onboard digital camera with image upload for verification and event evidence
- Fuel monitoring and fuel curve upload to support consumption analysis
- GSM GPRS wireless communication for continuous data uplink to a tracking server
- Remote engine control and vehicle status monitoring including position and speed

## Core Features of Noran - NR024

- GPS positioning with assisted location support using A GPS LBS for improved fix performance
- Digital camera capable of taking photos and uploading images to a tracking system
- Fuel monitoring with the ability to produce and upload fuel curve information
- Audio monitoring functionality for remote audio capture where installed and permitted
- GSM GPRS connectivity for sending location, events, images, and telemetry to a backend
- Remote engine control that can be used to disable or control engine function as supported by installation
- Real time upload of location and event data using configurable time or distance intervals
- Alerts and event features such as geo fencing, over speed alerts, SOS function, and general vehicle status monitoring

## How These Features Work with Plaspy

Plaspy receives and normalizes the NR024 data so fleet managers can view location, events, and media in a single interface. When an NR024 device reports, Plaspy maps position updates, surfaces alerts, and attaches supported media to relevant events for review.

- Live map tracking of reported GPS positions and recent breadcrumb history
- Event alerts for geo fence breaches, over speed incidents, and SOS notifications
- Attached images from the NR024 camera available with the corresponding event or trip record
- Fuel curve and fuel monitoring data visualized in Plaspy reports and fuel history tools
- Remote command support reflected in Plaspy as device actions or command activity where supported by the installation and permissions

## Typical Use Cases

- Fleet location tracking and route verification for daily operations
- Incident documentation by uploading photos from the tracker camera to confirm conditions
- Monitoring fuel use trends and identifying excessive consumption through fuel curve data
- Theft response and recovery workflows using remote engine control and SOS alerts
- Compliance and operational oversight with geo fence and over speed alerting
- Remote audio monitoring for specific operational needs where audio is enabled and lawful

## Feature Availability Notes

- Manufacturer firmware versions and hardware revisions can enable or disable specific features such as camera, audio, or fuel reporting.
- Some functions depend on how the device is installed and wired in a vehicle; optional sensors or accessories may be required for fuel or audio monitoring.
- Regional variants and GSM band support may affect connectivity in certain countries; check the device variant for your region.
- Plaspy displays and handles features that the device actually reports; missing fields typically indicate the device or installation did not provide that data.
- Always confirm the latest feature list and supported options with the manufacturer documentation for the specific NR024 unit you are using.

## Why Use Plaspy with These Features

Using Plaspy to centralize NR024 data helps organizations turn device reports into operational insight. Plaspy aggregates position updates, alerts, and media to provide a coherent view of vehicle activity, which simplifies monitoring, incident investigation, and fleet reporting. When the NR024 uploads images, fuel curve data, and status events, Plaspy can present those items alongside GPS tracks so teams can act on a richer set of information.
