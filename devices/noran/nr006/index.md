# Noran - NR006

![NR006](./tracker.jpg)

The NR006 Mini GPS Tracker is an ultra-compact GPS tracker optimized for motorcycles and small vehicles. Designed for discreet installation and reliable location reporting, the NR006 is Plaspy compatible out of the box—delivering real-time tracking data to your Plaspy account via SMS or Internet. Its small size and low data usage make it a practical choice for fleet management and anti-theft protection where space and bandwidth are limited.

Built with built-in GPS and GSM antennas and weighing approximately 100 g, the NR006 supports GPS satellite positioning with LBS fallback for poor-signal environments. The device transmits concise 34-byte position packets to minimize GPRS data usage and supports 24/7 access through client tracking software, enabling continuous telemetry and remote immobilizer control when integrated with Plaspy.

## Key Highlights

- Compact, motorcycle-friendly form factor — small, lightweight, and easy to hide for discreet anti-theft protection.
- Plaspy compatible for real-time tracking via SMS or Internet — view live location and historical routes in your Plaspy dashboard.
- Low-data operation with 34-byte position packets to reduce GPRS usage and lower operating costs for fleet management.
- Security and safety alarms — overspeed alarm, geo-fence alarm, and sleep \(power-saving\) mode to extend device life and reduce false alerts.
- Remote engine cut-off \(immobilizer\) capability via the supplied relay for immediate vehicle immobilization when needed.
- Optional backup battery and internal flash memory for power-cut alarm and offline data logging during connectivity loss.
- Simple 3-wire installation and included relay/connection cable for fast deployment on motorcycles and small vehicles.

## How It Works with Plaspy

The NR006 integrates with Plaspy by sending compact GPS/LBS position packets and alarm events over SMS or GPRS to Plaspy’s ingestion endpoints. Plaspy processes those packets to offer real-time tracking, route playback, and configurable alerts. Because the NR006 is optimized for low-bandwidth reporting, it is ideal for deployments that require continuous telemetry without high data consumption.

- Real-time location and telemetry updates delivered to Plaspy via Internet \(GPRS\) or SMS.
- GPS positioning with LBS fallback ensures location reporting even in urban canyons and low-signal areas.
- Alarm and event notifications \(overspeed, geo-fence breach, sleep/power-saving alarms\) appear in Plaspy as immediate alerts.
- Remote immobilizer/engine cut-off: relay control commands from Plaspy can trigger the supplied relay for anti-theft action.
- Optional offline logging: internal flash memory \(if fitted\) holds data that Plaspy can ingest after connectivity is restored; optional backup battery supports power-cut alarm and short-term operation.
