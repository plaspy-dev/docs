# Noran - NR028 Features

This page provides a public, feature-focused overview of the Noran NR028 and how its capabilities are used with Plaspy for centralized vehicle tracking, telemetry, and operational monitoring. It explains the main capabilities you can expect to see in Plaspy when the NR028 is reporting, while keeping the description at a high, non-sensitive level suitable for public documentation.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, installation method and manufacturer implementation. Use this page as a practical guide to capabilities and integration with Plaspy, and consult the official Noran documentation for device-specific technical and installation details.

## Feature Overview

The NR028 is a vehicle-mounted navigation and telematics unit that combines satellite positioning with in-cab navigation, an embedded camera and telephony functions to support fleet operations and vehicle security. When paired with Plaspy, the unit delivers real-time location, alarms and selected telemetry for dashboards, alerts and historical playback.

- Real-time tracking via GPRS/Internet and SMS with LBS fallback to preserve location reporting in variable coverage.
- Integrated touchscreen navigation and embedded camera for driver navigation, incident capture and event metadata.
- Two-way voice calling, listen-in voice monitoring and text messaging to support driver communication and remote monitoring.
- Remote command functions including engine cut-off (remote immobilizer) and over-the-air parameter configuration for GPRS/IP and APN.
- Fuel monitoring support for up to two external fuel sensors and on-device logging to improve fuel oversight and anti-theft workflows.

## Core Features of Noran - NR028

- GPS satellite positioning with LBS fallback for continued location reporting in weak coverage.
- GPRS/Internet and SMS reporting for flexible connectivity into centralized platforms such as Plaspy.
- Built-in digital camera and event logging for incident documentation and visual evidence capture.
- 4.3 inch or 7 inch TFT touchscreen options for in-cab navigation and operator interaction.
- Two-way voice calling and listen-in voice monitoring to support driver communication and remote oversight.
- Remote immobilizer support with relay for engine cut-off and remote command execution.
- Onboard storage (4 GB) and optional internal flash logging to retain recent events and positions when connectivity is limited.
- Alarm set including overspeed, geo-fence, SOS emergency alarm and power cut-off detection with internal backup battery.

## How These Features Work with Plaspy

Plaspy ingests the NR028 telemetry and alarm states to present them in centralized dashboards, alerts and historical views. The platform translates incoming location, sensor and alarm data into actionable events and reporting suitable for fleet and security operations.

- Live location and position updates appear on Plaspy maps and can be used for real-time monitoring and route oversight.
- Alarm events such as SOS, geo-fence breaches, overspeed and power cut-off are processed by Plaspy to trigger notifications and workflows.
- Fuel sensor readings and related telemetry reported by the NR028 can be surfaced in Plaspy for consumption reports and anti-theft alerts.
- Remote immobilizer or engine cut-off commands are issued from Plaspy as part of a coordinated response when the device and installation support that function.
- Camera event metadata and logged incidents from the NR028 can be associated with Plaspy records for post-incident review and reporting.

## Typical Use Cases

- Fleet dispatch and route guidance using the NR028 touchscreen navigation combined with Plaspy location visibility.
- Vehicle security and anti-theft response leveraging SOS alarms, listen-in monitoring and remote immobilizer commands.
- Fuel monitoring and theft detection using external fuel sensors and centralized reporting through Plaspy.
- Incident documentation and driver coaching using embedded camera captures and historical event logs.
- Operations in regions with variable cellular coverage where SMS and LBS fallback help maintain minimal tracking continuity.
- Centralized telemetry and scheduled reporting for operations teams that need historical playback and event timelines.

## Feature Availability Notes

- Firmware and hardware revisions can affect which features are available; some capabilities may be added or changed in later firmware updates.
- Several features such as external fuel sensors, temperature inputs, or the remote immobilizer require proper installation and optional accessories to function.
- Regional or carrier firmware variants may change SMS, GPRS or telephony behavior; SIM configuration and APN settings will influence connectivity.
- Manufacturer settings and installer configuration determine which alarms and remote commands are enabled by default.
- Always confirm feature lists and behavior for a specific unit with the official Noran product documentation before deployment.
