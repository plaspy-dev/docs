# Noran - NR008 Features

This page provides a public feature overview for the Noran NR008 and explains how its documented capabilities can be used with the Plaspy platform. It focuses on user-facing features and operational value that matter for Plaspy-compatible deployments, including tracking, alerting, and remote control functions.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, or installation method. For device-specific technical details and the latest firmware behavior please refer to the official manufacturer documentation linked below.

## Feature Overview

The NR008 is a vehicle tracker built for real-time tracking and practical fleet control workflows. It combines GNSS positioning, cellular telemetry, and remote command functions to deliver location updates and event notifications into Plaspy for map-based monitoring and alerting.

- Real-time GNSS position updates for continuous vehicle location visibility.
- Remote immobilizer and engine control using SMS or GPRS commands for anti-theft response.
- SOS emergency alerts and in-vehicle voice monitoring to support incident response.
- Geo-fencing and movement detection to notify about boundary breaches or unexpected motion.
- Over-speed alarms and anti-dismantle alerts to support safety and tamper detection.
- Supplied accessories such as an SOS button, microphone, GPS antenna, and connection cable for rapid installation.

## Core Features of Noran - NR008

- SiRFstar GNSS positioning for dependable location fixes and navigation data.
- SIMCOM GSM/GPRS cellular connectivity for telemetry delivery and remote commands.
- SMS and GPRS channels for reporting location and receiving remote configuration or control.
- Remote immobilizer and engine control functionality for fuel shutoff via supported wiring and commands.
- SOS alarm input and emergency alert reporting to notify authorized contacts and platform channels.
- Voice monitoring via built-in microphone and call-in listening for authorized numbers.
- Geo-fencing, over-speed alarms, and movement detection for perimeter and driver safety monitoring.
- Anti-dismantle alarm triggered by vehicle power loss to detect tampering.

## How These Features Work with Plaspy

When integrated with Plaspy, NR008 position and event data are received by the platform and presented alongside other fleet telemetry for operational oversight. Plaspy can ingest the tracker’s SMS or GPRS reports and surface alerts on maps, timelines, and notification channels.

- Real-time location updates appear on Plaspy maps and can be used for live tracking and route review.
- Geo-fence violations, movement detection, over-speed events, and anti-dismantle alarms generate notifications and event records in Plaspy.
- SOS alerts from the device can be forwarded to Plaspy notifications and to authorized contacts for rapid response.
- Remote immobilizer and engine control commands can be sent through Plaspy using the device’s supported SMS or GPRS command channels.
- Plaspy automatically detects common tracker protocols to simplify setup and can aggregate NR008 data alongside other peripherals when deployments include additional sensors.
- Device configuration and server settings can reference Plaspy’s server address (for example d.plaspy.com) so telemetry and commands flow into the platform.

## Typical Use Cases

- Fleet management: track vehicles in real time, monitor routes, and generate historical movement reports.
- Anti-theft operations: detect tampering, receive anti-dismantle alarms, and perform remote immobilization when supported.
- Rental and shared mobility: use geo-fencing and movement alerts to protect assets and enforce location rules.
- Driver safety and emergency response: SOS button and voice monitoring help coordinate assistance during incidents.
- Compliance and safety enforcement: over-speed alarms support speed policy monitoring and incident investigation.
- Asset custody: centralized visibility for dispatch centers and logistics operators to manage mobile resources.
