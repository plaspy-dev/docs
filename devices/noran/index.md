## How Noran devices work with Plaspy

Plaspy receives location and telemetry data from Noran devices and presents it in a unified tracking interface. Integration typically relies on standard device telemetry formats and configurable device endpoints, allowing Plaspy to ingest position updates, status messages, and basic sensor inputs. Once a Noran device is connected to Plaspy, you can view live location, historical routes, and alerts through the Plaspy platform.

If you need assistance connecting a specific Noran model, consult the model entry in the catalog above and follow the setup guidance for device parameters and server settings. Plaspy documentation and support can help with common configuration patterns and troubleshooting.

## Common features found in Noran devices

While specific capabilities vary by model, Noran devices commonly provide the following types of functionality:

- Real time GPS location updates and historical route playback
- Configurable movement and geofence alerts
- Digital and analog inputs for external sensors and ignition detection
- Backup power and tamper or low battery alerts on some models
- Event reporting triggered by speed, movement, or input changes
