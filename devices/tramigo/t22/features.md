# Tramigo - T22 Features

This page describes the public feature context for using the Tramigo T22 with Plaspy. It summarizes the practical capabilities you can expect to see when the T22 reports into Plaspy and explains how those capabilities support location visibility, basic event reporting, and operational monitoring on the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. The information below is drawn from publicly available device descriptions and is intended to be accurate and useful, but some functions and operational details depend on the specific device configuration and firmware installed by the device owner or installer.

## Feature Overview

The Tramigo T22 is a combined GSM and GPS tracker designed for vehicle and asset monitoring. It uses mobile network data for real time position reporting, can store location data when connectivity is interrupted, and includes configurable inputs and power backup to support continuous tracking in common vehicle and asset scenarios.

- Real time location reporting over GSM GPRS for ongoing position visibility.
- Time or distance based reporting to control how often the device sends updates.
- Internal GPS and GSM antennas to simplify installation without external antenna wiring.
- Built‑in backup battery to continue tracking if main power is disconnected.
- Internal memory for local data storage and forward transmission when connectivity returns.
- Pre defined inputs such as ignition and panic button support for event based tracking.

## Core Features of Tramigo - T22

- GSM GPRS communication enabling live reporting and server side monitoring.
- Multi band GSM support including 850 1900 MHz and 900 1800 MHz for broad regional coverage.
- Internal GPS receiver providing position fixes for mapping and tracking.
- Backup battery that allows continued operation after main power removal.
- Internal memory for logging position and event data during network outages.
- Configurable reporting by time interval or distance travelled.
- Sleep mode to conserve battery when the device is idle.
- USB port for device configuration and data access plus pre defined inputs like ignition and panic buttons.

## How These Features Work with Plaspy

Plaspy ingests location and event data from compatible trackers and presents that information in a unified view so teams can monitor assets and respond to incidents. When a Tramigo T22 is configured to report to Plaspy, its position updates and supported input events become visible in the platform for analysis and operational use.

- Plaspy displays incoming GPS positions on maps and stores historical tracks for later review.
- Time or distance based updates from the T22 translate into configurable position reporting frequency inside Plaspy.
- Store and forward behavior from the T22s internal memory is reflected as delayed updates when connectivity is restored.
- Ignition and panic input events reported by the device are shown as event markers for timestamps and context in Plaspy.
- Plaspy automatically detects many tracker protocols and accepts device reports to the Plaspy server domain, simplifying initial setup.
- Device configuration and firmware behavior affect which events and intervals appear in Plaspy, so correct device setup is important.

## Typical Use Cases

- Vehicle fleet tracking and route oversight with periodic position updates.
- Asset recovery and stolen asset monitoring by maintaining location visibility.
- Remote monitoring of deployed equipment where cellular coverage is available.
- Tracking mobile assets where internal antennas and compact installation are preferred.
- Use cases that require temporary or backup power tracking thanks to the internal battery.

## Feature Availability Notes

- Firmware version and device configuration determine which inputs and reporting modes are active.
- Hardware revisions and regional model variants may affect supported GSM bands and local regulatory compliance.
- Installation method and wiring can influence visibility of inputs such as ignition or panic button events.
- Manufacturer firmware updates can add or change behaviors for sleep mode, reporting logic, and data storage.
- Always confirm feature lists and operational details against the device label and the manufacturer documentation for your specific unit.
