# TopFly - SolarGuardX 200 Features

This page provides a public overview of the TopFly SolarGuardX 200 features and how the device integrates with Plaspy for asset tracking and fleet monitoring. It focuses on practical, non sensitive feature context for users looking to understand what the SolarGuardX 200 can report, how events appear in Plaspy, and the operational value this tracker brings to container, trailer and remote asset protection.

Exact feature availability can vary by firmware version, hardware revision, regional SKU and installation method. Where the SolarGuardX 200 description lists multiple options and capabilities, the implementation you receive may differ based on the unit SKU and manufacturer configuration, so confirm device specifics with TopFly documentation.

## Feature Overview

The SolarGuardX 200 is a rugged solar powered GPS padlock designed for long autonomy and secure outdoor use. Its combination of persistent solar charging, a high capacity rechargeable battery and tamper detection makes it suited to long term container and trailer deployments where continuous location and event telemetry matter.

- Persistent solar assisted power combined with a large rechargeable Li Polymer battery for extended field operation
- IP67 rated rugged padlock form factor with lock and tamper event reporting for anti theft workflows
- High accuracy parallel GNSS positioning for precise location updates and reliable telemetry
- Multiple cellular connectivity options with standard reporting protocols to feed Plaspy in real time
- Local and remote access methods including RFID and Bluetooth plus OTA and SMS command support

## Core Features of TopFly - SolarGuardX 200

- Solar charging together with a 14,400 mAh rechargeable Li Polymer battery for extended autonomy
- IP67 rated enclosure in a padlock form factor built for outdoor container and trailer use
- Tamper detection and security events including rope cut, SIM cover removal, and lock or unlock reporting
- Parallel GNSS support with GPS GLONASS Galileo and Beidou and a Qualcomm Gen 8C receiver for sub 2.5 m CEP horizontal accuracy
- Multiple cellular radio options depending on SKU with reporting via standard protocols such as TCP UDP MQTT and SMS
- Local access and control via RFID and Bluetooth 5.1 plus remote control options through OTA commands or SMS
- Firmware upgrade over the air and configurable encryption options for secure fleet management

## How These Features Work with Plaspy

SolarGuardX 200 devices report position, security events and device status into Plaspy where those inputs become actionable items in dashboards, alerts and history. Plaspy receives standard telemetry and presents location and event data alongside other assets for unified monitoring and response.

- Real time location updates and position history displayed on Plaspy maps and timelines
- Lock unlock events and tamper alarms forwarded to Plaspy to trigger notifications and incident workflows
- Buffered tracking history from the device preserved and uploaded so Plaspy can show gapless routes when coverage returns
- Remote commands and configuration delivered from Plaspy using the device supported channels such as OTA or SMS where enabled
- BLE and accessory sensor inputs reported by the device and surfaced in Plaspy when those accessories are paired and supported

## Typical Use Cases

- Container and trailer security with real time anti theft alerts and remote control of access
- Long duration remote cargo monitoring where solar assisted power reduces maintenance intervals
- Customs and asset protection deployments that require tamper detection reporting and certified hardware
- Outdoor equipment and high value asset tracking in exposed environments with IP67 protection
- Fleet management and operational reporting with position and event telemetry feeding audits and compliance records
