# TopFly - SolarGuardX 100

![SolarGuardX 100](./tracker.png)

SolarGuardX 100 from SolarGuardX is a rugged, solar-powered cargo GPS tracker and padlock engineered for outdoor asset protection and Plaspy compatible deployments. Built for containers, trailers and trucks, the SolarGuardX 100 combines high-capacity battery and integrated solar charging with industrial waterproofing and multiple wireless interfaces to deliver persistent, low-maintenance security tracking that feeds directly into Plaspy for real-time location, alarm and telemetry workflows.

Designed for fleet management and anti-theft use cases, SolarGuardX 100 pairs strong physical protection \(IP67 enclosure, thick casing, integrated magnet and supplied rope\) with advanced connectivity \(LTE Cat M1 / NB2 plus GSM fallback\), BLE accessory support, robust GNSS performance and wide buffering to bridge coverage gaps. When integrated with Plaspy, it provides reliable real-time tracking, configurable geofences and secure transport options for large-scale cargo visibility and security operations.

## Key Highlights

- Plaspy compatible GPS tracker and padlock — native support for real-time tracking, alarms and telemetry ingestion.
- Solar-assisted power with a 14,400 mAh Li‑Polymer battery for extended field endurance and USB Type‑C charging.
- Industrial IP67 enclosure with strong built-in magnet and supplied 350 mm rope for rugged container and trailer mounting.
- High-accuracy GNSS \(MediaTek high-gain chipset\) with parallel GPS+GLONASS or GPS+BeiDou and \<2.5 m CEP horizontal accuracy.
- Wide cellular support: LTE FDD Cat M1 and NB2 for IoT connectivity, with GSM/EDGE fallback for legacy networks.
- BLE 5.x support for temperature/humidity, door sensors and wireless relays; pairs with TOPFLYtech accessories and third-party BLE sensors.
- Advanced security and buffering — up to 49,000 local locations buffered, geofence support \(64 regions\), and configurable rope-cut/lock/unlock alarms.

## How It Works with Plaspy

SolarGuardX 100 transmits position, event and sensor data to Plaspy using standard IoT transports. Once registered in Plaspy, devices stream frequent location updates, alarm events and auxiliary telemetry so dispatchers and security teams can monitor cargo in near real time and act on alerts.

- Real-time location and telemetry updates — configurable down to every 3 seconds for high-frequency tracking needs.
- Geofence events, motion, parking and security alarms \(rope cut, lock/unlock\) delivered to Plaspy for automated alerts and workflows.
- Buffered data upload — up to 49,000 points stored locally and transmitted when coverage is restored, preventing data loss.
- BLE accessory data — temperature, humidity and door status from TOPFLYtech and third-party Bluetooth sensors can be forwarded to Plaspy as telemetry.
- Secure transports — TCP/UDP/MQTT and SMS supported; data security options include MD5 and AES256 for encrypted payloads.

## Use Cases

- Container and trailer security — persistent anti-theft monitoring with rope-cut and lock/unlock alarms reported to Plaspy.
- Fleet asset tracking — real-time location feeds for trailers and portable assets to improve routing and visibility in fleet management.
- Temperature-sensitive cargo — pair BLE temperature/humidity sensors and forward telemetry to Plaspy for cold‑chain awareness.
- Remote access and control — RFID, BLE and remote network commands allow flexible unlocking and control workflows for last-mile operations.
- Off-network data resilience — large local buffering ensures historical tracks are preserved and uploaded when connectivity returns.

SolarGuardX 100 is purpose-built for long-duration outdoor asset security and integrates smoothly with Plaspy to deliver actionable, real-time insights. Its combination of solar-assisted battery capacity, industrial ingress protection, high‑accuracy GNSS and LTE Cat M1/NB2 connectivity makes it a low-maintenance choice for container and trailer deployments. Support for BLE sensors and multiple unlock/control modes \(RFID, BLE, OTA, SMS, remote commands\) extends its value for telemetry and operational workflows.

For operators using Plaspy, SolarGuardX 100 reduces manual checks and data gaps by providing frequent updates \(as fast as every 3 seconds\), resilient local buffering and standardized transports \(MQTT/TCP/UDP/SMS\) with encryption options. Whether you need anti-theft alarms, geofence-triggered alerts, or sensor-enriched telemetry, SolarGuardX 100 is a reliable Plaspy compatible solution for demanding outdoor fleet management and cargo security needs.
