# TopFly - KnightX 100 Features

This page describes the public feature context for using the TopFly KnightX 100 tracker with Plaspy. It focuses on the device capabilities that are relevant when the KnightX 100 is paired with Plaspy for fleet management, asset tracking, and environmental monitoring in enterprise deployments.

Exact feature availability, behavior, and supported options can vary by factory firmware, hardware revision, regional variant, and how the unit is installed or configured by the manufacturer. For device model specific details and the latest technical guidance consult the official TopFly documentation.

## Feature Overview

The KnightX 100 is a rechargeable, discreet GPS tracker designed for long term and covert monitoring of high value assets. It combines hybrid positioning, long battery runtime, on device buffering and BLE accessory support to provide flexible deployment options when used with Plaspy.

- Long life rechargeable battery designed for extended deployments and low maintenance.
- Hybrid positioning using GPS plus Wi‑Fi and LBS to improve location reliability across environments.
- Buffered storage for interrupted connectivity and configurable rapid reporting for real time tracking.
- BLE 5.1 support for external sensors and accessories including temperature and panic inputs.
- Optional external temperature probe for continuous cold chain or refrigerated cargo monitoring.

## Core Features of TopFly - KnightX 100

- Rechargeable large capacity battery suitable for multi‑month deployments depending on reporting interval and usage.
- Hybrid positioning stack with GPS, Wi‑Fi and LBS and multi constellation GNSS to improve fix reliability.
- Rapid update capability plus buffered on device storage for later upload when cellular is restored.
- BLE 5.1 accessory connectivity for temperature sensors, panic buttons and compatible peripherals.
- Optional external temperature probe support for continuous environmental monitoring.
- Discrete magnetic mounting and compact form factor for covert or temporary installations.
- IP67 environmental rating with LED status indicators and USB‑C for maintenance and charging.
- Remote firmware update support and encrypted communications for secure fleet maintenance.

## How These Features Work with Plaspy

When connected to Plaspy, the KnightX 100 streams location and telemetry so operators can monitor assets, receive alerts, and run historical reports. Plaspy ingests the device's location and sensor data to show live positions and events in fleet dashboards.

- Real time location updates and frequent reporting appear in Plaspy dashboards for location awareness and dispatch.
- Buffered positions and telemetry are uploaded to Plaspy after connectivity resumes to preserve historical continuity.
- BLE sensor readings and external temperature probe data are available in Plaspy for environmental monitoring and event rules.
- Movement start/stop and panic or tamper events from the device surface as alerts in Plaspy for incident response.
- FOTA and encrypted device communications help Plaspy users keep device firmware and configuration up to date and secure.
- Plaspy automatically detects many tracker protocols to simplify device onboarding and initial data ingestion.

## Typical Use Cases

- Covert hidden asset tracking for trailers, equipment and valuables where temporary mounting is required.
- High value cargo protection and anti theft monitoring by forwarding movement and panic alerts into Plaspy workflows.
- Cold chain monitoring using the optional external temperature probe and BLE temperature sensors.
- Fleet and trailer tracking for seasonal or temporary deployments where permanent wiring is impractical.
- Short term rentals and field assets that need rapid deployment and remote management.
- Remote assets that require buffered reporting when cellular coverage is intermittent.
