# TopFly - TLW2-2BL

![TLW2-2BL](./tracker.png)

The TLW2-2BL is a compact, hardwired GPS tracker designed for demanding vehicle and powered-asset deployments. Plaspy compatible out of the box, this 4G LTE \(LTE-M CAT-M1\) tracker brings high-frequency real-time tracking, robust offline buffering and integrated environmental sensing to fleets, logistics providers and cold‑chain operators who need reliable position and telemetry data.

Built for straightforward integration with Plaspy, the TLW2-2BL pairs LTE-M connectivity with BLE 5.0 accessory support, ignition detection and a relay output for remote control. Whether you need precise location updates every few seconds, anti-theft alerts or temperature and door monitoring via Bluetooth sensors, this small-form tracker delivers the core telemetry and remote control features fleet management teams expect.

## Key Highlights

- Plaspy compatible GPS tracker with LTE-M \(CAT‑M1\) connectivity and 2G/NB2 fallback for broad coverage and resilient data delivery.
- Real-time tracking with updates as frequent as every 3 seconds and onboard buffering of up to 49,000 location points for gap-free history during outages.
- Integrated BLE 5.0 support to pair temperature, humidity and door sensors plus wireless relays — ideal for cold‑chain monitoring and environmental telemetry.
- Ignition detection and relay output enable remote control actions, supporting anti-theft workflows and immobilizer-style functions via remote output control.
- High‑accuracy GNSS using a MediaTek high‑gain receiver \(GPS+GLONASS+Galileo+Beidou\) with autonomous position accuracy under 2 meters.
- Comprehensive alarms and event detection including power disconnection, low backup battery, speeding, towing, crash detection and network jamming.
- Compact, hardwired form factor \(IP65\) with wide input range \(7 V–60 V DC\), 200 mAh Li‑Polymer backup battery and extreme temperature operation for vehicle and trailer installs.

## How It Works with Plaspy

The TLW2-2BL connects to Plaspy using standard IP and messaging protocols to stream GNSS positions, sensor telemetry and event alerts. Plaspy ingests the device's high-rate location updates, BLE accessory sensor readings and alarm states to present live maps, telemetry dashboards and automated reports for fleet management and cold-chain monitoring.

- Real-time location and telemetry updates — frequent position fixes \(as fast as every 3 seconds\) and historical replay from buffered points.
- Ignition and alarm status — ignition detection and digital input/external sensors report on vehicle state changes to Plaspy for fleet workflows.
- Fuel monitoring — the unit transmits telemetry and supports integrations; when paired with appropriate fuel or CAN sensors, Plaspy can visualize fuel consumption and alerts.
- Remote immobilizer and control — relay output and remote output control can be used to implement immobilizer-style or engine-interrupt functions through Plaspy-triggered actions.
- Bluetooth sensors — BLE 5.0 accessory support enables temperature, humidity and door sensors to be forwarded to Plaspy for cold-chain and door-open monitoring.

## Use Cases

- Fleet management — continuous GPS tracker data, driving behavior telemetry and ignition events feed Plaspy dashboards for operational visibility and route optimization.
- Anti-theft and immobilization — real‑time alerts for towing, power disconnection and jamming plus relay control for remote immobilizer workflows.
- Cold-chain logistics — BLE temperature and humidity sensors paired to the unit send environmental telemetry to Plaspy for compliance and spoilage prevention.
- Trailer and container monitoring — compact, hardwired installation with long buffer memory provides location persistence and event alerts for detached assets.
- Post-incident analysis — 6‑axis accelerometer and crash detection capture event data for accident reconstruction and driver coaching via Plaspy reports.

## Why Choose This Tracker with Plaspy

The TLW2-2BL delivers a balanced mix of compact installation, precise GNSS positioning and extended telemetry through BLE sensors, making it a strong choice for teams deploying Plaspy across mixed fleets and cold‑chain assets. Its LTE‑M connectivity with 2G/NB2 fallback, deep onboard buffering and frequent update capability ensure Plaspy receives reliable, high-resolution tracking data even in challenging coverage areas.

For operators who value anti-theft features, telemetry extensibility and remote control, the TLW2-2BL’s relay output, ignition detection and remote output control provide the hooks necessary to implement immobilizer and alerting logic inside Plaspy. Combined with FOTA and standard protocols \(TCP/UDP/MQTT/SMS\), deployment and lifecycle management is straightforward for large-scale fleet management, logistics and temperature-sensitive asset monitoring.
