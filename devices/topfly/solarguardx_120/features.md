# TopFly - SolarGuardX 120 Features

This page describes the public feature context for the TopFly SolarGuardX 120 and how the device is used with Plaspy. It focuses on user facing capabilities such as tamper and lock state telemetry, multi lock coordination, solar assisted operation, and how those data points augment GPS tracker position feeds inside Plaspy for combined asset visibility and security monitoring.

Exact feature availability, naming, and behavior can vary by firmware version, hardware revision, installation method, regional variant, and manufacturer implementation. For device specific installation details, firmware notes, or compliance information consult the manufacturer documentation and release notes.

## Feature Overview

The SolarGuardX 120 is a rugged, solar assisted sub lock engineered for outdoor asset protection and synchronized multi lock operation. When paired with Plaspy, the unit contributes security and state telemetry that complements GPS position data and fleet dashboards, helping operators see access events and tamper conditions alongside location.

- Solar assisted operation to extend field life and reduce maintenance for deployed locks.
- Long range BLE 5.3 connectivity for control and diagnostics, enabling master/slave coordination.
- Tamper, motion, lid/open and lock state telemetry that can be recorded with GPS tracker feeds in Plaspy.
- Rugged IP67 housing for outdoor logistics and protected mounting on containers, trailers, and pallets.
- FOTA firmware updates and USB Type C access for remote maintenance and diagnostics.

## Core Features of TopFly - SolarGuardX 120

- Plaspy compatibility for delivering tamper, battery, and lock state telemetry into fleet dashboards.
- Solar assisted charging with onboard rechargeable battery to reduce onsite servicing.
- Long range Bluetooth Low Energy 5.3 for remote control, diagnostics, and master/slave synchronization.
- Master and slave multi lock capability for synchronized locking and unlocking across multiple points.
- Local alarms and visible LED status indicators for quick onsite diagnostics of events.
- Firmware over the air updates and USB Type C port for lifecycle management and troubleshooting.
- Rugged IP67 rated enclosure designed for outdoor logistics and harsh environments.
- Onboard temperature sensor and RFID support as part of local condition and access control features.

## How These Features Work with Plaspy

SolarGuardX 120 supplies security telemetry and event data that Plaspy ingests alongside GPS tracker position feeds to create a unified view of asset condition and access. Operators can correlate location with security events to improve situational awareness and auditability.

- Real time telemetry and event alerts visible in Plaspy including tamper, lid open, motion alarms, and battery state.
- Master/slave lock actions recorded for audit trails and coordinated access workflows.
- BLE telemetry collected through compatible gateways or mobile links can be associated with GPS trackers in Plaspy for consolidated reporting.
- FOTA and USB diagnostics enable centralized management of firmware versions and device health from Plaspy driven processes.
- Combined reporting where lock state and security events augment route, location, and historical logs for operations teams.

## Typical Use Cases

- Container and trailer logistics where synchronized locks secure multiple entry points and provide an auditable unlock history.
- High value asset protection with tamper detection feeding anti theft alerts alongside GPS location.
- Distributed asset fleets and remote equipment that benefit from long life solar charging and low maintenance security.
- Coordinated multi lock operations for deliveries that require a master lock to control multiple slave locks.
- One stop monitoring for access events and location to improve handoff, loading and pickup accountability.
