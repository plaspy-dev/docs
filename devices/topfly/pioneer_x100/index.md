# TopFly - Pioneer X100

![Pioneer X100](./Logo.png)

The Pioneer X100 is a compact wired GNSS tracker from TopFly designed for fleet management and vehicle security. It provides global LTE Cat 1 connectivity with 2G fallback and supports multi constellation GNSS positioning. The device includes multiple digital inputs and outputs for monitoring vehicle signals and supports Bluetooth sensor integration for environmental and accessory status monitoring, making it suitable for a broad set of vehicular monitoring needs.

As a Plaspy compatible device, the Pioneer X100 can feed location, status, and event data into the Plaspy platform for centralized fleet visibility. Its onboard event detection features such as driver behavior alerts and crash incident data allow fleet managers to surface actionable insights inside Plaspy for safety programs, operational oversight, and reporting, while remote update capability helps keep deployed units current with minimal downtime.

## Key Highlights

- Wired GNSS tracker optimized for fleet management and vehicle security deployments
- Global LTE Cat 1 connectivity with 2G fallback for broader coverage
- Multiple digital inputs and outputs for monitoring engine state, relays, and accessories
- Bluetooth sensor compatibility to extend monitoring to temperature humidity and door status
- Driver behavior detection and aggressive driving alerts to support safety programs
- Crash detection with incident data collection and remote firmware update support

## How It Works with Plaspy

When used with Plaspy the Pioneer X100 supplies position and event information to a centralized platform where operators can monitor assets, review incidents, and generate reports. Plaspy ingests the tracker's telemetry and makes it available through dashboards and alerting tools designed for fleet operational use.

- Real time and historical location tracking for vehicle visibility and route review
- Configurable alerts for events such as power loss aggressive driving and crash incidents
- Aggregated reporting to support fleet performance analysis and safety reviews
- Integration of BLE sensor readings for environmental monitoring alongside location data
- Centralized device management and status monitoring so administrators can see device health and connectivity

## Typical Use Cases

- Commercial truck and delivery fleets requiring continuous tracking and driver behavior monitoring
- Company cars and service vehicles that need engine state and accessory monitoring
- Asset protection and vehicle security with geofencing and tamper alerts
- Temperature sensitive cargo monitoring using BLE sensor accessories and centralized logging
- Organizations that benefit from remote firmware updates to reduce on site maintenance
