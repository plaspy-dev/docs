# Protrack - ET300 Features

This page describes the public feature context for using the Protrack ET300 GPS vehicle tracker with Plaspy. It summarizes the ET300’s practical capabilities as reported for vehicle monitoring and fleet management, and explains how those capabilities present value inside the Plaspy platform for real time tracking, alerts, and historical reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The content below reflects the publicly available feature set and practical use cases; consult official Protrack documentation and your installer for device specific details and the most current behavior.

## Feature Overview

The ET300 is a rugged, IP65 rated tracker aimed at dependable vehicle monitoring for cars, motorcycles, and light commercial vehicles. It focuses on essential telemetry and event reporting, with features that support anti theft workflows, driver oversight, and basic fleet operations without unnecessary complexity.

- Out of the box compatibility with Plaspy for straightforward integration into real time tracking workflows
- Rugged IP65 enclosure for exposed vehicle installations such as motorcycles and external mounts
- Configurable geo fence alerts and over speed warnings to support route enforcement and driver policy monitoring
- Fuel cutoff immobilizer capability to enable remote immobilization as part of theft response procedures
- Power outage detection and reporting to flag loss of external power or possible tampering
- Historical trip recording for retrospective route analysis and compliance reporting

## Core Features of Protrack - ET300

- Real time GPS location tracking for live position visibility
- IP65 water resistant housing suitable for exposed mounting environments
- Geofence alerting for entry and exit notifications on predefined areas
- Over speed warnings to detect and report speed policy violations
- Fuel cutoff or immobilizer control for remote immobilization support
- Power outage detection and event reporting when external power is removed
- Historical trip logging for audit, review, and operational analysis
- Out of the box Plaspy compatibility for quick platform onboarding

## How These Features Work with Plaspy

When an ET300 is installed and connected to Plaspy, the device’s position updates, event triggers, and logged trips are delivered into Plaspy so operators can monitor vehicles in real time and review historical data. Plaspy automatically recognizes supported tracker protocols and surfaces device events in the platform interface.

- Live location updates and map visualization of ET300 position fixes inside Plaspy
- Instant forwarding of geo fence and over speed alerts for operator notification and action
- Recording of immobilizer or fuel cutoff events and visibility of those events in Plaspy alert logs
- Power outage or lost power events shown to help identify possible tampering or battery issues
- Access to historical trip records and event timelines for audits, driver coaching, and route analysis

## Typical Use Cases

- Anti theft and recovery workflows using immobilizer control and alerting
- Driver behavior monitoring and enforcement with over speed warnings and event logging
- Small fleet tracking and dispatch for cars, motorcycles, and light commercial vehicles
- Exposed vehicle installations where a water resistant tracker is required
- Incident and compliance investigations using stored trip history and event records
- Basic route optimization and operational oversight without complex telematics setup

- Regional variants or manufacturer configuration may alter available alerts or labeled features

Using the Protrack ET300 with Plaspy provides a practical, low complexity solution for organizations that need reliable location visibility, event alerts, and historical trip records. Plaspy converts the ET300’s basic telemetry and alarm signals into actionable insights on maps, in alert streams, and in retrospective reports that support theft response, driver oversight, and small fleet operations.
