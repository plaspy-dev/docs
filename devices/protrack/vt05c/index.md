# Protrack - VT05C

![VT05C](./tracker.png)

The VT05C is a compact, wired GPS tracker designed for reliable vehicle monitoring and theft protection. Built to withstand harsh environments with an IP65 rating, this Plaspy compatible GPS tracker delivers continuous real-time tracking for cars and motorcycles. Its discreet, lightweight form factor and wired power connection make it ideal for fleet management and personal vehicle use where uninterrupted operation and tamper resistance matter.

Engineered for straightforward installation and long service life, the VT05C combines essential telemetry and security features — ACC detection, vibration alerts, geo-fencing, over-speed warnings, historical playback, and a fuel cutoff \(engine immobilizer\) — to help operators reduce theft risk, monitor driver behavior, and keep accurate route records. When paired with the Plaspy platform, the VT05C feeds live location and event data into a unified dashboard for alerts, reporting, and remote control functions.

## Key Highlights

- Plaspy compatible for seamless real-time tracking and centralized fleet management.
- IP65-rated enclosure resists dust ingress and water jets for durable outdoor and vehicle use.
- ACC detection and ignition status reporting to track engine on/off events accurately.
- Engine immobilizer \(fuel cutoff\) support for effective anti-theft response.
- Vibration detection and geo-fence alerts to notify of tampering or unauthorized movement.
- Over-speed warning and historical data recording for driver behavior analysis and route playback.
- Wired power design for uninterrupted operation while installed in a vehicle.

## How It Works with Plaspy

When integrated with Plaspy, the VT05C becomes part of a complete telemetry and asset-control solution. The unit transmits position and event data to Plaspy’s servers, where the platform processes, visualizes, and stores information for live monitoring, automated alerts, and historical reporting. Fleet managers, service technicians, and vehicle owners can use Plaspy’s web and mobile interfaces to view live location, review playback routes, and react to security events.

- Real-time tracking: Continuous position updates delivered to Plaspy for map-based monitoring.
- Ignition/ACC reporting: Plaspy receives engine on/off events to time trips and detect unauthorized starts.
- Immobilizer control & anti-theft: Fuel cutoff alerts are delivered to Plaspy; immobilizer events can be logged and acted on through the platform when configured.
- Alerts and telemetry: Geo-fence breaches, over-speed warnings, and vibration/tamper alerts trigger notifications in Plaspy for immediate response.
- Historical playback: Position records stored by Plaspy enable route replay, driver behavior analysis, and compliance reporting.
- Sensor integration: Although VT05C specifications do not list Bluetooth sensors, Plaspy can combine data from external BLE devices or other telemetry sources to extend monitoring and fuel monitoring workflows when required.
