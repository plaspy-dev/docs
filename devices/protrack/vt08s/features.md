# Protrack - VT08S Features

This page describes the public feature context for using the Protrack VT08S tracker with Plaspy. It focuses on the practical capabilities you can expect to see in a tracking platform when the VT08S is paired with Plaspy for real-time monitoring, alerts, and historical reporting.

Exact feature availability, behavior, and supported options can vary by firmware version, hardware revision, installation method, and manufacturer implementation. The information below is based on the VT08S feature summary and is intended to help you understand how these capabilities are used within Plaspy while encouraging confirmation against manufacturer documentation.

## Feature Overview

The VT08S is a compact tracker aimed at cars and motorbikes that delivers core location tracking and event reporting for fleet oversight and asset protection. When connected to Plaspy, the device supplies location and event streams that Plaspy converts into live maps, alerts, and historical reports useful for operations and incident response.

- Real-time GPS location reporting for live monitoring of vehicles and assets.
- SOS panic alert to notify operators of emergencies and escalate response.
- Geo-fencing to trigger entry and exit alerts for defined areas and routes.
- Over-speed warnings to support safety and policy enforcement.
- Historical trip data capture for replay, analysis, and record keeping.
- Power outage detection and remote fuel cutoff functionality for anti-theft and tamper response.

## Core Features of Protrack - VT08S

- Compact form factor intended for discreet installation in cars and motorbikes.
- IP65 rated enclosure for protection against dust and water splashes.
- SOS panic alert for immediate high priority notifications.
- Geo-fencing support for zone entry and exit events.
- Over-speed detection to generate alerts when speed thresholds are exceeded.
- Historical trip logging for route playback and reporting.
- Power outage detection to flag possible tampering or vehicle power loss.
- Remote fuel cutoff immobilizer capability to support authorized vehicle immobilization workflows.

## How These Features Work with Plaspy

Plaspy ingests the VT08S location and event data and normalizes it into the platform so fleet managers can view positions, receive alerts, and run historical reports. Plaspy detects compatible tracker protocols automatically and presents events as actionable items for operations teams.

- Live location updates displayed on Plaspy maps for dispatch and oversight.
- SOS panic alerts forwarded as high priority events with timestamp and last known position.
- Geo-fence entry and exit events shown in Plaspy as alert records and historical events.
- Over-speed events logged and available for driver performance review and reporting.
- Historical trip data available for playback, route analysis, and compliance documentation.
- Remote immobilizer actions and monitoring surfaced through Plaspy workflows when the device and installation support remote fuel cutoff.

## Typical Use Cases

- Fleet anti-theft workflows that combine tamper detection, SOS alerts, and remote immobilization.
- Driver safety programs using over-speed warnings and incident alerting to reduce risk.
- Historical trip logging for route optimization, billing, and compliance audits.
- Geo-fence based site control to monitor arrivals and departures for locations or job sites.
- Discreet tracking of motorbikes and small vehicles where compact installation is required.
- Monitoring high value or rental vehicles with centralized alerting and playback.
