# TZone - AVL-05

<div className="device-logo">
![AVL-05](./logo.jpg)
</div>

The TZone AVL-05 is a GPS vehicle tracking device designed for vehicle security, recovery, and fleet management. It provides location tracking through software and mobile phone access, plus a suite of notification features such as over speed low power and geo fence alarms. The device also supports remote monitoring and control functions including door and engine state detection and remote engine cut off for emergency situations.

As a Plaspy compatible device the AVL-05 can feed location updates alarms and basic telematics into the Plaspy platform to support fleet visibility and operational oversight. Its support for GPRS and SMS based communication and features like mileage calculation fuel level detection and optional temperature sensing make it a practical choice for organizations that want to manage vehicles within Plaspy without relying on specialized or proprietary hardware details.

## Key Highlights

- Designed for vehicle security recovery and fleet management across cars taxis buses and trucks
- Location tracking accessible via software and cell phone for remote monitoring
- Multiple alarm types including over speed low power and geo fence alerts
- Remote detection and control of door and engine status with emergency engine cut off
- GPRS and SMS communication with support for sending data to an IP or DNS endpoint
- Mileage calculation plus fuel oil level detection and optional temperature sensor support
- Built in memory for local data storage and listen in microphone for two way audio

## How It Works with Plaspy

When connected to Plaspy the AVL-05 supplies position updates and event notifications that Plaspy can display and act on for monitoring and reporting. Plaspy ingests the device data to provide map views historical tracks and alert routing so fleet managers can maintain situational awareness and manage responses.

- Vehicle location and historical tracks visible in Plaspy dashboards and maps
- Alarms such as geo fence triggers overspeed and low power forwarded to Plaspy alerting rules
- Mileage and basic sensor data available for operational reporting and cost analysis
- Remote commands and status checks routed via the device communication channels and reflected in Plaspy
- Integration supports sending device data to Plaspy for consolidated fleet monitoring and oversight

## Typical Use Cases

- Fleet management for taxi bus and truck operations requiring location visibility and mileage reporting
- Vehicle security and recovery workflows that depend on real time tracking and alarms
- Remote monitoring of engine and door status for operational control and theft deterrence
- Long distance or cross region fleets benefiting from roaming and flexible communication options
- Fuel and temperature monitoring for vehicles that require condition awareness during transport
