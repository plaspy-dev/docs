# TZone - TZ-RD05

![TZ-RD05](./logo.jpg)

The TZone TZ-RD05 is a versatile 2.4G RFID Reader designed by TZone Digital. It is specifically designed to manage multiple 2.4G RFID Tags, including TZ-Tag01/TZ-Tag02, TZ-Tag03, TZ-Tag04, and TZ-Tag201. With its multiple functions and easy configuration, this RFID reader is an ideal solution for various applications.

The TZ-RD05 operates on a working frequency of 2.400-2.4835GHz and has a receiving sensitivity of 1Mbps@-85dBm. It features an omnidirectional tag identification angle, allowing for efficient and accurate tag detection from any direction. The communication interface options include RS485 and LAN, providing flexible connectivity options to integrate with an upper management system. Additionally, the TZ-RD05 supports firmware upgrades via serial port, ensuring that it can adapt to future enhancements and improvements.

This RFID reader is built to withstand harsh environments, with a working temperature range of -40°C to +60°C and an IP55 protection level. It has a reading distance of up to 50m, making it suitable for applications that require long-range tag detection. The TZ-RD05 is designed for ceiling-mounted installation, and its compact cylindrical form factor \(Diameter 170mm, Height 40mm\) ensures easy integration into various settings.

With its advanced features and reliable performance, the TZone TZ-RD05 is an excellent choice for managing multiple 2.4G RFID Tags in a wide range of applications, including asset tracking, inventory management, access control, and more.

#### Key Features:

- Multiple functions 2.4G RFID Reader
- Supports TZ-Tag01/TZ-Tag02, TZ-Tag03, TZ-Tag04, and TZ-Tag201
- RS485 and LAN communication interfaces
- Omnidirectional tag identification angle
- Easy firmware upgrade via serial port
- Wide working temperature range \(-40°C to +60°C\)
- IP55 protection level
- Long reading distance of up to 50m
- Compact and easy to install \(ceiling-mounted\)
