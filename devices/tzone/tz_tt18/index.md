# TZone - TZ-TT18

![TZ-TT18](./logo.jpg)

The TZone TZ-TT18 is a single-use temperature and humidity transmitter that is equipped with a built-in temperature/humidity transmitter and GSM module. This device requires the insertion of a SIM card to function. The TZ-TT18 is designed to wake up only when it is time to send data or when the user operates it, remaining in a sleep state the rest of the time. This feature allows for longer battery life and greater convenience for the user.

The TZ-TT18 is capable of quickly and accurately collecting high-precision temperature and humidity data, which it then transmits to the server software through GPRS. This makes it an ideal solution for applications in cold chain logistics, medicine storage, refrigeration, and more. With its compact dimensions of 80mm x 64mm x 25mm, the TZ-TT18 is easy to install and can be discreetly placed in various environments.

Key Features:

- Built-in temperature/humidity transmitter and GSM module
- Long battery life with a built-in 3.7V/2000mAh Lithium battery
- Can save up to 2880 GPRS data
- High-precision temperature measurement with ±0.3℃ accuracy
- Wide temperature range of -40℃ to +125℃
- ±3% humidity accuracy with a range of 0% to 100%
- Operating temperature range of -20℃ to +60℃
- Low power consumption in both active and sleep modes
- Compact and easy to install with dimensions of 80mm x 64mm x 25mm
- Equipped with SIMCOM GSM chip for reliable communication
- LED indicators for temperature and GSM status
