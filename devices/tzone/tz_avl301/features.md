# TZone - TZ-AVL301 Features

This page provides a public feature summary for the TZone TZ-AVL301 GPS tracker and explains how those features relate to using the device with Plaspy. It focuses on practical, non sensitive details about what the tracker can do when paired with Plaspy for location, event visibility, and basic fleet oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, mobile network coverage, and manufacturer implementation. For device specific details, settings, and the latest firmware behavior consult the official TZone documentation.

## Feature Overview

The TZ-AVL301 is a compact 3G GPS tracker designed for vehicle and asset tracking with features that support real time location reporting, driver identification, logging, and basic remote control. Its rugged enclosure and onboard memory make it suitable for installations exposed to weather and for environments where intermittent connectivity is expected.

- Real time GPS positioning with reported 2D position accuracy around 3 meters
- Dual cellular band support for GSM and WCDMA networks to provide broad 3G connectivity
- iButton support for driver identification to associate trips with drivers
- IP67 rated waterproof enclosure for reliable outdoor use
- Onboard flash memory for local logging and data retrieval when connection is intermittent
- SMS location links and remote engine immobilization for simple remote actions

## Core Features of TZone - TZ-AVL301

- GPS location reporting with multi channel tracking and position accuracy as specified by the manufacturer
- 3G cellular connectivity across supported GSM and WCDMA bands for location and event transmission
- iButton driver identification for tracking driver activity and trip association
- IP67 waterproof design for protection in wet or dusty environments
- Flash memory (32 Mbit) for local data logging and later upload to the server
- Ignition detection and mileage calculation to support usage tracking and basic maintenance planning
- Ability to send location as Google map links via SMS for direct mobile lookup
- Engine immobilization capability to remotely disable vehicle engine for security response

## How These Features Work with Plaspy

Plaspy receives and interprets the TZ-AVL301 reporting so fleet managers and operators can view location, events, and basic status in one platform. Plaspy automatically detects compatible tracker protocols and maps incoming reports into position and event records without requiring manual protocol selection.

- Live and historical location display in Plaspy using the tracker GPS reports and logged data uploads
- Driver attribution in Plaspy when iButton events are reported, enabling per driver trip views and reporting
- Ignition and mileage events recorded as trip or odometer entries to support operational oversight
- Alerts and event visibility for immobilization actions and other reported device events
- SMS location links and messages can complement Plaspy reporting for mobile workflows when SMS is enabled
- Logged data from device flash memory is shown in Plaspy after upload to provide continuity during coverage gaps

## Typical Use Cases

- Fleet vehicle tracking for routing and location visibility during operations
- Driver identification and trip association using iButton for accountability and record keeping
- Remote theft response using engine immobilization and location reporting
- Outdoor and exposed equipment tracking where IP67 protection is required
- Mileage tracking for maintenance scheduling and operational analytics
- Asset monitoring where local logging is needed to bridge temporary connectivity gaps

## Feature Availability Notes

- Some features depend on the device firmware version and may behave differently across firmware releases
- Hardware revisions and regional variants of the TZ-AVL301 may affect supported cellular bands or exact performance
- SMS functions and Google map link delivery rely on an active SIM and carrier support in the deployment region
- Local logging behavior and memory retention depend on configuration and available flash capacity
- Installer wiring and vehicle integration affect ignition detection and mileage calculations
