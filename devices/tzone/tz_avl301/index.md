# TZone - TZ-AVL301

![TZ-AVL301](./logo.jpg)

The TZ-AVL301 is a compact 3G GPS tracker from TZone designed for vehicle and asset monitoring. It supports GSM and WCDMA frequencies and includes features commonly required for fleet management such as iButton driver identification, ignition detection, mileage calculation, onboard flash logging, and the ability to send location links via SMS. Built to IP67 waterproof specifications, the TZ-AVL301 is intended for use in demanding environments where reliable positioning and status reporting are needed.

As a device compatible with Plaspy, the TZ-AVL301 can provide the location and status information Plaspy relies on for live monitoring, historical playback, and operational reporting. Its onboard logging and standard communication capabilities make it a practical option for integrating into Plaspy for everyday fleet oversight, driver identification workflows, and basic theft response actions such as engine immobilization where supported by the platform configuration.

## Key Highlights

- 3G GPS tracker supporting GSM and WCDMA frequencies for broad cellular coverage
- IP67 rated waterproof housing suitable for outdoor and exposed installations
- iButton support for driver identification and driver event tracking
- Onboard flash memory for data logging and retrieval during intermittent connectivity
- Ignition detection and mileage calculation for fleet usage and cost monitoring
- Engine immobilization capability and SMS location link feature for rapid response

## How It Works with Plaspy

When connected to Plaspy, the TZ-AVL301 delivers position and status data that Plaspy can display, record, and act upon for fleet management tasks. The tracker communicates over standard transport methods and stores logs locally if network connectivity is interrupted, enabling Plaspy to reconstruct historical activity once data is delivered.

- Real time location display and map visualization within Plaspy
- Historical route playback using logged data from the device
- Driver identification events imported into Plaspy for user and trip association
- Ignition and mileage metrics used in Plaspy reports and utilization dashboards
- Immobilization and control signals coordinated through Plaspy where configured and supported
- SMS location links available as a fallback to share position details quickly

## Typical Use Cases

- Managing mixed fleets of cars and light commercial vehicles that need regular location updates
- Asset tracking in outdoor or wet environments where IP67 protection is beneficial
- Monitoring driver assignments and shift changes using iButton identification
- Tracking vehicle usage and mileage for maintenance scheduling and cost analysis
- Rapid response and theft mitigation using immobilization features when integrated with a monitoring platform
