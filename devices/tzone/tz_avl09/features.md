# TZone - TZ-AVL09 Features

This page describes the public feature context for the TZone TZ-AVL09 GPS tracker when used with Plaspy. It focuses on the practical capabilities you can expect to surface inside Plaspy for monitoring, alerts, and operational oversight rather than low-level protocol details.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation method, and manufacturer implementation. For device-specific configuration and the latest technical specifications consult the official TZone documentation.

## Feature Overview

The TZ-AVL09 is a full‑featured vehicle tracker designed for continuous and single location tracking, standard alarm reporting, and rich I/O options for integration with vehicle systems. Its combination of connectivity, inputs and outputs, and optional accessories makes it suitable for fleet tracking and vehicle security deployments.

- Continuous or single location tracking for real time and occasional position updates
- Multiple alarm types including over speed, low power, geo fence, tremble, parking, and SOS
- Vehicle control and status functions such as door open/close control and engine on/off detection
- Communication via GPRS (TCP/UDP) and SMS for real time reporting and notifications
- Optional SD card recording and interfaces for external devices like RFID readers and cameras
- Onboard storage and processing features such as mileage calculation and flash memory for logs

## Core Features of TZone - TZ-AVL09

- Location reporting modes supporting both single fix and continual tracking
- Alarm suite including over speed alarm, low power alarm, geo fence alarm, tremble alarm, parking alarm, and SOS alarm
- Vehicle interface capabilities including door open/close control, engine on/off detection, and staged engine cutoff for immobilization
- Communication over GPRS (TCP or UDP) and SMS for sending position and alarm data
- Optional media and accessory support such as external RFID readers, cameras, printers, and SD card logging
- 3D accelerometer for motion and tamper detection reflected in tremble and movement alerts
- Multiple I O and serial interfaces: analog and digital inputs, digital outputs, multiple serial ports, and mini USB for local access
- Onboard components and environmental specs including backup battery, external GSM and GPS antennas, operating temperature range, and compact dimensions

## How These Features Work with Plaspy

Plaspy receives location and event reports from the TZ-AVL09 and makes them actionable through mapping, event logs, and monitoring dashboards. The platform maps incoming position fixes and alarms to device activity so you can monitor assets in near real time and review historical behavior.

- Live and historical location display for single and continuous tracking reports
- Alarm and event notifications for over speed, geo fence breaches, parking, tremble, SOS, and low battery conditions
- Visibility of input and output states in Plaspy to reflect door status, engine on/off, and similar vehicle signals
- Event-driven data capture where optional SD or external peripherals trigger recorded logs or attachments
- Mileage and usage records generated from device reports to support route verification and basic vehicle usage analysis
- Two‑way conversation availability noted in device capabilities so voice interactions and related events can be surfaced if supported in deployment
