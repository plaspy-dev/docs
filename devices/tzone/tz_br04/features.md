# TZone - TZ-BR04 Features

This page provides a public feature overview for the TZone TZ-BR04 and how those capabilities relate to use with Plaspy. It summarizes the practical, non-sensitive functions of the device so fleet managers and system integrators can understand what to expect when using the TZ-BR04 with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. For device specific configuration, firmware details, and up to date technical specifications consult the manufacturer documentation and your device vendor.

## Feature Overview

The TZ-BR04 is an industrial GPS tracker designed for reliable tracking and monitoring in large areas and outdoor environments. Its hardware design and connectivity options make it suitable for installations that require durable performance and flexible integration.

- Industrial grade construction suitable for harsh environments and outdoor use
- ISM band operation with a practical identification range up to 50 meters for reliable signal reception
- Bluetooth 4.0 support for local device interoperability and accessory compatibility
- RS232 and RS485 output modes to support different integration and wiring layouts
- External antenna option and high receiving sensitivity to improve signal stability
- Wide operating temperature range for use in extreme climates

## Core Features of TZone - TZ-BR04

- Industrial grade enclosure and design intended for consistent performance in demanding environments
- Operation in the ISM microwave frequency band with a stated effective range up to 50 meters
- Bluetooth 4.0 protocol support for short range communication and device pairing
- RS232 output mode for serial data interfacing where required
- RS485 output mode for alternative serial network integration
- External antenna to enhance reception quality in challenging locations
- Receiving sensitivity of approximately -85 dBm at 1 Mbps for reliable signal detection
- Wide working temperature span from minus 40 degrees Celsius to plus 60 degrees Celsius

## How These Features Work with Plaspy

Plaspy can collect and present the location and status information that the TZ-BR04 reports. The platform is designed to accept tracker reporting and make it visible in maps, lists, and event logs to support operational monitoring.

- Plaspy automatically detects the tracker protocol to simplify initial integration
- The TZ-BR04 can be configured to report into Plaspy using common transport options supported by the platform
- External antenna and strong receiving sensitivity help maintain stable reporting into Plaspy in outdoor or industrial settings
- Bluetooth 4.0 can be used for local configuration or short range data exchange while Plaspy remains the central server for ongoing monitoring
- RS232 and RS485 outputs provide installation flexibility so site wiring and data flows can be adapted while Plaspy aggregates device reports

## Typical Use Cases

- Asset tracking across large outdoor sites where robust signal reception is required
- Monitoring vehicles, equipment, or personnel in industrial environments
- Installations that need serial interface options to integrate with existing onsite systems
- Deployments that require hardware rated for extreme temperature ranges
- Scenarios where an external antenna improves connectivity in challenging terrain

## Feature Availability Notes

- Firmware revisions can change available features and configuration menus; check firmware release notes for device behavior
- Hardware revisions and regional variants may affect radio performance, supported interfaces, or certifications
- Installation choices such as antenna placement and wiring for RS232 or RS485 influence real world performance
