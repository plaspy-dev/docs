# TZone - AVL-08 Features

This page provides a public feature overview for the TZone AVL-08 GPS tracker and explains how its capabilities are used with Plaspy for monitoring, alerts, and operational visibility. It is intended to describe practical, non sensitive feature context for users who want to understand what the device can do when paired with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Where the AVL-08 offers optional functions, those may require specific accessories or configuration and should be confirmed with the device manufacturer or installer.

## Feature Overview

The AVL-08 is positioned as a versatile vehicle and asset tracker offering location reporting, alarms, integration options, and several interfaces for peripherals. Below are the most relevant practical capabilities that operators typically use in Plaspy or similar platforms.

- Single location and continual tracking for real time and periodic position updates
- Multiple alarm types including over speed alarm, low power alarm, geo fence alarm, tremble alarm, parking alarm, and SOS alarm
- Remote vehicle control features such as door control, engine status detection, and gradual engine cut off for emergency immobilization
- Support for external peripherals including SD card recording, RFID readers, cameras, and printers to extend data capture and workflow integration
- Onboard features for mileage calculation, internal flash storage, and optional temperature sensing to support operational reporting
- Fuel or oil level detection and 3D accelerometer based inputs to assist in monitoring vehicle condition and events

## Core Features of TZone - AVL-08

- Location reporting modes for single point queries and continual tracking sessions
- Alarm suite including overspeed, low battery, geo fence, tremble, parking, and SOS notifications
- Engine and door interface with status detection and the ability to perform a controlled engine cut off
- Support for external SD card for local recording and expanded storage
- Interfaces for external peripherals such as RFID readers, cameras, and printers for integrated workflows
- 3D accelerometer input for motion and tamper related alarms
- Mileage calculation and internal flash memory for event and data buffering
- Optional sensor support including fuel or oil level detection and temperature sensing where provided by hardware variants

## How These Features Work with Plaspy

When an AVL-08 device is connected to Plaspy, the tracker reports location, event, and alarm information which Plaspy surfaces for monitoring and historical review. Plaspy detects compatible tracker protocols and ingests the device data so fleet managers can view positions and events in one place.

- Live and historical location display in Plaspy mapping views for single and continual tracking modes
- Alarm and event notifications routed to Plaspy so operators can see overspeed, geo fence, tremble, parking, SOS, and low power events
- Engine and door status visible in the device event stream to support operational checks and incident response
- Mileage and stored event records shown in Plaspy reports to support vehicle usage and maintenance planning
- Integration of external peripheral events such as RFID reads or camera triggers as part of the device event timeline when those peripherals are installed and reporting
