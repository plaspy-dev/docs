# TZone - TZ-AVL05 Features

This page documents the public feature context for using the TZone TZ-AVL05 GPS tracker with Plaspy. It summarizes the tracker capabilities you can expect to see in Plaspy, and explains how those capabilities translate into monitoring, alerts, and operational value when the device reports into the Plaspy platform.

Exact feature availability for any individual TZ-AVL05 unit can vary by firmware version, hardware revision, installation method, regional model, and manufacturer configuration. Where relevant this page notes optional features and recommends checking manufacturer documentation for device specific behavior.

## Feature Overview

The TZ-AVL05 is a compact vehicle tracker designed to deliver real time location and status updates while supporting remote commands and multiple reporting channels. Its combination of location tracking, alarm functions, and remote connectivity make it suitable for vehicle monitoring and light fleet use.

- Real time GPS location reporting to allow live map tracking and history playback
- Built in alarm functions including over speed alerts, low power notifications, and geo fence alerts for immediate event visibility
- GPRS and SMS communication with support for remote commands and firmware updates over the air
- Backup battery operation and roaming support to maintain reporting when main power is removed or when used across regions
- On device data storage and mileage calculation to preserve events and travel history between reports
- Optional inputs and sensors such as fuel level detection, temperature sensors, and a built in microphone for two way conversation when those options are present

## Core Features of TZone - TZ-AVL05

- Real time GPS location tracking suitable for vehicle and asset visibility
- Remote monitoring via software or cell phone using GPRS TCP UDP or SMS
- Alarm types including over speed alarm, low power alarm, and geo fence alarm
- Roaming support to help reduce costs when operating in multiple regions
- Backup battery providing up to 12 hours of working time as a secondary power source
- Firmware upgrade capability via GPRS to apply remote updates
- On device storage with 32 Mb flash and mileage calculation for trip logging
- Optional sensor support for fuel or oil level detection, optional temperature sensors, and a built in microphone for two way communication

## How These Features Work with Plaspy

Plaspy receives tracker reports and presents location, events, and history in a centralized view. Plaspy automatically detects common tracker protocols and supports devices configured to report over TCP or UDP to the Plaspy server and standard platform port settings.

- Live and historical location shown on Plaspy maps and timeline for route reconstruction
- Alarm events such as geo fence, over speed, and low battery appear as actionable events and notifications in Plaspy
- Mileage and stored trip data from the device are reflected in vehicle history when the tracker uploads stored records
- Remote commands and configuration requests that the TZ-AVL05 supports can be initiated from Plaspy when device communication allows
- Optional telemetry such as fuel level or temperature are displayed in Plaspy only when the installed hardware and firmware report those inputs

## Typical Use Cases

- Personal vehicle tracking for owner visibility and simple security monitoring
- Small fleet oversight with live tracking, mileage logging, and event alerts
- Asset monitoring for mobile equipment that needs periodic location and status updates
- Geofence based notifications for site entry exit monitoring and route compliance
- Remote monitoring where SMS fallback or GPRS reporting is required across regions

## Feature Availability Notes

- Manufacturer firmware versions can enable or disable specific features such as optional sensors or remote command sets
- Hardware revisions and installation wiring determine whether optional inputs like fuel level or temperature sensors are supported
- Some capabilities depend on regional cellular support and roaming agreements which affect data and SMS behavior
- The presence and behavior of the built in microphone and two way conversation rely on the specific device configuration and regional regulatory allowances
- Always consult the manufacturer documentation for exact wiring diagrams, configuration commands, and supported optional modules
