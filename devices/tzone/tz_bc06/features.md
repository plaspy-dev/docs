# TZone - TZ-BC06 Features

This page provides a public feature summary for the TZone TZ-BC06 and how its capabilities relate to use with Plaspy. It focuses on practical, user-facing information such as iBeacon support, Bluetooth behavior, size and form factor, and what customers can reasonably expect when integrating the device with Plaspy for location and proximity monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer's implementation choices. The information below is drawn from the device description and is intended as guidance for using the TZ-BC06 with Plaspy rather than a definitive technical manual.

## Feature Overview

The TZ-BC06 is a compact, lightweight tracker that uses the iPhone iBeacon protocol over Bluetooth 4.0 to provide proximity and short range location awareness. Its adjustable broadcast settings make it flexible for different detection ranges and responsiveness needs while remaining broadly compatible with modern mobile platforms.

- Compact and lightweight housing suitable for discreet placement or attachment
- Uses iPhone iBeacon protocol over Bluetooth 4.0 for proximity broadcasts
- Configurable broadcasting interval offering responsiveness trade offs
- Adjustable transmitted power to tune detection range in different environments
- Compatible with iOS 7.0 and above and Android 4.3 and above for common mobile integrations

## Core Features of TZone - TZ-BC06

- Compact physical dimensions and low weight for versatile placement
- iPhone iBeacon protocol support for standard BLE proximity broadcasts
- Bluetooth 4.0 connectivity consistent with BLE compatible receivers
- Adjustable broadcasting interval from 0.1 seconds up to 3 seconds
- Transmitted power adjustable in the range provided by the manufacturer
- Password protected connections to restrict configuration access
- Designed for 5V DC operation for standard power setups
- Reported open field transmission distance in the 50 to 80 meter range

## How These Features Work with Plaspy

Plaspy can be used to centralize visibility and event monitoring for compatible devices such as the TZ-BC06. When the tracker is active and discovered by receivers or gateway devices managed within Plaspy, its proximity broadcasts and presence events can be reflected in the platform to support operational workflows.

- Plaspy recognizes compatible beacon and tracker protocols and integrates device presence into the platform
- Adjustable broadcasting interval maps to how frequently the device is detected or reported within Plaspy
- Transmit power affects detection footprint that Plaspy uses to interpret proximity and presence
- Password protected configuration helps control who can change the device settings before it reports into Plaspy
- Device compatibility with common mobile operating systems helps with mobile-assisted provisioning or discovery workflows

## Typical Use Cases

- Short range asset proximity monitoring where compact form factor is important
- Item tracking in environments where BLE beacon detection is available
- Retail or workplace presence detection for tagged objects or equipment
- Mobile assisted discovery and occasional location validation using smartphones or gateways
- Temporary deployments where easy mounting and adjustable broadcast settings are useful

## Feature Availability Notes

- Firmware version and device configuration can change how broadcast intervals, power settings, and security behave
- Hardware revisions or regional variants may alter the exact transmitted power range or radio performance
- Installation and placement have strong influence on practical detection range and reliability
- Mobile device operating system behavior (iOS or Android) affects how and when beacon broadcasts are detected
- Always check the manufacturer documentation for up to date behavior and supported configuration options
