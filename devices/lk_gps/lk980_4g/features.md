# LK-GPS - LK980-4G Features

This page provides a public feature overview for the LK-GPS LK980-4G and explains how its capabilities are used with Plaspy. It focuses on practical, non sensitive descriptions of tracking, alarm and telemetry functions when the device is paired with the Plaspy platform.

Exact feature presence and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. For deployment planning confirm device specific capabilities and firmware notes with the manufacturer and your installer.

## Feature Overview

The LK980-4G is a compact wired GPS tracker designed for continuous vehicle and motorcycle tracking, offering network resilience and a set of security and telemetry features geared toward fleet and asset protection. When integrated with Plaspy the tracker provides location visibility, event forwarding and historical route data for operational oversight.

- Real time tracking using 4G LTE with automatic 2G fallback for broader network coverage and continuous reporting.
- Security oriented alarms including SOS, silent listen in, vibration and tamper alerts and remote fuel or power cut off for anti theft response.
- Wired installation with a broad voltage range and compact housing suited to vehicle and motorcycle deployments.
- Multiple configurable input output ports to capture vehicle signals and feed telemetry into monitoring systems.
- Shock wake up and vibration modes to detect movement while helping conserve vehicle power circuits.
- Historical route playback and event logs for review, reporting and fleet optimization.

## Core Features of LK-GPS - LK980-4G

- Built in GPS and GSM antennas in a compact form for discreet vehicle installation.
- 4G LTE connectivity with automatic fallback to 2G for continued location updates where coverage varies.
- SOS alarm for rapid alerting of critical events.
- Silent listen in capability for remote audio monitoring when configured.
- Vibration and tamper alerts to detect movement or interference.
- Remote fuel or power cut off functionality to support immobilization workflows.
- Multiple configurable input and output ports for external signals and event triggers.
- Historical route storage and playback for forensic review and compliance analysis.

## How These Features Work with Plaspy

When the LK980-4G is connected to Plaspy it reports location, alarms and telemetry so operators can monitor fleets from a central view. Plaspy ingests the device events and presents them as live map positions, notifications and historical records for operational use.

- Real time location and telemetry updates appear in Plaspy maps and dashboards for continuous visibility.
- Alarm events such as SOS, vibration or tamper are forwarded to Plaspy for immediate notification and escalation.
- Remote immobilizer or fuel power cut off commands can be managed through Plaspy where device wiring and firmware support those controls.
- Configurable input output events such as ignition or door signals feed into Plaspy reports and event logs.
- Historical route playback and stored event logs are available inside Plaspy for review and analysis.

## Typical Use Cases

- Fleet management with continuous tracking and route analysis to optimize vehicle utilization.
- Anti theft response using vibration alerts, SOS and remote immobilization to protect assets.
- Rental and ride hailing operations needing discreet wired installation and tamper alerts.
- Logistics and delivery monitoring with event logging to validate routes and times.
- Driver behavior and compliance review using historical playback and event triggered telemetry.

## Feature Availability Notes

- Feature presence can depend on device firmware and the specific hardware revision installed.
- Some functions require correct wiring and configuration at installation to enable inputs outputs and immobilizer control.
- Regional cellular network support and 4G band availability affect connectivity and fallback behavior.
- OEM customizations and local firmware variants may add or alter certain capabilities.
- Always consult the manufacturer documentation for details on configuration options and supported commands.
