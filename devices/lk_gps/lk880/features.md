# LK-GPS - LK880 Features

This page provides a public feature overview of the LK-GPS LK880 and explains how the tracker’s capabilities can be used with Plaspy for monitoring and fleet style visibility. It summarizes the LK880’s user-facing functions such as location tracking activity reporting geo fencing and training features that are relevant when the device is integrated with the Plaspy platform.

Exact availability and behavior of specific features can vary by firmware version hardware revision installation method and manufacturer implementation. For device specific operational details and the latest firmware notes consult the manufacturer documentation while using this page as a practical compatibility and capability summary for Plaspy users.

## Feature Overview

The LK880 is presented as a compact 4G waterproof pet tracker with activity monitoring and an integrated dog training collar. It combines location reporting with activity and alerting features useful for pet owners and managers who need both tracking and basic training oversight. When paired with Plaspy the device’s reports can be used for map visualization alerts and historical review.

- Real time GPS and LBS positioning for location awareness and route tracking
- Activity monitoring including step count and distance walked to track pet movement
- Dog training function with a remote controller for on device training workflows
- Geo fence support to define safe areas and receive exit or entry notifications
- Blind zone supplementary report to improve location reporting in poor signal areas
- Historical track and platform mode query positioning for playback and review

## Core Features of LK-GPS - LK880

- 4G network connectivity for faster location reporting where cellular coverage is available
- Waterproof design suitable for outdoor and pet applications
- GPS plus LBS hybrid positioning to provide location in a variety of environments
- Activity tracking including step count and distance metrics
- Geo fence creation and alerting for boundary management
- Blind zone supplementary reporting to reduce data gaps in weak GPS conditions
- Displacement alarm and low battery alert to notify unexpected movement or power status
- Historical track and platform query positioning for reviewing past routes

## How These Features Work with Plaspy

In Plaspy the LK880’s position and event data can be collected and presented alongside other devices to provide live visibility and historical context. Plaspy focuses on displaying the device’s reports so operators can quickly see location changes alerts and movement patterns without changing device firmware.

- Live location shown on Plaspy maps for immediate situational awareness
- Historical track playback using stored location reports and platform queries
- Geo fence events surfaced as notifications or timeline entries inside Plaspy
- Activity and health status reports displayed as telemetry items for monitoring movement
- Alerts for displacement and low battery presented to users to prompt follow up
- Supplementary blind zone reports incorporated to reduce perceived location gaps in timelines

## Typical Use Cases

- Real time pet location monitoring during walks or outdoor activities
- Boundary management using geo fences to receive immediate exit alerts
- Reviewing historical tracks to reconstruct routes or check activity patterns
- Monitoring activity and basic health status metrics for daily oversight
- Overseeing training sessions by logging training device use alongside location data
- Using displacement and low battery alerts to detect when a device needs attention
