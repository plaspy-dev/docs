# LK-GPS - LK980 Features

This page provides a public feature overview of the LK-GPS LK980 and how its capabilities map to the Plaspy platform. It covers the main, non-sensitive functions you can expect when using this compact car tracker with Plaspy for location awareness, alerting, and route history.

Exact feature availability depends on the device firmware, hardware revision, installation method, and the manufacturer implementation. Use this page as a practical summary and consult official LK GPS documentation for the most current, device specific details.

## Feature Overview

The LK980 is a compact car tracker with built in GPS and GSM antennas designed for discreet installation and continuous location reporting. When used with Plaspy, the unit provides real time location visibility, basic alarm notifications, battery status, and historical route playback for operational oversight.

- Compact form factor for discreet vehicle placement and straightforward installation
- Built in GPS and GSM antennas for position reporting and cellular communication
- 4G connectivity to support responsive updates and real time tracking workflows
- Mobile app compatibility for Android and Apple plus web platform access for remote monitoring
- Alarms including low battery, vibration, removal, and overspeed to notify operators of important events

## Core Features of LK-GPS - LK980

- Compact and discreet design suitable for car tracking installations
- Integrated GPS and GSM antennas to provide position and cellular connectivity
- 4G cellular support to enable timely position updates and remote access
- Mobile app tracking on Android and Apple and access via web platforms
- Low battery alarm and remaining battery capacity reporting
- Vibration alarm and removal alarm for tamper and movement detection
- Historical route tracking for playback of past trips
- Overspeed alarm to notify when configured speed thresholds are exceeded

## How These Features Work with Plaspy

Plaspy collects and presents the data the LK980 reports so fleet managers and vehicle owners can monitor status, review events, and replay routes in a single interface. Plaspy automatically detects many common tracker protocols to simplify setup and device onboarding.

- Real time vehicle position visible on Plaspy maps for live monitoring
- Alerts for low battery, vibration, removal, and overspeed appear as events in Plaspy for timely operator response
- Historical route playback in Plaspy to review past movements and trip details
- Battery level and basic device health indicators available through the platform for scheduling maintenance
- Street level map context and multi platform queries supported by the device can be accessed from Plaspy for clearer location context

## Typical Use Cases

- Discreet car tracking for personal vehicles or high value assets
- Real time visibility for small fleet management and route oversight
- Security monitoring with tamper and vibration alerts to detect unauthorized handling
- Reviewing historical routes for trip verification and operational analysis
- Remote battery monitoring to reduce downtime and schedule recharges
- Multi platform access for managers who need web and mobile tracking options
