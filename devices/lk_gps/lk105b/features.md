# LK-GPS - LK105B Features

This page provides a public, non sensitive summary of the LK GPS LK105B Mini Pet GPS Tracker and how its features are reflected when the device is used with Plaspy. The intent is to describe practical capabilities, typical usage scenarios, and what you can expect to see in Plaspy when reports arrive from this tracker.

Exact feature availability can vary by firmware version, hardware revision, installation method, and manufacturer settings. Details such as update intervals, accuracy figures, and companion app behavior are controlled by the device firmware and the manufacturer's configuration, so consult the device documentation for the most current, device specific details.

## Feature Overview

The LK105B is a compact pet oriented tracker that combines GPS and LBS location reporting with several user facing features designed for real time monitoring and incident alerts. It is built to give pet owners and small asset users timely location visibility and basic remote interaction.

- Real time location reporting using GPS with supplemental LBS positioning for broader coverage
- Frequent location updates available as part of device configuration for near real time tracking
- Location history playback so past routes can be reviewed on the platform
- Voice monitoring and two way communication capability using the device and a cell phone
- SOS alarm button that notifies authorized phone numbers and the web platform
- Power saving standby behavior to extend operational time when no movement is detected

## Core Features of LK-GPS - LK105B

- GPS and LBS hybrid positioning for urban and outdoor coverage
- Real time tracking suitable for monitoring pets and small personal items
- Configurable frequent updates, with manufacturer notes indicating short interval reporting for active tracking
- Location history and route playback usable on a compatible platform
- Local audio monitoring and two way communication via mobile phone functions provided by the device
- SOS alarm that sends alerts to authorized contacts and the web platform
- Automatic power saving standby when no vibration or movement is detected
- Compact weather resistant enclosure for indoor and outdoor use and compatibility with common smartphone platforms

## How These Features Work with Plaspy

Plaspy receives reported location updates and status events from compatible trackers and presents them in a unified interface for visibility and oversight. When LK105B devices are configured to send data to Plaspy, their practical capabilities are exposed in the platform as location points, history, and alarm events.

- Real time location points appear on the map and are available for live monitoring in Plaspy
- Historical routes reported by the tracker can be played back in the platform when the device provides route history
- SOS events and movement alerts reported by the device are shown as platform events so teams can respond
- Device online status and activity patterns such as standby and wake events are visible as device telemetry where reported
- Geofence and movement alert events sent by the device are reflected as notifications and event records
- Plaspy automatically detects compatible tracker protocols so initial setup focuses on correct device credentials and basic configuration

## Typical Use Cases

- Real time pet location monitoring during outdoor walks or outings
- Recovering a lost pet using recent location and route playback
- Tracking small personal items or bags where compact size is important
- Periodic oversight of a person or object while using the device as a small safety tracker
- Monitoring movement patterns to understand typical routes and resting areas
- Receiving immediate alerts when an SOS alarm is activated by the tracker

Using Plaspy with the LK105B centralizes location and event data from the tracker into a single operational view.
