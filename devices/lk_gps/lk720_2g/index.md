# LK-GPS - LK720-2G

<div className="device-logo">
![LK720-2G](./tracker.jpg)
</div>

The LK720-2G Mini Relay GPS Tracker is a compact device designed for discreet vehicle security and reliable real time tracking. Built for use in cars and motorcycles, the tracker pairs built in GPS and GSM antennas with a mini relay output to provide anti theft immobilizer functionality, shock triggered alarms, and continuous location telemetry. Its small form factor makes it suitable for covert installation while delivering the core tracking features needed by individual owners and fleet operators.

As a Plaspy compatible device, the LK720-2G integrates with Plaspy’s cloud platform and native mobile apps to provide live location updates, historical route playback, and battery status within the Plaspy dashboard. The tracker supports browser server platforms and mobile access, and includes SMS parameter configuration and query functions as a fallback for areas with intermittent internet, giving Plaspy users a practical option for remote monitoring and basic remote control workflows.

## Key Highlights

- Plaspy compatible for real time tracking and reporting via Plaspy web and mobile interfaces
- Compact and discreet form factor suited to cars and motorcycles
- Mini relay output for remote fuel or engine immobilization to support anti theft workflows
- Shock triggered alarm and wake up behavior to detect impacts or unauthorized movement
- 2G GSM connectivity with SMS fallback to maintain telemetry and alerts where data is limited
- Telemetry reporting including battery status and historical route information for operational oversight

## How It Works with Plaspy

When connected to Plaspy, the LK720-2G sends GPS positions and onboard telemetry to the Plaspy cloud so dispatchers and vehicle owners can monitor movement and device status in real time. Plaspy surfaces the tracker data in dashboards and mobile apps for continuous visibility, and SMS fallback provides a way to configure or query the device when network connectivity is unreliable.

- Real time location updates and telemetry available in Plaspy for live fleet monitoring
- Shock alarm and movement alerts forwarded to Plaspy to support incident notifications
- Battery status reporting visible in Plaspy to help plan maintenance and preserve uptime
- Remote immobilizer control via the mini relay as part of Plaspy workflows or authorized commands
- SMS based configuration and status query to assist setup and troubleshooting when data services are unavailable

## Typical Use Cases

- Fleet management for small to mid sized vehicle fleets requiring basic location and battery telemetry
- Anti theft protection using shock alarms and remote immobilizer control to reduce theft risk
- Vehicle rental monitoring to track routes, detect unauthorized movement, and perform remote immobilization
- Discreet asset tracking for valuable mobile equipment that benefits from covert installation
- Operations in areas with limited data connectivity where SMS fallback ensures continued control and diagnostics
