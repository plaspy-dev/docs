# LK-GPS - LK720-2G Features

This page provides a public feature summary of the LK-GPS LK720-2G and how its capabilities appear when used with Plaspy. It focuses on practical, non sensitive information about tracking, telemetry, alarm and immobilizer functions that the device reports to Plaspy for monitoring and operational use.

Exact feature availability and behavior can vary depending on device firmware, hardware revision, the details of installation, and the manufacturer's implementation. For device specific command sets, wiring diagrams, and the latest firmware notes consult the official LK GPS documentation.

## Feature Overview

The LK720-2G is a compact GPS tracker designed for discreet vehicle installation and straightforward integration with Plaspy. It combines positioning, cellular connectivity, a mini relay output for immobilization workflows, and basic telemetry reporting to support vehicle security and fleet oversight.

- Real time GPS location reporting to Plaspy for live tracking and situational awareness
- Mini relay immobilizer for remote fuel or engine cut off to support anti theft responses
- Shock wake up and alarm to detect and notify impacts or unauthorized movement
- 2G GSM connectivity with SMS parameter configuration and query as a fallback
- Telemetry reporting including remaining battery status and historical routes viewable in Plaspy

## Core Features of LK-GPS - LK720-2G

- Built in GPS antenna for position fixes and route history reporting
- 2G GSM connectivity with SMS fallback for configuration and status queries
- Mini relay output to support remote immobilizer actions such as fuel or ignition cut off
- Shock wake up mode and shock triggered alarm for low power standby and impact detection
- Telemetry and diagnostics reporting including battery status and location updates
- Support for browser server platform and native Android and iOS apps via Plaspy
- Compact, discreet form factor suitable for cars and motorcycles
- No onboard Bluetooth included on the device hardware

## How These Features Work with Plaspy

When connected to Plaspy, the LK720-2G sends location and status updates that feed into Plaspy dashboards and mobile apps for monitoring and management. Plaspy surfaces the device telemetry and events so dispatchers and owners can act on location and alarm information from a central view.

- Live location and movement updates appear in Plaspy for map based tracking and monitoring
- Historical routes and position history available through Plaspy for trip review and analysis
- Shock alarms and movement alerts forwarded into Plaspy event lists for incident response
- Battery and basic telemetry status visible in Plaspy to support maintenance planning
- Remote immobilizer workflows can be executed from Plaspy interfaces where allowed by device setup
- SMS configuration and query provide a fallback method for setup and troubleshooting when data is unavailable

## Typical Use Cases

- Small fleet vehicle tracking for location awareness and route history
- Anti theft protection using shock alarms and remote immobilizer control
- Vehicle rental monitoring for unauthorized movement detection and recovery assistance
- Discreet tracking of motorcycles and compact vehicles where small form factor is required
- Asset monitoring with SMS fallback for areas with intermittent data coverage
- Basic telemetry monitoring to avoid downtime from low battery situations

## Feature Availability Notes

- Feature availability may differ by firmware version and hardware revision from the manufacturer
- Regional 2G network support depends on local GSM operator bands and SIM card compatibility
- Installation wiring and relay integration vary by vehicle and should follow manufacturer instructions
- SMS fallback behavior depends on the SIM operator and local SMS delivery conditions
- Some capabilities shown in Plaspy depend on correct device configuration and permissions

## Why Use Plaspy with These Features

Using the LK720-2G with Plaspy provides a practical path to centralized visibility and simple remote control. Plaspy consolidates live location, route history, alarm events, and basic telemetry so operators can monitor vehicles, respond to theft events, and manage fleet uptime from web and mobile interfaces.
