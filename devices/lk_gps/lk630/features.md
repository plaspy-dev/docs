# LK-GPS - LK630 Features

This page provides a public feature summary for the LK-GPS LK630 CatM tracker and explains how its capabilities map into Plaspy for centralized monitoring, alerts, and historical playback. It is intended to help pet owners and administrators understand the practical functions of the device when used with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific configuration and the latest technical details, consult the official LK-GPS documentation and release notes.

## Feature Overview

The LK630 is a compact, collar-friendly CatM tracker designed for cats and small dogs, balancing frequent location updates with a lightweight form factor. It combines GPS positioning with Wi‑Fi and Bluetooth assistance and uses cellular CatM/4G connectivity to report location and status to monitoring platforms such as Plaspy.

- Real-time outdoor positioning with GPS and assistive fixes from Wi‑Fi and Bluetooth for improved performance in urban and edge‑of‑indoor environments.
- CatM/4G cellular reporting for frequent location and status uploads to a remote monitoring platform.
- Configurable geofence alerts and instant notifications to inform owners when a pet leaves or enters defined safe zones.
- Movement and activity reporting to help detect roaming behavior and trigger event notifications.
- Compact, lightweight, and water‑resistant design that fits collars and harnesses for continuous wear.
- Rechargeable battery with an active tracking profile up to about 4 hours and power saving modes to extend runtime depending on reporting intervals.

## Core Features of LK-GPS - LK630

- GPS positioning combined with Wi‑Fi assisted fixes for better urban accuracy
- Bluetooth assistance to improve last‑meter and short range positioning
- CatM/4G cellular connectivity for low power wide area reporting
- Real‑time tracking suitable for frequent location updates
- Configurable geofence alerts for safe zone entry and exit notifications
- Movement and activity status reporting for behavior visibility
- Lightweight water‑resistant enclosure designed for collar or harness mounting
- Rechargeable battery with configurable power profiles for active or extended operation

## How These Features Work with Plaspy

When used with Plaspy, the LK630 streams position and status data into a central dashboard where owners and administrators can view live location, receive alerts, and review history. Plaspy ingests the tracker data and makes it available through configurable rules and notification channels.

- Live location updates and position history visible in Plaspy for route playback and situational awareness
- Geofence events (enter and exit) presented as alerts and actionable events inside Plaspy rule sets
- Movement and activity indicators available for monitoring and for triggering custom alerts
- Low battery and device status notifications forwarded to Plaspy so owners can manage charging proactively
- Assistive Wi‑Fi and Bluetooth location points stored alongside GPS fixes to improve historical accuracy and context

## Typical Use Cases

- Rapid pet recovery using real‑time tracking and recent route history
- Creating safe zones around home or yard with instant geofence alerts on leave or return
- Monitoring roaming patterns and receiving alerts for unexpected movement
- Improving urban tracking with Wi‑Fi and Bluetooth assisted fixes when GPS is impaired
- Everyday wear monitoring with notification of low battery or device status through companion tools
