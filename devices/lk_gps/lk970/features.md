# LK-GPS - LK970 Features

This page provides a public feature overview for the LK-GPS LK970 and explains the practical context for using this tracker with Plaspy. It focuses on user facing capabilities and how those capabilities appear in Plaspy rather than low level protocol details or private configuration steps.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device specific instructions and the latest technical details review the official manufacturer documentation and firmware notes.

## Feature Overview

The LK970 is a compact 4G tracker designed for discreet placement on vehicles, motorcycles, or handheld assets. It combines cellular connectivity, location reporting, and several alarm and reporting modes to deliver continuous tracking and event visibility suitable for fleet and personal monitoring.

- 4G cellular connectivity for wide area coverage across supported bands
- Real time tracking and position reporting for up to date location visibility
- SMS platform mode query and positioning for ad hoc location requests
- Electronic fence alarm and inflection point reporting for event driven alerts
- Overspeed and displacement vibration alarm for movement and behavior monitoring

## Core Features of LK-GPS - LK970

- 4G FDD LTE TDD LTE WCDMA and GSM band support for regional cellular compatibility
- SMS platform mode query and positioning to request location via text
- Real time tracking that delivers frequent location updates
- Inflection point reporting for detailed path and turn detection
- Electronic fence alarm for boundary breach notifications
- Overspeed and displacement vibration alarm to flag movement events
- GPS data supplement function to improve reported position when gaps occur
- Built in battery backup to support monitoring during external power loss

## How These Features Work with Plaspy

Plaspy ingests device reports and presents location and event data on an operational dashboard to help teams maintain visibility and act on alerts. The LK970 can feed position updates and alarms into Plaspy so users can monitor assets in near real time and review historical movement.

- Real time and periodic location reports appear on Plaspy maps and device timelines
- Geofence and alarm events are surfaced as alerts and can be included in reports
- Movement alerts such as displacement vibration and overspeed are logged for review
- SMS platform mode is a device side method for querying position while Plaspy provides continuous server side tracking and history
- Plaspy detects tracker protocol automatically and accepts device reports for display and reporting

## Typical Use Cases

- Fleet vehicle location monitoring and route visibility for operations teams
- Motorcycle or lightweight vehicle tracking for recovery and theft deterrence
- Discreet asset tracking where compact size and hidden installation are required
- Personal or handheld device monitoring for on demand location checks
- Backup tracking during external power loss using internal battery support

## Feature Availability Notes

- Feature behavior can differ across LK970 hardware variants labeled A B and C and across firmware releases
- Cellular band support and network performance depend on regional carriers and device configuration
- Installation type such as fixed wiring versus portable placement can affect available power reporting and behavior
- Some features such as SMS mode are device side and operate alongside server side tracking by Plaspy
- Always confirm supported functions and firmware notes with the manufacturer documentation

## Why Use Plaspy with These Features

Using the LK970 with Plaspy gives organizations a single view of location and event data so they can monitor movement, receive alarms, and generate reports for operational oversight. Plaspy collects incoming reports from compatible trackers and presents them through maps timelines and alerting to support routine monitoring and incident response.
