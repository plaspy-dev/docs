# LK-GPS - LK770

![LK770](./logo..jpg)

The LK770 is a compact wired vehicle GPS tracker designed for cars and motorcycles. It combines onboard GPS positioning with built in GSM connectivity and antennas to provide discreet location monitoring. The device is described as supporting common cellular networks and a mobile app experience, and it includes security features such as an SOS alarm, vibration tamper alert, and remote fuel and power cut functionality.

As a Plaspy compatible device, the LK770 can deliver location and event data into the Plaspy fleet platform so organizations can add it to their vehicle inventory and operational workflows. Its app and web friendly design and support for remote configuration make it a practical option for users who want to monitor vehicles through Plaspy for live visibility, alerts, and history playback.

## Key Highlights

- Compact wired form factor suitable for discreet vehicle installation
- Built in GPS and GSM antennas for reliable position reporting
- SOS alarm for emergency notification and responsive alerts
- Remote fuel and electricity cut capability for added security
- Vibration alarm to detect unauthorized movement or tampering
- Mobile app support for Android and Apple devices and web access
- Supports SMS parameter settings and query functions for remote configuration

## How It Works with Plaspy

When integrated with Plaspy, the LK770 submits location updates and event notifications to the platform so they can be viewed, analyzed, and managed alongside other fleet assets. Plaspy provides a central interface where data from the tracker becomes part of ongoing monitoring, reporting, and alerting workflows.

- Live location display on Plaspy maps for real time vehicle visibility
- History route playback and basic reporting to review past movements
- Alerting for SOS and vibration events routed into Plaspy notifications
- Use of remote control features where supported by the device and operator, surfaced through Plaspy controls when available
- SMS parameter and query functions can complement platform management for configuration and status checks

## Typical Use Cases

- Private car owners seeking discreet tracking and emergency alerting
- Vehicle rental operations that need basic location oversight and security controls
- Small fleet management for field staff monitoring and route review
- Equipment or off road asset tracking where compact installed devices are preferred
- Security and investigative applications that require SOS and tamper alerts
