# LK-GPS - LK770 Features

This page provides a public feature overview for the LK-GPS LK770 and describes how its capabilities relate to use with Plaspy. It focuses on user-facing functions and operational value rather than device configuration or sensitive internals, and is intended to help fleet managers, installers, and technical users understand what the tracker can report and how Plaspy can present that information.

Exact feature availability for any individual LK770 unit can vary by firmware version, hardware revision, regional variant, or installation type and manufacturer implementation. For the most current, device-specific technical details consult the manufacturer documentation, and verify compatibility and behavior for your deployment scenario.

## Feature Overview

The LK770 is a compact wired car tracker with integrated GPS and cellular connectivity intended for discreet vehicle monitoring. It combines location reporting with security-oriented functions that can be reflected inside a fleet management platform such as Plaspy.

- Compact wired design with built-in GPS and GSM antennas for discreet installation in cars and motorcycles
- Real-time location tracking and history route playback for monitoring vehicle movements
- SOS alarm and vibration alarm for emergency signaling and tamper detection
- Remote fuel and electricity cut-off capability for theft response and vehicle immobilization
- App and web access compatibility allowing monitoring from Android and Apple devices
- SMS parameter setting and query support for remote configuration where supported

## Core Features of LK-GPS - LK770

- Built-in GPS and GSM antennas for integrated location and mobile reporting
- Wired car tracker form factor intended for permanent installation
- Real-time tracking with history route playback for post-event review
- SOS alarm for emergency signaling to a monitoring platform or app
- Remote cut off of fuel and electricity to disable vehicle power where supported
- Vibration alarm to detect movement or tampering
- Support for SMS parameter settings and query functions for remote configuration
- Low-power mode and shock wake-up modes to reduce power draw and respond to movement events

## How These Features Work with Plaspy

Plaspy receives location and event data from compatible trackers and presents those events in a central dashboard for monitoring and analysis. The LK770 can report common tracking and security events that Plaspy will display alongside other fleet telemetry and history.

- Location points and route history are shown on Plaspy maps and playback tools for situational awareness
- SOS and vibration events are logged and surfaced as alert events so operators can review and triage incidents
- Remote immobilization actions initiated by authorized workflows may be tracked in Plaspy when the device and deployment support remote commands
- Device-reported status such as network connection and basic telemetry are visible in device lists and event timelines
- Plaspy automatically detects many tracker protocols and accepts device reporting to the Plaspy server domain, simplifying device onboarding
- Where SMS configuration is required, Plaspy can be used in parallel with device SMS controls; consult device documentation for SMS command details

## Typical Use Cases

- Vehicle security and theft response for private cars and motorcycles
- Fleet vehicle monitoring for small business and service fleets
- Rental vehicle oversight and mileage or route history review
- Monitoring of externally deployed equipment where a wired tracker can be installed
- Emergency alerting for drivers and passengers using the SOS alarm
- Tamper detection and alerting using the vibration alarm

## Feature Availability Notes

- Firmware differences may enable or limit specific functions such as remote cut off, SOS behavior, or low-power modes
- Hardware revisions and regional network variants can affect cellular band support and connectivity options
- Installation type matters: wired installations should be performed by qualified technicians to ensure functions such as fuel or power cut operate correctly
- SMS parameter commands and exact query formats depend on the device firmware and manufacturer command set
- Manufacturer app behavior and third party platform integration can vary between Android and Apple clients and across app versions

## Why Use Plaspy with These Features

Using the LK770 with Plaspy provides a centralized way to monitor location, alerts, and historical movement across a mixed fleet. Plaspy’s device management and mapping give operators visibility into SOS events, vibration alerts, and route history from LK770 units alongside other devices, helping simplify operational oversight and incident response.
