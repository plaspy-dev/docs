# LK-GPS - LK109 Features

This page presents the public feature context for using the LK-GPS LK109 personal tracker with Plaspy. It describes the tracker capabilities that are relevant to visibility and monitoring in Plaspy and explains how those capabilities are typically used without delving into device configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. Use this page as a practical overview and review the official LK-GPS documentation for the most current device specific details.

## Feature Overview

The LK109 is a compact and waterproof personal tracker designed for discreet location monitoring and emergency alerting. It reports position and event data that Plaspy can use for live tracking, history, and alerting. The device emphasizes portability, basic alert functions, and simple reporting methods suitable for personal and light fleet uses.

- Compact portable design for easy carry or concealment
- Built in GPS providing high sensitivity and position accuracy up to about 5 meters
- Waterproof housing for use in wet or outdoor environments
- SOS alarm and fall alarm functions for emergency notification
- Geo fence capability to trigger entry and exit alerts for predefined areas
- Support for phone app tracking and SMS parameter queries for flexible monitoring

## Core Features of LK-GPS - LK109

- Small form factor optimized for personal use and light equipment tracking
- Built in GPS chip with reported sensitivity and position accuracy suitable for close range tracking
- Waterproof construction to maintain operation in damp or exposed conditions
- SOS alarm to request help and notify caretakers or monitoring services
- Fall alarm to signal potential falls or sudden events requiring attention
- Geo fence functionality to define virtual boundaries and receive alerts
- Call function to enable voice contact with the device user where supported
- Support for phone app tracking on Android and Apple platforms and SMS based parameter queries

## How These Features Work with Plaspy

Plaspy receives location and event data from compatible trackers like the LK109 and presents that information in dashboards, maps, and notifications so teams and caregivers can stay informed.

- Live location updates and historical tracks visible on Plaspy maps for operational oversight
- Alarm events such as SOS and fall alerts surfaced as notifications and event records
- Geo fence entry and exit events logged in Plaspy to support perimeter monitoring and alerts
- Device status and recent communications available in Plaspy device details for troubleshooting
- Plaspy automatically detects supported tracker protocols so devices can report without manual protocol selection

## Typical Use Cases

- Personal safety monitoring for elderly family members or children
- Portable tracking of valuable items and small equipment
- Short term tracking for rental vehicles or temporary assets
- Field staff location awareness for check ins and safety
- Pet tracking where a small waterproof tracker is desirable
- Remote monitoring for caretakers and small scale fleet managers

## Feature Availability Notes

- Feature behavior can depend on firmware version and manufacturer firmware updates
- Some functions such as call handling and app features may vary by regional variant or service provider
- Installation method and accessory choices can affect how a device is used in practice
- SMS parameter and query functions depend on cellular service and device configuration
- Always confirm which features are active on your device model and firmware before deployment

## Why Use Plaspy with These Features

Using the LK109 with Plaspy provides a practical way to centralize location and alarm information from compact personal trackers. Plaspy gives teams and caregivers map based visibility, event history, and notification workflows that make SOS, fall, and geofence events actionable without requiring deep device level management.
