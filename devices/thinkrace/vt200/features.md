# ThinkRace - VT200 Features

This page summarizes the public feature context for the ThinkRace VT200 OBD2 car tracker and how those capabilities are used with Plaspy. It focuses on practical, non sensitive descriptions of what the tracker does, and how Plaspy can present location and event information for fleet and vehicle monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation. For precise technical details and the latest firmware behavior refer to the manufacturer documentation and release notes.

## Feature Overview

The VT200 is an OBD2 form factor vehicle tracker designed for real time GPS tracking and basic driving monitoring. It is intended for easy installation into a vehicle OBD port and provides continuous location and movement visibility suited to taxis, emergency vehicles, and service fleets.

- Real time GPS location reporting to enable live tracking of vehicles.
- OBD2 form factor for simple plug in installation and vehicle power.
- Mileage tracking to support distance based reporting and basic usage analytics.
- Moving test and motion detection to verify vehicle movement and status.
- Abnormal alarm reporting to notify of unusual events as defined by the device.
- Remote upgrade capability to apply firmware improvements when available.

## Core Features of ThinkRace - VT200

- OBD2 plug in design for straightforward installation into compatible vehicle ports.
- Real time GPS tracking for continuous position updates.
- Mileage tracking to record distance traveled for trips and reporting.
- Moving test feature for confirming movement and basic status checks.
- Abnormal alarm functionality to signal unexpected or out of norm conditions.
- Internal 3 axis accelerometer for motion detection and driving behavior analysis.
- Support for remote firmware upgrades to keep device software current.

## How These Features Work with Plaspy

Plaspy ingests reporting from compatible trackers like the VT200 and presents location, motion, and event information through its mapping, alerting, and reporting interfaces. Plaspy automatically detects common tracker protocols to simplify setup and device onboarding.

- Live location is displayed on Plaspy maps for real time visibility and tracking.
- Trip and mileage data are available for reporting and basic usage analysis inside Plaspy.
- Motion events and accelerometer based driving behavior can be surfaced as events or markers for review.
- Abnormal alarms generated by the device can be shown as alerts within Plaspy to support faster operational response.
- Plaspy detects tracker protocol automatically and accepts device connections to d.plaspy.com using common transport modes so the VT200 can report into the platform with minimal manual configuration.

## Typical Use Cases

- Fleet location monitoring for taxi and private hire operations.
- Real time tracking and dispatch visibility for emergency service vehicles.
- Usage and mileage monitoring for engineering and service vehicles.
- Basic driving behavior review to support safety and coaching programs.
- Route verification and trip logging for operational oversight.
- Centralized monitoring of vehicle movement and abnormal event reporting.
