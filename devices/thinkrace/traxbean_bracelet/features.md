# ThinkRace - Traxbean Bracelet Features

This page provides a public feature overview of the ThinkRace Traxbean Bracelet and how its capabilities are used with the Plaspy platform. It summarizes the device functions that matter for monitoring, event handling, and integration into Plaspy workflows without replacing manufacturer documentation.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and the manufacturer implementation chosen for a deployment. For implementation details, configuration steps, and up to date technical specifications consult the official ThinkRace documentation or your device supplier.

## Feature Overview

The Traxbean Bracelet is a compact, person‑centric tracker designed for continuous wear and dependable location awareness. With multi mode positioning and on device safety features, it is intended to support supervision, compliance, and rapid incident response when paired with monitoring platforms such as Plaspy.

- Real time tracking for continuous location awareness and supervision.
- Multi mode positioning that combines satellite GNSS with assisted Wi‑Fi and cellular triangulation to improve coverage in urban and indoor scenarios.
- RF based indoor locating to provide additional situational awareness inside buildings.
- Tamper resistant hardware and strap cut detection to help supervisors detect removal attempts.
- On device safety controls including an SOS button, two way voice calling, siren, and vibration alerts for immediate verification and response.
- Web and mobile applications plus an SDK/Open API for integrations and custom telemetry consumption.

## Core Features of ThinkRace - Traxbean Bracelet

- Precise satellite GNSS positioning for outdoor fixes.
- Assisted locating using Wi‑Fi and cellular triangulation to help obtain positions in challenging environments.
- RF based indoor positioning to supplement satellite fixes inside structures.
- Tamper and strap cut detection with event reporting for removal attempts.
- SOS button for user initiated emergency alerts.
- Two way voice calling to allow incident verification and direct communication.
- Audible siren and vibration alerts to attract attention or prompt compliance.
- IP67 rated compact wrist design intended for continuous, discreet wear; portable charger included and supported mobile and web apps plus SDK/Open API for integration.

## How These Features Work with Plaspy

When used with Plaspy, the Traxbean Bracelet transmits location and event data into the Plaspy platform so supervisors and integrators can monitor status, respond to incidents, and integrate telemetry into case systems. Plaspy surfaces device events and makes telemetry available to dashboards and integrations.

- Real time location updates and assisted positioning shown on Plaspy maps and device timelines.
- Geofence entry and exit events configurable in Plaspy to trigger alerts and workflows.
- Tamper and strap cut events routed into Plaspy notifications and escalation processes.
- SOS presses and two way voice sessions surfaced in the Plaspy dashboard to support verification and response coordination.
- Push notifications and mobile alerts delivered to supervisors; SDK/Open API allows integrators to pull telemetry and event streams into external systems.

## Typical Use Cases

- Electronic monitoring for community corrections programs including parole and probation supervision.
- Alternative sentencing and bail monitoring programs that require discreet continuous wear and real time oversight.
- Protective services or workforce tracking for programs that need non intrusive person monitoring.
- Public safety and emergency response scenarios where SOS and two way voice improve incident handling.
- Deployments where indoor locating and assisted positioning reduce blind spots in buildings and urban canyons.
