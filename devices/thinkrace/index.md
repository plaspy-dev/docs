# ThinkRace

ThinkRace produces compact GPS tracking hardware commonly used for vehicle and asset tracking. This page explains how ThinkRace devices work with Plaspy, what to expect from their typical features, and how to navigate device compatibility using the Plaspy platform. Use the device catalog below to view all ThinkRace models that integrate with Plaspy and follow links to model specific pages for setup and configuration details.

## How ThinkRace devices work with Plaspy

ThinkRace devices typically send location and telemetry over cellular networks using standard tracking protocols. Plaspy ingests those data streams and normalizes them so devices appear and behave consistently inside the Plaspy platform. In most cases you will configure device reporting to point to Plaspy and confirm protocol settings on the device. For device level setup and example configuration steps consult the individual device pages accessible from the catalog below.

## Common features found in ThinkRace devices

ThinkRace trackers commonly include features you will find useful across fleet and asset use cases. Typical capabilities include
- GNSS location reporting for real time and historical tracking
- Cellular connectivity for live position updates
- Geofence support for zone alerts
- Motion and ignition detection for activity based reporting
- Configurable reporting intervals and power saving modes
- Basic I O for integration with sensors and immobilizers

Exact feature availability depends on the specific ThinkRace model. Use the catalog above to open a model page in Plaspy where device specific capabilities and configuration guides are provided.

## Typical use cases for ThinkRace GPS trackers

ThinkRace devices are often used in scenarios that require compact and reliable location tracking. Common deployments include
- Small and medium sized vehicle fleets requiring live tracking and history
- Rental and shared vehicles where ignition and motion events matter
- Asset tracking for containers trailers and equipment
- Basic security and recovery solutions for cars and motorcycles

Plaspy helps translate device data into actionable insights for these use cases with alerts dashboards and reporting tools.
