# PST - AVL-011 Features

This page provides a public feature overview for the PST AVL-011 GPS tracker and how those features are reflected when the device is used with Plaspy. It summarizes practical capabilities that matter to users and fleet operators and explains how the tracker can be deployed in Plaspy for location awareness and operational oversight.

Exact feature availability can vary by the device firmware version, hardware revision, installation method, and the manufacturer implementation. Use this page as a general guide and consult the manufacturer documentation for the definitive device behavior for your specific unit.

## Feature Overview

The PST AVL-011 is positioned as a vehicle security focused GPS tracker with features designed to help recover vehicles and respond to emergency situations. It combines location reporting with remote control and emergency monitoring features intended to improve situational awareness and asset protection.

- GPS based location reporting to track vehicle position and movement history
- Remote cut off of vehicle power or fuel supply to immobilize a vehicle when supported and authorized
- Stealthy installation options to keep the tracker hidden from casual inspection
- SOS emergency mode that enables voice monitoring around the vehicle for situational awareness
- Compatibility with Plaspy for centralized monitoring and event visibility

## Core Features of PST - AVL-011

- GPS location tracking suitable for vehicle position monitoring and history
- Remote engine or fuel cut off functionality for anti theft response when enabled
- Stealth installation design to allow unobtrusive placement inside a vehicle
- SOS emergency functionality that supports voice monitoring for urgent situations
- Designed for use in cars, trucks, and other vehicles where anti theft and emergency monitoring are required
- Compatibility with standard tracker reporting workflows used by platforms such as Plaspy

## How These Features Work with Plaspy

When an AVL-011 is connected to Plaspy, the platform presents location and event information alongside other fleet data to give operators a clear operational view. Plaspy detects compatible tracker protocols automatically and makes device events available in the platform interface for monitoring and response.

- Real time and historical location data appear in Plaspy maps and trip timelines
- Immobilization or remote cut off events are recorded as device events when issued and reported by the tracker
- SOS activations and related emergency events are surfaced to operators for immediate attention
- Hidden installation does not affect Plaspy visibility; reported telemetry is available regardless of placement
- Plaspy centralizes device status so administrators can review last known state and recent activity

## Typical Use Cases

- Recovering a stolen vehicle by tracking location and using immobilization features where supported
- Adding a hidden security layer to personal vehicles or high value assets
- Emergency monitoring on scene via SOS voice monitoring to assist first responders or owners
- Protecting rental and fleet vehicles by combining tracking with remote disable capabilities
- Operational oversight for small fleets that need simple anti theft and emergency features
