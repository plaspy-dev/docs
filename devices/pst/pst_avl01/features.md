# PST - PST-AVL01 Features

This page provides a public feature overview for the PST PST-AVL01 GPS tracker and how those capabilities are presented when the device is used with Plaspy. It summarizes practical functions you can expect to see in Plaspy for monitoring and managing vehicles that use the PST-AVL01 while remaining non-sensitive and suitable for general reference.

Exact availability and behavior of specific features depend on the device firmware version, hardware revision, regional model, and how the unit is installed and configured by the manufacturer or installer. Where helpful, this page notes practical considerations, but users should confirm current device behavior with the PST product documentation and release notes.

## Feature Overview

The PST-AVL01 is designed for real-time vehicle tracking and fleet management using GPS positioning and GSM/GPRS connectivity. In practice this provides continuous location updates and event reports that support operational oversight, route monitoring, and security workflows.

- Real-time GPS location reporting for ongoing position visibility
- GSM/GPRS connectivity for sending location and event data to a remote server
- Geo-fencing support to detect entry and exit of predefined areas
- Remote immobilization capability for security and recovery workflows
- SOS alert reporting for emergency notification to operations staff
- Compact and durable form factor suited to vehicle installations

## Core Features of PST - PST-AVL01

- Real-time GPS tracking to report position fixes at configurable intervals
- GSM/GPRS communication to transmit tracking data to remote services
- Geo-fence events to trigger alerts when a vehicle crosses defined boundaries
- Remote immobilization function to support vehicle disablement where implemented
- SOS alert generation for emergency signaling from the device
- Robust design intended for in-vehicle use and discreet installation

## How These Features Work with Plaspy

When connected to Plaspy, the PST-AVL01's location and event messages are presented in the platform to give operators situational awareness and event visibility. Plaspy automatically detects supported tracker protocols and integrates incoming device data into the same monitoring environment used across fleet assets.

- Live position display on Plaspy maps for route following and location checks
- Geo-fence events and alerts shown in Plaspy event timelines and notifications
- SOS alerts highlighted so dispatchers can quickly identify emergency events
- Remote immobilization status and commands reflected in Plaspy when the device and installation support the function
- Historical tracks and trip playback available from recorded position data

## Typical Use Cases

- Fleet dispatch and route monitoring for day-to-day operations
- Security and recovery workflows using remote immobilization and alerts
- Geographical compliance and perimeter monitoring via geo-fences
- Rapid incident response using SOS alert visibility in operations dashboards
- Asset oversight for mixed fleets where discreet installation is required

## Feature Availability Notes

- Feature support can vary by firmware version; manufacturers sometimes add or change behavior in updates.
- Hardware revisions and regional variants may include different feature sets or regulatory-specific limitations.
- Some functions require specific installation wiring or configuration; installers should confirm capabilities before deployment.
- Plaspy shows events and states based on the data the device reports; certain platform features rely on the tracker sending corresponding messages.
- For the most accurate, device-specific details consult PST product documentation and firmware release notes.

## Why Use Plaspy with These Features

Using the PST-AVL01 together with Plaspy gives organizations a unified view of vehicle location, event alerts, and historical movement in a single fleet management environment. Plaspy's device detection and consolidated presentation make it practical to monitor mixed fleets while maintaining clear operational visibility and faster response to events.
