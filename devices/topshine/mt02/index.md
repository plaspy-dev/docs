# TopShine - MT02

![MT02](./tracker.jpg)

The 4G MT02 is a professional-grade GPS tracker designed for reliable Plaspy compatible real-time tracking, fleet management and vehicle anti-theft protection. Built for vehicle installations, the MT02 combines 4G LTE cellular connectivity, GPS/A‑GPS positioning, onboard data logging and fuel-sensor integration to provide continuous telemetry, configurable alerts and remote immobilization when used with the Plaspy platform.

The MT02 is engineered for fleet operators and service providers who need accurate location, fuel monitoring and remote control over a single device. With support for multiple reporting methods \(TCP/UDP, SMS, mobile APP and web\), OTA firmware updates and IP65-level protection, the MT02 integrates easily into Plaspy deployments to deliver actionable vehicle data, history and safety alarms.

## Key Highlights

- Plaspy compatible for real-time tracking and fleet management via TCP/UDP, mobile APP and web portal.
- 4G LTE primary connectivity with GSM/GPRS fallback for broad cellular coverage and reliable telemetry.
- Integrated fuel sensor support with refill and stolen-fuel alerts to reduce losses and improve fuel monitoring.
- Onboard memory logging \(4B\) to retain GPS and event history when network is unavailable and upload when restored.
- Remote immobilize \(relay\) control and SOS button for anti-theft and driver safety workflows.
- Wide input voltage \(+9V to +90V\) and 650 mAh backup battery to report location after main power loss.
- IP65-level dust/water resistance and robust operating range for professional vehicle installations.

## How It Works with Plaspy

When deployed with Plaspy, the 4G MT02 streams vehicle position and telemetry to the platform using the device's supported reporting channels. Plaspy ingests these messages and provides map visualization, event alerts, historical routes and customizable reports. Configuration and remote commands can be issued from Plaspy to control immobilization, adjust alarm thresholds and manage firmware updates where applicable.

- Real-time location and telemetry updates delivered over TCP/UDP to Plaspy servers or via the device’s web/mobile reporting options.
- Fuel monitoring and alarms — Plaspy receives fuel level data and triggers refill or stolen-fuel alerts based on configured thresholds.
- SOS, geofence, overspeed and tamper alerts sent to Plaspy for immediate notification and incident tracking.
- Remote immobilize \(relay\) control — Plaspy can issue commands to disable vehicles as part of anti-theft workflows.
- Offline logging: MT02 stores GPS records in onboard memory and uploads stored data to Plaspy once connectivity is restored.

## Use Cases

- Fleet management: monitor real-time location, route history and mileage for cars, taxis, buses and trucks.
- Anti-theft protection: SOS alerts, tamper alarms and remote immobilize \(relay\) control to secure stolen vehicles.
- Fuel monitoring: integrate an external fuel sensor to detect refills and stolen fuel events and report them to Plaspy.
- Driver safety and dispatch: overspeed and geofence alerts plus SOS button notifications for rapid response.
