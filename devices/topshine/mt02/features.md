# TopShine - MT02 Features

This page provides a public feature summary for the TopShine MT02 and explains how those capabilities are reflected when the device is used with Plaspy. It focuses on user facing capabilities, practical value for fleet and vehicle deployments, and how telemetry and alerts can appear in the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional SKU, and the specifics of the installation. For definitive device details consult the manufacturer documentation and firmware release notes before deployment.

## Feature Overview

The TopShine MT02 is a vehicle focused 4G GPS tracker designed to deliver continuous position reporting, fuel monitoring, offline data logging and anti theft controls. When integrated with Plaspy, the MT02 supplies the platform with location, event history and alert data used for monitoring and operational workflows.

- Real time GPS and A GPS positioning for continuous vehicle location reporting.
- 4G LTE connectivity with GSM fallback to maintain telemetry across networks.
- Integrated fuel sensor support for fuel level monitoring and refill or stolen fuel alerts.
- Onboard memory logging to store GPS and event history when network coverage is unavailable.
- Remote immobilize (relay) control and SOS input to support anti theft and emergency workflows.

## Core Features of TopShine - MT02

- 4G LTE primary cellular connectivity with GSM GPRS fallback for broad coverage.
- GPS with A GPS assistance for faster position fixes and reliable tracking.
- Fuel sensor integration to report fuel level changes and generate fuel related alerts.
- Onboard data logging to retain location and event records during offline periods.
- Remote immobilize relay control for vehicle disablement as part of security workflows.
- SOS button and tamper detection for incident reporting and driver safety.
- OTA firmware update support and remote configuration options for lifecycle management.

## How These Features Work with Plaspy

When the MT02 is deployed on Plaspy, the device reports telemetry and events that Plaspy ingests, displays, and archives to support monitoring and operational decisions.

- Real time location and telemetry appear on Plaspy maps and live monitoring dashboards.
- Fuel level reports and fuel related alarms are received by Plaspy and can be used in alerts and fuel monitoring reports.
- SOS and tamper events are surfaced in Plaspy for immediate notification and incident tracking.
- Remote immobilize commands and configuration changes can be issued from Plaspy to supported MT02 installations.
- Offline logged data stored on the MT02 uploads to Plaspy after connectivity is restored, preserving historical traces.

## Typical Use Cases

- Fleet tracking for cars vans taxis and light trucks requiring continuous location visibility.
- Anti theft protection with SOS alerts tamper notifications and remote immobilization.
- Fuel monitoring programs that track refills consumption and detect suspicious fuel loss.
- Driver safety and dispatch workflows using alerts and historical route information.
- Service and maintenance logging where offline data retention prevents gaps in trip history.

## Feature Availability Notes

- Some features such as band support optional sensors and accessory availability vary by regional SKU and hardware revision.
- Firmware version can affect alarm behavior command support and reporting options; check firmware release notes for specifics.
- Certain capabilities require proper installation and connected accessories such as an external fuel sensor or relay wiring.
- Manufacturer supplied accessories and optional sensors may be sold separately and have their own configuration requirements.
- Always verify the device model and firmware on arrival to confirm the exact set of supported features.

## Why Use Plaspy with These Features

Using the TopShine MT02 with Plaspy gives organizations consolidated visibility of location fuel status and security events in a single fleet management platform. Plaspy can aggregate MT02 telemetry into map views alerts and historical reports so operators can monitor vehicle health, investigate incidents, and run routine operational analytics.
