# TopShine - MT02-4G Features

This page describes the public feature context for the TopShine MT02-4G GPS tracker and how those features integrate with Plaspy. It focuses on practical capabilities you can expect when the MT02-4G is paired with Plaspy for live location, historical route playback, event alerts and device lifecycle management.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method and manufacturer implementation. For precise technical details, wiring diagrams and the latest firmware notes consult the device manufacturer documentation and release notes.

## Feature Overview

The MT02-4G is a compact 4G vehicle tracker designed for continuous fleet use, offline logging and reduced service overhead through OTA updates. In combination with Plaspy, the device provides visibility and event awareness suitable for cars, motorcycles and commercial vehicles.

- Real time GPS tracking and live location reporting into Plaspy for monitoring and dispatch.
- Built in data logger with approximately 26,000 offline points for uninterrupted telemetry when network is unavailable.
- 4G cellular connectivity for reliable reporting and future network compatibility.
- Wide DC input voltage range for flexible installation across vehicle types.
- 500mAh backup battery to capture key events during main power loss.
- OTA firmware upgrade capability to simplify maintenance and keep devices current.

## Core Features of TopShine - MT02-4G

- Out of the box compatibility with Plaspy for immediate integration into web and mobile dashboards.
- 4G cellular connectivity enabling frequent position updates and telemetry transfer.
- Onboard data logger (2MB standard, expandable) capable of storing tens of thousands of points for later upload.
- Wide input voltage support for stable operation across cars, trucks and motorcycles.
- Integrated backup battery to support offline positioning and event reporting during power interruptions.
- Over the air firmware upgrade support to reduce on site service visits.
- Support for fuel monitoring and driver identification via optional accessories as implemented by the manufacturer.
- Remote immobilizer control and relay support available when used with approved external accessories.

## How These Features Work with Plaspy

Plaspy receives and presents the MT02-4G telemetry so teams can monitor position, review history and respond to events. Plaspy automatically detects compatible tracker protocols and surfaces device data for operational use, alerting and reporting.

- Live position and route history playback visible in Plaspy’s map and timeline views.
- Event driven alerts such as power loss, low battery, geo fence triggers and SOS notifications relayed into Plaspy for immediate attention.
- Offline logged points are uploaded to Plaspy when the device regains connectivity, enabling post event analysis.
- Device management functions such as triggering OTA updates or reviewing firmware status can be coordinated alongside tracked data in the platform.
- Accessory derived inputs like fuel monitoring or driver ID appear in Plaspy if the accessory is installed and the manufacturer exposes that telemetry.

## Typical Use Cases

- Fleet operations needing continuous location visibility and route history for vehicles and motorcycles.
- Anti-theft workflows where remote immobilizer control, SOS alerts and geo fence events support recovery.
- Fuel management programs that integrate ultrasonic or cuttable fuel sensors for refuel and leak detection when supported.
- Driver identification and safety monitoring using optional ID accessories and event alerts for coaching and compliance.
- Distributed device management where OTA upgrades reduce service visits across a large vehicle estate.
- Post incident analysis using offline data logger points captured during network loss.
