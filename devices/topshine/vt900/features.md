# TopShine - VT900 Features

This page provides a public feature overview of the TopShine VT900 and how those capabilities map to use with Plaspy. It is intended to describe user-facing capabilities and practical functions of the tracker in a fleet or security context and to explain how the device can be used through Plaspy for monitoring and operational oversight.

Exact feature availability and behavior can vary by manufacturer firmware version, hardware revision, installation choices, and regional model variants. For the most current device specific technical details and implementation notes consult the manufacturer documentation and release notes.

## Feature Overview

The TopShine VT900 is a vehicle tracking device designed for real-time position reporting, security monitoring, and operational control. It combines GPS positioning with cellular connectivity to report location and status to a web platform and supports a range of alerts and remote functions useful for fleet management and vehicle security.

- Real time GPS location reporting to a web tracking platform for live monitoring and route review
- Multiple reporting methods including SMS and GPRS to support remote updates and server reporting
- Alerts for events such as speeding, geo fencing, power loss, and SOS to support rapid response
- Remote control and monitoring features including engine on off detection, remote engine cut off, and remote listening where supported by firmware
- On device logging and OTA firmware updates to help maintain device functionality and recover recent position history

## Core Features of TopShine - VT900

- GPS positioning with continuous real time tracking capability for vehicle location awareness
- Cellular connectivity via GSM GPRS to deliver location and event reports to a server or mobile
- Support for SMS based queries and reporting alongside data reporting over GPRS
- OTA firmware update capability for remote maintenance and feature updates
- Alerts including overspeed, geo fence, low power or power failure, and SOS panic button
- Engine on off detection and remote engine cut off control for security and immobilization workflows
- Built in backup battery and on device position logging to preserve recent data when main power is removed
- Support for camera and voice prompt or broadcasting functions and remote listening where enabled by the device firmware

## How These Features Work with Plaspy

Plaspy receives and displays the VT900 reporting and alerts to provide visibility and operational context for vehicles and assets. Plaspy is designed to detect common tracker protocols automatically and present location, events, and basic device status in the web interface for monitoring and historical review.

- Live location updates and trip playback visible in Plaspy for route analysis and asset oversight
- Event and alert reporting such as overspeed, geo fence, SOS, and power status mapped into Plaspy notifications and history
- Position logging on the device combined with Plaspy storage helps fill gaps and provide continuity when connectivity is intermittent
- Remote command support exposed in Plaspy when device firmware and configuration allow remote control actions such as engine cut off or remote listening
- OTA and firmware related information surfaced in device details, helping administrators track firmware versions where the device reports that information

## Typical Use Cases

- Fleet location tracking and route management for light and commercial vehicles
- Security monitoring and theft response using position reporting, SOS alerts, and remote engine cut off
- Driver behavior and event review using overspeed and sudden braking alerts for coaching and safety programs
- Asset monitoring for vehicles that require backup battery tracking and offline logging
- Remote monitoring and voice broadcast or camera functions for security checks where supported

## Feature Availability Notes

- Feature availability depends on the device firmware version and the specific hardware revision installed in the vehicle
- Some functions such as remote engine cut off, remote listening, camera use, and voice broadcasting require correct wiring, permissions, and firmware support
- Regional variants and cellular network compatibility can affect reporting methods such as SMS versus GPRS
- Manufacturer configuration and installation choices may enable or disable specific inputs, outputs, and sensors
- Always confirm the device feature set and supported commands against official TopShine documentation for your specific serial number and firmware
