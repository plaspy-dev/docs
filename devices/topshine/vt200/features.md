# TopShine - VT200 Features

This page provides a public overview of the TopShine VT200 feature set and how those capabilities relate to monitoring and fleet management with Plaspy. It focuses on practical, non-sensitive details about what the tracker reports, the accessories and sensors it supports, and the ways those inputs and outputs can be used inside Plaspy for location visibility, alerts, and historical reporting.

Exact feature availability for any VT200 unit can vary with the device firmware, hardware revision, installation type, and the manufacturer's current implementation. Where the VT200 description lists optional sensors or accessories, those items may require additional modules or cabling and may depend on the installer configuration and regional variants.

## Feature Overview

The VT200 is a vehicle-focused tracker designed for Plaspy compatible deployments. It combines core location reporting with onboard data logging, backup power, multiple vehicle I O points, and optional fuel sensing to support fleet, rental, and asset tracking scenarios.

- Real-time position reporting via 2G GPRS or SMS for continuous location feeds to Plaspy.
- Built-in 2MB data logger that stores records during coverage gaps and uploads them when connectivity is restored.
- Internal backup battery to maintain tracking during primary power loss.
- Multiple inputs and outputs for vehicle telemetry and remote engine control including relay based engine cut-off.
- Optional ultrasonic no-drill fuel sensor support and included accessories such as GPS and GSM antennas and an SOS panic button.

## Core Features of TopShine - VT200

- 2G GSM connectivity with GPRS reporting using standard TCP or UDP and support for SMS position reports.
- Onboard 2MB data logger for temporary record storage in GSM blind spots.
- Internal backup battery for short term operation during external power loss.
- Multiple I O channels: two digital inputs (one positive trigger, one negative trigger), one analog input, and two output ports for relay or remote engine cut-off.
- Optional ultrasonic no-drill fuel sensor support for fuel level monitoring where fitted.
- Supplied vehicle installation accessories including GPS and GSM antennas, SOS button, wiring harness, and a relay.
- Optional accessory support such as a Bluetooth smartphone reader, crash sensor, temperature sensor, RFID identification, and an internal microphone with optional voice listening.
- Certifications and commercial details including CE FCC and RoHS listings and a two year warranty as provided by the manufacturer.

## How These Features Work with Plaspy

Plaspy ingests the VT200 location and telemetry so operators can view live positions, receive alerts, and analyze historical events. The platform accepts standard reporting from devices configured for GPRS or SMS and reflects input and output events in maps, reports, and alerting tools.

- Real-time location updates and position history visible on Plaspy maps when the VT200 reports via GPRS or SMS.
- Offline records from the VT200 data logger are uploaded after connectivity returns and appear in Plaspy historical reports to reduce data gaps.
- Digital input and analog states such as ignition or power cut are available as event markers and can trigger configurable alerts in Plaspy.
- Fuel sensor telemetry from an optional ultrasonic sensor can be presented in Plaspy fuel reports and used to detect sudden changes consistent with theft or refueling.
- Relay output status and remote engine cut-off commands are reflected in device status where Plaspy supports remote control and where device firmware permits command execution.
- Plaspy automatically detects common tracker protocols and accepts standard GPRS TCP or UDP streams when the device is configured to report to the Plaspy service.

## Typical Use Cases

- Fleet operations tracking for real-time location, route history, and operational oversight.
- Anti-theft protection using power cut alerts, SOS button events, and remote engine cut-off where supported.
- Fuel monitoring for consumption analysis and theft detection using the optional ultrasonic fuel sensor.
- Rental vehicle tracking with tamper and immobilization controls to protect assets between hires.
- Equipment and trailer tracking where compact form factor and backup power provide continuity.
- Safety and compliance monitoring using optional crash and temperature sensors and driver identification accessories.

## Feature Availability Notes

- Some features are optional and require additional accessories or sensor modules from the manufacturer or installer.
- Firmware versions and hardware revisions can enable or limit specific functions such as accessory support and remote command handling.
- Regional network availability and 2G coverage vary by country and can affect GPRS and SMS based reporting.
- Professional installation is recommended for wiring, relay setup, and sensor integration to ensure reliable behavior.
- Consult the manufacturer documentation for the exact accessory part numbers and installation guides for optional sensors such as the ultrasonic fuel sensor.
