# TopShine - MT01-4G Features

This page provides a public feature-level overview of the TopShine MT01-4G GPS tracker and how its capabilities integrate with the Plaspy platform. It summarizes the practical telemetry, sensor, and control features that are relevant for fleet management, taxi dispatch, and vehicle anti-theft workflows when the device is used with Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type, and manufacturer implementation. Always consult the device vendor documentation and installation notes for details that apply to a specific unit or deployment.

## Feature Overview

The MT01-4G is a compact vehicle tracker designed to deliver real-time location, fuel telemetry, driver identification, and remote immobilization features for mixed fleets. It emphasizes continuous fuel monitoring, dispatcher communications, and reliable operation across a wide input voltage range, with local logging for offline scenarios.

- 4G LTE connectivity for timely position updates and telemetry transmission.
- Ultrasonic fuel sensor support for ongoing fuel level monitoring and fuel-theft alerts.
- Relay output for remote immobilizer or engine/fuel cut-off to assist recovery.
- Driver identification via iButton to associate drivers with vehicles and events.
- Two-way voice capability for dispatcher to driver communication.
- Wide 9–90V input range and built-in backup battery to support varied vehicle types.

## Core Features of TopShine - MT01-4G

- 4G LTE data connectivity for live tracking and fast telemetry delivery.
- Ultrasonic fuel sensor interface and continuous fuel-level reporting.
- Relay output for remote engine or fuel cut-off (immobilizer control).
- iButton reader for driver identification and event linking.
- Two-way voice support with microphone and speaker ports.
- Wide operating voltage range of 9–90V for multi-vehicle compatibility.
- Built-in backup battery to send alerts on main power loss.
- On-board data logger for offline storage and later upload when connectivity returns.

## How These Features Work with Plaspy

When an MT01-4G is configured to report to Plaspy, location updates and supported telemetry are received by the Plaspy platform and presented through dashboards, alerts, and reports. Plaspy can use the incoming data to drive notifications, trend charts, and operational workflows for fleet and security teams.

- Real-time positions and movement updates appear on Plaspy maps for live tracking.
- Fuel-level readings and fuel-theft alerts are available in Plaspy reports and can trigger notifications.
- Engine or ignition status and relay-triggered immobilizer events are reflected as status events inside Plaspy.
- Driver iButton events can be linked to trips and driver logs for accountability.
- Two-way voice is supported by the device for dispatcher communications while Plaspy centralizes event history.
- The MT01-4G supports local logging for offline operation and will upload stored records to Plaspy when connectivity is restored. Plaspy automatically detects supported device protocols and the device may be configured to use standard transport options.

## Typical Use Cases

- Fleet management for trucks and vans where continuous fuel monitoring and driver identification reduce operating costs.
- Taxi and ride-hailing dispatch with iButton driver checks and two-way voice coordination.
- Theft prevention and recovery using fuel-theft alerts, SOS events, and remote immobilizer actions.
- Mixed fleet deployments and marine use where a wide input voltage range simplifies installations.
- Post-incident analysis using crash sensor alarms, power-failure logs, and saved telemetry.
- Remote sites or intermittent connectivity scenarios where on-board logging preserves critical data.
