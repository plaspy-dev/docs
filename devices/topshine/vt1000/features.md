# TopShine - VT1000 Features

This page describes the public feature context for using the TopShine VT1000 tracker with Plaspy. It summarizes the VT1000's practical capabilities for fleet management, passenger connectivity and vehicle security, and explains how those capabilities can be used and viewed through the Plaspy platform.

Exact feature availability can vary by firmware revision, hardware variant, installation method and manufacturer implementation. Use this overview to understand core capabilities and how they integrate with Plaspy, and consult manufacturer documentation for the most current, device specific technical details.

## Feature Overview

The VT1000 is a professional vehicle tracker that combines high precision GNSS positioning, multi band cellular connectivity and an integrated WiFi hotspot to deliver location awareness, passenger internet and camera integration for mixed use fleets. It is designed to provide continuous tracking, vehicle telemetry and evidence capture while reporting into Plaspy for monitoring and reporting.

- High precision GNSS positioning for reliable real time location tracking.
- Multi band LTE/3G/GSM connectivity to maintain links across regions and networks.
- Integrated WiFi hotspot that supports passenger internet access and connection of multiple WiFi cameras.
- Rich vehicle telemetry including engine on/off detection, door status, fuel and temperature analog inputs, and driving event alarms.
- Remote engine cut off relay and SOS input for emergency immobilization and alerting.
- Onboard SD storage and internal logging to preserve waypoints and media when connectivity is interrupted.

## Core Features of TopShine - VT1000

- Precision GNSS location reporting suitable for continuous fleet tracking and timestamped telemetry.
- Multi band cellular modem with LTE, 3G and GSM support for broad network coverage.
- Built in WiFi hotspot enabling passenger connectivity and support for 20 plus WiFi cameras.
- Video support with SD card storage and RS232 camera interfacing for photo and video evidence capture.
- Engine on/off detection and ignition monitoring for accurate vehicle state reporting.
- Door open and close status inputs to signal security events and loading operations.
- Analog inputs for fuel and temperature sensors to feed operational telemetry into Plaspy.
- Emergency features including an SOS input and remote engine cut off relay for rapid immobilization.

## How These Features Work with Plaspy

When registered on Plaspy the VT1000 supplies location, alarms and sensor readings so managers and dispatchers get a consolidated view of vehicle status and events. Plaspy aggregates position fixes, sensor inputs and alarms into maps, timelines and reports to support operational decisions and incident response.

- Real time location updates and historical tracks visible on Plaspy maps and logs.
- Sensor and alarm visibility such as engine on/off events and door open alerts for operational monitoring.
- Fuel and temperature inputs presented as telemetry values for fuel management and temperature sensitive deliveries.
- Event correlation between camera photo logs and vehicle telemetry so media can be matched to incidents recorded in Plaspy.
- Remote immobilizer status and control where device hardware and installation permit, shown within Plaspy workflows.
- Plaspy automatically detects supported tracker protocols and receives the VT1000 telemetry for display and reporting.

## Typical Use Cases

- Fleet route monitoring and dispatch for buses, shuttles and commercial vehicles.
- Passenger transport with onboard WiFi plus video monitoring for safety and service quality.
- Anti theft and emergency immobilization workflows using SOS alerts and engine cut off relay.
- Fuel and temperature sensitive delivery monitoring using analog sensor inputs.
- Incident evidence collection with synchronized camera photo logging and SD based archival.
- Compliance reporting and historical playback for driver behavior and route verification.

## Feature Availability Notes

- Feature sets depend on the VT1000 firmware version and the specific hardware revision installed in each unit.
- Some functions such as remote engine cut off, analog sensor readings and camera counts require proper vehicle wiring and accessory installation.
- Cellular band availability and roaming behavior vary by region and local carrier support.
- Video performance and number of active cameras depend on WiFi configuration, bandwidth and on board settings.
- Manufacturer options such as SD card size and factory enabled features may differ between units and distribution channels.
