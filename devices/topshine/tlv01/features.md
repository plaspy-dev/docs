# TopShine - TLV01 Features

This page summarizes the public feature context for the TopShine TLV01 Mini Hide GPS Tracker and how those capabilities are used with Plaspy. It focuses on practical, non sensitive information about device capabilities, compatible reporting methods, and the kinds of monitoring and control you can expect when the TLV01 is integrated into the Plaspy platform.

Exact feature availability can vary by firmware version, hardware revision, installation method, regional model, and manufacturer implementation. Use this guide to understand the TLV01's practical strengths with Plaspy, and confirm device specific details against the official manufacturer documentation when precision is required.

## Feature Overview

The TLV01 is a compact, covert tracker built for discreet asset and vehicle protection. It supports multiple reporting paths and position sources so trackers can stay visible to a platform like Plaspy in a variety of installation and signal conditions. The device emphasizes concealment, flexible power options, and basic remote control features useful for fleet and security use.

- Compact mini hide form factor suitable for covert installation in vehicles and portable assets.
- Real-time location reporting via GSM GPRS and SMS to maintain continuous visibility to Plaspy.
- Hybrid GPS plus LBS positioning with AGPS support to help obtain fixes in weak signal or indoor scenarios.
- Wide input voltage tolerance for flexible installation across cars, motorcycles, and non automotive equipment.
- Backup battery and smart power saving to maintain telemetry during external power loss.
- Configurable reporting by time, distance, or course and support for common alarm types used in security workflows.

## Core Features of TopShine - TLV01

- GSM GPRS and SMS reporting for internet and fallback messaging based tracking.
- Hybrid GPS and LBS locating with AGPS assistance to improve position acquisition.
- Mini hide form factor with small installation dimensions for covert placement.
- Wide input voltage support to simplify wiring across different vehicle classes.
- Integrated backup battery (250 mAh) and configurable power saving strategies.
- Configurable reporting triggers by time, distance, or course for flexible telemetry.
- Alarm support for geo fence, tow, and overspeed events for security monitoring.
- Remote engine or oil cut off immobilizer and optional external power cut alarm for anti theft response.

## How These Features Work with Plaspy

When the TLV01 is connected to Plaspy, device position and event data are presented in a unified dashboard so operators can monitor assets, receive alerts, and take authorized actions from one place. Plaspy ingests the tracker messages and maps location, event history, and alarm states for operational use.

- Device locations appear on Plaspy maps and can be viewed in near real time based on the configured reporting schedule.
- Geo fence, tow, overspeed, and power cut events are forwarded to Plaspy so teams receive alerts and can review event history.
- Remote immobilizer commands supported by the TLV01 can be issued through Plaspy when deployments require authorized vehicle control.
- Reporting intervals and event thresholds configured on the device translate into the cadence and granularity of data shown in Plaspy.
- AGPS and LBS fallbacks help Plaspy display the best available fixes in weak GPS conditions to maintain situational awareness.

## Typical Use Cases

- Fleet management for small vehicle fleets that need continuous position updates, event alerts, and basic remote control.
- Anti theft protection for cars and motorcycles using covert placement plus power cut and immobilizer features.
- Recovery of portable assets such as equipment that benefits from a small, hidden tracker form factor.
- Rental and shared vehicle monitoring where geo fence and movement alerts support compliance and recovery.
- Security monitoring in mixed signal environments where AGPS and LBS help maintain location visibility.
