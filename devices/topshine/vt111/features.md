# TopShine - VT111 Features

This page describes the public feature context for using the TopShine VT111 mini GPS vehicle tracker with the Plaspy platform. It focuses on the practical capabilities that end users and fleet operators can expect when the device is used to provide location awareness, alarm functions, and remote control through Plaspy.

Exact feature availability and behavior can vary with firmware version, hardware revision, optional accessories, installation choices, and the manufacturer implementation. Where the VT111 description lists optional parts or features, those items may require additional modules or specific configuration to work with Plaspy.

## Feature Overview

The VT111 is a compact vehicle tracker that combines basic GPS tracking with vehicle security functions and remote control options. Its small footprint and flexible operation modes make it suitable for both single-vehicle security and small fleet monitoring.

- Real time tracking by SMS or GPRS with configurable reporting by time interval or distance
- Alarm and security functions including Arm/Disarm by SMS or call and movement or tamper alerts
- Remote control capability to cut off vehicle power or fuel supply via SMS or a tracking platform
- Backup battery and external power failure alerts to detect device power loss
- Dual location methods available: GPS and cellular positioning system (CPS) for broader coverage

## Core Features of TopShine - VT111

- Compact mini tracker design intended for discreet installation and anti-tamper placement
- Tracking over SMS and GPRS with position, speed, and direction reporting
- Arm and Disarm control by SMS or telephone call, with optional RFID for automatic arming
- Movement alerts, geo-fence alerts, and over-speed alerts to notify of events
- Remote engine power or fuel cut command supported via SMS or a connected tracking platform
- Built-in rechargeable backup battery with external power failure alarm reporting
- Two types of location fixes: GPS and CPS, and the ability to send a Google Maps link via SMS
- Optional anti-robbery switch and optional engine status detection where provided by the manufacturer

## How These Features Work with Plaspy

Plaspy can receive and interpret reporting from VT111 devices so location, alarms, and remote control commands are visible inside the platform. Plaspy automatically detects many tracker protocols and provides a unified interface for monitoring and issuing control commands.

- Live location points and history playback displayed on Plaspy maps for route and speed review
- Alarm events such as movement, geo-fence breaches, over-speed, and power loss surfaced in the Plaspy event feed
- Remote immobilization commands can be sent through Plaspy when the device and installation support power or fuel cut control
- Device status including backup battery and external power alerts shown in device details within Plaspy
- VT111 devices can be configured to report into Plaspy servers; Plaspy accepts common tracker connections and will detect the device protocol automatically

## Typical Use Cases

- Fleet vehicle tracking for route monitoring and operational oversight
- Anti-theft monitoring for private cars, taxis, and light commercial vehicles
- Remote immobilization for stolen vehicle recovery when supported by the installed VT111 variant
- Geofencing to enforce area access or to trigger alerts when a vehicle leaves an assigned zone
- Low-profile installations where a small, easy to conceal tracker is preferred
- Rental or shared vehicle monitoring to capture movement and event history

## Feature Availability Notes

- Some features are optional and depend on the specific VT111 hardware variant or additional modules such as RFID or anti-robbery switches
- Firmware version and manufacturer configuration can change behavior for alarms, reporting intervals, and command handling
- Installation choices affect availability of vehicle inputs like ACC or door signals and the ability to perform remote power cut
- SMS versus GPRS reporting availability may vary by region and SIM provider; network services affect reporting reliability
- For the most accurate device capabilities confirm the exact model configuration and firmware with the manufacturer

## Why Use Plaspy with These Features

Using the VT111 with Plaspy centralizes location and event information so organizations gain consistent visibility across vehicles and devices. Plaspy collects tracking points, surfaces alarms, and provides a platform for remote commands and event review, reducing the operational overhead of managing many individual trackers.
