# TopShine - PT30 Features

This page provides a public feature summary for the TopShine PT30 and explains how those capabilities relate to using the device with Plaspy. The content focuses on practical, non-sensitive information about what the PT30 can do and how Plaspy can present and use those data points for monitoring and operational oversight.

Exact feature availability and behavior for any individual PT30 unit can vary depending on firmware version, hardware revision, the type of installation or accessories used, and manufacturer implementation choices. Always verify critical details against the manufacturer documentation for the specific device and firmware you have.

## Feature Overview

The PT30 is a compact, power saving personal tracker intended for straightforward location and safety use via SMS or GPRS. It targets people tracking and small asset or pet monitoring with a set of user-oriented functions that emphasize portability, basic alerts, and offline logging.

- Real time and on demand location reporting over GPRS or SMS for flexible monitoring
- Supports TCP and UDP reporting which allows integration with server platforms like Plaspy
- SOS panic button and two way conversation to support emergency notification and remote voice contact
- Geo fence and speeding alerts for boundary and speed awareness
- Large on device logging capacity with support for 10,000 plus stored waypoints for offline tracking
- Compact, no installation required design with backup battery and sleep mode for extended use

## Core Features of TopShine - PT30

- Power saving GPS tracking designed for personal and small asset use
- Dual reporting methods: SMS based position queries and GPRS for continuous reporting
- Network protocol support for TCP and UDP to transmit location data
- Real time tracking capability intended to work with web platforms for live position visibility
- Two way conversation capability for remote voice contact with the device
- SOS panic button to send an alert in emergencies
- Built in backup battery and sleep mode to preserve operation when main power is unavailable
- On device position logging with large waypoint capacity and Google Maps URL support via SMS

## How These Features Work with Plaspy

Plaspy collects and displays location and event data reported by compatible trackers. When a PT30 is configured to send data via GPRS using TCP or UDP, Plaspy can receive those reports and present them in the platform for monitoring and historical review.

- Live location visualization on Plaspy maps when the device sends GPRS position updates
- Event visibility for SOS, geo fence, and speeding alerts so operators can respond to important conditions
- Historical route and position history in Plaspy driven by periodic reporting or uploaded device logs
- Plaspy automatically detects supported tracker protocols to ease integration
- Devices can be configured to report into Plaspy using the platform server addressing and supported transport modes

## Typical Use Cases

- Keeping intermittent or continuous location awareness for children, elderly family members, or tourists
- Portable asset tracking where simple, no installation monitoring is required
- Pet tracking for monitoring location and receiving alerts if the animal leaves a defined area
- Personal safety devices for lone workers or travelers who may need SOS notification and voice contact
- Short term deployments where compact and battery backed tracking is needed without vehicle wiring

## Feature Availability Notes

- Some features such as specific alert behavior and voice call handling can vary by firmware version
- Hardware revisions and regional variants can change available functions or button labeling
- SMS based features depend on cellular service and may behave differently than GPRS reporting
- On device logging capacity and the method of retrieving stored waypoints can depend on manufacturer firmware and settings
- For configuration and the most up to date feature set consult the manufacturer documentation

Using Plaspy with a TopShine PT30 provides a simple path to consolidate location and alert data from the tracker into a single monitoring platform. Plaspy focuses on making real time positions, event alerts, and historical routes visible to operators so teams can maintain situational awareness and respond when needed.
