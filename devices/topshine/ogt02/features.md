# TopShine - OGT02 Features

This page provides a public feature overview for the TopShine OGT02 OBD2 GPS tracker and how those capabilities are used within Plaspy. It is intended to summarize the device's main, user‑facing functionality as reported by the manufacturer and to explain practical uses when the OGT02 is connected to Plaspy for centralized tracking and reporting.

Exact feature availability and behavior can vary by firmware version, hardware revision, vehicle OBD implementation, and installation method. For device specific technical details, firmware changes, and the latest manufacturer guidance consult the official TopShine documentation.

## Feature Overview

The OGT02 is a plug‑and‑play OBD‑II form factor tracker designed for quick deployment and continuous telematics reporting. It combines cellular connectivity, high precision GPS, and a built‑in accelerometer with OBD telemetry to deliver location, movement detection, and vehicle data into Plaspy for monitoring and reporting.

- Instant OBD‑II plug in installation for fast rollout without wiring or professional installation
- 4G cellular connectivity with fallback to 2G/3G and support for GPRS and SMS reporting modes
- High precision GPS positioning for real time location and historical track playback
- Built in accelerometer for movement and sudden event detection to support alerts
- OBD telemetry including odometer and diagnostic PIDs where the vehicle exposes them
- Historical track playback capability up to 180 days for trip reconstruction and audits

## Core Features of TopShine - OGT02

- Plug and play OBD‑II installation that requires no hardwiring
- 4G cellular communication with compatibility across 2G and 3G networks
- GPRS and SMS working modes for flexible data uplink options
- High precision GPS receiver for continuous location reporting
- Built in accelerometer for displacement and impact related event detection
- OBD based telemetry such as odometer reporting and vehicle diagnostic PIDs where supported
- Historical route storage and playback up to 180 days for review and compliance
- Compact, certified design intended for in‑vehicle deployment

## How These Features Work with Plaspy

When connected to Plaspy, the OGT02 reports location, movement events, and available OBD telemetry so fleet managers and vehicle owners can monitor assets in real time and review historical data. Plaspy automatically detects supported tracker protocols and ingests the device data for mapping, alerts, and reporting.

- Real time position updates displayed on Plaspy maps for live vehicle tracking and route monitoring
- Movement and sudden event alerts from the accelerometer surfaced in Plaspy notifications and event feeds
- OBD telemetry such as odometer readings and supported PIDs presented in Plaspy vehicle reports where available
- Geofence and displacement alarms configured in the device and processed by Plaspy for manager notifications
- Historical track playback accessible through Plaspy for trip reconstruction and compliance review
- Plaspy server domain recognition and automatic protocol detection simplify onboarding of compatible OGT02 units

## Typical Use Cases

- Fleet management for visibility into vehicle locations, trips, and odometer data
- Anti‑theft monitoring using movement and displacement alerts for rapid response
- Rental and car sharing operations where plug‑and‑play installation accelerates onboarding
- Remote diagnostics and vehicle health monitoring using OBD telemetry where the vehicle provides PIDs
- Compliance and route verification through historical track playback and trip reports

## Feature Availability Notes

- Firmware versions and hardware revisions can enable or alter specific features and behaviors
- Available OBD telemetry depends on vehicle make, model, and the OBD PIDs the vehicle exposes
- Network availability and regional cellular support affect 2G/3G/4G connectivity and data reporting
- Some device capabilities such as alarm behavior and historical storage windows depend on device configuration and provider settings
- Check the manufacturer documentation for details about certifications, supported bands, and environmental ratings

The OBD‑II form factor and integrated sensors provide the core inputs Plaspy needs for live tracking, event alerts, and historical reporting so teams can monitor assets, investigate incidents, and streamline fleet operations.
