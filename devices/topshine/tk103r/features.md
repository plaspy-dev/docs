# TopShine - TK103R Features

This page describes the public feature context for using the TopShine TK103R with Plaspy. It summarizes the tracker and car alarm capabilities that are relevant to Plaspy users, explains how those capabilities map to monitoring and control inside the Plaspy platform, and highlights practical operational value without delving into private or device specific configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation wiring, regional model differences, and manufacturer implementation. The content below is grounded in the TK103R public feature description and is intended to help you understand what to expect when the device is used with Plaspy.

## Feature Overview

The TopShine TK103R combines GPS tracking with integrated car alarm functions and driver identification via an active RFID kit. In practical terms the device focuses on continuous location awareness, vehicle security events, and remote control options that can be surfaced in a tracking platform like Plaspy.

- Real time location reporting with both GPS and cellular positioning system CPS for improved coverage
- Automatic arm and disarm using RFID tags or remote control, reducing the need for multiple remotes
- Alarms for ACC on, door open, movement, geo fence breach, and over speed for theft and misuse detection
- Remote actions such as power or fuel supply cutoff triggered by SMS or a compatible tracking platform
- Backup battery and external power failure alerts to keep monitoring active during tampering or power loss

## Core Features of TopShine - TK103R

- GPS positioning plus cellular positioning system CPS to provide location information when GPS is limited
- Active RFID driver identification with automatic arm and disarm functionality
- Compatibility with original car remote to lock and unlock the vehicle using the factory fob
- Multiple alarm inputs and alerts including ignition status, door open, movement detection, geo fence, and over speed
- Auto tracking by SMS or GPRS with configurable time interval or distance reporting
- Remote cutoff of power or fuel supply via SMS or when controlled through a compatible tracking center
- Built in rechargeable backup battery and external power failure notification
- Voice monitoring and an anti robbery switch to send a help SMS in high risk situations

## How These Features Work with Plaspy

Plaspy can receive the TK103R position reports, alarms, and event messages and present them in a consolidated view for monitoring and operational oversight. Plaspy also supports issuing commands to compatible devices when the device and platform integrations allow.

- Real time location and historical track playback of GPS and CPS reports inside Plaspy
- Event visibility for alarms such as door open, ignition on, movement, geo fence breaches, and over speed
- Driver identification events from RFID tags shown as part of trip and usage logs where available
- Remote control actions supported when the device and platform integration expose them, such as remote arm/disarm or power cutoff
- Plaspy automatically detects supported tracker protocols and accepts device connections to the platform endpoint d.plaspy.com using standard TCP or UDP transport on the shared port used by Plaspy

## Typical Use Cases

- Personal vehicle security with remote arm/disarm and theft alerts
- Fleet tracking and oversight with periodic reporting and event alarms for drivers and vehicles
- Rental and car sharing operations that need driver identification and activity logs
- Stolen vehicle response workflows using movement alerts and remote power cutoff where supported
- Valet or service vehicle monitoring to track ignition and door events
- Anti hijack or emergency alerting using the device anti robbery switch and voice monitoring feature

## Feature Availability Notes

- Feature sets depend on firmware and hardware revision; not every factory unit or regional model will offer identical behavior
- Some functions such as remote power cutoff, voice monitoring, and Google Maps SMS links require correct installation, carrier SMS/GPRS service, and platform support
- Compatibility with an original car remote depends on the vehicle remote system and how the tracker is integrated during installation
- RFID driver ID and automatic arm/disarm behavior can vary with the supplied RFID kit and how tags are programmed
- Always confirm which features are active on your specific unit and firmware before relying on a feature for security critical workflows

## Why Use Plaspy with These Features

Using the TK103R with Plaspy gives organizations a single platform to monitor location, receive security alerts, and manage operational events from the tracker. Plaspy consolidates position reports, alarm events, and driver identification data so fleet managers and vehicle owners can maintain situational awareness, review historical activity, and act on alerts from a central interface.
