# TopShine - CA02 Features

This page describes the public feature context for using the TopShine CA02 with the Plaspy platform. It focuses on the CA02 capabilities that are relevant to Plaspy users and fleet operators, explaining how the device reports location and alarm telemetry and what functionality you can expect to see in Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional network conditions and the manufacturer implementation. Use this page as a high level feature guide and consult the official TopShine documentation for the definitive device details.

## Feature Overview

The CA02 is an in dash GPS tracker with integrated vehicle security features designed for passenger cars and light commercial vehicles. It combines audible alarm functions and tamper detection with real time GPS reporting and relay outputs for immobilization, enabling centralized monitoring and remote control through Plaspy.

- Real time GPS tracking for live location and historical route playback when used with Plaspy.
- Integrated siren and shock sensor for audible alarms and tamper detection at the vehicle.
- Central locking and trunk control commands available via platform, SMS or app controls.
- Relay driven engine or oil cut off for remote immobilization when activated.
- Geofence, overspeed and movement alarms delivered as events for situational awareness.
- Optional expansion modules such as fuel monitoring and external microphone when fitted.

## Core Features of TopShine - CA02

- Real time GPS location reporting and historical route playback compatibility.
- Built in siren and shock sensor to detect impact or tampering and trigger audible alerts.
- Central locking control and remote trunk open support for convenient vehicle access management.
- Relay outputs for engine or oil cut off to provide remote immobilizer capability.
- Geofence and overspeed alarm reporting as standard event types.
- GSM jamming detection and alarm reporting to support anti theft workflows.
- Support for optional expansions such as fuel monitoring and external microphone where installed.

## How These Features Work with Plaspy

When installed and configured to report to Plaspy, the CA02 sends location updates and alarm events to the platform so fleet managers and vehicle owners can monitor status and respond to incidents from a single interface.

- Live location updates and route history appear in Plaspy for tracking and playback.
- Alarm events such as shock sensor triggers, door open and movement are delivered to Plaspy for immediate notification.
- Geofence breaches and overspeed events can be shown as alerts inside the Plaspy dashboard and mobile apps.
- Relay based immobilizer commands can be sent from Plaspy or via supported control methods to the CA02 when remote engine cut off is required.
- Optional telemetry from expansion modules will be presented in Plaspy when those modules are fitted and reporting.

## Typical Use Cases

- Fleet anti theft protection using shock detection, siren activation and remote immobilizer controls.
- Real time vehicle monitoring and route playback for passenger cars and light commercial fleets.
- Parked vehicle security with tamper alerts and audible deterrence combined with geofence monitoring.
- Remote access and convenience operations such as central locking and trunk release from a platform or mobile device.
- Integrated fleet oversight where optional fuel monitoring is required alongside GPS and alarm telemetry.

## Feature Availability Notes

- Feature behavior depends on firmware and hardware revision; some alarms or optional functions require specific firmware releases.
- Optional expansions such as fuel monitoring or external microphone require additional hardware and specific installation.
- Installation type matters for some features for example wiring to relay outputs and central locking interfaces must be performed by a qualified installer.
- The CA02 uses 2G GSM for cellular connectivity as specified by the manufacturer; network availability and regional regulations can affect service.
- Check TopShine documentation for regional model variants and supported frequency bands or options.

Pairing the TopShine CA02 with Plaspy gives organizations centralized visibility over vehicle location, alarms and immobilizer controls. Plaspy collects and presents the CA02 telemetry so managers can see live positions, receive incident alerts and apply remote controls from the same platform used for other fleet assets.
