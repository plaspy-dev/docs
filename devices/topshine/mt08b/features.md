# TopShine - MT08B Features

This page provides a public feature overview of the TopShine MT08B portable motorcycle GPS tracker and explains how its capabilities map into Plaspy for live tracking, alerts, and reporting. Content here focuses on practical, non sensitive descriptions of what the device can do and how those functions are surfaced when used with Plaspy.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and manufacturer implementation. The summary below is based on the MT08B model description and lists features that are commonly present; consult the official manufacturer documentation for the most current device specific details.

## Feature Overview

The TopShine MT08B is a compact, waterproof GPS tracker designed for discreet motorcycle and small vehicle installations. It reports position and status over global GSM networks using SMS or GPRS, and provides a set of security and fleet management features that are useful for live monitoring and historical analysis in Plaspy.

- Compact matchbox sized enclosure suitable for concealment on motorcycles and small vehicles
- Real time location reporting via GSM using SMS or GPRS for live map tracking
- Motion detection and geo fence alerts for anti theft monitoring
- Power cut notifications and internal backup battery to continue reporting after mains loss
- Configurable inputs and an output to report or control external vehicle signals
- Two way listen in and SOS support for emergency attention and voice monitoring

## Core Features of TopShine - MT08B

- Real time tracking over GSM networks using SMS or GPRS for integration with Plaspy
- High sensitivity GNSS positioning using SIRF Star III chipset with consumer grade accuracy
- Motion detection for movement triggered alerts and event reporting
- Geo fence and over speed alert capabilities for perimeter and speed based notifications
- Power cut reporting and an internal backup battery to maintain tracking after power loss
- Two configurable inputs and one output to report status or accept simple remote control
- Remote engine immobilizer support for disabling vehicle engine when configured
- SOS signaling and two way listen in for emergency and voice monitoring scenarios

## How These Features Work with Plaspy

When the MT08B is connected to Plaspy, location and status messages sent by the device are processed to provide map views, alerts, and historical data. Plaspy displays events and telemetry so operators can monitor devices and respond to security or operational incidents.

- Live map position updates and movement history based on device location reports
- Security alerts such as geo fence breaches, motion triggers, overspeed, and power loss visible in Plaspy
- I O state and input events shown in device activity logs for remote monitoring
- SOS events and recorded listen in attempts logged and available for operator review
- Historical reports and timelines for route reconstruction and incident investigation

## Typical Use Cases

- Motorcycle anti theft protection using motion detection, power cut alerts, and remote immobilizer
- Small vehicle and courier fleet tracking for location visibility and route history
- Rental or shared vehicle monitoring with geo fence enforcement and event logging
- Remote status monitoring of doors or engine state using configurable inputs
- Emergency response and rider safety monitoring using SOS signaling and two way listen in

## Feature Availability Notes

- Firmware variations can enable or disable specific alert types and I O behavior; check your device firmware version
- Hardware revisions or regional variants may differ in supported GSM bands and accessory wiring
- Installation method and the quality of power or antenna placement will affect GNSS performance and alert reliability
- Some manufacturer functions are configurable only via the vendor command set or platform and may require setup to work with Plaspy
- Always review the device user manual and vendor documentation for configuration commands and wiring diagrams
