# TopShine - GT103

![GT103](./tracker.jpg)

The GT103 Anti-Theft GPS Vehicle Tracker is a Plaspy compatible, cost-effective GPS tracker designed for cars, trucks, buses and fleet management. Built for reliable real-time tracking and vehicle security, the GT103 combines smart RFID driver identification, a built-in SOS panic button, and a remote engine cut-off relay to deliver practical anti-theft and fleet protection features that integrate directly with Plaspy’s platform.

The GT103 uses 2G GPRS connectivity and a u-blox7 GNSS chip for fast GPS positioning and telemetry. With two-way voice capability, ACC detection for ignition status, geo-fence and over-speed alarms, and full certifications \(FCC, CE, RoHS\) along with a legal IMEI code, the GT103 is optimized for fleet management, asset protection and on-demand security workflows via Plaspy’s web and mobile interfaces.

## Key Highlights

- Plaspy compatible GPS tracker offering real-time tracking and vehicle telemetry over 2G GPRS for web, Android and iOS access.
- Anti-theft functionality with smart RFID driver identification and a remote engine cut-off relay \(immobilizer\) for secure vehicle control.
- Built-in SOS panic button, wiretapping / two-way voice communication \(microphone and speaker\) and motion sensor for immediate incident response.
- Essential fleet alarms: over-speed alerts, geo-fence notifications and ACC detection for ignition on/off status.
- Compact form factor with backup battery and durable operating range \(-20°C to 75°C, 5%–95% humidity\) suitable for vehicle environments.
- Fast GPS performance using u-blox7, with positioning accuracy around 10 meters \(2D RMS\) and high GPS sensitivity \(-159 dB\).
- Certified and compliant: FCC, CE and RoHS with a legal IMEI code — suitable for commercial fleet deployments and large monthly supply orders.

## How It Works with Plaspy

Integration with Plaspy is straightforward: the GT103 sends location and status data over 2G GPRS to Plaspy’s servers \(with SMS as a fallback option\). Plaspy ingests the device’s telemetry — including GPS coordinates, ACC/ignition status, SOS alarms, geo-fence and over-speed events — and displays them on the Plaspy web portal and mobile apps for real-time monitoring, alerts and historical reports.

- Real-time location and telemetry updates via 2G GPRS \(with SMS fallback where supported\).
- Ignition \(ACC\) detection for accurate engine on/off tracking and driver behavior analysis.
- SOS alarm and motion sensor events delivered as immediate alerts to Plaspy users and administrators.
- Remote immobilizer capability: Plaspy can send control commands \(via GPRS/SMS when supported\) to trigger the GT103’s engine cut-off relay for anti-theft response.
- Two-way voice / wiretapping and microphone support are logged and available as part of the incident workflow when used alongside Plaspy’s incident management features.
- Fuel monitoring and external sensor telemetry can be consolidated in Plaspy when third-party fuel sensors are integrated; the GT103 provides core telemetry and I/O to support expanded fleet monitoring solutions.
- Note on Bluetooth sensors: the GT103 does not include BLE sensor support out of the box, but Plaspy supports BLE devices for extended telemetry when a BLE-capable tracker is deployed in parallel.
