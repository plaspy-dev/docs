# TopShine - GT103 Features

This page provides a public feature overview for the TopShine GT103 and how its capabilities are used with Plaspy for fleet tracking, anti-theft workflows, and vehicle monitoring. It focuses on the practical functions visible to fleet managers and administrators when the GT103 is integrated with Plaspy’s platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device-specific configuration steps, firmware notes, and the latest technical details consult TopShine’s official documentation.

## Feature Overview

The GT103 is a cost-effective vehicle tracker that combines real-time GPS positioning, anti-theft controls, and driver identification features designed for cars, trucks, buses, and fleet operations. When paired with Plaspy the device provides location visibility, alarm forwarding, and remote control options to support security and operational workflows.

- Real-time GPS tracking and position updates over cellular data for live map visibility and route history.
- Anti-theft controls including RFID driver identification and a remote engine cut-off relay to support immobilization workflows.
- Immediate incident signaling via built-in SOS panic button and motion-triggered alerts for rapid response.
- Vehicle state inputs such as ACC (ignition) detection and over-speed and geo-fence alarms for driver and route monitoring.
- Two-way voice capability for on-the-ground communication and event verification when used alongside Plaspy incident features.

## Core Features of TopShine - GT103

- Real-time GPS positioning and telemetry suitable for continuous fleet tracking and historical playback.
- 2G GPRS connectivity for sending location and status updates to a backend platform.
- Smart RFID driver identification to associate drivers with vehicle trips and events.
- Built-in SOS panic button for immediate alerting of critical incidents.
- Remote engine cut-off relay (immobilizer) to support anti-theft responses when authorized and configured.
- ACC detection to report ignition on/off state and help distinguish driving from parked periods.
- Geo-fence and over-speed alarm generation for perimeter and speed compliance monitoring.
- Two-way voice support (microphone and speaker) to enable communication and incident verification.

## How These Features Work with Plaspy

When the GT103 is registered in Plaspy, the device’s location and event telemetry are ingested into the Plaspy platform so teams can monitor assets from the web and mobile interfaces. Plaspy consolidates the tracker’s signals into map views, alerts, and historical reports for operational oversight.

- Live location and trip playback shown on Plaspy maps and dashboards for vehicle visibility.
- Alarm events such as SOS, geo-fence breaches, and over-speed triggers forwarded to Plaspy alerting for immediate notification.
- Ignition (ACC) status reported to Plaspy to support trip segmentation, engine on/off reporting, and fuel or driver behavior analysis workflows.
- RFID driver ID events reflected in Plaspy logs to help link drivers with trips and events for auditing and compliance.
- Remote immobilizer and control commands can be coordinated through Plaspy where supported, enabling administrators to act on theft incidents or unauthorized use.

## Typical Use Cases

- Fleet operations tracking: monitor vehicle locations, route history, and ignition events to support dispatch and scheduling.
- Anti-theft protection: detect unauthorized movement, use RFID-based driver ID, trigger SOS alerts, and immobilize a vehicle when needed.
- Driver safety and incident response: use the SOS button and two-way voice to verify incidents and coordinate assistance.
- Geo-fence enforcement and compliance: generate alerts when vehicles enter or leave defined areas for route adherence.
- Asset protection for trailers and equipment: discreet installation and motion alerts to detect unexpected movement.

## Feature Availability Notes

- Firmware and hardware revisions can change the exact behavior or set of supported features; confirm the device firmware level before relying on a specific capability.
- Some functions such as remote immobilization, two-way voice, or SMS fallback depend on regional cellular support and how the unit is installed and configured.
- Accessories and wiring (for example external antennas, relay wiring, and RFID components) affect the final feature set available after installation.
- Regional product variants or carrier limitations may affect 2G connectivity and related telemetry delivery.
- Plaspy can ingest the GT103’s telemetry, but administrators should validate event definitions and alarm thresholds in the platform to match operational needs.

Using the GT103 together with Plaspy gives organizations centralized visibility and a unified interface for both tracking and anti-theft responses. Plaspy aggregates the device’s GPS positions, driver identification events, alarms, and status signals into dashboards and alert flows that help teams react faster and manage larger fleets more effectively.
