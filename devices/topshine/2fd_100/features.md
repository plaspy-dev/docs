# TopShine - 2FD-100 Features

This page provides a public feature summary for the TopShine 2FD-100 as used with Plaspy. It explains the device capabilities that are relevant when the tracker is configured to report to Plaspy, how those capabilities are experienced in a fleet or vehicle security workflow, and which features are commonly used for monitoring and remote management within the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, optional accessories, and manufacturer implementation. The 2FD-100 is described as a two way OBD2 GPS tracker and smart 4G car alarm that combines GPS and GSM positioning, alarm inputs and outputs, a mobile WiFi hotspot, and two way voice to support real time tracking and vehicle security. For the most current device specific details consult the manufacturer documentation.

## Feature Overview

The 2FD-100 is designed as an integrated tracking and alarm unit for professional vehicle security and fleet deployments. When used with Plaspy it provides position updates, alarm reporting, and remote control capability where enabled, while also supporting passenger WiFi and camera connectivity for richer monitoring.

- Real time GPS tracking and position reporting for vehicle visibility and route playback.
- Integrated car alarm functions and digital inputs for crash, overspeed, movement detection, and geofence events.
- Two way voice communication plus support for multiple WiFi cameras to enable remote audio and visual monitoring.
- OBD2 form factor and wiring harness options for vehicle integration and telemetry access.
- Optional immobilizer and remote control functions such as lock unlock, trunk release, and ignition control where enabled.

## Core Features of TopShine - 2FD-100

- Two way OBD2 GPS tracker combined with a smart 4G car alarm for unified tracking and vehicle security.
- GPS and GSM positioning via an independent GSM GPS module with a lawful IMEI and support for external antenna connections.
- Mobile WiFi hotspot and support for multiple IP cameras to enable in vehicle internet access and remote camera monitoring.
- Two way voice capability for live audio communication between the vehicle and monitoring operators.
- Alarm inputs and outputs with comprehensive anti theft features including crash alarm, overspeed alarm, geofence alerts, movement detection, and optional SOS panic support.
- Remote control functions such as remote lock unlock, trunk release, ignition status reporting, and optional engine cut off immobilizer where configured.
- Expandable with optional accessories including siren, vibration or crash sensors, ultrasonic or cutable fuel sensors, and optional internal battery backup.

## How These Features Work with Plaspy

When the 2FD-100 is configured to report to Plaspy, the device transmits location, event, and status information to the platform so fleet managers and operators can monitor vehicles in real time and review historical activity.

- Live location and history playback within Plaspy for route analysis and vehicle tracking.
- Alarm and event reporting such as crash, overspeed, geofence, and movement detection surfaced as platform events and notifications.
- Remote command and control where the tracker supports remote functions, enabling operators to send supported commands from the Plaspy interface.
- Integration of optional telemetry such as fuel level sensors and external inputs displayed in Plaspy when those accessories are installed and configured.
- Visibility into WiFi camera presence and two way audio capability as part of vehicle monitoring workflows when camera hardware is paired with the tracker.

## Typical Use Cases

- Fleet management for location visibility, dispatching, and route auditing across mixed vehicle types.
- Anti theft protection and recovery using alarms, geofence alerts, and optional remote immobilization.
- Rental and leasing operations that require remote monitoring, geofence enforcement, and incident reporting.
- Passenger and VIP transport where in vehicle WiFi and camera monitoring improve comfort and safety.
- Fuel monitoring and loss detection by integrating optional ultrasonic or cutable fuel sensors.
- Rapid deployment scenarios that leverage the OBD2 form factor or wiring harness installation for fast installation.
