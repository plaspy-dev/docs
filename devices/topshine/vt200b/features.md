# TopShine - VT200B Features

This page provides a public feature overview of the TopShine VT200B GPS tracker and how its capabilities map to monitoring and fleet workflows in Plaspy. It summarizes the VT200B functions relevant to real time location, event reporting, driver identification, and external sensor telemetry when used with a Plaspy fleet account.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional product variant, and manufacturer configuration. For device specific technical details, firmware notes, and installation guidance refer to the official TopShine documentation and release notes.

## Feature Overview

The VT200B is a vehicle grade tracking terminal designed for professional fleet and anti theft use. It combines high sensitivity GNSS positioning with quad band GSM connectivity, an internal offline data logger, and multiple alarm and input options to support continuous tracking and event reporting.

- Real time location reporting over cellular networks with SMS fallback and data logging for offline continuity.
- Internal logger that stores more than 10,000 records and uploads stored data when network access is restored.
- Built in alarm and anti theft functions including SOS panic reporting, geo fence and remote engine cut off functionality.
- Driver identification options using Bluetooth and RFID to attribute trips to individual drivers.
- Support for external sensors such as temperature, crash, and fuel sensors to extend telemetry capabilities.

## Core Features of TopShine - VT200B

- High sensitivity GNSS receiver for reliable position fixes and route telemetry.
- Quad band GSM connectivity supporting SMS and GPRS data reporting.
- Internal data logger with multi thousand record capacity for offline continuity.
- SOS panic button and programmable alarm inputs for emergency and anti theft alerts.
- Remote engine cut off and external power cut off alarm support for theft response workflows.
- Bluetooth and RFID driver identification options for driver attribution.
- Inputs for external sensors including temperature, crash, and fuel monitoring where sensors are installed.
- Rugged automotive power input range and backup battery for continued operation during power interruptions.

## How These Features Work with Plaspy

When the VT200B is connected and reporting, Plaspy ingests position, status, and sensor inputs to provide live tracking and historical reporting. The device's offline logger and event outputs help Plaspy present continuous histories and timely alerts for operational decision making.

- Live map positions and real time vehicle traces shown in Plaspy dashboards.
- Historical tracks restored automatically after logger uploads when connectivity returns.
- Event notifications for SOS, geo fence entry and exit, over speed and power loss visible in Plaspy alert streams.
- Driver ID records from Bluetooth or RFID mapped to trips for driver accountability and reporting.
- External sensor readings such as temperature or fuel status available in telemetry views where those sensors are installed and reporting.

## Typical Use Cases

- Centralized fleet tracking for route visibility, schedule verification, and asset location.
- Anti theft deployments using SOS alerts, geo fence monitoring, and remote engine cut off for recovery workflows.
- Refrigerated transport or temperature sensitive cargo monitoring when a temperature sensor is attached.
- Bulk fuel monitoring and inventory oversight when external fuel sensors are integrated.
- Driver identification and trip attribution for payroll, compliance, or behavior analysis across mixed fleets.
- Mixed vehicle fleets that require compact, vehicle grade installation and continuous logging.

## Feature Availability Notes

- Some features require specific firmware builds or optional hardware options such as external sensors, RFID modules, or Bluetooth modules.
- Installation choices and wiring influence alarm functions like remote engine cut off and external power cut off alarm behavior.
- Regional cellular support and regulations affect GSM service availability; device radio bands and local network support should be confirmed.
- Manufacturer firmware updates and hardware revisions can add, modify, or remove capabilities compared to earlier units.
- Review TopShine documentation for sensor wiring, input/output configuration, and recommended installation practices.

Using the VT200B with Plaspy centralizes vehicle position, events, and sensor telemetry into a single platform so operators can monitor fleets, investigate incidents, and maintain operational continuity when networks are interrupted. The combination of an internal logger and real time reporting helps preserve history while enabling immediate alerts for theft, power loss, or emergency events.
