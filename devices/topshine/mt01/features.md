# TopShine - MT01 Features

This page provides a public feature overview of the TopShine MT01 GPS vehicle tracker and explains how those features are used with Plaspy for tracking, telemetry, and event monitoring. It focuses on practical, non-sensitive capabilities and how the device integrates into Plaspy workflows so fleet managers and integrators can understand what to expect from a Plaspy compatible installation.

Exact feature availability and behavior can vary by device firmware, hardware revision, optional accessories, installation method, and manufacturer implementation. For the most current and device specific technical details consult the official TopShine documentation and your supplier before deployment.

## Feature Overview

The MT01 is a compact, weatherproof 4G tracker designed for vehicle and fleet use with integrated telemetry and optional sensor support. It is intended to maintain real-time visibility, preserve trace data during coverage gaps, and provide inputs for safety and anti-theft workflows that Plaspy can surface in dashboards and alerts.

- Real-time GPS tracking with persistent reporting for live map views and route playback in Plaspy.
- Wide input voltage support suitable for a variety of vehicle electrical systems, reducing the need for specialized power modifications.
- Built-in flash data logger to store location and event data when cellular coverage is intermittent and upload later to Plaspy.
- Smart inputs and optional sensor compatibility for fuel monitoring, driver safety sensors, and anti-theft immobilizer control.
- Compact weatherproof housing and small form factor for concealed installations across motorcycles, cars, trucks, and e-bikes.
- Two-way remote command support and event reporting to enable remote configuration and immobilizer actions when integrated with Plaspy.

## Core Features of TopShine - MT01

- Multi band cellular connectivity with 2G 3G and 4G support for broad regional coverage.
- Wide voltage input range to support common vehicle electrical systems and heavy duty fleets.
- Integrated GPS receiver for position fixes with onboard GNSS performance suited for vehicle tracking.
- 4 MB flash data logger that preserves GPS and event data during short term connectivity loss.
- Built in backup battery to maintain reporting and safe shutdown behavior when external power is interrupted.
- Smart inputs, relay output and accessory interfaces for optional fuel sensors, RFID or iButton identification, and external alarms.
- SOS panic button and anti theft functions including remote engine cut off via the immobilizer relay.
- Compact weatherproof enclosure rated for harsh operating temperatures suitable for outdoor vehicle use.

## How These Features Work with Plaspy

When the MT01 is installed and connected, it reports location, status, and events to Plaspy where they become visible to operators and automated workflows. Plaspy ingests device reports and presents them as live positions, event alerts, and historical traces while allowing remote commands and configuration changes from the platform.

- Live location updates and route playback in Plaspy mapping and history tools for operational visibility.
- Event alerts such as SOS panic, external power loss, and configured sensor events routed to Plaspy notifications and logs.
- Fuel sensor and other optional sensor data appear in Plaspy when a compatible accessory is connected and configured.
- Remote immobilizer commands and confirmations are handled through two way device reporting and shown in Plaspy event timelines.
- Offline logger uploads restore missing trace segments to Plaspy after temporary GSM coverage loss to maintain continuous history.
- Device reporting cadence, alarm thresholds, and power saving behaviors can be adjusted via Plaspy remote configuration where supported by the firmware.

## Typical Use Cases

- Centralized fleet tracking and route playback for mixed fleets that include motorcycles, cars, trucks, and e bikes.
- Anti theft monitoring with remote engine cut off, external power cut alarms, and SOS panic handling.
- Fuel monitoring and theft prevention when a compatible fuel sensor is connected to the MT01 inputs.
- Driver safety and compliance setups using optional alcohol or crash sensors and identification peripherals.
- Installations requiring compact, weatherproof hardware and integrated data logging to handle intermittent coverage.
- Asset tracking for vehicles operating across regions with multi band cellular requirements.

## Feature Availability Notes

- Some functions depend on device firmware and may require a specific firmware version to enable remote commands or certain sensor integrations.
- Optional sensors and accessories such as fuel sensors, alcohol sensors, RFID, or camera options are not always included and may vary by supplier or regional variant.
- Hardware revisions or regional models may differ in supported cellular bands, connector options, or bundled accessories.
- Installation method impacts available features for alarms and immobilizer control because wiring and accessory mounting are performed onsite.
- Always verify supported features and configuration procedures with the manufacturer documentation and your device supplier.

## Why Use Plaspy with These Features

Combining the MT01 hardware with Plaspy gives organizations a straightforward path to vehicle visibility, event driven alerts, and historical reporting. Plaspy aggregates the tracker reports into unified dashboards, supports remote configuration where the firmware permits it, and provides event and alarm workflows to help operations teams respond to incidents faster.
