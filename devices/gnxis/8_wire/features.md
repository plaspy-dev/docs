# Gnxis - 8-wire Features

This page provides a public feature summary for the Gnxis 8-wire GPS tracker and explains how its capabilities are used with Plaspy for real time tracking and alerting. It focuses on practical, non-sensitive details about what the device can report and how that information appears in a fleet or vehicle monitoring workflow.

Exact feature availability and behavior can vary by the device firmware, hardware revision, installation wiring, and the manufacturer implementation. Where optional features are mentioned, they may require specific wiring, configuration, or manufacturer options to be active.

## Feature Overview

The Gnxis 8-wire is positioned as a compact vehicle tracker for private cars, commercial fleets, and motorcycles that offers live location, motion and power alerts, and configurable behaviors to reduce power use while parked. It supports common cellular networks to maintain connectivity and includes internal antennas for straightforward installation.

- Real time tracking and live monitoring through supported platforms and mobile apps
- Ignition and movement alarms to detect start and stop events
- Speeding and ACC detection alerts for operational oversight
- Angle based location updates to refresh position when heading changes
- Power off alarm that notifies if external power is disconnected
- Optional remote fuel or electricity cut off capability where provided by the manufacturer

## Core Features of Gnxis - 8-wire

- Real time GPS position reporting for live tracking on mapping platforms
- Ignition and movement detection for event based alerts and reporting
- Speeding detection to flag potential overspeed incidents
- Angle based location update logic to improve position relevance during turns
- Power off alarm to detect disconnection of external power
- Optional remote fuel or electricity cut off function as an added security measure
- Built in GSM and GPS antennas for simplified installation and placement

## How These Features Work with Plaspy

Plaspy ingests standard tracker reports and presents them as live positions and event notifications, helping operations teams keep visibility of vehicles and respond to incidents. Plaspy automatically detects many tracker protocols and accepts reports from compatible Gnxis devices without requiring protocol selection.

- Live GPS positions appear on Plaspy maps for real time location awareness
- Ignition, movement, speeding, and power off events can generate alerts and timeline entries in Plaspy
- Angle based updates translate into more frequent position updates when heading changes, improving route detail in Plaspy
- Optional remote cut off functionality is visible as a device capability when enabled and configured by the installer or manufacturer
- Gnxis devices may be configured to report using UDP or TCP to the Plaspy server domain, and Plaspy will detect the tracker protocol automatically

## Typical Use Cases

- Fleet vehicle location and route monitoring for dispatch and logistics
- Private vehicle tracking for security and family vehicle oversight
- Motorcycle tracking where compact installation and built in antennas simplify setup
- Security workflows that rely on power off and movement alerts to detect tampering
- Operational monitoring for speeding events and ignition activity across a vehicle fleet
