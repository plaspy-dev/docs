# NVS - Navitrek UM-04 Features

This page summarizes the public feature context for using the NVS Navitrek UM-04 with Plaspy. It describes the practical capabilities you can expect to use inside Plaspy for location awareness, alarm event visibility, and vehicle condition monitoring when the device reports into the platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, installation method, and the manufacturer implementation. For device specific configuration and the most current technical details consult the official manufacturer documentation and consider the installation context when evaluating which features will be visible in Plaspy.

## Feature Overview

The Navitrek UM-04 is designed to determine navigational parameters using satellite navigation signals and to exchange information with a dispatch center, offering core functionality useful for fleet visibility and event monitoring.

- Determines navigational parameters using GLONASS and GPS signals for position reporting
- Monitors vehicle condition and reports status information to a dispatch platform
- Notifies about alarm events so operators can respond to incidents
- Enables two way information exchange with a dispatch center or monitoring system
- Built for compatibility with Navionis Automated Monitoring and Control System and other monitoring software

## Core Features of NVS - Navitrek UM-04

- Satellite navigation using GLONASS and GPS to provide vehicle position and navigation parameters
- Vehicle condition monitoring capability for reporting status to a monitoring system
- Alarm event notification to alert dispatch or monitoring operators
- Information exchange channel with a dispatch center for operational coordination
- Designed compatibility with the Navionis Automated Monitoring and Control System
- Support for integration with other transport monitoring software complexes

## How These Features Work with Plaspy

Plaspy receives device reports and presents location and event data in a unified interface. Plaspy automatically detects supported tracker protocols so reported navigation and event data from the UM-04 can be mapped to features in the platform without manual protocol selection.

- Real time or periodic position updates appear on Plaspy maps for visibility and route checks
- Alarm events from the device are surfaced as notifications or timeline events inside Plaspy
- Vehicle condition indicators reported by the device are available for operator review and status dashboards
- Two way information exchange can be reflected in dispatch workflows and message logs when the device supports such reporting
- Plaspy supports standard device reporting endpoints and will accept data from devices configured to send to Plaspy, with automatic protocol detection to simplify setup

## Typical Use Cases

- Fleet location tracking for day to day route oversight and asset visibility
- Dispatch center monitoring and coordination using device event and status reports
- Rapid incident response using alarm notifications reported by the tracker
- Historical route review and operational analysis using position and event logs
- Integration into existing Navionis or other monitoring ecosystems for centralized oversight
