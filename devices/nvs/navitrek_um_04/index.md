# NVS - Navitrek UM-04

![Navitrek UM-04](./logo.jpg)

The NVS Navitrek UM-04 is a versatile car device that offers a range of features to enhance vehicle monitoring and navigation. This equipment set is designed to determine navigational parameters of a vehicle using the signals of satellite navigation systems GLONASS/GPS. It also allows for the monitoring of vehicle condition, notification of alarm events, and information exchange with a dispatch center.

The Navitrek UM-04 is specifically designed to work seamlessly with the Navionis Automated Monitoring and Control System. However, it is also compatible with other transport monitoring software complexes, providing flexibility for different monitoring needs.

Key Features:

- Determines navigational parameters using GLONASS/GPS signals
- Monitors vehicle condition
- Notifies of alarm events
- Allows for information exchange with a dispatch center
- Compatible with Navionis Automated Monitoring and Control System
- Can work with other transport monitoring software complexes
