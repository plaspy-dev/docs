# NVS - SIGNAL S-2115

![SIGNAL S-2115](./logo.jpg)

The SIGNAL S-2115 by NVS is a mobile set of equipment designed for automotive wireless alarm and monitoring. It operates on the signals of SNON GLONASS / GPS / GALILEO / SBAS, utilizing the certified receiver NV08C manufactured by ZAO KB NAVIS. This mobile kit is equipped with an open protocol of information exchange, allowing for seamless integration into any existing navigation and information systems.

Recommended for use in monitoring and dispatching systems of land vehicles, the SIGNAL S-2115 has been awarded the GLONASS / GNSS-Forum Test Certificate No. 06I-2011. This certification ensures its reliability and accuracy in providing real-time tracking and monitoring capabilities. Additionally, the package includes free transport monitoring software, making it a comprehensive solution for fleet management and vehicle tracking needs.

Key Features:

- Mobile set of equipment operating on SNON GLONASS / GPS / GALILEO / SBAS signals
- Certified receiver NV08C manufactured by ZAO KB NAVIS
- Automotive wireless alarm and monitoring system
- Open protocol of information exchange for integration into existing navigation systems
- Recommended for monitoring and dispatching systems of land vehicles
- GLONASS / GNSS-Forum Test Certificate No. 06I-2011
- Includes free transport monitoring software
