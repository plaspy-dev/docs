# NVS - SIGNAL S-2115 Features

This page provides a public, features-focused overview of the NVS SIGNAL S-2115 and how its capabilities map when used with the Plaspy fleet management platform. It is intended to help fleet managers, integrators, and technical users understand the practical functions of the device and what to expect when pairing it with Plaspy for vehicle monitoring and dispatch.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation approach, and manufacturer implementation. Where applicable this page highlights the features described in the official device information, but users should verify device specifics with the manufacturer and confirm current firmware behavior for their deployed units.

## Feature Overview

The SIGNAL S-2115 is a mobile automotive monitoring kit designed for vehicle tracking and wireless alarm monitoring. It emphasizes multi-constellation GNSS reception, a certified receiver, and an open information exchange protocol to support integration into navigation and dispatching systems.

- Multi constellations supported including GLONASS GNSS, GPS, GALILEO, and SBAS for broad satellite coverage
- Certified NV08C receiver by ZAO KB NAVIS for reliable position fixing
- Automotive wireless alarm and monitoring functionality intended for vehicle security and status observation
- Open protocol of information exchange to enable integration with existing navigation and information systems
- Recommended for land vehicle monitoring and dispatch systems, with certification from GNSS testing authorities
- Includes free transport monitoring software as part of the device package

## Core Features of NVS - SIGNAL S-2115

- Support for GLONASS GNSS GPS GALILEO and SBAS signals for position determination
- Certified NV08C receiver manufactured by ZAO KB NAVIS
- Automotive focused wireless alarm and monitoring capabilities
- Open protocol of information exchange for system integration
- Recommended design for monitoring and dispatch in land vehicles
- GLONASS GNSS Forum Test Certificate No 06I-2011 confirming compliance with relevant testing
- Packaged free transport monitoring software for basic fleet or vehicle monitoring

## How These Features Work with Plaspy

When integrated with Plaspy, the SIGNAL S-2115 can provide position and event data that Plaspy presents as location traces, status indicators, and alarm events. Plaspy detects device protocols automatically to simplify onboarding and to help display the device data in a unified fleet view.

- Real time location visibility in Plaspy using the device GNSS reporting
- Alarm and monitoring events from the device shown as actionable items in Plaspy dashboards
- Integration benefits from the device open protocol allowing mapping of device messages to Plaspy event types
- Plaspy aggregates device location and status alongside other fleet assets for dispatch and oversight
- Free transport monitoring software included with the device can be used alongside Plaspy or for initial device setup and testing
