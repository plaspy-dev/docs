# NVS - Navitrek UM-02 Features

This page describes the public feature context for using the NVS Navitrek UM-02 with Plaspy. It highlights the device capabilities that are relevant to location monitoring and fleet or asset oversight and explains how those capabilities can be reflected in Plaspy for operational visibility.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer configuration. Where possible this page stays close to the device description provided by NVS and avoids speculative details. For the most current device specific information consult the manufacturer documentation.

## Feature Overview

The Navitrek UM-02 is an autonomous search and location device that reports position information to a control center using GPRS and SMS channels. It is compact and intended for tracking assets, vehicles, or individuals, and uses the domestic certified NV08C GLONASS GPS receiver to improve location accuracy.

- Reports location by GPRS and can deliver information via SMS as an alternative channel
- Uses NV08C GLONASS GPS receiver series for improved positioning reliability
- Compact form factor suitable for discreet installation on assets or vehicles
- Designed for autonomous search and continuous location reporting to a control center
- Position data can be viewed on computer or mobile interfaces when integrated with monitoring systems

## Core Features of NVS - Navitrek UM-02

- Autonomous search and locate capability for object discovery and tracking
- Dual channel reporting options through GPRS and SMS communication
- Domestic certified NV08C GLONASS GPS receiver for stable position fixes
- Compact design for flexible installation on a variety of assets
- Practical for tracking vehicles, movable equipment, and individuals in monitoring scenarios
- Intended transmission of location data to a remote control center for oversight
- Usable with standard mapping and monitoring tools when integrated with a compatible server

## How These Features Work with Plaspy

Plaspy can receive and display position reports from compatible trackers such as the Navitrek UM-02 so organizations can monitor location data in a unified interface. Plaspy automatically detects many tracker protocols and provides a centralized view for devices that report over cellular data channels.

- Plaspy receives GPRS position reports and displays device locations on live maps
- SMS based reports can serve as an alternative information channel depending on device configuration and operator setup
- Plaspy automatically detects supported tracker protocols which simplifies device onboarding
- Devices compatible with Plaspy can be pointed at the Plaspy server d.plaspy.com for data reporting
- Centralized history and device listing in Plaspy helps correlate reports from the Navitrek UM-02 with other fleet data
