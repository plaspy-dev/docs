# Ulbotech - T380 Features

This page provides a public feature summary for the Ulbotech T380 and how its capabilities are used with Plaspy for fleet management, vehicle monitoring, and basic remote control. It focuses on user facing functionality and practical operational value when the T380 is paired with Plaspy, without reproducing internal or proprietary configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and how the device is installed. For the most current and device specific technical details consult the manufacturer documentation and release notes, since behavior may change across firmware updates and production batches.

## Feature Overview

The T380 is a plug and play OBDII tracker designed to deliver continuous location and event telemetry while providing an in-vehicle Wi‑Fi hotspot. Its combination of cellular connectivity, GNSS positioning, motion eventing, and remote control outputs supports real-time tracking, driver monitoring, and anti-theft workflows when integrated with a telematics platform such as Plaspy.

- Fast OBDII installation for rapid deployment and immediate vehicle telemetry.
- Real-time GNSS tracking using GPS and GLONASS positioning for route visibility.
- Built in 4G LTE modem plus an onboard Wi‑Fi hotspot to provide connectivity for drivers and devices.
- Onboard motion sensing to detect and log driving events and vehicle motion.
- Digital engine cut output and multi function digital input to support remote control and anti‑theft workflows.
- FOTA updates and automatic APN and time zone detection to simplify fleet rollouts.

## Core Features of Ulbotech - T380

- OBDII plug and play form factor for quick installation without hardwiring.
- 4G LTE modem with integrated Wi‑Fi hotspot supporting client devices for on the move connectivity.
- GNSS positioning with GPS and GLONASS for reliable location fixes.
- Onboard 3‑axis accelerometer for motion detection and event logging.
- Engine immobilizer digital output to support remote engine cut where permitted and configured.
- Multi function digital input for ignition or sensor status monitoring.
- Wi‑Fi bridging to utilize nearby networks and reduce cellular data usage.
- FOTA firmware update support and automatic APN and time zone detection for easier maintenance.

## How These Features Work with Plaspy

When the T380 is connected to Plaspy, the device streams location and telemetry so fleet managers can monitor vehicles in near real time. Plaspy automatically detects compatible tracker protocols, ingests reported GNSS fixes and event data, and surfaces those signals in map views, alerts, and historical reports to support operational decisions.

- Continuous location feeds appear on live maps and in route history for tracking and dispatch.
- Motion events and accelerometer driven alerts are available for driver behavior analysis and incident investigation.
- Digital input and engine cut output states can be recorded and shown as events to support anti‑theft procedures and remote control workflows.
- Wi‑Fi hotspot and bridging behavior helps maintain connectivity and reduce cellular usage while preserving telematics reporting into Plaspy.
- FOTA and remote configuration features can be coordinated from the backend to keep device firmware and settings consistent across a fleet.

## Typical Use Cases

- Fleet operations wanting real time vehicle visibility for routing and dispatching.
- Anti‑theft monitoring and remote immobilization workflows for asset protection.
- Driver behavior programs using motion event telemetry for coaching and safety reviews.
- Rental and shared vehicle programs needing plug and play telemetry to track usage and incidents.
- On the move internet access for drivers and technicians via the device hotspot while maintaining telematics connectivity.
- Large scale rollouts where auto APN, time zone detection, and FOTA reduce management overhead.

## Feature Availability Notes

- Feature set depends on the installed firmware version and the device hardware revision shipped by the manufacturer.
- Regional device variants may differ in cellular band support and fallback behavior for 3G or 2G networks.
- Some functions such as engine immobilizer use may be subject to local regulation and installation practices.
- OBDII installation provides vehicle power and standard interface access but installation environment can affect available signals.
- Always verify supported features, accessories, and limitations with the official Ulbotech documentation for your device batch.
