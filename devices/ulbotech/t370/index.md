# Ulbotech - T370

![T370](./tracker.jpg)

The T370 OBD GPS tracker is a compact, Plaspy compatible vehicle tracker built for reliable real-time tracking, theft protection and driver behavior monitoring. Designed for fast deployment, the T370 plugs into the vehicle OBD port for plug-and-play installation and delivers accurate positioning using a u‑blox MAX‑7 GNSS receiver together with Telit xE910‑family cellular connectivity. Fleet managers, rental operators and insurance telematics providers will find the T370 a practical choice for telemetry, anti-theft and profiling applications when integrated with Plaspy.

As a Plaspy compatible GPS tracker, the T370 supplies location, movement and OBD-sourced vehicle data for immediate use in Plaspy dashboards, alerts and reports. Its internal accelerometer, internal antennas, built-in immobilizer output and FOTA-capable modem make the T370 a turnkey device for fleet management, roadside assistance and secure vehicle monitoring without extensive installation work.

## Key Highlights

- Plaspy compatible GPS tracker with plug-and-play OBD installation for fast fleet rollout.
- Telit xE910 modem supports GSM/WCDMA/LTE-capable variants for broad cellular coverage.
- u‑blox MAX‑7 GNSS with A‑GPS and ~56 channels for fast fix times and ~2.5 m horizontal accuracy.
- Internal 3-axis accelerometer for driver behavior detection, crash and movement events.
- Internal immobilizer digital output to cut engine supply for anti-theft actions.
- FOTA support \(firmware updates via GPRS/WCDMA from FTP\) for remote maintenance.
- Compact OBD form factor, wide operating voltage \(8–32V DC\) and built-in Li‑Polymer backup battery.

## How It Works with Plaspy

When integrated with Plaspy, the T370 streams real-time location and telemetry so you can monitor vehicles, receive status alerts and run compliance or driver behavior reports. Plaspy consumes the device’s GNSS fixes, accelerometer events, OBD-derived parameters \(where available\) and device status updates to enable automated rules, geofence notifications and remote actions.

- Real-time location and telemetry updates for accurate tracking and route playback.
- Geofence alerts \(circular, rectangular, polygon up to 32 points\) fed directly into Plaspy rules.
- Accelerometer-based driver behavior events \(harsh braking, acceleration, cornering\) for driver scoring.
- OBD-sourced vehicle data: power, diagnostic and vehicle signals when available \(enables fuel-related and ignition status monitoring where supported by the vehicle\).
- Remote immobilizer control via the device’s digital output can be used in Plaspy workflows for anti-theft interventions when enabled by the integration and local procedures.
