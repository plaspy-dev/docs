# Ulbotech - T381 Features

This page provides a public feature summary of the Ulbotech T381 and how its capabilities map to Plaspy for fleet visibility, diagnostics, and operational monitoring. It describes the practical functions you can expect when the T381 is used as a telematics endpoint with Plaspy, while keeping the discussion at a public, non-sensitive level.

Exact feature availability and behavior can vary by device firmware, hardware revision, regional variant, and the specifics of how the unit is installed and configured. For the most current, device-specific technical details consult the manufacturer documentation and firmware release notes.

## Feature Overview

The T381 is a plug-and-play OBDII tracker designed to deliver GNSS location, vehicle-level telemetry, and in-vehicle connectivity that integrates with Plaspy. It emphasizes fast installation, continuous reporting, and operational features that support fleet management, diagnostics, and anti-theft workflows.

- Plug-and-play OBDII form factor for rapid installation and immediate telemetry streaming into Plaspy.
- 4G LTE connectivity with fallback to older cellular generations to maintain real-time location and parameter updates.
- Full OBDII and SAE J1939 parameter collection including RPM, speed, engine coolant temperature, fuel level, fuel consumption, and DTC reporting.
- Built-in Wi‑Fi hotspot and Wi‑Fi bridging to support in-cab devices and reduce cellular data usage.
- Digital immobilizer output for remote engine cut control as part of security and recovery workflows.
- Internal backup battery and compact design to support uninterrupted reporting and straightforward deployment.

## Core Features of Ulbotech - T381

- OBDII plug-and-play interface with support for standard OBD protocols and SAE J1939 vehicle networks.
- 4G LTE modem with fallback to maintain connectivity and continuous position reporting.
- Integrated GNSS receiver for real-time positioning and accurate tracking.
- Engine and vehicle telemetry ingestion including RPM, speed, coolant temperature, fuel level and consumption, plus diagnostic trouble codes.
- Digital immobilizer output for remote engine cut control.
- Built-in Wi‑Fi hotspot and bridging capability to serve in-cab devices.
- Onboard motion sensing and driver event detection to report harsh braking, acceleration, and cornering events.
- Remote firmware updates over the air via cellular or Wi‑Fi to streamline maintenance.

## How These Features Work with Plaspy

When connected to Plaspy, the T381 becomes an active telematics source that feeds location, diagnostics, and event data into the Plaspy platform for monitoring, alerting, and reporting. Plaspy can automatically detect supported tracker protocols and reflect incoming data in dashboards and reports.

- Real-time GNSS position and OBDII parameter updates visible on Plaspy maps and asset timelines.
- Diagnostic trouble codes and OBD parameter alarms presented in Plaspy for faster fault detection and maintenance workflows.
- Fuel level and consumption metrics imported into Plaspy for efficiency reporting and trend analysis.
- Immobilizer control available as an operational action when the device and installation support remote engine cut functions.
- Driver behavior and motion events delivered to Plaspy as actionable events for coaching and safety programs.
- Wi‑Fi hotspot and bridging reduce cellular use for cabin devices while the T381 continues to report to Plaspy and receive remote updates.

## Typical Use Cases

- Fleet management with vehicle location, utilization tracking, and engine telemetry for maintenance planning.
- Anti-theft and vehicle recovery workflows using remote immobilizer control combined with live location reporting.
- Fuel monitoring and consumption analysis for cost control and efficiency programs.
- Rental and insurance use cases that rely on DTCs and driving behavior events for profiling or claims support.
- Roadside diagnostics and rapid dispatch using in-time engine trouble code visibility.
- Driver coaching and safety programs using event data for performance feedback.

## Feature Availability Notes

- Firmware differences and updates can enable or change specific telemetry, event detection, and remote control behavior.
- Hardware revisions and regional cellular variants may alter supported bands, hotspot behavior, or power characteristics.
- Installation method matters: features tied to the OBDII interface require an accessible and properly wired OBDII port.
- Manufacturer configuration and provisioning determine which parameters and outputs are enabled by default.
- Confirm compatibility details, supported parameters, and security recommendations in the official manufacturer documentation.
