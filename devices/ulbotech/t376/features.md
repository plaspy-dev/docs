# Ulbotech - T376 Features

This page describes the public feature context for using the Ulbotech T376 GPS tracker with Plaspy. It focuses on the practical capabilities you can expect when the T376 is deployed for vehicle tracking and fleet telemetry, and how those capabilities are typically reflected inside Plaspy for monitoring and operational oversight.

Exact feature availability and behavior can vary by firmware version, hardware revision, the way the device is installed, and manufacturer implementation. For device specific installation details, firmware notes, and the latest technical specifications consult Ulbotech documentation and release notes.

## Feature Overview

The T376 is a plug and play OBDII tracker designed to deliver vehicle location, engine and sensor telemetry, and anti theft control while offering flexible connectivity over cellular and Wi Fi. It combines GNSS positioning, OBDII and SAE J1939 vehicle data, an immobilizer output, an on board accelerometer for event detection, and remote firmware management to support fleet operations.

- Plug and play OBDII installation for rapid deployment and immediate access to engine and vehicle parameters.
- GNSS positioning using u‑blox MAX‑7 with GPS and GLONASS plus a high gain antenna for fast fixes and accurate location reporting.
- Comprehensive OBDII and SAE J1939 telemetry including RPM, speed, engine parameters, fuel data and diagnostic trouble codes.
- Integrated immobilizer output and dedicated digital control for anti theft response and remote engine disablement.
- Dual communications with cellular and built in Wi Fi for redundancy and cost aware data reporting plus FOTA updates.
- On device accelerometer for driver behavior and harsh event detection to support safety and coaching programs.

## Core Features of Ulbotech - T376

- Plug in OBDII form factor with J1962 connector and support for common OBD protocols and SAE J1939 vehicle networks.
- Cellular modem based on the Telit xE910 family with 2G/3G/4G ready variants and built in Wi Fi for alternate data channel and FOTA.
- u‑blox MAX‑7 GNSS engine with GPS and GLONASS and an integrated high gain active antenna for improved TTFF and position accuracy.
- Integrated immobilizer and a dedicated digital output that can be used for engine cut or other anti theft controls.
- 3 axis accelerometer providing on device detection of harsh braking, rapid acceleration and other driving events.
- Remote firmware update capability over cellular or Wi Fi to keep devices aligned with platform features and fixes.
- On device buffering and local memory to store records when network connectivity is intermittent.
- Vehicle voltage sensing and basic device telemetry for remote diagnostics and operational monitoring.

## How These Features Work with Plaspy

When connected to Plaspy, the T376 reports location, OBDII parameters and event data so fleet managers and operators can monitor assets in real time and run historical analysis. Plaspy ingests the device streams and exposes them through mapping, alerts, event logs and reporting tools to support operational decisions.

- Live location and GNSS position updates visible on Plaspy maps and in playback history.
- OBDII and J1939 parameter reporting such as RPM, speed, fuel and diagnostic codes showing up in telemetry panels and reports.
- Immobilizer control and ignition related monitoring available as actionable events and alert triggers within Plaspy.
- Driver behavior and accelerometer detected events posted to event logs for scoring and safety programs.
- Redundant communications with cellular and Wi Fi help maintain continuous reporting into Plaspy and enable remote FOTA management.
- Buffered data forwarding when connectivity is restored so Plaspy retains a consistent historical record.

## Typical Use Cases

- Fleet management for live tracking, route replay, and operational reporting based on OBDII telemetry.
- Anti theft and recovery workflows using geofence alerts plus the T376 integrated immobilizer output for rapid response.
- Driver safety and coaching programs that use accelerometer events and vehicle telemetry to identify risky behavior.
- Rental and insurance applications that require remote diagnostics, DTC capture and usage records.
- Fuel monitoring and consumption analysis driven by OBDII fuel and engine parameters.
- Roadside assistance and recovery services using accurate GNSS position and vehicle state information.

## Feature Availability Notes

- Feature availability depends on device firmware and the specific hardware variant purchased; regional cellular variants may differ.
- Some OBDII parameters and diagnostic codes depend on vehicle make, model and year and may not be available on every vehicle.
- Installation method matters: plug in OBDII installation provides immediate access to vehicle bus data while some integrations may use alternative wiring.
- FOTA and remote management require an active data connection over cellular or Wi Fi.
- Always consult manufacturer release notes and firmware documentation for the definitive list of supported features for a given device revision.
