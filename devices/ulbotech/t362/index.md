# Ulbotech - T362

![T362](./tracker.jpg)

The Ulbotech T362 is a Plaspy compatible GPS tracker built as a compact, plug-and-play OBD-II telematics unit for reliable real-time tracking, fleet management and anti-theft protection. Designed for vehicles and heavy-duty units, the dual-SIM T362 combines u-blox GNSS performance, quad-band GSM/GPRS connectivity and rich OBD telemetry to deliver continuous position, engine and driver behaviour data to backend platforms like Plaspy.

The T362 is ideal for operators who need immediate deployment without wiring — simply plug into the vehicle OBD-II port and begin secure data transmission. With internal immobilizer control, built-in accelerometer for driver behaviour detection and FOTA firmware updates over GPRS, it supports advanced fleet workflows including theft response, driver profiling, and telematics-based service triggers.

## Key Highlights

- Plaspy compatible GPS tracker with real-time tracking over GPRS and dual-SIM failover for continuous connectivity.
- Plug-and-play OBD-II installation supporting broad vehicle and heavy-vehicle protocols for rich telemetry.
- Integrated immobilizer \(engine cut\) via digital output for anti-theft and remote disable workflows.
- u-blox 6M GNSS with A-GPS and high sensitivity \(tracking down to −162 dBm\) for fast fixes and accurate positioning.
- Driver behaviour and event detection \(cornering, hard braking, speeding, etc.\) using the internal 3-axis accelerometer.
- FOTA \(firmware over-the-air\) via GPRS for remote updates and maintenance, minimizing vehicle visits.
- Configurable geo-fences \(circle, rectangle, polygon up to 32 points\) and a range of alert types for operational control.

## How It Works with Plaspy

The T362 transmits standard telematics and OBD data over GPRS to backend servers, enabling Plaspy to ingest live GPS positions, OBD-derived telemetry and event records for dashboarding, alarms and reports. Dual-SIM support and auto APN identification keep the device online while FOTA ensures firmware and feature parity without site visits.

- Real-time location and telemetry updates: GPS position, speed and time-stamped OBD data.
- Driver behaviour and event records: cornering, hard braking, rapid acceleration, speeding and other detected events.
- Immobilizer control: digital output for engine cut can be used from Plaspy workflows where supported.
- Geo-fence alerts and configurable notifications for perimeter breaches and defined events.
- OBD-sourced vehicle data enabling fuel monitoring where the vehicle exposes fuel parameters via supported OBD protocols.

## Technical Overview

| Connectivity | Quad-band GSM/GPRS modem with dual SIM slots \(1 normal + 1 micro SIM\); multi-slot class 12 |
| --- | --- |
| Bands | GSM 850 / 900 / 1800 / 1900 MHz |
| Supported Protocols | OBD-II \(J1850 PWM/VPW, ISO 9141-2, ISO14230 KWP2000, ISO15765-4 CAN\), SAE J1939, SAE J1708/J1587 |
| GNSS | u-blox 6M with A‑GPS; typical position accuracy &lt; 3 m \(SBAS 2.0 m\); tracking sensitivity to −162 dBm; TTFF Cold ~25 s, Hot &lt;1 s |
| Power & Battery | Operating voltage 8–32 V DC; internal Li-Polymer backup battery 3.7 V, 180 mAh; typical current 70 mA active / 10 mA sleep \(max &lt;250 mA\) |
| Memory | Approx. 8 MB internal memory \(≈15,000 records\) |
| Interfaces & I/O | OBD-II J1962 connector \(plug-in\), micro USB for configuration/debugging/firmware, 1 digital output for engine cut, SIM slots, indicator LEDs |
| Sensors & Detection | Internal 3-axis accelerometer for motion detection and eight driver behaviour detections; supports temperature and battery voltage sensors |
| Remote Management | FOTA \(firmware over-the-air via GPRS\), remote configuration via GPRS |
| Bluetooth | Device reports Bluetooth status via an LED \(check integration notes for supported Bluetooth sensor options\) |
| Physical | Dimensions 50 × 50 × 23 mm \(excluding J1962 connector\), weight ≈ 50 g; internal GSM/GPS antennas \(25×25 mm ceramic GPS antenna\) |
| RF Power | GSM850/900 ~33±2 dBm; DCS/PCS ~30±2 dBm |

## Use Cases

- Fleet management: live tracking, route history, driver scoring and automated reports for operational efficiency.
- Vehicle security and anti-theft: immobilizer-based engine cut and geo-fence alerts to prevent theft and enable rapid response.
- Insurance and driver monitoring: behaviour analytics for risk scoring, teen-driver oversight and usage-based insurance programs.
- Roadside assistance and rental vehicles: plug-and-play OBD deployment for temporary monitoring, voice monitor and remote diagnostics.
- Telemetry-driven maintenance: capture battery voltage, engine parameters and event logs to support preventive maintenance scheduling.
