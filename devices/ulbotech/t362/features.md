# Ulbotech - T362 Features

This page provides a public feature context for using the Ulbotech T362 tracker with Plaspy. It summarizes the device capabilities that are relevant to fleet tracking, telemetry ingestion, event monitoring, and anti theft workflows when the T362 is paired with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, region, and installation type. Where manufacturer behavior or firmware options affect function, operators should verify the current capabilities against Ulbotech documentation and the device configuration in Plaspy.

## Feature Overview

The Ulbotech T362 is a compact OBD II plug and play telematics unit designed for quick deployment in vehicles and heavy units. It combines GNSS positioning, cellular connectivity, and vehicle bus telemetry to deliver continuous position and event data to backend platforms like Plaspy.

- Plug and play OBD II installation for fast deployment without permanent wiring
- Dual SIM and quad band GSM GPRS connectivity for resilient cellular coverage
- u blox GNSS positioning with assisted GNSS support for fast fixes
- Internal accelerometer driven driver behaviour and event detection
- Digital output for remote immobilizer control to support anti theft workflows
- Firmware over the air updates to keep devices current without site visits

## Core Features of Ulbotech - T362

- OBD II plug in interface supporting broad vehicle protocols for engine and vehicle telemetry
- Dual SIM dual band cellular modem with quad band GSM GPRS support for continuous connectivity
- u blox GNSS receiver with A GPS assistance for reliable location fixes
- Internal 3 axis accelerometer for motion sensing and driver behaviour detection
- Digital output usable for immobilizer engine cut and related remote disable workflows
- Firmware over the air updates via GPRS to manage firmware remotely
- Onboard event and record storage to buffer data during temporary connectivity loss
- Micro USB port and indicator LEDs for local configuration and status checks

## How These Features Work with Plaspy

When connected to Plaspy, the T362 reports position, telemetry, and event data so operators can monitor fleets, respond to alerts, and generate reports. Plaspy automatically detects many tracker protocols and maps incoming data into the platform for visualization and rules-based alerts.

- Real time location updates and historical tracks shown on Plaspy dashboards
- OBD derived telemetry and time stamped engine parameters available for reporting
- Driver behaviour and event records translated into alerts and scoring workflows
- Immobilizer output can be represented in Plaspy workflows where remote control is supported
- Geo fence events and perimeter alerts available for notifications and escalation
- FOTA and device configuration status visible to help maintain fleet firmware consistency

## Typical Use Cases

- Fleet operations monitoring with live position, route history, and scheduled reporting
- Vehicle security and anti theft response using immobilizer control and geo fence alerts
- Driver behaviour monitoring and scoring for safety coaching and compliance
- Rental and short term deployments using plug and play OBD II installation
- Telemetry assisted maintenance planning using OBD sourced engine and battery data
- Rapid rollouts where FOTA and remote configuration reduce field visits

## Feature Availability Notes

- Feature sets can differ by firmware version and software configuration provided by Ulbotech
- Hardware revisions and regional variants may change available communication bands or SIM slot arrangements
- Some telemetry fields depend on the vehicle exposing data through its OBD II interface
- Immobilizer and digital output behavior can be constrained by vehicle wiring and installation practices
- Plaspy mapping of device fields depends on the incoming protocol and available telemetry from the unit
