# Ulbotech - T371

![T371](./tracker.jpg)

The Ulbotech T371 is a Plaspy compatible OBD II GPS tracker engineered for professional fleet and vehicle management. Plug-and-play OBD connectivity, a Telit xE910 cellular modem and a u-blox MAX‑7 GNSS engine combine to deliver reliable real-time tracking, rich vehicle telemetry and fast time‑to‑first‑fix positioning — all fully integrable with Plaspy for centralized monitoring and reporting.

The T371 is purpose-built for fleets, rental car programs, insurance telematics and anti‑theft installations. Support for multiple OBD/CAN protocols \(including SAE J1939\), internal immobilizer control, accelerometer-based event detection and FOTA firmware updates make the T371 a compact, high-value GPS tracker for operations that need accurate position data, fuel monitoring and diagnostic insight through Plaspy.

## Key Highlights

- Plaspy compatible GPS tracker with plug‑and‑play OBD II connectivity for rapid installation and integration.
- Global cellular connectivity via Telit xE910 \(2G/3G/4G GSM/WCDMA\) for dependable real‑time tracking and data upload.
- Accurate GNSS positioning using u‑blox MAX‑7 with GPS + GLONASS and AssistNow AGPS for fast TTFF.
- Comprehensive vehicle telemetry: RPM, speed, engine coolant temperature, fuel level, fuel consumption and DTCs via OBD/CAN.
- Security features including an internal immobilizer \(engine cut\) output and a 3‑axis accelerometer for motion and driving behaviour events.
- Flexible tracking modes \(time, distance, course, status\) and geo‑fencing support \(circle, rectangle, polygon\) for automated alerts in Plaspy.
- FOTA firmware updates and automatic APN/time zone detection to simplify remote device management.
- Compact OBD form factor, low power consumption and internal backup battery for basic offline logging.

## How It Works with Plaspy

When integrated with Plaspy, the T371 streams location and vehicle telemetry to the Plaspy platform via cellular networks. Plaspy ingests GPS positions, OBD parameters and event flags so you can visualize real‑time location, analyze driver behaviour, monitor fuel usage and trigger anti‑theft workflows. The device’s internal immobilizer output and accelerometer events are available to Plaspy for immediate action and historical reporting.

- Real‑time location and telemetry updates pushed over Telit xE910 cellular link to Plaspy.
- Ignition/engine status and vehicle diagnostics via OBD II/CAN \(RPM, speed, coolant temp, DTCs\).
- Fuel monitoring and fuel consumption telemetry available for Plaspy analytics and reporting.
- Remote immobilizer control \(engine cut output\) can be coordinated from Plaspy for anti‑theft response.
- Accelerometer events \(motion, harsh braking/acceleration, etc.\) for driver behaviour scoring and alerting.

## Technical Overview

| Connectivity | Telit xE910 cellular module — GSM/WCDMA \(2G/3G/4G capable for wide‑area connectivity\) |
| --- | --- |
| Bands | GSM 850/900/1800/1900 MHz; WCDMA 800/850/900/1700/1900/2100 MHz; HSPA downlink up to 21 Mbps |
| Power & Battery | Operating voltage 8–32 V DC; Li‑Polymer backup battery 3.7 V, 180 mAh; typical current 70 mA \(active\), 10 mA \(sleep\), max &lt;250 mA |
| Interfaces | Plug‑and‑play OBD II connector; Micro USIM slot; micro USB port for configuration/debug; status LEDs; one digital output for engine cut \(internal immobilizer\) |
| GNSS | u‑blox MAX‑7 GNSS \(56 channels\) with GPS + GLONASS; AssistNow AGPS; TTFF: cold ~30 s, hot ~1 s; horizontal accuracy ~2.5 m \(autonomous\) |
| Vehicle Protocols | OBD/CAN support: J1850 PWM/VPW, ISO 9141‑2, ISO 14230 \(KWP2000\), ISO 15765‑4 \(CAN\); SAE J1939 / J1708 / J1587 |
| Remote Management | FOTA \(firmware over the air\) via cellular; automatic APN and time zone identification |
| Form Factor & Environmental | Compact OBD II unit — dimensions 50 × 50 × 23 mm \(excluding J1962 connector\); weight ~50 g; operating temperature -30°C to +80°C \(without battery\) |
| Memory & Accessories | Internal memory ~15,000 records; standard Micro USB cable included; optional OBD T‑cable, OBD cables and external immobilizer unit |
