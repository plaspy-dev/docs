# Ulbotech - T366 Features

This page provides a public feature summary for the Ulbotech T366 and explains how those capabilities map to the Plaspy platform. It is intended to help fleet managers, integrators, and technical evaluators understand the T366's practical functions when deployed and monitored through Plaspy.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, regional radio variants, and the manufacturer's configuration choices. Users should treat the content here as a high-level reference and consult the device documentation for device-specific technical details.

## Feature Overview

The T366 is an OBD plug‑in tracker designed to deliver real‑time location, OBD/CAN telemetry, immobilization control, and remote device management with automatic connectivity switching to optimize reporting. It combines GNSS positioning, cellular and Wi‑Fi connectivity, and a set of vehicle-focused functions that are useful for fleet and security workflows.

- Plug‑in OBD‑II installation for quick, tool‑free deployment across vehicles.
- Accurate GNSS positioning with assisted GPS for reliable real‑time tracking.
- Automatic Wi‑Fi and cellular switching to preserve connectivity and manage data usage.
- Full OBD and CAN telemetry for vehicle diagnostics and operational oversight.
- Built‑in immobilizer and digital engine cut output for anti‑theft and remote control.
- Firmware updates over the air to simplify remote maintenance and security updates.

## Core Features of Ulbotech - T366

- OBD‑II plug form factor for fast installation and access to vehicle data via the OBD port.
- GNSS positioning with assisted GPS to support precise location reporting.
- Dual communications using Wi‑Fi and cellular with automatic switching for continuity.
- Broad OBD and CAN protocol support including SAE J1939 and J1708/J1587 for heavy vehicle compatibility.
- Built‑in immobilizer plus a configurable digital engine cut output for remote disablement workflows.
- Configurable driver behavior detection with multiple event types for driver scoring and coaching.
- Voice monitor and remote diagnostic capabilities where supported by firmware and network.
- Firmware update over the air (FOTA) via available networks for remote management.

## How These Features Work with Plaspy

When configured for Plaspy, the T366 reports positions, telemetry, and events to the platform where those data appear in real time and in historical reports. Plaspy can present OBD and CAN parameters, behavior events, and security alerts so operators can take action and run analytics on fleet performance.

- Real‑time location and historical replay from GNSS points captured by the device.
- OBD and CAN telemetry visible in Plaspy dashboards for vehicle health and status monitoring.
- Immobilizer and engine cut actions coordinated through Plaspy workflows and remote controls.
- Driver behavior events delivered as Plaspy alerts for scoring, coaching, and reporting.
- Battery and power loss indicators reflected in Plaspy to support maintenance and recovery.
- Remote device management and FOTA status surfaced in Plaspy to track firmware and configuration updates.

## Feature Availability Notes
