# Ulbotech - T366

![T366](./tracker.jpg)

The T366 is an enhanced OBD GPS tracker from Ulbotech designed for vehicle monitoring and integration with telematics platforms. It connects via a standard OBD II port for tool free installation and combines a u blox 6M GNSS module with assisted GPS together with internal cellular and Wi Fi radios and a built in immobilizer to provide continuous location reporting, anti theft control and a range of vehicle telemetry useful to fleet managers and service providers.

As a Plaspy compatible device, the T366 is optimized to feed location, OBD and CAN telemetry, and event alerts into the Plaspy platform for real time monitoring and historical reporting. Automatic switching between Wi Fi and GPRS helps balance connectivity and data costs while features like driver behavior detection and firmware updates over the air make it a practical option for fleets, insurers and rental operators seeking integrated vehicle intelligence on Plaspy.

## Key Highlights

- Plaspy compatible OBD form factor for quick plug in deployment across mixed vehicle fleets.
- Accurate GNSS positioning using a u blox 6M module with assisted GPS for reliable real time tracking.
- Automatic Wi Fi and GPRS switching to maintain connectivity while helping control data usage.
- Built in immobilizer and a digital engine cut output for remote anti theft control via Plaspy.
- Rich vehicle telemetry from OBD and CAN data plus configurable driver behavior detection for operational insights.
- Firmware updates over the air for remote maintenance and configuration when connected.

## How It Works with Plaspy

When installed, the T366 transmits GNSS positions, OBD and CAN telemetry, event alerts and driver behavior events to Plaspy so operators can monitor vehicles live, receive configurable alerts and analyze historic data. Plaspy ingests these streams to provide map based visibility, reporting tools and workflows for security and fleet optimization.

- Live location and telemetry on Plaspy maps with historical replay for incident review.
- Remote immobilizer and engine cut control surfaced in Plaspy workflows for security responses.
- Driver behavior events appear as alerts and records in Plaspy for scoring and coaching programs.
- Battery and power loss alerts maintain continuity of critical notifications to operations teams.
- Remote device management and FOTA allow updates and setting changes through Plaspy when the tracker is connected.
