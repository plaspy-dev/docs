# iStartek - VT900 Features

This page provides a public summary of the iStartek VT900 features and how those capabilities are presented when the device is used with Plaspy. It focuses on user-facing functions and the practical ways the VT900 can be used for location awareness, event monitoring, and historical logging inside the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For device-specific setup details, configuration parameters, and the latest technical information consult the official iStartek documentation.

## Feature Overview

The VT900 is a compact GPS tracker designed for flexible tracking and monitoring across cellular networks. It supports both SMS and GPRS reporting, includes onboard logging, a vibration sensor, and multiple alarm types to protect assets and provide operational visibility.

- Cellular network support for broad regional coverage using UMTS HSDPA and GSM GPRS
- Multiple reporting modes including on demand, timed interval, SMS, and GPRS
- Internal 8MB flash memory for logging position data when connection is intermittent
- Inbuilt tremble sensor to detect movement or vibrations and generate alerts
- Onboard backup battery and SOS alarm for continued operation and emergency notification
- Multiple I/O options including RS232, digital and analog inputs, and output ports for external integrations

## Core Features of iStartek - VT900

- Support for UMTS HSDPA and GSM GPRS networks for wide area connectivity
- Tracking via SMS and GPRS with options for on demand or scheduled reports
- 8MB internal flash memory for local data logging and later upload
- Inbuilt tremble sensor for movement and tamper detection
- Internal backup battery to maintain operation during external power loss
- SOS alarm for user-triggered emergency alerts
- Geo-fence alarms, GPS blind area alarms, low battery alarms, and speeding alarms
- Physical interfaces including 1 RS232 port, 3 digital inputs, 1 analog input, and 2 output ports for accessory connection

## How These Features Work with Plaspy

Plaspy displays and aggregates tracker data to provide centralized visibility of location and events. The VT900 can send position reports and alarm messages that Plaspy associates with devices for monitoring and historical review. Plaspy automatically detects common tracker protocols to simplify onboarding.

- Real-time and periodic location updates from the VT900 appear in Plaspy maps and device lists
- Alarms such as SOS, geo-fence, tremble, low battery, speeding, and blind area are surfaced as events for operator review
- Logged records stored in the device memory can be uploaded and shown in Plaspy for historical playback
- External inputs and outputs connected via RS232, digital, or analog interfaces are represented as device events or state changes in Plaspy when reported by the tracker
- On-demand tracking and interval reporting are visible in Plaspy as immediate or scheduled position records
- Plaspy automatically detects supported tracker protocols to help with initial device connection and message parsing

## Typical Use Cases

- Vehicle location tracking for small fleets and individual vehicles
- Asset anti-tampering monitoring using tremble sensor and alarms
- Emergency alerting via SOS alarm to notify operators of urgent incidents
- Historical route review and incident reconstruction using onboard logs and Plaspy playback
- Remote monitoring of equipment where inputs or external sensors are required
- Operational oversight for delivery, service, and field teams
