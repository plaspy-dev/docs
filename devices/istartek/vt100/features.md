# iStartek - VT100 Features

This page provides a public feature overview for the iStartek VT100 GPS tracker and explains how the device is used with Plaspy for real time vehicle monitoring. It summarizes the VT100 capabilities that matter to fleet managers, dispatch teams, and security operators when the tracker is connected to Plaspy.

Exact feature availability can vary by firmware version, hardware revision, regional variant, installation type and manufacturer configuration. For device specific implementation details, optional sensor configurations, and the latest firmware behavior, refer to the official manufacturer documentation before finalizing deployment decisions.

## Feature Overview

The VT100 is a compact 2G vehicle tracker designed for continuous location reporting and operational telemetry. It combines multi GNSS positioning with vehicle oriented inputs and anti theft controls, and includes built in offline logging and remote management capabilities to support reliable tracking in commercial fleets and security workflows.

- Dual GNSS positioning with GPS and BEIDOU for precise location reporting and reliable route replay.
- 2G cellular connectivity for real time telemetry, configurable server upload and SMS or GPRS command support.
- Rugged IP66 enclosure and wide DC input range to suit diverse vehicle installations and harsh environments.
- Integrated motion detection and 3D accelerometer for collision and driver behavior event reporting.
- SOS alarm and listen in microphone support plus remote engine or power cut off for anti theft response.
- Built in flash memory for offline logging with automatic upload when connectivity is restored.

## Core Features of iStartek - VT100

- GNSS positioning using GPS and BEIDOU with high sensitivity and submeter to meter level positional accuracy as specified by the manufacturer.
- Quad band 2G GSM connectivity and dual server upload for redundancy in data delivery.
- Wide voltage input range to accommodate light vehicles and heavy equipment and IP66 rated enclosure for weather resistance.
- Integrated 3D accelerometer for collision, vibration and driver behavior detection.
- SOS panic alarm and listen in microphone support to assist emergency and security workflows.
- Remote engine or power cut off (immobilizer) control for anti theft and fleet enforcement actions.
- Built in flash memory for offline position logging and automatic forward of stored data when network access returns.
- Remote management capabilities such as firmware over the air and configurable SMS or GPRS commands for maintenance and configuration.

## How These Features Work with Plaspy

When a VT100 is connected to Plaspy, the device becomes a real time source of location and event data that Plaspy presents in maps, alerts and reports. Plaspy automatically recognizes compatible tracker protocols and ingests the device data so operations teams can monitor assets through a consistent dashboard experience.

- Live location updates and route histories appear on Plaspy maps for dispatch and post trip analysis.
- Event notifications for SOS, collision or motion detection are translated into alerts and automated workflows inside Plaspy.
- Immobilizer or remote engine cut off events are visible in device history and can be used to support theft response procedures.
- Offline logged positions are forwarded to Plaspy when connectivity resumes, preserving trip continuity and historical records.
- Fuel monitoring and other optional sensor telemetry reported by VT100 are available in Plaspy when the tracker is paired with compatible sensors.

## Typical Use Cases

- Fleet management for live vehicle tracking, route replay and operational oversight.
- Public transport and school bus supervision with route compliance and safety alerts.
- Taxi and ride services for trip telemetry, live location sharing and anti theft measures.
- Vehicle leasing and insurance monitoring for mileage, incident telemetry and immobilization control.
- Private vehicle anti theft deployments using SOS, listen in and remote engine cut off features.

## Feature Availability Notes

- Manufacturer firmware updates can enable or change features; behavior may differ across firmware versions.
- Optional features such as fuel monitoring require compatible external sensors and proper installation.
- Hardware revisions and regional variants can affect supported cellular bands and connector options.
- Installation choices and wiring determine which inputs or outputs are available and how immobilizer or ACC detection functions operate.
- Always verify the specific feature set and configuration options for the exact VT100 unit you are deploying.
