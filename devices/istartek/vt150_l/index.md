# iStartek - VT150-L

![VT150-L](./tracker.png)

The VT150-L is a compact 4G GPS motorcycle tracker engineered for reliable, Plaspy compatible real-time tracking and vehicle security. Designed with multi-constellation GNSS \(BDS/GPS/GLONASS/QZSS\) and 4G cellular connectivity, the VT150-L delivers accurate positioning, telemetry and alarm reporting to Plaspy for fleet management, anti-theft protection and telematics deployments.

Small and rugged with an IP66 rating and wide input voltage range, the VT150-L fits motorcycle and light-vehicle installations where space and durability matter. It supports dual-mode GPS+GSM base station positioning to improve location reliability in urban or challenging reception environments, and offers event-driven alerts, remote fuel/electricity cut-off \(immobilizer\), FOTA firmware updates and dual server configuration for seamless Plaspy integration.

## Key Highlights

- Plaspy compatible 4G GPS tracker for real-time tracking and fleet management of motorcycles and small vehicles.
- Multi-constellation GNSS \(BDS/GPS/GLONASS/QZSS\) plus GPS+GSM base station positioning for improved location reliability.
- Comprehensive safety and alarm suite: geo-fence, speeding, impact/vibration \(towing\), harsh driving, idling and power-disconnect alerts.
- Remote immobilizer support via remote fuel/electricity cut-off for fast anti-theft response through Plaspy.
- Compact, IP66 rugged housing with wide DC 9–90 V power input and backup 120 mAh battery for resilient telemetry.
- Integrated 3D acceleration sensor for motion, impact and towing detection plus configurable ACC input for ignition monitoring.
- FOTA firmware upgrade capability and dual server support to simplify remote management and platform reliability.

## How It Works with Plaspy

The VT150-L reports position, status and events to Plaspy over 4G LTE or GSM networks. Plaspy ingests location and telemetry messages \(interval, distance or event-triggered\) to provide live maps, historical routes, alerts and fleet reports. The device’s dual-server option and SMS alarm capability keep notifications resilient, while FOTA and remote control functions work through the platform for administration and security actions.

- Real-time location and telemetry updates: interval, distance-based and event-triggered reporting to Plaspy.
- Ignition and input monitoring: ACC detection via configurable Input2 and digital inputs for door/engine status.
- Remote immobilizer / fuel & electricity cut-off: support for remote stop commands via Plaspy for anti-theft response.
- Event & alarm integration: geo-fence, speeding, impact/vibration, harsh driving, idling, low battery and power-disconnect alerts.
- Bluetooth sensors/beacons: not specified in the device specification; external sensor integration can be implemented via vendor accessories where available.
