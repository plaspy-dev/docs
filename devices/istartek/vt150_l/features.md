# iStartek - VT150-L Features

This page describes public feature context for the iStartek VT150-L when used with Plaspy. It highlights practical capabilities, event types, and behavioral expectations that matter for real time tracking, fleet oversight, and anti theft scenarios on the Plaspy platform.

Exact feature availability and behavior can vary by device firmware version hardware revision installation method and manufacturer implementation. Users should understand that some functions may depend on optional accessories regional variants or configuration steps performed during installation and provisioning.

## Feature Overview

The VT150-L is a compact 4G motorcycle tracker designed to deliver reliable position and event reporting into Plaspy for live monitoring and historical analysis. It combines multi constellation GNSS with cellular assisted positioning and a set of event alarms to support theft protection and fleet visibility.

- Real time 4G location reporting with multi constellation GNSS for improved positioning accuracy across environments
- GPS plus GSM base station positioning to enhance location reliability in urban or weak GNSS conditions
- Event driven alerts including geo fence speeding impact vibration harsh driving idling and power disconnect
- Remote immobilizer support for fuel or electricity cut off to aid anti theft response
- Rugged IP66 housing with wide input voltage tolerance and a small backup battery for resilient motorcycle installations

## Core Features of iStartek - VT150-L

- 4G LTE with GSM fallback for cellular reporting and wide area coverage
- Multi constellation GNSS support including BDS GPS GLONASS and QZSS for robust positioning
- Dual mode GPS plus GSM base station positioning to reduce blind spots in dense urban areas
- Integrated 3D acceleration sensor for impact vibration towing and harsh driving detection
- Remote immobilizer capability via fuel or electricity cut off for rapid anti theft actions
- Configurable digital inputs with ACC detection support and an output relay for vehicle control
- FOTA firmware updates plus dual server and SMS alarm options for remote management and notification reliability

## How These Features Work with Plaspy

Plaspy ingests location status and event messages from the VT150-L to present live maps historical routes alerts and device status to operators. The platform uses the tracker telemetry to trigger notifications build reports and enable remote control actions where supported by the device and configuration.

- Live location and route playback based on interval distance or event triggered reports from the device
- Event visibility for geo fence speeding impact vibration idling and power disconnect so operators can triage incidents quickly
- Input and ignition state reporting reflected in Plaspy for trip segmentation and status monitoring
- Remote immobilizer commands and administrative controls routed through Plaspy where the device and installation allow remote stop actions
- Device management indicators such as firmware update status dual server connectivity and SMS alarm fallback surfaced in the platform

## Typical Use Cases

- Real time tracking and route history for motorcycle and light vehicle fleets
- Anti theft protection with impact alerts and remote immobilizer to aid recovery
- Taxi rental and lease operations requiring ignition detection trip logging and event notifications
- Public transport and shuttle oversight using geo fence and route deviation alerts
- Usage based monitoring for insurance and telematics reporting through event and mileage data
- Field service and delivery fleets needing compact rugged trackers for two wheel and small vehicle installs
