# iStartek - VT150 Features

This page provides public feature context for using the iStartek VT150 tracker with Plaspy. It summarizes the VT150 capabilities that are relevant to Plaspy users and fleet operators, focusing on practical functions such as real time tracking, telemetry reporting, alarm events, and remote control options when integrated into Plaspy workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, optional accessories, installation method, and manufacturer implementation. Review official iStartek documentation and your device configuration to confirm which features are enabled on a specific VT150 unit before deploying in production.

## Feature Overview

The VT150 is a compact, rugged 2G GPS tracker designed for continuous vehicle monitoring and integration with tracking platforms like Plaspy. It offers GNSS position reporting, GSM fallback for location, an extensive alarm set, remote control functions, on device logging, and support for optional wired accessories to extend telemetry.

- Continuous GNSS position reporting with dual mode GNSS plus GSM base station positioning for improved reliability in urban and marginal signal areas
- Event driven and periodic telemetry reporting for ignition state, alarms, and vehicle status
- Broad alarm suite including geo fence, speeding, GPS loss, low battery, door and engine status changes, harsh driving, impact and towing vibration
- Remote control capabilities such as ACC upload intervals and remote fuel or electricity cut off for immobilizer style security
- Onboard flash logging and FOTA support for offline data retention and remote firmware updates

## Core Features of iStartek - VT150

- 2G GSM connectivity for position and telemetry uplink compatible with tracking platforms
- Multi GNSS support for accurate positioning across different satellite systems
- Extensive alarm and event reporting including geo fence, speeding, GPS loss, low battery, door and engine status changes, harsh driving, impact and vibration
- Remote control functions including configurable ACC on off interval reporting and remote fuel or electricity cut off where configured
- Onboard data logging with local flash storage to preserve tracks during network interruptions
- FOTA firmware update capability for remote device management
- Rugged IP66 enclosure and compact form factor suitable for vehicle installation
- Support for optional wired accessories such as fuel sensors, buzzers and load sensors to expand telemetry

## How These Features Work with Plaspy

When connected to Plaspy, the VT150 reports position fixes, alarm events and telemetry to the platform where data is visualized, logged and used to drive alerts and operational workflows. Plaspy ingests device events and makes them available for monitoring, reporting and automation.

- Real time location and historical route playback visible in Plaspy dashboards
- Ignition and engine status reporting surfaced as vehicle state and filterable events
- Alarm events such as geo fence breaches, GPS loss, impact and harsh driving appear as alerts that can trigger notifications or rules
- Onboard logging enables recovery of position history and missed events in Plaspy after temporary network loss
- Remote control actions initiated through Plaspy can be mapped to device remote functions where supported by installation and configuration

## Typical Use Cases

- Fleet management and dispatch with continuous location, track playback and operational oversight
- Anti theft and immobilization workflows using movement alarms and remote fuel or electricity cut off
- Taxi and ride hail operations for ignition monitoring, trip playback and driver behavior review
- School bus and public transport monitoring with geo fence alerts and incident detection
- Rental and lease vehicle tracking for mileage, location history and alarm response
- Commercial vehicle telemetry where optional wired sensors are used to extend data collection

## Feature Availability Notes

- Feature presence and behavior depend on VT150 firmware version and device configuration applied by the installer or fleet operator
- Hardware revisions and regional variants may influence available inputs, outputs and supported accessories
- Optional wired accessories such as fuel sensors and buzzers require compatible wiring and configuration to appear in telemetry
- Local logging capacity and FOTA functionality are subject to manufacturer firmware and server settings
- Verify specific alarm thresholds and event types in the device configuration and Plaspy mapping before relying on automated workflows
