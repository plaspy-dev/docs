# iStartek - VT202 Features

This page provides a public feature overview of the iStartek VT202 and how its capabilities relate to use with Plaspy. It focuses on practical, user-facing capabilities such as location reporting, alarm signals, and options for remote control, and explains how those functions can appear in a Plaspy deployment without delving into device-specific configuration details.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation and wiring choices, and manufacturer configuration. For critical details about supported commands, installation requirements, or firmware-specific behavior, consult the manufacturer's documentation and verify device settings before deployment.

## Feature Overview

The iStartek VT202 is a compact GPS tracker designed for motorcycles, electric bicycles, cars, and a range of light vehicles. It combines position reporting with anti-theft alarms and a remote cut-off capability, providing core tools for location awareness and basic fleet or asset protection.

- Mini form factor suitable for discreet installation on motorcycles, e bikes, and cars
- Built-in GPS positioning with supplementary LBS positioning for improved coverage
- Multiple anti-theft alarms including vibration alarm, wire cut-off alarm, and ACC alarm
- Remote cut-off function to stop the vehicle by breaking fuel connection when supported and configured
- Reporting and tracking via SMS, mobile app, and web interfaces for flexible monitoring

## Core Features of iStartek - VT202

- Compact design intended for motorcycle and electric bicycle tracking as well as car management
- Built-in GPS module for precise position data
- LBS based positioning to supplement GPS in weak signal areas
- Wide input voltage range for use across different vehicle types including trucks and trailers
- Vibration alarm to detect movement or tampering
- Wire cut-off alarm to notify if power or wiring is severed
- ACC alarm to indicate ignition state changes
- Remote cut-off (fuel break) capability to assist in theft response when supported by firmware and installation

## How These Features Work with Plaspy

When used with Plaspy, VT202 position and event data become visible on the platform for monitoring and operational oversight. Plaspy automatically detects many common tracker protocols and can ingest location and event messages from compatible devices for real-time tracking and historical review.

- Real-time location updates and position history displayed on Plaspy maps and timelines
- Alarm events such as vibration, wire cut, and ACC changes shown as events or notifications in Plaspy
- Remote command support can allow actions like remote cut-off to be issued from Plaspy when the device firmware and configuration permit remote control
- Flexible reporting: VT202 can report to a configured server and Plaspy can receive those reports for unified monitoring; Plaspy will detect the tracker protocol automatically
- Alerts and event visibility in Plaspy help operations teams act on theft or misuse signals more quickly

## Typical Use Cases

- Motorcycle and electric bicycle tracking for location recovery and theft deterrence
- Small vehicle and car fleet monitoring for route visibility and basic oversight
- Asset protection for trailers and light trucks where a compact tracker is required
- Remote theft response workflows using alarm signals and remote cut-off where available
- Owners who prefer multiple tracking interfaces such as SMS, mobile app, and web access

## Feature Availability Notes

- Feature set can differ between firmware versions and hardware revisions; check device firmware release notes for exact behavior
- Some functions, like remote cut-off, require correct wiring and installation and may be restricted by local regulations
- LBS positioning reliability depends on cellular network coverage and may vary by region
- Alarm sensitivity and behavior may be configurable; installer setup can affect how and when alarms trigger
- Manufacturer region variants or optional accessories can change available features

Using the iStartek VT202 with Plaspy gives organizations a centralized view of location and alarm events across vehicles and assets. Plaspy's platform is designed to present position history, event timelines, and alert notifications so that operators can monitor fleet status and respond to incidents with contextual information.
