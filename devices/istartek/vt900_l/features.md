# iStartek - VT900-L Features

This page provides a public overview of the main features and practical capabilities of the iStartek VT900-L when used with Plaspy. It focuses on the device capabilities relevant to tracking, telemetry, alarms, and integrations that fleet managers and technical users commonly consider when deploying Plaspy compatible trackers.

Exact feature availability, behavior, and supported integrations can vary by firmware version, hardware revision, regional module variant and by how the device is installed and configured. Review installation notes and the manufacturer documentation for device specific instructions and the latest technical details.

## Feature Overview

The VT900-L is a compact vehicle tracker designed for professional fleet and telematics deployments. It combines multi network cellular connectivity, dual GNSS positioning, local logging and a broad set of wired interfaces so that location, events and connected sensor data can be reported into Plaspy for monitoring and reporting.

- Real time location reporting to Plaspy using TCP, UDP or SMS for live fleet visibility and alarms
- Dual GNSS positioning with GPS and BeiDou for improved satellite availability in mixed coverage areas
- Multi network cellular support across 4G LTE, 3G and 2G for broad regional connectivity
- Onboard logging and backup battery to preserve position and event records during connectivity gaps
- Multiple wired inputs and outputs plus serial and 1 Wire interfaces for sensor and accessory integration
- Rich alarm set and scheduled reporting options to feed event driven workflows in Plaspy

## Core Features of iStartek - VT900-L

- Multi channel reporting via TCP, UDP and SMS for flexible server delivery and redundancy
- Dual GNSS receiver supporting GPS and BeiDou with position accuracy reported in manufacturer specs
- Multi band cellular modules supporting 4G LTE with fallback to 3G and 2G depending on regional variant
- Onboard logging (8 MB flash) and an internal backup battery for power loss reporting and data preservation
- Multiple I O interfaces including digital inputs, digital outputs, analog input, 1 Wire and RS232 for peripherals
- Comprehensive alarm suite including geofence, parking and antenna disconnect among other event types
- Remote device management features including FOTA firmware updates and OTA control of digital outputs

## How These Features Work with Plaspy

The VT900-L sends location, events and connected sensor telemetry to Plaspy where those records are presented for monitoring, reporting and operational control. Plaspy detects tracker protocol and maps incoming data into device position histories, alerts and telemetry panels so teams can act on live and historical information.

- Live position updates and GNSS derived values become visible on Plaspy maps and location histories
- Alarm and event forwarding into Plaspy for geofence breaches, parking events, antenna disconnects and other alerts
- Scheduled and conditional reporting such as time based or distance based uploads for route and utilization reports
- Stored log upload after connectivity recovery so Plaspy retains continuity of telemetry when cellular coverage is intermittent
- Sensor and accessory data from analog, 1 Wire and RS232 interfaces appear in Plaspy telemetry streams when configured

## Typical Use Cases

- Real time fleet tracking and route monitoring across mixed cellular networks
- Anti theft and recovery workflows using geofence and parking alarms combined with remote output control
- Integration of external sensors and peripherals for consolidated telemetry in Plaspy dashboards
- Scheduled reporting for route compliance, utilization and mileage analysis
- Cold chain monitoring when temperature probes are attached via 1 Wire and reported through Plaspy
- Driver behavior and safety programs leveraging alarm events and scheduled reports for coaching
