# iStartek - PT81 Features

This page provides a public, features-focused overview of the iStartek PT81 and how its capabilities map to Plaspy for real time tracking, alerts, and historical playback. It is intended to describe practical, user facing functions and common operational uses when the PT81 is used with the Plaspy platform.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional model, installation method and manufacturer configuration. For device specific details such as the latest firmware behavior, regional variants, or full technical specifications consult the official manufacturer documentation.

## Feature Overview

The PT81 is a compact 4G wearable tracker designed for continuous location awareness and personal safety monitoring. In everyday use it delivers multi mode positioning and a set of safety features that are useful for caregivers, schools, and personal security scenarios.

- Multi mode positioning combining GPS, BeiDou, Wi‑Fi and LBS for improved coverage in urban and rural areas.
- Compact IP67 wearable design with a 1.0 inch TFT display for quick status checks on the device.
- Safety functions including SOS alarm, fall detection, geo fence alerts and device Finder ringing to assist responders.
- Two way voice calls and remote voice monitoring to enable direct communication between a wearer and a caregiver.
- Long battery endurance with a 1000 mAh battery and power optimizations for extended standby between charges.

## Core Features of iStartek - PT81

- Multi mode GNSS positioning: GPS plus BeiDou augmented by Wi‑Fi and LBS hybrid positioning for better location availability.
- Wearable and ruggedized enclosure rated IP67 for everyday water resistance and durability.
- Dedicated SOS button for emergency alerts and prioritized alarm handling.
- Two way voice communication and remote voice monitoring using the built in speaker and microphone.
- Fall detection using an onboard gravity sensor to trigger alerts when configured.
- Geo fence support to generate location based alerts and notifications.
- Device Finder ring function to locate a nearby tracker by sound.
- Long life 1000 mAh battery with power saving modes for prolonged standby times.

## How These Features Work with Plaspy

Plaspy ingests the PT81’s location and event data so caregivers and managers can monitor status, receive alarms, and review historical movement easily in the platform. Integration focuses on visibility, timely alerts and continuity of records rather than device level configuration details.

- Real time location updates and historical track playback visible inside Plaspy timelines and maps.
- SOS alarms and fall detection events forwarded as platform alerts so designated contacts can be notified promptly.
- Two way voice and remote voice monitoring routed through the platform or mobile client where supported for direct communication.
- Geo fence triggers, low battery notifications and device finder events available as configurable notifications in Plaspy.
- Customizable reporting intervals and alert rules in Plaspy help balance timeliness with battery life for wearable deployments.

## Typical Use Cases

- Elderly care and assisted living monitoring where fall detection and SOS help caregivers respond quickly.
- Student safety and school check ins using wearable tracking and geo fence alerts for defined locations.
- Personal security and solo worker monitoring for discreet on person location and emergency communications.
- Outdoor everyday use such as walking or light recreational activities where a waterproof wearable is useful.
- Luggage or personal item monitoring where the device finder and location history assist recovery efforts.
- Caregiver coordination and remote monitoring to streamline routine check ins and status checks.
