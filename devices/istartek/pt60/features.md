# iStartek - PT60 Features

This page presents the public feature context for the iStartek PT60 tracker and how those features are used with Plaspy. It focuses on practical capabilities, common operational value, and what to expect when the PT60 is integrated into the Plaspy platform for location awareness and monitoring.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation method, and manufacturer implementation. For final device specifications, configuration details, and the latest firmware notes refer to iStartek documentation while using this page to understand how the PT60 typically maps to Plaspy monitoring and reporting.

## Feature Overview

The iStartek PT60 is a compact 4G GPS tracker designed for extended deployments and flexible installation. It balances long battery life, multiple operating modes, and remote update capability to support vehicle and asset tracking scenarios where long unattended operation and tamper awareness are important.

- 4G LTE connectivity for broad network coverage and reliable reporting.
- High sensitivity GNSS positioning with support for GPS, BDS, and QZSS, with Glonass available as an option.
- Very long standby life from a rechargeable battery to reduce maintenance intervals.
- Light sensor based tamper alarm for detection of enclosure opening or tampering.
- Strong magnetic cover for simple, installation free mounting to vehicles and assets.
- Multiple configurable working modes to balance reporting frequency and power consumption.

## Core Features of iStartek - PT60

- 4G LTE CAT1 and CATM network compatibility for modern cellular connectivity.
- Built in high sensitivity GNSS receiver supporting GPS BDS and QZSS with optional Glonass.
- Rechargeable battery with ultra long standby capability reported by the manufacturer.
- Light sensor triggered tamper alarm to notify unauthorized access or disassembly.
- Strong magnetic cover for quick attachment to vehicles trailers containers and other metal surfaces.
- Multiple working modes including normal mode sports modes timer wake up and alarm clock mode to fit different tracking scenarios.
- 16Mb flash memory for local storage of location data when network is unavailable.
- Supports FOTA for remote firmware updates and dual server setup for redundant data delivery.

## How These Features Work with Plaspy

When the PT60 is used with Plaspy, the tracker reports location and status data to the platform so fleet managers and operators can monitor assets in near real time. Plaspy automatically detects supported tracker protocols and ingests the device data for visualization, history, and alerts.

- Location updates from the PT60 appear on Plaspy maps and history views for route and position analysis.
- Tamper alarm events reported by the device are presented as alerts or events in Plaspy for quick operational response.
- Multiple working modes and long standby capability help Plaspy users balance tracking fidelity with battery life when configuring reporting expectations.
- Local storage and dual server support increase data reliability when temporary network interruption occurs, and Plaspy displays recovered history when it arrives.
- FOTA support allows manufacturers to provide firmware updates that Plaspy can continue to consume without manual reconfiguration on most compatible devices.

## Typical Use Cases

- Long term tracking of trailers containers and stored assets where infrequent maintenance is desired.
- Remote asset monitoring in locations without constant supervision using long battery standby.
- Temporary or installation free tracking for rented equipment or short term deployments using the magnetic mount.
- Tamper detection for unattended assets that require security alerts when the device enclosure is disturbed.
- Fleet visibility for vehicles that need occasional position reports balanced with battery conservation.
- Redundant reporting setups where dual server support helps ensure delivery to monitoring platforms.

## Feature Availability Notes

- Feature sets such as supported GNSS constellations and optional Glonass may vary by hardware revision or regional model.
- Battery standby time depends on configured reporting intervals working mode and environmental conditions.
- Tamper alarm behavior and the sensitivity of the light sensor can be impacted by installation location and enclosure configuration.
- FOTA and dual server functionality require manufacturer support and appropriate provisioning during setup.
- Confirm regional cellular band compatibility and network support with the manufacturer or local provider.
