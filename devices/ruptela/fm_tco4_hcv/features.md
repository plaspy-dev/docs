# Ruptela - FM-Tco4 HCV Features

This page provides a public feature overview of the Ruptela FM-Tco4 HCV and how its capabilities are commonly used with Plaspy for fleet monitoring and telematics. It describes the device functionality that is relevant to Plaspy users and highlights practical uses without replacing the official device documentation.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation wiring, and manufacturer implementation. For device specific instructions, legal compliance, or advanced configuration always consult Ruptela documentation and your certified installer.

## Feature Overview

The FM-Tco4 HCV is a truck focused GPS tracker built for modern fleet telematics, combining vehicle bus data, tachograph access, I/O interfaces, and refrigeration monitoring to support transport operations and compliance workflows.

- Real time vehicle tracking combined with telematics data for route and order optimization
- CANbus reading in J1708 and FMS standards plus Dual CAN for simultaneous vehicle bus and digital tachograph data
- RS232 and RS485 serial ports and a 1-Wire interface for accessory integration and sensor connectivity
- Remote tachograph file reading and downloading to support data collection and compliance workflows
- Monitoring of ThermoKing, Optitemp, and Carrier refrigeration telemetry for temperature sensitive cargo
- Fuel control and eco drive monitoring to support cost and efficiency programs

## Core Features of Ruptela - FM-Tco4 HCV

- GPS location and trip logging for vehicle position and movement history
- CANbus data reading with support for J1708 and FMS standards to surface vehicle diagnostics and operational metrics
- Dual CAN functionality allowing simultaneous access to vehicle bus data and digital tachograph streams
- RS232 and RS485 ports that can operate simultaneously for multiple serial devices
- 1-Wire interface for connecting supported accessories and external sensors
- Integrated support for ThermoKing, Optitemp, and Carrier refrigeration systems telemetry
- Remote tachograph data reading and downloading for central collection of files
- Features for fuel control, eco drive monitoring, and remote engine blocking as implemented by the manufacturer

## How These Features Work with Plaspy

Plaspy receives and normalizes telematics sent by the FM-Tco4 HCV so fleet managers can view location, vehicle status, and supported bus or accessory data alongside other fleet information. Plaspy adapts to the data the device provides and surfaces that information in dashboards, reports, and event logs.

- Map and history views that show vehicle location and trip segments reported by the tracker
- Telematics panels displaying CANbus derived metrics and FMS parameters when provided by the device
- Tachograph file handling workflows for collecting and storing downloaded tachograph data in Plaspy
- Temperature monitoring and alerting for refrigerated assets when ThermoKing, Optitemp, or Carrier data is transmitted
- Fuel and eco drive trend charts based on the telemetry the device reports
- Event visibility for actions such as remote immobilization events and status changes when those events are reported by the device

## Typical Use Cases

- Long haul and regional truck tracking with integrated vehicle bus monitoring for fleet operations
- Temperature controlled transport monitoring for food and pharmaceutical distribution
- Remote collection and central archiving of digital tachograph data for compliance and driver hours management
- Fuel consumption and eco driving programs to reduce operating costs and improve efficiency
- Mixed fleet telematics where serial accessories or specialized refrigeration data must be collected and correlated
- Remote vehicle control and safety workflows using supported immobilization and command features

## Feature Availability Notes

- Feature availability can depend on the device firmware version and the specific hardware revision shipped by Ruptela
- Physical installation and wiring determine which serial ports, CAN channels, and 1-Wire peripherals are accessible
- Regional regulatory differences and tachograph implementations may affect what data can be read or downloaded
- Manufacturer configuration options and enabled features at purchase time can change the set of usable functions
- Consult Ruptela documentation and your installer to confirm which features are enabled for your unit
