# Ruptela - Trace5 Features

This page provides a public feature overview for the Ruptela Trace5 and how its capabilities are used with Plaspy. It describes practical, non-sensitive device features that are relevant to vehicle tracking and fleet monitoring, and it explains how the Trace5 can feed data into Plaspy for operational visibility.

Exact feature availability and behavior can vary by firmware version, hardware revision, regional variant, and installation type. For firmware specific behavior, hardware options, or accessory compatibility consult the official Ruptela documentation and device release notes.

## Feature Overview

The Trace5 is a compact GNSS vehicle tracker designed for reliable position reporting and robust field use. Its combination of a premium GNSS module, 4G connectivity, and rugged IP67 housing makes it suitable for fleets operating in demanding environments while maintaining consistent data transmission.

- High quality GNSS positioning for accurate location updates in Plaspy
- 4G cellular connectivity to support frequent and reliable reporting
- IP67 rated rugged housing for installations exposed to water, dust, and rough conditions
- Installation flexibility including concealed OBD style mounting and tailored harness options
- Built in security features such as jamming detection, back up battery, and TLS v1.2 encryption for secure communication in supported variants

## Core Features of Ruptela - Trace5

- Premium GNSS module for dependable positioning and tracking
- 4G cellular link for near real time data transmission
- IP67 rated rugged enclosure designed for external mounting near the engine or other exposed locations
- Concealed OBD installation options and dedicated harnesses for tidy installations
- Small ergonomic form factor with screwless housing to simplify physical installation
- Manufacturer tools such as Device Center and Installation Assistant to guide setup
- Jamming detection for added security and operational awareness
- Back up battery and TLS v1.2 encryption in supported versions to protect continuity and data integrity

## How These Features Work with Plaspy

Plaspy receives and presents the Trace5 data so fleet operators can monitor vehicles, review movement history, and act on events. Plaspy automatically detects the tracker protocol for compatible devices so Trace5 units can be added to the platform with minimal protocol configuration.

- Live and historical location visualization on Plaspy maps for route review and playback
- Status and connectivity indicators that reflect cellular link and reported device health
- Event visibility for detected security conditions reported by the device such as jamming detection and backup battery events
- Device grouping and asset assignment to support fleet workflows and operational oversight
- Integration of installation notes and device identifiers so administrators can track physical installation style such as concealed OBD or harnessed setups

## Typical Use Cases

- Real time vehicle tracking for delivery and logistics fleets
- Asset movement visibility for utility and field service operations
- Deployment on vehicles operating in harsh or exposed conditions due to IP67 housing
- Concealed installations for rental fleets or discreet tracking requirements
- Small vehicle and light commercial fleet monitoring where compact form factor and simple installation are priorities

## Feature Availability Notes

- TLS v1.2 encryption is present in supported Trace5 variants and may not be available in the Trace5-LTE variant per manufacturer specifications
- Some features and behaviors depend on firmware version, regional model, or optional accessories; not all units will match the same feature set
- Installation type and harness selection can affect which physical connections and events are available to Plaspy
- Manufacturer tools described such as Device Center and Installation Assistant are provided by Ruptela and may be updated independently of Plaspy

## Why Use Plaspy with These Features

Using the Ruptela Trace5 together with Plaspy provides a practical path from rugged, accurate vehicle tracking hardware to organized operational insight. Plaspy surfaces location history, connectivity status, and device reported events so operations teams can manage fleets, investigate incidents, and optimize routes with clear, consolidated data.

To learn more about Plaspy and how Trace5 devices integrate into the platform visit https://www.plaspy.com. For the most current and detailed device specifications, firmware notes, and manufacturer guidance please verify feature details on the official Ruptela website https://ruptela.com/ as device features and firmware behavior can change over time.
