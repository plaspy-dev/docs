# Ruptela - Eco5 Lite Features

This page provides a public overview of the Ruptela Eco5 Lite features as they relate to use with Plaspy. It summarizes the device capabilities you can expect to see in Plaspy for real time tracking, short range Bluetooth telemetry, basic vehicle inputs and energy efficient operation. The focus here is practical feature context for fleet and light telematics deployments rather than step by step configuration.

Exact feature availability and behavior can vary depending on device firmware, hardware revision, installation type and manufacturer implementation. For device specific configuration, firmware details, and the latest technical specifications please consult the manufacturer documentation.

## Feature Overview

The Eco5 Lite is a compact, energy efficient tracker designed for straightforward fleet tracking and basic telemetry. It combines a modern GNSS receiver with BLE 5.0, low power modes, and simple vehicle I O to provide dependable location and event reporting in a slim IP54 housing.

- Slim 14 mm form factor and IP54 rated housing for discreet vehicle installations.
- Energy efficient operation with very low deep sleep consumption for long term installs.
- High performance u blox GNSS for accurate positioning and BLE 5 0 for driver ID and short range sensors.
- Cellular connectivity in 4G Cat 1 and Cat M1 variants with 2G fallback to support broad regional coverage.
- Basic vehicle I O including digital and analog inputs plus a digital output for event detection and simple control.

## Core Features of Ruptela - Eco5 Lite

- Compact, vehicle friendly form factor at approximately 14 mm thickness for space constrained installations.
- IP54 rated enclosure for protection in common vehicle environments.
- Energy efficient design with very low deep sleep consumption for extended deployments.
- High performance u blox GNSS module to provide dependable positioning.
- BLE 5 0 support for driver identification and short range Bluetooth sensors or beacons.
- Cellular variants offering 4G Cat 1 and 4G Cat M1 with 2G fallback for broad network reach.
- Jamming detection to help identify GNSS interference events.
- Built in backup battery to maintain operation during primary power interruptions and basic digital and analog I O for telemetry and control.

## How These Features Work with Plaspy

Plaspy receives standard telematics streams from the Eco5 Lite so you can visualize location, monitor events, and include device telemetry in reports and alerts. Plaspy automatically detects common tracker protocols and will show incoming location and telemetry data alongside other fleet assets.

- Real time location updates and GNSS based tracking are visible in Plaspy for route monitoring and historical playback.
- Digital input changes such as ignition, door or alarm signals can be mapped to Plaspy events and triggers.
- Analog input readings and paired BLE sensor data can be used in Plaspy for simple telemetry reporting and notification rules.
- BLE based driver identification and short range sensors appear as supplemental telemetry to improve asset context in Plaspy.
- Jamming detection and backup battery events can be surfaced as alerts to help maintain situational awareness.

## Typical Use Cases

- Fleet tracking for route monitoring, asset visibility, and basic operational reporting.
- Anti theft monitoring and stolen vehicle recovery aided by continuous location updates and jamming alerts.
- Driver identification and event logging using BLE driver ID combined with digital inputs for ignition and door status.
- Basic cargo awareness using short range BLE sensors and analog input reading where applicable.
- Low power or space constrained installations such as trailers, service vehicles, or small vans.
- Simple remote control or immobilization workflows when a digital output is configured as part of the installation.

## Feature Availability Notes

- Feature sets can differ by firmware version and hardware revision; newer firmware can add functionality or change behavior.
- Regional cellular variants are available and network support may vary by model and country.
- Some features depend on how the device is installed and wired; available inputs or outputs in your installation affect what Plaspy receives.
- BLE functionality requires paired sensors or driver ID tags and appropriate placement for reliable short range detection.
- For remote configuration and firmware management Ruptela provides device management tools; check manufacturer guidance for update procedures.
