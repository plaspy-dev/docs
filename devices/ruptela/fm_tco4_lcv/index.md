# Ruptela - FM-Tco4 LCV

![FM-Tco4 LCV](./logo.jpg)

The Ruptela FM-Tco4 LCV is a GPS tracker designed for light commercial vehicles such as vans and passenger cars. It gathers vehicle location and route information while also reading on board computer data for LCV platforms, enabling mileage, speed and fuel level monitoring directly from the vehicle system. The device includes features oriented to fleet operations like engine error code reading, driver registration, remote ignition blocking, internal geozones and anti jamming measures.

As a Plaspy compatible device, the FM-Tco4 LCV can feed vehicle and fleet data into Plaspy for unified monitoring and reporting. Its ability to provide fuel consumption and engine code information without extra sensors aligns with Plaspy use cases for fuel management, driver accountability and preventive maintenance oversight. This compatibility allows fleet managers to consolidate tracking, alerts and historical reports in a single platform.

## Key Highlights

- Designed for light commercial vehicles including vans and passenger cars
- Reads vehicle on board computer data for fuel level and consumption monitoring
- Can report OBD II engine error codes to support preventive maintenance
- Driver registration and identification for accountability and operator tracking
- Remote ignition blocking for enhanced vehicle security and theft prevention
- Internal geozones and antijamming features to improve operational reliability

## How It Works with Plaspy

When integrated with Plaspy, the FM-Tco4 LCV delivers vehicle position and on board data into Plaspy dashboards and reporting tools. Plaspy ingests the tracked information to offer visibility across fleets and to trigger operational alerts based on vehicle events or thresholds.

- Live and historical location tracking displayed on Plaspy maps for route review
- Fuel level and consumption data used in Plaspy reports to monitor efficiency and cost
- Engine error code events surfaced in Plaspy to support maintenance planning
- Driver identification events logged for duty attribution and activity audits
- Geozone and security events routed to Plaspy alerts for timely notifications

## Typical Use Cases

- Monitoring delivery van fleets to improve routing and on time performance
- Fuel management programs for cost control across small commercial fleets
- Service and maintenance fleets tracking to detect engine issues early
- Driver assignment and accountability for multi operator operations
- Vehicle security use cases relying on remote ignition blocking and alerts
