# Ruptela - Eco5 Features

This page provides a public feature overview of the Ruptela Eco5 GPS tracker and how its capabilities map into Plaspy for fleet management, cargo monitoring and driver identification. It is intended to describe practical, non-sensitive functions you can expect when deploying the Eco5 with Plaspy and to highlight the kinds of telemetry and operational visibility the device can contribute to your Plaspy dashboards and workflows.

Exact feature availability and behavior can vary by firmware version, hardware revision, installation type and manufacturer implementation. For device-specific technical details, firmware notes and the latest compatibility statements please consult Ruptela documentation and release notes.

## Feature Overview

The Eco5 is a Plaspy compatible tracker designed for reliable positioning, low-power operation and flexible telemetry for vehicle and asset deployments. It combines a premium GNSS module with multiple cellular variants, Bluetooth Low Energy support and a range of inputs and outputs for common fleet telemetry needs.

- High quality GNSS positioning for dependable location reports in Plaspy.
- Multiple cellular options to match network coverage and longevity requirements.
- Rugged IP54 and IP68 housings suitable for a variety of vehicle and cargo environments.
- BLE 5.0 for connecting wireless accessories and peripheral sensors.
- Multiple digital and analog I/O plus a 1-wire interface for driver identification and sensor connections.
- Built-in backup battery and jamming detection for continuity and anti-theft awareness.

## Core Features of Ruptela - Eco5

- Multi-constellation GNSS using a premium u-blox module for consistent position fixes.
- Cellular connectivity options including 4G Cat-1 and 4G Cat-M1 with 2G fallback to support broad deployments.
- Bluetooth Low Energy 5.0 for wireless accessory connectivity such as BLE sensors and beacons.
- Multiple inputs and outputs: digital inputs, digital outputs and combo analog/digital inputs plus a 1-wire interface.
- Rugged form factors available in IP54 and IP68 housings to suit different installation environments.
- Built-in backup battery to maintain reporting during primary power interruptions.
- Jamming detection to provide device status indicators relevant for security monitoring.
- Ultra-low deep-sleep current to support long-term parked deployments and reduced power drain.

## How These Features Work with Plaspy

When the Eco5 reports telemetry to Plaspy, location, I/O events, BLE peripheral data and device status are mapped into Plaspy interfaces so fleet managers can monitor assets and respond to events in near real time. Integration into Plaspy enables the device to feed maps, reports and alerts that support everyday operational decisions.

- Real-time location streams and historical route playback visible on Plaspy maps.
- Digital and analog input events reflected in Plaspy event logs and used in rule-based alerts.
- 1-wire driver identification events linked to driver assignment and behavior reports in Plaspy.
- BLE accessory readings (where configured and available) presented in Plaspy as additional telemetry for cargo or environmental monitoring.
- Device status notifications such as backup battery activity and jamming detection surfaced in Plaspy for security and continuity monitoring.

## Typical Use Cases

- Mixed fleet tracking for light and heavy vehicles across urban and regional operations.
- Anti-theft monitoring with jamming detection and backup battery alerts for recovery workflows.
- Fuel-level and analog telemetry reporting to support consumption analysis and loss prevention.
- Driver identification and duty attribution using the 1-wire interface for accurate driver logs.
- Cargo condition monitoring with BLE sensors feeding temperature or status data where applicable.
- Scalable deployments that require rugged hardware and remote device management.
