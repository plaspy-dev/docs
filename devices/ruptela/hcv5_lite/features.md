# Ruptela - HCV5 Lite Features

This page summarizes the public feature context for using the Ruptela HCV5 Lite with Plaspy. It focuses on practical capabilities and how those capabilities are typically used inside Plaspy for vehicle tracking, telemetry, and operational visibility. The content is intended for fleet managers, integrators, and technical readers looking for a clear overview of what the HCV5 Lite provides when connected to the Plaspy platform.

Exact feature availability and behavior can vary by device firmware, hardware revision, the chosen installation method, and manufacturer implementation. For the most current and detailed device specifics, consult official Ruptela documentation and release notes, and confirm configuration details during integration with Plaspy.

## Feature Overview

The HCV5 Lite is built for commercial vehicle tracking and provides a mix of positioning, vehicle interface options, and installation flexibility. It is designed to be compact and easy to install while supporting accessory connectivity and vehicle data reporting that can be consumed by fleet platforms like Plaspy.

- Reliable GNSS positioning powered by u-blox technology for accurate location reporting.
- BLE 5.0 built in to support accessory connectivity and local configuration workflows.
- Multiple inputs, outputs, and accessory interfaces to connect vehicle systems and add-on modules.
- Support for a wide range of OBD and CANbus parameters including certain proprietary manufacturer data.
- Onboard security features such as jamming detection and an internal backup battery for continuity.
- Compact screwless housing with dedicated device center and installation assistant tools for simplified installations, plus options for wireless solutions and concealed OBD installation.

## Core Features of Ruptela - HCV5 Lite

- GNSS positioning using u-blox modules for consistent location updates.
- BLE 5.0 for accessory pairing and local device interactions during setup and service.
- Multiple physical inputs and outputs and accessory interfaces for vehicle integration.
- Support for OBD and CANbus parameter reading including manufacturer specific data where available.
- Jamming detection to signal potential RF interference with GNSS reception.
- Integrated backup battery to maintain operation and event reporting during power interruptions.
- Compact, screwless housing and installation tools plus optional concealed OBD mounting and tailored harnesses.

## How These Features Work with Plaspy

When paired with Plaspy, the HCV5 Lite's capabilities translate into improved visibility and operational data for fleet monitoring and reporting. Plaspy automatically detects supported tracker protocols and ingests device reports so users can view location histories and vehicle telemetry without manual protocol selection.

- GNSS position reports populate live maps and historical trip views in Plaspy for route analysis and location awareness.
- OBD and CANbus parameters reported by the device appear as telemetry points and vehicle metrics inside Plaspy dashboards and reports.
- Jamming detection events can be surfaced in Plaspy as alerts or log entries to help identify potential signal interference incidents.
- Backup battery operation helps maintain continuity of events and location reporting to Plaspy during temporary power loss.
- BLE and accessory connectivity support local setup and accessory pairing workflows that complement Plaspy device provisioning and on vehicle commissioning.
- Plaspy supports common transport options used by trackers and automatically handles protocol detection during device connection.

## Typical Use Cases

- Commercial fleet tracking for heavy and light vehicles with location history and route replay.
- Vehicle telemetry collection and fleet health monitoring using OBD and CANbus parameter reporting.
- Secure installations where concealed OBD mounting or tailored harnesses are preferred.
- Operations that benefit from local accessory pairing and setup through BLE during installation.
- Monitoring for signal interference using jamming detection to improve asset security.
- Use in mixed fleets where compact form factor and flexible interfaces simplify standardized installations.
