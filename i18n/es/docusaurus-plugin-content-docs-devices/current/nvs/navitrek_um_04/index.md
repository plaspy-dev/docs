# NVS - Navitrek UM-04

![Navitrek UM-04](./logo.jpg)

El conjunto de equipos Navitrek "UM-04" de NVS es un dispositivo de automóvil que proporciona la determinación de parámetros de navegación de un vehículo utilizando las señales de los sistemas de navegación por satélite GLONASS / GPS. Además de la navegación, este dispositivo también permite la supervisión del estado del vehículo, la notificación de eventos de alarma y el intercambio de información con el centro de despacho.

El conjunto de equipos Navitrek UM-04 está diseñado para funcionar como parte del Sistema Automatizado de Monitoreo y Control de Navionis, pero también es compatible con otros complejos de software de monitoreo de transporte. Esto significa que puede integrarse fácilmente en diferentes sistemas de monitoreo existentes para mejorar la eficiencia y la seguridad del transporte.

Características destacadas:

- Determinación de parámetros de navegación utilizando señales GLONASS / GPS
- Supervisión del estado del vehículo
- Notificación de eventos de alarma
- Intercambio de información con el centro de despacho
- Compatible con el Sistema Automatizado de Monitoreo y Control de Navionis
- Integración con otros complejos de software de monitoreo de transporte
