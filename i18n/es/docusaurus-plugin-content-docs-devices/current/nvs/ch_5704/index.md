# NVS - CH-5704

![CH-5704](./logo.jpg)

El rastreador GPS NVS CH-5704 es un conjunto de terminal de automóvil fabricado por ZAO KB NAVIS. Este rastreador utiliza las señales del sistema de navegación GLONASS / GPS / GALILEO / SBAS SNS y transmite datos a través del canal GSM.

Este conjunto de terminal de automóvil está diseñado para ser utilizado como un sistema de monitoreo y protección de vehículos. Está desarrollado sobre la base del receptor de navegación NV08C fabricado por ZAO KB NAVIS. El terminal cuenta con un protocolo abierto de intercambio de información y puede integrarse en cualquier sistema de navegación e información existente.

Características destacadas:

- Compatible con las señales GLONASS / GPS / GALILEO / SBAS SNS
- Transmisión de datos a través del canal GSM
- Protocolo abierto de intercambio de información
- Integración en sistemas de navegación e información existentes
