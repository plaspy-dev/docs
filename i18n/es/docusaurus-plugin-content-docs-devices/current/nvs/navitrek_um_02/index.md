# NVS - Navitrek UM-02

![Navitrek UM-02](./logo.jpg)

El dispositivo de búsqueda autónoma Navitrek UM-02 de NVS es un rastreador GPS compacto diseñado para localizar objetos y transmitir esta información a través de canales GPRS / SMS al centro de control. Con este dispositivo, los usuarios pueden ver la ubicación en tiempo real en su computadora o teléfono móvil.

El Navitrek UM-02 utiliza el receptor certificado nacional GLONASS / GPS serie NV08C fabricado por ZAO KB NAVIS, lo que proporciona al usuario una serie de ventajas adicionales. Este receptor ofrece una mayor precisión y confiabilidad en la localización de objetos, incluso en áreas con una señal de GPS débil. Además, el Navitrek UM-02 cuenta con una batería de larga duración que garantiza un seguimiento continuo durante períodos prolongados.

Características destacadas del Navitrek UM-02:

- Localización en tiempo real a través de canales GPRS / SMS
- Receptor certificado nacional GLONASS / GPS serie NV08C para una mayor precisión y confiabilidad
- Batería de larga duración para un seguimiento continuo
- Compacto y fácil de instalar
