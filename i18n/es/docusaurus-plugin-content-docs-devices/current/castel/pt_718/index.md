# Castel - PT-718

![PT-718](./logo.jpg)

El Castel PT-718 es un rastreador GPS portátil y compacto diseñado para localizar personas, vehículos y mascotas. Combina posicionamiento por GPS y A‑GPS con conectividad GSM/GPRS para ofrecer actualizaciones oportunas de ubicación y admite funciones habituales para la seguridad personal y el seguimiento ligero de activos. El dispositivo prioriza una larga autonomía de espera y bajo consumo energético, a la vez que brinda alarmas prácticas como SOS y notificaciones por geocerca.

Como dispositivo capaz de comunicar la ubicación por SMS o GPRS, el PT-718 es una opción natural para integrarse con Plaspy en tareas de monitoreo y gestión. Plaspy puede recibir y visualizar los reportes de posición de rastreadores compatibles, permitiendo a administradores de flota y usuarios particulares supervisar movimientos, recibir alertas y generar análisis operativos de los dispositivos PT-718 junto con el resto del equipamiento en la plataforma.

## Características principales

- Diseño portátil y liviano, ideal para uso personal y para mascotas
- Función de alerta SOS para notificaciones de emergencia
- Rastreo en tiempo real y posicionamiento por intervalos para información de ubicación actualizada
- Modos de posicionamiento GPS y A‑GPS para mejorar la fiabilidad de los fixes
- Alerta de geocerca para notificar entrada o salida de áreas predefinidas
- Batería integrada de alta capacidad y bajo consumo para una mayor autonomía en espera

## Cómo funciona con Plaspy

Al usarse con Plaspy, el PT-718 proporciona datos de ubicación y alertas que la plataforma presenta para supervisión operativa y respuesta a incidentes. Plaspy centraliza esa información en una vista donde el seguimiento en vivo, la reproducción histórica y la gestión de alertas están disponibles junto con otros dispositivos.

- Vista centralizada de ubicación en tiempo real para dispositivos individuales y grupos
- Mapeo de alertas, incluyendo SOS y notificaciones de geocerca dirigidas a los usuarios de la plataforma
- Reproducción de rutas históricas para revisar movimientos a lo largo del tiempo
- Informes personalizables y exportación de registros de ubicaciones y eventos
- Resumen del estado del dispositivo y conectividad para apoyar decisiones operativas

## Casos de uso típicos

- Monitoreo de seguridad personal para niños, adultos mayores y trabajadores solitarios
- Rastreo de mascotas para localizar y recuperar animales perdidos
- Localización de vehículos ligeros o scooters para flotas pequeñas
- Supervisión temporal de activos para equipos en tránsito
- Monitoreo situacional cuando se requiere un rastreador compacto y portátil

## Por qué elegir este rastreador con Plaspy

El PT-718 ofrece un factor de forma compacto con funciones esenciales de seguimiento y alarma que se alinean bien con los casos de uso de Plaspy en seguridad personal y supervisión de flotas a pequeña escala.
