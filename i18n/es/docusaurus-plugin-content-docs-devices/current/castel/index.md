# Castel

Castel es una marca reconocida por su hardware para el seguimiento de vehículos y activos. En esta página encontrará orientación clara sobre cómo integrar dispositivos Castel con Plaspy para la supervisión de flotas, qué capacidades suelen ofrecer los equipos y cómo localizar los modelos compatibles. Use el catálogo más abajo para ver los dispositivos Castel soportados y acceda a la documentación específica de cada equipo cuando esté listo.

<BrandCatalog brand={brand} />

## Cómo funcionan los dispositivos Castel con Plaspy

Los rastreadores Castel transmiten la ubicación y el estado de activos y vehículos. Plaspy recibe la telemetría de los modelos compatibles y procesa esos datos para ofrecer ubicaciones en tiempo real, recorridos históricos, alertas e informes. Si un dispositivo Castel figura en el catálogo, puede conectarse a Plaspy configurando el envío de datos hacia la plataforma y mapeando su telemetría dentro de Plaspy. El BrandCatalog lista los modelos con compatibilidad conocida para que identifique el equipo correcto y siga los pasos de configuración específicos en las páginas de detalle del dispositivo.

## Funciones comunes en los dispositivos Castel

Aunque las capacidades varían según el modelo, muchos equipos Castel comparten funciones telemáticas útiles para seguimiento de flotas y activos:
- Reporte de posición GPS para ubicación en tiempo real y rastro de puntos
- Detección de movimiento e ignición, útil para seguimiento de vehículos
- Soporte básico de entradas digitales y analógicas para sensores y estados
- Reporte de batería y alimentación para rastreadores portátiles o instalados en vehículos

Para conocer conjuntos de funciones y parámetros de configuración por modelo, seleccione un dispositivo en el catálogo y siga las instrucciones de la página correspondiente.

## Casos de uso típicos para rastreadores Castel

Los dispositivos Castel se usan frecuentemente en escenarios como:
- Seguimiento de vehículos de flota para visibilidad en ruteo y despacho
- Monitoreo de activos como remolques, maquinaria y equipos en renta
- Supervisión de estado mediante entradas digitales que informan sobre el equipo
- Rastreo de activos con batería para equipos sin fuente de energía continua donde la ubicación periódica es suficiente

Estos casos de uso encajan con las capacidades de Plaspy, que agrega telemetría, gestiona alertas y genera reportes para obtener información operativa.

## Por qué elegir Plaspy para monitorear dispositivos Castel

Plaspy es una plataforma diseñada para aceptar y normalizar telemetría de una amplia variedad de dispositivos y marcas. Al elegir Plaspy para monitorear Castel usted obtiene:
- Una interfaz unificada para ver ubicaciones, recorridos y alertas en flotas mixtas
- Herramientas de geocercas, reproducción histórica y reportes de eventos
- Una capa de integración que facilita la incorporación de dispositivos compatibles

Si está evaluando plataformas, revise los detalles de cada dispositivo en el BrandCatalog y consulte las páginas de dispositivo para seguir la guía paso a paso de conexión. Para información general sobre la plataforma visite https://www.plaspy.com.

## Ayuda para encontrar el dispositivo Castel adecuado

Si no está seguro de qué dispositivo Castel se ajusta a su proyecto:
1. Use el BrandCatalog más arriba para explorar los modelos disponibles y sus miniaturas.
2. Abra las páginas de cada dispositivo para ver especificaciones técnicas y notas de configuración.
3. Compare características necesarias como tipo de alimentación, número de entradas y frecuencia de actualizaciones con su caso de uso.
4. En caso de dudas, pruebe con un dispositivo para verificar el flujo de telemetría hacia Plaspy antes de un despliegue masivo.

Las páginas de dispositivo incluyen consejos de configuración que explican cómo apuntar un rastreador a Plaspy y cómo verificar la llegada de datos en la plataforma.
