# Castel - IDD-213N

![IDD-213N](./logo.jpg)

El rastreador GPS Castel IDD-213N es un dispositivo inteligente de diagnóstico a bordo y tecnología plug-and-play, diseñado para ser compatible con vehículos de pasajeros y comerciales. Este dispositivo es capaz de leer la información de diagnóstico a partir de los datos del ECU del vehículo y capturar la ubicación, para luego enviarlos en tiempo real a un servidor backend con fines de diagnóstico y seguimiento a distancia.

El IDD-213N cuenta con una red de apoyo 3G \(N: 800/850/1700/1900\) y está equipado con componentes de alta calidad de clase industrial. Es compatible con OBD II / EOBD, J1939 y J1708, lo que lo hace versátil y adaptable a diferentes tipos de vehículos.

Entre las características destacadas de este rastreador GPS se encuentran:

- Tecnología Plug & Play, que facilita su instalación y uso.
- Recopilación exhaustiva de datos y análisis, incluyendo datos de diagnóstico, ubicación y comportamiento de conducción.
- Seguimiento en tiempo real para una supervisión constante del vehículo.
- Lectura de datos de diagnóstico, como velocidad del vehículo, RPM, etc.
- Lectura de códigos de diagnóstico y datos de trama congelados.
- Estadísticas de kilometraje y consumo de combustible.
- Control de comportamiento de conducción, como exceso de velocidad, aceleración/desaceleración brusca, motor inactivo, entre otros.
- Envío de alarmas vía SMS al terminal del usuario.
- Conexión al servidor backend a través de dominio o dirección IP.

El rastreador GPS Castel IDD-213N es ideal para la gestión de flotas y la localización de vehículos, así como para la industria de alquiler de coches y el seguro de vehículos. Su capacidad de diagnóstico y seguimiento en tiempo real lo convierten en una herramienta valiosa para optimizar la eficiencia y seguridad de los vehículos.
