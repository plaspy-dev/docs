# LK-GPS - LK900

![LK900](./logo..jpg)

El rastreador GPS LK900 \(A/B/C\) de la marca KJ-GPS es un dispositivo de seguimiento GPS+GSM para vehículos con una batería de larga duración de 5000/10000/20000 mAh. Este rastreador magnético para automóviles utiliza tecnología 4G y se puede monitorear en tiempo real a través de una plataforma o aplicación. Es ideal para rastrear vehículos privados, alquiler de vehículos y equipos externos, así como contenedores y cargas.

El LK900 ofrece una amplia gama de funciones, incluyendo seguimiento en tiempo real, seguimiento automático, seguimiento en áreas sin cobertura, alertas de GPS y GSM, revisión de historial de rutas, geovalla, alerta de batería baja, alerta de caída, alerta de exceso de velocidad, alerta de sensor de movimiento, modo de suspensión, alerta de impacto y alerta de movimiento. Además, cuenta con una batería de respaldo incorporada de 20000mAh para un uso prolongado.

Este rastreador GPS también cuenta con un imán potente incorporado que permite una fácil fijación a superficies metálicas, así como con un modo de ahorro de energía en reposo que prolonga la vida útil de la batería cuando el dispositivo no está en uso activo. También ofrece la capacidad de monitorear de forma remota el sonido ambiente y tiene un nivel de resistencia al agua y al polvo IP67.

Con el rastreador GPS LK900 de KJ-GPS, puede tener la tranquilidad de saber la ubicación de su vehículo en todo momento y recibir alertas instantáneas en caso de cualquier evento sospechoso o inusual.
