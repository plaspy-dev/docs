# KHD - KC200

![KC200](./logo.jpg)

El rastreador GPS KC200 de la marca KHD es una solución potente y confiable para el seguimiento de vehículos y buques. Diseñado con tecnología de comunicación inalámbrica GSM y sistema GPS \(o GLONASS\), este rastreador ofrece una sensibilidad de recepción superior para una precisión óptima en la ubicación y seguimiento de activos.

El KC200 se destaca por su capacidad de comunicarse con el servidor back-end a través de la red GPRS/GSM o SMS, lo que permite reportar alertas de emergencia, cruces de fronteras Geo-Fence y programación. Además, los usuarios pueden configurar fácilmente sus propias plataformas de seguimiento personalizadas para comunicarse con el KC200, ya sea a través de una PC o un teléfono inteligente con sistema operativo Android o iOS.

Características destacadas:

- Tecnología de comunicación inalámbrica GSM
- Sistema GPS \(o GLONASS\) para una precisión óptima
- Sensibilidad de recepción superior
- Comunicación con el servidor back-end a través de GPRS/GSM o SMS
- Alertas de emergencia y cruces de fronteras Geo-Fence
- Configuración personalizada de plataformas de seguimiento
- Compatibilidad con PC y teléfonos inteligentes Android e iOS
