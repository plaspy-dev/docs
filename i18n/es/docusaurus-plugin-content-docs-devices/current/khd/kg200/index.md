# KHD - KG200

![KG200](./logo.jpg)

El rastreador GPS KG200 de KHD es una solución potente y confiable para el seguimiento de vehículos y buques. Diseñado con tecnología de comunicación inalámbrica GSM y el sistema GPS \(o GLONASS\), este rastreador ofrece una sensibilidad de recepción superior para una precisión óptima en la ubicación y seguimiento de activos.

El KG200 se comunica con el servidor back-end a través de la red GPRS / GSM \(o SMS\), lo que permite la transmisión de alertas de emergencia, cruces de fronteras Geo-Fence y programación. Además, los usuarios pueden configurar fácilmente sus propias plataformas de seguimiento personalizadas para comunicarse con el KG200 a través de PC y Smartphones con sistema operativo Android o iOS.

Características destacadas:

- Tecnología de comunicación inalámbrica GSM y sistema GPS \(o GLONASS\)
- Sensibilidad de recepción superior para una precisión óptima
- Comunicación con el servidor back-end a través de la red GPRS / GSM \(o SMS\)
- Transmisión de alertas de emergencia, cruces de fronteras Geo-Fence y programación
- Configuración personalizada de plataformas de seguimiento a través de PC y Smartphones
