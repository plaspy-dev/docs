# KHD - KG300 — Funciones

Esta página ofrece un panorama público de las funciones del rastreador GNSS KHD KG300 y cómo se aprovechan esas capacidades con Plaspy para el rastreo, monitoreo y alertas de vehículos. Resume las funciones prácticas del KG300, como posicionamiento GNSS (GPS o GLONASS), reporte de datos por celular y soporte para alertas de emergencia, geocercas e informes programados cuando se integra con una plataforma de rastreo como Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Use esta página como guía general sobre lo que el KG300 puede hacer con Plaspy y confirme los detalles específicos por región y firmware con el fabricante y la documentación del dispositivo.

## Resumen de funciones

El KG300 es un rastreador GNSS diseñado para el seguimiento y monitoreo de vehículos y para aplicaciones publicitarias que requieren visibilidad de ubicación. Combina posicionamiento satelital con reporte celular para entregar actualizaciones regulares de ubicación y notificaciones de eventos a backends y plataformas personalizadas.

- Posicionamiento GNSS preciso mediante GPS o GLONASS para conocer la ubicación del vehículo
- Comunicación celular por GPRS/GSM para reporte de datos en tiempo real y SMS como canal alterno
- Reporte de eventos para alertas de emergencia, cruces de geocercas e informes programados
- Soporte para integración con plataformas de rastreo personalizadas en PC y smartphones mediante conexiones de red estándar
- Diseñado para despliegues en vehículos y para aplicaciones publicitarias donde se requiere visibilidad continua de la ubicación

## Funciones principales del KHD - KG300

- Posicionamiento GNSS compatible con GPS o GLONASS
- Reporte de datos por GSM usando GPRS para comunicación con servidores
- Canal de reporte por SMS como respaldo para mensajes y alertas
- Reporte de eventos en tiempo real para alertas de emergencia
- Notificaciones de cruces de geocerca para monitoreo de zonas
- Informes programados para enviar actualizaciones periódicas de ubicación o estado
- Diseñado para integrarse con plataformas personalizadas en PC, Android e iOS

## Cómo funcionan estas funciones con Plaspy

Plaspy recopila y muestra las actualizaciones de ubicación y los reportes de eventos del KG300 para ofrecer una vista centralizada de vehículos y alertas. Cuando configura el dispositivo para reportar a Plaspy, el KG300 puede enviar sus fijaciones GNSS y notificaciones de eventos al backend de Plaspy para que los operadores monitoreen el movimiento y respondan a incidentes desde una misma plataforma.

- Las actualizaciones de ubicación aparecen en los mapas de Plaspy para seguimiento en tiempo real y reproducción de recorridos
- Las notificaciones de eventos, como alertas de emergencia y cruces de geocerca, se presentan como eventos monitoreables
- Los informes programados del dispositivo se muestran como actualizaciones periódicas de posición dentro de Plaspy
- Los dispositivos pueden configurarse para comunicarse con Plaspy usando TCP o UDP en el puerto de ingestión común de Plaspy
- El SMS puede usarse como vía alterna de reporte cuando no hay datos celulares, con eventos reenviados a la plataforma Plaspy donde esté soportado
- Plaspy detecta automáticamente muchos protocolos comunes de rastreadores para simplificar la incorporación de dispositivos compatibles

## Casos de uso típicos

- Rastreo de flotas para despacho y supervisión de rutas
- Monitoreo de actividad vehicular y detección de violaciones de geocerca para control de acceso a sitios
- Reportes periódicos de ubicación para cumplimiento o revisiones regulares
- Reporte de alertas de emergencia para notificar a los operadores sobre incidentes
- Verificación de ubicaciones y seguimiento de entregas en aplicaciones publicitarias basadas en vehículos
- Integración con paneles personalizados en móviles o PC para presentar datos de ubicación y eventos

## Notas sobre la disponibilidad de funciones

- Las diferencias de firmware pueden afectar qué eventos y modos de reporte están disponibles en una unidad específica
- Las revisiones de hardware y las variantes regionales pueden cambiar las bandas celulares soportadas o el conjunto de funciones
- El tipo de instalación y el cableado pueden influir en la funcionalidad disponible y en la fiabilidad de los reportes
- El reporte por SMS depende de la red local y del servicio de la SIM y suele actuar como respaldo
- Verifique siempre el comportamiento específico del dispositivo respecto a geocercas, emergencias y funciones programadas en la documentación del fabricante

## Por qué usar Plaspy con estas funciones

Usar el KG300 con Plaspy ofrece a las organizaciones visibilidad centralizada de ubicaciones de vehículos, alertas de eventos e informes programados. La plataforma de Plaspy agrega fijaciones GNSS y mensajes de eventos de rastreadores compatibles para que los equipos puedan visualizar movimientos, configurar notificaciones y mantener supervisión operativa sin gestionar múltiples canales de reporte.

Para más información sobre Plaspy y cómo admite integraciones de dispositivos, visite https://www.plaspy.com. Para las especificaciones más actuales del dispositivo, notas de firmware y detalles del fabricante del KG300, verifique la información en el sitio oficial de KHD en http://www.khd.hk.
