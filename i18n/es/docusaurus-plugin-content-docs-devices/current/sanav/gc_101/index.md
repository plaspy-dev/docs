# Sanav - GC-101

![GC-101](./logo.jpg)

El SANAV GC-101 es un rastreador GPS compacto diseñado para aplicaciones de seguimiento intensivo, como la gestión de flotas y la seguridad personal. Utiliza GPRS para subir sentencias RMC que contienen latitud, longitud, velocidad y hora a un servidor web asignado. El equipo ofrece cobertura GSM cuatribanda, memoria interna y una batería de respaldo para preservar los datos durante interrupciones de energía, además de una carcasa plástica resistente con antenas GSM internas para una instalación de bajo perfil.

Como dispositivo compatible con Plaspy, el GC-101 es idóneo para proporcionar flujos continuos de ubicación y telemetría básica que Plaspy puede ingerir para monitoreo e informes. Su soporte para comunicaciones TCP y UDP, el reporte de posiciones configurable por tiempo o distancia, el modo de reposo para reducir transmisiones y la entrada de pánico lo convierten en una opción práctica para organizaciones que requieren visibilidad constante de vehículos y activos dentro de la plataforma Plaspy.

## Características principales

- Subida por GPRS de sentencias RMC con latitud, longitud, velocidad y hora para un reporte de posición sencillo  
- Soporte GSM cuatribanda para conectividad amplia en distintas zonas  
- Batería de respaldo y memoria interna para conservar datos ante cortes de energía o fallas de red  
- Comunicación con servidor mediante TCP y UDP para flexibilidad en la entrega de datos  
- Reporte de posición por tiempo o distancia para ajustar la frecuencia de actualizaciones según necesidades operativas  
- Modo de reposo para reducir transmisiones y ahorrar energía entre informes  
- Entradas predefinidas como botón de pánico, carcasa compacta de plástico y antenas internas

## Cómo funciona con Plaspy

Al conectarse a Plaspy, el GC-101 puede enviar datos posicionales en formato RMC a los servidores de Plaspy, donde se muestran, registran y utilizan para activar alertas e informes. Plaspy interpreta la hora, la posición y la velocidad para ofrecer visibilidad en tiempo real y reproducción histórica, permitiendo además que usted configure reglas de notificación e intervalos de reporte según sus necesidades operativas.

- Visualización de ubicación en tiempo real y seguimiento en mapas dentro de Plaspy basados en las sentencias RMC subidas  
- Reproducción histórica de rutas e informes utilizando las marcas de tiempo y posiciones almacenadas por el rastreador  
- Generación de alertas en Plaspy a partir de entradas predefinidas como eventos del botón de pánico para respuesta rápida  
- Uso de reportes basados en tiempo o distancia para equilibrar frecuencia de actualizaciones, consumo de datos y duración de batería  
- Manejo de continuidad de datos en Plaspy cuando el dispositivo usa memoria interna y alimentación de respaldo para almacenar y luego subir posiciones no transmitidas

## Casos de uso típicos

- Seguimiento de vehículos de flotas y supervisión operativa para transporte y servicios  
- Monitoreo de seguridad de activos como equipos valiosos y remolques  
- Seguridad personal y monitoreo de personas en los que se requiere entrada de pánico  
- Visibilidad en entregas y logística con intervalos de reporte configurables  
- Seguimiento remoto o transregional donde el GSM cuatribanda asegura mayor conectividad

## Por qué elegir este rastreador con Plaspy

El GC-101 ofrece una combinación práctica de reporte continuo de ubicación, resiliencia de datos y opciones flexibles de comunicación que encajan con los flujos de trabajo habituales en Plaspy. Su capacidad para almacenar datos durante cortes y reportar por tiempo o distancia lo hace adecuado para operaciones que necesitan seguimiento fiable con control sobre el flujo de datos.

Para organizaciones que evalúan rastreadores para usar con Plaspy, el GC-101 puede ser una opción sensata cuando necesita un dispositivo sencillo capaz de entregar sentencias de posición estándar y entradas de eventos básicas a una plataforma de monitoreo. Como siempre, le recomendamos ajustar las capacidades del equipo y los parámetros de reporte a sus requisitos operativos para obtener el máximo valor de Plaspy.
