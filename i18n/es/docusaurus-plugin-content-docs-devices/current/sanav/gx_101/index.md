# Sanav - GX-101

![GX-101](./logo.jpg)

El rastreador GPS Sanav GX-101 está diseñado específicamente para aplicaciones de seguimiento de vehículos. Está equipado con un módulo GSM Siemens y un receptor GPS GM-158 \(chipset MTK-3301\). Su estructura metálica robusta lo convierte en una excelente opción para entornos automotrices. Además, cuenta con entradas y salidas abiertas para sensores y relés. Si estás buscando asegurar tus vehículos favoritos, el Sanav GX-101 será tu mejor elección.

Este rastreador GPS de Sanav ofrece una serie de características técnicas destacadas. Cuenta con una banda GSM cuatribanda completa, lo que garantiza una amplia cobertura de red. No tiene función de voz, pero cuenta con una batería de respaldo para asegurar un seguimiento continuo incluso en caso de pérdida de energía. También tiene memoria interna y permite la posición por tiempo y distancia. Además, cuenta con ahorro de energía para una mayor eficiencia. Con más de 4 entradas digitales, este rastreador GPS ofrece flexibilidad en la conexión de sensores y relés. La carcasa metálica garantiza durabilidad y resistencia en entornos automotrices. El Sanav GX-101 es fabricado en Taiwán, lo que garantiza su calidad y confiabilidad.

En resumen, el rastreador GPS Sanav GX-101 es una excelente opción para aplicaciones de seguimiento de vehículos. Con su robusta estructura metálica, amplia cobertura de red y diversas características técnicas, este rastreador GPS te brindará la tranquilidad de saber dónde se encuentran tus vehículos en todo momento.
