# Sanav - GX-101

<div className="device-logo">
![GX-101](./logo.jpg)
</div>

El Sanav GX-101 es un rastreador GPS para vehículos diseñado para ofrecer un seguimiento confiable a bordo. Combina un receptor GPS GM-158 con un módulo GSM de Siemens para proporcionar reportes de posición y comunicaciones consistentes. El equipo se aloja en una carcasa metálica resistente e incluye puertos I/O abiertos para una integración sencilla con sensores y relés externos. Además, el GX-101 cuenta con cobertura GSM cuatribanda, memoria interna y batería de respaldo para mantener la continuidad del rastreo durante interrupciones de energía o señal.

Como dispositivo compatible con Plaspy, el GX-101 puede enviar datos de ubicación y estado a la plataforma Plaspy para facilitar el monitoreo centralizado y la supervisión de flotas. Su combinación de construcción robusta, opciones flexibles de I/O y la capacidad de reportar posiciones por tiempo y distancia lo convierten en una opción práctica para organizaciones que buscan hardware integrable con software de rastreo en la nube. Plaspy usa los datos del dispositivo para ofrecer mapas en vivo, informes y alertas operativas orientadas a la seguridad vehicular y la gestión de flotas.

## Puntos clave

- Posicionamiento GPS preciso mediante receptor GM-158
- Módulo GSM Siemens con cobertura cuatribanda para conectividad amplia
- Estructura metálica resistente diseñada para entornos a bordo
- Puertos I/O abiertos para integrar sensores y relés
- Memoria interna y batería de respaldo para preservar datos durante interrupciones
- Reporte de posición configurable por tiempo y distancia para un seguimiento flexible

## Cómo funciona con Plaspy

El Sanav GX-101 envía la ubicación y el estado del dispositivo a Plaspy para que los gestores de flota puedan supervisar los vehículos desde una sola plataforma. Plaspy procesa estos datos para presentar información de posición en tiempo real e histórica junto con alertas e informes operativos.

- Ubicación en vivo y visualización en mapa para vehículos individuales y flotas completas
- Reproducción histórica de rutas e informes de viajes basados en marcadores de tiempo y distancia
- Alertas y notificaciones para eventos configurados en Plaspy mediante las señales del dispositivo
- Manejo de dispositivos sin conexión y reporte de datos almacenados soportado por la memoria interna
- Integración con las herramientas de informes de Plaspy para análisis operativo y cumplimiento

## Casos de uso típicos

- Rastreo de flotas para vehículos ligeros y comerciales
- Seguridad vehicular y monitoreo para recuperación de activos
- Supervisión de movimientos de vehículos para mejorar la eficiencia operativa
- Integración con sistemas auxiliares mediante puertos I/O abiertos para funcionalidades adicionales
- Registro de rutas y análisis de viajes para despacho y logística

## Por qué elegir este rastreador con Plaspy

El GX-101 es una opción práctica para organizaciones que necesitan un rastreador vehicular duradero y compatible con una plataforma en la nube como Plaspy. Su diseño robusto y las capacidades ampliadas de I/O lo hacen adaptable a diversas implementaciones de rastreo, mientras que la memoria interna y la batería de respaldo ayudan a mantener la continuidad cuando cambian las condiciones.

Al combinarlo con Plaspy, el GX-101 facilita la incorporación de los datos del hardware a un flujo de trabajo centralizado de gestión de flotas. Plaspy permite ver posiciones en tiempo real, generar informes y configurar alertas para que sus equipos puedan actuar sobre la información de los vehículos de forma eficiente.
