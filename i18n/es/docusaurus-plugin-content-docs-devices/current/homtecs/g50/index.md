# Homtecs - G50

![G50](./logo.jpg)

El enrutador Homtecs G50 es un dispositivo de comunicación inalámbrica de Internet de alta velocidad y resistente. Este enrutador utiliza 5 modos de 13 bandas o 7 modos de 15 bandas de red de banda ancha móvil para proporcionar una conexión conveniente y de alta velocidad. Con un procesador de comunicación dual-core ARM y un sistema operativo en tiempo real integrado, este enrutador ofrece una red inalámbrica segura y estable, así como interfaces Ethernet, RS-485/232 y WiFi 2.4G / 5G.

El Homtecs G50 es ideal para una variedad de aplicaciones, como finanzas, correos, redes eléctricas inteligentes, transporte inteligente, monitoreo ambiental, protección contra incendios, seguridad, conservación del agua, seguridad pública, publicidad, control industrial, monitoreo sísmico, reloj meteorológico e instrumentación.

El diseño industrial del G50 incluye un módulo inalámbrico industrial de alto rendimiento, un procesador ARM dual-core industrial, bajo consumo de energía y una carcasa de metal plateado CRS para una buena disipación de calor. Además, cuenta con una fuente de alimentación de + 7.5V ~ 32V DC y un grado de protección IP34 \(ampliable a IP51\).

Entre las características de red del G50 se incluyen la detección de flujo de puerto, el monitoreo en tiempo real, múltiples protocolos VPN, soporte de función DTU del puerto serie y soporte UPnP. Además, este enrutador ofrece estabilidad con detección de enlaces blandos y de hardware, mecanismos de autocontrol y protección ESD en cada puerto.

La gestión remota del G50 permite la configuración remota de parámetros, copia de seguridad remota, reinicio y consulta de registros, actualización remota y monitoreo en línea. Con todas estas características, el Homtecs G50 es una opción confiable y versátil para satisfacer las necesidades de conectividad en diversas aplicaciones.
