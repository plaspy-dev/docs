# Homtecs - H50

![H50](./logo.jpg)

El enrutador HomtecsM2M H50 3G es una solución de comunicación inalámbrica de internet que utiliza la red de banda ancha móvil HSPA+ para proporcionar una transmisión conveniente y de alta velocidad. Compatible con redes 3G existentes, este enrutador ofrece conectividad HSPA+ de alta velocidad de hasta 21.6 Mbps, así como conectividad estándar HSPA \(21 Mbps\), HSPA, EDGE \(2G\) y GPRS \(2G\).

El HomtecsM2M H50 3G Router es ideal para aplicaciones industriales debido a sus características y construcción resistente. Diseñado para admitir aplicaciones de banda ancha móvil de alta velocidad en áreas como M2M, CCTV, seguridad, medios, energía, servicios públicos, comercio minorista y transporte, este dispositivo se puede utilizar con tarjetas SIM IP fijas o SIM de datos normales. También es compatible con DNS dinámico a través de la red del operador. Las comunicaciones de datos móviles utilizando enrutadores incorporados se están convirtiendo rápidamente en una herramienta esencial para las soluciones de comunicaciones basadas en el campo de los proveedores.

El enrutador 3G HomtecsM2M H50 está diseñado para mantenerse en línea y conectado, con características que garantizan una comunicación remota confiable, segura y discreta. Proporciona una excelente capacidad técnica y una propuesta comercial única en comparación con otros productos en el mercado.

El enrutador HomtecsM2M H50 3G viene con dos antenas de montaje magnético y cuenta con una conexión de antena celular y una conexión de antena WiFi. Además, tiene 4 puertos LAN y 1 puerto WAN, que se pueden configurar para funcionar como un puerto LAN, lo que permite la conexión de hasta cinco dispositivos cableados si es necesario.

### Características destacadas:

- Diseño robusto industrial y carcasa de metal compacta
- Alta velocidad de datos a través de la red 3G, compatible con 2.5G hacia atrás
- Resistencia a la interferencia electromagnética, al calor y capacidad de radiación
- Soporte para múltiples VPN \(PPTP, L2TP, GPE, IPSec, etc.\)
- Soporte para múltiples protocolos de red \(ICMP, TCP, UDP, Telnet, SSH, HTTP, HTTPS, etc.\)
- Soporte para múltiples funciones \(DHCP, DNS, DDNS, Firewall, NAT, DMZ host, etc.\)
- Reloj de pulsera incorporado y detección de enlaces múltiples para garantizar un trabajo estable y seguro
- Soporte para WiFi 802.11b/g/n con velocidad de datos de hasta 21.6 Mbps
- 1 antena GSM y 1 antena WiFi incluidas
- 4 puertos LAN y 1 puerto WAN \(configurable como puerto LAN\)
- Siempre en línea, reinicio automático en caso de desconexión para garantizar una conexión continua
- Soporte para APN y acceso VPDN a redes privadas inalámbricas
- Administración fácil a través de plataforma web, CLI, SSH y SNMP
- Resistente a golpes y vibraciones

El enrutador HomtecsM2M H50 3G es una opción ideal para aquellos que buscan una solución confiable y de alta velocidad para sus necesidades de comunicación inalámbrica.
