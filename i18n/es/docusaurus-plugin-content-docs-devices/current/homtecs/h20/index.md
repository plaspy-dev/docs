# Homtecs - H20

![H20](./logo.jpg)

El enrutador 3G HomtecsM2M H20 es una solución de comunicación inalámbrica de Internet que utiliza la red de banda ancha móvil HSPA+ para proporcionar una transmisión conveniente y de alta velocidad. Con velocidades de hasta 21.6 Mbps, este enrutador es compatible con redes 3G existentes y ofrece conectividad estándar HSPA, HSPA+, EDGE y GPRS.

Este enrutador es ideal para aplicaciones industriales debido a su diseño compacto, características avanzadas y construcción resistente. Está diseñado para admitir cualquier aplicación de banda ancha móvil de alta velocidad en áreas como M2M, CCTV, seguridad, medios, energía, servicios públicos, comercio minorista, transporte y más. Puede utilizarse con tarjetas SIM IP fijas o SIM de datos normales, y también es compatible con DNS dinámico a través de la red del operador.

El enrutador 3G HomtecsM2M H20 está diseñado para mantenerse en línea y conectado, con características que garantizan una comunicación remota confiable y segura. Además, ofrece una conexión LTE de alta capacidad y una excelente capacidad técnica, a un precio competitivo en comparación con otros productos similares en el mercado.

Este enrutador viene con dos antenas de montaje magnético, una para la conexión celular y otra para la conexión WiFi. También cuenta con 1 puerto LAN y 1 puerto WAN, que se pueden configurar para funcionar como un puerto LAN adicional si es necesario.

### Características destacadas:

- Diseño robusto industrial y carcasa de metal compacta
- Alta velocidad de datos a través de la red 3G, compatible con versiones anteriores de 2.5G
- Resistencia a la interferencia electromagnética, al calor y capacidad de radiación
- Soporte para múltiples VPN y protocolos de red
- Reloj de pulsera incorporado y detección de enlaces múltiples para una conexión estable y segura
- Compatibilidad con Wi-Fi 802.11b/g/n y velocidad de datos de hasta 21Mbps
- 1 Antena GSM y 1 Antena WiFi incluidas
- 2xLAN o 1xLAN + 1xWAN
- Siempre en línea, reinicio automático en caso de desconexión
- Admite acceso de red privada inalámbrica APN y VPDN
- Gestión de red SNMP y soporte NTP
- Resistente a golpes y vibraciones

Este enrutador también ofrece funciones opcionales avanzadas, como diferentes tipos de red \(4G, UMTS, EVDO, EDGE, GPRS\), Wi-Fi de mayor velocidad, capacidad de GPS para la gestión de flotas, función de comunicación en serie DTU, OpenVPN, PPTP Sever, comando AT, control por SMS, programación de reinicio y más. Si necesita utilizar estas funciones avanzadas, se recomienda ponerse en contacto con el proveedor antes de realizar la compra.
