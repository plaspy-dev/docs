# ArkNav - K-18U

![K-18U](./logo.jpg)

El K-18U es un registrador de datos GPS que ofrece un seguimiento preciso del satélite GPS y registra los datos en una tarjeta micro SD. Este dispositivo es ideal para el registro de viajes y el seguimiento de activos. El K-18U registra la ubicación, la hora, la fecha y los datos GPS cada segundo, y almacena los datos en formato de sentencias NMEA GPS completas, lo que brinda a los usuarios la libertad de analizar y utilizar los datos de la manera que deseen.

Una de las características destacadas del K-18U es que no requiere la instalación de software o controladores adicionales. Además, es compatible con la mayoría de las tarjetas micro SD y ofrece una capacidad de almacenamiento de datos ilimitada. Los archivos se guardan automáticamente en orden cronológico y el dispositivo se puede conectar a una computadora como una unidad flash extraíble.

Otras características notables incluyen la capacidad de configurar la sensibilidad de movimiento y el intervalo de tiempo para el registro de datos, así como la opción de agregar una suma de comprobación de datos. En resumen, el K-18U es una solución de seguimiento rentable que puede ser utilizado para la vigilancia de empleados, activos de la empresa y flotas.

### Características destacadas:

- Ninguna instalación de software o controladores adicionales.
- Compatible con la mayoría de las tarjetas micro SD.
- Capacidad de almacenamiento de datos ilimitada.
- Guarda las sentencias NMEA GPS \(GPRMC y GPGGA\).
- Guarda los archivos en orden cronológico de forma automática.
- Se conecta a una computadora como una unidad flash extraíble.
- Sensibilidad de movimiento configurable y intervalo de tiempo para el registro de datos.
- Suma de comprobación de datos opcional.
