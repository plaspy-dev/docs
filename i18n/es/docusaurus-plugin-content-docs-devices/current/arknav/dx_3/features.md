# Características de ArkNav - DX-3

Esta página describe el contexto público de funciones para usar el ArkNav DX-3 con Plaspy. Se centra en las capacidades visibles para el usuario y el valor práctico que aporta el DX-3 cuando se integra con Plaspy para seguridad personal, rastreo bajo demanda y notificación rápida de incidentes.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la configuración del fabricante. Considere siempre estas variables al planear despliegues y consulte la documentación del fabricante para detalles técnicos específicos del dispositivo.

## Resumen de funciones

El ArkNav DX-3 es un rastreador GPS personal compacto, compatible con Plaspy, diseñado principalmente para la protección de personas vulnerables y la respuesta ante incidentes. Pone énfasis en la privacidad compartiendo la ubicación continua solo cuando el usuario activa Start Tracking o cuando ocurre una emergencia, y al mismo tiempo ofrece opciones inmediatas de alarma y comunicación para cuidadores y equipos de monitoreo.

- Botón de pánico de goma dedicado y activación por cordón para alertas inmediatas a Plaspy
- Voz bidireccional manos libres con altavoz y micrófono integrados para facilitar la comunicación en incidentes
- Ayudas de accesibilidad como vibración, señales de audio e indicadores LED para usuarios con limitaciones auditivas o visuales
- Rastreo que prioriza la privacidad: la ubicación continua se comparte únicamente bajo demanda o en emergencias
- Carcasa resistente a salpicaduras IP54 y base de carga apilable para un uso diario práctico
- Batería de larga duración de aproximadamente 1100 mAh con alrededor de 72+ horas entre cargas para disponibilidad confiable

## Funciones principales del ArkNav - DX-3

- Alarma de pánico con botón dedicado y activación por cordón para alertas rápidas
- Detección de caída (man-down) y comportamiento de alerta de emergencia integrados en la operación del dispositivo
- Función Start Tracking para compartir ubicación continua bajo demanda solo cuando se necesite
- Comunicación de voz bidireccional mediante el altavoz y micrófono a bordo para comunicación manos libres
- Funciones de accesibilidad incluyendo vibración, avisos de audio e indicadores LED icónicos
- Soporte del protocolo Contact ID para mensajes de alarma estandarizados cuando aplique
- Carcasa resistente a salpicaduras IP54 adecuada para uso portátil diario
- Base de carga apilable y opciones de accesorios para una gestión simple de los dispositivos

## Cómo funcionan estas funciones con Plaspy

Cuando el DX-3 está emparejado con Plaspy, los eventos de alarma y las actualizaciones de ubicación bajo demanda se entregan a la plataforma para que cuidadores, despachadores o equipos de monitoreo puedan actuar rápidamente sin mantener vigilancia continua.

- Plaspy recibe eventos discretos de pánico y detección de caída y los presenta a los operadores para una respuesta rápida
- Las actualizaciones de posición en vivo aparecen en el mapa de Plaspy cuando se activa Start Tracking o durante una sesión de emergencia
- Es posible iniciar sesiones de voz bidireccional durante las alertas para habilitar comunicación directa si la red admite voz
- El reporte de estado de batería y carga por parte del dispositivo ayuda a Plaspy a notificar a los cuidadores sobre baterías bajas y mantener la disponibilidad del equipo
- Los mensajes de alarma en Contact ID pueden integrarse en flujos de recepción de alarmas y en integraciones que soporte Plaspy

## Casos de uso típicos

- Seguridad de personas mayores y protección discreta portátil con alertas inmediatas de pánico y detección de caída para cuidadores
- Protección de trabajadores solitarios con Start Tracking bajo demanda para registros de chequeo y comunicación rápida en incidentes
- Rondas de seguridad y guardias donde se requiere señalización de emergencia simple y voz manos libres sin rastreo continuo
- Monitoreo de personas vulnerables en entornos de atención asistida o comunitaria que priorizan la privacidad y la independencia
- Despliegues temporales y eventos donde las bases de carga apilables y la larga autonomía facilitan la rotación y el mantenimiento de dispositivos

## Notas sobre disponibilidad de funciones

- Las actualizaciones de firmware y software pueden cambiar el comportamiento o activar/desactivar funciones específicas; verifique el nivel de firmware para conocer las capacidades exactas
- Las revisiones de hardware y las variantes regionales pueden afectar accesorios disponibles, protección contra ingreso de agua o protocolos soportados
- Algunas funciones, como la voz bidireccional, dependen de la disponibilidad de servicio de voz en la red y del soporte del operador en la región de despliegue
- Las elecciones de instalación y el uso de accesorios (por ejemplo cordón frente a docking) influyen en cómo se manejan los disparadores de emergencia y la carga
- El soporte de Contact ID puede usarse para mensajería de alarma estandarizada, pero el comportamiento de integración puede depender de la configuración del sistema receptor

## Por qué usar Plaspy con estas funciones

Utilizar el ArkNav DX-3 con Plaspy permite a organizaciones centradas en la seguridad personal consolidar alertas de incidentes y ubicaciones bajo demanda en un flujo único de monitoreo. El enfoque en la privacidad del DX-3 y sus interfaces de emergencia claras permiten que cuidadores y operadores reciban notificaciones accionables sin requerir rastreo continuo, mientras que Plaspy ofrece la visibilidad y el enrutamiento necesarios para una respuesta oportuna.

Si desea saber más sobre Plaspy y cómo soporta dispositivos como el DX-3, visite https://www.plaspy.com. Para las especificaciones más recientes del dispositivo, notas de firmware y detalles de implementación del fabricante, verifique la información actual en el sitio de ArkNav https://www.arknavgps.com.tw/.
