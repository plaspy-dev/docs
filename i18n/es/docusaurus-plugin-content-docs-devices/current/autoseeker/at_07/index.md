# Autoseeker - AT-07

![AT-07](./Logo.jpg)

El Autoseeker AT-07 es un mini rastreador GPS compacto pensado para múltiples escenarios de seguimiento. Se presenta como un dispositivo pequeño y discreto, adecuado para monitorear vehículos, camiones y contenedores, así como para usos de seguridad personal como el seguimiento de adultos mayores o personas con necesidades médicas. El AT-07 destaca por ofrecer visibilidad de la ubicación en tiempo real, una interfaz sencilla para acceder a los datos de seguimiento y una batería de larga duración para soportar usos prolongados.

Como dispositivo compatible con Plaspy, el AT-07 puede integrarse en los flujos de trabajo de la plataforma para proporcionar visibilidad centralizada y supervisión operativa. Los usuarios de Plaspy pueden emparejar el AT-07 con las funciones de la plataforma para seguimiento en mapas, alertas básicas e informes que apoyen la gestión de flotas y la protección de activos. La combinación del hardware AT-07 y el software Plaspy ofrece a las organizaciones una opción directa para necesidades de seguimiento cotidianas.

## Aspectos destacados

- Seguimiento de ubicación en tiempo real para visibilidad continua de activos y personas
- Formato compacto y discreto, fácil de ocultar o sujetar
- Aplicaciones versátiles para vehículos, camiones, contenedores y seguridad personal
- Informes y monitoreo accesibles mediante una interfaz de seguimiento fácil de usar
- Larga duración de batería para reducir la frecuencia de recargas
- Opción práctica tanto para protección de activos como para supervisión básica de flotas

## Cómo funciona con Plaspy

El AT-07 puede integrarse en la plataforma Plaspy para ofrecer una vista única de ubicaciones e historial de movimientos. Dentro de Plaspy, el dispositivo aparece junto a otros rastreadores, de modo que los equipos pueden monitorear unidades en conjunto, generar reportes sencillos y recibir notificaciones oportunas relacionadas con las operaciones.

- Visualice la ubicación en tiempo real del dispositivo en los mapas de Plaspy para mantener conciencia situacional
- Supervise una flota o un grupo de activos en conjunto para obtener una supervisión consolidada
- Configure alertas y notificaciones en Plaspy para destacar eventos importantes
- Acceda al historial de viajes e informes básicos para apoyar la revisión operativa y el registro
- Agrupe dispositivos y gestione la visibilidad según los flujos de trabajo de su organización

## Casos de uso típicos

- Seguimiento de pequeñas flotas de vehículos y camiones
- Monitoreo de contenedores para logística y almacenamiento
- Protección de activos para equipos portátiles de alto valor
- Monitoreo de seguridad personal para adultos mayores o personas con condiciones médicas
- Seguimiento de equipos y alquileres a corto plazo para control operativo
