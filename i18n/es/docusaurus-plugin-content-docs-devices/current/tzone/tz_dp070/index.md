# TZone - TZ-DP070

![TZ-DP070](./logo.jpg)

El monitor de temperatura TZ-LCD070 es un dispositivo desarrollado con el sistema operativo WinCE6.0, diseñado para recibir datos de temperatura a través de RS485 desde un sensor. Este monitor de temperatura se utiliza en conjunto con un lector de RFID y etiquetas de temperatura, y luego envía los datos utilizando tecnología de transmisión inalámbrica 2.4G RF.

Este monitor de temperatura cuenta con una pantalla táctil resistiva de cuatro hilos, lo que facilita su uso y navegación. Además, es compatible con tarjetas SD y MMC, lo que permite almacenar y transferir datos de manera conveniente.

El monitor de temperatura TZ-LCD070 también cuenta con una interfaz Ethernet de 100M, lo que permite una conexión rápida y estable a una red. Además, tiene una interfaz USB para conectar dispositivos externos.

Con una resolución de 800 × 480 píxeles y una pantalla de 7 pulgadas, este monitor de temperatura ofrece una visualización clara y nítida de los datos. Además, cuenta con un nivel de protección IP65 en la parte frontal, lo que lo hace resistente al polvo y al agua.

Con un peso neto de 0.74KG y dimensiones de 206 × 142 × 45 mm, este monitor de temperatura es compacto y fácil de transportar. Además, tiene un rango de temperatura de trabajo de -10 ℃ a +60 ℃ y un rango de humedad de trabajo del 10% al 90% \(sin condensación\).

Este monitor de temperatura funciona con el sistema operativo Windows CE 6.0 R3 y cuenta con retroiluminación LED con una vida útil de más de 25000 horas.

En resumen, el monitor de temperatura TZ-LCD070 es una herramienta confiable y eficiente para monitorear y controlar la temperatura en diversos entornos. Con su pantalla táctil, interfaz Ethernet y capacidad de almacenamiento, este dispositivo ofrece una solución completa para el seguimiento preciso de la temperatura.
