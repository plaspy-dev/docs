# TZone - TZ-BR04

![TZ-BR04](./logo.jpg)

El rastreador GPS TZ-BR04 de la marca TZone es un dispositivo de grado industrial diseñado para funcionar en la banda de frecuencias de microondas ISM general. Con un receptor de señal de larga distancia de hasta 50 metros, este rastreador ofrece un rendimiento confiable y preciso.

Este rastreador GPS funciona con una tensión de trabajo de DC12V a 24V y utiliza el protocolo estándar Bluetooth 4.0. Con una distancia de lectura de tarjeta de hasta 50 metros, este dispositivo es ideal para aplicaciones que requieren un rango de lectura extendido.

El TZ-BR04 cuenta con un modo de salida RS232/RS485 y una sensibilidad de recepción de -85dBm a 1Mbps. Además, tiene una antena externa y una velocidad de transmisión de serie configurable de 115200. Esto garantiza una comunicación estable y confiable con otros dispositivos.

Este rastreador GPS es resistente a condiciones extremas, con una temperatura de trabajo que va desde -40 ℃ hasta +60 ℃. Con dimensiones de L78mm x W67mm x H27mm, es compacto y fácil de instalar en diferentes tipos de vehículos o equipos.

El TZ-BR04 también cuenta con la capacidad de leer el estado de la tarjeta y tiene un ángulo de identificación omnidireccional. Esto lo hace adecuado para aplicaciones de control de acceso, seguimiento de activos y otras aplicaciones que requieren una identificación precisa y confiable.

#### Características destacadas:

- Banda de frecuencias de microondas ISM general
- Diseño de grado industrial
- Receptor de señal de larga distancia de hasta 50 metros
- Tensión de trabajo de DC12V a 24V
- Protocolo estándar Bluetooth 4.0
- Modo de salida RS232/RS485
- Sensibilidad de recepción de -85dBm a 1Mbps
- Antena externa
- Velocidad de transmisión de serie configurable de 115200
- Temperatura de trabajo de -40 ℃ a +60 ℃
- Dimensiones compactas de L78mm x W67mm x H27mm
- Capacidad de leer el estado de la tarjeta
- Ángulo de identificación omnidireccional
