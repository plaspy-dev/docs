# TZone - TZ-TT18

![TZ-TT18](./logo.jpg)

El transmisor de temperatura y humedad TT18 de TZone es un dispositivo compacto que cuenta con un transmisor incorporado de temperatura/humedad y un módulo GSM. Para su funcionamiento, es necesario insertar una tarjeta SIM. El TT18 puede despertar solo cuando es el momento de enviar datos o cuando el usuario lo opera, lo que le permite estar en estado de suspensión y prolongar su tiempo de uso para mayor comodidad.

El transmisor de temperatura y humedad TT18 puede recopilar rápidamente datos de temperatura/humedad de alta precisión y transmitirlos al software del servidor a través de GPRS. Este dispositivo es ampliamente utilizado en la logística de la cadena de frío, almacenamiento de medicamentos, refrigeración, entre otros.

Características destacadas:

- Dimensiones: 80 mm x 64 mm x 25 mm
- Batería incorporada de litio de 3.7V / 2000mAh
- Antena GSM incorporada
- Memoria flash de 2880 datos GPRS
- Precisión de temperatura: ± 0.3 ℃
- Rango de detección de temperatura: -40 ℃ ~ 125 ℃
- Precisión de humedad: ± 3%
- Rango de detección de humedad: 0 ~ 100%
- Rango de temperatura de funcionamiento: -20 ℃ ~ +60 ℃
- Consumo de energía: Modo activo \(prom.\) &lt;100 mA, Modo de suspensión \(prom.\) &lt;2 mA
- Hasta un 75% de humedad sin condensación
- Chips GSM SIMCOM, 4 frecuencias GSM 850/900/1800/1900MHz
- Indicadores LED para temperatura y GSM
