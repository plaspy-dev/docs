# TZone - TZ-RD05

![TZ-RD05](./logo.jpg)

El lector de RFID TZ-RD05 de TZone es un dispositivo multifuncional diseñado para gestionar etiquetas RFID de 2.4G. Es compatible con varias etiquetas RFID, incluyendo TZ-Tag01 / TZ-Tag02, TZ-Tag03, TZ-Tag04 y TZ-Tag201. Con este lector, podrás administrar fácilmente una de estas etiquetas después de la configuración. Sin embargo, es importante tener en cuenta que no puede manejar todas las etiquetas a la vez utilizando un solo firmware.

El TZ-RD05 utiliza una combinación de RS485 / USB y un puerto LAN para conectarse al sistema de gestión. Esto facilita la administración y el control de las etiquetas RFID. Además, cuenta con una sensibilidad de recepción de 1Mbps a -85dBm, lo que garantiza una lectura precisa y confiable de las etiquetas.

Este lector de RFID tiene un diseño cilíndrico con un diámetro de 170 mm y una altura de 40 mm, lo que lo hace fácil de instalar en el techo. También cuenta con una distancia de lectura de hasta 50 metros, lo que lo hace ideal para aplicaciones en entornos grandes. Además, tiene una protección IP55, lo que significa que es resistente al polvo y al agua, lo que lo hace adecuado para su uso en diferentes condiciones ambientales.

En resumen, el lector de RFID TZ-RD05 de TZone es una solución confiable y versátil para la gestión de etiquetas RFID. Con su capacidad para administrar múltiples etiquetas y su fácil conectividad, es una opción ideal para aplicaciones en entornos industriales, logísticos y de control de acceso.

### Características destacadas:

- Compatible con varias etiquetas RFID de 2.4G
- Conexión a través de RS485 / USB y puerto LAN
- Sensibilidad de recepción de 1Mbps a -85dBm
- Diseño cilíndrico para montaje en techo
- Distancia de lectura de hasta 50 metros
- Protección IP55 contra polvo y agua
