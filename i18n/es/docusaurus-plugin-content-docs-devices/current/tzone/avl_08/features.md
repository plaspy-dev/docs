# TZone - Características del AVL-08

Esta página ofrece una descripción pública de las funciones del rastreador GPS TZone AVL-08 y explica cómo sus capacidades se integran con Plaspy para el monitoreo, las alertas y la visibilidad operativa. Está pensada para describir, en términos prácticos y no sensibles, lo que el dispositivo puede hacer cuando se usa junto con Plaspy y usted desea comprender sus posibilidades.

La disponibilidad y el comportamiento exactos de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Cuando el AVL-08 ofrece funciones opcionales, estas pueden requerir accesorios o configuraciones específicas y deben confirmarse con el fabricante o el instalador.

## Resumen de funciones

El AVL-08 se posiciona como un rastreador versátil para vehículos y activos que ofrece reporte de ubicación, alarmas, opciones de integración y varias interfaces para periféricos. A continuación se detallan las capacidades prácticas más relevantes que los operadores suelen utilizar en Plaspy u otras plataformas similares.

- Informe de ubicación puntual y seguimiento continuo para actualizaciones en tiempo real o periódicas
- Varios tipos de alarma: exceso de velocidad, batería baja, geocerca, vibración (tremble), alarma de estacionamiento y botón SOS
- Control remoto del vehículo como control de puertas, detección de estado del motor y corte gradual del motor para inmovilización de emergencia
- Soporte para periféricos externos como grabación en tarjeta SD, lectores RFID, cámaras e impresoras para ampliar la captura de datos y la integración de procesos
- Funciones a bordo para cálculo de kilometraje, almacenamiento interno en flash y sensor de temperatura opcional para informes operativos
- Detección de nivel de combustible o aceite y entradas basadas en acelerómetro 3D para ayudar a monitorear el estado del vehículo y detectar eventos

## Funciones principales del TZone - AVL-08

- Modos de reporte de ubicación para consultas puntuales y sesiones de seguimiento continuo
- Conjunto de alarmas que incluye exceso de velocidad, batería baja, geocerca, vibración, estacionamiento y SOS
- Interfaz para motor y puertas con detección de estado y capacidad para realizar un corte controlado del motor
- Soporte para tarjeta SD externa para grabación local y almacenamiento ampliado
- Interfaces para periféricos externos como lectores RFID, cámaras e impresoras para flujos de trabajo integrados
- Entrada de acelerómetro 3D para detección de movimiento y alarmas por manipulación
- Cálculo de kilometraje y memoria flash interna para almacenamiento temporal de eventos y datos
- Soporte de sensores opcionales como detección de nivel de combustible o aceite y medición de temperatura cuando lo permite la variante de hardware

## Cómo funcionan estas funciones con Plaspy

Cuando un dispositivo AVL-08 está conectado a Plaspy, el rastreador envía información de ubicación, eventos y alarmas que Plaspy presenta para monitoreo y revisión histórica. Plaspy detecta los protocolos compatibles del rastreador e ingiere los datos del dispositivo para que los gestores de flota puedan ver posiciones y eventos en un solo lugar.

- Visualización en vivo e histórica de ubicaciones en las vistas de mapas de Plaspy para modos de seguimiento puntual y continuo
- Notificaciones de alarmas y eventos en Plaspy para que los operadores puedan ver excesos de velocidad, geocerca, vibración, estacionamiento, SOS y eventos de batería baja
- Estado de motor y puertas visible en el flujo de eventos del dispositivo para apoyar revisiones operativas y respuesta a incidentes
- Kilometraje y registros de eventos almacenados mostrados en los reportes de Plaspy para apoyar la planificación de uso y mantenimiento
- Integración de eventos de periféricos externos como lecturas RFID o disparos de cámara como parte de la línea de tiempo de eventos del dispositivo cuando esos periféricos están instalados y reportan

## Casos de uso típicos

- Disuasión y recuperación de vehículos robados mediante geocercas, alarmas de vibración, estacionamiento y SOS
- Seguimiento de flotas para supervisión de rutas, control de kilometraje e informes operativos
- Monitoreo de buses escolares y vehículos de pasajeros donde la localización y las alarmas apoyan la supervisión de seguridad
- Logística y seguimiento de activos con grabación local e integración de periféricos para prueba de servicio
- Inmovilización remota o corte de motor en escenarios coordinados de seguridad o recuperación
- Integración de eventos de RFID y cámaras para flujos combinados de localización y control de accesos

## Notas sobre disponibilidad de funciones

- Algunas funciones, como sensor de temperatura, detección de nivel de combustible o integración de cámara, dependen de las opciones de hardware y pueden no estar disponibles en todas las unidades
- La versión de firmware y la configuración del dispositivo afectan las alarmas disponibles, los intervalos de reporte y el comportamiento de los periféricos
- Las elecciones de instalación y el cableado determinan qué entradas y salidas están activas para reportes de estado de motor y puertas
- Las variantes regionales y los requisitos regulatorios locales pueden influir en las funciones soportadas
- Para el cableado preciso, compatibilidad de accesorios y comportamiento de comandos, consulte la documentación oficial del fabricante
