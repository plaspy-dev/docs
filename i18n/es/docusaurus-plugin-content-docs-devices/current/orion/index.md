# Orion

Orion es un nombre reconocido en hardware de rastreo GPS, ampliamente utilizado en aplicaciones para vehículos y flotas. Plaspy es compatible con los dispositivos Orion y puede procesar la telemetría de sus rastreadores, de modo que su equipo pueda supervisar ubicación, estado y eventos desde una sola plataforma. En esta página explicamos cómo funcionan los dispositivos Orion con Plaspy, casos de uso habituales y dónde encontrar modelos compatibles en el catálogo.

## Cómo funcionan los dispositivos Orion con Plaspy

Plaspy recibe datos GPS y telemáticos estándar transmitidos por los dispositivos Orion a través de redes celulares. La integración normalmente implica configurar el equipo Orion para reenviar mensajes de ubicación y sensores a la plataforma Plaspy y verificar el identificador del dispositivo usado para el emparejamiento. Una vez que el dispositivo envía datos a Plaspy, la plataforma normaliza la telemetría para mapas, alertas e informes.

Si necesita una configuración paso a paso para un modelo Orion específico, abra la entrada del dispositivo en el catálogo abajo. Las páginas de cada dispositivo incluyen las instrucciones concretas para conectarlo a Plaspy.

## Funcionalidades comunes en los dispositivos Orion

Los dispositivos Orion abarcan distintos tipos de rastreadores e incluyen con frecuencia características orientadas a flotas y activos. Entre las capacidades típicas que puede esperar están:
- Posicionamiento GPS en tiempo real y actualizaciones periódicas de ubicación
- Conectividad celular para enlace de datos
- Entradas y salidas para sensores externos o sistemas de alarma
- Detección de movimiento y manipulación para protección de activos
- Intervalos de reporte configurables y mensajes activados por eventos

Las características específicas varían según el modelo. Use el catálogo para revisar las capacidades de cada modelo antes del despliegue.

## Casos de uso habituales para rastreadores Orion

Los dispositivos Orion son adecuados para diversos escenarios de rastreo y gestión de flotas, por ejemplo:
- Monitoreo de ubicación y rutas de flotas de vehículos
- Rastreo de activos como remolques y equipos de alto valor
- Registro de viajes y comportamiento del conductor al integrarse con sensores telemáticos
- Detección y recuperación ante robos mediante alertas de geovallas y movimiento
- Monitoreo remoto del estado para operaciones de entrega y servicio en campo

Plaspy apoya estos flujos operativos al convertir la telemetría del dispositivo en información procesable y alertas.

## Por qué elegir Plaspy para monitorizar dispositivos Orion

Plaspy ofrece las herramientas que los equipos necesitan para operar dispositivos Orion a escala:
- Vistas centralizadas en mapa y de historial para flotas de dispositivos
- Alertas y notificaciones personalizadas basadas en la telemetría de Orion
- Informes y análisis para uso y rendimiento operativo
- Flujos de gestión de dispositivos para seguir instalaciones y configuraciones
- Acceso a API para integrar los datos de los dispositivos Orion con otros sistemas

Usar Plaspy con dispositivos Orion le brinda una única vista para visibilidad y control sin cambiar el hardware.
