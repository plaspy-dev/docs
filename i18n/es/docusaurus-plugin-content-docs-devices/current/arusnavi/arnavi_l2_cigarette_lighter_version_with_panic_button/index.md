# Arusnavi - Arnavi L2 (cigarette lighter version with panic button)

![Arnavi L2 (cigarette lighter version with panic button)](./tracker.png)

El Arnavi L2 \(versión con encendedor de cigarrillos y botón de pánico\) es un rastreador GPS plug-and-play diseñado para una instalación rápida sin taladros y una fácil reubicación entre vehículos. Pensado para gestores de flotas, operadores de alquiler y plataformas de coche compartido, y vehículos arrendados a corto plazo, este rastreador compatible con Plaspy ofrece reporte continuo de posición, telemetría del comportamiento del conductor y señalización de emergencias sin cableado permanente; ideal cuando la implementación rápida y las medidas antirobo son importantes.

El Arnavi L2 combina posicionamiento GNSS de múltiples constelaciones, un módem GSM/GPRS 2G, conectividad BLE para sensores externos y un botón de pánico dedicado para informes de alarma inmediatos. Con detección de remolaje basada en acelerómetro y detección del estilo de conducción, registro offline de la caja negra y protección amplia de entradas, el Arnavi L2 proporciona las funciones centrales de telemetría y seguridad necesarias para un seguimiento en tiempo real fiable y la gestión de flotas en Plaspy.

## Aspectos clave

- Rastreador GPS plug-and-play compatible con Plaspy que se instala a través del arnés del encendedor para cambios de vehículo rápidos.
- GNSS de múltiples constelaciones \(GPS/GLONASS/Galileo/BeiDou/QZSS\) para una localización satelital robusta.
- Seguimiento y telemetría en tiempo real vía 2G GPRS, con soporte para configuración remota y actualizaciones de firmware.
- Botón dedicado de pánico \(alarma\) y acelerómetro incorporado para señalización de emergencias, detección de remolaje y análisis de conducción eficiente.
- Soporte BLE \(Bluetooth Low Energy\) para hasta cinco sensores externos: temperatura, apertura de puertas, etiquetas BLE para modo de guardia y más.
- Registro a bordo de 8 MB \(~12,000 registros\) para grabación de caja negra fuera de línea cuando la cobertura es intermitente.
- E/S universal protegida para sensores de combustible o relés de inmovilizador, y entradas discretas para detección de encendido.

## Cómo funciona con Plaspy

El Arnavi L2 se integra con Plaspy utilizando sus protocolos configurables desde el servidor para entregar la posición GNSS, telemetría y datos de eventos a tu cuenta de Plaspy en tiempo casi real. Los datos fuera de cobertura se almacenan localmente en la memoria flash del dispositivo y se cargan cuando se restablece la conexión, lo que permite auditoría continua y un historial de viajes preciso.

- Actualizaciones de ubicación y telemetría en tiempo real \(GNSS + 2G GPRS\) para una visibilidad continua de la flota en los paneles de Plaspy.
- Alertas del botón de pánico y eventos activados por el acelerómetro \(remolaje, impacto o conducción agresiva\) enviados de inmediato a Plaspy para una respuesta rápida.
- Estado de ignición mediante una entrada discreta positiva para eventos de encendido/apagado del motor y reportes por kilometraje en Plaspy.
- Monitoreo de combustible y control del inmovilizador mediante la E/S universal protegida; son compatibles sensores de combustible por frecuencia y inmovilizadores basados en relé.
- Sensores y etiquetas BLE \(hasta cinco\) para modo de guardia, monitoreo de temperatura y telemetría de accesorios integrados en las fuentes de sensores de Plaspy.

## Casos de uso

- Gestión de flotas para pequeñas y medianas flotas donde los vehículos se cambian con frecuencia: instalación rápida y seguimiento en tiempo real en Plaspy sin necesidad de cableado permanente.
- Vehículos de alquiler a corto plazo y de coche compartido que requieren monitoreo antifurto, alarma de pánico y retirada rápida entre conductores.
- Modo de guardia del vehículo mediante etiquetas BLE para protección al estacionar y detección de remolaje/evacuación, con alertas inmediatas en Plaspy.
- Telemetría y programas de conducción eficiente que se apoyan en datos del acelerómetro para puntuaciones de conductor y monitoreo de combustible mediante sensores por frecuencia.
- Monitoreo de temperatura o accesorios mediante sensores BLE compatibles para logística de última milla o cargas sensibles.

## Por qué elegir este rastreador con Plaspy

Elegir el Arnavi L2 para Plaspy le ofrece un rastreador GPS confiable y de baja fricción que prioriza la implementación rápida y la telemetría esencial. Su arnés de encendedor facilita su uso en flotas de alquiler, coche compartido y arrendamientos, donde una instalación permanente no es deseable. El GNSS de múltiples constelaciones y el soporte para sensores BLE aseguran una alta precisión de posicionamiento y entradas de sensor flexibles para monitoreo de combustible, temperatura o etiquetas de modo de guardia. El botón de pánico y las alertas basadas en acelerómetro añaden una capa importante de antifurto y seguridad que se integra directamente en las alertas de Plaspy y en los flujos de incidentes.

Entre los beneficios operativos se incluyen registro offline para la continuidad de los datos, configuración remota y actualizaciones de firmware para escalar la gestión de dispositivos, y E/S universal capaz de manejar la detección de ignición y relés de inmovilizador. Para operadores que buscan un rastreador GPS compatible con Plaspy con instalación sencilla, telemetría robusta y señalización de emergencia, el Arnavi L2 ofrece una solución equilibrada y práctica para el rastreo en tiempo real, la gestión de flotas y la protección antifurto.
