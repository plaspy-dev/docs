# BoxTrack - Control

![Control](./Logo.png)

### **Boxtrack Control Antirobo**

El **Boxtrack Control Antirobo** es un rastreador GPS avanzado diseñado para garantizar la seguridad y monitoreo en tiempo real de vehículos. Con una precisión de ubicación menor a 5 metros, este dispositivo permite conocer la ubicación exacta en todo momento. Gracias a su capacidad de corte de motor, puede ser controlado de manera remota a través de SMS, una aplicación móvil o una plataforma web, lo que proporciona un nivel adicional de seguridad en caso de robo o uso no autorizado.

Además, el **Boxtrack Control Antirobo** cuenta con funciones adicionales como un botón de pánico **SOS**, audio en vivo mediante un micrófono externo y un sensor G que detecta impactos y conducción brusca. Su conectividad **4G/2G/GPRS** garantiza una comunicación estable en diversas condiciones. También dispone de una memoria interna capaz de almacenar hasta **2,000 registros**, asegurando que ningún dato importante se pierda, incluso si la señal se interrumpe momentáneamente. Con una batería de respaldo de **200mAh**, ofrece hasta **4 horas de autonomía**, asegurando el rastreo continuo en situaciones críticas.

#### **Especificaciones técnicas**

| Característica | Descripción |
| --- | --- |
| **Precisión GPS** | &lt;5m |
| **Conectividad** | 4G/2G/GPRS |
| **Corte de motor** | Control vía SMS, App o Web |
| **Botón SOS** | Sí |
| **Audio en vivo** | Micrófono externo |
| **Sensor G** | Detecta impactos y manejo brusco |
| **Control remoto** | Pánico, corte de energía y sirena |
| **Voltaje de operación** | 9V - 36V |
| **Batería interna** | 200mAh \(hasta 4h de respaldo\) |
| **Memoria interna** | 2,000 reportes |
| **Puerto sirena** | Sí |
| **Sensor de ignición** | Detecta encendido del vehículo |

#### **Características destacadas**

- Monitoreo en tiempo real con alta precisión.
- Posibilidad de apagar el motor a distancia para prevenir robos.
- Alertas por movimientos bruscos o impactos.
- Botón de pánico para emergencias.
- Micrófono externo para audio en vivo.
- Conexión estable mediante redes 4G y 2G.
