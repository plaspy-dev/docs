# GOTOP - VT-320

![VT-320](./logo.jpg)

El rastreador GPS GOTOP VT-320 es un dispositivo de seguimiento GPS/GSM/GPRS especialmente desarrollado y diseñado para la seguridad y seguimiento en tiempo real de motocicletas. Con módulos GPS y GPRS superiores, este rastreador ofrece una buena sensibilidad y un rendimiento estable, permitiendo obtener una ubicación precisa incluso en lugares remotos.

Este rastreador GPS es ideal para diversas aplicaciones, como el seguimiento de motocicletas, vehículos, seguridad y recuperación de vehículos, seguimiento de activos móviles, servicios basados en la ubicación y gestión de flotas de coches, taxis, autobuses, camiones, entre otros.

El GOTOP VT-320 cuenta con una amplia gama de características que lo hacen altamente funcional y confiable. Algunas de sus características destacadas incluyen:

- Fuente de alimentación de 6V-24V
- Seguimiento por SMS/GPRS
- Seguimiento por intervalo de tiempo
- Seguimiento por intervalo de distancia
- Botón de pánico SOS
- Alarma de geo-cerca
- Alarma de exceso de velocidad
- Sensor de movimiento incorporado para ahorrar energía
- URL de Google Maps para localización vía SMS
- Obtención del nombre de la dirección física a través de SMS
- Corte remoto del motor
- Informe de kilometraje
- 1 entrada positiva, 1 entrada negativa y 2 salidas
- Tamaño mini, fácil instalación y bajo costo para motocicletas y vehículos de 12V y 24V

Con el rastreador GPS GOTOP VT-320, puedes tener la tranquilidad de saber la ubicación de tu motocicleta en todo momento y contar con funciones de seguridad adicionales para proteger tu vehículo.
