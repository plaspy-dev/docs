# GOTOP - VT-391: Características

Esta página ofrece un resumen público de las funciones del rastreador GPS GOTOP VT-391 y cómo sus capacidades pueden aprovecharse con Plaspy para el monitoreo de vehículos y flotas. Resume el conjunto de funciones del VT-391 en términos no sensibles y explica el valor práctico que aportan cuando el dispositivo reporta datos a la plataforma Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, la variante regional y las elecciones de instalación. Utilice esta página como referencia general y consulte la documentación del fabricante para obtener especificaciones precisas y diferencias entre unidades.

## Resumen de funciones

El VT-391 se posiciona como un rastreador vehicular versátil con capacidades multimedia, de identificación y múltiples opciones de conectividad, diseñado para aplicaciones que requieren tanto localización como captura de eventos. A continuación se describen las capacidades prácticas más relevantes que los usuarios suelen aprovechar con Plaspy.

- Conectividad WiFi integrada para transmisión de datos inalámbrica además de los canales celulares
- Soporte para cámara integrada para registrar imágenes con contexto de ubicación y conducción
- Identificación de conductor por RFID para relacionar la presencia del conductor con la actividad del vehículo
- Almacenamiento local compatible con tarjetas SD de hasta 64 GB para media y registros extendidos
- Alertas por frenadas bruscas y aceleraciones fuertes, además de detección de accidentes para reporte oportuno de eventos

## Funciones principales del GOTOP - VT-391

- Módulo WiFi para comunicación local inalámbrica y subida de datos cuando esté disponible
- Puerto para cámara y capacidad de registro de imágenes para capturar contexto visual de incidentes
- Identificación de conductor mediante RFID para asociar conductores con viajes y eventos
- Ranura para tarjeta SD con soporte de hasta 64 GB para almacenamiento de fotografías y registros
- Audio bidireccional que permite escuchar y hablar de forma remota para comunicación dentro del vehículo
- Varias entradas y salidas analógicas y digitales, incluyendo entradas analógicas para sensores externos
- Alarmas por frenadas y aceleraciones bruscas y alerta de accidentes para notificación rápida de eventos
- Soporte OTA para actualizaciones de firmware proporcionadas por el fabricante

## Cómo se integran estas funciones con Plaspy

Cuando un VT-391 reporta a Plaspy, las funciones del dispositivo se traducen en visibilidad y datos de eventos sobre los que los operadores pueden actuar. Plaspy detecta automáticamente el protocolo del rastreador y acepta conexiones de dispositivos compatibles, por lo que las unidades VT-391 pueden monitorearse junto con otros equipos de la flota.

- Las actualizaciones de ubicación enviadas por el rastreador aparecen en los mapas y líneas de tiempo de Plaspy
- Las alertas de eventos como frenadas bruscas, accidentes, SOS y exceso de velocidad se presentan como eventos en la plataforma
- Los datos de identidad del conductor reportados por el lector RFID pueden vincularse a perfiles de conductor en Plaspy
- Las imágenes de cámara y otros medios transmitidos por el dispositivo se asocian con eventos y marcas de tiempo en Plaspy cuando el rastreador las provee
- Los estados de entradas digitales y analógicas reportados por el VT-391 están disponibles como entradas o disparadores de eventos dentro de Plaspy
- El estado del dispositivo, incluido el método de conectividad y el firmware o configuración reportados, puede consultarse en la página de detalles del dispositivo en Plaspy

## Casos de uso típicos

- Rastreo de ubicación de flotas con registros visuales complementarios para revisión de incidentes
- Identificación y responsabilidad del conductor mediante registro por RFID y asociación con viajes
- Alertas en tiempo real para eventos de seguridad como frenadas bruscas y detección de accidentes
- Registro de incidentes con soporte multimedia donde se capturan imágenes con marca de tiempo y ubicación
- Monitoreo de sensores analógicos externos para supervisión operativa usando las entradas del dispositivo
- Comunicaciones de voz bidireccionales para despacho o asistencia al conductor durante las operaciones

## Notas sobre disponibilidad de funciones

- La presencia y el comportamiento de las funciones dependen del firmware y la revisión de hardware del fabricante
- Algunas funciones, como la cámara, el RFID o ciertas entradas, pueden requerir cableado accesorio específico o módulos opcionales
- Las variantes regionales y las aprobaciones de operadores pueden afectar qué métodos de conectividad están disponibles por defecto
- El rendimiento de la tarjeta SD y la capacidad máxima admitida pueden cambiar con actualizaciones de firmware o indicaciones del fabricante
- Plaspy mostrará las funciones e entradas reportadas por el dispositivo, pero la interacción exacta para funciones avanzadas puede requerir configuración tanto en el rastreador como en la plataforma

## Por qué usar Plaspy con estas funciones

Combinar el VT-391 con Plaspy proporciona a las organizaciones una vista unificada de la ubicación, la identidad del conductor y los medios basados en eventos. Plaspy recopila y presenta la telemetría y las alertas del dispositivo para que los operadores puedan monitorear rutas, revisar incidentes con contexto de imagen y correlacionar la presencia del conductor con la actividad del vehículo para la toma de decisiones operativas.
