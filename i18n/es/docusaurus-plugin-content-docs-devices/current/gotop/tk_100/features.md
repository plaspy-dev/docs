# GOTOP - TK-100: características

Esta página describe el contexto público de funciones para usar el rastreador GOTOP TK-100 con Plaspy. Se centra en capacidades visibles para el usuario, como el reporte de ubicación, las alarmas y las formas en que estas funcionalidades resultan útiles cuando el dispositivo está conectado a Plaspy para supervisión y visibilidad.

La disponibilidad exacta de las funciones puede variar según la versión de firmware, la revisión de hardware, el modelo regional y la forma en que el dispositivo esté instalado o configurado. Esta página toma como base la descripción del fabricante y busca explicar el comportamiento práctico más que los detalles internos del dispositivo.

## Resumen de funciones

El TK-100 se presenta como un rastreador GPS compacto para mascotas, pensado para ofrecer ubicación en tiempo real y alertas. Soporta reportes vía SMS y GPRS y está diseñado para uso en exteriores, con varias alarmas destinadas a notificar movimiento, batería baja o salida de un área predefinida.

- Reporte de ubicación en tiempo real mediante SMS o GPRS para seguimiento continuo
- Alarma de geocerca para notificar cuando la mascota sale de un área definida
- Alarma de batería baja para ayudar a mantener operación continua
- Alarmas por vibración y movimiento para detectar actividad o intentos de escape
- Carcasa resistente al agua y al polvo para uso confiable en exteriores

## Funciones principales del GOTOP - TK-100

- Seguimiento en tiempo real usando reportes por SMS o GPRS según indica el fabricante
- Alarma de geocerca para supervisar límites y recibir alertas
- Alarma de batería baja que notifica cuando la energía del dispositivo es reducida
- Alarma por vibración que señala sacudidas u otros movimientos detectados
- Alarma de movimiento para detectar y reportar eventos de desplazamiento relacionados con la mascota
- Soporte de modo de reposo para ahorrar energía durante periodos prolongados de inactividad
- Compatibilidad con software de seguimiento en línea y una aplicación Android para monitoreo

## Cómo funcionan estas funciones con Plaspy

Cuando el TK-100 está conectado a Plaspy, sus reportes de ubicación y sus alarmas se muestran dentro de Plaspy para supervisión y revisión histórica. Plaspy reconoce automáticamente los datos de los rastreadores compatibles y presenta los eventos del dispositivo junto al historial de ubicaciones, de modo que equipos y propietarios puedan mantener la visibilidad sin gestionar detalles en crudo del dispositivo.

- Las actualizaciones de ubicación aparecen en el mapa de Plaspy para conciencia situacional continua
- Los eventos de geocerca se muestran como alertas cuando el dispositivo entra o sale de las zonas configuradas
- Los indicadores de batería baja y las alertas de movimiento o vibración se registran en las listas de eventos de Plaspy
- Los recorridos históricos y el historial de posiciones recientes pueden revisarse en Plaspy para analizar movimientos pasados
- Usted puede combinar las alertas del dispositivo con las notificaciones y herramientas de informes de Plaspy para supervisión operativa

## Casos de uso típicos

- Localización en tiempo real y asistencia para recuperación cuando una mascota se pierde
- Supervisión de límites de patios o áreas locales usando alertas de geocerca
- Monitoreo de actividad para saber cuándo la mascota se mueve o se agita después de descansar
- Notificación remota de batería baja para programar recarga o reemplazo
- Aventuras al aire libre donde el diseño resistente al agua y al polvo reduce riesgos por el clima

## Notas sobre disponibilidad de funciones

- Los nombres de funciones y su comportamiento, como alarmas o modo de reposo, pueden variar según la versión de firmware o el modelo regional
- Revisiones de hardware o soportes adicionales pueden afectar las opciones de montaje y la resistencia ambiental
- Las aplicaciones móviles y portales en línea provistos por el fabricante pueden ofrecer ajustes adicionales que no se reflejen exactamente en Plaspy
- Las elecciones de instalación y configuración pueden influir en la rapidez con que se reportan los eventos y en qué alertas están activas
- Para obtener detalles técnicos más precisos y actualizados consulte la documentación del fabricante

## Por qué usar Plaspy con estas funciones

Usar Plaspy con el GOTOP TK-100 centraliza la información de ubicación y alertas, de modo que propietarios y equipos pueden supervisar el estado de la mascota desde una sola plataforma. Plaspy presenta marcadores de ubicación, historial de eventos y alertas en una interfaz consistente, ayudando a tomar medidas ante salidas de geocerca, eventos de movimiento y condiciones de batería baja sin cambiar entre sistemas.
