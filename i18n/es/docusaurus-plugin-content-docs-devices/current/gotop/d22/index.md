# GOTOP - D22

![D22](./logo..jpg)

El rastreador GPS GOTOP D22 es un dispositivo resistente al agua diseñado para el seguimiento de vehículos y la gestión de flotas. Utiliza comunicación inalámbrica 4G y tecnología de posicionamiento por satélite GPS/BDS para proporcionar capacidades de seguimiento y monitoreo en tiempo real. El D22 cuenta con una antena integrada de alta integración y un sensor de 3 ejes incorporado para el modo de ahorro de energía inteligente.

Con el D22, puedes disfrutar de una variedad de funciones avanzadas, como detección de corriente continua, detección de ACC, alarma de fallo de energía, alarma de exceso de velocidad, estadísticas de kilometraje, corte remoto de combustible, alarma de SOS y comunicación bidireccional. El dispositivo admite la red 4G LTE para una comunicación fluida y se puede conectar a un relé de corte de aceite externo para el corte remoto de energía. También ofrece una función de cerco electrónico y un micrófono para escucha remota.

El D22 está equipado con un módulo 4G de alta estabilidad de grado industrial y un módulo de posicionamiento de doble satélite GPS/BDS de alta sensibilidad con una antena cerámica antiinterferencias. Admite transmisión de datos TCP/IP y puede almacenar datos en estado sin conexión para la transmisión suplementaria de datos de áreas ciegas. El dispositivo también cuenta con un sensor de aceleración de 3 ejes incorporado con un algoritmo de aceleración preciso para el monitoreo en tiempo real del estado del vehículo.

Con su bajo consumo de energía y diseño de ahorro de energía, el GOTOP D22 es un rastreador GPS confiable y eficiente para el seguimiento y la gestión de vehículos. Ya sea que necesites rastrear un solo vehículo o gestionar una flota, el D22 proporciona las funciones y capacidades necesarias para optimizar tus operaciones.

### Características destacadas:

- Red 4G LTE para comunicación
- Alarma de fallo de energía, alarma de exceso de velocidad, alarma de movimiento y alarma de batería baja
- Corte remoto de energía con relé de corte de aceite externo
- Función de cerco electrónico
- Alarma de SOS y comunicación bidireccional
- Micrófono para escucha remota
- Soporte para sensor de puerta para verificación de estado
- Módulo 4G de alta estabilidad de grado industrial
- Módulo de posicionamiento de doble satélite GPS/BDS de alta sensibilidad
- Bajo consumo de energía y ahorro de energía
