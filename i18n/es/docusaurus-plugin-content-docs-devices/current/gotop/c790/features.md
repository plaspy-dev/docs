# GOTOP - C790: Características

Esta página ofrece un resumen público de las características del rastreador GPS GOTOP C790 y cómo se aprovechan con la plataforma de gestión de flotas Plaspy. El contenido se centra en las funciones visibles para el usuario y en las capacidades prácticas que puede esperar al integrar un C790 con Plaspy para monitoreo de ubicación, visibilidad de eventos y control remoto básico.

La disponibilidad y el comportamiento exacto de cada función dependen de la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Considere este resumen como una guía general basada en la descripción pública del producto y confirme siempre los detalles específicos del dispositivo con la documentación oficial del fabricante para la revisión vigente.

## Resumen de funcionalidades

El GOTOP C790 es un rastreador vehicular compacto que combina posicionamiento satelital y comunicación de datos móviles para ofrecer actualizaciones de ubicación en tiempo real y funciones básicas de control del vehículo. Está diseñado para seguimiento y seguridad vehicular y puede integrarse con Plaspy para monitoreo centralizado y revisión de historial.

- Posicionamiento satelital en tiempo real mediante GPS y Beidou para actualizaciones continuas de ubicación
- Comunicación de datos por GPRS para reportar posición y alertas a una plataforma de rastreo
- Corte remoto de combustible y control del interruptor de aceite y electricidad del vehículo mediante comandos móviles
- Detección ACC para supervisar el estado del encendido y soportar reportes por eventos
- Entradas de alarma como alarma de vibración, exceso de velocidad y pérdida de alimentación
- Botón SOS y alertas de geocerca con historial de eventos rastreable hasta 180 días

## Funciones principales del GOTOP - C790

- Posicionamiento satelital con GPS y Beidou para obtener coordenadas de ubicación
- Comunicación por GPRS para enviar reportes de posición y alarmas a través de redes móviles
- Corte remoto de combustible que permite controlar el suministro de combustible o la alimentación eléctrica del vehículo desde una orden remota
- Detección ACC para identificar si el encendido está activado o desactivado y activar reportes
- Alarma de vibración para detectar movimiento o manipulación
- Alarma por exceso de velocidad para notificar cuando se supera un umbral de velocidad
- Alarma por pérdida de alimentación para reportar desconexión de la corriente externa
- Botón SOS para solicitar asistencia en situaciones de emergencia

## Cómo funcionan estas funciones con Plaspy

Plaspy recibe los reportes del rastreador y los presenta en una interfaz de monitoreo compartida para que su equipo pueda ver ubicación, alertas y actividad reciente del C790 en un solo lugar. Plaspy detecta automáticamente el protocolo del rastreador e ingiere los mensajes de ubicación y eventos enviados por el dispositivo, habilitando visibilidad operativa y revisión histórica.

- Las posiciones en tiempo real y las actualizaciones de ubicación del dispositivo se muestran en los mapas de Plaspy para seguimiento y despacho
- Los eventos de alarma, como vibración, exceso de velocidad, SOS y pérdida de alimentación, se registran y pueden visualizarse en listados de eventos
- Las acciones de corte remoto de combustible iniciadas por comandos al dispositivo se registran como eventos de control y pueden correlacionarse con ubicación y hora
- Las entradas y salidas de geocerca se reportan y están disponibles como alertas dentro de Plaspy
- El historial de conducción retenido por el dispositivo hasta por 180 días puede importarse o consultarse como historial de viajes mediante los informes de Plaspy
- Plaspy soporta la conectividad de dispositivos usando métodos de transporte comunes y detecta automáticamente los protocolos compatibles cuando el rastreador reporta a d.plaspy.com

## Casos de uso típicos

- Seguridad y recuperación de vehículos, donde el corte remoto de combustible y las alertas SOS agregan capas de protección
- Monitoreo de flotas para empresas que requieren visibilidad de ubicación, revisión de rutas y registro de eventos
- Disuasión e intervención ante robos mediante la capacidad del dispositivo para inhabilitar suministro de combustible o eléctrico de forma remota
- Monitoreo remoto del estado del encendido para confirmar uso autorizado o arranques no autorizados
- Notificaciones basadas en geocercas para rastrear entradas y salidas de zonas definidas
- Revisión histórica de viajes para cumplimiento, facturación o análisis operativo

## Notas sobre disponibilidad de funciones

- Algunas funciones pueden variar según la versión de firmware o la revisión de hardware del dispositivo C790
- La configuración por parte del fabricante y las prácticas de instalación pueden cambiar el comportamiento de las entradas y las funciones de control remoto
- Las variantes regionales o las configuraciones de los operadores móviles pueden afectar la conectividad GPRS y la frecuencia de reporte
- Verifique si una unidad C790 específica es la variante C790-Y y si esa variante incluye las funciones exactas que necesita
- Consulte la documentación oficial del fabricante para detalles de pines de hardware y comandos antes de intentar la instalación o la integración de control
