# GOTOP - TK-120

![TK-120](./logo.jpg)

El rastreador GPS TK-120 de GOTOP es un dispositivo de seguimiento compacto y versátil que utiliza la red GSM y GPS para transmitir la ubicación en tiempo real. Con su tamaño reducido, este rastreador puede ser fácilmente ocultado para rastrear y proteger personas, activos, vehículos, mascotas, entre otros. Además de enviar la longitud y latitud a través de SMS, el TK-120 también puede responder con un enlace de Google Maps que muestra la posición detallada en el mapa. Este dispositivo también es compatible con el seguimiento a través de GPRS, lo que permite transmitir datos de posición a un software de seguimiento a intervalos programados.

Características destacadas:

- Tamaño compacto y discreto
- Utiliza la red GSM y GPS para la transmisión de ubicación
- Envío de la ubicación a través de SMS con enlace de Google Maps
- Seguimiento en tiempo real a través de GPRS
- Compatible con software de seguimiento
