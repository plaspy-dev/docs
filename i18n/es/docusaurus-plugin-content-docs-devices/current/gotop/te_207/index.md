# GOTOP - TE-207

![TE-207](./logo.jpg)

El rastreador GPS personal TE-207 de GOTOP es un dispositivo de tamaño mini ideal para la localización y seguimiento de niños, ancianos, trabajadores solitarios y pacientes. Está disponible en colores Azul, Negro, Rosa y Verde. Este rastreador ofrece dos formas de comunicación, permitiendo al titular hablar directamente con el centro de control, como un teléfono móvil, y también escuchar el sonido alrededor del rastreador. Además, cuenta con una función de alerta de caída que notifica cuando el dispositivo se cae. El TE-207 es compatible con la plataforma web GPS y la aplicación Android para un seguimiento en tiempo real.

El rastreador GPS TE-207 tiene una batería de larga duración, con hasta 30 días en espera. También cuenta con soporte AGPS para recibir señales GPS rápidamente. Otras características destacadas incluyen un gran botón de SOS para situaciones de emergencia, una tarjeta de memoria de 8 MB para almacenar hasta 60000 waypoints, un sensor G-sensor 3D para detectar movimiento y gestionar la energía, y conversación de dos vías con sonidos de alta calidad.

Además, el TE-207 ofrece seguimiento en tiempo real a través de SMS o GPRS, un botón de llamada para hablar, supervisión de voz, alarmas de geo-cerca y movimiento, alerta de batería baja y alerta de exceso de velocidad. También cuenta con posicionamiento con enlace de mapa de Google y una batería de litio recargable de 900 mAh. Utiliza la tecnología GPS U-Blox y se carga a través de un cargador micro USB y utiliza una tarjeta micro SIM.
