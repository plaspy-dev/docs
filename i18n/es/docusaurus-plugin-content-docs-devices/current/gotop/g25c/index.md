# GOTOP - G25C

![G25C](./logo..jpg)

El rastreador GPS GOTOP G25C-4G es un dispositivo diseñado para el Internet de las Cosas. Combina la tecnología de comunicación inalámbrica LTE con la tecnología de posicionamiento satelital GPS/BDS para proporcionar un seguimiento preciso y en tiempo real. El dispositivo cuenta con un diseño de antena integrada de alta integración de grado industrial, lo que garantiza un rendimiento confiable y estable.

Con el G25C-4G, puedes disfrutar de una variedad de funciones avanzadas, como seguimiento en tiempo real, ubicación en el mapa de Google a través de SMS, monitoreo de voz remoto, alarma de batería baja, alarma de exceso de velocidad y alarma de caída. El dispositivo también ofrece tres modos de ahorro de energía para adaptarse a diferentes escenarios de seguimiento.

Este rastreador GPS es adecuado para una variedad de aplicaciones, como automóviles privados/alquiler de vehículos/localización de equipos, seguimiento de flotas/vehículos/camiones/contenedores, monitoreo de bicicletas/e-bikes/motocicletas, protección y gestión de activos, seguimiento en tiempo real de cajas de troncos/cajas de cartón y otros fines de seguridad y protección.

Características destacadas:

- Antena GPS y 4G integrada para posicionamiento preciso y seguimiento en tiempo real.
- Alta clasificación de resistencia al agua \(IP65\) y superimán para una instalación fácil e inalámbrica.
- Compatible con plataforma web y aplicación móvil para un monitoreo conveniente.
- Batería grande de 20000mAh con un tiempo de espera de hasta 240 días.
- Compatible con la configuración de parámetros a través de SMS y enlace de mapa de Google para una configuración y seguimiento sencillos.
- Ubicación a través de enlace de mapa de Google y seguimiento en tiempo real para obtener información precisa de ubicación.
- Funciones de alarma diversas, incluyendo alarma de caída, alarma de movimiento, alarma de batería baja, alarma de sacudida y alarma de geo-cerca.
- Modo de ahorro de energía en reposo y encendido/apagado remoto para una gestión eficiente de la energía.
- Monitoreo y grabación de voz para mayor seguridad.
- Memoria interna para almacenamiento de datos y reenvío después de la recepción de la red LTE.
- Compatible con redes 4G LTE y 2G 850/900/1800/1900 MHz para una amplia compatibilidad.
