# GOTOP - Funciones del VT-390

Esta página ofrece un resumen público de las funciones del rastreador GPS GOTOP VT-390 y explica cómo sus capacidades se integran con Plaspy para el rastreo, la supervisión y la gestión operativa. Resume las funciones prácticas que puede esperar al usar el VT-390 con Plaspy y señala los tipos de datos y eventos que el dispositivo puede enviar a la plataforma.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, los accesorios instalados y la forma en que se integra la unidad en el vehículo. Utilice esta página como referencia general y consulte la documentación del fabricante para las especificaciones y opciones de configuración más actuales.

## Resumen de funciones

El GOTOP VT-390 está pensado para aplicaciones de gestión de flotas y seguridad vehicular, combinando seguimiento de ubicación con identificación del conductor, alertas de eventos, soporte de medios y conectividad de entradas y salidas. Sus funciones se orientan a mejorar la supervisión del vehículo, la responsabilidad del conductor y la recopilación de evidencia, además de permitir acciones de control remoto cuando están soportadas.

- Reporte de ubicación y seguimiento en tiempo real para visibilidad de la flota
- Identificación de conductor por RFID para vincular usuarios al uso del vehículo
- Entrada para cámara para capturar imágenes asociadas a ubicaciones o eventos
- Almacenamiento para medios y registros mediante tarjeta SD
- Alertas de eventos y seguridad como SOS, exceso de velocidad, movimiento y conducción brusca

## Características principales del GOTOP - VT-390

- Sistema de identificación de conductor por RFID para rastrear usuarios autorizados y flujos de trabajo anti robo
- Puerto para cámara y soporte para registrar imágenes como evidencia situacional
- Funcionalidad de audio bidireccional que permite escuchar y hablar para comunicación dentro del vehículo
- Sensor de movimiento integrado para reducir el consumo de energía cuando el vehículo está detenido
- Múltiples opciones de E/S, incluyendo entradas digitales, salidas y entradas analógicas para sensores y conexiones externas
- Soporte para sensores de combustible externos para monitorear entradas relacionadas con el combustible
- Funcionalidad de control remoto del motor para permitir acciones remotas autorizadas cuando estén habilitadas
- Informes de kilometraje para rastrear la distancia y el uso del vehículo

## Cómo funcionan estas funciones con Plaspy

Plaspy recibe los reportes del dispositivo y traduce los eventos y la telemetría del VT-390 en funciones de la plataforma para despacho, alertas e informes. La identificación del conductor, las imágenes, las alertas y los eventos de E/S del VT-390 pueden mostrarse en Plaspy para mejorar la toma de decisiones operativas y el registro de incidencias.

- Los eventos de identificación de conductor del VT-390 se pueden asociar con los perfiles de conductor en Plaspy para responsabilidad y atribución de viajes
- Las imágenes de la cámara y los medios almacenados en la tarjeta SD pueden vincularse a eventos o marcas de tiempo de ubicación en Plaspy para revisión de incidentes
- Las alertas SOS, de movimiento, exceso de velocidad y conducción brusca aparecen como notificaciones y eventos en la línea de tiempo dentro de Plaspy
- Los datos de kilometraje y rutas reportados por el dispositivo se integran en los informes de Plaspy para análisis de flota y planificación de mantenimiento
- Las entradas digitales y analógicas del VT-390 pueden representarse como eventos de sensores discretos en Plaspy para supervisar periféricos conectados

## Casos de uso típicos

- Operaciones de flota que rastrean vehículos, asignaciones de conductores y kilometraje de rutas
- Autenticación de conductores y prevención de uso no autorizado mediante identificación RFID
- Documentación y revisión de incidentes usando imágenes de cámara vinculadas a ubicación y alertas
- Monitoreo de seguridad con alertas de conducción brusca, exceso de velocidad y movimiento para mejorar el comportamiento del conductor
- Escenarios de intervención remota donde se requiere control del motor por motivos de seguridad o recuperación
- Monitoreo de combustible mediante sensores externos para supervisión del consumo

## Notas sobre disponibilidad de funciones

- Muchas capacidades del VT-390 dependen de accesorios instalados, como etiquetas RFID, módulos de cámara y tarjetas SD
- La versión de firmware y la revisión de hardware pueden modificar cómo funcionan alertas específicas, audio y control remoto
- El método de instalación y el cableado del vehículo pueden afectar qué entradas y salidas están disponibles o son recomendadas
- Las variantes regionales y la disponibilidad de redes pueden influir en cómo el rastreador reporta a través de redes celulares
- Revise las notas de lanzamiento del fabricante y los registros de cambios de firmware para actualizaciones de funciones y cambios de comportamiento

## Por qué usar Plaspy con estas funciones

Usar el GOTOP VT-390 con Plaspy ofrece a las organizaciones una vista consolidada de la ubicación del vehículo, la identidad del conductor y el historial de eventos. Plaspy traduce las alertas, el kilometraje y los medios del rastreador en información accionable para despacho, supervisión de seguridad y rendición de cuentas, ayudando a los equipos operativos a tomar decisiones informadas sin necesidad de gestionar el dispositivo a bajo nivel.
