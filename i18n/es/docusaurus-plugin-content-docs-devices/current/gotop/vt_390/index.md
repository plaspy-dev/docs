# GOTOP - VT-390

![VT-390](./logo.jpg)

El rastreador GPS GOTOP VT-390 es una opción avanzada y rentable para aquellos que buscan un dispositivo de seguimiento de alta calidad. Equipado con un potente microprocesador ARM9, este rastreador ofrece un rendimiento rápido y confiable. Además, cuenta con una cámara incorporada que permite capturar imágenes y registrar información de ubicación y conducción.

Una de las características destacadas del VT-390 es su capacidad de comunicación bidireccional, lo que significa que puede escuchar y hablar a través del dispositivo. También es compatible con tarjetas SD de hasta 64 GB, lo que le permite almacenar una gran cantidad de datos e imágenes. Además, cuenta con 4 conectores A / D para el seguimiento de múltiples sensores de combustible, lo que lo hace ideal para la gestión de flotas.

Otra característica interesante del VT-390 es su compatibilidad con la identificación del conductor a través de RFID activo. Esto permite una identificación automática y anti-robo, lo que brinda una mayor seguridad para su vehículo. Además, este rastreador GPS admite actualizaciones de firmware en línea a través de GPRS, lo que le permite mantenerse actualizado con las últimas mejoras y características.

En términos de seguridad, el VT-390 cuenta con alarmas de frenado y aceleración bruscas, así como una alarma de accidente. Estas características le permiten monitorear y recibir alertas en caso de eventos inesperados en la carretera. Además, este rastreador GPS ofrece una amplia gama de funciones y capacidades de expansión para satisfacer sus necesidades de gestión de flotas y seguridad del vehículo.

Características destacadas:

- Identificación del conductor RFID
- Registro de imágenes y monitoreo en línea
- Compatibilidad con tarjetas SD de hasta 64 GB
- Comunicación bidireccional
- Control de sensor de combustible
- Alarmas de frenado y aceleración bruscas
- Seguimiento vía SMS o GPRS
- Microprocesador ARM9 de alta velocidad
- Función de actualización en línea
- Control remoto del motor
- Informe de kilometraje
- Sensor de movimiento incorporado para ahorrar energía
- Localización por SMS con enlace a Google Maps
- Alerta SOS, alarma de movimiento, alerta de Geo-Fence, alerta de exceso de velocidad
- Alarma de corte de alimentación externa
- Monitoreo de temperatura \(opcional\)
- Entradas y salidas digitales y analógicas
