# GOTOP - VT-393: Funciones

Esta página ofrece una visión pública y orientada a funciones del GOTOP VT-393 y cómo sus capacidades pueden aprovecharse con Plaspy. Su objetivo es describir las funciones visibles para el usuario que son relevantes cuando el VT-393 está conectado a la plataforma Plaspy para la gestión de flotas y el monitoreo de vehículos.

La disponibilidad y el comportamiento exactos de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Esta página resume las características del modelo según la información pública y explica cómo suelen integrarse con Plaspy; para detalles definitivos consulte la documentación del fabricante.

## Visión general de funcionalidades

El GOTOP VT-393 se presenta como un rastreador vehicular completo pensado para gestión de flotas y seguridad de vehículos. Combina el reporte de ubicación con amplio soporte de periféricos como cámaras, almacenamiento, entradas y salidas, y admite actualizaciones por aire (OTA) para mantener el firmware actualizado. A continuación se destacan las capacidades más relevantes y prácticas para las operaciones diarias.

- Soporte integrado para cámara que permite capturar imágenes con contexto de ubicación y conducción para documentación o revisión de incidentes.
- Gran almacenamiento local mediante tarjeta SD con soporte de hasta 64 GB para fotos y datos registrados.
- Comunicación bidireccional para soportar comandos remotos e interacción en tiempo real entre el operador y el equipo.
- Múltiples entradas analógicas y digitales para sensores externos y monitoreo de señales, facilitando telemetría y control de estado.
- Alertas integradas para eventos como frenadas bruscas, aceleraciones fuertes, accidentes, SOS, movimiento, geocerca y exceso de velocidad, para seguridad operativa y cumplimiento.

## Funciones principales del GOTOP - VT-393

- Puerto para cámara y captura de imágenes que puede registrar fotos con información de ubicación o datos de conducción para evidencia de incidentes y revisión operativa.
- Soporte de almacenamiento en tarjeta SD de hasta 64 GB para retención local prolongada de datos e imágenes.
- Comunicación bidireccional que habilita comandos y confirmaciones entre el dispositivo y el centro de monitoreo.
- Capacidad de actualización de firmware OTA mediante datos celulares para permitir actualizaciones y mantenimiento remotos.
- Soporte activo de RFID para funciones automáticas antifurto e identificación de conductores.
- Múltiples canales analógicos y digitales, incluidos entradas analógicas y conectores A/D para integración y monitoreo de sensores.
- Sensor de movimiento integrado y alarmas de eventos, incluyendo frenadas bruscas, aceleraciones fuertes, alertas de accidente, movimiento, SOS, geocerca y exceso de velocidad.
- Reportes de kilometraje y funciones de control remoto del motor para supervisión operativa y control.

## Cómo funcionan estas funciones con Plaspy

Plaspy puede recibir y mostrar los reportes y eventos del VT-393 para proporcionar conciencia de ubicación, visibilidad de eventos y monitoreo operativo. Cuando el dispositivo está conectado y reportando, Plaspy muestra eventos clave y medios almacenados para que los equipos de flota puedan actuar.

- Los eventos y alarmas del dispositivo aparecen en Plaspy como alertas y entradas en la línea de tiempo para revisión rápida y escalamiento.
- Las imágenes capturadas por la cámara del rastreador pueden asociarse con posición y tiempo dentro de Plaspy para investigación de incidentes y registro.
- Los archivos almacenados en la tarjeta SD y los reportes de kilometraje aportan datos históricos que Plaspy puede utilizar para análisis e informes de cumplimiento.
- La identificación de conductor por RFID y los estados de entradas digitales pueden mostrarse en Plaspy como entradas personalizadas o atributos para flujos de trabajo de asignación de conductores y control de accesos.
- Las actualizaciones OTA y la comunicación bidireccional permiten administración remota y confirmación de comandos a través de la plataforma cuando el dispositivo y la red lo soportan.

## Casos de uso típicos

- Operadores de flotas que documentan incidentes con fotos vinculadas a la posición GPS para reclamaciones y formación de conductores.
- Monitoreo de seguridad vehicular usando alertas de movimiento, SOS y antifurto para responder a actividades no autorizadas.
- Identificación de conductores y control de acceso mediante integración de RFID activo para vincular conductores con viajes y eventos.
- Control operativo remoto y verificaciones de estado usando comandos bidireccionales junto con monitoreo de kilometraje y entradas.
- Retención de datos a largo plazo para cumplimiento usando el amplio almacenamiento SD para imágenes y registros de viaje.

## Notas sobre disponibilidad de funciones

- La presencia y el comportamiento de las funciones dependen de la versión de firmware del dispositivo y de la revisión de hardware enviada por el fabricante.
- Ciertas funciones, como el comportamiento de la cámara, la retención de imágenes y la mecánica de actualizaciones OTA, pueden verse afectadas por variantes regionales o limitaciones del operador.
- El cableado de entradas y salidas y las decisiones de instalación influyen en qué sensores y dispositivos externos están disponibles y cómo reportan los datos.
- Algunas funciones requieren configuración tanto en el dispositivo como en Plaspy para aparecer correctamente en la plataforma y garantizar que los datos se capturen como se espera.
- Para detalles técnicos e instrucciones de instalación más recientes, consulte la documentación del fabricante.

## Por qué usar Plaspy con estas funciones

Usar Plaspy con el GOTOP VT-393 integra las capacidades del dispositivo en un entorno centralizado de gestión de flotas. Plaspy recopila datos de ubicación y eventos, muestra alertas y enlaza medios y telemetría para ayudar a los equipos a monitorear la actividad de los vehículos, investigar incidentes y generar informes operativos. La combinación de soporte de cámara, identificación de conductores por RFID, opciones de E/S y actualizaciones OTA hace que el VT-393 sea útil para operadores que necesitan visibilidad y la posibilidad de mantener los dispositivos a distancia.

Para obtener más información sobre Plaspy y cómo puede integrarse con rastreadores compatibles visite https://www.plaspy.com. Para detalles técnicos específicos del dispositivo, notas de firmware y orientación del fabricante, verifique la información en el sitio de GOTOP https://www.gotop.cc/.
