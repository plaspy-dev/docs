# GOTOP - VT-393

![VT-393](./logo.jpg)

El rastreador GPS GOTOP VT-393 es una opción avanzada y rentable para el seguimiento de vehículos. Equipado con un microprocesador ARM9 de alta velocidad, este rastreador ofrece un rendimiento excepcional. Una de las características destacadas de este dispositivo es su cámara incorporada, que permite tomar fotos y registrar información de ubicación y conducción. Además, el VT-393 admite comunicación bidireccional y puede almacenar datos e imágenes en una tarjeta SD de hasta 64 GB.

Este rastreador también cuenta con 4 conectores A / D para el seguimiento de múltiples sensores de combustible, lo que lo hace ideal para la gestión de flotas. Además, el VT-393 es compatible con RFID activo para la identificación automática de conductores y protección contra robos. También ofrece la función de actualización en línea \(OTA\) para actualizar el firmware a través de GPRS.

El VT-393 está equipado con alarmas de frenado y aceleración bruscas, así como una alarma de accidente. Estas características adicionales garantizan la seguridad del vehículo y sus ocupantes. Con su amplia gama de funciones y su capacidad de expansión, el rastreador GPS GOTOP VT-393 es una opción confiable para la gestión de flotas y la seguridad de los vehículos.

### Características destacadas:

- WCDMA850 / 900 / 1900MHz / 2100MHZ
- Identificación del conductor RFID
- Foto tomada y monitoreo de imagen en línea
- Compatibilidad con tarjetas SD de hasta 64 GB
- Comunicación bidireccional
- Control de sensor de combustible
- Alarmas de frenado y aceleración bruscas
- Seguimiento vía SMS o GPRS \(TCP / UDP\)
- Microprocesador ARM9 de alta velocidad
- Función de actualización en línea \(OTA\)
- Control remoto del motor
- Informe de kilometraje
- Sensor de movimiento incorporado para ahorrar energía
- Localización por SMS con enlace de Google Maps
- Alerta SOS, alarma de movimiento, alerta de Geo-Fence, alerta de exceso de velocidad
- Alarma de corte de alimentación externa
- Monitor de temperatura \(opcional\)
- I / O: 5 entradas digitales, 5 salidas, 4 entradas analógicas, 1 puerto de cámara, 1 puerto RS232, 1 ranura para tarjeta SD
