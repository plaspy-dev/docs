# GOTOP - D06

![D06](./logo..jpg)

El rastreador GPS GOTOP D06-4G es un dispositivo diseñado para el seguimiento en tiempo real y la gestión de flotas de automóviles, motocicletas, bicicletas eléctricas y otros vehículos. Este dispositivo utiliza su capacidad LTE para enviar datos de posición precisos a un teléfono móvil especificado o a una base de servidores para fines de seguimiento. Con su módulo GPS incorporado, el D06-4G garantiza información de posicionamiento precisa. También cuenta con memoria interna para almacenar coordenadas GPS cuando no hay conexión GPRS o a intervalos especificados por el usuario. Además, el D06-4G ofrece la opción de conectar un micrófono para escuchar el interior del vehículo de forma discreta.

Algunas características destacadas del GOTOP D06-4G incluyen:

- Compatibilidad con bandas de frecuencia 4G LTE y 2G
- Soporte de posicionamiento GPS/BD/WIFI/LBS
- Múltiples modos de alarma para una mayor seguridad
- Botón de SOS para rescate de emergencia
- Corte remoto de energía con relé
- Función de escucha con micrófono
- Clasificación de resistencia al agua IP65 para mayor durabilidad
- Configuración de doble IP de servidor para un seguimiento flexible

Algunos de los parámetros principales del GOTOP D06-4G son:

- Modo de alimentación: alimentación por batería
- Rango de voltaje de funcionamiento: DC 9V - 95V
- Corriente de trabajo: 12V/30MA - 40MA
- Corriente en reposo: 12V/5MA - 15MA
- Capacidad de la batería incorporada: 140 mAh \(batería de polímero de 3.7V\)
- Marca/modelo de chip del módulo de comunicación: SIMcom A7670E, SIMcom A7670SA
- Banda de frecuencia de comunicación: LTE-FDD: B1/B2/B3/B4/B5/B7/B8/B28/B66, LTE-TDD B34/B38/B39/B40/B41, GSM/EDGE/2G: 850/900/1800/1900MHz
- Tarjeta SIM: Tarjeta SIM micro
- Antena de comunicación: Antena incorporada
- Tamaño de apariencia: 80mm \* 38mm \* 17mm
- Material de la carcasa: Plástico ABS
- Peso de la unidad principal: 50.6 gramos
