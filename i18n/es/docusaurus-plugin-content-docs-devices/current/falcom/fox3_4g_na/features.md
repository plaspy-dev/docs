# Falcom - FOX3-4G-NA — Funciones

Esta página ofrece una visión pública de las funciones del rastreador Falcom FOX3-4G-NA y de cómo esas capacidades se presentan cuando el dispositivo se usa con Plaspy. Se enfoca en capacidades prácticas orientadas al usuario, como conectividad, posicionamiento, expansión de E/S y funciones telemáticas avanzadas, manteniendo un tono adecuado para documentación pública y búsqueda.

La disponibilidad exacta de funciones y su comportamiento pueden variar según la versión de firmware, la revisión de hardware, el tipo de instalación y la implementación del fabricante. Para detalles de configuración del equipo y las especificaciones técnicas más recientes, consulte la documentación de Falcom y a su proveedor de dispositivos según sea necesario.

## Resumen de funciones

El FOX3-4G-NA está pensado para telemática vehicular industrial y uso como gateway IoT cuando se requieren conectividad celular de alta velocidad y posicionamiento GNSS preciso. Ofrece diversas opciones de expansión y varias funciones telemáticas avanzadas útiles para operaciones de flotas e integración con plataformas como Plaspy.

- Conectividad celular LTE Cat 4 con retroceso a 3G y 2G para amplia cobertura de redes
- Receptor GNSS moderno para mayor precisión de ubicación y soluciones consistentes
- Entradas y salidas configurables para integrarse con señales del vehículo o equipo
- Compatibilidad con módulos de la familia IOBOX para expansión CAN, WLAN y E/S
- Cambio automático entre antena interna y externa para mayor flexibilidad en la instalación
- Funciones premium como cifrado de datos, modos de historial múltiples, monitoreo de conducción eficiente y comportamiento, registro de datos y detección de interferencias GSM/GPS

## Funciones principales del Falcom - FOX3-4G-NA

- Módem celular LTE Cat 4 con fallback a redes heredadas para conectividad robusta
- Receptor GNSS moderno para reportes de posición precisos
- Entradas y salidas configurables para capturar estados digitales y señales externas
- Soporte para módulos IOBOX MINI, IOBOX CAN e IOBOX WLAN para ampliar la funcionalidad
- Soporte para antena interna y externa con desactivación automática de la antena interna cuando se conecta una externa
- Cifrado de datos y manejo seguro de información según las capacidades provistas por Falcom
- Múltiples modos de historial y registro de datos a bordo para obtener registros de viaje y eventos más completos

## Cómo funcionan estas funciones con Plaspy

Plaspy recibe datos de posición y eventos de rastreadores compatibles y presenta la ubicación y el contexto operativo dentro de la plataforma. Cuando un FOX3-4G-NA está conectado a Plaspy, las funciones habituales del dispositivo se traducen en visibilidad e información operativa para monitoreo e informes.

- Datos de posición en tiempo real e históricos se muestran en los mapas de Plaspy y en las vistas de historial de viajes
- Las entradas y salidas del dispositivo pueden reflejarse como eventos o indicadores de estado dentro de Plaspy
- Los reportes de estado y mensajes de alerta del rastreador se convierten en notificaciones y entradas de la línea de tiempo de la plataforma
- Los modos de historial múltiples y el registro a bordo mejoran los informes de Plaspy cuando se requieren registros más largos o de mayor fidelidad
- Funciones de seguridad como cifrado de datos y detección de interferencias pueden registrarse o destacarse en Plaspy para mayor conciencia operativa

## Casos de uso típicos

- Seguimiento de flotas y historial de rutas para logística y servicios
- Gateways IoT industriales donde se necesita E/S expandida o conectividad WLAN mediante módulos IOBOX
- Monitoreo remoto de equipos o activos que se benefician del registro de datos y modos de historial
- Monitoreo de comportamiento del conductor y conducción eficiente para apoyar programas de seguridad y ahorro
- Despliegues de rastreo seguro donde se requieren detección de interferencias y comunicaciones cifradas
- Instalaciones que demandan arreglos de antena flexibles o integración de sensores externos

## Notas sobre disponibilidad de funciones

- La disponibilidad de funciones depende de la versión de firmware del dispositivo y de la revisión de hardware específica
- Las variantes regionales del modelo y el soporte de bandas celulares pueden afectar el comportamiento de conectividad en distintos mercados
- Algunas capacidades de expansión requieren el módulo IOBOX correspondiente y pueden no estar presentes en la unidad base
- Las decisiones de instalación, incluyendo selección de antena y cableado, determinan qué entradas y salidas estarán disponibles en la práctica
- Consulte la documentación de Falcom para características específicas según firmware e instrucciones de configuración

## Por qué usar Plaspy con estas funciones

Usar el FOX3-4G-NA con Plaspy permite a las organizaciones convertir de forma práctica la conectividad y los datos GNSS del dispositivo en visibilidad operativa. Plaspy presenta ubicación, historial de eventos e información de estado del equipo para que los equipos puedan monitorear activos, analizar viajes y responder a alertas desde una plataforma centralizada.

Learn more about how Plaspy works with devices like the FOX3-4G-NA on the Plaspy website https://www.plaspy.com. For the most current device specific feature details firmware behavior and manufacturer implementation notes check the official Falcom documentation at https://www.falcom.de.
