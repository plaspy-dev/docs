# Falcom - FOX3-4G-NA

![FOX3-4G-NA](./logo.jpg)

El Falcom FOX3-4G-NA es un rastreador GPS de alto rendimiento y una pasarela telemática para vehículos, diseñado para entornos industriales y de IoT de flota que exigen conectividad de datos robusta. Basado en LTE Cat 4 con retroceso a 3G y 2G, garantiza alcance de red continuo mientras emplea posicionamiento GNSS moderno para ofrecer datos de ubicación precisos. El equipo admite múltiples entradas y salidas y puede ampliarse con las cajas de expansión Falcom como IOBOX-MINI, IOBOX-CAN o IOBOX-WLAN para adaptarse a distintos requerimientos de integración con vehículos y equipos.

Como dispositivo compatible con Plaspy, el FOX3-4G-NA puede enviar información de ubicación, estado y eventos a la plataforma de gestión de flotas de Plaspy para facilitar la supervisión en tiempo real, el envío de alertas y la generación de informes históricos. Su combinación de opciones de conectividad, soporte flexible de E/S y funciones avanzadas como cifrado de datos, múltiples modos de historial, monitoreo de comportamiento eco drive, registro de datos y detección de interferencias lo convierten en una opción práctica para organizaciones que desean integrar hardware avanzado con Plaspy para supervisión operativa y análisis.

## Características principales

- Conectividad LTE Cat 4 con retroceso a 3G y 2G para cobertura móvil resiliente
- Tecnología GNSS de última generación para posicionamiento fiable y preciso
- Entradas y salidas flexibles y compatibilidad con expansión IOBOX para capacidades adicionales
- Soporte para antenas internas y externas con conmutación automática para mayor flexibilidad de instalación
- Funciones avanzadas como cifrado de datos, múltiples modos de historial, monitoreo eco drive, registro de datos y detección de interferencias
- Funciones telemáticas estándar como reportes de estado, mensajería de alertas y geocercas

## Cómo funciona con Plaspy

Al integrarse con Plaspy, el FOX3-4G-NA suministra la ubicación del vehículo y eventos que Plaspy utiliza para ofrecer visibilidad operativa y herramientas de gestión de flotas. Plaspy procesa los datos del dispositivo y los presenta en paneles, reglas de alerta e informes, permitiendo que usted actúe sobre información en vivo y registros históricos.

- Seguimiento de ubicación en tiempo real y visualización de estado en los paneles de Plaspy
- Geocercas y notificaciones de alerta enviadas a Plaspy para avisos oportunos
- Reproducción de rutas históricas e informes aprovechando los múltiples modos de historial del dispositivo
- Datos de comportamiento y eco drive disponibles para monitoreo y análisis operativo
- Eventos de E/S y señales de cajas de expansión mapeados en Plaspy para monitoreo y flujos de trabajo personalizados

## Casos de uso típicos

- Flotas comerciales que requieren monitoreo continuo de ubicación y estado
- Entornos de IoT industrial y seguimiento de equipos donde se necesitan funcionalidades de gateway y expansión de E/S
- Operaciones de logística y transporte que se benefician de informes históricos y geocercas
- Vehículos y activos que requieren detección de manipulación e interferencias para mayor seguridad
- Operaciones que buscan insights de eco drive y comportamiento para mejorar seguridad y eficiencia

## Por qué elegir este rastreador con Plaspy

El FOX3-4G-NA combina conectividad práctica y escalabilidad con un conjunto de funciones telemáticas que se alinean bien con las capacidades de monitoreo y reporte de Plaspy. Su diseño favorece la integración flexible y despliegues escalables, lo que lo hace adecuado para flotas y usuarios industriales que necesitan una puerta de enlace configurable que pueda adaptarse a sus requerimientos.

Dado que el dispositivo admite diversas opciones de expansión y ofrece funciones mejoradas como cifrado de datos y múltiples modos de historial, las organizaciones que usan Plaspy pueden diseñar flujos de trabajo, alertas y análisis a medida sin depender exclusivamente de un perfil de hardware fijo. Esta combinación ofrece un equilibrio entre conectividad moderna y flexibilidad operativa para la gestión profesional de flotas.
