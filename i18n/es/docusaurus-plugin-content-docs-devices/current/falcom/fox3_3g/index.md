# Falcom - FOX3-3G

![FOX3-3G](./logo.jpg)

La serie FOX3-3G de Falcom es un dispositivo de puerta de enlace y telemática todo en uno compacto que combina la conexión de datos de alta velocidad HSPA + / 2G con la última tecnología GNSS para satisfacer completamente las necesidades del cliente. Este dispositivo telemático altamente personalizable ofrece una variedad de entradas y salidas para satisfacer los requisitos más exigentes.

Para ampliar la funcionalidad de la serie FOX3-3G, se puede utilizar una caja \(IOBOX-MINI, IOBOX-CAN o IOBOX-WLAN\) para opciones de expansión más flexibles en la industria. Además, este dispositivo está diseñado para operar con antenas internas o externas, con las antenas internas incorporadas que se apagan automáticamente cuando se utilizan las antenas externas.

La serie FOX3-3G simplifica drásticamente la logística, el proceso de instalación y el soporte posterior a la instalación. Las "Características Premium" de FALCOM recientemente desarrolladas muestran el camino hacia el futuro del registro, almacenamiento, procesamiento y envío de datos móviles. Este dispositivo de rastreo de vehículos avanzado y totalmente personalizable ofrece nuevas características como cifrado de datos, varios modos de historia, Eco-Drive/Comportamiento, registro de datos, detección de atascos GSM/GPS, junto con elementos estándar como informes de estado, mensajes de alerta, llamadas de audio, llamadas espías o geofencing.

Tenga en cuenta que, excepto el modelo FOX3-3G-AU, todos los demás modelos de esta serie de dispositivos no son compatibles con la interfaz de audio.
