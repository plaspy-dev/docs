# Falcom - FOX3-3G - Características

Esta página ofrece una visión pública de la serie Falcom FOX3-3G y describe, en contexto práctico, cómo funcionan sus características cuando se utilizan con Plaspy. Se enfoca en las capacidades del dispositivo relevantes para los usuarios de Plaspy, cómo se reflejan en los flujos de trabajo de gestión de flotas y qué aspectos considerar al emparejar dispositivos FOX3-3G con la plataforma Plaspy.

La disponibilidad y el comportamiento exactos de las funciones pueden variar según la versión de firmware, la revisión de hardware, la variante del modelo, el método de instalación y la implementación del fabricante. Cuando aplica, esta página señala diferencias de modelo, como la interfaz de audio disponible solo en la variante FOX3-3G-AU, y recomienda verificar la documentación oficial de Falcom para detalles específicos del dispositivo.

## Resumen de funciones

La serie FOX3-3G está posicionada como un gateway telemático compacto para vehículos que combina datos móviles de alta velocidad y posicionamiento GNSS avanzado con opciones flexibles de entradas y salidas. Está pensada para seguimiento de flotas, monitoreo de comportamiento de conductores y recolección de datos para logística, y su enfoque modular permite expandir capacidades mediante accesorios.

- Recepción GNSS avanzada para reportes de posición fiables en entornos vehiculares
- Conectividad de datos móviles de alta velocidad para telemetría ágil y acceso remoto a datos
- Múltiples entradas y salidas para integración con el vehículo y recolección de telemetría
- Soporte para antenas externas para mejorar la recepción cuando sea necesario
- Funcionalidad ampliable mediante cajas accesorias como IOBOX-MINI, IOBOX-CAN y IOBOX-WLAN
- Funciones premium para registro de datos móviles, manejo cifrado de datos y modos de historial de eventos

## Funciones principales del Falcom - FOX3-3G

- Tecnología GNSS avanzada para localización y rastreo precisos
- Conexión de datos móviles de alta velocidad para soportar reportes frecuentes y transferencia remota
- Soporte de E/S ampliable y accesorios incluyendo IOBOX-MINI, IOBOX-CAN y IOBOX-WLAN para telemetría extendida
- Suite de Premium-Features que incluye registro de datos móviles, múltiples modos de historial y cifrado de datos
- Capacidades de monitoreo de eco drive y comportamiento del conductor para obtener información operativa
- Detección de jamming o interferencias GSM y GPS para mejorar la seguridad y el conocimiento de la señal
- Funciones telemáticas estándar como reportes de estado, mensajes de alerta y geocercas
- Funcionalidad de llamada de audio y spy call disponible únicamente en el modelo FOX3-3G-AU

## Cómo funcionan estas funciones con Plaspy

Plaspy recibe y normaliza los datos entrantes de rastreadores compatibles, incluida la serie FOX3-3G, de modo que la información de ubicación, los eventos y los historiales registrados puedan ser monitoreados y gestionados dentro de una única interfaz de gestión de flotas. Plaspy presenta las funciones del dispositivo para apoyar flujos operativos y supervisión.

- Localización en tiempo real y seguimiento en los mapas de Plaspy usando los reportes de posición GNSS del dispositivo
- Visibilidad de eventos y alertas para reportes de estado, mensajes de alerta, activaciones de geocerca y notificaciones de detección de interferencias
- Reproducción de rutas históricas y vistas de historial de datos que reflejan los modos de historial y la telemetría guardada por el dispositivo
- Acceso a datos registrados y cargas útiles cifradas mostrado a través de las herramientas de reporte y exportación de Plaspy
- Visibilidad de entradas E/S y accesorios cuando el dispositivo está emparejado con módulos IOBOX y reporta esa información hacia Plaspy
- Detección automática de protocolo por parte de Plaspy para que los dispositivos FOX3-3G puedan ser reconocidos e integrados sin necesidad de seleccionar manualmente el protocolo

## Casos de uso típicos

- Rastreo de ubicación de vehículos de flota y monitoreo de rutas para operaciones diarias
- Supervisión logística y de entregas mediante actualizaciones frecuentes de posición y reproducción histórica
- Programas de comportamiento de conductores y eco driving que usan datos de monitoreo para mejorar la eficiencia
- Integración de sensores del vehículo y cajas externas para telemetría ampliada en flotas especializadas
- Monitoreo de seguridad frente a intentos de interferencia GSM o GPS y generación de alertas relacionadas
- Interacciones de voz remotas cuando se utiliza el modelo FOX3-3G-AU con funciones de audio para escenarios de llamada

## Notas sobre disponibilidad de funciones

- Los conjuntos de funciones pueden variar entre modelos y variantes regionales; el modelo FOX3-3G-AU incluye interfaces de audio que no están presentes en otras variantes
- Las versiones de firmware y las revisiones de hardware pueden habilitar o modificar el comportamiento de las Premium-Features, como modos de historial o cifrado de datos
- Los accesorios IOBOX son expansiones opcionales y pueden requerir configuración e instalación por separado
- El tipo de instalación y el cableado afectan qué entradas y salidas están disponibles para reportes de telemetría
- Confirme siempre las listas de funciones y el comportamiento de firmware actuales con la documentación de Falcom para el número de serie y modelo específicos

## Por qué usar Plaspy con estas funciones

Emparejar la serie Falcom FOX3-3G con Plaspy ofrece una forma centralizada de recopilar datos de posición, eventos e historiales registrados en una flota mixta, presentando esas entradas en paneles, alertas e informes que ayudan a responsables operativos y gestores de flota a tomar decisiones. La detección de dispositivos y la normalización de datos de Plaspy facilitan la incorporación de dispositivos FOX3-3G y cualquier expansión IOBOX adjunta en flujos de monitoreo e informes.
