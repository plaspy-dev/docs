# Falcom - FOX3-2G

![FOX3-2G](./logo.jpg)

La serie FOX3-2G de Falcom es un dispositivo compacto de telemática y rastreo de vehículos que combina la conexión de datos 2G con la última tecnología GNSS para satisfacer las necesidades del cliente. Este dispositivo telemático altamente personalizable ofrece una variedad de entradas y salidas para adaptarse a los requisitos más exigentes. Además, se puede utilizar una caja \(IOBOX-MINI o IOBOX-CAN\) para ampliar la funcionalidad de la serie FOX3-2G y proporcionar opciones de expansión flexibles.

La serie FOX3-2G está diseñada para funcionar con antenas internas o externas. Las antenas internas se apagan automáticamente cuando se utilizan las antenas externas. Esto simplifica drásticamente la logística, la instalación y el soporte posterior a la instalación. Además, las "Características Premium" desarrolladas por FALCOM muestran el camino hacia el futuro del registro, almacenamiento, procesamiento y envío de datos móviles. La serie FOX3-2G ofrece características avanzadas y totalmente personalizables, como cifrado de datos, varios modos de historial, Eco-Drive/Comportamiento, registro de datos, detección de atascos GSM/GPS, informes de estado, mensajes de alerta, llamadas de audio, llamadas espías y geofencing.

Características destacadas:

- Conexión de datos 2G
- Tecnología GNSS de última generación
- Altamente personalizable
- Variedad de entradas y salidas
- Compatibilidad con cajas de expansión IOBOX-MINI o IOBOX-CAN
- Funcionamiento con antenas internas o externas
- Características Premium de FALCOM
- Cifrado de datos
- Varios modos de historial
- Eco-Drive/Comportamiento
- Registro de datos
