# WP - SPT-10

![SPT-10](./logo.jpg)

El rastreador GPS WP SPT-10 es un dispositivo versátil que ofrece una aplicación universal para el seguimiento en línea de personas, automóviles, motocicletas, animales y otros activos. Con este rastreador GPS, podrás adquirir la posición actual, velocidad y dirección de movimiento, y enviar los datos a un servidor especificado por el usuario o a un número de teléfono a través de GPRS y/o SMS.

Con el WP SPT-10, podrás tener un control total sobre tus activos y asegurarte de su seguridad en todo momento. Ya sea que necesites rastrear la ubicación de tu vehículo, supervisar a tus seres queridos o proteger tus pertenencias más valiosas, este rastreador GPS te brinda la tranquilidad que necesitas.

Características destacadas:

- Aplicación universal para el seguimiento en línea de personas, automóviles, motocicletas, animales y otros activos.
- Adquisición de posición actual, velocidad y dirección de movimiento.
- Envío de datos a un servidor especificado por el usuario o a un número de teléfono a través de GPRS y/o SMS.
