# WP - M7

![M7](./logo..png)

El WP M7 es un dispositivo portátil de rastreo GPS que ofrece un tamaño compacto y una fácil instalación gracias a su característica de montaje magnético. Está diseñado para proporcionar un seguimiento confiable y conveniente para vehículos, con módulos GPS y GSM/GPRS superiores. El M7 también cuenta con un consumo de energía en espera ultra bajo y una clasificación de resistencia al agua IP67, lo que lo hace adecuado para entornos exteriores.

Una de las características clave del M7 es su capacidad para transmitir datos a través de SMS, GPRS, UDP y TCP. Esto permite el seguimiento y monitoreo en tiempo real del dispositivo. Además, el M7 cuenta con una función de alerta desacoplada, que envía notificaciones cuando el dispositivo se retira o se manipula.

Otras características destacadas del M7 incluyen informes de movimiento, configuración de preferencia de roaming, alertas de nivel de batería baja, configuraciones de administración de energía y seguimiento mediante llamada de voz. También ofrece una instalación rápida y sencilla, con un montaje magnético que permite una sujeción segura a cualquier superficie metálica. Con su batería recargable de 5200mAh de iones de litio incorporada, el M7 puede proporcionar hasta 3 años de tiempo de espera.

Las especificaciones de hardware del M7 incluyen dimensiones de 102 mm x 47 mm x 46 mm y un peso de 300 g. Opera en una red GSM de banda cuádruple \(850/900/1800/1900 MHz\) y cuenta con un receptor GPS de 66 canales con seguimiento de alta sensibilidad \(-165dBm\). El dispositivo tiene 4MB de memoria y un sensor de aceleración de 3 ejes incorporado. La carcasa está hecha de plástico ABS y tiene una clasificación IP67 para protección contra polvo y agua.

En resumen, el WP M7 es un dispositivo de rastreo GPS versátil y confiable que ofrece una instalación fácil, capacidades avanzadas de transmisión de datos y una variedad de características útiles. Es una opción ideal para aplicaciones de seguimiento de vehículos, proporcionando información precisa y en tiempo real sobre la ubicación.
