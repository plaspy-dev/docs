# WP - OT-10

![OT-10](./logo..png)

El rastreador GPS WP OT-10 de Wonde Proud es un dispositivo de seguimiento de vehículos de alto rendimiento y fácil instalación. Con comunicación a través de datos CS, SMS y GPRS UDP/TCP, este rastreador ofrece una amplia gama de opciones de seguimiento y configuración.

El OT-10 cuenta con un sistema de posicionamiento por satélite GPS + GLONASS de doble modo, con soporte AGPS. Esto garantiza una precisión y fiabilidad óptimas en la ubicación del vehículo. Además, su comunicación GSM/GPRS de banda cuádruple permite una conectividad estable y confiable en todo momento.

Este rastreador GPS también cuenta con un sensor de aceleración triaxial para detectar movimientos y cambios de dirección del vehículo. Además, tiene una batería de respaldo incorporada de 2100mAh \(opcional\) para garantizar un seguimiento continuo incluso en caso de pérdida de energía.

El OT-10 es compatible con todos los protocolos OBD-II legislados, lo que le permite obtener información detallada sobre el vehículo, como el consumo de combustible, el número de identificación del vehículo \(VIN\) y el estado del encendido \(IG\). También ofrece configuración remota del dispositivo y actualización de firmware a través del aire.

Con el rastreador GPS WP OT-10, puede establecer hasta 100 eventos autodefinidos para recibir notificaciones sobre geovallas, remolques, ralentí, exceso de velocidad y más. Además, puede configurar preferencias de roaming y administración de energía para optimizar el rendimiento del dispositivo.

### Características destacadas:

- Comunicación por datos CS, SMS, GPRS UDP/TCP
- Sistema de posicionamiento por satélite GPS + GLONASS
- Comunicación GSM/GPRS de banda cuádruple
- Sensor de aceleración triaxial
- Batería de respaldo incorporada \(opcional\)
- Compatibilidad con todos los protocolos OBD-II legislados
- Configuración y actualización remota del dispositivo
- Notificaciones de eventos autodefinidos
- Configuración de preferencias de roaming y administración de energía
