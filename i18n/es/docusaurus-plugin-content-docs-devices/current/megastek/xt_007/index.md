# Megastek - XT-007

![XT-007](./logo.jpg)

El rastreador GPS Megastek XT-007 es una opción versátil que ofrece opciones de antena GPS externa y cable de conexión personalizable. Con una función de antena GPS y batería interna, el XT-007 se puede utilizar como un rastreador personal o como un logger con memoria interna. Además, este rastreador también puede utilizarse para la vigilancia de antecedentes de voz.

El XT-007 ofrece una variedad de funciones y características que lo hacen ideal para diferentes aplicaciones. Los usuarios pueden configurar geofences, alarmas de exceso de velocidad, alarmas de movimiento y alarmas de batería baja. Además, este rastreador también permite la parada remota del motor y el inicio con un cable especial y un relé. Además, el firmware del XT-007 es actualizable tanto a través de USB como de forma inalámbrica, lo que garantiza que siempre esté actualizado con las últimas mejoras y características.

Características destacadas del Megastek XT-007:

- SMS / GPRS de seguimiento \(soporte TCP y UDP\) Seguimiento en tiempo real.
- Seguimiento por intervalo / demanda Vigilancia de la voz de fondo.
- Modo de ahorro de energía.
- Alarma SOS.
- Detección ACC Detección de aceites Combustible remoto / motor cortado.
- Alarma de Geo-cercas.
- Alarma de velocidad.
- Sensor de movimiento.
- Advertencia de baja potencia Batería de reserva incorporada.
