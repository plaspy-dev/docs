# Megastek - GVT-390

![GVT-390](./logo.jpg)

El Megastek GVT-390 es un dispositivo de seguimiento basado en GPRS diseñado específicamente para equipos de maquinaria pesada, máquinas de construcción y vehículos. Utilizando la tecnología GPS y la comunicación GSM o GPRS, este rastreador puede proporcionar información precisa sobre la ubicación y enviar datos a su teléfono o plataforma de gestión de flotas.

El GVT-390 cuenta con varias características destacadas, como un botón de SOS que permite enviar mensajes de alarma para situaciones de rescate. También cuenta con 2 salidas digitales, 5 entradas digitales y 2 entradas analógicas para diferentes informes y aplicaciones. Además, este dispositivo es compatible con 2 interfaces RS232, lo que permite la conexión de una cámara adicional, un teléfono o una pantalla LCD.

Algunas de las características adicionales del GVT-390 incluyen la capacidad de establecer hasta 5 números de teléfono celular autorizados, seguimiento de demanda por intervalo de tiempo, alarma de límite de velocidad, alarma de batería baja, alarma de vibración, alarma de corte de energía, registro de datos en áreas sin señal GSM utilizando una tarjeta Micro SD \(máximo 2 GB\), 2 salidas de relé, detección de combustible y detección de encendido.
