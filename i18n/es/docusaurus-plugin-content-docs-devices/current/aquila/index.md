# Aquila

Aquila es un nombre reconocido en el sector de rastreo GPS, con modelos de dispositivos que funcionan con plataformas de terceros. Esta página explica cómo se integran los rastreadores Aquila con Plaspy, cómo elegir el dispositivo correcto para su aplicación y dónde encontrar documentación adicional. Utilice el catálogo a continuación para explorar los dispositivos Aquila compatibles y acceder a las páginas específicas de cada modelo.

## Cómo funcionan los dispositivos Aquila con Plaspy

Plaspy puede recibir la telemetría de los rastreadores Aquila para que usted monitoree ubicación, estado y eventos desde una única plataforma. La integración normalmente implica registrar la identidad del dispositivo en Plaspy y configurar el rastreador para que reporte a la plataforma usando las credenciales del equipo. Una vez conectado, Plaspy muestra actualizaciones de posición en tiempo real, rutas históricas y alertas generadas por el rastreador.

Esta página se enfoca en compatibilidad y recomendaciones. Para la configuración a nivel de dispositivo y los detalles del servidor, abra la entrada del dispositivo en el catálogo y siga las instrucciones específicas allí.

## Funciones comunes en los dispositivos Aquila

Aunque las capacidades varían según el modelo, muchos rastreadores Aquila incluyen un conjunto de funciones comunes útiles para el monitoreo de flotas y activos:
- Reporte de ubicación GPS continuo o periódico para mantener el historial de posiciones
- Detección de movimiento y de encendido para supervisar actividad
- Reporte de estado de alimentación y de manipulación para detectar cambios no autorizados
- Batería interna de respaldo para informes de corto plazo cuando se pierde la alimentación externa
- Intervalos de reporte y umbrales de alerta configurables

Consulte las páginas de cada dispositivo en el catálogo para ver listas de funciones exactas y especificaciones de hardware.

## Casos de uso típicos de los rastreadores GPS Aquila

Los dispositivos Aquila se usan comúnmente para:
- Seguimiento de vehículos de flota para monitorear rutas, conducta del conductor y utilización
- Rastreo de activos como remolques, maquinaria y activos móviles de alto valor
- Operaciones de renta y arrendamiento para aplicar geocercas y límites de uso
- Servicio de campo y pequeñas flotas comerciales que requieren rastreadores compactos
Plaspy puede adaptar los informes y las alertas a estos escenarios para que los equipos operativos obtengan información accionable de los dispositivos Aquila.

## Por qué elegir Plaspy para monitorear dispositivos Aquila

Plaspy ofrece una plataforma unificada para gestionar flotas mixtas de dispositivos, incluidos los rastreadores Aquila. Ventajas clave al combinar Aquila con Plaspy:
- Gestión centralizada de dispositivos y herramientas de aprovisionamiento para incorporar rastreadores
- Alertas configurables y geocercas para adecuarse a políticas operativas
- Historial de rutas e informes que ayudan a reducir tiempos muertos y mejorar la utilización
- Roles de usuario y permisos para controlar el acceso entre equipos

Si ya utiliza hardware Aquila, Plaspy ayuda a consolidar datos y flujos de trabajo en una vista operativa única. Learn more about the platform and enterprise features at https://www.plaspy.com.
