# Aquila - TS101 Advanced: Características

Esta página presenta el contexto público de funciones del Aquila TS101 Advanced y cómo sus capacidades se emplean comúnmente con Plaspy. Está enfocada en detalles prácticos y no sensibles sobre lo que puede hacer el equipo y cómo esas funciones resultan útiles cuando el dispositivo está conectado a la plataforma Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, la forma de instalación y la implementación de interfaces opcionales por parte del fabricante. Para la configuración final y los detalles técnicos más recientes consulte la documentación y las notas de firmware del fabricante.

## Resumen de funciones

El TS101 Advanced está diseñado como un rastreador compacto y resistente para el monitoreo de vehículos y activos en diversas operaciones. Su combinación de localización en tiempo real, almacenamiento local de registros y múltiples interfaces de E/S para vehículos lo hace adecuado para seguimiento continuo y monitoreo basado en eventos cuando se utiliza con una plataforma en la nube como Plaspy.

- Seguimiento en tiempo real para visibilidad continua de la ubicación y monitoreo operativo
- Almacenamiento sólido en el dispositivo capaz de guardar hasta 16 000 registros de seguimiento para registro offline y posterior subida
- Carcasa de ABS resistente con certificación IP67 para funcionamiento fiable en entornos exigentes
- Interfaces de inmovilizador y salida para bocina/alarma para control remoto e integración de alertas
- Interfaz para sensor de combustible para capturar el nivel de combustible cuando se instala un sensor compatible
- Acelerómetro de 3 ejes para detección de movimiento e impactos

## Características principales del Aquila - TS101 Advanced

- Compatibilidad con Plaspy para seguimiento y gestión centralizados
- Reporte de ubicación GPS en tiempo real para visibilidad inmediata de la flota y activos
- Almacenamiento local sólido de hasta 16 000 registros para preservar el historial durante cortes de conexión
- Interfaz de inmovilizador para flujos de trabajo de desactivación remota del motor donde esté instalado y soportado
- Salida para bocina/alarma para alertas acústicas locales o indicación de estado
- Interfaz para sensor de combustible que muestra niveles cuando hay un sensor conectado
- Acelerómetro de 3 ejes que permite detección de movimiento e impactos para alertas basadas en eventos
- Carcasa ABS con grado IP67 y batería de respaldo integrada para operación continua en condiciones adversas

## Cómo se integran estas funciones con Plaspy

Al registrar el TS101 Advanced en Plaspy, el dispositivo puede aportar datos continuos e históricos a un único entorno de monitoreo para que los equipos mantengan conciencia situacional sobre vehículos y activos.

- Los datos de ubicación en vivo aparecen en los mapas de Plaspy para seguimiento en tiempo real y decisiones de despacho
- Los registros almacenados pueden subirse y reproducirse en Plaspy para revisar rutas o eventos históricos
- Los eventos de inmovilizador y el estado de control pueden mostrarse en la plataforma como eventos del dispositivo o indicadores de estado cuando están configurados
- Las lecturas del sensor de combustible reportadas por el equipo son visibles en los paneles o en la vista de detalles del dispositivo cuando hay sensor presente
- Los eventos de movimiento e impacto detectados por el acelerómetro pueden aparecer como alertas o entradas en la línea de tiempo dentro de Plaspy
- El hardware resistente y la batería de respaldo ayudan a mantener la continuidad del reporte de posición a Plaspy durante interrupciones de energía

## Casos de uso típicos

- Seguimiento de flotas logísticas para monitoreo de rutas y análisis histórico de recorridos
- Operaciones de taxis y flotas de transporte que requieren ubicación en vivo y controles remotos sencillos
- Gestión de flotas de alquiler de autos con historial de eventos para vehículos administrados
- Rastreo de seguridad para activos de alto valor en entornos exteriores o industriales
- Escenarios de telemática para aseguradoras que usan datos de movimiento e históricos para análisis de siniestros
- Seguimiento de activos en emplazamientos donde la protección ambiental y la batería de respaldo son importantes

## Notas sobre disponibilidad de funciones

- La versión de firmware puede afectar qué funciones están activas y cómo se reportan los eventos
- Revisiones de hardware o paquetes de accesorios opcionales pueden cambiar la disponibilidad de inmovilizador, bocina o interfaces de sensor de combustible
- La correcta instalación y cableado son necesarios para que las interfaces de control vehicular y sensores funcionen adecuadamente
- Variantes regionales o requisitos regulatorios pueden modificar las configuraciones o certificaciones soportadas
- Confirme siempre las listas de funciones actuales, diagramas de cableado y el comportamiento del firmware en la documentación del fabricante

## Por qué usar Plaspy con estas funciones

Usar el Aquila TS101 Advanced con Plaspy ofrece a las organizaciones una plataforma única para agregar ubicación en vivo, registros históricos y datos de eventos desde dispositivos desplegados en entornos operativos diversos. Plaspy convierte las capacidades del hardware TS101 Advanced en información operativa útil al presentar ubicación, movimiento, combustible y datos de control en mapas, líneas de tiempo y vistas de dispositivo.
