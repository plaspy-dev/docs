# iTriangle - TS101 BASIC

![TS101 BASIC](./tracker.png)

El TS101 BASIC es un rastreador GPS compacto y resistente pensado para el monitoreo esencial de flotas y la seguridad vehicular. Ofrece posicionamiento GNSS multinave (multi constelación) para mejorar la disponibilidad de la ubicación y dispone de entradas/salidas prácticas para capturar el estado de encendido y otras señales de eventos. Diseñado para continuidad operativa, incorpora almacenamiento interno para miles de registros y un amplio rango de entrada de tensión que facilita su instalación en diferentes vehículos.

Como dispositivo compatible con Plaspy, el TS101 BASIC incorpora esos flujos básicos de telemetría y eventos en la plataforma Plaspy para visibilidad en tiempo real, generación de alertas e informes históricos. Su combinación de características de hardware robusto y capacidades de gestión remota lo convierte en una opción directa para operadores que buscan seguimiento confiable y un flujo de datos fluido hacia Plaspy para supervisión operativa.

## Características principales

- Dispositivo compatible con Plaspy para seguimiento y reportes en tiempo real confiables tanto a nivel de flota como por vehículo
- Soporte GNSS multinave para mejorar la disponibilidad de ubicación en entornos variados
- Almacenamiento interno de hasta 6,000 registros de seguimiento para cubrir interrupciones temporales de red
- Amplio rango de entrada de tensión y batería interna de respaldo para preservar la telemetría durante cortes de energía
- Detección de movimiento integrada y alertas por manipulación para apoyar el monitoreo antirrobo y la detección de eventos
- Entradas/salidas prácticas para monitoreo de encendido y control básico con integración a sistemas del vehículo
- Carcasa con grado IP65 y factor de forma compacto para operación fiable en condiciones exigentes de uso vehicular

## Cómo funciona con Plaspy

Al instalarse en un vehículo, el TS101 BASIC registra posiciones, eventos de movimiento, estado de encendido y señales de E/S, y transmite telemetría compacta a Plaspy para su ingestión. Plaspy presenta estos datos en mapas en vivo, reglas de alerta e informes históricos para que los equipos operativos puedan tomar decisiones basadas en ubicaciones y eventos.

- Ubicación y telemetría en tiempo real mostradas en Plaspy para seguimiento en vivo y conciencia situacional
- Eventos de encendido y entradas digitales reportados para activar reglas, alertas de geocerca y seguimiento de eventos de conductores
- El almacenamiento a bordo garantiza que los puntos capturados durante cortes se sincronicen con Plaspy cuando se restablece la conectividad
- Flujos de trabajo OTA FOTA y de configuración remota permiten a los administradores actualizar firmware y ajustes del dispositivo mediante los caminos de gestión soportados
- Soporte de emparejamiento Bluetooth para que Plaspy muestre telemetría extendida cuando se usan sensores compatibles localmente con el rastreador

## Casos de uso típicos

- Gestión de flotas para monitoreo de rutas, apoyo a despachos y análisis de utilización
- Antirrobo y seguridad vehicular con alertas por movimiento y manipulación, además de flujos remotos usando control de salida digital
- Monitoreo de transporte escolar para registro de encendido y eventos que apoyen la seguridad y el cumplimiento
- Visibilidad en logística y reparto que se beneficia del almacenamiento interno durante brechas de cobertura
- Telemetría habilitada por sensores, como monitoreo de combustible o temperatura, al emparejar sensores locales apropiados

## Por qué elegir este rastreador con Plaspy

El TS101 BASIC es una opción práctica para organizaciones que requieren un rastreador resistente y sin complicaciones que se integre en una plataforma moderna de gestión de flotas. Su enfoque en ubicación confiable, captura de eventos y funciones de continuidad como almacenamiento a bordo y respaldo de energía lo hacen adecuado para flotas mixtas y necesidades operativas rutinarias.

Si usted necesita un dispositivo compacto que alimente telemetría y datos de eventos esenciales a Plaspy para seguimiento en vivo, alertas e informes, el TS101 BASIC ofrece una base sólida.
