# TS101 BASIC

El TS101 BASIC es un rastreador GPS compacto y resistente, diseñado para el monitoreo esencial de flotas y la seguridad de los vehículos. Como dispositivo compatible con Plaspy, ofrece seguimiento en tiempo real fiable, posicionamiento GNSS de múltiples constelaciones \(GPS/GLONASS/Galileo/BeiDou\) y las interfaces necesarias para que las flotas recolecten telemetría y datos de eventos de diversos tipos de vehículos.

El equipo está diseñado específicamente para gestión de flotas, seguridad en transporte escolar y aplicaciones logísticas que exigen continuidad y simplicidad. Con entrada de 9–32 V DC amplia, protección IP65, almacenamiento a bordo para hasta 6.000 registros y soporte OTA/FOTA, el TS101 BASIC ayuda a mantener reportes continuos, reducir el tiempo de inactividad y respaldar flujos de antirrobo e inmovilizador cuando se integra con los sistemas del vehículo y las herramientas de la plataforma Plaspy.

## Key Highlights

- Rastreador GPS compatible con Plaspy para un seguimiento y reporte en tiempo real confiables, tanto para flotas como para vehículos individuales.
- GNSS de múltiples constelaciones \(GPS, GLONASS, Galileo, BeiDou\) para mejorar la disponibilidad de la ubicación en entornos desafiantes.
- Integridad de datos robusta con almacenamiento a bordo para hasta 6.000 registros de seguimiento, para cubrir interrupciones de red.
- Entrada amplia de 9–32V y batería de respaldo interna de 500 mAh para telemetría ininterrumpida durante fallos de energía.
- Detección de movimiento y alertas de manipulación integradas mediante un acelerómetro interno para respaldar el monitoreo antirrobo.
- I/O práctico: monitorización de encendido, 1 entrada analógica, 2 entradas digitales, 1 salida digital y depuración RS232 para una integración fluida con el vehículo.
- Carcasa con clasificación IP65 y formato compacto para una instalación sencilla y operación confiable en entornos vehiculares severos.
- Bluetooth Classic \(BLE 3.0\) y comunicación TCP/IP para el emparejamiento de sensores locales y el intercambio de datos en red.

## How It Works with Plaspy

El TS101 BASIC se integra con Plaspy para entregar datos de flotas de forma continua y accionables. Cuando se instala en un vehículo, el dispositivo recopila lecturas GNSS, eventos de aceleración/movimiento, estado de encendido y señales de E/S, y envía paquetes de telemetría compactos mediante 2G TCP/IP. Plaspy procesa esos datos para ubicación en tiempo real, alertas, reproducción histórica e informes.

- Actualizaciones de ubicación y telemetría en tiempo real enviadas a Plaspy para seguimiento en vivo y vistas de enrutamiento.
- Estado de encendido y eventos de entrada digital reportados para activar reglas, alertas de geocerca y seguimiento de eventos del conductor.
- Almacenamiento a bordo de hasta 6.000 registros que garantiza no perder datos durante interrupciones temporales de la red; los puntos almacenados se sincronizan con Plaspy cuando la conectividad retorna.
- Actualizaciones OTA/FOTA y configuración remota permiten a los administradores actualizar firmware y ajustes a través de flujos de trabajo compatibles con Plaspy \(donde la provisión lo permita\).
- Soporte Bluetooth para sensores locales o balizas permite a Plaspy mostrar telemetría extendida \(p. ej., temperatura o proximidad\) cuando se empareja con sensores Bluetooth compatibles.

## Use Cases

- Gestión de flotas: seguimiento en vivo de vehículos, reproducción de rutas e ingestión de telemetría para control de costos y eficiencia de despacho.
- Antirrobo y seguridad del vehículo: detección de movimiento, alertas de manipulación y flujos de trabajo remotos \(control de inmovilizador vía salida digital\) para reducir el riesgo de robo.
- Seguridad en transporte escolar: monitorización de encendido y eventos para garantizar el cumplimiento del transporte de estudiantes y la generación de incidentes.
- Logística y visibilidad de activos: continuidad de rastreo mediante almacenamiento a bordo durante brechas de cobertura, mejorando la verificación de entregas y la cadena de custodia.
- Telemetría habilitada por sensores: emparejar sensores Bluetooth o usar la entrada analógica para monitoreo de combustible, detección de temperatura u otra telemetría personalizada cuando se requiera.

## Why Choose This Tracker with Plaspy

El TS101 BASIC es una opción práctica para organizaciones que buscan un rastreador GPS compatible con Plaspy que equilibre costo, resiliencia y funcionalidad. Su GNSS de múltiples constelaciones y su acelerómetro interno proporcionan datos de posición y movimiento confiables; el amplio rango de tensión y la carcasa IP65 respaldan flotas de vehículos diversas. El almacenamiento a bordo y la batería interna de respaldo preservan la telemetría durante interrupciones de red o energía, mientras que OTA/FOTA y las interfaces estándar simplifican la gestión remota e integración. Para operadores centrados en el seguimiento en tiempo real, gestión de flotas, protección antirrobo y recopilación de telemetría directa \(incluyendo monitoreo de combustible o control de inmovilizador a través de las I/O disponibles\), el TS101 BASIC ofrece una base confiable cuando se empareja con la plataforma Plaspy.
