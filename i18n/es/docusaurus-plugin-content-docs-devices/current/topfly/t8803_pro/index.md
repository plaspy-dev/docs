# TopFly - T8803 PRO

![T8803 PRO](./logo.jpg)

El rastreador GPS TopFly T8803 PRO es una herramienta útil para el seguimiento de vehículos, con una amplia gama de características. Este modelo PRO es una versión mejorada del T8803A, con más alarmas de sensores, una entrada adicional, un G-sensor, un cable SOS y un micrófono integrado. También cuenta con un modo de suspensión inteligente y un nuevo protocolo que optimiza el consumo de GPRS. Además, tiene la certificación IP66, lo que lo hace resistente al agua.

El paquete incluye el rastreador GPS, una línea de entrada digital de extensión, cinta adhesiva de doble cara y una línea de extensión de alimentación. También se ofrecen como opciones adicionales un bloque del motor relé, un micrófono y una línea SOS. El T8803 PRO está integrado con GPS y no es compatible con GLONASS ni otros sistemas alternativos. En caso de falta de señal de satélite, utiliza la identificación móvil \(LBS-tracking\) como respaldo.

Este modelo ofrece diferentes modos de seguimiento, como el seguimiento de tiempo/intervalo, pistas de variación de dirección y pistas de intervalo de distancia. También permite recibir informes de SMS en intervalos de tiempo. El módulo GSM 2G del T8803 PRO es cuatribanda y puede operar en todo el mundo. La fuente de alimentación externa puede ser de 6-36V, lo que permite su instalación en coches y furgonetas. Además, cuenta con una batería de reserva recargable incorporada que proporciona aproximadamente 3-4 horas de funcionamiento en condiciones normales.

El rastreador T8803 PRO se puede controlar completamente a través de GPRS y también ofrece una amplia lista de comandos SMS de fácil uso. Es compatible con la configuración remota del APN a través de SMS. El dispositivo cuenta con dos LED, uno rojo que indica el modo GSM/GPRS y uno azul que indica la recepción de GPS. Los LED se apagan automáticamente después de cinco minutos de encender el dispositivo.
