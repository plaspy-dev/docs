# TopFly - Pioneer X100

![Pioneer X100](./Logo.png)

El **PioneerX 100 \(4G CAT-1\)** es un rastreador GNSS alámbrico diseñado para aplicaciones versátiles en la gestión de flotas y seguridad vehicular. Este dispositivo compacto y robusto soporta bandas globales de LTE Cat-1 con retrocompatibilidad 2G, lo que asegura conectividad confiable incluso en áreas con cobertura limitada. Su diseño incluye múltiples entradas y salidas digitales, lo que lo hace ideal para monitorear condiciones como encendido del motor, activación de relés y accesorios como botones SOS. Además, su compatibilidad con sensores Bluetooth \(BLE 4.2\) permite la integración con accesorios para el monitoreo de temperatura, humedad, y estado de puertas.

Equipado con capacidades de detección de comportamiento del conductor y alertas de conducción agresiva, este rastreador no solo mejora la seguridad, sino que también ofrece funciones avanzadas como detección de accidentes y análisis de datos para reconstrucción de incidentes. Su firmware se puede actualizar de manera remota \(FOTA\), garantizando que las funcionalidades del dispositivo se mantengan actualizadas sin necesidad de intervención física. Es ideal para flotas comerciales, vehículos personales y cualquier objeto con fuente de alimentación constante.

### Características Destacadas

- **Conectividad Global:** Compatible con bandas LTE Cat-1 y retrocompatibilidad 2G para un uso confiable en cualquier lugar.
- **Monitoreo en Tiempo Real:** Reportes programados basados en tiempo, ángulo o distancia.
- **Integración con Sensores BLE:** Monitoreo de temperatura, humedad y estado de puertas mediante accesorios adicionales.
- **Alertas y Notificaciones:** Incluye notificaciones sobre eventos como encendido/apagado del motor, desconexión de energía y más.
- **Diseño Compacto y Versátil:** Perfecto para instalaciones ocultas en vehículos de diversos tipos.

Este rastreador combina funcionalidad avanzada con un diseño práctico y una implementación simple, asegurando un monitoreo eficiente y seguro para cualquier aplicación vehicular.
