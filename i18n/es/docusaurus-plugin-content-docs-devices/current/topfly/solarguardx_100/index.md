# TopFly - SolarGuardX 100

![SolarGuardX 100](./tracker.png)

SolarGuardX 100 de SolarGuardX es un rastreador GPS de carga robusto alimentado por energía solar y un candado diseñado para la protección de activos al aire libre y despliegues compatibles con Plaspy. Construido para contenedores, remolques y camiones, el SolarGuardX 100 combina batería de alta capacidad y carga solar integrada con un sellado impermeable de grado industrial y múltiples interfaces inalámbricas para ofrecer una monitorización de seguridad persistente y de bajo mantenimiento que alimenta directamente a Plaspy para flujos de trabajo de ubicación en tiempo real, alarmas y telemetría.

Diseñado para la gestión de flotas y casos de uso antirrobo, el SolarGuardX 100 combina una sólida protección física \(carcasa IP67, carcasa gruesa, imán integrado y cuerda suministrada\) con conectividad avanzada \(LTE Cat M1 / NB2 con respaldo GSM\), soporte para accesorios BLE, rendimiento GNSS robusto y amplia capacidad de almacenamiento para cubrir las lagunas de cobertura. Cuando se integra con Plaspy, ofrece un rastreo en tiempo real fiable, geocercas configurables y opciones de transporte seguras para una visibilidad de la carga a gran escala y operaciones de seguridad.

## Aspectos clave

- Rastreador GPS y candado compatibles con Plaspy — soporte nativo para rastreo en tiempo real, alarmas y telemetría.
- Alimentación asistida por energía solar con una batería Li‑Polymer de 14,400 mAh para una mayor autonomía en campo y carga USB Type‑C.
- Carcasa IP67 industrial con imán integrado robusto y cuerda de 350 mm suministrada para montaje robusto en contenedores y remolques.
- GNSS de alta precisión \(conjunto de chips MediaTek de alto rendimiento\) con operación paralela GPS+GLONASS o GPS+BeiDou y precisión horizontal CEP \< 2.5 m.
- Amplio soporte celular: LTE FDD Cat M1 y NB2 para conectividad IoT, con respaldo GSM/EDGE para redes legadas.
- Soporte BLE 5.x para sensores de temperatura/humedad, sensores de puerta y relés inalámbricos; se empareja con accesorios TOPFLYtech y sensores BLE de terceros.
- Seguridad avanzada y almacenamiento local — hasta 49,000 puntos almacenados localmente y soporte de geocerca \(64 regiones\), y alarmas configurables de corte de cuerda / bloqueo / desbloqueo.

## Cómo funciona con Plaspy

SolarGuardX 100 transmite datos de posición, eventos y sensores a Plaspy utilizando transportes IoT estándar. Una vez registrado en Plaspy, los dispositivos envían actualizaciones de ubicación frecuentes, eventos de alarma y telemetría auxiliar para que los coordinadores y equipos de seguridad puedan monitorizar la carga en tiempo casi real y actuar ante las alertas.

- Actualizaciones de ubicación y telemetría en tiempo real — configurables hasta cada 3 segundos para necesidades de seguimiento de alta frecuencia.
- Eventos de geocerca, movimiento, estacionamiento y alarmas de seguridad \(corte de cuerda, bloqueo/desbloqueo\) enviados a Plaspy para alertas y flujos de trabajo automatizados.
- Subida de datos en búfer — hasta 49,000 puntos almacenados localmente y transmitidos cuando se restablece la cobertura, evitando la pérdida de datos.
- Datos de accesorios BLE — temperatura, humedad y estado de la puerta de sensores BLE de TOPFLYtech y de terceros pueden enviarse a Plaspy como telemetría.
- Transportes seguros — compatibles TCP/UDP/MQTT y SMS; las opciones de seguridad de datos incluyen MD5 y AES256 para cargas útiles cifradas.

## Casos de uso

- Seguridad de contenedores y remolques — monitorización anti‑robo persistente con alarmas de corte de cuerda y bloqueo/desbloqueo reportadas a Plaspy.
- Rastreo de activos de la flota — flujo de ubicación en tiempo real para remolques y activos portátiles para mejorar la planificación de rutas y la visibilidad en la gestión de flotas.
- Carga sensible a la temperatura — emparejar sensores BLE de temperatura/humedad y enviar telemetría a Plaspy para la trazabilidad de la cadena de frío.
- Acceso y control remoto — RFID, BLE y comandos de red remotos permiten flujos de desbloqueo y control flexibles para operaciones de última milla.
- Resiliencia de datos fuera de red — gran almacenamiento local garantiza que las rutas históricas se conserven y se carguen cuando vuelve la conectividad.

## Por qué elegir este rastreador con Plaspy

SolarGuardX 100 está diseñado específicamente para la seguridad de activos al aire libre de larga duración y se integra sin problemas con Plaspy para ofrecer información accionable en tiempo real. Su combinación de capacidad de batería con energía solar, protección IP industrial, GNSS de alta precisión y conectividad LTE Cat M1/NB2 lo convierte en una opción de bajo mantenimiento para despliegues en contenedores y remolques. El soporte para sensores BLE y múltiples modos de desbloqueo/control \(RFID, BLE, OTA, SMS, comandos remotos\) amplía su valor para telemetría y flujos de trabajo operativos.

Para operadores que usan Plaspy, SolarGuardX 100 reduce las comprobaciones manuales y los vacíos de datos al proporcionar actualizaciones frecuentes \(tan rápidas como cada 3 segundos\), almacenamiento local resistente y transportes estandarizados \(MQTT/TCP/UDP/SMS\) con opciones de cifrado. Ya sea que necesites alarmas antirrobo, alertas disparadas por geocerca o telemetría enriquecida por sensores, SolarGuardX 100 es una solución fiable y compatible con Plaspy para una gestión de flotas al aire libre exigente y necesidades de seguridad de la carga.
