# AoYa - Funciones del T2D

Esta página ofrece una descripción pública y orientada a las funciones del rastreador GPS AoYa T2D y explica cómo sus capacidades se integran con Plaspy para el seguimiento y monitoreo de vehículos. Resume las funciones prácticas que usted encontrará al usar el T2D con Plaspy, manteniendo el nivel técnico adecuado para una audiencia general.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware del dispositivo, la revisión de hardware, el método de instalación y la implementación del fabricante. Utilice esta página como guía sobre las capacidades comunes y consulte al fabricante para obtener detalles técnicos específicos y actualizados del dispositivo.

## Resumen de funciones

El AoYa T2D es un rastreador GPS automotriz compacto, pensado para una instalación sencilla y un reporte de ubicación confiable. Sus principales fortalezas son la precisión de ubicación mediante múltiples métodos de posicionamiento, la amplia compatibilidad con voltajes de vehículos y un tamaño reducido que facilita instalaciones ocultas o en espacios limitados.

- Factor de forma compacto y ligero para una instalación flexible en autos, camiones o motocicletas
- Localización multimodal usando GPS, AGPS y LBS para mejorar la disponibilidad de la posición
- Conectividad celular 2G GSM/GPRS para el envío periódico de ubicaciones
- Amplio rango de voltaje operativo compatible con muchos sistemas eléctricos de vehículos
- Batería de emergencia incorporada para conservar el rastreo durante interrupciones de energía
- Precisión de posicionamiento adecuada para monitoreo rutinario de vehículos y supervisión de flotas

## Características principales del AoYa - T2D

- Dimensiones compactas y bajo peso pensados para un montaje discreto en vehículos
- Métodos híbridos de localización GPS, AGPS y LBS para mejorar las tasas de fijación de posición
- Conectividad 2G GSM/GPRS para enviar actualizaciones de ubicación y estado
- Soporte para un amplio rango de voltaje, desde valores bajos hasta altos, que permite compatibilidad con diversos vehículos
- Batería de emergencia de 180 mAh para mantener operaciones básicas si se pierde la alimentación externa
- Sensibilidad GPS publicada y precisión posicional típica que cubren necesidades de seguimiento rutinario
- Componentes RF y GNSS integrados que el fabricante indica como soporte al rendimiento del dispositivo

## Cómo funcionan estas funciones con Plaspy

Plaspy muestra y almacena las ubicaciones y eventos reportados por el dispositivo para que usted pueda monitorear sus vehículos de forma centralizada. El posicionamiento multimodal y la resiliencia ante cortes de energía del T2D se traducen en una visibilidad más consistente dentro de la plataforma Plaspy.

- Puntos de ubicación en tiempo real e históricos aparecen sobre el mapa de Plaspy cuando el dispositivo reporta datos de posición
- Los modos asistidos AGPS y LBS contribuyen a mantener actualizaciones cuando la señal GPS se retrasa o no está disponible
- El soporte de batería de emergencia ayuda a que los dispositivos sigan enviando información a Plaspy durante cortos cortes de energía
- La conectividad 2G GPRS proporciona el transporte para que el T2D envíe actualizaciones al servicio Plaspy
- Plaspy detecta automáticamente muchos protocolos de rastreadores y acepta conexiones de dispositivos compatibles para facilitar la configuración

## Casos de uso típicos

- Monitoreo de ubicación de vehículos para flotas comerciales ligeras y vehículos de servicio
- Seguridad y recuperación de vehículos cuando se requiere reporte de ubicación persistente
- Despliegues mixtos de vehículos que necesitan un amplio rango de voltaje de entrada para sistemas eléctricos diversos
- Instalaciones temporales o discretas que se benefician de una huella física reducida
- Conciencia básica de rutas y movimientos para supervisión operativa

## Notas sobre disponibilidad de funciones

- La disponibilidad real de cada función depende del firmware del dispositivo y de la revisión de hardware específica enviada por el fabricante
- La disponibilidad del servicio celular 2G varía según la región y el operador; verifique el soporte de la red local antes del despliegue
- Las decisiones de instalación y la colocación de la antena pueden afectar el rendimiento GPS y la precisión reportada
- Algunas funciones o comportamientos pueden ser configurables por el instalador o requerir ajustes del fabricante
- Verifique los límites técnicos detallados e instrucciones de cableado en la documentación oficial del fabricante

## Por qué usar Plaspy con estas funciones

Usar el AoYa T2D con Plaspy ofrece a las organizaciones una vía sencilla para centralizar los datos de ubicación de vehículos y obtener visibilidad operativa. Plaspy consolida los reportes de posición, los muestra en un mapa y facilita el monitoreo del movimiento, tiempo de actividad y presencia en una flota diversa.

Plaspy está diseñado para aceptar reportes comunes de rastreadores y proporcionar una única interfaz para monitorear dispositivos como el T2D. Para notas de configuración más detalladas y el comportamiento específico más reciente del dispositivo, conozca más sobre Plaspy en https://www.plaspy.com. Las funciones del dispositivo, el comportamiento del firmware y los detalles del fabricante pueden cambiar con el tiempo, por lo que le recomendamos verificar las especificaciones y la guía de instalación actuales con el fabricante en http://www.aoyagps.com/
