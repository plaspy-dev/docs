# AoYa - T2D

![T2D](./logo.jpg)

El rastreador GPS AoYa T2D es una excelente opción para la gestión de flotas en el sector automotriz. Con un tamaño compacto de 82x39x15mm y un peso de solo 54g, este dispositivo se puede instalar fácilmente en cualquier vehículo sin ocupar mucho espacio.

El AoYa T2D ofrece una función de seguimiento precisa a través de GPS, LBS y AGPS. Con un chip GPS UBLOX y una sensibilidad GPS de -169dBm, este rastreador proporciona una precisión de 5-10 metros, lo que garantiza una ubicación precisa en todo momento. Además, cuenta con una batería de emergencia de 180 mAh para asegurar un funcionamiento continuo incluso en caso de corte de energía.

Este rastreador GPS funciona en la red 2G GSM/GPRS y es compatible con voltajes de 9V a 100V, lo que lo hace adecuado para una amplia gama de vehículos. Con una garantía de 1 año, puedes confiar en la calidad y durabilidad de este dispositivo.

En resumen, el rastreador GPS AoYa T2D es una solución confiable y rentable para la gestión de flotas en el sector automotriz. Su precisión de seguimiento, tamaño compacto y compatibilidad con una amplia gama de vehículos lo convierten en una opción ideal para empresas que desean mejorar la eficiencia y seguridad de su flota.

### Características destacadas:

- Tamaño compacto de 82x39x15mm
- Peso ligero de 54g
- Función de seguimiento GPS/LBS/AGPS
- Chip GPS UBLOX con sensibilidad de -169dBm
- Precisión GPS de 5-10 metros
- Batería de emergencia de 180 mAh
- Compatible con voltajes de 9V a 100V
- Garantía de 1 año
