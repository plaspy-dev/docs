# AoYa - T8GPS

![T8GPS](./logo.jpg)

El rastreador GPS AoYa T8GPS es una excelente opción para aquellos que buscan un dispositivo confiable y de alta calidad para rastrear vehículos automotrices. Con un diseño compacto y resistente al agua con certificación IP67, este rastreador GPS es capaz de soportar condiciones adversas y garantizar un rendimiento óptimo en todo momento.

El AoYa T8GPS ofrece una variedad de funciones de seguimiento, incluyendo GPS, LBS y AGPS, lo que permite una precisión de ubicación confiable y precisa. Con su chip GPS UBLOX y una sensibilidad GPS de -169dBm, este rastreador proporciona una precisión de 5-10 metros, lo que lo convierte en una herramienta ideal para el seguimiento de vehículos de carga, flotas de transporte y más.

Este rastreador GPS es compatible con redes GSM/GPRS y cuenta con un voltaje de funcionamiento de 9V-100V, lo que lo hace adecuado para una amplia gama de vehículos. Además, cuenta con una batería de emergencia de 42 mAh, lo que garantiza un seguimiento continuo incluso en caso de pérdida de energía.

Con su tamaño compacto de 68.2 \* 46.2 \* 21.6 mm y un peso de solo 52 g, el AoYa T8GPS es fácil de instalar y transportar. Su garantía de 1 año respalda la calidad y confiabilidad de este rastreador GPS.
