# AoYa - T2

![T2](./logo.jpg)

El rastreador GPS AoYa T2 es un dispositivo de seguimiento en línea diseñado específicamente para vehículos. Con un tamaño compacto de 72 \* 32 \* 15 mm y un peso de solo 56 g, este rastreador es fácil de instalar y ocultar en cualquier vehículo.

El AoYa T2 utiliza la red GSM / GPRS para transmitir datos de ubicación en tiempo real. Cuenta con un chip GSM SIMTK6260 y un chip GPS UBLOX, lo que garantiza una conexión estable y una precisión confiable en la ubicación. La sensibilidad GPS del T2 es de -169dBm, lo que permite una excelente recepción de señal incluso en áreas con mala cobertura.

Con una precisión de GPS de 5-10 metros, el rastreador AoYa T2 proporciona información de ubicación precisa y confiable. Además, cuenta con una batería de emergencia de 42 mAh, lo que garantiza que el dispositivo siga funcionando incluso en caso de corte de energía.

El AoYa T2 es ideal para aquellos que desean mantener un seguimiento constante de la ubicación de sus vehículos. Ya sea para uso personal o comercial, este rastreador GPS ofrece una solución confiable y fácil de usar para el monitoreo de vehículos.

### Características destacadas:

- Tamaño compacto de 72 \* 32 \* 15 mm
- Peso ligero de 56 g
- Red GSM / GPRS para transmisión de datos
- Chip GSM SIMTK6260 y chip GPS UBLOX para una conexión estable
- Sensibilidad GPS de -169dBm para una excelente recepción de señal
- Precisión GPS de 5-10 metros para una ubicación precisa
- Batería de emergencia de 42 mAh para un funcionamiento continuo
