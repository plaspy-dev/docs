# AoYa - A14

![A14](./logo.jpg)

El rastreador GPS AoYa A14 es un dispositivo de seguimiento diseñado específicamente para uso automotriz. Con un tamaño compacto de 88 mm x 46 mm x 16 mm y un peso de 80 g, este rastreador es fácil de instalar y ocultar en cualquier vehículo.

El AoYa A14 utiliza tecnología GPS, LBS y AGPS para proporcionar un seguimiento preciso de la ubicación en tiempo real. Con una sensibilidad GPS de -159dBm y una precisión de 5-10 metros, este rastreador garantiza una ubicación precisa y confiable en todo momento.

Este rastreador GPS es compatible con redes GPS, AGPS, GSM y GPRS, lo que permite una conectividad estable y confiable en cualquier lugar. Utiliza el chip GSM SIMTK6260 y el chip GPS UBLOX para un rendimiento óptimo.

El AoYa A14 también cuenta con una batería de emergencia de iones de litio de 3.7V y 250mAh, lo que garantiza un funcionamiento continuo incluso en caso de pérdida de energía. Además, este rastreador viene con una garantía de 1 año, lo que brinda tranquilidad y confianza al usuario.

En resumen, el rastreador GPS AoYa A14 es una opción confiable y eficiente para el seguimiento de vehículos. Con su tamaño compacto, tecnología avanzada y características de seguridad, este rastreador es una herramienta invaluable para cualquier propietario de automóvil.

### Características destacadas:

- Tamaño compacto y fácil instalación
- Tecnología GPS, LBS y AGPS para un seguimiento preciso
- Compatibilidad con redes GPS, AGPS, GSM y GPRS
- Chip GSM SIMTK6260 y chip GPS UBLOX para un rendimiento óptimo
- Batería de emergencia de iones de litio de 3.7V y 250mAh
- Garantía de 1 año
