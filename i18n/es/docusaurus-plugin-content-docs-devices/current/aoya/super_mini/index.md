# AoYa - super mini

![super mini](./logo.jpg)

El rastreador GPS AoYa Super Mini es una excelente opción para aquellos que buscan una solución de seguimiento confiable y compacta. Con su tamaño súper mini, este rastreador es fácil de ocultar y puede adaptarse a una variedad de aplicaciones.

Este rastreador GPS utiliza tecnología GPS, LBS y WIFI para proporcionar una precisión de seguimiento de 5-15 metros. Esto significa que podrás rastrear la ubicación de tu vehículo en tiempo real con una gran precisión. Además, este rastreador también cuenta con un sensor de luz incorporado, lo que lo hace ideal para aplicaciones de seguimiento en interiores.

El rastreador AoYa Super Mini ofrece una amplia gama de funciones para satisfacer tus necesidades de seguimiento. Algunas de las características destacadas incluyen seguimiento en tiempo real, alarma de luz, alarma de corte de energía, alarma de exceso de velocidad, alarma de vibración, corte de aceite / motor, geo-cerca y reproducción de ruta histórica.

Este rastreador es especialmente adecuado para pequeñas empresas de alquiler de flotas que desean mantener un control preciso sobre sus vehículos. Con su rango de voltaje de trabajo de 9-100V, este rastreador es compatible con una amplia gama de vehículos.
