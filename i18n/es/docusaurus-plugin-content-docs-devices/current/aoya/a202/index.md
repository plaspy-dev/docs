# AoYa - A202

![A202](./logo.jpg)

El rastreador GPS AoYa A202 es un dispositivo de seguimiento diseñado específicamente para su uso en vehículos. Con un tamaño compacto de 130 mm x 72 mm x 20 mm y un peso de 240 g, este rastreador es fácil de instalar y transportar. Su diseño resistente y duradero lo hace adecuado para su uso en condiciones adversas.

Este rastreador GPS utiliza la red GSM/GPRS para transmitir datos de ubicación en tiempo real. Equipado con un chip GSM SIMTK6260 y un chip de GPS UBLOX, ofrece una sensibilidad GPS de -159dBm y una precisión de 5 metros. Esto garantiza una ubicación precisa y confiable en todo momento.

La batería de iones de litio de 3.7V y 10000mAh proporciona una larga duración de la batería, lo que permite un seguimiento continuo durante períodos prolongados. Además, este rastreador GPS es resistente al agua y al polvo, lo que lo hace adecuado para su uso en diversas condiciones climáticas y entornos.

El rastreador GPS AoYa A202 es una opción ideal para aquellos que desean mantener un seguimiento preciso de sus vehículos. Ya sea para uso personal o comercial, este dispositivo ofrece una solución confiable y eficiente para el seguimiento de vehículos.

### Características destacadas:

- Tamaño compacto y peso ligero
- Red GSM/GPRS para transmisión de datos
- Chip GSM SIMTK6260 y chip de GPS UBLOX
- Sensibilidad GPS de -159dBm y precisión de 5 metros
- Batería de iones de litio de larga duración: 3.7V, 10000mAh
- Resistente al agua y al polvo
