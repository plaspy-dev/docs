# AoYa - T6

![T6](./logo.jpg)

El rastreador GPS AoYa T6 es un dispositivo de seguimiento diseñado específicamente para uso automotriz. Con un tamaño compacto de 45.2 mm x 25.1 mm x 32 mm y un peso de solo 28 g, este rastreador es fácil de instalar y ocultar en cualquier vehículo.

El AoYa T6 utiliza tecnología GPS / LBS / AGPS para proporcionar un seguimiento preciso de la ubicación en tiempo real. Con su chip GPS UBLOX y una sensibilidad GPS de -159dBm, este rastreador ofrece una precisión de 5-10 metros, lo que garantiza una ubicación precisa en todo momento.

Este rastreador GPS es compatible con redes GPS / AGPS / GSM / GPRS / CDMA, lo que permite una amplia cobertura y conectividad confiable. Además, cuenta con un chip GSM SIMTK6260 para una comunicación estable y eficiente.

El AoYa T6 también viene con una batería de emergencia de 40 mAh, lo que garantiza que el rastreador siga funcionando incluso en caso de pérdida de energía. Además, este dispositivo cuenta con una garantía de 1 año, lo que brinda tranquilidad y confianza al usuario.

En resumen, el rastreador GPS AoYa T6 es una opción confiable y eficiente para el seguimiento de vehículos. Con su tamaño compacto, precisión de ubicación y amplia conectividad, este dispositivo es ideal para cualquier propietario de automóvil que desee mantener un control total sobre su vehículo.

### Características destacadas:

- Tamaño compacto y peso ligero
- Tecnología GPS / LBS / AGPS para un seguimiento preciso de la ubicación
- Compatibilidad con redes GPS / AGPS / GSM / GPRS / CDMA
- Chip GSM SIMTK6260 para una comunicación estable
- Batería de emergencia de 40 mAh para una mayor duración de la batería
- Garantía de 1 año para mayor tranquilidad
