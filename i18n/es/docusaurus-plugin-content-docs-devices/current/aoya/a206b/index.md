# AoYa - A206b

![A206b](./logo.jpg)

El rastreador GPS AoYa A206b es un dispositivo de seguimiento diseñado específicamente para uso automotriz. Con un tamaño compacto de 96 mm x 42 mm x 24 mm y un peso de 100 g, este rastreador es fácil de instalar y transportar.

El AoYa A206b utiliza tecnología de localización GPS para proporcionar información precisa sobre la ubicación de su vehículo. Con una sensibilidad GPS de -159dBm y una precisión de 5 metros, puede confiar en que obtendrá datos confiables y precisos sobre la ubicación de su vehículo en todo momento.

Este rastreador GPS funciona a través de la red GSM / GPRS y utiliza el chip GSM SIMTK6260 y el chip GPS UBLOX. Con una batería de iones de litio de 3.7V y 5000mAh, el AoYa A206b tiene un tiempo de trabajo de hasta 720 horas, lo que le brinda una duración de batería prolongada y confiable.

El AoYa A206b es un rastreador magnético inalámbrico para vehículos, lo que significa que se puede colocar fácilmente en cualquier parte del vehículo sin necesidad de instalación complicada. Esto lo hace ideal para el seguimiento de flotas, la seguridad de vehículos personales y el monitoreo de activos.

### Características destacadas:

- Tamaño compacto y peso ligero para facilitar la instalación y el transporte.
- Tecnología de localización GPS con una precisión de 5 metros.
- Funciona a través de la red GSM / GPRS.
- Batería de iones de litio de larga duración con hasta 720 horas de tiempo de trabajo.
- Rastreador magnético inalámbrico para una fácil colocación en cualquier parte del vehículo.
