# AoYa - T128GPS - Características

Esta página describe el contexto público de las funciones al usar el rastreador AoYa T128GPS con Plaspy. Se centra en las capacidades prácticas y orientadas al usuario y en cómo se reflejan en una implementación de Plaspy, en lugar de entrar en configuraciones privadas o comportamientos no documentados.

La disponibilidad exacta de funciones y el modo en que se reportan pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la forma en que el fabricante implementa funciones específicas. Para detalles definitivos a nivel de dispositivo, consulte la documentación del fabricante y las notas de la versión de firmware.

## Resumen de funciones

El AoYa T128GPS es un rastreador compacto con montaje magnético pensado para rastreo personal y de activos. Combina una instalación sencilla con capacidades estándar de GPS y GSM para proporcionar información de ubicación y reportes de eventos que pueden integrarse en plataformas de gestión de flotas y activos como Plaspy.

- Carcasa magnética resistente para una instalación rápida y segura en superficies metálicas
- Antenas GPS y GSM integradas para determinación de ubicación y reporte por celular
- Soporte de rastreo en tiempo real para monitorear actualizaciones de posición a medida que el dispositivo las envía
- Compatibilidad con geocercas para vigilar límites virtuales y generar alertas
- Batería recargable para instalaciones portátiles y temporales
- Botón SOS integrado para señalizar emergencias cuando el dispositivo está configurado para reportar ese evento

## Características principales del AoYa - T128GPS

- Diseño magnético para montaje sin herramientas y colocación flexible en activos metálicos
- Factor de forma compacto y ligero, adecuado para ubicaciones discretas
- Antenas GPS y GSM integradas para fijar posiciones y comunicación celular
- Actualizaciones de ubicación en tiempo real cuando el rastreador está transmitiendo
- Funcionalidad de geocerca para definir zonas virtuales y recibir alertas de entrada o salida
- Batería interna recargable para necesidades de rastreo portátil
- Botón SOS incorporado para activar una notificación de emergencia
- Compatibilidad con dispositivos de consumo comunes para acceder a datos de rastreo y alertas

## Cómo funcionan estas funciones con Plaspy

Plaspy actúa como plataforma central para recibir, normalizar y presentar la información de posición y eventos reportados por el T128GPS. Cuando el rastreador envía datos de ubicación o eventos, Plaspy muestra esa información en mapas, registros de eventos y canales de notificación para que los equipos puedan tomar acción.

- Visualización en vivo de la ubicación y historial reciente de posiciones tal como las reporta el dispositivo
- Eventos de geocerca mostrados como alertas o entradas en la línea de tiempo de Plaspy cuando el dispositivo reporta transiciones de zona
- Eventos SOS señalados en los flujos de eventos de Plaspy para que los operadores identifiquen señales de emergencia
- Metadatos del dispositivo, como notas de montaje o identificación del modelo, disponibles para gestión de activos
- Acceso a los datos del rastreador desde equipos de escritorio y dispositivos móviles a través de la interfaz de Plaspy

## Casos de uso típicos

- Monitoreo temporal de vehículos para alquileres, mantenimiento o asignaciones de corta duración
- Rastreo de activos como equipos rodantes, contenedores u otros elementos portátiles con superficies metálicas
- Monitoreo de seguridad personal donde la colocación discreta y la función SOS son relevantes
- Despliegues a corto plazo para recuperación o vigilancia donde el montaje magnético acelera la instalación
- Visibilidad remota de activos de campo que requieren actualizaciones de ubicación periódicas o continuas

## Notas sobre disponibilidad de funciones

- La presencia y el comportamiento de funciones dependen del firmware del rastreador y su versión
- Revisiones de hardware y variantes regionales pueden cambiar el rendimiento de las antenas y la compatibilidad celular
- El método de instalación y la ubicación afectan la recepción GPS y la frecuencia de reporte
- El comportamiento del SOS y las notificaciones dependen de cómo esté configurado el dispositivo y qué datos envíe
- Confirme las capacidades compatibles y los pasos de configuración con la documentación del fabricante

Al usar Plaspy con el AoYa T128GPS, centraliza la información de ubicación y el reporte de eventos para que las organizaciones puedan monitorear activos, recibir notificaciones de geocerca y SOS, y mantener un registro de auditoría de las actualizaciones de posición.
