# AoYa - A206

![A206](./logo.jpg)

El rastreador GPS AoYa A206 es un dispositivo de seguimiento diseñado específicamente para uso automotriz. Con un tamaño compacto de 96 mm x 42 mm x 24 mm y un peso de 100 g, este rastreador es fácil de instalar y ocultar en cualquier vehículo.

El AoYa A206 utiliza tecnología de posicionamiento GPS y AGPS de doble canal para proporcionar una precisión de seguimiento confiable. Con una sensibilidad GPS de -159dBm y una precisión de 5 metros, este rastreador garantiza una ubicación precisa en todo momento.

Este rastreador GPS funciona a través de la red GSM/GPRS, lo que permite una comunicación estable y confiable. Utiliza el chip GSM SIMTK6260 y el chip GPS UBLOX para garantizar un rendimiento óptimo.

El AoYa A206 cuenta con una batería de larga duración de 3.7V y 7800mAh, lo que garantiza un tiempo de funcionamiento prolongado sin necesidad de recargar. Además, este rastreador viene con una garantía de 1 año, lo que brinda tranquilidad y confianza al usuario.

En resumen, el rastreador GPS AoYa A206 es una opción confiable y eficiente para aquellos que buscan un dispositivo de seguimiento para sus vehículos. Con su precisión de posicionamiento, comunicación estable y batería de larga duración, este rastreador proporciona una solución completa para el seguimiento de vehículos.

### Características destacadas:

- Tamaño compacto y peso ligero
- Tecnología de posicionamiento GPS y AGPS de doble canal
- Sensibilidad GPS de -159dBm y precisión de 5 metros
- Funciona a través de la red GSM/GPRS
- Batería de larga duración de 3.7V y 7800mAh
- Garantía de 1 año
