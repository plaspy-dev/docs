# YulongDa - H02

![H02](./logo.jpg)

El rastreador GPS YulongDa H02 es un dispositivo de seguimiento en tiempo real que utiliza el Sistema de Posicionamiento Global \(GPS\) y la red GSM de cuatro bandas para determinar la ubicación exacta de un vehículo, persona u otro activo al que está conectado. Este rastreador registra la posición del activo a intervalos regulares y puede almacenar los datos de ubicación dentro del dispositivo o transmitirlos a una base de datos central o a un ordenador conectado a Internet utilizando la red celular \(GPRS o SMS\) o un módem satelital integrado en el dispositivo.

El rastreador GPS YulongDa H02 ofrece varias funciones de alarma, como exceso de velocidad, vibración, geo-valla y alarma de cambio ilegal, que se pueden recibir en tiempo real a través de mensajes de texto \(SMS\). Además, cuenta con una batería incorporada que proporciona horas extras de espera y emite una alarma en caso de corte de electricidad o baja energía.

Este rastreador también ofrece una función de recuperación automática de firmware y se puede instalar fácilmente a través de la interfaz OBDII \(opcional\). Además, cuenta con una amplia gama de configuraciones y ajustes, como la configuración APN, configuración IP, ajuste de la hora, ajuste de la geo-cerca, ajuste del número IMEI, entre otros.

En resumen, el rastreador GPS YulongDa H02 es una solución confiable y versátil para el seguimiento y localización en tiempo real, con funciones de alarma y configuraciones personalizables que lo hacen adecuado para una variedad de aplicaciones.

### Características destacadas:

- Seguimiento y localización en tiempo real
- Historial de reproducción de la pista
- Funciones de alarma: exceso de velocidad, vibración, geo-valla y cambio ilegal
- Batería incorporada para horas extras de espera y alarma de corte de electricidad o baja energía
- Recuperación automática de firmware
- Interfaz OBDII para una instalación sencilla \(opcional\)
- Configuraciones y ajustes personalizables
