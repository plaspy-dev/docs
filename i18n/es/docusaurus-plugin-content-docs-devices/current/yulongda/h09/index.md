# YulongDa - H09

![H09](./logo.jpg)

El rastreador GPS YulongDa H09 es una unidad de seguimiento GPS que utiliza el Sistema de Posicionamiento Global para determinar la ubicación exacta de un vehículo, persona u otro activo al que está conectado. Este dispositivo registra la posición del activo a intervalos regulares y puede almacenar los datos de ubicación dentro de la unidad o transmitirlos a una base de datos de localización central o a un ordenador conectado a Internet utilizando la tecnología celular \(GPRS o SMS\) o un módem por satélite integrado en la unidad. Esto permite mostrar la ubicación del activo en un mapa en tiempo real o analizar la ruta posteriormente utilizando la plataforma de seguimiento GPS.

El rastreador GPS YulongDa H09 cuenta con una serie de características destacadas, entre las que se incluyen:

- Frecuencia GSM de cuatro bandas para uso mundial.
- Tecnología de posicionamiento A-GPS para una mayor precisión.
- Amplio rango de voltaje de entrada de DC 0-58V.
- Sensor de vibración incorporado para detección de robos.
- Detección de encendido ACC para notificación del estado del vehículo.
- Botón SOS externo para casos de emergencia.
- Micrófono externo para control de voz.
- Batería de respaldo incorporada para soporte de alarma de corte ilegal de la alimentación principal.
- Relé externo para corte remoto de la potencia del motor o el aceite.
- Altavoz externo para llamadas telefónicas o alarmas.
- Ajustes de velocidad múltiples para alarmas de exceso de velocidad inteligentes.
- Configuraciones de geo-cerca múltiples para alarmas de geo-cerca inteligentes.
- Compatibilidad con la aplicación iOS y Android, así como seguimiento en línea a través de WeChat.
- Plataforma de monitoreo en vivo para gestionar de forma remota.
