YulongDa fabrica hardware de rastreo GPS orientado al seguimiento de vehículos y activos. Si está evaluando equipos o administra una flota mixta, esta página le explica cómo los dispositivos YulongDa pueden integrarse con Plaspy y dónde encontrar modelos compatibles y documentación del fabricante. ## Cómo funcionan los dispositivos YulongDa con Plaspy

Plaspy se conecta a dispositivos YulongDa compatibles usando protocolos estándar de rastreo GPS y métodos habituales de reporte por datos celulares. Una vez que un dispositivo está configurado para reportar a Plaspy, la plataforma recibe actualizaciones de ubicación y estado para que usted pueda ver posiciones en tiempo real, recorridos históricos y telemetría en el panel de Plaspy.

Esta página de marca tiene como objetivo ayudarle a confirmar compatibilidad y a localizar las páginas de modelo y guías de configuración dentro de Plaspy. La configuración específica del dispositivo y los ajustes de APN se documentan en la página de cada modelo, no aquí.
