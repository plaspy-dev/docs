# Telic - SBC3 CAN

![SBC3 CAN](./logo.jpg)

El rastreador Telic SBC3 CAN es una unidad robusta diseñada para aplicaciones telemáticas sofisticadas. Este dispositivo versátil ha sido desarrollado para brindar acceso a una variedad de interfaces de vehículos, incluyendo interfaces en serie \(RS232\), 1-Wire y bus CAN. Su carcasa resistente lo hace adecuado para su uso en ambientes hostiles.

El Telic SBC3 CAN está disponible en dos versiones: una con antenas internas y otra con antenas externas. Además, la versión con antena integrada también se ofrece como una variante con una batería de 4 Ah, lo que proporciona una mayor duración de la batería.

Características destacadas:

- Acceso a interfaces de vehículos como RS232, 1-Wire y bus CAN
- Carcasa robusta para uso en ambientes hostiles
- Opción de antenas internas o externas
- Versión con antena integrada y batería de 4 Ah disponible
