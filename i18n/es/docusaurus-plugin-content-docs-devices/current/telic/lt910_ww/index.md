# Telic - LT910-WW

![LT910-WW](./tracker.jpg)

El LT910-WW es un terminal IoT industrial compacto pensado para despliegues celulares a nivel global. Construido sobre el módulo Telit LE910C1-WWX, ofrece conectividad LTE como enlace principal con conmutación automática a 3G y 2G, un amplio rango de temperatura de operación, capacidad de entrada de tensión extensa e interfaces industriales para conectar unidades GNSS externas o equipos de telemetría. Su soporte SIM con cierre y la carcasa robusta lo hacen ideal para instalaciones en vehículos, gabinetes y activos de campo donde se requiere transporte celular confiable.

Como dispositivo compatible con Plaspy, el LT910-WW actúa como una pasarela de comunicaciones fiable para flujos de trabajo de gestión de flotas y telemetría remota. Combinado con receptores GNSS externos, sensores o interfaces de control vehicular mediante las conexiones serie y USB disponibles, el terminal puede reenviar datos de ubicación y estado a Plaspy para obtener visibilidad en tiempo real, alertas e informes históricos. Esta combinación convierte al LT910-WW en una opción práctica para organizaciones que necesitan conectividad modular y endurecida para campo, junto con las herramientas analíticas y operativas de Plaspy.

## Aspectos clave

- Conectividad LTE primaria con conmutación automática a 3G y 2G para reporte persistente en la nube.
- Basado en el módulo de banda ancha Telit LE910C1-WWX para amplia cobertura celular global.
- Interfaces industriales, incluyendo RS232 y USB, para integrar unidades GNSS y dispositivos de telemetría externos.
- Amplio rango de alimentación y temperatura de operación robusta para entornos exigentes en vehículos y campo.
- Soporte SIM bloqueable y conector de antena externa para uso seguro y fiable en campo.
- Modo de bajo consumo y carcasa industrial compacta adecuada para despliegues portátiles o con espacio limitado.

## Cómo funciona con Plaspy

El LT910-WW transmite telemetría y datos de estado a través de enlaces celulares hacia Plaspy, donde dichos datos se procesan en paneles, reportes, geocercas y reglas de alerta. Plaspy ingiere flujos posicionales y de telemetría enviados por el terminal para que operadores de flota y técnicos puedan monitorear activos casi en tiempo real y ejecutar reportes operativos sobre datos históricos.

- Actualizaciones de ubicación y movimiento en tiempo real cuando el terminal se empareja con un receptor GNSS externo o una fuente NMEA.
- Reenvío de estado y eventos como encendido, puertas o alarmas cuando esas señales se suministran a las interfaces del terminal.
- Disparadores de alertas y geocercas en Plaspy basados en ubicación, tiempo o umbrales de telemetría informados por el dispositivo.
- Informes históricos, análisis de rutas y monitoreo de disponibilidad a partir de la telemetría almacenada por Plaspy.
- Flujos de acción remota, como comandos de inmovilizador o controles a distancia, cuando Plaspy activa salidas a través de interfaces conectadas al vehículo.

## Casos de uso típicos

- Conectividad y monitoreo de flotas a nivel internacional donde se requiere compatibilidad multibanda celular.
- Telemetría remota de activos de campo y generadores usando sensores externos y receptores GNSS.
- Flujos de trabajo antirrobo e inmovilización vehicular combinando interfaces de control externas y acciones de Plaspy.
- Monitoreo de sitios temporales o portátiles donde la tolerancia a voltajes de entrada amplios y modos de bajo consumo son beneficiosos.
- Supervisión de maquinaria industrial para visibilidad centralizada de estados y alertas a través de Plaspy.
