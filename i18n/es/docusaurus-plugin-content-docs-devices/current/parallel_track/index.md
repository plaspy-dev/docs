# Parallel track

Parallel track fabrica dispositivos de rastreo GPS utilizados en mercados de monitoreo de vehículos y activos. Si está evaluando hardware para seguimiento de ubicación, gestión de flotas o supervisión remota de activos, los dispositivos Parallel track suelen elegirse por su conjunto práctico de funciones y su instalación sencilla. En esta página explicamos cómo funcionan los dispositivos Parallel track con Plaspy, qué puede esperar de la marca y cómo elegir el modelo adecuado para su implementación.

## Cómo se integran los dispositivos Parallel track con Plaspy

Los dispositivos Parallel track capturan posición y datos de sensores desde el GPS y entradas a bordo, y transmiten esa información a través de redes celulares. Cuando se configuran para enviar datos a Plaspy, esas transmisiones se muestran en la plataforma Plaspy, donde usted puede ver ubicaciones en tiempo real, recorridos históricos y telemetría.

Plaspy ofrece una interfaz única para recibir datos de dispositivos Parallel track, procesar eventos y alertas, y presentar información útil mediante mapas, reportes y notificaciones. Para detalles de conexión y pasos de configuración específicos de cada dispositivo consulte la ficha del dispositivo en el catálogo y las páginas de guía dentro de Plaspy.

## Funciones comunes en los dispositivos Parallel track

Aunque las capacidades varían según el modelo, muchos dispositivos Parallel track suelen incluir:
- Localización en tiempo real y seguimiento histórico
- Opciones de batería interna o respaldo para uso portátil
- Monitoreo de alimentación del vehículo y detección de ignición
- Entradas y salidas digitales para sensores y accesorios externos
- Detección de movimiento y modos de ahorro energético
- Alertas básicas como exceso de velocidad o eventos de geocerca

Estas características hacen que el hardware de Parallel track sea adecuado para el rastreo estándar de vehículos y para flujos sencillos de monitoreo de activos. El conjunto exacto de funciones para cada modelo se muestra en el catálogo de dispositivos.

## Casos de uso habituales para los rastreadores GPS Parallel track

Los dispositivos Parallel track se emplean frecuentemente en:
- Seguimiento de vehículos de flota y supervisión de rutas
- Localización de remolques, contenedores y equipos
- Detección de robos y asistencia en recuperación
- Recolección básica de telemetría para operaciones logísticas pequeñas
- Monitoreo de vehículos de renta o compartidos donde se requiere hardware compacto

Si su caso de uso demanda integración avanzada de sensores, analítica telemática o flujos de trabajo personalizados, Plaspy puede combinar los datos del dispositivo con entradas adicionales y reglas para satisfacer sus necesidades operativas.

Plaspy está diseñado para consolidar datos de dispositivos en una experiencia de plataforma coherente. Al combinar hardware Parallel track con Plaspy usted obtiene:
- Un tablero unificado para seguimiento en vivo e historial de todos los dispositivos y marcas

Usar Plaspy reduce la necesidad de operar múltiples portales de proveedores y centraliza los datos de Parallel track dentro de un flujo de trabajo único de gestión de flotas o activos.

## Ayuda para elegir el dispositivo Parallel track adecuado

La elección del dispositivo depende del lugar de instalación, disponibilidad de alimentación, frecuencia de reporte y entradas necesarias. Considere estos factores al seleccionar:
