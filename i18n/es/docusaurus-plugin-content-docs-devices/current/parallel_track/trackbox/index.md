# Parallel track - Trackbox

![Trackbox](./logo.jpg)

El 'TrackBox Paralelo' es un dispositivo de hardware diseñado para rastrear y reportar la ubicación de forma precisa y confiable. Este rastreador GPS puede enviar datos de posición a intervalos regulares a través de la red de telefonía móvil o mediante mensajes de texto SMS a solicitud. Además, se puede configurar para enviar los datos de posición directamente a su propio sitio web, lo que le permite integrar el seguimiento en tiempo real en su presencia en línea a través de servicios como Google Maps, Yahoo Maps o Microsoft Virtual Earth.

Con el 'TrackBox Paralelo', puede mantener un control constante sobre la ubicación de sus activos, vehículos o personas importantes. Ya sea que necesite monitorear una flota de vehículos comerciales, rastrear la ubicación de su equipo de campo o garantizar la seguridad de sus seres queridos, este rastreador GPS le brinda la tranquilidad de saber dónde se encuentran en todo momento.

Características destacadas:

- Envío de datos de posición a intervalos regulares
- Compatibilidad con redes de telefonía móvil y mensajes de texto SMS
- Integración con servicios de mapas en línea como Google Maps, Yahoo Maps y Microsoft Virtual Earth
- Posibilidad de enviar datos de posición directamente a su propio sitio web
- Control y monitoreo en tiempo real de activos, vehículos o personas
