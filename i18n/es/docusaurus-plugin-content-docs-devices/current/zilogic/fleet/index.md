# Zilogic - Fleet

![Fleet](./logo.jpg)

El rastreador GPS BlackKite-Fleet de Zilogic es una variante diseñada específicamente para abordar las necesidades de gestión de flotas y activos móviles. Equipado con un GPS integrado de alta precisión SiRF IV, este dispositivo ofrece un seguimiento preciso y confiable de los vehículos en tiempo real.

Además de las funciones básicas de seguimiento, el BlackKite-Fleet cuenta con características adicionales que lo hacen ideal para soluciones más avanzadas. El dispositivo ofrece interfaces dedicadas para monitorear el encendido del vehículo, la batería y el botón de pánico, lo que permite una supervisión completa de la seguridad y el estado del vehículo.

Con 3 entradas digitales adicionales, el BlackKite-Fleet se puede configurar para monitorear de forma remota el estado del vehículo, como el bloqueo de la puerta, la indicación del nivel de aceite y el medidor de la feria. Además, el dispositivo proporciona 3 líneas de salida digital para controlar dispositivos electrónicos a bordo y para inmovilizar el vehículo en caso de uso no autorizado.

El BlackKite-Fleet también cuenta con 2 entradas analógicas que permiten monitorear y medir parámetros analógicos como el nivel de combustible, la temperatura y la carga. Además, incluye una interfaz en serie RS232 que permite la conexión de dispositivos externos como lectores de RFID para la autenticación del operador o sensores digitales para la monitorización de parámetros adicionales.

Con su combinación de funciones avanzadas y precisión de seguimiento, el rastreador GPS BlackKite-Fleet de Zilogic es una opción ideal para empresas que buscan una solución completa de gestión de flotas y activos móviles.

### Características destacadas:

- GPS integrado de alta precisión SiRF IV
- Interfaces dedicadas para monitoreo del encendido del vehículo, batería y botón de pánico
- 3 entradas digitales adicionales para monitoreo remoto del estado del vehículo
- 3 líneas de salida digital para control de dispositivos electrónicos a bordo e inmovilización del vehículo
- 2 entradas analógicas para monitoreo de parámetros como combustible, temperatura y carga
- Interfaz en serie RS232 para conexión de dispositivos externos
