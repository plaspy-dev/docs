# Zilogic - Fleet Pro

![Fleet Pro](./logo.jpg)

El rastreador GPS BlackKite-FleetPro de Zilogic es un sistema telemático de vehículo habilitado para GPRS que ofrece una solución robusta y plataforma independiente. Con su acelerómetro incorporado y la interfaz OBD II opcional, este dispositivo facilita el monitoreo y control del patrón de conducción y la salud del vehículo.

Este rastreador GPS ofrece una serie de características destacadas que lo hacen ideal para diversas aplicaciones. Cuenta con un acelerómetro incorporado que permite controlar el patrón de conducción, lo que resulta útil para mejorar la seguridad y eficiencia en la conducción. Además, ofrece la función de E-Call y B-Call para alertas de emergencia y desglose.

El BlackKite-FleetPro también ofrece la opción de interfaz OBD II, lo que permite obtener información detallada sobre el estado del vehículo, como el consumo de combustible, la temperatura del motor y los códigos de error. Esto facilita el mantenimiento preventivo y la detección temprana de problemas.

Otras características destacadas incluyen el seguimiento en línea y bajo demanda a través de GPRS y SMS, un intervalo de transmisión de datos configurable, alertas de SMS generadas por el dispositivo para cambios de estado IO, alertas de sobrevelocidad configurables, memoria FLASH interna para almacenar datos durante la interrupción de GPRS, autenticación de dos niveles para acceso remoto y bloqueo de GPS más rápido con GPS asistido.

El BlackKite-FleetPro también cuenta con una variedad de interfaces, como banda dual GSM/GPRS para conectividad, GPS de alta precisión para detección de ubicación, LED de estado útiles para la instalación y resolución de problemas, entradas y salidas digitales para controlar dispositivos del vehículo, entradas analógicas para controlar parámetros como el nivel de combustible y la temperatura, entradas SOS y de ignición dedicadas con alertas de SMS generadas por el dispositivo, batería incorporada para operación a prueba de fallas y una interfaz serial para conectar sensores o dispositivos externos.
