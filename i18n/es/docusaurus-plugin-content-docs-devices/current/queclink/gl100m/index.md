# QuecLink - GL100M

![GL100M](./logo.jpg)

El localizador GPS GL-100M de QuecLink es una solución confiable y potente para el seguimiento de activos, ya sea vehículos, mascotas o maquinaria industrial. Este dispositivo cuenta con conectividad cuatribanda GSM 850/900/1800/1900, lo que garantiza una amplia cobertura y comunicación estable.

El GL-100M se comunica con el servidor a través de la red GPRS/GSM o mediante mensajes de texto \(SMS\), lo que permite enviar alertas de emergencia, notificaciones de geo-cercas, informes de batería baja y posiciones GPS precisas. Además, ofrece una variedad de informes avanzados para un monitoreo detallado y eficiente.

Con el localizador GPS GL-100M, podrás tener un control total sobre tus activos, ya sea para asegurar la seguridad de tus vehículos, mantener a tus mascotas bajo vigilancia o supervisar el rendimiento de tu maquinaria industrial. Su diseño compacto y resistente lo hace ideal para su instalación en diferentes tipos de activos.

### Características destacadas:

- Conectividad cuatribanda GSM 850/900/1800/1900 para una amplia cobertura.
- Comunicación a través de la red GPRS/GSM o mensajes de texto \(SMS\).
- Alertas de emergencia y notificaciones de geo-cercas para una mayor seguridad.
- Informes de batería baja y posiciones GPS precisas.
- Diseño compacto y resistente para una fácil instalación en diferentes activos.
