# QuecLink - GL500

![GL500](./logo.jpg)

El GL500 es un localizador GPS de la marca QuecLink diseñado específicamente para aplicaciones de monitoreo de activos fijos. Este dispositivo utiliza dos baterías de litio CR123A y se puede configurar para "despertar" en horarios preestablecidos y verificar si es necesario cambiar el modo de operación, recibir comandos o enviar reportes de ubicación, para luego volver al modo de hibernación. Con una configuración óptima, la duración de las baterías puede superar los 1,000 días.

El GL500 cuenta con un sensor de movimiento integrado que permite detectar cualquier movimiento del activo y enviar una alarma. Utiliza el protocolo de comunicaciones @Track, lo que le permite comunicarse con los servidores de comunicación a través de la red GPRS/GSM para el envío de reportes y alarmas, o con un número telefónico a través de SMS. Además, los integradores de sistemas pueden incorporar fácilmente el protocolo de comunicación en los sistemas existentes.

Algunas de las características destacadas del GL500 incluyen un bajo consumo de energía, una larga duración de más de 1,000 días, un chipset interno u-blox, compatibilidad con GSM/GPRS cuatribanda 850/900/1800/1900MHz, un acelerómetro interno de 3 ejes para la detección de movimiento, antenas internas para GSM y GPS, y la opción de agregar un micrófono interno. Además, el GL500 cuenta con certificación CE/FCC, lo que garantiza su calidad y cumplimiento de estándares internacionales.
