# Navtelekom - Funciones del SIGNAL S-4651

Esta página ofrece un resumen público de las funciones del Navtelekom SIGNAL S-4651 y de cómo se reflejan cuando el dispositivo se utiliza con Plaspy. Está orientada a capacidades visibles para el usuario y al valor operativo para gestores de flota e integradores que usan Plaspy para seguimiento en tiempo real, telemetría y continuidad de datos.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, la SKU regional, las decisiones de instalación y la configuración del fabricante. Use esta guía como referencia práctica de cómo interactúan el dispositivo y Plaspy, y consulte la documentación del fabricante para detalles técnicos específicos del equipo.

## Visión general de funciones

El SIGNAL S-4651 se presenta como un módulo telemático profesional para vehículos, diseñado para conectividad continua, amplia interfaz con el vehículo y registro local resiliente. Al integrarse con Plaspy, el rastreador aporta posición GNSS y datos a bordo en una consola única para monitoreo, alertas e informes históricos.

- Conectividad celular LTE Cat 1 con retroceso a generaciones anteriores para cobertura móvil resiliente y doble SIM para redundancia de operadores.
- Conexiones externas de antena GNSS y GSM para asegurar posicionamiento y recepción celular fiables en instalaciones vehiculares.
- Interfaces de vehículo completas, incluyendo CAN bus, múltiples puertos serie, entradas universales y salidas de control para integrar telemetría y gestión.
- Persistencia local de datos mediante registro en microSD y batería de respaldo integrada para proteger contra interrupciones breves de alimentación.
- Bluetooth 4.0 y opciones de E/S de audio para integraciones de corto alcance y comunicación bidireccional con el conductor cuando está soportado.

## Funciones principales del Navtelekom - SIGNAL S-4651

- Módem LTE Cat 1 con fallback a 3G y 2G y soporte de doble SIM para conectividad celular robusta.
- Posicionamiento GNSS con conexión de antena externa para reportes de ubicación precisos.
- Interfaz CAN bus para telemetría y diagnóstico del vehículo cuando el vehículo lo permite.
- Múltiples interfaces serie, incluyendo RS-232 y RS-485 para dispositivos y sensores de terceros.
- Seis entradas universales y cuatro salidas de control para sensores, señales de estado y control de actuadores.
- Registro en tarjeta microSD para conservar datos de eventos y soportar operación offline.
- Bluetooth 4.0 para emparejamiento de dispositivos de corto alcance e integraciones con sensores.
- Batería de respaldo LiPo integrada para mantener reportes esenciales durante cortes de energía.

## Cómo funcionan estas funciones con Plaspy

Plaspy recibe la telemetría y los datos de ubicación del rastreador y los presenta en una interfaz unificada de gestión de flotas. La plataforma procesa datos GNSS y del bus vehicular junto con entradas y salidas para ofrecer visibilidad, alertas e informes históricos al equipo operativo.

- Actualizaciones de ubicación en tiempo real y reproducción histórica a partir de las posiciones GNSS reportadas por el dispositivo.
- Telemetría del vehículo y diagnósticos derivados de CAN y entradas serie que Plaspy muestra para monitoreo e informes.
- Entradas y salidas digitales que se traducen en eventos de estado y flujos de control dentro de Plaspy para ignición, puertas u otros estados de E/S.
- El registro local en SD y la batería de respaldo ayudan a asegurar la continuidad de datos que Plaspy puede recuperar o reconciliar tras interrupciones temporales.
- Sensores emparejados por Bluetooth e integraciones de corto alcance pueden reenviarse a Plaspy cuando el rastreador está configurado para transmitir esos datos.

## Casos de uso típicos

- Seguimiento de flotas comerciales con ubicación en vivo, historial de rutas y telemetría integrada del vehículo para supervisión operativa.
- Diagnóstico remoto y recopilación de telemetría mediante interfaces CAN y serie para apoyar flujos de trabajo de mantenimiento.
- Flujos de trabajo antirrobo e inmovilización que aprovechan salidas de control y comandos del bus vehicular cuando están configurados.
- Monitorización del entorno de la carga usando sensores Bluetooth y registro local para capturar eventos durante el tránsito.
- Comunicación bidireccional con el conductor a través de E/S de audio a bordo para despacho y coordinación de seguridad.

## Notas sobre disponibilidad de funciones

- Las revisiones de firmware influyen en las funciones disponibles y su comportamiento; algunas funcionalidades pueden añadirse o mejorarse en firmware posteriores.
- Las revisiones de hardware y las SKU regionales pueden cambiar las bandas celulares compatibles, conectores o funciones opcionales.
- Las decisiones de instalación y el cableado del vehículo determinarán qué interfaces del vehículo están disponibles y cómo se interpretan las entradas.
- Las utilidades y herramientas de configuración del fabricante son la fuente autoritativa para la puesta a punto del dispositivo y los protocolos soportados.
- Para la integración con Plaspy, verifique que el dispositivo esté configurado para reenviar los tipos de telemetría y eventos necesarios a su instancia de Plaspy.

## Por qué usar Plaspy con estas funciones

Combinar el SIGNAL S-4651 con Plaspy permite a las organizaciones centralizar la ubicación, telemetría del vehículo y datos de eventos de una unidad telemática potente en una vista operativa única. Los paneles, alertas e informes históricos de Plaspy convierten los datos crudos GNSS y del bus vehicular en información accionable para operaciones de flota, planificación de mantenimiento y procesos de seguridad.
