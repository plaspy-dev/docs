# Navtelekom - Signal S-2115

![Signal S-2115](./logo.jpg)

El rastreador GPS Navtelekom Signal S-2115 es un sistema de vigilancia y seguridad basado en la tecnología de comunicaciones por satélite GPS. Diseñado especialmente para el transporte, este dispositivo ofrece funciones de búsqueda, seguridad y control remoto.

El Signal S-2115 cuenta con una interfaz USB que permite su conexión a un ordenador para una mayor personalización y configuración. Además, está equipado con un acelerómetro incorporado que registra los golpes, la flexión y el movimiento del vehículo. En caso de eventos de alerta, el dispositivo notifica al usuario a través de SMS o mensajes de voz.

Una de las ventajas de este rastreador es su capacidad de gestión remota. A través del menú de voz y comandos SMS, es posible controlar y configurar el dispositivo de forma remota. Además, cuenta con comandos de control a través de GPRS, sensores analógicos y sensores digitales para una mayor precisión en la detección de eventos.

Características destacadas:

- Comandos de control a través de GPRS
- Sensores analógicos
- Sensores digitales
- Comunicación a través de TCP
