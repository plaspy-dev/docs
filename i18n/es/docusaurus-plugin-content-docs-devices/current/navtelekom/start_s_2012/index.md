# Navtelekom - START S-2012

![START S-2012](./tracker.jpeg)

El START S-2012 es un rastreador vehicular compacto con soporte GLONASS y GPS, pensado para instalación permanente con cable cuando se requiere un equipo de perfil reducido y posicionamiento confiable. Combina posicionamiento GNSS con conectividad GSM para ofrecer seguimiento en tiempo real, telemetría básica y reporte de eventos en automóviles, vehículos comerciales ligeros y otros activos móviles. El dispositivo no incorpora batería interna y está diseñado para alimentarse de forma continua desde el vehículo, por lo que es ideal para instalaciones integradas al sistema eléctrico del vehículo y de bajo perfil.

Este modelo es compatible con Plaspy desde el primer momento, por lo que puede reenviar datos de posición y de sensores directamente a la plataforma Plaspy para supervisión e informes. El START S-2012 admite sensores de nivel de combustible tanto cableados como inalámbricos, sensores ambientales inalámbricos como temperatura y humedad, sensores Bluetooth y entradas y salidas estándar, permitiendo que los usuarios de Plaspy consoliden ubicación, estado de combustible y telemetría ambiental junto con otros datos de la flota para una supervisión operativa completa.

## Características principales

- Rastreador compacto con GLONASS y GPS y antenas GNSS/GSM integradas para una instalación discreta en el vehículo.
- Compatible con Plaspy para reenviar ubicación en tiempo real, telemetría e informes de eventos a la plataforma.
- Soporte para sensores de nivel de combustible cableados e inalámbricos y sensores ambientales inalámbricos para control de combustible y temperatura.
- Bluetooth 4.0 para conectar sensores y balizas inalámbricas compatibles y enriquecer la telemetría.
- Múltiples entradas y una salida de control que permiten reportes por eventos e integración básica de control remoto.
- Diseñado para uso permanente con cable en vehículos, con protecciones de alimentación para operación estable.

## Cómo funciona con Plaspy

Cuando está conectado a la red celular y configurado para Plaspy, el START S-2012 transmite ubicación y datos de sensores a Plaspy, donde los operadores pueden ver posiciones en vivo, activar alertas y analizar comportamientos históricos. Plaspy recibe las entradas del rastreador y las transforma en acciones a través de notificaciones, paneles e informes.

- Actualizaciones de ubicación en tiempo real y el historial de rutas visibles en Plaspy para monitorización y reproducción.
- Datos de nivel de combustible procedentes de sensores cableados o inalámbricos reportados a Plaspy para análisis de consumo y alertas.
- Entradas por eventos, como señales de puerta o ignición, encaminadas a Plaspy para activar notificaciones o flujos de trabajo.
- La salida de control puede emplearse junto con las funciones de comandos de Plaspy para acciones remotas habituales en operaciones de flota.
- Datos de sensores Bluetooth y telemetría ambiental inalámbrica presentados en los paneles de Plaspy para supervisar cargas sensibles a la temperatura.
- Configuración remota y reporte de estado del equipo integrados en los flujos de trabajo de Plaspy para facilitar el mantenimiento y la gestión de la flota.

## Casos de uso típicos

- Seguimiento de flotas pequeñas y medianas que requieren un rastreador compacto y con instalación fija compatible con Plaspy.
- Monitoreo y control de combustible mediante sensores cableados o inalámbricos para detectar patrones de consumo.
- Vigilancia antirrobo con alertas basadas en eventos y opciones de control remoto para soportar inmovilizaciones básicas.
- Monitoreo ambiental de cargas sensibles mediante sensores inalámbricos de temperatura y humedad emparejados al rastreador.
- Telemática básica y supervisión operativa para vehículos comerciales ligeros y activos móviles.

## Por qué elegir este rastreador con Plaspy

El START S-2012 es una opción práctica para organizaciones que necesitan un rastreador de perfil bajo instalado de forma permanente que integre ubicación y telemetría básica en Plaspy. Su compatibilidad con sensores de combustible, sensores ambientales y periféricos Bluetooth permite ampliar la información disponible en Plaspy más allá de la simple ubicación, lo que ayuda en el control de combustible, la supervisión de condiciones de la carga y las notificaciones basadas en eventos. Las herramientas de configuración del fabricante y la gestión remota facilitan el despliegue y el mantenimiento continuo cuando se utilizan junto con Plaspy.
