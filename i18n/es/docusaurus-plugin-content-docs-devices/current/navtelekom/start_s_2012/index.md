# Navtelekom - START S-2012

![START S-2012](./tracker.jpeg)

El START S-2012 es un rastreador compacto para vehículos compatible con GLONASS/GPS, diseñado para instalación permanente cuando un factor de forma reducido y una posición fiable son prioritarios. Compatible con Plaspy de serie, el START S-2012 combina un posicionamiento GNSS preciso con conectividad GSM para ofrecer seguimiento en tiempo real, telemetría básica y reportes de eventos para automóviles, vehículos comerciales ligeros y otros activos móviles.

Con una batería interna ausente para uso en vehículos con conexión cableada, el START S-2012 admite sensores de nivel de combustible cableados e inalámbricos, sensores universales y ambientales inalámbricos \(temperatura y humedad\), sensores Bluetooth y entradas/salidas estándar para la integración con sistemas a bordo. La integración se simplifica mediante el NTC Configurator del fabricante y las herramientas de gestión remota DRC; cuando se empareja con Plaspy, este rastreador ofrece una solución compacta y rentable para la gestión de flotas, monitoreo anti-robo y flujos de trabajo de monitoreo de combustible.

## Aspectos Clave

- Rastreador compacto GLONASS/GPS con antenas GNSS y GSM integradas para una instalación de vehículo discreta y de perfil bajo.
- Compatible con Plaspy — diseñado para enviar la ubicación y telemetría en tiempo real a Plaspy para seguimiento, alertas e informes.
- Soporta sensores de nivel de combustible cableados e inalámbricos, además de sensores universales/ambientales inalámbricos para monitoreo de combustible y registro de temperatura.
- Conectividad: módem GSM 2G con una sola ranura SIM; USB Type-C y RS-485 para interfaz con dispositivos externos.
- Bluetooth 4.0 para conectar sensores y beacons Bluetooth para enriquecer los datos de telemetría en Plaspy.
- Entradas múltiples y una salida de control que permiten informes basados en eventos, control remoto básico e integración con los sistemas del vehículo.
- Diseñado para instalación permanente: sin batería interna y protección de alimentación hasta 200 V para un funcionamiento estable en los sistemas eléctricos del vehículo.

## Cómo Funciona con Plaspy

Cuando se integra con Plaspy, el START S-2012 transmite ubicación y datos de sensores a través de la red celular a la plataforma Plaspy, donde los operadores obtienen seguimiento en tiempo real, alertas de geocercas, historial de rutas y paneles de telemetría. Las entradas/salidas flexibles y el soporte para sensores Bluetooth permiten a Plaspy recibir el estado del vehículo, lecturas de nivel de combustible y condiciones ambientales para informes más completos y alertas accionables.

- Actualizaciones de ubicación y telemetría en tiempo real enviadas mediante la conexión GSM del dispositivo a Plaspy para seguimiento en vivo y reproducción histórica.
- Monitoreo de combustible desde sensores cableados o inalámbricos enviados a Plaspy para análisis de consumo y alertas de control de combustible.
- Entradas de eventos para señales de puerta, alarma o encendido; Plaspy puede usar estos eventos para activar notificaciones o flujos de trabajo automatizados.
- La salida de control puede usarse para accionar relés comúnmente utilizados en configuraciones de inmovilización remota o corte remoto, cuando se combina con la funcionalidad de comandos de Plaspy.
- El soporte de Bluetooth 4.0 permite conectar sensores BLE \(temperatura, humedad, beacons de proximidad\) para ampliar la telemetría visible en los paneles de Plaspy.
- Las interfaces RS-485 y USB Type-C permiten la integración con dispositivos externos o fuentes de datos que Plaspy puede ingerir para obtener una visión consolidada de la flota.
- Gestión remota de firmware y configuración mediante DRC del fabricante y NTC Configurator complementa los flujos de despliegue y mantenimiento de Plaspy.

## Casos de Uso

- Gestión de flotas y enrutamiento para flotas de vehículos pequeños a medianos que requieren seguimiento GPS discreto y compatible con Plaspy.
- Monitoreo y control de combustible usando sensores de combustible cableados o inalámbricos para reducir pérdidas y supervisar el consumo.
- Monitoreo anti-robo con alertas basadas en eventos; la integración con un relé mediante la salida de control admite flujos de inmovilización remota.
- Monitorización de carga sensible a la temperatura y condiciones ambientales mediante sensores inalámbricos de temperatura y humedad emparejados vía Bluetooth.
- Telemática básica y recopilación de telemetría para vehículos comerciales ligeros y activos móviles donde es aceptable la instalación cableada permanente.

## Por Qué Elegir Este Rastreador con Plaspy

START S-2012 es un rastreador GPS práctico y compatible con Plaspy para implementaciones donde se prefiere un dispositivo compacto y cableado. Sus antenas integradas GLONASS/GPS y GSM simplifican la instalación, mientras que Bluetooth 4.0 y RS-485 amplían las opciones de sensores y periféricos. La capacidad de aceptar sensores de combustible cableados e inalámbricos, además de sensores ambientales, lo convierten en una opción sólida para monitoreo de combustible y telemetría. Combinado con el NTC Configurator del fabricante y la gestión remota DRC, el START S-2012 soporta una configuración sencilla, gestión de firmware y mantenimiento continuo, permitiendo un seguimiento en tiempo real confiable, gestión de flotas y monitoreo anti-robo a través de Plaspy sin complejidad innecesaria.
