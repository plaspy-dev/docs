# Navtelekom - START S-2013

<div className="device-logo">
![START S-2013](./tracker.jpeg)
</div>

El START S-2013 de Navtelekom es un rastreador vehicular compacto con GLONASS y GPS, pensado para instalaciones discretas y monitoreo sencillo de activos. Su tamaño reducido y las antenas internas lo hacen ideal para vehículos ligeros y equipos donde se prefiere mínimas conexiones externas. El equipo envía posicionamiento y telemetría a través de una conexión GSM 2G, incorpora una batería de respaldo para interrupciones breves de alimentación y cuenta con un puerto USB Type C para configuración y carga.

Como dispositivo compatible con Plaspy, el START S-2013 se integra en el entorno de seguimiento y generación de informes en tiempo real de Plaspy, entregando ubicación, datos de sensores y alertas de eventos desde una unidad de perfil bajo. El rastreador admite entradas cableadas, conectividad RS 485 y Bluetooth 4.0 para sensores de corto alcance, lo que permite a Plaspy recopilar telemetría ampliada —como mediciones de combustible o ambientales— manteniendo una implementación del dispositivo simple y ordenada.

## Características principales

- Rastreador compacto con GLONASS y GPS y antenas internas para una instalación discreta en vehículos y equipos.
- Transmisión de posición y telemetría mediante GSM 2G para integración con plataformas de gestión de flotas.
- Batería de respaldo integrada y puerto USB Type C para operar durante cortes de energía y facilitar la configuración.
- Conectividad flexible para sensores: entradas cableadas, interfaz RS 485 y Bluetooth 4.0 para expansión con sensores externos.
- E/S configurable para telemetría basada en eventos, como señales de puertas, alarmas o entradas de sensores personalizadas.
- Diseñado para despliegues rápidos que reducen el tiempo de instalación en flotas y vehículos de servicio.

## Cómo funciona con Plaspy

Al emparejarse con Plaspy, el START S-2013 envía posiciones GNSS y telemetría de sensores a la plataforma para su normalización en seguimiento en vivo, alertas e informes históricos. Plaspy utiliza esos datos para ofrecer visibilidad operativa, notificaciones de eventos y herramientas de reporte que los gestores de flota necesitan.

- Actualizaciones de ubicación en tiempo real y reproducción histórica en Plaspy para revisión de rutas y seguimiento de activos.
- Entradas digitales y analógicas que informan a Plaspy sobre eventos de puertas, alarmas u otros sensores como señales configurables para alertas y registro.
- Datos de monitoreo de combustible desde sensores cableados o inalámbricos que pueden enviarse a Plaspy para análisis de consumo y recargas.
- Conectividad Bluetooth 4.0 para sensores de corto alcance que aportan telemetría ambiental como temperatura y humedad, visible en Plaspy.
- La interfaz RS 485 permite agregar datos de controladores externos que Plaspy puede presentar junto con la información GPS y de eventos.

## Casos de uso habituales

- Seguimiento discreto de vehículos en flotas ligeras donde se prefieren antenas internas y un formato compacto.
- Monitoreo y análisis de combustible para vehículos de servicio y reparto mediante sensores cableados o inalámbricos.
- Control ambiental de cargas sensibles a la temperatura emparejando sensores Bluetooth al rastreador.
- Localización de equipos y maquinaria ligera en obras donde el cableado mínimo y el tamaño reducido son determinantes.
- Consolidación de telemetría de controladores o sensores conectados por RS 485 para supervisión centralizada de la flota.

## Por qué elegir este rastreador con Plaspy

El START S-2013 es una opción práctica para organizaciones que requieren un rastreador GNSS de bajo perfil capaz de soportar variadas opciones de telemetría. Su combinación de antenas internas, alimentación de respaldo y múltiples interfaces para sensores simplifica el despliegue de hardware y, al mismo tiempo, permite el flujo de telemetría que Plaspy necesita para el monitoreo y los informes en tiempo real.
