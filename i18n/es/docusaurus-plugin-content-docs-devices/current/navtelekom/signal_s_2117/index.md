# Navtelekom - Signal S-2117

![Signal S-2117](./logo.jpg)

El rastreador GPS Navtelekom Signal S-2117 es un dispositivo basado en el coche de comunicación GSM estándar GPS-receptor que se utiliza para la supervisión de la condición del vehículo, la advertencia de alarmas y eventos, y el control remoto de los dispositivos conectados. Este rastreador cuenta con una interfaz RS-485 que permite la conexión de hasta tres medidores de combustible digitales, lo que facilita el monitoreo preciso del consumo de combustible.

Además, el Signal S-2117 ofrece la posibilidad de conectar sensores de temperatura digitales y la interfaz del sistema de identificación 1-Wire. Esto permite monitorear la temperatura del vehículo y realizar un seguimiento de los cambios en tiempo real. También es posible configurar el altavoz entre el centro de control y el conductor en cualquier momento o pulsando el botón de pánico, lo que brinda una mayor seguridad y comunicación efectiva en situaciones de emergencia.

En resumen, el rastreador GPS Navtelekom Signal S-2117 es una solución confiable y versátil para la supervisión y control de vehículos. Con su capacidad para conectar medidores de combustible, sensores de temperatura y la interfaz del sistema de identificación 1-Wire, este dispositivo ofrece un monitoreo completo y preciso, así como una comunicación efectiva entre el centro de control y el conductor.

### Características destacadas:

- Comunicación GSM estándar
- Receptor GPS integrado
- Interfaz RS-485 para conectar medidores de combustible digitales
- Posibilidad de conectar sensores de temperatura digitales
- Interfaz del sistema de identificación 1-Wire
- Configuración de altavoz para comunicación entre centro de control y conductor
- Botón de pánico para situaciones de emergencia
