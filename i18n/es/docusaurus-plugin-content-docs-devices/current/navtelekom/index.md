# Navtelekom

Navtelekom fabrica dispositivos de rastreo GPS y telemática para el seguimiento de vehículos y activos. Esta página describe cómo integran estos dispositivos con Plaspy, qué esperar de los rastreadores en términos generales y cómo elegir el modelo adecuado según sus necesidades de monitoreo. Use el catálogo más abajo para ir directamente a los modelos compatibles y ver detalles de integración con la plataforma Plaspy.

## Integración de dispositivos Navtelekom con Plaspy

Los rastreadores Navtelekom suelen captar la ubicación GPS y datos básicos de telemetría, enviándolos a través de redes móviles. Plaspy puede recibir y procesar esta información cuando el equipo está configurado para enviar mensajes a la plataforma. En Plaspy usted puede ver ubicaciones en tiempo real, reproducir historiales y recibir actualizaciones de estado de los dispositivos conectados.

Si planea conectar un equipo Navtelekom a Plaspy, los pasos habituales son:
- Verificar que el dispositivo aparezca en el catálogo de Plaspy en esta página.
- Configurar los ajustes de conexión del dispositivo (dirección del servidor y formato de datos) según la documentación del equipo.
- Agregar el dispositivo a su cuenta Plaspy para que se muestre en mapas e informes.

Para instrucciones detalladas consulte la documentación del dispositivo y siga las indicaciones de conexión en la página específica del modelo dentro del catálogo.

## Funciones comunes en dispositivos Navtelekom

Aunque las características varían según el modelo, muchos rastreadores Navtelekom comparten capacidades útiles para la gestión de flotas y activos:
- Reporte de ubicación GPS para seguimiento en tiempo real y registro histórico
- Conectividad por red celular para envío remoto de datos
- Entradas de telemetría básicas como detección de encendido y movimiento
- Intervalos de reporte configurables para ubicación y estado
- Soporte a nivel de plataforma para alertas geográficas y detección de movimiento

El BrandCatalog más abajo muestra todos los modelos Navtelekom compatibles que pueden utilizarse con Plaspy. Haga clic en un modelo para ver la documentación específica y las notas de configuración para Plaspy.

## Casos de uso típicos para rastreadores Navtelekom

Los dispositivos Navtelekom se suelen emplear en:
- Seguimiento de flotas y supervisión de rutas de vehículos
- Monitoreo de activos a corto o largo plazo donde haya cobertura celular
- Control básico de utilización de conductores o equipos
- Alertas basadas en ubicación y reportes telemáticos sencillos

Suelen elegirse cuando se necesita un reporte de ubicación confiable y sin integraciones hardware complejas.

## Por qué usar Plaspy para monitorear dispositivos Navtelekom

Plaspy ofrece una plataforma flexible para recibir datos de rastreadores y convertirlos en información útil:
- Vista unificada en mapa para todos los dispositivos y tipos de activos
- Alertas, informes y geocercas configurables según sus necesidades operativas
- Gestión de usuarios y acceso por roles para equipos
- Plataforma escalable que admite flotas mixtas y múltiples marcas de dispositivos

Usar Plaspy con dispositivos Navtelekom le brinda un único lugar para monitorear ubicaciones, realizar análisis y gestionar alertas en toda su flota. Para más información sobre la plataforma y las opciones de cuenta visite https://www.plaspy.com.
