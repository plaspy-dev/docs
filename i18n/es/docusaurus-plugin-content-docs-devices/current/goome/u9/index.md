# Goome - U9

![U9](./logo.jpg)

El rastreador GPS Goome U9 es un dispositivo de alta gama que utiliza la tecnología GPS de u-blox 7 y 4ª generación. Es compatible con GPS, LBS y AGPS para una ubicación precisa. Cuando la señal GPS es débil, el dispositivo activará la ubicación LBS para garantizar un seguimiento continuo. Además, este rastreador GPS cuenta con la capacidad de apagar el motor del vehículo cuando está conectado a un relé.

El Goome U9 ofrece una serie de características destacadas que lo convierten en una opción preferida para los clientes. Estas características incluyen seguimiento en tiempo real, la capacidad de definir Geo-fences para establecer áreas de seguridad, reproducción de seguimiento para revisar el historial de rutas, monitorización remota de voz a través de un micrófono incorporado, botón SOS para situaciones de emergencia, alarma de corte de alambre, corte remoto de gasolina o electricidad, y alarma de vibración para detectar movimientos no autorizados.

Además de estas características, el Goome U9 también cuenta con una batería de respaldo para garantizar un funcionamiento continuo incluso en caso de pérdida de energía, un sensor de aceleración incorporado para detectar cambios bruscos de velocidad, detección ACC para monitorear el estado del vehículo, y la capacidad de control remoto del seguimiento en tiempo real a través de una plataforma web y de aplicaciones.
