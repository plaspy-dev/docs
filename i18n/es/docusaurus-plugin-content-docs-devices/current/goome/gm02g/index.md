# Goome - GM02G

![GM02G](./logo.jpg)

El rastreador GPS GM02G de Goome es un dispositivo compacto y fácil de instalar en cualquier vehículo. Con solo conectar la energía, el rastreador comenzará a funcionar de inmediato. Este dispositivo cuenta con tecnología antiespía y una función de reposo que se conecta al servidor en horarios preestablecidos y cuando el vehículo está en movimiento.

Este rastreador GPS ofrece una serie de características destacadas que lo hacen ideal para el seguimiento de vehículos. Entre ellas se encuentran:

- Seguimiento en tiempo real: Podrás conocer la ubicación exacta de tu vehículo en todo momento.
- Geo-fence: Permite definir áreas geográficas y recibir notificaciones cuando el vehículo entra o sale de ellas.
- Reproducción de seguimiento: Podrás revisar el historial de rutas y movimientos del vehículo.
- Detección de ACC: El rastreador detecta cuando el vehículo se enciende o apaga, lo que te permite conocer su estado de uso.
- Alarma de exceso de velocidad: Recibirás alertas cuando el vehículo supere los límites de velocidad establecidos.
- Alarma de corte de alambre: Si alguien intenta cortar los cables de alimentación del rastreador, recibirás una notificación inmediata.
- Impermeable: El rastreador está diseñado para resistir condiciones climáticas adversas.
- Alarma de vibración: Serás notificado si el vehículo sufre movimientos no autorizados.

Además de estas características, el rastreador GPS GM02G cuenta con una batería de respaldo, lo que garantiza su funcionamiento incluso en caso de corte de energía. También incluye un sensor de aceleración incorporado y la posibilidad de realizar un seguimiento en tiempo real de forma remota a través de una plataforma web y de aplicaciones.
