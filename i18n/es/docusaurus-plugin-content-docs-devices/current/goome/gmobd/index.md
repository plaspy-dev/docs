# Goome - GMOBD

<div className="device-logo">
![GMOBD](./logo.jpg)
</div>

El Goome GMOBD es un rastreador GPS tipo OBD2 que integra un módulo GSM con posicionamiento BDS. Diseñado para la supervisión vehicular, ofrece funciones como antirrobo, escucha remota, alarmas, seguimiento en tiempo real, reporte de posiciones, geocercas y reproducción de recorridos. El dispositivo es compacto, cuenta con batería de respaldo para mantener la operación cuando se corta la alimentación del vehículo y es compatible con una amplia variedad de vehículos que disponen de una interfaz OBD de 16 pines.

Como dispositivo compatible con Plaspy, el GMOBD puede enviar datos de ubicación y eventos en vivo a la plataforma Plaspy para obtener visibilidad y control operacional. Plaspy puede aprovechar el seguimiento en tiempo real del rastreador, los eventos de geocerca, el historial de reproducción y las alertas de corte de energía para respaldar la supervisión de flotas, la gestión de despachos y los procesos de seguridad vehicular, lo que convierte al GMOBD en una opción práctica para organizaciones que requieren un rastreo tipo plug-in integrado con un sistema de gestión de flotas.

## Aspectos clave

- Factor de forma OBD2 pensado para conectarse fácilmente a interfaces OBD de 16 pines.
- Seguimiento en tiempo real para visibilidad continua de los vehículos.
- Soporte para geocercas y reproducción de trazas para alertas de límites y revisión de rutas.
- Alerta por corte de energía y batería de respaldo para ayudar a mantener la continuidad del rastreo cuando se interrumpe la alimentación del vehículo.
- Módulos integrados GSM y GPS BDS para el reporte de posición y comunicaciones.
- Funciones antirrobo, alarma por vibración y escucha remota para mayor seguridad.

## Cómo funciona con Plaspy

Al integrarse con Plaspy, el Goome GMOBD proporciona datos de ubicación y eventos que la plataforma puede visualizar, monitorear y reportar. Plaspy procesa los estados y actualizaciones de posición del rastreador para que los gestores de flotas mantengan una vista operativa de los vehículos y puedan responder a alertas.

- Visualización en mapa en tiempo real de las posiciones de los vehículos para monitoreo constante.
- Configuración de geocercas y notificaciones en Plaspy para avisos de entrada y salida.
- Reproducción histórica de rutas para revisión de viajes y análisis de incidentes.
- Alertas de eventos como corte de energía, vibración o alarmas configuradas, integradas en los flujos de trabajo de Plaspy.
- Dashboards y reportes a nivel de flota para resumir la actividad de múltiples dispositivos GMOBD.

## Casos de uso típicos

- Flotas de alquiler de autos que necesitan rastreo plug-in y fácil redeploy entre vehículos.
- Pequeñas flotas de última milla, servicios o transporte local que requieren gestión básica de vehículos.
- Sistemas de despacho que precisan ubicaciones en vivo y reproducción de rutas.
- Monitoreo de seguridad vehicular y antirrobo con alertas por corte de energía y vibración.
- Escenarios donde se prefiere un rastreador compacto tipo OBD2 con batería de respaldo para minimizar modificaciones al vehículo.

## Por qué elegir este rastreador con Plaspy

El Goome GMOBD es una opción práctica para organizaciones que prefieren un rastreador plug-in OBD2 de tamaño reducido con las funcionalidades esenciales de monitoreo vehicular. Su seguimiento en tiempo real, soporte de geocercas y alimentación de respaldo lo hacen adecuado para flotas y operadores de alquiler que buscan visibilidad de posiciones y alertas básicas de seguridad. Integrado en Plaspy, el GMOBD contribuye a mejorar las decisiones de despacho, simplificar la supervisión y mantener un historial de viajes consultable sin requerir instalaciones especializadas.
