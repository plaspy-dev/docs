# Goome - EV02

![EV02](./logo.jpg)

El terminal de posicionamiento del motor eléctrico EV02 de Goome es la solución perfecta para satisfacer las demandas antirrobo en el mercado de electromóviles y motocicletas. Este dispositivo combina la red GSM y la tecnología de posicionamiento del sistema GPS para ofrecer un seguimiento preciso y en tiempo real de tu vehículo.

El EV02 es de tamaño compacto y fácil de ocultar, lo que lo hace ideal para proteger tu vehículo de posibles robos. Además, cuenta con una serie de características que te permitirán tener un control total sobre tu vehículo. Podrás realizar un seguimiento en tiempo real, reproducir trazas de recorrido anteriores y recibir alarmas de vibración. También podrás controlar la gasolina o electricidad a distancia.

Este rastreador GPS utiliza la plataforma de autos en línea desarrollada de forma independiente por Goome, lo que te permitirá gestionar de forma remota el control de tu vehículo. Además, es compatible con la versión de iPhone y Android, lo que te brinda una mayor flexibilidad y comodidad.

### Características destacadas:

- GSM + GPRS + GPS
- Seguimiento en tiempo real
- Usuario define Geo-fence
- Reproducción de seguimiento
- Antena incorporada
- Tamaño pequeño
