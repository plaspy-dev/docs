# Goome - EV02: Características

Esta página ofrece un resumen público de las funciones del Goome EV02 y de cómo sus capacidades se integran con Plaspy. Su propósito es describir las funciones prácticas del EV02, el valor que aportan al usuario y cómo se presentan cuando el dispositivo está conectado a la plataforma Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Para especificaciones detalladas del dispositivo, comportamiento del firmware y guías de instalación, consulte siempre la documentación oficial de Goome y las notas de la versión del firmware.

## Resumen de características

El Goome EV02 es un terminal de posicionamiento diseñado para el mercado de vehículos eléctricos ligeros y motocicletas. Combina conectividad celular con posicionamiento satelital para ofrecer rastreo discreto y continuo y monitorización básica antirrobo en un equipo de tamaño reducido.

- Conectividad GSM GPRS GPS para reporte continuo de posición y comunicación
- Rastreo en tiempo real para ver la ubicación y el movimiento actual del vehículo
- Soporte para geocercas definidas por el usuario que notifican entradas y salidas de zonas
- Reproducción de rutas para revisar trayectos y recorridos históricos
- Factor de forma compacto y antena integrada para facilitar la ocultación y mantener una recepción fiable

## Funciones principales del Goome - EV02

- Conectividad GSM GPRS GPS que combina comunicación celular y posicionamiento satelital
- Rastreo en tiempo real para visibilidad inmediata de la ubicación
- Capacidad de geocercas definidas por el usuario para monitorizar límites virtuales
- Reproducción de rutas para revisión y análisis de trayectos históricos
- Antena integrada diseñada para soportar una recepción de señal consistente
- Carcasa compacta y discreta, adecuada para instalar en vehículos eléctricos ligeros y motocicletas
- Enfoque de diseño orientado a la localización antirrobo y a la monitorización de seguridad del vehículo

## Cómo se integran estas funciones con Plaspy

Cuando el EV02 se utiliza con Plaspy, sus funciones principales se traducen en visibilidad y conocimiento operativo dentro de la plataforma. Plaspy detecta automáticamente los protocolos de rastreadores compatibles y muestra los reportes del dispositivo sin necesidad de seleccionar manualmente el protocolo.

- Las ubicaciones en tiempo real del dispositivo aparecen en los mapas de Plaspy para monitoreo en vivo y despacho
- La reproducción de rutas históricas del EV02 está disponible en Plaspy para revisión de recorridos y auditoría
- Los eventos de geocerca configurados en el dispositivo o en Plaspy generan alertas y registros de eventos para supervisión operativa
- El estado compacto del dispositivo y la información de conectividad se reflejan en Plaspy para que los equipos puedan verificar la salud de los reportes
- Plaspy admite conexiones estándar y detectará el protocolo EV02 para aceptar reportes de posición y eventos

## Casos de uso típicos

- Monitorización antirrobo para scooters eléctricos, motonetas y motocicletas
- Visibilidad de flota para pequeños servicios comerciales con vehículos eléctricos
- Revisión de rutas e investigación de incidentes mediante reproducción de trazas
- Control de perímetros y áreas usando geocercas para zonas restringidas o estacionamientos
- Instalaciones discretas cuando se prefiere un rastreador pequeño y oculto
