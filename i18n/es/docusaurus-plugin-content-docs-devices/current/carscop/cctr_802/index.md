# Carscop - CCTR-802

![CCTR-802](./logo.jpg)

El rastreador GPS Carscop CCTR-802 es un dispositivo de seguimiento en tiempo real diseñado para el rastreo encubierto de vehículos. Con una carcasa resistente al agua y un imán, este rastreador se puede colocar discretamente en cualquier parte del vehículo. Además, cuenta con una batería recargable de larga duración que no requiere mantenimiento. Este dispositivo utiliza el módulo GSM SIMCOM y el módulo GPS de Taiwán para proporcionar una precisión de seguimiento confiable.

Una de las características destacadas de este rastreador es su capacidad para cargar la ubicación actual en tiempo real a través de una plataforma web gratuita. No hay cargos de servicio de plataforma, lo que significa que los usuarios pueden acceder a la plataforma de seguimiento de Carscop de forma gratuita. El rastreador utiliza GPS para localizar y GPRS para cargar la ubicación. También cuenta con una memoria interna para grabar la ruta sin conexión a la red GSM.

El rastreador Carscop CCTR-802 también incluye un sensor de impacto incorporado que controla el encendido y apagado del GPS para prolongar la vida útil de la batería. Este sensor también se puede utilizar como una alarma de movimiento o impacto en el vehículo. Los usuarios pueden acceder al seguimiento del vehículo o ver el historial de seguimiento a través del sitio web de Carscop sin necesidad de descargar ningún software adicional.

Otras características destacadas incluyen la capacidad de preconfigurar hasta 3 números de teléfono para recibir alertas de SOS o información de alarma, alertas de exceso de velocidad o de salida de áreas restringidas, y una batería de respaldo recargable de polímero de larga duración. El rastreador también es resistente al agua y se puede colocar en cualquier parte metálica del vehículo con un pin magnético.

El rastreador GPS Carscop CCTR-802 es una opción ideal para aquellos que buscan un dispositivo de seguimiento encubierto y confiable para vehículos como automóviles, autobuses, taxis, vehículos de alquiler y equipos móviles.

### Características destacadas:

- Carga en tiempo real de la ubicación actual en un sitio web
- Sin cargos de servicio de plataforma \(plataforma de seguimiento gratuita\)
- Impermeable y con pin magnético
- Batería recargable de gran capacidad \(2000 mAh\) y larga duración en espera
- Acepta pedidos pequeños

### Especificaciones técnicas:

- Dimensiones principales: 69 mm x 48 mm x 26 mm
- Peso principal: 130 g
- Paquete: caja de color
- Dimensiones del paquete: 130 mm x 200 mm x 46 mm
- Peso del paquete: 0.38 kg
