# BCE - FM-500 Light

![FM-500 Light](./logo.jpg)

El BCE FM-500 Light es un dispositivo de rastreo GPS/GLONASS con conectividad GSM diseñado para el seguimiento de objetos. Este dispositivo es capaz de adquirir información sobre la ubicación del objeto, velocidad, dirección, entre otros datos, y transferirlos a través de la red GSM. Además, cuenta con entradas digitales y analógicas, así como una interfaz 1-Wire que permite la conexión de diferentes sensores o dispositivos externos. También cuenta con salidas que pueden ser utilizadas para controlar equipos externos de forma remota. La configuración flexible del dispositivo permite a los usuarios y distribuidores ajustarlo según sus requisitos específicos.

El BCE FM-500 Light cuenta con una serie de características destacadas, entre las cuales se incluyen:

- Interfaces: 1-Wire
- Entradas: 4x digitales \(frecuencia, contador de impulsos, modos ON/OFF\), 2x analógicas \(11 bits, 0-36V\)
- Salidas: 3x digitales \(-\)
- Fuente de alimentación: 8-36V, protección contra impulsos de hasta 120V
- Consumo: activo &lt;50 mA, en modo de suspensión &lt;8 mA
- Memoria interna: 4 MB, hasta 150,000 entradas
- Acelerómetro: LIS3DH
- Odómetro interno
- Rango de temperatura operativa: -40 a 85 °C
- Dimensiones: 26x80x55 mm
- Peso: Tracker - 62 g, set - 141 g
- Antena interna para GSM
- Clase GSM/GPRS: 10 \(hasta 85.6 kbit\), clase B
- Detección de interferencia GSM
- Antena externa para GPS/GLONASS
- Sensibilidad: -162 dBm
- Tiempo de adquisición: en frío &lt;30 s, en caliente 1 s, soporte A-GPS
