# BCE - FM-500 Blue

![FM-500 Blue](./logo.jpg)

El rastreador GPS FM-500 Blue de BCE es un dispositivo diseñado para el seguimiento de objetos. Con GPS/GLONASS y conectividad GSM, este dispositivo es capaz de adquirir información sobre la localización del objeto, velocidad, dirección, entre otros datos, y transferirlos a través de la red GSM. Además, cuenta con entradas digitales y analógicas que permiten la conexión de diferentes sensores o dispositivos externos, así como salidas que pueden ser utilizadas para controlar equipos externos de forma remota. El FM-500 Blue también es capaz de leer datos FMS CAN \(protocolo J1939\) de vehículos. Su configuración flexible permite ajustarlo a los requisitos específicos de los usuarios o distribuidores.

El rastreador FM-500 Blue cuenta con una serie de características destacadas, entre las cuales se encuentran:

- Interfaces: FMS CAN \(J1939\), OBDII \(protocolo de diagnóstico de vehículos ligeros, SAE-1979 sin adaptadores\), CAN protocolos de vehículos ligeros \(sin adaptadores\).
- Entradas: 4x digitales \(frecuencia, contador de impulsos, modos ON/OFF\), 3x analógicas \(11 bits, 0-36V\).
- Salidas: 3x digitales \(-\).
- Fuente de alimentación: 8-36V, con protección contra impulsos de hasta 120V. Consumo a 12V: activa: \<50 mA, en modo de suspensión: \<8 mA. Cuenta con una batería interna de 700 mAh \(opcional\).
- Memoria interna: 4 MB, con capacidad de hasta 150,000 entradas.
- Acelerómetro: LIS3DH.
- Odómetro interno: Sí.
- Rango de temperatura operativa: -40 a 85 °C.
- Dimensiones: 26x80x55 mm.
- Peso: Rastreador - 64 g, set - 160 g.
- GSM: Antena interna, clase GSM/GPRS 10 \(hasta 85.6 kbit\), clase B.
- Detección de interferencia GSM: Sí.
- GPS/GLONASS: Antena externa, sensibilidad de -162 dBm. Adquisición: Frías \<30 s, calientes 1 s, con soporte A-GPS.
