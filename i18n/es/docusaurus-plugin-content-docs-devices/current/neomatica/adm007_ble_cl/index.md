# Neomatica - ADM007 BLE CL

![ADM007 BLE CL](./logo..png)

El rastreador de automóviles ADM007 BLE de Neomatica es una solución compacta y eficiente para el monitoreo de vehículos. Con una instalación sencilla en el encendedor de cigarrillos, este rastreador ofrece una forma rápida y precisa de determinar la ubicación de su vehículo. Es económico en consumo de energía y tráfico, utilizando un promedio de 8-10 Mb por mes.

Una de las características clave del ADM007 BLE es su capacidad para conectarse con sensores inalámbricos BLE. Esto le permite recopilar datos de sensores instalados hasta a 100 metros de distancia. Puede conectar hasta 8 sensores inalámbricos utilizando la tecnología Bluetooth de baja energía.

El ADM007 BLE también ofrece una función de detección de interferencias, asegurando la seguridad de su vehículo. Su cuerpo compacto y ranura externa para tarjeta SIM facilitan la instalación y el uso. Puede configurarlo a través de Bluetooth utilizando una aplicación móvil.

Aquí hay algunas de las especificaciones del rastreador de encendedor de cigarrillos ADM007 BLE:

- Sensibilidad del receptor GLONASS/GPS: -167 dBm
- Número de canales del receptor GLONASS/GPS: 33 para seguimiento/99 para captura
- Número y tipo de tarjetas SIM: 1 NanoSIM
- Estándar de comunicación: GSM 850/900/1800/1900, GPRS Multi-slot Class 12
- Voltaje de alimentación: +8.5...+45V
- Número de registros de ruta guardados: hasta 63,000
- Administración: Bluetooth, SMS, GPRS, FOTA
- Interfaz para comunicación con sensores: Bluetooth 4.0
- Consumo de corriente \(voltaje de alimentación 12 V\): 200mA \(máximo\), 30mA \(promedio\)
- Dimensiones: 105x33x20 mm

El rastreador de encendedor de cigarrillos ADM007 BLE es una solución confiable y eficiente para el monitoreo de vehículos. Su tamaño compacto y fácil instalación lo convierten en una opción popular para la gestión de flotas y el seguimiento de vehículos personales.
