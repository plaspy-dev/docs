# ADM500 NEW

El ADM500 NEW es un rastreador GPS de grado profesional diseñado para telemática de vehículos y activos. Con soporte para GNSS de múltiples constelaciones \(GPS, GLONASS, BDS y Galileo\) y conectividad celular LTE/GPRS, el ADM500 ofrece rastreo en tiempo real confiable y telemetría continua para flotas, transporte público, maquinaria agrícola y automóviles de pasajeros. Con un formato compacto, compatibilidad con dos nanoSIM y una batería interna de 1000 mAh, este rastreador GPS compatible con Plaspy está hecho para mantener la precisión de ubicación y un flujo de datos fiable incluso bajo condiciones de energía intermitentes.

Diseñado para integrarse con plataformas telemáticas modernas, el ADM500 es compatible con Plaspy a través de protocolos telemáticos estándar e interfaces flexibles. Su extenso soporte de sensores — sensores de combustible cableados e inalámbricos, periféricos BLE, sondas de temperatura 1-Wire, dispositivos RS-485 y múltiples canales I/O — lo convierten en una opción versátil para gestión de flotas, sistemas anti-robos, transporte de temperatura controlada y aplicaciones avanzadas de telemetría.

## Aspectos clave

- Rastreador GPS compatible con Plaspy y GNSS de múltiples constelaciones para un seguimiento estable en tiempo real y una precisión de hasta 3 m en el 95% del tiempo de operación.
- LTE/GSM/GPRS/EDGE comunicación con dos ranuras nanoSIM para conectividad celular redundante y telemetría continua.
- Flexible ecosistema de sensores: admite sensores de combustible cableados/inalámbricos, hasta 5 sensores Bluetooth Low Energy, hasta 8 sondas DS18B20 y periféricos RS-485.
- Robustos sistemas anti-robos y de seguridad, que incluyen un acelerómetro de tres ejes y detección de interferencia de señal para alertas de manipulación.
- Batería integrada de 1000 mAh para varias horas de operación autónoma y almacenamiento a bordo para hasta 246,000 registros de ruta.
- Gestión remota vía actualizaciones OTA GPRS y actualizaciones de firmware por Bluetooth, además de configuración mediante herramientas para Windows/Android, SMS y comandos del servidor.
- Múltiples E/S para telemetría de vehículos: entrada de ignición, entradas analógicas y de pulso y salidas discretas de colector abierto adecuadas para control remoto y estrategias de inmovilización.

## Cómo funciona con Plaspy

El ADM500 se integra con Plaspy enviando paquetes estandarizados de ubicación y telemetría a través de redes celulares y soportando protocolos telemáticos comunes. Una vez conectado, Plaspy recibe coordenadas GPS en tiempo real, telemetría de sensores y mensajes basados en eventos para alimentar paneles, alertas e informes históricos. El diseño de doble SIM y la amplia memoria de ruta a bordo ayudan a mantener la continuidad de datos para la gestión de flotas y flujos de trabajo de seguridad.

- Actualizaciones de ubicación y telemetría en tiempo real \(GNSS + celular\) enviadas a Plaspy para mapeo y monitoreo en vivo.
- Estado de ignición y telemetría de entradas analógicas capturados para alimentar informes de comportamiento del conductor, tiempo de funcionamiento del motor y eventos.
- Soporte de monitorización de combustible mediante sensores cableados/inalámbricos y sensores de combustible RS-485 para análisis detallado del consumo y detección de recargas/desvíos de combustible.
- Inmovilizador/control remoto: salidas de colector abierto pueden usarse con flujos de trabajo de Plaspy para activar inmovilización o control remoto del dispositivo cuando sea compatible.
- Sensores Bluetooth y detección de beacons \(BLE\) para temperatura, humedad, inclinación, efecto Hall y etiquetas iBeacon/Eddystone en cola; todo reportado a Plaspy para el monitoreo del estado de los activos.

## Casos de uso

- Gestión de flotas: seguimiento en tiempo real continuo, historial de rutas y telemetría para camiones, furgonetas y flotas mixtas mediante los paneles de Plaspy.
- Antirrobo y seguridad del vehículo: detección de movimiento basada en acelerómetro, alertas de interferencia de señal y salidas de control remoto para apoyar acciones de inmovilización a través de Plaspy.
- Transporte con control de temperatura: sensores de temperatura BLE y sondas DS18B20 para monitoreo de carga refrigerada y alertas automáticas en Plaspy.
- Monitoreo de combustible y prevención de robo de combustible: soporte para múltiples sensores de combustible cableados/inalámbricos y dispositivos de combustible RS-485 para análisis detallado del consumo.
- Rastreo de activos estacionarios y monitoreo ambiental: operación con respaldo de batería y sensores BLE/1-Wire lo hacen apto para instalaciones semi-permanentes de activos.

## Por qué elegir este rastreador con Plaspy

El ADM500 NEW combina GNSS de múltiples constelaciones con alta precisión, amplia compatibilidad de sensores y comunicaciones celulares resilientes para entregar telemetría accionable para telemática comercial. Su compatibilidad con Plaspy garantiza una integración sencilla en los flujos de monitoreo existentes, permitiendo a los operadores aprovechar el rastreo en tiempo real, el monitoreo de combustible, eventos de encendido y datos de sensores BLE en una única plataforma. Las características de seguridad integradas, como la detección de interferencias y un acelerómetro, fortalecen los casos de uso anti-robo, mientras las actualizaciones de firmware OTA y por Bluetooth simplifican la gestión de dispositivos a gran escala. Para equipos de gestión de flotas y proveedores de telemática que buscan un rastreador GPS flexible y preparado para sensores que se empareje con Plaspy, el ADM500 ofrece una base confiable y configurable para el monitoreo y control avanzados de vehículos.
