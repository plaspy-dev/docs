# Neomatica - ADM100

![ADM100](./tracker.png)

El Neomatica ADM100 es un rastreador GPS compacto, compatible con Plaspy, diseñado para un monitoreo fiable de vehículos y un despliegue a gran escala sencillo. Con recepción GPS/GLONASS integrada y conectividad GSM, el ADM100 ofrece seguimiento en tiempo real preciso de la posición, la velocidad y la dirección — lo que lo convierte en una opción práctica para la gestión de flotas, telemetría y monitoreo anti-robo en vehículos ligeros, camiones y maquinaria especial.

El ADM100 combina un receptor GNSS de alta sensibilidad, almacenamiento no volátil de rutas para hasta 16.000 puntos, entradas analógicas y por pulso flexibles y una interfaz RS-485 para integrar equipos adicionales. Diseñado para funcionar con sistemas de alimentación vehicular estándar \(+8…+45 V\) y para reportar vía GPRS usando EGTS o direccionamiento por nombre de dominio, este dispositivo está optimizado para conectarse directamente a Plaspy para mapas en tiempo real, alertas y análisis de rutas históricas.

## Aspectos clave

- Rastreador GPS compatible con Plaspy para seguimiento en tiempo real y una integración simplificada de la gestión de flotas.
- Receptor GNSS de alta sensibilidad \(GPS/GLONASS\) con 132 canales de seguimiento para fijaciones rápidas y fiables en áreas con recepción difícil.
- GSM integrado \(GPRS Multi-slot Class 12\) para informes de datos continuos y actualizaciones de firmware remotas vía GPRS.
- Conjunto de E/S robusto: dos entradas analógicas, dos entradas de pulso y entradas discretas para señales de encendido o sensores y registro de eventos.
- Interfaz RS-485 para conectar dispositivos adicionales o módulos de telemetría; configuración flexible vía USB, SMS o GPRS.
- Memoria no volátil que almacena hasta 16.000 puntos de ruta para conservar los datos ante interrupciones en las comunicaciones.
- Amplio rango de tensión de alimentación \(+8…+45 V\) y formato compacto para una instalación fácil en diferentes tipos de vehículos.
- Seguridad y soporte: protección con contraseña para la terminal y la SIM, además de asistencia técnica del fabricante y garantía de dos años.

## Funcionamiento con Plaspy

Cuando se integra con Plaspy, el ADM100 transmite datos de posición y de eventos a la plataforma a través de canales GPRS estándar y protocolos admitidos. Plaspy ingiere telemetría en tiempo real y mensajes de eventos para proporcionar rastreo en tiempo real, alertas de geocerca, informes de recorrido y reproducción histórica. El almacenamiento local y la fiabilidad de los reportes del ADM100 lo hacen adecuado para el monitoreo continuo incluso cuando la cobertura de red es intermitente.

- Actualizaciones en tiempo real de ubicación y telemetría \(posición, velocidad y rumbo\) enviadas a Plaspy a través de GPRS.
- Carga de historial de rutas desde la memoria del dispositivo \(hasta 16.000 puntos\) para reproducción y generación de informes de cumplimiento.
- Las entradas analógicas y por pulso capturan datos de sensores \(pulsos de combustible, caudalímetros, estado de encendido\) para análisis de consumo y optimización.
- Las entradas discretas y el registro de eventos habilitan alertas anti‑robo e informes de estado de alarmas a Plaspy.
- La interfaz RS-485 admite la conexión a equipos de telemetría externos y sensores secundarios para obtener flujos de datos más ricos.
- Actualización de firmware remota vía GPRS mantiene las unidades desplegadas actualizadas sin visitas al sitio.

## Casos de uso

- Gestión de flotas: ubicación en tiempo real del vehículo, reproducción de rutas y monitoreo de velocidad para una asignación y despacho eficientes y generación de informes de cumplimiento.
- Anti-robo y recuperación: el registro de eventos de entradas discretas y alertas en tiempo real a Plaspy ayudan a detectar movimientos no autorizados y a respaldar flujos de recuperación.
- Telemetría y monitoreo de combustible: las entradas analógicas y de pulso capturan datos de sensores \(pulsos de combustible, caudalímetros, estado de encendido\) para análisis de consumo y optimización.
- Seguimiento de maquinaria especial: la recepción GNSS robusta y el amplio rango de tensión de alimentación hacen del ADM100 una solución adecuada para construcción, agricultura y equipos móviles.
- Sitios remotos y cobertura intermitente: el almacenamiento no volátil a bordo conserva los datos de rutas y eventos hasta restablecerse la conectividad con Plaspy.

## Por qué elegir este rastreador con Plaspy

El ADM100 está diseñado para organizaciones que necesitan un rastreador GPS duradero y de fácil despliegue que se integre de forma fiable con Plaspy para seguimiento en tiempo real y telemetría. Su GNSS de alta sensibilidad, su completo conjunto de E/S y la conectividad RS-485 permiten capturar señales del motor y de los sensores —útil para el registro de encendidos y el monitoreo de combustible—, mientras que los informes basados en GPRS y el soporte EGTS simplifican la integración con el backend. El almacenamiento de rutas no volátil y la capacidad de actualizar el firmware de forma remota reducen las visitas de mantenimiento y mejoran la disponibilidad para operaciones de flota. Respaldado por la documentación del fabricante, soporte técnico y una garantía de dos años, el ADM100 es una opción práctica para la monitorización de vehículos a escala y flujos de trabajo anti-robo cuando se usa con Plaspy.
