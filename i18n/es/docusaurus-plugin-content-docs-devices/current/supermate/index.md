# Supermate

Supermate es un fabricante de hardware de rastreo GPS empleado en aplicaciones de monitoreo de vehículos, activos y flotas. Muchos dispositivos Supermate son rastreadores en red que transmiten datos de ubicación, movimiento y estado a plataformas de seguimiento. Esta página explica cómo funcionan los dispositivos Supermate con Plaspy, qué esperar de estos equipos en general y cómo identificar modelos compatibles para su despliegue.

## Cómo funcionan los dispositivos Supermate con Plaspy

Plaspy acepta formatos de datos de seguimiento estándar y protocolos telemáticos comunes utilizados por muchos fabricantes. Los dispositivos Supermate que transmiten ubicación y telemetría mediante protocolos soportados pueden integrarse en Plaspy para ofrecer ubicación en tiempo real, historial, geocercas y alertas. La integración suele implicar configurar el equipo para enviar datos a Plaspy y verificar el informe del dispositivo en la interfaz. Para la configuración específica por modelo y las cadenas de parámetros, consulte las páginas de dispositivo que aparecen en el catálogo más abajo.

## Funciones comunes en dispositivos Supermate

Aunque las características varían según el modelo, muchos rastreadores Supermate comparten grupos de funciones útiles para usuarios de Plaspy:

- Reporte de posición GPS para seguimiento en tiempo real y historial
- Detección de movimiento e ignición para estado básico de la flota
- Informes de eventos como manipulación o entradas SOS
- Monitorización de batería y alimentación para visibilidad del tiempo operativo
- Intervalos de reporte configurables para equilibrar precisión y uso de datos
- Entradas y salidas básicas (I/O) para integración con sensores externos

Tenga en cuenta que las capacidades exactas difieren por modelo. Revise las páginas individuales de los dispositivos enlazadas desde el catálogo para listas de funciones precisas y las variantes de protocolo soportadas.

## Casos de uso típicos para rastreadores GPS Supermate

El hardware Supermate se emplea frecuentemente en escenarios como:

- Seguimiento de flotas de vehículos para reparto local o servicios
- Monitoreo de activos como remolques o equipos desmontables
- Historial a largo plazo y reproducción de rutas para revisión operativa
- Monitoreo remoto sencillo cuando la telemetría básica y las alertas son suficientes

Plaspy proporciona la plataforma para visualizar, alertar e informar sobre estos casos de uso una vez que el dispositivo esté conectado.
