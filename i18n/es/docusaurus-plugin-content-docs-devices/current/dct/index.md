# DCT

Los dispositivos DCT forman parte del ecosistema global de hardware GPS y telemática empleado para el rastreo de vehículos y activos. Esta página explica cómo los dispositivos DCT pueden integrarse con Plaspy, qué esperar del hardware DCT de forma general y cómo elegir el modelo DCT adecuado para sus necesidades de monitoreo. Use el catálogo de dispositivos más abajo para ver modelos compatibles y acceder a las páginas de cada dispositivo con detalles de configuración y protocolo.

## Cómo funcionan los dispositivos DCT con Plaspy

Plaspy recibe datos de ubicación y telemetría de numerosos rastreadores de terceros, incluidos los dispositivos DCT que envían posición e información de sensores a través de redes móviles. Cuando una unidad DCT se configura para reportar a Plaspy, el equipo envía posiciones GPS periódicas y mensajes de evento a los servidores de Plaspy, donde los datos se procesan, almacenan y muestran en las interfaces de Plaspy.

Para los pasos exactos de configuración consulte la página del dispositivo en el catálogo o la documentación del equipo DCT. Las páginas de dispositivo enlazadas desde el catálogo incluyen el protocolo y ejemplos de mensajes necesarios para completar la configuración. Si necesita ayuda, el soporte de Plaspy puede verificar los ajustes de configuración para los modelos DCT más comunes.

## Funciones habituales en los dispositivos DCT

Aunque las capacidades concretas varían según el modelo, el hardware DCT suele ofrecer las funciones que esperan los usuarios de telemática:
- Ubicación GPS en tiempo real e informes de posición periódicos
- Detección de movimiento y sensores de encendido o vibración
- Monitoreo de batería y detección de alimentación externa
- Entradas y salidas para alarmas y control remoto
- Soporte básico para geocercas y alertas de exceso de velocidad
- Conectividad celular para transmisión de datos

Estas características estándar hacen que los dispositivos DCT sean adecuados para muchos escenarios de rastreo y monitoreo cuando se integran con una plataforma como Plaspy.

## Casos de uso típicos para rastreadores GPS DCT

Los dispositivos DCT se emplean habitualmente para:
- Rastreo de vehículos de flota y supervisión de rutas
- Monitoreo de activos como remolques y equipos
- Recuperación ante robos y alertas de ubicación
- Supervisión de servicios de campo y entregas de última milla
- Informes básicos de comportamiento del conductor y utilización

Plaspy convierte la telemetría del dispositivo en información accionable con mapas, alertas e informes pensados para gerentes de flota y equipos operativos.

## Por qué elegir Plaspy para el monitoreo de dispositivos DCT

Plaspy está diseñado para funcionar con ecosistemas de hardware diversos y centralizar los datos de rastreo de múltiples marcas de dispositivos. Entre las ventajas al usar Plaspy con dispositivos DCT se incluyen:
- Un panel unificado para seguimiento en vivo y reproducción histórica
- Reglas de alertas y eventos basadas en los mensajes entrantes del dispositivo
- Herramientas de informes para utilización, kilometraje y resúmenes de actividad
- Un catálogo de dispositivos que enlaza cada modelo DCT con guías de configuración y protocolo
- Escalabilidad para flotas de cualquier tamaño y herramientas para gestionar acceso de equipos

Plaspy facilita la interoperabilidad del hardware para que usted pueda administrar dispositivos DCT junto a otros fabricantes desde una sola plataforma.

## Preguntas frecuentes

Q: ¿Qué dispositivos DCT son compatibles con Plaspy?
A: Los modelos DCT compatibles aparecen listados en el catálogo de dispositivos más arriba. El catálogo enlaza a la página de cada dispositivo donde encontrará el protocolo requerido y los detalles de configuración para conectar ese modelo a Plaspy.

Q: ¿Puedo usar rastreadores GPS DCT con Plaspy?
A: Sí. Muchos rastreadores DCT pueden enviar telemetría a Plaspy. Verifique la página específica del dispositivo en el catálogo para las instrucciones de configuración y confirme que el firmware y el formato de reporte del equipo coincidan con el protocolo esperado.

Q: ¿Plaspy admite monitoreo de flotas con dispositivos DCT?
A: Plaspy admite funciones de monitoreo de flotas como seguimiento en tiempo real, alertas, geocercas e informes para dispositivos que transmiten los datos de ubicación y eventos necesarios. Use las páginas de modelo DCT para confirmar la telemetría que proporciona cada equipo.

Q: ¿Dónde encuentro la documentación de los dispositivos DCT en Plaspy?
A: La documentación del dispositivo y las notas de configuración están disponibles en las páginas individuales de dispositivo del catálogo más arriba. Esas páginas incluyen el formato de protocolo y ejemplos de mensajes que puede usar para configurar el equipo y reportar a Plaspy.

Q: ¿Qué hago si mi dispositivo DCT necesita ajustes de APN o configuración de red?
A: Los ajustes de APN y red se configuran en el propio dispositivo o mediante las herramientas de gestión del SIM de su proveedor. Consulte la página del dispositivo para los ajustes recomendados y contacte al soporte de Plaspy si necesita ayuda para confirmar cómo interactúan esos ajustes con la configuración en Plaspy.
