# DCT - Funciones del Syrus 3G+ BT

Esta página describe el contexto público de funcionalidades para el uso del rastreador DCT Syrus 3G+ BT con Plaspy. Resume las capacidades del dispositivo en relación con el seguimiento en tiempo real, la integración de sensores y la conectividad en la nube a través de Plaspy, de modo que equipos de flota y telemetría puedan evaluar su idoneidad y valor operativo.

La disponibilidad exacta de funciones puede variar según la versión de firmware, la revisión de hardware, los accesorios instalados y la implementación del fabricante. La información que sigue se basa en la descripción del producto proporcionada por el fabricante y resalta funcionalidades comúnmente empleadas al integrar el Syrus 3G+ BT con Plaspy.

## Resumen de capacidades

El Syrus 3G+ BT es una pasarela telemática robusta diseñada para agregar ubicación y telemetría periférica en implementaciones vehiculares e industriales. Cuando se usa con Plaspy, actúa como un nodo flexible en el borde para recolectar datos de sensores Bluetooth, entradas de accesorios y opciones de continuidad para operaciones remotas.

- Bluetooth 4.1 Smart Ready para emparejar sensores y etiquetas de bajo consumo como el Syrus BTT-1634
- Múltiples puertos físicos para conectar periféricos de telemetría y entradas de estado
- Accesorio opcional de respaldo satelital Iridium para mantener conectividad fuera de cobertura celular
- APIs REST de Pegasus Gateway para integración con la nube y gestión abstracta del dispositivo
- Diseño resistente pensado para instalaciones vehiculares e industriales y operación fiable en campo
- Diseñado para reenviar flujos de ubicación y sensores para seguimiento y generación de reportes en tiempo real

## Características principales del DCT - Syrus 3G+ BT

- Soporte Bluetooth 4.1 Smart Ready para emparejar sensores de bajo consumo e integrar beacons
- Compatibilidad con la etiqueta multi-sensor Syrus BTT-1634 para ampliar la telemetría
- Múltiples puertos de accesorios para conectar sensores externos e interfaces de vehículo
- Soporte de accesorio Satcom Iridium opcional para respaldo satelital de mensajería
- APIs REST de Pegasus Gateway que simplifican la integración con la nube y la abstracción del dispositivo
- Diseño de pasarela telemática resistente, apto para entornos vehiculares e industriales
- Ecosistema modular de sensores que permite despliegues con múltiples periféricos externos

## Cómo funcionan estas funciones con Plaspy

Los dispositivos Syrus 3G+ BT pueden reenviar información de ubicación y sensores hacia Plaspy para que usted vea la posición del vehículo, su estado y la telemetría periférica en una plataforma unificada. Plaspy recibe los flujos de datos del dispositivo y los presenta como marcadores en el mapa, eventos y reportes para supervisión operativa.

- Actualizaciones de ubicación en tiempo real y recorridos históricos mostrados en las vistas de mapa y reportes de Plaspy
- Datos de sensores Bluetooth de etiquetas emparejadas que aparecen como canales de telemetría en los paneles de Plaspy
- Las entradas de los puertos de accesorios se reenvían a Plaspy como datos de estado o eventos cuando están configuradas e instaladas
- El respaldo satelital opcional conserva alertas y reportes de ubicación esenciales hacia Plaspy cuando la red celular no está disponible
- Las APIs REST de Pegasus Gateway permiten flujos de trabajo de configuración y gestión remota basados en API que integran con Plaspy
- Plaspy puede detectar e interpretar automáticamente protocolos de rastreadores compatibles para simplificar la incorporación

## Casos de uso típicos

- Seguimiento de flotas y visibilidad de rutas para operaciones vehiculares con datos combinados de ubicación y sensores
- Monitoreo antirrobo que combina ubicación del dispositivo y entradas de sensores externos con alertas configurables
- Supervisión de activos industriales empleando etiquetas Bluetooth para registrar condiciones ambientales o señales de manipulación
- Telemetría de combustible y estado cuando sensores externos están conectados a puertos de accesorios y los datos se envían a paneles de Plaspy
- Despliegues con conectividad híbrida que usan celular como transporte principal y satélite como respaldo para activos remotos
- Implementaciones rápidas donde las APIs de Pegasus Gateway reducen el tiempo de integración para el reenvío a la nube hacia Plaspy

## Notas sobre la disponibilidad de funciones

- El conjunto de funciones depende del firmware y la configuración del dispositivo; las actualizaciones de firmware pueden añadir o modificar comportamientos
- Las revisiones de hardware y los accesorios instalados afectan las interfaces disponibles y las opciones de telemetría
- Algunas capacidades de telemetría requieren sensores o etiquetas externas específicas que deben instalarse y configurarse
- El respaldo satelital requiere el accesorio Satcom Iridium opcional y las suscripciones de servicio necesarias
- Las opciones regionales de cobertura celular y satelital pueden variar; verifique disponibilidad para su región de despliegue

## Por qué usar Plaspy con estas funciones

Emplear el Syrus 3G+ BT junto con Plaspy centraliza la telemetría a nivel de dispositivo en una plataforma única para monitoreo, alertas e informes históricos. Plaspy traduce los flujos entrantes de ubicación y sensores en información operativa que ayuda a los equipos a gestionar rutas, recibir alertas relevantes y revisar la actividad de los dispositivos en flotas mixtas.

Para más información sobre Plaspy y cómo soporta soluciones de flota y telemetría, visite https://www.plaspy.com. Para detalles actualizados del dispositivo, incluyendo firmware, opciones de accesorios y guías de instalación, consulte la documentación del fabricante en https://www.digitalcomtech.com/ para verificar comportamiento y compatibilidad.
