# DCT - SYRUS OBDII-CAT1

![SYRUS OBDII-CAT1](./tracker.png)

El SYRUS OBDII-CAT1 es un dongle telemático OBDII plug-and-play de DCT Syrus, diseñado para vehículos particulares y de carga ligera. Pensado para ofrecer ubicación en tiempo real y diagnóstico del vehículo directamente desde el conector OBDII, el dispositivo facilita despliegues rápidos y la captura inmediata de datos para administradores de flota. Combina posicionamiento GNSS de alta sensibilidad con telemetría vehicular y detección de movimiento para cubrir las necesidades habituales de visibilidad operacional.

Como dispositivo compatible con Plaspy, el SYRUS OBDII-CAT1 se integra con la plataforma para visualización centralizada, alertas y flujos de trabajo basados en API. Su diseño preparado para la nube y con configuración automática permite incorporar dispositivos con rapidez y comenzar a usar Plaspy para seguimiento en vivo, notificaciones por eventos, reportes históricos y supervisión operativa sin instalaciones complejas.

## Características principales

- Instalación OBDII instantánea plug-and-play para despliegues de flota rápidos y tiempo mínimo de instalación.
- Posicionamiento GNSS de alta sensibilidad con soporte SBAS y rendimiento reportado de hasta 2 metros para ubicaciones precisas.
- Conectividad celular pentabanda para cobertura regional amplia y entrega confiable de telemetría.
- Amplia información de diagnóstico expuesta a través de la interfaz OBDII para monitoreo de motor y combustible.
- Acelerómetro integrado de 3 ejes para detectar frenadas bruscas, impactos y eventos de conducción.
- Gestión de dispositivos preparada para la nube y comportamiento autoconfigurable para simplificar despliegues a gran escala.
- Factor de forma optimizado para autos particulares y vehículos comerciales ligeros, facilitando su uso a escala de flota.

## Cómo funciona con Plaspy

Cuando se utiliza como dispositivo compatible con Plaspy, el SYRUS OBDII-CAT1 transmite ubicación, telemetría del vehículo y eventos de movimiento a Plaspy, donde esos datos se procesan para monitoreo en tiempo real, alertas e informes. Plaspy consolida la información entrante para que los operadores de flota utilicen una sola plataforma con visibilidad y flujos operativos integrados.

- Actualizaciones de ubicación en tiempo real y monitoreo de rutas para mantener visibilidad continua de la flota.
- Diagnósticos del vehículo en los paneles de Plaspy para monitoreo de consumo de combustible, tendencias del motor y chequeos de estado.
- Detección de eventos de conducción y alertas por impactos para apoyar programas de capacitación y seguridad vial.
- Registros de viajes y reproducción de rutas con informes históricos para analizar utilización y desempeño.
- Provisionamiento remoto y diagnóstico de dispositivos mediante gestión en la nube para agilizar soporte y mantenimiento.

## Casos de uso típicos

- Seguimiento en vivo de flotas de vehículos particulares y comerciales ligeros para mejorar rutas y utilización.
- Diagnósticos remotos del motor y planificación de mantenimiento preventivo usando telemetría OBDII para reducir tiempos de inactividad.
- Programas de monitoreo del comportamiento del conductor que aprovechan los eventos del acelerómetro para capacitación y mejora de la seguridad.
- Despliegues rápidos y de bajo costo donde la instalación plug-and-play acelera la distribución en grandes cantidades de vehículos.
- Detección y alertas antirrobo combinadas con monitoreo centralizado para una respuesta más rápida.
