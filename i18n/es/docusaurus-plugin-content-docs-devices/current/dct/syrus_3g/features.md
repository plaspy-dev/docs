# DCT - Características de Syrus 3G+

Esta página ofrece una visión pública de las funciones del DCT Syrus 3G+ y explica cómo sus capacidades se integran con Plaspy para el seguimiento de flotas y activos. Describe las características del equipo relevantes para despliegues con Plaspy, las integraciones para desarrolladores y los usos operativos habituales, sin sustituir la documentación del fabricante ni las guías formales de integración.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, la variante regional, el método de instalación y cómo el fabricante implemente funciones específicas. Para detalles técnicos concretos del equipo y las últimas actualizaciones de firmware o hojas de datos, consulte la documentación oficial de DCT y a su proveedor.

## Descripción general de funciones

El Syrus 3G+ está concebido como un concentrador telemático robusto y listo para API que entrega ubicación y telemetría a plataformas en la nube como Plaspy. Combina un diseño de carcasa resistente, operación de bajo consumo y una pila de integración orientada al desarrollador para soportar seguimiento en tiempo real, enriquecimiento de telemetría y flujos de trabajo automatizados.

- Soporte de Pegasus Gateway y API REST listo para acelerar la integración con la nube y la ingestión de datos.
- Puertos múltiples para sensores y accesorios que permiten recopilar telemetría más allá de las coordenadas GPS básicas.
- Carcasa sellada IP65 para instalaciones en exteriores y en vehículos en condiciones exigentes.
- Modo de reposo de ultra bajo consumo adecuado para despliegues con batería o remotos.
- Contadores y lógica de eventos integrados para monitoreo de rutas, generación de métricas y disparo de automatizaciones.
- Kit de desarrollo y plataforma de enablement orientados a facilitar el prototipado rápido y flujos M2M.

## Características principales del DCT - Syrus 3G+

- Preparado para Pegasus Gateway y API REST para integrarse con plataformas en la nube y Plaspy.
- Puertos para múltiples sensores y accesorios que permiten entradas externas y flujos de telemetría más ricos.
- Carcasa robusta con índice IP65 pensada para instalaciones en vehículos y activos exteriores.
- Capacidad de reposo de ultra bajo consumo optimizada para operación prolongada con batería.
- Contadores integrados y lógica orientada a eventos para métricas de flota y automatizaciones personalizables.
- Kit de desarrollo Syrus IoT y plataforma de enablement para respaldar flujos de trabajo de desarrolladores y diagnósticos.
- Soporte para conectividad multicarrier y acceso a servidores de diagnóstico a través de la plataforma de enablement.
- Diseñado para reporte de ubicación y telemetría en tiempo real, apto para ingestión por parte de Plaspy.

## Cómo funcionan estas funciones con Plaspy

Plaspy ingiere las corrientes de telemetría y ubicación del Syrus 3G+ y expone esos datos mediante mapas en vivo, reproducción histórica, alertas y paneles de control. El enfoque orientado a API del dispositivo y los recursos para desarrolladores facilitan la incorporación rápida de las cargas útiles de Syrus y la conversión de datos crudos en información operativa dentro de Plaspy.

- Actualizaciones de ubicación en tiempo real y reproducción histórica de posiciones visibles en los mapas e informes de Plaspy.
- Informes de eventos y métricas que muestran contadores, eventos de ruta y telemetría personalizada para paneles y alertas.
- Visualización de sensores en Plaspy basada en los datos de las entradas múltiples del Syrus para mostrar valores y estados de sensores externos.
- Soporte de integración para flujos de trabajo de seguridad y antirrobo coordinados mediante automatizaciones de Plaspy cuando se configuran cableados y acciones sobre el vehículo.
- Habilitación para desarrolladores vía Pegasus Gateway y API REST para mapear la telemetría de Syrus al modelo de datos de Plaspy y construir webhooks o parseos personalizados.
- Detección automática de protocolo en Plaspy que simplifica la incorporación inicial y la conectividad para muchas cargas útiles comunes de rastreadores.

## Casos de uso típicos

- Gestión de flotas con seguimiento GPS en tiempo real, monitoreo de rutas y métricas operativas.
- Flujos de trabajo de seguridad y antirrobo que generan eventos y respuestas remotas a través de los paneles de Plaspy.
- Recolección de telemetría de vehículo y motor donde los contadores y diagnósticos son necesarios para la planificación de mantenimiento.
- Integraciones IoT y M2M personalizadas usando el kit Syrus IoT y las APIs de Pegasus Gateway.
- Monitoreo de activos a largo plazo y seguimiento de equipos remotos aprovechando modos de reposo de bajo consumo.
- Prototipado rápido y despliegues orientados a desarrolladores que requieren dispositivos con enfoque API y soporte de diagnóstico.

## Notas sobre disponibilidad de funciones

- Los conjuntos de funciones y las configuraciones de E/S soportadas pueden diferir entre versiones de firmware y revisiones de hardware.
- Algunas capacidades dependen de cómo se instale el equipo y de qué sensores o cableados externos estén presentes en una implementación concreta.
- Las variantes celulares regionales y el soporte de operadores pueden afectar las opciones de conectividad y las funciones disponibles.
- Opciones inalámbricas adicionales como Bluetooth no están especificadas en esta descripción pública y deben confirmarse en la hoja de datos del dispositivo si se requieren.
- Verifique siempre con la documentación oficial del fabricante los pines de interfaz exactos, los tipos de accesorios compatibles y el comportamiento del firmware.

## Por qué usar Plaspy con estas funciones

Utilizar el Syrus 3G+ con Plaspy ofrece una vía práctica para combinar hardware telemático resistente y de bajo consumo con una plataforma en la nube que prioriza visibilidad, eventos y supervisión operativa. El enfoque API first del dispositivo y los recursos para desarrolladores reducen la carga de integración para que los equipos puedan centrarse en transformar la telemetría en información accionable mediante paneles y reglas de automatización.
