# DCT - Syrus 3G+

![Syrus 3G+](./tracker.png)

El Syrus 3G+ \(ITEM # SL3G-1645\) es un localizador GPS y hub telemático duradero, preparado para API, diseñado para un despliegue fiable y compatible con Plaspy en flotas y proyectos de IoT. Construido para conectar múltiples sensores y accesorios de forma simultánea, el Syrus 3G+ añade puertos adicionales y contadores inteligentes para entregar telemetría accionable para seguimiento en tiempo real, monitoreo de rutas, diagnósticos del motor y automatización personalizable—lo que lo convierte en una opción eficaz para la gestión de flotas, flujos de trabajo anti-robo y telemetría avanzada de vehículos.

Con una carcasa sellada IP65 y modo de reposo de consumo ultra bajo \(aproximadamente 1 mA\), el Syrus 3G+ admite instalaciones a largo plazo con respaldo de batería y uso en entornos adversos. Su Pegasus Gateway y su preparación para REST API, junto con el kit de desarrollo Syrus IoT y la plataforma de habilitación, aceleran la integración con Plaspy para ingestión rápida de datos, visualización y control remoto en vehículos y activos.

## Key Highlights

- Localizador GPS y hub telemático compatibles con Plaspy: listo para API para una rápida integración con Plaspy y plataformas en la nube.
- Soporte para múltiples sensores: múltiples puertos e integración de accesorios permiten telemetría enriquecida y entradas de sensores personalizadas.
- Carcasa resistente IP65: resistente al agua y al polvo para instalaciones fiables en exteriores y en vehículos.
- Modo de reposo de consumo ultrabajo \(≈1 mA\): optimizado para instalaciones con respaldo de batería y despliegues prolongados.
- Métricas y contadores avanzados: lógica integrada para la gestión de flotas, monitoreo de rutas y automatización basada en eventos.
- Plataforma para desarrolladores: Pegasus Gateway/REST APIs y el kit Syrus IoT para desarrollo rápido de M2M e IoT.
- Conectividad para múltiples operadores y diagnósticos: soporte para conectividad con varios operadores y acceso a servidores de diagnóstico mediante la plataforma de habilitación.

## How It Works with Plaspy

El Syrus 3G+ transmite datos de vehículos y sensores a Plaspy mediante APIs REST estándar y la capa de abstracción Pegasus Gateway. Una vez conectado, Plaspy ingiere la ubicación y la telemetría del dispositivo en tiempo casi real, habilitando mapas en vivo, alertas, informes y respuestas automatizadas. El diseño listo para API facilita mapear las cargas útiles de Syrus a los modelos de datos de Plaspy, de modo que los gestores de flotas y los desarrolladores puedan convertir rápidamente entradas en conocimientos útiles.

- Actualizaciones de ubicación y telemetría en tiempo real enviadas a Plaspy para seguimiento en vivo y reproducción histórica.
- Informes de eventos y métricas para el monitoreo de rutas, diagnósticos del motor y contadores personalizados expuestos en los tableros de Plaspy.
- Soporte para visualización de sensores: múltiples puertos de accesorios permiten a Plaspy mostrar valores y estados de sensores externos.
- Listo para integraciones en flujos anti-robo y acciones de inmovilización a través de tableros y reglas de automatización de Plaspy \(donde se haya configurado el cableado e interfaces del vehículo\).
- Acceso para desarrolladores: Pegasus Gateway/REST APIs y el kit Syrus IoT permiten análisis y procesamiento personalizados, webhooks y enriquecimiento de telemetría dentro de Plaspy.

## Use Cases

- Gestión de flotas y seguimiento en tiempo real: seguimiento GPS en vivo, cumplimiento de ruta y telemetría para flotas de vehículos comerciales.
- Flujos anti-robo y seguridad: alertas desencadenadas por eventos y acciones remotas coordinadas a través de los tableros y reglas de automatización de Plaspy.
- Diagnósticos del motor y telemetría: captura y transmisión de contadores de diagnóstico y métricas del motor a Plaspy para la programación de mantenimiento y análisis de fallos.
- Automatización personalizada e integraciones IoT: use el kit Syrus IoT y las APIs para crear disparadores, tableros personalizados y flujos M2M.
- Despliegues a largo plazo y activos remotos: modo de reposo de bajo consumo y protección IP65 para localizadores respaldados por batería y monitoreo de equipos al aire libre.

## Why Choose This Tracker with Plaspy

El Syrus 3G+ combina la durabilidad y el diseño de bajo consumo necesarios para despliegues en campo con una arquitectura orientada a la integración que acelera la adopción de Plaspy. Su modelo de hardware de múltiples puertos y sus contadores avanzados facilitan la recopilación de telemetría más allá de simples coordenadas GPS, soportando la gestión de flotas, flujos de monitoreo de combustible \(cuando se combina con sensores adecuados\), mantenimiento basado en telemetría y automatización anti-robo. Pegasus Gateway/REST APIs, el kit para desarrolladores y la plataforma de diagnósticos reducen la fricción de integración para que los equipos de desarrollo puedan lograr seguimiento en tiempo real, alertas de eventos y control remoto con un mínimo esfuerzo.

Para operadores de flotas y desarrolladores de IoT que buscan un localizador GPS compatible con Plaspy que combine robustez, eficiencia energética y APIs amigables para desarrolladores, el Syrus 3G+ está diseñado para acelerar el despliegue, al mismo tiempo que habilita telemetría escalable y funciones de seguridad en toda la flota de vehículos y activos. Para detalles exactos de interfaces, bandas celulares y opciones de Bluetooth, consulte la hoja de datos del Syrus 3G+ o a su proveedor para adaptar las variantes del dispositivo a sus requisitos de implementación de Plaspy.
