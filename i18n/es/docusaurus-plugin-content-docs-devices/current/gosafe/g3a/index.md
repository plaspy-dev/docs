# Gosafe - G3A

![G3A](./logo.jpg)

El rastreador GPS Gosafe G3A es un dispositivo compacto y de tamaño reducido que ofrece un rendimiento excepcional. Con su batería de reserva interna, este rastreador GPS es capaz de funcionar incluso en ausencia de energía externa, lo que garantiza un seguimiento constante y confiable de sus activos.

Una de las características destacadas del Gosafe G3A es su sistema de detección de atascos GSM, que le permite recibir notificaciones en tiempo real en caso de interferencias o bloqueos en la señal de GPS. Esto asegura que siempre esté informado sobre la ubicación de sus activos, incluso en situaciones adversas.

Además, el Gosafe G3A cuenta con múltiples entradas y salidas \(E/S\), lo que le brinda una mayor flexibilidad y capacidad de personalización. Puede configurar el dispositivo para que registre cambios de distancia, tiempo y eventos específicos, y también tiene la opción de elegir entre diferentes modos de E/S para adaptarse a sus necesidades.

Este rastreador GPS es extremadamente fácil de usar y se puede conectar con un micrófono y diferentes entradas analógicas para una mayor funcionalidad. Además, está equipado con un acelerómetro 2D interno, lo que le permite detectar movimientos y cambios de dirección con precisión.

En resumen, el Gosafe G3A es un rastreador GPS confiable y versátil que ofrece un rendimiento excepcional en un tamaño compacto. Ya sea que necesite realizar un seguimiento de vehículos, equipos o cualquier otro activo, este dispositivo le brindará la tranquilidad de saber siempre su ubicación exacta.

### Características destacadas:

- Batería de reserva interna para un funcionamiento continuo
- Sistema de detección de atascos GSM para notificaciones en tiempo real
- Múltiples entradas y salidas \(E/S\) para mayor flexibilidad
- Registro de cambios de distancia, tiempo y eventos
- Opciones de modos de E/S para adaptarse a sus necesidades
- Conexión con micrófono y entradas analógicas
- Acelerómetro 2D interno para detectar movimientos y cambios de dirección
