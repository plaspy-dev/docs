# Gosafe - CAN-9600

![CAN-9600](./logo.jpg)

El Gosafe CAN-9600 es un accesorio especializado de rastreo GPS diseñado para leer datos FMS de camiones y buses. Recibe la salida FMS de los sistemas del vehículo mediante protocolos CAN estándar y entrega esa información a través de una interfaz serial RS232 a dispositivos posteriores. La unidad está pensada para capturar información operativa del vehículo desde el puerto FMS y transmitirla por enlace serial para que pueda ser reenviada a un sistema de rastreo.

Como dispositivo compatible con Plaspy, el CAN-9600 permite incorporar datos FMS a la plataforma Plaspy junto con la ubicación y el contexto de la flota. Gosafe informa de integraciones entre el CAN-9600 y sus rastreadores GPS, lo que posibilita que la información FMS recopilada se retransmita a un servidor para acceso web. Para flotas que requieren datos del vehículo además del posicionamiento, el CAN-9600 ofrece un puente práctico para alimentar esa información en Plaspy para monitoreo y generación de informes.

## Aspectos principales

- Diseñado para leer datos FMS de camiones y buses para telemática de flotas
- Funciona con salidas FMS basadas en CAN estándar como J1939 y J1708
- Entrega los datos recopilados a una interfaz serial RS232 para dispositivos posteriores
- Pensado para integración sencilla con rastreadores GPS y sistemas de rastreo
- Conocido por interoperar con modelos de rastreadores Gosafe como G6S y G92I
- Permite enviar información FMS a un servidor para acceso centralizado

## Cómo funciona con Plaspy

Al conectarse a un rastreador GPS compatible o a una pasarela serial, el CAN-9600 reenvía la información FMS para que Plaspy la presente junto con la ubicación del vehículo y los viajes históricos. Esto permite a los administradores de flota ver los datos operativos en la misma plataforma utilizada para el seguimiento y la supervisión.

- Consolide la telemetría FMS con los datos de posición dentro de Plaspy para vistas unificadas de la flota
- Utilice los paneles y reportes de Plaspy para analizar tendencias operativas de los vehículos a lo largo del tiempo
- Combine la entrada FMS con el historial de ubicaciones para apoyar análisis de utilización y enrutamiento
- Active alertas o notificaciones en Plaspy basadas en umbrales de datos del vehículo
- Archive registros FMS en Plaspy para cumplimiento normativo y revisión operativa

## Casos de uso típicos

- Operadores de flota que recopilan datos FMS de camiones y buses para monitoreo centralizado
- Combinar datos operativos del vehículo con rastreo GPS para análisis de rendimiento
- Enviar información FMS a un servidor para informes y registro histórico
- Integración con rastreadores Gosafe existentes para ampliar la telemetría capturada de los vehículos
- Brindar a los gestores de flota mayor visibilidad del estado del vehículo junto con su ubicación

## Por qué elegir este rastreador con Plaspy

El CAN-9600 es una solución focalizada para flotas que necesitan extraer datos FMS de vehículos pesados y ponerlos a disposición de las plataformas de seguimiento. Su función es traducir la salida FMS del vehículo en un flujo serial que dispositivos GPS y servidores compatibles pueden consumir, por lo que resulta útil cuando se desea visibilidad FMS sin cambiar la infraestructura principal de rastreo.

En conjunto con Plaspy, el CAN-9600 ayuda a centralizar los datos operativos del vehículo en una sola plataforma para monitoreo, informes y supervisión operativa. Si su flota necesita información a nivel FMS además del posicionamiento, el CAN-9600 es un componente práctico a considerar junto con rastreadores y flujos de trabajo compatibles con Plaspy.
