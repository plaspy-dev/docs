# Gator - M588S

![M588S](./logo.jpg)

El rastreador GPS Gator M588S es un dispositivo de localización GPS que consta de un módulo GPS y un módulo GSM. El módulo GPS se utiliza para obtener datos de ubicación del satélite, mientras que el módulo GSM se encarga de transferir los datos al servidor para que puedan ser consultados a través de PC o teléfono móvil.

Este rastreador GPS es ideal para aplicaciones como el seguimiento de vehículos y la gestión de flotas. Puede utilizarse para el seguimiento de motocicletas, taxis, coches, autobuses y camiones.

El Gator M588S cuenta con una amplia gama de características destacadas, como la compatibilidad con las bandas GSM 850/900/1800/1900, un amplio rango de voltaje de entrada de 9-36vDC, posicionamiento GPS continuo, intervalo de tiempo GPRS, y la capacidad de ver la ubicación a través de SMS. También cuenta con un sensor de vibración incorporado para protección antirrobo, detección de ignición ACC, función de corte de tetera \(gasolina / electricidad\), tres números SOS, alarma SOS y antirrobo, función de monitor de voz, alarma de desconexión de la fuente de alimentación, configuración de Geo-fence desde la plataforma o vía comando SMS, reenvío de datos de la señal en zonas muertas, estadísticas de kilometraje y SMS para avisos de alarma.
