# Gator - M588T

![M588T](./logo.jpg)

El rastreador GPS Gator M588T es un dispositivo de localización GPS que consta de un módulo GPS y un módulo GSM. El módulo GPS se utiliza para obtener datos de ubicación del satélite, mientras que el módulo GSM se encarga de transferir los datos al servidor para que puedan ser consultados a través de PC o teléfono móvil.

Este rastreador GPS es ideal para aplicaciones como el seguimiento de vehículos y la gestión de flotas. Puede utilizarse para el seguimiento de motocicletas, taxis, coches, autobuses y camiones. Además, cuenta con una amplia gama de características que lo hacen muy versátil y funcional.

Algunas de las características destacadas del Gator M588T incluyen:

- Cuatro bandas GSM 850/900/1800/1900
- Amplio rango de voltaje de entrada: 9-36vDC
- Posicionamiento GPS continuo y intervalo de tiempo GPRS
- Visualización de ubicación a través de SMS
- Sensor de vibración incorporado, a prueba de robo
- Detección de ignición ACC
- Función de corte de tetera \(gasolina / electricidad\)
- Tres números SOS como máximo
- Alarma SOS y alarma antirrobo
- Función de monitor de voz
- Alarma cuando la fuente de alimentación se desconecta intencionalmente \(con batería de reserva\)
- Configuración de Geo-fence desde la plataforma o mediante comando SMS
- Reenvío de datos de señal muerta
- Estadísticas de kilometraje
- Notificación de alarma a través de SMS

Con todas estas características, el rastreador GPS Gator M588T es una excelente opción para aquellos que buscan un dispositivo confiable y versátil para el seguimiento y la gestión de vehículos.
