# CAREU - U1

![U1](./logo..png)

El CAREU U1 PLUS LTE es uno de los dispositivos más avanzados de esta serie. Cuenta con cobertura de red 4G \(LTE Cat 4/1/M1/NB1\) que incluye compatibilidad con 3G \(UMTS\) y 2G \(GSM\). El dispositivo está equipado con módulos GNSS y LTE, así como antenas internas GNSS y LTE. Puede venir con Bluetooth para fines de configuración. El CAREU U1 PLUS LTE está diseñado para comunicarse con varios accesorios de terceros RS-232 o RS-485 \(sensor de fatiga, cámara de tablero, lector RFID, etc.\). El rastreador tiene capacidad de lectura de datos OBDII y bus CAN \(J1939 o J1708\) desde la computadora de a bordo del vehículo. El rastreador también es excelente para el transporte refrigerado, ya que tiene un conjunto de entradas / salidas extendidas e interfaz 1-Wire® para monitoreo de temperatura. El CAREU U1 PLUS LTE Cat 4 tiene WiFi opcional para transmisión de video a través de nuestras cámaras, lo que también permite que el rastreador tenga un punto de acceso para que las personas accedan a Internet.

Las ventajas del producto incluyen un intérprete OBD II / CAN incorporado, detección de aceleración brusca / frenado brusco / detección de impacto / curvas bruscas / detección de vuelco \(acelerómetro de 6 ejes\), versión WiFi para transmisión de video y punto de acceso a Internet, detección de interferencia GSM \(solo para 2G/3G\), interfaz RS232 para accesorios \(sensor de fatiga, cámara de tablero, sensor de nivel de combustible, lector RFID, código de barras, etc.\).

Las características clave incluyen transmisión de datos a través de LTE / UMTS / HSPA / GPRS / EDGE, SMS, FTP, USSD, sistema eCall \(112\), soporte para 1-Wire® para control de temperatura e identificación del conductor a través de i-Button, GPS asistido \(Efemérides\), registro de hasta 200,000 registros de posición, acelerómetro de 6 ejes \(soporte para detección de aceleración brusca / frenado brusco / detección de impacto / curvas bruscas / detección de vuelco\), soporte para operación Garmin FMI 2.0, interfaz RS232 para accesorios \(sensor de fatiga, cámara de tablero, sensor de nivel de combustible, lector RFID, código de barras, etc.\), actualización de firmware FOTA a través de FTP, informe de geovalla en tipos circular y poligonal, lectura de datos del odómetro GPS y informes flexibles definidos por el usuario, alarma de bajo consumo / pérdida de energía, detección de interferencia GSM \(solo para 2G/3G\), alarma de detección de manipulación de la antena GPS.

Las características opcionales incluyen interfaz Bluetooth para configuración inalámbrica \(versión 4G\), comunicación WiFi \(con dongle WiFi externo / 3G\), comunicación WiFi \(módulo de punto de acceso interno / 4G Cat.4\), cifrado de datos AES-256, intérprete OBD / CAN incorporado, soporte de cámara DSC \(versión 3G/4G\), comunicación de voz bidireccional, soporte GPS / Glonass / BDS / Galileo, RS-485 para cámara y otros accesorios \(versión 3G/4G\).

Tenga en cuenta que las especificaciones pueden estar sujetas a cambios sin previo aviso.
