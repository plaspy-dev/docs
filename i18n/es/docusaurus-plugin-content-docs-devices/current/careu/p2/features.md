# CAREU - P2: Funciones

Esta página ofrece una visión pública de las funciones del rastreador personal GPS CAREU P2 y del contexto práctico para su uso con Plaspy. Se centra en las capacidades orientadas al usuario, los usos habituales del dispositivo y cómo esas capacidades se reflejan en Plaspy para proporcionar visibilidad y monitoreo.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, accesorios opcionales, el método de instalación y la implementación del fabricante. Para detalles técnicos específicos del dispositivo y las especificaciones más recientes, consulte la documentación del fabricante enlazada al final de esta página.

## Resumen de funciones

El CAREU P2 es un rastreador GPS personal compacto diseñado para ofrecer reportes de posición confiables y funciones de seguridad personal. Combina conectividad de red, reportes configurables y un conjunto de herramientas de seguridad para soportar escenarios de rastreo de personas y despliegues comerciales ligeros.

- Reportes continuos de posición con tasas de actualización configurables, incluyendo la capacidad de informar cada segundo para rastreo de alta precisión
- Comunicación de voz bidireccional con capacidad para realizar y recibir llamadas y almacenar hasta cuatro números de emergencia
- Alerta SOS y detección de caída/incapacitación para señalar situaciones urgentes
- Estación de carga opcional que soporta carga inalámbrica de batería y emparejamiento Bluetooth 4.1 para sincronización y gestión de energía
- Soporte de geocercas con límites circulares predefinidos y dinámicos y alertas automáticas cuando los dispositivos emparejados abandonan una zona segura

## Funciones principales del CAREU - P2

- Conectividad a redes 3G y 2G para cobertura amplia donde haya servicio celular disponible
- Alerta de emergencia SOS para notificación rápida de situaciones críticas
- Llamadas de voz bidireccionales y memoria para hasta cuatro números de contacto de emergencia
- Reportes configurables de alta frecuencia, con soporte para actualizaciones de posición cada segundo
- Alerta por caída/incapacitación (man down) con ajustes de sensibilidad configurables
- Acelerómetro de 3 ejes para detección de actividad y postura, usado por la lógica de man down
- GPS asistido y posicionamiento inteligente por multi-celda GSM para mejorar la fiabilidad de la localización
- Estación de carga opcional con carga inalámbrica, sincronización por Bluetooth y soporte para zonas seguras inteligentes

## Cómo funcionan estas funciones con Plaspy

Plaspy muestra la ubicación, eventos y alertas de los rastreadores compatibles para ofrecer supervisión operativa y contexto histórico. El CAREU P2 puede integrarse en Plaspy para que las actualizaciones de posición y los eventos de seguridad aparezcan junto con otros activos de flota o rastreo personal.

- Las actualizaciones de ubicación enviadas por el P2 se muestran en los mapas de Plaspy y pueden monitorearse casi en tiempo real cuando el dispositivo está configurado para reportar con frecuencia
- Los eventos SOS y de caída/incapacitación se tratan como alertas críticas en Plaspy para ayudar a los operadores a identificar y responder a emergencias
- Las salidas de geocerca desde zonas circulares predefinidas o dinámicas se registran como eventos en Plaspy para el monitoreo de límites y notificaciones
- Alertas de batería baja y otras notificaciones del dispositivo se presentan en Plaspy para ayudar a mantener la disponibilidad del equipo
- La capacidad de llamada bidireccional es una función gestionada por el dispositivo; Plaspy registra y muestra los eventos y alertas relacionados, pero las llamadas de voz se administran por el dispositivo y la red celular
- Plaspy detecta automáticamente los protocolos de rastreadores compatibles y puede aceptar reportes de dispositivos cuando el rastreador está configurado para enviar datos a los servidores de Plaspy

## Casos de uso típicos

- Monitoreo de adultos mayores para conocimiento de ubicación y alertas de emergencia
- Rastreo de seguridad infantil con opciones rápidas de SOS y llamadas bidireccionales
- Protección de trabajadores solitarios donde la detección de caída y el SOS mejoran la respuesta
- Flujos de trabajo de seguridad y patrullaje que requieren actualizaciones frecuentes de posición
- Escenarios de dispositivos emparejados a corta distancia que usan la Estación de Carga para gestión de batería y sincronización BLE
- Casos empresariales que requieren reportes consistentes hacia una plataforma centralizada de visibilidad

## Notas sobre disponibilidad de funciones

- Las versiones de firmware y software pueden cambiar el comportamiento de las funciones; no todas las funciones están garantizadas en cada versión de firmware
- Algunas funciones son opcionales y requieren la Estación de Carga u otros accesorios como adhesivos o fundas para carga inalámbrica
- Las revisiones de hardware y las variantes regionales pueden alterar el soporte de bandas de red o la compatibilidad de accesorios
- Las decisiones de instalación y configuración pueden afectar el comportamiento de las funciones, por ejemplo intervalos de reporte y ajustes de sensibilidad
- Verifique siempre la documentación del fabricante más reciente para obtener las especificaciones técnicas y el soporte de accesorios más actuales

## Por qué usar Plaspy con estas funciones

Usar Plaspy con dispositivos CAREU P2 integra las capacidades del rastreador individual en una plataforma única para visibilidad, alertas y supervisión operativa. Plaspy ayuda a las organizaciones a consolidar flujos de ubicación, ver eventos SOS y de geocerca junto a otros activos, y mantener un registro histórico de movimientos y alertas para apoyar decisiones de seguridad y operativas.

Para saber más sobre cómo Plaspy puede trabajar con dispositivos como el CAREU P2 visite https://www.plaspy.com. Para los detalles específicos más recientes, notas de firmware e información sobre accesorios, verifique las especificaciones con el fabricante en https://www.systech-iot.com/.
