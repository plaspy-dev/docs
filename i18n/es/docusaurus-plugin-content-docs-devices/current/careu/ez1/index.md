# CAREU - EZ1

![EZ1](./logo..png)

El CAREU EZ1 LTE es un rastreador GPS de ubicación automática de vehículos \(AVL\) pequeño y compacto diseñado para el seguimiento de vehículos y la gestión de flotas. Ofrece todas las características esenciales necesarias para un seguimiento y monitoreo eficientes. Con su diseño rentable y fácil instalación, el CAREU EZ1 es adecuado para una variedad de industrias, incluyendo logística, entrega, servicios públicos, alquiler de automóviles y financiamiento de vehículos.

El CAREU EZ1 viene en dos versiones. La versión avanzada admite LTE Cat 1 con red de retroceso 3G/2G, mientras que la segunda versión opera en 2G y cuenta con Bluetooth 3.0 para llamadas y configuración. Ambas versiones ofrecen compatibilidad con bandas globales, asegurando su uso en todo el mundo.

Las características clave del CAREU EZ1 incluyen la transmisión de datos a través de LTE/UMTS/HSPA/GPRS/EDGE, SMS, FTP y USSD. Admite los sistemas de satélite GPS y Glonass para una posición precisa. El acelerómetro de 3 ejes incorporado detecta aceleraciones bruscas, frenadas bruscas e impactos, proporcionando información valiosa sobre el comportamiento del conductor.

El CAREU EZ1 también admite 1-Wire® para el control de temperatura e identificación del conductor a través de i-Button. Cuenta con una interfaz RS232 para conectar accesorios como sensores de nivel de combustible, lectores RFID y códigos de barras. Además, admite la operación Garmin FMI 2.0 para capacidades mejoradas de gestión de flotas.

Otras características destacadas incluyen informes de geovalla en tipos circulares y poligonales, lectura de datos del odómetro, informes definidos por el usuario, actualizaciones de firmware FOTA a través de FTP, alarma de bajo voltaje/pérdida de energía y la capacidad de registrar hasta 200,000 registros de posición.

Las características opcionales incluyen una versión con antena GPS interna y configuración remota a través de Bluetooth para la versión LTE.

Tenga en cuenta que las especificaciones están sujetas a cambios sin previo aviso.
