# CAREU - U1 Lite+

![U1 Lite+](./logo..png)

El CAREU U1 Lite+ LTE es un rastreador altamente avanzado y rentable que ofrece una amplia gama de características y capacidades. Admite redes 4G \(LTE Cat 4 o Cat 1\) con retroceso a 3G \(UMTS\) y 2G \(GSM\), lo que garantiza una comunicación confiable y rápida. Además, también admite conectividad WiFi y acceso a Internet, lo que permite la transmisión de video a través de cámaras compatibles.

Una de las características destacadas del CAREU U1 Lite+ LTE es su compatibilidad con varios accesorios RS-232, como sensores de fatiga, cámaras de tablero, sensores de alcohol, lectores RFID y más. También cuenta con múltiples E/S digitales y analógicas y soporte 1-Wire®, lo que lo convierte en un rastreador versátil que se puede personalizar para satisfacer necesidades específicas de seguimiento y monitoreo.

El CAREU U1 Lite+ LTE está equipado con detección de interferencias para redes 2G, 3G y LTE, lo que lo hace particularmente útil para el transporte de mercancías de valor. También puede realizar tareas avanzadas como la lectura de datos del ordenador de a bordo CAN \(J1939 o J1708\) o datos OBDII, lo que permite una gestión eficiente de flotas y el monitoreo del comportamiento de conducción y el consumo de combustible.

La instalación del CAREU U1 Lite+ LTE es fácil y rentable. Admite comunicaciones de datos a través de LTE, UMTS, HSPA, GPRS, EDGE, SMS y FTP. También cuenta con soporte para el sistema de satélites GPS y Glonass, un acelerómetro de 3 ejes incorporado para detectar aceleraciones bruscas, frenadas bruscas, impactos y vuelcos. El rastreador también admite 1-Wire® para el control de temperatura e identificación del conductor a través de i-Button.

Otras características destacadas del CAREU U1 Lite+ LTE incluyen informes de geovalla, configuración remota, lectura de datos del odómetro, actualizaciones de firmware FOTA a través de FTP, alarma de bajo consumo o pérdida de energía, alarma de detección de manipulación de la antena GPS y la capacidad de registrar hasta 200,000 registros de posición.

Las características opcionales para el CAREU U1 Lite+ LTE incluyen comunicación de voz bidireccional, acelerómetro de 6 ejes incorporado para detectar curvas bruscas, interfaz Bluetooth para configuración inalámbrica, cables de extensión RS-232, cables de extensión de E/S, cable de interfaz RS-485, comunicación WiFi con módulo hotspot interno o 4G Cat.4, cifrado de datos AES-256 e intérprete OBDII o CAN \(J939 o J1708\) incorporado.

En general, el CAREU U1 Lite+ LTE es un rastreador altamente capaz y versátil que ofrece características avanzadas y opciones de personalización. Es adecuado para una amplia gama de aplicaciones de seguimiento y monitoreo, lo que lo convierte en una opción ideal para la gestión de flotas, el seguimiento de activos y más.
