# P88L Rastreador GNSS Portátil

El P88L es un rastreador GPS compacto, compatible con Plaspy, diseñado para la seguridad personal y el seguimiento familiar. Desarrollado para personas mayores, niños y trabajadores solitarios, combina posicionamiento de múltiples tecnologías \(GNSS, LBS, Wi‑Fi opcional y Bluetooth opcional\) con una interfaz simple de dos botones y un botón SOS dedicado para ofrecer seguimiento en tiempo real y alertas oportunas a través de la plataforma Plaspy.

Portátil y robusto, el P88L admite 4G LTE Cat 1 con compatibilidad hacia atrás con 3G y 2G, y variantes regionales para una cobertura celular amplia. Con carga magnética rápida, larga autonomía en modo de trabajo inteligente y memoria búfer offline, este dispositivo está diseñado para monitoreo continuo y una fácil integración con Plaspy para telemetría, alertas y un historial de ubicación seguro.

## Puntos clave

- Rastreador GPS compatible con Plaspy para seguimiento en tiempo real y alertas a través de redes celulares.
- Posicionamiento multienfoque: GNSS \(precisión típica ~2.5 m cuando está disponible\), LBS, con Wi‑Fi opcional y BLE para mejorar fijaciones en interiores o zonas densas.
- Botón SOS dedicado, alerta de caída y compatibilidad Bluetooth anti‑pérdida para una respuesta rápida ante incidentes y escenarios anti‑robo/anti‑pérdida.
- Hardware de larga duración: hasta 200 horas de espera en modo de trabajo inteligente y carga magnética rápida \(1800 mA, aprox. 1,5 horas para completar\).
- Diseño robusto con IP67 y amplio rango operativo \(‑10 °C a 65 °C\), adecuado para uso diario y al aire libre.
- Memoria búfer offline de 8 MB y actualizaciones OTA \(over‑the‑air\) para continuidad de datos fiable y mantenimiento remoto.
- Formato compacto y accesorios \(p. ej., funda protectora AGP101\) para un uso discreto y cómodo.

## Cómo funciona con Plaspy

Integrado con Plaspy, el P88L transmite la ubicación y telemetría básica a través de redes celulares para que cuidadores, equipos de seguridad y familias puedan ver la posición en tiempo real, recibir alertas y revisar el historial de desplazamientos. El posicionamiento de múltiples tecnologías del dispositivo alimenta a Plaspy con fijaciones GNSS cuando hay exterior y datos suplementarios LBS/Wi‑Fi/BLE cuando GNSS no está disponible, mejorando la continuidad del seguimiento. Las alertas como SOS y alerta de caída se envían a Plaspy en tiempo real para que los operadores puedan actuar con rapidez.

- Actualizaciones de ubicación y telemetría en tiempo real \(GNSS/LBS/Wi‑Fi/BLE según disponibilidad\) a paneles y APIs de Plaspy.
- Recepción de alertas SOS y de caída con ubicación con marca de tiempo y reproducción del historial para la revisión de incidentes.
- Conteo de pasos y telemetría de actividad básica para el monitoreo de bienestar y reporte contextual.
- Soporte Bluetooth anti‑pérdida: beacons BLE y sensores pueden complementar las alertas de Plaspy ante la separación cercana entre dispositivos.
- Buffer offline \(8 MB\) almacena datos durante interrupciones de cobertura y los envía a Plaspy cuando la conectividad se restablece; las actualizaciones OTA permiten mantenimiento remoto.

## Casos de uso

- Seguridad personal para personas mayores: detección de caídas \(alerta de caída\), alertas SOS y compartición de ubicación con cuidadores a través de Plaspy.
- Seguimiento de niños y monitoreo familiar: notificaciones de geocerca, alertas BLE anti‑pérdida y posición en tiempo real para los cuidadores.
- Monitoreo de trabajadores aislados: supervisión remota del personal en campo con SOS y telemetría de ubicación hacia Plaspy para una respuesta rápida.
- Seguimiento de eventos y personal temporal: formato compacto y alta autonomía lo hacen adecuado para despliegues de corta duración.
- Emparejamiento persona‑activo: usar BLE para vincular a las personas con activos o equipos pequeños, para alertas de proximidad y escenarios anti‑robo.

## Por qué elegir este rastreador con Plaspy

El P88L ofrece una solución enfocada y confiable para el rastreo personal que se integra de forma limpia con Plaspy para seguimiento en tiempo real, alertas e historial. Sus fortalezas son el posicionamiento multimodo, la larga duración de la batería con modo inteligente, su construcción robusta IP67 y una interfaz de usuario simple, lo que facilita una adopción rápida y su uso por parte de usuarios no técnicos. El soporte OTA y el buffering offline reducen la carga de mantenimiento y mejoran la continuidad de datos para paneles e informes de Plaspy.

Nota sobre el alcance: el P88L está diseñado para el rastreo centrado en las personas y telemetría de seguridad \(conteo de pasos, SOS, alerta de caída y BLE anti‑pérdida\). Para necesidades centradas en vehículos, como entradas de ignición, control de inmovilizador o monitoreo de combustible, normalmente se utilizan rastreadores de vehículos específicos; sin embargo, el P88L puede complementar los sistemas de gestión de flotas al rastrear conductores o pasajeros y reportar telemetría a nivel de persona junto con rastreadores GPS de vehículos dentro de Plaspy.
