# Meitrack - MT-80i

![MT-80i](./logo.jpg)

El rastreador GPS MT-80i de Meitrack es un mini perseguidor personal diseñado para brindar seguridad y tranquilidad a los usuarios. Este dispositivo es adecuado para una variedad de aplicaciones, como el seguimiento de niños, personas de edad avanzada, trabajadores solitarios, bienes y animales domésticos.

El MT-80i es compatible con la banda cuádruple 850/900/1800/1900 MHz, lo que garantiza una amplia cobertura y conectividad en diferentes regiones. Con un tamaño mini de solo 61x42x15mm y un peso de 50g, este rastreador es compacto y fácil de llevar. Además, cuenta con un clip para el cinturón, lo que facilita su sujeción a diferentes objetos.

Una de las ventajas del MT-80i es su bajo consumo de energía y largo tiempo de espera. Esto significa que el dispositivo puede funcionar durante largos períodos sin necesidad de recargarlo constantemente. Además, el rastreador ofrece seguimiento por SMS/GPRS, lo que permite a los usuarios obtener información en tiempo real sobre la ubicación de la persona o el objeto que están rastreando.

En resumen, el rastreador GPS MT-80i de Meitrack es una opción confiable y versátil para aquellos que buscan una solución de seguimiento personal. Con su tamaño compacto, conectividad confiable y características avanzadas, este dispositivo ofrece tranquilidad y seguridad en diversas situaciones.

### Características destacadas:

- Banda cuádruple 850/900/1800/1900 MHz para una amplia cobertura y conectividad.
- Tamaño mini \(61x42x15mm\) y peso de solo 50g para facilitar su transporte.
- Clip para el cinturón para una sujeción segura y conveniente.
- Bajo consumo de energía y largo tiempo de espera para un uso prolongado sin necesidad de recargar.
- Seguimiento por SMS/GPRS para obtener información en tiempo real sobre la ubicación.
