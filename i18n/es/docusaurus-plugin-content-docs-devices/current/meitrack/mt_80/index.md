# Meitrack - MT-80

![MT-80](./logo.jpg)

El rastreador GPS MT-80 de Meitrack es un dispositivo compacto diseñado para el seguimiento de individuos o pequeños bienes. Con una antena integrada, un acelerómetro y una batería recargable, el MT-80 es fácil de instalar en una variedad de bienes para una implementación sencilla. Además, también puede ser utilizado como un rastreador personal gracias a su botón de SOS programable y micrófono integrado.

El MT-80 es ideal para aquellos que desean mantener un seguimiento preciso de sus activos o para aquellos que buscan una solución de seguridad personal. Con su tamaño compacto y su fácil instalación, este rastreador GPS ofrece una gran versatilidad en su uso.

Características destacadas del rastreador GPS MT-80:

- Antena integrada para una mejor recepción de señal
- Acelerómetro para detectar movimientos y cambios de dirección
- Batería recargable para un uso prolongado sin necesidad de alimentación externa
- Botón de SOS programable para situaciones de emergencia
- Micrófono integrado para escuchar el entorno en tiempo real
