# Meitrack - MT-90

![MT-90](./logo.jpg)

El rastreador GPS personal MT-90 de Meitrack es una solución ultra portátil para el seguimiento de personas y objetos. Diseñado para el seguimiento de ancianos, niños, pacientes, animales domésticos y trabajadores individuales, este dispositivo compacto se puede colocar fácilmente en un bolsillo, bolso o alrededor del cuello. En caso de una emergencia, el MT-90 cuenta con una función de alarma SOS que se activa simplemente pulsando el botón correspondiente.

El MT-90 cuenta con una serie de características destacadas que lo convierten en una opción confiable para el seguimiento personal. Este rastreador GPS utiliza tecnología GPS y cuádruple banda GSM \(850/900/1800/1900 MHz\) para una precisión y cobertura óptimas. Con un tamaño pequeño de 77x47x20mm y un peso ligero de 65g, es fácil de llevar y no resulta incómodo para el usuario.

Además, el MT-90 es resistente al agua con una clasificación IP66, lo que significa que puede soportar salpicaduras y condiciones climáticas adversas. Con un bajo consumo de energía y un largo tiempo de espera de hasta 16 horas de trabajo y 60 horas en modo de ahorro de energía, este rastreador GPS es confiable y duradero.

Otras características notables del MT-90 incluyen un módulo GPS y GSM base de doble posición, seguimiento por SMS/GPRS, un sensor de movimiento incorporado, una batería incorporada, alarma de batería baja y alarma de exceso de velocidad. Estas características hacen del MT-90 una opción versátil y confiable para el seguimiento personal en una variedad de situaciones.
