# Meitrack - GT-30X

![GT-30X](./logo.jpg)

El GT30X es un dispositivo de seguimiento personal GPS/GPRS de la marca Meitrack. Este rastreador es compacto y fácil de usar, ideal para controlar personas o animales domésticos. Cuenta con un módulo GPS incorporado que proporciona datos de posición precisos, y utiliza la capacidad GSM para enviar estos datos a un teléfono móvil o a un servidor específico, permitiendo a los usuarios tener un control total sobre el rastreador.

El GT30X ofrece comunicaciones de voz bidireccionales, lo que significa que tanto el guardián como el titular del rastreador pueden activar llamadas al dispositivo. Además, cuenta con un botón SOS que puede ser activado por el titular del rastreador en caso de emergencia. El rastreador puede ser configurado para reportar su ubicación a intervalos preestablecidos a un servidor o a un teléfono móvil. También cuenta con memoria interna para almacenar coordenadas.

Características destacadas del GT30X:

- Seguimiento por SMS/GPRS
- Seguimiento en el teléfono móvil
- Audio bidireccional \(auricular\)
- Escuchar-en \(Monitoreo de voz\)
- Memoria interna para el registro
- Sensor de batería incorporada
- Botón SOS
- Alarma de baja batería
- Alarma de exceso de velocidad
- 3 botones para llamadas telefónicas y envío de SMS
