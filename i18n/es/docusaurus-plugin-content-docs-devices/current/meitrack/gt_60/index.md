# Meitrack - GT-60

![GT-60](./logo.jpg)

El rastreador GPS Meitrack GT-60 es un dispositivo compacto y fácil de usar diseñado para el seguimiento de mascotas y personas. Con su módulo GPS incorporado, este rastreador proporciona datos de posición precisos que se pueden enviar a un teléfono móvil o a un servidor de base a través de la capacidad de GSM. Esto permite a los usuarios monitorear y rastrear a sus mascotas o personas utilizando el rastreador.

Además de su función de seguimiento, el GT-60 también se puede utilizar como un teléfono celular de emergencia. Con la capacidad de marcar rápidamente hasta 3 números, este dispositivo permite la comunicación de voz bidireccional para situaciones de emergencia. Su tamaño compacto, alta precisión y facilidad de uso hacen del GT-60 una excelente opción como dispositivo de localización personal.

Características destacadas:

- Seguimiento de mascotas y personas
- Módulo GPS para datos de posición precisos
- Capacidad de GSM para enviar datos de posición
- Función de teléfono celular de emergencia
- Comunicación de voz bidireccional
- Tamaño compacto y fácil de usar
