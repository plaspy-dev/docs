# Suntech - ST 300K

![ST 300K](./logo.jpg)

El rastreador GPS Suntech ST300K es parte de la línea de productos de alta gama de Suntech. Este dispositivo cuenta con una interfaz RS232 y CANbus, lo que le permite una fácil conexión con otros dispositivos y sistemas. Además, el ST300K también está equipado con una entrada 1-Wire, lo que le permite conectar hasta 3 sensores de temperatura o utilizar i-Button para identificar al conductor y restringir el uso del vehículo.

Con el ST300K, podrá aprovechar al máximo las funciones avanzadas de generación de informes. Podrá crear perfiles de conducción, horarios de trabajo y reportes de mantenimiento para reducir el desgaste de su flota. Además, este dispositivo cuenta con una entrada analógica configurable y entradas y salidas digitales, lo que le permite realizar funciones como la inmovilización del motor, la detección de emergencias mediante el botón de pánico y recibir alertas de arrastre de grúa, colisiones y golpes gracias a su sensor de movimiento de 3 ejes.

Características destacadas del Suntech ST300K:

- Interfaz RS232 y CANbus para una fácil conexión con otros dispositivos y sistemas.
- Entrada 1-Wire para conectar hasta 3 sensores de temperatura o utilizar i-Button para identificar al conductor.
- Funciones avanzadas de generación de informes, como perfiles de conducción, horarios de trabajo y reportes de mantenimiento.
- Entrada analógica configurable y entradas y salidas digitales para realizar funciones como la inmovilización del motor y la detección de emergencias.
- Sensor de movimiento de 3 ejes para recibir alertas de arrastre de grúa, colisiones y golpes.
