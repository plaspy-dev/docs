# Suntech - ST 300V

![ST 300V](./logo.jpg)

El Suntech ST300V es un rastreador GPS de localización que ofrece una comunicación directa con el conductor sin necesidad de estar en la cabina. Este dispositivo cuenta con la capacidad de extraer informes y puede ser utilizado en vehículos con interfaz OBDII y 1-Wire norma J1939, lo que permite una identificación del conductor.

La localización del ST300V se puede realizar a través de una plataforma de gestión de seguimiento desde la web o mediante el envío de SMS que proporciona la ubicación actual del dispositivo junto con un enlace a Google Maps.

El Suntech ST300V cuenta con una serie de características técnicas destacadas, entre las cuales se incluyen:

- Banda GSM cuatribanda completa
- Funcionalidad de voz
- Batería de respaldo
- Memoria interna
- Métodos de comunicación GPRS, TCP y UDP
- Posicionamiento por tiempo, distancia y cambio de ángulo
- Ahorro de energía
- Entradas digitales y analógicas
- Eventos internos basados en configuraciones predefinidas
- Antenas GPS y GSM internas
- Carcasa de plástico
- Conexiones extras para antenas fijas, micrófono/altavoz, sensores de combustible y temperatura, identificación del conductor, puerto serie
- Compatibilidad con Can Bus J1939 y OBDII
- Hecho en Corea del Sur

El Suntech ST300V es ideal para aplicaciones de seguimiento y recuperación de vehículos, gestión de flotas, sistemas de navegación inteligentes y mensajes bidireccionales con los conductores. Su diseño y funcionalidades lo convierten en una opción confiable y versátil para cualquier necesidad de rastreo GPS.
