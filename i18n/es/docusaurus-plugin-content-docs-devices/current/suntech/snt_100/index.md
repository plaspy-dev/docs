# Suntech - SNT 100

![SNT 100](./logo.jpg)

El rastreador GPS Suntech SNT 100 es una terminal de datos diseñada para facilitar la interacción entre el conductor de un vehículo y la central de monitoreo. Con este dispositivo, es posible enviar y recibir mensajes de doble vía, así como acceder a funciones avanzadas como el bloqueo/desbloqueo del motor, el monitoreo de geocercas y el análisis del patrón de manejo del conductor.

Es importante destacar que la terminal de datos SNT 100 es compatible únicamente con los equipos de rastreo ST300R y ST300H de Suntech. Esto garantiza una integración perfecta y un rendimiento óptimo al utilizar estos dispositivos en conjunto.

Características destacadas del rastreador GPS Suntech SNT 100:

- Envío y recepción de mensajes de doble vía.
- Bloqueo/desbloqueo del motor.
- Monitoreo de geocercas.
- Análisis del patrón de manejo del conductor.
- Compatible con los equipos de rastreo ST300R y ST300H de Suntech.
