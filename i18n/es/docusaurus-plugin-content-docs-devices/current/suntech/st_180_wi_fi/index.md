# Suntech - ST 180 Wi-FI

![ST 180 Wi-FI](./logo.jpg)

El rastreador GPS Suntech ST180 es una excelente opción para aquellos que buscan un dispositivo confiable y eficiente para el seguimiento de vehículos. Este rastreador GPS cuenta con una memoria interna que almacena las posiciones y las descarga cuando se conecta a una red Wi-Fi accesible. Una de las características más destacadas del ST180 es su capacidad para conectarse a los CAN-Bus de vehículos con estándar J1939, FMS y OBDII. Esto permite obtener información valiosa sobre el rendimiento y el estado del vehículo, lo que resulta especialmente útil para la gestión de flotas.

Además, el ST180 no utiliza la red GSM para la comunicación, lo que ayuda a reducir los costos de operación desde el momento de la instalación. Este rastreador GPS también ofrece otras características como ahorro de energía, entradas digitales, eventos internos, antenas GPS y Wi-Fi internas, carcasa de plástico resistente y conexiones extras como puerto USB y ranura MicroSD.

En resumen, el rastreador GPS Suntech ST180 es una opción confiable y versátil para el seguimiento de vehículos. Su capacidad para conectarse a los CAN-Bus de vehículos y su uso eficiente de la red Wi-Fi lo convierten en una herramienta valiosa para la gestión de flotas y sistemas de navegación inteligentes.

### Características destacadas:

- Memoria interna para almacenamiento de posiciones
- Conexión a los CAN-Bus de vehículos con estándar J1939, FMS y OBDII
- No utiliza la red GSM para la comunicación, lo que reduce los costos de operación
- Ahorro de energía
- Entradas digitales
- Eventos internos
- Antenas GPS y Wi-Fi internas
- Carcasa de plástico resistente
- Conexiones extras: puerto USB y ranura MicroSD
