# Suntech - ST 910

![ST 910](./logo.jpg)

El rastreador GPS independiente Suntech ST910 es ideal para el seguimiento de activos móviles. Cuenta con una batería recargable de polímero de litio de 800 mAh que le permite funcionar de manera autónoma durante largos períodos de tiempo. Además, tiene una memoria interna que puede almacenar hasta 1000 eventos.

Con el Suntech ST910, puede localizar de forma segura sus activos móviles y recibir alertas a través del botón de pánico, que envía la ubicación actual del GPS a través de SMS o servicio de localización GPS a través de la web. Esto le brinda tranquilidad y le permite tomar medidas rápidas en caso de emergencia.

El Suntech ST910 es compatible con cuatribanda completa GSM y utiliza los métodos de comunicación GPRS, TCP y UDP para transmitir datos de ubicación de manera eficiente. También cuenta con funciones de ahorro de energía y entradas predefinidas para el botón de pánico, lo que lo hace aún más versátil y fácil de usar.

Este rastreador GPS tiene una carcasa de plástico resistente y viene con una antena GPS interna y una antena GSM interna. También cuenta con una conexión adicional a través de un puerto mini USB. El Suntech ST910 es fabricado en Corea del Sur, lo que garantiza su calidad y confiabilidad.

### Características destacadas:

- Batería recargable de polímero de litio de 800 mAh
- Memoria interna para almacenar hasta 1000 eventos
- Botón de pánico con envío de ubicación actual a través de SMS o servicio de localización GPS
- Compatible con cuatribanda completa GSM
- Métodos de comunicación GPRS, TCP y UDP
- Funciones de ahorro de energía
- Entradas predefinidas para el botón de pánico
- Carcasa resistente de plástico
- Antena GPS interna y antena GSM interna
- Conexión adicional a través de puerto mini USB
