# Box - Box Tracker

![Box Tracker](./logo.jpg)

El rastreador GPS BOX Tracker de la marca Box es un dispositivo de localización de vehículos diseñado específicamente para integradores de sistemas de terceros. A pesar de ser uno de los rastreadores más pequeños del mercado, ofrece todas las características necesarias para una integración sin problemas en los sistemas existentes con un esfuerzo mínimo.

El principal propósito del BOX Tracker es registrar los movimientos del vehículo utilizando la última tecnología GPS. A diferencia de otros rastreadores, este dispositivo es capaz de funcionar en áreas y espacios cerrados donde otros rastreadores no son adecuados. Además, se destaca por su velocidad en la obtención de la comunicación satelital inicial, lo que garantiza una ubicación precisa desde el inicio.

Características destacadas del rastreador GPS BOX Tracker:

- Mercado objetivo: Track & Trace, recuperación de vehículos, gestión de flotas
- Banda GSM: cuatribanda completa
- Voz: No
- Realizar copias de seguridad de la batería: Sí
- Memoria interna: Sí
- Método de comunicación: GSM, GPRS, TCP, UDP
- Posición por: Tiempo, Distancia
- Ahorro de energía: Sí
- Entradas digitales: 2
- Entradas analógicas: 1
- Antenas: GPS, GSM
- Carcasa: Plástico
- Conexiones extras: Antenas Fix
- Hecho en: Europa
