# Box

Box fabrica dispositivos de rastreo GPS compactos que se usan para el monitoreo de vehículos y activos. Esta página describe cómo funcionan los dispositivos Box con Plaspy, qué esperar de los rastreadores Box en términos generales y cómo empezar a usar dispositivos Box con la plataforma Plaspy. El catálogo de dispositivos que aparece más abajo muestra todos los modelos Box que se sabe son compatibles con Plaspy para que pueda ir rápidamente a la página del dispositivo que coincida con su hardware.

## Visión general: Box y rastreo GPS

Los dispositivos Box están diseñados para reportar ubicación y telemetría en escenarios de transporte y gestión de activos. Al integrarse con una plataforma de rastreo como Plaspy, los equipos Box proporcionan actualizaciones continuas de posición, alertas de movimiento y telemetría básica que ayudan a las flotas y a los propietarios de activos a supervisar operaciones de forma remota. Esta página se centra en la compatibilidad con Plaspy y le ayuda a encontrar el dispositivo Box adecuado según sus necesidades.

## Cómo funcionan los dispositivos Box con Plaspy

Los dispositivos Box envían información de ubicación y estado que Plaspy recibe y muestra en la plataforma. Para conectar un dispositivo Box a Plaspy, por lo general debe:

- Verificar la compatibilidad en el Catálogo de Marcas y seleccionar la familia de dispositivos que corresponda a su unidad.
- Configurar el dispositivo mediante su menú o herramienta de configuración para que reporte a Plaspy según las instrucciones del fabricante.
- Registrar el dispositivo en Plaspy usando su identificador único para que la plataforma pueda asociar los datos entrantes con su cuenta.

Plaspy acepta datos de una amplia variedad de rastreadores y ofrece un punto centralizado para ver historial de ubicaciones, posición en tiempo real, alertas y telemetría básica. Para pasos específicos de configuración del dispositivo, consulte las páginas individuales de cada modelo enlazadas en el catálogo. Evite modificar ajustes del equipo si no está familiarizado con la interfaz de configuración del dispositivo.

## Funciones comunes en los dispositivos Box

Aunque las capacidades varían según el modelo, los rastreadores Box normalmente incluyen funciones utilizadas para el monitoreo de activos y vehículos:

- Ubicación GPS y reportes de posición con sello de tiempo
- Detección de movimiento para reportes basados en desplazamiento
- Estado de batería o alimentación para unidades portátiles o cableadas
- Generación de eventos básicos por encendido o cambios en entradas
- Intervalos de reporte configurables y modos de ahorro de energía

El conjunto exacto de funciones depende del modelo. Use el catálogo superior para ver los modelos Box compatibles con Plaspy y consulte la documentación del dispositivo para especificaciones detalladas.

## Casos de uso típicos

Los rastreadores Box se utilizan en diversas situaciones donde es importante un reporte de ubicación compacto y confiable:

- Seguimiento de vehículos de flota para monitoreo de rutas y despacho
- Rastreo de activos como remolques, contenedores y equipos
- Casos de seguridad que requieren alertas basadas en ubicación
- Monitoreo de equipos en alquiler o compartidos para registrar uso y ubicación

Al combinar los dispositivos Box con Plaspy, las organizaciones pueden visualizar la ubicación de activos, crear geocercas, recibir alertas y generar reportes básicos para operaciones y cumplimiento.

## Por qué elegir Plaspy para monitorear dispositivos Box

Plaspy ofrece una interfaz consistente para gestionar y supervisar dispositivos de muchos fabricantes, incluido Box. Beneficios clave al usar rastreadores Box con Plaspy:

- Gestión centralizada de dispositivos y vistas de ubicación en tiempo real
- Alertas y notificaciones unificadas en una sola plataforma
- Herramientas de historial e informes para analizar trayectos y uso
- Incorporación sencilla mediante páginas del catálogo y guías por modelo

Plaspy está diseñado para trabajar con diversas marcas de rastreadores, por lo que puede estandarizar los flujos de monitoreo en flotas con hardware mixto. Para obtener más información sobre la plataforma Plaspy visite https://www.plaspy.com.
