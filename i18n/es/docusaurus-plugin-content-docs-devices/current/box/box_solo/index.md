# Box - Box Solo

![Box Solo](./logo.jpg)

El rastreador GPS Box Solo es una unidad de seguimiento diseñada específicamente para remolques. Utiliza receptores GPS de alta sensibilidad y tecnología GSM/GPRS de cuatro bandas para registrar continuamente la posición del remolque y transmitir los datos al sitio web de Box para su colección y análisis. 

Este rastreador ha sido aprobado por la Agencia de Certificación de Vehículos \(AVC\) y cuenta con las certificaciones EMC/FCC/UL para su uso en los mercados de Estados Unidos. Utiliza las bandas de frecuencia de 850 y 1900MHz para la comunicación GSM/GPRS. 

La instalación del Box Solo es sencilla y solo requiere la conexión de tres cables a los terminales positivo, negativo y APC del remolque \(normalmente ubicados dentro del conector Suzzie\). 

Características destacadas del rastreador GPS Box Solo incluyen: 

- Banda GSM cuatribanda completa 
- No cuenta con función de voz 
- Batería de respaldo 
- Memoria interna 
- Comunicación a través de GSM, GPRS, TCP y UDP 
- Posicionamiento por tiempo, distancia y cambio de ángulo 
- Función de ahorro de energía 
- 2 entradas digitales 
- 1 entrada analógica 
- Antenas GPS y GSM 
- Carcasa de plástico 
- Conexiones extras para antenas fijas 
- No cuenta con soporte para Can Bus 
- Hecho en Europa 

El rastreador GPS Box Solo es ideal para aplicaciones de seguimiento y recuperación de remolques, así como para la gestión de flotas. Su diseño robusto y su fácil instalación lo convierten en una opción confiable para mantener un control preciso sobre la ubicación de los remolques en todo momento.
