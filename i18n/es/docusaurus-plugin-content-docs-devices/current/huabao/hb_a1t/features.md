# Huabao - HB-A1T — Características

Esta página ofrece una visión pública de las funciones del rastreador Huabao HB A1T y de cómo sus capacidades se aprovechan en Plaspy para la gestión de flotas y activos. Describe las funciones prácticas y no sensibles del dispositivo relacionadas con posicionamiento, telemetría, alarmas y sensorización ambiental dentro de flujos de trabajo gestionados por Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, los módulos opcionales y la forma de instalación. Para especificaciones finales y detalles técnicos actualizados consulte la documentación del fabricante y los avisos de cambios de producto.

## Resumen de características

El HB A1T es un rastreador GPS robusto pensado para remolques y activos en exteriores que requieren resistencia a la intemperie, larga autonomía en espera y opciones flexibles de sensores. Su enfoque principal es la fiabilidad en el reporte de posición, detección básica de sabotaje y soporte para sensores externos, de modo que los operadores mantengan visibilidad de los activos aun en despliegues remotos.

- Posicionamiento GNSS en tiempo real usando GPS y BeiDou para localización precisa
- Conectividad celular 4G con opciones regionales de módulo para reportes continuos
- Carcasa resistente IP65 diseñada para montaje en remolques, contenedores y cubiertas
- Batería interna de gran capacidad con larga autonomía en espera para periodos de almacenamiento o tránsito
- Detección de manipulación integrada y salida de relé cableada para control remoto de alimentación o inmovilizador
- Soporte Bluetooth 5.0 para sensores externos de temperatura y humedad y módulo LoRa opcional para redes de sensores de mayor alcance

## Características principales del Huabao - HB-A1T

- Posicionamiento GNSS dual con GPS y BeiDou para mejor cobertura satelital
- Datos celulares 4G para seguimiento en tiempo real, con soporte regional para módulos de generación inferior cuando corresponda
- Carcasa con clasificación IP65 que protege contra agua y polvo en uso exterior
- Batería interna de gran capacidad y opción de baterías de mayor capacidad para operación en espera extendida
- Detección de manipulación por efecto Hall para alertas de desmontaje y monitoreo antirrobo
- Salida de relé cableada para soportar corte remoto de energía o acciones tipo inmovilizador
- Bluetooth 5.0 para integración de sensores de temperatura y humedad, y LoRa opcional para redes de sensores alternativas
- Bus CAN además de múltiples entradas analógicas y digitales para telemetría e integración de señales del vehículo

## Cómo funcionan estas características con Plaspy

Cuando se despliega con Plaspy, el HB A1T informa ubicación, estado y entradas de sensores para proporcionar una vista operativa unificada. Plaspy ingiere la posición y la telemetría del dispositivo, muestra alertas y mantiene un historial para reportes y revisión de incidentes.

- Actualizaciones de ubicación en tiempo real y registros históricos de viajes visibles en los paneles de Plaspy
- Alertas por manipulación y notificaciones de geocercas enviadas a Plaspy para flujos de trabajo antirrobo
- Reportes de batería y batería baja para ayudar a mantener visibilidad continua de los activos
- Datos de sensores Bluetooth o de módulos LoRa opcionales disponibles para monitoreo ambiental
- Comandos remotos de relé iniciados desde Plaspy que pueden cortar alimentación o activar otras acciones cableadas cuando el dispositivo lo soporta

## Casos de uso típicos

- Gestión de flotas de remolques con monitoreo continuo de ubicación y protección contra manipulación de remolques desacoplados
- Seguimiento de contenedores durante transporte intermodal con capacidad de larga espera para periodos de almacenamiento
- Monitoreo de carga refrigerada usando sensores Bluetooth de temperatura y humedad
- Rastreos marítimos y en puertos para contenedores montados en cubierta y embarcaciones pequeñas
- Telemetría remota para activos de alto valor que requieren lecturas ocasionales de sensores y medidas antirrobo
- Redes de sensores distribuidas en instalaciones usando LoRa opcional para cobertura de bajo consumo

## Notas sobre disponibilidad de características

- El módulo celular y la generación de red pueden variar por región y por proyecto, lo que hace que las opciones de conectividad móvil difieran entre unidades
- Componentes opcionales como módulos LoRa y baterías de mayor capacidad dependen de la variante y pueden no estar presentes en todas las unidades
- Las versiones de firmware afectan el comportamiento, incluidos los intervalos de reporte, la lógica de alarmas y el manejo de sensores
- La instalación y el cableado determinan qué entradas y funciones de relé están disponibles para integraciones con vehículos o remolques
- Las revisiones de hardware del fabricante pueden cambiar detalles de la carcasa o la disposición de conectores con el tiempo
