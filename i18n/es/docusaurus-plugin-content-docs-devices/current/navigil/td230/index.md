# Navigil - TD230

![TD230](./logo.jpg)

El Navigil TD230 es un dispositivo de rastreo OEM pensado para que las empresas incorporen capacidades de localización GPS al mercado de manera rápida. Se entrega con firmware TG2 listo para producción y una membrana de interfaz de usuario que permite rebranding, ofreciendo varios diseños de membrana con diferentes combinaciones de botones y LEDs para adaptarse a distintos diseños de producto. El TD230 está orientado a una rápida salida al mercado y a la personalización flexible del hardware para empresas que desean integrar rastreo dentro de sus propios equipos.

Como dispositivo compatible con Plaspy, el TD230 se ajusta a los flujos de trabajo habituales de monitoreo de flotas y activos soportados por plataformas telemáticas modernas. Sus funciones integradas, como geovallas, monitoreo del estado del vehículo, informes periódicos al servidor, lógica de ahorro de energía, configuración por aire (OTA) y un SDK disponible, facilitan la integración con Plaspy para visibilidad de ubicación, alertas e informes operativos. La combinación de personalización OEM y software de producción convierte al TD230 en una opción práctica para organizaciones que despliegan hardware de rastreo junto con Plaspy.

## Puntos clave

- Diseño amigable para OEM que facilita la integración rápida del producto y el rebranding
- Firmware TG2 listo para producción con funciones de rastreo comunes como geovallas y monitoreo de estado
- Membrana personalizable con múltiples diseños de botones y LEDs para interfaces de usuario a medida
- Capacidad de actualización por aire (OTA) para firmware y archivos de configuración
- SDK disponible para personalizaciones adicionales a nivel de dispositivo y extensión de funciones
- Gestión inteligente de energía y modos de bajo consumo para operación prolongada en campo
- Informes al servidor diseñados para comunicación periódica con plataformas back end

## Cómo funciona con Plaspy

El TD230 puede integrarse en Plaspy para aportar datos de ubicación y operativos desde los dispositivos desplegados hacia la plataforma. Dado que el equipo soporta funciones de firmware de producción e informes periódicos al servidor, Plaspy puede mostrar información de ubicación, eventos y estado para casos de uso de gestión de flotas y activos.

- Visibilidad de ubicaciones en tiempo real y del historial en mapas y líneas de tiempo de Plaspy
- Reenvío de eventos de geovallas y alertas para monitoreo de perímetros y rutas
- Informes de estado del vehículo o activo que apoyan la supervisión operativa y la gestión de despachos
- Informes regulares al servidor que permiten la reproducción de recorridos y reportes de uso en Plaspy
- Comportamiento de ahorro de energía que equilibra la frecuencia de reporte y la autonomía en despliegues remotos
- Firmware y configuración con capacidad OTA que complementan los flujos de trabajo de gestión de dispositivos en la plataforma

## Casos de uso típicos

- Integración OEM cuando los fabricantes desean añadir rastreo GPS a sus propios productos
- Seguimiento de flotas para vehículos ligeros y unidades de servicio que requieren ubicación y estado
- Monitoreo de activos remotos donde la larga autonomía y los informes periódicos son esenciales
- Rastreo de equipos de alquiler y uso compartido con requisitos de UI personalizados para el usuario final
- Despliegues que necesitan una base de firmware lista para producción con posibilidad de mejoras vía SDK

## Por qué elegir este rastreador con Plaspy

El TD230 es una opción sensata para empresas que requieren un rastreador OEM listo para usar con firmware de nivel de producción y opciones para rebranding visual. Su conjunto de funciones cubre las necesidades habituales de rastreo de flotas y activos, mientras que el SDK y la personalización de la membrana permiten a los equipos de producto adaptar el comportamiento y la interacción con el usuario según su oferta de servicio. Para organizaciones que usan Plaspy, el TD230 aporta las capacidades de dispositivo que se ajustan bien a características de la plataforma como mapeo, alertas, reportes y gestión de dispositivos.

Si desea evaluar el TD230 para su despliegue con Plaspy, obtenga más información en el sitio principal https://www.plaspy.com. Las especificaciones del producto, la disponibilidad y los datos del fabricante pueden cambiar con el tiempo; por favor verifique la documentación oficial de Navigil en http://www.navigil.com/ antes de finalizar un plan de compra o integración.
