# OKB Tehnoavtomatika - MTA-02

![MTA-02](./logo.jpg)

El GPS Sistema MTA-02 de OKB Tehnoavtomatika es un producto completo que ofrece una solución flexible para resolver problemas específicos. Este dispositivo cuenta con configuraciones que permiten la conexión de un auricular "manos libres" para comunicación de voz, sensores para control de nivel de combustible, tecnología Bluetooth y una cámara de video, lo que permite monitorear no solo vehículos y equipos, como camiones y cosechadoras, sino también objetos estacionarios y propiedades remotas para funciones de seguridad.

Las características del dispositivo requieren que el titular sea notificado mediante el uso de Internet \(GPRS\), ya sea a través de envío de SMS a un número especificado o mediante monitoreo a través de un centro de control de servicios.

El dispositivo cuenta con un receptor GPS de alta sensibilidad que permite la determinación precisa de las coordenadas. Tiene un consumo de corriente bajo en modo activo y en modo de espera, y cuenta con una batería recargable con una capacidad de hasta 600 mA/h, lo que garantiza un tiempo de espera de al menos 6 horas. El dispositivo tiene un tiempo de preparación técnica de no más de 3 minutos y cumple con el estándar de protección IP30. Sus dimensiones son de aproximadamente 140 × 80 × 35 mm y tiene un peso de 330 g.

### Características destacadas:

- Configuración flexible del sistema
- Conexión de auricular "manos libres" para comunicación de voz
- Control de nivel de combustible
- Tecnología Bluetooth
- Cámara de video para monitoreo
- Notificación a través de Internet \(GPRS\) o SMS
- Receptor GPS de alta sensibilidad
- Batería recargable con capacidad de hasta 600 mA/h
- Tiempo de preparación técnica de no más de 3 minutos
- Protección IP30
