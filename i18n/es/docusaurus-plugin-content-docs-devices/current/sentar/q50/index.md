# Sentar - Q50

![Q50](./logo.jpg)

El Sentar Q50 es un reloj GPS diseñado específicamente para niños. Con su diseño elegante y colorido, no solo es un dispositivo funcional, sino también un accesorio de moda. El Q50 está equipado con un chipset MTK2503, que garantiza un seguimiento de ubicación preciso y confiable. Admite modos de ubicación GPS, AGPS y LBS, lo que proporciona múltiples opciones para una posicionamiento preciso.

El Q50 está disponible en una variedad de colores vibrantes, incluyendo azul, rosa, verde, negro y azul oscuro, lo que permite a los niños elegir su estilo favorito. El reloj está diseñado para ser cómodo de llevar y fácil de usar, lo que lo hace adecuado para niños de todas las edades.

Características destacadas:

- Chipset MTK2503 para un seguimiento de ubicación preciso y confiable
- Admite modos de ubicación GPS, AGPS y LBS
- Disponible en una variedad de colores vibrantes
- Cómodo de llevar y fácil de usar
