# CalmAmp - LMU-4520

![LMU-4520](./logo.jpg)

El rastreador GPS CalmAmp LMU-4520 es un dispositivo de localización y mensajería diseñado específicamente para los mercados de minería y construcción. Este dispositivo resistente a la intemperie cuenta con comunicaciones vía satélite y celulares, así como la capacidad de conectarse a la ECU de los vehículos. Con una calificación medioambiental IP67, el LMU-4520 ofrece un conjunto completo de funciones de gestión de flotas.

El LMU-4520 está equipado con acelerómetros de 16G para medir el movimiento, el comportamiento del conductor y eventos de impacto. También cuenta con una variedad de interfaces, como un switch de dos puertos en serie de potencia, soporte para Terminal de datos móvil \(MDT\) y un sistema integral de E/S. Además, este dispositivo ofrece la opción de utilizar tecnologías de comunicación satelital o WiFi.

La flexibilidad es una característica destacada del LMU-4520. Este dispositivo utiliza el motor de alertas PEG \(Programmable Event Generator\) de CalAmp, que permite a los clientes definir reglas basadas en excepciones para satisfacer las necesidades específicas de su aplicación. Además, el LMU-4520 se beneficia del sistema de gestión de dispositivos PULS \(Programming, Updates, and Logistics System\) de CalAmp, que permite la actualización de parámetros de configuración, reglas de PEG y firmware a través del aire.

En resumen, el rastreador GPS CalmAmp LMU-4520 es una solución robusta y versátil para la gestión de flotas en los sectores de minería y construcción. Con su resistencia a la intemperie, amplia gama de interfaces y capacidad de expansión, este dispositivo ofrece una solución rentable y escalable para las necesidades cambiantes de los clientes.

### Características destacadas:

- Resistente a la intemperie con calificación IP67
- Comunicaciones vía satélite y celulares
- Conexión a la ECU de los vehículos
- Acelerómetros de 16G para medir el movimiento y eventos de impacto
- Amplia variedad de interfaces, incluyendo switch de dos puertos en serie de potencia y soporte para MDT
- Opción de utilizar tecnologías de comunicación satelital o WiFi
- Motor de alertas PEG para definir reglas basadas en excepciones
- Sistema de gestión de dispositivos PULS para actualizaciones y configuración a través del aire
