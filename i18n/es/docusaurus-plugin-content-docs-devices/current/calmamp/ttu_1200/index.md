# CalmAmp - TTU-1200

![TTU-1200](./logo.jpg)

El rastreador GPS CalmAmp TTU-1200 es una solución confiable y duradera diseñada para la gestión de activos que normalmente están atados a sistemas de 12 o 24 voltios, pero que pueden quedar inutilizados durante períodos prolongados. Con un tamaño compacto y un rendimiento superior de GPS, el TTU-1200 cuenta con una batería interna recargable de 3.8 Ah y tres entradas/salidas \(I/O\).

Este dispositivo de seguimiento de vehículos y comunicaciones utiliza la tecnología GPS de alta sensibilidad en redes celulares GPRS, CDMA y HSPA, lo que permite su instalación en cualquier vehículo móvil de 12 o 24 voltios. Además, cuenta con antenas internas de alta calidad para las comunicaciones celulares y GPS, eliminando la necesidad de antenas con cable y facilitando su montaje en cualquier parte del vehículo de manera fácil y económica.

El TTU-1200 utiliza el avanzado motor de alertas PEG™ \(Programmable Event Generator\) de CalAmp, que monitorea continuamente las condiciones externas y responde instantáneamente a eventos predefinidos por el cliente, como tiempo, fecha, movimiento, ubicación, zona geográfica, entre otros. Esto permite adaptar el dispositivo a las necesidades específicas de cada aplicación.

Además, el TTU-1200 cuenta con el sistema de gestión de dispositivos y mantenimiento PULS™ \(Programming, Updates, and Logistics System\) de CalAmp, que permite la actualización inalámbrica de parámetros de configuración, reglas de PEG y firmware. También ofrece actualizaciones automáticas de configuración y monitoreo del estado de salud de la unidad, lo que ayuda a identificar problemas antes de que se conviertan en costosos.

En resumen, el rastreador GPS CalmAmp TTU-1200 es una solución flexible y confiable para la gestión de activos, con características como batería recargable, rendimiento superior de GPS, entradas/salidas \(I/O\) y tecnología de comunicación celular avanzada. Su motor de alertas PEG™ y el sistema de gestión de dispositivos PULS™ permiten adaptar el dispositivo a las necesidades específicas de cada aplicación y realizar actualizaciones de forma inalámbrica.

### Características destacadas:

- Batería interna recargable de 3.8 Ah
- Tres entradas/salidas \(I/O\)
- Tecnología GPS de alta sensibilidad
- Compatibilidad con redes celulares GPRS, CDMA y HSPA
- Antenas internas de alta calidad para comunicaciones celulares y GPS
- Motor de alertas PEG™ para monitoreo y respuesta a eventos predefinidos
- Sistema de gestión de dispositivos y mantenimiento PULS™ para actualizaciones inalámbricas y monitoreo del estado de salud
