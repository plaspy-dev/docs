# CalmAmp - AUT-620

![AUT-620](./logo.jpg)

El rastreador GPS CalmAmp AUT-620 es una solución de seguimiento de activos a pilas diseñada para despliegues fiables a largo plazo. Es ideal para la gestión de activos que requieren seguimiento durante largos períodos sin necesidad de mantenimiento.

El AUT-620 cuenta con un tamaño compacto y un rendimiento superior de GPS. Utiliza pilas alcalinas AA para una mayor duración de la batería. Este dispositivo de seguimiento de activos incorpora tecnología GPS de alta sensibilidad y se puede instalar en el interior de cualquier activo móvil gracias a sus antenas internas de calidad para celulares y GPS. Esto elimina la necesidad de antenas con cable y permite una instalación fácil y económica en prácticamente cualquier lugar.

La comunicación de datos se realiza a través de redes celulares utilizando SMS o mensajes UDP, lo que proporciona un enlace de comunicación fiable entre el dispositivo y los servidores de aplicaciones. El AUT-620 está diseñado para reducir costos y tamaño, al tiempo que mejora la fiabilidad en el campo.

Este rastreador GPS ofrece flexibilidad gracias a su motor de alertas programable \(PEG\) de CalAmp. PEG monitorea continuamente las condiciones externas y puede responder instantáneamente a condiciones predefinidas relacionadas con el tiempo, la fecha, el movimiento, la ubicación, la zona geográfica, las entradas y otras combinaciones de eventos. Esto permite adaptar el comportamiento del dispositivo a las necesidades específicas de la aplicación.

El AUT-620 también aprovecha el sistema de gestión de dispositivos de CalAmp, Puls \(Programación, Actualizaciones y Logística System\). Con Puls, es posible actualizar los parámetros de configuración, las reglas de PEG y el firmware del dispositivo de forma remota. Además, Puls ofrece actualizaciones automáticas de configuración y supervisión del estado de salud de la unidad, lo que permite identificar rápidamente problemas antes de que se conviertan en costosos.

#### Características destacadas:

- Seguimiento de activos a pilas
- Tamaño compacto
- Rendimiento superior de GPS
- Pilas alcalinas AA
- Tecnología GPS de alta sensibilidad
- Comunicación a través de redes celulares
- Motor de alertas programable \(PEG\)
- Sistema de gestión de dispositivos \(Puls\)
