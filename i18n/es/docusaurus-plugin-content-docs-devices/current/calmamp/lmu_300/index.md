# CalmAmp - LMU-300

![LMU-300](./logo.jpg)

El rastreador GPS CalmAmp LMU-300 es una solución económica y completa para el seguimiento de vehículos. Diseñado para instalaciones encubiertas y confiables en automóviles, este dispositivo es ideal para aplicaciones como la recuperación de vehículos robados, financiamiento de vehículos y alquiler de automóviles.

La LMU-300 cuenta con características avanzadas, como un rendimiento superior en un tamaño compacto, una batería interna de respaldo opcional, modos de suspensión de energía ultra baja y un acelerómetro de 3 ejes opcional para detectar el movimiento. Además, ofrece hasta dos entradas y dos salidas \(I/O\) para una mayor flexibilidad en la configuración.

Este rastreador GPS utiliza tecnología GPS supersensible y redes celulares para proporcionar una instalación fácil y económica en cualquier vehículo móvil de 12/24 voltios. Con antenas internas de alta calidad para la comunicación celular y GPS, no es necesario utilizar antenas con cable.

La LMU-300 se comunica a través de la red celular utilizando mensajes SMS o mensajes UDP, lo que garantiza una conexión confiable entre el dispositivo y los servidores de aplicaciones. Además, este dispositivo cuenta con el motor de alertas PEG \(Programmable Event Generator\) de CalAmp, que permite supervisar y responder a condiciones específicas definidas por el cliente, como tiempo, fecha, movimiento, ubicación, zona geográfica, entradas y más.

La LMU-300 también aprovecha el sistema de mantenimiento y gestión de CalAmp, Puls \(Programming, Updates, and Logistics System\), para la configuración y actualización de parámetros a través del aire. Esto permite una configuración sin complicaciones y actualizaciones automáticas posteriores a la instalación, lo que facilita el monitoreo del estado de salud de la unidad y la identificación de problemas antes de que se conviertan en costosos.

- Rendimiento superior en un tamaño compacto

- Modos de suspensión de energía ultra baja
