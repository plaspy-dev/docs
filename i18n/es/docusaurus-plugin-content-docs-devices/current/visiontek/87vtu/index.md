# VisionTek - 87VTU

![87VTU](./logo.jpg)

El rastreador GPS Visiontek 87VTU es una unidad de seguimiento de vehículos que cuenta con un módem GSM de banda cuádruple/GPRS y un receptor GPS de 48 canales. Su función principal es adquirir, controlar y transmitir datos de posición, fecha, hora y dirección al servidor en forma de paquetes o mensajes de texto.

El Visiontek 87VTU está equipado con un puerto USB para cargar el firmware, configurar el dispositivo y capturar registros de GSM/GPS. También cuenta con 3 indicadores LED \(GSM, GPS y energía\) que muestran el estado del dispositivo. Además, incorpora un sensor de movimiento 3D que detecta el sueño/movimiento y reduce el consumo de datos y energía.

Este rastreador GPS ofrece 4 entradas digitales, 4 salidas digitales, 2 entradas analógicas de tensión, 2 entradas analógicas de corriente, 1 puerto serie \(RS 232\) y 1-Wire \(sensor de temperatura\). Además, proporciona información detallada como ID del vehículo, IMEI del dispositivo, fecha y hora actuales, ubicación, velocidad, dirección, altitud, kilometraje acumulado, fuerza de la señal GSM y GPS, y estado de la posición GPS.

El Visiontek 87VTU cuenta con características de software como protección de contraseña, bloqueo de SIM, barreras geográficas, modo de reposo, reenvío de SMS, almacenamiento y reenvío de datos históricos, seguimiento bajo demanda, comandos OTA y actualización remota de firmware. Estas características hacen que este dispositivo sea potente y robusto en áreas de aplicación como gestión de flotas, gestión de ambulancias, taxis, logística, centros educativos, barcos, etc.

El Visiontek 87VTU viene en una caja de plástico IP65 y está equipado con antenas internas de GSM y GPS. Además, ofrece la opción de utilizar antenas externas para un mejor rendimiento.

### Áreas de aplicación:

- Gestión de flotas
- Despacho de taxis
- Gestión de autobuses escolares
- Logística
- Sistemas de transporte público
- Servicios de entrega y mensajería
- Vehículos de seguridad y emergencia
- Administración de personal
