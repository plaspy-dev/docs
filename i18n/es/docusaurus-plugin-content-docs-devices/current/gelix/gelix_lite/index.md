# Gelix - Gelix Lite

![Gelix Lite](./logo.jpg)

El rastreador GPS Gelix Lite es un controlador telemático diseñado para integrarse en el sistema GLONASS / GPS y realizar el seguimiento de objetos en movimiento. Este dispositivo recopila, registra y transmite datos a través de GPRS / IP y SMS. 

El Gelix Lite ofrece una configuración flexible, lo que permite al usuario determinar el formato de los datos y los eventos a registrar, así como la elección de la transferencia de datos. Además, este rastreador GPS es compatible con hasta dos servidores receptores y puede funcionar en modo de servidor de comandos, lo que permite la actualización remota del firmware.

Una de las características destacadas del Gelix Lite es su capacidad de integración con dispositivos externos. Por ejemplo, puede contar las entradas digitales utilizando sensores de pulso y admitir sensores de "contacto seco". También puede recopilar datos a través de una interfaz serial, lo que permite la conexión de adaptadores de bus CAN o sensores de nivel de combustible.

En resumen, el Gelix Lite es un rastreador GPS versátil y confiable que ofrece una amplia gama de funciones y opciones de configuración para satisfacer las necesidades de seguimiento de objetos en movimiento.
