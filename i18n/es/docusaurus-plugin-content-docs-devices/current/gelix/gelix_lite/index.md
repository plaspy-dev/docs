# Gelix - Gelix Lite

<div className="device-logo">
![Gelix Lite](./logo.jpg)
</div>

El Gelix Lite es un dispositivo telemático diseñado para integrarse con sistemas GLONASS y GPS para el seguimiento de objetos en movimiento. Como controlador telemático, recopila, registra y transmite datos de ubicación y eventos mediante GPRS IP y SMS, y ofrece configuración flexible del formato de datos y del registro de eventos. El equipo puede enviar información a dos servidores receptores, aceptar comandos de modo operativo desde un servidor y soporta actualizaciones remotas de firmware, lo que lo hace adecuado para la gestión continua de flotas y activos.

Como dispositivo compatible con Plaspy, el Gelix Lite puede enviar sus flujos de ubicación y eventos a la plataforma Plaspy para su visualización y supervisión operativa. Su soporte para formatos de datos configurables, entradas digitales, sensores de contacto seco y entradas por interfaz serial permite a los usuarios de Plaspy centralizar el rastreo, monitorear valores de sensores externos e incluir datos de eventos en informes y alertas. La compatibilidad con Plaspy ofrece una vía práctica para integrar dispositivos Gelix Lite en flujos de trabajo más amplios de monitoreo de flotas.

## Características principales

- Diseñado para telemática de conductores y seguimiento GLONASS/GPS en tiempo real
- Transmisión de datos vía GPRS IP y SMS con opciones de transferencia flexibles
- Registro de eventos y formato de datos configurables según las necesidades de reporte
- Soporte para dos servidores receptores para redundancia o enrutamiento escalonado de datos
- Capacidad de recibir comandos de modo operativo y actualizaciones de firmware remotas
- Integración con dispositivos externos, incluyendo entradas digitales, sensores de contacto seco y adaptadores de interfaz serial

## Cómo funciona con Plaspy

Cuando se utiliza con Plaspy, el Gelix Lite entrega datos de posición y eventos a un sistema de gestión de flotas donde se procesan para visualización, alertas e informes. Plaspy ingiere los datos del dispositivo y los presenta mediante herramientas de panel que ayudan a los operadores a supervisar la ubicación, el estado y los eventos de los vehículos.

- Ploteo de ubicaciones en tiempo real y casi en tiempo real sobre el mapa de Plaspy
- Registro de eventos y entradas digitales visible en Plaspy para contadores de pulsos y eventos de contacto seco
- Alertas y notificaciones configurables basadas en los eventos reportados por el dispositivo
- Informes históricos y exportación de rutas rastreadas y eventos registrados para análisis
- Visibilidad de los datos de sensores externos recolectados por la interfaz serial para su integración en informes vehiculares
- Uso de la capacidad de comandos al servidor del dispositivo para reflejar modos operativos y señalización de eventos dentro de los flujos de trabajo de Plaspy

## Casos de uso típicos

- Rastreo de vehículos de flota para operaciones logísticas y de reparto
- Telemática de conductores y supervisión operativa en flotas comerciales
- Monitoreo de nivel de combustible y otros sensores mediante datos por interfaz serial
- Conteo de uso de activos con sensores de pulso y monitoreo de entradas digitales
- Gestión remota de dispositivos y enrutamiento por servidores escalables para despliegues a gran escala

## Por qué elegir este rastreador con Plaspy

El Gelix Lite es una opción práctica para organizaciones que requieren un controlador telemático flexible, capaz de integrar sensores externos y soportar múltiples métodos de entrega de datos. Su soporte para formatos de datos configurables y comandos a servidor complementa la capacidad de Plaspy para mostrar ubicaciones, eventos y lecturas de sensores en paneles, alertas e informes, lo que ayuda a los equipos operativos a mantener conciencia situacional y reaccionar ante eventos relevantes.

Dado que el Gelix Lite puede reportar una variedad de telemetría y tipos de eventos a la vez que soporta funciones de gestión remota, encaja bien en entornos donde la monitorización centralizada y el mantenimiento periódico de dispositivos forman parte del flujo operativo. Para organizaciones que evalúan rastreadores, combinar el hardware Gelix Lite con el software Plaspy crea una solución coherente para visibilidad de ubicación e informes basados en eventos.
