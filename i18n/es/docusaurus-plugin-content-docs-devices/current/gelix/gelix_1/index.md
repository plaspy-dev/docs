# Gelix - Gelix 1

![Gelix 1](./logo.jpg)

El rastreador GPS Gelix 1 es una herramienta de navegación y grabación de datos digitales y señales digitales con salidas de relé programables. Diseñado para ser montado en objetos móviles como vehículos, este rastreador trabaja en conjunto con un módem externo o un receptor de navegación por satélite de GLONASS/GPS o NAVSTAR.

El controlador Gelix 1 se puede conectar a varios sensores, actuadores y interfaces de expansores. La versión Gelix 1G está equipada con un receptor GPS integrado SiRF-III. Este controlador montado en el vehículo proporciona funciones como el registro y navegación de estados de señal de datos de las interfaces de entrada y salida, incluyendo los datos recibidos desde el puerto serie.

Además, el Gelix 1 ofrece soporte para el sistema de navegación a bordo \(opcional\), control de actuadores y dispositivos externos, y la capacidad de devolver datos de la memoria no volátil \(LOG\) a un dispositivo externo a través de una interfaz en serie, como un adaptador Bluetooth, ZigBee o un módem por satélite Inmarsat-D+.

La configuración del controlador Gelix 1 y el cambio de su lógica no requieren los servicios de programadores y desarrolladores, lo que lo hace fácil de usar y personalizar según las necesidades del usuario. Este rastreador GPS también permite el monitoreo en línea de los vehículos a través de transmisiones por satélite, así como el monitoreo offline. Además, se puede utilizar para la logística del transporte y la optimización de las rutas, el control de actividades ejecutivas, el seguimiento del consumo de combustible, la etiquetación de ubicaciones geográficas, el control automático de equipos durante la conducción, la seguridad y la notificación, entre otros usos.

### Características destacadas:

- Navegación y grabación de datos digitales y señales digitales
- Salidas de relé programables
- Compatible con módem externo o receptor de navegación por satélite
- Conexión a varios sensores, actuadores e interfaces de expansores
- Receptor GPS integrado SiRF-III \(versión Gelix 1G\)
- Registro y navegación de estados de señal de datos
- Soporte para sistema de navegación a bordo \(opcional\)
- Control de actuadores y dispositivos externos
- Transferencia de datos a través de interfaz en serie \(Bluetooth, ZigBee, módem por satélite\)
- Fácil configuración y personalización
- Monitoreo en línea y offline de vehículos
- Aplicaciones en logística, control de rutas, seguridad y más
