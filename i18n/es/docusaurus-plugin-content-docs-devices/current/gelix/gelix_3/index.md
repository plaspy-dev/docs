# Gelix - Gelix 3

![Gelix 3](./logo.gif)

El rastreador GPS Gelix 3 está diseñado específicamente para el control remoto y el equipo de control montado sobre un objeto fijo. Este dispositivo proporciona transmisión periódica y por eventos de información sobre el objeto, como zonas de protección, pulsos y sensores analógicos, contadores y consumo de energía. Además, permite administrar relés y actuadores, como cerraduras electrónicas, válvulas, sistemas de alarma y sistemas de calefacción.

Una característica destacada del rastreador Gelix 3 es su capacidad de configuración y gestión a través de entradas GSM/GPRS. Esto significa que se pueden controlar las salidas del transmisor de relé \(zonas de protección\) y se pueden adaptar las sesiones de comunicación y el formato de los datos según los requerimientos del proyecto, sin necesidad de servicios para desarrolladores.

Características destacadas:

- Control remoto y equipo de control montado sobre un objeto fijo
- Transmisión periódica y por eventos de información sobre el objeto
- Gestión de relés y actuadores
- Configuración y gestión a través de entradas GSM/GPRS
- Adaptabilidad a los requerimientos del proyecto sin servicios para desarrolladores
