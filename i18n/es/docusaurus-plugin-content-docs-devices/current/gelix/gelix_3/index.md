# Gelix - Gelix 3

![Gelix 3](./logo.gif)

El Gelix 3 es un registrador de consumo eléctrico y rastreador GPS versátil, diseñado para recopilar y transmitir telemetría y eventos en una amplia variedad de aplicaciones. Cuenta con capacidades de E/S automáticas y opciones de conectividad mediante módem integrado o Ethernet, lo que lo hace ideal en entornos donde se requiere monitorización continua de consumo energético, temperatura, alarmas y otros sucesos relevantes. El dispositivo se ofrece como una plataforma única para el registro, la supervisión y la entrega remota de datos.

Dado que el Gelix 3 puede integrarse con medidores, termómetros, lectores de control de acceso y sistemas de alarma, encaja naturalmente con plataformas de gestión de flotas y activos como Plaspy. Al integrarlo con Plaspy, usted podrá combinar información de ubicación con telemetría de consumo y eventos en un sistema central para visualización, alertas e informes, ayudando a las organizaciones a unificar la supervisión operativa con el control energético y de seguridad.

## Aspectos destacados

- Monitorización de consumo eléctrico y registro de datos integrados en un solo equipo
- E/S automatizada y conectividad mediante módem integrado o Ethernet para entrega remota de datos
- Gran capacidad de integración con medidores, termómetros, lectores de control de acceso y sistemas de alarma
- Soporta monitoreo de eventos y telemetría de dispositivos para mayor visibilidad operativa
- Funciones de escucha de voz y capacidades relacionadas con control de acceso cuando se requieren
- Diseñado para despliegues que necesitan una visión combinada de seguridad, control e información energética

## Cómo funciona con Plaspy

Plaspy recibe la telemetría del Gelix 3 y la presenta junto con los datos de ubicación para ofrecer una visibilidad unificada de activos, consumo energético y eventos. La plataforma usa los datos entrantes para poblar paneles, activar alertas y generar informes históricos que ayudan a los equipos en la toma de decisiones operativas.

- Visibilidad en tiempo real del estado y la ubicación del dispositivo dentro de los paneles de Plaspy
- Historial de consumo energético y registros de eventos disponibles para informes y análisis
- Alertas y notificaciones basadas en umbrales de energía, alarmas o eventos personalizados
- Telemetría consolidada de medidores, sensores y dispositivos de acceso para facilitar la resolución de incidencias
- Integración en flujos operativos para monitoreo, programación de mantenimiento e informes de cumplimiento

## Casos de uso típicos

- Monitorización energética de instalaciones y elaboración de informes de consumo histórico
- Monitorización ambiental remota, incluyendo tendencias de temperatura y alertas
- Supervisión de seguridad y control de acceso para edificios y áreas restringidas
- Vigilancia de alarmas y eventos con registro centralizado para análisis de incidentes
- Telemetría remota y control del estado de dispositivos en activos distribuidos
- Combinación de rastreo de ubicación con monitoreo de consumo para activos móviles o equipos de campo

## Por qué elegir este rastreador con Plaspy

El Gelix 3 ofrece una combinación práctica de monitorización energética y telemetría de eventos que complementa las capacidades de gestión de flotas y activos de Plaspy. Las organizaciones que requieren información consolidada sobre consumo de energía, condiciones ambientales y eventos de seguridad se benefician al mantener los datos del Gelix 3 en la misma plataforma donde gestionan ubicación y estado operativo.

Al integrar el dispositivo con una amplia variedad de equipos periféricos, el Gelix 3 resulta apropiado para despliegues que demandan monitorización y generación de informes adaptables. Emparejar Gelix 3 con Plaspy permite centralizar flujos de datos, configurar alertas relevantes y generar reportes que apoyen tanto la eficiencia operativa como la supervisión, evitando la dependencia de sistemas desconectados.
