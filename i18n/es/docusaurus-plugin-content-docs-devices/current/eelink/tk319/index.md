# EElink - TK319

![TK319](./logo..jpg)

El rastreador GPS TK319-H de EElink es un dispositivo de seguimiento de red 3G diseñado para una variedad de aplicaciones, como alquiler de vehículos, logística, gestión de flotas y autobuses, gestión de riesgos y aplicaciones de IoT. Con características de rendimiento avanzadas, este rastreador GPS ofrece un seguimiento preciso y en tiempo real para garantizar la seguridad y la eficiencia en diversas industrias.

Una de las características destacadas del TK319-H es su capacidad de seguimiento GPS/LBS bidireccional. Utiliza AGPS para una ubicación rápida y LBS como ayuda. Además, realiza cargas regulares de datos utilizando redes GSM/WCDMA para un seguimiento en tiempo real. También cuenta con detección ACC para monitorear el estado de encendido del motor, y opcionalmente, un relé que permite el corte remoto del motor. Además, ofrece lecturas precisas de temperatura con un sensor de temperatura opcional con una precisión de ±0.5 grados Celsius. También cuenta con una extensión GPIO que proporciona puertos de E/S para una expansión adicional de datos.

El TK319-H también está equipado con una variedad de alertas y alarmas para garantizar la seguridad. Esto incluye una alarma de colisión/caída que notifica cuando ocurren accidentes, una alarma de velocidad que alerta o corta remotamente el motor en caso de exceso de velocidad, una batería interna con alarma de desconexión y baja potencia, y una alarma de GEO-cerca que envía una alerta cuando el dispositivo entra o sale de un área predefinida.

La configuración del TK319-H se puede ajustar de forma remota a través de un servidor, aplicaciones dedicadas o SMS. Además, este rastreador GPS es compatible con el Protocolo EELINK 2.0 para una fácil integración.

Especificaciones técnicas:

- Dimensiones: 89\(L\) x 37\(W\) x 12\(H\) mm
- Longitud del cable: 75 mm
- Color: Negro / Rojo
- Indicadores LED: GPS \(Azul\), GSM / WCDMA \(Rojo\)
- Batería: 140mAh
- Peso: 46 g
- Rango de voltaje: 12 / 24 / 36 / 48 / 60 / 72 VDC \(9-72VDC\)
- Condiciones de funcionamiento: -20°C a 75°C / 20% a 90% de humedad relativa

El rastreador GPS TK319-H cumple con los estándares PTCRB, GCF, FCC, IC, Anatel, AT&T y CCC, lo que garantiza su calidad y confiabilidad.
