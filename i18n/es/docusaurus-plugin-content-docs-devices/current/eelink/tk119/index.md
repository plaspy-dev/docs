# EElink - TK119

![TK119](./logo..jpg)

El rastreador GPS TK119-3G de EElink es una solución confiable y versátil para una variedad de aplicaciones, desde servicios de alquiler de vehículos hasta la gestión logística y el seguimiento de motocicletas. Con conectividad 3G WCDMA, este rastreador ofrece una cobertura integral y confiable en todo momento.

Con su clasificación IP67 a prueba de agua, el TK119-3G es resistente y duradero, lo que lo hace adecuado para su uso en cualquier condición climática. Además, cuenta con una extensión GPIO que proporciona funcionalidad mejorada con puertos de entrada/salida adicionales para la transferencia de datos.

Este rastreador también se destaca por su modularidad, lo que significa que es compatible con redes 3G y 4G, lo que le permite adaptarse a diferentes necesidades de conectividad. Además, cumple con múltiples estándares de certificación, incluyendo PTCRB, GCF, FCC, IC, Anatel, AT&T y CCC.

El TK119-3G ofrece un seguimiento bidireccional GPS/LBS, lo que significa que utiliza AGPS avanzado para una ubicación rápida y precisa, y también es compatible con LBS cuando el GPS no está disponible. Además, cuenta con la capacidad de carga continua de datos a través de GSM/WCDMA para un seguimiento en tiempo real.

Este rastreador también cuenta con una serie de características destacadas, como la detección ACC, que monitorea el estado de encendido del vehículo, y un relé opcional que permite el control remoto del corte del motor. También ofrece una interfaz serial para la transferencia de datos y una batería incorporada que garantiza la funcionalidad con alarmas de desconexión y baja potencia.

El TK119-3G también cuenta con un sistema de alerta avanzado que incluye alarmas de colisión/caída, alarmas de vibración, alarmas de velocidad y alarmas de GEO-cerca. Estas alertas inmediatas mantienen a los usuarios informados sobre cualquier evento anormal.

La configuración remota del TK119-3G es fácil y conveniente, ya que se puede ajustar y administrar el dispositivo de forma remota a través de un servidor, una aplicación dedicada o SMS. Además, es compatible con el protocolo EELINK 2.0 para una conectividad y transmisión de datos sin problemas.

Especificaciones técnicas:

- Dimensiones: 87\(L\) x 41.6\(W\) x 12\(H\) mm
- Color: Negro
- Indicadores LED: GPS \(Azul\), GSM/WCDMA \(Rojo\)
- Capacidad de la batería: 70mAh
- Peso: 50g
- Rango de voltaje: 12 VDC / 24 VDC \(6-28V\)
- Corriente de funcionamiento: 45mA@12V \(GPS abierto\), 20mA@12V \(GPS cerrado\)
- Temperatura y humedad de funcionamiento: -20°C~70°C / 20%~80%RH
