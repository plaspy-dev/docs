# Ulbotech - T363

![T363](./logo.jpg)

El rastreador GPS Ulbotech T381 es un dispositivo OBDII que combina la red 4G y la función de WIFI para ofrecer una conectividad rápida y estable. Con la capacidad de transferir la señal 4G del operador móvil a la señal de WIFI, el T381 puede funcionar como un punto de acceso WIFI, permitiendo que hasta 10 dispositivos se conecten a Internet de alta velocidad. Esto facilita el intercambio de recursos y la comunicación entre los dispositivos dentro de la zona.

Además de su conectividad avanzada, el T381 cuenta con un módulo interno u-blox MAX-7 GNSS que admite GPS y GLONASS. Con una antena activa de alta ganancia y la función Assist Now AGPS, el dispositivo puede proporcionar una ubicación precisa y rápida, incluso cuando está instalado en un lugar oculto dentro del vehículo.

Una de las características destacadas del T381 es su función de diagnóstico a bordo \(OBDII\) / SAE J1939. Esto permite obtener datos en tiempo real del vehículo, como RPM, velocidad, nivel de combustible y consumo de combustible. También puede monitorear códigos de problemas de diagnóstico \(DTC\), parámetros OBDII y generar alarmas. Además, el T381 está equipado con aceleración 3D, lo que permite detectar el movimiento y analizar el comportamiento de conducción del conductor y el consumo de combustible, proporcionando sugerencias de mejora.

Para mayor seguridad, el T381 cuenta con una salida de inmovilizador \(motor cortado\) que puede utilizarse como medida antirrobo.

### Características destacadas:

- Conectividad 4G y WIFI para acceso a Internet de alta velocidad
- Módulo interno u-blox MAX-7 GNSS para posicionamiento GPS y GLONASS
- Función de diagnóstico a bordo \(OBDII\) / SAE J1939 para obtener datos del vehículo en tiempo real
- Aceleración 3D para análisis del comportamiento de conducción y consumo de combustible
- Salida de inmovilizador para mayor seguridad y prevención de robos
