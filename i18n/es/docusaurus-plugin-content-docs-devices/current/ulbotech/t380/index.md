# Ulbotech - T380

<div className="device-logo">
![T380](./tracker.jpg)
</div>

El T380 es un rastreador GPS OBDII plug-and-play de Ulbotech diseñado para seguimiento de vehículos, telemetría y conectividad para el conductor. Combina comunicaciones de datos móviles con un hotspot Wi‑Fi integrado que admite múltiples dispositivos clientes; además integra posicionamiento GNSS y sensores de movimiento a bordo para ofrecer datos continuos de ubicación y eventos. Su factor de forma OBDII compacto permite un despliegue rápido sin necesidad de cableado, entregando la telemetría esencial para supervisión de flotas, control antirrobo y monitoreo del comportamiento del conductor.

Como dispositivo listado como compatible con Plaspy, el T380 puede enviar posiciones, eventos de movimiento y estados de entradas/salidas directamente a la plataforma Plaspy para mapas en vivo, alertas y reportes históricos. Su capacidad de puenteo Wi‑Fi, actualizaciones remotas y configuración automática lo hacen apto tanto para el monitoreo de vehículos individuales como para despliegues de flota a gran escala gestionados desde Plaspy, proporcionando visibilidad operativa y control integrado con los flujos de trabajo de Plaspy.

## Características principales

- Instalación OBDII plug-and-play para despliegues rápidos y telemetría inmediata del vehículo.
- Módem 4G LTE combinado con hotspot Wi‑Fi para rastreo en tiempo real y conectividad para pasajeros o conductores.
- Posicionamiento GNSS con receptor de alto rendimiento para obtención confiable de coordenadas.
- Acelerómetro de 3 ejes y detección de movimiento a bordo para registro de eventos y detección del comportamiento del conductor.
- Salida digital para inmovilizador y entrada multifunción para acciones antirobo y control remoto básico.
- Puenteo Wi‑Fi para reducir el consumo de datos móviles manteniendo la conectividad telemática.
- Capacidad de actualización remota de firmware y manejo automático de APN y zona horaria para simplificar la gestión de flotas.

## Cómo funciona con Plaspy

Al integrarlo con Plaspy, el T380 sube ubicación y telemetría para que los gerentes de flota y operadores puedan monitorear vehículos en tiempo real, recibir alertas de eventos y generar reportes. Plaspy procesa las fijaciones GNSS, los eventos del acelerómetro y los estados de entradas/salidas para ofrecer mapeo, alertas y análisis históricos. El hotspot y el puenteo Wi‑Fi del equipo ayudan a mantener la conectividad y a reducir el uso de datos celulares sin interrumpir el flujo de información hacia Plaspy.

- Actualizaciones de posición en tiempo real para seguimiento en vivo, visibilidad de rutas y alertas de geocercas dentro de Plaspy.
- Telemetría de movimiento y comportamiento del conductor enviada a Plaspy para detección de eventos, puntuación de conductores y revisión de incidentes.
- Reporte de estado de ignición e inmovilizador para flujos de trabajo antirobo y acciones de control remoto cuando están configuradas en Plaspy.
- Soporte de hotspot y puenteo Wi‑Fi para mantener enlaces de datos y reducir costos celulares mientras Plaspy se mantiene actualizado.
- Gestión remota y actualizaciones OTA para desplegar firmware y cambios de configuración con mínima intervención manual.

## Casos de uso habituales

- Gestión de flotas para monitoreo de rutas, soporte a despacho y visibilidad operativa.
- Protección antirrobo y flujos de inmovilización mediante corte remoto de motor y alertas de ubicación.
- Programas de seguridad y comportamiento del conductor basados en el registro y análisis de eventos del acelerómetro.
- Alquiler, seguros y monitoreo vehicular para servicios basados en uso y reporte de incidentes.
- Asistencia en carretera y conectividad en movimiento cuando el hotspot Wi‑Fi a bordo apoya a técnicos y conductores.

## Por qué elegir este rastreador con Plaspy

El T380 combina un práctico factor de forma OBDII plug-and-play con funciones telemáticas que se integran bien con las capacidades de la plataforma Plaspy. Su mezcla de posicionamiento GNSS, detección de movimiento y entradas/salidas digitales para control de inmovilizador proporciona la telemetría y puntos de control que requieren muchos programas de flota. El hotspot y el puenteo Wi‑Fi incorporados pueden reducir los costos móviles y mantener los dispositivos conectados, mientras que las funciones de actualización remota y configuración automática facilitan el manejo de despliegues a gran escala.

Usado con Plaspy, el T380 se convierte en una fuente confiable de datos para rastreo en vivo, alertas de eventos y reportes históricos. Las organizaciones que buscan un rastreador compacto alimentado por el vehículo, que ofrezca conectividad para el conductor y funcionalidad básica de control remoto, encontrarán en el T380 una opción práctica para integrar en flujos de trabajo gestionados por Plaspy.
