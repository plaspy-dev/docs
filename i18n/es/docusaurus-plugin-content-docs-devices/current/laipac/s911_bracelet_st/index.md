# Laipac - S911 Bracelet ST

![S911 Bracelet ST](./logo.jpg)

La pulsera de localización Laipac S911 ST es un dispositivo diseñado específicamente para el cumplimiento de la ley y puede ser utilizado para rastrear la ubicación de delincuentes, personas bajo arresto domiciliario o en libertad bajo fianza. Este dispositivo cuenta con un receptor GPS de alta sensibilidad y ofrece comunicación de voz bidireccional entre los delincuentes y los centros de monitoreo.

La pulsera de localización S911 ST está equipada con varias características destacadas, como un botón de emergencia SOS, un sensor G para detectar caídas, retención dentro de una geo-cerca y una alerta de sabotaje. Además, cuenta con una banda de detección de manipulación, que envía una notificación si se corta o se abre. También puede enviar alertas en tiempo real por correo electrónico, SMS o llamada telefónica si un delincuente entra o sale de una barrera geográfica predefinida.

Algunas de las aplicaciones sugeridas para este dispositivo incluyen el monitoreo de delincuentes de bajo riesgo, personas bajo arresto domiciliario, personas liberadas bajo fianza, casos de violencia doméstica y órdenes de retención.

Características destacadas:

- GSM / GPRS para cobertura global
- Pantalla LCD para mostrar la hora, estado del GPS, estado del GSM y nivel de batería
- Receptor AGPS de alto rendimiento para localización en exteriores e interiores
- Altavoz y micrófono incorporados
- Puerto micro USB para configuración y carga de energía
- Geo-valla con alarma de entrada/salida
- Banda de muñeca de seguridad
- Detección de manipulación
- Registrador inteligente con miles de puntos de referencia para registrar tiempo, velocidad, posición y estado de eventos
- Acelerómetro de 3 ejes para informar sobre impactos, accidentes, choques y caídas
- Actualizaciones de posición en tiempo real basadas en intervalos de tiempo y distancia
- Informe de kilometraje y alerta de exceso de velocidad
- Directorio telefónico y función de marcación rápida
- IP67 resistente al agua y al polvo

Especificaciones:

- Dimensiones: 5,0 x 4,4 x 1,5 cm \(sin incluir la banda\)
- Peso: 130 g
- Caja de regalo: 123 \(ancho\) x 168 \(alto\) x 86 \(profundidad\) mm
