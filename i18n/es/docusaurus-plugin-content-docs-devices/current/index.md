## ¿Qué es Plaspy?

Plaspy es una plataforma de software para rastreo GPS, gestión de flotas y monitoreo de telemetría. Empresas y proveedores de servicios GPS utilizan Plaspy para monitorear vehículos, activos y sensores conectados desde una sola plataforma.

Con Plaspy puedes:

- Monitorear vehículos y activos en tiempo real
- Crear geocercas y alertas
- Supervisar ignición, temperatura y datos de sensores
- Gestionar flotas desde una plataforma centralizada
- Analizar actividad mediante reportes y datos de telemetría

## Por qué la compatibilidad del hardware es importante

Elegir el rastreador GPS adecuado es una parte importante de una implementación exitosa. Diferentes dispositivos ofrecen diferentes capacidades según los requisitos del proyecto, como por ejemplo:

- Rastreo GPS en tiempo real
- Detección de ignición
- Alertas de geocerca
- Monitoreo de temperatura
- Análisis del comportamiento del conductor
- Lectura de combustible y datos CAN
- Soporte para sensores Bluetooth
- Rastreo de activos y remolques
- Instalación plug-and-play por OBD-II
- Supervisión remota de flotas

Plaspy está diseñado para soportar un amplio ecosistema de hardware de rastreo, para que empresas, instaladores y operadores de flota puedan centralizar el monitoreo en una sola plataforma.

## Casos de uso frecuentes

Los dispositivos GPS compatibles con Plaspy se utilizan comúnmente para:

- Gestión de flotas de carros, vans, camiones y motos
- Operaciones de logística y distribución
- Monitoreo de cadena de frío para transporte de alimentos y productos farmacéuticos
- Supervisión de maquinaria y equipos pesados
- Control de flotas de alquiler
- Protección de activos y mercancía
- Monitoreo de vehículos ejecutivos y personales
- Proyectos de telemetría IoT con integración de sensores

## ¿Necesitas ayuda para elegir un rastreador GPS?

Si no estás seguro de cuál dispositivo GPS es el más adecuado para tu proyecto, normalmente es mejor evaluarlo según:

- Tipo de instalación
- Cobertura de red disponible
- Sensores requeridos
- Tipo de vehículo
- Necesidades de reportes
- Disponibilidad del hardware en tu región

Algunas empresas necesitan un rastreador compacto y de instalación rápida, mientras que otras requieren telemetría avanzada, accesorios Bluetooth o monitoreo de temperatura para transporte refrigerado. Plaspy puede soportar tanto implementaciones simples como avanzadas dependiendo del hardware seleccionado.

## Preguntas frecuentes

### ¿Qué dispositivos GPS son compatibles con Plaspy?
Plaspy soporta múltiples marcas y modelos de rastreadores GPS utilizados para rastreo vehicular, gestión de flotas, monitoreo de activos y telemetría basada en sensores.

### ¿Puedo usar mi rastreador GPS actual con Plaspy?
En muchos casos, sí. La compatibilidad depende del protocolo del dispositivo, su firmware y las opciones de comunicación disponibles.

### ¿Plaspy soporta hardware de flota con sensores?
Sí. Muchos dispositivos compatibles soportan funciones como estado de ignición, geocercas, sensores de temperatura, accesorios Bluetooth y datos de telemetría.

### ¿Este catálogo es solo para rastreadores vehiculares?
No. Aunque muchos dispositivos están diseñados para vehículos, algunos modelos también se utilizan para rastreo de activos, monitoreo de carga, remolques y casos de uso de telemetría IoT.
