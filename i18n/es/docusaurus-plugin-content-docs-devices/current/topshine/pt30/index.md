# TopShine - PT30

![PT30](./logo.jpg)

El TopShine PT30 es un rastreador GPS personal compacto y de bajo consumo diseñado para un monitoreo sencillo y portátil de ubicación. Proporciona actualizaciones de posición mediante SMS o GPRS y ofrece funciones de seguridad prácticas como comunicación bidireccional, botón de pánico SOS, alarma de geocerca y alerta por exceso de velocidad. El equipo incluye memoria interna para el registro de posiciones y puede generar un enlace de Google Maps por SMS para una visualización rápida en dispositivos móviles.

Como dispositivo compatible con Plaspy, el PT30 puede enviar datos de ubicación y eventos a Plaspy para obtener visibilidad centralizada y control operativo. Su soporte para seguimiento en tiempo real vía web y sus métodos de comunicación habituales lo convierten en una opción práctica para organizaciones o personas que requieren seguimiento simple de personas, mascotas y activos portátiles, sin renunciar a alertas de emergencia y comunicación bidireccional.

## Características principales

- Rastreador GPS personal compacto y de bajo consumo, ideal para monitoreo de personas y activos
- Actualizaciones de posición por SMS y GPRS para conectividad flexible
- Seguimiento en tiempo real en plataforma web y enlace de Google Maps por SMS para vista rápida del mapa
- Comunicación bidireccional y botón de pánico SOS para respuesta ante emergencias
- Memoria interna que puede almacenar una gran cantidad de puntos para recuperación posterior
- Modo de suspensión y batería de respaldo para extender la autonomía cuando se requiera
- Soporta TCP y UDP para comunicación con servidores cuando se usa con plataformas de seguimiento

## Cómo funciona con Plaspy

Al conectarse a Plaspy, el PT30 puede entregar puntos de ubicación y eventos de alarma a la plataforma para que sean visibles en un mapa unificado y en los flujos de trabajo operativos. Plaspy puede mostrar las posiciones rastreadas del dispositivo, el historial registrado y las condiciones de alarma para apoyar las necesidades de monitoreo y reporte.

- Mostrar la ubicación en tiempo real en los mapas y paneles de operador de Plaspy
- Subir y revisar waypoints almacenados e historial de rutas para reproducción y análisis
- Mostrar alarmas de geocerca y exceso de velocidad en Plaspy para recibir notificaciones oportunas
- Registrar eventos SOS y los registros de comunicación bidireccional para la gestión de incidentes
- Usar actualizaciones por SMS o GPRS como fuentes complementarias para que Plaspy mantenga visibilidad aun cuando la conectividad varíe

## Casos de uso típicos

- Monitoreo de niños, adultos mayores o turistas para mayor seguridad personal
- Seguimiento de activos portátiles y equipos durante transporte o almacenamiento
- Localización de mascotas y seguridad básica de animales en tránsito o al aire libre
- Proveer un dispositivo de seguridad portátil para trabajadores aislados o pequeños equipos de campo
- Alquileres por corto plazo y despliegues temporales donde la instalación fija no es práctica

## Por qué elegir este rastreador con Plaspy

El PT30 es una opción sensata para quienes necesitan un dispositivo de seguimiento portátil y sin complicaciones que funcione bien con una plataforma en la nube como Plaspy. Su combinación de reportes por SMS y GPRS, registro a bordo y funciones de emergencia ofrece opciones prácticas para mantener la visibilidad y responder a eventos sin configuraciones complejas.

Para equipos y personas que dependen de Plaspy para la supervisión centralizada de flotas y activos, el PT30 aporta lo esencial para alimentar la plataforma con datos de ubicación, alarmas y comunicación básica, de modo que los incidentes se puedan supervisar y registrar en un solo lugar.
