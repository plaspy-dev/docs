# TopShine - Características del VT200B

Esta página ofrece un resumen público de las funciones del rastreador GPS TopShine VT200B y cómo sus capacidades se integran con los flujos de trabajo de monitoreo y gestión de flotas en Plaspy. Presenta las funciones del VT200B relevantes para ubicación en tiempo real, reporte de eventos, identificación de conductor y telemetría de sensores externos cuando se utiliza con una cuenta de flota en Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación, la variante regional del producto y la configuración del fabricante. Para detalles técnicos específicos del dispositivo, notas de firmware e instrucciones de instalación consulte la documentación oficial y las notas de lanzamiento de TopShine.

## Resumen de funciones

El VT200B es un terminal de rastreo de nivel vehicular diseñado para uso profesional en flotas y antirrobo. Combina un receptor GNSS de alta sensibilidad con conectividad GSM cuatribanda, un registrador interno de datos para uso sin conexión y múltiples opciones de alarmas e entradas para soportar seguimiento continuo y reporte de eventos.

- Reporte de ubicación en tiempo real a través de redes celulares con conmutación a SMS y registro de datos para continuidad cuando no hay red.
- Registrador interno que almacena más de 10,000 registros y sube los datos almacenados cuando se restablece la conexión.
- Funciones de alarma y antirrobo integradas, incluyendo botón SOS, geocercas y posibilidad de corte remoto de motor.
- Opciones de identificación de conductor mediante Bluetooth y RFID para atribuir viajes a conductores individuales.
- Soporte para sensores externos como temperatura, detección de choque y nivel de combustible para ampliar la telemetría.

## Funciones principales del TopShine - VT200B

- Receptor GNSS de alta sensibilidad para fijaciones de posición fiables y telemetría de ruta.
- Conectividad GSM cuatribanda que soporta reportes por SMS y datos GPRS.
- Registrador interno de datos con capacidad de varios miles de registros para continuidad sin conexión.
- Botón SOS y entradas de alarma programables para alertas de emergencia y antirrobo.
- Soporte para corte remoto de motor y alarma por corte de alimentación externa como parte del flujo de respuesta ante robos.
- Opciones de identificación de conductor con Bluetooth y RFID para atribución de viajes.
- Entradas para sensores externos, incluyendo monitoreo de temperatura, detección de choque y combustible cuando se instalan sensores.
- Rango de entrada de alimentación apto para uso automotriz y batería de respaldo para operación durante interrupciones de corriente.

## Cómo funcionan estas funciones con Plaspy

Cuando el VT200B está conectado y reportando, Plaspy recibe la posición, el estado y las entradas de sensores para ofrecer seguimiento en vivo e informes históricos. El registrador offline del dispositivo y las salidas de eventos ayudan a que Plaspy presente historiales continuos y alertas oportunas para la toma de decisiones operativas.

- Posiciones en vivo y trazas de vehículos en tiempo real mostradas en los paneles de Plaspy.
- Rutas históricas restauradas automáticamente después de las subidas del registrador cuando vuelve la conectividad.
- Notificaciones de eventos por SOS, entradas y salidas de geocercas, exceso de velocidad y pérdida de alimentación visibles en el flujo de alertas de Plaspy.
- Registros de identificación de conductor desde Bluetooth o RFID vinculados a los viajes para responsabilidad y reportes.
- Lecturas de sensores externos como temperatura o estado de combustible disponibles en las vistas de telemetría cuando esos sensores están instalados y reportando.

## Casos de uso típicos

- Seguimiento centralizado de flotas para visibilidad de rutas, verificación de horarios y ubicación de activos.
- Despliegues antirrobo usando alertas SOS, monitoreo de geocercas y corte remoto de motor para recuperación.
- Transporte refrigerado o carga sensible a la temperatura cuando se instala un sensor térmico.
- Monitoreo de tanques de combustible y control de inventario cuando se integran sensores externos de combustible.
- Identificación de conductores y atribución de viajes para nómina, cumplimiento o análisis de comportamiento en flotas mixtas.
- Flotas mixtas que requieren una instalación compacta de calidad vehicular y registro continuo.

## Notas sobre disponibilidad de funciones

- Algunas funciones requieren builds de firmware específicos u opciones de hardware opcionales como sensores externos, módulos RFID o módulos Bluetooth.
- Las decisiones de instalación y el cableado influyen en el comportamiento de alarmas como el corte remoto de motor y la alarma por corte de alimentación externa.
- El soporte celular regional y la normativa local afectan la disponibilidad del servicio GSM; confirme las bandas de radio del dispositivo y la compatibilidad con redes locales.
- Actualizaciones de firmware del fabricante y revisiones de hardware pueden añadir, modificar o eliminar capacidades respecto a unidades anteriores.
- Revise la documentación de TopShine para el conexionado de sensores, configuración de entradas/salidas y prácticas recomendadas de instalación.

## Por qué usar Plaspy con estas funciones

Usar el VT200B con Plaspy centraliza la posición del vehículo, los eventos y la telemetría de sensores en una sola plataforma, de modo que los operadores pueden monitorear flotas, investigar incidentes y mantener la continuidad operativa cuando las redes se interrumpen. La combinación de un registrador interno y reportes en tiempo real ayuda a conservar el historial mientras permite alertas inmediatas por robo, pérdida de alimentación o eventos de emergencia.
