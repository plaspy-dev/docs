# TopShine - MT02-4G: Funciones

Esta página describe las funciones públicas del rastreador GPS TopShine MT02-4G y cómo se integran con Plaspy. Está orientada a las capacidades prácticas que usted puede esperar cuando el MT02-4G se conecta a Plaspy para ubicación en tiempo real, reproducción histórica de rutas, alertas de eventos y gestión del ciclo de vida del dispositivo.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Para detalles técnicos precisos, diagramas de cableado y las notas de firmware más recientes, consulte la documentación y las notas de lanzamiento del fabricante.

## Resumen de funciones

El MT02-4G es un rastreador vehicular 4G compacto diseñado para uso continuo en flotas, registro de datos offline y reducción de mantenimiento mediante actualizaciones OTA. En combinación con Plaspy, el dispositivo ofrece visibilidad y detección de eventos adecuada para automóviles, motocicletas y vehículos comerciales.

- Rastreo GPS en tiempo real y reporte de ubicación en vivo hacia Plaspy para monitoreo y despacho.
- Registrador de datos integrado con capacidad para aproximadamente 26,000 puntos offline para mantener la telemetría cuando la red no está disponible.
- Conectividad celular 4G para reportes confiables y compatibilidad con redes futuras.
- Amplio rango de entrada de voltaje DC para instalaciones flexibles en distintos tipos de vehículos.
- Batería de respaldo de 500 mAh para capturar eventos clave durante pérdidas de energía principal.
- Capacidad de actualización de firmware OTA para simplificar el mantenimiento y mantener los dispositivos al día.

## Características principales del TopShine - MT02-4G

- Compatibilidad inmediata con Plaspy para integración rápida en paneles web y móviles.
- Conectividad celular 4G que permite actualizaciones frecuentes de posición y transferencia de telemetría.
- Registrador de datos a bordo (2MB estándar, ampliable) capaz de almacenar decenas de miles de puntos para carga posterior.
- Soporte de entrada de voltaje amplio para operación estable en autos, camiones y motocicletas.
- Batería de respaldo integrada para posicionamiento offline y reporte de eventos durante interrupciones eléctricas.
- Soporte de actualización de firmware por aire para reducir visitas de servicio en sitio.
- Soporte para monitoreo de combustible e identificación de conductor mediante accesorios opcionales según implementación del fabricante.
- Control remoto de inmovilizador y soporte de relé disponible cuando se usa con accesorios externos aprobados.

## Cómo interactúan estas funciones con Plaspy

Plaspy recibe y presenta la telemetría del MT02-4G para que los equipos puedan monitorear la posición, revisar el historial y responder a eventos. Plaspy detecta automáticamente los protocolos compatibles del rastreador y muestra los datos del dispositivo para uso operativo, alertas e informes.

- Posición en vivo y reproducción del historial de rutas visibles en las vistas de mapa y línea de tiempo de Plaspy.
- Alertas basadas en eventos como pérdida de energía, batería baja, activación de geocercas y notificaciones SOS entregadas a Plaspy para atención inmediata.
- Los puntos registrados en modo offline se cargan en Plaspy cuando el dispositivo recupera conectividad, permitiendo análisis posteriores al evento.
- Funciones de gestión del dispositivo, como desencadenar actualizaciones OTA o revisar el estado del firmware, se coordinan junto con los datos de rastreo en la plataforma.
- Entradas derivadas de accesorios como monitoreo de combustible o identificación de conductor aparecen en Plaspy si el accesorio está instalado y el fabricante expone esa telemetría.

## Casos de uso típicos

- Operaciones de flotas que requieren visibilidad continua de ubicación y historial de rutas para vehículos y motocicletas.
- Flujos de trabajo contra robo donde el control remoto del inmovilizador, alertas SOS y eventos de geocerca apoyan la recuperación.
- Programas de gestión de combustible que integran sensores ultrasónicos o cortables para detección de reabastecimiento y fugas cuando son compatibles.
- Identificación de conductores y monitoreo de seguridad usando accesorios de identificación opcionales y alertas por eventos para coaching y cumplimiento.
- Gestión distribuida de dispositivos donde las actualizaciones OTA reducen las visitas de servicio en una flota extensa.
- Análisis posterior a incidentes utilizando los puntos registrados por el datalogger durante pérdidas de red.

## Notas sobre disponibilidad de funciones

- Algunas funciones requieren accesorios opcionales o cableado específico y pueden no estar disponibles en todas las instalaciones.
- Las revisiones de firmware pueden cambiar el comportamiento, añadir capacidades o modificar valores por defecto. Verifique la versión de firmware para expectativas de funciones.
- Las revisiones de hardware y las variantes regionales pueden afectar el soporte de bandas celulares y la disponibilidad de ciertas entradas o salidas.
- La calidad de la instalación y el cableado del vehículo influyen en funciones I/O como el control de relés e integraciones de accesorios.
- Consulte la documentación de TopShine para listas de compatibilidad de accesorios y especificaciones de hardware detalladas.

## Por qué usar Plaspy con estas funciones

Usar el MT02-4G con Plaspy ayuda a las organizaciones a centralizar la ubicación, los eventos y la gestión de dispositivos en una sola plataforma. Plaspy combina rastreo en vivo, reproducción histórica y alertas configurables para que los equipos operativos mantengan la visibilidad, respondan a incidentes y administren el ciclo de vida de los dispositivos sin alternar entre sistemas distintos.
