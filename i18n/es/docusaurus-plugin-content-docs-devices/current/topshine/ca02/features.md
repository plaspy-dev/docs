# TopShine - Características del CA02

Esta página describe el contexto público de características para el uso del TopShine CA02 con la plataforma Plaspy. Se centra en las capacidades del CA02 que son relevantes para usuarios de Plaspy y operadores de flotas, explicando cómo el dispositivo reporta posición y telemetría de alarmas, y qué funcionalidades puede esperar ver dentro de Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación, las condiciones de red regionales y la implementación del fabricante. Use esta página como una guía general y consulte la documentación oficial de TopShine para obtener los detalles definitivos del dispositivo.

## Resumen de funciones

El CA02 es un localizador GPS integrado en el tablero con funciones de seguridad vehicular pensadas para autos particulares y vehículos comerciales ligeros. Combina alarma audible y detección de manipulación con reporte GPS en tiempo real y salidas por relé para inmovilización, lo que permite supervisión centralizada y control remoto a través de Plaspy.

- Rastreo GPS en tiempo real para ubicación en vivo y reproducción histórica de rutas cuando se utiliza con Plaspy.
- Sirena integrada y sensor de choque para alarmas audibles y detección de intentos de manipulación en el vehículo.
- Comandos de cierre centralizado y apertura de cajuela disponibles vía plataforma, SMS o controles en la app.
- Corte de motor u oil cut por relé para inmovilización remota cuando se activa.
- Alarmas de geocerca, exceso de velocidad y movimiento entregadas como eventos para mayor conocimiento situacional.
- Módulos opcionales de expansión como monitoreo de combustible y micrófono externo cuando se instalan.

## Funciones principales del TopShine CA02

- Reporte de ubicación GPS en tiempo real y compatibilidad con reproducción de historial de rutas.
- Sirena integrada y sensor de choque para detectar impactos o manipulación y activar alertas audibles.
- Control de cierre centralizado y soporte para apertura remota de cajuela para gestionar el acceso al vehículo.
- Salidas por relé para corte de motor u oil cut que permiten la funcionalidad de inmovilizador remoto.
- Reporte de alarmas de geocerca y exceso de velocidad como tipos de eventos estándar.
- Detección de interferencia GSM (jamming) y reporte de alarma para apoyar flujos de trabajo antirrobo.
- Soporte para expansiones opcionales como monitoreo de combustible y micrófono externo cuando están instaladas.

## Cómo funcionan estas funciones con Plaspy

Cuando el CA02 está instalado y configurado para reportar a Plaspy, envía actualizaciones de ubicación y eventos de alarma a la plataforma para que los administradores de flota y propietarios puedan monitorear el estado y responder a incidentes desde una única interfaz.

- Las ubicaciones en vivo y el historial de rutas aparecen en Plaspy para seguimiento y reproducción.
- Eventos de alarma como activaciones del sensor de choque, puertas abiertas y movimiento se entregan a Plaspy para notificación inmediata.
- Las infracciones de geocerca y los eventos de exceso de velocidad pueden mostrarse como alertas dentro del panel de Plaspy y en las aplicaciones móviles.
- Los comandos de inmovilización basados en relé pueden enviarse desde Plaspy o mediante métodos de control soportados al CA02 cuando se requiere corte remoto del motor.
- La telemetría opcional de módulos de expansión se presentará en Plaspy cuando dichos módulos estén instalados y reporten datos.

## Casos de uso típicos

- Protección antirrobo de flotas mediante detección de choque, activación de sirena y control remoto de inmovilizador.
- Monitoreo de vehículos en tiempo real y reproducción de trayectos para automóviles particulares y flotas ligeras.
- Seguridad de vehículos estacionados con alertas de manipulación y disuasión audible combinada con vigilancia por geocerca.
- Operaciones de acceso remoto y comodidades como cierre centralizado y liberación de cajuela desde la plataforma o un dispositivo móvil.
- Supervisión integrada de flota donde se requiere monitoreo de combustible opcional junto con GPS y telemetría de alarmas.

## Notas sobre disponibilidad de funciones

- El comportamiento de las funciones depende de la versión de firmware y la revisión de hardware; algunas alarmas o funciones opcionales requieren versiones específicas de firmware.
- Las expansiones opcionales, como monitoreo de combustible o micrófono externo, requieren hardware adicional y una instalación específica.
- El tipo de instalación influye en ciertas funciones; por ejemplo, el cableado a salidas de relé e interfaces de cierre centralizado debe ser realizado por un instalador calificado.
- El CA02 utiliza 2G GSM para conectividad celular según lo especificado por el fabricante; la disponibilidad de red y las regulaciones regionales pueden afectar el servicio.
- Consulte la documentación de TopShine para variantes regionales del modelo y las bandas de frecuencia o opciones compatibles.

## Por qué usar Plaspy con estas funciones

Combinar el TopShine CA02 con Plaspy ofrece a las organizaciones visibilidad centralizada sobre la ubicación de los vehículos, alertas de seguridad e instrumentos de inmovilización. Plaspy recopila y presenta la telemetría del CA02 para que los responsables puedan ver posiciones en tiempo real, recibir notificaciones de incidentes y aplicar controles remotos desde la misma plataforma utilizada para otros activos de la flota.

To learn more about how Plaspy supports the CA02 and other compatible trackers visit https://www.plaspy.com. For the most current device specific details, firmware notes and manufacturer instructions verify the information at the TopShine website https://www.gztopshine.com/ which is the source for official technical documentation.
