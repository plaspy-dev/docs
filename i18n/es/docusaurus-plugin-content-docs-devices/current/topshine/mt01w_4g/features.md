# TopShine - MT01W-4G: Características

Esta página ofrece una descripción pública y no sensible de las funcionalidades del TopShine MT01W-4G y de cómo se utilizan en Plaspy para la supervisión de flotas y vehículos. Se enfoca en las capacidades prácticas que puede esperar al integrar este modelo con Plaspy y aclara qué tipos de datos y flujos operativos puede soportar el dispositivo dentro de la plataforma.

La disponibilidad exacta de funciones puede variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Use esta página como guía de integración con Plaspy y consulte al fabricante para obtener los detalles técnicos más recientes y específicos del dispositivo.

## Resumen de funcionalidades

El MT01W-4G es un rastreador GPS compacto con capacidades de video, diseñado para la gestión de flotas y la seguridad vehicular cuando se requiere soporte de cámaras integradas y telemetría. Combina conectividad celular, un hotspot WiFi integrado para cámaras, grabación a bordo y un conjunto de alertas de seguridad y protección configurables para reducir la necesidad de dispositivos adicionales.

- Seguimiento GPS en tiempo real sobre 4G CAT1 para actualizaciones de ubicación oportunas y telemetría de baja latencia.
- Hotspot WiFi integrado para conectar múltiples cámaras WiFi, permitiendo transmisión en vivo y monitoreo multicanal.
- Grabación de video en tarjeta SD con acceso remoto a las transmisiones para revisión de incidentes.
- Alertas de seguridad del vehículo que incluyen SOS, detección de choque, geocerca, exceso de velocidad y notificaciones por robo o rellenado.
- Soporte de inmovilizador remoto mediante relé para corte de motor seguro cuando se combina con comandos desde la plataforma.

## Funciones principales del TopShine - MT01W-4G

- Conectividad celular 4G CAT1 para reportes continuos de posición y telemetría.
- Hotspot WiFi integrado que admite varias cámaras WiFi para video en vivo y monitoreo sincronizado.
- Grabadora de video a bordo con almacenamiento en tarjeta SD para captura local de evidencia y reproducción.
- Amplio rango de entrada de energía vehicular y batería interna de respaldo para mantener la operación ante pérdida de alimentación.
- Alertas de seguridad y protección que incluyen SOS, detección de choques, geocercas y notificaciones por exceso de velocidad.
- Corte remoto del motor vía relé para soportar flujos de trabajo de inmovilización cuando se usan comandos remotos.
- Soporte para identificación de conductor mediante iButton o RFID pasivo para asociar viajes con el personal.
- Soporte opcional de voz bidireccional con altavoz y micrófono para comunicación dentro del vehículo.

## Cómo funcionan estas funciones con Plaspy

Al integrar el MT01W-4G en Plaspy, la ubicación del rastreador, las alertas y los eventos relacionados con video se integran en el panel de Plaspy para dar visibilidad centralizada en una flota mixta. Plaspy detecta automáticamente los protocolos compatibles del rastreador e incorpora las posiciones y alarmas reportadas para que usted pueda actuar sobre eventos y revisar datos históricos.

- Ubicación en vivo y telemetría aparecen en los mapas y pueden reproducirse en trazas históricas dentro de Plaspy.
- Alertas como SOS, choque, geocerca y exceso de velocidad se envían a Plaspy como notificaciones y registros de eventos.
- Los eventos de identificación de conductor se registran para asociar viajes y marcas temporales con personal específico en la plataforma.
- Las transmisiones de video de cámaras WiFi conectadas y las grabaciones en SD pueden accederse junto con las trazas GPS para verificar incidentes de forma sincronizada.
- Los comandos de inmovilización remota y los flujos de trabajo relacionados están disponibles para administradores cuando las reglas de negocio requieren deshabilitar un vehículo.
- Plaspy centraliza los datos del dispositivo para que las flotas puedan combinar ubicación, evidencia de video y alertas en reportes operativos.

## Casos de uso típicos

- Operaciones de flota que requieren seguimiento en vivo y video sincronizado a bordo para seguridad y capacitación.
- Flujos de trabajo antirobo que combinan geocercas, alertas por robo y inmovilización remota para una respuesta rápida.
- Reconstrucción de incidentes y soporte de reclamaciones usando grabaciones en tarjeta SD y transmisiones en vivo alineadas con datos GPS.
- Programas de responsabilidad del conductor mediante identificación por RFID o iButton vinculada a los registros de viaje.
- Despliegues en flotas mixtas que necesitan una unidad compacta, resistente al agua, con amplia tolerancia de voltaje y respaldo de energía.
- Monitoreo de combustible y detección de sustracción cuando el equipo se conecta a sensores externos compatibles y se configura para reportar esos eventos.

## Notas sobre disponibilidad de funciones

- Las revisiones de firmware y software pueden afectar qué funciones están habilitadas o cómo se reportan las alertas; confirme la versión de firmware para cualquier capacidad específica.
- Las revisiones de hardware u opciones de accesorios determinan el soporte para elementos como lectores de identificación de conductor, módulos de voz y sensores externos.
- La cantidad de cámaras y el rendimiento de transmisión dependen de las condiciones de red, los modelos de cámara y la configuración del hotspot en el dispositivo.
- El soporte de bandas celulares regionales y la provisión por parte de los operadores varían según el mercado y pueden afectar la conectividad y el comportamiento del servicio.
- Para cualquier implementación que requiera inmovilización, comandos remotos o monitoreo de combustible, verifique el cableado, la instalación y la normativa local antes del despliegue.
