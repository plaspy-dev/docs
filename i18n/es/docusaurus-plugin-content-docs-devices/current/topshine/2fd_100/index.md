# TopShine - 2FD-100

![2FD-100](./tracker.jpg)

El 2FD-100 es un rastreador GPS OBD2 bidireccional integrado con una alarma vehicular inteligente 4G, diseñado para seguridad profesional y conectividad en vehículos. Como unidad todo en uno, combina posicionamiento, entradas y salidas de alarma, un punto de acceso WiFi y comunicación de voz bidireccional para ofrecer seguimiento en tiempo real y protección antirrobo en instalaciones exigentes. Fabricado con componentes de grado industrial y un módulo GSM/GPS con IMEI legal, el dispositivo está pensado para despliegues de flota y entornos donde la telemetría confiable y la gestión de alarmas son fundamentales.

Este modelo es compatible con Plaspy y puede configurarse para enviar posiciones, eventos de alarma y estado del vehículo a Plaspy para monitoreo y administración centralizada. Sus funciones de conectividad y control incluidas lo hacen útil para organizaciones que desean integrar monitoreo de cámaras, WiFi para pasajeros e inmovilización remota en sus flujos de trabajo de Plaspy, manteniendo también la opción de usar la plataforma propia de TopShine desde el primer momento.

## Características principales

- Rastreador OBD2 bidireccional combinado con una alarma 4G inteligente para seguridad y rastreo integrados.
- Punto de acceso WiFi integrado para ofrecer internet a pasajeros y soportar monitoreo de cámaras a bordo.
- Comunicación de voz bidireccional y funciones de control remoto para bloqueo/desbloqueo, apertura de cajuela e inmovilización cuando están habilitadas.
- Conjunto de alarmas que incluye detección de choque, exceso de velocidad, geocercas, movimiento y alertas SOS/pánico.
- Construcción de grado industrial con un módulo GSM/GPS independiente y IMEI legal para telemetría confiable.
- Expansible con accesorios opcionales como sirenas, sensores y opciones de monitoreo de combustible para instalaciones a medida.

## Cómo funciona con Plaspy

Cuando se configura para Plaspy, el 2FD-100 envía actualizaciones de ubicación, eventos de alarma y estado del vehículo a Plaspy para que los operadores de flota puedan ver posiciones en vivo, revisar el historial y responder incidentes desde una sola plataforma. Plaspy recibe los datos de eventos y ofrece funciones comunes de monitoreo y control que se usan habitualmente en la gestión vehicular.

- Ubicación en tiempo real y reproducción de rutas históricas para visibilidad de la flota y apoyo en despacho.
- Reporte de eventos y alarmas incluyendo alertas de choque, violaciones de geocerca, exceso de velocidad y notificaciones SOS.
- Envío de comandos remotos para bloqueo/desbloqueo, apertura de cajuela y control opcional del inmovilizador a través de la interfaz de Plaspy.
- Soporte para monitoreo de cámaras y dispositivos WiFi para ver cámaras conectadas y audio bidireccional cuando el hardware de cámara lo permita.
- Informes y alertas a nivel de flota para ayudar en la supervisión operativa, planificación de mantenimiento y respuesta a incidentes.

## Casos de uso típicos

- Gestión de flotas para supervisión diaria de rutas, despacho y seguimiento de activos.
- Protección antirrobo y respuesta rápida mediante eventos de alarma e inmovilización remota.
- Vehículos de pasajeros y transporte VIP que ofrecen WiFi a bordo y monitoreo por cámara para seguridad y confort.
- Operaciones de renta y leasing que requieren alertas de geocerca, monitoreo de choques y SOS, y capacidades de control remoto.
- Monitoreo de combustible y consumo cuando se integran sensores de combustible opcionales para control de costos y detección de hurto.

## Por qué elegir este rastreador con Plaspy

El 2FD-100 combina hardware de alarma vehicular consolidado con conectividad moderna para ofrecer a los gestores una opción práctica de seguimiento y seguridad en tiempo real. Su mezcla de integración OBD2, E/S de alarma y un hotspot WiFi a bordo lo hace adaptable a despliegues de flotas mixtas que requieren tanto monitoreo como servicios para pasajeros. La compatibilidad con Plaspy permite a las organizaciones consolidar datos de rastreo y alertas dentro de sus flujos de trabajo existentes para reportes y supervisión operativa.

Si usted desea un dispositivo integrado de alarma y rastreo que pueda informar a Plaspy y que además funcione con el software de TopShine desde el primer momento, el 2FD-100 es una opción flexible para flotas, operaciones de renta y transporte de pasajeros.
