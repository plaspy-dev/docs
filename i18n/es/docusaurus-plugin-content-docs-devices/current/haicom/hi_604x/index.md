# Haicom - HI-604X

![HI-604X](./logo.jpg)

El rastreador GPS Haicom HI-604X es parte de la nueva serie X de rastreadores GPRS con funciones mejoradas. Este rastreador no cuenta con DTMF, pero ofrece nuevas características que permiten al usuario programar y configurar diferentes aspectos del dispositivo, como el APN, el puerto, el intervalo de seguimiento y el número de teléfono para marcar de nuevo. Además, el HI-604X permite controlar el monitor de aceite de corte y actualizar el firmware desde la plataforma de seguimiento de GPRS de Haicom.

Una de las ventajas de este rastreador es su versatilidad en cuanto a la configuración. El usuario puede programar el dispositivo tanto desde una computadora utilizando el cable USB como a través de SMS desde un teléfono móvil. Además, el HI-604X puede enviar la posición en tiempo real a números de teléfono predefinidos, permitiendo al usuario verificar la ubicación desde un teléfono inteligente con un enlace a un mapa.

El HI-604X cuenta con una memoria flash interna que permite al gestor mantener un registro de las posiciones, incluso en áreas sin cobertura de red GSM. Con el software de seguimiento de Haicom, el usuario puede ver fácilmente los datos de posición en un plano de historia. Además, el rastreador cuenta con un sensor de movimiento que permite configurar el dispositivo para que entre en modo de sueño y ahorre energía cuando no está en uso.

Este rastreador GPS de Haicom es una solución de seguimiento de última generación con múltiples funciones. Es ideal para una amplia gama de aplicaciones, desde vehículos hasta maquinaria agrícola y contenedores. El HI-604X ofrece una combinación perfecta de tecnología avanzada y asequibilidad, convirtiéndolo en una opción ideal para aquellos que buscan una solución de seguimiento GPS confiable y versátil.

### Características destacadas:

- Sistema GSM cuatribanda \(850/900/1800/1900 MHz\)
- Receptor GPS externo de alto rendimiento SiRF Star III
- Antenas GSM internas activas
- Comunicación avanzada a través de SMS/TCP/UDP/HTTP
- Programación y control remoto a través de OTA \(Over the Air\) y configuraciones USB
- Sensor de movimiento para ahorrar energía
- Soporte para alarmas de velocidad, movimiento y pérdida de potencia de emergencia
- Informe de ubicación en tiempo real y seguimiento del estado del vehículo
- Funciones premium: GPS y A-GPS, geo-cercado, kit de manos libres, antirrobo y función de registro de datos
- Alarma de batería baja y estado de tensión de la batería
- Plataforma de software de seguimiento GPRS y servidor gratuitos
- Cobertura mundial sin programas adicionales ni costos ocultos
- Sensor de movimiento incorporado con modo de sueño profundo
- Batería interna de 5500 mAh para alimentación independiente
- Impermeable y resistente para entornos difíciles
- Fijación magnética para una fácil sujeción
- GPS de baja potencia
- Acceso 24/7 a la ubicación de los activos
- Seguimiento en tiempo real configurable
- Recuperación de activos robados
- Historial de activos en línea desde cualquier computadora
