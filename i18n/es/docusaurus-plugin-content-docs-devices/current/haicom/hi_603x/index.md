# Haicom - HI-603X

![HI-603X](./logo.jpg)

El rastreador GPS Haicom HI-603X es parte de la nueva serie X de rastreadores GPRS con funciones mejoradas. Este rastreador permite al usuario programar y configurar diversas opciones, como el APN, el puerto, el intervalo de seguimiento y el número de teléfono para marcar. También cuenta con la capacidad de controlar el monitor de aceite de corte y actualizar el firmware desde la plataforma de seguimiento GPRS. Además, el rastreador puede enviar la posición en tiempo real a través de un enlace web a números de teléfono designados, lo que permite al usuario verificar la ubicación en tiempo real desde un teléfono inteligente. El HI-603X también cuenta con una memoria flash interna que registra las posiciones incluso cuando no hay cobertura de red GSM.

El HI-603X es una plataforma de comunicación multifuncional y rentable que integra un chipset GPS de alta sensibilidad y un módulo de comunicación GSM cuatribanda \(850/900/1800/1900\). Este rastreador compacto y ligero se instala fácilmente y proporciona al usuario la ubicación GPS en tiempo real, así como el estado del vehículo de forma precisa y constante en el servidor. Además, permite al usuario controlar el vehículo de forma remota desde un ordenador. Con todas estas características, el HI-603X es ideal para aplicaciones de gestión de flotas, seguridad vehicular, respuesta de emergencia y transporte de mercancías.

Algunas de las características destacadas del Haicom HI-603X incluyen:

- Receptor GPS de alto rendimiento con chipset SiRF Star III
- Comunicación avanzada a través de SMS, TCP, UDP y HTTP
- Programación, control y actualización del firmware a través de OTA y USB
- Sensor de movimiento para ahorro de energía
- Soporte para alarmas de velocidad, movimiento y pérdida de potencia en tiempo real
- Intervalo de envío ajustable y mínimo de 5 a 10 segundos
- Fuente de alimentación de 9V a 28V DC
- Batería de respaldo de 550mAh
- Dimensiones de 116mm x 55mm x 24mm
- Rango de temperatura de funcionamiento de -20 °C a 55 °C
- Compatible con frecuencias GSM 900/1800/1900MHz
- Precisión de posición de 10 metros, 2D RMS
- Precisión de velocidad de 0.1 m/s
- Precisión de tiempo de 1 segundo sincronizado con el GPS
