# Astra Telematics - AT210

![AT210](./logo.jpg)

El rastreador GPS Astra Telematics AT210 ha sido diseñado utilizando la última tecnología, incluyendo un procesador Cortex M3 y el GPS SiRFStar IV. Este dispositivo cuenta con un diseño de apariencia automotriz, sellado IP67 a prueba de agua y antenas integradas.

El Astra Telematics AT210 es fácil de instalar y tiene una apariencia poco visible. Además, permite el uso de una antena GPS externa opcional para aplicaciones en las que el montaje del dispositivo con buena visibilidad GPS no es práctico.

Características destacadas del rastreador GPS Astra Telematics AT210:

- Mercado objetivo: Track & Trace, recuperación de vehículos, gestión de flotas, sistemas de navegación inteligentes
- Banda GSM: cuatribanda completa
- Voz: No
- Realizar copias de seguridad de la batería: Sí
- Memoria interna: Sí
- Método de comunicación: GPRS, TCP, UDP
- Posición por: Tiempo, Distancia
- Ahorro de energía: Sí
- Entradas digitales: 2
- Eventos internos basados: Sí
- Antenas: GPS interno, GSM interno
- Carcasa: Plástico
- Conexiones extras: Identificación del conductor, puerto serie
- Hecho en: Europa
