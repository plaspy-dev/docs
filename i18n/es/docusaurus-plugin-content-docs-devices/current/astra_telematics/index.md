# Astra Telematics

Astra Telematics desarrolla dispositivos de rastreo GPS y telemática usados habitualmente para monitorizar vehículos, activos y flotas. Esta página explica cómo el hardware de Astra Telematics puede integrarse con Plaspy, qué esperar de estos dispositivos y cómo encontrar el rastreador adecuado para su caso de uso utilizando el catálogo que aparece a continuación.

## Cómo funcionan los dispositivos Astra Telematics con Plaspy

Plaspy se integra con los dispositivos Astra Telematics recibiendo la telemetría que envían y transformando esos datos en vistas de mapa, alertas y reportes dentro de la plataforma Plaspy. La integración cubre posicionamiento GPS básico, estado de movimiento y señales telemáticas estándar. Para cada dispositivo Astra Telematics compatible, Plaspy ofrece los parámetros de conectividad y el mapeo de datos necesarios para transmitir los mensajes del equipo a su cuenta en Plaspy.

Los pasos de configuración y los detalles de protocolo se proporcionan en la página de cada dispositivo dentro de Plaspy. Use el BrandCatalog abajo para seleccionar un modelo y abrir su guía dedicada cuando necesite instrucciones paso a paso, parámetros de servidor o el formato de mensajes.

## Funcionalidades comunes en los dispositivos Astra Telematics

Aunque los modelos varían, los rastreadores de Astra Telematics suelen incluir una serie de funciones que encajan bien con las necesidades de seguimiento de flotas y activos. Entre las capacidades que podrá aprovechar con Plaspy están:
- Posicionamiento GPS y intervalos de reporte configurables
- Detección de movimiento y encendido para vehículos
- Monitoreo básico de entradas/salidas (IO) para sensores externos
- Reporte de batería y fuente de alimentación para rastreadores portátiles o de activos
- Soporte para formatos de reporte telemático estándar compatibles con plataformas en la nube

Plaspy utiliza estas señales para generar historial de ubicaciones, eventos de geocerca y paneles de telemetría sin requerir cambios específicos por modelo en la plataforma.

## Casos de uso típicos para rastreadores Astra Telematics

Los dispositivos Astra Telematics se emplean en una variedad de escenarios donde se requiere reporte fiable de posición y eventos. Los casos de uso habituales incluyen:
- Rastreo de vehículos en flotas pequeñas y medianas para supervisión de rutas y registros de servicio
- Seguimiento de remolques y activos para controlar ubicación y movimientos
- Monitoreo de vehículos de servicio para registrar tiempos de trabajo y recorridos
- Prevención y recuperación de robos de equipos mediante alertas por movimiento

Plaspy adapta los reportes y las reglas a estos casos de uso para que los equipos puedan concentrarse en la operación en lugar de en la integración de dispositivos.

## Por qué elegir Plaspy para monitorear dispositivos Astra Telematics

Plaspy ofrece una plataforma agnóstica al dispositivo que admite el hardware de Astra Telematics y, al mismo tiempo, entrega funciones de nivel empresarial:
- Telemetría centralizada y visualización en mapas para flotas con dispositivos mixtos
- Herramientas flexibles de alertas y reportes ajustadas a eventos del dispositivo
- Ingesta escalable de mensajes con almacenamiento histórico de rutas y eventos
- Guías y referencias de configuración para simplificar la incorporación de dispositivos Astra Telematics

Usar Plaspy con equipos Astra Telematics le permite combinar esos rastreadores con otras marcas y ofrecer una vista operativa unificada.
