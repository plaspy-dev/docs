# V-SUN - TLT-1D

![TLT-1D](./logo.jpg)

El dispositivo TLT-1D de V-SUN es un rastreador de coche con controles remotos GSM / GPS, compatible con SMS o GPRS TCP. Este dispositivo es ideal para fijar la posición incluso en un estado débil de la señal, lo que garantiza una ubicación precisa en todo momento.

Algunas de las características destacadas del TLT-1D incluyen:

- Soporte para redes GSM 900/1800MHz \(opcionalmente 850/1900MHz\), lo que permite su uso en todo el mundo.
- Compatibilidad con comunicación SMS o conexión GPRS TCP, lo que brinda opciones flexibles para el seguimiento y control del dispositivo.
- Capacidad para configurar hasta tres números de teléfono, lo que permite enviar la ubicación exacta a través del botón de SOS para una acción de rescate inmediata.
- Función de corte de electricidad que soporta el comando de recuperación de petróleo, lo que brinda mayor seguridad y control sobre el vehículo.

El TLT-1D de V-SUN es una opción confiable y eficiente para el seguimiento de vehículos, ofreciendo una amplia gama de características y funcionalidades que garantizan una experiencia de rastreo óptima.
