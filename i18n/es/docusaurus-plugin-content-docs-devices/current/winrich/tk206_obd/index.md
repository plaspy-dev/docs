# Winrich - TK206 OBD

![TK206 OBD](./logo.jpg)

El rastreador GPS TK206 OBD de Winrich es un dispositivo basado en la red GSM/GPRS y en el sistema de colocación por satélite GPS. Con una antena incorporada de G/M y GPS, se inserta directamente en el puerto OBDII del vehículo para leer los datos de la computadora del automóvil. Esto le permite localizar y gestionar el vehículo de forma remota a través de SMS o GPRS. La instalación es fácil y no requiere de un arnés de cableado.

El TK206 es nuestro último diseño de rastreador OBD plug-and-play. Puede leer los parámetros del OBD de la ECU del automóvil y realizar un seguimiento GPS para la localización del vehículo. Todos los datos se transmiten al servidor backend para fines de diagnóstico y seguimiento remoto.

Este rastreador GPS es ideal para aplicaciones en coches, vehículos de 12-24V, taxis y gestión de flotas. Ofrece una variedad de funciones principales, como seguimiento en tiempo real basado en la ubicación \(LBS\) y GPS, monitoreo de geovalla, alarma de movimiento y exceso de velocidad, así como alarmas de bajo voltaje y apagado de energía externa.

Características destacadas:

- Rastreador OBD II para vehículos \(9V-50V\)
- Servicio basado en ubicación \(LBS\) + GPS para seguimiento en tiempo real
- Monitoreo de geovalla, movimiento y alarma de exceso de velocidad
- Alarma de bajo voltaje y apagado de energía externa
- Alarmas de choque y ACC bajo el modo ARM
