# Winrich - GT06

![GT06](./tracker.jpg)

El GT06 es un terminal de posicionamiento GPS vehicular compacto e inteligente, diseñado para el seguimiento en tiempo real y la gestión remota de vehículos. Combina posicionamiento satelital con comunicación GSM GPRS cuatribanda para ofrecer actualizaciones continuas de ubicación, telemetría y reporte de alarmas por SMS o GPRS TCP. Diseñado como un mini rastreador para vehículos, el GT06 está pensado para automóviles, motocicletas, vehículos eléctricos y embarcaciones pequeñas donde se requiere monitoreo sencillo y reporte de eventos.

Como dispositivo compatible con Plaspy, el GT06 puede reenviar su posicionamiento y telemetría a una instancia de Plaspy con una configuración mínima. El dispositivo soporta configuración de IP y puerto del servidor y dispone de un conjunto completo de comandos por SMS, por lo que puede dirigirse a enviar datos GPRS TCP o reportes por SMS a Plaspy para visibilidad en vivo, informes históricos y entrega de alertas. Esto hace al GT06 una opción práctica para operadores que desean integración con Plaspy sin tener que modificar ampliamente su hardware.

## Características principales

- Mini rastreador compacto, ideal para vehículos donde el espacio y la simplicidad son importantes.
- Compatible con Plaspy mediante configuración de IP y puerto del servidor y comandos por SMS para dirigir los datos a su plataforma.
- Telemetría vehicular esencial: detección de encendido ACC, sensor de vibración/impacto y alarma SOS para avisos de eventos.
- Control remoto de relé para corte de combustible o energía, soportando flujos de trabajo de inmovilización bajo criterios de seguridad.
- Batería de respaldo integrada para alarmas por corte de energía y operación corta en ausencia de alimentación externa.
- Conectividad GSM GPRS cuatribanda que permite amplia cobertura geográfica y transporte remoto de datos.

## Cómo funciona con Plaspy

Integrar el GT06 con Plaspy es, en gran medida, una tarea de configuración del dispositivo: apunte el rastreador a su servidor Plaspy y comenzará a enviar ubicación y telemetría compatible para seguimiento en tiempo real, alertas e informes históricos. Si la conexión GPRS no está disponible, el dispositivo aún puede responder con posiciones y aceptar comandos vía SMS, lo que ayuda a mantener el monitoreo en escenarios de conectividad limitada.

- Actualizaciones en tiempo real de ubicación y telemetría enviadas a Plaspy para visibilidad de la flota.
- Estado de encendido ACC reportado a Plaspy para soportar registro de actividad y filtrado de eventos.
- Alarmas SOS y por vibración/impacto entregadas como eventos de alerta en Plaspy para una respuesta rápida.
- Control remoto de relé para habilitar inmovilización o corte de energía desde Plaspy o un administrador autorizado.
- Soporte de comandos por SMS para diagnóstico remoto, configuración y reporte de respaldo cuando la conectividad de datos es limitada.

## Casos de uso típicos

- Gestión de flotas y supervisión de rutas donde la ubicación en tiempo real y los registros de encendido mejoran la utilización.
- Monitoreo antirobo e inmovilización mediante alertas SOS, detección de vibración y control remoto de relé.
- Reporte de eventos del conductor y telemática básica utilizando estado de encendido y señales de alarma para seguimiento de cumplimiento.
- Diagnóstico y chequeos de seguridad remotos mediante funciones de voz y comandos basados en SMS.
- Rastreo de activos compactos para motocicletas, scooters y embarcaciones pequeñas que requieren amplio rango de voltaje de entrada y despliegue sencillo.

## Por qué elegir este rastreador con Plaspy

El GT06 ofrece un equilibrio entre la tecnología GSM GPS conocida y un conjunto de funciones práctico para la integración con Plaspy. Su soporte para configuración directa de servidor y control por comandos SMS reduce la fricción de integración, por lo que los equipos pueden comenzar a recibir actualizaciones de posición, alertas y telemetría sin cambios complejos en la infraestructura. El dispositivo entrega las funciones de telemetría y alarma esenciales que los gestores de flotas suelen requerir, manteniendo el despliegue simple.
