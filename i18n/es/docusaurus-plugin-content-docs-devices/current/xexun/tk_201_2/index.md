# Xexun - TK-201-2

![TK-201-2](./logo.jpg)

El rastreador GPS TK201-2 de Xexun es un dispositivo de localización que le permite conocer las coordenadas exactas de su ubicación y la velocidad a la que se está moviendo. Este rastreador funciona con una tarjeta SIM GSM para comunicarse, lo que le permite enviar comandos a través de mensajes de texto y recibir respuestas.

El TK201-2 es la versión actualizada del modelo TK201, y su característica principal es su resistencia al agua, lo que lo hace ideal para su uso en entornos exteriores y condiciones climáticas adversas. Entre las funciones destacadas de este rastreador GPS se encuentran la autenticación, que le permite gestionar usuarios y contraseñas para garantizar la seguridad de sus datos. También puede configurar números autorizados, lo que significa que solo los números predefinidos podrán enviar comandos y recibir información del rastreador.

Otras funciones importantes incluyen la capacidad de recibir coordenadas de ubicación en tiempo real, recibir alertas de movimiento cuando el rastreador comienza a moverse, la función de escucha ambiental que le permite escuchar el sonido del entorno, la configuración de geocercas para recibir notificaciones cuando el rastreador sale de una zona predefinida, alertas de exceso de velocidad para recibir notificaciones si se supera una velocidad determinada, y alertas de batería baja para recibir notificaciones cuando la batería del rastreador está baja. Además, cuenta con la función de pánico, que le permite enviar alertas a los números autorizados en caso de emergencia.

Con el rastreador GPS TK201-2 de Xexun, puede tener la tranquilidad de saber dónde se encuentra su vehículo, persona o activo en todo momento, y recibir notificaciones importantes para garantizar su seguridad y protección.

### Características destacadas:

- Resistente al agua
- Autenticación de usuarios y contraseñas
- Números autorizados para comandos y notificaciones
- Localización en tiempo real
- Avisos de movimiento
- Función de escucha ambiental
- Geocercas
- Avisos de exceso de velocidad
- Avisos de batería baja
- Función de pánico
