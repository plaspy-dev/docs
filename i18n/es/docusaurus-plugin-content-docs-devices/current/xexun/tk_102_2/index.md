# Xexun - TK-102-2

![TK-102-2](./logo.jpg)

El Xexun TK-102-2 es una versión mejorada de la popular serie TK102. Este modelo incorpora una ranura para tarjeta SD y una batería de mayor capacidad, y está basado en un procesador ARM7 para un funcionamiento ágil. Permite reportes de ubicación sin depender de un servidor y ofrece funciones prácticas como sondeos en tiempo real, seguimiento automático por SMS, vigilancia por voz, alertas por geocerca, avisos por movimiento y exceso de velocidad, botón SOS y autorización telefónica configurable para controlar el acceso.

Como dispositivo compatible con Plaspy, el TK-102-2 puede enviar información de posición y alertas a la plataforma Plaspy para su monitoreo y generación de reportes. Su registro local y su capacidad de operar de forma independiente lo hacen una opción flexible para despliegues que requieren tanto almacenamiento local como visibilidad en la nube. Plaspy puede mostrar los datos del rastreador junto con otros equipos de la flota para ofrecer una visión unificada de la situación.

## Características principales

- Ranura para tarjeta SD para registrar localmente posiciones GPS y conservar datos.
- Batería de mayor capacidad para prolongar el tiempo de operación entre cargas.
- Procesador ARM7 para un comportamiento de rastreo eficiente y ágil.
- Soporte para funcionamiento sin servidor que habilita operación independiente sin un servidor dedicado.
- Sondeos remotos y opciones de seguimiento automático por SMS para consultar posición y estado.
- Funciones de alerta integradas, incluyendo geocerca, movimiento, exceso de velocidad, batería baja y SOS.

## Cómo funciona con Plaspy

Cuando se utiliza con Plaspy, el TK-102-2 entrega actualizaciones de posición y alertas de eventos que Plaspy puede mostrar y gestionar como parte de su vista de flota o activos. Plaspy organiza los informes entrantes en mapas, líneas de tiempo y reportes para que los equipos operativos tengan visibilidad clara y puedan actuar frente a excepciones de forma rápida.

- Muestre la ubicación en vivo y el historial reciente de cada dispositivo TK-102-2 en el mapa de Plaspy.
- Configure reglas de alerta y notificaciones en Plaspy para eventos de geocerca, exceso de velocidad, movimiento y batería baja.
- Utilice los reportes de Plaspy para analizar el historial de ubicaciones y las tendencias de eventos con fines operativos.
- Combine los datos del TK-102-2 con otros dispositivos en Plaspy para un monitoreo unificado de la flota.
- Mantenga los puntos registrados en la tarjeta SD como respaldo para análisis posteriores o auditorías cuando sea necesario.

## Casos de uso típicos

- Rastreo de vehículos personales para mayor seguridad y localización.
- Monitoreo de flotas pequeñas y medianas donde el registro local y las opciones flexibles de reporte son valiosas.
- Protección y recuperación de activos móviles o equipos de valor.
- Despliegues remotos que se benefician de la capacidad de operar de forma independiente y del sondeo por SMS.
- Escenarios donde alertas concisas como SOS, geocerca o batería baja mejoran la respuesta operativa.

## Por qué elegir este rastreador con Plaspy

El TK-102-2 es una opción práctica para organizaciones que valoran tanto la conservación de datos a nivel de dispositivo como el monitoreo en la nube. El registro en tarjeta SD añade una capa extra de respaldo, mientras que la mayor capacidad de batería permite intervalos de despliegue más largos entre cargas. Combinado con sondeos por SMS y controles de autorización, el equipo ofrece opciones flexibles de visibilidad remota que complementan las capacidades centrales de monitoreo y reporte de Plaspy.

Dado que el dispositivo admite operación sin servidor, puede desplegarse en una variedad de escenarios y aun así integrarse con Plaspy para supervisión consolidada. Esta combinación convierte al TK-102-2 en una alternativa sensata para equipos que buscan un equilibrio entre fiabilidad autónoma y gestión de flotas basada en plataforma.
