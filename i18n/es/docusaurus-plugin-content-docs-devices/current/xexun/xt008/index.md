# Xexun - XT008

![XT008](./logo.jpg)

El rastreador GPS XEXUN XT008 es un dispositivo de localización que le permite conocer las coordenadas exactas de su ubicación y la velocidad a la que se está moviendo. Funciona con una tarjeta SIM GSM para comunicarse, lo que le permite enviar comandos a través de mensajes de texto y recibir respuestas. También se puede configurar para enviar datos a través de GPRS, lo que permite que el rastreador envíe información en tiempo real a través de Internet y se pueda utilizar una plataforma de seguimiento.

Entre las funciones destacadas del rastreador GPS XT008 se encuentran la autenticación \(gestión de usuarios y contraseñas\), números autorizados \(ignorar llamadas y comandos de otros teléfonos\), localización \(recepción de coordenadas\), alertas de movimiento \(notificación cuando el rastreador comienza a moverse\), escucha \(captura de sonido ambiental\), audio bidireccional \(hablar y escuchar\), geocercas \(notificación cuando se sale de una zona delimitada\), alertas de exceso de velocidad, alertas de batería \(notificación de baja carga\), botón de pánico \(notificación a los números autorizados\), sensor de vibración, alerta de corte de alimentación, alerta de encendido no autorizado del vehículo, corte de alimentación o aceite remoto, RFID \(opcional\), sensores de gasolina o temperatura \(opcionales\), entre otros.

Mediante el protocolo GPRS, es posible configurar el rastreador para que envíe constantemente información a una dirección IP, lo que permite configurar un servidor o un ordenador para recibir en tiempo real los datos del rastreador. De esta manera, no será necesario contactar directamente con el rastreador para conocer su actividad, ya que podrá ser monitorizada de forma remota y los datos almacenados en un ordenador con un programa de seguimiento.
