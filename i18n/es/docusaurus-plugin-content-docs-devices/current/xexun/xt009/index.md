# Xexun - XT009

![XT009](./logo.jpg)

El rastreador GPS XEXUN XT009 es un dispositivo de localización que le permite conocer las coordenadas exactas de su ubicación y la velocidad a la que se está moviendo. Funciona con una tarjeta SIM GSM para comunicarse, lo que le permite enviar comandos a través de mensajes de texto y recibir respuestas. También se puede configurar para enviar datos a través de GPRS, lo que le permite enviar datos en tiempo real a través de Internet y utilizar una plataforma de seguimiento.

Entre las funciones destacadas del rastreador GPS XT009 se encuentran la autenticación \(gestión de usuarios y contraseñas\), números autorizados \(ignorar llamadas y comandos de otros teléfonos\), localización \(recibir coordenadas\), avisos de movimiento \(notificar cuando el rastreador comienza a moverse\), escucha \(escuchar el sonido ambiental\), audio bidireccional \(hablar y escuchar\), geocercas \(avisar cuando se sale de una zona delimitada\), avisos de exceso de velocidad, avisos de batería \(notificación de baja carga\), botón de pánico \(avisar a los números autorizados\), alerta de vibración \(sensor de movimiento\), alerta de corte de alimentación, alerta de encendido no autorizado del vehículo, corte de alimentación o aceite remoto, RFID \(opcional\), sensores de gasolina o temperatura \(opcionales\), entre otros.

Mediante el protocolo GPRS, es posible configurar el rastreador para que envíe información constantemente a una dirección IP, lo que le permite configurar un servidor o un ordenador para recibir los datos del rastreador en tiempo real. De esta manera, no será necesario contactar con el rastreador para conocer su actividad, ya que podrá ser monitorizada de forma remota y los datos almacenados en un ordenador con un programa de seguimiento.
