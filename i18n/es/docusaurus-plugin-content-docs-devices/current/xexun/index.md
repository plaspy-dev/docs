# Xexun

Xexun fabrica una gama de dispositivos de rastreo GPS muy utilizados para el seguimiento de vehículos y activos. Plaspy reconoce los equipos Xexun y ofrece una plataforma centralizada para supervisar ubicación, estado y movimiento de flotas y equipos. En esta página encontrará cómo integrar dispositivos Xexun con Plaspy, las capacidades y casos de uso más frecuentes, y orientación para elegir el modelo Xexun adecuado para usar con Plaspy.

## Cómo funcionan los dispositivos Xexun con Plaspy

Los dispositivos Xexun compatibles con Plaspy pueden configurarse para enviar su ubicación y telemetría a la plataforma Plaspy. Normalmente esto implica ajustar los parámetros de reporte del dispositivo para que envíe actualizaciones de posición y mensajes de estado hacia Plaspy. Una vez que añada el dispositivo a su cuenta Plaspy, podrá ver la ubicación en tiempo real, el historial y las alertas junto con los demás equipos de su flota.

Plaspy ofrece una interfaz centralizada para guiar la configuración del equipo, visualizar datos y gestionar alertas. Para instrucciones específicas de conexión y configuración por modelo, consulte las páginas de dispositivos enlazadas desde el catálogo más abajo; allí encontrará los pasos necesarios para apuntar el dispositivo a Plaspy.

## Características comunes en los dispositivos Xexun

Aunque las características varían según el modelo, los rastreadores Xexun suelen incluir funciones útiles para el seguimiento de flotas y activos, tales como:
- Reporte de ubicación por GPS para seguimiento en tiempo real e histórico
- Detección de movimiento e informes de estado para monitoreo bajo demanda
- Intervalos de reporte configurables para equilibrar frecuencia de actualizaciones y duración de batería
- Soporte para monitoreo de alimentación y entradas de alarma básicas
- Opciones para instalación cableada en vehículos o funcionamiento con batería para seguimiento de activos

Las páginas de cada dispositivo enlazadas en el catálogo contienen las listas de características detalladas y los pasos de configuración para cada modelo.

## Casos de uso típicos para rastreadores GPS Xexun

Los dispositivos Xexun se emplean en una amplia variedad de necesidades de rastreo. Algunos escenarios comunes incluyen:
- Seguimiento de vehículos de flota para supervisión de rutas y control operativo
- Rastreo de activos como maquinaria, remolques y equipos no motorizados
- Seguimiento de vehículos particulares para seguridad y recuperación
- Monitoreo en alquileres y logística para control de responsabilidad y utilización

Plaspy facilita estos casos de uso al agregar los datos de los dispositivos, generar alertas y producir historial de ubicaciones y reportes.

- Seguimiento en vivo sobre mapas y reproducción histórica

- Administración de usuarios y permisos para acceso por equipos

## Ayuda para elegir el dispositivo Xexun adecuado

Para seleccionar el dispositivo Xexun que mejor se adapte a sus necesidades, considere:
- Fuente de alimentación y método de instalación requeridos por el activo
