# Xexun - TK-103-2

![TK-103-2](./logo.jpg)

El rastreador GPS XEXUN TK103-2 es un dispositivo de localización que le permite conocer las coordenadas exactas de su ubicación y la velocidad a la que se desplaza. Funciona con una tarjeta SIM GSM para establecer comunicación, lo que le permite enviar comandos a través de mensajes de texto y recibir respuestas. También se puede configurar para enviar datos a través de GPRS, lo que le permite enviar información en tiempo real a través de internet y utilizar una plataforma de seguimiento.

El TK103-2 es una versión mejorada y actualizada del modelo TK103. Ofrece todas las mismas funciones que su predecesor, pero con algunas mejoras adicionales. Cuenta con una ranura para tarjetas micro SD que le permite almacenar datos cuando el rastreador no tiene cobertura GSM/GPRS, evitando así la pérdida de información. Estos datos pueden ser guardados en la tarjeta micro SD y posteriormente transferidos. Además, el TK103-2 está equipado con un sensor de movimiento \(shake sensor\) que puede alertarle en caso de manipulación del dispositivo.

El TK103-2 utiliza un procesador ARM7 más potente que el del TK103, lo que le permite enviar datos por GPRS cada 5 segundos en lugar de cada 60 segundos, lo que aumenta la precisión de los seguimientos en tiempo real. También cuenta con nuevos comandos, como TLIMIT o VERSION, que no estaban disponibles en el modelo anterior. Además, el TK103-2 permite la comunicación bidireccional a través de GPRS, lo que significa que no solo puede enviar datos, sino también recibir comandos.

Características destacadas:

- Localización precisa de coordenadas y velocidad
- Comunicación a través de SIM GSM y SMS
- Envío de datos en tiempo real a través de GPRS
- Ranura para tarjeta micro SD para almacenamiento de datos
- Sensor de movimiento para detectar manipulaciones
- Procesador ARM7 para un rendimiento mejorado
- Comandos adicionales y comunicación bidireccional por GPRS
