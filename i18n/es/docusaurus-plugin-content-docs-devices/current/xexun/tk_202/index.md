# Xexun - TK-202

![TK-202](./logo.jpg)

El rastreador GPS TK-202 de Xexun es un dispositivo que te permite conocer las coordenadas exactas de su ubicación y la velocidad a la que se está moviendo. Funciona con una tarjeta SIM GSM para comunicarse, lo que te permite enviar comandos a través de mensajes de texto y recibir respuestas.

Utilizando el protocolo GPRS, puedes configurar el rastreador para que envíe constantemente información a una dirección IP específica. Esto te permite configurar un servidor u ordenador que reciba los datos del rastreador en tiempo real. De esta manera, no es necesario contactar directamente con el rastreador para conocer su actividad, ya que puedes monitorearlo de forma remota y almacenar los datos en un programa de seguimiento en tu ordenador.

El TK-202 cuenta con una base que se puede instalar en tu hogar. Cuando el rastreador se encuentre a menos de 20-30 metros de la base, se mantendrá inactivo y actuará como si estuviera apagado al recibir una llamada. Solo cuando el rastreador se aleje de la base, comenzará a enviar información. Además, el rastreador cuenta con un botón de SOS que, al ser presionado durante 3 segundos, enviará un mensaje de alerta a todos los teléfonos autorizados. También puedes utilizar el rastreador para comunicarte de forma bidireccional.

#### Características destacadas:

- Localización precisa de coordenadas y velocidad
- Comunicación a través de tarjeta SIM GSM
- Configuración de envío de datos en tiempo real mediante protocolo GPRS
- Base de casa para inactividad cuando está cerca
- Botón de SOS para enviar mensajes de alerta
- Comunicación bidireccional
