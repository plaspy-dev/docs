# Xexun - TK-103

![TK-103](./logo.jpg)

El rastreador GPS XEXUN TK103-2 es un dispositivo de localización que permite conocer las coordenadas exactas de su ubicación y la velocidad a la que se desplaza. Este rastreador funciona con una tarjeta SIM GSM para establecer comunicación, lo que le permite recibir comandos a través de mensajes de texto SMS y enviar respuestas. Además, se puede configurar para enviar datos a través de GPRS, lo que permite recibir información en tiempo real a través de internet y utilizar una plataforma de seguimiento.

El TK103-2 es la versión mejorada y actualizada del modelo TK103. Cuenta con todas las funciones del TK103, pero también incluye algunas mejoras adicionales. Una de las características destacadas del TK103-2 es la ranura para tarjetas micro SD, que permite almacenar datos cuando el rastreador no tiene cobertura GSM/GPRS. Estos datos se guardan en la tarjeta micro SD y se pueden transferir posteriormente. Además, el TK103-2 cuenta con un sensor de movimiento \(shake sensor\) que puede detectar manipulaciones o movimientos no autorizados del dispositivo.

El TK103-2 utiliza un procesador ARM7, que es más potente que el del TK103. Esto permite enviar datos por GPRS cada 5 segundos, lo que aumenta la precisión de los seguimientos en tiempo real. Además, el TK103-2 cuenta con nuevos comandos, como TLIMIT o VERSION, y tiene la capacidad de comunicarse bidireccionalmente a través de GPRS, lo que le permite recibir comandos además de enviar datos.

En resumen, el rastreador GPS XEXUN TK103-2 es una opción confiable y mejorada para aquellos que buscan un dispositivo de localización preciso y versátil. Con su capacidad de almacenamiento de datos, sensor de movimiento y comunicación bidireccional, el TK103-2 ofrece una solución completa para el seguimiento y control de vehículos y activos.

### Características destacadas:

- Localización precisa de coordenadas y velocidad
- Funciona con tarjeta SIM GSM para comunicación
- Envío de comandos y recepción de respuestas mediante SMS
- Posibilidad de enviar datos en tiempo real a través de GPRS
- Ranura para tarjeta micro SD para almacenamiento de datos sin cobertura
- Sensor de movimiento para detectar manipulaciones o movimientos no autorizados
- Procesador ARM7 para un rendimiento mejorado
- Envío de datos por GPRS cada 5 segundos para seguimientos en tiempo real
- Comandos adicionales como TLIMIT y VERSION
- Comunicación bidireccional por GPRS
