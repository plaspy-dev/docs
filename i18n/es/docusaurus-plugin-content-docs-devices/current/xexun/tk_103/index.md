# Xexun - TK-103

![TK-103](./logo.jpg)

El Xexun TK-103 es un rastreador GPS versátil diseñado para múltiples escenarios de seguimiento de vehículos y equipos. Frecuentemente utilizado en autos particulares, flotas de arrendamiento, protección antirrobo de maquinaria en exteriores y administración de vehículos corporativos, el TK-103 ofrece reportes de posición continuos y un conjunto de funciones de monitoreo. Entre sus capacidades destacadas están la consulta de ubicación inmediata, seguimiento periódico programado, consultas por SMS con dirección, reproducción de rutas históricas, función de geocerca y varios tipos de alertas para notificar eventos anormales.

Como dispositivo compatible con Plaspy, el TK-103 puede enviar actualizaciones de ubicación y notificaciones de eventos a Plaspy para lograr una visión centralizada de la flota y supervisión operativa. Plaspy puede mostrar los datos del rastreador en mapas, integrar las alarmas en flujos de notificación y conservar trayectos históricos para reportes y revisiones. Esto convierte al TK-103 en una opción práctica para organizaciones que desean combinar un equipo GPS con funciones avanzadas y las herramientas de monitoreo y reporte de Plaspy.

## Puntos clave

- Soporta consultas de ubicación en tiempo real y seguimiento programado para visibilidad continua
- Varios tipos de alarma, incluyendo SOS, exceso de velocidad, vibración y alertas relacionadas con la energía para proteger los activos
- Reproducción de rutas históricas y funciones de geocerca para revisión de incidentes y monitoreo perimetral
- Consulta por SMS de dirección y soporte de ubicación por estación base GSM para opciones flexibles de posicionamiento
- Monitoreo remoto y posibilidad de actualización remota del dispositivo para facilitar su mantenimiento
- Soporte para dos tarjetas SIM para mayor disponibilidad de red y opción de tarjeta SD para almacenamiento local
- Posibilidad de corte remoto de suministro de combustible para control adicional ante intentos de robo

## Cómo funciona con Plaspy

Al integrarse con Plaspy, el TK-103 aporta datos de ubicación y eventos que Plaspy utiliza para generar vistas operacionales accionables. Plaspy recibe las actualizaciones de posición y las alarmas del rastreador para que los gestores de flota puedan supervisar unidades en tiempo real y analizar comportamientos históricos.

- Visualice posiciones en vivo de vehículos y equipos en los mapas de Plaspy para obtener visibilidad centralizada
- Reenvíe alarmas del dispositivo a Plaspy para que los usuarios reciban notificaciones por SOS, rupturas de geocerca, eventos de velocidad y problemas de energía
- Reproduzca trayectos históricos dentro de Plaspy para análisis posterior a eventos y verificación de rutas
- Use eventos de geocerca para activar notificaciones e informes orientados a cumplimiento o seguridad
- Consolide múltiples TK-103 en Plaspy para informes a nivel de flota, resúmenes de estado y conocimientos operativos

## Casos de uso habituales

- Rastreo de vehículos particulares para consultas de ubicación por parte del propietario y disuasión de robos
- Flotas de arrendamiento y renta que requieren supervisión de ocupación y movimiento
- Gestión de flotas corporativas para monitorear rutas, generar reportes y responder a incidentes
- Protección de equipos mecánicos en obra o en ubicaciones remotas
- Monitoreo de logística y reparto donde el historial de posiciones y las alertas apoyan las operaciones

## Por qué elegir este rastreador con Plaspy

El TK-103 combina un conjunto amplio de capacidades estándar de rastreo con funciones operativas útiles para la gestión de flotas y activos. Su combinación de consulta de ubicación inmediata, seguimiento programado, consulta de dirección y múltiples tipos de alarma lo hace adaptable a escenarios comunes de seguimiento. Para organizaciones que ya usan o evalúan Plaspy, el TK-103 ofrece una opción práctica que suministra actualizaciones de ubicación y señales de eventos que Plaspy puede incorporar en flujos de monitoreo, alerta y reporte.
