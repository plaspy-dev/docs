# Appello - Características del TK103B

Esta página ofrece una visión general pública de las capacidades del Appello TK103B y de cómo se conectan con el uso en Plaspy. Resume las funciones orientadas al usuario y los comportamientos operativos que suelen mencionarse al implementar el TK103B en una plataforma de gestión de flotas como Plaspy. El objetivo es ayudar a los equipos a comprender el valor práctico y las interacciones típicas entre el rastreador y Plaspy, sin sustituir la documentación del fabricante.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Cuando la descripción del dispositivo identifica funciones específicas, esta página las toma como base factual. Para ajustes, opciones de configuración o los detalles técnicos más recientes consulte la documentación del fabricante.

## Resumen de funciones

El Appello TK103B es un rastreador GPS con conectividad GSM GPRS diseñado para el seguimiento en tiempo real y la supervisión remota de vehículos y activos. Permite reportes continuos o por intervalos, comandos remotos, monitoreo de estado y varios tipos de alertas útiles para la supervisión operativa.

- Informes de ubicación en tiempo real con latitud, longitud, velocidad y hora para conocimiento situacional
- Modo de seguimiento automático que reporta en intervalos configurables para monitorización rutinaria
- Funciones de control remoto para enviar comandos y gestionar el dispositivo a distancia
- Múltiples alertas, incluyendo geocerca, movimiento, exceso de velocidad, batería baja, alarma SOS y GPS desconectado
- Comprobación de estado de GSM, GPS, GPRS y batería para vigilar la salud y conectividad del dispositivo

## Características principales del Appello - TK103B

- Comunicación GSM GPRS para reportes remotos y conectividad con la plataforma
- Seguimiento en tiempo real de coordenadas de ubicación y velocidad
- Reportes por intervalos en modo auto track para obtener posiciones de forma automática
- Soporte de comandos remotos para gestionar el comportamiento del dispositivo desde un terminal remoto
- Alertas de geocerca para notificar cuando un dispositivo entra o sale de áreas predefinidas
- Alertas de movimiento y exceso de velocidad para detectar eventos operativos o de seguridad
- Alarma SOS y notificaciones de GPS apagado para emergencias y detección de manipulación
- Función de verificación de estado para reportes de GSM, GPS, GPRS y nivel de batería

## Cómo funcionan estas funciones con Plaspy

Plaspy puede recibir y mostrar los datos de ubicación y eventos del TK103B para que los equipos monitoreen activos en mapas, revisen alertas y gestionen reportes. Plaspy detecta automáticamente muchos protocolos de rastreadores y expone los datos en la interfaz de gestión de flotas, de modo que los operadores puedan utilizar las funciones del dispositivo sin trabajar a bajo nivel con los protocolos.

- Posiciones en tiempo real y reportes de auto track se muestran en los mapas de Plaspy para visibilidad continua
- Las alertas del TK103B, como geocerca, movimiento, exceso de velocidad, SOS y GPS desconectado, se registran como eventos en Plaspy para la atención del operador
- La información de estado del dispositivo, como GSM, GPRS, GPS y batería, está disponible en Plaspy para ayudar a diagnosticar problemas de conectividad o alimentación
- Los comandos remotos soportados por el rastreador pueden enviarse y rastrearse a través de Plaspy cuando los flujos de trabajo de la plataforma permiten la gestión de comandos
- Plaspy puede configurarse para aceptar reportes del TK103B mediante la entrega de red estándar al servidor de la plataforma y presentará la telemetría entrante automáticamente

## Casos de uso típicos

- Rastreo de vehículos de flota para supervisar rutas y mejorar la asignación de recursos
- Monitoreo de vehículos de alquiler para hacer cumplir políticas de uso y rastrear devoluciones
- Localización de equipos y activos en obras o sitios de trabajo
- Rastreo personal o de acompañantes cuando se requiere conciencia de posición continua
- Seguridad y prevención de pérdidas para detectar movimiento o uso no autorizado
- Monitoreo operativo con reportes automáticos periódicos para gerentes

## Notas sobre disponibilidad de funciones

- La disponibilidad de funciones puede cambiar con actualizaciones de firmware; lo descrito aquí refleja capacidades comunes en la documentación del TK103B
- Las revisiones de hardware y las variantes regionales pueden modificar funciones soportadas o el comportamiento de las alertas
- Las opciones de instalación y el cableado pueden afectar qué alertas y reportes de estado están disponibles
- La configuración del fabricante, como los ajustes de APN, puede ser necesaria para habilitar la resolución de nombres o el reporte completo por GPRS
- Consulte la documentación oficial del fabricante para valores por defecto y pasos de configuración específicos del modelo

## Por qué usar Plaspy con estas funciones

Usar el Appello TK103B con Plaspy brinda a las organizaciones una forma práctica de convertir los reportes y alertas del rastreador en información operativa. Plaspy agrega las fuentes de ubicación, muestra alertas y registra estados para que los equipos puedan gestionar activos, responder a eventos y mantener la conciencia situacional sin tener que manejar los detalles del protocolo a nivel de dispositivo.
