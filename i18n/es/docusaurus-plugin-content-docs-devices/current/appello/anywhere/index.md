# Appello - Anywhere

![Anywhere](./logo.jpg)

El rastreador GPS Appello Anywhere es una solución confiable y eficiente para el seguimiento de activos y vehículos. Con su red GSM / GPRS y su banda de frecuencia de 850/900/1800 / 1900Mhz, este dispositivo ofrece una amplia cobertura y conectividad estable en todo momento.

Equipado con un potente procesador ARM 7 y un chip GPS Star NS-1315 de última generación, el rastreador Anywhere garantiza una precisión y sensibilidad excepcionales. Con una sensibilidad de GPS de -159dBm y una precisión de 5 metros, puede rastrear y localizar con precisión la ubicación de sus activos en tiempo real.

El rastreador Anywhere también cuenta con un módulo GSM / GPRS QUECTEL M35 M35-02-NCH-STD M35AR01A10, que proporciona una conexión estable y confiable para transmitir datos de ubicación. Además, su batería de Li-ion de 3.7V 1460mAh ofrece hasta 150 horas de tiempo de espera, lo que garantiza un seguimiento continuo sin interrupciones.

Con un tamaño compacto de 68 x 50 x 20 mm y un peso neto de 85 g, el rastreador Anywhere es fácil de instalar y transportar. Su temperatura de funcionamiento de -20 ° C a + 55 ° C y su temperatura de almacenamiento de -40 ° C a +85 ° C lo hacen adecuado para una amplia gama de entornos y condiciones.

En resumen, el rastreador GPS Appello Anywhere es una opción confiable y eficiente para el seguimiento de activos y vehículos. Con su precisión, conectividad y duración de la batería, puede estar seguro de que sus activos estarán siempre bajo control.

### Características destacadas:

- Red GSM / GPRS para una conectividad estable
- Chip GPS Star NS-1315 para una precisión y sensibilidad excepcionales
- Módulo GSM / GPRS QUECTEL M35 M35-02-NCH-STD M35AR01A10 para una conexión confiable
- Batería de Li-ion de 3.7V 1460mAh para hasta 150 horas de tiempo de espera
- Tamaño compacto y peso ligero para una fácil instalación y transporte
- Rango de temperatura de funcionamiento de -20 ° C a + 55 ° C para adaptarse a diferentes entornos
