# Appello - Host

![Host](./logo.jpg)

El Appello Host describe el rastreador GPS para mascotas Appello 4P, una unidad compacta pensada para animales medianos y pequeños. Según la información disponible, el dispositivo combina una pequeña unidad GPS que se fija al collar de la mascota con una base de energía independiente que incorpora una gran batería de 6000 mAh. Host enfatiza una amplia autonomía en espera, carga inalámbrica desde la base, una carcasa resistente al agua para uso exterior y una alerta cuando la mascota sale de un rango aproximado de 20 metros de la base.

Al ser compatible con Plaspy, Host puede integrarse en la plataforma para ofrecer visibilidad centralizada y supervisión operativa. Los usuarios de Plaspy pueden agregar el Host a sus inventarios de activos, ver la ubicación y las alertas, y utilizar la plataforma para monitorear movimientos y estados de las mascotas dentro de los flujos de trabajo de seguimiento de flotas y activos existentes.

## Puntos clave

- Unidad GPS compacta indicada para colocarse en collares de mascotas medianas y pequeñas
- Larga autonomía en espera con duración reportada de hasta 12 meses entre cargas
- Base de energía con batería de gran capacidad de 6000 mAh que carga el rastreador de forma inalámbrica y actúa como punto de control local
- Diseño resistente al agua para posicionamiento en exteriores y durabilidad en condiciones variables
- Alerta automática cuando la mascota se aleja del rango aproximado de 20 metros de la base
- Factor de forma práctico y capacidad de gestión remota para monitoreo rutinario de mascotas

## Cómo funciona con Plaspy

Host puede utilizarse con Plaspy para consolidar la ubicación y las alertas de las mascotas en una sola plataforma para monitoreo e informes. Al añadirse a Plaspy, el rastreador pasa a ser un activo que contribuye a la conciencia situacional y a los flujos operativos.

- Mostrar la ubicación actual y reciente de las mascotas rastreadas en los mapas dentro de Plaspy
- Recibir alertas de salida de rango y otras notificaciones del dispositivo a través de los canales de notificación de Plaspy
- Organizar unidades Host junto a otros activos para una supervisión consolidada de la flota o inventario
- Usar los informes de Plaspy para revisar el historial de movimientos y las tendencias de alertas con fines operativos
- Configurar notificaciones de usuario y grupos para que los encargados o administradores estén informados cuando una mascota abandone el rango de la base

## Casos de uso típicos

- Monitoreo de mascotas en residencias o pequeñas fincas donde una estación base cubre el área principal del hogar
- Supervisión en perreras y servicios de hospedaje para controlar los movimientos individuales de las mascotas
- Escenarios de cuidado temporal donde las alertas remotas reducen la necesidad de revisiones manuales continuas
- Gestión de ejercicio y salida al aire libre para mascotas pequeñas y medianas
- Registro de eventos y revisión cuando las mascotas se desplazan fuera de las zonas esperadas

## Por qué elegir este rastreador con Plaspy

El Appello Host es una opción sensata para organizaciones y particulares que requieren un rastreador ligero para mascotas que reduzca el mantenimiento y se integre en una plataforma de seguimiento más amplia.
