# Appello - Host - Funciones

Esta página ofrece un resumen público de las funciones del rastreador Appello Host al integrarlo con Plaspy. Resume la descripción proporcionada por el fabricante y destaca las capacidades prácticas que puede esperar ver cuando el dispositivo se utiliza con Plaspy para rastreo, notificaciones y supervisión operativa.

La disponibilidad exacta y el comportamiento de las funciones pueden variar según la versión de firmware, la revisión de hardware, las opciones de instalación y la implementación del fabricante. Cuando el dispositivo informa estados o eventos específicos, Plaspy refleja esa información; para detalles definitivos y específicos del dispositivo, consulte siempre la documentación del fabricante.

## Resumen de funciones

El Appello Host se presenta como un rastreador GPS compacto para mascotas destinado al uso exterior, acompañado por una base de energía separada que actúa como centro de control. Las capacidades relevantes se centran en posicionamiento confiable para mascotas pequeñas y medianas, larga autonomía en reposo y una sujeción sencilla al collar, junto con una base recargable.

- Unidad compacta para montar en el collar, fácil de colocar y adecuada para uso diario
- Autonomía en reposo señalada por el fabricante de hasta 12 meses en condiciones óptimas
- Diseño resistente al agua pensado para uso exterior y exposición a los elementos
- Carga inalámbrica mediante una base de energía dedicada con batería de alta capacidad
- La base de energía funciona como centro de control local y admite gestión remota
- Alerta por proximidad cuando la mascota sale del rango de la base de energía, reportada como evento

## Funciones principales del Appello - Host

- Unidad GPS montable en el collar diseñada para mascotas pequeñas y medianas
- Autonomía en reposo declarada por el fabricante de hasta 12 meses en uso ideal
- Construcción resistente al agua para posicionamiento en exteriores
- Capacidad de carga inalámbrica mediante una base de energía dedicada
- La base de energía incluye una batería interna de alta capacidad y actúa como hub de control
- Alerta basada en proximidad cuando el dispositivo sale del rango aproximado de la base
- Funciones de gestión remota a través de la base de energía según lo describe el fabricante

## Cómo funcionan estas funciones con Plaspy

Al integrarse con Plaspy, el conjunto de funciones públicas del Host se refleja en la visibilidad dentro de la plataforma y en el manejo de eventos para apoyar la monitorización y la supervisión operativa.

- Las actualizaciones de ubicación del dispositivo aparecen en los mapas de Plaspy y en la línea de tiempo del dispositivo cuando el rastreador reporta posición
- Las características de larga autonomía reducen la frecuencia de eventos de mantenimiento mostrados en Plaspy relativos a comprobaciones de batería cuando el dispositivo informa el estado de carga
- Las alertas de fuera de rango o de proximidad generadas por la base de energía pueden representarse como eventos o notificaciones dentro de Plaspy
- El estado de la base de energía y las señales de gestión remota se muestran en Plaspy cuando el dispositivo transmite esa información
- Plaspy detecta automáticamente los protocolos de rastreador compatibles y presentará los estados y eventos que el dispositivo transmita

## Casos de uso típicos

- Monitorización de mascotas al aire libre para perros y gatos de tamaño pequeño y mediano
- Supervisión de base doméstica donde la base de energía define un radio seguro y alerta ante la separación
- Escenarios de rastreo de bajo mantenimiento que se benefician de largos periodos entre cargas
- Supervisión por parte de cuidadores que requieren visibilidad remota de la ubicación y alertas
- Situaciones en las que una base de carga inalámbrica simplifica la carga diaria y la gestión del dispositivo

## Notas sobre disponibilidad de funciones

- Los tiempos de autonomía especificados son máximos declarados por el fabricante y dependen en gran medida de los patrones de uso y la configuración
- Algunas funciones pueden verse afectadas por el nivel de firmware o la revisión de hardware y variar entre unidades
- El comportamiento y el alcance de la base de energía, incluido el rango de alerta aproximado de 20 metros descrito por el fabricante, pueden variar según la instalación y el entorno
- Variantes regionales o de modelo pueden modificar las funciones disponibles o el comportamiento de la carga inalámbrica
- Confirme siempre las capacidades del dispositivo, las actualizaciones de firmware y las especificaciones más recientes en la documentación del fabricante

## Por qué usar Plaspy con estas funciones

Usar el Appello Host con Plaspy proporciona una plataforma única para la visibilidad y la gestión de eventos de los rastreadores desplegados. Plaspy recopila y muestra las ubicaciones reportadas, las actualizaciones de estado y las alertas para que los equipos puedan supervisar mascotas y responder a eventos de separación u otras condiciones reportadas sin necesidad de gestionar múltiples sistemas de proveedores.

Si desea obtener más información sobre cómo Plaspy puede consolidar los datos de dispositivos y la visibilidad operativa, visite https://www.plaspy.com. Las funciones del dispositivo, el comportamiento del firmware y la implementación del fabricante pueden cambiar con el tiempo, por lo que le recomendamos verificar los detalles más recientes del dispositivo con el fabricante en http://www.cnjeo.com/ para obtener la información más actualizada.
