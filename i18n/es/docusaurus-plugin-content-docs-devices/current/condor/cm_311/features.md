# Condor - CM-311: Características

Esta página ofrece un resumen público de las capacidades del Condor CM-311 y su uso con Plaspy. Describe las funcionalidades prácticas que puede esperar al integrar el CM-311 en la plataforma Plaspy para ubicación en tiempo real, visualización de rutas y monitoreo rutinario, sin exponer detalles sensibles de implementación.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. Cuando sea relevante, se señalan esas variables y se recomienda verificar la documentación oficial de Condor para obtener los detalles específicos y más recientes del dispositivo.

## Resumen de características

El Condor CM-311 es un rastreador GPS compacto orientado a mascotas, diseñado para transmitir datos de ubicación a través de una red celular e integrarse con la plataforma Plaspy para un monitoreo en tiempo real y reproducción de recorridos de forma sencilla. Está pensado para tener un tamaño reducido y una instalación simple, de modo que los dueños puedan supervisar a sus mascotas con la mínima molestia.

- Dispositivo compatible con Plaspy para visualización de ubicación en vivo y del historial de rutas.
- Transmisión celular de actualizaciones de ubicación GPS para seguimiento confiable en exteriores.
- Diseño compacto y ligero para minimizar la incomodidad en perros y gatos.
- Reproducción de rutas y monitoreo rutinario para revisar patrones diarios de movimiento.
- Notificaciones y alertas por mascota perdida disponibles a través de Plaspy cuando se configuran.
- Fijación y puesta en marcha rápida para uso inmediato con el monitoreo de Plaspy.

## Funciones principales del Condor - CM-311

- Diseñado para el seguimiento de mascotas con un formato compacto y liviano.
- Envía actualizaciones periódicas de ubicación GPS mediante una red celular.
- Visibilidad de la ubicación en tiempo real cuando se vincula con la plataforma Plaspy.
- Historial de rutas y reproducción para revisar por dónde se ha movido una mascota.
- Integración con Plaspy para notificaciones y alertas en caso de mascota perdida.
- Configuración y sujeción sencillas para un despliegue rápido en la mascota.
- Telemetría básica y estado del dispositivo visibles desde la interfaz de Plaspy.

## Cómo funcionan estas características con Plaspy

Al conectarse a Plaspy, las actualizaciones de ubicación del CM-311 se incorporan a una plataforma de monitoreo unificada que convierte los datos de posición en vistas útiles y alertas para propietarios y cuidadores.

- Visualización de la posición en vivo sobre los mapas de Plaspy para conocer la ubicación inmediata.
- Historial de rutas y reproducción para analizar movimientos y recorridos habituales.
- Alertas y notificaciones configurables en Plaspy ante rupturas de geocercas o situaciones de mascota perdida.
- Estado del dispositivo y telemetría básica mostrados en la interfaz de Plaspy para supervisión operativa.
- Gestión de múltiples dispositivos y mascotas desde una única cuenta Plaspy para un monitoreo eficiente.

## Casos de uso típicos

- Monitoreo diario de mascotas para verificar ubicación en vivo y confirmar actividad segura.
- Recuperación de mascotas extraviadas usando actualizaciones rápidas de ubicación y alertas de Plaspy.
- Revisión de rutas diarias para entender dónde pasa tiempo la mascota.
- Supervisión de mascotas durante cuidados temporales, hospedaje o visitas al veterinario.
- Seguimiento en paseos y exploraciones al aire libre para mantener a las mascotas seguras y localizables.
- Gestión de varias mascotas o dispositivos desde una sola cuenta Plaspy.
