# Xirgo - XT62 — Características

Esta página resume el contexto público de funciones para el módulo de activos Xirgo XT62 cuando se utiliza con Plaspy. Describe las capacidades prácticas que puede esperar ver en Plaspy al integrar un XT62 para el monitoreo de remolques y contenedores refrigerados, con énfasis en ubicación, temperatura, estado de puertas y señales de E/S remotas.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el tipo de instalación y la implementación del fabricante. Use esta página como una guía de alto nivel sobre el uso típico del XT62 con Plaspy y consulte la documentación del fabricante para detalles específicos del modelo.

## Resumen de funcionalidades

El XT62 está diseñado para ofrecer visibilidad en la cadena de frío combinando el monitoreo continuo de condiciones con el reporte de ubicación. Al integrarse en Plaspy, la telemetría del XT62 ayuda a los equipos operativos a supervisar temperatura, eventos de acceso y el estado de E/S remotas junto con la ubicación del activo, apoyando la toma de decisiones operativas y los flujos de trabajo de cumplimiento.

- Soporte de entrada para monitoreo continuo de temperatura en remolques y contenedores refrigerados.
- Entradas para sensores de puerta y roll‑up para detectar eventos de acceso y registrar cambios de estado.
- Interfaces de E/S remotas para alarmas, activación de dispositivos externos o integración de control simple.
- Reporte de ubicación que combina datos de condición con la posición del activo para visibilidad de extremo a extremo.
- Alertas basadas en condiciones por desviaciones de temperatura y aperturas de puerta integradas en Plaspy.
- Factor de forma robusto e interfaces adecuadas para instalaciones en remolques y contenedores.

## Funciones principales del Xirgo - XT62

- Soporte de entrada de temperatura para monitoreo continuo de condiciones en la cadena de frío.
- Entradas para sensor de puerta y roll‑up para registrar eventos de acceso y cambios de estado.
- Interfaces de E/S remotas para conectar alarmas o circuitos de control externos.
- Reporte de ubicación del activo para ubicar la telemetría de condición en mapas y rutas.
- Monitoreo continuo de condiciones pensado para uso en remolques y contenedores refrigerados.
- Compatibilidad con Plaspy para ingestión centralizada de telemetría y procesamiento de eventos.
- Factor de forma compacto y orientado a la instalación en activos móviles.

## Cómo funcionan estas funciones con Plaspy

Cuando el XT62 envía telemetría a Plaspy, la plataforma normaliza los datos de ubicación y de sensores para que los equipos puedan visualizar la condición del activo y responder a eventos desde un único lugar. Plaspy recopila las entradas del XT62 y las pone a disposición para mapeo, alertas, informes y acceso vía API como parte de una vista unificada de flota o activos.

- Actualizaciones en tiempo real de ubicación y telemetría que aparecen en los mapas de Plaspy para monitoreo de rutas.
- Lecturas de temperatura disponibles para visualización de tendencias y alertas configurables por desviaciones.
- Eventos de sensores de puerta registrados para bitácoras de acceso, revisiones de seguridad y evidencia de cumplimiento.
- El estado de las E/S remotas puede supervisarse y utilizarse para activar alarmas o flujos de trabajo automatizados dentro de Plaspy.
- Plaspy consolida las entradas del XT62 con otras telemetrías de activos para ofrecer una vista operativa única.

## Casos de uso típicos

- Monitoreo de remolques refrigerados y contenedores con registro continuo de temperatura y seguimiento de ubicación.
- Cadena de frío en productos farmacéuticos y alimentos perecederos que requieren alertas rápidas ante desviaciones.
- Gestión de flota de activos refrigerados para combinar monitoreo de condiciones con datos de ruteo y utilización.
- Flujos de trabajo de seguridad y anti‑robo que utilizan el registro de eventos de puerta y el historial de ubicación para recuperación.
- Seguimiento de activos en alquiler e intermodales donde el monitoreo de condición y acceso protege el valor del equipo.
- Informes para cumplimiento regulatorio en envíos sensibles a la temperatura.

## Notas sobre disponibilidad de funciones

- Las diferencias de firmware pueden alterar la telemetría disponible, los umbrales de eventos y el comportamiento de reporte.
- Las revisiones de hardware o variantes regionales pueden afectar qué entradas de sensores están presentes.
- El cableado de instalación y los tipos de sensor determinan qué entradas de temperatura y puerta están disponibles.
- La configuración y el aprovisionamiento del fabricante influyen en cómo se reportan los datos a Plaspy.
- Confirme los conjuntos de funciones actuales y los requisitos de cableado con la documentación oficial del fabricante.

## Por qué usar Plaspy con estas funciones

Usar el Xirgo XT62 con Plaspy ofrece una manera práctica de combinar la condición del activo y la ubicación en una sola imagen operativa. Para equipos que gestionan remolques y contenedores refrigerados, esa combinación ayuda a reducir riesgos, acelerar la respuesta ante incidentes y facilitar el cumplimiento mediante alertas oportunas e informes consolidados.
