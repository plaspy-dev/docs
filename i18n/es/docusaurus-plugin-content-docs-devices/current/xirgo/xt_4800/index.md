# Xirgo - XT-4800

![XT-4800](./logo.jpg)

El Xirgo XT-4800 es un rastreador GPS de captación de energía diseñado para brindar soporte a largo plazo en implementaciones remotas sin la necesidad de reemplazar la batería. Es ideal para clientes que requieren datos frecuentes para la ubicación, salud y seguimiento de sus activos remotos. Este dispositivo ofrece datos más frecuentes durante períodos más largos en comparación con otros dispositivos de seguimiento de activos en el mercado actual.

El XT-4800 está diseñado para soportar diversos factores ambientales y cuenta con certificación IP67. Su carcasa totalmente sellada permite su implementación en ambientes marinos y desérticos sin comprometer su rendimiento. Es un rastreador de activos potente y confiable que se adapta a una amplia gama de aplicaciones, como contenedores secos, activos no motorizados y equipamiento pesado.

Algunas de las características destacadas del Xirgo XT-4800 incluyen:

- Recolección de energía: Este rastreador utiliza tecnología de captación de energía para mantener su funcionamiento a largo plazo sin necesidad de reemplazar la batería.
- Calificación IP67: El XT-4800 cuenta con certificación IP67, lo que significa que es resistente al polvo y al agua, lo que le permite funcionar en entornos adversos.
- Antenas celulares y GPS incrustados: Este dispositivo cuenta con antenas celulares y GPS integradas para una mejor recepción de señal y precisión en la ubicación.
- Motor integrado de GPS de alta precisión: El XT-4800 utiliza un motor de GPS de alta precisión para proporcionar datos de ubicación precisos y confiables.
- Admite los protocolos TCP, UDP, FTP: Este rastreador es compatible con los protocolos TCP, UDP y FTP, lo que permite una fácil integración con sistemas de gestión de activos existentes.
- Extensas Entradas y Salidas: El XT-4800 ofrece una amplia gama de entradas y salidas para la conexión de sensores y dispositivos externos.
- Opcional 1-Wire Bus: Este rastreador también ofrece la opción de un bus 1-Wire para la conexión de dispositivos compatibles.
