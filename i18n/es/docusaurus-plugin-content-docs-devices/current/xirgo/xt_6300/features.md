# Xirgo - XT-6300: Características

Esta página presenta un resumen público de las características del Xirgo XT-6300 cuando se usa con la plataforma Plaspy. Se enfoca en las capacidades del equipo relevantes para el seguimiento operativo, diagnóstico, monitoreo y la visibilidad telemática dentro de Plaspy, sin reproducir instrucciones de configuración del fabricante.

La disponibilidad exacta de funciones y la forma en que los datos se reportan a Plaspy pueden variar según la versión de firmware, la revisión de hardware, las interfaces opcionales seleccionadas, el tipo de instalación y la implementación del fabricante. Verifique siempre el comportamiento del dispositivo con la documentación del fabricante para detalles específicos del modelo.

## Visión general de funciones

El XT-6300 está diseñado como un dispositivo telemático flexible para el rastreo de vehículos y equipos, con opciones de conectividad al bus del vehículo y posibilidades de expansión. Combina el reporte de posición con capacidades de diagnóstico y detección de movimiento pensadas para flujos de trabajo de gestión de flotas y equipos.

- Reporte de ubicación GPS de alta precisión para seguimiento continuo y visibilidad de rutas
- Conectividad OBDII y JBUS para captura de datos diagnósticos y telemáticos del vehículo
- Firmware con soporte de scripting para manejo de datos personalizado y generación de eventos
- Antenas celulares y GPS integradas para simplificar la instalación y asegurar señal confiable
- Detección de movimiento mediante acelerómetro triaxial y sensor de movimiento para identificar actividad y desplazamientos

## Características principales del Xirgo - XT-6300

- Motor de posicionamiento GPS que ofrece posicionamiento preciso para servicios de seguimiento y geolocalización
- Interfaces de comunicación OBDII y JBUS para acceder a datos diagnósticos del vehículo y del bus cuando estén implementadas
- Antenas celulares y GPS integradas para facilitar la conectividad desde el primer uso
- Acelerómetro triaxial y detector de movimiento para eventos relacionados con movimiento e impactos
- Firmware con scripting que permite lógica personalizada y creación de eventos directamente en el equipo
- Funcionalidad Bluetooth opcional para integración inalámbrica con accesorios o dispositivos locales
- Soporte para Garmin FMI, entradas/salidas de propósito general y bus 1 Wire para telemetría e integraciones ampliadas
- Compatibilidad con la plataforma de administración de dispositivos XDMI para administración y monitoreo remoto

## Cómo funcionan estas funciones con Plaspy

Cuando el XT-6300 está conectado a Plaspy, las capacidades del dispositivo se traducen en visibilidad y gestión accionable dentro de la interfaz de Plaspy. Plaspy detecta protocolos compatibles del dispositivo y mapea los datos disponibles en vistas de monitoreo e informes para que los equipos puedan tomar acciones operativas.

- Trazas de ubicación en tiempo real e históricas visibles en Plaspy para seguimiento de flotas y análisis de rutas
- Datos del bus del vehículo desde OBDII y JBUS disponibles para diagnóstico e información operacional cuando están habilitados en el equipo
- Eventos de movimiento y del acelerómetro reportados a Plaspy para soportar monitoreo de actividad y flujos de trabajo de alertas
- Eventos a partir de scripts en el dispositivo pueden generar reportes personalizados o cambios de estado que Plaspy muestra a los operadores
- Indicadores de estado y ciclo de vida del dispositivo disponibles cuando el rastreador se administra junto con los flujos de trabajo de Plaspy

## Casos de uso típicos

- Seguimiento de ubicación de flotas y historial de rutas para vehículos de reparto o flotas de servicio
- Diagnóstico y monitoreo de estado del vehículo mediante las interfaces OBDII o JBUS cuando están instaladas
- Monitoreo de equipos y planificación de mantenimiento utilizando detección de actividad y movimiento
- Flujos de trabajo telemáticos personalizados habilitados por firmware scriptable para requisitos no estándar
- Soporte de cumplimiento, como flujos de trabajo de Horas de Servicio, cuando se integra con procesos de flota
- Administración y monitoreo remoto de dispositivos a través de plataformas de gestión compatibles

## Notas sobre disponibilidad de funciones

- Las interfaces opcionales como OBDII, JBUS y Bluetooth pueden estar presentes solo en variantes de hardware específicas o como configuraciones opcionales
- La versión de firmware y las personalizaciones de scripts pueden habilitar o deshabilitar comportamientos y formatos de reporte particulares
- El método de instalación y el cableado del vehículo determinan si los datos del bus del vehículo están disponibles para el rastreador
- Variantes regionales de hardware o requisitos regulatorios pueden afectar las bandas celulares disponibles y ciertas interfaces
- Consulte siempre las guías de instalación y las notas de la versión de Xirgo para conocer las capacidades exactas de una unidad concreta

## Por qué usar Plaspy con estas funciones

Usar el Xirgo XT-6300 con Plaspy proporciona a las organizaciones una vista unificada de ubicación, diagnósticos del vehículo y eventos generados por el dispositivo. Plaspy consolida la telemetría del rastreador en paneles de monitoreo, reportes históricos y canales de alerta para que los equipos tomen decisiones operativas con mayor rapidez. La combinación de acceso opcional al bus del vehículo, detección de movimiento y firmware scriptable permite adaptar los flujos de datos a casos de uso específicos mientras se mantiene la visibilidad centralizada.
