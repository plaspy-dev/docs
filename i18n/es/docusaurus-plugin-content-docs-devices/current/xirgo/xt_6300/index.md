# Xirgo - XT-6300

![XT-6300](./logo.jpg)

El rastreador GPS Xirgo XT-6300 es un dispositivo OBDII y JBUS versátil y habilitado con GPIO, interfaz 1-Wire y Bluetooth® opcional. Ofrece una solución de alta potencia en el tablero, proporcionando comunicación OBDII y JBUS junto con características adicionales como GPIO, 1-Wire, Garmin FMI, Bluetooth® opcional, identificadores de parámetros de diagnóstico, batería de respaldo opcional y se suministra con el software de gestión de dispositivos XDMI.

Este rastreador GPS es ideal para aplicaciones de seguimiento y telemáticos, así como para diagnóstico de equipos, seguimiento, monitoreo, control y mantenimiento. También es adecuado para la supervisión del cumplimiento federal de las Horas de Servicio \(HOS\).

Algunas de las características destacadas del Xirgo XT-6300 incluyen un firmware activable por script, antenas celulares y GPS incrustadas, un motor integrado de GPS de alta precisión, un acelerómetro de 3 ejes y detector de movimiento, interfaz OBDII e JBUS opcional, Bluetooth® opcional, Garmin FMI, GPIO, interfaz de bus 1-Wire y es compatible con la plataforma de gestión de dispositivos XDMI.
