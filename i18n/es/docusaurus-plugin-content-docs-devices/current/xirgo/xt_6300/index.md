# Xirgo - XT-6300

![XT-6300](./logo.jpg)

El Xirgo XT-6300 es un rastreador GPS versátil diseñado para diversas aplicaciones de telemática en vehículos y equipos. Integra un motor GPS de alta precisión con antenas embebidas y sensores de movimiento a bordo para ofrecer datos de ubicación confiables y detección básica de desplazamientos. El equipo cuenta además con firmware compatible con scripts y opciones de interfaces para diagnóstico vehicular y conectividad inalámbrica, lo que permite múltiples escenarios de monitoreo y control.

Como dispositivo compatible con Plaspy, el XT-6300 puede enviar información de ubicación, movimiento y diagnósticos a Plaspy para la gestión centralizada de flotas y activos. Su conjunto de funciones flexible lo hace adecuado para organizaciones que requieren visibilidad de ubicación, diagnóstico de equipos o comportamientos telemáticos personalizados. Plaspy puede ingerir y mostrar los datos del XT-6300 junto con otros dispositivos para ofrecer una supervisión operativa unificada.

## Puntos clave

- Motor GPS de alta precisión con antenas integradas para seguimiento de ubicación consistente
- Firmware compatible con scripts para personalización y comportamiento flexible
- Sensor de movimiento integrado con acelerómetro de 3 ejes para detectar eventos de inicio, parada y sacudidas
- Interfaces opcionales de bus vehicular para datos de diagnóstico y mantenimiento
- Funcionalidad Bluetooth opcional para ampliar las opciones de conectividad local
- Soporte para plataformas de gestión de dispositivos que facilitan la supervisión remota

## Cómo funciona con Plaspy

Al integrarse con Plaspy, el XT-6300 provee datos en tiempo real de ubicación y eventos que pueden visualizarse, analizarse y usarse para activar flujos de trabajo operativos. Plaspy agrega la salida del dispositivo y la presenta en paneles e informes para ayudar a los equipos a monitorear activos en tiempo real y revisar la actividad histórica.

- Visibilidad en vivo de la ubicación y seguimiento en mapas para vehículos y equipos móviles
- Detección de movimiento y actividad para generar alertas por arranques, paradas y movimientos inusuales
- Datos de diagnóstico y del bus vehicular disponibles en Plaspy para planificar mantenimiento y reportar excepciones
- Rutas históricas y registros de eventos para revisiones de cumplimiento y análisis operativo
- Alertas y notificaciones basadas en reglas configurables para respaldar la supervisión operativa

## Casos de uso típicos

- Seguimiento de vehículos de flota para visibilidad de rutas y localización de activos
- Monitoreo de equipos en sitios remotos y flotas con activos mixtos
- Planificación de mantenimiento basada en telemática usando datos de diagnóstico
- Reportes regulatorios y operativos, incluyendo horas de operación e historial de eventos
- Monitoreo remoto de movimiento y detección de desplazamientos no autorizados por seguridad

## Por qué elegir este rastreador con Plaspy

El XT-6300 es una opción práctica para organizaciones que requieren una combinación de seguimiento de ubicación preciso, detección de movimiento y acceso a información de diagnóstico vehicular. Su firmware compatible con scripts y las interfaces opcionales ofrecen adaptabilidad, permitiendo a integradores y administradores de flota ajustar el comportamiento a necesidades operativas específicas sin cambiar el hardware.

En conjunto con Plaspy, el XT-6300 forma parte de un entorno de monitoreo centralizado donde la ubicación, los eventos de movimiento y los diagnósticos pueden combinarse con otros datos de flota. Esta combinación ayuda a los equipos a mantener visibilidad en flotas con dispositivos mixtos y respalda análisis, generación de informes y flujos de alertas dentro de una sola plataforma.
