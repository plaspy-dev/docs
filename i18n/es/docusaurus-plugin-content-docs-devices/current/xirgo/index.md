# Xirgo

Xirgo fabrica una gama de dispositivos telemáticos y rastreadores GPS empleados en el monitoreo de vehículos y activos. En esta página encontrará cómo los equipos Xirgo se integran con Plaspy, qué características comunes puede esperar, casos de uso típicos y orientación para elegir el rastreador adecuado. El catálogo de dispositivos que aparece más abajo muestra todos los modelos que pueden integrarse con Plaspy para que pueda identificar hardware compatible rápidamente.

## Cómo funcionan los dispositivos Xirgo con Plaspy

Los rastreadores Xirgo transmiten ubicación y telemetría a través de redes celulares. Plaspy recibe esos datos utilizando protocolos telemáticos estándar y los presenta en una interfaz unificada. La integración cubre el aprovisionamiento de dispositivos, el rastreo en tiempo real y el reenvío de datos dentro de Plaspy, de modo que los administradores de flotas y operadores puedan monitorear activos junto con hardware de otras marcas.

Los puntos clave de integración suelen incluir la identificación del dispositivo, actualizaciones de posición, reporte de eventos y parámetros básicos de configuración. Para configuraciones específicas del equipo y funciones avanzadas, consulte la documentación por modelo accesible desde el catálogo y las guías de dispositivo en Plaspy.

## Características comunes en los dispositivos Xirgo

Aunque las capacidades varían según el modelo, muchos dispositivos Xirgo suelen ofrecer:
- Reporte de ubicación GPS con intervalos de actualización configurables
- Conectividad celular para seguimiento en vivo
- Detección de alimentación del vehículo y modos de reposo para activos con batería
- Entradas y salidas (I/O) para sensores y control remoto
- Informes de eventos básicos como encendido, movimiento, manipulación y entradas a geocercas
Estas funciones generales permiten que el hardware Xirgo se integre de forma ordenada con Plaspy para flujos de trabajo de rastreo y gestión de flotas.

## Casos de uso típicos para rastreadores Xirgo

El hardware Xirgo se emplea en diversos escenarios de rastreo:
- Seguimiento de vehículos de flota para despacho y supervisión de rutas
- Monitoreo de activos como remolques, maquinaria y equipos en alquiler
- Monitoreo de comportamiento del conductor cuando se integra en flujos telemáticos
- Alertas basadas en ubicación para geocercas y límites de obra
Plaspy organiza los datos entrantes de los dispositivos Xirgo en paneles, alertas e informes históricos para apoyar estas necesidades operativas.

## Por qué elegir Plaspy para monitorear dispositivos Xirgo

Plaspy ofrece una vista única para despliegues con marcas mixtas, lo que facilita gestionar dispositivos Xirgo junto con otro hardware telemático. Entre los beneficios de usar Plaspy con equipos Xirgo se incluyen:
- Gestión centralizada de dispositivos y monitorización de estado
- Informes flexibles y reproducción histórica de ubicaciones
- Herramientas integradas de alertas y geocercas personalizables
- Opciones de integración para exportar datos a sistemas de terceros o flujos downstream
Plaspy se enfoca en la interoperabilidad y la facilidad de uso para que los equipos puedan incorporar unidades Xirgo sin rehacer sus procesos de rastreo.
