# Xirgo - XT-2400

![XT-2400](./logo.jpg)

El rastreador GPS Xirgo XT-2400 es un dispositivo versátil y compacto diseñado para supervisar y comunicar información vital del vehículo. Es especialmente adecuado para su uso en vehículos de pasajeros y utilitarios.

Este rastreador GPS es ideal para una variedad de aplicaciones, incluyendo la gestión de recursos móviles, el mercado de accesorios automotrices, soluciones para consumidores y la supervisión del comportamiento del conductor y la modificación.

Algunas de las características destacadas del Xirgo XT-2400 incluyen:

- Scripts personalizables para adaptarse a las necesidades específicas de las soluciones.
- Antenas celulares y GPS integradas para una conectividad confiable.
- Motor de GPS de alta precisión para una ubicación precisa.
- Acelerómetro para detectar y registrar cambios en la velocidad y la dirección.
- Interfaz OBDII integrada que permite el seguimiento de la ubicación, velocidad, VIN y estado de encendido, entre otros parámetros.
- Capacidad para leer y registrar códigos de avería \(CFD / DTC\) para el diagnóstico de problemas del vehículo.

Con el rastreador GPS Xirgo XT-2400, puede tener la tranquilidad de saber que está monitoreando y controlando de manera efectiva su flota de vehículos o su propio vehículo personal. Su diseño compacto y sus características avanzadas lo convierten en una opción confiable para cualquier aplicación de rastreo GPS.
