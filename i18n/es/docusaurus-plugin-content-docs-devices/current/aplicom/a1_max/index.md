# Aplicom - A1 MAX

![A1 MAX](./logo.jpg)

El Aplicom A1 MAX es un rastreador GPS con funcionalidad telemática incorporada, diseñado específicamente para aplicaciones profesionales y telemática de flotas. Este dispositivo es ideal para aquellos que requieren información detallada sobre el rendimiento del conductor y los datos del motor, utilizando la conectividad digital de FMS/tacógrafo y la interfaz CAN. Con el Aplicom A1 MAX, podrás realizar seguimiento y localización, identificación del conductor, obtener información precisa sobre el kilometraje, administrar la energía, gestionar eventos internos y externos, y comunicarte de manera eficiente con los datos optimizados.

El Aplicom A1 MAX cuenta con una amplia gama de características destacadas, entre las cuales se incluyen:

- Interfaz CAN para FMS, con opciones de identificación o ISOBUS.
- 3 puertos serie \(2xRS232 y 1xRS485\).
- 1 hilo para mensajes de estado y reconocimiento del conductor.
- 6 entradas digitales \(4 de las cuales se pueden utilizar como entradas analógicas y 2 como contadores de pulsos\).
- 2 salidas digitales.
- Amplia capacidad de memoria para un funcionamiento suave y la posibilidad de ampliar las funciones.
- Arquitectura de dos procesadores altamente confiable.
- Posicionamiento GPS/GLONASS con soporte de A-GPS y posicionamiento identificador de celda.
- Antenas GSM y GPS/GLONASS.
- Acelerómetro 3D para medición de la aceleración basada, detección de movimiento y atención.
- Opción de kit manos libres.
- Opción de batería interna.
- Posibilidad de ampliar las características del dispositivo mediante opciones de software disponibles, incluso a través del servicio de actualización OTA de Aplicom.
- Programable en Java \(opción SDK\).
- Soporte de geocercas con diferentes formas para definir geocercas \(círculo, caja, polígono\) y generar informes de entrada/salida de geocercas.

Con el Aplicom A1 MAX, tendrás un rastreador GPS confiable y versátil que te brindará todas las herramientas necesarias para gestionar eficientemente tu flota y obtener información valiosa sobre el rendimiento de tus conductores y vehículos.
