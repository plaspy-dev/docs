# Aplicom - A9 Quick

![A9 Quick](./logo.jpg)

El Aplicom A9 Quick es una unidad telemática de vehículos diseñada para facilitar el seguimiento y la localización de vehículos. Es fácil de instalar y se puede mover fácilmente de un vehículo a otro. Todo lo que el conductor tiene que hacer es conectar la unidad a la toma del encendedor de cigarrillos para comenzar a utilizar sus funcionalidades preconfiguradas y versátiles.

El Aplicom A9 Quick ofrece más posibilidades de uso con el Aplicom 3PAD. El 3PAD es un pequeño teclado de 3 botones que se utiliza para el registro electrónico del conductor u otras interfaces de uso sencillo donde se requiere la presentación de informes por parte del usuario.

Algunas de las características destacadas del Aplicom A9 Quick incluyen un rápido punto de referencia con A-GPS, una pila de reserva, una amplia capacidad de memoria para un funcionamiento suave y la posibilidad de ampliar las funciones. También cuenta con una arquitectura de dos procesadores altamente confiable, posicionamiento GPS/GLONASS con identificador de celda de respaldo, antenas internas de GSM y GPS/GLONASS, medición de aceleración basada en un acelerómetro 3D para detección de movimiento y atención, y soporte de geocerca con diferentes formas para la definición de geocercas y generación de informes de entrada/salida.

El Aplicom A9 Quick también ofrece la posibilidad de expandir sus características, ya que cuenta con muchas opciones de software disponibles, que incluso se pueden actualizar más tarde a través del servicio de actualización OTA de Aplicom.
