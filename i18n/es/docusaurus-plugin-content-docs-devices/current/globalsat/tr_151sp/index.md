# GlobalSat - TR-151SP

![TR-151SP](./logo.jpg)

El GlobalSat TR-151SP es un rastreador GPS/GSM/GPRS de alta capacidad de batería diseñado para un largo tiempo de operación. Con su batería de 15A, este rastreador ofrece un impresionante tiempo de espera de hasta un mes, lo que lo hace ideal para necesidades de seguimiento prolongado. Ya sea que necesite monitorear equipos o activos, el TR-151SP es una solución confiable.

Este rastreador está equipado con tecnología GPS, lo que le permite determinar con precisión su ubicación. Puede enviar mensajes SMS con su ubicación GPS al teléfono celular del usuario a través de la red GSM o a una computadora personal a través de una conexión a Internet utilizando la red GPRS. Esto permite a los usuarios rastrear fácilmente la ubicación de sus equipos o activos.

El TR-151SP cuenta con un botón de reinicio para una operación conveniente. Su construcción duradera garantiza un rendimiento confiable incluso en entornos desafiantes. Este rastreador es particularmente adecuado para el seguimiento de carga durante el transporte y la monitorización de equipos/activos.

### Características destacadas:

- Batería de alta capacidad para un largo tiempo de operación
- Tiempo de espera de hasta un mes
- Tecnología GPS para un seguimiento preciso de la ubicación
- Notificaciones SMS con ubicación GPS
- Compatible con redes GSM y GPRS
- Botón de reinicio para una fácil operación
- Construcción duradera para un rendimiento confiable
- Ideal para el seguimiento de carga y la monitorización de equipos/activos
