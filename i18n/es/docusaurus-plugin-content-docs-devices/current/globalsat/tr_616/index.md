# GlobalSat - TR-616

![TR-616](./logo..jpg)

El GlobalSat TR-616C1 es un rastreador GPS 4G LTE diseñado para aplicaciones de seguimiento de vehículos. Es una plataforma de comunicación multifuncional y económica que integra un módulo GPS de alta sensibilidad y un módulo de comunicación LTE-FDD/LTE-TDD/HSPA+/EDGE/GPRS/GSM de banda múltiple. Este dispositivo compacto está encapsulado en una carcasa sólida para una fácil instalación.

El TR-616C1 proporciona posiciones GPS en tiempo real en el cielo abierto, lo que permite un seguimiento y monitoreo preciso de vehículos. Ofrece una gestión de flotas mejorada, una mayor seguridad de los vehículos, capacidades de respuesta en caso de emergencia y una eficiente transformación de mercancías/artículos. Con su potente microcontrolador y soporte de comandos AT, el TR-616C1 permite un desarrollo de aplicaciones fácil y rápido.

Las características clave del GlobalSat TR-616C1 incluyen soporte para transferencia de datos LTE CAT1/HSPA+/EDGE/GPRS, sistema GPS de alta sensibilidad incorporado con una antena activa, control remoto a través de LTE/SMS/GSM/GPRS y seguimiento GPS en tiempo real. También admite la función de geovallado, actualización de firmware OTA y tiene una capacidad de almacenamiento de búfer de datos de 3,000 puntos. El TR-616C1 está equipado con un sensor G y tiene 3 indicadores LED para el estado celular, GPS y de alimentación.

### Características destacadas:

- Soporte para transferencia de datos LTE CAT1/HSPA+/EDGE/GPRS
- Módulo GPS de alta sensibilidad con antena activa
- Control remoto a través de LTE/SMS/GSM/GPRS
- Seguimiento GPS en tiempo real
- Función de geovallado
- Actualización de firmware OTA
- Capacidad de almacenamiento de búfer de datos de 3,000 puntos
- Sensor G y 3 indicadores LED para estado celular, GPS y de alimentación
