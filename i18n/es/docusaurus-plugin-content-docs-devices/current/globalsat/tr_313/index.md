# GlobalSat - TR-313

![TR-313](./logo.jpg)

El rastreador GPS TR-313 de GlobalSat es un dispositivo avanzado diseñado para el seguimiento personal en redes 3G. Es compacto, ligero y fácil de usar, lo que lo convierte en una opción ideal para el control de la seguridad de los niños, los ancianos y una amplia gama de aplicaciones de seguimiento personal.

Equipado con un módulo GPS de rápida adquisición, el TR-313 proporciona una localización precisa en tiempo real. Además, cuenta con un micrófono y un altavoz, lo que permite las comunicaciones de dos vías con manos libres. Esto significa que no solo podrás rastrear la ubicación de la persona, sino que también podrás comunicarte con ella de forma remota.

Una característica destacada del TR-313 es su botón de emergencia, que permite al propietario acceder fácilmente a números de teléfono preestablecidos y enviar alertas de emergencia con solo una pulsación. Esto brinda una mayor tranquilidad y seguridad en situaciones de emergencia.

En resumen, el rastreador GPS TR-313 de GlobalSat es una opción confiable y versátil para el seguimiento personal. Su combinación de localización precisa, comunicaciones de dos vías y botón de emergencia lo convierten en una herramienta invaluable para el control de la seguridad de los seres queridos.

### Características destacadas:

- Red 3G para un seguimiento rápido y confiable
- Módulo GPS de rápida adquisición para una localización precisa
- Micrófono y altavoz para comunicaciones de dos vías con manos libres
- Botón de emergencia para acceder fácilmente a números de teléfono preestablecidos y enviar alertas de emergencia
- Compacto, ligero y fácil de usar
