# GlobalSat - TR-151

![TR-151](./logo.jpg)

El rastreador GPS TR-151 de GlobalSat es una opción duradera y resistente al agua para el seguimiento de vehículos y activos. Este dispositivo GPS / GSM / GPRS se puede instalar fácilmente en vehículos o activos y enviará la ubicación a través de SMS a un teléfono móvil o a través de una conexión a Internet a un ordenador personal.

Con una batería de alta capacidad de Li-ion, el TR-151 ofrece un tiempo de funcionamiento prolongado, lo que lo convierte en una opción confiable para el seguimiento a largo plazo. Además, cuenta con un botón de SOS para situaciones de emergencia, brindando una capa adicional de seguridad.

El TR-151 es extremadamente fácil de instalar y ocultar en un vehículo, lo que lo hace ideal para aplicaciones de seguimiento de vehículos y supervisión de activos. Ya sea que necesite realizar un seguimiento de una flota de vehículos o monitorear equipos valiosos, el TR-151 es una opción confiable y eficiente.

### Características destacadas:

- Duradero y resistente al agua
- Envío de ubicación a través de SMS o conexión a Internet
- Batería de alta capacidad de Li-ion para un tiempo de funcionamiento prolongado
- Botón de SOS para situaciones de emergencia
- Fácil instalación y ocultación en vehículos
