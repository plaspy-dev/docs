# GlobalSat - TR-300V

![TR-300V](./logo.jpg)

El rastreador GPS GlobalSat TR-300V es un dispositivo diseñado específicamente para monitorear la seguridad de niños y ancianos. Es compacto, ligero y fácil de usar, lo que lo convierte en una excelente opción para aquellos que buscan una solución de seguimiento personal confiable.

Equipado con un micrófono y un altavoz, este dispositivo permite la comunicación bidireccional manos libres, lo que brinda tranquilidad tanto para el usuario como para sus seres queridos. Además, cuenta con una batería de alta capacidad que evita la necesidad de cargarlo con frecuencia, lo que lo convierte en un dispositivo conveniente y de larga duración.

Una característica destacada del TR-300V es su botón SOS, que permite al propietario del dispositivo llamar a números de teléfono preestablecidos y enviar una alarma SOS con solo presionar un botón. Esto proporciona una forma rápida y fácil de solicitar ayuda en caso de emergencia.

Además, este rastreador GPS permite al centro de control configurar y realizar un seguimiento del dispositivo de forma remota mediante el envío de comandos GPRS / SMS. También ofrece la opción de configurar geocercas, que son áreas permitidas o restringidas, lo que brinda opciones de control más flexibles para el propietario del dispositivo.

En resumen, el rastreador GPS GlobalSat TR-300V es una excelente opción para aquellos que desean monitorear la seguridad de niños y ancianos. Con su comunicación bidireccional, batería de alta capacidad y funciones de control remoto, brinda tranquilidad y seguridad en todo momento.

### Características destacadas:

- Comunicación bidireccional manos libres
- Batería de alta capacidad
- Botón SOS para solicitar ayuda en caso de emergencia
- Control remoto mediante comandos GPRS / SMS
- Configuración de geocercas para áreas permitidas o restringidas
