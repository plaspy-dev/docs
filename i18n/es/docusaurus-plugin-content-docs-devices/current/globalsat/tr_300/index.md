# GlobalSat - TR-300

![TR-300](./logo.jpg)

El rastreador GPS GlobalSat TR-300 es un dispositivo de red 3G diseñado especialmente para monitorear la seguridad de niños y ancianos. Es compacto, ligero y fácil de usar, lo que lo convierte en una excelente opción para aquellos que buscan una solución de seguimiento personal confiable.

Equipado con un micrófono y un altavoz, el TR-300 permite la comunicación bidireccional manos libres, lo que brinda tranquilidad tanto para el usuario como para sus seres queridos. Además, cuenta con una batería de alta capacidad que evita la necesidad de cargarlo con frecuencia, lo que lo convierte en un dispositivo conveniente y de larga duración.

Una de las características destacadas del TR-300 es su botón SOS, que permite al propietario del dispositivo llamar a números de teléfono preestablecidos y enviar una alarma SOS con solo presionar un botón. Esto brinda una forma rápida y fácil de solicitar ayuda en caso de emergencia.

Además, el TR-300 permite al centro de control configurar y realizar un seguimiento del dispositivo de forma remota mediante el envío de comandos GPRS / SMS. Esto brinda una mayor flexibilidad y control sobre la ubicación y el estado del dispositivo.

Otra característica útil del TR-300 es la configuración de geo-cerca, que permite crear áreas permitidas o restringidas. Esto proporciona opciones de control más flexibles para el propietario del dispositivo, lo que es especialmente útil para garantizar la seguridad de los niños o para delimitar áreas seguras para los ancianos.

En resumen, el rastreador GPS GlobalSat TR-300 es una excelente opción para aquellos que buscan una solución de seguimiento personal confiable y fácil de usar. Con su comunicación bidireccional, botón SOS, batería de alta capacidad y configuración de geo-cerca, brinda tranquilidad y control a los usuarios y sus seres queridos.
