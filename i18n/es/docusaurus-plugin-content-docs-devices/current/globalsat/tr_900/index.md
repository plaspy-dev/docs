# GlobalSat - TR-900

![TR-900](./logo.jpg)

El rastreador GPS TR-900 de GlobalSat es un dispositivo plug and play tipo dongle que se conecta al puerto OBDII de cualquier vehículo de pasajeros fabricado después de 1998. Además de proporcionar posicionamiento GPS preciso, este rastreador también puede capturar datos de diagnóstico OBDII directamente desde el vehículo.

El TR-900 está equipado con módulos de red 3G que permiten la conexión a redes UMTS y GPRS. Esto garantiza una comunicación estable y confiable en tiempo real. Además, cuenta con un sensor de alta sensibilidad G que registra los valores de fuerza G para evaluar los comportamientos de conducción áspera y generar alertas de impacto.

Entre las funciones destacadas del TR-900 se encuentran el informe de acumulación de millas, la alerta de exceso de velocidad, la alerta de RPM de revoluciones, las alertas de temperatura del refrigerante, las alertas de estado MIL y la captura de códigos de diagnóstico \(DTC\). Además, este rastreador ofrece un protocolo basado en eventos altamente personalizable para generar informes de alerta personalizados que combinan datos OBDII y datos de ubicación GPS.

Con su fácil instalación y su capacidad para capturar datos de diagnóstico OBDII, el rastreador GPS TR-900 de GlobalSat es una excelente opción para aquellos que desean tener un control completo sobre la ubicación y el rendimiento de sus vehículos.

### Características destacadas:

- Plug and play: fácil instalación
- Conexión a redes 3G \(UMTS y GPRS\)
- Sensor de alta sensibilidad G para alertas de impacto
- Informe de acumulación de millas
- Alerta de exceso de velocidad
- Alerta de RPM de revoluciones
- Alertas de temperatura del refrigerante
- Alertas de estado MIL
- Captura de códigos de diagnóstico \(DTC\)
- Protocolo basado en eventos personalizable
