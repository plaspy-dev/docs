# HunterPro - CP60G

![CP60G](./logo.jpg)

El rastreador GPS HunterPro CP60G es una excelente opción para el seguimiento y recuperación de vehículos. Con su bajo costo y tecnología robusta, este dispositivo es ideal para empresas de seguros, empresas de alquiler de coches y empresas de seguimiento. El CP60G utiliza tecnología GSM/GPRS y GPS para una ubicación precisa y rápida, con una amplia cobertura y un rendimiento excepcional. Además, cuenta con un protocolo abierto para AVL/GPS y un software fácil de usar.

El HunterPro CP60G cuenta con una serie de características destacadas, como una banda GSM cuatribanda completa, lo que garantiza una conectividad confiable en cualquier parte del mundo. También cuenta con una batería de respaldo, lo que significa que seguirá funcionando incluso si se desconecta de la fuente de alimentación principal. Además, tiene tres entradas digitales y entradas predefinidas para la ignición, el pánico y las puertas, lo que permite una mayor flexibilidad en la configuración del dispositivo.

El rastreador GPS HunterPro CP60G está fabricado en Taiwán y cuenta con una carcasa de plástico resistente. También ofrece conexiones adicionales para antenas fijas, sensores de combustible y sensores de temperatura, lo que lo hace aún más versátil y adaptable a diferentes necesidades y aplicaciones.
