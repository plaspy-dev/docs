# CanTrack - GT06

![GT06](./logo.jpg)

El rastreador GPS CanTrack GT06 utiliza la tecnología de satélite GSM/GPRS y GPS para localizar y supervisar de forma remota cualquier objetivo. Diseñado para ser compacto y fácil de usar, este dispositivo cuenta con un módulo GPS y GSM que captura datos de ubicación y los envía a un número de teléfono móvil autorizado a través de SMS. Estos datos también se pueden visualizar en tiempo real en Google Earth o Google Maps. Además, los datos GPS pueden ser transmitidos por GPRS a un servidor de Internet, lo que permite un seguimiento en tiempo real en un ordenador.

El CanTrack GT06 es ideal para una variedad de aplicaciones, como el seguimiento de vehículos en alquiler o la gestión de flotas. También se puede utilizar como un sistema antirrobo para motocicletas, motos o bicicletas, permitiendo un seguimiento en tiempo real de su ubicación. Además, este rastreador GPS es útil para el manejo de personal, ya que permite conocer la ubicación de los empleados en todo momento.

Características destacadas del CanTrack GT06:

- GSM de cuatro bandas de frecuencia para uso global
- Seguimiento en tiempo real por SMS/GPRS
- Recuperación de contraseña original
- Configuración de números autorizados
- Alarma de exceso de velocidad
- Alarma antirrobo ACC
- Alarma SOS
- Función de control de voz en tiempo real
- Batería de respaldo para alarmas de apagón
- Opción de corte de aceite o circuito del vehículo
