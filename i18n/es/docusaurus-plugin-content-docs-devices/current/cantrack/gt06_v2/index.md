# CanTrack - GT06 v2

![GT06 v2](./logo.jpg)

El rastreador GPS CanTrack GT06 v2 utiliza la tecnología de satélites GSM / GPRS y GPS para localizar y supervisar de forma remota cualquier objetivo. Diseñado para ser compacto y fácil de usar, este dispositivo es ideal para el seguimiento de vehículos. Con su función de GPS y módulo GSM, captura datos GPS y los envía a un número de teléfono móvil autorizado a través de SMS. Puede mostrar la ubicación actual en el teléfono o realizar un seguimiento en tiempo real en Google Earth o Google Maps. Además, los datos GPS también se pueden transmitir por GPRS al servidor de Internet, lo que permite un seguimiento en tiempo real en un ordenador.

Este rastreador GPS es perfecto para una variedad de aplicaciones, como el alquiler de vehículos, la gestión de flotas, la prevención de robos de motocicletas, motos y bicicletas, y el seguimiento en tiempo real de estos vehículos. También es útil para el manejo de personal, ya que permite conocer la ubicación de los empleados en todo momento.

Algunas de las características destacadas del CanTrack GT06 v2 incluyen:

- GSM de cuatro bandas de frecuencia para uso global
- Seguimiento en tiempo real por SMS / GPRS
- Recuperación de contraseña original
- Configuración de números autorizados
- Alarma de exceso de velocidad
- Alarma antirrobo ACC
- Alarma SOS
- Función de control de voz en tiempo real
- Batería de respaldo para alarmas de apagón
- Opción de corte de aceite o circuito del vehículo
