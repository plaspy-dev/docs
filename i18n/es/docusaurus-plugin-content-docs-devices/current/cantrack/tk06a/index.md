# CanTrack - TK06A

![TK06A](./logo.jpg)

El rastreador GPS CanTrack TK06A utiliza la tecnología de satélites GSM / GPRS y GPS para localizar y supervisar de forma remota cualquier objetivo a través de SMS o GPRS. Diseñado para ser compacto y fácil de usar, este dispositivo es ideal para el seguimiento de vehículos. Con su función de GPS y módulo GSM, captura datos GPS y los envía a un número de teléfono móvil autorizado a través de SMS, lo que permite mostrar la ubicación actual en el teléfono o realizar un seguimiento en Google Earth o Google Maps. Además, los datos GPS también se pueden transmitir por GPRS al servidor de Internet, lo que permite realizar un seguimiento en tiempo real en un ordenador.

Este rastreador GPS CanTrack TK06A es perfecto para diversas aplicaciones, como la gestión de flotas de alquiler de vehículos, la prevención de robos de motocicletas, motos y bicicletas, el seguimiento en tiempo real de motocicletas, motos y bicicletas, y la gestión de personal. Con su amplia gama de funciones, este dispositivo ofrece una solución confiable y eficiente para el seguimiento y la supervisión de activos.

Características destacadas:

- Frecuencia GSM de cuatro bandas para uso global
- Seguimiento en tiempo real por SMS / GPRS
- Función de supervisión de voz en tiempo real
- Recuperación de contraseña original
- Configuración de números autorizados
- Reinicio del dispositivo
- Alarma de exceso de velocidad / fallo de alimentación
- Alarma de robo ACC
- Conexión de relé externo para controlar el petróleo y el circuito del vehículo \(opcional\)
- Capacidad de batería de reserva para alarma de fallo de alimentación \(opcional\)
