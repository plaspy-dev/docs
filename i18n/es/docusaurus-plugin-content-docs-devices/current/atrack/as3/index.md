# ATrack - AS3

![AS3](./logo.jpg)

El rastreador GPS AS3 de ATrack es una solución ideal para el control de vehículos o remolques. Utiliza GPS para el seguimiento de la ubicación y GPRS / HSPA / CDMA para la comunicación de datos. Además, cuenta con una batería interna recargable, lo que lo convierte en una opción perfecta para la gestión de activos que pueden ser desconectados por períodos de tiempo.

El AS3 está diseñado para funcionar en entornos difíciles, con un índice de protección IP67 que lo protege contra la temperatura, el polvo y el agua pulverizada. También cuenta con GPIOs que permiten una amplia gama de aplicaciones.

Algunas de las características destacadas del AS3 incluyen:

- Opciones de red de comunicación de datos flexibles.
- Comunicación de datos a través de SMS / TCP / UDP.
- Gran capacidad de batería de reserva.
- GPS opcional + GLONASS motor.
- Built-in de 3 ejes G-Sensor.
- Actualización del firmware a través de FOTA \(Firmware Over-The-Air\) mediante FTP.
- Configuración de seguimiento en tiempo real y tala.
- Máquina de control inteligente de eventos.
