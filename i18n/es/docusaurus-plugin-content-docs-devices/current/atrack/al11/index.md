# ATrack - AL11

![AL11](./logo..jpg)

El ATrack AL11 es un dispositivo de rastreo con conectividad 4G LTE/3G y clasificación IP diseñado para monitorear diversos tipos de activos móviles. Con su conectividad confiable y carcasa resistente, es adecuado para diversas aplicaciones de rastreo.

Este dispositivo de rastreo ofrece conectividad 4G Cat.1/3G, lo que garantiza una conexión estable y rápida para el seguimiento y monitoreo en tiempo real. Se puede instalar fácilmente con una conexión de 3 cables, lo que lo hace conveniente tanto para instaladores profesionales como para entusiastas del bricolaje.

El AL11 cuenta con un diseño de carcasa con clasificación IP67, que proporciona protección contra agua y polvo. Esta carcasa resistente garantiza que el dispositivo pueda resistir entornos difíciles y seguir funcionando de manera óptima.

Equipado con un acelerómetro de 3 ejes incorporado, el AL11 puede detectar impactos y proporcionar información valiosa sobre el movimiento y el comportamiento del activo rastreado. Esta característica es particularmente útil para la seguridad de los activos y la detección de accidentes.

En general, el ATrack AL11 es un dispositivo de rastreo flexible y confiable que ofrece una instalación fácil, conectividad robusta y características avanzadas para monitorear activos móviles. Ya sea que necesite rastrear vehículos, equipos u otros activos valiosos, el AL11 es una excelente opción.

### Características destacadas:

- Conectividad 4G LTE/3G
- Instalación fácil con conexión de 3 cables
- Carcasa resistente con clasificación IP67
- Acelerómetro de 3 ejes para detección de impactos
