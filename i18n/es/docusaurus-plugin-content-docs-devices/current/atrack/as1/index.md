# ATrack - AS1

![AS1](./logo.jpg)

El rastreador GPS AS1 de ATrack es ideal para el seguimiento de activos móviles. Utiliza tecnología GPS para rastrear la ubicación y GPRS / HSPA / CDMA para la comunicación de datos. Con un diseño resistente y un índice de protección IP67, este rastreador ofrece una protección total contra la temperatura, el polvo y el agua pulverizada.

Una de las características destacadas del AS1 es su duración de batería de hasta 3 años, lo que lo convierte en una solución ideal para despliegues a largo plazo. Además, no requiere cables externos ni antenas, lo que facilita su instalación y uso.

El AS1 ofrece opciones flexibles de comunicación de datos, incluyendo SMS, TCP y UDP. También cuenta con un motor GPS + GLONASS opcional para una mayor precisión en la ubicación. Además, incorpora un sensor de movimiento de 3 ejes para detectar cualquier movimiento del activo.

Otras características destacadas incluyen la capacidad de actualizar el firmware a través de FOTA \(Firmware Over-The-Air\) utilizando FTP, la posibilidad de configurar seguimiento en tiempo real y tala, y la capacidad de definir hasta 5 geo-cercas personalizadas.
