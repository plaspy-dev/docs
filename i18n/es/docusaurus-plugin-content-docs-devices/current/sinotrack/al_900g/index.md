# SinoTrack - AL-900G

![AL-900G](./Logo.png)

El rastreador GPS SinoTrack AL-900G es un dispositivo confiable y versátil que ofrece una amplia gama de funciones y características. Con una temperatura de funcionamiento de -15 ° C a 80 ° C y una temperatura de almacenamiento de -20 ° C a 85 ° C, este rastreador es adecuado para su uso en una variedad de entornos. Además, cuenta con una protección IP53, lo que significa que es resistente al polvo y a salpicaduras de agua.

El AL-900G tiene un voltaje de potencia de 9V a 40V y una corriente de entrada de 80mA a 2000mA. También cuenta con una batería de respaldo de litio de 4.2V / 750mAH para garantizar un funcionamiento continuo incluso en caso de pérdida de energía. El módulo GSM del rastreador es compatible con cuatro bandas GSM850 / 900/1800/1900 \(MHz\), lo que garantiza una conectividad confiable en todo momento.

Entre las funciones destacadas del SinoTrack AL-900G se incluyen el posicionamiento por satélite las 24 horas, el seguimiento de ubicación en tiempo real a través de SMS y GPRS, y la capacidad de realizar escuchas telefónicas autorizadas. También cuenta con alarmas de exceso de velocidad, llamadas de socorro y alarmas de encendido / apagado principal. Además, el rastreador ofrece funciones de entrada y salida, como el control remoto de combustible y electricidad, y la capacidad de configurar parámetros como la contraseña de SMS, el valor de exceso de velocidad y el intervalo de tiempo del informe de posición.

El SinoTrack AL-900G también ofrece características adicionales, como la capacidad de tomar fotos a través de comandos de la plataforma, la compatibilidad con lectores de tarjetas RFID para la identificación de conductores y la gestión de registros de conductores, y la capacidad de detectar la conducción por fatiga. Además, el rastreador cuenta con una tarjeta SD para almacenar todos los datos de ubicación, y una impresora opcional que se conecta directamente al rastreador para imprimir datos del vehículo, datos del conductor y más.

En resumen, el rastreador GPS SinoTrack AL-900G es una opción confiable y completa para aquellos que buscan un dispositivo de seguimiento de alta calidad con una amplia gama de funciones y características. Ya sea para uso personal o comercial, este rastreador ofrece un rendimiento excepcional y una gran cantidad de opciones de personalización.
