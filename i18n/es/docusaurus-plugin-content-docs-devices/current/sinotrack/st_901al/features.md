# SinoTrack - Características del ST-901AL

Esta página ofrece un resumen público de las capacidades prácticas del SinoTrack ST-901AL cuando se utiliza con Plaspy. Describe cómo se traducen sus funciones al monitoreo y control en Plaspy, y qué beneficios operativos pueden esperar las organizaciones al desplegar este rastreador vehicular cableado con nuestra plataforma.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y la implementación del fabricante. La descripción se basa en información pública del dispositivo y el conjunto de funciones del ST-901AL; los instaladores deben confirmar los detalles del equipo y el comportamiento del firmware más reciente en la documentación del fabricante.

## Resumen de funciones

El ST-901AL es un rastreador profesional cableado con conectividad 4G LTE pensado para la supervisión de vehículos. Ofrece varios canales de reporte y control remoto básico mediante un relé externo. Está diseñado para instalación por técnicos capacitados y permite la integración con plataformas de terceros como Plaspy mediante APN y ajustes de servidor configurables.

- Informes de ubicación en tiempo real usando GPRS como canal principal y SMS como alternativa para mayor resiliencia.
- Entrada ACC para detección de ignición, registrando eventos de encendido y apagado del motor para reportes de tiempo de conducción y uso.
- Control de relé externo para cortar suministro de combustible o circuitos eléctricos de forma remota, apoyando flujos de respuesta ante robo.
- Configuración de APN y servidor vía SMS para apuntar el dispositivo a la plataforma de seguimiento escogida, como Plaspy.
- Factor de forma cableado profesional apto para instalación en autos, motocicletas y otros vehículos alimentados por línea.

## Funciones principales del SinoTrack - ST-901AL

- Diseño cableado con soporte 4G LTE y compatibilidad GSM para amplio soporte de redes.
- Reportes en tiempo real sobre GPRS complementados por reportes vía SMS como canal alternativo.
- Entrada ACC para telemetría de encendido y apagado del motor.
- Salida de control de relé para habilitar inmovilizador remoto o corte externo cuando se conecta a un relé apropiado.
- Comandos de configuración por SMS para APN, ajustes de servidor y gestión de números autorizados.
- Soporte para SIM instalable por el usuario, de modo que el operador pueda elegir su operador móvil y APN.
- Documentación de instalación y referencias de cableado proporcionadas por el fabricante para instalaciones profesionales.

## Cómo funcionan estas funciones con Plaspy

Cuando se configura para reportar a un endpoint de ingestión de Plaspy, el ST-901AL puede enviar datos de ubicación y eventos para que Plaspy ofrezca monitoreo, historial de trayectos y alertas. Plaspy puede mostrar actualizaciones de posición, reconocer eventos de ignición y exponer el control de relé cuando la instalación y las políticas operativas lo permiten.

- Posiciones y estados en tiempo real recibidos en Plaspy vía GPRS con SMS como canal de respaldo.
- Los eventos de ignición desde la entrada ACC se convierten en marcadores de motor encendido/apagado que Plaspy puede usar en reportes de tiempo de conducción y filtros de estado.
- La capacidad de control de relé puede emplearse mediante comandos desde Plaspy para accionar un corte externo cableado, sujeta a una instalación segura y a requisitos legales.
- La configuración del dispositivo puede ajustarse en campo mediante secuencias SMS para apuntar APN y parámetros de servidor hacia la integración con Plaspy.
- Plaspy proporciona visibilidad de los eventos entrantes del dispositivo y puede transformar esos eventos en alertas, registros históricos y paneles operativos.

## Casos de uso típicos

- Gestión de flotas de autos, camionetas y camiones ligeros que requieren ubicación, registro de tiempo de ignición y registro básico de eventos.
- Flujos de trabajo de antirrobo y recuperación usando control de relé externo combinado con alertas desde Plaspy.
- Monitoreo de vehículos privados para historial de viajes, alertas de ubicación y notificaciones de seguridad básicas.
- Supervisión de motocicletas y micromovilidad donde es apropiada una instalación de rastreador cableado.
- Instalaciones donde los operadores prefieren controlar la selección de la SIM y la configuración del APN en lugar de depender de una SIM bloqueada por el proveedor.

## Notas sobre disponibilidad de funciones

- Algunas funciones dependen del firmware del equipo y pueden variar entre revisiones de hardware o variantes regionales.
- Las funciones de relé y ACC requieren un cableado correcto durante la instalación; la disponibilidad y el comportamiento dependen de las opciones de instalación.
- La compatibilidad de red para 4G LTE y la conmutación a GSM pueden variar según la región y el operador móvil.
- La configuración vía SMS requiere una SIM activa y servicio SMS del operador; las credenciales APN deben coincidir con la SIM elegida.
- Para conocer el comportamiento y la lista de funciones más actual, consulte la documentación del fabricante.

## Por qué usar Plaspy con estas funciones

Usar el SinoTrack ST-901AL con Plaspy brinda a las organizaciones una vía clara para consolidar ubicación de vehículos, eventos de ignición y alertas de dispositivos en una sola plataforma de monitoreo. Plaspy acepta el tráfico del dispositivo cuando el rastreador está configurado para reportar a la plataforma, lo que permite a los equipos visualizar desplazamientos, generar reportes operativos y responder a eventos desde un único lugar.
