# Teltonika - FMB640 - FMB641

![FMB640 - FMB641](./Logo.png)

El rastreador GPS Teltonika FMB640 es una solución profesional diseñada para aplicaciones complejas donde un dispositivo puede realizar múltiples tareas. Este terminal GNSS y GSM cuenta con funciones como datos FMS CAN \(J1939\), datos CAN de combustible \(J1708\), datos en vivo del tacógrafo \(K-line\), descarga remota de archivos de tacógrafo y compatibilidad con dispositivos RS232 o RS485 de terceros. Además, cuenta con Dual-SIM o eSIM para maximizar la eficiencia de su flota. El FMB640 es adecuado para aplicaciones como logística internacional, transporte refrigerado, agricultura, construcción, minería, seguridad y servicios de emergencia.

El rastreador GPS Teltonika FMB641 es una versión actualizada del FMB640, con un nuevo procesador que mejora la potencia de cálculo del dispositivo. Además, cuenta con terminadores CAN conmutables que permiten su uso en redes CAN con numerosos nodos. Este modelo también puede ser alimentado a través de USB para facilitar el proceso de configuración. Todas las funciones compatibles con el FMB640 también son compatibles con el FMB641, lo que le permite maximizar la eficiencia de su flota. El FMB641 es adecuado para aplicaciones como logística internacional.
