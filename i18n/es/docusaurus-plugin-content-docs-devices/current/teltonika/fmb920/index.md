# Teltonika - FMB920

<div className="device-logo">
![FMB920](./tracker.png)
</div>

El Teltonika FMB920 es un rastreador GPS compacto diseñado para ofrecer seguimiento fiable de vehículos y protección antirrobo. Con una carcasa de apenas 12 mm de altura y un formato pensado para instalaciones discretas, el FMB920 está orientado a vehículos pequeños y activos que requieren una solución telemática de bajo perfil, proporcionando reportes continuos de posición y eventos.

Como dispositivo compatible con Plaspy, el FMB920 entrega las señales telemétricas y entradas de seguridad básicas que los operadores de flota necesitan. Su batería interna de respaldo, soporte para inmovilizador remoto y conectividad Bluetooth LE para sensores y balizas externas lo convierten en una opción práctica para usuarios de Plaspy que requieren datos consistentes de ubicación, ignición y sensores para monitorización, alertas y reportes básicos.

## Características principales

- Rastreador GPS compatible con Plaspy para seguimiento en tiempo real de vehículos y activos.
- Perfil ultra delgado de 12 mm para instalaciones discretas en espacios reducidos.
- Batería interna de respaldo que mantiene los reportes ante cortes temporales de energía.
- Soporte para inmovilizador remoto para apoyar flujos de trabajo antirrobo.
- Entradas estándar para estado de ignición, puertas y alarma útiles para alertas basadas en eventos.
- Capacidad de monitoreo de combustible para soporte de seguimiento básico y detección de anomalías.
- Conectividad Bluetooth LE para emparejar balizas y sensores externos.

## Cómo funciona con Plaspy

Al conectarse a Plaspy, el FMB920 envía actualizaciones de posición, notificaciones de eventos y lecturas de sensores para que los gestores y operadores de flota puedan supervisar activos en tiempo real y revisar la actividad histórica. Plaspy utiliza estos flujos de datos para alimentar mapas en vivo, alertas e informes operativos que facilitan la toma de decisiones y la respuesta ante incidentes.

- Actualizaciones de ubicación en tiempo real y reproducción histórica disponibles en Plaspy para seguimiento y revisión de rutas.
- Estado de ignición, puertas y alarma mostrado en Plaspy para monitorización basada en eventos e información sobre la actividad del conductor.
- Datos de monitoreo de combustible visibles para informes básicos de consumo y alertas por posible robo o manipulación.
- Estado del inmovilizador remoto expuesto en Plaspy para respaldar flujos de respuesta antirrobo.
- Datos de sensores y balizas Bluetooth encaminados a Plaspy para ampliar la monitorización a escenarios de temperatura, humedad y movimiento.

## Casos de uso típicos

- Flujos de trabajo antirrobo y de inmovilización con opciones de respuesta remota.
- Gestión básica de flota y rastreo para vehículos de reparto pequeños y flotas de servicios.
- Monitoreo de combustible y detección de consumos o manipulaciones inusuales.
- Monitorización ampliada de activos usando sensores Bluetooth para condiciones de carga o remolques.
- Protección discreta de vehículos pequeños, scooters o equipos de alto valor.

## Por qué elegir este rastreador con Plaspy

El FMB920 ofrece un conjunto equilibrado de funciones para organizaciones que necesitan seguimiento confiable y características de seguridad básicas sin complejidad innecesaria. Su perfil delgado y la batería interna de respaldo lo hacen ideal para instalaciones discretas, mientras que las entradas telemétricas estándar y el soporte para inmovilizador remoto brindan los controles prácticos que los gestores de flota requieren para la seguridad y la monitorización de eventos.

Emparejado con Plaspy, el FMB920 suministra los datos de ubicación, estado y sensores necesarios para la supervisión en vivo, las alertas y los informes operativos. Si usted busca un rastreador compacto compatible con Plaspy para vehículos pequeños o activos, el FMB920 es una opción sensata a considerar.
