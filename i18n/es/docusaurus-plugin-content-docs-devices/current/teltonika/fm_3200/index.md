# Teltonika - FM 3200

![FM 3200](./logo.jpg)

El rastreador GPS Teltonika FM 3200 es un dispositivo capaz de obtener coordenadas y otros datos y transferirlos a través de la red GSM. Este dispositivo es perfectamente adecuado para aplicaciones donde se necesita la adquisición de la ubicación de objetos remotos, lo que le permite seguir de forma rápida y sencilla sus objetos remotos como camiones, coches, barcos, entre otros.

El FM 3200 también puede realizar tareas en objetos remotos, como el monitoreo del estado del motor y el control de la puerta del camión. En caso de perder conexión, el dispositivo puede almacenar hasta 15.000 registros y, una vez establecida la conexión, enviará los datos almacenados a través de GPRS, asegurando que no se pierdan los datos importantes como coordenadas y datos de sensores.

Características destacadas del rastreador GPS Teltonika FM 3200:

- Obtención de coordenadas y otros datos
- Transferencia de datos a través de la red GSM
- Seguimiento de objetos remotos como camiones, coches, barcos, etc.
- Monitoreo del estado del motor
- Control de la puerta del camión
- Almacenamiento de hasta 15.000 registros en caso de pérdida de conexión
- Envío de datos almacenados a través de GPRS
