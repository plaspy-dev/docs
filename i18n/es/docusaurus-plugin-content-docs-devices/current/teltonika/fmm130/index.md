# Teltonika FMM130

El Teltonika FMM130 es un rastreador GPS compacto diseñado para la gestión profesional de flotas y la seguridad de activos. Como rastreador GPS compatible con Plaspy, el FMM130 combina conectividad LTE Cat M1 y NB‑IoT \(NB2\) con soporte para sensores BLE, integración CAN y herramientas de firmware/configuración remotas para ofrecer un seguimiento en tiempo real confiable y telemetría amplia para vehículos y cargas sensibles.

Con despliegues a nivel mundial, el FMM130 admite modo de reserva 2G cuando se requiere e incluye una batería de respaldo, además de entradas y salidas flexibles. Cuando se integra con Plaspy, este rastreador se convierte en un endpoint telemático robusto que facilita el monitoreo de combustible, el inmovilizador anti‑robo y la monitorización ambiental a través de sensores Bluetooth, todo accesible desde el panel y las herramientas de informes de Plaspy.

## Puntos Clave

- Rastreador GPS compatible con Plaspy con LTE Cat M1 y NB‑IoT \(NB2\) para telemetría celular eficiente de bajo consumo y amplia cobertura.
- Seguimiento y telemetría en tiempo real para la gestión de flotas: posición, datos del CAN bus, odómetro y parámetros del motor.
- Monitoreo de combustible y soporte de entrada por impulso para una integración precisa del caudalímetro y análisis de consumo.
- Soporte de Bluetooth Low Energy \(BLE\) para sensores y balizas \(temperatura, humedad, estado magnético y movimiento\) — ideal para la logística de cadena de frío.
- Múltiples entradas y salidas digitales/analógicas y compatibilidad con adaptadores CAN para acciones remotas, incluida la inmovilización del motor.
- La batería de respaldo garantiza la continuidad de la generación de informes durante interrupciones de energía; gestión remota del dispositivo a través de Teltonika FOTA WEB y herramientas de configuración.
- Formato compacto para vehículos y activos, con opciones de conectividad preparadas para todo el mundo y variantes de producto del fabricante para diferentes regiones de red.

## Cómo Funciona con Plaspy

Cuando se empareja con Plaspy, el FMM130 transmite datos de posición y telemetría a su cuenta de Plaspy para visualización en tiempo real, geocercados, alertas y reportes históricos. Plaspy ingiere las lecturas GNSS del dispositivo, los parámetros derivados del CAN y las lecturas de sensores BLE para crear paneles unificados de vehículos y carga que respaldan la toma de decisiones operativas y el cumplimiento normativo.

- Actualizaciones de ubicación y telemetría en tiempo real entregadas a Plaspy para seguimiento en vivo y reproducción de rutas.
- Estado del motor y del vehículo mediante CAN bus: odómetro, RPM y temperatura del motor aparecen en los informes y diagnósticos de Plaspy.
- Monitoreo de combustible mediante entrada por impulso y datos CAN para un cálculo preciso del consumo y detección de robo de combustible.
- Capacidad de inmovilización remota a través de salidas de E/S para acciones anti‑robo activadas desde Plaspy cuando sea necesario.
- Sensores Bluetooth proporcionan telemetría ambiental \(temperatura, humedad, movimiento, estado magnético\) a Plaspy para el monitoreo de la cadena de frío y cargas sensibles.

## Casos de Uso

- Gestión de flotas: seguimiento continuo en tiempo real, historial de rutas y telemetría del vehículo para automóviles, furgonetas, camiones y autobuses.
- Gestión de combustible y anti‑robo: entrada por impulso más lecturas de combustible CAN y inmovilizador remoto reducen pérdidas de combustible y disuaden el robo.
- Monitoreo de cadena de frío y cargas sensibles: sensores BLE de temperatura y humedad reportan condiciones ambientales en Plaspy.
- Telemetría de maquinaria especial: integración CAN para monitorización remota de horas de motor, RPM y parámetros críticos del motor.
- Seguridad de activos: movimiento y estado magnético mediante balizas BLE, además de informes de la batería de respaldo si se corta la alimentación principal.

## Por qué Elegir Este Rastreador con Plaspy

El FMM130 combina fiabilidad y flexibilidad para satisfacer las necesidades telemáticas profesionales. Sus perfiles de radio LTE Cat M1 y NB2 lo hacen orientado al futuro para una cobertura celular de grado IoT, manteniendo la compatibilidad con 2G cuando sea necesario. Cuando se integra con Plaspy, el FMM130 es más que un rastreador GPS: se convierte en una puerta de telemetría que alimenta la ubicación en tiempo real, el monitoreo de combustible, los diagnósticos CAN y los datos de sensores BLE dentro de flujos de trabajo centralizados de gestión de flotas.

Elija el FMM130 con Plaspy para obtener seguimiento en tiempo real confiable, gestión remota simplificada mediante FOTA WEB y una solución compacta y escalable para la gestión de flotas y la seguridad de activos. La combinación admite flujos de trabajo anti‑robo con control remoto de inmovilización, monitorización detallada de combustible para ahorros operativos y telemetría ambiental para cargas reguladas, todo gestionable desde la plataforma de Plaspy para facilitar las operaciones y una respuesta más rápida.
