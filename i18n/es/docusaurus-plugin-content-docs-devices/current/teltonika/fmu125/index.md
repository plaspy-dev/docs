# Teltonika - FMU125

![FMU125](./Logo.png)

El rastreador GPS Teltonika FMU125 es un dispositivo de seguimiento en tiempo real pequeño y profesional con conectividad GNSS y 3G / GSM, además de una batería de respaldo. Este dispositivo está equipado con módulos GNSS / Bluetooth y 3G, así como antenas 3G internas. Además, cuenta con una interfaz de datos RS485 / RS232 que permite la conexión de varios dispositivos externos de terceros. El FMU125 es perfecto para aplicaciones que requieren la adquisición de la ubicación de objetos remotos, como la gestión de flotas, empresas de alquiler de coches, empresas de taxis, transporte público, empresas de logística y coches personales, entre otros.

El rastreador GPS Teltonika FMU125 cuenta con una amplia gama de características destacadas, entre las que se incluyen:

- Sensores: Acelerómetro
- Escenarios: Conducción ecológica, detección de exceso de velocidad, contador de combustible GNSS, control de DOUT mediante llamada, detección de ralentí excesivo, inmovilizador, notificación de lectura de iButton, detección de desconexión, detección de remolque, detección de colisiones, geovalla automática, geovalla manual, viaje
- Modos de reposo: Sueño GPS, Sueño profundo en línea, Sueño profundo, Sueño ultraprofundo
- Actualización de configuración y firmware: FOTA Web, FOTA, Configurador Teltonika \(USB, Bluetooth\), aplicación móvil FMBT \(Configuración\)
- SMS: Configuración, eventos, control DOUT, depuración
- Comandos GPRS: Configuración, control DOUT, depuración
- Sincronización de tiempo: GNSS, NITZ, NTP
- Monitoreo de combustible: LLS \(analógico\), LLS digital \(RS232\), LV-CAN200, ALL-CAN300, CAN-CONTROL, OBDII dongle
- Detección de ignición: Entrada digital 1, acelerómetro, voltaje de alimentación externa, RPM del motor \(adaptadores CAN, dongle OBDII\)
- Modos RS232: Modo de registro, NMEA, LLS, LCD, RFID HID / MF7, Garmin FMI, TCP ASCII / Binary
- Modos RS485: Modo de registro, NMEA, LLS, TCP ASCII / binario
