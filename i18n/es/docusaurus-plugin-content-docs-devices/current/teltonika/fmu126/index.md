# Teltonika - FMU126

![FMU126](./Logo.png)

El FMU126 es un rastreador GPS de última generación presentado por Teltonika. Este dispositivo cuenta con cobertura de red 3G y respaldo a 2G, lo que garantiza una conexión estable y confiable en todo momento. Además, está equipado con módulos GNSS/Bluetooth y antenas internas para una mejor recepción de señal.

Teltonika ha diseñado este rastreador para cumplir con los requisitos del Departamento de Transporte Terrestre \(DLT\) y ofrecer un valor adicional a los proveedores de soluciones telemáticas GPS. El FMU126 cuenta con una interfaz RS232 que permite la conexión de lectores de tarjetas magnéticas y otros dispositivos externos de terceros. También cuenta con una salida adicional de +5V que facilita la integración con otros sistemas.

Este rastreador GPS también ofrece una serie de características destacadas, como sensores de aceleración, soporte para adaptadores CAN para capturar datos CAN de cualquier tipo de transporte, y una batería interna con una duración de más de 6 horas que recopila registros cada segundo. Además, cuenta con funciones avanzadas como detección de exceso de velocidad, detección de colisiones, geovalla automática y manual, y mucho más.

Con el FMU126 de Teltonika, los usuarios pueden disfrutar de un rastreador GPS de alta calidad y confiabilidad, diseñado para satisfacer las necesidades de seguimiento en tiempo real en una amplia gama de aplicaciones, desde flotas de vehículos comerciales hasta equipos de construcción y maquinaria pesada.

### Características destacadas:

- Cobertura de red 3G y respaldo a 2G
- Módulos GNSS/Bluetooth y antenas internas
- Interfaz RS232 para lectores de tarjetas magnéticas y dispositivos externos
- Salida adicional de +5V para facilitar la integración
- Sensores de aceleración
- Soporte para adaptadores CAN
- Batería interna con más de 6 horas de duración
- Detección de exceso de velocidad, colisiones y geovalla automática
