# Teltonika - FMU130

![FMU130](./Logo.png)

El rastreador GPS Teltonika FMU130 es un dispositivo de seguimiento en tiempo real pequeño y profesional con conectividad GNSS y 3G / GSM, además de una batería de respaldo. Este dispositivo está equipado con módulos GNSS / Bluetooth y 3G, antenas 3G, entradas y salidas digitales configurables, entradas de impulso y entradas analógicas. Es perfecto para aplicaciones que requieren la adquisición de ubicación de objetos remotos, como la gestión de flotas, empresas de alquiler de coches, empresas de taxis, transporte público, empresas de logística y coches personales.

El rastreador FMU130 cuenta con una variedad de características destacadas, entre las que se incluyen:

- Sensores de acelerómetro para detectar movimientos y cambios de velocidad.
- Escenarios de conducción ecológica, detección de exceso de velocidad, contador de combustible GNSS, control de DOUT mediante llamada, detección de ralentí excesivo, inmovilizador, notificación de lectura de iButton, detección de desconexión, detección de remolque, detección de colisiones, geovalla automática, geovalla manual y viaje.
- Modos de reposo como sueño GPS, sueño profundo en línea, sueño profundo y sueño ultraprofundo.
- Actualización de configuración y firmware a través de FOTA Web, FOTA, Configurador Teltonika \(USB, Bluetooth\) y la aplicación móvil FMBT \(Configuración\).
- Funcionalidad de SMS para configuración, eventos, control DOUT y depuración.
- Comandos GPRS para configuración, control DOUT y depuración.
- Sincronización de tiempo a través de GNSS, NITZ y NTP.
- Monitoreo de combustible compatible con LLS \(analógico\), LV-CAN200, ALL-CAN300, CAN-CONTROL y dongle OBDII.
- Detección de ignición a través de la entrada digital 1, acelerómetro, voltaje de alimentación externa y RPM del motor \(adaptadores CAN, dongle OBDII\).

Con todas estas características, el rastreador GPS Teltonika FMU130 es una opción confiable y versátil para cualquier aplicación que requiera el seguimiento y monitoreo de objetos remotos.
