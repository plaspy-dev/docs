# Teltonika - FM 2200

![FM 2200](./logo.jpg)

El rastreador GPS Teltonika FM 2200 es un terminal ligero con GPS y conectividad GSM, diseñado para adquirir la ubicación de objetos remotos de manera rápida y sencilla. Este dispositivo es perfecto para aplicaciones donde se requiere el seguimiento de objetos remotos como camiones, coches, barcos, entre otros.

El FM 2200 es capaz de realizar el monitoreo de equipos y objetos a distancia, como el motor y las puertas de los camiones, así como cualquier otra condición a través de sensores digitales. En caso de perder la conexión, el dispositivo puede almacenar hasta 15.000 registros y, una vez restablecida la conexión, enviará los datos almacenados a través de GPRS, asegurando que no se pierda ninguna información importante, como coordenadas y datos de sensores.

Características destacadas del rastreador GPS Teltonika FM 2200:

- Terminal ligero con GPS y conectividad GSM
- Adquisición rápida y sencilla de la ubicación de objetos remotos
- Monitoreo remoto de equipos y objetos
- Almacenamiento de hasta 15.000 registros en caso de pérdida de conexión
- Envío de datos almacenados a través de GPRS
