# Teltonika - FMB150

![FMB150](./logo..png)

El rastreador GPS Teltonika FMB150 es un avanzado rastreador GPS 2G con un procesador de datos CAN integrado. Este dispositivo es capaz de leer datos CAN de vehículos ligeros y eléctricos, camiones, autobuses y maquinaria especializada. Además, cuenta con una conexión inalámbrica Bluetooth® LE para la conexión de dispositivos externos, como sensores de temperatura, humedad, detección de imanes y movimiento.

Una de las características destacadas del FMB150 es su capacidad para leer datos CAN de vehículos eléctricos, lo que amplía aún más los escenarios de uso del dispositivo. Con más de 40 vehículos eléctricos compatibles en el mercado, este rastreador GPS brinda un valor adicional a los propietarios de vehículos eléctricos.

El FMB150 cuenta con una amplia gama de especificaciones técnicas que garantizan un rendimiento confiable. Con tecnología GSM/GPRS/GNSS/BLUETOOTH, el rastreador GPS es compatible con GPS, GLONASS, GALILEO, BEIDOU, SBAS, QZSS, DGPS y AGPS. Además, tiene una sensibilidad de seguimiento de -165 dBM y una precisión de posición de menos de 2.5 metros CEP.

El rastreador GPS Teltonika FMB150 también cuenta con una serie de interfaces y características adicionales, como entradas y salidas digitales, entradas de impulso, entradas analógicas, interfaces CAN, 1-Wire, antena GNSS interna de alta ganancia, antena celular interna de alta ganancia, puerto USB 2.0 Micro-USB, indicación LED, memoria interna de 128 MB y más.

En resumen, el rastreador GPS Teltonika FMB150 es una solución avanzada y versátil para el seguimiento y monitoreo de vehículos. Con su capacidad para leer datos CAN, conexión Bluetooth® LE y una amplia gama de características técnicas, este dispositivo es ideal para una variedad de aplicaciones, desde el seguimiento de flotas hasta el monitoreo de vehículos eléctricos.

### Características destacadas:

- Rastreador GPS 2G avanzado con procesador de datos CAN integrado
- Lectura de datos CAN de vehículos ligeros y eléctricos, camiones, autobuses y maquinaria especializada
- Conexión inalámbrica Bluetooth® LE para dispositivos externos
- Lectura de datos CAN de vehículos eléctricos \(más de 40 vehículos compatibles\)
- Tecnología GSM/GPRS/GNSS/BLUETOOTH compatible con múltiples bandas 2G
- Antena GNSS interna de alta ganancia y antena celular interna de alta ganancia
- Interfaces y características adicionales, como entradas y salidas digitales, entradas de impulso, entradas analógicas, interfaces CAN, 1-Wire, puerto USB 2.0 Micro-USB, indicación LED y memoria interna de 128 MB
