# Teltonika - FMB150

![FMB150](./logo..png)

El Teltonika FMB150 es un avanzado rastreador GPS 2G con un procesador de datos CAN integrado, diseñado para leer información del bus CAN en vehículos ligeros y eléctricos, camiones, autobuses y maquinaria especial. Combina posicionamiento GNSS multiconstelación con un módulo de comunicaciones TM2500 y capacidad Bluetooth LE, lo que permite mezclar el rastreo de ubicación con la recopilación de datos a bordo, útil para la gestión de flotas y diagnósticos.

Como dispositivo compatible con Plaspy, el FMB150 puede enviar ubicación, datos CAN del vehículo y entradas de sensores externos a la plataforma Plaspy para una visibilidad consolidada de la flota. Su soporte para lectura CAN de vehículos eléctricos y la conexión con balizas y sensores Bluetooth LE lo hacen práctico cuando los usuarios de Plaspy necesitan tanto seguimiento posicional como telemetría adicional del vehículo o activo en un solo equipo.

## Aspectos clave

- Procesador de datos CAN integrado para lectura de información del vehículo y soporte para flujos básicos de diagnóstico.
- Soporte Bluetooth LE para conectar balizas externas y sensores de bajo consumo y así ampliar las capacidades de monitoreo.
- Receptor GNSS multiconstelación de alta sensibilidad para mejorar la precisión de ubicación.
- Diseñado para una amplia gama de vehículos, incluidos vehículos ligeros, camiones, autobuses y vehículos eléctricos.
- Rango operativo robusto y protección contra ingreso adecuados para entornos vehiculares exigentes.
- Múltiples interfaces de entrada y salida para una integración flexible con sistemas del vehículo y dispositivos externos.

## Cómo funciona con Plaspy

El FMB150 transmite datos de ubicación y del vehículo que Plaspy puede recopilar y presentar junto con otra información de la flota, permitiendo monitoreo y reportes unificados. Plaspy puede ingerir el flujo de datos del dispositivo para ofrecer visión operativa, alertas y análisis históricos para las flotas que usan este rastreador.

- Visibilidad de la ubicación del vehículo en tiempo real y seguimiento en mapas dentro de Plaspy.
- Información sobre el estado y operación del vehículo derivada de los datos CAN, presentada en paneles y reportes.
- Entradas de sensores conectados por Bluetooth LE, como balizas de temperatura o movimiento, visibles en Plaspy para un monitoreo extendido de activos.
- Alertas y notificaciones para eventos como encendido, movimiento o umbrales personalizados configurables en Plaspy.
- Registros históricos de viajes y reportes para análisis de recorridos, utilización y revisión de cumplimiento.
- Supervisión operativa centralizada para flotas mixtas, incluyendo vehículos de combustión y eléctricos.

## Casos de uso típicos

- Rastreo y gestión operativa de flotas para vehículos ligeros y pesados.
- Monitoreo de vehículos eléctricos con recopilación de datos CAN para parámetros específicos de EV.
- Supervisión de autobuses, camiones y maquinaria especial donde se requiere datos del vehículo y ubicación.
- Monitoreo de condiciones de activos mediante sensores Bluetooth LE para medir temperatura, humedad o detectar movimiento.
- Detección de seguridad y movimiento para activos gestionados y apoyo a flujos de despacho.

## Por qué elegir este rastreador con Plaspy

El FMB150 combina la recopilación de datos CAN del vehículo, posicionamiento GNSS multiconstelación y la extensibilidad Bluetooth LE para ofrecer un conjunto equilibrado de funciones para organizaciones que requieren tanto ubicación como información a nivel vehicular. Para flotas que incluyen vehículos eléctricos o que necesitan entradas de sensores adicionales, el FMB150 proporciona un único dispositivo capaz de ampliar la telemetría más allá del GPS básico.

Al integrarlo con Plaspy, esta compatibilidad permite a los operadores consolidar ubicación, diagnóstico del vehículo y datos de sensores en una única vista de gestión de flotas. Esto facilita monitorear la salud operativa, simplificar reportes y responder a eventos desde una plataforma unificada, además de permitir que los clientes elijan las características del dispositivo que se ajusten a sus necesidades operativas.
