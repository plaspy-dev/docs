# Teltonika - FMM003

![FMM003](./logo..png)

El rastreador GPS Teltonika FMM003 es un dispositivo 4G LTE Cat M1 con capacidad de lectura de datos OBD OEM, lo que lo convierte en una opción confiable para la gestión de flotas a nivel global. Su conectividad LTE Cat M1 y NB IoT, con respaldo a 2G, garantiza una cobertura amplia para satisfacer todas sus necesidades de gestión de flotas.

Una de las características destacadas del FMM003 es su capacidad para leer parámetros OBD OEM, lo que le permite obtener datos precisos sobre el odómetro y el nivel de combustible en tiempo real. Además, este rastreador GPS es compatible con una amplia lista de vehículos y datos, lo que le brinda una visión completa de su flota y su rendimiento.

La instalación del FMM003 es muy sencilla, ya que solo necesita conectar el dispositivo en el puerto OBD-II y comenzar a rastrear. Además, cuenta con una batería de respaldo interna y protección contra sobretensión y polaridad inversa.

El rastreador GPS Teltonika FMM003 también ofrece una serie de características adicionales, como conectividad Bluetooth 4.0, soporte para sensores de temperatura y humedad, interfaz OBD para la lectura de datos de hasta 32 parámetros del vehículo, y una memoria interna de 128MB.

En cuanto a las especificaciones técnicas, el FMM003 utiliza la tecnología LTE Cat M1/NB-IoT/GSM/GPRS/GNSS/BLUETOOTH, cuenta con un receptor GNSS de 33 canales y una precisión de posición de menos de 2.5 metros CEP. También es compatible con las bandas 2G y 4G LTE Cat M1, y tiene un consumo de energía bajo en diferentes modos de sueño.

En resumen, el rastreador GPS Teltonika FMM003 es una opción confiable y versátil para la gestión de flotas, con amplia cobertura global, capacidad de lectura de datos OBD OEM y una serie de características adicionales que lo hacen ideal para cualquier empresa que busque mejorar la eficiencia y seguridad de su flota de vehículos.
