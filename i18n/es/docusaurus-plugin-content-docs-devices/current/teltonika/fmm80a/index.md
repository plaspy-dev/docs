# Teltonika - FMM80A

![FMM80A](./tracker.png)

El Teltonika FMM80A es un rastreador GPS OBD‑II plug‑and‑play diseñado para un despliegue rápido y telemática confiable. Compatible con Plaspy desde el inicio, el FMM80A ofrece seguimiento en tiempo real y datos de gestión de flotas con un mínimo esfuerzo de instalación — basta con conectar el puerto OBD‑II del vehículo para iniciar la telemetría y el monitoreo de posición para aplicaciones de flota, alquiler o entrega.

El dispositivo combina conectividad celular LTE Cat M1 / NB‑IoT con capacidad de respaldo 2G, soporte Bluetooth Low Energy para balizas y sensores externos, y un acelerómetro de 3 ejes configurable para detección de colisiones y captura de trazas. Este modelo FMM80A está optimizado para el mercado de América del Norte e integra con las herramientas de gestión remota de Teltonika para actualizaciones de firmware y configuración sencillas, lo que lo convierte en una opción eficiente para soluciones de rastreo escalables compatibles con Plaspy.

## Aspectos clave

- Rastreador GPS OBD‑II plug‑and‑play compatible con Plaspy para un despliegue rápido y un seguimiento en tiempo real inmediato.
- Conectividad celular LTE Cat M1 / NB‑IoT con respaldo 2G para una cobertura amplia en América del Norte y telemetría de bajo consumo.
- BLE integrado \(Bluetooth® Low Energy\) para emparejarse con balizas y sensores externos \(temperatura, humedad, imán, movimiento\) para monitoreo de condiciones.
- Acelerómetro configurable de 3 ejes que ofrece detección de colisiones y trazas detalladas para análisis post-evento.
- Diseñado para gestión de flotas, alquiler/compartición de coches, logística de entrega y programas de instalación rápida.
- Se integra con el ecosistema de gestión remota de Teltonika \(FOTA, Configurador, Base de Conocimiento\) para un control centralizado de los dispositivos.
- Soporte de bandas para América del Norte y variantes de empaque para atender las necesidades de distribución y despliegue de una sola unidad.

## Cómo funciona con Plaspy

Cuando se empareja con Plaspy, el FMM80A transmite datos de ubicación y telemetría a la plataforma, habilitando mapas en tiempo real, alertas e informes históricos. La conexión OBD‑II plug‑and‑play suministra datos del vehículo y energía, mientras que los sensores BLE amplían la telemetría para monitoreo de temperatura, humedad y movimiento. Los usuarios de Plaspy pueden combinar estas entradas para construir tableros, activar alertas anti‑robo y realizar análisis a nivel de flota.

- Actualizaciones de ubicación GPS y telemetría en tiempo real enviadas a Plaspy para seguimiento en vivo y monitoreo de rutas.
- Los eventos de detección de colisiones y las trazas del acelerómetro se transmiten para revisión de incidentes y generación de informes.
- Los datos de sensores BLE \(temperatura, humedad, imán y movimiento\) se integran en Plaspy para monitoreo de condiciones y alertas.
- El acceso telemático OBD‑II permite parámetros del vehículo \(telemetría relacionada con combustible/consumo y estado de encendido\) cuando estén disponibles desde el sistema CAN/OBD del vehículo.
- Actualizaciones de firmware y configuración remotas a través de las herramientas de gestión de Teltonika, habilitando la administración centralizada de dispositivos para implementaciones de Plaspy.

## Casos de uso

- Gestión de flotas: seguimiento en tiempo real, reproducción de rutas y telemetría para flotas urbanas y regionales mediante los paneles de Plaspy.
- Alquiler y car‑sharing: instalación rápida de OBD‑II, monitoreo de uso y registro de colisiones/incidentes para vehículos de corta duración.
- Distribución y logística: ubicación en vivo, telemetría y monitoreo de condiciones con sensores BLE para proteger carga sensible a la temperatura.
- Antirrobo y recuperación: actualizaciones de ubicación inmediatas, alertas de movimiento y eventos perimetrales activados por BLE para reducir el riesgo de robo.
- Monitoreo de activos y condiciones: empareje sensores BLE de temperatura o humedad para rastrear condiciones ambientales en envíos sensibles.

## Por qué elegir este rastreador con Plaspy

El FMM80A ofrece un equilibrio práctico entre rapidez de despliegue, seguimiento en tiempo real confiable y flexibilidad de sensores — todo ello esencial para una gestión de flotas escalable en Plaspy. Su formato OBD‑II plug‑and‑play minimiza costos de instalación y tiempos de inactividad, mientras que la conectividad LTE Cat M1 / NB‑IoT garantiza telemetría eficiente en América del Norte con respaldo 2G. La integración de sensores BLE permite ampliar la telemetría \(temperatura, humedad, movimiento\) sin cableado adicional, y el acelerómetro configurable proporciona trazas de colisiones significativas para el análisis de incidentes.

Combinado con la gestión remota de Teltonika y las capacidades de la plataforma de Plaspy, el FMM80A admite implementaciones rápidas, control centralizado de firmware e informes integrados. Ya sea que necesite seguimiento GPS en tiempo real, telemetría de combustible o estado de ignición cuando esté disponible, o monitoreo de condiciones habilitado por BLE, este rastreador compatible con Plaspy está preparado para ofrecer un seguimiento confiable, escalable y monitoreo anti‑robo para flotas comerciales y operaciones de alquiler.
