# Teltonika - FMM640

![FMM640](./Logo.png)

El rastreador GPS Teltonika FMM640 es un dispositivo profesional de seguimiento global con conectividad LTE CAT M1, NB IoT, lo que lo hace compatible con las tecnologías más nuevas y rentables. Este rastreador ofrece una amplia gama de características, como datos FMS CAN \(J1939\), datos CAN de combustible \(J1708\), datos en vivo del tacógrafo \(K-line\), descarga remota de archivos de tacógrafo y compatibilidad con dispositivos RS232 o RS485 de terceros. Además, cuenta con Dual-SIM para maximizar la eficiencia de su flota.

El rastreador Teltonika FMM640 es adecuado para una variedad de aplicaciones, como logística internacional, transporte refrigerado, agricultura, construcción, minería, seguridad y servicios de emergencia, entre otros. Su diseño robusto y resistente garantiza un rendimiento confiable incluso en entornos exigentes.

Algunas de las características destacadas del Teltonika FMM640 incluyen detección de movimiento, acelerómetro, conducción ecológica, detección de exceso de velocidad, detección de ralentí excesivo, detección de remolque, detección de colisión, inmovilizador, geofencing automático y manual, odómetro, contador de combustible, seguimiento fuera de línea y compatibilidad con una amplia gama de periféricos.

Con el rastreador Teltonika FMM640, podrá tener un control total sobre su flota y optimizar la eficiencia de sus operaciones. Este dispositivo confiable y de alto rendimiento es una excelente opción para cualquier empresa que busque mejorar la gestión de su flota y garantizar la seguridad de sus activos.
