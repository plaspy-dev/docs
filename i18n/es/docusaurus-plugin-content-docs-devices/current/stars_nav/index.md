# Stars Nav

Stars Nav fabrica una variedad de dispositivos de rastreo GPS para el monitoreo de vehículos y activos. Muchos modelos de Stars Nav son compatibles con Plaspy, lo que permite centralizar el seguimiento, las alertas y los informes en la plataforma. Esta página describe cómo el hardware de Stars Nav puede integrarse con Plaspy, las capacidades típicas que puede esperar y cómo elegir el modelo adecuado para sus necesidades.

<BrandCatalog brand={brand} />

## Cómo funcionan los dispositivos Stars Nav con Plaspy

Los rastreadores Stars Nav suelen enviar datos de ubicación y estado a través de redes celulares hacia un servidor. Plaspy recibe esa telemetría, la normaliza y la pone a disposición mediante paneles, mapas, informes y reglas de alerta. La integración normalmente incluye:

- Entrega segura de posición GPS, velocidad y estado básico del dispositivo a Plaspy
- Opciones de configuración para intervalos de envío y reporte de movimiento, gestionadas en el dispositivo o desde Plaspy cuando el modelo lo soporta
- Uso de las herramientas de Plaspy para visualizar ubicación en tiempo real, reproducir recorridos históricos y generar informes periódicos

Dado que el firmware y el conjunto de funciones varían según el modelo, Plaspy procesa los datos entrantes de forma agnóstica al modelo y aplica las funciones de la plataforma de manera consistente a los dispositivos Stars Nav que se conectan a Plaspy.

## Funciones comunes en los dispositivos Stars Nav

Aunque las capacidades exactas dependen del modelo, el hardware GPS de Stars Nav suele incluir funciones útiles para el rastreo de flotas y activos:

- Ubicación en tiempo real y detección de movimiento
- Conectividad de datos celulares para reportes continuos
- Detección de encendido y entradas digitales para seguimiento del estado del vehículo
- Nivel de batería y alertas por manipulación o desconexión de energía
- Intervalos de reporte configurables para estados en reposo y en movimiento
- Compatibilidad con protocolos de rastreo estándar usados por plataformas de terceros

Estas capacidades permiten a Plaspy ofrecer información de ubicación y operativa relevante sin requerir configuraciones específicas por dispositivo en cada ocasión.

## Casos de uso típicos para rastreadores Stars Nav

Los dispositivos Stars Nav se implementan en muchos escenarios prácticos, entre ellos:

- Rastreo de vehículos de flota para enrutamiento, despacho y supervisión de conductores
- Localización de equipos y activos en construcción o servicios de campo
- Prevención y recuperación ante robos mediante alertas de manipulación y movimiento
- Control de kilometraje y uso para apoyar la planificación de mantenimiento
- Monitoreo remoto de remolques, generadores y activos sin alimentación cuando se usan con una fuente de energía externa o paquete de baterías

Plaspy transforma la telemetría del dispositivo en flujos de trabajo accionables para estos casos operativos.

## Por qué elegir Plaspy para monitorear dispositivos Stars Nav

Plaspy ofrece una plataforma única para gestionar y monitorear dispositivos Stars Nav junto con otros equipos en flotas mixtas. Ventajas clave:

- Paneles unificados para ver dispositivos Stars Nav y de otras marcas en una sola cuenta
- Reproducción de viajes históricos y reportes configurables para cumplimiento y análisis
- Reglas de alerta flexibles para geocercas, exceso de velocidad y eventos del dispositivo
- Gestión escalable de dispositivos para flotas de cualquier tamaño
- Manejo seguro de datos y acceso por roles para equipos

Plaspy está diseñado para que los datos de los rastreadores Stars Nav sean fáciles de usar, reduciendo el tiempo entre la puesta en marcha del dispositivo y el valor operativo.

## Ayuda para elegir el dispositivo Stars Nav adecuado

El catálogo arriba muestra los modelos de Stars Nav conocidos por ser compatibles con Plaspy. Para elegir un dispositivo:

- Comience por el caso de uso principal, por ejemplo rastreo de vehículos, monitoreo de remolques o etiquetado de activos
- Verifique las opciones de alimentación y montaje para que coincidan con las necesidades de instalación
- Considere las entradas requeridas, como detección de encendido o sensores adicionales
- Revise la compatibilidad de bandas celulares y la adecuación regional con su operador

Si necesita orientación, la documentación y el soporte de Plaspy pueden ayudarle a identificar qué modelos Stars Nav se ajustan mejor a su implementación y objetivos de integración.
