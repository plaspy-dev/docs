# iStartek - PT60

![PT60](./logo..jpg)

El rastreador GPS PT60-L de istartek es un dispositivo inalámbrico de seguimiento GPS 4G sin instalación. Está diseñado especialmente para aplicaciones de pan-IoT, incluyendo la localización de vehículos, activos y escenarios de aplicación sin supervisión. Cuenta con un GPS de alta sensibilidad incorporado y una antena de comunicación 4G para una rápida velocidad de posicionamiento. Es recargable y tiene imanes fuertes incorporados para una fácil instalación. El rastreador GPS PT60-L tiene una batería de 7500mAh de alta capacidad que permite un suministro de energía suficiente, lo que le permite tener un tiempo de espera de hasta 3650 días. Es adecuado para camiones, remolques, contenedores, equipaje y personas.

Características destacadas:

- 4G LTE CAT1/CATM, compatibilidad total de red. Múltiples sistemas de posicionamiento garantizan una ubicación precisa en tiempo real.
- Batería recargable de 7500mAh, tiempo de espera ultra largo de hasta 3650 días, compatible con el modo de despertador programado y el modo de reloj despertador.
- Funciona durante 10 años, se puede utilizar durante 10 años enviando una pieza de datos al día en el modo de trabajo de espera ultra largo.
- Alarma de manipulación mediante sensor de luz para evitar el desmontaje. Cubierta magnética fuerte que permite una instalación flexible y fácil.

Otras características incluyen un monitor de comportamiento de conducción, memoria flash de 16Mb para almacenar ubicaciones, 5 modos de trabajo diferentes, actualización rápida y fácil del firmware a través de FOTA, y la capacidad de configurar dos servidores para enviar datos simultáneamente.
