# SkyPatrol - SP3400C

![SP3400C](./logo.jpg)

El SkyPatrol SP3400C es un dispositivo de rastreo GPS CDMA diseñado para cumplir con todas las certificaciones de operadores y países. Construido para resistir las duras condiciones asociadas con la telemática de vehículos, este dispositivo de última generación es adecuado para una amplia gama de aplicaciones de localización de vehículos, incluyendo necesidades automotrices subprime, flotas y telemática de consumo.

El SP3400C cuenta con los últimos diseños de antenas celulares, optimizadas para operar en entornos urbanos y rurales desafiantes. Está equipado con el último diseño de firmware, lo que permite actualizaciones y configuraciones a través del aire. Con dos circuitos de E/S discretos, el SP3400C proporciona un control total sobre un vehículo, incluyendo el encendido automático inalámbrico y los disparadores de relé para habilitar o deshabilitar componentes automotrices.

Características destacadas:

- CDMA 1xRTT de doble banda 800/1900 MHz
- Acelerómetro de 3 ejes incorporado
- Actualización de firmware y configuración a través del aire
- Antenas celulares y GPS integradas
- Excelente seguimiento GPS y sensibilidad de adquisición
- Motor GPS de alta precisión integrado
- Soporta UDP y SMS para comunicaciones de datos
- Apilamiento TCP e IP integrado
- 2 salidas digitales, 1 entrada analógica y 1 entrada de encendido
