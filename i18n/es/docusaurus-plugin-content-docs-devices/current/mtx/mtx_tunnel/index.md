# Mtx - MTX Tunnel

![MTX Tunnel](./logo.jpg)

El MTX Tunnel GPS de la marca Mtx es un dispositivo diseñado para ser integrado en sistemas de control de flotas basados en localización GPS y comunicaciones GPRS. Una vez instalado en un vehículo, este rastreador tomará posiciones GPS y las enviará periódicamente hacia un servidor TCP/IP o webserver Http Get a través de comunicaciones GPRS.

Pero el MTX Tunnel GPS no se limita solo a eso. El software MTX Tunnel GPS v2 ha heredado muchas de las características del conocido MTX Tunnel v5, y también cuenta con una pasarela GPRS-RS232, Telnet, comandos AT por SMS y envío de telemetrías, entre otras funciones.

Algunas de las características principales del MTX Tunnel GPS incluyen:

- Envío periódico de posiciones GPS mediante comunicación GPRS hacia un servidor vía socket TCP/IP o webserver.
- Pasarela transparente GPRS-RS232 en modo TCP Server.
- Telnet para configuración remota del equipo y lectura de estados.
- Control total por SMS.
- Función de keep alive.
- Localización por celdas GSM en caso de no cobertura GPS.
- Envío de telemetrías, incluyendo entradas digitales.
- Modo de bajo consumo.
- Firewall para evitar accesos no autorizados.
- Túneles GPRS-I2C/SPI y SMS-RS232.
- Seguridad SSL.
- API para integración con aplicaciones de terceros.

Con todas estas características, el MTX Tunnel GPS es una opción confiable y versátil para sistemas de control de flotas que requieren una localización precisa y una comunicación segura.
