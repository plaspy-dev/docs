# Coban - GPS-109

![GPS-109](./logo..png)

El rastreador GPS Coban GPS-109 funciona en base a la red GSM/GPRS \(850/900/1800/1900MHZ\) y satélites GPS, lo que le permite localizar y monitorear cualquier objetivo remoto a través de SMS, computadora o PDA. Con dimensiones de 85×65×27mm y un peso de 188g, este dispositivo es compacto y fácil de transportar.

Este rastreador GPS cuenta con una precisión de GPS de 5m y una sensibilidad de GPS de -165dBm, lo que garantiza una ubicación precisa y confiable. Además, tiene una batería recargable de 3.7V 5000mAh Li-ion que proporciona una larga duración de la batería.

Entre las funciones destacadas de este rastreador GPS se encuentran la posibilidad de agregar y eliminar números de teléfono autorizados, la localización individual, el seguimiento automático continuo, la obtención de la dirección exacta de la calle, la consulta del saldo de la tarjeta SIM, la configuración de la cantidad de mensajes de alarma, la alarma de batería baja, la geovalla, la alarma de movimiento, la alarma de exceso de velocidad, la alarma de sensor de impacto, el modo de suspensión y la verificación del estado.

Con un nivel de impermeabilidad IP67, este rastreador GPS es resistente al agua y puede soportar condiciones climáticas adversas. Es ideal para su uso en vehículos, motocicletas, bicicletas, equipos de construcción, entre otros.

### Características destacadas:

- Red GSM/GPRS \(850/900/1800/1900MHZ\)
- Precisión de GPS de 5m
- Sensibilidad de GPS de -165dBm
- Batería recargable de 3.7V 5000mAh Li-ion
- Funciones de alarma de batería baja, geovalla, movimiento, exceso de velocidad y sensor de impacto
- Modo de suspensión para ahorrar energía
- Impermeabilidad IP67
