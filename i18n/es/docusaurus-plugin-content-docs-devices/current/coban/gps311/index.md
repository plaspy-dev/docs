# Coban - GPS311

![GPS311](./Logo.png)

El rastreador GPS Coban GPS311 es un dispositivo versátil que combina múltiples funciones de posicionamiento preciso, seguridad, vigilancia y monitoreo. Es especialmente adecuado para su uso en vehículos, brindando una solución integral para el seguimiento y la seguridad de su automóvil.

Este rastreador GPS es compatible con las funciones de transmisión de datos SMS / GPRS / Internet, lo que le permite utilizarlo en una amplia gama de aplicaciones, como supervisión a gran escala, programación de emergencias, servicios basados en la ubicación y seguridad del tráfico, entre otros.

El Coban GPS311 se basa en la tecnología de telecomunicaciones inalámbricas GSM / GPRS \(850/900/1800/1900 MHz\) y el sistema de posicionamiento global GPS. Ofrece múltiples formas de seguimiento y proporciona software de monitoreo y mapas globales. Puede realizar un seguimiento en tiempo real a través del software de monitoreo en su PC, así como a través de su teléfono celular, PDA y Google Earth.

Este rastreador GPS tiene un tamaño compacto de 60x36x18 mm y cuenta con una batería de 3.7 V 180 mAh. Además, acepta un amplio voltaje de 8 V a 40 V, lo que le permite funcionar con automóviles, bicicletas eléctricas, motocicletas y otros vehículos.
