# Coban - GPS103

![GPS103](./logo.jpg)

El localizador GPS modelo TK 103A de Coban es un dispositivo que utiliza la red GPRS GSM y el sistema de posicionamiento por satélite GPS para ofrecer múltiples funciones de seguridad, posicionamiento, control de vigilancia, alarmas de emergencia y seguimiento en su totalidad.

Este rastreador GPS ofrece varias formas de seguimiento. Puede llamar al dispositivo desde su teléfono móvil y recibirá un SMS con la longitud y latitud, así como un enlace de Google Maps para ver la ubicación en tiempo real. También puede realizar un seguimiento a través de una aplicación para iOS y Android, o utilizar el software CD en su PC. Además, cuenta con un sistema de seguimiento en línea basado en el servidor de Coban.

Entre las funciones destacadas de este localizador GPS se encuentran:

- Posicionamiento y seguimiento en tiempo real
- Obtención de la ubicación en calle real o nombre de dirección
- Control remoto del vehículo en caso de robo
- Función de seguimiento por tiempo y frecuencia
- Autorización de números de teléfono para acceder al dispositivo
- Geo-cerca para restringir los movimientos del vehículo
- Alarma de puerta/encendido y alarma de movimiento
- Alarma de velocidad excesiva y desconexión de alimentación
- Comprobación del estado del vehículo
- Configuración de alarmas y funciones remotas
- Menor consumo de tráfico GPRS
- Actualización automática de posiciones del vehículo
- Alarma de ángulo muerto

El localizador GPS modelo TK 103A de Coban es una opción confiable y versátil para aquellos que buscan un dispositivo de seguimiento y seguridad para sus vehículos.
