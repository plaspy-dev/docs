# WanWay - GS21

![GS21](./Logo.jpg)

El rastreador GPS OBD WanWay GS21 es un dispositivo de posicionamiento diseñado especialmente para vehículos. Con funciones como cerca electrónica, seguimiento remoto y diagnóstico de vehículos, este terminal puede satisfacer las necesidades de escenarios relacionados, como el monitoreo de automóviles, servicio de llamada y alquiler de vehículos en línea.

Con un tamaño compacto de 47x20x43 mm, el GS21 es fácil de instalar y reparar. Además, cuenta con una batería recargable incorporada de 60 mAh que permite enviar datos de posicionamiento a la plataforma de forma continua incluso después de apagar el dispositivo. También ofrece una función de alarma de desmontaje en caso de que el dispositivo sea desmantelado.

El rastreador GPS OBD WanWay GS21 cuenta con las siguientes características destacadas:

- Seguimiento inteligente de vehículos
- Dimensiones del dispositivo: 47 mm \(largo\) x 20 mm \(ancho\) x 43 mm \(alto\)
- Peso del dispositivo: 41g
- Cuatribanda: 850/1900/900/1800MHz
- Precisión del GPS: \<=5m
- Entrada de voltaje: 9-35v
- Batería de respaldo: 60mAh
- Inicio en caliente \<5S \(cielo abierto\)
- Tiempo de posicionamiento: Arranque en caliente \<15S, Arranque en frío \<30s \(cielo abierto\)
- Sensibilidad GPS: -144dBm
- Sensibilidad de seguimiento: -162dBm
- Temperatura de funcionamiento: -20℃ - 70℃
- Chip GPS: MTK
- Antena GSM/GPS: Diseño incorporado

El rastreador GPS OBD WanWay GS21 ofrece una amplia gama de funciones, incluyendo seguimiento en tiempo real, diagnóstico de mal funcionamiento, reproducción de seguimiento, geocerca definida por el usuario, batería incorporada y protecciones de alertas múltiples. Con todas estas características, el GS21 es una opción confiable para el monitoreo y seguimiento de vehículos.
