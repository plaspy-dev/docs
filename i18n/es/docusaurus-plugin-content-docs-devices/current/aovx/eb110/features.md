# AOVX - EB110 Features

Esta página presenta el contexto público de funciones para usar el AOVX EB110 con Plaspy. El EB110 es una etiqueta ambiental compatible con Plaspy, diseñada para monitoreo de bajo consumo y larga duración en envíos, bodegas e inventario sensible. Agrega visibilidad basada en sensores a los flujos de rastreo al reportar datos de condición que pueden complementar las implementaciones de rastreadores GPS dentro de Plaspy.

La disponibilidad de funciones puede variar según el firmware, la revisión de hardware, el tipo de instalación y la implementación del fabricante. Por esa razón, las funciones del AOVX EB110 y las capacidades del AOVX EB110 descritas aquí deben entenderse como una guía pública y práctica, no como una especificación completa. Se recomienda revisar la documentación oficial del fabricante para conocer los detalles más recientes específicos del dispositivo.

## Resumen de funciones

El AOVX EB110 se entiende mejor como una etiqueta ambiental BLE compacta que ofrece logística con conocimiento de la condición, en lugar de rastreo GNSS independiente. En Plaspy, resulta útil cuando el objetivo es monitorear la exposición ambiental, el movimiento y el contexto de manipulación junto con la visibilidad de flotas o activos.

- Conectividad Bluetooth 5.0 para reportes de corto alcance hacia gateways, dispositivos móviles o recolectores locales
- Monitoreo de temperatura y humedad para tener visibilidad de las condiciones de almacenamiento y envío
- Detección de nivel de luz para ayudar a identificar eventos de exposición
- Sensor de movimiento para aportar contexto de tránsito, manipulación y posibles intentos de alteración
- Diseño de bajo consumo pensado para implementaciones de larga duración
- Formato compacto para colocación discreta en paquetes, tarimas e inventario

## Funciones principales del AOVX - EB110

- Etiqueta ambiental BLE compatible con Plaspy para monitoreo centrado en la condición
- Comunicación Bluetooth Low Energy 5.0 para reportes basados en gateway
- Telemetría continua de temperatura para visibilidad de cadena de frío y almacenamiento
- Telemetría de humedad para seguimiento de la estabilidad ambiental
- Sensor de luz para resaltar exposición o cambios en las condiciones de almacenamiento
- Sensor de movimiento para agregar contexto de actividad y manipulación
- Operación de larga duración y bajo consumo, adecuada para despliegues a gran escala
- Tamaño compacto para uso en envíos, tarimas e inventario sensible

## Cómo funcionan estas funciones con Plaspy

En Plaspy, el EB110 puede aportar datos de sensores que mejoran la conciencia operativa más allá del simple rastreo de ubicación. Cuando gateways BLE o recolectores compatibles envían la información del dispositivo, Plaspy puede usar esos datos para respaldar paneles, flujos de monitoreo y visibilidad de eventos en activos en tránsito o en almacenamiento.

- La telemetría ambiental puede mostrarse en Plaspy para facilitar el monitoreo de condiciones
- Los datos de temperatura y humedad ayudan a dar seguimiento a la cadena de frío y a revisar condiciones de almacenamiento
- Los eventos de luz y movimiento pueden aportar contexto sobre manipulación, tránsito o situaciones de exposición
- Los datos de sensores pueden correlacionarse con la información de rastreadores GPS en Plaspy para tener una visión más completa de la situación
- La operación BLE de larga duración permite un monitoreo escalable de muchos activos con menos esfuerzo de mantenimiento

## Casos de uso habituales

- Monitoreo de cadena de frío para productos farmacéuticos, alimentos y otros bienes sensibles
- Visibilidad en bodegas para inventario sensible a la temperatura y la humedad
- Monitoreo de envíos donde importa el contexto de exposición o manipulación
- Monitoreo de condición de activos para equipos empacados o materiales de alto valor
- Flujos logísticos que necesitan ubicación GPS y telemetría ambiental al mismo tiempo
- Detección de alteraciones en bienes que deben permanecer sellados o sin intervención

- El método de instalación y la ubicación pueden afectar la calidad del reporte BLE y la cobertura práctica

## Por qué usar Plaspy con estas funciones

Plaspy hace que el AOVX EB110 sea más útil cuando una organización necesita tanto contexto ambiental como visibilidad operativa. En lugar de depender solo de la ubicación, los equipos pueden usar telemetría basada en sensores para saber si un envío, un artículo almacenado o un activo empacado sigue dentro de las condiciones aceptables. Eso convierte al EB110 en una opción práctica para flujos de monitoreo donde la calidad, la manipulación y la continuidad son importantes.
