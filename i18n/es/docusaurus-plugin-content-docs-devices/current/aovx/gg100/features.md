# AOVX - GG100 Features

Esta página cubre el contexto público de funciones del AOVX GG100 para su uso con Plaspy. Su objetivo es ayudarle a entender para qué fue diseñado el rastreador, cómo sus principales capacidades pueden apoyar la logística y la visibilidad de activos, y cómo Plaspy puede usarse para monitorear el dispositivo en una configuración operativa práctica.

El GG100 se describe como un rastreador GPS ultradelgado para mercancías, pensado para una implementación sin instalación en operaciones de logística y cadena de suministro. Su conjunto público de funciones destaca el posicionamiento multimodo, el monitoreo ambiental, Bluetooth 5.0 y las alertas por manipulación o apertura, lo que lo hace adecuado para envíos, pallets, cajas, contenedores y otros activos móviles.

## Resumen de funciones

El AOVX GG100 está enfocado en el rastreo práctico de mercancías más que en la telemática vehicular compleja. Sus capacidades públicas se centran en la visibilidad de ubicación, el monitoreo ambiental y la implementación sencilla para casos de uso con activos a gran escala. Esto lo vuelve especialmente relevante para organizaciones que necesitan un rastreador compacto que pueda colocarse rápidamente y supervisarse mediante Plaspy.

- Posicionamiento multimodo con GPS, BeiDou, posicionamiento por estaciones base y asistencia por Wi-Fi
- Diseñado para uso sin instalación en mercancías, pallets, cajas y contenedores
- Detección de temperatura y humedad para monitoreo ambiental
- Compatibilidad con Bluetooth 5.0 para uso con sensores cercanos y balizas
- Función de alarma por manipulación y apertura con luz indicadora
- Larga autonomía en espera para tránsito prolongado y monitoreo de activos

## Funciones principales del AOVX - GG100

El conjunto de funciones del AOVX GG100 está orientado al rastreo sencillo de activos logísticos y flujos de envío.

- Formato ultradelgado diseñado para colocarse fácilmente sobre mercancías y paquetes
- Uso sin instalación para una implementación rápida en grandes volúmenes de activos
- Posicionamiento GPS y BeiDou para visibilidad de ubicación en exteriores
- Posicionamiento por estaciones base y asistencia por Wi-Fi para ampliar la disponibilidad de ubicación
- Sensor de temperatura integrado para conocer el estado de la carga
- Sensor de humedad integrado para monitorear envíos sensibles
- Bluetooth 5.0 para capacidades inalámbricas locales
- Soporte para alarmas por manipulación y apertura para mayor control sobre el manejo
- Funcionamiento prolongado en espera para escenarios de tránsito extendido y rastreo con mínima intervención
- Construcción reciclable para implementaciones donde la reutilización y la sostenibilidad son importantes

Cuando el GG100 se utiliza con Plaspy, su conjunto público de funciones puede reflejarse como visibilidad de ubicación en tiempo real, monitoreo del estado ambiental y supervisión basada en eventos para mercancías en tránsito. Plaspy proporciona la capa de plataforma para organizar esta información en un flujo de rastreo práctico.

- Las actualizaciones de ubicación del rastreador pueden mostrarse en Plaspy para el monitoreo de envíos y activos
- El posicionamiento de múltiples fuentes ayuda a mantener la visibilidad cuando un solo método de ubicación no es suficiente

- Monitoreo de cadena de frío para envíos que requieren visibilidad de temperatura y humedad
- Rastreo de pallets en almacenes, centros de distribución y rutas de transporte
