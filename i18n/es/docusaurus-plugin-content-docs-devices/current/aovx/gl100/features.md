# AOVX - GL100 Features

Esta página presenta el contexto público de funciones para usar el AOVX GL100 con Plaspy. El GL100 es un rastreador GPS compacto, sin instalación, diseñado para el monitoreo prolongado de activos y el registro de condiciones ambientales, con posicionamiento GNSS, ayuda de ubicación Wi Fi de 2.4 GHz y sensores integrados de temperatura y humedad.

En Plaspy, el GL100 puede utilizarse para visualizar actualizaciones de ubicación, revisar información de estado basada en sensores y apoyar procesos de rastreo para mercancías, paquetes y carga vehicular. La disponibilidad exacta de funciones puede variar según el firmware, la revisión de hardware, el tipo de instalación y la implementación del fabricante, por lo que siempre conviene confirmar los detalles actuales del dispositivo antes de implementarlo.

## Panorama de funciones

El AOVX GL100 está pensado para brindar visibilidad práctica de activos, en lugar de integrar electrónica vehicular compleja. Su conjunto público de funciones se centra en el rastreo de ubicación, el monitoreo de condiciones y una operación de bajo mantenimiento, lo que lo hace adecuado para despliegues desatendidos donde importan los reportes periódicos confiables.

- Posicionamiento basado en GNSS para monitoreo de ubicación de activos
- Ayuda de ubicación Wi Fi de 2.4 GHz para mejorar el posicionamiento en entornos difíciles
- Sensor integrado de temperatura para rastreo con información de condición
- Sensor integrado de humedad para monitoreo ambiental
- Reportes inteligentes según movimiento para ayudar a reducir actualizaciones innecesarias
- Detección de luz configurable para operación basada en disparadores
- Almacenamiento fuera de línea para cargar posiciones de forma diferida
- Funcionamiento con batería recargable para implementaciones de largo plazo
- Actualizaciones de firmware por USB y OTA para un mantenimiento más simple

## Funciones principales del AOVX - GL100

- Diseño compacto de rastreador GPS sin instalación
- Reporte de ubicación GNSS para visibilidad de activos y carga
- Soporte de ubicación asistida por Wi Fi de 2.4 GHz
- Monitoreo de temperatura mediante sensores integrados
- Monitoreo de humedad mediante sensores integrados
- Detección de movimiento para un comportamiento de reporte más inteligente
- Detección de luz configurable para rastreo basado en eventos
- Soporte de carga diferida mediante memoria integrada

## Cómo funcionan estas funciones con Plaspy

Plaspy utiliza la ubicación reportada por el GL100 y su información de sensores para ayudar a los equipos a dar seguimiento a los activos con el paso del tiempo y revisar el estado operativo en un solo lugar. Esto facilita monitorear movimientos, entender condiciones de entrega y conservar registros históricos de activos que no están instalados de forma permanente en vehículos.

- Las actualizaciones de ubicación pueden aparecer en Plaspy para visualización en mapa y revisión histórica
- Las lecturas de temperatura y humedad pueden apoyar flujos de monitoreo de condiciones
- Los eventos activados por movimiento y luz pueden ayudar a resaltar actividad relevante
- Los registros de posición almacenados pueden reflejarse después de periodos sin conexión cuando el dispositivo vuelve a conectarse
- El reporte periódico puede apoyar el monitoreo con mínima intervención para despliegues prolongados de activos
- Plaspy detecta automáticamente el protocolo del rastreador, lo que ayuda a simplificar la integración entre dispositivos compatibles

## Casos de uso habituales

- Rastreo de mercancías durante transporte o almacenamiento
- Monitoreo de paquetes para conocer ubicación y condiciones
- Visibilidad de carga vehicular sin instalación invasiva
- Monitoreo prolongado de activos para equipos desatendidos
- Rastreo de entregas con conciencia de condición para envíos sensibles
- Rastreo de movimiento en almacenes o inventario
- Flujos antirrobo para activos portátiles

## Por qué usar Plaspy con estas funciones

El GL100 es una opción práctica para organizaciones que necesitan visibilidad sin instalaciones complicadas. Su combinación de rastreo de ubicación, sensores ambientales y reportes orientados al ahorro de energía lo hace útil para escenarios de gestión de flotas, supervisión de carga y monitoreo de activos donde tanto la posición como la condición son importantes.

Con Plaspy, estas capacidades pueden organizarse en un flujo operativo más claro con mapas, vistas históricas y monitoreo orientado a alertas.
