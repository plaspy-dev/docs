# TopTen - TK228

![TK228](./Logo.jpg)

El rastreador GPS TK228 de TopTen es una solución integral que combina un rastreador GPS, una alarma de coche RFID y diagnóstico remoto a través de Bluetooth. Con un diseño Plug & Play y un conector OBD-II, es compatible con la mayoría de los vehículos con conector OBD-II y CAN-BUS.

Este rastreador ofrece una amplia gama de funciones, como armado/desarmado por SMS/llamada telefónica o etiqueta RFID, seguimiento por SMS/sitio web para obtener información de ubicación en tiempo real, alarmas de movimiento, exceso de velocidad y geovalla, alarma de motor y falla de energía, alarma de vibración y anti-manipulación, entre otras.

Además, el TK228 cuenta con un sensor de choque incorporado, control de voz, etiqueta RFID de larga distancia para identificación del conductor, lectura precisa del odómetro y velocidad a través de CAN-BUS, registrador de datos de 8Mb para waypoint GPS fuera de línea, inmovilizador inalámbrico para detener el coche en modo seguro y una batería de respaldo recargable incorporada.

Una característica destacada del TK228 es su función de diagnóstico remoto, que permite la transmisión de datos CAN a través de Bluetooth o GPRS. Esto incluye datos en tiempo real del vehículo, como voltaje de la batería, RPM, velocidad, carga del motor, consumo de combustible, entre otros, así como datos de comportamiento del conductor, como tiempo de conducción, velocidad promedio y historial de alta velocidad.

Con el TK228, también es posible leer y borrar códigos de error del vehículo a través de GPRS o Bluetooth. En resumen, este rastreador GPS ofrece una amplia gama de funciones y características que lo convierten en una opción confiable y versátil para la seguridad y el seguimiento de vehículos.
