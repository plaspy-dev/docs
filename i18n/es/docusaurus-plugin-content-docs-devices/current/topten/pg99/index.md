# TopTen - PG99

![PG99](./Logo.jpg)

El rastreador GPS PG99 de TopTen es un dispositivo de rastreo con función antirrobo diseñado para activos. Este dispositivo ofrece cuatro modos de trabajo diferentes para adaptarse a diversas aplicaciones.

El PG99 cuenta con un modo de reposo profundo que utiliza un diseño de ahorro de energía extremo, lo que le permite funcionar durante años en modo de espera prolongado.

El rastreador GPS PG99 ofrece una amplia gama de características destacadas, que incluyen:

- Seguimiento al comando o por intervalo de tiempo o por reloj.
- Armar / desarmar por SMS / plataforma o llamada telefónica.
- Verificación de la dirección física real del automóvil, como el nombre de la ciudad y el nombre de la calle.
- Seguimiento por SMS móvil para obtener la latitud, longitud, velocidad, dirección y odómetro, entre otros datos.
- Verificación de la ubicación directamente a través de la URL del mapa de Google.
- Alarma de vibración.
- Alarma de batería baja.
- Alerta de exceso de velocidad.
- Función A-GPS con gran capacidad de recibir señal GPS.
- Verificación de coordenadas a través de LBS, incluso si no hay señal de GPS disponible.
- Batería de 12000mAH para un modo de funcionamiento en espera prolongado.
- Sensor de choque incorporado para ahorro de energía y activación de alarma.
- Fuerte imán para una fácil instalación.
- Diseño impermeable.
- Cuenta con 4 tipos de modos de trabajo para ahorrar energía de manera flexible.

Con todas estas características, el rastreador GPS PG99 es una opción confiable y versátil para el seguimiento y protección de activos.
