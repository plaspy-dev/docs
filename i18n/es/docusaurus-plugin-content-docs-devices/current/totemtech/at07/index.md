# Totemtech - AT07

![AT07](./logo.jpg)

El rastreador GPS Totemtech AT07 es una solución confiable y versátil para el monitoreo y seguimiento de vehículos. Con una amplia gama de características y especificaciones técnicas, este dispositivo ofrece un rendimiento excepcional y una funcionalidad avanzada.

Una de las características destacadas del AT07 es su capacidad para enviar datos a dos servidores simultáneamente, lo que garantiza una mayor confiabilidad y redundancia en la transmisión de datos. Además, cuenta con un acelerómetro digital de 3 ejes para monitorear el estado de movimiento y permite la actualización de firmware a través de OTA \(Over-The-Air\).

Este rastreador GPS es compatible con una amplia gama de voltajes de alimentación, desde 9V hasta 50V, y cuenta con protección contra sobretensión. También ofrece la posibilidad de enviar comandos a través de GPRS o SMS para un control y configuración remotos.

El AT07 utiliza un módulo GPS u-blox de alta precisión para una localización precisa y confiable. Además, ofrece comunicaciones SMS y GPRS TCP/UDP, lo que permite el seguimiento en tiempo real y el envío de datos de rastreo a través de teléfonos celulares o software de seguimiento basado en la web.

Entre las características adicionales se incluyen la detección de nivel de combustible/aceite con alta precisión, enlace de mapa de Google a través de SMS, función de supervisión de voz con micrófono ajustable y puertos I/O para entrada digital, salida digital y entrada analógica.

El rastreador GPS Totemtech AT07 es una opción ideal para empresas de transporte, flotas de vehículos y cualquier persona que necesite monitorear y rastrear sus activos de manera eficiente y confiable. Con su amplia gama de características y especificaciones técnicas, este dispositivo ofrece un rendimiento excepcional y una funcionalidad avanzada.

### Características destacadas:

- Envío de datos a dos servidores simultáneamente
- Acelerómetro digital de 3 ejes para monitoreo de movimiento
- Soporte de voltaje de alimentación de 9V a 50V
- Comandos remotos a través de GPRS o SMS
- Localización precisa con módulo GPS u-blox
- Comunicaciones SMS y GPRS TCP/UDP
- Seguimiento en tiempo real y envío de datos de rastreo
- Detección de nivel de combustible/aceite
- Función de supervisión de voz con micrófono ajustable
- Puertos I/O para entrada digital, salida digital y entrada analógica
