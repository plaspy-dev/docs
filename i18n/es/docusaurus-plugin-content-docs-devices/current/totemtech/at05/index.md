# Totemtech - AT05

![AT05](./logo.jpg)

El rastreador GPS Totemtech AT05 es una solución confiable y versátil para el monitoreo y seguimiento de vehículos. Con la capacidad de enviar datos a dos servidores simultáneamente, este dispositivo garantiza una comunicación estable y confiable. Además, cuenta con un acelerómetro digital de 3 ejes para monitorear el estado de movimiento, lo que permite detectar cualquier actividad sospechosa o accidentes.

Este rastreador GPS es compatible con una amplia gama de voltajes, desde 9V hasta 50V, lo que lo hace adecuado para su uso en diferentes tipos de vehículos. También ofrece la posibilidad de enviar comandos a través de GPRS o SMS, lo que brinda flexibilidad en la gestión y control del dispositivo.

El Totemtech AT05 utiliza tecnología GPS de alta precisión para proporcionar una ubicación precisa en tiempo real. Con comunicaciones SMS y GPRS, es posible rastrear y visualizar la ubicación del vehículo a través de un teléfono celular o software de seguimiento basado en la web. Además, ofrece diferentes tipos de alarmas, como exceso de velocidad, baja potencia, temblor, aparcamiento, SOS, entre otras, para garantizar la seguridad del vehículo y sus ocupantes.

Este rastreador GPS también cuenta con funciones avanzadas, como control de apertura/cierre de puertas del vehículo, detección del estado del motor de encendido/apagado y gestión inteligente de la energía. Además, tiene una memoria flash para almacenar datos en áreas sin cobertura GSM y un modo de suspensión para ahorrar energía y tráfico GPRS.

En resumen, el rastreador GPS Totemtech AT05 es una solución confiable y completa para el monitoreo y seguimiento de vehículos. Con su precisión de posicionamiento, comunicaciones estables y funciones avanzadas, este dispositivo es ideal para empresas de transporte, flotas de vehículos y cualquier persona que desee tener un control total sobre sus vehículos.

### Características destacadas:

- Envío de datos a dos servidores simultáneamente
- Acelerómetro digital de 3 ejes para monitoreo de movimiento
- Compatibilidad con voltajes de 9V a 50V
- Envío de comandos a través de GPRS o SMS
- Ubicación precisa en tiempo real con tecnología GPS
- Comunicaciones SMS y GPRS para rastreo y visualización de ubicación
- Diferentes tipos de alarmas para garantizar la seguridad del vehículo
- Control de apertura/cierre de puertas del vehículo
- Detección del estado del motor de encendido/apagado
- Gestión inteligente de la energía y modo de suspensión
