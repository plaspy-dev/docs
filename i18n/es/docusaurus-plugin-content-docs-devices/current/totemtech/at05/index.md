# Totemtech - AT05

![AT05](./logo.jpg)

El Totemtech AT05 es un rastreador GPS compacto diseñado para el monitoreo versátil de vehículos y activos. Combina el reporte de posición con la detección de estado de movimiento mediante un acelerómetro digital de 3 ejes, admite rastreo en tiempo real y revisión de trazas históricas, y ofrece múltiples tipos de alarma para notificar eventos como exceso de velocidad, batería baja, SOS y corte de alimentación. Además, permite actualizaciones de firmware por aire y acepta un amplio rango de alimentación con protección contra sobretensión, lo que lo hace adecuado para distintos entornos de instalación.

Como modelo compatible con Plaspy, el AT05 puede transmitir sus datos de rastreo a plataformas de gestión de flotas para ofrecer visibilidad operativa e informes. Su capacidad de enviar datos a dos servidores simultáneamente aporta redundancia para integraciones, mientras que los puertos I/O configurables y los distintos tipos de alarma hacen al AT05 flexible para diferentes flujos de monitoreo dentro de Plaspy. Estas características lo convierten en una opción práctica para organizaciones que necesitan ubicación en vivo y reproducción histórica centralizada.

## Aspectos clave

- Transmisión simultánea de datos a dos servidores para redundancia e integraciones paralelas
- Acelerómetro digital de 3 ejes para detección de actividad y estado de movimiento
- Capacidad de actualizar firmware de manera remota (OTA)
- Amplio rango de entrada DC con protección contra sobretensión para diversos vehículos y equipos
- Soporte de comandos remotos vía GPRS y SMS para control flexible del dispositivo
- Rastreo en tiempo real más trazas históricas para supervisión operativa e investigaciones
- Múltiples tipos de alarma y configuración de I/O definida por el usuario para alertas personalizadas y manejo de eventos

## Cómo funciona con Plaspy

El AT05 envía datos de posición y eventos a Plaspy, donde pueden visualizarse, generar alertas e incorporarse a informes. Plaspy consume la transmisión del rastreador para ofrecer una vista consolidada de los activos, permitir el análisis de trazas históricas y disparar notificaciones cuando se cumplen condiciones configuradas.

- Ubicación en vivo mostrada en los mapas de Plaspy para visibilidad continua de la flota
- Reproducción de rutas históricas y líneas de tiempo de eventos para revisión posterior y auditoría
- Integración de alarmas para que exceso de velocidad, SOS, pérdida de energía y otras alertas aparezcan como notificaciones en Plaspy
- Uso de salida a dos servidores para enviar datos primarios a Plaspy mientras se mantiene un endpoint secundario para respaldo o servicios paralelos
- Mapeo de eventos I/O definidos por el usuario dentro de los flujos de trabajo de Plaspy para alertas y reportes personalizados

## Casos de uso típicos

- Monitoreo de flotas de vehículos para entregas, servicios o transporte
- Seguimiento de equipos de construcción o alquiler entre distintas obras
- Supervisión de activos de alto valor que requieren ubicación en tiempo real y notificaciones de eventos
- Vigilancia remota de equipos en sitios con variabilidad de alimentación donde la protección es importante
- Situaciones que demandan trazas históricas para verificación de rutas y revisión de incidentes

## Por qué elegir este rastreador con Plaspy

El AT05 es una opción práctica para organizaciones que necesitan equilibrio entre visibilidad en tiempo real, alertas basadas en eventos y capacidad de configuración. El monitoreo de movimiento mediante acelerómetro y el amplio soporte de alarmas permiten identificar eventos accionables, mientras que las actualizaciones OTA reducen la carga de mantenimiento en despliegues dispersos. Unido a Plaspy, estas capacidades respaldan necesidades comunes de gestión de flotas y activos como monitoreo de ubicación, alertas y análisis histórico.

Dado su conjunto de funciones, el AT05 es especialmente apropiado para despliegues donde la redundancia y la administración remota son importantes. Si su operación requiere mapear telemetría en vivo hacia una plataforma centralizada para informes y supervisión operativa, la combinación AT05 y Plaspy ofrece una ruta de integración directa.
