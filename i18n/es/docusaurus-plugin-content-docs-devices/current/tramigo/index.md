# Tramigo

Tramigo fabrica hardware de rastreo GPS frecuentemente usado para el seguimiento de vehículos y activos. En esta página encontrará información sobre cómo funcionan los dispositivos Tramigo con Plaspy, qué características puede esperar y cómo elegir el modelo adecuado según sus necesidades. Use el catálogo a continuación para explorar los modelos Tramigo compatibles con la plataforma Plaspy.

<BrandCatalog brand={brand} />

## Cómo funcionan los dispositivos Tramigo con Plaspy

Los rastreadores Tramigo envían datos de ubicación y estado a través de redes móviles que Plaspy recibe, normaliza y muestra en la plataforma. Plaspy procesa posiciones GPS, telemetría básica de sensores y eventos estándar del equipo, y los presenta en mapas en vivo, reproducción de historial, alertas y reportes. La configuración y el aprovisionamiento específicos de cada dispositivo se gestionan en las páginas de modelo y en los ajustes de dispositivo dentro de Plaspy para asegurar que el rastreador se comunique correctamente con la plataforma.

Como el BrandCatalog lista los modelos compatibles, puede seleccionar un dispositivo y seguir la página del modelo para obtener guías de instalación, parámetros del equipo y la configuración recomendada para un mejor desempeño en Plaspy.

## Funciones comunes en dispositivos Tramigo

Aunque las capacidades varían según el modelo, el hardware de Tramigo suele incluir una combinación de estas funciones habituales:
- Reporte de ubicación GPS en tiempo real y registro de historial de posiciones
- Detección de movimiento y de ignición para monitoreo de vehículos
- Entradas digitales y analógicas básicas para sensores y alarmas externas
- Intervalos de reporte configurables y reporte basado en movimiento
- Opciones de batería de respaldo para rastreadores de activos portátiles
- Antenas integradas o externas para distintos escenarios de instalación

Plaspy interpreta estas señales y las expone como entradas configurables para seguimiento, alertas, geocercas y reportes dentro de la plataforma.

## Casos de uso típicos para rastreadores Tramigo

Los dispositivos Tramigo se emplean en diversos escenarios de rastreo. Los casos de uso más comunes incluyen:
- Seguimiento de flotas y supervisión de rutas de conductores
- Rastreo a largo plazo de remolques y equipos
- Recuperación ante robo y alertas de manipulación para bienes de alto valor
- Monitoreo remoto donde exista cobertura celular

Las herramientas de mapeo, alertas y reportes de Plaspy permiten a las organizaciones convertir los datos crudos de los dispositivos en información operativa útil para estos casos.

## Por qué elegir Plaspy para monitorear dispositivos Tramigo

Plaspy ofrece una plataforma única para gestionar conectividad de dispositivos, visualizar posiciones, configurar alertas y generar reportes para el hardware Tramigo. Los beneficios clave de usar Plaspy con Tramigo incluyen:
- Gestión centralizada de equipos con aprovisionamiento y control de parámetros
- Seguimiento en vivo y reproducción de historial optimizados para diagnósticos eficientes
- Alertas y geocercas flexibles que se adaptan a las políticas operativas
- Reportes exportables e integraciones para alimentar otros sistemas de negocio
- Acceso a recursos de soporte y documentación de dispositivos dentro de la base de conocimiento de Plaspy

Esta combinación reduce el tiempo para obtener valor y simplifica el monitoreo cotidiano de los rastreadores Tramigo.

## Ayuda para elegir el dispositivo Tramigo correcto

La elección del equipo Tramigo apropiado depende del entorno de instalación y de las funciones que necesite. Considere lo siguiente al comparar modelos:
- Tipo de alimentación e instalación requeridos para el activo o vehículo
- Necesidad de entradas externas o soporte para sensores
- Duración de batería necesaria para rastreadores portátiles
- Cobertura y compatibilidad de red en su región de operación

Use el BrandCatalog arriba para comparar visualmente los modelos Tramigo compatibles. Para orientación adicional, consulte las páginas específicas de cada dispositivo en Plaspy y el sitio del fabricante en http://www.tramigo.net/ o contacte al soporte de Plaspy.
