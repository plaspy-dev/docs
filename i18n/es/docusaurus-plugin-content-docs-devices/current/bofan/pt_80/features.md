# Bofan - PT-80: Características

Esta página ofrece un resumen público de las funciones del Bofan PT-80 y explica cómo sus capacidades se relacionan con el uso en la plataforma Plaspy. Está pensada para describir las funciones orientadas al usuario y el valor práctico para el monitoreo y rastreo cuando usted empareja el PT-80 con un servidor de gestión de flotas o de seguimiento como Plaspy.

La disponibilidad y el comportamiento exacto de las funciones pueden variar según la versión de firmware, la revisión de hardware, el método de instalación y cómo el fabricante configura funciones específicas. Para detalles de implementación por dispositivo y la información técnica más actualizada, consulte la documentación oficial de Bofan.

## Resumen de características

El PT-80 es un rastreador GPS personal compacto diseñado para el monitoreo discreto de ubicación en tiempo real y alertas básicas de situación. Combina tamaño reducido y portabilidad con funciones de seguimiento esenciales que apoyan la seguridad personal y la supervisión de activos.

- Factor de forma compacto y ligero para llevar con facilidad y colocación discreta
- Antenas GPS y GSM integradas para ubicación y conectividad de red
- Botón de pánico para alertas de emergencia inmediatas a contactos preconfigurados
- Monitoreo de voz para escuchar el entorno del dispositivo cuando está soportado
- Gestión de geocercas para notificaciones de entrada y salida de áreas predefinidas
- Seguimiento vía SMS y GPRS, además de seguimiento web en tiempo real cuando hay red disponible

## Funciones principales del Bofan - PT-80

- Reporte de ubicación GPS en tiempo real, apto para seguimiento personal y supervisión de activos
- Conectividad GSM integrada para enviar ubicaciones y mensajes de alerta por SMS o datos
- Botón de pánico que activa una alerta urgente a números o plataformas designadas
- Capacidad de monitoreo por voz para permitir escucha remota en flujos de trabajo compatibles
- Configuración de geocercas y reporte de eventos para vigilancia de límites virtuales
- Alerta de baja energía para indicar cuando el nivel de batería es bajo
- Alerta por exceso de velocidad para notificar cuando la velocidad reportada supera umbrales configurados
- Sensor de movimiento interno con alarmas de movimiento y comportamiento de ahorro de energía

## Cómo funcionan estas funciones con Plaspy

Cuando un PT-80 se usa con Plaspy, sus funciones básicas de rastreo y alerta se vuelven visibles y accionables dentro de una plataforma centralizada de monitoreo. Plaspy recibe datos de ubicación y eventos y los presenta junto con otros dispositivos para mayor visibilidad operativa.

- Las posiciones en tiempo real aparecen en los mapas de Plaspy para seguimiento y conocimiento de ubicación en vivo
- Pulsaciones del botón de pánico y eventos de entrada o salida de geocercas se registran como alertas en Plaspy
- Las alarmas de movimiento y las notificaciones de batería baja se muestran para que los operadores puedan responder
- Los registros históricos de posiciones enviados por el dispositivo están disponibles en Plaspy para revisar recorridos
- Los mensajes basados en SMS o GPRS del dispositivo se representan como eventos que pueden correlacionarse con los datos de ubicación

## Casos de uso típicos

- Rastreo para la seguridad personal de niños, cuidadores o personas vulnerables
- Monitoreo discreto de activos portátiles y equipaje durante el traslado
- Conciencia de ubicación y alertas de emergencia para trabajadores solitarios
- Protección temporal para tareas o viajes de corta duración
- Flujos de trabajo de recuperación y devolución de activos donde el historial de posiciones es importante

## Notas sobre disponibilidad de funciones

- Algunas funciones dependen de la versión de firmware del dispositivo y pueden cambiar con actualizaciones del fabricante
- Las funciones dependientes de la red, como el seguimiento por SMS o GPRS, requieren cobertura celular y pueden variar según la región y la configuración de la SIM
- El comportamiento de geocercas y alertas puede depender de cómo se configuren umbrales y zonas durante la instalación
- El monitoreo por voz y los servicios web pueden requerir servicios o permisos específicos del fabricante
- La capacidad de registro de posiciones y el comportamiento de los waypoints almacenados dependen de la configuración del dispositivo y del firmware

## Por qué usar Plaspy con estas funciones

Usar Plaspy con el PT-80 centraliza ubicaciones, alertas e historial de eventos para que organizaciones y cuidadores mantengan una conciencia situacional sobre múltiples dispositivos. Plaspy ayuda a convertir las señales del PT-80 en información accionable mostrando posiciones en vivo, registrando recorridos históricos y destacando eventos de emergencia para una respuesta rápida.
