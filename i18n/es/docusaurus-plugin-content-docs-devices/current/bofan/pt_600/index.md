# Bofan - PT-600

![PT-600](./logo.jpg)

El rastreador GPS Bofan PT-600 es una versión actualizada del PT-600, diseñado para ofrecer un seguimiento preciso y confiable en tiempo real. Con soporte para hasta 3 cámaras, este rastreador permite una vigilancia completa de su vehículo o activo. Puede realizar un seguimiento a través de SMS o utilizar la plataforma Plaspy para un seguimiento en vivo y recibir informes de ubicación actualizados en tiempo real.

Una de las características destacadas del PT-600 es su alarma SOS, que le permite enviar una señal de emergencia en caso de peligro. Además, cuenta con un control de alarma de energía baja para asegurarse de que siempre esté informado sobre el estado de la batería. Opcionalmente, también puede configurar una alarma de velocidad de corte del motor para proteger su vehículo contra robos.

Con una capacidad de registro de posición de hasta 30,000+ waypoints y un sensor de movimiento, el PT-600 le brinda un seguimiento detallado y preciso de sus activos. Además, puede configurar diferentes formas de notificación de alarma, como el envío de SMS de alarma, llamadas, notificaciones en la plataforma o incluso tomar una foto en caso de una alarma.
