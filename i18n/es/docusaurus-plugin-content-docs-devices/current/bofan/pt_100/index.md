# Bofan - PT-100

![PT-100](./logo.jpg)

El rastreador GPS Bofan PT-100 es un dispositivo de localización GPS/GSM/GPRS especialmente desarrollado y diseñado para el seguimiento en tiempo real y la seguridad de motocicletas. Equipado con módulos GPS y GPRS, el PT-100 ofrece una excelente sensibilidad y un rendimiento estable. Este rastreador ha sido diseñado para funcionar de manera óptima con la plataforma de seguimiento Plaspy, lo que permite a las empresas establecer su propio sistema de seguimiento y proporcionar servicios de seguimiento en tiempo real a sus clientes o gestionar su flota de vehículos de manera eficiente.

El Bofan PT-100 cuenta con una amplia gama de características destacadas que lo convierten en una opción ideal para el seguimiento de motocicletas. Estas características incluyen:

- Seguimiento a través de SMS o seguimiento en vivo por GPRS para una ubicación precisa y actualizada.
- Capacidad de registro de posición de hasta 3000+ waypoints, lo que permite un seguimiento detallado y exhaustivo.
- Botón de pánico SOS para situaciones de emergencia.
- Alerta de baja potencia para garantizar un uso continuo y evitar la pérdida de energía.
- Alarma de velocidad para recibir notificaciones cuando se excede un límite de velocidad preestablecido.
- Opción de corte del motor \(opcional\) para una mayor seguridad y control del vehículo.
- Obtención de la dirección de la calle a través de solicitudes de SMS para una ubicación precisa.
- Disponibilidad para establecer diferentes métodos de notificación de alarma, ya sea a través de SMS o de la plataforma de seguimiento.
- Recordatorio de mantenimiento del vehículo a través de informes de kilometraje para un mantenimiento oportuno y eficiente.
- Entrada y salida digital para una mayor flexibilidad y compatibilidad con otros dispositivos.

Con todas estas características y su compatibilidad con la plataforma de seguimiento Plaspy, el rastreador GPS Bofan PT-100 es una opción confiable y eficiente para el seguimiento y la seguridad de motocicletas.
