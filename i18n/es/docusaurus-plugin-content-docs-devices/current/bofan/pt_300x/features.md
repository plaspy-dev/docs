# Bofan - Características del PT-300X

Esta página ofrece una visión pública de las funcionalidades del rastreador GPS para vehículos Bofan PT-300X y explica cómo se utilizan normalmente estas funciones con Plaspy. Se enfoca en detalles prácticos y no sensibles sobre reportes, alertas y el valor operativo cuando el PT-300X está conectado a la plataforma Plaspy.

La disponibilidad exacta y el comportamiento de cada función pueden variar según el firmware del equipo, la revisión de hardware, el cableado de instalación y la implementación del fabricante. Cuando es posible, esta página refleja las capacidades del PT-300X descritas por el fabricante, pero usted debe verificar el comportamiento específico del dispositivo con la documentación oficial de Bofan.

## Resumen de funciones

El PT-300X es un rastreador compacto para vehículos diseñado para reportar ubicación y eventos por SMS o GPRS usando TCP o UDP. Soporta reportes periódicos, alertas por condiciones definidas y señales de emergencia manuales, lo que lo hace adecuado para monitoreo de vehículos y supervisión básica de flotas.

- Reporte de ubicación en tiempo real vía SMS o GPRS usando TCP o UDP
- Seguimiento por intervalo de tiempo para actualizaciones regulares de posición e historial de viajes
- Alerta de batería baja para notificar cuando la alimentación del dispositivo requiere atención
- Alerta por exceso de velocidad para señalar cuando se supera un umbral de velocidad configurado
- Soporte de geocercas para notificar cuando el vehículo entra o sale de áreas definidas
- Botón SOS para enviar una alerta de emergencia a contactos predefinidos

## Funciones principales del Bofan - PT-300X

- Reporte de ubicación por SMS o GPRS TCP UDP para que los dispositivos envíen actualizaciones de posición a servidores de rastreo
- Seguimiento por intervalos de tiempo que permite al dispositivo enviar reportes periódicos de posición para historial de rutas y monitoreo
- Alerta de batería baja para detectar problemas de alimentación y ayudar a mantener los dispositivos en línea
- Alerta por exceso de velocidad para detectar y reportar cuando se superan límites de velocidad configurados
- Control de geocercas para monitoreo de perímetros virtuales y notificaciones de entrada y salida
- Botón SOS para generar un evento de alerta inmediata en situaciones de emergencia
- Función de inmovilización del vehículo mediante un relé externo que puede usarse para inmovilizar el vehículo cuando el relé está instalado y configurado

## Cómo funcionan estas funciones con Plaspy

Cuando usted conecta un PT-300X a Plaspy, los reportes y alertas del rastreador se hacen visibles en la interfaz de Plaspy para monitoreo y uso operativo. Plaspy detecta automáticamente los protocolos de rastreadores compatibles y acepta reportes TCP o UDP en el puerto de la plataforma utilizado por Plaspy.

- Las actualizaciones de ubicación en tiempo real y por intervalo aparecen en los mapas de Plaspy y se almacenan como historial de rastreo para reproducción y análisis
- Las alertas por exceso de velocidad y batería baja se muestran como eventos para que los operadores puedan actuar o revisar las ocurrencias
- Los eventos de entrada y salida de geocercas pueden reflejarse como notificaciones o eventos registrados en Plaspy
- Las señales SOS se destacan como eventos de alta prioridad para una rápida toma de conciencia por parte de los operadores
- Las activaciones de inmovilización reportadas por el dispositivo quedan registradas como eventos del equipo en Plaspy cuando el rastreador envía la actualización de estado correspondiente

## Casos de uso típicos

- Monitoreo de ubicación de flotas con actualizaciones periódicas de posición para visibilidad de rutas
- Supervisión de seguridad mediante alertas por exceso de velocidad y visibilidad de eventos SOS
- Seguridad de activos usando geocercas para detectar movimientos no autorizados o cruces de límites
- Gestión de mantenimiento y disponibilidad al rastrear alertas de batería baja para la salud del dispositivo
- Revisión de incidentes y reproducción de rutas usando reportes por intervalo de tiempo para reconstruir viajes
- Flujos de trabajo de inmovilización remota donde el relé instalado y el reporte del dispositivo forman parte de un proceso de prevención de pérdidas

## Notas sobre disponibilidad de funciones

- Algunas funciones dependen del firmware del dispositivo y pueden añadirse, cambiarse o eliminarse por el fabricante en diferentes versiones de firmware
- Las revisiones de hardware y las variantes regionales del producto pueden afectar qué funciones están presentes o cómo se conectan durante la instalación
- El reporte por SMS y por GPRS pueden estar disponibles ambos, pero requieren la configuración correcta del transporte elegido
- Funciones que requieren hardware adicional, como un relé de inmovilización o una entrada SOS con cable, dependen de que el instalador habilite y conecte esos componentes
- Siempre consulte el manual de instalación del dispositivo y las notas de la versión del firmware para detalles específicos antes de confiar en una función en particular

## Por qué usar Plaspy con estas funciones

Usar Plaspy con el PT-300X centraliza los datos de ubicación y eventos, de modo que su organización obtiene visibilidad continua de los movimientos de los vehículos, las alertas y la salud del dispositivo. Los mapas, el registro de eventos y las notificaciones configurables de Plaspy ayudan a transformar los reportes brutos del rastreador en información operativa para gestores de flota, equipos de seguridad y personal de protección.

Para saber más sobre cómo Plaspy puede trabajar con el PT-300X y otros rastreadores, visite https://www.plaspy.com. Para los detalles más actualizados y específicos del dispositivo, notas de firmware e instrucciones de instalación, consulte al fabricante en https://www.bofancloud.com/ que es la fuente autorizada de la documentación técnica del PT-300X.
