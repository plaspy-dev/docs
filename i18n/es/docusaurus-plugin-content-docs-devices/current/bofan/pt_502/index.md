# Bofan - PT-502

![PT-502](./logo.jpg)

El rastreador GPS PT-502 de Bofan es un dispositivo de localización GSM / GPS / GPRS que ofrece una excelente sensibilidad y un rendimiento estable. Este rastreador es compatible con la plataforma de seguimiento Plaspy, lo que lo convierte en una opción ideal para aquellos que buscan una solución confiable para rastrear vehículos, activos o personas.

La instalación del PT-502 es sencilla y su uso es intuitivo, lo que lo hace accesible para usuarios de todos los niveles de experiencia. Con este rastreador, podrás obtener información precisa y en tiempo real sobre la ubicación de tus activos, lo que te permitirá tomar decisiones informadas y mejorar la eficiencia de tus operaciones.

Características destacadas:

- Localización GSM / GPS / GPRS
- Sensibilidad y rendimiento estables
- Compatible con la plataforma de seguimiento Plaspy
- Fácil instalación y uso
