# Concox - Funciones del GT300

Esta página describe el contexto público de funciones del Concox GT300 y cómo se presentan sus capacidades cuando se utiliza con Plaspy. Se enfoca en las funciones visibles para el usuario, el valor operativo y observaciones de alto nivel sobre la integración, para que usted comprenda qué puede hacer el GT300 dentro de la plataforma Plaspy.

La disponibilidad exacta y el comportamiento de las funciones pueden variar según la versión de firmware del dispositivo, la revisión de hardware, el método de instalación y la implementación del fabricante. Para detalles técnicos específicos del dispositivo y el comportamiento más reciente del firmware, consulte la documentación y las notas de la versión del fabricante.

## Resumen de características

El Concox GT300 es un teléfono de seguridad compacto con GSM/GPS diseñado para ofrecer rastreo de ubicación y notificación de eventos para personas y objetos pequeños. Combina un receptor GPS sensible con un subsistema GPRS GSM cuatribanda y admite una variedad de informes de alerta relevantes para flujos de trabajo de monitoreo y seguridad.

- Receptor GPS integrado de alta sensibilidad y tiempo rápido hasta la primera posición para actualizaciones de ubicación precisas
- Conectividad GPRS GSM cuatribanda para amplia cobertura regional
- Soporte para alertas de emergencia y SOS para señalar situaciones urgentes
- Informes de entrada y salida de geocercas para notificaciones basadas en ubicación
- Notificaciones de batería baja para ayudar a mantener la disponibilidad del equipo
- Factor de forma compacto y portátil apto para niños, adultos mayores, equipaje y mascotas

## Características principales del Concox - GT300

- Receptor GPS integrado optimizado para fijaciones de posición confiables
- Radio GPRS GSM cuatribanda compatible con las bandas 850 900 1800 1900 MHz
- Tiempo rápido hasta obtener la primera posición y mayor sensibilidad GPS para una adquisición de ubicación más ágil
- Alarma SOS y reportes de alertas de emergencia para notificaciones prioritarias
- Alertas de geocerca para notificar entradas y salidas de áreas definidas
- Reporte de estado de batería baja para indicar cuándo la unidad necesita carga o servicio
- Diseño pequeño y portátil pensado para llevar puesto o sujetar a personas y pertenencias personales

## Cómo funcionan estas funciones con Plaspy

Cuando el GT300 se integra con Plaspy, los reportes de ubicación y eventos del dispositivo se muestran en la plataforma para proporcionar visibilidad operativa y alertas oportunas. Plaspy detecta los protocolos de rastreador compatibles y presenta eventos estándar y datos de ubicación junto con la telemetría de la flota y otros dispositivos.

- Actualizaciones de ubicación en tiempo real o periódicas mostradas en los mapas y en la línea de tiempo del dispositivo en Plaspy
- Alertas SOS y de emergencia entregadas como eventos de alta prioridad dentro de Plaspy para atención rápida
- Eventos de geocerca registrados y disponibles para alertas, informes y revisión histórica
- Notificaciones de batería baja visibles en el estado del dispositivo para ayudar a mantener el tiempo de actividad
- Identidad del dispositivo y estado de conectividad disponibles en Plaspy para monitorear el estado en línea y la actividad reciente

## Casos de uso típicos

- Monitoreo de la ubicación y seguridad de niños o adultos mayores
- Colocación en equipaje y objetos personales para seguimiento y recuperación en viajes
- Seguimiento de mascotas durante salidas o traslados
- Monitoreo temporal de activos valiosos o portátiles
- Conciencia situacional y notificación de emergencias para cuidadores o responsables

## Notas sobre la disponibilidad de funciones

- El comportamiento de las funciones puede variar según la versión de firmware del GT300 y el conjunto de funciones instaladas
- Las revisiones de hardware y las variantes regionales pueden afectar las bandas celulares compatibles y la disponibilidad de ciertos reportes
- Las opciones de instalación y el cableado de accesorios pueden modificar qué indicadores y alertas están activos
- Las configuraciones del fabricante y del servidor influyen en la frecuencia con la que se reportan ubicaciones y alertas
- Verifique siempre la lista de funciones precisa para su lote de dispositivos y firmware consultando la documentación oficial de Concox

## Por qué usar Plaspy con estas funciones

Usar el Concox GT300 con Plaspy ofrece a organizaciones y cuidadores una forma práctica de consolidar actualizaciones de ubicación y alertas de seguridad en una única plataforma de monitoreo. Plaspy muestra datos de posición, señales de emergencia y notificaciones de estado para que los equipos puedan responder más rápido y mantener registros de movimientos e incidentes.
