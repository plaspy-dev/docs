# Concox - GT300

![GT300](./logo.jpg)

El Concox GT300 es un teléfono de seguridad GSM con GPS integrado, diseñado para el seguimiento personal y de objetos pequeños. Ofrece recepción GPS con alta sensibilidad y un rápido tiempo para obtener la primera posición, lo que lo hace adecuado para vigilar a niños, adultos mayores, equipaje o mascotas. El dispositivo integra un subsistema GPRS GSM cuatribanda y soporta múltiples tipos de reportes como alertas de emergencia, cruces de geocercas, notificaciones de batería baja y alarmas SOS.

Como dispositivo compatible con Plaspy, el GT300 puede enviar información de ubicación y alertas a Plaspy para su monitoreo centralizado y supervisión operativa. Esta compatibilidad permite que organizaciones y usuarios particulares incluyan al GT300 en los flujos de trabajo de Plaspy para visibilidad, alertas y revisión histórica de ubicaciones sin cambiar la forma ni el uso principal del dispositivo.

## Aspectos clave

- Receptor GPS integrado con alta sensibilidad y tiempo rápido para la primera fijación, ofreciendo actualizaciones de posición fiables.
- Soporte GPRS GSM cuatribanda para conectividad en distintas regiones.
- Diseñado como un teléfono de seguridad portátil, apto para niños, adultos mayores, equipaje y mascotas.
- Compatible con múltiples tipos de reportes: alertas de emergencia, eventos de geocerca, batería baja y SOS.
- Compacto y fácil de llevar o fijar a objetos personales para un rastreo discreto.
- Documentación disponible para facilitar la integración y la configuración del sistema.

## Cómo funciona con Plaspy

El GT300 se puede integrar en Plaspy para proporcionar visibilidad continua de ubicaciones e informes de eventos desde dispositivos de seguimiento personales. Una vez que los datos del dispositivo llegan a Plaspy, la plataforma consolida el historial de ubicaciones y las alertas junto con otros activos rastreados para un monitoreo unificado.

- Visibilidad en tiempo real e histórica de ubicaciones dentro de los paneles y mapas de Plaspy.
- Ingesta de eventos y alertas para notificaciones de emergencia, cruces de geocerca y advertencias de batería baja.
- Monitoreo centralizado para flotas mixtas y rastreadores personales, incluyendo la supervisión de niños y adultos mayores.
- Informes e historial de ubicaciones exportable para respaldar revisiones operativas y seguimiento de incidentes.
- Notificaciones y alertas operativas dirigidas a usuarios de Plaspy para una respuesta y supervisión más rápida.

## Casos de uso típicos

- Supervisión parental de los desplazamientos de un niño durante la ruta escolar o salidas.
- Seguimiento de familiares adultos mayores para controles de seguridad y bienestar.
- Localización de equipaje durante viajes para reducir pérdidas y recibir actualizaciones de ubicación.
- Rastreo de mascotas para recuperarlas y mantener conciencia de su posición durante paseos o viajes.
- Seguimiento de activos pequeños donde se prefiere un rastreador portátil y compacto.

## Por qué elegir este rastreador con Plaspy

El GT300 es una opción práctica cuando se requiere un rastreador de seguridad portátil y compacto, y se desea centralizar el monitoreo en Plaspy. Su enfoque en reportes de seguridad personal, como SOS y eventos de geocerca, lo hace especialmente útil en escenarios de bienestar individual y en usos logísticos a pequeña escala donde las alertas rápidas y un historial de ubicaciones simple son importantes.

La compatibilidad con Plaspy permite paneles y manejo de alertas unificados; así, organizaciones y familias pueden combinar unidades GT300 con otros activos rastreados bajo una sola plataforma para supervisión y reportes consistentes. Si sus necesidades se centran en rastreo de ubicación sencillo, alertas oportunas y fácil portabilidad, el GT300 junto con Plaspy es una combinación útil.
