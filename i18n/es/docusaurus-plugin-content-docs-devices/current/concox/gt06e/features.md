# Concox - GT06E Características

Esta página describe el contexto público de funciones al usar el rastreador Concox GT06E con Plaspy. Se centra en las capacidades visibles para el usuario dentro de Plaspy para este modelo, cómo resultan útiles en la supervisión de flotas y vehículos, y qué funciones destaca el fabricante en su documentación pública.

La disponibilidad y el comportamiento exactos de las funciones pueden variar según la versión de firmware, la revisión de hardware, accesorios opcionales, la variante regional y el método de instalación. Cuando una función es opcional o depende de la configuración del equipo, se indica esa dependencia; recomendamos revisar la documentación del fabricante y los ajustes del dispositivo para obtener los detalles finales.

## Resumen de funciones

El Concox GT06E se presenta como un rastreador GPS 3G pensado para supervisión de flotas y vehículos, con un conjunto de funciones básicas de seguimiento y alarmas además de opciones de entradas/salidas. Su propósito es ofrecer actualizaciones de ubicación en tiempo real y distintos reportes de eventos y estados que una plataforma de gestión de flotas como Plaspy puede consumir.

- Conectividad 3G para reportes de ubicación y eventos más rápidos y fiables
- Seguimiento en tiempo real y actualizaciones de posición para visibilidad de la flota
- Alarmas estándar como SOS, exceso de velocidad y notificaciones de geocerca
- Función de corte remoto de combustible cuando está soportada
- Salidas digitales opcionales para detección de puertas y localización del vehículo mediante alertas audiovisual
- Monitoreo de voltaje de alimentación externa para supervisión básica de energía

## Funciones principales del Concox - GT06E

- Soporte de red 3G para mejorar la fiabilidad y la inmediatez de las comunicaciones
- Reporte de ubicación GPS en tiempo real para seguimiento y visibilidad de rutas
- Funcionalidad de geocerca para activar alertas cuando un vehículo entra o sale de un área definida
- Reporte de alarma SOS para notificaciones de emergencia
- Alerta por exceso de velocidad para avisar de violaciones de umbrales de velocidad
- Capacidad de corte remoto de combustible cuando el dispositivo y la instalación lo permiten
- Entradas/salidas digitales opcionales para detección de puertas y localización audiovisual del vehículo
- Monitoreo de voltaje de alimentación externa para detectar cambios en el suministro eléctrico

## Cómo funcionan estas funciones con Plaspy

Plaspy recibe y normaliza los reportes del rastreador para que la ubicación, las alarmas y el estado de E/S de dispositivos compatibles como el GT06E aparezcan en una vista operativa única. Plaspy puede detectar automáticamente el protocolo del rastreador y mostrar eventos y telemetría en la interfaz de la plataforma para supervisión y revisión histórica.

- La ubicación en vivo y los movimientos recientes se muestran en los mapas de Plaspy y en los paneles de estado del dispositivo
- Las alarmas como SOS, exceso de velocidad y eventos de geocerca se registran y pueden activar notificaciones o registros
- Eventos de entrada digital opcionales, como la detección de puertas, se presentan como entradas de dispositivo cuando el rastreador los reporta
- Las lecturas de voltaje de alimentación externa se registran cuando el dispositivo informa el estado de voltaje y pueden utilizarse para supervisión básica de energía
- Las acciones de control remoto que admite el dispositivo, como el corte remoto, se reflejan en Plaspy como eventos o comandos cuando están habilitadas y configuradas correctamente

## Casos de uso típicos

- Seguimiento de ubicación y monitoreo de rutas para flotas de logística y vehículos de servicio
- Alertas rápidas ante eventos SOS reportados por conductores o ocupantes del vehículo
- Notificaciones basadas en geocercas para cumplimiento de rutas y control de entradas y salidas
- Monitoreo de apertura y cierre de puertas para seguridad de la carga cuando se instala la E/S opcional
- Supervisión del suministro de energía para detectar y registrar interrupciones o variaciones en la alimentación externa
- Flujos de trabajo de corte remoto cuando se requieren funciones de tele-cutoff y están permitidas por la normativa local

## Notas sobre disponibilidad de funciones

- Algunas funciones marcadas como opcionales por el fabricante dependen de revisiones de hardware específicas o del cableado de accesorios y pueden no estar presentes en todas las unidades
- La versión de firmware puede cambiar el comportamiento de alarmas, el reporte de E/S y el monitoreo de voltaje; las actualizaciones de firmware pueden añadir o modificar funciones
- Ciertas capacidades de control remoto requieren instalación y configuración adecuadas por parte de un instalador o técnico
- El soporte de bandas celulares y la compatibilidad de red para funciones 3G pueden variar según la región; verifique la variante local para compatibilidad de red
- Para un conjunto de funciones completo y específico por dispositivo, consulte la documentación oficial del fabricante y las guías de configuración del equipo

## Por qué usar Plaspy con estas funciones

Usar el GT06E con Plaspy centraliza los datos de ubicación y eventos para que las organizaciones puedan supervisar el estado de la flota, responder a alertas y revisar movimientos históricos desde una sola plataforma. Plaspy presenta posiciones, alarmas y estados de entradas en contexto, ayudando a los equipos operativos a tomar decisiones informadas y mantener supervisión sobre vehículos y activos.
