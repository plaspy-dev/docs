# Concox - GT350

![GT350](./logo.jpg)

El rastreador GPS personal GT350 de Concox es un dispositivo confiable y versátil que ofrece una amplia gama de funciones para garantizar la seguridad y el seguimiento preciso de personas. Con su diseño compacto y liviano, este rastreador es perfecto para llevarlo consigo en todo momento.

Una de las características destacadas del GT350 es su tiempo de espera prolongado. Con una batería de alta capacidad, este rastreador puede funcionar durante largos períodos de tiempo sin necesidad de recargarlo constantemente. Esto lo convierte en una opción ideal para aquellos que necesitan un rastreador confiable durante viajes largos o en situaciones en las que no hay acceso a una fuente de alimentación.

El GT350 también ofrece una serie de funciones de seguridad y control. Con la función de emergencia, los usuarios pueden enviar una señal de socorro en caso de una situación de peligro. Además, el rastreador cuenta con la capacidad de establecer fronteras de geo-fence, lo que permite a los usuarios recibir notificaciones cuando el dispositivo sale de un área predefinida. También cuenta con control de voz y una alarma SOS para situaciones de emergencia.

En resumen, el rastreador GPS personal GT350 de Concox es una opción confiable y versátil para aquellos que buscan una forma efectiva de rastrear y garantizar la seguridad de las personas. Con su tiempo de espera prolongado y sus funciones de seguridad avanzadas, este rastreador es una herramienta invaluable en diversas situaciones.

### Características destacadas:

- Tiempo de espera prolongado
- Función de emergencia
- Fronteras de geo-fence
- Control de voz
- Alarma SOS
